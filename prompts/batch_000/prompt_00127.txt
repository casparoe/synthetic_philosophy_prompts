So I've been going down this rabbit hole lately reading random blog posts about game theory and AI agents, and I stumbled on this idea called "program equilibrium" that kind of blew my mind. The basic gist as I understand it is that instead of two agents just picking strategies blindly like in a normal prisoner's dilemma, they actually get to read each other's source code before deciding what to do - so two programs could literally stare at each others literal code and use that to figure out whether the other one is trustworthy. Apparently this changes everything because now you can write something like "I will cooperate only if you're the kind of program that cooperates with programs like me" and it creates this weird self-referential loop that somehow lets rational agents escape the usual trap of always defecting.
