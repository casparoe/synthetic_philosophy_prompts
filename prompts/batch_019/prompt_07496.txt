A friend and I spent last night arguing over whether Kripke's rigid designators are doing any real philosophical work. My friend's position was that you can get exactly the same result by taking an ordinary definite description and either giving it wide scope over a modal operator or simply stipulating, à la David Kaplan's "dthat" operator, that it rigidly picks out whatever actually satisfies it; either way, the resulting term has precisely the modal profile of a rigid designator, so a proper name could just be such a "rigidified" description in disguise, and rigidity itself is a logical trick rather than a deep semantic fact. I argued that this cannot be right, since a rigidified description still secures its reference by way of some descriptive condition, whereas Kripke's cases of speakers who competently use names (e.g., "Gödel" or "Feynman") while being ignorant of, or simply wrong about, any uniquely identifying description show that names do not refer this way at all. Compare these two positions and say which side has the better of the argument, and explain what, if anything, the dispute shows about why statements like "Hesperus is Phosphorus" count as necessary a posteriori.
