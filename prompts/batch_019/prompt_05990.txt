And here, verbatim, is what she wrote:

**(a)** For Tarski, the Liar is paradoxical because natural languages are "semantically closed" — they contain their own truth predicate and enough resources (through indirect self-reference, e.g. via names or descriptions that pick out sentences) to construct a sentence that attributes falsity to itself. Given classical logic, any such closed language is inconsistent; this is essentially his undefinability theorem, that no sufficiently expressive consistent language can contain a predicate that correctly captures truth for all of its own sentences. His fix is to give up semantic closure: for any object language L0, truth-for-L0 is only defined in a distinct metalanguage L1, whose own truth predicate is only defined in L2, and so on up an infinite hierarchy, with the predicate at each level only applicable to sentences of the level below. This blocks the Liar because it simply can't be formulated using a single level's predicate. The cost is that this doesn't look anything like English, since we ordinarily use one word, "true," to talk about the truth of any sentence whatsoever, including sentences that themselves use the word "true" — so Tarski's hierarchy is really a recipe for building well-behaved formal languages, not a description of how truth actually works in natural language.

**(b)** Kripke wants to keep one language and one truth predicate Tr, but let Tr be partially interpreted rather than total. The construction starts with the extension and anti-extension of Tr both empty, and then repeatedly applies Kleene's strong three-valued scheme: given the current partial extension/anti-extension, work out which sentences containing Tr come out true, false, or undefined; add the true ones to the extension, the false ones to the anti-extension, and leave the undefined ones out of both, then repeat. The process is monotonic, so it eventually settles at a fixed point where another round changes nothing. Ordinary sentences ("snow is white") and sentences ascribing truth to them get in quickly — these are "grounded." The Liar sentence, though, never gets into either the extension or the anti-extension no matter how far the construction runs, since supposing it true makes it false and vice versa; every attempt to classify it flips it into the opposite camp, so once the fixed point is reached the construction has effectively settled into treating it as both true and false at once, which is exactly the kind of local, contained contradiction a language built on Kleene's non-classical scheme can tolerate without the whole thing exploding via ex falso. That's what lets Kripke get away with a single self-applicable Tr where Tarski couldn't. The Truth-teller sentence, "This sentence is true," is in the same predicament: it's also never grounded, since nothing in the base language ever forces a verdict on it either way, so it's stuck in the identical undefined, paradoxical status as the Liar within the fixed-point construction.

**(c)** The trouble is that we, from outside, want to describe the Liar as "not true" (since it never made it into the extension of Tr), but that description can't be imported into the object language itself: if we add a new predicate meant to express "false or undefined" — a genuine "untrue" predicate covering both ways of failing to be true — we can build a new Liar-type sentence using it, and that sentence generates exactly the same kind of paradox all over again, just one level up. So the very metalinguistic vocabulary ("gap," "undefined," "ungrounded") that Kripke needs in order to state his own theory can't be captured by his own object language's resources, which suggests the hierarchy Kripke wanted to avoid hasn't really been eliminated, just relocated to the relationship between the fixed-point language and the classical metalanguage used to describe it. I think this is a genuinely serious problem for the ambition of a single, universal, self-sufficient truth predicate, though the construction remains useful for showing how ordinary, non-paradoxical self-reference (like sentences about the truth of Nixon's Watergate-era assertions, where whether something is paradoxical depends on contingent facts rather than syntax alone) can be handled smoothly. The dialetheist, Priest-style response is really the mirror image of Kripke's own verdict on the Liar: where Kripke treats it as neither true nor false, Priest treats it as both true and false, and unlike Kripke takes this to be the literal truth about the sentence rather than an artifact of a three-valued construction — but the two views agree that the Liar is a counterexample to classical bivalence; they just disagree about which direction to relax it in.
