Ok so I've been building an agent at my startup (an LLM-based system that plans and executes multi-step tasks against a live environment), and this week we kept hitting the same annoying failure: after the agent takes an action, it has no principled way to decide which of it's other beliefs about the world still hold and which need re-checking. My cofounder, who has a philosophy degree, said "dude, that's literally the frame problem" and sent me Dennett's old robot-and-bomb thought experiment. Digging around more though, it looks like there are actually two different things going by that name: the original McCarthy/Hayes problem about frame axioms in formal logic (basically an efficient-representation problem for actions in a logical system), and this much broader "epistemic" version that Dennett, and later Fodor, talk about, which is really about how any mind decides what's relevant to update on at all. So: are these the same underlying problem showing up at two levels of description, or did the philosophers basically repurpose the name for a different, arguably harder problem? I want an actual compare-and-contrast here, not just a definition of "the frame problem" - and if you think they're genuinely different problems, tell me which one it sounds like my agent is actually running into.
