At my company, we have used the same fixed offline evaluation set of about a thousand recorded user sessions for the past two years to decide which candidate version of our ranking model gets promoted to production: whichever candidate scores highest on that set ships, replacing whatever it beat. This worked well at first, but lately a win on the evaluation set has stopped meaning much. Nothing about the set, the scoring code, or the promotion process has changed, and no one has touched held-out labels or taken any shortcuts, yet an increasing share of "winning" candidates show no real improvement once they serve live traffic, and a few have turned out to be quietly worse than the models they replaced.

One of our data scientists claims this is not bad luck but close to mathematically inevitable: it would keep happening even if every candidate were generated at random, and it is not particular to our evaluation set but would eventually happen with any fixed one. I cannot follow her reasoning. If the evaluation set genuinely tracks something real about quality, why would using it again and again to pick winners make it a worse guide to quality, given that the set itself and how we score against it have not changed? Is she right that this is a predictable pattern rather than a string of coincidences, and if so, could you walk me through why it happens? I would also like to know whether there is any real remedy short of discarding the evaluation set and building a fresh one every time we need a trustworthy comparison.
