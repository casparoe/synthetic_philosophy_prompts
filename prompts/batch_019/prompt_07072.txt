Question (20 points): Graham Priest argues, on the basis of the Liar sentence, that some contradictions are true -- a view he calls dialetheism and develops in "The Logic of Paradox" and in *In Contradiction*. (a) Reconstruct the argument from the Liar sentence to the conclusion that it is both true and false. (b) Explain why Priest thinks accepting this conclusion does not commit him to trivialism, the view that every sentence whatsoever is true. (c) Priest's own logic for reasoning about true contradictions is LP, the Logic of Paradox. Explain what it means for a logic to be paraconsistent, what it means for a claim to be dialetheist, and how LP's specific technical features are meant to secure the former in the service of the latter.

Student's answer: The Liar sentence, L, says of itself that it is false ("This sentence is false"). Suppose L is true: then, since that is what L says, L is false. Suppose instead L is false: then, since that is exactly what L asserts of itself, L is true. Either assumption forces us into the other, so it looks as though L is both true and false at once. Classically this is treated as a problem to be explained away -- for instance by denying that L expresses a genuine proposition, or by barring sentences from talking about their own truth via a Tarskian hierarchy of languages. Priest's dialetheist move is to stop explaining the result away and instead accept it at face value: L really is both true and false, a dialetheia.

The obvious objection is that classical logic lets you derive anything at all from a contradiction: from A, infer A-or-B by addition, then from not-A and A-or-B infer B by disjunctive syllogism, for arbitrary B. If the Liar hands us one true contradiction and classical logic is still in force, we get trivialism -- every sentence is true -- which is absurd. Priest avoids this by pairing dialetheism with a non-classical, paraconsistent logic on which a contradiction stays local instead of spreading to the rest of the language. His own system, LP, does this by adding a third semantic value, "both," alongside true and false, and by giving up the law of excluded middle for sentences like the Liar, so that L can simply be assigned this third value instead of being forced into true-or-false. Because "both" counts as a designated value, L comes out true, which is what dialetheism requires; and because not every sentence is forced to be determinately true or false, the contradiction cannot explode into trivialism the way it classically would. In this sense LP is paraconsistent because it is dialetheist: giving up excluded middle in order to accommodate true contradictions like the Liar is exactly what keeps the logic from exploding, so a logic's being paraconsistent in Priest's sense already amounts to a commitment to dialetheism.
