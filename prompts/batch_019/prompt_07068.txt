And here's what my classmate wrote:

"Kripke's puzzle in Naming and Necessity is that some sentences, like 'Water is H2O' or 'Hesperus is Phosphorus,' seem to be necessarily true (true in every possible world) even though we only found out they were true through empirical investigation, i.e. a posteriori. Two-dimensional semantics is supposed to explain this without abandoning the traditional idea that necessity and apriority should track each other.

The key move is to give every sentence two intensions rather than one. The primary intension is a function from possible worlds to truth-values that we get by holding fixed how the actual world turned out and asking what happens as we vary the world counterfactually from there — so for 'water is H2O,' since we've already fixed that water is H2O around here, the primary intension comes out true in absolutely every world we plug in, because water just is H2O rigidly, in this world and all the counterfactual ones. That's why the sentence is necessary. The secondary intension instead asks us to treat each world as a candidate for being the actual world in the first place, before we know anything empirical — so we imagine a world where the clear liquid in the rivers is XYZ rather than H2O, and relative to that world 'water is H2O' comes out false. Since there are candidate-actual worlds where it's false, the secondary intension is contingent, and that contingency is exactly what our a posteriori knowledge is tracking: we had to rule out the XYZ-world empirically before we could be sure we were in the H2O-world.

So on this picture, necessity and apriority still line up, just not both applied to the same intension: the sentence is necessary with respect to the primary intension and a posteriori (not a priori) with respect to the secondary intension, which is exactly what Kripke's examples require. The strategy generalizes to explain contingent a priori cases too, like 'the meter stick is one meter long,' in the mirror-image way.

The main problem with this whole approach, pointed out by Kripke himself in the same lectures, is that it only works if a name or natural kind term like 'water' comes packaged with some a priori-accessible description that fixes what counts as water in each candidate world (something like 'the clear drinkable stuff around here'), and Kripke's whole point earlier in the book was that ordinary speakers don't carry around any such description and reference works causally instead, so the objection is that two-dimensionalism smuggles descriptivism back in through the side door."
