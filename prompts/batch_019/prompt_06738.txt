As a backend engineer, I run into this all the time: two objects can return true from equals() -- every field matches -- while remaining separate instances at different memory addresses. The runtime insists there are two of them, even though nothing about their properties distinguishes one from the other. That looks like an everyday, working counterexample to Leibniz's identity of indiscernibles: two numerically distinct things sharing every property anyone could point to. So was Max Black's thought experiment about two symmetric, indiscernible spheres actually establishing something new, or is it just a more elaborate way of stating what any equals() override already demonstrates on every program run?
