I'm a philosophy PhD student TAing a graduate seminar on formal decision theory (cross-listed with computer science) this term, and I'd like a second, independent pass on a student's exam response before I record a grade for it. The question and the response are below.

Question (20 points total): Tennenholtz (2004) shows that if players in a one-shot game submit programs, rather than actions, that can read one another's source code before producing a move, then cooperation can be supported as a Nash equilibrium of the resulting "program game" — even in a single play of the Prisoner's Dilemma.

(a) [8 pts] Describe a construction that achieves this, and explain precisely in what sense the result is analogous to the folk theorem for repeated games.
(b) [8 pts] The program FairBot cooperates with any program provably disposed to cooperate with it; two copies of FairBot playing each other achieve mutual cooperation via an argument that invokes Löb's theorem. Explain how this construction avoids the infinite regress that a naive "simulate the opponent" approach would run into.
(c) [4 pts] Does either construction show that cooperation is the uniquely rational choice in a one-shot Prisoner's Dilemma? Defend your answer in a short paragraph.

Student's response:

Tennenholtz's result works by moving from a game in which players choose actions to one in which they choose programs that can read one another's source code before producing a move. This is essentially a formalization of the same insight behind Axelrod's round-robin tournaments: once programs can condition their behavior on one another in this way, outcomes that are unstable when the underlying game is played once become stable, in much the same way the folk theorem shows that cooperation becomes an equilibrium once a stage game is repeated indefinitely between sufficiently patient players. The standard construction has each player submit a program that cooperates just in case the opponent's submitted source code is identical to its own, and defects otherwise; since any unilateral deviation to a different program is detected and punished with defection, mutual cooperation is a Nash equilibrium of the program game even though the Prisoner's Dilemma is played only once. As with the folk theorem, what can be supported this way is not an arbitrary payoff profile but any feasible, individually rational one, with mutual defection serving as the relevant threat point.

FairBot goes further by cooperating with any program that is provably, rather than merely syntactically, disposed to cooperate with it, which lets it cooperate with a wider class of partners than the identity-checking program can. Two copies of FairBot facing each other would, on a naive approach, have to simulate one another's behavior to see whether the other cooperates, inviting an infinite regress of the form "I cooperate if you cooperate if I cooperate...". The construction avoids this by using Löb's theorem to let each FairBot's code refer to its own source within the very statement it is trying to prove, so that instead of simulating one another, the two programs can instead establish, in a single finite derivation within a system such as Peano Arithmetic, that they cooperate.

Neither result shows that cooperation is the uniquely rational choice in a one-shot Prisoner's Dilemma. Both are existence results: they show that mutual cooperation is among the Nash equilibria of the program game, not that it is the only one, since two copies of a program that always defects regardless of input form an equally good equilibrium of the same program game. So the question of which program a rational agent should submit simply reproduces, one level up, the equilibrium-selection problem already posed by the original one-shot game.
