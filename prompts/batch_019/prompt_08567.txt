"Skolem's Paradox arises from an apparent clash between the Löwenheim–Skolem theorem and Cantor's theorem. ZFC is a theory in a countable first-order language, so if it has a model at all, the Compactness Theorem guarantees it has a countable model M. But ZFC proves that uncountable sets exist — for instance, it proves that the power set of ω is not equinumerous with ω, via Cantor's diagonal argument. So M must contain some set that M itself thinks is uncountable, even though M has only countably many elements total. That looks like a flat contradiction: how can a set be uncountable if it lives inside a countable structure?

The standard resolution is that 'countable' and 'uncountable' aren't absolute properties of a set but are relative to a model. From outside M, since M's whole domain is countable, there really does exist a bijection between ω and M's version of the power set of ω. The catch is that this bijection isn't itself an element of M — M just doesn't contain the function that would witness that set's countability. Internally, 'X is uncountable' just means 'there is no bijection between X and ω belonging to this model,' so M is being completely consistent by its own lights when it calls that set uncountable; M isn't making an error, it just has a thinner stock of functions to draw on than the background universe does. Skolem introduced this observation back in the 1920s, and having shown that the apparent contradiction dissolves once cardinality is recognized as model-relative rather than absolute, he took the matter to be fully settled — once you see the model isn't missing anything by its own standards, there's nothing further to explain and no real threat to set theory as a foundation. Some philosophers, notably Putnam, later tried to repurpose this technical fact into a general argument against metaphysical realism, but that's a further, more controversial step beyond the mathematics itself."
