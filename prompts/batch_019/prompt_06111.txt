I TA a graduate seminar in formal epistemology, and this term's take-home included a question on Jeffrey conditionalization -- a topic I'm embarrassed to say I first encountered on LessWrong, working through the old Sequences and later the discussions of radical probabilism, rather than in an actual philosophy class. Below is the question and one student's answer. I'd like your assessment before I return grades.

Question:

Jeffrey conditionalization generalizes strict conditionalization to evidence that is received with less than certainty.

(a) State Jeffrey's updating rule for a partition {E1, ..., En}, and show that it reduces to strict conditionalization when the agent becomes certain of one cell of the partition.

(b) State precisely the "rigidity" (invariance) condition that licenses the rule.

(c) Jeffrey conditionalization is, in general, not commutative: updating on a partition {E1, ..., En} and then on a different partition {F1, ..., Fm} need not give the same result as updating in the reverse order. Explain why this can happen, and say what, if anything, it shows about the rule.

Student's answer:

(a) If {E1, ..., En} is a partition and the agent's new degrees of belief in the cells are P'(E1), ..., P'(En), Jeffrey's rule says that for any proposition A, P'(A) = Σ P(A|Ei)·P'(Ei), summed over i. If the agent becomes certain of some Ek, so that P'(Ek) = 1 and P'(Ei) = 0 for every other i, every term but one drops out and we're left with P'(A) = P(A|Ek), which is just strict conditionalization on Ek.

(b) The rule is licensed by rigidity: the requirement that the partition's probabilities conditional on the target proposition stay fixed across the learning experience, i.e. P'(Ei|A) = P(Ei|A) for every proposition A and every cell Ei. Because these conditional probabilities don't move, we're entitled to carry the old ones over into the updating formula.

(c) Rigidity is only assumed relative to whichever partition you happen to be updating on at the time. If you update on {E1, ..., En} first, you've frozen the conditional probabilities relative to that partition, but nothing guarantees that the conditional probabilities relative to {F1, ..., Fm} are still what they were before -- so updating on F second starts from a different place than it would have if you'd updated on F first. Since the two orders can yield two different final credence functions given the very same total evidence, at least one of them has to be wrong: an agent can't have two different rational credences in the same proposition after taking in the same evidence, so real applications of Jeffrey conditionalization need to fix an update order in advance, or else the result is simply incoherent.
