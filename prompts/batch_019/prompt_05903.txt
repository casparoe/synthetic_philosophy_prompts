"Frege noticed that a statement like 'a = a' is knowable just by reflecting on what the identity sign means, so it doesn't teach us anything new, whereas a statement like 'a = b' can express a real discovery, such as finding out that the morning star and the evening star are actually the same object, namely Venus. This is puzzling if identity statements simply assert that an object is identical with itself, because then 'a = b' should be exactly as trivial as 'a = a' whenever it happens to be true. Frege's solution was already present in his earlier Begriffsschrift, where he first proposed that names have both a sense and a reference: the reference is the object a name picks out, while the sense is the particular way that object is presented to us. 'The morning star' and 'the evening star' have the same reference, since they pick out the same planet, but they present that planet differently, so they differ in sense, and that difference is what makes identifying them informative rather than trivial. In 'On Sense and Reference' itself, Frege then refined this picture by insisting that identity, strictly speaking, is a relation between objects rather than between the signs used for them, which is precisely what allows an identity statement to be about the world rather than merely about our choice of notation.
