"State Skolem's Paradox and explain precisely why it does not amount to a genuine contradiction in ZFC. Be sure to say what work the distinction between a model's internal perspective and our external perspective is doing in the resolution."

The answer my fictional student turned in (worth 20 pts):
"By the (downward) Löwenheim–Skolem theorem, since ZFC is a first-order theory in a countable language, if ZFC is consistent then it has a countable model M. But Cantor's theorem, which is provable in ZFC, tells us the power set of ω is uncountable. So M must contain some set that it thinks is the (uncountable) power set of ω, even though M itself only has countably many elements. This looks contradictory -- how can a countable model contain an uncountable set?

The resolution is that "countability" isn't an absolute property of a set, its relative to the model evaluating it. From our external standpoint there really is a bijection between M's version of the power set of ω and the naturals, since M itself is only countable and that "power set" is just one of M's countably many elements. But M has no way of defining a bijection between that set and ω, so internally M correctly judges, by its own lights, that the set is uncountable. This is basically the same phenomenon Gödel exploited in the incompleteness theorems, where a statement can be true but unprovable in a system -- here a set can be really countable but "uncountable" inside the model."
