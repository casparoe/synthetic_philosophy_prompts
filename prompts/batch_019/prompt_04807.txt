For my philosophy club's reading this month, I've been going through Galen Strawson's Basic Argument against moral responsibility, and I want to make sure I've got the logic right before I write up my notes. As I understand it, the argument says that to be truly responsible for an action you would have to be responsible for the mental character that produced it, which in turn requires being responsible for whatever produced that character, and so on backward in a regress that can never be completed, since at some point there was no self yet formed to be doing the choosing — in short, no one can be causa sui, the cause of themselves, in the way true responsibility would require. Since the whole regress seems to depend on each link being causally fixed by the one before it, wouldn't the discovery that some neural events involve genuine quantum indeterminacy give us a way out, by breaking that chain of prior causes and letting at least some choices originate with the agent rather than being inherited from further back?
