Here's a rabbit hole on Godel's ontological argument. Sobel's modal collapse objection works by taking literally any actually-true proposition Q, noting that a God-like being trivially has the (constant) property 'being such that Q,' and then using the fact that God-likeness has already been proven to be that being's essence -- where an 'essence' is defined so it has to necessitate every property the being has, not just the positive ones -- to conclude that Q is necessary. Since Q was arbitrary, every truth turns out necessary, which is obviously nuts. Anderson and others have floated fixes for this; a natural one is to weaken the essence clause so it only has to necessitate the beings positive properties, not literally all of them. Can you argue that this fix doesn't actually save the proof? Specifically, argue that once you restrict things this way, the argument can no longer show it's the very same being that necessarily exists in every possible world -- only that something-or-other answers to 'God-like' in every world. Don't just assert that part, actually reconstruct which bit of the original derivation was doing the identity-securing work, and show the fix loses it.
