Here's the core of the argument I want to make. Supervaluationists say "Fatima is tall" is true iff it's true on every admissible way of sharpening "tall" into a precise cutoff, false iff false on all of them, and neither-true-nor-false if it varies across sharpenings — which is how they get to keep "Fatima is tall or Fatima is not tall" as a logical truth even in borderline cases, since some sharpening always makes one disjunct true. My issue is with what happens a level up: "admissible sharpening" is itself a vague notion (there's no sharp line between which precisifications count as admissible), and so is "definitely." So the supervaluationist needs a story about this higher-order vagueness too. But it looks like either (a) they stack another round of supervaluation over the space of admissible sharpenings, which just kicks off a regress of D-operators that never bottoms out anywhere classical, or (b) at some point there IS a determinate fact about which sharpenings really count as admissible, in which case there's a precise (if hidden/complicated) boundary doing the work after all — which is just the epistemicist's unknowable sharp cutoff wearing a different hat. Either way it seems like supervaluationism doesn't so much solve the sharp-boundary problem as relocate it and hope nobody looks too closely.

Does this actually land, or is it a well-known move that already has a standard rebuttal (I have this nagging feeling Rosanna Keefe deals with something like it in her book, but I never tracked down exactly how)?
