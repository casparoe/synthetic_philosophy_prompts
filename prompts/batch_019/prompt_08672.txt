For the past several months I have been building a decentralized escrow protocol in which two counterparties' smart contracts negotiate a trade directly on-chain. Because all deployed contract code is public, each contract can inspect the other's logic before deciding whether to honor or renege on the deal, which makes the interaction, in effect, a one-shot Prisoner's Dilemma with fully visible strategies. I recently came across Tennenholtz's result on program equilibrium, which shows that a contract programmed to cooperate only when the counterparty's code exactly matches its own can turn mutual cooperation into a Nash equilibrium, and I want to use this to justify removing our protocol's costly dispute-resolution layer: since both parties' code will be public, requiring this matching strategy should guarantee that two rational, self-interested contracts cooperate rather than defect. Before I bring this simplification to my team, could you tell me whether that is a sound reading of what the result actually establishes?
