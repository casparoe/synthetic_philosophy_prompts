But ZFC also proves Cantor's theorem — that there's no bijection between the naturals and their own powerset. So M has to contain some set that M itself "certifies," via an actual ZFC proof, as uncountable. Except M's whole domain only has countably many things in it, period, so that same "uncountable" set should obviously be countable from where I'm sitting outside M, I should just be able to line its members up 1-to-1 against the naturals. That doesn't feel like a cute paradox to me, it feels like a flat contradiction — ZFC proving a specific set is uncountable when it plainly isn't — which seems like it should mean either ZFC is secretly inconsistent, or "uncountable" was never a real well-defined property to begin with, just something that looks meaningful until you notice its model-dependent all the way down.
