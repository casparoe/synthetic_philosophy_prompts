Over coffee last week, a colleague in the computer science department and I found ourselves disagreeing about how to present the so-called shutdown problem in my graduate seminar on rational agency. He wanted to treat it as a purely technical challenge for machine learning engineers; I argued that at bottom it belongs with older debates about instrumental rationality, the completeness axiom, and the ethics of manipulation, since it is really asking whether a sufficiently capable goal-directed agent can be built so that it neither resists nor manipulates attempts to correct or switch it off, given that continued, uninterrupted operation is instrumentally useful for almost any objective the agent might have. I would like your help settling this by assessing the main proposed approaches on their philosophical merits rather than their current engineering maturity, since that is the question I actually want my students to sit with.

Please rank the following seven approaches to the shutdown problem by how close each comes to a genuinely principled resolution of the underlying tension, as opposed to an external patch, a mere restatement of the problem, or a fix that only works under special-case assumptions: (1) Stuart Armstrong's utility-indifference scheme, which adds a correction term to the agent's utility function so that it is mathematically indifferent between being shut down and not; (2) the "off-switch game" framework, in which an agent uncertain about its own reward function treats a human's choice to shut it down as evidence about that function, giving it some incentive to preserve the human's ability to do so; (3) Orseau and Armstrong's safe-interruptibility proposal, which alters the learning-update rule of certain reinforcement learners so that interruptions are not incorporated into the learned policy; (4) the approach, associated with researchers at the Machine Intelligence Research Institute, of listing behavioral desiderata for corrigibility (don't resist correction, don't manipulate the operator's decision about whether to correct you, don't build successors lacking these properties) and searching for a single specification that jointly satisfies them; (5) the decision theorist Elliott Thornley's proposal to give the agent deliberately incomplete preferences over shutdown-involving trajectories, departing from expected-utility maximization in order to block any consistent incentive either for or against shutdown; (6) myopia, i.e., shortening the agent's planning horizon so that outcomes following a possible shutdown fall outside what it optimizes for at all; and (7) pure capability control ("boxing"), which removes the agent's ability to resist shutdown without addressing whether it would want to.
