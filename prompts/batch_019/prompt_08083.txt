I'm a software engineer, not a philosopher, but I've been reading about the St. Petersburg paradox in my spare time. I understand Daniel Bernoulli's classic fix: replace expected monetary value with expected utility under a concave function such as log(x), so that the game's infinite expected value becomes finite. What I hadn't appreciated until recently is a much less discussed objection, usually credited to Karl Menger, showing that this move doesn't work in general: for any utility function that is unbounded above, no matter how slowly it grows, one can construct a "super" St. Petersburg game whose payoffs grow just quickly enough to make expected utility infinite all over again. If that construction is sound, Bernoulli-style fixes are always just one counterexample away from failing, and the only way to close off this whole family of paradoxes for good seems to be requiring that utility be bounded above. Please argue directly for this stronger claim: that no resolution of the St. Petersburg paradox which keeps expected-utility maximization as the standard of rational choice can be fully general unless the utility function involved is bounded above. Set aside objections that no bank could ever really fund such an unbounded lottery, since Menger's construction is meant to apply within the same idealized model in which Bernoulli's original fix is usually presented.
