**Question:** Skolem's Paradox arises from applying the Löwenheim–Skolem theorem to Zermelo–Fraenkel set theory (ZFC). State the paradox precisely, explain why it is not a genuine contradiction, and be explicit about exactly which notion of "countable" is doing the work at each stage of the resolution. Your answer should also address whether the paradox depends on working with non-transitive, Henkin-style models of ZFC, or whether it arises for transitive ∈-models as well.

**Student's answer:** By the downward Löwenheim–Skolem theorem, since the language of ZFC is countable, if ZFC is consistent then it has a countable model M. But ZFC proves Cantor's theorem, so M satisfies the sentence asserting that P(ω), the power set of the natural numbers, is uncountable. This looks contradictory: surveyed from outside, M has only countably many elements, and yet it contains a set that it takes to be uncountable.

The resolution is that countability is not an absolute property of a set but is relative to the model in which the claim is evaluated. To say that a set X is countable is to say that a bijection between X and ω exists, and an existential claim evaluated in M is only witnessed by elements of M itself. M is right that it contains no bijection between its version of P(ω) and ω — if it did, M would fail to satisfy Cantor's theorem, which is impossible given that M ⊨ ZFC. But because M has only countably many elements in total, its version of P(ω) is, viewed from outside, genuinely a countable set: a bijection between it and ω does exist, but that bijection is simply not among M's elements, so M cannot use it as a witness and correctly denies its existence internally.

This phenomenon depends essentially on M being a non-transitive, Henkin-style model of the sort delivered directly by the completeness theorem. If we instead built a transitive model — say, by taking a countable elementary submodel of some V_α and Mostowski-collapsing it — the required bijection would already be sitting inside V_α at the relevant rank, so the collapse would simply carry it along; a genuinely transitive ∈-model correctly computes its own power sets and so cannot misjudge their cardinality the way an abstract Henkin model can.

What the paradox ultimately shows is that "uncountable" is not a genuine, absolute property of a set at all, but only ever a relation between a set and whichever model happens to be under discussion — precisely the moral Skolem himself drew from the result.
