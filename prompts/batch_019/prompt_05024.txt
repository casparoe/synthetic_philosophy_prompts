"Explain Skolem's paradox. State the relevant form of the Löwenheim–Skolem theorem, show how it generates an apparent contradiction when applied to a countable model of ZFC, explain why this is not in fact a genuine contradiction, and briefly state the philosophical moral Skolem himself drew from it. (20 points)"

Here is the answer I've been asked to grade:

"By the downward Löwenheim–Skolem theorem, any first-order theory in a countable language that has an infinite model also has a countable model. ZFC is axiomatized in the countable language {∈}, so if ZFC is consistent it has a countable model M. Since ZFC proves Cantor's theorem — that there is no bijection between ω and its power set — and M satisfies every theorem of ZFC, M must contain some set that M thinks is P(ω), and M 'believes' there is no bijection between that set and its version of ω. Yet M itself, viewed from outside, has only countably many elements altogether, so the very set M calls uncountable is, from our vantage point, just a countable set. This is Skolem's paradox.

There is no real contradiction here because M must be a non-standard model: to make room for a set that looks uncountable from the inside while the whole domain is countable from the outside, M's version of the natural numbers has to run past every genuine finite number into nonstandard elements, and it is this nonstandard arithmetic that keeps M from ever packaging the external enumeration into an object it recognizes as a set. Put more generally, whether a set counts as countable is not absolute; it depends on which bijections happen to live inside the particular nonstandard model in question, not on some further fact about the set an sich.

Skolem took this to establish exactly the moral Putnam would later build into a full argument against metaphysical realism: since no first-order theory can fix a determinate, absolute answer to how many sets there are, a notion like uncountability only ever makes sense relative to a model, never absolutely outside of one."
