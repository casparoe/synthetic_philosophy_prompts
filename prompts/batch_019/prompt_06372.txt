I'm about two-thirds into a novel with a pretty unreliable narrator, and for the dialogue I've been using an LLM as a kind of brainstorming partner - feeding it a character sketch and seeing what voice comes out the other end. What keeps messing with my head is how totally the thing seems to *become* whoever I've described, then drops them completely the second I switch to a different character in the next message, like an actor with zero memory of the last role once the curtain falls. My writers' group got into an actual argument about this last week after one member sent around an essay by someone writing under the name "janus" (a LessWrong post, I beleive, called "Simulators") arguing that a model like this isn't an agent with it's own goals at all - it's more like an engine that can run lots of different "simulacra" (characters), none of which is really "it." That matched my experience pretty well. But another friend in the group said this sounds a lot like Dennett's old intentional stance - ascribing beliefs and desires to a system whenever doing so helps predict it, without any claim that the system actually has an inner life.

So here's my actual question for you: compare the "simulator" framing of LLMs with Dennett's intentional stance (bring in the design stance too, if it's useful) as ways of explaining what's happening when a model slips into character. Is there a genuine theoretical difference here, or is "simulator theory" basically the intentional stance wearing a new hat for the GPT era? Does that distinction hold up, or am I just forcing a tidy parallel onto something messier?
