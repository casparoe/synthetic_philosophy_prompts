"Gödel's first incompleteness theorem shows that for any consistent formal system M powerful enough to express arithmetic, there is a sentence G(M) — essentially, 'this sentence is not provable in M' — that is true but cannot be proved inside M. Lucas's argument in 'Minds, Machines and Gödel' turns this into a case against mechanism: if a human mind's mathematical reasoning could be captured by some formal system M, then since we can see, by reasoning about M from the outside, that G(M) must be true given that M is consistent, we know something M itself cannot prove. Since this works for whatever M is proposed as a model of the mind, no consistent formal system can capture everything the mind can know to be true, so the mind cannot be identified with any Turing machine. This was, in fact, exactly the moral Gödel himself drew from his own theorems, and it is what later led Lucas, and then Penrose in The Emperor's New Mind and Shadows of the Mind, to spell the argument out as a refutation of the thesis that the mind just is a computer program.

A natural objection is that the machine could simply be handed G(M) as a new axiom, giving an enlarged system M' = M + G(M), so it can now prove what it previously couldn't. This does not save mechanism, though, because M' is just as much a legitimate formal system as M was, so it has its own Gödel sentence G(M'), which M' cannot prove but which we can again see to be true. No matter how many times the machine is patched this way, the mind can always generate a sentence one step ahead of it, so the machine can never be extended to match the mind's output.

Putnam's response is that people are not perfectly consistent reasoners either — we make mistakes and sometimes hold contradictory beliefs without noticing — so it isn't obvious that comparing an idealized, consistent machine to a real human mind is fair to begin with. This doesn't end up rescuing mechanism, though: Lucas can simply say he means an idealized, error-corrected version of human reasoning, and in any case we obviously do know we're consistent, since we don't go around asserting things like '0=1'. So Putnam's worry doesn't really undermine the argument."
