As a software engineer who occasionally dabbles in machine learning, I recently learned that Solomonoff induction gives Occam's razor a rigorous mathematical foundation: among all programs that reproduce the data observed so far, the one with the lowest Kolmogorov complexity provably has the highest probability of being the correct explanation. Since this seems to settle, in a principled and machine-independent way, which hypothesis we should prefer, why do machine learning teams still spend so much effort on cross-validation and held-out test sets instead of simply selecting whichever model has the smallest compressed description length?
