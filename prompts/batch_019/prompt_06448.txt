My partner's answer:

"The Liar sentence, 'This sentence is false,' is paradoxical because assuming it's true makes it false, and assuming it's false makes it true. Tarski diagnosed the underlying problem as natural language being 'semantically closed': it contains its own truth predicate and lets sentences refer to themselves without restriction. His fix, at least for formal languages, is to separate the object language, which talks about the world, from a metalanguage, which is the only place a truth predicate for the object language can be defined. Because the object language has no predicate that applies to its own sentences, no Liar sentence can be built inside it — the cost is an infinite hierarchy of languages, each one only able to talk about the truth of the language below it.

Kripke found this too restrictive, since English obviously does apply 'true' to English sentences all the time without collapsing into contradiction. His alternative starts from a 'ground language' with no truth predicate at all, then builds up the extension of a truth predicate in stages, using a three-valued (Strong Kleene) logic that lets sentences come out true, false, or undefined. At each stage a sentence gets a definite value only if the sentences it depends on already have one; repeating this eventually reaches a fixed point where no more sentences change value. Sentences that receive a value at some stage are 'grounded'; the Liar sentence never does, so it stays 'ungrounded' forever — neither true nor false, rather than simply false.

A useful companion case is the Truth-teller, 'This sentence is true.' Like the Liar, it comes out neither true nor false in Kripke's minimal fixed point, since nothing in the ground language settles its value either — and it is exactly as paradoxical as the Liar, just a mirror-image case of a sentence whose truth depends on nothing but itself.

Because Kripke lets a single language contain its own truth predicate and handles self-reference with a third truth-value instead of banning it outright, his theory is a genuine improvement on Tarski's hierarchy — and it disposes of the Strengthened Liar ('this sentence is not true') as well, since that sentence is just one more ungrounded, gappy sentence in the same fixed point as the original Liar. Kripke's construction therefore gives a complete, self-contained account of truth for a single language, with no need for Tarski's endless ladder of metalanguages."
