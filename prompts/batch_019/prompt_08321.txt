Compare epistemicism and supervaluationism as treatments of vagueness, focusing specifically on how each accommodates higher-order vagueness—the fact that the boundary between the cases where a vague predicate clearly applies, the borderline cases, and the cases where it clearly fails to apply is not itself sharply drawn. Supervaluationists standardly respond to this by relativizing truth to a set of admissible interpretations (a sentence counts as true just when it is true on all of them) and then handling borderline-ness at any order via an iterated "definitely" operator. Does this maneuver actually succeed in avoiding a sharp, if unknowable, cutoff at some level—the very thing epistemicism candidly posits—or does it merely relocate that same commitment into facts about which interpretations count as admissible? Justify your answer with reference to this specific higher-order issue, rather than to the more familiar first-order complaints against each view (e.g., that epistemicism posits brute unknowable facts, or that supervaluationism sacrifices truth-functionality).
