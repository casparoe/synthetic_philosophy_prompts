I TA a graduate seminar in decision theory, and before I enter a final grade I'd like an independent assessment of how one exam answer should be scored. The question concerned the Pasadena paradox, a St. Petersburg-style puzzle that circulates on rationalist blogs now and then as a curiosity, but that rarely gets the rigorous treatment an exam setting demands.

The question, worth 20 points, read as follows:

The Pasadena game is defined as follows. A fair coin is tossed repeatedly until it first lands heads; suppose this first happens on toss n. The player then receives a payoff of (-1)^(n+1) · (2^n/n) dollars.

(a) [4 points] Compute the expected value of the game by summing payoff times probability over n = 1, 2, 3, ... in the natural order.
(b) [8 points] Decision theorists typically deny that this sum is the game's expected value, or indeed that the game has a well-defined expected value at all. Explain why, and contrast this with the sense in which the St. Petersburg game's expected value is 'infinite.'
(c) [8 points] Several authors hold that the moral of the St. Petersburg paradox is that rational agents should evaluate gambles by their expected utility, computed using a bounded utility function, rather than by their expected monetary value. Does adopting this response also dispose of the Pasadena paradox? Explain.

Here is the student's answer, in full:

"The probability that heads first appears on toss n is 1/2^n, so summing payoff times probability over n gives 1 - 1/2 + 1/3 - 1/4 + ..., the alternating harmonic series, which converges to ln 2. That answers (a).

But this convergence is only conditional: the series of absolute values, 1 + 1/2 + 1/3 + ..., is the harmonic series, which diverges. By the Riemann rearrangement theorem, a conditionally convergent series can be reordered to sum to any real number we like, or made to diverge, simply by changing the order in which we add up the same countably many terms. Since an expectation shouldn't depend on an arbitrary choice about which order to add up outcomes in, the Pasadena game doesn't really have an expected value of ln 2, or of anything else. This is different from St. Petersburg, where every rearrangement of the (all-positive) terms still diverges to infinity, so 'the expected value is infinite' is at least a stable verdict across every way of summing. Pasadena's trouble is subtler: it isn't that the expectation is too big, but that there is no well-defined answer at all.

That said, this puts Pasadena in the same family as St. Petersburg, and it should yield to the same medicine. As Bernoulli and later Menger showed, the fix for St. Petersburg is to stop pricing the gamble in dollars and price it in a bounded utility function instead, such as the logarithm of the payoff; once you do that, the resulting series of expected utilities converges nicely and the paradox evaporates. The same trick should defuse Pasadena for the same reason: once payoffs are run through a bounded function like the log, no term can grow large enough to generate the rearrangement problem in the first place, so a well-defined expected utility is restored."
