"Explain the Dutch Book argument for probabilism. Your answer should cover both the basic Dutch Book theorem and its converse, and explain what work each part does in the overall case for probabilism."

and here's the answer one student gave:

"The Dutch Book argument tries to show that an agent's credences ought to conform to the probability axioms. We interpret credence via fair betting prices: if my credence in A is p, then p is the price at which I'm indifferent between buying and selling a bet that pays $1 if A is true and $0 if it's false.

The Dutch Book theorem (Ramsey/de Finetti) says that if an agent's credences violate the probability axioms -- say, their credence in A and their credence in not-A don't sum to 1 -- then a bookie can construct a set of bets, each one fair by the agent's own lights, that together guarantee the agent a loss no matter how things turn out. So incoherent credences guarantee exploitability.

The converse Dutch Book theorem just falls out of this by contraposition: since 'incoherent implies exploitable,' 'not exploitable' must imply 'coherent' -- which is exactly the converse theorem. Together the two results give us a biconditional, exploitable iff incoherent, and this is supposed to show that probabilistic coherence is a requirement of rationality, since no rational agent should knowingly walk into a money pump like that.

One natural objection is that this whole approach presupposes agents have sharp, precise credences to begin with -- it's a lot less obvious how to run the argument if credences are represented by sets of probability functions rather than a single one."
