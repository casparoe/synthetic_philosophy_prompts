Here's the passage:

"Look," Odile said, wrapping both hands around a coffee that had gone lukewarm an hour ago. "The old problem was always enforcement. You sign a treaty, but nothing stops either side from cheating the second it's convenient, so nobody ever really believes the paper. What's different now is that these things aren't people, they're programs, and a program you can actually open up and read."

"Back in the early 2000s a game theorist, Tennenholtz I think, pointed out that if two players in a prisoner's dilemma submit programs instead of moves, and each program gets to read the other one's source code before it decides anything, you can write a program that says, in effect: cooperate if and only if you're looking at a mirror. Two copies of that program, staring at each other, cooperate, because neither one can gain by secretly swapping in a defector — the moment it does, the mirror breaks and they both lose."

"Problem is, that trick is brittle as glass. Rename a variable, compile it with a different flag, and the mirror doesn't recognize itself, and you're back to mutual defection. Which is why the version we actually took to Geneva is descended from a fix people found about a decade later using Löb's theorem, Löb being the same guy behind the incompleteness stuff. Instead of demanding an exact copy of itself, the program searches, for a fixed amount of effort, for a proof that the other program cooperates with it. Because of what Löb's theorem guarantees about that kind of self-referential proof search, if both sides are running provers like that, each one's search actually succeeds, and they both cooperate — not because they're twins, but because each one can certify the other's good behavior in finite time. The friendliest version of this got called something like 'FairBot.' There's a warier cousin too, built to cooperate with anything that would prove out safe, but not to get taken for a sucker by something that cooperates with literally everyone."
