I help run a scrappy little AI safety reading group (basically our own homebrew version of the BlueDot AGI safety fundamentals course), and for this week's homework I set the group the following question:

"MIRI's 2015 corrigibility paper (Soares, Fallenstein, Yudkowsky & Armstrong) proposes 'utility indifference' as a fix for the shutdown problem. Hadfield-Menell et al's off-switch game is usually cited in the same breath as another proposed fix for the same problem. In a short answer: (a) explain the mechanism by which utility indifference removes an agent's incentive to fight the shutdown button, (b) explain how the off-switch game's mechanism for getting shutdown-compliance actually differs from utility indifference, and (c) note one thing that still isn't guaranteed by either approach."

One of the group members (call them Alex) turned in this answer, and before I send back feedback I wanted a sanity check, since im not 100% sure I'm being fair to them:

"A pure expected-utility maximiser with a fixed goal has an instrumental incentive to resist being shut off, since being shut off pretty much guarantees it can't achieve that goal — this is just the standard Omohundro/Bostrom 'instrumental convergence' point. Utility indifference deals with this by adding a correction term to the agent's utility function that exactly cancels out, in expectation, whatever difference the shutdown makes to the agent's goal-utility, so the agent ends up genuinely indifferent between the button being pressed or not, and has no reason to causally influence it either way. The off-switch game gets to basically the same place, just dressed up in a Bayesian game-theoretic framing instead of a hand-added correction term — the agent is uncertain about its own reward function and ends up indifferent to being switched off because of that uncertainty, so structurally it's really the same trick as Armstrong's, just phrased as 'uncertainty' rather than 'correction term.' Neither approach gives the agent a positive reason to protect the button or keep it working, they only remove the negative incentive to fight it — and given that even two such different-looking fixes both fail to supply that positive incentive, that's pretty good evidence that corrigibility just isn't achievable for any expected-utility-maximising agent, full stop."
