Question (20 points): Explain the shutdown problem for advanced artificial agents. Your answer should (a) state the two failure modes a corrigible shutdown mechanism is meant to avoid; (b) explain how the utility function proposed in Soares, Fallenstein, Yudkowsky, and Armstrong's "Corrigibility" attempts to avoid them, and why the authors themselves regard the proposal as incomplete; (c) relate this proposal to Stuart Armstrong's "utility indifference" technique; and (d) explain what the Off-Switch Game of Hadfield-Menell, Dragan, Abbeel, and Russell adds to the picture, including how the robot's willingness to accept being switched off depends on the assumptions the model builds in about the human.

Student's answer: A corrigible shutdown mechanism has to steer between two failure modes. On one side is shutdown-avoidance: because almost any goal is easier to complete if the agent keeps existing, an agent maximizing a fixed utility function has an instrumental reason to resist being turned off. On the other side is shutdown-seeking: if pressing the button is assigned any positive value at all, the agent has a reason to bring the button-press about itself, or to manipulate its operators into pressing it, rather than simply awaiting their decision. Soares, Fallenstein, Yudkowsky, and Armstrong try to avoid both by splitting the agent's utility into a "normal" component u_N that governs behavior before the button is pressed and a "shutdown" component u_S that governs behavior after, then adding a correction term calibrated so that the agent's current expected utility comes out the same whether or not it expects the button to be pressed. This is meant to make the agent genuinely indifferent rather than merely obedient. The authors concede the proposal is incomplete mainly because indifference, as constructed, is a property of this particular agent's utility function: nothing in the setup stops a corrigible agent from building a tool or successor that pursues u_N without inheriting the correction term, so a perfectly corrigible parent could still give rise to an incorrigible child. This trick of correcting an agent's utility function to cancel out its stake in some future event is original to the corrigibility paper; Armstrong's own subsequent work on utility indifference takes the same correction-term device and generalizes it beyond the shutdown case, to cover other value-modifying events such as an operator changing the agent's reward function mid-deployment. The Off-Switch Game reframes the situation as a two-player game in which the robot is uncertain of the value of its own planned action and must choose between acting unilaterally and deferring to a human who may switch it off. Hadfield-Menell and colleagues show that the more uncertain the robot is about whether its action is good, the more it stands to gain by deferring, since the human's decision is informative about the action's true value; and, since the entire point of the model is to protect against a possibly mistaken robot, the robot's willingness to accept being switched off actually increases as the human is modeled as more prone to noisy, imperfectly rational decisions, on the reasoning that a cautious agent facing an unpredictable principal should if anything defer more rather than less.
