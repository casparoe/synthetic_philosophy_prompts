I'm a software engineer with a self-taught interest in logic, and I ran into Skolem's paradox while reading about the Löwenheim–Skolem theorem in the context of model theory. I follow the technical resolution: if ZFC is consistent it has a countable model, yet that same model still satisfies Cantor's theorem and so contains a set it regards as uncountable, because the bijection that would enumerate that set exists outside the model rather than inside it. What I haven't been able to pin down is what, if anything, this is supposed to show philosophically about the notion of uncountability itself.

Could you write a dialogue between two logicians who agree completely on the mathematics but draw opposite morals from it? One, following Skolem's own reaction to his result, argues that "countable" and "uncountable" are therefore not absolute properties of a set at all, only ever relative to some background model or theory. The other, a set-theoretic realist, insists that there remains a perfectly determinate, model-independent fact about which sets are truly uncountable, and that the paradox only exposes a weakness of first-order logic as a descriptive tool. I'd like each side to genuinely engage with the other's strongest objection rather than simply restate their own position — in particular, the realist should have to explain how we get cognitive access to that "determinate fact" given that every first-order description of it admits unintended countable models, while the relativist should have to explain why the same argument doesn't equally dissolve notions, such as consistency or finitude, that they are not prepared to treat as merely relative.
