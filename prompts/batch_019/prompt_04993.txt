So I was reading about "program equilibrium" the other day — apparently in game theory, instead of just picking cooperate or defect, you can have each player submit a program that gets to read the other player's source code before deciding what to output in a prisoners dilemma. From what I can tell this means each program can basically just simulate the other one to see what its gonna do, then pick whatever's best for itself, so mutual cooperation ends up being the guaranteed rational outcome once source code is public. That seems like a genuinely clean solution to the whole prisoners dilemma, not just some trick for one game. So why do decision theorists and AI safety people still treat this as an open problem instead of a done deal — is sharing source code basically a free lunch that solves cooperation for good?
