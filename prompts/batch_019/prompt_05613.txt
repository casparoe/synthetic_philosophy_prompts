Start with Tennenholtz's old "program equilibrium" result: in a one-shot Prisoner's Dilemma, let each player submit a program instead of an action, let the programs read each other's source code, and "cooperate iff your opponent's code is textually identical to mine" turns out to be a Nash equilibrium that gets you the cooperative payoff -- no repeated play, no external enforcement needed.
