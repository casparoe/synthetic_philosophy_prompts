Please argue that Skolem's Paradox, properly understood, shows that there is no non-question-begging way to fix an absolute, model-independent fact about which sets are uncountable, so that cardinality claims turn out to be relative all the way up. The paradox is standardly defused by noting that a countable model of ZFC merely lacks, among its own elements, the bijection that would witness some set's countability, a bijection available only from a richer, external vantage point. Your argument must explain why this diagnosis affords no final resting point: that external vantage point is itself, from some still further perspective, subject to exactly the same Löwenheim–Skolem phenomenon, so that gesturing at 'the' true, unformalizable universe of sets does not obviously halt the resulting regress.
