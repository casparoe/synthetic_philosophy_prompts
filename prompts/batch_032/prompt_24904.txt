I teach a philosophy of economics seminar, about 15 grad students, one 90-minute session. I want an in-class trading game that makes them feel the force of the no-trade theorem — the result that if everyone is rational and shares a common prior, the fact that someone wants to trade with you should make you update your beliefs and refuse the trade, so purely informational differences can't generate trade in equilibrium.

Design a game where students get private signals about some asset's value and can make trades with each other. Rules, a simple scoring system (no real money), and a timeline for the session. The crucial thing: students should start out trading happily and only gradualy realize something's wrong — they should discover the problem themselves before I name it. Then a debrief that maps what happened in the game onto the formal structure of the theorem, what predictably goes wrong the first time I run it, and an honest note about which feature of the real theorem the game can't reproduce and I'll have to supply myself.
