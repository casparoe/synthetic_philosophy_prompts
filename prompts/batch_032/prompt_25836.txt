I've been reading through the free will literature and keep tripping over a distinction that seems important but that I've never seen given a name. The standard move is to construct a case where an agent chooses to do something on their own, but a backup mechanism would have forced them to do the same thing if they'd wavered. The mechanism never activates, so the agent acts freely in the actual sequence, but they couldn't have done otherwise. The debate then turns on whether the agent is morally responsible.

But I've noticed that these cases split into two importantly different kinds, and the literature often runs them together. In the first kind, the backup mechanism would have produced the same outward behavior by overriding the agent's own deliberation — a neuroscientific intervention, hypnosis, or direct stimulation that bypasses the agent's reasons entirely. In the second kind, the backup mechanism would have worked through the agent's own deliberative faculties — it would have subtly altered the agent's reasoning so that they arrived at the same conclusion for the same reasons they actually had. In the first kind, the agent's actual reasons make a causal difference to how the action is performed; in the second, the agent's actual reasons are causally idle because the mechanism would have supplied them anyway.

Is there an established name for this distinction? If not, what would you call it, and has anyone argued that one kind of case succeeds in challenging the principle of alternative possibilities while the other fails for reasons specific to this distinction?
