I'm taking a seminar on paradoxes this semester and I've gotten myself completely tangled up on the Liar. I was reading Kripke and then some of the revenge literature—Priest, Beall, Field—and I built an argument that seems to prove something absurd, but I can't find the bad step.

Here's the argument:

(1) Let L be the sentence "L is not true." Classical logic plus the T-schema gives a contradiction: L is true iff L is not true.

(2) One natural fix is to reject bivalence: L is neither true nor false, it's a truth-value gap. Call this the gap view. On the gap view, L is not true (since it's gappy), so what L says is correct. But the gap theorist blocks the move from "what L says is correct" to "L is true" by restricting "true" in the object language to non-gappy sentences that correctly describe things.

(3) But now consider the revenge sentence R: "R is either false or gappy." If R is true, then what R says is the case, so R is either false or gappy—contradiction. If R is false, then what R says is not the case, so R is neither false nor gappy, i.e., true—contradiction. If R is gappy, then what R says is not the case (gappy sentences don't express propositions that can be correct on this view), so R is false—contradiction.

(4) The gap theorist replies that R is ill-formed: "gappy" is a metalanguage predicate and can't appear in the object language. Fine. But now consider H: "H is not true at any level of any hierarchy." If H is true at level n, then what it says is the case, so H is not true at any level—including level n. If H is not true at any level, then what it says is the case, so H is true at some level (it's a true sentence of English, which must belong to some level).

(5) The hierarchy view now has to say H is ill-formed because "true at any level" can't be expressed within the hierarchy. But this means the hierarchy can't express its own structure—we can't say, in English, that a sentence is true at some level of the hierarchy. Yet we just did say that. So the hierarchy theory seems to require that we can't talk about the hierarchy in the very language the hierarchy was supposed to be a theory of.

(6) This pattern looks general: any formal solution introduces some distinction (gaps, levels, contexts, whatever), and a revenge Liar gets built using that distinction to recreate the paradox. The solution always seems to require that you can't express the solution in the language the solution is about.

(7) So it looks like no consistent solution to the Liar is possible: every solution generates the vocabulary for its own revenge.

(8) But that's absurd. The Liar is a puzzle about our truth concept, not a proof that the concept is incoherent—we use "true" constantly without blowing up. So something in (1)–(7) has to give.

I have a hunch the slide happens somewhere around (5) or (6)—maybe the revenge sentence for the hierarchy isn't statable in the way I think it is, or maybe the argument equivocates between "true in the object language" and "true simpliciter" when it moves from the formal model back to English. But I can't make it precise. Which step should I reject, and what's the cost? If I have to give up the idea that English has a single unified truth predicate, is that a price worth paying, or does it just relocate the problem?
