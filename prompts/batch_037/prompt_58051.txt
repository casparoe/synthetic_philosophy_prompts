My current argument is that if there is no essence of hardness that all correct uses must share, then as long as each of my uses resembles some other accepted use, none of them can be marked wrong for confusing different senses. Is this the correct conclusion to draw from family resemblance, and if my reasoning is mistaken, can you explain exactly which step goes wrong?
