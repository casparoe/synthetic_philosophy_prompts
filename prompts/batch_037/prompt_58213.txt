Suppose an agent assigns substantial credence to more than one incompatible moral outlook and must decide how to act in light of that uncertainty. Consider two rival proposals for what rationality requires in such a situation. On the expectational proposal, the agent should assign numerical values to options as assessed by each candidate theory, normalize those values to permit comparison across theories, weight by credence in each theory, and select the option with the highest weighted total. On the constraint proposal, the agent should first set aside any option that any sufficiently credible theory regards as a grave wrong, even if that option scores well on weighted totals, and only then select among the remaining options by weighted total.

Compare these two proposals with attention to the following stylized cases. First, an agent has high credence that a common dietary practice is permissible and mildly beneficial, but modest credence that it constitutes a serious wrong against sentient beings. Second, an agent has very low credence in a population-centered outlook according to which creating many additional flourishing lives would be of enormous moral importance, and high credence in a person-affecting outlook according to which such creation matters little, where acting on the former would impose significant costs on existing people. Third, an agent is uncertain between an outlook that evaluates actions solely by their actual outcomes and one that treats the imposition of unjustified risk itself as wrong, even when the risk does not materialize.

Develop a systematic comparison that explains where the proposals converge and diverge across these cases, how each handles the influence of low-credence theories with extreme stakes, and whether each preserves a principled difference between moral uncertainty and ordinary empirical uncertainty about consequences. Defend an overall verdict about which proposal offers the more satisfactory general account of decision under moral uncertainty, identifying any revision or hybrid that would be needed to handle the hardest case.
