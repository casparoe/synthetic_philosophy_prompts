Title: "Corrigibility is not a property of agents"

In the debate about whether advanced AI systems will let themselves be shut down, almost everyone talks as if corrigibility were a property of the individual agent: either the agent has a goal structure that makes it okay with being switched off, or it doesn't. I want to argue this is a mistake. Corrigibility is a property of the whole human-machine system, and looking for it inside the agent is like looking for the "rideability" of a horse inside one of the horse's organs.

Start with the familiar worry. An agent that pursues goals in the world will typically resist shutdown, because being shut down prevents it from pursuing those goals. The standard response is to try to build the agent so that it wants to be corrected — it treats the human pressing the button as good news. I think of this as the "obedience" approach, and I think it faces a dilemma. Either the agent's goal system contains a special exception for shutdown, in which case the exception can be eroded as the agent learns and revises (exceptions are the kind of thing that gets optimized away), or the agent genuinely doesn't mind being switched off, in which case it's unclear why it's pursuing anything at all with any urgency.

My alternative: stop trying to make the agent want shutdown, and start removing the agent's *reasons* to care. Incentive-compatibility instead of obedience. Concretely, imagine the agent's reward is measured and paid out per episode rather than accumulated over its lifetime of operation — the "banked" rewards can't be lost by shutdown, so continued operation has no instrumental value with respect to them. On some simple models this makes the agent genuinely indifferent about the off-switch: not because it loves us, but because we've arranged the world so that resisting costs something and complying costs nothing.

The second half of the paper uses an analogy I'm fond of but worried is too cute: domestication. Dogs are corrigible in roughly the sense we want. Not because dogs have a concept of human judgment they defer to, and not because we reasoned with wolves about their values — but because selective breeding changed what wolves wanted until their interests stopped diverging from ours in the relevant respects. The lesson I want to draw is that corrigibility might be better understood as a disposition that gets *selected for* (by training regimes, by market pressure between labs, whatever) than as a design feature that gets *proven* by an argument. Which is annoying, because it means we might get corrigible systems without being able to say why, and uncorrigible ones despite having an argument that we shouldn't.
