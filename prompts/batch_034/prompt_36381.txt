My mate reckons he's broken expected value theory and I genuinely cant find the exit. He showed me this coin game: flip a fair coin until it first lands heads. If that first heads comes on flip n, you win £(2^n)/n if n is odd and lose £(2^n)/n if n is even. So flip 1 wins you £2 (probability 1/2), flip 2 loses you £2 (probability 1/4), flip 3 wins about £2.67 (probability 1/8), and so on forever. He says a version of this is called the Pasadena game in some paper or other, but we can just work with the setup as I've described it. Here's his argument:

(1) Whether it's rational to play a gamble depends on the gamble itself — on which payoffs hang on which outcomes — and not on how we happen to write it down. In particular, the rational evaluation of a gamble can't depend on the order in which we enumerate the states when computing an expectation. Enumeration order is bookkeeping, and bookkeeping can't matter.
(2) For finite gambles this is trivially true — add up the state contributions left to right or right to left or alphabetically, you get the same number every time.
(3) For the coin game, enumerating states in the natural order (flip 1's contribution, flip 2's, flip 3's, ...) the contributions are +1, −1/2, +1/3, −1/4, ..., which is the alternating harmonic series, summing to ln 2 ≈ 0.69. So EV reasoning says pay up to about 69p to play.
(4) But that series converges only conditionally — the contributions in absolute value are 1, 1/2, 1/3, ..., which diverges. And there's a classical result that a conditionally convergent series can be rearranged to converge to any number you like, 100 or −5 or whatever, just by enumerating the very same terms in a different order.
(5) By (1) and (2), each such rearrangement is just as legitimate an evaluation of the same game — the terms are the same state-payoff products, only the enumeration order changed, and enumeration order was supposed to be bookkeeping.
(6) So the game is simultaneously worth 0.69 and 100 and −5. Worse, a bookie who knows which enumeration I'm running can sell me the game for £90 while my valuation sits on the rearrangement converging to 100, then get me re-anchored on the natural order and buy the game back off me for 60p. That's a money pump on repeat. So EV theory — or at least its application to gambles with infinitely many states — refutes itself.

The conclusion is obviously too hot for me: as far as I can tell this argument would trash the valuation of every gamble whose expectation converges only conditionally, and my mate says fine, so much the worse for all of them, which feels like proving way too much. So, which step do you actually reject, and what does rejecting it cost? I have a hunch the trouble is somewhere in (1)-(2), but I also can't see that it's cheap to give up: if enumeration order can matter, then I want to know what privileges the natural order in (3) other than that it happens to be the first one we thought of. One more thing — please can you keep straight for me what here is settled maths versus what is genuinely contested among decision theorists who work on this stuff. I don't want to walk away thinking the money-pump conclusion is the consensus view if it's actually one position in a live fight.
