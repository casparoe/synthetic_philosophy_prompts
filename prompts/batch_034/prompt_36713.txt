I'm TA-ing an intro set theory course and finally getting through the stack of midterm proofs this weekend. We spent a good two weeks on the axiom of choice, so this question was on the exam, and I want to make sure I grade this one carefully rather than on vibes:

"Let f : A → B be a surjection. Working in ZF (without the axiom of choice), what exactly does AC contribute to the proof that f has a right inverse, i.e. a function g : B → A such that f(g(b)) = b for all b in B? Identify the precise step where choice enters, explain why that step is not available in ZF alone, and discuss how much choice the proof needs in the general case and in special cases such as finite or countable B."

And here's the student's answer, copied from their bluebook:

"Take any surjection f : A → B. For each b ∈ B, the fiber f⁻¹(b) = {a ∈ A : f(a) = b} is nonempty, because f is onto. Now, picking a single element from a single nonempty set requires no choice at all — that's just what nonempty means, ∃x(x ∈ S). So for each b, pick some element of its fiber and call it g(b). Then f(g(b)) = b holds by construction, so g is a right inverse. A function is just an assignment of exactly one output to each input, and we have assigned exactly one element of each fiber to each b, so g is a legitimate function. The axiom of choice never had to enter: we only needed to make one pick from each nonempty set, and picking from a nonempty set is free in ZF.

As for how much choice is needed: if B is finite, we can pick representatives one at a time by induction, so no choice axiom is needed. If B is countably infinite, countable choice suffices — but countable choice is itself provable in ZF, since the same induction that handles the finite case can be run over the natural numbers. In the general case, the statement 'every surjection has a right inverse' is strictly weaker than AC; it is a relatively mild consequence of it, like the well-ordering theorem."
