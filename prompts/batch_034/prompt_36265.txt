been following the string theory fights on the blogs and forums since forever and I finally tried writing down where I actually stand so people can poke at it. here's the list:

1. I'm a boring Bayesian — credences should only move on evidential relevance, i.e. stuff that's more expected if the theory is true than if its false.
2. The no-alternatives argument is real evidence for string theory. Decades of smart people failing to find any other consistent unification of QM and GR is more likely if string theory is roughly on track than if its not, so it legitimately shifts credence up. This isn't some exotic non-empirical logic grafted onto Bayes, its just Bayes applied to the research process itself.
3. The string landscape plus anthropic reasoning predicted a small positive cosmological constant before the 1998 supernova results, and that counts as a genuine novel prediction, so the landscape framework is confirmed in the completely ordinary way.
4. A theory that can accommodate any possible observation can't get confirmed by observations, and the landscape can accommodate pretty much any constant we could ever measure.
5. Given all of the above I still shouldn't hold more than like 20% credence in string theory, because nothing empirical distinguishes it from rivals nobody has thought of yet.

does this package hang together? my gut says 3 and 4 can't both be true but I can't pin down which one is the wrong one, and I genuinely can't tell whether 2 is sneaking in the same disease or is fine on its own. rank the tensions by severity, tell me which are real vs only apparent, and say what the cheapest fix is — I'm not attached to any particular item on the list, so don't pull punches on which one has to go.
