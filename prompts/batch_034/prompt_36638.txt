For my graduate seminar on formal epistemology, each of us has to submit a position profile on imprecise credence to be workshopped by the group next week. Here is mine, in six commitments: (1) an agent's epistemic state is sometimes best represented by a set of probability functions rather than a single one, and in Ellsberg-type cases with symmetric evidence and unknown chances this is the correct representation rather than a defect awaiting repair; (2) the Ellsberg preferences — preferring a bet on the urn of known composition — are fully rational, and ambiguity aversion is not a bias to be explained away; (3) rational preferences over acts must be complete, so that between any two options the agent either prefers one or is indifferent, with "incomparable" not a permissible verdict at the point of choice; (4) a rational agent will never refuse costless, relevant information before deciding; (5) imprecision is evidence-sensitive in a specific way — updating goes by conditioning every function in the set, and as evidence accumulates the set should contract, so that a persistent non-shrinking credal set reflects an unwillingness to learn; and (6) each probability function in the set must itself satisfy the sure-thing principle. I'd like an audit of whether this package hangs together: which of the commitments are in genuine tension, which only appear to be, and what would have to give? Please rank the problems by severity, and for each one tell me what the cheapest repair is and what it costs elsewhere in the package.
