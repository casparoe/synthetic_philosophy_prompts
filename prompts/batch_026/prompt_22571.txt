I'm designing the subtyping rules for a new statically typed language, and I keep coming back to Gongsun Long's "White Horse" argument from the School of Names — the claim that the name "white horse" is not the name "horse," because "horse" names the form while "white" names the color, so that adding the color-qualifier changes what the name is. Please describe the most important implications of that argument for how we should read the "is-a" relation between a qualified type and its base type. In particular, I want to know whether the argument supports treating "WhiteHorse is-a Horse" as identity, as subsumption (a proper subtype), or as something else, and what concretely breaks in a type system if we conflate a qualified type with its base type.
