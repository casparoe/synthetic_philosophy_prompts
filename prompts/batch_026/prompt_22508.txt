Question:
Explain Jeffrey's rule for updating on uncertain evidence. Let the prior be P, and let the evidence lead the agent to adopt new probabilities p_i for a finite partition {E_i} of the state space. (i) State the rule. (ii) Explain how Jeffrey's rule can be understood as a special case of ordinary conditionalization in an enlarged state space. (iii) State one standard philosophical objection to Jeffrey's rule and explain why it matters.

Student answer:
Jeffrey's rule says that if the evidence changes the probabilities of the partition {E_i} to p_i, then for any hypothesis H, P^*(H)=Σ_i P(H|E_i)p_i. It is a special case of ordinary conditionalization because one can enlarge the state space with a new event F meaning that the evidence has arrived, and then condition on F. The probabilities p_i are just the conditional probabilities of the E_i given F, so the law of total probability yields the same formula. The standard objection is that Jeffrey's rule is circular: it uses the conditional probabilities P(H|E_i), which are themselves defined by the prior and the partition, so the rule presupposes the very probabilities it is meant to justify. The objection matters because it shows that the rule cannot be applied unless the agent already has a fully specified prior over the enlarged space.
