I'm in a course on game theory and the philosophy of cooperation, and we covered program equilibrium for the one-shot prisoner's dilemma. The argument as I understood it goes like this. In a one-shot PD you can't get cooperation by appealing to self-interest alone: whatever the other player does, defecting gives you more, so rational players defect. But that's only when players privately choose actions. If each player instead submits a program, and every program is handed the other program's source code before it outputs cooperate or defect, then a player can submit a program that cooperates iff the other program is an exact copy of itself and defects otherwise. If both submit that program, both cooperate, and neither can profitably switch to an always-defect program, because the remaining copy detects the difference and defects; the switcher then gets the sucker's payoff, which is worse than mutual cooperation. So being forced to make your decision procedure transparent turns mutual cooperation into an equilibrium.

What's been nagging me is that this seems to depend entirely on code transparency, and that's exactly what we don't have with the sorts of systems that get called agents now. A neural network's source code is basically the same few hundred lines of matrix multiplication whether it's cooperative or not; the behavior lives in the weights, and you can't read a policy off the weights by inspection. Two copies of the same model can also act differently on the same input because of sampling or nondeterministic hardware. So the move the original construction relies on—reliably recognizing a twin by looking at its code—just isnt available for learned policies.

I want to know whether the program equilibrium argument survives that change. Is source-code transparency the load-bearing premise, or is it really just one way of getting a more general thing, like a credible signal of your decision procedure? If transparency goes away in the opaque-policy case, does the one-shot cooperation result simply collapse back to defection, or is there a repaired version that proves something weaker but still interesting—say, that cooperation becomes feasible again once agents can behaviorally test each other, or that the original result only ever showed what's possible under ideal transparency rather than what's robust? I'm less after practical AI policy and more after what the original argument actually established and which part of it stops carrying over.
