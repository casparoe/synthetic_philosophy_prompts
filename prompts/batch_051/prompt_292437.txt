Here's a classic puzzle. 'Sherlock Holmes' is an empty name — no flesh-and-blood person answers to it — yet 'Holmes is a detective' seems straightforwardly true once we add 'in the stories.' Two rough camps: (i) the name is just empty, and the phrase 'in the fiction' is an operator that shifts evaluation to worlds where the books are told as fact; (ii) the name refers to something after all, an abstract object the author created (a fictional character). Now a variation. Imagine a version of the Sherlock Holmes stories indentical to the real ones except for a final page, added after the last story, on which Watson confesses he has been narrating a long hallucination: Holmes never existed, even inside the world of the books, and Watson has been recording his own illness all along. In this variant the fiction itself makes it true that Holmes does not exist. Run the variant through both camps. What should each say about 'Holmes is a detective' and 'Holmes does not exist' in the revised story? Does camp (i) have to treat the earlier chapters as the narrator's errors while the final page gives the story's real content, and does camp (ii) simply ignore the twist because the character exists as soon as the author writes about him? Say which camp comes out looking better, and be clear about where the standard views need tuning. If the variant is too mangled to be worth running, or rests on a confused idea of what 'in the fiction' means, say so plainly instead of playing along. Please write in British English.
