I have been trying to reconstruct a standard argument for functionalism about the mind, and I want to check whether it actually works before I use it in a paper. I have laid it out below. Could you assess whether the argument is valid as written, and if not, identify exactly which step fails? If it is valid but unsound, which premise seems weakest, and what is the strongest objection to it?

(1) The same mental state type — pain, for instance — could in principle occur in a human, an octopus, and a silicon-based robot.
(2) If pain were identical with some particular physical state type P, then any system in pain would have to be in physical state type P.
(3) A human, an octopus, and a silicon robot could all be in pain even though there is no single physical state type P that all three share when they are in pain.
(4) Therefore pain is not identical with any particular physical state type.
(5) If pain is not identical with any physical state type, then the only defensible account of what makes it pain is that it is a functional state type: a state defined by its causal relations to sensory inputs, behavioral outputs, and other mental states.
(6) Therefore mental states in general are functional kinds, and any physical system that implements the right functional organization has a mind.

I have a vague worry that step (5) is doing too much — that ruling out identity with a physical state type is not yet an argument that mental states are functional kinds. I also wonder whether a type-identity theorist could simply accept (4) but insist that pain is identical with a disjunctive physical kind — the disjunction of all the different physical states that play the pain role in different organisms. Would that be a legitimate escape? Please go through the argument step by step, say whether it is valid, and identify the precise step, if any, that should be rejected.
