I'm a software engineer, not a philosopher, and I've been turning over an argument that starts from a theorem I use at work — the no-free-lunch theorem from machine learning — and ends somewhere I don't want to go. My working understanding of the theorem is this: over the space of all possible target functions, every learning algorithm has the same expected out-of-sample error, so no algorithm generalizes better than any other once you average over every function it could be asked to learn. A neural network, a decision tree, and the rule "always return the same label" are all tied under that average. I've always taken the practical moral to be that you need assumptions about the kinds of problems you'll face, because there is no universally superior algorithm. That part feels fine.

But someone in a reading group pushed it further, and I couldn't knock the argument down:

(1) The no-free-lunch theorem says that, averaged across all possible data-generating functions, every learning rule has exactly the same expected out-of-sample performance.
(2) So for any inductive method, there is no expectation-based advantage over the dumbest possible rule, such as always predicting the same class.
(3) For induction to be rationally justified, it must beat arbitrary guessing at least in expectation; otherwise "justified" merely means "we happen to favor this rule."
(4) By (2), no inductive method beats arbitrary guessing in expectation.
(5) Therefore no inductive method is rationally justified — which sounds like Hume's problem of induction, but now backed by a theorem rather than a skeptical mood.

I'd like to keep both the theorem and the obvious fact that, in the actual world, any competent ML engineer would rather use a regularized model than a constant predictor. So the question is narrow: exactly which step or premise should I reject, and what does rejecting it cost? My guess is that something goes wrong in the move from an average over all logically possible functions — each weighted equally — to a claim about what we should expect in this world, where past data gives us real information about the structure we're likely to meet. But I don't know whether that objection is precise enough, or whether I'm smuggling in the very regularity I was trying to justify.
