**Question.** In epistemic utility theory, a scoring rule (or inaccuracy measure) assigns to each credence function and each possible world a number measuring how inaccurate that credence function is at that world; the Brier score is one standard example. Using the Brier score as a running example, explain how an accuracy-first epistemologist argues from such scoring rules to Probabilism, the claim that rational credence functions obey the probability axioms. Your answer should identify the key property of the scoring rule that the argument relies on, define that property precisely, and distinguish it from any property it is easily confused with.

**Student's answer.** An inaccuracy measure tells you how far a credence function is from the truth at a world. The Brier score does this by summing the squared differences between the credence assigned to each proposition and that proposition's truth-value at the world (1 if true, 0 if false), with lower scores being better. The accuracy-first argument for Probabilism runs like this. Take a non-probabilistic credence function, one that violates the probability axioms. Because the Brier score is a proper scoring rule, there is some probabilistic credence function that is strictly closer to the truth in every possible world — that is, has a lower Brier score in every world — so the non-probabilistic credence function is accuracy-dominated. Since a rational agent should not adopt an accuracy-dominated credence function, rational credence functions must be probabilistic. The property doing the heavy lifting is propriety: a scoring rule is proper just in case it always assigns its best, i.e. lowest, expected score to the omniscient credence function — the one that assigns 1 to all truths and 0 to all falsehoods at a world. This ensures that the dominance comparison is not rigged in favor of probabilistic credences; without propriety, a scoring rule could judge some non-probabilistic credence function as more accurate than all probabilistic ones, and the argument would collapse.
