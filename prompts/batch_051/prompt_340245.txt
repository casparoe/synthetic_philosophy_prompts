I'm a philosophy prof, and I've been chewing on whether Hofstadter's superrationality and program equilibrium are really the same idea in different clothing or genuinely differnet claims. In the classic one-shot prisoner's dilemma they both say cooperate. Superrationality's story is that you and the other player are running the same decision procedure in the same situation and both know it, so you act on the correlated move: the real options are 'we both cooperate' and 'we both defect.' Program equilibrium gets to the same place mechanistically: each player submits a program, programs can inspect each other's source code, and a program that cooperates only if the other program is identical to itself makes mutual cooperation a stable outcome—both run that program, both cooperate. Compare them properly. Where do they come apart: asymmetric payoffs, non-identical players, one side able to read the other's code but not vice versa, bounded computation, slightly corrupted copies? Which one gives the better account of why one-shot cooperation can be rational, and what hidden assumption is each one resting on that a skeptical game theorist would push back on? Give me your bottom line in the first sentence, then your reasoning. No preamble, and don't restate the question.
