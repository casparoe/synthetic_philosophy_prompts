I've been chewing on Russell's paradox and I keep coming back to a distinction I want checked. I want to say there are two kinds of ways a condition can fail to pick out a set: it can be too big, like the set of all sets or all ordinals, or it can be too self-referential, like the Russell condition. My homemade principle is what I call the No Look-Ahead Rule: a condition is set-forming only if you can tell whether something falls under it without already knowing the membership facts about the very set your defining. So "x is not a member of itself" is disqualified because, when x is the set being defined, the question loops back on itself. The usual ZFC fix (separation: you can only carve sets out of ones that already exist) looks to me like it's just an implementation of No Look-Ahead rather than a real solution. Is this distinction already in the literature under a name I'm forgetting? Is it just the vicious circle principle restated? And give me the nastiest case you can think of: either something we clearly want as a set that my rule wrongly bans, or a paradox that still slips through even if you obey No Look-Ahead.
