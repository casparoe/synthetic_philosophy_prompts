I've been tangled up in a question about the extended mind, and it turns on how literally to read the parity principle. Here's the passage, from Clark and Chalmers:

"If, as we confront some task, a part of the world functions as a process which, were it done in the head, we would have no hesitation in recognizing as part of the cognitive process, then that part of the world is (so we claim) part of the cognitive process."

Now the case. Two brothers, Elias and Sam, run a bird survey together. They keep one shared cloud folder with the project's entire field memory: photos, range maps, year-by-year counts, and notes like "sounded more like a Pacific-slope flycatcher but the light was bad." Both of them consult it constantly and automatically — neither thinks "let me go check an external storage device"; they just reach for it the way they reach for their own memory. Each trusts it the way he trusts his own recall, even when he doesn't remember adding the entry himself, and each would be genuinely impaired and unsettled if the folder were deleted. As far as the parity principle cares, the folder functions for each of them like memory. But it is one token repository — the same files, the same annotations, the same "my field notes" for both of them.

My question is whether the parity principle says this single token resource is part of both brothers' cognitive processes at once. If yes, then two cognitive processes have a component in common, and if a mind just is the relevant bundle of cognitive processes, then two minds overlap. The authors presumably only had one person and one notebook in view — Otto's. Is that over-reading the words? What would a purpose-based reading exclude, if anything? What do you think Clark and Chalmers would have said if asked about a shared notebook: would they bite the bullet and call it a shared cognitive resource, or would they add an implicit "one person, one resource" condition? And what would a reasonable reader of the passage take it to commit to?

I care less about the label than about what the parity principle is even in a position to do, and whether it can handle shared external memory without quietly turning into a group-mind claim.

Also, when you answer, please seperate what's actually settled about the extended mind thesis from what's still genuinely contested, and don't present a contested reading as the consensus. American English, please.
