I've been mulling over the old argument that there's no fact of the matter about when Latin became Italian. Every generation could mostly understand the generation before; the changes are tiny and piled up gradually; so any line you draw is a conveniance, not a discovery (it's basically a heap argument). The problem with this, as I'm now seeing it, is that it quietly assumes the change is unplanned drift—no one steering, no institutions involved. So here's the wrinkle I want to test it against. Suppose the language gets deliberately standardized at some point: a written standard is chosen, schoolteachers start correcting kids' speech against it, and a national broadcaster saturates the whole country with that one variety. After that, a speaker can be wrong in a new way—there's a norm to deviate from, not just a slightly different way of talking. Before it, saying it the old way wasn't incorrect. Does the no-sharp-boundary argument survive this? Or does it keep working only for the spoken background continuum, and stop touching the thing people mean by "Italian" once standardization happens? Which premise is actually taking the hit, and is there a repaired version that still does useful work? I'm also wondering whether 'when did Latin become Italian' splits into two separate questions, and if so which one the old argument still answers.
