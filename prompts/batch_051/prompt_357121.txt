So my friend and I spent most of last night going back and forth about Yablo's paradox, and I came away convinced it's more unsettling than the standard liar, but also kind of annoyed that I can't explain why to people who haven't stared at it. The setup, just so we're on the same page: imagine an infinite list of sentences, one for each natural number, and each sentence says that every sentence later in the list is false. So the first one says the second, third, fourth, and so on are all false; the second says the third, fourth, fifth, and so on are all false; and so on down the line forever. No sentence says anything about itself, and the reference only ever runs forward, so there is no circle anywhere. Yet if you try to assign each sentence true or false you get a contradiction: if some sentence is true, then all the later ones are false, but then the very next sentence in line is saying something true, so it should be true, not false. And if every sentence is false, then each sentence's claim that all the later ones are false is correct, so every sentence is true after all. My friend kept insisting there had to be hidden self-reference or circularity somewhere, and I kept failing to find one, which is exactly the point.

Anyway, I've been asked to run a single 90 minute session for an upper level undergraduate logic seminar, 12 students, most of them comfortable with truth tables and basic semantic talk but not with anything infinitary. I don't want to lecture about the paradox. I want to design a structured activity or game that makes the students run into the problem themselves before it gets named — roles, rules, constraints, or payoffs arranged so that they try to settle the truth values and the whole thing unravels in their hands, while also noticing that nobody ever needs to refer to their own sentence. By the end they should come away seeing that paradox doesn't require self-reference or circularity, and that the trouble is something more like an endless chain of deferred justification.

Please design the whole thing in enough detail that someone else could run it: the setup, materials, timeline, exact instructions, the roles, what to watch for, and a debrief that maps moments in the activity back onto the paradox. Also say what predictably goes wrong when you run it and how to handle it, and be honest about the one feature of the real paradox that a room of twelve finite people cannot reproduce — presumably the actual infinity — and how the facilitator should fill that gap. And please write it all as continuous prose, the way you'd write an email or letter: no headings, bullet points, bold text, or tables.
