The Gödelian anti-mechanist argument, in the form Lucas and Penrose gave it, was aimed at a particular sort of candidate mechanism: a Turing machine or consistent formal system whose outputs are the theorems it proves. The argument runs roughly as follows: if a human can recognize that a given formal system is sound for arithmetic, the human can also see the truth of that system's Gödel sentence, while the system itself cannot prove that sentence; hence the human's mathematical capacity exceeds that of the machine. The most capable systems now under discussion are not of that kind. A large language model is a trained, stochastic, approximate predictor of text; it is not presented as a recursively axiomatized theory, its outputs are not generated by a proof relation, it has no canonical consistency predicate from which a Gödel sentence could be extracted, and it can assert flatly inconsistent things within a single session. Does the Lucas–Penrose argument survive this shift in what the candidate mechanism actually is? Does it still have force against a system of this type, does it need repair, or does it simply fail to apply? Identify which premise the development bears on — that the candidate is a formal system, that it is consistent, that the human can see its soundness, or that human mathematical reasoning itself has some non-mechanical capacity the argument is meant to exhibit — and state what the argument would need to be true in order to go through against a language model. Address the natural reply that any physically implemented digital system, including a language model, can be given a computational description and is thus in some sense a formal system, and explain whether that is enough to run the Gödelian argument or whether it misses what the original argument required. Finally, say whether a repaired version can still be formulated, and what exactly it would establish if it worked.
