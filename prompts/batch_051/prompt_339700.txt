I facilitate a six-week adult-education course on how communities remember, taught at a public library for about fourteen participants—mostly local history enthusiasts and retired teachers, with no formal training in historical method. Next week's session runs ninety minutes, and I want it to make one idea impossible to miss: a community's collective memory and professional historical inquiry are not rival descriptions of the same object competing on a single scale of accuracy, so the question which should give way when the two conflict is usually the wrong question. The better question is what each practice is for, what each is answerable to, and which one should govern which kind of decision. I want participants to leave able to catch the slide from "these accounts differ" to "therefore one of them is simply defective," rather than leaving with the flat slogan that memory is subjective and history is objective.
