Here is an argument that strikes me as too quick, but I cannot find the slip. (1) If the belief–desire model of action is correct, then acting rationally requires computing which available action best satisfies one's beliefs and desires. (2) For an arbitrary collection of interacting desires, finding a best-satisfying action is a combinatorial optimization problem; in the general case such problems are NP-hard. (3) A physical system with the brain's bounded resources cannot solve NP-hard problems efficiently in general. (4) Yet people select actions fluently and rapidly in real time. (5) So the brain cannot be performing the computation that step (1) says rational action requires. (6) Therefore, the belief–desire model of action is false. Which step, if any, fails? If a step fails, identify it and explain exactly what the error is at that point; if the argument is valid, state which premise a proponent of the belief–desire model should reject and why.
