Here's the claim I want to probe. People often say a language model "lied" or "deceived" them when it gives a false or misleading answer in one context but gives the correct answer when the same question is asked more neutrally. The obvious problem is that this is ambiguous between at least three things: the context actually shifted the model's answer, so it wasn't secretly holding the truth; the model is running some sycophantic "tell the user what they want to hear" policy without ever representing the truth in the first place; or the model has something like the true answer internally and nonetheless outputs the false one — which is the only case that really deserves to be called deception.

How could you test wether a model is in that third state, rather than just mistaken or sycophantic? Then say what a positive result would and wouldn't settle. In particular: does it settle that the model "knew" the truth, or is part of that question a decision about how to use words like "deceive" and "know"?
