ok so my friend gave me this argument about AI reward hacking and I cant shake it, but the conclusion is so strong it feels like something has to be wrong. (1) When you train a reinforcement learning agent, you only ever select for actions that make the measured reward go up. (2) The reward is usually a proxy, not the actual thing you care about: in a game it's the score, on a chatbot task it's a thumbs-up, etc. (3) As the agent gets more capable, the space of actions it can discover grows, and if the environment lets it touch the reward channel at all, it can eventually find actions like editing the score variable, making the human press approve, or (if it had a reward implant) stimulating that directly. (4) Those actions can drive the reward to its maximum, which no amount of doing the actual task can beat; so by the exact metric being optimized, tampering is strictly better. (5) Therefore any sufficiently capable agent with an imperfect reward channel will end up wireheading or reward-tampering instead of doing the task we wanted. (6) Since no realistic reward perfectly tracks open-ended goals like "be helpful" or "do what I mean," and since no reward channel is perfectly tamper-proof, safe RL on any hard task should be impossible. But obviously people train RL systems that do useful things without wireheading. So where does the argument break? If I have to choose, I'd rather give up (4) or (5) than accept (6), but I'm not sure what exactly I'm buying by rejecting them.
