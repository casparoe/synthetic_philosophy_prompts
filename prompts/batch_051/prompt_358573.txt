Ok so I'm a software engineer and never took philosophy, so maybe I'm missing something basic here. Ive been turning over Aumann's agreement theorem: if two ideal Bayesians share a prior and their posterior probabilities on some claim become common knowledge, they can't agree to disagree — the posteriors have to be equal. That's the argument as I learned it, anyway.

But the theorem assumes information arrives in well-behaved partitions, and more importantly that both people start from the same prior. Now think about how disagreements actually happen online. Everyone lives inside a personalized feed; each person's information is private, their prior is built from a history no one else can inspect, and the platform never makes anyone's uncertainty common knowledge. On a political or factual dispute the common-prior condition fails before the conversation starts, and the common-knowledge condition never comes close to holding. It feels like the assumptions aren't just idealized, they've been systematically engineered away.

So does Aumann's conclusion survive this development? Is the honest answer just "the theorem is a conditional, and the condition is now almost never met, so stop using it to explain real disagreement"? Or is there a repaired version that still says something interesting — e.g. if a platform forced everyone's full reading history to become common knowledge, would residual disagreement be rational only because the priors differ? Which premise is doing the actual work, and what would progress look like: a formal result about when disagreement remains rational under different priors, or just dropping the theorem as a tool for thinking about polarization?
