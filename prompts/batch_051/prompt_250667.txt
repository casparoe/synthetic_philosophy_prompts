I am trying to settle what I actually think about randomness, and I would like to know whether there is a principle that captures my gut reactions to particular cases, or whether some of those reactions have to be revised. Consider binary strings of length 20.

Here are the cases and my verdicts.

(1) The string 00000000000000000000 (twenty 0s), with no information about how it was produced. My verdict: not random.

(2) The string 01010101010101010101 (ten repetitions of 01), with no information about how it was produced. My verdict: not random.

(3) The string 01101110010100110101, which I am told was produced by a genuinely fair coin. My verdict: random.

(4) The all-zero string from case (1), but now I am told it was produced by a genuinely fair coin. My verdict: still not random, though I admit this sits uneasily with case (3).

(5) The first twenty terms of the Thue–Morse sequence, defined by starting with 0 and repeatedly appending the bitwise complement of the block produced so far (so it begins 0, 01, 0110, 01101001, and so on). This sequence is generated by a trivially simple deterministic rule. My verdict: not random, because of how it was produced, even though the string itself does not look as obviously patterned as cases (1) and (2).

(6) The very same string as in case (3), 01101110010100110101, but now produced by a deterministic pseudo-random number generator, a device whose output is entirely fixed by its seed and an update rule. My verdict: not random, even though the string is indistinguishable, considered on its own, from the one I called random in case (3).

(7) The alternating string from case (2), 01010101010101010101, but now produced by a genuinely fair coin. My verdict: not random, even though the process was random.

The tension I cannot resolve is this. My verdicts in cases (4) and (7) treat the string itself as what matters, since learning that a fair coin produced the string does not move me. My verdict in case (6) treats the process as what matters, since the same string changes status when I learn that its source was deterministic. I do not see how a single account can respect both instincts.

I also have a more basic worry. If randomness is a property of the generating process, then a finite string is never random in its own right, only derivatively. If randomness is instead a property of the string itself, I need a criterion that makes the all-zero string non-random while making most irregular strings random, even though a fair coin assigns every 20-bit string exactly the same probability. The only proposal I half-endorse is that a string is random to the degree that it has no description much shorter than itself; but I do not see how to make that precise for strings this short, since one can always say "the string from case (3)."

So I would like you to do the following. State the principle, or a small set of candidate principles, that best captures my verdicts; tie each clause to the case or cases that motivate it; say what the principle predicts for cases I have not listed, including a 20-bit string such as 10001101011001011100 presented to me with no information about its source; and tell me honestly which of my verdicts it cannot accommodate, or which of my instincts I would have to give up to keep it. Please also answer directly whether a finite string can be random in its own right, or whether randomness in the full sense belongs only to processes or only to infinite sequences.
