I've been chewing on the unilateralist's curse — the idea that when a bunch of people can each unilaterally take some risky action, the action tends to happen if any one of them is optimistic enough, so the group's behavior tracks the most optimistic person rather than the median. I think I've found a symmetrical case people don't talk about, and I'm not sure whether its novel, trivially known, or just wrong.

I've been calling it the "default curse" (maybe "the conservative's unilateralist curse"). The thought is: the standard curse only describes a world where the default is "nothing happens unless someone acts." But flip the default — say the system is already running and any single person can pull the plug — and you get the mirror image: the group now tracks the most cautious person. Example: a lab deploys models by default and any reviewer can block release; then the effective rule isn't "release if the median reviewer approves" but "release only if nobody is scared enough to block." That's the same curse wearing a cautious hat. Another: a vaccine program that auto-rolls out unless one safety officer objects will be governed by the most risk-averse officer, not the consensus safety judgment.

So my claim is that the curse isn't really about optimism or risk appetite; it's about the default. Any status quo, plus the ability of any one person to deviate from it, hands the decision to the most extreme deviator. The optimist gets the unilateral option when the default is inaction, the pessimist gets it when the default is action. If that's right, some of the proposed fixes — like "make unilateral action harder" or "require consensus" — don't solve the problem, they just move the default and therefore change which extreme governs.

I want an honest assessment: is this coherent, does it collapse into existing stuff (status quo bias, veto players, opt-in/opt-out defaults, the precautionary principle), and where does it break? One place I can already see it creaking: acting and blocking usually have different costs and different information; a cautious reviewer who blocks might face reputational or institutional costs that an eager actor doesn't. Maybe the symmetry only works when deviation from the default is costless in both directions, which is almost never. Tell me if the central claim survives some obvious counterexample, or whether the whole thing is just the precautionary principle re-described.

Also, in your assessment, please be clear about what's actually settled in this literature and what's genuinely contested, and don't present one interpretation of the unilateralist's curse as if it were the agreed view.
