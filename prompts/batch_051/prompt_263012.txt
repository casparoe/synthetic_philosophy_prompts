Consider a variant of the one-shot prisoner's dilemma in which the two players are unsure which of two payoff matrices they are facing. There are two possible states of the world, P and H, each with prior probability 1/2. If the state is P, the payoffs are those of a standard prisoner's dilemma:

                  Other: C          Other: D
    I choose C    (3,3)             (1,4)
    I choose D    (4,1)             (2,2)

If the state is H, the payoffs are:

                  Other: C          Other: D
    I choose C    (6,6)             (4,3)
    I choose D    (3,4)             (1,1)

Thus, in state P defection strictly dominates cooperation for each player, while in state H cooperation strictly dominates defection for each player. Before choosing, each player privately observes a signal about the state. Conditional on the true state, the two players' signals are independent, and each signal matches the true state with probability q, where 1/2 < q < 1. Both players know both matrices, the prior, and q, but neither observes the other's signal.

In the complete-information prisoner's dilemma, the dominance argument delivers (D,D) immediately: whatever the other player does, D yields more. Analyze how this reasoning changes once the state is only privately observed. In particular:

1. For each possible private signal, compute a player's posterior belief about the state, and determine the rule that selects the expected-payoff-maximizing action. Explain why this rule does not require a belief about the other player's action.

2. Characterize all pure-strategy Bayesian Nash equilibria of this game as a function of q. A pure strategy specifies an action for each possible signal, and a Bayesian Nash equilibrium requires each specified action to be a best response to the other player's strategy given the player's posterior.

3. For which values of q is there an equilibrium in which both players cooperate with certainty even when the true state is P? Explain in qualitative terms why cooperation can be rational here despite the fact that, conditional on the state being P, defection would have yielded more no matter what the other player did.
