I've backed myself into a view I can't quite shake, and I'd like someone to try to dislodge me from it. I don't have any philosophy background—I mostly mess around with small language models on my laptop and read interpretability blog posts—so excuse my vocabulary if it's off. The view is this: a trained network isn't just a pile of weights that happens to get the right outputs. It has actual representations inside it, in the sense that there are directions or patterns in the activations that genuinely stand for things—dogs, rhyme, irony, whatever. I sometimes think of a model as having its own internal vocabulary, and interpretability as more like translating that vocabulary than doing an inkblot test on a big matrix. I'm not saying current tools read it perfectly, just that there's a real text there to be read. What tipped me into this was fiddling with a small vision model and finding that if I zeroed out one direction in the activations, the model stopped doing one specific thing while everything else mostly stayed intact. That felt like finding a word, not like projecting my own categories onto noise.

What I want is a map of how exposed that view is. What would have to be true for me to be wrong? I can think of a few things myself—like if two completely different ways of decomposing the same network into features both work equally well and there's simply no fact of the matter about which is right; or if the features people find are mostly an artefact of the probe they aimed at the network, not something the network would use on its own; or if you could train a network on teh same data that behaves identically on every input you'll ever see but has internals that can't be lined up with the first network by any reasonable translation. But I don't know how much weight each of those should carry, and there are probably defeaters I haven't thought of. I'd like to know which evidence would be decisive and which would just be awkward, and whether people who defend the reality of internal representations would themselves admit that some of these would count against them. Also, and I'm willing to have this said about me: has the view been qualified so much that it can't really be tested anymore? Like, if someone says representations are real but only relative to a chosen decoding scheme, is that a deep point or is it just giving up the part that mattered? The thing that would probably move me most is a clean, repeated case where two behaviorally identical models trained on the same data end up with internal vocabularies that don't correspond to each other at all under any sensible translation. If that turned out to be the normal case, I think I'd drop the strong version of my view. But maybe the weak version would survive. I'd like an honest assessment of whether my view is actually risking anything, and if it isn't, whether that's a problem.
