I'm a PhD student in comparative politics, and I'm trying to turn a section of my diss into an article about the outside view, reference classes and the persistence of empires and states. I have a set of notes for the paper and I'd like comments, mostly on whether the central argument is actually new and whether it has an obvious fatal flaw I've missed. Please write your comments in British English.

The working title is something like No outside view for empires (don't worry about the title yet). The claim is that the outside view is usually sold as a way to discipline forecasting by anchoring on base rates from a reference class of similar cases. But when the thing being forecast is something like whether the United States, the EU, China, or the liberal international order survives the next half-century, the choice of reference class is doing almost all the work, and there is no outside-view-compatible way to pick it.

Notes:

- The object being forecast isn't a natural kind. Whether the post-1945 United States is a great power, an empire, a hegemon, or a liberal democratic state is a coding choice, and each choice supplies a different base rate. I want to use illustrative numbers rather than real ones, since real estimates are all over the place.
- The original appeal of the outside view was that it lets you forecast without a causal story about the particular case. But choosing among reference classes seems to require exactly that story. If you call the United States an empire, you've already decided that certain features, like military reach or informal control, are the survival-relevant ones.
- I call this the reference-class regress: to choose a class you need a view about which similarities matter, and that view looks like the inside view coming back through the side door.
- A possible reply is that we don't need one class; we can use several and weight them. But then the weights need justification. Flat weights are not neutral, because treating every class as equally informative is itself a substantive judgement.
- Another possible reply is that the outside view was never meant to eliminate judgement, only to correct overconfidence. If that's the real target, my criticism only hits strong formulations. I'm a bit worried I'm therefore attacking a strawman, or just rerunning the standard reference-class problem from the foundations of statistics and adding the word empire.

What I'd like from you:

- Tell me honestly wich of these notes are doing original work and which are familiar to the point of being unpublishable.
- Is reference-class regress misleading? If so, suggest a better name.
- Can you think of a real objection a defender of the outside view would make that doesn't rely on citations? I want to know if the argument is dead before I spend more time on it.
