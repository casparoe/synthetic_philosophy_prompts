I've been messing around with a side project that ranks scientific theories by how "close to the truth" they are, like a semantic diff between a theory and the world. I wrote a brute-force checker over propositional theories (finite set of atoms, so I can enumerate models), fed it a definition, and it kept outputing a result so weird I assumed I'd coded it wrong. The definition: theory A is closer to the truth than theory B just in case (i) every true consequence of B is also a true consequence of A, and (ii) every false consequence of A is also a false consequence of B, with at least one of (i) and (ii) strict. In words, A has to cover all the truths B covers and not introduce any falsehoods B didn't already have. ("True" and "false" here mean true or false in the actual world; a consequence is a sentence that follows logically from the theory; and a theory is false if it has at least one false consequence.)

But my checker, and then a hand proof, both say that on this definition no false theory can ever be closer to the truth than another false theory. The argument goes:

1. Suppose A and B are both false and A is closer than B under the definition.
2. If A has a true consequence t that B lacks, then since A is false it also has some false consequence f, so A entails t ∧ f, which is false. Since B doesn't entail t, B can't entail t ∧ f. So A has a false consequence B lacks, violating (ii). Contradiction.
3. So A has no true consequence B lacks. With (i), that makes the truth contents equal, so the strict improvement must be on the falsehood side: there is a false consequence b of B that A does not entail. Since A doesn't entail b, there is a model M of A where b is false. And since A is false, the actual world is not a model of A, so M and the actual world differ on some atom; take a literal ℓ that is true in the actual world and false in M. Then b ∨ ℓ is true in the actual world and is entailed by B (since B entails b), but M shows A does not entail b ∨ ℓ. So B has a true consequence A lacks, contradicting (i).
4. Both cases end in contradiction, so no false theory is closer to the truth than another false theory.

That conclusion is insane—Newtonian mechanics is false, but it's obviously closer to the truth than the theory that planets are pushed around by angels. So I'm missing something. My question: is the formal argument valid, and if not, exactly which step fails? If it is valid, which premise is doing the damage, and what should I replace it with? I keep staring at the literal ℓ move in step 3, but I can't find the actual hole.
