Okay so Searle's Chinese Room was supposed to be a knockdown against computationalism: a person in a room follows rules for matching Chinese symbols, passes the Turing test, but understands zero Chinese, so running the right program can't be sufficient for understanding. But the original setup assumes something like a finite set of explicit rulebooks, and the system doesn't learn. We now have LLMs trained on essentially all the text we've produced, with no clean separation between data and rules. Does the Chinese Room argument survive this development?

I can see two pulls. On the one hand, an LLM is still just a bunch of matrix multiplications over token vectors; if the room can implement any program, nothing stops it from implementing a transformer in principle, and the operator would still not know what the Chinese means. On the other hand, the room's rules were written by people who did understand Chinese, while the LLM's weights are learned by gradient descent from corpus statistics, and there's no separate rulebook to point to. So maybe the argument was never about computation in general but about the claim that explicit symbol manipulation is enough.

What exactly would have to be different about the learned, opaque system for the argument to lose its force? If the argument still goes through, what's the strongest version of it now? If it doesn't, is that because computationalism was right all along, or because the argument was aimed at a strawman? And what does this mean for the larger question of whether the brain is a computer, since the brain is also a learned, opaque system rather than a hand-coded rulebook?
