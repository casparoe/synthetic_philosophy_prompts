I'm a reporter on the science desk and I've been going back and forth with a math editor about a gap in a journal's rules, and I want you to help me think it through.

The journal's author guidelines say: "A submitted proof must be surveyable: a single referee, working with no more than ordinary effort, must be able to verify each step. Where a proof relies on computation, the referee must be able to reproduce the computation in full from the published code and input data."

Now take a proof in the style of the four-colour theorem or the Kepler conjecture: a human proves that if every case in a finite list checks out, the theorem follows, and then a computer checks the cases. The list is far too long for any person to work through. The code is short enough to read in an afternoon, a proof assistant has checked that the code really does the check it claims to do, and two independent teams running different code got the same output. But no single human being could ever redo the computation in full, not in a lifetime.

Does that proof satisfy the rule? Walk through the four readings: the plain words, the purpose of the rule, what the people who wrote it would have said if someone had asked them about unsurveyable computations, and what a reasonable referee reading it today would take it to mean. Then tell me what the rule was actually protecting, and wether that thing is still worth protecting when what stands between us and error is a short piece of code plus a proof assistant's kernel rather than a referee's ability to redo the arithmetic.
