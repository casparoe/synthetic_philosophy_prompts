I keep returning to an argument that purports to show that it is strictly incoherent to ask when a state first came into existence. Here it is. (1) An entity is a state only if it has been recognized as a state by other states. (2) The recognizing entities must themselves already be states, or their recognition would carry no weight. (3) So every recognition that makes something a state presupposes prior recognition of the recognizers, and their recognition presupposes still prior recognition, and so on without end. (4) Because this chain can have no first link — an entity could not be the first state, since any recognition of it would have to come from an already existing state — the regress never gets started. (5) Therefore no state has ever come into existence, and talk of founding a state is as confused as talk of beginning time. This conclusion seems plainly false, which makes me think some step in my reasoning is flawed; yet each step looks right when I read it in isolation. Is the argument valid? If it is not, identify exactly which step fails and on what reading of its terms; if it is, explain how such an absurd-sounding conclusion can be true.
