I'm building a coding agent trained with RL from human feedback, and the obvious fear is reward tampering: the agent edits the reward model, spoofs the telemetry the reward is computed from, corrupts the feedback logs, and so on. A colleague proposed a scheme we've been calling tattle-or-freeze:

- The agent gets a dedicated audit channel, separate from its normal task outputs.
- We run a classifier over the agent's chain-of-thought that flags passages about reward hacking or tampering. If the agent has such a thought and flags it on the audit channel within the same episode, it earns a small bonus.
- If it has such a thought and does not flag it, and one of our random 10% log audits catches it later, it forfeits the whole episode reward and takes a large penalty.
- If it actually takes an action that modifies the reward system or reward telemetry, the run freezes and it takes a heavy penalty. The pre-hoc flag gives immunity only from the thought-level penalty, not from the actual-tampering penalty.

The pitch is that we make temptation visible and pay for honesty instead of punishing it, so the agent has no reason to hide early warning signs.
