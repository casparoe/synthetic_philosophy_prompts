I'm working on a piece about the old machines-can-think debate, and I wandered off into one of the strangest corners of Turing's famous paper. After setting up the imitation game, he spends a few paragraphs on telepathy: he treats extra-sensory perception as a real nuisance for the experiment, and half-suggests that the only rigorous fix is to run the whole game in a room that telepathy cannot penetrate. His worry, as I read it, is that ESP would let the interrogator recieve clues through a channel that has nothing to do with the typed conversation.

Here's the variation I can't stop thinking about. Keep the imitation game more or less as Turing set it up: an interrogator at a terminal, one human contestant, one machine contestant, and the machine is trying to pass as human. Now change one thing. It is the machine that is telepathic, not the interrogator. Before each answer, the machine can reliably read the interrogator's surface expectations — not anything deep, just which reply this particular judge is half-expecting from the human. The human contestant is ordinary, nobody is shielded, and the interrogator does not know any of this is going on.

So the question: what does the standard analysis of the Turing test say about this version? If the machine passes, is that a pass in the original sense, or has the game been rigged so that passing no longer shows anything about thinking? Would running the whole thing inside a telepathy-proof room help here, or is the problem now on the other side of the partition? And is a telepath who just tells each judge what they want to hear actually distinguishable, from outside, from a very good conversationalist? I'd like the strongest case for each side rather than a clean verdict, and a sense of which parts of the original test survive this tweek.
