I have been thinking on my own about what a fair voting method would have to be like, and I have settled on a set of convictions. I would like a consistency check, because I cannot locate the difficulty myself.

(1) Once all the ballots are in, the method should always produce a definite ranking of the candidates, no matter how voters filled out their ballots and no matter how many candidates there are.
(2) If every voter ranks one candidate above another, the method should rank that candidate above the other.
(3) How the method ranks two candidates should depend only on how voters ranked those two candidates against each other; what they think about a third candidate should not be able to change that ranking.
(4) No single voter should be able to make the group ranking match their own ballot in every one-on-one contest, no matter how everyone else votes.
(5) If one candidate would beat every other candidate in a one-on-one vote, the method should rank that candidate first.

Each of these seems to me a bare minimum for fairness, but whenever I try to picture a concrete system, I run into trouble. Which of these are genuinely in tension, which only appear to be, and what is the least costly revision? Please rank the tensions by severity rather than treating them all as equal.
