Question (20 points):

"Accuracy-first epistemologists often appeal to strictly proper scoring rules. (a) Define strict propriety and illustrate it with the Brier score. (b) Explain how strictly proper scoring rules figure in dominance arguments against non-probabilistic credence functions. (c) Once the accuracy-first framework adopts a strictly proper scoring rule, does it still have resources to criticize particular coherent priors, or is it committed to permissivism about priors? In answering (c), engage the point that probabilistically coherent credence functions are 'immodest' under strictly proper scoring rules."

Student answer:

"Strict propriety is a condition on a scoring rule: for every probability function p, p assigns itself expected accuracy at least as high as it assigns to any alternative credence function q, with equality only when q = p. With the Brier score — where the inaccuracy of a credence x in a proposition with truth-value v (1 or 0) is (x − v)², summed over the relevant propositions — every probability function expects itself to be uniquely most accurate, so the Brier score is strictly proper. Strict propriety is at bottom a calibration requirement: it says a credence function counts as accurate to the extent that its announced probabilities match the actual frequencies.

This matters for probabilism because, using the Brier score, one can show that any credence function violating the probability axioms is accuracy-dominated: there is some coherent probability function that is at least as accurate in every possible world and strictly more accurate in at least one. Since being accuracy-dominated looks like an epistemic defect, the norm 'do not have accuracy-dominated credences' yields probabilism without simply assuming it.

For priors: under a strictly proper rule, every coherent credence function is immodest — it expects itself to be uniquely best in expectation. It follows that the accuracy-first framework has no resources left to criticize any particular coherent prior; any prior that satisfies the axioms is as rationally good as any other. So accuracy-first epistemology, in its standard scoring-rule form, is committed to a thoroughgoing permissivism about priors: coherence is the only norm accuracy can support there."
