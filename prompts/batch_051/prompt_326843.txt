We set up a four-node version: A and B alternate, and at each node the player can Take or Pass. Payoffs, in (A, B) order: if A takes at node 1, (3, 0); if B takes at node 2, (2, 4); if A takes at node 3, (5, 3); if B takes at node 4, (4, 6); if B passes at node 4, the game ends and it's (7, 5).

My friend walked me through this argument:

(1) At node 4, B gets 6 by taking and only 5 by passing, so a rational B takes.
(2) At node 3, A knows that if A passes, rational B takes at node 4 and leaves A with 4; by taking now A gets 5, so rational A takes.
(3) At node 2, B knows rational A takes at node 3, so passing leaves B with 3; by taking now B gets 4, so rational B takes.
(4) At node 1, A knows rational B takes at node 2, so passing leaves A with 2; by taking now A gets 3, so rational A takes.
(5) So two perfectly rational players stop at the very first move and end up with (3, 0), even though they'd both be better off (7, 5) if they just passed the whole way down.

My friend says the whole thing breaks somewhere around step 3, because by the time A is actually at node 3, B has already passed at node 2 — which the argument itself says a rational B would never do — so A cant go on assuming B is rational.
