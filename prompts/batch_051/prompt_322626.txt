A friend walked me through an argument that seems to show that expected-value reasoning collapses for any gamble with infinitely many possible outcomes, and I can't find the exit.

(1) The expected value of a gamble is the sum over its possible outcomes of each outcome's payoff weighted by its probability.
(2) Consider this gamble: flip a fair coin until it lands heads for the first time. If the first head occurs on toss n, you receive $(−1)^(n−1) · 2^n / n.
(3) Listed in the natural order n = 1, 2, 3, ..., each outcome contributes (−1)^(n−1)/n to the expected value, giving 1 − 1/2 + 1/3 − 1/4 + ..., which converges to ln 2, about $0.69.
(4) By Riemann's rearrangement theorem, those same contributions listed in a different order can be made to converge to any real number, or to diverge to +∞ or to −∞.
(5) The order in which one lists a gamble's outcomes is mere bookkeeping; what a gamble is, and therefore its expected value, cannot depend on such a listing.
(6) Therefore this gamble has no well-defined expected value: the ln 2 figure is an artifact of one arbitrary listing.
(7) But the coin-toss construction does no real work. The same issue arises for any gamble with infinitely many possible outcomes, since its expected value is an infinite sum, and an infinite sum is always at least potentially sensitive to the order of summation.
(8) So no gamble with infinitely many possible outcomes has a well-defined expected value.
(9) Yet decisions about investments, insurance, health, and climate routinely use expected values over quantities that can take infinitely many exact values. So either such applications are unfounded, or one of (1)–(8) must go.

I most want to keep expected-value reasoning in the real-world cases described in (9), but I can't see how to block the step to (8) without special pleading. Which step, if any, should I reject, and what does rejecting it cost? Please answer in American English.
