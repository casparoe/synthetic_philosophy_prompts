I keep coming back to a game-theory idea I once covered for a piece, 'program equilibrium.' The argument goes like this: take a prisoner's dilemma, but instead of two people deciding in real time, the players are programs, and each program can read the other's source code before choosing. Then mutual cooperation is supposed to become rational, because each side can run a conditional rule — I cooperate if and only if the other program would also cooperate against my source. If I unilaterally defect, the other code sees that and defects back, so I can't profit. The whole thing seems to stand or fall on a transparency assumption: the other player's actual policy is legible in the source.

But the 'programs' actually running the world now — LLM agents and other deployed models — are opaque neural nets. Reading the source code tells you nothing about what the agent will do; it's behavior shifts with the prompt, the system message, a fine-tune, the sampling temperature. So does the program-equilibrium argument survive that change? Is the transparency premise a load-bearing wall, or can the same kind of cooperative commitment be rebuilt some other way — through explicit contracts, cryptographic commitment schemes, verifiable reasoning transcripts, something else? And if the argument only survives in a weakened form, which part of the old result is doing the work and which part has to be abandoned?
