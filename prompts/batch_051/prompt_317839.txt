I'm running a small reading group on time, freedom, and fatalism, and people keep talking past each other about Aristotle's sea-battle passage because they're answering different questions without noticing. I'd like a sorting handout — a short quiz with a scoring key, presented as a decision tree — that drags those differences into the open before we read the named positions. Build it around the old example in which we ask whether the sentence that there will be a sea battle tomorrow is already true today, even though nothing about tomorrow is settled.

The tree should end in these leaves: Ockhamism, the thin red line view, Peirceanism, a truth-value-gap or three-valued view (Łukasiewicz-style; add supervaluationism as a separate leaf only if you think it earns one), and logical fatalism as the box you land in if you conflate truth with necessity. Each diagnostic question should probe exactly one of three things that get run together: whether future-tensed sentences have a truth-value today, whether having one would settle the future or make it necessary, and what the word 'will' actually asserts — the actual future course, or every still-open branch. Use concrete cases: the sea battle, a bet on a coin toss, a predictor or god who knows the full actual future, a promise that gets broken, a forecast that turns out wrong. Phrase each question so someone can answer without knowing which position it nudges them toward. Build the tree from the logical space first (bivalence or gap; strong or weak 'will'; truth versus settledness), then locate the positions in that space, and for each empty combination say whether it's empty because the view is incoherent, unattractive, or merely underexplored.
