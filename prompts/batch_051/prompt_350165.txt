Question: A textbook describes the genetic code as a cipher that translates the sequence of bases in a nucleic acid into the sequence of amino acids in a protein. Some people take this to show that DNA (or mRNA) carries semantic information, the way a sentence or a blueprint means something. Does the fact that the genetic code is called a code show that DNA carries semantic information? Explain, being explicit about what a code is and what semantic information would require.

Student answer: Yes, but in a qualified way. A code is a systematic mapping between two sets of symbols, and the genetic code maps 61 sense codons plus 3 stop codons onto 20 amino acids, with degeneracy. What makes it a real code is that the mapping is arbitrary: UUU specifies phenylalanine, but there is no chemical necessity that it do so, since the assignment is implemented by tRNA synthetases and could have differed in another lineage. Arbitrariness is exactly what seperates a real code from a merely causal correlation, since causal correlations are fixed by physical law, whereas in a code the mapping is set by convention. Morse code maps dot-dash patterns to letters, and .- means A only because of a convention among telegraph operators, just as UUU means phenylalanine only because of a biochemical convention. So the genetic code carries semantic information: a gene for hemoglobin is about hemoglobin in the same way a recipe is about a dish. The only real difference is that the convention was stabilized by natural selection rather than by human agreement, but natural selection can act as a convention-fixing process. So the code metaphor is not merely metaphoric, and DNA literally carries semantic information.
