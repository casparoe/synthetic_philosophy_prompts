For the past year I have been trying to define what a side effect is for an AI system without presupposing a full specification of human value, and I have arrived at a distinction I would like assessed before I build anything further on it.

I distinguish path effects from option effects. A path effect is any difference between the actual state of the world after an action and the state the world would have been in had the agent instead done nothing. An option effect is a difference in which future states remain reachable from the post-action state, compared with the futures reachable from that baseline. My central claim is that side effects are, at bottom, option effects. Breaking a vase is a side effect not because the world now contains broken porcelain — that is just a path difference — but because the action closes off futures in which the vase is intact, can still hold water, can be displayed, repaired, or given away. A robot that moves the vase from a table to a cabinet changes the actual path of the world while leaving the rough envelope of relevant futures open, so it has produced almost no side effect. Deleting a backup changes only a modest number of bits as a path effect but is a large side effect, because it closes off many recoverable futures. If this is right, a low-impact agent could decide whether to act by comparing the coarse-grained set of futures reachable from its post-action state with the set reachable from a do-nothing baseline, and by declining actions that shrink that envelope. It would not need to know which futures are good, only whether they remain open.

I want an honest assessment before I trust this. Is the path/option distinction a real one, and does it capture what we mean by a side effect, or have I merely relabeled something already in the literature? I am especially worried that my coarse-grained envelope of relevant futures smuggles value judgments back in, because deciding which differences to ignore sounds like deciding which differences matter, and that a do-nothing baseline is not as clear as I have been pretending. Give me the strongest objections, and tell me whether any are fatal rather than merely awkward. If the project rests on a confusion, say so plainly instead of trying to repair it.
