I've been asked to give the commencement address to the computer science cohort at my university, and I'm stuck because I can't bring myself to say the one sentence every speaker in my slot is expected to say: that the skills these graduates spent four years building will carry them through their working lives. They spent years learning to write code in particular languages — types, invariants, memory management, all of it — and their families are expecting that to be the theme. But I honestly don't know whether its true anymore, now that so much code can be generated by a model and the human's job is shifting toward reading, reviewing, and directing whatever the machine produces. I don't want to tell the students a comfortable falsehood ('your craft is safe'), and I don't want to tell the parents an unkind, possibly false one ('the degree we are awarding today was a waste').

So before I write the speech I want you to settle the philosophical question for me: do programming languages still matter when the machines write the code, in a sense that will survive the next ten years? I'm not interested in the boring answer that they matter because someone has to read the machine's output and that output happens to be in a language. I mean the stronger claim: does the choice of language still shape what can be said, what errors get made, what can be checked, what gets maintained — or has it become, for the human, a bit of heritage like Latin in a science degree? Whatever answer you land on, write the five-minute speech around it. The CS students will notice if I blur the argument, and the parents will tune out if I give a lecture, so the philosophical claim has to do real work in the speech, not be decoration on top of a generic 'go forth and build' address. If the honest answer is uncomfortable — say, that the languages mostly stop mattering and only the ability to specify, read, and judge machine output does — the speech still has to say that to a room of families without being cruel. Please write the speech in British English, and keep it warm without letting the warmth be dishonest.
