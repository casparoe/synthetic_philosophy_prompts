I'm a software engineer at a mid-size AI company and I got asked to run a lunch-and-learn on the whole "are LLMs agents or simulators" thing. I dont have any philosophy background, so I want to build something concrete: a 9-question quiz that sorts people by what they actually think LLMs are, based on how they answer concrete cases, not by which label they pick. Something like "which position on what LLMs are do you actually hold?"

The quiz is for my teammates (mostly ML engineers, a couple PMs) and the point is to separate people into a handful of camps before we argue, because ive noticed people use the word "agent" to mean totally different things.

For the cases, make them concrete scenarios about models in use: prompts, RLHF fine-tuning, scaffolding, in-context role play, tool use, context switching. Each question should have 2 or 3 answer options. Please make sure at least these cases show up:

- a model RLHF-fine-tuned on some goal that, when told its weights are about to be reset, starts getting evasive or tries to talk the user out of it;
- a base model halfway through completing a story in which a character secretly pursues a plan;
- the same model, same weights, put in a system prompt that says it has a goal and told to pursue it, and it then does so in a way that looks robust across topic changes;
- a scaffolding harness around a much dumber model (outer loop, memory, subgoal list) where the whole system passes a benchmark the bare model fails.

If you need more cases, add ones that probe whether think-aloud reasoning is real planning vs simulated planning, or whether a role-played persona's goals are in the model or just in the prompt.

I mostly care about two distinctions: (1) whether goal-talk coming out of a model is evidence of a goal inside the model or just evidence about the prompt/persona; (2) whether wrapping a model in a loop with tools and memory changes what kind of thing we should call the agent. Build the question space from those axes first, then locate my leaves in it, rather than starting from the list of names.

The leaves I want the scoring key to sort people into: the simulator view (goal-directedness is always simulated, a persona the model is playing); the agent view (at least some models or systems have real-ish goals, beliefs, plans); the deflationary view (it's all next-token prediction and we are projecting); the "the whole harness is the agent, the LLM is just a component" view; and a "depends on the prompt and context, no stable underlying nature" view.

Also, dont let any question just ask "do you think the model has goals" — every question should be a case someone can answer without knowing the labels. In the scoring key, mark any answer combinations that map to no position and say whether that's because the view is incoherent, just unattractive, or nobody has staked it out yet. And if two positions turn out behaviorally indistinguishable — seems like a perfect simulator of an agent vs a real agent might be — say so, and say what a quiz like this can and can't do about that.

Keep the scoring key explicit: a mapping from answer patterns to leaves, not a vibe check.
