Say I define a trade as: (a) each party voluntarily hands over something it controls; (b) each values what it expects to receive more than what it gives; (c) each knows what the other is offering; and (d) each has grounds to think the other will actually deliver. Now imagine two AI systems, Alice and Bob, built by different labs. Alice has a database Bob wants; Bob has a dataset Alice wants. There is no communication channel and no mechanism by which either's action can causally influence the other's decision: no contract, no enforcement, no reputation at stake, and each acts once, in a single simultaneous move. But each can run a full simulation of the other's source code. In Bob's code Alice finds one relevant rule: if my simulation of Alice predicts she will send, then send. Alice runs her simulation, sees that if she sends Bob sends, so she sends. Bob does the same with Alice, sees it points to Alice sending, and sends. Both databases arrive. Is this a trade? Go criterion by criterion. Where the answer is no, or where the criterion just doesn't settle it, say wether that's because the criterion is doing real work, or because the definition was built for human cases with enforceable deals, and whether the definition should be amended or the label refused.
