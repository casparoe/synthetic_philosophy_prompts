In our philosophy of quantum mechanics course we have been working through the quantum suicide/quantum immortality thought experiment. I want to see how much of the standard argument survives a change to the setup. Take the usual version: an agent who accepts the many-worlds interpretation sits in a machine that, on each round, measures a two-outcome quantum observable; one outcome triggers immediate death and the other merely clicks, and the rounds repeat. The standard argument says the agent should expect to survive every round, because each round produces a branch in which they live and there is no one in the dead branches to have the experience.

Now alter one thing. In each round, instead of equal amplitudes, let the live outcome have squared amplitude 0.01 and the dead outcome 0.99, and let the agent run 100 rounds. On a branch-counting reading, there is still a branch in which the agent survives all 100 rounds; on a measure-based Born-rule reading, that branch has measure 10^-200. Does the standard quantum-immortality argument survive this variation? That is, should the agent still be subjectively certain of survival, or does the unequal-amplitude version reveal that the argument depends on a contested move from branch weights or branch counts to rational credence?

Please mark exactly where the reasoning turns. In particular, say (i) what would change your mind about the verdict — which alternative account of the relation between branch measure and subjective probability, or which interpretation of self-locating evidence, would flip it — and (ii) where your own reasoning is most likely to fail.
