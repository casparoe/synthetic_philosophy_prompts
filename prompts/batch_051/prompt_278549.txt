I've been mulling over Galen Strawson's Basic Argument against moral responsibility, the one that goes something like: you act from the way you are, so to be truly responsible for your actions you'd have to be truly responsible for the way you are. But to be responsible for the way you are, you'd have had to choose it in some earlier act, which would itself have issued from a still earlier way you were, and so on. The regress never bottoms out in a self-caused chooser, so nobody is ultimately morally responsible.

I can't shake the resemblence to how people assign blame for a misbehaving machine learning system. When a deployed model produces a harmful decision, everyone agrees the model itself isn't responsible — it didn't choose its weights — so you look upstream. Someone chose the architecture, the training data, the loss function, the reward shaping, the deployment conditions, and so on. But under Strawson's argument each of those human choices is the same kind of thing: it issued from who that engineer was, which traces back to their training, socialization, genetics, and luck. So the same regress that is supposed to exonerate the model would, if you actually kept going, seem to exonerate everyone in the chain. Yet in practice we stop the regress at some human or institution and call that the responsible party.

Is this a deep parallel — maybe both cases show that responsible agency has to be assigned by a pragmatic stop in a causal chain rather than discovered at its origin — or is it superficial? In particular, does the ML case break the analogy because a model is an artifact and a human is an agent in a way the model is not, and if so, what exactly is the disanalogy doing the work?
