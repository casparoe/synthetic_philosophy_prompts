Two people in my board game group got into a long argument during a game of Nomic. The rules in force at the time were:

1. Any rule may be changed by a two-thirds vote.
2. Rule 2 may be changed only by unanimous vote.

The catch is that Rule 2 itself had been adopted earlier that evening by a two-thirds vote. Toward the end of the night, Priya proposed Rule 3, which simply said that Rule 2 is deleted. The argument went roughly like this.

Priya: Deletion isn't the same as change. Rule 2 only restrict votes that change Rule 2; my proposal deletes it, so Rule 1 applies and I need two-thirds.

Tom: That can't be how the game works. Deleting a rule is as much a change as adding one. Your proposal changes Rule 2 by removing it, so Rule 2's own procedure controls: you need unanimity.

Priya: Then Rule 2 has entrenched itself against future majorities, but that entrenchment was put in place by a two-thirds vote. A two-thirds majority can't just decide that two-thirds majorities will never again be enough. That's bootstrapping.

Tom: All rules bootstrap, that's what it is to have a rule. Once Rule 2 is in force, the only legal way to remove it is the way Rule 2 prescribes. Procedures don't have to be symmetrical.

Priya: But if a two-thirds vote could create the unanimity requirement, then a two-thirds vote should be able to un-create it, because both are the same kind of act: a two-thirds vote about Rule 2. The first one changed Rule 2's amendment rule; the second changes it back.

Tom: No. The first vote happened when Rule 2 was just a proposal. The second would happen when Rule 2 is already law. 'Already law' is doing all the work. The first vote set the procedure that now binds you; it didn't leave a standing power to reset it.

Priya: Then the players have a power they can use exactly once and never revoke. That's not a game rule anymore, it's a one-way door. A game whose rules can be changed by two-thirds can't contain, as a valid internal move, the permanent destruction of that very power.

Who's right at each step, and who's right overall? Can this be settled from the rules themselves, or only by deciding what kind of game they thought they were playing? Where does each argument genuinely bite, and where do they talk past each other.
