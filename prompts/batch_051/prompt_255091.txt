In my AI reading group, the same arguement about whether LLMs are agents, simulators, or something else has been going in circles for months. The agent camp points to goal-directed behavior, planning, tool use, and the fact that psychological descriptions seem to earn their keep: saying the model wants the task done a certain way predicts its next moves. The simulator camp replies that all of this is just the model simulating an agent character, and the underlying system is only a distribution over token continuations, so the agency is a property of the character in the text, not of whatever is sampling the text. Agent camp fires back that fine-tuned assistants are trained to persist across contexts and hold commitments, so simulator is just agent with extra steps. Simulator camp says the persistence is itself simulated: change the system prompt and the identity evaporates, which wouldn't happen for a real agent. I have a hunch the two sides are not always talking about the same thing, since sometimes the LLM means the base weights, sometimes the whole system of weights plus context plus scaffolding, sometimes the character in the dialogue, but I'm not sure that dissolves the debate, because they also seem to disagree about what should count as evidence here: mechanism or behavior. Diagnose what kind of disagreement this actually is, and given the diagnosis, say what would count as progress: a sharper distinction, an experimental or interpretability result, a formal claim, or a reason to think none is coming.
