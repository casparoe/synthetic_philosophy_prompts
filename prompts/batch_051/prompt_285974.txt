You're a lawyer-philosopher and an expert on software licensing. I want you to really think this through, not just pattern-match to the usual GPL talking points. Start by brainstorming several candidate stopping points, then defend whichever one you think is least wrong.

Take the old Ship of Theseus problem and run it on a codebase. Suppose a project called Origo is distributed under the GPL. Its maintainer decides to rewrite it in place: every month she replaces one 40-line function with an equivalent one. Release 1 differs from the original by just that one function; by release 100, no line of the original remains. The function names, the interfaces, the overall architecture, and even a written spec of what each function is supposed to do all carry over from the original, but every line of implementing code is new.

Here is the variation I care about. In one world, each replacement function gets written by a contractor in a clean room, working only from the behavioral spec and never seeing the old code. In another world, the maintainer writes each replacement herself while looking at the old function: she keeps the logic but renames variables and shuffles some statements. And in both worlds, the last remaining piece of the old code is a one-line comment at the top of a file, something like initialize the planner before parsing input.

Now, the standard copyleft line is that the license obligations attach to any work that is derivative of the GPL'd code. So at some release, if ever, the project stops being a derivative work of the original Origo and becomes the maintainer's own program. Where is that line? Does the clean-room world and the look-at-the-code world give different answers, or does the difference wash out once no original expression survives? And is there really a fact of the matter here, or is derivative work in copyleft just a sorites predicate with a flat, arbitrary cutoff that practice tries to dress up as a legal test? If you had to pick a stopping point, which one is least wrong—and, wether it lands early or late, tell me if that line tracks anything principled.
