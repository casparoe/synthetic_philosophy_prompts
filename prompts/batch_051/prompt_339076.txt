I have been trying to think through Douglas Hofstadter's claim that creativity is largely a matter of knob-twiddling: that a maker produces something new less by summoning it out of nothing than by taking an existing pattern or concept and varying its parameters—turning one knob up, another down, recombining settings that had never been combined, or pushing a single parameter to an extreme. A friend recently defended the view with the following argument, and I cannot tell whether it is stronger than it should be or just refreshingly unsentimental.

(1) A work is genuinely creative only if it contributes something that was not already present, even implicitly, in the prior tradition.  
(2) But any feature of any work can be located in a space built from knobs on earlier works: it is some combination of amplifying, reducing, inverting, recombining, or otherwise perturbing elements that were already there.  
(3) If a feature can be located in such a knob-space, then it is merely a variation on what already existed, not a genuinely creative contribution.  
(4) Therefore, no feature of any work is a genuinely creative contribution; all apparent originality is knob-twiddling.  
(5) So the romantic picture of the creator who invents something from nothing is false—which, my friend says, we should accept rather than treat as a reductio.

I half-suspect that step (2) is doing more work than it admits: the knob-space sounds as if it gets constructed only after we have already seen the new work, with a fresh knob added whenever the old knobs fail to reach it. Is the argument valid? If it is, does the conclusion actually deflate creativity in the way it sounds? If it is not, state exactly which step fails, give the strongest corrected version of that step on which the argument would go through, and say whether the corrected argument still proves the conclusion or merely registers a truism.
