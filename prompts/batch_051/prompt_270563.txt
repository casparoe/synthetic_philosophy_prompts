I'm putting together a list of counterexamples to the simple conditional analysis of dispositions for a seminar. The simple analysis says: x is disposed to M in conditions C iff, if x were placed in C, x would M. So being fragile just means the thing would break if it were struck.

So far I have five:

1. Finks. A fragile vase has a sorcerer standing by who would remove its fragility the instant it was struck. If it were struck, it would not break, but it is fragile.
2. Reverse finks. A non-fragile object would be made fragile by a sorcerer just before a strike, and then break. It would break if struck, but it is not fragile.
3. Masks. A fragile glass is wrapped in bubble wrap. If it were struck, it would not break, but it is still fragile.
4. Antidotes. Someone has swallowed a lethal poison but an antidote is standing by. If the antidote were withheld, the person would die; with it, the death would be stopped. The poison is still lethal either way. I know some people treat antidotes as a kind of mask.
5. Mimics. A non-fragile object is attached to a machine that would shatter it as soon as it detected a strike. It would break if struck, but it is not fragile.

I want one more that is genuinely different in structure from all five — in particular, not another case that just adds an external intervener (sorcerer, bubble wrap, antidote, machine) to break the link between stimulus and manifestation. Say what it shows that the five do not, and then be honest about whether it is really a distinct problem for the simple analysis or whether the simple analysis can absorb it with a small tweak. British English please.
