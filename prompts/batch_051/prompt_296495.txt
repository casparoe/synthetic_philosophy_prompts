Student answer: "Strawson's Basic Argument says that in order to be morally responsible for a given action, you'd have to be responsible for the mental states that produced it — your beliefs, desires, values, and so on. The action is just the causal upshot of those states, so responsibility for the act presupposes responsibility for the states. But being responsible for a mental state would mean you had chosen to have it. And any choice to have a mental state would itself have to come from mental states you already had. If we then ask whether you're responsible for those earlier states, the same problem repeats forever. So the only thing that could stop the regress is if you were causa sui, the cause of yourself, which is impossible. That's why Strawson thinks no one is ultimately morally responsible. The argument doesn't rely on determinism, by the way, because adding an undetermined event doesn't give you any more control — a random happening isn't something you own. The standard compatibilist response is that Strawson is using an impossible standard: everyday moral responsibility doesn't require self-creation, just that your action came from your own reasons and values in the right way, which is what Fischer calls reasons-responsiveness. I think this reply works. If an action came from a person's settled character, and they could have done otherwise if they had wanted to, then they're morally responsible in the only sense we should care about."
