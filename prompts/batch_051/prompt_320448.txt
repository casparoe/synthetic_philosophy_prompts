I keep going back and forth on the "epistemic backstop" idea about recordings. The rough argument: when testimony conflicts or seems fishy, video/audio acts as a backstop because the causal path from scene to sensor is hard (or at least expensive) to fake well enough, so the cost asymmetry does real epistemic work. Deepfakes were supposed to break that. But here's the development: capture devices and platforms are starting to attach cryptographic provenance, signed at the sensor with an edit history, so a clip can carry a verifiable chain saying it was actually recorded in that way and not synthesized. I cant tell whether the original argument survives this, gets repaired, or dies. If the point was cost asymmetry, provenance seems to restore a version of it—but only if people actually check certificates, which feels shaky. If the point was the causal link between light and sensor, then the backstop might survive even if nobody checks, but I'm not sure that was ever the argument. Which premise is doing the work, and is the repaired version weaker in a way that matters? Keep clear what's actually settled here and what's genuinely contested; don't present a contested answer as the consensus.
