ok so I've been arguing with a friend about simulated minds and I keep ending up stuck. Here's the setup. Suppose we can simulate a mouse's brain neuron-by-neuron, with the electrochemistry replaced by faithful software, and the simulation is in a state that, in a real mouse, would be pain — injury signals coming in, the simulated body flinching, the whole nociceptive machinery lit up. Grant everything for the sake of argument.

On one side, the functionalist in me is convinced. If suffering is about what a system does rather than what it's made of, then this thing suffers too, and saying it can't because it's made of silicon instead of carbon is the same kind of chauvinism as saying someone can't suffer because of their species. If you swapped a real mouse's neurons one at a time for tiny chips that performed the same function, I'd say the mouse is still there at the end, still hurting — and the pure simulation is just that endpoint. So the theory says: it has the same moral status, and running it for fun is the same kind of wrong as hurting the mouse.

But then I picture it as it actually is: a file on a computer, deterministic, pausable, copyable, deletable. And my gut says it doesn't matter in the way the mouse matters. If someone told me "I ran ten thousand copies of a suffering mouse overnight," I woudln't feel anything like the sickening thing I'd feel about ten thousand actual mice with pins in them. The code looks like it's describing suffering the way a novel describes suffering, not instantiating it. And I don't think that reaction is mere carbon chauvinism: it might be tracking that the simulation has no body, no life, no history, no stake in continuing, and that one of those things matters for moral status more than the functionalist admits.

So I'm torn, and I don't think both can be fully right. Which should yield, and why?
