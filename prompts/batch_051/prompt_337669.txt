I read a blog post on program equilibrium and I'd like a check on how much of it I should trust. Here's its explanation. In a one-shot prisoner's dilemma where each agent can submit a program, and each program gets to inspect the other's source before choosing, you can write a program that says: cooperate exactly if the other player's program is identical to mine, otherwise defect. If we both run that program we both cooperate, and if either of us switches to a defecting program, the other reads it and defects too, so the switcher isn't better off. The post says this shows defection is irrational in transparent one-shot dilemmas, so cooperation is the unique rational outcome. My instinct is that the last step is too strong — wouldn't always-defect still be an equilibrium? — but I'm not sure how much of the rest survives. Could you go through the explanation and tell me what's accurate, what's overstated, and whether the 'unique rational outcome' conclusion follows from anything true in it?
