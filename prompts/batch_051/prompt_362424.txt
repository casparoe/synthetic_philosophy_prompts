i work on RL systems, mostly reward models for language models, and the whole setup treats 'good' as a scalar: you learn a reward function from preference data and then optimise against it. the longer i do this the more attractive i find the view that human values are really one thing in disguise — that honesty, loyalty, kindness and so on are just different strategies or framings for increasing the same underlying quantity, the way one scalar utility function can rationalise a huge amount of behaviour. the appeal for me is that it gives a decision procedure: when values conflict, in principle there's always a trade-off and a gradient to follow. but i also have an intuition that wont go away. if a close friend tells me something in confidence and breaking that confidence would genuinely help someone else, it doesnt feel like i'm comparing two amounts of the same stuff. it feels like two different kinds of demand, and treating 'pick the higher expected value' as the whole story feels like it flattens something real. i can scalarise objectives in code with weights, but choosing the weights feels arbitrary in a way that no amount of data fixes, which makes me suspect the scalar is doing the conflation rather than discovering a real common currency. i'm not asking you to tell me which side wins. i want to know what it would take for the intuition to be the thing that goes, what it would take for the monist scalar view to be the thing that goes, and whether there's a reading on which both survive — say, one underlying currency with many incommensurable ways of tracking it. please answer in british english.
