Me and a few friends play a game where the rulebook is itself part of the game. One of the rules says: any rule can be changed if a majority of players vote for it. Since that sentence is itself a rule, it can be changed too — we could vote to make amendments need a unanimous vote, or vote to make some rule impossible to change, or even delete the amendment rule entirely. We actually argued for an hour about this. If we use the amendment rule to switch to unanimous amendment, did the old rule authorize the new one, so the old rule is somehow still working at the very moment it gets replaced by something that says the old way was wrong? And if we delete the amendment rule, what authorizes us to ever bring it back? It seems like we'd have to break the very idea that changes need authorization. Then someone said that if any rule can be changed, we should also be able to change the scoring rule after the game is over and make the loser the winner. That feels different, but I cant say why without assuming rules point forward in time or something.

So I'm trying to figure out: what view of what a rule is does this sort of game presuppose? Is it committed to rules being nothing but whatever the text currently says, or does it secretly depend on something outside the text — like our shared acceptance or the act of voting — that no written rule can amend? And if you swapped in a different picture, where rules are commands from an authority the players don't control, what would have to change about the game for it to still work?
