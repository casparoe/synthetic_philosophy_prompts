I'm in an epistemology seminar and I've written out an argument that I now dont trust, because it seems to prove too much. It was supposed to be an objection to Nozick's tracking theory, but if it works it looks like it takes down every method- or basis-relative account of knowledge, which can't be right. Here it is as I have it.

(1) On Nozick's view, S knows p only if S's belief that p is sensitive: roughly, if p were false and S used the same method M that S actually used, S would not believe p via M.
(2) For that to be a real condition, there needs to be a fact of the matter about which method S actually used; otherwise the "same method" clause has no content.
(3) But there is no such fact independent of how we describe or type the method.
(4) For any true belief, we can describe the method finely enough to make sensitivity trivially satisfied. Let M1 be "believe p iff p." If p were false, M1 would not output belief in p, so the belief is sensitive.
(5) Or we can describe the very same belief coarsely enough to make sensitivity trivially fail. Let M2 be "believe p no matter what." If p were false, M2 would still output belief in p, so the belief is insensitive.
(6) Since nothing in the tracking view picks M1 over M2 as the method the subject really used, the sensitivity condition gives no determinate verdict for any belief.
(7) So tracking theory is contentless. In particular it can't explain the closure failure Nozick wants (knowing you have hands but not knowing you are not a brain in a vat), because which descriptions count as "the same method" is itself up for grabs.
(8) The same move applies to any view that relativizes knowledge to a method, process, or basis: safety views with their "same basis" clauses, process reliabilism, virtue epistemology's competences.
(9) So all those views are contentless too. But that is absurd; whatever their problems, they clearly say something determinate.

Where does this argument go wrong, if it does? Which premise or step should I reject, and what does rejecting it cost? I'd most like to reject (9), but I don't see how the earlier steps stop short of it, so I want to know exactly where the overreach happens and what a tracking view would have to add to block it.
