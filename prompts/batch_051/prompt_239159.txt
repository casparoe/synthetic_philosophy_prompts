I'm a journalist who covers science and ideas, and I've been reporting on the forecasting movement—people who think you can improve judgments about politics and history by starting with base rates instead of stories. The move I keep hearing is the outside view: when you're asked how long a current arrangement will last, don't simulate the particular case, find a reference class of similar cases and start from its base rate. The method was built for planning projects—buildings, software, infrastructure—where there are hundreds or thousands of roughly similar past examples. Lately I've been watching people extend it to the lifespan of great powers: gather the past empires and dynasties, compute how often they collapse within a given number of years, and adjust from there. And I've started to think this extension quietly breaks the argument, but I can't figure out which part breaks. The reference class isn't large; it's a few dozen cases spread over millennia. The cases arn't independent, since Rome's fall shaped how later states built themselves, and everyone involved has read about earlier collapses. The list is also retrospective: which polities get called empires depends on the outcome we're trying to predict. And once leaders themselves start reading base-rate research, the base rate can move—like a poker player adjusting after studying their own tells.

So: does the outside-view argument survive when it is imported into history, or did it need a large, roughly exchangeable, stable reference class all along? I'm not asking for an actual forecast of any country. I want to know which premise is now under pressure, whether it can be repaired (for instance, by using the outside view only to set a wide prior or to check inside-view stories for overconfidence), or whether the honest conclusion is that this class of cases is too small and reactive for base-rate reasoning to do its normal work.
