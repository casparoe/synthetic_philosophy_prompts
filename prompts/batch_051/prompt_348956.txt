Design a runnable classroom game for a philosophy-of-science seminar of about twenty students in a single seventy-five-minute session. Participants should leave having felt, rather than only heard, the no-free-lunch structure of inductive prediction: a deterministic forecasting rule that wins on some binary sequences loses by a compensating amount on others, so no rule dominates across all possible data streams, and the apparent success of learning the regularities one has seen so far is a bet on what kind of world one is in rather than a universally valid privilege.

The activity should use online prediction of a fixed-length binary sequence. Small teams each commit publicly to a deterministic rule for predicting the next bit after seeing the earlier bits. Permitted rules should be fixed functions of the observed history—for example, always predict 0, always predict 1, repeat the last observed bit, alternate with respect to the last observed bit, or some simple history-sensitive rule of the team's invention. The hidden sequence is fixed or generated in advance, revealed bit by bit, and teams earn points for each correct next-bit prediction; stakes should be symbolic rather than real money.

Arrange the rules, score sheets, sequence selection, and order of play so that participants themselves compile a tally across all 2^n possible hidden sequences of length n and thereby discover the central fact before it is named: every deterministic rule earns exactly the same total score over the full set of possible sequences, since at each position exactly half of the still-compatible continuations contain 0 and half contain 1. The instructor should not announce this result; it should surface from the tally and from the teams' own attempts to explain why a rule that looked clever earlier failed later.

Your plan should specify the exact rules and materials, a payoff or privilege scheme that does not use real money, and how the room should be run within the session. It should also provide a debrief that maps specific moments of play to (a) the combinatorial fact above, (b) the no-free-lunch idea in learning theory—no learner is better than any other when averaged over all possible target functions or data streams—and (c) the problem of induction: however well a rule has done on the bits seen so far, that record underdetermines the next bit, and any pattern of past success is compatible with failure next. Finally, say what will predictably go wrong the first time the activity is run and how the facilitator should handle it, and be frank about what the activity cannot reproduce—in particular, the uniform average over all possible binary sequences is one specific and arguably unreasonable measure of possible worlds, so the game must not be allowed to suggest that all real inductive practices, with their priors and constrained model classes, are equally good.
