So I'm in a formal epistemology course and we just did the accuracy-first argument for conditionalization, and I'm pretty sure I've found a hole in it, but every time I try to explain it to my TA it comes out sounding dumb. Here's the argument as I understand it:

(1) Accuracy—having credences close to the truth—is the only fundamental epistemic good, so a rational agent should always choose whatever credence function has the highest expected accuracy.

(2) Accuracy is measured by a strictly proper scoring rule. All that means is: for any probability function c, c itself is the unique function that maximizes expected score by c's own lights. (The Brier score is the standard example.)

(3) So, by (2), my current credences are already the credence function I expect to be most accurate.

(4) Learning some evidence E doesn't change the fact in (3): my old credence function is still, by my old lights, the one that maximizes expected accuracy.

(5) So if I'm just trying to maximize expected accuracy, learning E gives me no reason to move off my old credences.

(6) But conditionalization says that after learning E I should move to my old credences conditioned on E, which is usually a different function.

(7) So accuracy-first epistemology either can't vindicate conditionalization, or it has to add some extra rule like "you must assign probability 1 to whatever you learn"—but that extra rule isn't itself about accuracy, so adding it definately feels like giving up on accuracy being the only epistemic good.

I'm pretty sure the move from (4) to (5) is where something sneaky happens, but I can't articulate exactly what. Is the argument valid? If not, which step fails, and can the accuracy-first person add the "certainty about the evidence" constraint without it just being a back-door way of assuming conditionalization? Be specific about the step and the reading of it.
