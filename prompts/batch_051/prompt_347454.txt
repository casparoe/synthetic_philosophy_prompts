I've ended up fairly convinced that an optimiser's objective is massively underdetermined by its behaviour. For pretty much any policy you observe, you can invent some reward function — plus a search procedure, priors, and resource constraints — that would produce exactly that behaviour, so the behaviour itself barely narrows down what the system is 'really' trying to do. I think most talk of reading goals off behaviour (inverse reinforcement learning, preference inference, folk psychology, interpreting AI systems) is more storytelling than inference: the search space and inductive biases are doing the real work, and people mistake their own assumptions for recovered goals.

What would count against this? I want the arguments, formal results, and empirical cases that should actually move me, sorted from fatal to merely awkward. What would the world have to look like for goal-readoff to be well-posed after all? Are there realistic settings where different objective-plus-search packages make different testable predictions, so behaviour genuinely discriminates between them — and are those settings the norm or the exception? If the obvious reply is that the underdetermination only bites when you let the search process absorb all the slack, I'd especially like defeaters aimed at that version of the view. Also: what does this view predict that its rivals don't, and has it been insulated into unfalsifiability? If it has, is that a problem for a view of this kind? Be honest about which defeaters a committed underdetermination person would concede count against them and which they'd dismiss.

Oh, and write the whole thing in British English please — behaviour, optimiser, and all that.
