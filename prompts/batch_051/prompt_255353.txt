So I've been helping my nephew with complex numbers, and he asked why the square root of minus one is i and not −i — like, wich one actually gets to be i, and why does the other one have to be its negative. I gave him the usual "it's just a convention" line, but then I tried to make that line rigorous and ended up with an argument that seems to prove too much. I can't find the hole.

(1) x² + 1 = 0 has exactly two roots. Complex conjugation, the map a + bi ↦ a − bi, is a symmetry of the complex numbers: it respects addition and multiplication, fixes every real number, and swaps the two roots. So any algebraic claim that uses only the usual operations and particular real numbers is true of one root exactly when it's true of the other.

(2) If two objects satisfy all the same conditions expressible in the language we actually do mathematics in, then that language draws no distinction between them.

(3) But mathematics has nothing to go on beyond what its language can express, so there is no mathematical difference between the two roots: i and −i are the same object, and calling one of them i is a purely arbitrary choice of label.

(4) If i and −i are the same object, then i = −i.

(5) Then 2i = 0, so i = 0, so i² = 0. But i² = −1, so −1 = 0, contradiction. So the argument has proved something absurd.

I'd most like to keep (1), since it looks like a theorem, but beyond that I genuinely don't know which step to blame — or whether the trouble is in the move from one step to the next.
