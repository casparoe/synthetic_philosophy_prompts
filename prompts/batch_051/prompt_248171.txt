My friend Sam has this argument he calls the unstarted-chain argument, and I can't find the exit. It seems to prove way too much, but each step looks fine on its own.

(1) In any chain where each link has a status only because the previous link has it, no link in the chain has that status unless some first link has it without receiving it from anything earlier.
(2) Justification works like that: a belief is justified only if it is justified by another belief, which is justified only if it is justified by another belief, and so on.
(3) So if your belief is supported by an infinite chain of justifiers, no belief in the chain is ever actually justified. There is no first justifier to start the flow and pass justification down the line.
(4) Causation also works like that: an event happens only if its cause happens.
(5) So if the past were infinite—every event caused by an earlier event—then no event would ever happen. There would be no first cause to pass existence down the line.
(6) Therefore the past cannot be infinite; there had to be a first event or a first cause.
(7) But the reasoning in (3) seems to rule out any infinite chain whatsoever, which would make an infinite past, infinite space, or even an infinite series of mathematical objects impossible. That seems like too much.

Sam says the only way out is to reject (2) or (4)—that is, to give up foundationalism about justification or the principle that every event has a cause. I have a hunch the real slip is somewhere between "each link needs a previous one" and "the whole chain needs a first one," but I can't say exactly what that slip is or what it would cost me. Which step should I reject? If I reject the step I suspect, does that also defuse the classic first-cause argument, and how do I then say wich regresses are vicious and which are benign?
