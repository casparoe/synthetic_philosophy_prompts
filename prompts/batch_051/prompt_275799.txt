So I've been reading around in foundations of math and I keep noticing a pattern I don't have a word for, and I'd like to know if one exists. A theory picks a particular way to build some familiar mathematical object out of other objects, and then the building blocks bring along extra facts — facts that nobody in the object's home field would ever use, and that flip if you choose a different but equally good construction. The obvious case is numbers-as-sets. In the von Neumann setup, 0 is the empty set, 1 is {0}, 2 is {0,1}, and 4 is {0,1,2,3}, so the sentence "2 ∈ 4" is literally true. In the other setup where each number is the singleton of the previous one, the same sentence is false. Mathematicians don't treat "is 2 an element of 4?" as a real arithmetic question, but the same textbook will happily say in chapter one that numbers are sets. The same thing happens when you model the Euclidean plane as ℝ²: you have to pick an origin and axes, so the model has a distinguished point and direction that the plane itself doesn't have, and "which point is (0,0)?" is treated as a non-question even though the model makes it perfectly well-formed.

Is there an established name for this — the way a reduction of an object can create answers to questions that weren't questions about the original thing, together with the idea that the real facts are just the ones that survive across all the rival encodings? And is there a separate name for the junk itself, the extra facts that are true only under some particular encoding? I'm asking less for labels than for the carving: how do you actually tell the invariant, structural facts from the coding junk without already knowing what the object really was before you started reducing it?
