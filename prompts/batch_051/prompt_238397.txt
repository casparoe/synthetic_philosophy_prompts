In the things I've read about how beliefs get justified, the standby image is a building. The thought goes: a belief is justified only if another belief supports it; that support cannot usefully run downward forever, because a building whose floors rest only on floors, with no foundation, is ultimately resting on nothing; so our reasons must finally terminate in basic beliefs that are justified in themselves, and any view that tries to do without them — whether through an endless chain of reasons or through beliefs supporting one another in a closed circle or web — is like a structure floating unsupported. I've also seen coherentists answer with the image of a raft we repair at sea while standing on it, and I cannot tell whether that is a better model or just a different label for the same problem. I'd like an audit of the building analogy as it's used here. What corresponds to what, where does the mapping start to break, and does it already build in the foundationalist answer, so to speak? Which disanalogies matter for the conclusion the analogy is meant to support, and how much of the claim that coherentism and infinitism are incoherent is actually being carried by the picture rather than by an argument? If the building is the wrong model, what should replace it?
