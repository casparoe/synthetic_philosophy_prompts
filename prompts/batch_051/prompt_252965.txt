Question. Compare the supervaluationist and epistemicist responses to the sorites paradox. Make sure you (i) state how each view diagnoses the key induction premise, (ii) say how each view treats borderline sentences, and (iii) explain what higher-order vagueness is and whether it threatens the two views equally.

Student answer. Supervaluationism says 'heap' is vague because there is no single privileged sharpening of the predicate. A sentence is true if it's true on every admissible precisification, false if it's false on every one, and otherwise neither true nor false. Each admissible precisification draws a sharp boundary somewhere in the series, so the major premise — for every n, if n grains make a heap then n-1 grains make a heap — is false on every precisification. So the supervaluationist rejects that premise and the argument is unsound. Individual conditionals far from the boundary are true, while the ones straddling a possible boundary are neither true nor false. Because borderline sentences are neither true nor false, the supervaluationist also has to restrict excluded middle: a sentence like 'either these grains make a heap or they don't' won't be true in borderline cases.

The epistemicist instead says there really is a sharp cutoff; it's just that we can't know where it is. Vagueness is a kind of ignorance, not a failure of truth-value. So the induction premise is false because exactly one conditional in the chain has a true antecedent and a false consequent. The paradox only looks sound because we confuse our inability to find the cutoff with there being no cutoff.

Higher-order vagueness is vagueness in the location of the borderline region itself: there's no sharp line between the clear heaps and the borderline heaps, or between the borderline heaps and the clear non-heaps. I think this is much more serious for the supervaluationist than for the epistemicist. To state supervaluationism you must specify which precisifications are admissible, and if 'admissible' is itself vague then 'supertrue' is vague too, so the theory just pushes the problem into the metalanguage. The epistemicist can absorb higher-order vagueness as higher-order ignorance: there are further cutoffs between the clear cases and the borderline cases, and we can't know those either. So epistemicism handles higher-order vagueness with the same basic move, while supervaluationism has no corresponding story.
