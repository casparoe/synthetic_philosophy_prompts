I'm a software engineer with no philosophy background, and the claim that DNA is a code keeps snagging on something I've never heard anyone spell out. In every actual codebase I've worked on, the mapping from source to behavior is handled by a toolchain that's separate from the source: compiler, interpreter, operating system, CPU. The genome isn't like that. The machinery that decodes it — ribosomes, tRNAs, the enzymes that attach amino acids to them — is itself built from DNA-encoded parts. So DNA looks like code that writes its own decoder, and the decoder is partly made of the message it's reading. I've been calling this 'bootstrapped semantics' and arguing that code is the wrong word for DNA, or at best a special case with no clean analogue in software. Honest assesment please: is this a real distinction or am I just forcing engineering intuitions onto biology? Has someone already said this under a better name? And where does the comparison break — does, e.g., the fact that the decoder is inherited rather than rebuilt from scratch each generation matter for my claim?
