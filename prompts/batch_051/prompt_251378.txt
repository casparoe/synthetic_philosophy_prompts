Consider the following argument, which has been proposed as a way to establish the Church-Turing thesis without relying on experiment or mere intuition. I suspect it is circular, but I cannot locate the exact step where the circularity enters. Please go through it step by step.

(1) Any effective procedure can be expressed as a finite string of symbols in some fixed alphabet.
(2) The set of finite strings over a finite alphabet is effectively enumerable.
(3) Given any finite string, one can decide whether it is a well-formed specification of an effective procedure, and if it is, one can carry out that procedure.
(4) Therefore, there is an effectively enumerable list of all functions computable by effective procedures.
(5) But every function in an effectively enumerable list is a partial recursive function, since partial recursive functions are precisely those whose values can be obtained by mechanically following a finite specification.
(6) Hence every function computable by an effective procedure is partial recursive, which is the Church-Turing thesis.

Is this argument valid? If it is not, identify the first step that fails and say exactly what false or question-begging assumption it makes. If it is valid, explain why it still does not settle the epistemic status of the thesis. Please answer in American English.
