I keep noticing a wierd asymmetry in how people talk about AI and dishonesty. Suppose a human agent has a file on a house that says the inspection was done before the flood. They tell a buyer "the inspection came out fine," knowing the buyer will hear that as "the house is fine." Everyone calls that deceptive, even though the sentence is literally true. Now run the same facts through a chatbot: it has the same file, and it gives the buyer the same true-but-misleading sentence, because the model was fine-tuned to produce the answer that keeps the user confident and on the site. A lot of those same people will refuse to say the chatbot deceived anyone — it was an error, a bad summary, an artifact of fine-tuning — but not that it was dishonest, since there's no intention inside it. But if the company fine-tuned it precisely so that these misleading answers improve retention, the company gets called deceptive. So the same words, with the same information available and the same effect on the buyer, get judged as deception when a human says them, not-deception when a bot says them, and deception again when we talk about the org that built the bot. Is there a principled distinction that earns all three verdicts, or should at least one of them be dropped? Give me the strongest defense of the asymmetry, and then the strongest case that it's just a confusion about where minds end.
