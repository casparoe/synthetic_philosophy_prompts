I'm grading a philosophy of language exam and I've been at it for hours, so I want a second set of eyes to make sure I'm not being to generous or too harsh on one answer. The question was:

"Does 'Sherlock Holmes' refer? And how should we make sense of the fact that a sentence like 'Sherlock Holmes lived on Baker Street' is true in the Conan Doyle stories but false in the actual world? Discuss at least two accounts."

The student wrote:

"Sherlock Holmes does not refer, since there is no actual person who satisfies the descriptions associated with the name, so it is an empty name. Frege and Russell both agree on this much but spell it out differently. For Frege, the name has a sense—roughly, the brilliant consulting detective created by Arthur Conan Doyle—but no reference, so 'Sherlock Holmes lived on Baker Street' expresses a complete thought but is false. Truth in fiction, for Frege, is then just the truth of that thought under the pretense that Holmes exists. For Russell, the name is not a real name but abbreviates a definite description, something like 'the detective who lives at 221B Baker Street.' His theory of descriptions then makes the whole sentence false in the actual world, because there is no unique detective satisfying the description. But in the world of the story the description is satisfied, so the very same proposition comes out true there. Russell's account of truth in fiction is therefore: a sentence is true in the fiction iff the proposition it expresses is true at the possible world of the story. A problem for Russell is that 'Sherlock Holmes is a fictional character' would also come out false, since the description is unsatisfied, even though it is obviously true. A problem for Frege is that if the sentence is false outside the fiction, he cannot explain why it counts as true inside the story. Pretense theory handles that by saying the fiction invites us to make believe that 'Holmes' refers and that Holmes lived on Baker Street, but it struggles with mixed sentences like 'Holmes is smarter than any actual detective,' where the make-believe has to interact with genuinely referring terms."
