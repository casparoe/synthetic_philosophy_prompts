I've been going back and forth on the Platonia dilemma and whether superrationality actually has a solution for it. The setup: 20 people receive a letter. Each can send in a single postcard by the deadline. If exactly one postcard is received, that person gets a million dollars. If none arrive, or if more than one arrives, no one gets anything. No communication, and everyone knows everyone else is in the same situation.

Here's an argument that superrationality fails to give a useful answer here:

(1) Superrationality says that in a fully symmetric problem, all superrational players will arrive at the same strategy.
(2) In the Platonia dilemma, the only strategies are send, don't send, or a probabilistic mix of the two.
(3) If everyone follows the same deterministic strategy, then either everyone sends or everyone doesn't send, and in both cases everyone loses.
(4) A mixed strategy would require each player to independently randomize, say by rolling a die.
(5) But if the players are genuinely identical reasoners, there is no principled way for them to generate independent random outputs: any deterministic algorithm they all follow will produce the same "random" result for each of them.
(6) So a mixed strategy is irrelevant; it collapses into everyone making the same choice, and we're back to universal loss.
(7) Therefore superrationality does not offer a winning strategy in the Platonia dilemma, so it is incomplete as a decision rule.

I have a nagging feeling that step 5 is doing something sneaky, but I can't articulate exactly what. Is the argument valid? If not, which step fails, and what is the correct version of that step? Am I right that if step 5 is fixed, superrationality can handle the Platonia dilemma, or does the problem go deeper?
