Set out the desiderata that any adequate resolution of Russell's paradox must meet. For each requirement, give the motivating case or consideration and state whether it is non-negotiable or a preference of a particular foundational tradition. Cover at least the following: a resolution must preserve as much of naive comprehension as possible, and any restriction must flow from a general principle rather than a gerrymandered exemption for the Russell set; it must take a motivated stand on whether self-membership and the universal set are well-formed; it must say precisely which background logic is kept and which principle, if any, is abandoned; it must preserve extensionality or explain what replaces it; it must recover the mathematics that working mathematicians actually use; it must handle the other standard paradoxes of naive set theory, including the largest-ordinal and largest-cardinal problems, in a unified way rather than patching each separately; and it must not secure consistency by weakening the language so much that the original paradox can no longer even be stated. Then give the verdict I most want: which subsets of these desiderata are jointly unsatisfiable. In particular, say whether unrestricted comprehension, classical logic, extensionality, and a place for the set of all sets can be retained together without contradiction, and if they cannot, which one should bear the cost and why. The point is for the list of requirements itself to do argumentative work, not merely to express preferences.
