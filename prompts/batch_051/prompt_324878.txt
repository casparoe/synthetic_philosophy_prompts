Was reading a popular maths book on the train and it gives this account of Skolem's paradox, and I realised I might've been carrying around a garbled version of it for years. Here's roughly what it says:

If the usual axioms of set theory have any model at all, the Löwenheim–Skolem theorem says they have a countable model — a model whose domain is only as big as the natural numbers. But inside that model you can prove Cantor's theorem, so the model contains a set which the model recognises as 'uncountable', in the sense that there is no function inside the model pairing its elements with the model's natural numbers. So here is a perfectly consistent mathematical description of an uncountable set that nonetheless has only countably many members. That's meant to show that 'uncountable' is not an absolute notion: a set can be uncountable from inside a model and countable from the point of view of an observer outside the model. And the book's moral is that there is therefore no fact of the matter about how many real numbers there are, or about the continuum hypothesis — those questions are just artefacts of the model you happen to be working in.

I'm uneasy. That last move sounds like it slides from 'the model can't see a bijection' to 'there isn't one', and I don't want to be the amateur who corrects something he's misunderstood. Is this a fair summary of Skolem's paradox? I'd like to know which bits are acurate, which bits overstate or understate what Skolem actually established, and whether the book's moral about the reals and the continuum hypothesis actually follows.
