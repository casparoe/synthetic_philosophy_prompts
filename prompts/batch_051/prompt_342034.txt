Below is a question from a take-home exam in an upper-level course on formal epistemology and the foundations of probability, followed by a student's answer.

Question. Objective Bayesians sometimes claim that the maximum entropy principle identifies the uniquely rational prior for a given body of constraints: among all distributions satisfying the stated constraints, the one that maximizes Shannon entropy is the one a rational agent is obligated to adopt. Explain, with the relevant formalism, what this claim comes to, and then evaluate the objection that the rule is not invariant under reparameterization of the state space. If the objection succeeds, what exactly does it rule out, and can the objective Bayesian block it without giving up the idea that there are rationally privileged priors?

Student answer. The principle says: given a space of hypotheses Ω and expectation constraints E[f_k] = c_k, choose the distribution p that maximizes H(p) = −Σ_i p_i log p_i, or the differential analogue −∫ p(x) log p(x) dx in the continuous case. Introducing Lagrange multipliers for the constraints gives the exponential-family form p_i ∝ exp(Σ_k λ_k f_k(i)), with the multipliers fixed by the constraints. On a finite state space this distribution is unique whenever the constraints are consistent, since entropy is strictly concave. The rationale for calling it uniquely rational is that entropy is a measure of missing information; maximizing it under the constraints incorporates exactly the information the constraints carry and no more, so any other prior encodes information the agent does not have.

The invariance objection runs as follows. If the same problem is described in new variables Y = g(X), with g smooth and one-to-one, the distribution that maximizes entropy in the X-description, when re-expressed as a distribution over Y, is generally not the distribution that maximizes entropy in the Y-description. But this is a red herring. A one-to-one transformation preserves the entire probability assignment: every event in the X-description corresponds to an event in the Y-description with the same probability. The agent's partial information is therefore exactly the same; the fact that the entropy functional itself changes is an artifact of writing the same distribution in different coordinates. Moreover, the same worry could be raised against any nontrivial rule for choosing priors, because any rule must be formulated in some particular set of variables. The maximum entropy principle is therefore unique in the only sense that matters: for a fixed formulation of the problem it selects a unique least-informative distribution, and two agents who formulate the problem in the same way will assign identical probabilities.
