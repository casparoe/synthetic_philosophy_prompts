Newcomb's problem, except the opaque box doesn't pay out in cash. If the predictor put the big prize in it, what you actually receive is a lottery ticket: a 50% shot at $2,000,000 and a 50% shot at nothing. (So the expected dollar value is still the usual $1,000,000.) The transparent box still holds a sure $1,000, and the predictor is still right 90% of the time.

First do the standard analysis as an expected-utility maximizer with linear utility in dollars: does swaping the sure million for the 50/50 $2M-or-nothing lottery change the dominance argument for two-boxing, or the evidential argument for one-boxing?

Now redo the scenario for someone who uses risk-weighted expected utility (REU), in its two-outcome form: a gamble that pays W with probability p and L otherwise is worth r(p)*W + (1-r(p))*L, where r is increasing with r(p) < p for 0 < p < 1, say r(p) = p^2. So the probability of the best outcome is shrunk, and the leftover weight gets dumped on the worst outcome. Does the causal dominance argument for two-boxing survive intact under REU? And for the evidential one-boxer, does the minimum predictor reliability needed for one-boxing to beat two-boxing go up, go down, or stay the same compared to plain EU? If you can, pin down the new threshold condition.
