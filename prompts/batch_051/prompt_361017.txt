I run a small commercial refrigeration and kitchen-equipment repair business, and over the years I have settled into a rule for deciding when two recurring faults should be treated as the same fault. I call two anomalies the same mechanism only when a single, targeted intervention removes both. If I replace or clean one specific component and fault A clears while fault B does not, I file them as different mechanisms even when the symptoms looked identical. If the same intervention clears both, I file them as the same mechanism and stop looking for a separate cause. I adopted the rule because I can rarely justify a full teardown of every unit, and judging by symptoms alone has repeatedly misled us.

Lately the rule has failed me in both directions. Two cold-store units turned up with the same icing pattern and poor cooling. Replacing a blocked metering line fixed one but not the other. The second turned out to have the same blockage, but it had run so long while starved of oil that the compressor had become damaged, so the single fix did not clear the fault. By my rule, those were different mechanisms, yet the fault that set both off was the same. In the other direction, a controller reset cleared two different faults on the same unit, and for months I treated them as one mechanism until the event log showed the reset had only suppressed two unrelated conditions.

My question is whether this rule is defensible as an epistemic shortcut, or whether it is a bias dressed up as a policy. In particular, is inferring a shared mechanism from a shared remedy sound, or does it confuse "the same treatment worked" with "the same thing was wrong"? I would like you to treat the rule as a policy: say under what conditions it is reliable, where it is most likely to fail, and whether it can be restated so that it keeps the discipline of requiring an intervention without mistaking where along the causal chain the intervention lands. Please also say explicitly which argument or example would change your verdict, and where you think your own reasoning about this is most likely to fail. Please write in British English.
