we're doing causal discovery in my causation course, and after the lecture on faithfulness I've been turning over this argument. it feels like it proves too much, but I can't find which step is doing the sneaky part. it goes:

(1) suppose the true causal graph G over some variables is causally sufficient (no hidden common causes) and satisfies the causal Markov condition. and suppose the observed distribution P is not faithful to G.

(2) then P contains some conditional independence that G doesn't entail. which means the parameters of the true causal model have to be set just so — two or more paths exactly cancel, or something of the sort — anyway they end up satisfying some nontrivial algebraic constraint.

(3) in any smooth parameterization of the model, the set of parameter values satisfying a nontrivial algebraic constraint has Lebesgue measure zero.

(4) so the unfaithful parameter values have probability zero under any continuous prior over the parameters.

(5) so faithfulness isnt really an empirical assumption — the probability it fails is zero. we're safe taking it for granted when we run causal discovery.

(6) under faithfulness plus the Markov condition, the DAGs that are perfect maps of P (i.e., that entail exactly the observed independences) are exactly the true Markov equivalence class.

(7) and that's what the 'minimal Bayes nets track causation' slogan amounts to: a graph with fewer edges than the true one would entail some false independence (by faithfulness), while a graph with extra edges entails too few independences to be a perfect map. so the minimal perfect maps just are the true causal structure, up to equivalence class.

(8) therefore, from purely observational data and with no real risk from unfaithfulness, we can recover the causal structure (up to Markov equivalence) by looking for minimal Bayes nets.

i keep going back and forth on whether this is valid. my main suspicion is the move from (4) to (5): probability zero under a prior doesn't seem to mean we can just ignore the possibility, since any exact parameter value has probability zero under a continuous prior but we don't declare every exact value impossible. but maybe that's just a finite-sample worry and the argument is fine asymptotically? or is step (7) misusing minimality? if the argument fails, tell me exactly which step fails and on what reading; if it goes through, tell me why the conclusion isn't as strong as it sounds.
