I've been chewing on the doomsday argument again and I think I've found the part that's actually doing the work, and its not the birth-rank math. I've been calling it reference-class gerrymandering. The standard move is: pick the class of observers I'm supposed to be a random draw from (all humans, all minds, all Earthlings, all observers with my exact evidence...), then my rank inside that class lets me estimate the class's total size. But class choice looks like the whole game, and I don't see what in the world picks one out. 'All humans' is just one gerrymander among many. If my reference class is 'people who read this exact argument,' I should predict only a handful more people will ever read it, which is absurd; if it's 'all possible sentient observers including sims and aliens,' doom basically never comes. So the doomsday argument starts to look like: pick your conclusion by picking your gerrymander, then dress it up as a random sample.

I know there's the usual SSA/SIA fight (roughly, whether you should treat yourself as a random draw from a reference class or favor classes where observers-like-you are more numerous), and I'd trust it got hashed out somewhere, but I want this checked on its own terms.
