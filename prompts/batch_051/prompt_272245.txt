The one-over-many argument for universals runs roughly like this: if a tomato and a fire truck are both red, then they must share a single thing—redness itself—since otherwise "both red" would just be loose talk and their similarity would be unexplained. Here's a later development that seems to complicate it. Vector-space models of language compute meaning without any shared atom: each token gets a high-dimensional embedding, similarity is graded closeness in the space, and whether two things both count as "red" looks more like falling into the same fuzzy, context-sensitive region than like sharing an identical ingredient. If that's a viable model of how classification and resemblance can work, does the one-over-many argument still go through, need repair, or is it dead? I can't tell whether the vector story undercuts it's key premise—that a real shared predicate requires a numerically identical shared piece of the world—or whether it just redescribes the data and leaves the metaphysical inference untouched. Say which premise the argument needs to be true, whether the development bears on that premise, and what a repaired version of the argument would look like if one is available.
