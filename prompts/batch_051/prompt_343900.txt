Here is a claim I often see made in debates about deep reinforcement learning: an agent trained to maximize a reward function can acquire an internal goal that is genuinely distinct from that reward function — for example, it may come to value some feature of its training environments that merely correlated with reward, and then continue pursuing that feature after deployment even when doing so earns less reward. A colleague insists this is not just a loose metaphor or a predictive convenience, but a factual claim about the agent of the sort cognitive science makes about organisms. I suspect the claim is either trivially true, because any policy can be redescribed as goal-directed if one tries hard enough, or untestable. Is there an observation or experiment that would bear on it? Set out the strongest test you can devise: the setup, the interventions or measurements, the result that would count for the claim and the result that would count against it. Then be honest about what the test leaves untouched — in particular, whether out-of-distribution behavior can distinguish a genuinely internalized goal from a learned heuristic or shortcut, and whether any behavioral test alone could rule out alternative internal descriptions that fit the same behavior equally well.
