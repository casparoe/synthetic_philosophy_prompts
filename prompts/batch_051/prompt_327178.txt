So I've been trying to actually get ergodicity economics straight, and the core move as I understand it is that a single agent lives one path through time, so what should matter to them is what happens along that path — the time average — not what happens across an ensemble of parallel versions of themselves. Fine. But why is this always illustrated with repeated gambles? If the ensemble average is a fiction for an individual, it's a fiction on the very first play too, isnt it? Say someone offers me a single one-off bet with positive expected value but a negative time-average growth rate. No repetition, no compounding, no long run to hide in. Does ergodicity economics still tell me to turn it down, because the ensemble never actually gets sampled? And if it doesn't, aren't you basically admitting expected value was fine for one-shot choices all along, and that the critique only kicks in once you've helped yourself to a long sequence of repetitions? Where's the cutoff between 'not repeated enough, use expected utility' and 'repeated enough, use the time average'?
