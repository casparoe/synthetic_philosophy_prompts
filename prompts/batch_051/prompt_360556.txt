An argument has been going round my philosophy of mind seminar, and although its conclusion seems plainly wrong, none of us can say where the argument fails. I have reproduced it below as it appeared on the handout.

(1) According to machine functionalism, a mental state is a state whose nature is exhausted by its causal role in a programme: a finite machine table that maps inputs and current internal states onto outputs and successor internal states.
(2) A physical system realises such a machine table just in case there is an assignment of the system's physical states, inputs, and outputs to the table's abstract states, inputs, and outputs under which the system's causal transitions agree with the table's transition rules.
(3) Any physical system with sufficiently many distinct internal states realises any finite machine table under such an assignment. For one can assign the system's states to the table's states state by state over time, mapping whatever state the system is in at a given moment to whichever abstract state the table is in at that moment, and then count the system's actual transition to its next state as the transition prescribed by the table.
(4) On the machine-functionalist view, a human mind is specified by some finite machine table of this kind.
(5) Therefore, by (3), any sufficiently complex physical system — a bucket of water, a wall, a stomach — realises the very same machine table as a human mind.
(6) By (1), a system that realises that machine table has the corresponding mental states: beliefs, desires, pains, and so on.
(7) A bucket of water is sufficiently complex.
(8) Therefore a bucket of water has beliefs, desires, and pains.
(9) That is absurd; no one believes the bucket has a mental life.
(10) Hence either machine functionalism is false, or (2) is too permissive an account of realisation — in which case the doctrine that mental states are multiply realisable is either false or far more demanding than its defenders suppose.

Where does the argument go wrong, if it does? I should like to keep machine functionalism and the multiple-realizability doctrine, and I am equally unwilling to accept that a bucket thinks, so I want to know which step must be given up, why that step looked so natural, and what each available option costs. Above all, I should like to know whether there is a way of rejecting the argument that does not collapse into the claim that only biological systems can be minds.
