I've been arguing with my roommate about the standard simulation argument—the trilemma where either almost all civilizations like ours go extinct before they can run ancestor simulations, or almost no posthuman civilizations bother to run them, or we're probabaly living in one because simulated minds would vastly outnumber nonsimulated ones. My roommate thinks the third horn is basically inescapable: one posthuman civilization could run billions of ancestor sims, and those simulated civilizations could run their own, and so on, so simulated minds dominate no matter what. I'm not convinced the explosion is automatic.

Here's the variation I want to work through carefully. Suppose there's a fidelity tax between levels: a civilization that decides to run ancestor simulations can run N of them, but each simulated world one level down only contains about 1/k as many lives as the world above it (coarser grain, slower, whatever). So if the base level is normalized to 1, it produces N/k simulated lives at the first level down, those produce (N/k)^2 at the next, and so on. Redo the counting argument with that geometric series. When does it converge, and for what values of N and k does the old explosion return? What does that do to the trilemma—is the third horn still one of three jointly exhaustive options, or does it split into subcases the original argument smeared together? And if my roommate wants to keep the conclusion that we're almost certainly simulated, exactly which values of N and k does he need to defend, and are those assumptions the original argument was entitled to?
