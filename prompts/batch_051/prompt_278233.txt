Thing one is assembly theory, the Cronin/Walker program from origins-of-life chemistry. As I understand it, the assembly index of an object is the minimum number of joining operations you'd need to build it from a fixed set of elementary parts, where you're allowed to reuse subassemblies you've already made. So a pile of gravel has low assembly index because there's no real nested structure, but a ribosome has high assembly index because you have to build small modules, then join those into bigger modules, then join those, with the same modules used over and over. The punchline of the theory is that high assembly index plus high copy number is a signature of selection, since unguided chemistry doesn't reliably churn out many copies of deeply nested structures.
