Ok so I've been thinking about whether video game characters can actually matter morally. Not the question of whether it's ok to steal in a game because a guard sees you, but whether the character itself counts the way a dog or a person does. My friends say obviously not, because they're not real and you can just reload. But i think thats exactly the wrong way round, and I came up with something I call the Save-Scum Test.

The test: a character has moral status if and only if a reasonable player, knowing there are zero in-game consequences (no loot, no achievement, no quest lockout, no reputation change), would still reload a save to undo hurting the character, and not because it messes up their immersion or their build, but because leaving it that way feels wrong in itself. The amount of progress you'd throw away to reload measures how much the character matters. So if you'd reload ten minutes for a shopkeeper you like but wouldn't reload thirty seconds for a random bandit, the shopkeeper has more moral status in that world. Deliberately not about sentience, because NPCs don't have any. It's a test of the observer, not the character.

I know some people talk about why players are fine with some virtual harms but not others, and I know philosophers usually tie moral status to suffering or interests. Mine is deliberately different. But I can't tell if it's (a) secretly circular, because it just measures how attached the player is, not whether the character matters, (b) actually some existing idea like sentimentalism or response-dependence but awkwardly applied to fiction, or (c) new but kind of stupid.
