Define mathematical proof — the property a result has when it has been proved, not merely the genre of textbook argument — so that it classifies the following cases correctly. Start with fixed data points: the usual proof that there are infinitely many primes is a proof, and a respected mathematician's bare assurance that a theorem is true is not. Then run the definition through the hard cases: the Appel–Haken proof of the four-colour theorem, resting on a computer case analysis no human has checked by hand; the same theorem re-derived as a formal proof verified by a proof assistant, which no human has read line by line; an exhaustive search over a finite but enormous case space that no single mathematician could survey, though the full case list could in principle be printed; a proof with a genuine but unnoticed gap that the field accepts for a decade before the gap is found; a number accepted as prime only after many rounds of a randomized test, with residual error probability below 10^-30 and no deterministic certificate; and a computer-discovered counterexample to a conjecture. I lean toward counting the machine-checked derivation as a proof and the probable-prime verdict as not, but I want to know whether that is coherent. Propose the definition, run it through every case, and say which verdict is least secure. In particular, test whether proof requires human surveyability, formal derivability, or only correctness with reliable production — and whether the concept has shifted under pressure from computer-assisted cases rather than keeping a single stable meaning.
