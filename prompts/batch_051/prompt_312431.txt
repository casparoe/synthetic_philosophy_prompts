For a long feature on AI safety, I've been trying to pin down what the narrow "intent alignment" problem is really about, and an engineer I interviewed sketched an argument I haven't been able to shake. It seems to show that intent alignment either collapses into value alignment or has no determinate target. I'd like to know where it goes wrong before I print any version of it.

(1) A system is intent-aligned when its behavior is best explained by the hypothesis that it is competently pursuing what its operator actually has in mind, as distinct from what the operator literally wrote.
(2) For an operator to have something in mind in the sense required by (1), there has to be a determinate intended objective across the relevant possible outcomes.
(3) An intended objective is determinate across possible outcomes only if it is settled, for the relevant tradeoffs, by which outcomes the operator would regard as better and worse.
(4) What settles which outcomes the operator regards as better and worse just is the operator's values.
(5) So there is no determinate intended objective that is independent of the operator's values.
(6) Value alignment was supposed to be the distinct, harder problem of aligning systems with human values.
(7) Therefore the narrow intent-alignment problem is either the value-alignment problem in disguise, or a problem defined over an object that does not exist.

Each premise seems plausible to me, but the conclusion would dissolve a distinction the field leans on. Which step should I reject, and what does rejecting it cost? If the argument is valid, which premise is the least costly to give up? I would most like to keep (1), and I am suspicious of (3), but I can't yet say which step is actually doing the damage.
