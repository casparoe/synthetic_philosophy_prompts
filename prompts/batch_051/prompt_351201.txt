I have been working on a project for my school's computer science club in which I watch a simple simulated agent — a grid-world robot — and try to work backward from what it does to what it is optimizing and which options it is even considering. Before I commit to a method, I want the specification that any adequate method would have to meet. Please give me the requirements list for a theory of inferring an optimizer's objective and search space from its behavior.

The purpose is fixed: I need a theory good enough for a small agent with a finite behavioral record, where I can run new experiments but cannot read its code. With that in mind, what cases must the theory handle, and what distinctions must it not collapse? I already suspect a few, but I want the full list with the case or consideration behind each requirement:

- Any finite record of behavior is consistent with infinitely many objectives, so a method has to say how it breaks that tie.
- An agent may satisfice rather than maximize, which can make a satisficing agent with one objective look exactly like a maximizing agent with a different objective.
- The search space is not fixed: an agent can learn new actions or prune old ones, and a method that assumes a fixed menu of options will misread that as a change in objective.
- The agent may anticipate being observed and choose actions partly to shape what an observer infers, so behavior can be about the inference itself rather than only about the objective.
- The theory must keep separate a change in what the agent knows from a change in what the agent wants, since both can produce the same behavioral shift.

For each requirement, say why it is a requirement rather than a convenience, and tell me which requirements are negotiable for my purpose and which are not. Then, if it helps, briefly note which of the main approaches survive the list, but keep the weight on the criteria themselves. Finally, say which single requirement does the most to exclude popular approaches, and please separate what is settled from what is genuinely contested among people who work on this; do not present a contested view as if it were the consensus.
