I work as a software engineer, and a small collective I'm part of is drafting governance rules that will live in a git repository, with votes recorded as approvals on pull requests that edit the rule files. We want the system to be fully self-amending — including the rule that says how to amend rules — because none of us wants any piece of the text to be permanently beyond revision. I have no formal background in this, so I keep reasoning about it the way I would about a state machine or a compiler, and I keep hitting what feel like recursion bugs in the rules themselves. The draft we keep returning to divides rules into Ordinary and Constitutional. Ordinary rules change by a two-thirds vote of all members. There is one Constitutional rule, which says: (1) the Constitutional rules are this rule and any rule that is explicitly made Constitutional by a Constitutional amendment; (2) any change to a Constitutional rule must pass two votes — first under the procedure currently in force, and then, before the change takes effect, a second confirmation vote under the procedure the proposal would itself establish; and (3) the procedure currently in force for all rule changes is a two-thirds vote of all members. The attraction is obvious: a proposal to lower the amendment bar to a bare majority must clear the old two-thirds bar, while a proposal to raise it to ninety percent must clear ninety percent, so the two-stage rule seems to prevent both easy capture and easy entrenchment.

What I cannot convince myself of is whether it actually pins any of this down, given that it is a rule about itself. Could a proposal simply amend the Constitutional rule to say that it is now an Ordinary rule, or that the two-stage procedure no longer applies to changes made by this very amendment? Does a proposal that redefines what counts as Constitutional get evaluated under the old classification, the new one, or both? I would like a walkthrough of how this mechanism would behave in practice: what invariant it really enforces, what sequence of moves a patient coalition could use to route around it, where it deadlocks or produces inconsistent states (for example, if two amendment proposals pass in flight and then conflict in the repo), and whether the failure modes can be fixed without reintroducing the same self-reference problem one level up.
