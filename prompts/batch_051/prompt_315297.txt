The question was: "State the simple conditional analysis of dispositions. Then explain, using a concrete example of each, what finkish and masking counterexamples are, and say what exactly they show is wrong with the analysis."

Student answer: "A disposition is a property like fragility or solubility: it concerns what something would do under certain conditions, not what it is actually doing right now. The simple conditional analysis says that an object x is disposed to manifest M under stimulus S if and only if x would M if it were S. So a glass is fragile iff it would break if struck.

Finkish cases are usually credited to C.B. Martin. In his example, a wire is live, but it is hooked to a safety device that makes the wire dead whenever a conductor touches it. If a conductor touched the wire, no current would flow, so the conditional 'if touched, it would conduct' is false; still, the wire is live before the contact. In a mask case, a fragile glass packed in thick styrofoam is still fragile, but if you struck it, the packaging would absorb the blow and the glass would not break. Again, the disposition is present while the conditional is false.

Honestly, finks and masks are just two names for the same thing: in both, some outside factor interferes between the stimulus and the usual manifestation, so nothing important hangs on which term we use. Formally, both kinds of case are counterexamples to the right-to-left side of the biconditional: the analysis says that if the conditional holds, the disposition is present, and in these cases the conditional holds without the disposition. So the simple conditional analysis overgenerates dispositions and is refuted."
