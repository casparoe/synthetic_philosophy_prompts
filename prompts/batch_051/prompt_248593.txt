I just read a popular philosophy book that summed up the idea of incommensurable values roughly like this. When two options are valuable in different ways — say, keeping a promise to a friend or taking a job abroad — there is no common currency, no single scale on which they can be measured. The author then says that if values are incommensurable, reason is silent about which option is better: its not just that we don't know, there is no fact of the matter, and that's why hard choices feel hard. From this he concludes that cost–benefit analysis is irrational when values are incommensurable, because it forces a comparison that cannot meaningfully be made, and that in a genuinely hard choice any decision is ultimately arbitrary — so we should stop agonising and might as well flip a coin. I find the coin-flipping advice suspicious. How fair is this summary to the actual philosophical view? Go through the claims one by one, say which are right, which are subtly off, and what a philosopher who defends incommensurability would object to. Does the flip-a-coin advice follow from anything true in the summary?
