A friend who works on AI alignment walked me through this argument last week and now I can't shake it. It seems to prove that corrigibility — the whole idea of building agents that don't resist being switched off — is basically impossible except in a boring, goal-free sense. He laid it out like this:

(1) An agent is corrigible about shutdown only if it doesn't act to prevent the shutdown button from being pressed, doesn't act to make the button easier or harder to press, and just lets itself be turned off.

(2) The natural way to understand an agent's behavior is as expected utility maximization over some utility function.

(3) If an agent is shut down, it stops performing actions, so the outcomes its future actions would have brought about never occur.

(4) If the agent has any non-trivial goals, then for at least some action A available to it, the utility of (A followed by shutdown) is lower than the utility of (A followed by continuing), or higher — but not equal.

(5) So the agent has a utility-based reason to tilt the world toward one side of that comparison: it will tend to prevent the button from being pressed, or tend to cause it, and either way it isn't indifferent to the button.

(6) The only way to make a utility maximizer indifferent to shutdown across all actions is to make its utility function indifferent among all outcomes, which is just giving it no goals.

(7) Therefore corrigibility is impossible for any expected utility maximizer with non-trivial goals.

(8) But corrigibility seems like the sort of thing an engineer could just build: hard-code a switch that halts the agent, and the agent doesn't remove it.

So either the argument is right and the whole corrigibility research program is confused, or one of these steps has to go. I'd like to keep (2), at least as an idealization, and (8) as a real design target, but I can't see how both survive. Which step should I reject, and what does rejecting it actually cost? I'm less interested in learning the name of the right position then in understanding the trade-off — like, if I reject (2), do I lose the ability to predict the agent at all, or is there a nearby framework that keeps most of expected utility theory but changes what the utility function is over?
