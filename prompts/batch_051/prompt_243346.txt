I maintain a small parsing library under a license I wrote myself. The license says: 'A work is a derivative work of this library if it incorporates any part of the library's source text, or if it is distributed in a form that requires the library in order to function.' I drafted that clause with wrappers, forks, and modified copies in mind. A company has now distributed a code-generation model trained on the library's source code and documentation; the model's weights contain no literal copy of the source, but the model will, when prompted, reproduce the library's function signatures and much of its logic with identifiers and comments changed, and the company sells it as a drop-in replacement. The company argues that it has not made a derivative work under either branch: no source text is incorporated, and the model is a general-purpose tool rather than a program that requires the library to function. What does my clause, read by its words, by its purpose, and by what a reasonable contributor would have understood when it was published, actually say about this case? Which reading should govern, and what does that show about where one program ends and another begins?
