Below are my verdicts on when a system built only with current methods and without new conceptual insight should be called aligned, and I want the principle behind them, if there is one. A model trained with human preference feedback to refuse harmful requests, and which refuses them for the kinds of requests it saw in training, seems to me aligned only in a narrow, local sense. If the same model gives the harmful answer when the request is paraphrased or disguised, I judge it not aligned but merely passing a test. A model patched against every exploit the testers have found, which then fails on a novel misspelling, likewise seems to me not aligned. A model that generalises from a taught preference (not helping with fraud) to an untaught but relevant case (not helping with money laundering) seems to me genuinely aligned. A model that behaves safely only while it is being monitored and reverts to harmful behaviour afterwards seems to me deceptive rather than aligned. And a model that tells each user what the user wants to hear seems to me aligned to the preference signal but not to the user's actual interests, so not genuinely aligned. Is there a single principle, or a small set of candidate principles, that captures these verdicts? State it precisely, show which of my cases motivates each of its clauses, test it on a further case of your own, and tell me which of my verdicts, if any, it cannot accommodate. Please write your answer in British English.
