Here's an argument from a reading group I'm in that's bugging me. We were talking about origin essentialism—the idea that you couldn't have come from a different sperm and egg—and someone proposed this:

(1) I could not have come from a different sperm and egg; any possible world where I exist is one where the same gametes produced me.
(2) If so, then in every possible world where I exist, that particular sperm fertilized that particular egg.
(3) But identity is necessary: if a given possible child is me, then it could not have failed to be me.
(4) So there is no possible world in which a different sperm fertilized that egg and produced someone else, while I simply fail to exist.
(5) Therefore, it is impossible for that egg to have been fertilized by any other sperm, full stop.
(6) But that's absurd: which sperm got there first was a paradigmatically chancy matter.

Where does this go wrong? I'd like to keep (1), but (5) seems clearly too strong.
