I'm currently a student in a course on autonomous agents and decision theory, and there is a configuration I keep noticing that I do not know how to name. The textbook setup has always been that an agent sits inside an environment, taking observations as input and producing actions as output. But the moment the agent starts modeling real situations, that clean boundary leaks: the agent is itself a part of the environment, so any prediction it makes about its own future behavior becomes a causal input to that behavior. A prediction of failure can make it try harder and succeed; a prediction of success can make it lazy and fail; and there is no neutral standpoint from which the agent can simply update on a prediction, because the prediction changes the very thing being predicted.

I have now hit this in three places. First, in a project about a delivery agent that had to estimate whether it would finish a route before recharging, where its estimate changed how it planned, so the only sensible estimates looked like fixed points of some map from predictions to outcomes. Second, in thinking about an agent that considers rewriting its own code: to judge whether the successor will still pursue the original objective, the agent has to reason about a system whose construction depends on that very reasoning, so it cannot simulate the successor from outside. Third, in a two-agent setting where each agent models the other's next move, and there may be no stable pair of mutual predictions, or several.

Is there an established term for this specific breakdown, and is it right to treat my three cases as instances of a single phenomenon? I am not asking for a bare label. I want to know how the concept is bounded: which of these cases actually fall under it, which nearby ideas such as self-reference and self-fulfilling prophecy it should be distinguished from, and where the edges are. If no standard term exists, I would like a proposed name together with a definition precise enough to test against boundary cases. Along the way, please separate what is settled among people working on this from what is genuinely contested; I would rather hear about the disagreement than be given a single school's view as if it were consensus.
