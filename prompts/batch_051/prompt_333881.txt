I've been teaching Kant's Groundwork for years, but a grad student in my ethics seminar yesterday pushed me on a reconstruction of the universalizability test that I can't quite get out of my head. I'm not sure weather the argument is sound, or if it equivocates somewhere, or if the conclusion just shows that my student's description of the maxim is rigged from the start. I'll lay it out as numbered steps, because I want someone to tell me exactly which step, if any, is the one that fails.

The argument goes like this. (1) According to the formula of universal law, an action is permissible only if one can at the same time will that one's maxim become a universal law. (2) A maxim is the subjective principle on which one acts, e.g., "When I need money, I will make a false promise to repay." (3) To test whether one can will a maxim as a universal law, we ask whether universalizing the maxim would make the action or the institution it relies on impossible, i.e., whether there is a contradiction in conception. (4) For the false-promise maxim, if everyone in need made false promises, no one would believe promises, so promising as an institution would collapse; thus the maxim fails the test. (5) But consider the maxim "When breaking a promise is the only way to save an innocent person's life, I will break the promise." If everyone followed this maxim, promising would still function perfectly well in ordinary circumstances, because the condition it specifies is rare and does not erode general trust. So there is no contradiction in conception. (6) Therefore, the formula of universal law permits breaking a promise to save an innocent life. (7) But Kant apparently held that lying is always wrong, even to a murderer at the door, because lying cannot be willed as a universal law. (8) So either Kant's test doesn't actually yield the exception in (6), or Kant was wrong about what his own test implies.

I half-suspect the problem is that the maxim in (5) is just a gerrymandered version of something like "I will break a promise whenever doing so suits my purposes better than keeping it," which would fail. But then I'm not sure what principled rule stops someone from gerrymandering every maxim to include whatever conditions make it universalizable without contradiction. Is the argument valid? If not, which step fails, and what's the correct account of maxim description that would fix it?
