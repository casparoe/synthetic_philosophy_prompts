I have been noticing a structural resemblance between Frankfurt cases about responsibility and causal preemption cases in the literature on actual causation, and I would like to know whether it is deep or superficial. In a Frankfurt case, an intervener stands ready to make the agent perform the action if the agent does not decide to perform it on her own; because the agent does decide, the intervener never acts, yet the standby mechanism is meant to remove the agent's alternative possibilities and thereby undercut the principle of alternative possibilities. In a preemption case, a backup cause stands ready to bring about the effect if the actual cause fails; because the actual cause does not fail, the backup never fires, yet the effect does not counterfactually depend on the actual cause, so simple counterfactual theories of causation judge wrongly. In both, a would-be sufficient condition breaks a counterfactual dependence without doing any work in the actual sequence. Is this the same underlying structure, or only a loose family resemblance? State the mapping explicitly and say what would have to be true of both sides for lessons to transfer between them; in particular, indicate whether a structural-equations treatment of actual causation could model the Frankfurt case and where it would need normative resources the causal case lacks. Name at least one point where the parallel predicts something false. Please answer in British English.
