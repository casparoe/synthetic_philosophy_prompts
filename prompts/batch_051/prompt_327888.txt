Question: On Lewis's account of convention, a regularity must be arbitrary and must be supported by common knowledge. Explain why these two features seem to make convention change hard, and say whether a Lewisian convention could ever evolve into a new one without an outside shock to payoffs.

Student answer: Lewis says a convention is a regularity R that everyone follows, everyone expects everyone else to follow, and everyone prefers to follow given those expectations. It also has to be arbitrary: there is some other regularity R' such that if others conformed to R' instead, everyone would prefer to conform to R' too. This is why change is hard. If everyone expects R, then each person does best by conforming to R, so no single person can rationally start deviating to R'. The only way a convention changes is if something external shifts the payoffs so that R is no longer a coordination equilibrium, at which point everyone can see that and switch. Common knowledge doesn't add much beyond this: it just means everyone knows the regularity and knows everyone else conforms to it. So on a strict Lewisian picture, conventions can't evolve gradually from within; endogenous norm change is basicly impossible.
