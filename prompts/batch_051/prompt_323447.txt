Question: Explain how the standard possible-worlds semantics for knowledge gives rise to the problem of logical omniscience. Then describe one proposed modification of the semantics intended to avoid the problem, and one residual difficulty for that modification.

Student response: On the standard Kripke semantics for knowledge, an agent knows a proposition p just in case p is true at every possible world that is epistemically accessible from the actual world. Logical omniscience follows immediately. If p is a logical truth, p is true at every possible world, so it is true at every accessible world and the agent knows p. Similarly, if p entails q, then q is true at every world where p is true; so if p is true throughout the agent's accessible worlds, q is too, and knowledge is closed under logical consequence. This is usually treated as an idealization rather than a refutation of the framework.

Two standard repairs are often discussed. The awareness approach adds a function that records which formulas the agent is aware of, and an agent knows p only if p is true at all accessible worlds and the agent is aware of p. The impossible-worlds approach expands the space of worlds to include worlds at which logically impossible situations obtain, so a logical truth can fail at an accessible world and the agent can fail to know it. These two repairs do essentially the same work: both make knowledge non-veridical, because an agent can now know p even though p is false at the actual world, and the awareness approach can be understood as a special case of the impossible-worlds approach in which the agent is unaware of precisely the formulas that fail at impossible worlds. A residual difficulty is that impossible-worlds models make validity relative to a choice of worlds, and it is unclear which choice corresponds to real agents.
