You're a philosopher of probability who's actually run a few adversarial-collaboration workshops, and you're good at drafting the kind of joint statement both sides can sign without either one feeling sandbagged. I'm putting together a small workshop session on the reference class problem, and I want the centerpiece to be a document written as if two people who've argued about this for years sat down and produced an honest summary of where they stand.

The two positions are these. One — call them the pragmatist — holds that the choice of a reference class is always a modeling decision: there is no fact of the matter about which of the many classes a particular case "really" belongs in for purposes of assigning a probability. You pick the class that gives useful predictions for the decision at hand, and a different decision problem can legitimately make a different class the best one. The other — call them the realist — holds that at least some reference classes are objectively better than others because they carve out real similarities, causal structure, or the kind of thing the case actually is. For the realist, the choice between "40-year-old male smoker" and "person with this exact combination of genetic markers" isn't just about which one predicts well for your purposes; some classes are get-it-right classes and some are gerrymandered, even if we can't always tell which is which in practice.

Draft the document they'd produce. Please:

1. Start by brainstorming quietly — think hard about whether the two sides are even using "probability" the same way (single-case chance, credence, long-run frequency), because I suspect part of the dispute is that they talk past each other about that. Then write only the final document, not the brainstorming.

2. Include a numbered list of agreed claims that are substantive enough not to be truisms — e.g. claims about what the reference class problem actually is, why Venn's or Reichenbach's-style worries arise, what a reference class needs to be minimally good for, and what both sides would reject (such as reading off probabilities from no class at all).

3. Then a disagreements table. Each row: the issue, the pragmatist's phrasing of their own view (worded so the pragmatist would sign it), and the realist's phrasing of theirs (worded so the realist would sign it). Make the wording neutral in the issue column, not slanted toward either side.

4. Then pick three or four cruxes — sub-questions such that settling one of them would actually move at least one side. For each crux, give a concrete case both sides agree bears on it. I'd like at least these: a tossed coin with unknown but fixed bias (does the coin's long-run frequency privilege some reference class over "tosses by this machine on Tuesdays"?), a clinical risk score for a single patient (what makes "patients with these biomarkers" a better or worse class than "patients seen at this clinic"?), and the probability that a specific scientific theory is true. For each crux, write down what each side predicts or expects an ideal method to deliver, so the dispute is exposed to possible evidence.

5. Add a section on which part of the dispute, if any, is merely verbal, and which part would survive even after both sides agree on a single sense of "probability." Be honest here — don't dissolve the whole thing into terminology if there's a real disagreement left.

6. No citations needed; this is a working document and I'll add them later. Don't ask either side to concede. What I want is the document both could have co-signed at the end of a good-faith collaboration, with the residual disagreement made exact.

End with a one-sentence summary on a line by itself beginning "Summary:" that says what the two sides still fundamentally disagree about after all the verbal issues are cleaned up.
