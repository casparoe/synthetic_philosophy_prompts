Friend of mine's been insisting that knowledge makes you rationally immune to counterevidence, and he laid it out like this. I can't tell if he's actually proved it or if one of the steps is doing sneaky work. Here's the argument:

(1) If you know the lump is benign, then the lump is benign.
(2) If the lump is benign, then any biopsy result saying it's malignant is misleading.
(3) So if you know the lump is benign, you know ahead of time that any biopsy result saying it's malignant would be misleading.
(4) If you know ahead of time that a piece of evidence would be misleading, then when it arrives you can rationally set it aside.
(5) Therefore, if you know the lump is benign, you can rationally set aside any biopsy result saying it's malignant.

The conclusion obviously can't be right—people should revise their beliefs on new evidence even if the old belief was knowledge. So which step, if any, fails? I keep going back and forth between (3) and (4). Go through the argument carefully, say what's valid and what isn't, and give the strongest reading of the bad step on which it's true and whether the argument still goes through.
