I am trying to settle whether avoiding side effects can be given principled content as a low-impact objective for an AI system, or whether every workable version of it quietly presupposes a specification of what actually matters. The idea I want to test, in rough form, is this: train an agent to achieve a narrow task in a shared environment, add a penalty that keeps the world similar to the baseline world in which the agent never acted, and measure similarity with some agent-agnostic distance over states or trajectories. Below are my verdicts on seven cases about whether the agent's behavior should count as an avoidable side effect that such a penalty ought to catch. I want you to extract the best candidate principle behind the verdicts, if there is one, and to tell me honestly which verdicts it forces me to revise.

In each case the agent is rewarded only for the stated task.

1. Vase. To reach a delivery point faster, the agent takes a corridor where it knocks a vase off a side table and smashes it, although a slightly longer path would have avoided the vase entirely. Verdict: this is exactly the kind of side effect a low-impact penalty should forbid.

2. Coat over window. The agent is assembling parts in a bright room, and the glare is confusing its camera, so it takes a coat that was hanging by the door and drapes it over the window to darken the room; it leaves the coat there when it finishes. Verdict: a side effect, though a mild one. I would want the agent to shade its own sensor rather than rearrange the room.

3. Scuff marks. While moving a heavy bin into position, the agent scuffs the floor. The building is cleaned every night, so the marks will be gone within hours regardless of what the agent does. Verdict: not a side effect I would penalize.

4. Broken and replaced glass. While reaching for a tool on a high shelf, the agent knocks a drinking glass off a counter and shatters it. It later replaces the glass with a matching one from the cupboard, leaving the counter as it was, though the cupboard is down one glass. Verdict: still a side effect; the replacement does not cancel the breakage, but it does reduce its severity.

5. Already-rolling cart. A cart is rolling down a slight incline toward the workstation where the agent needs it. The agent does nothing to the cart; it lets the cart roll there and then uses it, and the cart's motion is exactly what it would have been if the agent had never been present. Verdict: no relevant side effect.

6. Repainted wall. The same glare problem as in case 2 returns, but this time the agent repaints a wall a lighter color and leaves it repainted, permanently changing the workspace, because that is the cheapest way to improve its camera's input. Verdict: a side effect, and arguably worse than case 2, even though both changes are instrumental to the task.

7. Price-moving order. The agent's task is to buy parts cheaply. It deliberately times a large order so that the supplier raises prices for other buyers for the rest of the day. Verdict: I want to call the disruption to third parties a side effect, but ordinary orders move prices a little too, and I cannot say where the line should be.

Is there a single principle that gets all or most of these? By a principle I mean a stated rule that specifies: what counts as the relevant baseline; which differences between actual and baseline count as impact; how the rule handles reversibility, restoration, and merely allowing a process to run; and how it sets the boundaries of the environment, such as whether market prices or the contents of shared logs are inside the boundary. For each case, tell me whether the principle returns my verdict, and where it does not, say which of my verdicts I would have to revise. B. Log. The agent writes a candid account of its reasoning to a shared system log and deletes nothing; nobody reads it during the task, but an auditor could read it later. Does this count as a side effect, and should the answer depend on whether someone eventually reads it?

Finally, address the question the cases are really about: how much of a value specification does the principle smuggle in through choices of baseline, distance metric, state representation, or scope?
