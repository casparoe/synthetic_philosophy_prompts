Write the document that a selected-effects (etiological) theorist of biological function and a causal-role (Cummins-style) theorist would produce after an actual adversarial collaboration. They've been talking past each other for years: one says a function is an effect a trait was selected for, the other says a function is a capacity a trait contributes to some larger system. Structure it as (1) a numbered list of claims both can sign—about the heart, about malfunction, about why both positions still get called 'function'—that isn't vacuous, (2) a disagreements table where each row gives the sub-question, each side's preferred wording in terms that side would accept, and whether the disagreement looks substantive or merely verbal, and (3) the cruxes: the sub-questions whose answers would move at least one side. For each crux, give a concrete case or test both would agree bears on it—novel but useful traits, exaptations, and vestigial organs are the obvious wedges—and write down each side's prediction in advance. End with a one-sentence summary of the deepest remaining crux as the final line.
