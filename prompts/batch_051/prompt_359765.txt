Please assess a principle I have been developing, which I call the Arrival-Indifference Principle for rationally selecting priors. Let a constraint be any information that partially specifies a probability assignment: a known expectation, a symmetry, an independence condition, an interval bound on some probability, and so on. A prior-selection rule maps each finite set of constraints to a unique probability distribution on a fixed finite state space. The principle states that such a rule is rational only if its output depends on the total content of the constraints and not on the order in which they were learned: whether an agent first acquires constraint A and then B, or first B and then A, the resulting prior must be the same, and it must also equal the prior assigned directly to A ∪ B. I also impose a no-op condition: appending a constraint already entailed by the others must leave the prior unchanged. For example, an agent who learns first that a variable has a particular expected value and later that two variables are independent should end up with the same prior as an agent who learns the independence condition first; and appending a redundant restatement of the expectation should be completely inert.

My conjecture is that, for a fixed finite state space, the only prior-selection rule satisfying arrival-indifference, no-op, and the requirement that an empty constraint set yields the uniform distribution is the maximum-entropy rule — the rule that selects, among all distributions satisfying the constraints, the one with the greatest entropy. If this is right, I think it gives objective Bayesianism a cleaner foundation: maximum entropy would follow not from a principle of indifference or an appeal to epistemic conservatism, but from the thin requirement that a rational prior be a function of an agent's information rather than of the history through which that information happened to arrive.

I would like an honest assessment. Is the conjecture true, or are there counterexamples — rules that are order-insensitive in this sense yet differ from maximum entropy? Is the idea behind arrival-indifference already familiar under another name, and how does it relate to the usual ways of motivating maximum-entropy reasoning? Finally, does arrival-indifference actually carry epistemic weight, or does it merely restate a consistency condition too weak to select a prior on its own?
