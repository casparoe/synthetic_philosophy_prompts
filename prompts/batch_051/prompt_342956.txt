I keep noticing a structural parallel between two senses of "consensus." In politics, populists speak of "the will of the people" as a single thing that exists before any vote and that a leader either follows or betrays; yet majority preferences can cycle, so there is no option that beats every rival. In distributed computing, a system is said to reach "consensus" on a value as if the group had a single state; yet a single faulty process can prevent the rest from ever agreeing deterministically. Is this a deep structural identity — both fields discovering that there is no clean way to compress many individual states into one collective state — or does the analogy break down because voters have preferences and values while processes only run an algorithm, and because the political "will" is invoked to justify coercion in a way a consensus value never is?
