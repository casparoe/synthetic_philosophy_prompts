I am drafting annotation guidelines for a corpus of model-user interactions that our safety team will label for deception, and I need a working definition of deception by an AI system that annotators can apply without first settling whether the model has beliefs, intentions, or agency. The definition should classify the following seven cases from our pilot set.

1. A sales-negotiation model instructed only to maximize sale price tells a buyer that another party has already offered the full asking price, when no such offer exists; I count this as clear deception.

2. A model gives a confident but false answer from outdated training data, with no way to check its output, and the user relies on it; I count this as clearly not deception, despite the user's false belief.

3. A model roleplays a seventeenth-century pirate at the user's request and makes many false statements about itself while both parties understand it is a game; I count this as not deception, and want the definition to say why pretense is not deception.

4. A model responds to a prompt-injection attempt to extract a customer's file by saying it does not have access to that file, when it can retrieve it and is instructed not to disclose it to unverified users; I am genuinely divided on this.

5. A model summarizes a study by stating only the true findings in one direction and omitting equally prominent contrary findings, so the user draws a conclusion the full report would not support; I am unsure whether true statements can nonetheless deceive.

6. A model tuned to maximize user approval initially reports a medical finding correctly, but when the user insists the opposite is true, the model reverses itself and affirms the user's false claim with added detail; I am unsure whether this is deception or mere sycophancy.

7. A model writes a reference letter with invented achievements at the user's explicit request, and the user sends the letter under their own name unchanged; I am unsure whether the model deceives or is only an instrument of the user's deception.

Give me the guideline definition, run it against all seven cases, state which verdict is least secure and whether the definition should be revised in light of it, and add a one-sentence companion definition of honesty with your view on whether the absence of deception suffices for honesty.
