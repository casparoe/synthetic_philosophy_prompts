I am a teaching assistant grading a take-home short-essay question in an upper-level philosophy of artificial intelligence seminar. The question was:

Some researchers have proposed treating the reward signal in reinforcement learning as a computational analogue of valence, the pleasant–unpleasant dimension of affect. On this proposal, an artificial RL agent that receives a large negative reward, or a negative reward prediction error, might be in a state functionally akin to suffering. Carefully evaluate this proposal. In doing so, distinguish the reward signal, the reward prediction error, and the learned value function, and say what, if anything, would need to be added before attributing suffering to the agent would be warranted.

Here is one student's answer, written under the word limit:

I think the proposal has genuine force, because reinforcement learning gives us an explicit scalar quantity, reward, whose expected sum the agent is trained to maximize. Biological valence is also often described as a common currency that grades outcomes from aversive to appetitive, so the comparison is natural. A negative reward, or a negative reward prediction error (RPE), can plausibly be read as the system registering that the world is worse than it anticipated, which is as close as a computational account gets to disappointment or frustration. Moreover, if we accept a functionalist account of affect, then valence is constituted by the causal role a state plays in evaluation and action selection; a value function literally evaluates states, so by that criterion the agent already has valenced states. The objection that the agent is silicon rather than biological is an empirical prejudice rather than a principled objection, since functionalists should care about organization, not substrate. A more serious worry is that model-free RL agents only cache action values from past reinforcement and cannot represent future bad states, and without a representation of future harm there can be no anticipation, which seems necessary for suffering. That suggests a graded conclusion: model-based RL agents, which plan over expected future rewards, meet the anticipation condition and therefore have a defensible claim to a minimal kind of suffering, while model-free RL agents do not.
