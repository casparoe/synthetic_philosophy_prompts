My undergrad philosophy club has about 18 regulars and a single 75-minute slot coming up. I'd like to spend it running a game on the prisoner's dilemma, but I don't want the standard one-round version everyone has already seen. I want an activity where students actually experience why the one-shot and repeated versions feel completely different — specifically, how the same payoffs switch from defecting being the smart play to cooperating possibly being the smart play when there's a real prospect of running into the same person again. One thing I'd love the game to make vivid is the known-endpoint problem: if the final round is common knowledge in advance, the rational-defection logic creeps backwards, so I'm thinking the game should let the interaction continue with some probability each round instead of a fixed number of rounds. I need rules, materials, a points-only payoff scheme (real money would get weird), and a debrief that ties what actually happened back to the evolution of cooperation. Also a candid list of what will predictably go wrong the first time I run it and what to do about it.
