I teach an upper-level undergraduate seminar on conceptual issues in programming — sixteen students who can all write code but have never studied language semantics — and I have one 75-minute session. Design an unplugged classroom activity that makes them feel, rather than merely hear, why mutation makes programs hard to reason about. The activity should be built around two distinctions: rebinding a variable versus mutating the object it points to, and copying a value versus copying a reference. It should also force the issue of object identity independent of value: each object should carry an identity (a serial number, say) so that two objects holding the same value are not confused with one object having two names. By the end, students should have run into the surprise of action at a distance themselves — a step that changes x and unexpectedly changes what y sees, because the two names are bound to the same object — and they should see why a swap function that tries to exchange a caller's two variables by rebinding its parameters fails to touch the caller's variables at all. Do not front-load the lesson: the named concepts — aliasing, pass-by-sharing, read-modify-write races — should come out in the debrief, after the students have stumbled into them.

Give me: the materials (index cards for objects, labels or arrows for bindings, a whiteboard heap diagram); a set of escalating rounds with exact rules and a timeline for the 75 minutes, including at least a round that isolates the value-copy versus reference-copy ambiguity, a round in which a swap routine goes wrong, and a round in which two interleaving threads execute a read-modify-write on the same card; and a debrief that maps each moment of confusion onto the underlying concept. Also tell me what will predictably go wrong the first time I run it — which distinction students blur, where the room stalls, how to recover — and end with an honest note on which feature of real mutation the activity cannot reproduce and where I, as facilitator, have to supply the missing piece.
