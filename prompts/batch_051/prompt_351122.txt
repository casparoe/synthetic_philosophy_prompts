Here's the argument more or less as he gave it:

1. For set-theoretic purposes, the real line is the powerset of the naturals, so the continuum is the cardinal 2^{ℵ₀}, and CH asks whether there is any cardinal strictly between ℵ₀ and 2^{ℵ₀}.
2. Every uncountable closed set of reals has a perfect subset and therefore has size exactly continuum (Cantor–Bendixson). The same holds for all Borel sets and even for all analytic sets, which are continuous images of Borel sets: any uncountable set from those families has size continuum.
3. So a set of reals of intermediate size — a counterexample to CH — would have to come from outside those nice families. It would have to be a non-analytic, wild set of the kind that only shows up through heavy use of the axiom of choice or nonconstructive tricks.
4. But those wild sets are precisley the ones we have no independent grip on. They cannot be exhibited, named, or defined in any ordinary mathematical sense; they are an artifact of letting the axioms posit arbitrary subsets, rather than something our concept of 'subset of the reals' actually commits us to.
5. So when we ask whether there is a set of reals of intermediate size, the honest answer is: not among any sets we can actually mean or point to.
6. Therefore CH is true in the only sense that matters, and the allegedly consistent models of not-CH are just models that happen to contain such artifacts.
