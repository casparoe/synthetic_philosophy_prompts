For a paper I am writing in the philosophy of mind, I have been working through the language of thought hypothesis by taking seriously its most common analogy: that the mind runs something like a program written in an inner code. I have built an argument that seems to show either that the analogy is empty or that it undermines the view it was meant to support, and I cannot find the mistake. I would like a diagnosis rather than a survey.

(1) The language of thought hypothesis holds that the vehicle of thought is a systematic, productive inner code: complex representations are built from primitives by recursive rules, and the semantics of a complex representation is determined compositionally from its parts.

(2) The best-understood examples of such a code are high-level programming languages. A language such as Python has a finite stock of primitive constructs, recursive rules of composition, and a compositional semantics supplied by an explicit language specification.

(3) If the inner code is code in the sense in which Python is code, then its semantics must likewise be supplied by a specification that assigns an interpretation to each primitive and to each rule of composition.

(4) For Python, that specification is an artifact made by language designers. The symbol system receives its interpretation from outside; neither the expressions themselves nor an interpreter executing them supplies their meanings.

(5) The inner code of thought cannot receive its interpretation from outside in that way: ex hypothesi there is no designer, and the primitives of the inner code are supposed to be the very things in virtue of which mental states have content.

(6) Therefore, either the inner code is not code in the programming sense, in which case the analogy does no explanatory work, or it is code in that sense but lacks any supplied semantics, in which case the analogy has made representational content mysterious instead of explaining it.

That conclusion seems too strong, since the programming analogy is usually introduced precisely to explain the combinatorial character of thought. I would most like to keep something close to (1) and (2), but if they cannot be held together with the rest, I want to know what the cheapest repair is. Tell me which step is the first to go wrong, why that step looked true, and what abandoning or modifying it commits me to about mental representation. For each part of your diagnosis, indicate how confident you are and where the diagnosis depends on a contestable reading of the language of thought hypothesis. If you think the question as posed is badly formed or rests on a mistaken assumption, say so plainly rather than forcing a diagnosis. Please answer in American English.
