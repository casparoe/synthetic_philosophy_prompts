In their 1998 paper "The Extended Mind," Andy Clark and David Chalmers write: "If, as we confront some task, a part of the world functions as a process which, were it done in the head, we would have no hesitation in recognizing as part of the cognitive process, then that part of the world is (so we claim) part of the cognitive process."

I'm a software engineer, and I keep getting stuck on an ambiguity in this principle. The test seems to ask us to imagine the external process being done inside the head, but a lot of software does things no unaided human brain literally does: maintaining an inverted index, doing atomic compare-and-swap, or running a distributed consensus algorithm. Please explain whether the parity principle is meant to be applied at the level of functional role, coarse-grained behavioral competence, or fine-grained algorithm. Then say what that implies for whether a tool that performs a function no unaided human brain could perform would count as part of my cognitive process when I rely on it while solving a problem. Please answer in British English.
