I'm in a class on long-run forecasting and state decline, and we keep running into the outside-view point, and i honestly cannot figure out which part of my own head to trust. The outside-view argument about empires strikes me as basically right as a method: if you want to know how long a polity like ours will last, you should not start from the fine-grained texture of its current politics — you should start from the base rate in some reference class of roughly similar cases and then update only on genuinely discriminating evidence. Elites in every polity that collapsed thought their own situation was special, so the fact that we think our situation is special should count for almost nothing. That is a tidy, impersonal decision procedure, and I am attracted to it. At the same time, I have a very firm intuition that putting a modern liberal state in the same bucket as Rome or the Ottomans is missing something — nuclear weapons change the cost of great-power war, economic interdependence changes incentives, maybe democracies dont fight each other, and anyway the reference class feels up for grabs: pick 'empires' and you get one base rate, pick 'great powers after 1945' and you get another, pick 'nuclear-weapon states' and you get a third. So I don't know whether my sense that the present is structurally different is actual insight or just the inside-view bias the theory predicts I would have. Which should yield? Is there a way to make the outside view and the intuition compatible, and how would I tell the difference between a legitimate reason to narrow my reference class and ad hoc special pleading?

What I'd really like is the strongest version of both sides and then a negotiated verdict: what would justify giving up the intuition and going with the base rate, what would justify amending or restricting the outside-view rule, and whether there is a reading on which they don't conflict. The deeper question I keep hitting is how anyone earns the right to a reference class in the first place — is that a factual question, a methodological question, or both?
