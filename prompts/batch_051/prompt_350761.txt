I'm a PhD student working on conditionals and formal semantics, and I keep going back and forth on Lewis's triviality result for indicative conditionals. I've reconstructed the argument below and I cant tell whether step 4 is licensed by (1) as stated or whether it silently strengthens the thesis. Write A → C for the indicative conditional 'if A then C', with A and C ordinary factual propositions. Take a rational credence function P over a language containing all of these, with 0 < P(C) < 1, and pick A, C such that P(A ∧ C) > 0, P(A ∧ ¬C) > 0 and P(C|A) ≠ P(C) — e.g. P(A) = 0.5, P(C) = 0.5 and P(A ∧ C) = 0.4.

(1) Stalnaker's Thesis: for any probability function Q over this language, Q(A → C) = Q(C|A) whenever Q(A) > 0.
(2) So P(A → C) = P(C|A).
(3) By the law of total probability, P(A → C) = P(A → C | C)·P(C) + P(A → C | ¬C)·P(¬C).
(4) Applying (1) to Q = P(·|C): P(A → C | C) = P(C | A ∧ C) = 1.
(5) Applying (1) to Q = P(·|¬C): P(A → C | ¬C) = P(C | A ∧ ¬C) = 0.
(6) Substituting (4) and (5) into (3): P(A → C) = P(C).
(7) Combining (2) and (6) gives P(C|A) = P(C), contradicting the choice of A and C.
(8) So Stalnaker's Thesis trivialises: it forces every such pair A, C to be probabilistically independent.

Step 4 looks suspicious to me — applying the thesis to a conditionalised probability function feels like it sneaks in the assumption that learning C shouldn't change the conditional. But (1) does say 'any probability function Q over this language', and P(·|C) is one. Is the argument valid as a reductio of the unrestricted thesis, or does something after (1) fail?
