In the chapter of The Logic of Chance where he introduces what later came to be called the reference class problem, John Venn observes in effect that any individual event has an indefinite number of properties, that it can therefore be placed in many different classes, and that the probability assigned to the event will vary according to the class chosen. I think this observation, pressed hard, proves too much. I have an argument I cannot escape: (1) A singular probability claim about an individual, such as a statement that the probability that this patient survives five years is 0.8, is true only if there is a correct reference class relative to which that number is asserted. (2) Any individual belongs to indefinitely many natural reference classes: smoker, male, aged 50 to 60, smoker with this tumor grade, patient enrolled in this trial, and so on. (3) Many of these classes support incompatible probability values for the same outcome, and none is automatically privileged. (4) If a correct reference class exists, there must be a non-arbitrary rule that picks it out from the rest. (5) Every candidate rule either is empty, collapses into using the class that gives the right answer, or selects a class on purely pragmatic grounds. (6) So there is no non-arbitrary rule, and by (4) no singular probability claim is true. (7) But medicine, law, and insurance constantly make such claims, and we treat some as much better-founded than others; if (6) is right, that entire practice rests on falsehood or arbitrary choice. Which step should I reject, and what do I give up by rejecting it? If I have to choose, I would rather keep (7) and reject (1), but I cannot yet see what a probability for this individual could be once truth is out of the picture.
