The other day someone gave me this argument that chat models still are not agents, and I can't work out if its sound. Could you go through it step by step and tell me whether the conclusion follows, and if not exactly where it goes wrong?

(1) A system counts as an agent only if it has goals that persist across a whole episode and it selects actions because it expects them to make those goals more likely.
(2) A language model, even after instruction tuning and RLHF, is still just trained to output whichever token scores highest under its objective given the context.
(3) Outputting the token that scores highest under an objective is sequence completion or function fitting, not selecting an action because it will achieve a goal.
(4) Chain-of-thought doesn't help, because every step in the chain is itself just a predicted token, and the final answer is still whatever token is most probable given the prompt plus the chain.
(5) Therefore a chat model that plans out loud, calls tools, or works through a request is not an agent; its just doing very elaborate next-token prediction.

I find (4) suspicious, because the model is allowed to spend extra intermediate computation before committing to an answer, which sounds like it's doing something more than one-shot prediction. But maybe that's just a surface difference. Is the argument valid? If it isn't, say which step fails and give the strongest version of that step on which the argument would go through, or the strongest objection to it.
