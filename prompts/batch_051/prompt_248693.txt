Here is an argument that the notion of readiness-to-hand, used to describe how we normally encounter equipment in use, is a reconstruction that can never be given in experience directly.

Start with the standard distinction. A tool is ready-to-hand when it is in use and transparent: you do not attend to it as an object with properties because you are absorbed in the task, and the tool is there for your purposes. A tool is present-at-hand when it becomes a thing you can inspect and describe — a hammer with a certain weight and shape, a pen that has run dry.

(1) A tool is ready-to-hand only if it is encountered in use, not as an object of explicit attention.
(2) Whatever is genuinely encountered must be available to awareness in some way, however peripheral.
(3) The only point at which readiness-to-hand becomes available to awareness is when use breaks down: the hammer slips, the pen runs dry, the interface freezes.
(4) But breakdown is precisely the point at which the tool stops being transparent in use and instead becomes conspicuous as an object with properties that obstruct the task.
(5) So at the very moment readiness-to-hand is available to awareness, the tool is no longer ready-to-hand but present-at-hand.
(6) Therefore readiness-to-hand is never itself available to awareness; it is posited only as the mode whose absence one notices after it has already collapsed.
