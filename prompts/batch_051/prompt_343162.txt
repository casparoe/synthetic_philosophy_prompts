I'm reading a pop linguistics book, and there's a chapter that keeps coming back to the claim that a writing system is basically a theory of which parts of speech are worth recording. The author sums it up in a paragraph I can't fully evaluate:

"An alphabet is a map from letters to sounds, and the ideal is one letter per sound, which Spanish and Finnish get basically right. English fails at this because it uses twenty-six letters for more than forty sounds, so letters do double duty and the same sound can be spelled five different ways. A properly designed writing system would be completely phonemic: one symbol per phoneme, no silent letters, no irregular spellings. Hangul is the usual example of a script that actually pulled this off, which is why Korean spelling is basically problem-free. By this standard, English orthography is just bad engineering."

I'm inclined to buy that English spelling is a mess—the standard story about the Great Vowel Shift and borrowed French spellings is probably true—but the slide from "English doesn't match pronunciation" to "English is badly engineered" feels like it's smuggling in a value judgment. How much of this paragraph should I trust? I'd like an audit of it: which claims in the paragraph are safe, which ones only look true because the author is using "sound" and "phoneme" loosely or assuming that writing's only job is to notate speech, and does the final "bad engineering" verdict survive once those are cleaned up?
