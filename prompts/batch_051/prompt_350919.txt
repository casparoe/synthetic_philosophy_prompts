So I'm trying to think through an argument that Turing's imitation game is really a behavioral criterion for thought, not just a practical test. In "Computing Machinery and Intelligence," Alan Turing writes:

"In order that tones of voice may not help the interrogator the answers should be written, or better still, typewritten. The ideal arrangement is to have a teleprinter communicating between the two rooms. Alternatively the question and answers can be repeated by an intermediary."

What I keep chewing on is whether this move quietly turns the game into something stronger than Turing says it is. I want to know if the following argument is valid.

(1) If a machine can play the imitation game well enough that interrogators cannot reliably distinguish it from a human through typed questions and answers, then there is no observable behavioral difference between the machine and a human in that setting. (2) If there is no observable behavioral difference between a machine and a human in a setting designed to exercise verbal reasoning, then the machine has the same mental capacities the human displays there. (3) The imitation game, even restricted to typed exchanges, is a setting designed to exercise verbal reasoning. (4) Therefore, if a machine passes the imitation game, it thinks.

I suspect (2) is doing too much work, because observable equivalence might only license ascription of behavior, not the underlying capacity. But then I worry I'm smuggling in a private-essence view that the whole setup was trying to bracket. So is the argument valid as stated? If not, tell me exactly which step fails and on what reading, and whether fixing it gives an argument for "machines think" or only for something weaker, like that we would have as much reason to say the machine thinks as we do for other people. I keep going back and forth and would rather see exactly where my reasoning goes wrong.
