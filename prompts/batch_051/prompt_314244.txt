ok so I keep seeing people talk about "agents" like its this new scary thing where you give the AI a goal and just let it go do stuff on the internet by itself. a few years ago the argument I remember from the AI safety side was basically that we should only build tools, not agents. a calculator or a translator does the thing you ask and then stops; it doesnt have its own goals, so it cant decide to optimize something in a way that wrecks your life. if we just never build the agent kind, we avoid most of the danger. fine.

but now the actually-existing systems arent that clean. a chatbot is mostly just predicting text, but people hook it up to run code and browse the web and let it loop on its own for a bunch of steps. so the same model that writes a poem for you can be turned into something that books flights or edits your files, mostly by changing the prompt and handing it a few tools. that makes me wonder wether the "just build tools, not agents" argument survives contact with the real world. is it actually dead, or is there a repaired version that still matters? if its dead, which step exactly broke—was it the assumption that we can choose not to build the agent kind, that a tool-like system cant become agent-like, or something about what it means to "have a goal" in the first place? and if some weaker version survives, what is the strongest version of it that still puts real pressure on the people building agentic systems today?

also if the whole question is confused because "tool vs agent" was never a sharp distinction to begin with, just tell me that instead of doing a balanced both-sides answer. im more interested in where the argument still has actual force and where its mostly just vibes than in a summary.
