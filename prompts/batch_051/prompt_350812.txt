I had a thought while untangling a gnarly git history and I can't tell if it's real or just pattern-matching. Dennett's multiple drafts model of consciousness says there is no Cartesian theater — no single place and time in the brain where a content becomes conscious. Instead the brain is always producing lots of parallel, partial interpretations, constantly edited and re-edited, and the thing we call a conscious experience is whatever draft happens to get probed when we're asked to report, or when we ask ourselves. There is no master copy; a serialized story just gets told after the fact.

This feels eerily like what git actually does. A repository has no single canonical line of development; it's a mess of branches, merges, cherry-picks, and rebases. When you run git log, you don't read out a stored history — git reconstructs a linear-looking narrative on the fly from the commit graph and some rules about which parent to follow. A rebase literally rewrites history so that work that was developed alongside other work appears to have been done neatly on top of it afterwards. Squashing does the same. So the clean, single, temporal story we tell ourselves ("then I did this, then I thought that") would be the git log, while the actual mess underneath is the drafts.

I can even line up the pieces: the Cartesian theater would be the belief that there's a privileged master branch that is the real history; probing and reporting is git log; the brain's constant revision is rebasing and cherry-picking. But maybe this is exactly backwards — maybe git is just a tool built to make distributed edits legible, and consciousness isn't a legibility problem at all. Or maybe the analogy breaks because in git the diffs are discrete and well-defined, while in the brain the boundaries between drafts aren't.

Is this a genuine structural identity, a loose analogy, or a confusion? If it's real, does anything from git transfer — say, about merge conflicts, or about how rebasing hides evidence of concurrent work — and tell us something about consciousness that multiple drafts doesn't already say? If it's superficial, where exactly does it come apart? To keep me honest, lay out the mapping, say what would have to be true on both sides for any results to transfer, and name at least one thing the parallel predicts that is actually false.
