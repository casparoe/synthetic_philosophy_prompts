Hey, I'm a PhD student on the theory/historiography side of history, and I'd love comments on an essay I'm sketching. The topic is the standard one about collective memory versus the historical record: when a community's memory and the record conflict, which should give way? I think almost everyone frames this wrong, as if memory is always trying to establish facts and just doing it badly. I want to argue there are really three registers, and the answer changes by register.

First, memory-as-evidence: when a community's story is being offered to establish what happened, the better-sourced record wins and memory gives way. Second, memory-as-identity: when a community's rituals, commemorations, and self-descriptions carry a story whose work is orientation rather than report, the record and the memory aren't actually competitors, and talk of one 'giving way' is a category error. Third, memory-as-counter-archive: when the surviving record is thin or was produced by powerful actors, transmitted memory can be positive evidence against or beyond the record — which means memory can win on epistemic grounds, not just ones of politeness or harm-aviodance.

My read is that once you sort these apart, the hard residue is only the case where an identity-bearing memory hangs on a specific factual claim that the record contradicts. There I don't think there's a general rule, and I want to say the debate should stop looking for one: that case is an ethical/political choice, and calling it a 'memory versus history' problem hides that.

So the comments I'd like: (a) is the three-register distinction doing real work or just relabeling the positions people already hold? (b) where does it start to break — e.g., when an oral memory gets written down and enters the archive, or when the 'record' is itself mostly sedimented memory? (c) does the final move just shrink the original question rather than answer it, and if so is that still a contribution? Also, I suspect the first register is less clean than I'm making it sound; can you push on that?
