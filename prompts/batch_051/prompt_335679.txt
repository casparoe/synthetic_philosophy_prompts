I have been working through the definition of randomness used in algorithmic information theory, because I need a principled way to say whether an individual cryptographic key is acceptable, and I have hit an argument that seems to show the definition is self-defeating. I would like a precise diagnosis, not just a vote on which premise to drop.

Take the standard incompressibility criterion: a finite binary string is random just in case no program shorter than the string, when run on a fixed universal computer, outputs that string. Now consider this chain of reasoning:

(1) By counting, for every length n there is at least one incompressible n-bit string. There are 2^n strings of length n, but at most 2^n − 1 programs shorter than n bits, so not every string can be compressed below its own length.

(2) Therefore, for every n, there is a lexicographically first incompressible n-bit string. Call it s_n.

(3) The string s_n admits a description: the lexicographically first incompressible string of length n.

(4) This description is short. Writing n in binary costs about log₂ n bits, and the rest of the description is a fixed phrase whose size does not depend on n. So the whole description is roughly log₂ n plus a constant.

(5) In this theory, a description of a string is exactly a program that prints the string. Since the description in (3) uniquely identifies s_n, there is a program of length roughly log₂ n plus a constant that outputs s_n.

(6) For all sufficiently large n, that length is less than n. So s_n is compressible.

(7) But s_n was defined to be incompressible. The one string guaranteed to be random is therefore not random, and the incompressibility criterion for a random finite string appears to collapse. Taken seriously, this would leave no principled sense in which one key is random and another is not.

The conclusion is absurd, yet I cannot see which step is false. Which step in this chain should be rejected, and why did it look like a harmless formal detail? If you take the argument to be valid, then which premise is least costly to abandon, and what else would have to be given up along with it?
