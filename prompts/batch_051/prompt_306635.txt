I spent forty years as a research chemist, and in all that time I never once asked what justifies modus ponens — you just put the data together and see whether the prediction comes out. Since I retired I've been reading philosophy of logic, and Lewis Carroll's little dialogue where Achilles tries to get the Tortoise to accept a simple conclusion has gotten under my skin. Out of it I've built the following argument, and I honestly can't tell whether I've proved something deep or just fooled myself.

(1) I'm entitled to use an inference rule only if I can give a good argument that it is truth-preserving. (2) Any argument that a rule is truth-preserving must itself be deductively valid, so it must rely on some inference rule. (3) For a given rule R, the required argument either uses R itself or uses some other rule. (4) If it uses R itself, the argument is circular — for modus ponens you'd get something like: if a rule is truth-preserving then it's a good rule; modus ponens is truth-preserving; so modus ponens is a good rule, and that very move is a modus ponens — and a circular argument can't justify anything. (5) If it uses some other rule, then that rule has been used without first being justified, so it's just the same problem moved one step along. (6) The whole thing either regresses forever or bottoms out in a rule used without justification. (7) So no inference rule is ever justified, and deduction rests on nothing. The conclusion seems absurd — my whole career was a long exercise in drawing conclusions from data — but I cant locate the bad step. I half-suspect (4) trades on two senses of 'circular,' becuase an argument for modus ponens that happens to use modus ponens isn't circular the way an argument that assumes its conclusion is. But I can't make that precise, and it might just be wishful thinking.
