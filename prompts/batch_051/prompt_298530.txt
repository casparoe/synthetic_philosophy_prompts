I work on language and system design, so I want to test an old philosophical argument against an engineering proposal. The argument, sometimes called the essential-indexical argument, says that self-locating knowledge cannot be reduced to objective description: someone can know every objective fact about a scene — for instance, that a particular shopper is making a mess — and still not know that he is the shopper; replacing the pronoun with a name, a description, or a set of coordinates is said not to help, because the agent would still need to know which name, description, or coordinates pick him out. Now suppose a community deliberately designs its language to contain no context-dependent expressions at all: no pronouns or demonstratives, no words like here, now, or you; every agent has a unique permanent public identifier (like a UUID), and all spatial and temporal reference must be given explicitly as coordinates and timestamps, the way one might make the agent and context explicit parameters of a function rather than implicit state. Does the essential-indexical argument survive this engineered language? If such a language is workable, does it show that the first-person pronoun was replaceable all along, or does the same problem reappear in a new form — for instance, in a speaker's need to know which identifier corresponds to their own body? I want to know exactly which premise of the original argument the proposal puts pressure on, and how the argument should be restated or repaired if it still goes through.
