I've been going back and forth with some friends about what actually makes something a "mathematical object," and I've realized I don't have a working definition I can apply when a case gets weird. By a legitimate mathematical object I mean the kind of thing mathematicians are allowed to talk about, prove things about, and use inside other proofs without feeling like they've drifted into physics or poetry. Propose a definition and test it against these: the natural number 7; the imaginary unit i back when people used it to solve cubics but had no real story for what it was; the infinitesimals of Euler-style calculus, which people treated as smaller than any positive number but bigger than zero; the Dirac delta, usually written δ(x), which physicists describe as zero everywhere except at x = 0 and integrating to 1, even though no ordinary function does that; a non-measurable set of real numbers, which you can prove exists if you allow the axiom of choice but which can't be exhibited by any formula and has no well-defined length; and the set of all sets, which is easy to describe but leads straight to Russell's paradox. I'm fairly confident 7 is legit and the set of all sets is not, and I genuinly don't know about the four middle ones. Run the definition through all six, tell me where it forces you into a surprising verdict, and if you think the word "exists" in math is doing two different jobs, give me both definitions and say which cases move between them.
