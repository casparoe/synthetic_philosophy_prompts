I keep being told that suffering is substrate-neutral, and I want to know if the following argument against that actually works or whether I'm fooling myself.

(1) If suffering is just the running of a certain kind of computation, then any physical system that runs that computation is suffering.
(2) A human brain during, say, a thirty-second episode of agony runs some finite computation C, if we idealize the brain as a finite-state machine over that interval.
(3) Whether running a computation is morally bad is fixed by what kind of computation it is, not by the hardware.
(4) Any finite computation can be run by a sufficiently large lookup table: a clerk follows instructions of the form "in state S with input I, write O and move to state T."
(5) So the clerk-plus-table system runs C, and is therefore in agony (by 1) and doing something morally bad (by 3).
(6) Therefore, functionalism about suffering commits us to saying a clerk stepping through a giant printed table full of state transitions is in agony, and we should stop them.

I don't believe (6), but the individual steps all sound right to me. I suspect the word "runs" shifts between (4) and (5), but I can't make the distinction precise. Tell me: is the argument valid, and if not, exactly which step fails, under what reading, and how should it be restated so the conclusion doesn't follow?
