Program equilibrium was originally set up for two bots playing prisoner's dilemma, where each player's strategy is a program that can read the other program's source before choosing, and the classic move is a program like "cooperate iff the other program is identical to me, otherwise defect": against itself it cooperates, and an attempt to deviate to a defecting program gets punished because the first program notices the mismatch. The setup quietly assumes the programs are small, transparent, and can be simulated or at least checked for exact equivalance.

Now suppose the players are current LLM agents: huge models accessed through an API, with hidden weights, hidden sampling parameters, and system prompts the other side can't see, and no reliable way to simulate the other agent or prove what it will do. Does the program-equilibrium argument for cooperation survive this change? Which specific premise(s) does it break, and is there a repaired version—using public commitments, hashes of system prompts, costly signals, or something else—that still gets us more cooperation than plain causal game theory would?
