I've been reading David Pearce's The Hedonistic Imperative and I can't shake the basic argument: if we could use biotech to phase out suffering across the whole living world, and if what we'd replace it with isn't just numbness but gradients of genuine well-being, then a lot of the usual objections start to feel like they're arguing against a straw man. I'm a software engineer, not a philosopher, so I want to pressure-test the actual position rather than the cartoon of it. Let's say Pearce is right that the biological capacity for suffering is a contingent evolutionary thing, not a necessary feature of any mind. My question is: what would count against that view? Not "what do critics say", but what would a defender of the view have to take seriously as actual counterevidence or conceptual trouble. For example: if we discovered that eliminating the hedonic set point for suffering destabilized other forms of learning or reinforcement in ways that couldn't be patched around, would that be a real defeater, or just an engineering problem? If there are possible minds that need the contrast between pain and pleasure to have any preferences at all, does that undermine the claim that suffering is always dispensable? Or if "gradients of bliss" turns out to be unfalsifiable as a claim because any post-human report can be interpreted as compatible with it, is that a problem for the theory or just for the public messaging around it? I want an honest map of where the position is exposed: which results or arguments would be fatal, which would be merely awkward, and which are basically absorbed by the view without much cost. And I'd appreciate it if you'd say whether the view has gotten insulated enough that almost no observation could actually count against it.
