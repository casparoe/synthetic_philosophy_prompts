Question: Explain how the frequentist and Bayesian frameworks each interpret a 95% interval estimate. Then discuss whether optional stopping—collecting data, checking the results repeatedly, and stopping once a prespecified threshold such as p < 0.05 is reached—is a problem for each framework. Finally, state whether, in your view, pre-registration is necessary for a Bayesian analysis, and briefly justify your position.

Student answer: Frequentists interpret a 95% confidence interval as a procedure that contains the true parameter value in 95% of repeated samples; for any single realized interval, the probability that it contains the true value is either 0 or 1, not 0.95. Bayesians instead compute a 95% credible interval, which permits the direct statement that the parameter lies in the interval with 95% posterior probability, conditional on the model and the prior. Optional stopping is a serious problem for frequentist inference: if a researcher peeks at the data after each new participant and stops as soon as p < 0.05, the nominal significance level is no longer preserved, and the actual Type I error rate rises over repeated experiments. By contrast, Bayesian inference is unaffected by optional stopping, because the posterior depends only on the data actually observed and not on the sampling plan that produced them. A researcher can therefore peek at accumulating data freely; and since the stopping rule drops out of the posterior, pre-registration is not really needed to keep a Bayesian analysis valid.
