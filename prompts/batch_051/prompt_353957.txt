Construct a thought experiment to a precise specification, using the distinction between the inside view and the outside view of a decision. The inside view treats the case at hand as unique and builds a forecast from the specific features of the situation. The outside view treats the case as an instance of a reference class and defers to the distribution of outcomes in that class.

Build a case that satisfies all of the following at once. It must be an ordinary professional or personal decision — no lotteries, no games with stipulated probabilities, no medical-screening scenarios, and no cases in which the base rate is literally the only information available. The outside view must recommend against taking an action, the inside view must recommend taking it, and taking it must be the correct decision on the evidence available at the time — correct not merely in hindsight and not by luck. The outside view's base rate must be true and accurately stated for its reference class, and that reference class must be a natural one to use, not one rigged to be obviously irrelevant. What makes the two views diverge must be visible in the case itself, not imported by stipulating that the protagonist is especially informed, talented, or lucky.

Then carry out the check. State the decision; state the reference class and the base rate the outside view uses; state the inside view's model of the situation; give the verdict each view delivers and the reasoning behind it in that view's own terms. Identify the single feature of the case that does the work — the feature whose presence makes an accurate base rate nonetheless point away from the right decision — and say what both views would recommend if that feature were removed. Finish with the strongest objection a defender of the outside view would raise (for example, that a sophisticated outside view would simply adopt a finer reference class, or that the alleged inside information is already reflected in the base rate), and explain why the case survives that objection.

The case is for isolating the reference-class problem for outside-view deference: the possibility that a base rate can be true of its class, and the class a reasonable one, while still being the wrong class for the decision at hand. A case that merely makes the base rate false, or that makes the protagonist a statistical outlier from the outset, would fail the purpose.
