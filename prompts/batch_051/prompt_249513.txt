Ok so we're covering copyleft in my software/IP class and i keep coming back to one sentence in the GPLv2 (Free Software Foundation, 1991). Section 0 says:

"The act of running the Program is not restricted, and the output from the Program is covered only if its contents constitute a work based on the Program (independent of having been made by running the Program). Whether that is true depends on what the Program does."

This sentence feels like it's doing all the real boundary work, but then it just says "depends on what the Program does" and leaves it at that. For my paper i'm trying to think through a counterfactual. Imagine that starting in, say, 1991, US courts interpreting this exact text came to a stable majority rule: any output whose content is substantially generated by running a GPL-licensed program counts as a work based on the Program, even if it contains no literal Program code and is not a translation or adaptation in the ordinary copyright sense. So a binary compiled from GPL code is contaminated, a PDF typeset by a GPL formatter is contaminated if the formatter contributed non-trivially to its structure, and a lexer generated by a GPL parser generator contaminates anything processed through it? Maybe not that last one, but you get the idea.

My question: how do you think the next twenty years of software practice and the legal debate over "where does one program end and another begin" actually play out under that rule? I want the visible reasoning: which industries or tools would route around GPL software, whether companies would adopt more permissive licenses for foundational tools, how the FSF itself might adjust its rhetoric or licenses, and whether the rule would ultimately collapse because it's unworkable or instead expand because it's self-reinforcing. Which parts of your prediction are robust, and which ones hinge on stuff we can't know? If your prediction would be wrong, what would the world have had to look like?
