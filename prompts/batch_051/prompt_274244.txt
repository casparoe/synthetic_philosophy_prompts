If the shared program defects, then in the symmetric case the other instance defects on you; if it cooperates, the other cooperates. So the program should cooperate, and that's supposed to show that a one-shot PD has a cooperative 'rational' move once you add the premise that both players are running the same decision procedure. It's not reciprocity, it's not reputation, it's just symmetry.
