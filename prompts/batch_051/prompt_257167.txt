Every time I try to understand the GPL and derivative works, the line seems to move. If I copy a GPL function into my own project, everyone agrees the whole thing becomes a derivative work and has to be GPL'd. If I dynamically link my code against a GPL library, a lot of people say that's also derivative. But if I run that exact same library as a seperate helper process and have my program talk to it over a local socket, suddenly they're treated as two programs and my code can stay proprietary — even though the inputs, outputs, and almost all the bytes the CPU actually touches are identical. A function call is just pushing values into a register and getting a result back; an HTTP request is just pushing values into a socket and getting a result back. So does the GPL have an actual rule about where one program ends and another begins, or is the boundary just a legal convenience? And if it's a convenience, why do people act like linking versus not-linking is this huge meaningful fact?
