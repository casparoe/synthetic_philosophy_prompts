For a seminar on modularity, I constructed the following argument. It now strikes me as proving too much, but I cannot locate the mistake. I would rather keep the distinction between encapsulated input systems and isotropic central systems than accept the conclusion, but I need to know which step to reject and what rejecting it costs.

(1) Fodor claims that central belief fixation, unlike the input systems, is isotropic and Quinean: in principle, any belief may bear on the confirmation of any other.
(2) This raises the frame problem for central cognition: how could a system determine which of its many beliefs are relevant to a given inference without already considering all of them?
(3) Fodor takes the frame problem to show that central cognition cannot be modular, since encapsulation would block access to information from outside the module.
(4) But every modular input system faces an analogous problem within its own domain: to process any input, it must determine which representations in its proprietary database are relevant to the current task.
(5) If the frame problem is unsolvable for a non-encapsulated central system, it is equally unsolvable for an encapsulated module facing its local problem; if a module can solve its local problem, then a central system can solve the global problem.
(6) Therefore the frame problem does not distinguish encapsulated modules from non-encapsulated central systems.
(7) If that is right, Fodor's frame problem argument fails to support the claim that central cognition is not modular.
(8) And if central cognition can be modular, then the central argument for rejecting massive modularity collapses.
(9) I cannot accept that the frame problem argument fails, because I share Fodor's sense that central cognition must be non-modular; but I also cannot see which step to give up. Which premise is false, or which inference is invalid, and what does rejecting it cost?
