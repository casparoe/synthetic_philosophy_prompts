The position I want examined is a claim about the foundations of cooperation. In the standard one-shot Prisoner's Dilemma, the orthodox conclusion is that rational self-interested players defect: cooperation looks sustainable only when the interaction is repeated, reputations are at stake, or an external enforcer is available. A family of results on program equilibrium challenges that conclusion. Suppose each player's strategy is realized as a computer program, and each program receives the other program's source code before producing its action. A player can then implement a conditional policy: cooperate exactly if the other program would cooperate, and defect otherwise. When both sides run such policies, mutual cooperation is an equilibrium. A unilateral switch to a defecting program would be detected by the opponent's code, which would answer with defection, leaving the switcher with the punishment payoff rather than the temptation payoff. So, if choices are implemented transparently in code, cooperation can be stable even in a one-shot dilemma with no repetition, reputation, or enforcement.

That is my view, provisionally. I want a map of what would count against it, not a general survey of cooperation. Tell me which assumptions and commitments of the position could in principle fail, and what the world, or the formal model, would have to look like for each to be a live problem rather than a merely logical possibility. Sort the defeaters from fatal to merely awkward, and mark which ones a committed defender would concede as genuinely counting against the position and which they would dismiss as changing the subject. I would also like an honest assessment of whether the view has been qualified into near-unfalsifiability, and whether that would be a problem for a claim of this kind. In particular, address at least these points: whether showing that a cooperative equilibrium exists is enough to overturn the standard conclusion about what it is rational to do, given that mutual defection may also remain an equilibrium; whether replacing bare choices with transparent programs changes the game rather than solving it; and how much damage is done if source code can be hidden, simulated, self-modified, or executed unfaithfully. I am personally most moved by the equilibrium-selection worry, but I want to know whether that cuts against the view itself or only against an overstatement of it.
