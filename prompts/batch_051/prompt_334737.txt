My logic professor has this argument he says shows dialetheism is a dead end, and I can't shake it. It goes like this:

1. A dialetheist handles the liar by saying the liar sentence is both true and false, and they switch to a paraconsistent logic so a contradiction doesn't explode into everything. Fine so far.
2. But take the sentence C: "If C is true, then every sentence is true." C is a sentence about itself, and it looks well-formed enough.
3. Suppose C is true. Then things are the way C says they are. C says that if C is true, then every sentence is true. But we're supposing C is true, so by modus ponens, every sentence is true.
4. So from the supposition that C is true we've reached "every sentence is true." By conditional proof, that means "if C is true, then every sentence is true" is true.
5. But that sentence just is C. So we've proved C, no contradictions involved anywhere.
6. Now C is true, and C says that if C is true then every sentence is true, so by modus ponens again: every sentence is true.
7. And that's trivialism — everything is true, including "1+1=3" and its negation. So dialetheism unpacks into trivialism after all, without ever using explosion.

He says the only real options are to reject modus ponens, reject the claim that C is well-formed, or go trivialist, and that all three are worse then just giving up on true contradictions. But rejecting modus ponens feels insane, and if C isn't well-formed that seems like it'd force weird restrictions on self-reference the dialetheist elsewhere wants to exploit — the liar was supposed to be fine.

Which step is actually doing the damage, and what does rejecting it cost? I'd most like to keep dialetheism and modus ponens if that's viable, but I suspect that's exactly what's not on the menu. Max 700 words.
