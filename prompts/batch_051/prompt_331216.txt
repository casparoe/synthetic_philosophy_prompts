I am a doctoral student in formal epistemology and game theory, and I have been trying to reconstruct an argument about program equilibrium that appears to overturn the standard analysis of the one-shot Prisoner's Dilemma. The argument below purports to show that, once players are allowed to submit computer programs rather than bare actions, mutual cooperation is not merely an equilibrium outcome but the uniquely rational one. The conclusion seems too strong to me, but I cannot identify where the reasoning goes wrong. Please evaluate the argument step by step and say which step, if any, fails, why it fails, and what the corrected version of the argument would establish.

In the one-shot Prisoner's Dilemma, each player chooses strictly between cooperation (C) and defection (D). Let T be the payoff for unilateral defection, R for mutual cooperation, P for mutual defection, and S for unilateral cooperation, where T > R > P > S.

1. In the ordinary version of the one-shot Prisoner's Dilemma, interpreted as a game among actions, defection strictly dominates cooperation because T > R and P > S. Consequently, joint defection is the only Nash equilibrium, and mutual cooperation is not sustained by purely rational self-interest.

2. Now consider a modified game, sometimes called program equilibrium. Each player submits a finite program to a neutral machine. The machine executes the two submitted programs against each other exactly once. Each program may condition its output, which is either C or D, on the exact source code of the other program. The programs cannot communicate in any other way, cannot be revised after submission, and are not played repeatedly.

3. In a suitably expressive programming language, a player can submit a quine Q: a program that, when executed against an opponent program X, first determines its own exact source code, checks whether X is the same string as that source code, and outputs C if it is and D otherwise. Standard fixed-point methods show that such a self-referring program can be written without infinite regress.

4. If both players submit Q, each program sees that the other program is the same string as itself, and both output C. The outcome is mutual cooperation, giving each player R.

5. Suppose one player unilaterally deviates to some alternative program P while the other continues to submit Q. Because P is not the same string as Q, Q outputs D. The deviator therefore receives at most P if P defects, and receives S if P cooperates; both are strictly less than R. Hence no unilateral deviation from (Q,Q) is profitable.

6. It follows that (Q,Q) is a Nash equilibrium of the program game.

7. Since no unilateral deviation from (Q,Q) is profitable, defection has been rationally eliminated in the program game. Rational players will therefore submit programs of the conditional-cooperation kind, and joint defection is no longer a rational outcome. The move from actions to programs therefore transforms the one-shot Prisoner's Dilemma from a game in which rational players defect to a game in which rational players cooperate.
