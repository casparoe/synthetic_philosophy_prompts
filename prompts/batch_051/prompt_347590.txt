Here's one I've been turning over and I cant find the hole. A friend has an argument that "jumping out of the system" — JOOTSing — is forced for any formal system, and he builds it from the MU-puzzle. In the MU-puzzle you start with the string MI and four rules: you can add U to any string ending in I; you can double everything after an M (so Mx becomes Mxx); you can replace III with U wherever it appears; and you can delete UU wherever it appears. The target is to reach MU. The usual proof that you can't is that the number of I's is never divisible by 3. You start with one I; doubling sends 1 to 2 and 2 back to 1 mod 3; removing three I's changes nothing mod 3; and the other rules don't touch the I-count. So the I-count is always 1 or 2 mod 3, while MU has zero I's.

So far so good. Then he lays out the argument:

(1) That proof is not a derivation inside the MI-system; it uses arithmetic on the strings, i.e. it steps outside the system.
(2) So the question of whether MU is derivable cannot be settled from inside the MI-system.
(3) The MI-system isn't defective or unusually weak; it's just a simple formal system.
(4) So for any formal system, there will be questions about its strings that cannot be settled from inside it.
(5) Therefore any formal system requires you to jump out of it to settle some question about it.
(6) So JOOTSing isn't a parlour trick; it's necessary, and in effect every formal system is incomplete in something like Gödel's sense.

I keep thinking the trouble is around (3) or (4), but I can't make it stick, because each step sounds right when I read it aloud. Is the argument valid? If not, exactly which step fails, and what should a corrected version of that step say? If it is valid, does it really show what the last step says? (British English please.)
