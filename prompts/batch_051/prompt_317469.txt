I'm in a grad seminar on causation and a friend gave me this argument; he's now fully convinced causal realism is dead, and I can't find the flaw but also can't except the conclusion. Two kids throw rocks at a bottle. The first rock arrives and shatters the bottle; the second rock was on its way and would have shattered it a moment later if the first hadn't been thrown. Everyone except my friend thinks the first throw caused the shattering and the second didn't. His argument:

(1) If causation is a mind-independent feature of the world, there should be a principled, non-arbitrary reason the first throw, and not the second, caused the shattering.
(2) Counterfactual theories can't deliver that verdict: if the first throw hadn't occurred, the bottle would still have shattered, so the shattering is not counterfactually dependent on the first throw; and the usual fix, chaining through intermediate events, has nothing to grab onto here, because the second rock would have produced the same end state a moment later.
(3) Interventionist theories can deliver it. Hold fixed at its actual state that the second rock doesn't hit the bottle, and it is true that if the first kid doesn't throw, no shattering occurs; if she does throw, it does.
(4) But that answer is an artifact of the model. If the model only has variables for whether each kid throws and whether the bottle shatters, both throws come out as interventionist causes. You get the asymmetry only by adding a variable for the timing of the shattering, or for whether the second rock would have arrived too late, and nothing inside the interventionist framework forces you to use that finer model rather than the coarser one. Model choice is driven by explanatory interest.
(5) So the interventionist avoids the counterexample only by using a model that is already built to make the first throw come out as the cause. That looks circular.
(6) Therefore the two main approaches to actual causation either fail on late preemption (the counterfactual approach) or go in a circle (the interventionist approach).
(7) The best explanation, he says, is that there is no mind-independent fact of the matter about what caused what: actual causation is relative to a model, and which model is right is relative to our interests.

I want to reject (7). But I can't tell wether the weak step is (2), (4), or both, and I don't know what rejecting either one would cost. Where does this go wrong, if it does? Which premise should I give up, and what do the main positions each have to pay to give it up?
