Consider Hofstadter's Platonia dilemma: twenty players are each invited to send, within 48 hours, a message claiming a billion dollars; exactly one message wins the prize for its sender, two or more messages mean no one wins, and zero messages mean no one wins. The superrational argument for this setup assumes that perfectly rational players facing a symmetric problem will all adopt the same strategy, and on that assumption the symmetric answer is for each player to send with probability 1/20. Now alter the dilemma so that the number of invitees is no longer common knowledge: a random process determines how many invitations are sent, and each player learns only that she herself has been invited. Does Hofstadter's superrational argument survive this change? If it does, state the repaired principle and the resulting strategy when the selection process is common knowledge; if it does not, identify the premise that fails. Then say whether a weaker superrational principle still applies when different players hold different priors about the invitation process, or whether the argument necessarily collapses into ordinary Bayesian decision theory.
