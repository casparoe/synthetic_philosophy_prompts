I've been going down a rabbit hole lately about whether human values are really many things or just one thing in disguise. I'm a software engineer, so the way I'd naturally cash this out is: if I can represent someone's choices with a single utility function, doesn't that already settle the question? A freind of a friend posted this argument in a Discord thread and it's been bugging me because it sounds like it proves too much:

(1) Suppose a person's preferences are consistent in the minimal sense: for any two options, they either prefer one, prefer the other, or are indifferent, and their preferences never cycle.
(2) With a couple more mild technical conditions, there's a function u such that the person always chooses the option with the higher u. This is a standard decision-theory result.
(3) If such a function exists, then everything the person cares about—honesty, loyalty, fun, whatever—enters their choices only through a single number attached to each outcome.
(4) A single number can only represent more or less of one single kind of thing.
(5) So all of the person's values must really be amounts of one underlying stuff: utility. The apparent many values are just different ways of producing it.
(6) Therefore, value monism is true, at least for that person.

Set aside the question of whether real humans actually satisfy (1), and assume for the argument that someone does. Is this argument valid? If not, which step fails exactly, and what's the right way to state why?
