Consider the dispute between epistemicism and supervaluationism about vagueness, and fix the following working definitions. Epistemicism says that vague predicates have sharp boundaries, but we cannot know where those boundaries fall; every borderline sentence has a determinate truth value, and our inability to state it is a purely epistemic limitation. Supervaluationism says that vague language admits many admissible ways of drawing the sharp boundaries—call these precisifications. A sentence is true simpliciter if and only if it is true on every admissible precisification; false simpliciter if and only if it is false on every admissible precisification; and otherwise it is neither true nor false. A borderline case is one on which different admissible precisifications disagree.

Now consider the following argument that supervaluationism is committed to sharp boundaries after all, and that its disagreement with epistemicism is smaller than its proponents usually claim.

(1) On supervaluationism, for any sentence S, S is true simpliciter iff S is true on every admissible precisification; S is false simpliciter iff S is false on every admissible precisification; and otherwise S is neither true nor false.
(2) Whether a candidate precisification is admissible is fixed by the meaning of the language together with the non-semantic facts: meaning and the facts settle, for each candidate, whether it belongs to the admissible set.
(3) Therefore, "admissible precisification" is a sharp predicate—any candidate precisification either is admissible or is not admissible, and there is no third kind of status for admissibility itself.
(4) From (1) and (3), the condition "true on every admissible precisification" sharply partitions all sentences into the true, the false, and the neither-true-nor-false.
(5) So, for any vague predicate F and any object a in a sorites sequence for F (a sequence running from a clear case to a clear non-case), there is a sharp, objective fact about whether "a is F" is true, false, or neither. The extension of truth simpliciter has a sharp boundary, even if the extension of F itself does not.
(6) But higher-order vagueness is precisely the phenomenon that it can be vague whether a given case is borderline: the borderlines themselves have borders.
(7) If (5) is correct, there can be no higher-order vagueness, since for each case the status true/false/neither would already be sharp.
(8) Therefore, supervaluationism as stated is incompatible with higher-order vagueness.
(9) The only escape for the supervaluationist is to make admissibility itself vague—to allow that it is vague which precisifications are admissible. But that merely relocates the problem: now "admissible" is a vague predicate, and the supervaluationist must either apply the same treatment to it (and so on up a hierarchy), or accept a sharp boundary somewhere in the hierarchy, which is to concede the epistemicist's point at that level.

Question: Is this argument valid? If not, identify the exact step at which it fails, and state what the correct reading or replacement of that step would be. If it is valid through step (8), can a supervaluationist reject step (9) without circularity, and if so what exactly does that rejection amount to? Be specific about what "sharp" means at each step, and about whether the sharpness in step (5) is the same kind of sharpness that epistemicism asserts.
