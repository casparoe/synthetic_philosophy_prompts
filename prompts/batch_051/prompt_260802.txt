I'm setting this year's final exam for a final-year undergraduate course that runs philosophy of religion together with formal decision theory. Draft one question on Pascal's wager. I want the question to force candidates to do three things: (i) reconstruct the wager precisely enough to say whether it is an argument from dominance or from expected utility, and to write out the decision matrix each reading requires; (ii) run the many-gods objection at its strongest, showing that it is not the bare addition of another row to the matrix but a problem about how the state space is partitioned — so that, if repartitioning is unconstrained, the very same reasoning could be made to recommend any act whatsoever; and (iii) work through a mixed strategy on which the agent wagers with probability q and abstains with probability 1−q for any q strictly between 0 and 1, say what expected-utility theory must conclude about that strategy under the infinite-payoff formulation — the answer should distinguish any version that includes a negative infinity from one that includes only a positive infinity — and explain what this shows about the wager's power to guide action.

Then provide: (a) the exam question itself, which may be broken into sub-parts but must hang together as one 90-minute question; (b) a full model answer that would earn full marks; and (c) a marking scheme built around five must-hit points, with the marks each is worth (total 20) and a one-line note on how candidates typically get each point wrong. The fifth must-hit point should deal with the strongest available reply on Pascal's behalf — for instance, bounding the utilities or restricting the partition by appeal to independent evidence — and whether the resulting argument still deserves to be called a wager.
