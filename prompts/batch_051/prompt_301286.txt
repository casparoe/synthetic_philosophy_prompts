I cover science and ideas for a general-interest magazine, and I am working on a piece about whether the foundations of mathematics are in the business of telling us what numbers are. In the standard set-theoretic development used in many textbooks, 0 is identified with the empty set, 1 with the set containing 0, 2 with the set containing 0 and 1, 3 with the set containing 0, 1, and 2, and 4 with the set containing 0, 1, 2, and 3. On this development, 2 is an element of 4. There is also a rival development in which each number is identified with the set whose only member is its predecessor: 1 is the set containing 0, 2 is the set containing 1, 3 is the set containing 2, and 4 is the set containing 3. On this rival development, 2 is not an element of 4. Both developments satisfy the usual axioms for the natural numbers, and both give the same arithmetic, so arithmetic itself cannot tell them apart. Given that only the first development is standard, am I justified in telling readers that mathematics has discovered a genuine fact about the numbers — that 2 belongs to 4 — and that the rival development simply gets the membership facts wrong? I know there are philosophers who say numbers are only positions in a structure, with no inner set-theoretic constitution; does the success of the standard development settle that debate in favor of the idea that numbers really are sets?
