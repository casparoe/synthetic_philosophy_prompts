I am a doctoral student in moral philosophy, currently working out how much of Kant's Formula of Universal Law survives once it is read through Hare's universal prescriptivism and the generalization argument whose test question is, as it is usually put, "what if everyone did that?" I have built an argument that seems to me to show the test is caught between condemning innocuous occupational choices and being vacuous, and I cannot find where the reasoning fails. It runs as follows. (1) A moral judgment is universalizable in Hare's sense: if I judge that I ought to do A in circumstances C, I am committed to judging that anyone in circumstances relevantly like C ought to do A, and special pleading — exempting myself from a law I prescribe for others — is a defect of rationality. (2) The generalization test is the usual way of giving that formal requirement content: an act is assessed by universalizing it under some description and asking whether a world in which everyone performed acts of that description would be acceptable. (3) In practice this is a consequences-of-universal-performance test, and that is how Kant's own cases seem to work: a false promise is prohibited because, if everyone made promises they did not intend to keep, the practice of promising on which the promisor relies would collapse. (4) But consider the maxim on which I act in choosing to pursue a career in academic philosophy rather than, say, farming, medicine, or infrastructure work. If everyone acted on the maxim of pursuing specialized academic work, the division of labor that makes such work possible would collapse, and the end of the maxim would be defeated just as surely as the end of the false promise. So the test yields that it is wrong to train as a research philosopher. (5) The problem is general: under a coarse description, nearly every occupational choice becomes wrong because universal performance of any single occupation would unbalance the division of labor — if everyone were teachers there would be no food system, if everyone were farmers there would be no one to build or run the equipment — so the test erases exactly the domain of permissible vocational choice it was never meant to govern. (6) The obvious repair is to universalize under the finer description that includes the circumstances distinguishing my case: a society with room for only some academic philosophers, my aptitude, the existing demand, and so on. But under that description the test seems to rule out nothing, because any agent can add circumstances until no one else falls under the same law, laundering special pleading instead of excluding it. The test therefore seems to face a dilemma: overgenerate with a coarse description, or collapse into a merely formal consistency condition with a fine one.

I want to know which step in this argument should be rejected and what rejecting it costs. I would most like to keep the thought behind (1), that making an exception of oneself is a genuine moral and rational defect, and the ordinary verdict that it is permissible to choose an honest profession even when not everyone could choose it; but I do not see how to hold both if the generalization test is the only way to give (1) content. Is the right diagnosis that the test equivocates between universalizing a maxim and universalizing the social consequences of an act, that it mishandles the difference between a world in which everyone does one thing and a world in which the same principle is differently instantiated by different people, or that one of (1) through (3) must simply be given up? And if a fine-grained description saves the test, can Hare's universalizability still exclude anything, or only the kind of blatant self-exemption that no one seriously defends?
