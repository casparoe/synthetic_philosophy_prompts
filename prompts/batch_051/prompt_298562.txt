A friend in my game-theory course showed me this and I can't shake it. Take a program-equilibrium setup: instead of choosing an action, each player submits a program (guaranteed to halt) that will choose their action for them, and each program gets to inspect the other program's source code before deciding; programs can also refer to their own source. Use a one-shot Prisoner's Dilemma with payoffs 5 (temptation), 3 (mutual cooperation), 1 (mutual defection), 0 (sucker). Let P be the program that cooperates iff the other player's source code is exactly P, and defects otherwise. Now:

(1) If both players submit P, each sees the other's source is P, so both cooperate, for 3 each.
(2) If I unilaterally submit anything else, the other player, still running P, sees my source isn't P and defects, so I get at most 1.
(3) Since 3 > 1, neither of us can profitably deviate, so (P, P) is a Nash equilibrium.
(4) Nash equilibrium is the standard game-theoretic account of what rational players will do.
(5) So two rational players in a one-shot Prisoner's Dilemma will cooperate.
(6) And the same trick seems to prop up nearly any outcome both players prefer to some fallback as an equilibrium, which makes equilibria look too cheap.

I want to keep the idea that game theory isn't just broken, but I can't find the step to give up. Which premise or step goes wrong, why did it look right, and what does giving it up commit us to?
