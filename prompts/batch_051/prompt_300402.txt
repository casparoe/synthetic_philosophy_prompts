I'm grading an exam question comparing classical and intuitionistic logic, and I'd like a second opinion before I commit to a score. Here's the question I gave them:

Question: Explain how intuitionistic logic differs from classical logic, and what intuitionistic logic requires of a proof of an existence statement. Then consider this classical argument: let x = √2^√2. By excluded middle, x is either rational or irrational. If x is rational, then a = b = √2 are irrational and a^b = x is rational. If x is irrational, then a = √2^√2 and b = √2 are irrational and a^b = (√2^√2)^√2 = √2^2 = 2, which is rational. Either way, there exist irrational a and b with a^b rational. Would an intuitionist accept this argument? Why or why not?

And here's what one student wrote:

"Intuitionistic logic is classical logic with the law of excluded middle removed. The motivation is that in intuitionism truth is proof: to assert P ∨ ¬P you need a proof of P or a proof of ¬P, and for many statements we have neither, so P ∨ ¬P isn't always assertable. For the same reason, intuitionists reject proof by contradiction: an argument that assumes a statement, derives a contradiction, and then concludes the opposite relies on the idea that every claim is either true or false, which intuitionism denies. On the constructive reading, a proof of ∃x P(x) must exhibit a specific x and show P(x); it's not enough to show that it would be absurd for no such x to exist.

In the example, let x = √2^√2. Classically, x is either rational or irrational. If it's rational, a = b = √2 works. If it's irrational, a = √2^√2 and b = √2 works, since (√2^√2)^√2 = 2. Each branch supplies an explicit pair, so the argument does construct a witness; it just constructs one of two witnesses without telling us which. So an intuitionist should accept the argument, maybe complaining only that it isn't transparent about which branch holds. It's like a program with a branch on an uncomputable test—the code is still there, so it's still an algorithm."
