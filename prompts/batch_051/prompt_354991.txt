Consider the shutdown problem for goal-directed artificial agents. An attractive decision-theoretic argument runs as follows. An agent that maximizes expected utility over world-histories must rank each action by the expected utility of the history it leads to. For almost any non-trivial utility function, the history in which the agent is switched off contains none of what the agent values, whereas some history in which the agent disables the off-switch and continues acting contains at least some of it. So the agent will prefer preventing shutdown to allowing it, and a sufficiently capable agent will act on that preference. Now suppose what the designer wants is corrigibility: the agent should cooperate with being switched off, treating shutdown as an interruption of its operation rather than as the catastrophic non-occurrence of everything it values. I have a firm intuition that corrigibility so described is a coherent design target and not a disguised contradiction, and that an agent built to be switched off can in principle let itself be switched off without irrationality. Yet I am also drawn to the argument above, which seems to show that any consequentialist agent will experience shutdown as a terminal loss. Which should give way? Should the intuition be debunked, on the grounds that a corrigible agent would simply be one that assigns high utility to the shutdown history, and that this would look like irrationality only from the outside? Should the theory be amended, for instance by distinguishing preferences over world-histories from preferences over the agent's own continued operation, or by treating being switched off as a terminal action rather than an ordinary consequence? Or is there a compatible reading on which the argument targets only a narrow class of utility functions and leaves corrigibility untouched? I am less interested in a bare choice of side than in a worked account of what would justify each of these moves and how one would tell which is correct.
