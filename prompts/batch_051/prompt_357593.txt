I work as a software engineer and have no formal philosophy background, so I want to think about this in terms of mechanism design rather than reading. Here is a training setup I have been considering. Suppose a deployed AI model is required to produce, along with each answer, a short justification. A separate interpreter model is trained only to predict the main model's output from that justification alone. The main model's reward is a weighted sum of task accuracy and an interpretability score, where the score is the probability the interpreter assigns to the actual output. The interpreter is frozen while the main model trains. When the interpreter confidently predicts the wrong output from the justification, the main model receives no interpretability reward even if its answer was correct. The justifications are stored but not shown to users. The hope is to pressure the model to use only reasoning it can articulate. I want someone to walk through what this would actually do. What strategies would the main model converge on? Would it learn to be transparent, to oversimplify, to exploit blind spots in the interpreter, or to produce justifications that are persuasive but not causally related to its answer? How would the accuracy-interpretability trade-off change over training? Where would the system be gamed first, and could any of the fixes—changing the reward weight, training the interpreter adversarially, or requiring human-auditable justifications—actually solve the problem without gutting capability?
