A student was given the following question on an exam in formal epistemology.

Question. In accuracy-first epistemology, an agent's degrees of belief, or credences, are evaluated by how accurate they are at the actual world. For a two-cell partition {X, not-X}, one standard measure of inaccuracy is the Brier score: at a world where X is true, a credence function c receives inaccuracy (1 - c(X))^2 + (0 - c(not-X))^2. A scoring rule is strictly proper if every probability function expects itself to have strictly lower inaccuracy than any distinct credence function, where the expectation is computed by that probability function itself. Accuracy-first epistemologists argue for Probabilism, the thesis that rational credences obey the probability axioms, by appeal to accuracy dominance: any non-probabilistic credence function is dominated, in the sense that some coherent probability function is less inaccurate in every possible world. Consider the following objection. Propriety and dominance are static constraints. Propriety tells a coherent agent only that, by her own lights, no single rival credence function looks more accurate than her own, and dominance rules out only non-probabilistic credences. Neither one compares credences across time or says how an agent should respond to new evidence. Conditionalization is a dynamic rule, and it cannot be recovered from norms that compare only one credence function with another at a single time. Therefore accuracy-first epistemology either has nothing to say about rational updating, or it must import an evidential norm that is not itself justified by accuracy alone. Reconstruct this objection in your own words. Then explain how an accuracy-first epistemologist would answer it, by arguing that the proper object of evaluation is not a single credence function but an updating plan, evaluated by its expected accuracy from the prior's perspective, and state exactly what this argument establishes about conditionalization. Finally, identify one residual problem for the accuracy-first answer: either that it covertly relies on a non-accuracy norm, or that it merely relocates the problem rather than solving it.

Here is the student's answer.

Student answer. The objection is that accuracy-first arguments are all synchronic. They support Probabilism by showing that non-probabilistic credences are dominated, and they show that a coherent agent is immodest in the sense that she regards her own credence function as uniquely most accurate, but none of this compares credences across times or with evidence. The standard reply is to move from evaluating individual credence functions to evaluating updating plans. Fix a prior p and a partition of possible total evidence. An updating plan assigns a posterior credence function to each cell E of the partition. We evaluate a plan by its expected inaccuracy from p's perspective: for each cell E, take the expected inaccuracy of the posterior assigned to E, where the expectation weights worlds within E by p(·|E), and then average these branch expectations using p(E). Because the scoring rule is strictly proper, the posterior that minimizes expected inaccuracy within branch E, subject to the constraint that it assigns probability one to E, is p(·|E). Hence the best updating plan is conditionalization, and this is delivered entirely by accuracy considerations plus the definition of learning E as certainty in E. This answers the objection: accuracy-first epistemology has a dynamic story, and that story singles out conditionalization. A residual problem is that the argument takes the prior as given and therefore says nothing about which prior an agent should have; it cannot rule out a coherent agent with a wildly evidentially insensitive prior.
