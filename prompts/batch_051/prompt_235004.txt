As best I can tell, the thesis is something like this: for a huge class of systems, even when the rule and the initial condition are dead simple, there is no shortcut. The only way to find the state at step n is to run the system forward n steps. You can't outrun it with a formula, a effective model, or a summary statistic, because the system itself is already the shortest and fastest description of what it does. Science, on this picture, only gets traction in the comparatively rare spots where a shorter description happens to exist.
