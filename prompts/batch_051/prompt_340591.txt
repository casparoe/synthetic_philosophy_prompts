Here's a scheme for a world where human minds run as software (ems) that can be copied, run at different speeds, and terminated, and where a restored backup is usually treated, legally, as the same person. Every em pays a subscription to a termination-insurance pool, say 5% of income. The pool keeps a recent backup of each member, taken whenever they pay their premium. If an em is terminated involuntarily — employer shuts them down, hardware failure, an accident — the pool restores them from the most recent backup and pays a small stipend for a few subjective weeks while they find new work. If an em is terminated as punishment for a crime, no payout. If an em self-terminates, no payout either, so the pool has to classify every termination as involuntary, punishment, or self-termination.

The wrinkle I keep chewing on: the restored em lacks all the memories between the backup and the termination. So an em that deliberately engineers an 'accident' after its last backup comes back as a version of itself that doesn't remember engineering it.
