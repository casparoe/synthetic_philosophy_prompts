Ok so I've been spiraling about this thing called program equilibrium and I need someone to actually untangle it rather than tell me who wins. The idea is that in a one-shot prisoner's dilemma, you shouldn't ask which move is rational; you should ask which decision procedure (or program) is rational, because once both players' programs are on the table, a program can condition on the other program's source. So I can submit a program that cooperates if and only if the other program would cooperate with me under the same rule, and defects otherwise. If we both submit that, mutual cooperation is an equilibrium: if you switch to a program that defects against me, my program sees your source and defects, so you end up worse than if you'd just cooperated. That feels clean and pretty airtight, and it gives a recipe for cooperation with no reputation or repetition. But I also have this rock-solid intution that in the actual one-shot case — two strangers, separate rooms, no source code, no precommitment — defecting is simply the rational move, because my choice can't affect what yours is. The source-code stuff feels like it changes the game instead of answering the original question. I'm not looking for someone to just announce a winner. I want to know what it would cost to drop the intuition, what it would cost to drop the program-equilibrium argument, and whether there's a reading of 'one-shot' or 'affects' where both can be true. oh and could you write the answer in British English?
