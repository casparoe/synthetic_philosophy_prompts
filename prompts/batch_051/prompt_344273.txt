I'm a network engineer, so I naturally think about coordination as a problem about nodes, shared protocol code, packet drops, timeouts, acknowledgements, clock drift, Byzantine faults, and so on. I keep coming across a decision-theory position called evidential cooperation in large worlds. As I understand it: take two agents in separate one-shot prisoner's dilemmas with different partners; each runs, and knows the other runs, the same decision procedure. Then each agent's choosing to cooperate is evidence that the other will also cooperate, because the same procedure given similar reasoning will output the same action. So they cooperate even though there is no causal channel between them and neither can affect the other's payoff, and the claim is that in a "large world" of many anonymous agents this evidential linkage is enough to make cooperation beat defecting in expectation. Restate this position in my vocabulary as faithfully as you can: nodes running identical protocol code and converging on the same behavior without exchanging a packet, correlated failures, shared timers, whatever fits best. Then give me a residue report. Which parts of the position map cleanly onto my world? Which parts did you have to distort to squeeze in? And which parts have no counterpart at all in how I think about networks, or, conversely, which things I'd immediately worry about as an engineer does the position seem to ignore? The thing I actually want to know is this: is evidential cooperation just the observation that two boxes running the same deterministic protocol will take the same action even if they never message each other, or does that translation miss the part that matters, and which part is it?
