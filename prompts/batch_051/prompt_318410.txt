I need a preparation sheet for a talk I'm giving next month. The venue is a workshop on probability and evidence in medicine and the social sciences. The audience will be mostly formal epistemologists and philosophers of science, with two statisticians who work on hierarchical models and propensity scores. The Bayesians in the room think the reference class problem is handled by conditionalizing on total evidence; the propensity theorists think probabilities are properties of chance setups; the statisticians think the philosophical problem is overblown and that the practical fix is better modeling. I am the session's contrarian.

The thesis I am defending is intervention-relative reference class contextualism. Roughly: a singular probability claim about a case is true only relative to a reference class, and the admissible classes are the cells of a partition generated by the explanatory covariates that are stable under the interventions the context treats as live. A class is admissible for a given claim when, first, it is projectible for the target outcome under the causal graph shared by those interventions, and, second, it is the coarsest class that respects every invariance boundary in that graph. The consequence is that there is no "correct reference class" simpliciter; which class it is rational to use changes when the decision context changes which interventions are live. I will open with the classical reference class problem, using Venn's point that the probability assigned to an event varies with the series into which we place it, and then argue that neither total-evidence Bayesianism nor propensity theories give a principled answer to why one partition rather than another is the one that matters for singular belief and action.

My argument sketch, for objections to target, is: (1) single-case probability needs an account of what makes a probability claim evidence about a particular case; (2) the usual candidates either smuggle in a partition as subjective prior input, or treat objective chance as if it automatically resolved which class to use; (3) a relativized semantics with invariance under live interventions satisfies the desiderata of projectibility, non-gerrymandering, and decision-relevance. I know the weakest load-bearing point is the test for when an intervention is "live": I worry that liveness is doing philosophical work while looking like a pragmatics-level notion.
