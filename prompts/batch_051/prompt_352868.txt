Exam question: Explain the relation between possibility and probability. Some people say an event is possible exactly when it has positive probability. Is that right? Use a fair dart thrown at the unit interval [0,1] in your discussion. In particular, can a probability-zero event be genuinely possible? Can a probability-one event fail to be certain? Finish by giving your own positive proposal.

Student answer: Naively, possible iff positive probability looks right. But the dart case shows it isn't. Under the uniform distribution on [0,1], each particular point has probability 0, since there are continuum many points and the distribution doesn't single any of them out. Yet 0.4 is a possible result: nothing in the model rules it out, and if we denied possibility to every point we'd be saying no result is possible even though the dart must land somewhere. So probability 0 doesn't imply impossibility, and "possible" can't mean "has positive probability."

A better fix is to use the support of the distribution: an outcome is possible exactly when it's in the support. The support is just the set of outcomes that get positive probability. But that only restates the original problem: in the uniform dart case the support turns out empty, since every point gets probability 0, which is obviously wrong. So support-based accounts fail too. I conclude that possibility and probability are seperate notions: probability is about degrees of belief or frequencies, possibility is purely modal.

This also tells us what to say about probability one. A probability-one event is certain to happen, because probability one is the maximum and any failure would get probability zero. So the event that the dart doesn't land on 0.4 has probability one and is certain, while landing on 0.4 is possible but has probability zero. There's no contradiction because possibility and probability answer different questions.
