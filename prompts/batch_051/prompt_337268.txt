There's a guy at work who keeps settling our lunch arguments about uploading and AI consciousness with the line "the mind is just software running on the brain; the hardware doesn't matter." He means it literally: run the right program on a silicon machine and it's conscious; run your program and it's you. I code for a living, so the hardware/software split is something I actually think about, and the slogan buggs me because even in real computers "software" is doing a lot of work: a program compiled for x86 wont run on an ARM chip without translation, timing and memory layout can change behavior, and nobody would say the source code and the running binary are the same thing even though both get called "the software."

I don't want one definition. I want a menu. When someone says "the mind is just software running on the brain," what are the distinct precise claims they could be making, from the boring ("brains process information, and you can describe that processing abstractly") to the wild ("any system running the same computation has the same subjective experience")? For each reading, say whether it's a platitude, a substantive but defensible empirical claim, or probably false, and say which one my coworker actually needs for his conclusion that an upload would be you rather than a very good copy. And if the copy-vs-you question is actually a different question than the consciousness question, say that too.

Then, for the substantive readings, tell me what would change your mind: what evidence or argument would push you the other way, and where in this whole disambiguation you're least confident rather than giving me a clean-sounding answer.
