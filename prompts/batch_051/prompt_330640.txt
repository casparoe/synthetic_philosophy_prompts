A book on the philosophy of mathematics I read recently gives roughly the following account of Skolem's paradox. The downward Löwenheim–Skolem theorem says that any first-order theory in a countable language with an infinite model has a countable model. The language of set theory is countable, so if ZFC is consistent it has a countable model. But ZFC proves Cantor's theorem, and so it proves that the set of real numbers is uncountable. The book then offers what it presents as the standard resolution: there is no function inside such a model that enumerates the model's real numbers, even though, from outside, the real numbers of the model can be counted because the model's whole domain is countable. It then takes the further step of saying that the real numbers are therefore countable after all, and that uncountability is an artifact of what a formal system can see — a limitation of first-order description rather than a fact about mathematical objects. From this it concludes that cardinality is a relative notion, that there is no fact of the matter about how many real numbers there are, and that Skolem's paradox should be read as a result about the relativity of mathematical notions. How fair is this account? I would like a sentence-by-sentence audit: which claims a careful logician or model theorist would accept, which are subtly conflated or overstated, what the standard resolution would and would not license, and whether the philosophical conclusion follows once the technical point is stated precisely.
