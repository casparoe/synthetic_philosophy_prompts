Exam question: "Explain how the accuracy-first program in formal epistemology uses inaccuracy measures to argue for probabilism. Your answer should: (i) define an inaccuracy measure and the Brier score; (ii) define propriety and strict propriety, and explain the norm of immodesty; (iii) state Joyce's dominance argument and make clear which premises do what work; and (iv) discuss at least one limitation of the accuracy-first approach."

Student answer: "The guiding idea of accuracy-first epistemology is that credences can be evaluated the way forecasts are: some are closer to the truth than others. An inaccuracy measure assigns each credence function a penalty at each possible world, measuring distance from truth. The standard measure is the Brier score: if proposition X is true at a world, the penalty for credence c(X) is (1 − c(X))²; if X is false, it is c(X)². For multiple propositions one sums or averages these terms, and lower scores are better.

The central result is Joyce's dominance argument for probabilism. Suppose a credence function is incoherent, for instance because it assigns 0.6 to P and 0.5 to ¬P. Then there is some coherent credence function that is at least as accurate at every possible world and strictly more accurate at some world. Since rational agents do not adopt dominated options, incoherent credences are irrational. The attraction of this argument is that it derives the probability axioms from purely truth-directed considerations, with no appeal to betting or prudential reasoning of the kind used in Dutch book arguments.

The framework is also supposed to constrain the specific credences one holds. A scoring rule is proper if a probability function expects itself to be at least as accurate as every alternative, and strictly proper if it expects itself to be strictly more accurate than every distinct alternative. Propriety is what underwrites immodesty: by its own lights, a credence function regards no other credence function as expected to do better, so it has no reason to move. Propriety alone suffices for this. Since the Brier score is proper, a coherent agent's own credence function is always self-recommending in this way.

A limitation is that the choice of scoring rule is not settled by the framework. The Brier score is not mandatory; other strictly proper rules weigh errors differently and can order the same two credence functions oppositely at the same world. Thus any verdict about which credences are most accurate depends on a prior choice of scoring rule. A further limitation is that the whole approach presumes accuracy is the sole fundamental source of epistemic value, which is a substantive commitment rather than a neutral starting point."
