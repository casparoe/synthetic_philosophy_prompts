Let G be the following gamble. A fair coin is tossed until it lands tails for the first time; if the first tails occurs on the nth toss, the payoff is $((-1)^(n-1) · 2^n)/n. The payoffs therefore alternate in sign and grow without bound in magnitude.

Consider this argument that the expected value of G is ln 2.

(1) If a gamble has countably many possible outcomes, with payoffs x₁, x₂, ... and probabilities p₁, p₂, ..., then its expected value is Σ pᵢxᵢ, provided this series converges.
(2) In G, the possible outcomes are indexed by n = 1, 2, 3, ..., with probabilities p_n = 2^(-n) and payoffs x_n = (-1)^(n-1) · 2^n / n.
(3) So the expected value is Σ_{n=1}^∞ 2^(-n) · (-1)^(n-1) · 2^n / n = Σ_{n=1}^∞ (-1)^(n-1) / n.
(4) This series converges by the alternating series test, and its sum is ln 2.
(5) Therefore the expected value of G is ln 2 dollars, about 69 cents.

But there is a familiar worry about this reasoning. The series in (4) converges only conditionally: the series of absolute values is the harmonic series Σ 1/n, which diverges, and a conditionally convergent series can be rearranged to sum to any real number or to diverge. That suggests the sum obtained in (4) depends on the order in which the outcomes were listed in (2), rather than on anything intrinsic to the gamble.

Is the argument (1)–(5) valid? Is each premise true? If a premise fails, identify the first step that does, give the strongest reading of that step on which it is true, and say whether the argument then still yields (5). Does the natural chronological ordering of the outcomes—by the toss on which tails first appears—defeat the rearrangement worry? Give the correct verdict about the expected value of G, and state the principle about summing over countably many outcomes that settles the matter.
