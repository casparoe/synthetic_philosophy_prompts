I'm putting together a lesson on metric design, and I want a decision tree that sorts someone into an account of why Goodhart's law actually happens — the type of failure behind specification gaming. The question the tree should answer: when a metric is optimized and the outcome goes bad, where should the failure be located?

Make the leaves these five positions, restated in your own words:

1. Strategic/incentive: the metric could have been fine as a measurement, but once it became a target, agents (or RL systems) found and exploited the gap between the metric and the real goal.
2. Statistical selection: the metric is a decent correlate of the goal in ordinary conditions, but optimizing it hard selects cases where the correlation breaks, so the failure would occur even with no adversarial agent at all.
3. Causal: the metric is causally downstream of the goal or otherwise tangled with it the wrong way, so pushing on the metric does not push on the goal; the fix is a causal model of which variable actually matters.
4. Specification/semantic: the target itself was never defined precisely enough, so the metric optimized a different concept from the one people thought they had asked for.
5. Recursive/no-fact-of-the-matter: there is no clean split between a true target and a proxy; any operational goal can in principle be gamed, so the problem is not a bad proxy but overconfident optimization against any fixed metric. Call this leaf unnamed if you think nobody actually holds it.

Build the tree from the logical space first. Work out which combinations of yes/no answers are live positions, put the occupied leaves in, and flag any empty cells (combinations the tree allows but no live position occupies) with a one-sentence guess as to why nobody is there — incoherent, unattractive, or just unexplored. Also flag any two leaves the tree cannot really seperate and say why.

Each branch question should be one a person could answer about a concrete case without knowing which leaf it points to. Use at least these cases somewhere in the questions: the boat-racing RL agent that gets a huge score by driving in circles instead of finishing the race; a hospital that hits its ER wait-time target by keeping patients in ambulances just outside the door; a university gaming a ranking by gaming its citation counts; a recommender that maximizes watch time and ends up promoting outrage. Don't include anything like "are you an adversarialist?"

Keep it to five leaves, or four if you think two collapse. Audience is undergrads who have heard of Goodhart's law but have not done the philosophy. Give each leaf a short name and one sentence on its most awkward commitment.

Start directly with the tree itself, no preface or commentary. Write the whole thing in British English. After the tree, add a two- or three-sentence note saying how confident you are in the splits and which one you are least sure about.
