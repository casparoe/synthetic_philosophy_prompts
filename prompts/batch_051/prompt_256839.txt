I coordinate a long-running working group on probabilistic prediction and decision-making. For over a year, the same argument has repeatedly stopped us: when we assign a probability to a single event—say, that this patient will be readmitted within thirty days, or that this applicant will repay a loan—what determines which prior outcomes belong in the reference class for that individual? One faction holds that only objective frequencies in the broadest available class matter; another holds that the only coherent interpretation is a personal degree of belief, with the reference class chosen as a convenience; a third holds that there is a fully specific objective probability for each case but that it is unknowably fine-grained, so every usable number is a pragmatic approximation. The strange thing is that we agree on the actuarial tables and the formal mathematics, yet the dispute does not move, and I suspect we are disagreeing about something other than probability theory. Diagnose what kind of disagreement this actually is. Is it a hidden metaphysical dispute about whether single-case probabilities exist, a disagreement about what the statement is for—prediction, decision, explanation, blame—or an ill-posed question under one name? And given your diagnosis, what would count as genuine progress: a distinction, a formal result, a change in practice, or should we expect a permanent impasse?
