I have been going back and forth with a friend about what it means to say that a single event has a probability, and he has constructed an argument that seems to show that frequentism either collapses into a denial of non-trivial chance or cannot say what we ordinarily want it to say. He reasons as follows. (1) According to frequentism, the probability of a single event is the limiting relative frequency with which events of that kind occur in a suitable reference class of trials. (2) But a single event never comes with a unique reference class: the rain in Glasgow tomorrow can be described as rain in Glasgow on a Tuesday in June, rain at a particular grid square under a particular weather pattern, rain of at least two millimetres in an hour, and so on, and the long-run frequencies across these classes often diverge. (3) So the frequentist can assign the single event a determinate probability only if one of these descriptions is somehow privileged, yet nothing in the event itself selects one description over the others. (4) Worse, if we refine the description far enough, the reference class contains only the event itself, and the frequency for that singleton class is just 1 if the event occurs and 0 if it does not. (5) Therefore frequentism either refuses to assign probabilities to single events at all, or assigns them only 1 and 0 after the fact; and he adds that subjectivism and propensity accounts each face their own version of the problem, since each must explain what fixes the correct way to describe the event before it can assign a probability to it.

I cannot find the step to reject, because each step seems to follow from the one before, but the conclusion that no single event gets a non-trivial probability seems to prove too much: we put odds on tomorrow's rain, on a patient's recovery, and on a coin before we toss it, and those odds guide action and improve prediction. Which step should I reject or qualify, and what does rejecting it cost? Please answer as exactly five numbered points, each a sentence or two, with no introduction or conclusion.
