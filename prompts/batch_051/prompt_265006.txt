For an AI safety reading group I'm trying to work out whether 'avoid side effects' can be made precise without already having a full account of human value. Please write me a working definition of 'side effect'. It should get the obvious cases right: a Roomba shifting a rug while it cleans is clearly one, and an optimiser converting all reachable matter into paperclips is its goal rather than a side effect. Then run it against these: a chess engine using more memory during search than expected; a delivery drone detouring around a pedestrian and draining a bit of extra battery; a robot that knocks a vase off a table so it can reach a ball; a language model that changes a user's beliefs by answering a question; and an assistive robot that moves a chair, does its task, then puts the chair back exactly where it was. I'd like the definition to be one an engineer could apply without a full specification of human value, or, if you think that's impossible, say why not. Propose the definition, test it on all the cases, and revise it or defend any surprising verdicts where it misfires. Please start with the definition itself in the first sentence, then give the reasoning, with no preamble or restating of the question, and write in British English.
