The article's gloss goes roughly like this: Good proved that a rational person should never turn down free information, because information can't make a rational agent worse off. If you don't like what you learn, the thought goes, you can always ignore it and do what you would have done anyway; so the expected value of any free signal—a medical test, a leaked document, even gossip—is never negative, and a rational agent should always prefer to look. So an ideal agent would be insatiably curious, and there's no coherent way to rationally dread a result as long as the information itself is free.

I can't shake the feeling this flattens something. I vaguely remember the result is specifically about expected value before you see the information, and that you can be worse off after finding out in particular cases.
