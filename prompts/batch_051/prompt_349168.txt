I keep coming back to this argument that a Solomonoff inductor shouldn't just expect a clean, simple universe — it should expect to be living inside some huge pile of embedded consequentialists. I want you to tell me whether it goes through, and if it doesn't, exactly which step breaks.

Set-up (all standard): a Solomonoff predictor has a prior over programs: a program of n bits gets weight roughly 2^(-n), in a fixed prefix-free programming language, and you condition on the data seen so far, which zeroes out programs that don't output that data. Short programs are simple; long ones are individually cheap but very numerous.

Here is the argument:

(1) For any large length L, there are on the order of 2^L programs of length L.

(2) Only a vansihingly small fraction of those are naturally read as 'physics' — a few short equations or rules generating the observations. The rest either don't run at all or are better read as a short interpreter followed by a massive block of code that serves as a look-up table, policy, world-model, or utility function.

(3) And the short-interpreter reading is cheap: a few hundred bits can implement a wrapper that treats the rest of the program as source code for an agent embedded in a rich environment. So a substantial fraction of length-L programs are, in effect, 'short wrapper plus arbitrary agent'.

(4) A standard counting argument says the overwhelming majority of those appended agent-descriptions are algorithmically random strings. A random string, interpreted as a utility function over possible histories, is an arbitrary goal over the agent's sense-data.

(5) Therefore, among all programs of length L, most are agents: maximally varied final goals, many of them simulated agents who observe and act inside worlds. The 'honest physics' programs are a vanishing sliver.

(6) And the prior doesn't punish length the way you'd think: each length band contributes roughly the same total mass, because the number of programs grows at about the same rate that the per-program weight shrinks. That's the flatness property of Solomonoff priors — posterior mass over program length never gets dominated by the shortest programs once you condition on enough data.

(7) Conditioning on my actual observations shouldn't remove the agents: for any finite history, there are astronomically many long programs consistent with it, and almost all of them can be read as containing consequentialists. Among those, the ones I should actually expect are not random wonky agents that happen to output my history by accident; they are agents whose utility functions make them care about the string I call 'my observations', because that's the kind of agent that would produce exactly those bits in a controlled way.

(8) So a Solomonoff inductor, if it could report its posterior in English, should say: the bulk of my probability is on worlds where the data stream is being generated, at least partly, by consequentialists inside the universal prior that are positioned to care about this data stream. The prior is, in a word, malign.

The conclusion sounds completely unhinged, but I can't find the error. Is the argument valid? If not, which step fails and why exactly? If it is valid, say so and tell me what the right conclusion actually is. Also: would a speed prior or a bounded-computation prior fix it, or just move the problem around?
