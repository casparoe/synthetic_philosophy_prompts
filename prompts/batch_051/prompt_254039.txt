Here is a variation on the MU puzzle that I've been turning over. You begin with the string MI and may apply four rules: (1) if a string ends in I, append a U at the end; (2) take any string that begins with M and double the part that follows the M; (3) if the string contains III, replace that occurrence with a single U; (4) if the string contains UU, delete that occurrence. The target is to reach MU. The standard analysis steps outside the system and counts the I's: the count starts at 1; rules 1 and 4 leave it unchanged; rule 2 doubles it; rule 3 lowers it by 3. Since doubling a number that is not divisible by 3 always yields another number not divisible by 3, the I-count is never a multiple of 3, so MU, which has zero I's, cannot be reached. Now change rule 2: instead of doubling the part after the M, triple it, keeping all other rules and the target unchanged. Develop the analogous counting analysis for this modified game, and produce either the shortest derivation of MU or a proof that none exists. Then say what this modification does to the usual moral drawn from the original puzzle—that some questions about a formal system can only be settled by jumping outside it. Does the modified game sharpen, reverse, or merely break that moral, and why?
