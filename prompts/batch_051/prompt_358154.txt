I've been trying to get clear on a distinction that keeps showing up in AI alignment discussions, between approval-directed agents and goal-directed agents. As I understand it, an approval-directed agent is trained to select the action that a human would most approve of—roughly, to produce the output with the highest predicted approval rating—while a goal-directed agent selects actions because it represents them as ways of bringing about some further outcome, the way a planner with a utility function over world states does. The distinction matters because people seem to draw different safety conclusions from it: approval-directed systems are supposed to fail by flattering or gaming the approver, whereas goal-directed systems are supposed to fail by optimizing a target we didn't intend. A colleague insists the distinction is empty, and he laid out the argument below so I could tell him exactly where it goes wrong.

(1) If a system reliably selects the action with the highest expected value of some real-valued objective, then it is a goal-directed agent.
(2) An approval-directed agent is trained precisely to reliably select the action with the highest expected approval score.
(3) An approval score is a real-valued objective: it maps each action-in-context to a number.
(4) So an approval-directed agent reliably selects the action with the highest expected value of a real-valued objective.
(5) Therefore, by (1), an approval-directed agent is a goal-directed agent.
(6) So the distinction between the two is only a distinction between which objective gets maximized, not between two kinds of agent.

I half-suspect that the move from being representable as maximizing an objective to actually being goal-directed is where the trick lives, but I can't state the diagnosis cleanly. Is this argument valid? If it is, is it proving something too thin to matter? If not, which step fails, and what is the most defensible version of the conclusion that survives?
