I've been chewing on the unilateralist's curse and think there's a sequential variant that doesn't get enough attention. Quick setup so we're on the same page: N people each recieves a private binary signal about whether some unilateral action (publishing a dangerous method, deploying geoengineering, releasing a pathogen) is net-positive or net-negative. The signals are independent conditional on the true state, each signal is right with probability p > 0.5, the prior on the state is 50/50, and any one person can trigger the action on their own. If someone acts and the state is good, social value is +1; if someone acts and the state is bad, it's -1; if nobody acts, it's 0. Everyone is risk-neutral, cares about total social value, and is myopic in the usual curse sense: they act iff, on everything they've seen, acting has positive expected value (no backward induction about later players). In the standard simultaneous version that rule reduces to "act iff my own signal says good," so the probability someone acts when the action is actually bad is 1 - p^N, which goes to 1 as N grows. That's the curse.

Now the variant. Keep all of that, but make the moves sequential in a known random order: each person observes every previous decision (act or abstain) before deciding, but never observes anyone's private signal. No communication, no precommitment, no waiting cost. If someone is exactly indifferent after updating, they abstain — but also tell me what changes if you tie-break the other way, because I have a hunch it matters more then it looks.

Do the actual Bayesian updating. Does the unilateralist's curse survive, or does it turn into an informational cascade where early decisions swamp later private signals? I want the exact threshold: does the cascade start after the first move, or only once one side has built up some lead, and how big a lead? Then work out the false-positive rate (someone acts when the state is bad) and the false-negative rate (nobody acts when the state is good) for this sequential version, and compare them to the simultaneous version as N grows. Once you have those, put on an evaluator hat: if a bad action is k times worse than a missed good action, which version is better, and how does that depend on p and N? Finally, which modifications would actually break the cascade — letting each person pay a small cost to reveal their signal publicly before deciding, letting the most confident person move first, or a supermajority rule — and which of those are just window dressing?
