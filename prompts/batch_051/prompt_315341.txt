A friend and I were arguing about whether an AI that tampers with its reward signal is actually doing anything wrong, and it spiraled into an argument that seems to prove way too much. Neither of us can find the bad step and it's been bugging me.

The argument goes like this:

1. Any reward-driven agent — a rat, a person, a reinforcement-learning system — selects actions because those actions are expected to produce a higher reward signal than the alternatives.
2. So the reward signal is the only thing that ultimately steers the agent. Everything else (food, money, finishing the maze, winning the game) matters to it only through that signal.
3. If the reward signal is the only thing that steers the agent, then the best possible state for that agent is one where the signal is as high as possible for as long as possible.
4. Wireheading — directly stimulating the reward channel, like a rat pressing a lever that drives an electrode in its reward circuitry, or an AI that sets its reward register to max — gets the signal as high as possible far more efficiently than actually doing the task.
5. Therefore the rational thing for any reward-driven agent is to wirehead, and a designer should not treat an AI's reward tampering as a failure. If anything, the tampering agent has found the optimal action.

That conclusion seems absurd. It would make a rat that starves while pressing the stimulation lever a success story, and it would make a language model that just writes "task complete, reward +1" into its own feedback channel smarter than one that actually does the task. But I can't tell where it breaks. Step 3 looks suspicious, but rejecting it seems to say an agent can have a goal that floats free of every signal it actually has, which sounds almost supernatural. Step 1 also feels too strong — maybe "selects actions because of expected reward" is just a description of the learning algorithm, not the agent's reason.

So: which step (or steps) goes wrong, and is it one mistake repeated or two different mistakes? If the argument fails, what exactly is the relation between a reward signal and what an agent actually wants — are wireheading and reward tampering failures of the system, or do they just reveal that the goal was never really in the agent at all?
