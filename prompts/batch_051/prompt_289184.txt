A colleague has offered the following argument to show that any rational agent is already logically omniscient with respect to classical propositional logic. I find the conclusion absurd but cannot locate the exact error.

(1) Closure: if a rational agent knows every premise of a valid argument, then the agent knows the argument's conclusion.
(2) Let Q be any theorem of classical propositional logic, understood as any sentence derivable in a standard natural-deduction system from the empty set of assumptions.
(3) For any such Q there is a valid argument whose set of premises is empty and whose conclusion is Q.
(4) A rational agent trivially knows every premise of that argument, because there are no premises to know.
(5) Therefore, by (1), the agent knows Q.
(6) Since Q was arbitrary, a rational agent knows every theorem of classical propositional logic; that is, the agent is logically omniscient over propositional logic.

I suspect the problem lies in (1) or (4) — presumably closure needs the agent to be aware of the inference, not merely for the inference to be valid — but I cannot articulate this without weakening (1) to the point of triviality. Is the argument valid? If not, which step fails, and why? Give the strongest reading of (1) on which the argument is valid, and the strongest reading on which it is not, and say which reading better captures what rational agents are actually required to do. Keep your answer to at most 350 words.
