An argument I read claims to show that countability is not an absolute property of sets, or even that set theory lands in trouble. It runs:

(1) Assume ZFC has a model. By the downward Löwenheim–Skolem theorem, ZFC then has a countable model M, i.e., a model whose domain can be paired one-to-one with the natural numbers from the outside.
(2) Inside M, the usual construction of the reals (as, say, the powerset of the natural numbers) goes through, and Cantor's theorem holds. So M contains an object R that M regards as the set of reals, and M satisfies 'there is no function pairing R one-to-one with the natural numbers.'
(3) Therefore there is no function pairing R one-to-one with the natural numbers: R is uncountable.
(4) But R is a subset of M's domain, which by (1) is countable from the outside; and R is infinite, since M proves it is. So from the outside there is a function pairing R one-to-one with the natural numbers: R is countable.
(5) Contradiction: the same set R is both uncountable and countable. Hence countability is not a genuine, frame-independent property of sets, or ZFC is inconsistent.

I find each step plausible, but I half-suspect the argument moves too quickly somewhere. Is the argument valid? If not, which step or steps fail, and what is the strongest correct conclusion the argument supports? Lead with your bottom line in the first sentence, then give the reasoning, with no preamble and no restating of the question.
