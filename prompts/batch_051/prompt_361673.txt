I keep going back and forth on whether the reference class problem still hits. The classic version says frequentism can't handle single-case probabilities because the probability changes depending on whether you sort me into people with this diagnosis, people with this diagnosis at this age, people with this diagnosis at this age in this zip code, etc., and nothing in the data picks the right level of granularity. But now models do the sorting automatically, into thousands of micro-classes, and institutions act on those scores, with an appeals process if you think you got binned wrong. Does the old problem actually bite here, or does it just get relocated into questions about training data, loss functions, and fairness constraints? If it survives, what should the updated argument be; if not, say exactly which premise the algorithmic set up destroys.
