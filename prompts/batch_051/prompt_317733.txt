Gaunilo's perfect island is usually brushed off because an island can always be improved — another palm tree, calmer water — so 'greatest island' is incoherent in a way 'greatest being' supposedly isn't. Now change the case: suppose an island's greatness is defined by a fixed checklist of ten yes/no features (fresh water, deep harbor, mild climate, and so on), so a ten-out-of-ten island is a genuine maximum and a nine-out-of-ten island is strictly less great. Run Anselm-style reasoning on that ten-out-of-ten island: if it existed only in thought, a version of it that also existed in reality would be greater, so the greatest possible island must exist in reality. Does the parody now actually go through, or is there still a difference between the island and the God case that blocks it? Spell out what the difference would have to be.
