I have been reading in the foundations of decision theory and keep noticing a recurring style of argument that I do not know how to name precisely. The pattern is this: someone defends expected utility theory, or the axioms behind it, by showing that an agent whose preferences violate the axioms can be induced to accept a collection of transactions, each of which looks rational or at least permissible on its own, even though the transactions jointly guarantee that the agent ends up worse off no matter how things turn out. Sometimes the case is set up as a package of bets the agent finds acceptable one by one and would therefore accept together, yet loses under every possible outcome. Other times the case is a sequence of trades over time: at each step the trade seems attractive, but by the end the agent has returned to the original position minus a loss. I want to know whether this style of argument has an established name, but a bare label will not satisfy me. I want to understand what the argument is really meant to establish about rationality and coherence, whether the package version and the sequence version are ultimately the same argument or importantly different, and how the argument relates to the broader project of justifying expected utility maximization through requirements of coherence on preferences. If there is no standard name for exactly this thing, please say so and propose one with a precise definition and clear boundaries. Answer in continuous prose only, as one would write a letter; no headings, bullet points, bold text, or tables.
