I run a reading group whose members span ML engineers, product researchers, and a few philosophers, and I want to open our next session with a sorting quiz rather than a talk. The underlying question is: what kind of thing is a large language model—an agent, a simulator, a tool, or something less? The difficulty is that participants arrive already attached to labels (agent, simulator, stochastic parrot, tool) and interpret those labels differently, so the labels do almost none of the sorting work. I want an instrument that sorts people by what they actually say about concrete cases, not by which term they find congenial.

Write a "which view of LLMs do you actually hold?" quiz with eight to ten questions. Each question should present a concrete system or behavior—say, a base model prompted to write in the voice of a character plotting an escape; a fine-tuned assistant that refuses a request and offers a rationale; a model running inside a scaffold with a memory buffer, tool access, and a long-horizon objective; a model trained end-to-end to control a robot arm; a model whose probes appear to track whether its next claim is true; a model that produces a stable persona on one prompt and a wholly different one on another—and offer two to four answer options expressing a small behavioral or evaluative judgment (for example, "there is a real goal here," "the goal belongs to the character," "there is only a prediction of what goal-bearing text sounds like"). The quiz must sort respondents into at least five positions: a strong-agent view on which an LLM literally has beliefs, goals, or preferences of its own; a simulator view on which the model is not itself the agent but can instantiate simulated agents whose apparent goals remain inside the simulation; a scaffolded-agent view on which the bare model is not an agent but becomes one only when embedded in a loop with memory, tools, and an objective; a tool or instrument view on which agency resides entirely in the user or developer and the model is closer to a calculator; and a deflationary or emulative view on which the model merely reproduces surface patterns and all agent-talk is metaphor or category mistake. You may split or rename any of these if your diagnostic questions force it, but explain the change.

I want the instrument built from the logical space rather than from a list of names. First identify two or three dimensions along which the positions genuinely come apart—candidate dimensions include whether the model has its own goal-directedness or merely represents it, whether its outputs are about the world in the right way, whether it can enter or leave the agent category depending on its embedding, and whether there is any fact of the matter about what the model itself wants. Then phrase every question so a person can answer it without already knowing any named position or technical term, loading each question primarily on one dimension. Supply a scoring key that maps answer patterns onto the positions. Flag every pair of positions your instrument cannot genuinely separate, and for any combinations of answers that no coherent position occupies, diagnose each as incoherent, merely unattractive, or simply unexplored.
