(1) After you receive new evidence, you always still have the strategy of ignoring it and doing whatever you would have done anyway. (2) So costless evidence can only enlarge your set of available strategies. (3) Enlarging a set of strategies can't lower the maximum expected utility, since the best old strategy is still there. (4) So costless evidence can never make a rational person worse off in expectation; I think this is Good's theorem about the value of information. (5) Now suppose you're offered a free, perfectly reliable genetic test for an untreatable disease, and no decision of yours would be effected either way. Good's theorem seems to say you shouldn't prefer to avoid the test. (6) But avoiding it seems perfectly rational, because the knowledge itself would make you miserable. Which step goes wrong, and why?
