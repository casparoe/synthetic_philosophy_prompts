The thing I keep chewing on is iterated amplification and distillation: start with a weak but aligned model, amplify it by letting it break a hard problem into subproblems and call itself on each one, then distill that slow amplified process back down into one fast model, and repeat. The claim is that this preserves alignment and competence as long as the base model is aligned and every decomposition is "faithful." As a chemist, I find it darkly funny that a word I used to use for seperating mixtures now has to carry an argument about where a goal survives.
