Ray Solomonoff's original theory of algorithmic probability is often presented as a formal resolution of the problem of induction: instead of choosing a subjective prior, one assigns each computable hypothesis h a prior proportional to 2 raised to the power of minus its Kolmogorov complexity, so that simpler hypotheses are automatically favored. But the Kolmogorov complexity of h is defined only relative to a fixed universal Turing machine, and different universal machines produce different complexity values up to an additive constant. Doesn't this simply relocate the arbitrary element that Bayesian epistemologists tried to eliminate? If one can change the universal machine and thereby multiply any hypothesis's prior by a constant, and if every finite data set is consistent with infinitely many computable hypotheses, then for any finite amount of evidence some choice of universal machine should be able to make almost any hypothesis look simple. Why, then, is Solomonoff induction considered a vindication of Occam's razor rather than a demonstration that the "right" simplicity ordering is still underdetermined?
