I keep going back and forth on this and want someone to actually redo the argument rather than tell me it's just a matter of degree. The old line on finite sequences and randomness — the von Mises/Kolmogorov line, roughly — is that a finite string can't be intrinsically random: limiting relative frequencies only make sense for infinite sequences, and a finite string can always be made to look compressible by choosing the right description language, so "random" isn't a property of the string itself. At best a finite string is random-like relative to the tests you happen to run. Then the world moved on. Today almost nothing that needs randomness uses anything like an infinite sequence or a genuinely stochastic source; it uses a finite pseudorandom string, and the guarantee is not "no description language can compress it" but "no computationally bounded observer can tell it apart from uniform." Does the old argument survive this shift? If you take the computational pseudorandomness picture on board, are finite sequences still "not really random," with "random" now meaning "random relative to bounded observers"? Or does a premise of the old argument — that randomness has to be absolute, or that only infinite sequences can be random — get abandoned rather than repaired? And if the old argument can be repaired, is the repaired version actually doing any work, or has it just changed the subject to feasibility?
