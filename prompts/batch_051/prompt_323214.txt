ok so I need a philosopher of mind who actually works on functionalism and multiple realizability to think this through carefully with me — please start by brainstorming the possible moves before you commit, and then give me a definite verdict, not a menu.

Take the Chinese-nation thought experiment: the whole population of China is wired up with two-way radios so that, for one hour, the country instantiates the same functional organization as your brain. The standard anti-functionalist reaction is that the system would act like you but obviously have no qualia (no headache, no taste of coffee), so functionalism is too liberal about what gets a mind. Now vary it. Suppose we leave all the original wiring in place and add a second, parallel radio network connecting the same billion people. This second network also instantiates a functional organization that is behaviorally equivalent to you over the same hour, but it assigns each person a different role than the first network does, and it would diverge from the first network only if a certain unusual input occurred — an input that never actually arrives during the hour. So there's one physical system and two distinct functional descriptions of it, both adequate for the hour, both in some sense claiming to be 'you.'

I keep going back and forth on wether this is supposed to make things easier or harder for the functionalist. So: what is a functionalist actually committed to saying here — one mind, two minds, no minds, or that the question has no determinate answer? And does adding the second network change the force of the original 'no qualia' intuition: does it make that objection stronger, weaker, or leave it untouched? I don't want a survey of positions. Take a definite stand on what the best version of functionalism says, and be explicit about which part of functionalism (or of the original anti-functionalist intuition) has to give if your answer is right.
