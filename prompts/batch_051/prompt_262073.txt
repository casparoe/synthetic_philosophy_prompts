A friend in a semantics class sent me this argument she built as a joke, and now neither of us can find the wrong turn. She says that once you take ordinary polysemy seriously, you have to conclude that words have no semantic range at all—either a word has one fixed core meaning or it means anything. That sounds crazy, but I can't locate the slide.

Here's the argument as she numbered it:

(1) A word's meaning is whatever constrains its correct use. If nothing constrains correct use, the word has no meaning at all.
(2) Take an ordinary polysemous word like bank. Some uses pick out financial institutions (a savings bank), some pick out bits of terrain (the river bank), some pick out repositories (a blood bank, a sperm bank), some pick out stored collections (a data bank, a memory bank).
(3) There is no single condition all these uses satisfy. A river bank and a savings bank share nothing but the spelling; a blood bank and a data bank share something like storage, but a river bank and a blood bank don't.
(4) So what holds the different uses of bank together isn't a core meaning but similarity to prior uses.
(5) But similarity has to be constrained to do any work. If any respect of similarity is enough, then any word can be extended to any new case, since for any two things there is some respect in which they're similar.
(6) If instead you constrain the similarity by specifying which respects count, you've brought back a core: a set of features that every legitimate extension must share.
(7) So the middle view is unstable. The similarity story either collapses into the fixed-core view or becomes a free-for-all.
(8) Polysemy like bank shows the fixed-core view is false.
(9) So the free-for-all is the only coherent option: bank can correctly mean anything, and calling a use 'incorrect' is just enforcing a local habit, not tracking a real boundary.

She says (9) is obviously false, so the argument is a reductio of some other step, but she can't figure out which. I'd like to keep the ordinary view that bank has a bounded but stretchy semantic range. Which step would you reject, why does it look so natural, and what do you have to give up to reject it? Also, please write the answer in American English.
