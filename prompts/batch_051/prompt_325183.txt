Okay here's one I keep getting stuck on, and I'd rather crowdsource than keep going in circles. Mechanistic anomaly detection: what counts as the same mechanism? The project I'm imagining wants to flag when a model is doing a task by a different internal mechanism than the one you validated it had — after fine tuning, after a prompt injection, after distribution shift, whatever. But "anomaly" is only defined relative to some baseline mechanism, and nobody seems to agree on how to individuate mechanisms. The candidates I already have on my list: (1) same circuit — literally the same attention heads/MLP neurons and connections carrying the task, so an anomaly is any case where a different circuit is doing the work; (2) same intervention profile — interventions on the same components produce the same downstream effects, so the mechanism is whatever your causal prods reveal; (3) same abstract computation — same input-output function even when different components implement it; (4) same intermediate features — the same human-readable features show up in the activations at the same stages; (5) same failure signature — the mechanism is individuated by where it breaks, i.e., the same adverserial examples and edge-case errors. I want five more candidate criteria for "same mechanism" that are genuinely different from these — not rewordings, not special cases, not combinations — and for each one, a sentence on what it captures that the list above misses. Give me exactly five numbered items, each a sentence or two, no introduction or conclusion.
