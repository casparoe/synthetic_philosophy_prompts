I've been kicking around an idea I call "compiled values," and I want someone to tell me if its actually a thing or if I'm just reinventing something dumber than I think.

The analogy is from software: when you compile a program, the original source gets turned into machine code and the source can get lost; the binary runs anyway, and you can't easily tell why it does what it does. I think some values work like that. A value starts out instrumental — you hold it because it gets you something else. Then at some point it gets "compiled": the original payoff drops out, and the value gets treated as an end in itself. The reasons are gone, like debug symbols stripped out of a shipped binary, but the behavior is still there and people defend it as if it were obviously worth having for its own sake.

The core claim is that the values that feel most intrinsic are exactly the ones with the longest instrumental histories — because the longer the chain, the easier it is to lose the source and promote some intermediate step to a terminal value. My three examples are truth-seeking, tradition, and purity.

Truth-seeking: originally you want true beliefs because they let you predict and act. Then it compiles into "truth is worth having for its own sake," even when the truth is useless or painful. Tradition: originally you repeat what worked in the past; then it compiles into "we do it because it's ours / because it's what we do," and the cost-benefit check just stops running. Purity: originally about avoiding actual contamination; then it compiles into "impure is wrong, period," detached from any health risk.

What I want to know: Is this coherent as a distinction, or is "terminal vs instrumental value" itself too mushy to build on? Is there already a name for this — I assume there is — and what does the existing version get right that mine gets wrong? Where does the theory actually break? For instance, maybe the fact that truth-seeking sticks around when it's useless is exactly what makes it intrinsic, not evidence that it was compiled. What's the strongest example of a value that doesn't fit either because it seems intrinsic from the start or because it stayed transparently instrumental forever? And is there any way to tell the difference between a compiled value and a genuinely intrinsic one from the inside, or does the analogy just re-describe the problem?
