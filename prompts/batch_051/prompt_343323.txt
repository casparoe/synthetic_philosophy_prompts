I started keeping a dream log in september and it's messed with my head a little. After a few months I noticed my dreams are basically recombinations of the same thirty or forty ingredients — same buildings, same people, same specific panic. So now I keep chewing on this: if a mind is finite, is the set of experiences it can have also finite? And if so, wouldn't a long enough life have a genuine last new experience — after which everything is a rerun?

The reason I cant let it go is that this feels like the exact same argument as a finite state machine. An FSM has finitely many states, so any long enough run has to revisit a total state; once you've seen all the states there's nothing new. The exhaustibility argument for minds seems to run: finitely many neurons (or finitely many possible activation patterns, to be generous) -> finitely many possible experiences -> pigeonhole principle -> eventually you're just cycling. Structurally it's the same move: finite configuration space plus enough time equals repetition.

Am I actually seeing the same argument twice, or is this just pattern-matching? What would have to be true of mental states for the FSM result to genuinely apply — do experiences have to be discrete, does 'same experience' have to be well defined, does the mind have to be closed in the relevant way? If the parallel is real, does other stuff from automata theory transfer, like attractors or strongly connected components telling us something about what a maxed-out mind looks like? Or does the analogy predict something false about experience — and if so, where does it break down?
