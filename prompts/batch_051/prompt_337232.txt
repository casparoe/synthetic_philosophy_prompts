Ok so I've been messing around with typogenetics for a couple weeks now — the toy formal system where strings over A, C, G, T are read as code and translated into enzymes that do operations like cut, copy, insert, and delete on other strings, so the same string can be data and program at once. I built a little simulator of it and now I cant shake the thought that a self-replicating string is exactly Gödelian self-reference wearing a biochemical costume, and that DNA is the real-life version of the same trick. Heres the argument I keep going back and forth on. I can't tell if its deep or just a bad analogy, so please go step by step: is the argument valid, and if not, which step exactly fails, and what's the strongest corrected version of that step?

(1) In typogenetics, a quine is a string S such that the enzymes S codes for, run on a copy of S, produce a new copy of S. I've got one running in my simulator, so at least one exists.

(2) A quine is self-referential: S contains encoded instructions, and those instructions operate on the very string that contains them.

(3) Gödel's first incompleteness theorem works by constructing, inside a formal system that can encode its own syntax, a sentence G that asserts of itself that it is not provable.

(4) The deep enabling feature of Gödel's construction is self-encoding: the system can represent its own expressions and apply syntactic operations, like substitution, to those representations.

(5) Typogenetics is also a self-encoding system: strings encode enzymes, and enzymes apply operations to encoded strings.

(6) Therefore typogenetics should contain a Gödel sentence in the strong sense — a string whose behavior is the analogue of 'this string is not producible' — not merely a quine.

(7) So by diagonalization there should be a string that is unproducible by the system's rules, even though what it says is true — which is just incompleteness.

(8) DNA is a real typogenetic system (nucleotides encode proteins, proteins copy and manipulate nucleotides), so the same conclusion carries over: living systems have a built-in Gödelian blind spot.

I keep suspecting the slide happens at (4) or (5), but I can't say precisely why. And to be honest I don't know how to make (6) and (7) precise enough to be false. So: which step fails, if any, and does fixing the wording of that step save the rest of the argument?
