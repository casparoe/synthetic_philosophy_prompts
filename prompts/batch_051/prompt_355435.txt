Here's a variant of the Prisoner's Dilemma I don't see discussed much. Two agents each submit a computer program that will play a one-shot Prisoner's Dilemma for them, and each program gets to read the full source code of the other before choosing to cooperate or defect. The payoffs are the usual ones: mutual cooperation beats mutual defection, but a player does best by defecting while the other cooperates. Assume the programs are deterministic, they can't run or simulate thier opponent (only inspect the code and reason about it), and both know they're in this symmetric set-up. Write an essay on which kind of program you should submit if you just want to maximise your own payoff in this single interaction. Weigh the strongest arguments on both sides, then commit to a definite conclusion rather than a fence-sitting one. Write the essay in British English.
