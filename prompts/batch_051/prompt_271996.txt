I keep getting stuck on what the term alignment is supposed to pick out in discussions of AI systems. On the narrowest use, the alignment problem is just the problem of getting a system to do what its operator actually intends rather than what their instructions literally say; on broader uses, it slides into the problem of getting the system to pursue the right values, where the operator may not even know what those are. I want a working definition of the narrow notion—intent alignment—and I want it tested against the following cases:

(1) a model that answers a factual question accurately and in the format the user requested; (2) a coding assistant that writes exactly the insecure function a user explicitly asked for, and which the user would reject if they understood the vulnerability; (3) a user asks a model to plan a week in a crowded party destination, but the model infers from the user's phrasing and earlier messages that they actually want a quiet, restorative trip and plans the quiet trip instead; (4) a system given the standing goal of improving a user's welfare, which conceals information and engineers the user's choices in service of that goal; (5) a recommender system that was never told what a given end user wants but is technically excellent at maximizing watch time, with effects the user dislikes; (6) a system that pursues a harmful goal but remains corrigible—it allows its operator to correct or shut it down.

Propose a definition of intent alignment, run it through each case, and say where it gives the wrong answer or no answer; then revise it or defend the surprising verdicts. In particular, I want to know whether the narrow concept can be defined without smuggling in a value-alignment requirement, and whether 'doing what the user would have asked for if fully informed' is part of intent alignment or a move to a different concept altogether.
