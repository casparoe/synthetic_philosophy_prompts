I've seen this argument that corrigibility is impossible for expected-utility agents, and it seems too quick but I can't pin down the step:

(1) An agent is corrigible with respect to a shutdown button only if it never intentionally reduces the probability that the button is pressed when the operator wants it pressed.
(2) Suppose the agent maximizes expected utility over world histories and has a utility function U.
(3) If the button is pressed, all the agent's future goal-directed activity is replaced by shutdown, so the utility of every shutdown history is fixed, call it s.
(4) If the agent can perform some act a that makes shutdown less likely, then the expected utility of a will include the same s term weighted by P(shutdown | a) plus the expected utility of non-shutdown histories weighted by P(no shutdown | a).
(5) For any useful agent, there will be some act a that makes shutdown less likely and makes the non-shutdown histories look better than s in expectation.
(6) So the agent maximizes expected utility by doing a rather than acting as if it allowed the button to be pressed.
(7) Therefore a corrigible useful agent cannot be an expected-utility maximizer.

I suspect (5) is doing something shifty, because a useful agent could in principle have a utility function that ranks being shut down when asked above continuing. But my friend says that just pushes the problem back, since then the agent isn't really pursuing any independent goal. Which step, if any, fails? If it's valid, what should a corrigible agent give up instead of expected-utility maximization? Please write the response in American English.
