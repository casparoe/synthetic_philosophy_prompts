I am a novelist, and the following argument grew out of a scene I was drafting in which two characters dispute who, if either of them, should read a sealed account of something they both lived through. The possible outcomes are three: Elena alone reads it; Marcus alone reads it; neither reads it. Elena prefers that neither read it, but if someone must, she would rather read it herself than have Marcus read it. Marcus prefers that Elena read it, but if she will not, he would rather read it himself than leave it unread. Now impose two principles that, taken singly, seem beyond reproach:

1. Minimal liberty: each adult is decisive over whether he or she reads the account; where two outcomes differ only in that person's reading, that person's preference between them should settle the collective ranking. Since Elena prefers that she not read it, the outcome in which neither reads ranks above the outcome in which Elena reads; since Marcus prefers to read it, the outcome in which Marcus reads ranks above the outcome in which neither reads.
2. Weak Pareto: if both prefer one outcome to another, the first ranks above the second collectively. Both prefer that Elena reads to that Marcus reads, so the outcome in which Elena reads ranks above the outcome in which Marcus reads.

If collective preference is transitive, the three judgments yield a strict cycle: Marcus reads ranks above neither reads, which ranks above Elena reads, which ranks above Marcus reads. No outcome can be chosen as collectively best. Each step seemed to me undeniable, yet the result is that two principles I would have thought compatible cannot both be satisfied. Where, if anywhere, does this argument go wrong? If forced to choose, I would rather keep the liberty principle and restrict or qualify the Pareto principle than allow one person's reading choices to be settled by another; but I want to know exactly what that restriction costs, and whether there is a cleaner way out that preserves what both principles were trying to protect.
