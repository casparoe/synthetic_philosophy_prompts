The rough-and-ready criteria I was taught for deciding where one program ends and another begins, for the purposes of a copyleft licence, are these. A program B is to be treated as a derivative work of a program A licensed under the GNU General Public License (GPL) when several of the following hold, none of which is decisive on its own:

(1) B contains expression copied or adapted from A, including code generated from A’s source or taken from A’s header files.
(2) At run time, A and B execute within a single process, or exchange complex data structures in shared memory.
(3) B is written against A’s private implementation rather than against a published interface that has an independent implementation.
(4) B has no substantial use apart from functioning as a component of A.
(5) A and B are distributed and presented to the user as a single work.

Now consider Albatross, a proprietary audio-processing plugin. It contains no code from Ember: its developers compiled it against their own headers, written from a published, permissively licensed specification of Ember’s plugin interface. At run time, Ember — a GPL-licensed workstation program — loads Albatross directly into its own process; Albatross calls Ember’s functions and passes complex buffer and graph objects back and forth. A clean-room reimplementation of Ember exists and can host Albatross, though in practice nearly every user runs Albatross inside Ember itself. Albatross is distributed separately from Ember, and it does nothing useful unless Ember, or something that implements the same interface, is present to host it.

Does Albatross count as a derivative work of Ember for the purposes of the GPL? Work through the criteria honestly, say where they underdetermine the answer, and then say whether the case shows that any of the criteria are doing too much or too little work. Throughout, separate what is settled in software licensing from what is genuinely contested among people who know the area — the significance of loading a plugin into the host’s process is one candidate for the contested category — and do not present a contested view as the consensus.
