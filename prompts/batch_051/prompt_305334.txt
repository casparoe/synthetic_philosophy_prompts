So I'm in a poker league with some friends, and we've got a written rulebook of house rules. One of the rules is about how the rules themselves get changed: before each season, any rule can be changed by a majority vote. Last month someone proposed changing that rule itself, so that from now on changing any rule would need a unanimous vote instead. We voted on the proposal, and it passed 4-2. So today the rulebook says: any future rule change requires unanimity. The thing is, that new rule only got in by a 4-2 majority, not unanimously. The old rule seems to say the change was valid, because majority was enough at the time. The new rule seems to say it wasn't valid, because majority isnt enough anymore. Both answers sound right and wrong at the same time, and its honestly been bugging me for weeks.

I'm not a philosophy guy and I'm not looking for a reading list, I just want the puzzle laid out. It feels like we accidentally built a tiny legal system, and now I want to know what it actually presupposes: what makes a rule valid in a system like ours? Is there automatically some more fundamental rule that can't be changed by the usual procedure, like a constitution we never wrote down? Can rules even change the rule for changing rules, or does that already commit us to a hierarchy where some rules are above others? If someone said our league doesn't have to be read any particular way and the whole thing is underdetermined, what would the different readings be? And if we ended up writing down this hidden fundamental rule, would that actually change how we run the league, or just make explicit what we were already doing?
