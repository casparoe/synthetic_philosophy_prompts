I cover science and technology for a general readership, and a version of the following wager-style argument keeps surfacing in discussions of cryonics. I want to know whether it is valid and, if not, which step fails.

(1) Let p be the probability that a person preserved at death is eventually revived to a worthwhile life, V the value of that revived life, and C the total cost of preservation, payable while alive through insurance premiums.
(2) If revival happens, the preserved person gains V; if it does not, they gain nothing, since they are dead in any case.
(3) The only significant drawback of signing up is C, which can be kept small.
(4) The expected value of signing up is therefore pV minus C.
(5) V is enormous: several additional decades of worthwhile conscious life.
(6) Because V is so large, even a very small positive p makes pV far larger than C, so pV minus C is positive for any p greater than zero.
(7) A rational person should accept any affordable wager with positive expected value.
(8) Therefore, any rational person who can afford C should sign up for cryonic preservation, no matter how small they take p to be.

Is this argument valid? If so, state which interpretation of each premise makes it so. If not, identify the exact step or steps that fail, distinguish the readings under which they hold from those under which they do not, and say whether a corrected version still supports the conclusion. Please answer in British English.
