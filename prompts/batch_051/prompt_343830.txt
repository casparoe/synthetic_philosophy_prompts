In *The Logic of Chance*, John Venn observes that a single event or individual can be assigned to any of a large number of different classes or series, and that the probability one attaches to it changes with the choice of class. A given death, for example, may be placed among deaths of men of the same age, or of the same occupation, or of the same place of residence, and the resulting probabilities come apart. Venn takes this to be a serious difficulty for any view that grounds probability in frequencies or class membership.

Before I read any more proposed solutions to this problem, I want the full specification of what an adequate account would have to get right. Please write the desiderata for a theory of direct inference and reference-class selection. I want the cases it must handle, the distinctions it cannot collapse, the formal results from probability theory it must respect, and a note on which requirements are non-negotiable and which are merely local preferences. For each requirement, give the motivating case or consideration.

In particular, make sure the list addresses at least the following: the same outcome under multiple statistically relevant classes; the demand that a rational agent not be entitled to incompatible degrees of belief in the same proposition; the total-evidence requirement and whether it is compatible with treating some reference class as privileged; the difference between classes we find and classes we design for a purpose; Simpson-type reversals where finer partitioning changes the import of a statistic; and the case of a genuinely singular event for which no natural frequency is available. I especially want to know whether some subset of these desiderata is jointly unsatisfiable, and if so, which trade-off you take to be forced. Flag any pair that pulls in opposite directions.

Finally, give only a brief indication of how the main existing approaches—Venn-style frequentism, propensity theories, subjectivist/conditional-probability treatments, and objective Bayesianism—fare against the list. Keep the weight on the criteria themselves rather than on the scoring.
