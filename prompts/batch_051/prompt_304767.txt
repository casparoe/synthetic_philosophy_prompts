Suppose an agent has access to a machine that, before the agent has made up its mind, outputs the probability that the agent will perform some specified action, and suppose the agent then adopts that output as its own credence about what it will choose. Explain the conceptual problem with doing this while the choice is still under deliberation. In doing so, distinguish self-prediction from predicting another agent's choice, explain why the machine's output could be unstable or undefined when it is fed back into the agent's own reasoning, and assess whether assuming physical determinism would resolve the problem.
