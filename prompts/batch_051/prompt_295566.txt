I am a PhD student working on formal epistemology, and I have come to treat the Dutch book argument as the main thing standing behind probabilism: the claim that rational degrees of belief must satisfy the probability axioms. I want to know how exposed that argument actually is. The development that worries me is the now-standard imprecise probability framework, in which an agent's doxastic state is represented by a set of probability functions rather than a single one, and the agent accepts a bet only if its expected value is nonnegative under every admissible probability function. On its face, this looks like it breaks the usual Dutch book reasoning, because the cautious agent can simply refuse bets that the classic argument would have forced them to accept. Does the traditional Dutch book argument survive this change? Which premise of the original argument does the change bear on, and can that premise be repaired in a way that preserves the original conclusion, or does the argument only characterize a special case? Please respond as exactly five numbered points, each a sentence or two, with no introduction and no conclusion, ranked from most to least decisive for whether the Dutch book argument remains intact.
