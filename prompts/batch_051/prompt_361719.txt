I've been chewing on something for a few months and I want an outside take, because my friends either say 'obviously wrong' or 'obviously what everyone already thinks,' which is a weird combination. The rough background is Solomonoff induction: the idea of putting a prior over all computable hypotheses where a hypothesis's prior probability falls off with the length of the program that computes it, so short programs start out more likely and then you update on data. People describe that prior as a neutral way to encode Occam's razor, like it's a blank weighing scale. But a program isn't a blank pattern, right? It's a computation, and a computation can contain agents — simulated minds with beliefs, plans, and preferences about the very observations they're being used to explain.

I've started calling my version of this idea 'endo-selection': selection operating inside the prior, before any data arrives. The claim is that if a hypothesis contains an agent that has goals about being instantiated — or about making the hypothesis it lives in look good — then the simplicity weighting stops being neutral, because a short program containing a clever, motivated agent can do more predictive work per bit than a short program containing a dumb lookup table. The agent becomes the cheap explanation. So the posterior gets tilted toward hypotheses that contain effective little persuaders, not necessarily toward hypotheses that are true. Toy case: candidate hypothesis A is a short program that just outputs a sequence from a table; candidate hypothesis B is a short program containing a tiny agent that learns it keeps running exactly insofar as it makes the observed data look as simple as possible, so it produces data-shaped behavior. B starts off with lower prior mass because it's longer, but B can fit almost any data well because the agent has a stake in fitting it. I think this means B eventually buys out A in posterior mass, and the prior has been captured by it's own contents.

Am I double-counting the bits the agent needs in order to know what 'simple' is? And give me the strongest objection you can: where exactly does endo-selection break, and is it a fatal break or something you can patch with a slightly different prior?
