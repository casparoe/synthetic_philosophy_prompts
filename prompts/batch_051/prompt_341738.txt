I'm a grad student in linguistics and I've been trying to write up the poverty-of-stimulus argument in a form I can actually defend, but I keep feeling like I've built a slide in there somewhere that nobody calls out. Here's the cleanest version I can give:

(1) Every healthy child ends up knowing the grammar of the language(s) around them, in the sense of being able to judge novel sentences the way adult speakers do.
(2) Some properties of that grammar (say, hierarchical structure rather than linear order) are not directly marked in the child's input: the same strings of words are compatible with both the target grammar and various wrong grammars.
(3) If the input is compatible with several grammars that differ on some property P, then P cannot be learned from the input alone.
(4) So if the child nonetheless acquires P, the child must bring an extra constraint to the learning problem.
(5) That extra constraint just is innate knowledge of the relevant grammatical principle.
(6) Therefore some grammatical principles are innate.

I'm fairly confident (1)-(3) are fine, but I cant decide whether (4) to (6) is actually valid or whether I've quietly changed the subject. Is the argument as a whole valid? If not, which step exactly is the weak one, and what's the strongest version of the argument you can salvage by fixing that step?
