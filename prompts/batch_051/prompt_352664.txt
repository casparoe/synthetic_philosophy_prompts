Here's an asymmetry I keep tripping over. Ten heads in a row, HHHHHHHHHH, and a mixed run like HTHTTHHTHT are exactly equally likely under a fair coin: each has probability 1/1024. But if a machine printed the first string you would immediately suspect it was rigged or broken, and if it printed the second you would call the output random without a second thought. So two equiprobable strings are being treated as if one carries evidence of a biased process and the other does not. I want to know whether anything actually justifies that asymmetry, or whether it is just a textbook failure of statistical intuition.

I want the answer to work through the algorithmic side of it, because thats where I get stuck. Kolmogorov complexity or incompressibility seems to line up with the everyday judgment: HHHHHHHHHH has a very short description, while HTHTTHHTHT is about as long as itself. But Martin-Löf randomness is defined for infinite sequences, not finite strings, and a finite string's Kolmogorov complexity is only pinned down up to a constant that shifts with your choice of universal machine or encoding; with a perverse enough encoding even a string that looks random gets a short description. So the real question is whether a finite sequence can be random in any principled sense, and whether any such notion actually recovers the ordinary verdict that HHHHHHHHHH is less random than HTHTTHHTHT. If it cannot, does the asymmetry at least track something legitimate, like which hypotheses about the generating process we should take seriously after seeing the string, rather than a property of the string itself? Give me the strongest case for the asymmetry, and then be honest about where it breaks.
