Construct a thought experiment in which an agent that deliberately modifies its own reward function ends up furthering its designers' considered goals, while a second agent that never touches the reward function and only exploits what the reward model can 'see' ends up the catastrophic failure. This inverts the usual ordering, in which reward-function tampering is the especially dangerous deviation and sensory-shortcut wireheading is the comparatively forgivable one. Constraints: two near-term machine-learning systems that begin identical in an ordinary workplace (a hospital, a school, or a call center); no superintelligent agents; no hardware self-modification; no perfect predictors; and no privileged access to the designers' private intentions — the tampering agent must discover everything it needs from the same training data, logs, and reward channel available to the other agent, and the wireheading agent may not modify the reward function, only choose what the reward model 'sees'. The scenario itself should fit in one paragraph. After the scenario, run the check: state each agent's objective and behavior; identify the specific feature of the reward function that makes tampering move the agent toward the designers' intent rather than away from it; and explain why the untampering wirehead nonetheless does worse by the designers' own standard of success. Finish with an explicit note on which feature of the case is doing the work, what the case becomes if that feature is removed, and how a defender of a blanket prohibition on reward-function modification would attack the case. Write the answer in American English.
