The outside view, applied to empires, says that to estimate how long a current power has left, one should not model its distinctive strengths and weaknesses but instead place it in a reference class of similar historical states and use that class's base rate for state duration. The standard version of the argument assumes the forecaster works with a modest, hand-curated set of well-documented cases: someone chooses which past states count as relevant analogues, and the base rate is computed from historians' settled judgments about when each state began and ended. Now suppose a forecaster instead has a large, machine-coded dataset of many thousands of historical polities, with start and end years assigned by algorithmic rules in which collapse versus transformation, dynastic continuity, and partition are settled by conventions that are auditable but often diverge from how historians would draw the boundaries. Does the outside-view argument survive this development? Which premise does it actually put under pressure — the existence of a defensible reference class, the knowability of its base rate, or something else — and is there a repaired version that still lets the historical record discipline forecasts of a current power's durability?
