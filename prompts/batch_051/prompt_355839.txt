My friend and I got into the expected-value-fanaticism debate and ended up with an argument that seems to prove expected-value reasoning eats itself, and now neither of us can find the bad step. Start with the rule: always choose the act with the highest expected value. Then:
(1) For any sure thing with finite value V, there is some possible gamble with a tiny probability p and an enormous payoff H such that p × H > V.
(2) So the rule always tells you to take that gamble instead of the sure thing.
(3) But the same reasoning applies to the gamble itself: it is outdone in expected value by an even tinier chance of an even bigger payoff, and so on without end.
(4) So the rule never settles on any act; it just keeps pushing you toward longer and longer longshots.
(5) A rule that never settles on an act is not a usable rule of choice, so the highest-expected-value rule must go.

I'd rather keep some version of expected-value reasoning, but not if it commits me to chasing a lottery ticket forever. Which step do you reject, and what does rejecting it cost?
