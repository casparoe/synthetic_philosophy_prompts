I run a small rationalist-adjacent blog on formal philosophy and game theory. My readership is comfortable with the one-shot Prisoner's Dilemma, Nash equilibria, Newcomb problems, and agent-foundations vocabulary such as Löbian cooperation, but I should assume nobody remembers the formal details. I am planning a sorting quiz for a post: the quiz should place a reader by what they choose in concrete cases, never by which named position they prefer from a menu.

The quiz's shared setup is a one-shot Prisoner's Dilemma in which each agent submits a program instead of a bare action. Before acting, each program can read the other's full source and may condition its action on any fact about that source or about how the other program would respond. The classical program-equilibrium observation is that mutual cooperation is a Nash equilibrium in program space: each agent can rationally submit a program that cooperates with an opponent iff the opponent's program would cooperate with it. Mutual defection is also an equilibrium, so the model makes cooperation available rather than mandatory. The games may be varied slightly in individual questions — asymmetric payoffs, side payments, a third player — as long as the one-shot read-the-source structure stays. The quiz should not drift into iterated-play reciprocity; my readers already know Tit-for-Tat is an answer to a different question.

Write the quiz and its scoring key. Requirements:

1. Eight to ten questions. Each question states a concrete variant or case and offers two or three answers phrased as things a reader might actually conclude about that case, never as labels. Cases I expect to see covered include: a program with comically different source text but identical behavior; a self-referential cooperation condition that fails to terminate if you try to simulate it; a proof-bounded agent that cooperates with one cooperative opponent but not another because the proof is too long for it; a threat to substitute a different program after submission but before execution; a two-agent cartel that cooperates internally and exploits a third player; and an extortionate program that refuses to cooperate unless the other program grants it most of the surplus in a game with side payments. No question may just ask whether the reader accepts syntactic matching, quining, Löbian cooperation, or any other named view.

2. Score answer patterns onto the following six positions:

- Template-matching program equilibrium: the cooperative equilibrium depends on exact or near-exact source match, and textual variation legitimately breaks cooperation; the interesting questions are all downstream of what counts as the same program.
- Semantic program equilibrium: the right rule is behavioral — cooperate iff the other program would cooperate with me — with self-reference made well-defined by a quine-style fixed-point construction or its equivalent, rather than by comparing source text.
- Proof-based Löbian cooperation: source reading is replaced by proof; an agent cooperates with an opponent iff it proves the opponent cooperates with it, which supports mutual cooperation without halting problems or syntactic comparisons, at the price of sensitivity to proof length, axiom choice, and formal details.
- Equilibrium-selection/bargaining-first: the cooperative equilibrium is uninteresting compared with the many other equilibria, including extortionate ones; programs function as bargaining moves, and the real theory is about which programs get selected and how surplus is divided.
- Commitment-device deflationism: program equilibrium just restates precommitment or contracts-by-code, and the actual work is external enforcement — who audits that the submitted code is the code that runs, and what the surrounding institutions do about bugs or substitution.
- Sourceless generalisation: full source access is only one implementation of mutual transparency about decision rules, and the object of study should be cooperation under that transparency, with program equilibrium as a convenient special case.

3. The scoring key should aggregate across questions rather than assigning one position per question. Say which questions load on the same underlying choice, and if some pair of these positions ends up inseparable by the cases after honest effort, say so plainly and explain what would distinguish them.

4. For any combination of the underlying choices that no position occupies, add a one-line diagnosis: unoccupied because incoherent, unattractive, or merely unexplored.

5. The whole thing should work as a standalone quiz post, with a headline for each item and a short explanation of the final sorting; do not ask for readings or citations.

The angle I care about: what exactly does the cooperative work in the program-equilibrium result — the source access itself, the self-reference fix, the proof system, the bargaining-and-selection backdrop, or the external enforcement assumption that the submitted program is the one that gets run? The questions should force readers to reveal their commitments on that question first, and only then place them in one of the six positions.
