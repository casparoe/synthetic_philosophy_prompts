I want a working definition of the predicate 'x is a token of the lowercase letter a'. My interest is the question what makes every 'a' an 'a' across its wildly different realizations; I am setting aside the uppercase form and asking only about the lowercase.

Begin with the judgments I expect a successful definition to capture.

It should count as tokens of the letter 'a':
(1) a double-storey 'a' set in a serif typeface;
(2) a single-storey 'a' handwritten in the style taught in many schools;
(3) a heavily stylized display-face 'a' that a novice reader initially fails to parse but an experienced reader decodes by context and convention.

It should not count as tokens of the letter 'a':
(4) a lowercase 'o';
(5) the numeral '2'.

The following cases are ones on which I have no settled view, and I ask the definition to return a definite verdict either way:
(6) a machine-generated closed loop with a trailing stroke, geometrically indistinguishable from a printed 'a' but produced by a random process with no alphabetic function;
(7) the IPA symbol ⟨ɑ⟩, a single-storey shape used for the open back unrounded vowel but functioning as a distinct symbol within a phonetic notation system;
(8) a glyph in an invented script that is geometrically identical to a printed single-storey 'a' but belongs to no Latin-derived writing system and is pronounced /v/ by its users;
(9) a corporate logotype in which the designer has deliberately made one character ambiguous between 'a' and 'd', so that which letter viewers see varies with context;
(10) a child's attempt to write the word 'cat', in which the intended 'a' is, considered as an isolated shape, indistinguishable from a 'u'.

Please propose a definition, run it against all ten cases, and say explicitly where it yields an answer you regard as wrong or no answer at all. Then either revise the definition or defend the surprising verdict. Finally, address two questions: does the concept come in degrees, and, in the last analysis, is being an 'a' a matter of intrinsic geometry, of causal origin, of role in a symbol system, of competent readers' classificatory dispositions, or a combination — and if a combination, which factor is doing the work in which cases?
