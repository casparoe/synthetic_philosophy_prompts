I've been trying to map out the space of counterexamples to the simple conditional analysis of dispositions, and I keep getting stuck at four. The SCA says an object is disposed to manifest M under stimulus S just in case if it were S, it would M. The four I have so far are: finks, where the stimulus itself makes the object lose the disposition before the manifestation can happen, like a glass that is fragile but would be annealed by the very shock that would break it. Masks, where the disposition is still present but some standing background factor blocks the manifestation, like a fragile glass wrapped in bubble wrap, struck but not breaking. Antidotes, where the stimulus initiates the causal process but a later event reverses it before manifestation, like a poison followed by an antidote before death. And mimics, where the object lacks the disposition but an external cause produces the manifestation anyway, like a non-fragile glass wired to shatter on impact.

I'm treating these as four distinct structural types, not just examples. I'm looking for a fifth type that is genuinely different from each of them. Ideally one that doesn't invoke an outsider intervening, a later reversal, or the stimulus destroying the disposition. Give me a new kind of case, explain exactly how it differs from finks, masks, antidotes, and mimics, and say whether it points to a different flaw in the SCA or just presses the same problem harder. If you think there is no fifth type, I'd like the argument for why these four exhaust the possible ways the conditional can come apart from the disposition, but I'd much rather see the new one.
