Ok, a friend argued himself into the following and now I can't find the bad step.

(1) Arithmetic is the firmest thing there is: 2 + 2 = 4 is true regardless of anyone's notation, and it seems like "is 2 an element of 4?" has to have a plain yes-or-no answer.
(2) In the von Neumann coding of the natural numbers, each number is the set of all smaller ones: 0 = ∅, 1 = {∅}, 2 = {∅, {∅}}, 3 = {∅, {∅}, {∅, {∅}}}, and 4 = {0, 1, 2, 3}. Since 2 is one of the elements of {0, 1, 2, 3}, 2 ∈ 4.
(3) In the Zermelo coding, 0 = ∅ and each number is just the singleton of the previous one: 1 = {∅}, 2 = {{∅}}, 3 = {{{∅}}}, 4 = {{{{∅}}}}. So 4 has exactly one element, namely 3, and since 2 ≠ 3, 2 ∉ 4.
(4) Both codings give the same arithmetic; successor, addition, and multiplication all work the way they should, and no arithmetic fact picks one coding over the other.
(5) If the real 2 existed independently of these codings, one of them (or some third thing) would have to correctly identify it, and then "2 ∈ 4" would have a hidden truth value. But arithmetic is silent about membership, and there's no other way to get at what numbers themselves are. So there's no fact of the matter there to be right or wrong about.
(6) So the number 2 doesn't exist independently of a coding; numbers only become objects once we arbitrarily pick a representation.
(7) The same move works for any mathematical object, since groups, graphs, functions, and spaces all allow multiple equivalent representations. So no mathematical object exists on its own, and even "2 + 2 = 4" is true only relative to an arbitrary coding.

Step (7) is insane to me — math isnt a notation game. But if I want to keep that, I dont know which earlier step to reject or what it costs. Which step goes wrong here? If someone wants to insist that numbers really exist, where exactly should they break the chain, and what do they lose?
