I keep trying to convince myself that a bare LLM isn't an agent, only the whole scaffold is: (1) To be an agent, a system has to act from its own world-directed desires, not just from someone else's. (3) When an LLM helps me plan a wedding, the desire to plan the wedding is mine; the model just carries it because the prompt steers the sampling. (4) So the LLM has no world-directed desire of its own—only a token-prediction objective. (5) Therefore the bare LLM is not an agent. But step 1 feels like it's cheating, because by the same logic a sous-chef following a chef's orders, or an employee doing exactly what their manager wants, wouldn't be an agent either.
