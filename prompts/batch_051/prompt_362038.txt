I am a third-year undergraduate enrolled in a machine ethics course, and for my term project I am building a classification instrument for the question of how ethical reasoning should be implemented in an autonomous system. I would like it to take the form of a decision tree, not a prose survey.

The target system is a home-care robot placed in the homes of elderly users with mild cognitive impairment. The robot is not being asked to choose its own values; the problem is to decide how it should select actions in genuinely conflictual situations. I want the tree to sort the standard positions in machine ethics by how they settle a fixed set of design problems, not by which label a designer already likes.

Please organize the tree around four distinctions that matter for my project. The first is whether the robot should be built with constraints that make certain actions wrong independently of their expected outcomes, or whether only expected outcomes count. The second is whether the right unit of evaluation is the individual action or the long-run policy or disposition the robot encodes. The third is whether moral competence can be specified top-down in advance or must be learned bottom-up from cases, examples, or feedback. The fourth is whose values count, and how they combine, when the user, their family, and the care agency disagree.

Every internal node should be phrased as a concrete question about the home-care setting that a designer without philosophical vocabulary could answer. Useful node cases include—though you need not use them verbatim—whether the robot may tell a small reassuring falsehood when doing so reduces the user's distress; whether it should follow the care agency's written medication protocol in a case where it predicts that deviating once would produce a better outcome; and whether the user's expressed refusal should be decisive when the family insists on overriding it. No node should name a theory.

Each leaf should carry a named position in machine ethics and one sentence on its most awkward commitment in the home-care setting. About eight to ten leaves would be appropriate, and they should at minimum include: top-down deontic constraint satisfaction; act-consequentialist optimization; rule- or policy-consequentialism; principlism, understood as balancing mid-level principles; contractarian or preference-aggregation approaches; bottom-up case-based learning of moral judgments; virtue-theoretic approaches that aim at reliable dispositions; and the view that the robot is not itself a moral agent but only a tool of its designers and operators.

Finally, please flag any combination of answers that is logically possible but that no developed position occupies, and say briefly whether it is unoccupied because it is incoherent, unattractive, or merely unexplored. Also flag any pair of leaf positions the tree cannot fully separate, and indicate what further concrete case would separate them.
