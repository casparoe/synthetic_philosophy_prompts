Consider the following argument for the conclusion that everything that actually exists, exists necessarily.

(1) Necessarily, everything is self-identical: □∀x(x = x).
(2) The Converse Barcan Formula: for any predicate F, if necessarily everything is F, then each thing is necessarily F. Schematically: □∀xFx → ∀x□Fx.
(3) To be self-identical at a possible world, a thing must be something at that world; it could not be self-identical at a world where it does not exist.
(4) From (1) and (2), substituting self-identity for F: each thing is necessarily self-identical, i.e., ∀x□(x = x).
(5) From (3) and (4): each thing is such that it exists at every possible world, i.e., ∀x□∃y(y = x).
(6) Therefore, everything that exists exists necessarily.

Is this argument valid? If it is not, identify the first step that fails, and specify the semantic assumptions — about whether the quantifier ranges over possibilia or actualia, and about how identity and existence relate — under which it fails. If it is valid on some reading, state that reading and say which premise is doing the metaphysical work.
