Somebody in my logic class put this argument on the board and now I cant decide which step to give up. Let C be the sentence "If C is true, then the moon is made of green cheese."

(1) C is true iff (if C is true, then the moon is made of green cheese). That's just the truth principle: a sentence is true exactly when things are as it says.
(2) Suppose C is true. Then by (1), if C is true, then the moon is made of green cheese. By modus ponens, the moon is made of green cheese.
(3) From the assumption that C is true we got green cheese. So by conditional proof: if C is true, then green cheese.
(4) But that conditional is exactly what C says. So by (1) in the other direction, C is true.
(5) Now C is true, and by (1) that makes "if C is true, then green cheese" true; one more modus ponens gives green cheese.

So the moon is made of green cheese, and swapping in any claim you like proves anything. The usual dialetheist fix—rejecting explosion—doesn't touch this, since the proof never uses a contradiction. I'd most like to keep modus ponens and the truth principle. Which step do you reject, and what does rejecting it cost?
