I want the full desiderata list for a theory of reference class selection — the standard you would use to judge claims of the form "the base rate for cases like this is thus-and-so" before updating on them. The motivating use case is outside-view forecasting of whether a given empire or regime will collapse, but the desiderata should apply to outside-view reasoning generally. What does such a theory have to get right? It must, at minimum, handle these pressures: a single target case belongs to indefinitely many classes with different base rates, so a choice has been made that needs justifying; a coarse class and its fine partitions can support opposite conclusions; broad classes are stable but only weakly diagnostic, while narrow ones are diagnostic but noisy and easily gamed; base rates are not constants, so selecting a reference class is partly a forecast that the past will remain similar in the respects that matter; and resemblance alone is not enough — the theory must separate merely matching features from causally relevant similarity to the target. For each requirement, give the motivating case or consideration and say whether it is negotiable, and note any place where two requirements cannot be jointly satisfied. Then say which single requirement excludes the most popular heuristics, and briefly score the usual moves — the class that feels right, the broadest available class, the most causally similar class — against your list. Lead with your bottom line in the first sentence, then give the reasoning, with no preamble and no restating of the question.
