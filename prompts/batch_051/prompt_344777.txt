In a philosophy of science class we did the standard underdetermination-by-curve-fitting example: you have finitely many data points, and infinitely many functions pass through them exactly, so the observations alone don't single out a curve; the usual response is to bring in simplicity or some other theoretical virtue. I remember thinking at the time that the setup was a bit unfair because real data never come as exact points. So I've been trying to rebuild the argument with realistic data and now I honestly can't tell which way it goes.

Suppose each observation comes as an interval: the thermometer at noon on Tuesday said 20.1 plus or minus 0.2 degrees, and so on for, say, thirty readings across a month. Say a hypothesis is compatible with the data just in case the curve it predicts passes through every interval. That seems to make underdetermination even worst, since more wiggly curves fit intervals than fit points exactly. But now add a prediction constraint: we split the intervals at random into a fitting set and a test set before looking at any candidates, and we only accept a curve if it passes through the intervals in both sets. Does that filter out the wildly overfit functions and maybe leave only a small class, or does it still leave infinitely many because any finite test set can be threaded by some high-degree polynomial? Then add a simplicity prior over polynomial degree; some people would say that kills the underdetermination, but I want to know whether it just relocates it: don't we now face underdetermination between all the different possible priors, or between different measures of simplicity? I'm trying to pin down the exact step at which the original skeptical result — that evidence alone leaves infinitely many theories open — either survives or collapses.
