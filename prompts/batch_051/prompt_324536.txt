For a seminar that has been using Dennett's four-way hierarchy of Darwinian, Skinnerian, Popperian, and Gregorian creatures, I would like you to build a decision tree that classifies a cognitive system into one of those four kinds using only facts about where its behavioral options come from and where they are filtered before being kept or discarded.

Use the following operational definitions, and treat the categories as cumulative unless you explicitly argue otherwise:
- Darwinian: the system's behavioral repertoire is produced by blind variation and selection across generations; an individual system's behavior is not revised by feedback within its own lifetime.
- Skinnerian: the system also revises its behavior within a lifetime by trial and error: it emits candidate behaviors, and outcomes select among them.
- Popperian: the system also tests candidate behaviors "offline," against an internal representation of the world, before acting, so that some candidates are discarded without ever being performed.
- Gregorian: the system also acquires and runs thinking tools made by other minds — words, notations, diagrams, algorithms — so that its internal testing can draw on other minds' past tests.

Build the tree under the following constraints.

1. Phrase every internal node as a concrete diagnostic question that a researcher could answer about a system's architecture or learning history without already knowing which of the four labels it would receive. Questions about what the system was exposed to or what happens when it tries a bad action are appropriate; questions that use the four labels are not.

2. Let the branching order track the logical space rather than a memorized list: ask first where variation comes from (across generations or within a lifetime); then ask whether selection occurs only in the world or also in an internal model; then ask whether the internal model is stocked with tools inherited from other agents.

3. Give each leaf a brief entrance-and-exit criterion.

4. In a short appendix, run the tree on the following cases, state exactly which path each takes, and note where the tree strains:
   - a digger wasp whose behavior is fixed within its lifetime and changes only over evolutionary time;
   - a rat in an operant chamber;
   - a dog that halts before a novel gap, looks back and forth between possible paths, and only then takes one;
   - a human navigator using a paper map and a compass;
   - an AI trained first on next-token prediction over human text and then fine-tuned with a reward model to prefer some outputs;
   - a species that learns foraging techniques by imitating conspecifics but has no language.

5. Set out the unoccupied or unstable combinations in the logical space (for example, internal testing without any lifetime behavioral revision, or socially acquired tools without internal simulation) and state briefly whether each is incoherent, merely unattractive, or viable but not what the four labels pick out. In doing so, say whether you are treating the cumulative assumption as an empirical claim or as a stipulation, and why.

6. Flag any pair of leaf positions that the tree cannot cleanly separate on the information supplied, and say what additional observation would settle the classification.

Keep the answer under 1,200 words, write it in American English, and do not include citations or a reading list; the instrument should stand or fall on the operational definitions given here.
