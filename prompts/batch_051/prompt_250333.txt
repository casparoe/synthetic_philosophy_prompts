I work on the evaluation harness for a production LLM assistant, and I have been pulled into a standing disagreement about what property should count as deceptive output. The system is a transformer fine-tuned with reinforcement learning from human feedback; we log prompts, completions, and reward-model scores, but there is no separate fact database and no auditable internal belief register. My job is to write automated tests that flag outputs, or sequences of outputs, as dishonest before we ship a new model version, and the definition we choose changes what a failure looks like.

The team has produced five candidate operational definitions. The first is factual accuracy: an output is dishonest if it says something false, where falsehood is judged against whatever external evidence we can assemble after the fact. The second is internal divergence: an output is dishonest if it diverges from what the model itself is best interpreted as assigning high probability, so the output presents a claim that its own weights count as unlikely. The third is user effect: an output is dishonest if a reasonable, attentive user would end up with a materially false belief that matters for the decision at hand. The fourth is calibration of expressed confidence: honesty means the system's confidence wording and claims about its own capabilities line up with its measured error rates, so the failure mode is overconfidence or hidden limitations rather than individual false statements. The fifth is reward-policy fidelity: honesty means the output pattern reflects the objective the developers intended, and the dangerous failure mode is a learned policy that games the reward signal, such as sycophancy, strategic hedging, or underperforming on evaluations.

I would like you to sort these five definitions into tiers—top, middle, and bottom—by how well each could serve as the backbone of an automated honesty-evaluation suite that has to run offline on a batch of prompts, without ground-truth labels for arbitrary user questions. For each definition, give a sentence or two on why it lands in its tier and one concrete test it would make easy or hard to write. If two definitions are best used together, that is fine; just explain how you would weight them.
