The stochastic-parrot argument dismissed large language models as pure continuations of text: a model trained only to predict the next token, whatever else we wrap around it, ultimately samples from a distribution over word sequences, so its fluency is evidence of scale and not of reference, communicative intent, beliefs, or goals. Since that argument was framed, systems built on the same pretraining objective have been fine-tuned by reinforcement from human feedback, supplied with tools and external memory, and embedded in agentic scaffolds in which their outputs are treated as actions — executed in an environment, with the resulting observations fed back in and used to select further outputs. Does the stochastic-parrot argument survive this development in its original form, does it need repair, or is it dead? If it survives, identify the premise that still does the work and explain why fine-tuning and scaffolding do not touch it. If it needs repair, identify the premise the development undercuts and state the strongest version of the argument that remains. If it is dead, say what, if anything, the argument still correctly warns against.
