I'm in a Computers and the Law seminar and we've been on GPL copyleft for two weeks. I've got a list of gut calls about when one program is a derivative of another, and they don't obviously fit one rule. I want to know whether there's a single principle behind them, or which of my calls I should overturn.

Here are my verdicts:

1. I copy 300 lines of a GPL library into my proprietary codebase. Derivative, has to be GPL. No real doubt.

2. I statically link a proprietary binary against a GPL library. Also derivative.

3. I compile against a GPL library's headers and dynamically link to the .so at runtime, so the GPL code stays in it's own file but my object code calls into it. I think this is derivative, but I can't actually defend where the line is.

4. My proprietary app shells out with system() to a seperate GPL command-line tool and parses its stdout. Not derivative, just two programs talking, even though my app is nearly useless without that tool.

5. I write a plugin for a GPL host, loaded into the same process, calling the host's data structures through its plugin API. Derivative; the plugin has to be GPL.

6. I ship a proprietary program and a GPL program in the same installer, completely unlinked. Not derivative, just aggregation.

7. I translate a GPL C program into Rust by hand, keeping the overall structure and variable names but copying no literal line of code. Derivative.

The one that bugs me is the gap between 3 and 4. Both feel like my code invoking their code, but I treat dynamic linking as one work, and a process boundary as two. My half-baked rule is: it's one program when both sides run in a single address space. That rule gives me 3 and 5 as derivative and 4 as not, which matches my gut, but it says nothing about 7 and it feels like the wrong sort of line, like I'm doing physics instead of copyright.

So: is there a principle that gets all seven, and if not, which verdict would you give up first? What does the principle you like say about the case I keep flip-flopping on: a closed-source app that talks over a network socket to a modified GPL server, where I deliberately wrote the wire protocol to mirror the server's internal function calls?

Also tell me what would change your mind — which case or argument would flip you to a different verdict, and where your own reasoning is shakiest. And keep the whole answer under 600 words.
