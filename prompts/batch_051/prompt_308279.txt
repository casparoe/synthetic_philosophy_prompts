I keep tripping over a weird little argument pattern that I don't have a word for, and it shows up a lot in blog posts about rational choice. The cleanest version goes like this. Someone flips a fair coin. If it lands heads, they'll give you ten thousand dollars, but only if you would pay them a hundred dollars in the version of the story where the coin lands tails. The coin lands tails, so now they come to you asking for the hundred. Nothing you do now can make the coin have landed heads — that branch is already settled, and paying the hundred won't cause the ten thousand to appear. Yet a lot of people say you should pay anyway, because an agent who pays in the tails branch is exactly the agent who gets the ten grand in the heads branch. The general shape seems to be: you should do a thing with no actual causal payoff, because doing it makes you the kind of agent who would have recieved the payoff. I don't have a name for the puzzle or for that principle, and I'm especially unsure whether the real point is about causes, about evidence, or about committing to a policy across possible worlds. Does this puzzle have an established name? And is there a separate name for the principle that says you should pay? If there are nearby positions that disagree — some say pay, some say don't — I'd want to know exactly what separates them, because a bare label won't really settle it for me.
