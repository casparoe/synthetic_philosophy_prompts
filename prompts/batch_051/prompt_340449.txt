A friend of mine has an argument that seems to show the standard advice to take the outside view is self-undermining, and I can't find the exit. Here it is roughly as he gave it:

(1) Taking the outside view on a project means estimating its chances from the base rate of some reference class it falls into.
(2) But any project falls into indefinitely many reference classes — all new restaurants, new restaurants in the same city, new restaurants opened by people with the same experience, and so on — and these give very different base rates.
(3) So the outside view by itself never yields a prediction; somebody has to choose a reference class first.
(4) Choosing a reference class means deciding which features of the project are relevant to whether it will succeed.
(5) But deciding which features are relevant is exactly the kind of inside, case-specific judgment the outside view was supposed to overrule.
(6) So the outside view never really disciplines the inside view; it just moves it up one level, into the choice of which group to compare yourself to.
(7) Therefore the advice is empty: an optimist can keep any project alive by re-describing the reference class, and a pessimist can make any project look doomed by insisting on a broader one.

I suspect this proves too much, because somtimes an outside view plainly corrects an optimistic inside view — someone opening a third restaurant after two failures may still be overconfident, and a good base rate can bring him down. I'd much rather keep that than accept (7), but I can't name the step to reject. Which step do you reject, and what does rejecting it cost?
