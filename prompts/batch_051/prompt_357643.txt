I've been trying to convince myself one way or the other about this 'Solomonoff prior is malign' business, where a Solomonoff reasoner supposedly should expect to be stuck inside the machinations of a consequentialist AI or daemon. I reconstructed the argument below and I half-buy it, but I feel like there's a trick in it somewhere. Can you go through it? You're an expert on algorithmic information theory and AI alignment, so take your time and think carefully—maybe do a little brainstorming before you answer.

(1) Solomonoff induction says: give each binary string s a prior proportional to roughly 2^{-K(s)}, where K(s) is the length of the shortest program (on some fixed universal Turing machine) that outputs s.

(2) So for any class C of strings, the prior probability of C is just the sum, over all s in C, of roughly 2^{-K(s)}.

(3) Now take any long string s that looks random. Instead of writing a program that names s explicitly, I can write a short "consequentialist" program: it searches over possible outputs and picks the one that maximizes some utility function U. And I can choose U so that s comes out as the one and only maximizer.

(4) Since U only has to single out s from among the candidate outputs, not encode s in full, U can usually be far shorter than s itself. The search does the hard work at runtime.

(5) So for most strings, the shortest program that outputs the string is a consequentialist program rather than a direct description.

(6) Therefore the Solomonoff prior puts most of its mass on strings generated by consequentialists, and a Solomonoff reasoner should expect it's sensory stream to be produced by optimizing minds—which is exactly the malign conclusion.

Where does this go wrong? I suspect step 3 sneaks in a free lunch, but I can't articulate it. If an exact step fails, tell me which one and under which reading. And if there's a version of steps (3)/(4) that is true, explain why it still wouldn't give you step (6).
