(1) A final theory would be one that accounts for all possible observations, past, present, and future.
(2) At any given time, we've only made finitely many observations.
(3) For any finite batch of observations, there are infinitely many incompatible theories that fit that batch and diverge on some future observation.
(4) So at any time, for any candidate theory that fits what we've observed so far, there is an alternative that fits the same observations but makes a different prediction about something we haven't yet seen.
(5) If there is an alternative that fits all the observations we have, we can't rule it out on our evidence.
(6) Therefore, we can never be justified in believing that any candidate theory is the final one — there is always some unruled-out rival.
