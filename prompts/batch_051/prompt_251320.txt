Someone will point out that the genetic code is not a metaphor, it's literally a code: you've got codons as symbols, ribosomes decoding them, a translation table from RNA triplets to amino acids, and a mapping that's arbitrary enough that it can't just be chemistry, so it counts as a real code and not a figure of speech. Then they'll conclude that the genome carries actual semantic information, that a cell is literally executing a program, and that talk of biological "information" isn't loose shorthand—it's the correct description.

Stress-test this for me. How far does the code analogy hold? Give me the explicit mapping first: what plays the role of the symbol, the message, the sender, the receiver, the convention/mapping, the interpreter, error-correction, whatever else matters. Then take it apart: the decoder is itself specified by the same genome, there's no sender or intended recipient, the same transcript can mean different things depending on splicing, RNA editing, reading frame, or cell state, and so on. Which of those disanalogies actually matter for the conclusion that a genome contains semantic information, and which are just cosmetic? Once those are on the table, does the conclusion survive—is "genetic information" literally semantic information after all—or was the code analogy carrying the whole thing? And if it doesn't survive, whats a better analogy for what DNA actually does, one that keeps the specificity and combinatorial structure without smuggling in an author and a recipient?
