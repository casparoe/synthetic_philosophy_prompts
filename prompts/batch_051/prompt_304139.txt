In my logic seminar we've been going through the classic self-reference paradoxes, and I got stuck on something. Yablo's point is usually put like this: you can get a liar-style paradox with no sentence referring to itself, just an infinite chain where each sentence says all the later ones are false. Curry's paradox, by contrast, doesn't even go through negation: from a sentence C that says if C is true then P, you seem to be able to derive arbitrary P using conditional proof, modus ponens, and the usual truth rules. So I want to know whether Curry survives the Yablo treatment. Can you build an infinite, non-self-referential chain, each sentence only talking about sentences further down the chain, that yields an arbitrary P the way Yablo's chain yields a contradiction? If yes, give the construction and run the derivation. If no, say exactly which step of the standard Curry proof breaks when you try to Yablo it, and what Curry-specific feature is doing the work. Keep it under 700 words.
