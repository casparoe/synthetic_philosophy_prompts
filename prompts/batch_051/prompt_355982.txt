I have been thinking about two limitative arguments that look, on their face, as though they belong to unrelated fields, and I want to know whether the structural resemblance I see between them is genuine or merely an artifact of pattern-matching.

The first is Fitch's argument against the knowability principle. Let Kp mean that p is known at some time by some agent, and let the knowability principle say that every truth is knowable: if p is true, then it is possible that Kp. Now take any true proposition q that is in fact never known, so that q ∧ ¬Kq is also true. This conjunction cannot be known. For suppose K(q ∧ ¬Kq); because knowledge distributes over conjunction, we get Kq ∧ K¬Kq; and because knowledge is factive, K¬Kq entails ¬Kq. We therefore get Kq ∧ ¬Kq, a contradiction. So q ∧ ¬Kq is an unknowable truth, which already refutes the unrestricted knowability principle whenever any unknown truth exists. The stronger familiar result is that the knowability principle, together with modest modal and epistemic assumptions, collapses into the claim that every truth is known.

The second is the undecidability of the halting problem. Suppose a program H decides, for any program x and input y, whether x halts on y. Construct a program D that, given as input a specification of a program, halts exactly when H predicts that that program does not halt on itself. Run D on a specification of D itself: D halts on D exactly when H predicts that D does not halt on D, so H's verdict is wrong in both directions, contradicting the assumption that H decides the halting problem.

The parallel I see is this. Each argument constructs a self-undermining object — a truth that includes its own never-being-known, or a program that includes the decider's negative verdict on itself — and then shows that a certain operator cannot coherently apply to that object. Knowledge must distribute over conjunction and be factive; the halting decider is supposed to return a correct total verdict; and each assumption yields a contradiction. The conclusions are also both limitative: unrestricted knowability collapses into omniscience, and unrestricted decidability is impossible.

Is this mapping sound, and where does it break down? In particular, how much should I make of the apparent disanalogy that the halting argument is driven by self-reference on D, whereas the Fitch conjunction q ∧ ¬Kq can be formed from any unknown truth q, with no need for q itself to mention knowledge? If the parallel is deep, does anything transfer between the two settings — for example, does recasting Fitch's argument in terms of diagonalization or fixed points clarify why it works, or does the epistemic case shed light on the role of self-application in the halting proof? If the parallel is superficial, identify the exact point at which the two arguments come apart, and name at least one thing the parallel predicts that turns out false.
