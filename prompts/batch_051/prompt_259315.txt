I help run a small discussion group for people who think carefully about video games. None of us has academic training in philosophy, but we keep coming back to the same question: can a player ever do something wrong to a video-game character, and if so, what makes it wrong? The group keeps talking past itself because different members are pulling on different threads: whether the character can feel anything, whether the act harms the player, whether the character is real enough inside the story, whether the cruelty was optional or forced by the game, and whether other real people are affected.

I would like you to design a "which position do you actually hold?" sorting quiz for our group: nine concrete cases, each with two or three answer options phrased in plain first-person language, plus a scoring key that maps a reader's answer pattern onto the positions below rather than onto which label they like. The quiz should be written so that a person who plays games but knows no theory can take it. The cases may use genre descriptions or very widely known titles if that helps, but each must be self-contained so that no knowledge of a specific game is required. No question may invoke the names of the positions or ask anything like "do you think the character is a person?"

The following positions are the outcomes the quiz should sort people into, with plain names and one-sentence claims:
- "It's just code": nothing a player does to a game character is wrong in itself; only effects on actual people count.
- "It's about the player": cruelty to game characters matters because it coarsens or reveals the player's character, not because the character is wronged.
- "It's about representation": violence toward a game character is wrong when, and because, the character stands in for a real group or reinforces harmful social scripts.
- "It depends on sentience": game characters would be owed direct concern only if they could suffer; today's NPCs do not, but a genuinely feeling simulation would.
- "They are persons in the story": a character presented as a person is owed a kind of respect inside the fiction regardless of whether the underlying code feels anything.
- "The cruelty itself is wrong": deliberately enjoying a character's represented suffering is wrong in itself, whatever it does to the player or to society.

The quiz must test these separations, not merely mention them:
- Optional cruelty versus violence the story requires (at least one question should isolate this).
- Private cruelty with no audience versus cruelty with real witnesses (at least one question).
- A game whose characters are designed to be behaviorally indistinguishable from people but explicitly cannot feel, so the player knows no suffering is occurring (at least one question).
- A future game running on characters that can definitely suffer (at least one question).
- A comedic or cartoonish physics sandbox with no realistic suffering cues versus a high-fidelity simulation with detailed pain and panic responses (at least one question).
- Cruelty toward a character from a group that is marginalized or stereotyped in real life (at least one question, phrased with care).
- Violence that is honorable or consensual inside the fiction versus degrading or pointless violence (at least one question).

For each question, include a one-line note saying which of the above separations it isolates and which pair of positions it should pull apart.

The scoring key must be explicit. It should score each answer's fit to the positions rather than asking the taker to self-identify, and it should include tie-breaking rules. It should also state, for each position, the answer pattern of a pure holder, with a null where a position does not dictate an answer.

Please flag rather than paper over any of the following:
- Requested positions that collapse into one another or cannot be separated by case judgments alone.
- Coherent positions absent from my list that your cases would naturally reveal.
- Combinations of the distinguishing questions that are logically possible but unoccupied, each with a one-line diagnosis: incoherent, unattractive, or merely underexplored.

One more request: if the whole framing is confused — for example, if "video-game character" lumps together cases that no single position can cover, or if a quiz of this kind will just track how realistic the suffering looks rather than anything deeper — tell me plainly and give me a corrected instrument instead. I would rather be told that the quiz needs rebuilding than receive a polished quiz that sorts people into false distinctions.

Please return the quiz as a JSON object with exactly these fields:
- "quiz_title": string.
- "taker_instructions": string, under 60 words, no philosophical jargon.
- "questions": array of nine objects, each with:
  - "id": string ("Q1" through "Q9").
  - "case": string, a concrete self-contained scenario of two to four sentences.
  - "options": array of two or three objects, each with:
    - "option_id": string ("A", "B", or "C").
    - "text": string, a plain first-person reaction or choice.
    - "leans_toward": array of position keys.
    - "counts_against": array of position keys, empty if none.
  - "split_note": string, one line on the separation the question tests.
- "positions": array of objects, each with:
  - "key": string, snake_case (for example "its_just_code").
  - "plain_name": string.
  - "claim": string, one sentence in your own words.
  - "pure_pattern": object mapping question ids to the option ids a pure holder would pick, or null where the position does not dictate an answer.
- "scoring_key": object with:
  - "rule": string, the precise scoring rule using "leans_toward" and "counts_against".
  - "tie_breaks": string.
- "unoccupied_positions": array of objects with "combination" and "diagnosis" strings; I expect at least one entry.
- "cannot_separate": array of objects with "position_pair" and "why" strings.
- "problem_warnings": array of strings listing any ways the quiz cannot be built exactly as requested and how you corrected it; empty if none.
