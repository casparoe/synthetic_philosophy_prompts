Okay so I've been taking a non-major logic course this semester (career change, don't ask) and Russell's paradox has been living in my head rent free. Here is the version we did:

(1) Naive comprehension: for any condition you can state, there is a set of exactly the things that satisfy it.
(2) So there is a set R of all sets that do not contain themselves.
(3) Either R contains itself or it doesn't.
(4) If R contains itself, then R is one of the things in R, so it must satisfy the condition for being in R — namely, not containing itself. So it doesn't contain itself.
(5) If R doesn't contain itself, then it satisfies that condition, so it's in R — meaning R contains itself.
(6) So R contains itself iff it doesn't. Contradiction.

My question: is this argument valid all the way through, or is there a step where it breaks? A kid in my class keeps saying the problem is step (2), because self-membership is incoherent and R never gets defined, but I dont see why self-membership is any sketchier than a sentence that refers to itself. If the argument is valid, does the blame land entirely on (1)? Walk through the steps and tell me which is the first false one, or say outright that the argument is valid and the first premise is the casualty. Please write the answer in American English.
