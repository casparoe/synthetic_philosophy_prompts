I've been trying to write a seminar paper on the outside view in forecasting and I've built an argument that now looks like it proves too much, and I can't locate the bad step. Here's the argument in the form I'd present it:

(1) To estimate how much longer a polity or institution will last, you classify it into a reference class of past comparable polities or institutions and use that class's survival base rates.
(2) If it has already lasted longer than the median lifetime in that class, the base rate says most members of the class were gone by this age, so its expected remaining life should be short.
(3) This move is fully general: for any long-lived institution—banks, universities, churches, firms, states, empires—you can select a reference class of past comparables in which the thing is already past the class median, and the outside view then says it's probably near its end.
(4) So the outside view appears to tell us that almost every old institution around us should be expected to fail soon.
(5) But applied retrospectively, the same method would have written off every institution that in fact survived for centuries—including the very cases that generated it's own base rates.
(6) Worse, if the historical record is full of long survivors that the method would have counted out early, then the base rates drawn from it are biased upward, so the outside view's numbers are polluted by exactly the long tails it refuses to expect.
(7) Therefore either the outside view can't be applied to durable institutions at all, or reference classes do no real work.

I'd much rather keep (1) and (2) and reject (7); I think the outside view is a good tool, and the alternative seems like giving up on base rates entirely. But I don't see how to escape (7) without just refusing to follow the argument. Where does it go wrong, if it does? If I have to reject one step, which should it be, and what does rejecting it cost?
