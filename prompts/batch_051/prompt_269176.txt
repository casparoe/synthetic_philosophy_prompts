ok ive been gnawing on the liar for a while and i want someone whos not going to be nice about it to tell me if this picture is just confused. ive been calling it thermostat semantics. the setup: truth isnt a static property, its an equilibrium of an update rule. you start with a guess about whether a sentence is true, you read what the sentence says, and you adjust: set the sentence true iff what it says is the case. for ordinary sentences like snow is white, every starting guess gets pulled to true immediately, so the sentence has exactly one fixed point and its an attractor. the liar, this sentence is false, has no fixed point at all: start at true, the rule tells you to flip to false; start at false, it tells you to flip back; you just bounce true false true false forever, like a thermostat mounted right next to the heater, overshooting and never settling. the truth teller, this sentence is true, is the opposite: every guess is already a fixed point, so theres one fixed point for each guess and no fact of the matter picks one out. so my actual claim is that the standard question is wrong: we ask whether a sentence has a truth value, but we should ask whether its update rule has exactly one fixed point and whether that point is a global attractor. pathology then comes in at least two flavors: no fixed point, and too many fixed points. i think this also predicts something nice: leave two valued semantics alone for all the single fixed point sentences, add a third status, cycling, only for the no fixed point cases, and let the too many fixed point cases stay undefined. so two questions for an honest assessor: am i just reinventing kripke fixed points or tarskis hierarchy under a dumber name, and where does the thermostat picture actually crack? my own worry is that the update rule quietly smuggles in the word true, so maybe ive relocated the paradox into the rule instead of getting rid of it.
