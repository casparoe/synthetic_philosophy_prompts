Question: Consider a two-person bargaining problem with disagreement point (0,0) and a compact, convex feasible set containing the individually rational points, so that the maximal feasible payoff for each player among individually rational alternatives is positive. Define the Kalai–Smorodinsky solution and explain which monotonicity axiom it was designed to satisfy. Does the Kalai–Smorodinsky solution satisfy strong monotonicity, meaning that whenever the feasible set expands, both players' solution payoffs weakly increase? Justify your answer.

Student answer: The Kalai–Smorodinsky solution first takes the ideal point, whose coordinates are the maximum payoff each player can get among the individually rational alternatives. It then selects the unique Pareto efficient point on the line segment from the disagreement point to the ideal point. Kalai and Smorodinsky introduced the solution to replace Nash's independence of irrelevant alternatives with a monotonicity requirement. The solution satisfies Pareto efficiency, symmetry, scale invariance, and individual monotonicity. Individual monotonicity says that if the feasible set expands but one player's ideal payoff stays the same, then that player's KS payoff cannot decrease. Because the KS solution depends only on the disagreement point and the ideal point, any expansion of the feasible set that raises both ideal payoffs cannot make either player worse off. Thus the KS solution satisfies strong monotonicity, which is the main advantage over the Nash solution.
