The instrument is for a one-page handout in an upper-level course on probability and rational choice, and the reader has not heard of the game. Begin the handout with a short opening note using the following construction.

A fair coin is tossed until it lands heads. If the first heads comes on the nth toss, the player receives 2^n/n dollars when n is odd and pays 2^n/n dollars when n is even. So toss 1 pays +$2, toss 2 pays −$2, toss 3 pays +$2.67, and so on. Because the probability of first heads on toss n is 1/2^n, the expected payout is the alternating harmonic series 1 − 1/2 + 1/3 − 1/4 + ···. That series converges only conditionally: its terms can be rearranged to sum to any real number or to diverge, which is why the game's expected value is usually described as undefined. The Altadena game is identical except that one dollar is added to every possible payout, so it weakly dominates the Pasadena game while still having an undefined expected value.
