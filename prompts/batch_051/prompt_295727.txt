Epistemic logics built on possible worlds with a normal modal operator make knowers logically omniscient: if an agent knows a proposition, and that proposition entails another, the agent thereby knows the latter, and every logical truth is known automatically. Consider five familiar strategies for loosening this idealisation. First, syntactic or sentential models, in which an agent's knowledge is represented as a set of sentences that need not be deductively closed, and in which closure is something achieved, if at all, by stepwise derivation rather than by the semantics alone. Second, awareness models, which retain the usual possible-worlds core but add an awareness function that selects the sentences an agent is actively attending to, so that implicit knowledge may outrun explicit knowledge. Third, impossible-worlds semantics, which adds worlds at which the classical connectives misbehave, so that the transition from p to an equivalent or entailed q need not be valid at every world the agent regards as possible. Fourth, justification logic, which replaces the bare operator with claims of the form that some term t justifies a proposition p, so that knowing p requires possessing a specific piece of evidence or proof, rather than merely standing in a world-relation. Fifth, algorithmic or bounded-resource accounts, which treat the agent as a computing device with limited time, memory, or inference rules, so that what counts as known is what can actually be produced within those limits.

Please sort these five approaches into three tiers according to how well they distinguish an agent who merely has not yet performed a derivation from an agent for whom the transition is genuinely unavailable, while still yielding a coherent formal account of knowledge and inference rather than a mere catalogue of failures. In continuous prose, say why each approach lands where it does, and then identify the cost you are most willing to tolerate in the top tier.
