ok so i'm a software engineer and i've never taken a philosophy class, but i keep running into wolfram's computational irreducibility thing and i cant get it out of my head. the way i understand it: for a lot of systems (rule 30, turbulence, the economy, whatever), the only way to find out the state at time t is to actually run the system forward to time t. you cant skip ahead with some cheap formula or shortcut, because any predictor would have to do about as much computational work as the system itself does. so there's supposed to be a hard limit on how much you can compress a system's behavior into an explanation or a prediction.

meanwhile i spend half my week using trained models as little oracles. a neural net trained on a pile of examples can look at the start of some process and spit out a rough guess about the next state without running the real simulation — learned surrogates for physics sims, code models that "know what this function does" well enough to be useful, that kind of thing. theyre wrong a lot and they hallucinate, but they demonstrably and cheaply shortcut stuff that wolfram's argument says you cant shortcut. so does that kill the argument, or is the argument saying something narrower than i think? specifically: is computational irreducibility a claim about guaranteed exact prediction of a single system youve never seen before, and learned guessers are just amortizing over a training distribution of similar systems, which is a totally different game? if the argument survives, which premise is actually under pressure, and what does a repaired version look like — one that's weaker but still says something real about the limits of explanation now that everything is a learned approximator?
