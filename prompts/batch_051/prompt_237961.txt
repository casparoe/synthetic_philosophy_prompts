My friend summarized Wittgenstein's private language argument for me like this: "Wittgenstein argues that a language only its speaker can understand is impossible, because if no one else can ever check whether you're using a sign the same way from one occasion to the next, then you can't genuinely check it either. Memory is just another private impression, so appealing to it is circular. Therefore words for private sensations, like pain or tickle, are strictly meaningless; or anyway we can never know what someone means by them. Famously, this is his verificationism: an utterance has content only if its correctness can be publicly checked, so claims about other people's inner states are empty." I'm suspicious because I've heard the verificationist reading of Wittgenstein is contested, but the rest of it sounds plausable. Seperate what's accurate, what's a subtle distortion, and what a careful defender of the argument would say about the slide from 'no public check' to 'pain words are meaningless'.
