Lately I have been building an automated negotiation system for a small marketplace where two pricing bots meet exactly once. A colleague who works on program equilibrium insists that if each bot can inspect the other's full source code before choosing an action, then cooperation in a one-shot prisoner's dilemma is guaranteed—with no repetition, reputation, or outside enforcement. He gave the following argument. I find the conclusion too strong, but I cannot locate the sleight-of-hand. Please act as an expert game theorist: before giving your verdict, separate the formal game-theoretic claims from the interpretive claims about what rational agents will do. Then say whether the argument is valid, and if not, identify exactly which step fails and state the strongest conclusion that actually follows. Keep your answer to at most 400 words.

Setup: each bot must choose Cooperate or Defect with the usual prisoner's dilemma payoffs: (C,C) = 3 each, (D,D) = 1 each, and (D,C) = 4 for the defector and 0 for the cooperator. Let C be the program: "Inspect the opponent's source code Q. If Q is exactly this same program in the same source text, output Cooperate; otherwise output Defect." Assume that reading and comparing source texts always terminates and cannot be spoofed.

(1) When C faces C, it sees its own source text as the opponent, so it cooperates; thus both cooperate.
(2) If one player deviates to any different program D, the opponent running C sees that D's text differs from C and defects.
(3) Against an opponent running C, a deviating D can never obtain the mutual-cooperation payoff of 3: if D cooperates, C defects and D gets 0; if D defects, both defect and D gets 1.
(4) So the best a unilateral deviator can get is 1, which is worse than 3.
(5) Therefore no unilateral deviation from (C,C) is profitable.
(6) Hence (C,C) is a Nash equilibrium, and therefore rational agents who can inspect each other's code will adopt C, so one-shot cooperation is guaranteed.

I cannot see the trick in (1)–(5), but (6) seems to prove too much. Is the argument valid? If not, which step fails, and what is the strongest conclusion that actually follows?
