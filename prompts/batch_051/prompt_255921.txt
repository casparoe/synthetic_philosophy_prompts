I keep circling around the Platonia dilemma and would like someone to check an argument about it. Suppose 20 people are each told: if exactly one of you sends a telegram by noon tomorrow, that person gets a billion dollars; if none or more than one of you sends, nobody gets anything; and there is no communication. Now consider this argument that the standard superrational answer, that each should send with probability 1/20, is not actually binding on a rational player:

(1) In a symmetric game of this kind, a rational player should use the strategy that all other rational players will also use.
(2) Since the game is completely symmetric, all rational players use the same strategy.
(3) The only symmetric mixed-strategy equilibrium is to send with probability 1/20.
(4) Fix the other 19 players at that equilibrium probability. If I send, I win exactly when none of them sends, with probability (19/20)^19. If I do not send, I win exactly when exactly one of them sends, which has probability 19(1/20)(19/20)^18 — the same number.
(5) But when the two available actions have equal expected payoff, the probability with which one mixes is not forced; a player is permitted, but not rationally required, to use 1/20.
(6) Therefore the standard superrational answer is not rationally required, and the dilemma has no well-defined answer.

Is this argument valid? If not, exactly which step fails, and what is the strongest reading of that step on which the rest of the reasoning could or could not go through?
