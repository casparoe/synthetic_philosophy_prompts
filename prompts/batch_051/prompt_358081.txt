So I run a small reading group on complex systems, and two of us have been going back and forth for months about what computational irreducibility does to scientific explanation, and we keep talking past each other. By computational irreducibility I mean the claim that for some systems there's no shortcut: the fastest way to know the state at time t is to run the rule forward t steps, and no shorter description compresses the outcome. One person (call them the compressibilist) thinks this puts a hard ceiling on explanation, because an explanation should compress the data, and if the only account available is 'and then the rule iterated a billion times,' you've got a simulation, not an explanation. The other (call them the generativist) thinks thats a false picture: showing the mechanism that generates the outcome is exactly what explanation does, and running the rule just is the explanation.

I want the document they would have produced if they'd spent a year doing a proper adversarial collaboration instead of bickering. Write the joint statement both could sign. It should have: (1) a numbered list of claims both camps accept, about what computational irreducibility itself says, about how prediction differs from explanation, about cases where everyone agrees no compressed account exists, and about what would count as understanding the system. Make these specific, not vacuous. (2) A disagreements table, where each row is one residual disagreement, with the compressibilist's wording and the generativist's wording each written so that side would happily sign it. (3) The cruxes: the sub-questions such that settling one would actually move at least one side. I suspect one crux is whether 'compressible in principle but not by us' differs importantly from 'not compressible at all,' and another is whether we ever accept 'watch this 1000-step simulation' as an explanation rather than a demonstration. (4) For each crux, a concrete system or case both sides agree bears on it, plus what each side predicts. Keep the whole thing under 900 words.
