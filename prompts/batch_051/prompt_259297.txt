Ok so I've been turning Skolem's paradox over in my head for a week and I've managed to compress it into an argument where every step looks unkillable but the conclusion feels like something has gone badly wrong. I need someone to tell me exactly wich step fails, and why.

(1) ZFC is a first-order theory, so by the downward Löwenheim–Skolem theorem, if it has any model at all then it has a countable model; call it M. (Assume ZFC is consistent, so such a model exists.)

(2) ZFC proves Cantor's theorem, so inside M there is a set that M regards as uncountable — the object M treats as the powerset of the naturals, P(N).

(3) But M's entire domain is countable, by construction. So that same object has to be countable too: from outside M we can enumerate the things M regards as its members.

(4) So one and the same set is countable and uncountable. Contradiction. And step 3 isn't optional — the domain literally contains only countably many things.

(5) Therefore either ZFC is inconsistent, or 'uncountable' doesn't pick out any objective, model-independent feature of sets; cardinality talk only makes sense relative to a model, and the whole Cantorian hierarchy of infinities is a formal artifact rather than a fact about some mind-independent mathematical territory.

My reflex is to blame step 4 by saying 'countable' is being used in two different senses — internal versus external, object language versus metalanguage — but I can't make that stick. In the ambient set theory there's a perfectly real function from the naturals onto the extension of M's P(N), so M's P(N) really is countable out there. The model just fails to notice a fact about its own set; how does that defuse the contradiction rather than just relocating it? And is the alternative move — saying M's 'P(N)' isn't the real powerset of the naturals — question-begging, since it presupposes an absolute 'really'? I don't want the history or any citations; I want the precise distinction that breaks the argument, or a flat statement that it's valid if that's what you think.
