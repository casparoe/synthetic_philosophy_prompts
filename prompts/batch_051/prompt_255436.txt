I'm a PhD student in philosophy of math, and I've been trying to write up the structuralist response to the old Benacerraf worry about what numbers are. I built the following argument for a seminar and now I think it proves too much, but I cant find the step to blame. Here it is:

(1) Structuralism says a number like 2 just is a place in the natural-number structure. Everything there is to being 2 is exhausted by its structural relations to the other places: 2 is the successor of 1, the predecessor of 3, less than 3, greater than 1, and so on.
(2) If that's all there is to being 2, then any two things that occupy the second position in a system isomorphic to the natural numbers are the same mathematical object. The '2' in the von Neumann construction and the '2' in the Zermelo construction can't be two different objects, since they have exactly the same structural role.
(3) So if structuralism is true, whether 2 is an element of 4 should get the same answer no matter which set-theoretic implementation we choose to look at.
(4) But it doesn't. In the von Neumann construction, 4 = {0,1,2,3}, so 2 ∈ 4. In the Zermelo construction, 4 = {3}, and 2 ≠ 3, so 2 ∉ 4.
(5) So structuralism seems to imply that 2 both is and isn't an element of 4. That's a contradiction, so structuralism must be false.
(6) The obvious structuralist response is to say that set-membership isn't part of the natural-number structure, so '2 ∈ 4' isn't a well-formed question about numbers at all; it's a question about arbitrary set-theoretic proxies.
(7) But by the same standard, a lot of structuralism's own claims come out meaningless or unstatable: '2 is a position in a structure', 'the von Neumann system realizes the natural-number structure', '2 is not identical to {∅,{∅}}'. None of those are definable in the pure natural-number structure either.
(8) So either structuralism is false, or structuralism is true but can't say what it means without violating its own standard.

I'd like to keep (1) and something like (6) if I can, but I don't see how to have both without either making numbers too thin or quietly bringing back the set-theoretic facts I was trying to get rid of. Which step should I reject, what does rejecting it cost, and how do structuralists usually pay? Also tell me how confident you are in that diagnosis and which point in your answer you're least sure about.
