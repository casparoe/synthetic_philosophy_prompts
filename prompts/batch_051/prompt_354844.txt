I read scripture pretty seriously but I have no training, so I've had to build my own way of deciding which commands are for every culture and which were only for the culture they where written into. My rule is: a command counts as transcultural only if it shows up in several different genres and several different cultural settings. So I treat the head covering stuff as cultural because it's basically one letter to one congregation, and the dietary laws as a change rather than a straight contradiction because they're everywhere in the Old Testament but then get set aside in the New. But then slavery appears across basically every era and every genre, and my rule would force me to call it transcultural, which I can't stomach. So here's what I want to know: is this rule a defensible epistemic shortcut, or is it just a bias with better bookkeeping? Where exactly does it break, and can it be patched so it handles slavery without me just suspending the rule whenever it gives a result I don't like? Or would I be better off abandoning the shortcut and doing it case by case, accepting that I'll be slower and less consistent?
