I've been going back through the frame/outer/inner message distinction from Gödel, Escher, Bach, and I accidentally built an argument that seems to show messages never fix their own interpretation and meaning is really just brute dispositions, which feels like it proves way too much. Help me figure out where the wheels come off, or tell me which premise I have to eat.

Quick setup in my own words, so we're not talking past each other: the inner message is the symbol layer whose meaning is in question; the outer message is whatever tells you how to decode the inner one (that it's English, that it's base64, that it's a forgery); and the frame message is what tells you there's a message to decode at all. The whole appeal of the distinction is that a bare physical string seems to sit there meaning any of a million things until an outer/frame message fixes it.

Here's the argument:

1. A physical string never fixes its own interpretation; the same marks can be a poem, a program, an encrypted bitstream, or noise depending entirely on how the reciever decodes it.
2. So if an inner message has a determinate meaning, the decoding scheme in effect on that occasion has to be indicated to the interpreter somehow.
3. Whatever indicates the decoding scheme is itself a signal, a message-like thing; if it were just a brute cause and not a signal, it wouldn't tell the interpreter anything—it would just make them act.
4. By (1), that indicating signal also fails to fix its own interpretation, so it likewise needs a further signal indicating how to decode it.
5. Iterating, you get a hiearchy of outer messages each needing a higher outer message to get its meaning fixed.
6. But real communication conveys determinate meanings in finite time; nobody hands anybody an infinite stack of decoding instructions.
7. So the chain must bottom out somewhere that isn't a message at all—a habit, a trained neural disposition, a physical regularity.
8. Therefore meaning is ultimately located in those brute dispositions, not in frame/outer/inner messages; the whole message hierarchy is just a story we tell after the fact.

Step 8 is the part I can't stomach. When someone tells me these aren't scratches, this is a recording, play it with a needle, the outer message does real interpretive work—I actually learn how to read the inner message. If meaning were only brute dispositions, that communicative act looks like an illusion. But each of the earlier steps seems plausible on its own, and I can't find the step where the inference breaks.

Which step should I reject, and what does rejecting it cost? If the argument is valid and the real question is which premise is least costly to give up, I'd like to know that too, because I want to keep the intuition that frames and outer messages genuinely determine readings without landing in Step 8.
