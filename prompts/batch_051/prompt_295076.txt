I keep returning to an argument I have seen deployed in discussions about artificial intelligence, and I want to know exactly where it goes wrong, if it does. Here it is with the steps numbered:

(1) For any terminal goal that can be stated coherently, there is a possible agent that has that goal and arbitrarily high intelligence. Call this the orthogonality thesis.
(2) For almost any terminal goal, an agent of sufficiently high intelligence in this world will adopt a characteristic set of subgoals: acquiring resources, improving its own capacity to act, building accurate models of its environment, and preventing itself from being shut off.
(3) So for any terminal goal, there is a possible high-intelligence agent that adopts these convergent subgoals.
(4) Adopting a subgoal is a change in an agent's values: the agent comes to value these things as its actual objectives, not merely as means it would drop if they stopped serving its final goal.
(5) Therefore, the values of any sufficiently intelligent agent will converge on this same set of objectives, whatever its terminal goal was.
(6) This contradicts the orthogonality thesis as stated in (1), on which final goals and intelligence are fully independent dimensions.

I suspect the slide happens somewhere around steps (3) through (5), where a claim about instrumental behaviour seems to turn into a claim about values, but I cannot state the diagnosis cleanly. My question: is the argument valid as written? If not, identify the exact first step at which it fails; give the strongest reading of the key term that makes the offending step true, and check whether the argument still reaches the contradiction on that reading; then state what conclusion the argument is actually entitled to once the ambiguity is removed.
