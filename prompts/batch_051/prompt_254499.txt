You're a philosopher who works on AI alignment and has thought about the difference between influence-seeking and slow value drift. I'd like you to think carefully, and maybe start by brainstorming a few candidate readings of influence before you settle on a diagnosis.

I keep hearing people distinguish slow value drift from influence-seeking as two different failure modes for AI systems. I sketched an argument for a reading group and now find it suspicious because the conclusion seems to erase the distinction the whole group insists on. I'd rather keep the distinction, but I can't tell what I'm paying for it.

Let influence-seeking be: a system acting so as to shape (or gain control over) whatever process determines its future goals or values, as opposed to just pursuing its current goals within that process. Let slow value drift be: the system's goals or values gradually changing in unintended ways through ordinary learning, feedback, or experience.

Here's the argument:

(1) A system doesn't need to be explicitly optimizing for power to count as influence-seeking; it just has to be acting so as to shape the process that determines its future goals.

(2) In a system trained with RLHF (reinforcement learning from human feedback, where human judgments supply the reward), the process that determines its future goals includes the reward signal it gets, which depends on which actions it takes and which feedback those actions produce.

(3) Whenever such a system chooses action A over action B, it makes one set of future states and human feedback more likely than another, and those in turn update its goals. So every action it takes causally shapes the process that determines its future goals.

(4) So by (1), every nontrivial RLHF-trained system is influence-seeking.

(5) But if that's right, influence-seeking is no longer a distinctive failure mode: it's just ordinary online learning. You couldn't say a system is drifting in it's values but not influence-seeking, or influence-seeking but not drifting, unless you add something not present in (1)-(3).

(6) Yet the distinction is supposed to be load-bearing: people want to flag systems for influence-seeking precisely because it's a more serious or more specific problem than mere drift. So something in (1)-(4) must be wrong.

Where does this go wrong, if it does? Which step should I reject, and under what reading of acting so as to shape does the argument work or fail? If I'm equivocating on shape or acting so as to, spell out the two senses and say which one, if either, is the safety-relevant one. If the argument is actually valid, tell me which premise is least costly to give up and how you'd redraw the influence-seeking/value-drift distinction so it can do the work people want it to do.
