I'm a medical-journal editor who handles case reports. A few times a month I receive manuscripts describing recoveries with no accepted physiological mechanism, often attributed to intercessory prayer, a faith healing service, or an unproven remedy. I have about an hour per manuscript to decide whether to send it to peer review or reject it. Publishing a credulous case report misleads clinicians and feeds false hope; rejecting a genuine anomaly buries a signal and draws accusations of editorial bias. I want a reusable screening procedure drawn from Hume's argument about testimony and miracles — not a summary of the essay, not a history of the debate, and not a reading list. The procedure should translate his maxim — roughly, that a report of an extraordinary event should be credited only when it would be more extraordinary for the testimony to be false than for the event to be true — into a checklist or decision sequence a junior editor could run. It should say which distinctions in Hume's argument must survive translation and which can be simplified away; how to estimate prior improbability when there is no usable base rate; how to combine multiple witnesses without double-counting testimony that is merely repeated; how to treat motivated or suspiciously consistent reporters; and which steps are judgment calls dressed up as rules. Then apply the procedure to three representative cases: one where a single prestigious clinician reports a single inexplicable recovery; one where several patients from the same clinic report similar recoveries after discussing them with each other; and one where the event is extremely improbable but the evidence is well documented and the authors have no apparent incentive to deceive. For each case, say what the procedure instructs, what it cannot rule out, and whether it gives an answer an editor would find hard to accept. Throughout, state how confident you are in each recommended step and identify the single point in the procedure you are least sure of.
