ok so we're doing Carroll's tortoise in my philosophy of logic class and I have to write a paper on whether deduction can be justified. I wrote down all the things I think and I'm pretty sure they dont all hang together, but I cant tell where the real problem is. Here's the list:

1. The lesson of the tortoise is that modus ponens is a rule of inference, not a premise. Adding "if P and (if P then Q), then Q" as another premise doesn't help, because you'd still need a rule to apply that premise.
2. Rules of inference aren't the kind of thing that can be true or false. Truth is for propositions; rules are more like moves in a game.
3. If someone asks what justifies modus ponens, any argument I give is going to have to use modus ponens (or something at least as strong), so the justification is circular.
4. Circular arguments are normally worthless, but maybe with the absolute basics -- modus ponens, non-contradiction -- we have no choice, since there's no deeper floor to dig to, and it's still rational to use them.
5. The tortoise's infinite regress isn't really a skeptical problem. It just shows you're making a category mistake: treating a rule as if it were a premise. Once you see the difference, the regress stops.
6. But I also think there is a fact of the matter about which rules are valid. It's not just that we happen accept modus ponens; it's the correct rule for "if".
