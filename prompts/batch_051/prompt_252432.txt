A friend and I have spent the evening arguing about whether the money-pump argument really shows that cyclic preferences are irrational, and the discussion kept returning to a variant I still cannot see all the way through. I would like a careful treatment of it.

Begin with the standard synchronic money pump. An agent has intransitive preferences: A ≻ B, B ≻ C, and C ≻ A. A trader charges a small fee ε to swap a less preferred item for a more preferred one. Starting from C, the agent pays to swap to B, then to A, then back to C, and finishes where it began, poorer by 3ε. The standard claim is that the cyclic preferences are irrational because they leave the agent exploitable in this way.

Here is the variant my friend pressed on me. The agent has perfectly transitive preferences at every moment, but they rotate through a fixed three-phase cycle. In phase 1 the agent ranks A ≻ B ≻ C; in phase 2, B ≻ C ≻ A; in phase 3, C ≻ A ≻ B; then the cycle repeats. The agent knows the schedule and the trader's offers. Assume the gaps between adjacent items are large enough that, at the moment of each offer, the agent is willing to pay ε to move from the lower-ranked to the higher-ranked item. The agent enters phase 1 holding C. In phase 1 the trader sells A for C plus ε, and the agent buys; in phase 2 the trader sells B for A plus ε, and the agent buys; in phase 3 the trader sells C for B plus ε, and the agent buys. The agent ends phase 3 holding C, exactly where it started but poorer by 3ε, having improved its position by its own current lights at every trade.

Does this diachronic variant inherit the force of the synchronic money-pump argument, or does spreading the cycle across time break the charge of irrationality? Work through the standard argument carefully. In particular: (i) Is there a defensible sense in which the agent's temporally extended self has cyclic preferences, and would that be enough to justify the same verdict as in the synchronic case? (ii) Does the diachronic agent have a resource the synchronic intransitive agent lacks—for instance, forming and maintaining a resolution not to trade, or precommitting against its future preference shifts—and is using that resource rational, or is it a form of self-binding against preferences the agent will later sincerely endorse? (iii) How does the verdict change if the phase transitions are unpredictable to the agent but predictable to an informed trader, or if ε is set to zero? I am less interested in a yes-or-no ruling than in knowing what the money-pump argument is ultimately an argument about: local choiceworthiness, the global structure of preference across time, or vulnerability to exploitation.
