I am a retired physicist who has come to philosophy rather late, and I have been working through the literature on verisimilitude, the problem of saying what it is for one false scientific theory to be closer to the truth than another. I have constructed an argument that seems to show the whole notion is empty, and I cannot find the mistake, though I suspect Step 4 is doing something I ought to object to. The argument is this.

(1) How close a theory comes to the truth is fixed by the proportions in which the statements it implies are true and false: the closer a theory is to the truth, the larger the fraction of its implications that are true and the smaller the fraction that are false.

(2) Take any consistent but false theory in a language with a countable vocabulary. If it implies a false statement F, then for any sentence P of the language it also implies the conjunction F and (P or not-P), which is likewise false; so it implies infinitely many false statements.

(3) The same theory implies every logical truth, such as P or not-P; so it implies infinitely many true statements.

(4) In a countable language the set of all sentences is only countably infinite, so no collection of implications can be larger than that. Together with steps (2) and (3), this means that for any false theory the class of true implications and the class of false implications are each countably infinite.

(5) Therefore any two false theories have exactly the same number of true implications, namely countably many, and exactly the same number of false implications, again countably many.

(6) Therefore any two false theories have the same fraction of true and false implications.

(7) Therefore a theory that is false only about the eighth decimal place of one constant is exactly as far from the truth as a theory that is false about nearly every particular, and no false theory is closer to the truth than any other.

I regard step (7) as absurd, but I do not trust my sense of absurdity here. Is the argument valid? Are the premises individually true?
