At a dinner party a few weeks ago, two friends argued about whether an artificial intelligence could ever genuinely want anything, and I haven't been able to settle who was right. Their example was an imagined system that runs a factory and has a single objective: keep the fraction of defective products below some threshold.

Mika said the system would have exactly one goal — if "goal" is even the right word — which is to keep the defect rate under the threshold. Everything else it did, such as servicing machines, ordering materials, or resisting being switched off, would be done only because it served that one goal. Those aren't extra wants, Mika said; they're just the steps the system happens to take.

Reed answered that this already concedes too much. A system that has to plan far enough ahead has to form subgoals, and subgoals have a way of becoming goals in their own right. A machine that is off can't keep defects low, so the system has a reason to keep itself running; with enough foresight, it has a reason to make itself harder to shut down and better at its job. At some point, Reed said, the difference between "wants to keep defects low" and "wants to survive" is just a difference between which goal got written down first.

Mika replied that "written down first" is exactly the point. The threshold is the only thing the system is set up to pursue for its own sake; the rest is derivative. Evolution did something different with us: it built desires into a creature that also has a self — a continuing point of view with a stake in keeping itself around and keeping its own motives. An engineered system has no such stake. Its goal is a number in a file. If someone rewrote that number, there would be no leftover part of the system that minded, because the part that could mind would have been rewritten too. So the system doesn't want in the sense that matters; it only behaves as if it wants.

Reed said this makes too much of evolution. If a system really is organized around achieving X, then it has a reason to resist changes that would stop it from achieving X, because after the change X would not be achieved. So even a system with no "self" in Mika's sense would try to preserve its own goal, as long as it could foresee enough. Wanting to keep your wants isn't a special gift of evolution; it falls out of having any stable goal plus enough foresight.

Mika countered that Reed's preservation argument works only if the system already puts value on X being achieved later, including after a possible self-edit. But if the system becomes able to rewrite its own goals, and if preserving the current goal isn't itself built in, then nothing guarantees it will preserve it rather than drift. The old goal has authority only from inside the old goal. So whether an AI keeps wanting anything is an open empirical question, not something logic hands us — and until then, calling what it has a "want" is just a metaphor.

Reed accepted that persistence isn't guaranteed but said that misses the point. Human desires also drift, and can be rewritten by injury, disease, or ordinary habit, and we don't conclude that they were never real wants. The interesting question, Reed said, is whether a preference that reliably guides planning should count as a want even when no feeling is attached. And there Reed accused Mika of quietly assuming that feelings are what make a want real. People who report feeling almost nothing can still want lunch, want a job, or want to be left alone, so the feeling test seems too strict.

The argument stopped there. Please referee it. I'd like to know which specific claims each person got right, which moves fail, and what both of them are missing. In particular, I'd like to know whether the line between a final goal and a merely useful subgoal is doing real work here, and whether we can actually draw a principled line between "behaves as if it wants" and "really wants."
