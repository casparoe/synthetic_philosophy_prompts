A friend and I spent the evening arguing about whether perfectly rational players could cooperate in a one-shot Prisoner's Dilemma if each could submit a computer program rather than a bare action. We arrived at the following argument, and I cannot tell whether it is sound or where it sneaks in an extra assumption.

Setup: Each player hands a program to a referee. The referee gives each program the source code of the other program, runs the two programs, and pays the standard PD payoffs: mutual cooperation pays 3 each, mutual defection pays 1 each, defecting against a cooperator pays 5, and cooperating against a defector pays 0.

The argument:
(1) Standard decision theory says to defect because a bare move cannot be conditioned on the opponent's move; but a program can make its move depend on what the opponent's program would do.
(2) Consider the program P: on input Q, P outputs C if and only if Q(P) would output C; otherwise P outputs D.
(3) If both players submit P, each outputs C if and only if the other does. By symmetry, whatever one outputs, the other outputs the same.
(4) The pair (C,C) satisfies this condition and gives each 3 rather than the 1 from (D,D). Since both players prefer 3 to 1, the equilibrium outcome among identical P-programs should be (C,C).
(5) Unilateral deviation is blocked: if I switch to a program that always outputs D, the other P sees that my program, run on P, outputs D, so the other P outputs D too. I then get 1 instead of the tempting 5.
(6) Therefore rational program-choosing players will cooperate in the one-shot Prisoner's Dilemma, and the standard conclusion that they must defect is an artifact of forcing players to choose bare moves.

You are an expert on game theory and self-referential programs. Think through this carefully. Is the argument valid? If not, exactly which step fails, and under what reading of the rules? In particular, does the biconditional in step 3 actually single out (C,C), or does it leave the outcome underdetermined? Does mutual defection remain an equilibrium alongside (P,P), and what does that do to the selection claim in step 4? If the conclusion can be repaired, say what the repair must assume about how programs evaluate one another and how equilibria are selected; if not, explain where the standard result reasserts itself.
