I'm writing something on whether neural networks genuinely have representations — the realism-vs-instrumentalism fight in interpretability, not the sci-fi kind — and I want a thought experiment built to order rather than a loose illustration. Use two positions and make them disagree in both directions. First, an operationalist view: a network represents a feature if the feature can be cleanly recovered and locally manipulated — concretely, a linear probe decodes it reliably from activations, and intervening on that direction alone changes behavior. Second, a causal-role realist view: a network represents whatever plays a real role in the computation, even if it's entangled — implemented as an interaction between lower-level features rather than a standalone direction.

Then give me two cases. Case A: operationalist says yes, causal-role realist says no. The mechanism should be a confound: the cleanly decodable, locally manipulable direction is real but encodes something correlated with X (a shortcut, a source-domain label, that kind of thing), and the network never actually computes X itself. So the evidence looks decisive by operationalist standards and the content attribution is wrong by causal-role standards. Case B: operationalist says no, causal-role realist says yes. The mechanism should be an entangled factor: the network does compute X and X does causal work, but only as a nonlinear interaction among other components, so no first-order direction can be decoded by a linear probe and no single direction can be removed to isolate X — removing any one direction either leaves the behavior alone or breaks a bunch of other things at once. Make both scenarios concrete and as mundane as you can (an image classifier with a scanner confound works fine for A; for B something like an irony-sensitive language model or a relational reasoning task is fine).

After the two scenarios, do the check for each case: state what the probe recovers, what the intervention shows, and why each position gives the verdict I requested. Then say which single feature of each case is doing the work, and what would happen if you removed it — does the disagreement collapse, and to what? Then let the defender of whichever view loses in each case push back: what would they say is wrong with the case, or with the other view's criterion? Finally, seperate what's settled from what's genuinely contested here — shortcut learning being a real and documented failure mode is pretty settled, but whether an entangled causal factor deserves to be called a representation is a live dispute — and don't write your read of either case as if it were the consensus.
