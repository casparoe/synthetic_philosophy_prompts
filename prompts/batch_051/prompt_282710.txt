Langdon Winner's argument that artifacts can have politics rested on cases in which a fixed, deliberately engineered object shaped social arrangements before anyone chose how to use it: low-clearance parkway overpasses that kept buses, and the people who rode them, away from certain public beaches, and a mechanical tomato harvester that made small-scale farming uncompetitive. Those are stable artifacts whose relevant properties were specified by designers. Now take a large machine-learning system: its behavior is learned from historical data and changes with retraining, no one specified the properties that produce its social effects, and engineers often cannot state those properties in advance. Does the claim that artifacts can have politics survive this shift? If it does, identify which part of Winner's argument does the surviving work and state the strongest version that remains; if it does not, say exactly which premise fails and whether we should say the system is political in only a weaker, outcome-based sense.
