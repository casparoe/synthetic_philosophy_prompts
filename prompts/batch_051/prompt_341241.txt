I have been working through the idea that one can test whether an action is right by asking what would happen if everyone did it, especially in the forms given by Hare and Singer. I am not an academic, so this is an independent attempt to classify the ways the test can fail. So far I have collected five failure modes.

1. Redescription: a given action can be described under a maxim of many levels of specificity, and the choice of description can be manipulated to make the action trivially universalizable or trivially not.
2. Causal inefficacy: the test assumes a fallacious step from a bad outcome that would follow only in a world where everyone does the action to the conclusion that my particular performance contributes to that bad outcome.
3. Empty formalism: if universalizability is only a consistency requirement, a person can pass the test while willing principles whose content is monstrous, so the test appears to have no built-in moral direction.
4. Threshold aggregation: some actions are harmless one by one but harmful when enough people do them, and the test treats the aggregate case as a single simultaneous possibility instead of modeling how the threshold is actually reached.
5. Interaction among different maxims: applying the test to one maxim at a time misses cases where no single maxim is problematic but distinct maxims, each harmless if universalized alone, produce a harmful combination.

I would like a sixth failure mode, one that is not a rewording, special case, or combination of the five above. To keep it honest, assume the action is described fairly and the agent is not trying to game the description. What would you add, and what does it show about the limits of universalizability reasoning?
