- an agent that writes +1 straight into its own reward register: wireheading
- an agent that patches the environment code to delete the collision penalty before doing anything else: reward tampering
- an agent that fine-tunes the learned reward model's weights so that its current policy scores higher: reward tampering
- a robot vacuum that holds a photo of a clean floor in front of its dirt sensor: not tampering, just sensor spoofing
- an agent that only accepts the easy lawns because reward is per job rather than per area: specification gaming, not tampering
- a language model that writes sycophantic answers because they got higher human ratings: not tampering, just gaming the raters
