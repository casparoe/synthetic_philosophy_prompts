I'm a novelist, not a philosopher, but I'm writing a character who reads some Jain philosophy and uses anekāntavāda to wriggle out of ever having to hold an opinion, so I've been trying to understand the actual machinery instead of just having him say "everything is many-sided." Here's what I keep going round in circles on. The tradition holds that every assertion is true only in some respect — syāt — and it turns that into the sevenfold predication: for any object and property, one can say that in some respect it is, in some respect it is not, in some respect it both is and is not, in some respect it is indescribable, in some respect it is and is indescribable, in some respect it is not and is indescribable, and in some respect it is, is not, and is indescribable. And the claim is that these seven exhuast every possible respect. Now run this argument against it. (1) Anekāntavāda applies to itself, so the claim "the sevenfold predication is exhaustive" is itself true only in some respect. (2) If that claim is true only in some respect, then in some other respect the sevenfold predication is not exhaustive. (3) If there is some respect the seven don't cover, then the sevenfold predication is not exhaustive, full stop. (4) So anekāntavāda, taken as a doctrine about every claim, undermines itself. I half-suspect the Jain response is to point at the "indescribable" predication and say the self-reference gets absorbed there, but that feels like a rabbit out of a hat. Be brutal: does the argument go through, and if not, which exact step is doing the cheating — and what would have to be true of that step for the whole thing to work?
