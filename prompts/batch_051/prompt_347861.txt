Take the one-urn Ellsberg setup: 90 balls, 30 red, and the other 60 blue or green in an unknown mix. Before any draw, people typically prefer a bet on red to a bet on blue, and also prefer a bet on blue-or-green to a bet on red-or-green; no single probability for the blue/green split makes both pairs consistent with expected utility.

Now change one thing: before you place your bets, one ball is drawn, shown to you, and returned. You see it is blue. All bets then concern the next draw from the same urn. Work out how each of the following three agents behaves after this observation, on the two Ellsberg pairs above:

(i) a precise Bayesian with a flat prior over the count b of blue balls (b = 0, ..., 60);
(ii) a maxmin expected-utility agent whose set of priors is the full set of distributions over b, updated by conditionalizing each prior individually (priors that assigned zero probability to the observed draw get dropped, so the b=0 prior is out once blue is seen; for min/max purposes you can just track the point masses);
(iii) an alpha-maxmin agent on that same set, with alpha high enough to reproduce the standard Ellsberg choices before the observation (alpha = 2/3 works).

For each of the three: does it still exibit the original Ellsberg choice pattern after seeing blue, and do any of the three now disagree with the others?

Then suppose you see k blue draws in a row (each ball returned before the next), not just one. Find the smallest k at which the precise Bayesian strictly prefers blue to red. Does the maxmin agent ever prefer blue to red for any k? If not, say exactly which prior in its set is stopping it, and diagnose whether that is a bug in elementwise updating of the prior set or the correct expression of stubborn ambiguity. Finally: what is the smallest change to the setup (the initial set of priors, the conditioning rule, or the decision rule) that would let an imprecise-probability agent actually learn from blue draws, and does that change spoil the original Ellsberg predictions?
