Consider the following argument. Let P be any proposition you are certain is false — say, that water is dry. Let C be the sentence:

(C) If C is true, then P,

where the conditional is read as the material conditional throughout. Assume the usual truth principle that a sentence is true just in case things are as it says. Applied to C, this gives:

(1) C is true if and only if (if C is true, then P).

Now reason as follows:

(2) Suppose C is true.
(3) The left-to-right direction of (1) says that C is true only if (if C is true, then P); so from (2) and (1) we get: if C is true, then P.
(4) From (2) and (3), by modus ponens, P.
(5) Since supposing C is true led to P, by conditional proof: if C is true, then P.
(6) The right-to-left direction of (1) says that (if C is true, then P) only if C is true; so from (5) and (1) we get: C is true.
(7) From (5) and (6), by modus ponens, P.

But P was arbitrary, so this derives every proposition whatsoever. Is the argument valid? If not, which numbered step is the first to fail, and why? If it is valid, then some ingredient of the setup must be given up; say exactly which one, and how rejecting it blocks this derivation.

Finally, consider Yablo's variant. Instead of one self-referential sentence, take an infinite sequence S1, S2, S3, ..., where each Sn says that every later sentence is false — that is, Sn is true if and only if for every m > n, Sm is false. Does your diagnosis of the Curry argument carry over to this sequence? If it does, state where it blocks the corresponding contradiction; if it does not, explain what further move is needed, and whether giving up self-reference alone is enough.
