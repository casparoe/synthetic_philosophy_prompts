Consider the following argument about accuracy-first epistemology, which I find seductive but whose conclusion I do not want to accept. A scoring rule is strictly proper just in case every credence function assigns itself strictly higher expected accuracy than it assigns to any alternative. The Brier rule scores a credence x in a proposition P as 1 − (1 − x)² when P is true and 1 − x² when P is false. Accordingly, relative to a credence c in P, the expected Brier accuracy of adopting credence x is c[1 − (1 − x)²] + (1 − c)[1 − x²] = 1 − c + 2cx − x², which has its unique maximum at x = c.

Now evaluate each step of the following argument.

(1) A rational credence is one that maximizes expected accuracy according to the one true scoring rule.
(2) If the Brier rule is the one true scoring rule, then for any credence c in P, c maximizes expected Brier accuracy relative to c itself.
(3) Therefore, if the Brier rule is the one true scoring rule, every credence c in P satisfies the norm stated in (1): by the standard of the one true scoring rule, c is the expected-accuracy-maximizing option.
(4) Hence, if the Brier rule is the one true scoring rule, every credence in P is rational—however extreme, unresponsive to evidence, or arbitrarily chosen it may be.
(5) Since that cannot be right, the Brier rule is not the one true scoring rule. The same reasoning applies to every strictly proper scoring rule, so no strictly proper scoring rule can be the one true scoring rule.
(6) But accuracy-first epistemology standardly requires the one true scoring rule to be strictly proper.
(7) Therefore accuracy-first epistemology is self-undermining.

Is the argument valid? If it is valid, is it sound? If it is not valid, identify exactly which step or steps fail, and state the principle that blocks the faulty inference.
