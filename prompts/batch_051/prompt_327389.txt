I teach an intermediate game theory course and am writing a problem-set exercise on iterated elimination of strictly dominated strategies when mixed strategies are allowed. Please write one exercise, with a full model solution and a marking scheme out of 20 marks, based on the following two-player normal-form game. Row is Player 1 and Column is Player 2; in each cell, the first payoff is Row's and the second is Column's.

|       | L      | C      | R      |
|-------|--------|--------|--------|
| U     | 3, 2   | 0, 0   | 0, 0   |
| M     | 0, 0   | 3, 2   | 0, 0   |
| D     | 1, 0   | 1, 0   | -1, 5  |

The exercise should require students to (i) carry out iterated elimination of strictly dominated strategies, testing for dominance by mixed strategies as well as by pure strategies, and state exactly where the procedure stops; (ii) compare the outcome with what pure-strategy iterated elimination alone would have delivered; and (iii) explain briefly whether the surviving set yields a unique prediction and what this shows about the difference between dominance reasoning and Nash equilibrium. The model solution should show each dominance calculation explicitly, including the supporting mixed strategy in each case. The marking scheme should distribute all 20 marks among the parts and, for every mark or mark-band, name the specific error it catches (for example, believing that a mixed-strategy test cannot eliminate a strategy unless some pure strategy would already have eliminated it).
