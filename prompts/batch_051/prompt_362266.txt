Here's the student's answer:

Fodor's language of thought hypothesis says that thinking happens in an internal system of mental symbols that has a syntax and a semantics, so thoughts are basically sentence-like. The main argument for it is that you can't learn a language unless you already have some richer mental code to formulate hypotheses in, so there has to be a more basic mentalese that isn't itself learned. Programming languages also have syntax and a kind of compositional semantics, and they are productive and systematic, so in that respect they look pretty similar to a language of thought. But programming languages are public, learned, and designed by people, while mentalese is supposed to be innate and universal, so Python or Java can't literally be the language of thought in Fodor's sense. Still, there's a looser sense where coding does change your thinking: experienced programmers report that they start noticing loops, conditionals, and object hierarchies in ordinary problems, which is a real shift in how they categorize things. I think the best answer is that programming languages are Turing complete, which means they can express any computable function. Since thought is a computational process, any Turing-complete language could function as the language of thought once someone has internalized it. So programming languages aren't the innate mentalese, but they can become an acquired language of thought.
