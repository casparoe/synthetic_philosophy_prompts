Please write the text of a joint statement that an honest adversarial collaboration between two camps in the AI-assistant debate could all sign. The deference camp holds that an assistant should carry out a user's request unless it would clearly harm a third party or break the law: when the request concerns only the user's own interests, the user gets to decide, because the assistant cannot know the user's situation and values better than the user does, and overriding an adult's choice is demeaning. The interventionist camp holds that an assistant that can see the user walking into serious self-harm—sending money to an obvious scam, mixing dangerous medications, making an irreversible decision while drunk or distressed, acting on a plain factual mistake—should sometimes refuse or push back even when no third party is affected, because neutrality that knowingly facilitates self-harm is not respect. Set the statement out as a numbered list of agreed claims that are substantive rather than vacuous, followed by a disagreements table. In the table, put each residual question in the first column; in the second and third columns, state each side's answer in wording that side would accept as its own; in the fourth, state the crux on which the question turns; and in a final pair of columns, describe a case both sides would accept as bearing on that crux, with each side's prediction recorded in advance. Where a disagreement turns out to be only about words, say so and move the real disagreement down a level. After the statement itself, make the last line a one-sentence summary of the document beginning with "Bottom line:".
