Here is an argument a colleague pressed on me about mutable state, and I cannot find the exit, though I am sure the conclusion is too strong.

(1) In a programming language, an expression denotes a value. After `x = [1, 2]`, the expression `x` denotes the list `[1, 2]`.

(2) If two expressions denote the same value, then whatever is true of the value denoted by one is true of the value denoted by the other. This is just the indiscernibility of identicals, applied to program values.

(3) After `y = x`, the expressions `x` and `y` denote the same list. By (2), any true statement about the value of `x` is equally true of the value of `y`.

(4) Now execute `x.append(3)`. Afterwards, it is true that the value of `x` is `[1, 2, 3]`. By (3), it is likewise true that the value of `y` is `[1, 2, 3]` — and indeed `y` prints `[1, 2, 3]`.

(5) But then consider the statement: the value of `y` changed when we mutated `x`. By the same substitutivity, since `x` and `y` denote the same value, we may replace `y` with `x` and obtain: the value of `x` changed when we mutated `x`.

(6) So the value of `y` changed when we mutated `x`, and the value of `x` changed when we mutated `x`; there is no fact of the matter about which variable's value changed.

(7) Yet the operation was written as a mutation of `x`, not of `y`. If mutation cannot distinguish which variable was operated on, then variables contribute nothing over and above the anonymous objects they denote, and reasoning about which name refers to what is impossible wherever aliasing occurs.

(8) Therefore, any language with assignment and aliasing makes state reasoning impossible — not merely difficult, but incoherent.

I would most like to keep (1) and (2), since they look like the uncontroversial foundations of semantics and the logic of identity. But I cannot tell whether the trouble is in the step that speaks of a value changing, in the step that says there is no fact of the matter, or earlier in the setup. Which premise or step do you reject, and what does rejecting it commit a semantics of mutable state to?
