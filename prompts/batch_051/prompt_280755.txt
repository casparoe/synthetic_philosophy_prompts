I've been stalled on my novel in a way that turned into a little theory, and I'd like an honest read on whether it's real or just me re-inventing a wheel with a worse name. I've been calling it "trait windowing." A character trait, I realized, is a disposition, not a constant. My supposedly brave character is only brave when the stimulus matches: she'll run into a burning building but freeze in waist-deep water. That's a disposition with a mask, in the philosophers' sense, if I'm using the word right — the bravery is there but blocked, like a poison with an antidote. But then the actual unit of character isn't "brave," it's "brave-within-a-window": the bunch of conditions under which the disposition can manifest, plus the finks and masks that turn it off or hide it. The writers real job, I've been telling myself, is defining those windows, not the traits.

Here's the stronger claim: backstory's narrative function is to license the windows. A character who's brave in every scene except when the plot needs convenient cowardice feels fake, but if she has a drowning phobia from a childhood incident, then the same cowardice feels like character. The backstory doesn't cause the trait; it legitimizes the mask. This would also mean fictional people are more legible than real people, because a real person has an open-ended set of finks and masks we keep discovering, whereas a fictional person — at least a well-made one — has a finite, authored set, and in principle you could list them all. I like this because it explains why characters feel knowable in a way actual people don't.

I'm not a philosopher, so I want the candid version: is "trait windowing" coherent, or is it just the old nature-of-dispositions stuff warmed over and applied to novels? If it's coherent, where does it break? My main worry is that it makes backstory weirdly instrumental, as if trauma exists only to justify future cowardice, which feels false to how I actually write.
