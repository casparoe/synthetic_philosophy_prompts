I spent my career in biology and have only recently started reading philosophy, so maybe I'm missing something obvious. I keep getting told this commits the naturalistic fallacy, and I'd like to know where. (1) The human kidney has the function of filtering metabolic waste from the blood; that's an ordinary biological fact. (2) If an organ has a function F, and it can't perform F, then it is a defective instance of its kind. (3) If an organ is defective, then, other things equal, there is reason to fix or replace it. (4) Forming beliefs is a capacity whose function is to track truth. (5) A belief-forming capacity that systematically fails to track truth is therefore defective, and by (3) there is reason to correct it. (6) "There is reason to correct it" is an ought-claim, so purely descriptive facts about function have yielded an ought. So the is-ought gap isn't as hard as advertised. Is the argument valid? If not, which step fails? I half-suspect (3) is sneaking something in, but if you say (3) is the problem, give the strongest reading on which (3) is true and say wether the conclusion on that reading is a moral ought or only a hypothetical one.
