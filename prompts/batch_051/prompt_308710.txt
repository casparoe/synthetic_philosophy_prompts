Here's a counterfactual I keep going back and forth on. Imagine a lab actually implements HCH (humans consulting humans) as a real deliberative system: for any query, the system recursively decomposes it into subquestions, and each subquestion is answered by a fresh copy of the same process that sees only its own subquestion, not the parent query or its siblings. Assume the decomposition step is perfect and compute/attention is unlimited, so the only thing being tested is the form of the deliberation itself, not cost. You're an expert on factored cognition and the theory of deliberation. Predict, with your reasoning visible, how the outputs of this system would systematically differ from a single extremely capable agent thinking about the whole problem "in one head" for as long as it wants. I'm especialy interested in the failure modes you'd expect from factorization itself: context too thin at the leaves, subquestions whose meaning shifts when they're cut off from the parent, questions that can't be decomposed without already settling the parent, and value-laden queries where the top-level framing does the real work. Tell me which of these you're most confident are robust, which would mostly disappear if each subquestion got a generous chunk of context, and what would have to be true for the one-head agent to lose. Start by saying what the HCH idealization is supposed to buy, then attack it.
