i'm drawn to the model-theoretic conclusion that there's no absolute notion of uncountability: ZFC is first-order, and Löwenheim–Skolem gives it a countable model if it has any model at all, so the object that model calls "the powerset of the naturals" is countable from outside. but i also can't shake the intuition that Cantor's theorem is about the actual continuum — that there just are more reals than naturals, full stop. the standard line, that "uncountable" only ever means "uncountable relative to a model" and i should stop asking, feels like it overcorrects, because the same compactness tricks seem to make "finite" relative too (a model can think a set is finite while its infinite from outside), and i refuse to accept that whether a set is finite is merely model-relative. so i don't want to be told which side wins. i want to know: what exactly would it take for the absolutist intuition about finiteness, and then about uncountability, to be the thing that goes; what exactly would it take for the model-theoretic relativity claim to be the thing that goes or gets restricted; and is there a stable reading on which finiteness is absolute, uncountability is also absolute, and the Löwenheim–Skolem point is a true but narrower point about what first-order descriptions can pin down? i especially want the part where someone tells me whether the "outside" perspective from which i say "that model is countable" is itself just another model, or something i'm entitled to.
