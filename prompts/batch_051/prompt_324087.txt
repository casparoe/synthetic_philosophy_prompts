I keep feeling like Kim's causal exclusion argument is just the variable-selection problem from regression with heavier terminology. The mapping would go like this: the physical realizer of a mental state is the predictor already in the model, the mental state is the extra predictor, and the behavior is the outcome. If the neural state already predicts the behavior, adding the intention doesn't improve fit, so a modeler drops it for parsimony. Kim's version says the physical cause is already sufficient, so the mental cause would overdetermine, and we shouldn't postulate that. Are these actually the same argument? If I fit a causal model and the mental variable adds no predictive power once the neural variable is in, is that evidence for epiphenomenalism? And if it did add predictive power, would Kim's exclusion worry just evaporate? I suspect the parallel is superficial because causation isn't prediction, but I can't put my finger on exactly where the structure comes apart.
