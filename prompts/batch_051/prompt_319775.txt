I teach a grad seminar on consciousness, and next week we're on higher-order thought theories. I'd like to close the session by reading a short poem out loud, somethign that gives the students the shape of the view to carry home. Write me a sonnet about the Rosenthal-style higher-order thought theory: a mental state becomes conscious not because of how it feels from the inside but because a higher-order thought targets it, roughly the way a spotlight doesn't change the thing it hits but makes it visible. The octave should build that basic picture — a first-order state below the threshold, the higher-order thought pointing at it, consciousness as a relational property rather than a glow inside the state. Then the volta, right where the octave turns, should be the classic objection: if it takes a thought to make a state conscious, isn't the higher-order thought conscious too, and doesn't that start a regress of thoughts about thoughts about thoughts? The sestet should work through the reply — the higher-order thought doesn't need to be conscious itself, since that would only be required if there were yet another thought about it — and the closing couplet should land the upshot: consciousness is a relation between levels, not a property each level must already possess. It should be accurate enough that a philosopher of mind wouldnt wince, and good enough as a poem that it doesn't read like a textbook that got stuck in a rhyme scheme. No name-dropping in the poem itself; it should do the explaining.
