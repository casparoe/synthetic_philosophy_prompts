I've been chewing on this argument about whether a lookup table could be conscious, and I can't decide if it's sound or if one step is cheating. (1) A system is conscious iff it runs the right kind of computation, regardless of what it's made of. (2) Running a computation is just a matter of having the right causal structure: the right internal states, transitions among them, and input-output mappings. (3) Now imagine a huge lookup table wired to behave exactly like me over an entire evening of conversation; if we count all the sensory and motor variables involved, it has the same input-output mapping as I do during that period, and its internal stored entries implement the same transitions. (4) So by (1) and (2), the lookup table is conscious, and its 'aching' or 'seeing red' would be as real as mine. But that feels crazy. Is the argument valid, and if not, which step fails? If it's (3), say exactly what the table is missing when it replicates all the input and output; if it's (2), give a version of the computational view on which (2) is true and say whether (3) and (4) still go through.
