been messing with small transformer models as a hobby and something keeps bugging me. people find a direction in the activations—like a 'sentiment' direction—and immediately say the model represents sentiment. but when i actually zero that direction out, sometimes the model barely changes on anything real; it only looked like sentiment on the probe. other times, killing a direction breaks exactly one kind of thing (say, the model stops handling negation words correctly) while everything else chugs along. i've started calling the first kind 'decorative features' and the second kind 'wiring features,' and my rule is that only wiring features count as the model really representing something; decorative ones are just shadows the training happened to leave behind, not something the model is using. wether that rule survives the obvious counterexample i don't know: if there are three redundant sentiment directions and i delete one, the model is fine, but maybe the feature is still wiring because it sits in a redundant circuit. so my questions are: is this decorative/wiring distinction already a thing under another name, is it just restating causal abstraction, and is 'only wiring counts as representing' too strict—could a decorative feature still be a real representation in a sense worth caring about?
