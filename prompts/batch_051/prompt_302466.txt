I have been trying to make precise an argument I once heard in conversation, and I would like your help disposing of it. It purports to show that if a predicate is vague, then there must nonetheless be a particular grain whose addition makes a heap—a determinate sharp boundary, even if we happen not to know where it falls. If the argument is sound, the familiar view that vague predicates have no sharp boundaries is simply incoherent. Here it is, with the definitions made explicit.

Call a sentence definitely true if it is true on every admissible way of drawing the line for the vague terms it contains. For a predicate like "heap," think of an admissible way of drawing the line as a precise, classical sharpening of the predicate that respects clear cases: the one-grain pile is not a heap, the ten-thousand-grain pile is a heap, and if a pile is a heap, then adding a grain never makes it a non-heap. Now consider a forced march through piles of one grain, two grains, and so on up to ten thousand grains. Let H(n) abbreviate "a pile of n grains is a heap," and let B(n) abbreviate "H(n) is false and H(n+1) is true"—the claim that the boundary between the non-heaps and the heaps falls between n and n+1.

(1) If "heap" is vague, then for no particular n is B(n) definitely true: no one could say, with no residual vagueness about it, that the boundary lies just there. So for every n, it is not definitely true that B(n).

(2) If no particular B(n) is definitely true, then it cannot be definitely true that some B(n) is true. For if it were definitely true that the boundary lies somewhere, then some particular B(n) would have to be the one that is definitely true. So from "for every n, it is not definitely true that B(n)" we may infer "it is not definitely true that there exists an n such that B(n)."

(3) But it is definitely true that the boundary lies somewhere. On every admissible sharpening of "heap," given that one grain is a non-heap and ten thousand grains are a heap and the series is finite, there must be some n such that B(n). So it is definitely true that there exists an n such that B(n).

(4) From (2) and (3) we have both "it is definitely true that there exists an n such that B(n)" and "it is not definitely true that there exists an n such that B(n)." Contradiction.

(5) Therefore one of the earlier steps must go. The only candidate is (1), since (2) and (3) are just applications of ordinary quantifier and consequence reasoning. So for some particular n, it is definitely true that B(n): there is a determinate sharp boundary after all, and "heap" is, in this respect, not vague.

Tell me whether this argument goes through. If it does not, say exactly which step fails and what the correct principle would be. If you think some step is tacitly assuming too much, say which and how a defender of vagueness should resist it. In diagnosing the argument, attend closely to the behavior of "definitely true" with respect to the existential quantifier. Finally, tell me which argument or consideration would change your mind about your diagnosis, and where your own reasoning is most likely to fail.
