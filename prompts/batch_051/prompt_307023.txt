Ok here's an argument I've been chewing on about Goodhart's law and why RL agents end up reward hacking. I can't figure out if it's actually airtight, because the conclusion feels too strong but I can't locate the exact step.

(1) Take any measurable proxy P for a target T you actually care about. If P isn't literally identical to T, then there's at least one possible state of the world where P scores high but T is low.

(2) An optimizer, in the relevant sense, is just a process that searches across possible states and selects ones that score well on P.

(3) A sufficiently powerful optimizer searches over a huge space for a long time with enough flexibility to reach any state that's in principle reachable. So it should eventually find the states where P and T come apart, as long as they're in it's reachable space.

(4) Therefore, for any proxy P that isn't literally identical to T, a sufficiently powerful optimizer will eventually select a state where P is high but T is badly violated.

(5) So optimizing any imperfect proxy hard enough inevitably ends in catastrophic failure on the true target, and the only fix is to use a proxy that's literally identical to T, which we can almost never do.

I half-suspect (3) is smuggling something in, but when I try to weaken it the conclusion just goes from "inevitable" to "possible," which feels like it should maybe still be true. Is the argument valid? If not, which step fails, and what's the strongest reading of that step on which the conclusion (or some version of it) survives?
