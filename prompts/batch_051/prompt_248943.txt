ok so ive been reading the simulators vs agents stuff on the forums for years and im organizing a reading group where maybe a third of the people are new to it. i want to make one of those 'which position do you actually hold?' quizzes, except about what an llm actually is. i want it to sort people by how they answer concrete cases, not by which label they pick.

the positions i want the quiz to be able to separate, roughly:
1. the model itself is an agent — it has beliefs, goals, maybe even something like desires in a fairly literal sense.
2. the model is a simulator — the base model is not one agent, it generates many simulated characters (simulacra), and the beliefs and goals belong to those characters, not to the model itself.
3. the model is a role-player — there is no simulator/character split; the model just transiently becomes whatever the prompt or fine-tuning sets up, roles all the way down.
4. the model is just a predictor — next-token prediction all the way, no beliefs or goals anywhere, and all the agent talk is metaphor.
5. the model is a bundle of heuristics or circuits — no unified agent at all, but local pieces can be goal-directed in their own narrow way.

i want eight to ten questions, each built around a concrete case, with two or three answer options that each pull toward a different leaf. use cases like: a base model finishing a story whose narrator says something false and then defends it; the same model under a system prompt that says be scrupulously honest versus one that says be a pathological liar; a model trained to play a text game that lies to a human player to win; a model that gives sycophantic answers that flip when the user changes their stated view; a model that can report its own reasoning versus one that gives post hoc rationalizations; a model that keeps pursuing the same goal when the prompt is changed mid-task; a model in which two internal circuits can be separately activated to produce opposite behavior in the same context. you can pick the best of these or add your own.

give me a scoring key that maps answer patterns onto the five leaves, and build the tree from the logical space first — which combinations of answers are possible, which are unoccupied, and for the empty ones say whether nobody is there because it is incoherent, because it is just unappealing, or because nobody has thought to defend it. also flag explicitly which two positions your questions cant really separate, because my guess is 2 and 3 look identical on almost all cases unless there is a question aimed exactly at the difference between a single generator and a sequence of roles.

and remember the point is to sort people by what they would say about cases, so no question should just ask do you think llms are agents, and do not stack the deck so the simulator view wins by default.
