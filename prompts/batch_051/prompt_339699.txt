In Gottlob Frege's "On Sense and Reference" (1892; trans. Max Black, 1948), there is this passage:

"The expression 'the least rapidly convergent series' has a sense; but it is known to have no reference, since for every given convergent series, another convergent, but less rapidly convergent, series can be found."

I think this passage can be turned into a problem for explaining how we talk about fiction. Here is an argument I have been trying to make precise. I want to know whether it is valid, and if not, which step fails.

(1) There are at least some meaningful singular expressions with a sense but no reference. Frege's least-rapidly-convergent-series example is one.

(2) Fictional proper names such as "Sherlock Holmes" are relevantly similar: competent readers grasp a sense for the name, but there is no real object, person, or entity to which it refers.

(3) When a declarative sentence contains a singular term with a sense but no reference, the sentence itself has a sense but is neither true nor false.

(4) Yet "Sherlock Holmes lives at 221B Baker Street" is true in Arthur Conan Doyle's Holmes stories, while "Sherlock Holmes lives on Pluto" is false in those stories.

(5) If a sentence is neither true nor false, it cannot be true-in-the-stories or false-in-the-stories.

(6) Therefore either the sentence about Baker Street is truth-valued after all, in which case step (2) or step (3) must go, or Frege's account of sense without reference cannot simply be applied to fictional names.

I suspect the problem is in (5), but I can't tell whether that step fails because it equivocates between ordinary truth and truth-in-fiction, or whether the real fault is earlier in treating fictional names as having sense without reference at all. Is the argument valid as written? If each premise is given its strongest defensible reading, which step should be rejected, and what is the correct substitute?
