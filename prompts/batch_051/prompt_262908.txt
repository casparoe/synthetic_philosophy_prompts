I've been going back and forth with someone about Wittgenstein's private language argument after a thread on whether a system could have genuinely private concepts, and I've got a reconstruction I can't fully trust because I can't see where it overreaches. It's built around the passage in the Philosophical Investigations where he imagines a dictionary that exists only in the imagination and says that looking a word up in it would yield only a subjective justification, since justification normally appeals to something independent. He then considers the objection that I can check one memory against another — like remembering how a page of a timetable looked to check a remembered departure time. His reply, as I read it, is that the second memory would itself have to be correct, and checking one memory against another is like buying several copies of the morning paper to confirm what the paper says.

The argument I extracted goes like this: (1) To mean something by a word for a private sensation, I must be able to use it correctly. (2) To use it correctly, I must be able to tell correct from incorrect uses. (3) The only thing I can consult to tell whether my use is correct is my own memory of the sensation or of how I linked the word to it. (4) But a check that itself cannot be checked for correctness cannot establish the correctness of another memory. (5) My memory of the sensation, or of the original link, cannot be checked for correctness, because there is no independent access to the sensation. (6) So I cannot really tell correct from incorrect uses of a word for a private sensation. (7) Therefore there cannot be a language whose words refer to what only I can access.

I'm prepared to accept that the conclusion is too strong for other reasons — I do talk meaningfully about my own pain, and the phrase same pain as yesterday doesn't feel like a guess. But each step seems plausible when I read it in order. Is the argument valid? If not, which step fails, and on what reading? If a step is doing sneaky work, I want to know exactly which one and whether replacing it with a weaker premise lets the conclusion still go through. As part of the verdict, say what would change your mind: if you think the argument fails, which amendment to premise (4) or (5) would make it go through, and if you think it's sound, which reading of the private language passages would most likely flip you.
