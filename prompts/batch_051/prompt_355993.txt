- Additive: value = c + h. This lets a state with no consciousness (c = 0) still have positive value if it is happy, because the two factors contribute independently.
- Multiplicative: value = c · h. This gives a state with c = 0 zero value no matter how high h is, and it makes a gain in h matter more when c is high.

I can construct intuitive-sounding arguments for each, but I don't know how to determine which rule is the correct one rather than just picking whichever fits the edge cases I happen to find compelling. Are there formal principles, measurement-theoretic constraints, or conceptual arguments that settle whether consciousness and happiness should combine additively, multiplicatively, or lexically?
