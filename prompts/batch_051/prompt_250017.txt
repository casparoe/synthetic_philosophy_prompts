A friend of mine — smart guy, not a philosopher — was holding forth at dinner last night about why minds can't be machines, and he gave me this summary of the Lucas–Penrose line. I half-remember the original papers and I don't trust my memory, so I'd like you to audit his version rather than just rehearse the standard story. Here's roughly what he said:

"Gödel's incompleteness theorem shows that for any formal system there are true arithmetical statements the system can't prove. Now a computer program, no matter how sophisticated, is exactly that: a formal system with fixed rules that grind out theorems. So for any program you give me, I can find its Gödel sentence — a statement the program can't prove but that I, standing outside the system, can see is true. And since I can do this for any program whatsoever, no program can ever replicate my mathematical understanding. Gödel's second theorem sharpens the point: a machine can't even prove its own consistency, while we obviously can. The usual objection that maybe the mind is just a very complicated program we haven't found yet misses the point, because whatever program you propose, the theorem applies to it. So the mind has to be something non-computable."

Something about this feels too strong to me, but I can't put my finger on all the places it goes wrong, and I don't want to misstate the original arguement either. Go through it piece by piece. Which parts would a careful defender of Lucas or Penrose actually accept? Which parts are overstatements or conflations — for instance, does the first sentence hold for any formal system, or only for consistent ones strong enough to encode arithmetic? And does the conclusion that the mind must be non-computable follow from the accurate parts, or does it need extra premises — like that we can know a given program is consistent, or that we can always recognize its Gödel sentence as true? Where exactly does the argument get its force, and where does a mechanist push back?
