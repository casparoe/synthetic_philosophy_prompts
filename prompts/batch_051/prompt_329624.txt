In a lot of the back-and-forth between ML and evolutionary biology people talk as if natural selection just is an optimization algorithm: evolution is gradient descent on a fitness landscape, a population is a batch of parameter settings, adaptations are solutions, mutation is injected noise. This analogy gets used to license pretty different conclusions — some lean on it to say evolution is a stupid optimizer so we shouldnt expect organisms to be optimal, others to say we should copy evolutionary mechanisms to build better optimizers. I want an audit of the analogy itself, not a defense of one side. Make the mapping explicit: what corresponds to what — allele, phenotype, fitness, mutation, recombination, population. Then sort the disanalogies into the ones that matter for those two conclusions and the ones that are merely superficial. In particular, which features of gradient descent as used in ML get quietly imported into natural selection but are not actually there — a fixed differentiable objective, a single trajectory through parameter space, something like credit assignment or backprop, an infinite-population limit, an external loss function? Does either conclusion survive the audit, and is there a better analogy if this one fails? Keep the answer in American English.
