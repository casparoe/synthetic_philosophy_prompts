I've spent the last few weeks trying to get a clean map of every serious answer people have offered to the Meno problem, the question in the Meno about why knowledge is worth more then a true belief that happens to be correct. True belief gets you to Larissa just as well, so the extra value has to come from somewhere else. As far as I can tell, this is more or less the whole menu of strategies. First, the original stability answer: true opinion is like one of Daedalus's statues that won't stay put, and knowledge is worth more because it is tied down by reasoning and therefore stays around to be relied on later. Second, the achievement answer: knowledge is true belief you got through your own competence, so it has the value of an accomplishment, while a merely lucky true belief is like scoring a goal because the ball bounced in off your back. Third, the normative-role answer: knowledge is worth more because it plays a special role in governing what we may assert and what we may permissibly rely on in practical deliberation, a role that bare true belief cannot play. Fourth, the knowledge-first reversal: the question is posed backwards, since knowing is the more basic state and mere true belief should be treated as a derivative or watered-down version of it, so once you start from knowledge the value gap may dissolve rather than need filling.

What I want is one more positive proposal, not a restatement, special case, or combination of any of those four. I already know the swamping problem too, so don't give me that: the objection that if truth is the fundamental epistemic value and the extra ingredient in knowledge is valuable only as a means to landing on truth, then adding that ingredient to a belief that is already true adds nothing, because the truth value swamps it. That's an objection, not an answer, and I want an answer. The new proposal should draw its value from a different underlying source from the ones above (social, moral, practical, aesthetic, whatever seems genuinely different), and then tell me honestly whether it can survive the swamping problem, dodge it, or collapses under it.
