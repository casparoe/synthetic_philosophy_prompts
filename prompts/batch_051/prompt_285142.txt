I'd like an audit of my views on talk about fictional names, because I'm not sure they hang together. Here is the package.

(1) Proper names are directly referential: the semantic contribution of a name is just the object it stands for, and if there is no object, the name contributes nothing for the rest of the sentence to work with.
(2) 'Sherlock Holmes' is an empty name; there is no such person and no referent.
(3) 'Sherlock Holmes is a detective' is true. It is the kind of sentence one can straightaway know and assert.
(4) 'Sherlock Holmes does not exist' is also true, and it is substantive—not merely a comment on how we use the name.
(5) Existential generalization is valid: whenever 'a is F' is true, 'something is F' is true as well.
(6) Still, I do not think that accepting 'Sherlock Holmes is a detective' forces me to believe in a detective. We can talk about what is true in a story without adding extra objects to the world.

Does this set hang together? Go through the pairs that might pull against each other, rate how severe each tension is, say what the cheapest repair would be and what it would cost, and separate the merely apparent tensions from the genuine ones. Then tell me which single revision would do the most to make the whole package stable, and why.
