The usual animal-welfare line is that if you're gonna eat meat anyway, beef beats chicken: one steer provides alot of meals while a chicken provides only a couple, so a chicken-based diet kills far more animals per plate. Now add crop deaths to the picture. Broilers eat grain and soy, so each chicken carries a share of the field animals killed growing that feed. A grass-finished steer mostly grazes, but a feedlot steer is grain-fed too, at a much worse feed conversion ratio. Work through how this changes the beef-vs-chicken comparison. Does the standard verdict survive, or does it only survive for grass-fed beef? What sort of numbers for feed conversion, crop deaths per acre, and finishing systems would flip the comparison one way or the other? Finally, say how the analysis changes if you treat a wild animal's death as unambiguously bad, versus if you think many wild animals live such brief, brutal lives that being killed at harvest might be no loss at all.
