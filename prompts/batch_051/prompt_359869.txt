I keep seeing the user-illusion view of consciousness summarized like this: consciousness is like a computer desktop, a simplified interface that hides all the messy stuff underneath. But I feel like either the metaphor is broken, or the view is way weaker then people make it sound. A desktop interface isn't a lie—the folder icon really does let me open actual files; it just hides the machine code and circuits. So if consciousness is like a desktop, wouldn't the only illusion be that we're wrong about the underlying machinery, while the experiences themselves are admitted to be real? And doesn't the computer analogy smuggle in a real user sitting at the keyboard, which is exactly the sort of inner little person the view is supposed to eliminate? I can't tell what the claim is actually denying: the experiences themselves, the self, or just our impression that introspection shows us how our own minds work.
