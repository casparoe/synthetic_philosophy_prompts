Setup: the one-shot Prisoner's Dilemma has these payoffs. Both cooperate: 3 each. One cooperates while the other defects: the defector gets 5 and the cooperator gets 0. Both defect: 1 each. Both players know the payoff matrix and both are rational in the usual sense.

Here is the argument:

(1) In the standard one-shot Prisoner's Dilemma, each player chooses Cooperate or Defect without seeing the other's choice. Since Defect strictly dominates Cooperate for each player, a rational player defects, and mutual defection is the only Nash equilibrium.

(2) Now change one thing: each player submits source code instead of a bare move. Each program is run with two inputs: its own source and the opponent's source. The program outputs C or D, and payoffs are the numbers above. To keep things well-defined, stipulate that a program that fails to halt counts as having output D.

(3) Define the program P as follows: "If the opponent's source is textually identical to my own source, output C; otherwise output D." If both players submit P, each instance sees an opponent source identical to its own, so both output C.

(4) P is a best response to itself. Against an opponent running P, any program that is not textually identical to P causes the opponent's P to output D. The best such a non-identical program can then do is also output D, yielding 1, which is worse than the 3 obtained by submitting P. So no deviation improves.

(5) Therefore (P, P) is a Nash equilibrium in which both cooperate.

(6) So the standard claim that a rational player must defect in the one-shot Prisoner's Dilemma is false: once players can commit to transparent programs, cooperation is rational, and the usual case forces defection only because each move is an opaque action rather than an inspectable program.
