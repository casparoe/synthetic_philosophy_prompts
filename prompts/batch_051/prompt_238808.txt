I have been trying to make satisficing precise as an ideal of bounded rationality, and an argument I wrote for a discussion group now seems to prove too much. I want to know which step to reject before I build anything on it.

The setting is a sequential search problem. An agent encounters options one at a time, and inspecting the next option has a cost in time and attention. A satisficing agent fixes an aspiration level t and takes the first option whose assessed quality is at least t. A maximizing agent instead keeps searching until the expected gain from one more search falls below the marginal cost of searching. The underlying question is whether the satisficer's threshold can be justified without secretly turning the satisficer back into a maximizer, and whether any stopping procedure can be justified at all.

Here is the argument.

(1) Any procedure for solving a sequential search problem must include a stopping rule: a function from the agent's current information state to either "continue searching" or "stop and choose."
(2) A stopping rule is justified only if, at each point where it says to stop, stopping maximizes expected utility relative to continuing.
(3) Applying (2) requires knowing the expected value of further search: what continuing might turn up, with what probability, and what acting on those findings would be worth.
(4) The expected value of further search is not given to the agent; the agent can determine it only by performing more search, this time over the possible outcomes of the search itself.
(5) So the agent needs a second-order stopping rule governing the search it uses to estimate the expected value of first-order search.
(6) The same reasoning applies to the second-order rule, then to a third, and so on: justifying any stopping rule requires first justifying the rule by which one stops evaluating stopping rules.
(7) Therefore no stopping rule, including any satisficing threshold, can be justified by the only standard that could justify one.
(8) But that conclusion is too strong. Some stopping rules are plainly more reasonable than others, and the difference between a sensibly chosen threshold and an arbitrary one cannot be an illusion.

So I am left with a conclusion I cannot accept and a chain I cannot yet break. If forced to choose, I would rather keep (2) than any of the later steps: deliberation has costs, and those costs must enter the justificatory picture somewhere, presumably as expected costs weighed against expected gains. But keeping (2) seems to force the rest. Which premise or step do you reject, and what does rejecting it cost?
