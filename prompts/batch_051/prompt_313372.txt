Imagine an epistemicist and a supervaluationist about vagueness actually sat down for a good-faith adversarial collaboration, instead of the usual seminar shouting match. Their shared material is a sorites series: 1 grain is clearly not a heap, 10,000 grains clearly is a heap, and you add one grain at a time. Quick characterizations so it's clear what I mean: the epistemicist holds that there realy is a sharp cutoff in that series — some exact n is the last non-heap — and each sentence 'n grains is a heap' is true or false even for borderline n, but we can't know which; the supervaluationist holds that 'heap' is semantically unsettled between many admissable sharpenings, so a sentence can be true on every sharpening (true), false on every sharpening (false), or true on some and false on others (borderline), and a borderline one is neither true nor false even though all classical tautologies still hold. Write the actual document these two could both sign, not an essay about their views. First give a numbered agreed-claims section: substantive claims they agree on about the endpoints, about exactly what goes wrong with the sorites induction step, and about the borderline region — don't paper over cracks. Then give a disagreements table. Include rows at least for: whether every instance of 'n grains is a heap' has a truth value; whether a true statement like 'there is a first n at which the heap begins' has to have a determinate witness, and the parallel question whether a true disjunction can lack a true disjunct; what the source of the cutoff is — a hidden fact vs semantic indecision; and what competent speakers are committed to about the cutoff. For each row, first give each side's preferred wording of the disagreement, then name the crux, then give one test, argument, or case both sides would accept as bearing on the crux, with each side's prediction recorded in advance. Finally flag any places where the two of them were mostly talking past each other rather than disagreeing.
