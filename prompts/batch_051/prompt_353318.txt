In a finite two-person game with complete and perfect information, players A and B alternate moves. At each decision node, the mover either Takes, ending the game with a specified payoff, or Passes to the next node. Payoffs for taking are as follows: A at node 1 takes for (5,1); B at node 2 takes for (3,6); A at node 3 takes for (7,3); and B at node 4 takes for (4,9). If B passes at node 4, the game ends at (11,5).

Now evaluate the following argument for the conclusion that the game ends immediately.

(1) If node 4 were reached, a rational B would Take, because 9 exceeds 5.
(2) If node 3 were reached, A, knowing that B is rational, would expect to receive 4 after passing; because 7 exceeds 4, A would Take.
(3) Repeating this reasoning backward: if node 2 were reached, B, knowing that A is rational, would expect 3 after passing and, because 6 exceeds 3, would Take; so at node 1, A, knowing that B is rational, would expect 3 after passing and, because 5 exceeds 3, would Take.
(4) Therefore, if the rationality of both players is common knowledge, play ends at node 1 with (5,1), even though both players would do better if the game reached (11,5).

Is this argument valid as stated? If not, say exactly which step fails and under what reading of 'common knowledge of rationality' it would be repaired. If it is valid, explain what it commits us to at nodes 2 and 3, given that reaching those nodes would contradict the very reasoning being applied there. State any stronger assumption the conclusion requires.
