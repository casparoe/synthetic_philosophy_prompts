I'm TAing an upper-level course on paradoxes and the semantics of truth, and I need a second pair of eyes on a take-home answer. Here's the question I set and one student's answer. Give it a mark out of 10, and then give me the specific comments you'd write on it — not just a general impression, the actual point-by-point corrections, including anything the answer gets subtly wrong or overstates. Dont pad it with praise; I need to know whether they actually see the difference between Curry and a glorified liar.

Question:

Curry's paradox and Yablo's paradox.

(a) State the Curry sentence and run through the derivation of an arbitrary proposition P from it, as carefully as you can.
(b) What exactly makes Curry different from the ordinary liar paradox — what logical resources does each one actually use?
(c) Describe Yablo's construction.
(d) What should these two paradoxes together make us blame for the semantic paradoxes: self-reference? negation? bivalence? the T-scheme? Explain your answer.

Student answer:

Curry's sentence is C: "If this sentence is true, then P," where P is arbitrary — say, "the moon is made of Gruyère." By the T-scheme, C is true iff (if C is true then P). Suppose C is true. Then by the T-scheme the sentence "if C is true then P" is true, and modus ponens gives P. So on the assumption that C is true we've derived P, which means the conditional "if C is true then P" holds outright. But that conditional just is C, so C is true. Then modus ponens again gives P, unconditionally. And since P was arbitrary, any sentence at all follows.

Curry is importantly different from the liar. The liar works by forcing a sentence to be both true and false and then letting explosion do the rest, so it leans on negation and non-contradiction. Curry doesn't do any of that. It never derives a contradiction and it never uses a negation; it shows that a truth predicate combined with a completely ordinary conditional and modus ponens trivializes the language all by itself.

Yablo constructs an infinite sequence S1, S2, S3, ... where each Sn says "all later sentences in the sequence are false." Assume for reductio that Sn is true. Then every later sentence is false, so Sn+1 in particular is false. But Sn+1 says that all sentences after Sn+1 are false, and that is exactly what follows from our assumption. So Sn+1 is true as well — contradiction. Therefore no sentence in the sequence is true. But if no sentence is true, then in particular all the later sentences are false, which is precisely what each Sn says, so each Sn is true — contradiction again. The payoff is that no sentence in the sequence refers to itself, so the whole construction is free of circularity. Yablo's point is that the liar family doesn't need self-reference at all.

Together Curry and Yablo triangulate the blame pretty cleanly. Curry shows it's not really about negation, since it never touches negation. Yablo shows it's not really about self-reference, since nothing in his sequence refers to itself. What's left is the T-scheme and bivalence, and both paradoxes would just dissolve if we let paradoxical sentences take a third value — neither true nor false. So the lesson is: keep the T-scheme, keep the conditional and modus ponens untouched, but give up the idea that every sentence is determinately true or false.
