I've been messing around with probes on some toy transformers and I've landed on a view I want a verdict on. I call it the Linear Readout Criterion: a net has a representation of a feature X exactly when a plain linear probe can be trained on its activations to recover X better than chance. If a linear probe can read it off, the feature was already in the layer; if you need a deep nonlinear probe, than the probe is constructing the feature, not discovering it. So representations are a fact about the geometry (there's a direction for X), not about behavior — a model could act as if it uses X while actually using a proxy, and it could have X sitting in a layer but never use it for anything. A chess model represents 'one move before mate' if a linear probe detects it; a language model represents subject–verb agreement only if some layer linearly seperates agreeing from violated sentences. I know people say probes just find whatever you train them to find, but this feels like it draws the line in the right place. Give me the three hardest objections to making linear decodability the test for representation, and tell me whether this is just a version of something already out there under a name I don't know.
