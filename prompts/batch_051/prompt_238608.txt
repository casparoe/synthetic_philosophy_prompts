I've been defending a view in mechanistic anomaly detection, and I want to know how exposed it is. Setup: you model some system — a gene regulatory network, a supply chain, whatever — as a mechanism with components and causal arrows, and you want to flag when new behavior is anomalous because it comes from a different mechanism rather than the same one in different conditions. My view: sameness of mechanism just is sameness of causal structure — same nodes, same edges, same functional form of the equations. Parameter tweaks, initial conditions, background shifts don't make a new mechanism; only adding or removing nodes, rewiring edges, or changing functional forms do. So anomaly detection should hunt for structural differences and treat pure parameter drift as noise.

Now tell me what would count against this. Not the first obvious objection; I want a map of my actual exposure. Which cases would force me to admit that a parameter change really can amount to a new mechanism — a rate constant crossing a bifurcation, a sign flip that changes what a component is doing, a regime shift where the same equations stop being a good description of the system? Which formal or modeling results show that "same causal structure" is itself underdetermined by any data we could ever collect, say through realization equivalence or degeneracy, where different structures produce identical input–output behavior? Which of these would a defender of my view have to grant as a genuine cost, and which could they wave off as changing the subject? Rank the defeaters from fatal to merely awkward. And tell me honestly wether the view has by now been qualified into unfalsifiability, and whether that matters for something that's supposed to guide detection practice.

I'd personally be most moved by cases where a parameter shift and a structural change are behaviorally indistinguishable on all possible data, or where the same/different-mechanism line turns out to be relative to a grain of description. If the whole framing is off — if "same mechanism" is the wrong unit and anomaly detection should track something else — say so plainly instead of humoring me.

Format: (1) The strongest defeaters, two or three of them, each with a sentence on how it bites (~150 words); (2) What I can concede versus what I can dismiss (~150 words); (3) A ranked verdict from fatal to awkward (~100 words); (4) Whether the position is insulated, and if so whether that's a problem (~75 words).
