I have been going back and forth with a friend who works in a molecular biology lab, and we keep talking past each other. He insists it is no metaphor that DNA contains information: the genetic code is a literal code, a mapping from nucleotide triplets to amino acids implemented by tRNA and the ribosome, and a fixed lookup table is exactly what a code is. I want to say this is loose talk — that codes are things agents devise to carry messages, and that DNA is causal machinery that happened to get called a code because the metaphor was useful. But when I try to make that objection precise, I find I cannot state a defensible line between a code and a mere causal mapping. I have come to suspect that code is one of those words whose ordinary use is confident but whose definition is contested.

So I would like a working definition of a code: not a dictionary report, but a principled criterion that can settle our argument. Here are the cases I want it to handle. Clearly codes, to my ear: Morse code, the ASCII character encoding, and a substitution cipher. Clearly not codes: the moon's gravity raising the tides, and a sun-warmed rock whose heat is just an effect of the sunlight. The cases I actually care about, on which I do not trust my own intuitions: (i) the mapping from nucleotide triplets to amino acids in a cell, (ii) a Python source file that a compiler translates into machine code, (iii) a blueprint for a house, (iv) a recipe for baking bread, (v) the pattern of tree rings that records each year's rainfall, (vi) the wiring signal by which a thermostat switches on a furnace, and (vii) ordinary spoken English. I also half-suspect that code does two jobs — an encoding scheme for converting one thing into another, and a set of instructions or rules — and that the interesting question is which job DNA does, if either. If you think so too, say how the cases split between the senses.

Run your proposed definition through all of the cases, say exactly where it gives a verdict that clashes with ordinary usage, and then either revise the definition or defend the surprising verdict. Please end with your final one-sentence definition in the form \answer{your definition}.
