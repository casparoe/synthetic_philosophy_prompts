A friend of mine has been running a game theory reading group, and last week they went through this "program equilibrium" setup, and now he won't stop pushing an argument built on it that I can't shake even though the conclusion is obviously wrong. The setup: a one-shot Prisoner's Dilemma with the usual payoffs — 3 each for mutual cooperation, 1 each for mutual defection, and if one defects while the other cooperates the defector gets 5 and the cooperator gets 0. The twist is that players don't choose actions: each submits a computer program, and the program is run with access to both programs' source code, so it can condition its move on exactly what the other program is (and on its own source too — assume the usual quine trick, and assume every program terminates and outputs either Cooperate or Defect). In this setting, define C as the program that cooperates when the other program's source is exactly C's own source, and defects otherwise.

His argument:

(1) If I submit C and you submit any program other than C, then C defects against you, so you get 0 if you cooperate and 1 if you defect — at most 1.
(2) If you submit C, then each program sees its exact twin and cooperates, so you get 3.
(3) Therefore your unique best response to C is C itself; anything else is strictly worse.
(4) So (C, C) is a Nash equilbrium.
(5) But since C is the unique best response to C, and an equilibrium requires each program to be a best response to the other, C is the only program that can appear in any equilibrium — so (C, C) is the unique Nash equilibrium of the whole game.
(6) That can't be right, because DefectBot, the program that defects no matter what it sees, played against itself is also an equilibrium: against a program that always defects, defecting is a best reply and still nets you 1.

Every step sounds fine when I read it alone, but the conclusion is that mutual defection isn't an equilibrium, which is obviously false. So the argument must slip somewhere. I want to know exactly where it goes wrong, why that step looked so natural, and what rejecting it commits us to — in particular, what the right way is to think about equilibrium and equilibrium selection in these open-source games. Please be careful to separate the parts of your answer that are just the math of checking equilibria from the parts that are genuinely disputed among people who work on this, rather than presenting a contested view as the settled one.
