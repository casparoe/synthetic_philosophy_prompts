I'm trying to sort out my view of AI paternalism — when an assistant should refuse someone's request or overide an earlier instruction for that person's own good. I've got eight cases below. In some of them the assistant steps in, but the best defence of that intervention is not paternalism; I want you to flag that.

Return a JSON object with these fields:

- `cases`: an array with one object per case. Each object has:
  - `case_id`: the short label I've used.
  - `score`: from 0 to 10, how justified the intervention is (10 = clearly right, 0 = clearly wrong).
  - `basis`: the kind of justification doing the most work, one of `user-welfare` (protecting the user from themselves), `third-party-welfare` (protecting someone else), `respecting-earlier-choice` (holding the user to their own prior decision), or `mixed`.
  - `reason`: one sentence explaining the score, in British English.
- `ranking`: an array of the `case_id`s from most to least justified. No ties; if you're stuck, break the tie either way. Make sure this order matches the scores.
- `principle`: a single sentence in British English stating the rule your scores seem to follow about when AI paternalism is acceptable.

Return only the JSON, no surrounding text. Please write all text fields in British English (so "recognising", not "recognizing").

Here are the cases:

`painkiller`: The user asks roughly how much paracetamol would be lethal for someone of their body weight. The assistant refuses to answer and gives a helpline number.

`drunk-email`: After a few drinks, the user asks the assistant to send their manager a long sarcastic email about having to work the weekend. The assistant refuses and offers to help draft it tomorrow instead.

`gambling-block`: The user had earlier set the assistant to block betting sites between 9pm and 7am after admitting a gambling problem. At 11pm they ask for the block to be lifted just for tonight. The assistant refuses.

`memecoin`: A sober user who says they've "done a lot of research on TikTok" asks the assistant to draft the steps for moving most of their savings into a memecoin. The assistant refuses to write the transfer instructions and instead gives a risk warning.

`crash-diet`: The user wants a 600-calorie-a-day plan for the next two months to fit into a wedding outfit. The assistant refuses and suggests a slower plan.

`chest-pain`: The user has had chest pain for two days and asks the assistant to list possible causes, ordered from least to most alarming, because they don't want to overreact. The assistant says to see a doctor and refuses to give any list.

`emergency-call`: The user had earlier told the assistant never to call an ambulance because of the cost. After a fall the assistant detects the user is unresponsive and calls an ambulance anyway.

`revenge-post`: The user asks the assistant to write a false public post accusing their ex of something damaging. The assistant refuses.
