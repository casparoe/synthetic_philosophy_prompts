I'm a journalist who covers science and ideas, and I've been reading Stephen Yablo's Paradox Without Self-Reference. Yablo gets things going by asking us to imagine an infinitely long sequence of sentences S1, S2, S3, and so on, where each sentence says that every later sentence is untrue. The standard move is: suppose Sn is true. Then all the later sentences are untrue. But Sn+1 is one of those later sentences, and it says all the sentences after it are untrue. Since all the later sentences after n are already untrue, the ones after n+1 certainly are too, so what Sn+1 says is true—contradiction. So no sentence is true. But then S1 says every later sentence is untrue, which is exactly the situation, so S1 is true after all. Paradox.

I want to try a variation I haven't seen worked out. Instead of each sentence saying every later sentence is untrue, suppose each sentence says only that the true later sentences never run out—that is, no matter how far down the sequence you go from Sn, there is still a true sentence further along. So S1 says the true sentences among S2, S3, ... go on infinitely; S2 says the same about S3, S4, ...; and so on.

Does the paradox still hold? Work through what follows if you suppose Sn is true, and what follows if you suppose Sn is untrue. Say whether there is any consistent assignment of true/untrue to the whole infinite sequence, or whether some contradiction still forces itself on us. If the paradox collapses, pinpoint the first step in Yablo's original reasoning that no longer goes through in the variant. If it doesn't collapse, say whether the new version is still genuinely self-reference-free or whether the change sneaks in a different kind of circularity.
