After a long argument with a friend about whether a legislature could make a statutory code so precise that judges would become mere calculators, my friend produced the following argument; neither of us wants its conclusion, but I cannot locate the error.

(1) Suppose there is a finite, consistent legal code whose application to any case is a matter of proof from the code's rules. (2) Encode the code's symbols, sentences, cases, and proof sequences as natural numbers in the usual way, so that claims about what the code proves become arithmetical claims. (3) Since the code can be given a finite set of axioms and inference rules — otherwise it could not be applied mechanically — it is a formal system. (4) Its language is rich enough to express elementary arithmetic, since it contains dates, quantities, money, ages, and the numbers of its own provisions. (5) By Gödel's first incompleteness theorem, then, if the code is consistent, there is a sentence G, constructed from the code's own coding, that says of itself that it is not provable in the code; G is true but not provable in the code. (6) A human judge who understands the coding can see that G is true, because if G were provable in the code it would be false. (7) Therefore, for any such code, there is a truth within the code's own language and subject matter — a truth about what the code proves and decides — that the code cannot prove but a human judge can. (8) So no complete mechanical legal code could eliminate judicial judgment.

But this seems to prove too much: the same argument would apply to a human judge's own deliberative processes if they are physical and finitely describable, implying that every judge also outruns every formalization of herself. Which step should be given up, why did it look so plausible, and what is a corrected statement of what Gödel's first incompleteness theorem does and does not show when exported beyond mathematics?
