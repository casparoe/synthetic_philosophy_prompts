Consider the ship of Theseus, but make the ship a computer program. Suppose a program is released under a copyleft license, so that anyone who distributes a derivative work must release the whole thing under the same terms. Over several years, a company replaces every source file one at a time: each new file is written from scratch by people who have studied what the old file does, and after each replacement the program still passes the same tests. At the end, no original line of code remains, but at no point did a complete new program exist alongside the old one. Is the finished program a derivative work of the original? Does the answer change if the company instead writes a plain-language description of the program's observable behavior, hands it to a separate team that never sees the source code, and has that team build a program matching the description? Work through how the familiar answers to the ship puzzle—identity as shared history, identity as current structure, and the view that the question has no definite answer—do and do not line up with the legal notion of a derivative work, and say where the analogy breaks.
