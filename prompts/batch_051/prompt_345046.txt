Is there a name for this? I keep seeing people argue about a familiar word — "planet", "woman", "marriage", "racism" — where they start by granting that the word is vague or contested or carries bad baggage, but then, instead of trying to report how it's actually used, they argue we'd be better off using it some new way (neater boundaries, better political effects, more scientific). Then a few paragraphs later they write as if they'd discovered the thing's real definition, and treat anyone using the old sense as confused rather than simply pursuing a different goal. It isn't plain stipulation — nobody says "let's agree to use X to mean..." — and it isn't plain analysis of what people already mean, because existing usage keeps getting overruled whenever it clashes with the proposed one. Is there a settled label for that move, and if there are several neighbouring labels in the literature, can you sort out which fits and where the edges are? I'm not really after a name so much as the carving: how is this different from coining a new technical term, from a dictionary merely recording a shift in usage, and from just insisting everyone else is misusing the word? And which feature of the case pushes it toward one thing rather than another?
