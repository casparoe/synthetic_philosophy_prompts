I have been working through the game-theoretic idea of program equilibrium, in which two players in a one-shot prisoner's dilemma each submit a program, the programs are allowed to inspect one another's source code, and cooperation becomes stable without contracts or reputation. The standard illustration is a program that says, in effect, cooperate just in case the other program is exactly this program, and defect otherwise.

I have a distinction I keep reaching for and want subjected to a stress test. I call a program equilibrium shallow when the cooperating programs are checking only the literal code of their counterparts — for instance, scanning for whether the other code contains a conditional that says it will cooperate against this very program. I call it deep when each program verifies what the other would actually do across a range of circumstances, including circumstances the other code does not explicitly mention. My suspicion is that shallow equilibria are systematically exploitable: a player could submit code that passes the other program's inspection but defects at runtime because of a branch conditioned on a clock reading, a random draw, a call to an outside service, or a buried subroutine the inspector never evaluates. I can almost convince myself that any equilibrium built on inspecting source text rather than on establishing facts about the other program's behavior is shallow in this sense and therefore fragile.

Is this distinction already a known one under a better name, or is it confused at the root? Is the deep variety achievable at all, or does it run into general undecidability limits — and if those limits apply, how much is left of the claim that program equilibrium provides a rigorous foundation for cooperation rather than a formally pretty story? I would like both the strongest case that shallow equilibria are stable enough in practice to support the picture, and the strongest case that the whole framework collapses once agents can hide their actual decision procedure behind code that passes inspection.
