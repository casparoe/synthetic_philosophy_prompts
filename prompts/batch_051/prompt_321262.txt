I have been trying to steelman a line I see in rationalist-adjacent discussions: the simulation argument should weaken fanaticism about the far future. Here is the cleaned-up argument, using a passage from Nick Bostrom, “Are You Living in a Computer Simulation?”:

“The argument we shall present does not, however, depend on any very strong version of functionalism or computationalism. For example, we need not assume that the thesis of substrate-independence is necessarily true (either analytically or metaphysically) – just that, in fact, a computer running a suitable program would be conscious. Moreover, we need not assume that in order to create a mind on a computer it would be sufficient to program it in such a way that it behaves like a human in all situations, including passing the Turing test etc. We need only the weaker assumption that it would suffice for the generation of subjective experiences that the computational processes of a human brain are structurally replicated in suitably fine-grained detail, such as on the level of individual synapses. This attenuated version of substrate-independence is quite widely accepted.”

The argument:

(1) On Bostrom’s own presentation, the simulation argument requires only the attenuated substrate-independence premise quoted above, not full functionalism or strong artificial-intelligence claims.
(2) If that attenuated premise is true, then the simulations that posthuman civilizations would run contain conscious minds whose subjective states matter morally no less than ours in principle.
(3) If you assign non-negligible probability to posthumans running many such simulations, then by Bostrom’s probabilistic reasoning you should assign high probability to your own current experiences being among those simulated minds.
(4) If your own life is almost certainly inside an ancestor simulation, then the expected value of your actions for the far future depends primarily on the purposes and persistence conditions of the simulators, about which you have no reliable base rate.
(5) Therefore the simulation argument materially dampens fanaticism about shaping the far future through ordinary existential-risk work, because the high-probability world is one in which your actions are not robustly connected to the far-future outcomes that longtermists care about.
(6) So a rational longtermist should discount the far future substantially on simulation grounds.

Is this argument valid? If not, which step fails and why? Be specific about the strongest reading of each premise. In particular, does the quoted passage actually license premise (2), or does it license only something weaker about subjective experience, not moral significance? And is premise (4) an illicit move from epistemic uncertainty about being simulated to practical discounting?
