I've been reading about Aumann's agreement theorem — the one that says if two Bayesian agents share a prior and their posterior probabilities for some event become common knowledge, then the posteriors have to be equal; two rational people with the same prior can't end up with different numbers.

The variant I'm stuck on: in the theorem, what becomes common knowledge is the exact value of each person's posterior. What if the only thing that becomes common knowledge is a rounded version of it? Say Alice's true posterior is p and Bob's is q, and the number that gets posted publicly is round-to-the-nearest-tenth of p and round-to-the-nearest-tenth of q. So 0.51 and 0.49 both get posted as 0.5. Everyone knows the rounding rule and everyone sees the posted numbers. Does the theorem still force p = q, or can Alice and Bob sit at 0.51 and 0.49 forever while both honestly post 0.5? Does the theorem still bite in some coarser form, like forcing the posted values to match? And where exactly does the argument break?

Then the second layer: if after each round they each condition on the other's posted value, update, and re-post their new posterior (rounded the same way), do the underlying p and q converge to the same number, or can they just stabilize inside the same rounding bin while still actually disagreeing? I keep trying to model it like two nodes in a distributed system exchanging quantized updates, and I go in circles about whether the 'both parties post 0.5' event is really common knowledge in the technical sense.

I'm not a philosophy person, fwiw, so if I got the original theorem wrong just tell me which assumption is doing all the work.
