ok so in my school's philosophy club someone gave this argument that consciousness is basically a user illusion, and I tried to number the steps but i cant tell if the argument is valid or if one of the steps is quietly changing the subject. here it is:

(1) The desktop on a computer is a user interface: the folder you click on is not the actual memory where the file lives, its just a simplified picture the computer generates so a person can use the machine.
(2) The brain is, in some useful sense, a computer, and consciousness is the brain's user interface for representing its own activity.
(3) If consciousness is a user interface, then the feeling that I am making a decision is part of the picture, not the actual process that makes the decision.
(4) A picture that represents a process without being that process is not doing the causing; the underlying process does all that.
(5) So my conscious feeling of deciding doesn't actually cause my actions; it just represents decisions that are already happening in the nonconscious brain.
(6) But if the conscious feeling represents a decision as mine and as something I made, when really the nonconscious process made it, then consciousness is an illusion in the everyday sense: things aren't how they seem.
(7) So consciousness, the way we experience it, is an illusion.

I half-suspect the slide from (4) to (6) is the sneaky part, but I can't put my finger on what exactly the trick is. I also keep getting stuck on this: an illusion has to be experienced by someone, and if the self is part of the illusion, who's left to be fooled? Can you go step by step and say whether the argument is valid, and if not, which step fails, and what the correct version of that step would have to be for the conclusion to still go through?
