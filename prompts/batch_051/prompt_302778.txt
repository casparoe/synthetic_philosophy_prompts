I work as a software engineer and have been trying to formalize an argument about how deployed AI systems should make moral decisions. I want to know whether the argument goes through.

(1) A system can be held to a moral standard only through its actual decision procedure; a standard is realizable for that system only if the procedure can apply it.
(2) The utilitarian standard says an action is right just in case it produces the greatest expected total welfare among the available alternatives.
(3) No actual decision procedure can apply that standard, because computing expected total welfare requires a value function we do not have, and every tractable approximation introduces systematic errors.
(4) The deontological standard says an action is right just in case it conforms to a finite list of constraints (for example: do not deceive, do not cause serious harm).
(5) A decision procedure can apply a finite list of constraints, because checking an action against each constraint is tractable and can be verified before deployment.
(6) Therefore, for any AI system whose violations would be serious, the deontological standard is the only realizable moral standard; utilitarian reasoning is not a live option.

I have a nagging sense that the move from (3) and (5) to (6) is too strong, but each step looked plausible when I wrote it down. Is the argument valid? If it is not, identify the first step where it fails and say whether that step can be repaired so that the conclusion still follows. If it is valid, identify the premise I should be most reluctant to accept.
