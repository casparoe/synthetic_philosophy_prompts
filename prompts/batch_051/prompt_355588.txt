After I retired from computational physical chemistry, I started reading philosophy the way I used to debug old Fortran: slowly, and with the assumption that if an argument seems easy to summarize, I have probably missed something. One argument I keep revisiting is the Free Software Foundation's long-standing analysis of copyleft and derivative works. As I understand it, that analysis was built on a particular technical picture: a program is a single executable assembled by a compiler and a linker from source files, so when a developer links a proprietary object file against a GPL-covered library, the combined executable inherits the library's status as a derivative work, and the GPL's copyleft conditions attach to the whole. The argument presupposes that a program has a fairly sharp boundary and that the link operation is what marks it.

I am trying to work out whether that argument survives contact with how software is assembled today. Suppose a proprietary dashboard talks over HTTP to a small GPL-covered solver running in a separate container: no object files are linked, no address space is shared, and the interface between the two is a network protocol rather than a subroutine call. Then add a code assistant trained on public repositories, many of them GPL-licensed, which emits short routines that developers paste into the proprietary dashboard without knowing or checking whether those routines resemble anything in the training corpus. My question is conceptual, not legal; I am not asking what a court would likely hold or what policy would be sensible. I want the anatomy of the argument under these changed conditions. Which premise does the development bear on most directly: the idea that a derivative work has been formed, the idea that a program has a boundary visible in how it is linked, or the idea that provenance and human intention are stable enough to carry the analysis? Can the argument be repaired into a weaker but still meaningful form—perhaps one that distinguishes modification from mere aggregation by the degree of control and coupling between components rather than by the mechanics of linking—or does it simply lose its force? I would be grateful for the response in American English.
