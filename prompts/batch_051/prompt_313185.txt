I've been chewing on a parallel and I can't tell weather it's deep or just me pattern-matching. Purity and sanctity norms in moral psychology look weirdly like static type systems to me.

Mapping first. A static type system is only about categories: it rejects an expression that mixes types even when the operation would have run fine at runtime. It enforces boundaries for the health of the whole program, not the convenience of any one line, and a cast is a way to cross a boundary that works only because it's marked as a crossing. Purity norms seem built the same way. The classic observation they rest on is that impurity attaches to things in the wrong category, not to things that are intrinsically dangerous — shoe on the table, menstrual blood, a corpse where a living person should be. Disgust is the compile error. Purification rituals are the casts. Sacred values are like types that refuse coercion: a taboo trade-off is just comparing a sacred value and money as if they had the same type.

If the mapping is real, stuff from type theory should transfer. Strict vs gradual typing would map onto moral communities that police purity categorically vs ones that tolerate case-by-case impurity, and subtyping might explain how taboos chain together. If it's superficial, I'd like to know exactly where the structures come apart. Two candidate breaks already occur to me. First, a type checker is a designed artifact with an author and a revision history; a purity system is more like a legacy codebase nobody wrote and nobody can refactor. Second, type systems are broadly compositional — well-typed pieces compose into well-typed wholes — but purity doesn't seem to be: two individually clean things can be defiling in combination.

So: is this a genuine shared structure, and what would have to be true on both sides for results to transfer? Where's the cleanest place the analogy predicts something false, rather than just staying silent? And is the compositional disanalogy fatal, or just the purity analogue of type imcompatibility showing up one level up?
