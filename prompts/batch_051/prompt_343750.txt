I'm a software engineer and not really a philosophy person, but I got curious about Frank Ramsey's 1927 paper Facts and Propositions because someone linked it in a programming Slack. From what I can tell, Ramsey thinks there is no separate problem of truth, just a kind of linguistic muddle about how the word true works. I want to test that idea against some intuitions I have, and see whether they add up to a coherent view.

Here are my gut reactions to cases. When a coworker says the build is broken and I check CI and the build is broken, I'm fine saying what he said is true. But it doesnt feel like his sentence has acquired any extra property; saying "what he said is true" just sounds like a longer way of saying the build is broken. Same with "it's true that the server is down"—I hear no extra content over "the server is down." When my boss says everything the client said this morning is true, though, I dont take him to be asserting some giant conjunction I already know; he's using true to endorse a bunch of statements without having to list them all. That seems like a useful compression or endorsement device. But then I get stuck on a case I keep going back to: are there true statements no one will ever prove or verify? I want to say yes—if a jar has a definite number of gummy bears and I never open it, the statement that the jar contains exactly N bears is either true or false even if no one ever checks. But if true is just a device for endorsement, I dont know what is being endorsed in that case. Another case: when debugging, I sometimes say "if the original developers assumptions are true, then the bug is in the parser." That use of true in an antecedent seems to be doing logical work; I'm not asserting the assumptions, so its not just a long-winded way of asserting them. And when a coworker says the code compiles and it doesnt, I say his statement is false, which again seems like the flip side of the same simple thing rather than a deep property.

So: is there a single principle about the word true that captures all these verdicts, or close to it? If yes, state it and tell me what it predicts for a case I havent listed—say, a judge instructing a jury that a witness is telling the truth. If no, which of my verdicts should I overturn? And am I actually agreeing with Ramsey, or have I smuggled in something he would reject?
