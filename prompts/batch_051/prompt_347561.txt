Write the joint statement that a utility-indifference corrigibility researcher and an incentives-and-oversight corrigibility researcher could both sign after six months of adversarial collaboration. The first camp holds that a corrigible agent needs a utility function that is indifferent between the shutdown button being pressed and not pressed, because any leftover preference about its own operation will create an incentive to disable the button; the second camp holds that built-in shutdown-indifference is the wrong target, since a useful agent should still warn you about the house fire it can see from the porch, and shutdown-handling should instead come from training, oversight, and genuine uncertainty about the operators. Have them separate real disagreements from definitional noise. Produce: (1) a numbered list of non-vacuous claims both sides sign, including about what the shutdown problem is, why it is hard, and what any acceptable solution must preserve; (2) a disagreements table where each row states the disputed point in neutral wording, then gives each side's position in wording that side would accept; (3) three cruxes, each with a concrete scenario both sides agree is diagnostic and a prediction from each side about what a capable but misaligned agent would do in it. Make the scenarios actually distinguish the camps rather than restating them.
