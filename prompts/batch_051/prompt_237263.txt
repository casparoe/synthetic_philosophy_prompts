In a philosophy of cognitive science course I am taking, we discussed von Neumann's argument — offered partly as a model of how the brain might work — that reliable computation can be built from unreliable neurons by multiplexing each signal across many units and taking a majority vote after each stage, with the overall error probability falling steeply as long as component failures are independent. This looked to me like the Condorcet jury theorem translated into engineering terms: if each voter is independently more likely to be right than wrong, majority judgment becomes overwhelmingly reliable as the electorate grows, and shared sources of error destroy the guarantee. I want to work out whether the mapping — neuron to voter, redundant bundle to electorate, majority gate to majority rule, correlated component failure to correlated voter information — is a genuine identity of structure or only a loose analogy trading on words like independence and correlation. If it is genuine, what would have to be true on both sides for results to transfer between them? And where does the parallel break down, that is, what is true of one domain but would be false of the other if the analogy were pressed?
