I'm a software engineer, not a philosopher, and I keep running into a disagreement on our team that sounds philosophical but ought to be testable. We ship an instruction-tuned coding assistant. Several teammates describe the model as understanding the spec in a prompt and trying to satisfy it; they point to cases where it refuses to write code that would break an existing test or asks a clarifying question about an ambiguous requirement. My prior is that this is anthropomorphism: the fine-tuned model is just emitting tokens that are statistically typical of helpful-assistant text, and the apparent goal-directedness is all on the surface, with no internal counterpart. I don't want to argue about the word understanding. I want to know whether there is a real difference behind the two descriptions and whether we could detect it.

State the sharpest version of that difference, then design the best concrete experiment you can, using only methods a current lab could plausibly run — fine-tuning, comparisons to the base model, held-out evals under distribution shift, prompt perturbations, and, if you think they are justified, probes or causal interventions — to test the claim that a fine-tuned assistant represents and conditions its output on the user's objective rather than merely matching behavioral statistics. For example, one arm might probe whether its competence survives rephrasings that preserve the objective while breaking the surface features the base model relies on, but choose whatever arms you think are most diagnostic. For each arm, specify in advance what result would push toward a real internal representation of the objective and what result would push toward pure surface behavior. Then be explicit about what even a clean result could not settle in principle. Commit: pick the single experiment you would run first if you could only run one, say what you expect it would most likely show about this class of models, and defend that expectation with reasons.
