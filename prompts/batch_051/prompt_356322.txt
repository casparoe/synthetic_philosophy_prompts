Question: Contrast etiological and causal-role accounts of biological function. State each view's core commitment, then explain how each would classify (i) a novel mutation that happens to detoxify a poison and (ii) a vestigial organ that no longer does anything useful. Illustrate with at least one example of your own.

Student answer:
Both accounts try to capture what it is for a trait to have a function, as opposed to merely having an effect. Etiological accounts say the function of a trait is the effect for which it was selected: the effect that explains why the trait spread through the population. So the heart's function is to pump blood, not to produce a thumping sound, because pumping blood is what hearts were selected for. Causal-role accounts, by contrast, say the function of a trait is just whatever causal effect it has in the larger system; and because which system you analyze is partly up to you, the thumping sound could count as a function in one analysis and not another. A novel beneficial mutation that lets an organism detoxify a poison would be functional on both accounts: on the causal-role account because it now plays a helpful role, and on the etiological account because it currently increases fitness. Vestigial organs come apart more sharply. The etiological account says a vestigial organ still has the function it was selected for even if it no longer performs it, since function is a historical matter. The causal-role account says the organ has no function once it stops doing anything, since function is a matter of present contribution. So the real difference is that etiological functions can outlive their current usefulness, whereas causal-role functions track what a trait does now.
