I've been going back and forth on the killing/letting die distinction and I think I've got a way of cashing it out that I'd like someone to stress-test. I call it the thermostat model. The idea: for any situation where someone is alive, there's a background "maintenance loop" keeping them alive—breathing, circulation, someone feeding them, a ventilator, whatever. That loop has a set point (the state it's maintaining) and a power supply (whatever keeps it running). Killing, on the thermostat model, is when an agent reaches in and changes the set point or breaks the loop so the maintenance stops. Letting die is when the loop is already winding down or would need a new power supply, and the agent simply doesn't supply it. So a doctor who switches off a ventilator kills, because she interrupts a running loop; a doctor who never hooks one up lets die, because that would mean starting a new supply. The payoff, I think, is that it explains why some omissions feel more like killings: a nurse who "forgets" to feed an infant was already part of the infant's maintenance loop, so her omitting is more like pulling a plug than like not donating a kidney. It also predicts fuzzy edges where people disagree about whether a loop was ever really running, which tracks how people actually argue about these cases.
