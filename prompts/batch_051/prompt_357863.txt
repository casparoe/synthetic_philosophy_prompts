I'm tinkering with a variant of the absent-minded driver problem, and want to know how the standard analysis shifts. In the usual set-up: two identical exits, 0 if you take the first, 4 if you take the second, and 1 if you drive past both. The driver cant remember at an exit whether he's already passed one, and the ex ante best rule is to exit with probability 1/3 at whatever exit he finds himself at. Now change one thing. As he approaches each exit, independently with probability r he has a brief memory flash telling him correctly whether he has already passed an exit; the flash then fades, so if no flash comes at the next exit he's back to not knowing. With probability 1-r he's just the usual absent-minded driver. If the flash occurs, he obviously continues if it says he's at the first and exits if it says he's at the second. In a no-flash state he still must choose an exit probability p. Work out the ex ante optimal p for no-flash states as a function of r, then run the ex post calculation at a no-flash state. Does the old ex post argument still bite for every r<1, or is there a threshold where the paradox disappears? What exactly changes in the conditional beliefs? If I've set this up badly or left an ambiguity, just say so. Please answer in British English.
