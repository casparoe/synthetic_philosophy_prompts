Backend dev here, not a philosopher, but I keep noticing a move in talk about rational agents and I don't know what to call it. Take two agents in a one-shot prisoner's dilemma. No way to communicate, no reputation or future interaction, and their actions can't causally effect each other. The only thing connecting them is that they run the same decision code (or close enough), and each knows this. So each one reasons: if my code outputs cooperate, then the other's code probably outputs cooperate too, since it's the same code looking at the same problem; so cooperating is better for me. If my code outputs defect, the other probably defects too, and we both do worse. This still seems to go through when the two are just similar nodes in a huge population and when their code isn't literally identical. I know this is adjacent to superrationality and evidential decision theory, but those usually get discussed with perfect copies or in small worlds, and I'm not sure that's whats doing the work. What I want: is there a name for this specific move, and more importantly what are its actual triggering conditions? How similar do the agents need to be, how much does each one need to know about the other's code, and what should one of them do if it knows its own reasoning is only weakly correlated with the other's? I won't be satisfied with just a label—I need to know where the phenomenon starts falling apart.
