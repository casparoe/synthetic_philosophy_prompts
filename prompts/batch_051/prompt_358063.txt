I've been mulling over Parfit's nonidentity problem and whether it survies a specific development. The standard illustration is a woman who can conceive now, in which case the child will have some congenital impairment, or wait a while, in which case a diferent, healthy child exists. The usual verdict is that the impaired child isn't harmed by the choice, because waiting would have meant that particular child never existed; so no specific person is worse off, but many people still feel the choice to conceive now is wrong. My question is whether this argument survives the case of preimplantation genetic diagnosis (PGD). There you have, say, eight embryos already sitting in the lab, each a distinct genetic individual, and you're choosing which one to implant. That no longer looks like deciding whether to create a particular person; it looks like deciding which already-distinct individual gets to be born, which feels closer to a distributive choice amongst existing parties than to a creation choice. Does the nonidentity problem carry over here? Specifically, which premise of the original argument is doing the real work — the claim that a different person would exist, or the claim that there is no subject who is worse off — and is that premise still true when the candidates are individuated even though none of them is yet a person? Is there a repaired version of the nonidentity argument that keeps its force, or does PGD change the situation enough that the problem dissolves for this case?
