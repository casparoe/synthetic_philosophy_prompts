Define 'replication' in science in a way that gets these cases right: (a) a second lab runs the exact same protocol on a new sample and gets p=.04 in the same direction; (b) a second lab re-runs the original data with the original code and gets the original numbers; (c) a second lab runs the same protocol and finds almost the identical effect size but p=.06, with a Bayes factor that weakly favors the effect; (d) a new study finds the same effect through a different manipulation meant to tap the same underlying construct; (e) a meta-analysis of the original and all follow-ups finds the effect only after trimming one outlier study. I lean toward: (a) is replication, (b) is not—it's just reproducability—and (c) should count as replication even though a strict p<.05 test calls it a failure, but I flip-flop on (d) and (e). Propose a definition, run it through all five, and tell me which verdict you're least confident about.
