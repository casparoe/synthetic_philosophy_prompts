Two positions in the philosophy of probability — frequentism and subjectivism — are to be treated as parties to an adversarial collaboration. A careful frequentist holds that a probability is, in the cases that matter, an objective long-run or limiting relative frequency in some reference class of repeatable trials. A careful subjectivist holds that a probability is an agent's degree of belief, constrained by coherence, with observed frequencies entering only as evidence that bears on those degrees of belief, not as the meaning of the term. Propensity interpretations are set aside except where a proposed test for a crux needs them.

Draft the joint document itself, not a dramatized exchange and not a verdict on who is right. Structure it as follows:

1. Agreed claims (350–450 words). Numbered claims about the probability calculus, Bayes' theorem, and the practical conditions under which the two camps issue the same recommendations, phrased so that neither side needs a hedge.

2. Where they part ways (300–400 words). A two-column table, one column for the frequentist formulation and one for the subjectivist formulation. Cover at least single-case probabilities, the reference class problem, and what it means for a probability assignment to be right or wrong. Each cell should be wording its own camp would sign.

3. Cruxes (200–300 words). The sub-questions such that settling one would move at least one side. For each crux, state in one sentence what each side would have to concede if the crux went against it.

4. Jointly accepted tests, with predictions recorded (250–350 words). For each crux, give a case, argument, or formal result that both sides agree is probative — for instance an exchangeability or de Finetti-style representation result, a forecasting-calibration test, or a reference-class construction problem — and record each side's prediction or required condition in advance.

5. Verbal or substantive? (100–200 words). State which parts of the dispute, if any, are only about words, and which parts survive an agreed terminological cleanup.
