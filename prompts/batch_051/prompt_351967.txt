It should push them to say whether the mixed strategy actually repairs the act-state dependence or just hides it, and whether the fixed-prediction variant collapses into an ordinary Newcomb problem or leaves the deliberation instability untouched.

Please write the question itself (worth 25 marks, 90 minutes, expecting 700 or so words), a model answer around the same length, and a marking scheme that names five or six moves an A answer has to make, with the marks each is worth and a one-line note on the usual way candidates get each one wrong. Dont worry about making the question too polished.
