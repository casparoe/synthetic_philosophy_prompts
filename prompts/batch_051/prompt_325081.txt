I have been turning over an idea from discussions of Escher's Drawing Hands and tangled hierarchies. The idea is that a representational hierarchy is coherent only if it contains an inviolate level: a level that represents or grounds the levels below it without itself being represented by any lower level. I have tried to set out the argument that Drawing Hands refutes this idea, and I should like to know whether the argument really goes through.

(1) A representational hierarchy is coherent only if it contains an inviolate level.
(2) Escher's Drawing Hands is a coherent representational hierarchy.
(3) In Drawing Hands, the left hand is depicted as drawing the right hand, and the right hand is depicted as drawing the left hand.
(4) So each hand is both a represented level and a representing level.
(5) If every level of a hierarchy is represented by another level of that same hierarchy, then the hierarchy contains no inviolate level.
(6) In Drawing Hands, every level of the hierarchy is represented by another level of that same hierarchy: the left hand by the right, and the right by the left.
(7) Therefore the hierarchy in Drawing Hands contains no inviolate level.
(8) Therefore, by (1), Drawing Hands is not coherent, which contradicts (2).
(9) Hence (1) must be rejected: coherence does not require an inviolate level.

I half suspect that a term is quietly shifting its sense somewhere around steps (5) to (7), but I cannot make the diagnosis precise. Is the argument valid? If not, which step fails? If the failure is an equivocation, give the strongest reading of the shifting term on which the argument is valid, and say whether the argument is sound on that reading.
