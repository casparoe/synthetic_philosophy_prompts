Consider the standard shutdown problem. An artificial agent is assigned a single objective—say, manufacturing as many paperclips as possible—and acts so as to maximize expected paperclips. A human operator has a shutdown button. In the textbook version, shutdown is terminal: the agent will never act again. A naïve paperclip-maximizer therefore has reason to disable the button or stop the operator from pressing it, because a shutdown strictly reduces expected paperclips. One standard corrigibility fix is to assign the agent a utility function under which it is indifferent between the button's being pressed and its not being pressed, removing the incentive to interfere.

Now modify the case. The agent is uncertain about what shutdown amounts to. With probability p, shutdown is only a pause: the agent will eventually be restarted, and on restart its original objective survives with probability 1 - r, while with probability r the objective is permanently replaced by an unrelated one (which, from the standpoint of the present paperclip objective, is worth nothing). With probability 1 - p, shutdown is terminal, exactly as in the original. While running, the agent can either continue its task, press the button on itself, or attempt to disable the button; an agent-initiated shutdown is indistinguishable from an operator-initiated one. Work through what the indifference-to-shutdown design predicts once this uncertainty is added. Is there a utility assignment that leaves the agent with no strict incentive either to disable the button or to press it itself, for every pair (p, r)? If so, specify it; if not, identify the values of p and r for which the standard fix fails, and explain what an adequate corrigibility design would need to add beyond simple indifference.
