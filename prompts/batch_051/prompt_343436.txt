I help moderate the compliance list for a GPLv3 constraint solver called Knothole. The lead maintainer, Rik, is not a lawyer, but he has made enough 'is this a derivative work?' calls over the years that the list treats them as informal precedent. As best I can reconstruct from the archive, his past calls are: (1) a proprietary GUI that statically links Knothole's solving library is derived; (2) a fork that patches the search heuristic and redistributes the binary is derived; (3) a plugin that loads into Knothole's process and includes its internal headers to add a new branching strategy is derived; (4) a standalone CSV preprocessor invoked as a subprocess, sold seperately and also used with three non-GPL tools, is not derived; (5) a clean-room reimplementation of Knothole's file format and command-line flags, built from scratch, is not derived; (6) a general-purpose data manager bundled with Knothole on the same USB stick is not derived.

A lab now wants his view on a new case: a 'warm-start daemon' that runs as a separate process and talks to Knothole over a private Unix-domain-socket protocol. It holds parsed problem state in memory and returns hints for warm starts. It was written only for Knothole, has no real use outside it, and copies none of Knothole's source. It would be shipped alongside Knothole, but as a separate binary.

I keep going back and forth between candidate rules that all seem to fit his past calls: a link/process rule (derived iff it runs in or links the solver's code), a purpose/dependence rule (derived iff it is purpose-built for Knothole and has no substantial independent life), and a copying rule (derived iff it actually copies or modifies solver source). What would each rule predict about the warm-start daemon, which one(s) do you think Rik is really running, and what is your best guess for his verdict? Then give me the next test case you would run to separate whichever rules survive, and say which pair it would settle and which pair it would still leave tied. I care more about getting the underdetermination right than about the bottom line. For my notes, please do the answer in British English.
