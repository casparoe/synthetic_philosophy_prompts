The loose check says a language is a finite set of words plus grammatical rules that let you build an open ended number of new sentences, and its learned from other people. The stricter check says: on top of that, the words themselves have to be built by recombining a smallish set of meaningless pieces, the way consonants and vowels do it in speech or handshape, location, and movement do it in sign. Build me a thought experiment where these two checks come apart in the direction that feels backwards: the system that flunks the stricter check is a spoken one, while a mature signed system passes both checks. So the scenario should have two systems in one community: a signed system that passes both checks, and a spoken system that passes the loose check but fails the stricter one because its words are whole sound-gestures with no reusable parts inside them. Dont just stipulate that the words have no parts though; set the spoken system up so thats honestly true, and make it genuinely useful and passed down, not some crippled toy code. Constraints: a normal village or island, no exotic tech or supernatural stuff, and keep the scenario itself to one paragraph. Afterward do the check: walk through each checks verdict and why, say exactly which feature of the example is doing the work, explain what happens if you add a small set of reusable sound pieces back into the spoken system, and give the strongest objection someone defending the stricter check would make, and how youd answer it.
