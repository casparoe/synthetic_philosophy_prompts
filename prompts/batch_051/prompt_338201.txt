I'm writing a term paper defending a pretty strong empiricist line and I've gotten to the point where I dont trust my own ability to figure out which findings would actually hurt me. The position, put roughly, is this: human infants start out with only domain-general learning mechanisms—statistical learning, associative mechanisms, a few attentional salience biases—plus whatever low-level perceptual hardware is needed to run them, and no domain-specific knowledge at all. Everything that developmental psychologists call core knowledge (object permanence, an approximate number system, early theory of mind, the language faculty) is, on my view, built up from experience by those general-purpose mechanisms. I'm not asking for the standard Chomsky-style replies everyone already knows.

What I want instead is a map of this position's exposure. Suppose I'm wrong: what's the single finding, argument, or developmental pattern that should make me update the most, and why? More specifically, what would a genuine poverty-of-stimulus case have to look like to be decisive rather than just awkward—where it's not merely that the input is messy, but that the relevant structure is provably absent and the child still acquires it on a normal schedule? Are there other kinds of evidence that ought to weigh more: cross-cultural universals that appear without anything like the relevant experience, species-specific acquisition patterns, artificial learners that fail to converge on the same competence from the same data? And then the meta-worry: I have a nagging suspicion that domain-general learning is flexible enough that my view can absorb any result post hoc by adding a bit more learning or a slightly different salience bias, in which case it isn't risky at all. Is that right, and if so is that a decisive problem for the view, or just a sign the debate is being drawn at the wrong grain? I'd trade the whole paper for an honest assessment of where the position is genuinely exposed versus merely insulated.
