I've recently caught myself, in a drawn-out disagreement at work, wanting to set aside new evidence against a conclusion I'm sure I know—on the ground that, if I do know it, the evidence must be misleading. That led me to the dogmatism paradox, and I've tried to reconstruct the underlying argument as follows:

(1) If I know that P, then P is true.
(2) If P is true, then any genuine evidence that P is false is evidence for a false proposition.
(3) Evidence for a false proposition is misleading evidence.
(4) Therefore, if I know that P, then any genuine evidence that P is false is misleading.
(5) If I know that P, I can know in advance that any genuine evidence that P is false would be misleading.
(6) If I can know in advance that any genuine evidence that P is false would be misleading, then I may rationally dismiss any apparent evidence that P is false without examining it.
(7) Therefore, if I know that P, I may rationally dismiss any apparent evidence that P is false without examining it.

I suspect the trouble lies in the move from (5) to (6), or perhaps in what it takes to be in a position to know, but I cannot make the diagnosis precise. Is the argument valid? If not, which step fails and on what reading? If it is valid, is the conclusion as objectionable as it sounds? Please separate what is settled about this paradox from what remains genuinely contested among epistemologists, and don't present a contested resolution as if it were the consensus.
