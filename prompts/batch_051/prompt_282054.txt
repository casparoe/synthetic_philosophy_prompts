The setup is this. Let ZFC be first-order set theory. The Löwenheim–Skolem theorem says that if ZFC has any model at all, then it has a countable model, call it M. Since M is a model of ZFC, it satisfies Cantor's theorem, so inside M there is a set, call it c, such that M contains no bijection between c and M's version of the natural numbers — that is, M thinks c is uncountable. But now step outside M. M itself is countable, so there is, in the real mathematical universe, a bijection from the whole domain of M to the natural numbers. Restricting that bijection to the elements of c shows that c is at most countably infinite. So one and the same set looks uncountable from inside M and countable from outside, which is a contradiction. Put as numbered steps: (1) if ZFC has a model it has a countable model M; (2) since M models ZFC, M thinks some set c is uncountable; (3) so c is uncountable; (4) M is countable and c is contained in M's domain; (5) so c is countable; (6) contradiction. My lecturer keeps saying countability is relative to a model, which I half get, but I don't see how that tells me which line of the argument actually fails. Is the argument valid? If not, exactly which step fails, and what does that step's failure show about what countability amounts to in first-order terms?
