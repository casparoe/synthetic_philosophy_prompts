An evolutionary-psychology book I'm reading argues that the mind is a Swiss army knife: a collection of specialized tools, each built for a narrow adaptive problem — face recognition, cheater detection, mate choice, and the like — with no serious general-purpose reasoning component left over. From this, the author concludes that the idea of a domain-general faculty of intelligence is a pre-scientific myth. The book explicitly sets this against Fodor's older view, on which only input systems such as perception and language are modular, while central cognition is precisely not modular. I want an audit of how far the Swiss army knife analogy actually carries the book's conclusion. Spell out the mapping: what corresponds to what. Then isolate the disanalogies that matter — for example, the knife has no component that integrates the separate tools' outputs into a single judgment or action, its tools come as a fixed manufactured set rather than developing through learning, and a Swiss army knife functions only because an outside agent decides which tool to open. Which of these are fatal to the conclusion that there is no domain-general cognition, which can be repaired by improving the analogy, and what would a better analogy be, if one exists?
