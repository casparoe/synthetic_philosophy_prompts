heres an argument ive been turning over about whether saying that dna is a code is doing any real explanatory work, and i cant put my finger on where it goes wrong, if it does. (1) If something is a literal code, then there are symbols whose mapping to what they stand for is laid down by rules that a sender and receiver both share, and the receiver must in some sense take the symbol as meaning that thing. (2) But in a cell, nothing takes a codon as meaning an amino acid; tRNAs and aminoacyl-tRNA synthetases just bind molecules whose shapes and charges fit, the way a key fits a lock. (3) If nothing takes the codon as meaning anything, then the relation between a nucleotide sequence and a protein is causal rather than semantic. (4) The only kind of information left in that causal relation is covariance: this sequence raises the probability of that protein. (5) Covariance is cheap, because every cause covaries with its effect, so by itself it gives you no semantic content. (6) Therefore the genome is not a code or blueprint in any substantive sense, and genes carry no semantic information. I think the conclusion is probably right, but i have a nagging feeling step 6 slides from not being a literal code to there being no semantic information, which may not be the same thing. Is the argument valid? If not, which step exactly fails? If the problem is in how a key term is being used, give the strongest reading of that term on which the step is true, then check whether the conclusion still follows.
