I build autonomous agents that maintain an explicit set of beliefs and only add to that set when an inference engine actually fires a rule. Recently I learned that in the standard possible-worlds approach to modeling knowledge, an agent automatically knows every logical consequence of everything it already knows: every tautology, every derivable theorem, immediately and for free. Philosophers call this the problem of logical omniscience, and the usual fix is to weaken the model so that a reasoner can fail to know something that follows from what it knows. I get the formal point at a high level, but I have never trusted my sense of why it matters in an actual running system.

Write a short story in which a reasoning system—a proof assistant, a planning agent, a code-reviewing tool, or something similar—is built so that its beliefs are closed under logical consequence. Make that closure property, which would normally be an invisible formal convenience, the engine of the plot: something should go wrong, or become strange, precisely because the system already counts as knowing things it has never derived. Avoid making it a generic superintelligence story; the pressure should come specifically from the mismatch between what the system has actually derived and what it is modeled as knowing. The story should leave a reader with a sharper sense of what the logical-omniscience idealization buys and what it quietly hides.
