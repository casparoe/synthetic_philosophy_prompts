I've been going around in circles on the reference class problem and would love a second opinion, because I've built an argument that seems to prove there are no objective probabilities for individual events, and that can't be right.

The setup: take a specific event like Alice getting lung cancer within five years. To estimate that, you put her in a reference class and read off a frequency. All 50-year-old American women? Call it x%. All 50-year-old American women who smoke a pack a day? Call it y%, much higher. All 50-year-old American women who smoke a pack a day and have her specific family history and genetic markers? Call it z%, different again. Then there's the maximally specific class: all people who are exactly like Alice in every relevent respect. That class has exactly one member, so the frequency is 0 or 1.

So the argument goes like this:

(1) The objective probability of a particular event is the relative frequency of that type of event in the appropriate reference class.
(2) Every particular event belongs to many reference classes.
(3) No feature of the world picks out one of those classes as "appropriate"; that's a modeling choice we make.
(4) For different choices of reference class, the relative frequencies differ, sometimes by a lot (in the limit, to 0 or 1).
(5) So the same particular event has many different objective probabilities.
(6) But if objective probability is a real feature of the world, an event can have at most one objective probability.
(7) Therefore particular events don't have objective probabilities at all.

I know the obvious Bayesian exit is to say that probability is just subjective credence and the reference class problem only bites frequentism. But that feels like giving up exactly the thing I wanted to explain. When an oncologist says "your five-year risk with this treatment is 15%," I want to say there's a fact of the matter that makes some reference classes better and others worse, not just that everyone has their favorite partition. Is there a hidden false premise or equivocation in (1)-(7), or is the argument valid and I have to price out what it costs to keep single-case objective chances? If you reject a step, tell me which one and what the strongest repair looks like. Write the answer in American English.
