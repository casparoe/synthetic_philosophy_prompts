Consider the following reconstruction of the brave-officer objection, familiar from Reid but here set out as a numbered argument against Locke's memory criterion of personal identity.

(1) According to the memory criterion, a person P₂ at a later time is the same person as a person P₁ at an earlier time if and only if P₂ can remember P₁’s experiences or actions.

(2) As a young man, the officer can remember being flogged as a schoolboy for stealing from an orchard. Thus, by (1), the officer is the same person as the schoolboy.

(3) In advanced life, the general can remember the officer’s brave action in battle but cannot remember being flogged as a schoolboy. Thus, by (1), the general is the same person as the officer but is not the same person as the schoolboy.

(4) Identity is transitive: if a is the same person as b, and b is the same person as c, then a is the same person as c.

(5) By (2), (3), and (4), the general both is and is not the same person as the schoolboy.

(6) Therefore, since the criterion leads to contradiction, the memory criterion as stated in (1) must be rejected.

Your task: determine whether this argument is valid. If it is not, identify the exact step at which the logical error occurs. If it is valid, state which numbered premise a defender of the memory criterion should reject or revise, and set out the revised criterion precisely enough to show that the same objection no longer arises. In that case, also say whether the revised position is still recognisably Lockean or whether it in effect concedes Reid’s main point. Please write your assessment in British English.
