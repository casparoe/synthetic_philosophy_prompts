I have been trying to articulate my view of the moral difference between lying and misleading, and I would like a consistency audit before I present it to a reading group. Here is the position as it now stands:

(1) Lying—asserting what one believes to be false—is normally worse than deliberately causing a false belief by saying something true.

(2) The extra wrong in lying does not come from the false belief the hearer ends up with, since a carefully worded true statement can cause exactly the same false belief.

(3) The extra wrong comes from the liar's using the institution of assertion itself to implant the false belief, whereas the misleader only invites the hearer to draw a false inference.

(4) A difference of moral weight should not turn on whether the false proposition is semantically encoded in the utterance or merely pragmatically conveyed, because that is a difference in packaging, not in what the speaker is doing to the hearer.

(5) And yet, in a case where a speaker selects each literally true sentence precisely because the hearer will predictably build a false picture from them—say, a suspect who answers every question truthfully but designs the answers so the detective concludes he was elsewhere—the speaker seems to me exactly as bad as one who asserted the false alibi outright.

Please trace which of these commitments pull against which: distinguish real tensions from merely apparent ones, rank the real tensions by severity, and specify for each what would have to give and what it would cost. If one revision would resolve more than one tension, say which one and what it would leave unsettled.
