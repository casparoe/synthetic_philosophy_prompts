The exam question was: "Can a finite string of 0s and 1s ever properly be called random? Discuss with reference to Kolmogorov complexity and Martin-Löf randomness."

The student answered:

"At first glance, randomess seems to be a property of the process that generated a sequence, not of the sequence itself. After all, any finite string—even a string of a thousand zeros—could have been produced by a fair coin, and any random-looking string could have been written out deliberately by a deterministic agent. So if by 'random' we mean 'produced by a genuinely chancy process,' then a finite string considered on its own is neither random nor non-random; the predicate just doesn't apply to the string alone.

Algorithmic randomness is often presented as a way around this, by relocating randomness from the process to the object. On this approach, a string is random when it is incompressible: the shortest program that prints it is about as long as the string itself. The standard criterion is that a finite string of length n is random just in case its Kolmogorov complexity is at least n. That captures the idea that a random string has no pattern we could exploit to describe it more briefly than by listing it digit by digit.

Martin-Löf then extended this to infinite sequences. He defined an infinite binary sequence to be random if it passes every effective statistical test, and he proved that a sequence is random in exactly this sense when there is some constant c such that every initial segment of length n has Kolmogorov complexity at least n minus c. That theorem is what connects the statistical notion of randomness to incompressibility, and it licenses saying that the finite prefixes of a random sequence look like typical, patternless strings."
