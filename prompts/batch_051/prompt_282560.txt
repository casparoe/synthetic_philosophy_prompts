A recurring move in debates about whether human values are many or ultimately one is the old utilitarian maxim that each person is to count for one and no one for more than one. I have seen it used to brush aside value pluralism: if everyone’s interests count equally, the thought goes, we already have a single common currency in which all values can be measured. I want to take that maxim apart. What are the distinct claims it could be expressing? For each reading, say whether it is trivial, substantive but defensible, or false, and which of those readings would actually license the inference from equal counting to a single common currency of value. Lay the readings out as a menu rather than picking one, and be specific about where the slide from egalitarian counting to value monism would be justified and where it would not.
