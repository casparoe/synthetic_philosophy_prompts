Set-up. Think about Typogenetics, the toy formal system Hofstadter describes in GEB. You've got strings over {A, C, G, T}. The strings code for enzymes, and the enzymes do operations on strings: cutting at a pattern, copying a chunk, inserting, deleting, etc. The funky bit is that a string can code for an enzyme that copies that very string, so the strand is data and program at once — it does something to it's own code. Hofstadter pushes this as the same abstract shape as Gödel's proof: in both cases a system encodes itself and then performs some operation on its own encoding (proving something about it vs. copying it). People sometimes call this the DNA–Gödel isomorphism, and like most catchy labels it's doing a lot of work.
