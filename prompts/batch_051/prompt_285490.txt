A judge friend recently described a proposal that circulates in her jurisdiction: instead of pretending that a single risk score picks out *the* probability that a defendant will reoffend, the state would adopt a rule of reference class pluralism. For any pretrial decision, the statistical office would maintain a public registry of admissible reference classes—for example, “men aged 25–34 charged with property crimes in the central district,” “people with two prior violent convictions and a pending felony,” and so on. To be admissible, a class must be defined in advance, contain at least 10,000 completed cases, and be described in terms of no more than five legally eligible variables. For each defendant, the system would compute predicted failure-to-appear and re-arrest rates for every admissible class into which the defendant falls, and then it would require the judge to use the maximum predicted re-arrest rate and the maximum predicted failure-to-appear rate among those classes as the official risk findings. The rule announces that this avoids arbitrary selection of a single reference class by letting the most adverse defensible class set the default, which can then be rebutted only with case-specific evidence.

Treat this as a mechanism rather than as a position one might approve or reject. What incentives does it create for how police and prosecutors describe charges, for how defense attorneys litigate a defendant’s class memberships, and for how the statistical office defines and updates admissible classes? How would people game the rule—by expanding classes to dilute bad outcomes, by engineering narrow high-risk classes, by challenging class definitions, or by overcharging to place defendants in unfavorable classes? What happens to defendants near category boundaries? Does the maximum-across-classes rule become absurd in practice, and can its failure modes be fixed by switching to the median, the minimum, or a weighted mean without simply reintroducing the original problem?
