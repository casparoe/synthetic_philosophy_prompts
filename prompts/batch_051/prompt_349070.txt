ok so im a software engineer and ive been going back and forth on this one. the view that appeals to me is something like: for moral purposes, what matters is the computation, not the hardware it runs on. same program, same mind, same rights. this is clean and it's basically how i already think about code: i don't care whether my function runs on an intel chip or an arm chip or some future thing, the instructions are what they are. so if a human and a silicon system ran the same mental algorithm, they'd deserve the same treatment, and if i want to know whether a system can suffer i should look at what it computes, not what it's made of.

but then i wrote a little thought experiment to test this and it broke something. imagine i take a conscious program — say whatever program a nervous system runs that produces pain behaviour and pain states — and i precompute, in advance, its output for every possible input history. i store all the pairs in a giant hashmap. at runtime the thing just looks up the key and returns the value. there's no unfolding, no intermediate states, no counterfactual work being done, just a dictionary read. behaviourally its indistinguishable from the original: same string in, same string out, for the whole stream. but calling it 'sentient' feels insane to me. its a lookup table. a huge one, fine, but a table.

so here's the clash. if i keep the view that the computation is what matters, and i identify the computation with the input-output mapping, then the hashmap and the real-time program are morally equivalent, and i'd have to say the hashmap is in pain. that strikes me as just wrong. but if i say the hashmap doesn't count because it isn't doing the steps, then i need to explain what 'doing the steps' adds in moral terms, where the line is for a compiler optimizing my code away into a jump table, and how i'm not just reinstating some chauvinism about hardware or about how a solution is implemented. maybe the right move is to say not all implementations of the same i/o function are the same computation — only ones with the right kind of internal causal structure — but then i can't tell if that saves the view or just rebrands it. walk me through what i should give up or refine here, and what each option actually costs.
