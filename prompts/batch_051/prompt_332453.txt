Set-up. Let G be a finite gamble yielding outcomes x_1, ..., x_n with probabilities p_1, ..., p_n. Order outcomes by utility, u(x_1) ≤ ... ≤ u(x_n), and write q_j = p_j + ... + p_n for the probability that G yields at least u(x_j), with q_{n+1} = 0. A risk function r is continuous and strictly increasing on [0,1], with r(0) = 0 and r(1) = 1; taking r(p) = p returns ordinary expected utility. Risk-weighted expected utility evaluates G as:

REU(G) = Σ_{j=1}^n u(x_j) [ r(q_j) − r(q_{j+1}) ].

Now the argument.

(1) For any gamble G and any j with p_j > 0, define a gamble-adjusted utility by

v_G(x_j) = u(x_j) [ r(q_j) − r(q_{j+1}) ] / p_j.

(2) Substituting into the REU formula gives REU(G) = Σ_j p_j v_G(x_j). That is simply the expected utility of G with utility function v_G — no risk-weighting appears, only ordinary expectation.

(3) So for every gamble G, REU(G) equals an expected utility with respect to some utility function. A choice between gambles is just a comparison of these quantities, so every choice an REU maximizer makes maximizes expected utility for some utility function.

(4) But an agent whose every choice maximizes expected utility for some utility function is, by definition, an expected-utility maximizer. Expected utility theory does not prescribe which utility function represents a person's preferences; it only requires that some utility function makes their choices expectation-maximizing. Allowing the function to vary from gamble to gamble is an inessential detail of representation.

(5) Therefore risk-weighted expected utility is not a rival to expected utility theory; it is expected utility theory with unusual, gamble-relative utility functions. The risk function r is redundant notation and should be eliminated by Occam's razor.

Conclusion: the debate over whether rational agents should weight probabilities by r(p) rather than by p is merely a dispute about notation. The real question, which ordinary expected utility theory already answers, is what utility function the agent has.
