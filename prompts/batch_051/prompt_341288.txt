I've been going back and forth with a friend about what counts as solving a formal derivation puzzle, and I want a second opinion on a specific case, because the criteria I was taught seem to give the wrong answer about it.

Take the MU-puzzle. You start with the string MI and four rules:

1. If a string ends in I, you can append U.
2. From any string of the form Mx you can produce Mxx (so from MIU you get MIUIU).
3. Anywhere the substring III occurs, you can replace it with U.
4. Anywhere the substring UU occurs, you can delete it.

The question is whether you can reach the string MU.

Here are the criteria I was taught for a solution to a derivation puzzle:

A. A solution is a finite sequence of strings that starts at the given string and ends at the target string.
B. Each step in the sequence has to be licensed by one of the rules.
C. A solution has to be checkable by someone who just follows the rules mechanically, without needing to understand what the symbols mean or have any clever idea.

Now the borderline case. Someone answers the puzzle not by deriving MU, but by proving it is impossible. They note that the number of I's in any reachable string is never a multiple of 3: MI begins with one I; appending U doesn't change the I-count; doubling a string multiplies the I-count by two, which can't turn a non-multiple of 3 into a multiple of 3; replacing III with U subtracts three I's, which also preserves not-being-a-multiple-of-3; and deleting UU leaves the I-count alone. So every reachable string has an I-count that is not a multiple of 3. But MU has zero I's, and zero is a multiple of 3. Therefore MU is unreachable, and the correct answer to the puzzle is "no."

Does this count as a solution by my criteria? It plainly fails A and B, since there's no string sequence ending in MU. It sort of satisfies C, because the modular arithmetic is as mechanical as the string rules, but it's mechanical over numbers and multiples, wich are not part of the system the puzzle defined. If it doesn't count, then the puzzle has no solution under these criteria, which feels wrong because this impossibility proof is the whole payoff of the puzzle. If it does count, then a solution need not derive the target string, and I should add a criterion like D: a solution is either a derivation of the target string or a proof that no derivation exists.

I'm also wondering whether this is the same move people call "jumping out of the system" (JOOTSing): the solver stops trying to work the string rules and instead reasons about the system using arithmetic the system never supplied. Is that a genuine leap out of the system, or just a normal shift to a meta-level? Go criterion by criterion, give me a verdict on the case, and tell me whether the criteria themselves need fixing.
