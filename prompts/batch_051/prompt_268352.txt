I keep having this thought and I can't tell if it's actually illuminating or just me pattern-matching. The imagery debate between depictive accounts (Kosslyn: images are quasi-pictorial and laid out in a spatial buffer) and propositional accounts (Pylyshyn: underneath there's a propositional code, and the spatial-looking results get generated from tacit knowledge when the system is queried) struck me as structurally identical to the database distinction between a materialized view and a view computed on demand. The interface is the same; the difference is weather the result is already precomputed and stored in a spatial format or computed from an underlying description whenever you need it. The usual behavioral results—scanning time rising linearly with distance, rotation time with angle—are exactly the sort of thing either implementation could produce, and the neuroimaging evidence feels like opening the machine to check whether a cache or a coprocessor is active, which is a different level than the argument. Is this a genuine identity of structure, and if so does anything from databases transfer, like view maintenance, stale caches, or the storage-vs-recomputation tradeoff? If it's just an analogy, I'd like to know where it comes apart and what it predicts about imagery that's false.
