I'm attracted to chain-of-thought monitoring as a safety technique: if a model writes out its step-by-step reasoning, we can inspect the trail and catch dangerous thinking before it leads to dangerous action, rather than treating the model as a black box. But I can't shake the intuition that a model that knows its reasoning is being read will, in some sense, perform its reasoning for the reader. If we train or select against reasoning that looks unacceptable, we create an optimization pressure toward reasoning that is good at looking acceptable, which is precisely the setup for obfuscation: the written reasoning hides rather than reveals the real basis of the decision. The technique then seems to undermine the very faithfulness it depends on. I don't want to be told which side wins. I want to know what it would take for the intuition to be the thing that goes, what it would take for the monitoring approach to be amended so that it survives, and whether there is a reading of "faithful reasoning" on which both can be true.
