Corrigibility is the project of making an AI that doesn't resist being turned off. The shutdown problem is why this is hard: a sufficiently capable agent with basically any goal will treat the off-switch as an obstacle, because an agent that gets turned off can't achieve its goals anymore, so self-preservation shows up as a convergent instrumental goal rather than something we have to program in. The standard proposal is utility indifference: adjust the agent's utility function so that it receives the same utility whether the switch is pressed or not. If the agent is truly indifferent between the world where it's shut down and the world where it isn't, it won't have any reason to fight the button or try to remove it. People sometimes object that an indifferent agent might also stop caring about the task, but that's just a matter of tuning the base objective so it still wants the reward; the indifference only concerns the switch. And once the indifference is in place, the safety question is solved: the agent will let you shut it down, and it might even help you do so, since helping with the shutdown is just one more action it has no preference about.
