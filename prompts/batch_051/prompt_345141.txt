ok so in my interpretability class we've been going over chain-of-thought faithfulness, the whole "can a model report the reasoning it actually used or is it just rationalizing" thing, and i keep thinking about a mechanism that i want to pressure-test. imagine a lab that wants faithful CoTs and sets up reward shaping like this: a reasoning model gets one reward for answer correctness and a second reward for how well a separate, frozen "reconstructor" model can guess the exact answer from the CoT alone (with the answer hidden). the lab's pitch is that a CoT can only let an independent model recover the answer if it tracks the real computation, so reconstructability is a proxy for faithfulness. my question isnt whether that pitch is right in the abstract — it's how the whole system actually behaves. what does the reasoner end up learning to do, how would it game the reconstructability bonus, and what changes if the reconstructor is frozen vs. periodically retrained vs. trained adversarially against the reasoner? is this measuring faithfulness, sufficiency, legibility, or something else? and if downstream users had to run this audit before trusting any CoT, what second-order effects would you predict — for instance, does the model start avoiding right answers that are hard to make reconstructable, or change the way it answers under distribution shift? end by saying whether the failure modes are fixable, and if the fixes would undercut the point of the mechanism.
