I’ve been arguing with a friend about Aristotle’s sea battle and I tried to turn one side of the dispute into a numbered argument so we’d stop talking past eachother. The argument goes like this:

(1) Suppose it was true yesterday that there will be a sea battle today.
(2) If it was true yesterday that there will be a sea battle today, then, given only what had already happened up through yesterday, today’s sea battle was guaranteed.
(3) Whatever is guaranteed by what had already happened up through yesterday cannot now be prevented by anyone.
(4) So if it was true yesterday that there will be a sea battle today, no one can now prevent the sea battle.
(5) The same logic runs the other way: if it was false yesterday that there will be a sea battle today, then no one can now prevent the sea battle’s not happening.
(6) Either it was true yesterday or it was false yesterday.
(7) So one of the two outcomes, battle or no battle, is unpreventable and the other is impossible; so there are no future contingents after all.

My friend says the fishy step is (2), because true yesterday only settles what the world is like if its truthmaker had already been settled, or something, but that sounds like he’s just denying that claims about the future are ever true. I half-wonder whether the real problem is a slide in the word guaranteed between (2) and (3). Is the argument valid? If so, which premise is doing all the work and is it acceptable? If not, which exact step fails, and under what reading of it? Please answer in American English.
