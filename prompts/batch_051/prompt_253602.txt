Consider an argument that has been pressed on me recently. (1) A rational agent is not susceptible to a Dutch book: a finite collection of bets, each at least fair by the agent's own degrees of belief at the time it is offered, whose combined payoff is a loss no matter how the world turns out. (2) If an agent's degrees of belief violate the probability axioms, then such a collection of bets exists. So (3) rationality requires degrees of belief to conform to the probability axioms.

Now run the same reasoning on logical non-omniscience. Suppose an agent assigns credence 0.9 to a complicated logical truth T, a long disjunction they have not yet recognized as a tautology. By their lights, a ticket that pays $1 if T is worth 90 cents, so a bookie who has worked through the derivation can buy such a ticket from them for 91 cents, a sale the agent regards as favorable. Since T is a logical truth, the agent pays out $1 with certainty and is guaranteed to lose 9 cents. By (1), the agent is irrational. But any realistic agent has some unrecognized tautology of this kind, so the argument seems to show that rationality requires logical omniscience, which is far more than probabilism was supposed to demand.

Where does this argument go wrong? Identify the premise or step you would reject, explain why it initially looked harmless, and say what rejecting it costs the original Dutch book argument for probabilism. If you think the original argument survives in a restricted form, state that form and show how it blocks the logical omniscience conclusion.
