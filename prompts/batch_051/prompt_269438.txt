You are a professional philosopher working in value theory and population ethics. Approach the task carefully and start by brainstorming several candidate scenarios and their numerical profiles before settling on your final design. Write your answer in American English.

Construct a thought experiment to the following specifications.

Setup. We are comparing outcomes that differ in two goods. Let N be the number of ordinary conscious beings in an outcome, and let H be their average felt well-being on a bounded 0-to-100 scale. Three proposed rules for combining the two goods are on the table:

- Additive: overall value = N + H, once N and H are expressed in a common unit of value.
- Multiplicative: overall value = N × H.
- Lexical (consciousness first): rank outcomes first by N, and use H only to break ties in N.

Build three outcomes—call them A, B, and C—such that each rule ranks a different outcome first and no two rules produce the same complete ranking of all three. Constraints:

1. Each outcome must contain only ordinary conscious beings—humans or familiar nonhuman animals whose sentience a mainstream audience would accept—living lives that can be described concretely. No infinite populations, no supernatural beings, no experience machines, no beings with exactly zero or exactly maximal well-being, and no stipulation that some individuals' welfare counts for less than others'.
2. Describe each outcome in qualitative terms: what kinds of beings exist, roughly how many there are, and what their lives are like. The values of N and H should be read off these descriptions rather than simply stipulated. Then state the numbers you read off.
3. State your normalization for the additive rule: how many units of H one unit of N is worth. Defend that choice briefly, or, if you think no fully principled choice exists, say so and show that the three-way divergence is robust across any plausible normalization within a stated range.
4. Size the case for a seminar handout: each outcome should be described in no more than one short paragraph.

Then run the check. State the ranking of A, B, and C that each rule delivers, and explain in each case why the rule gives exactly that verdict. Identify the single structural feature of the case that is doing most of the work in producing the three-way split. Explain what happens when that feature is removed or softened: which two rules collapse into a standard two-way dispute, and which rule's distinctiveness disappears first. Finish with the strongest objection that a defender of each rule would raise against the way the case is constructed—in particular, the additive defender's objection to your normalization and the lexical defender's objection to treating a huge number of barely-welfare-positive lives as automatically more valuable. This case is intended for a seminar on how values combine, so the verdicts must be generated by applying the rules to the described lives; a case that simply stipulates the verdicts fails.
