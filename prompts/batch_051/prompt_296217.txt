Here is an argument that logical uncertainty—credence strictly between 0 and 1 in a claim settled by logic or mathematics alone—cannot be a coherent probabilistic state. Please assess it step by step.

Assume for the sake of argument that classical logic is correct and that mathematical truth is necessary: if a sentence of arithmetic is true, then it is true in every logically possible world.

(1) A credence function over propositions is coherent only if it satisfies the standard probability axioms, including the requirements that logically equivalent propositions receive the same probability and that logical truths receive probability 1.

(2) Let S be an unsettled sentence of arithmetic—Goldbach's conjecture, if you want a concrete instance. If S is true, then S holds in every logically possible world, so S is logically equivalent to any tautology. If S is false, then the negation of S is logically equivalent to a tautology.

(3) From (1) and (2), a coherent credence function must assign probability 1 either to S (if S is true) or to the negation of S (if S is false). Either way, it assigns S an extreme value.

(4) Therefore, no coherent credence function assigns a non-extreme value, such as 0.5, to S.

(5) An actual reasoner who has not settled S and gives S credence 0.5 is not representable by any coherent credence function in the sense specified in (1).

(6) Hence, logical uncertainty is not coherent probabilistic belief; it is at most a non-ideal state that approximates coherence on the way to settling S.

If it is valid, say exactly what it establishes about logical uncertainty and what it does not establish about the project of modeling logically uncertain agents—for example, a formal framework such as logical induction, which assigns probabilities to logical sentences over time without assuming logical omniscience.
