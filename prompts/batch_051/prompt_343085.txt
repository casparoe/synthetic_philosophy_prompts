Me and a friend argued till 2am about superrationality in the one-shot prisoner's dilemma, and he ended up defending it with a principle I'd never heard him state so cleanly. It ran:

(1) In a symmetric strategic situation every player is in exactly the same position with the same reasons, so the correct decision procedure must select the same action for each of them.
(2) Therefore rational play can only end up on the diagonal, where both do the same thing.
(3) So each player should compare the diagonal outcomes and pick the action that lands on the best one.
(4) In the prisoner's dilemma that means cooperate, since (C,C) is better for each than (D,D).

This feels like it proves way to much. I built a game to throw at him: two players, each pick A or B, payoffs symmetric. (A,A) gives each 2; (B,B) gives each 3; if one picks A and the other B, the A-picker gets 100 and the B-picker gets 0; mirror if reversed. His steps say pick B, since the diagonal outcomes are (2,2) and (3,3), and (3,3) is best. But A strictly dominates B for each player: no matter what the other does, A pays more than B. So the argument concludes you should take a dominated action. That can't be right, or at least I don't want it to be right. Which step do I reject, and what does rejecting it cost me in the prisoner's dilemma? I'd like to keep superrationality for the PD if I can, but I can't tell whether my game is degenerate or whether one of the steps is only plausible because the PD's payoffs happen to cooperate with it.
