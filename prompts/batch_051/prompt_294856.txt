You are grading a take-home exam in a philosophy of language course. The exam question was:

Explain how a Millian (direct-reference) theorist and an abstract-artifact theorist would each handle the name "Sherlock Holmes." In particular: (i) Does "Sherlock Holmes" refer to anything? (ii) Is the sentence "Sherlock Holmes was a detective" true, false, or neither, read as a claim about the actual world? (iii) Distinguish a sentence's being true from its being true in the Sherlock Holmes stories. Then say, for the sentence "Sherlock Holmes had a left elbow," whether it is true in the stories, given that Conan Doyle never explicitly says that Holmes has a left elbow, and justify your answer using the view you prefer.

The student answered:

On a Millian view, a proper name's only semantic contribution is its referent, so "Sherlock Holmes" has no referent and is an empty name. A sentence containing an empty name either fails to express a proposition or expresses a gappy proposition, so "Sherlock Holmes was a detective" is not true; I will call it false. This does not make the stories false, because being true in a fiction is different from being true in the actual world: in the stories, Holmes is a detective. The abstract-artifact view handles this better, since it takes the name to refer to the character Conan Doyle created, and since the character is a detective, the sentence comes out true after all. As for the left elbow, Conan Doyle never says that Holmes has one, so it is not part of the stories and is false in the fiction unless we add the unstated premise that Holmes is a normal human being. With that premise added, it becomes true in the fiction.
