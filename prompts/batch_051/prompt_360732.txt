Hey, could you sanity-check a student argument for me before I write comments on it? In my metaphysics seminar we've been on the special composition question, and one of my students submitted this numbered argument that composition never happens — braver than most. I want to tell him exactly where the mistake is, if there is one, rather than just muttering that it seems too quick. Here it is:

(1) If tables exist, a table is made entirely of many tiny particles.
(2) Either the table is identical with those particles, or it is distinct from them.
(3) The table can't be identical with the particles, since the particles are many and the table is one, and one thing can't be identical to many things.
(4) But if the table is distinct from the particles, then the table and the particles are two distinct occupants of the very same region at the same time.
(5) Two things can't occupy exactly the same region at the same time.
(6) So the table is neither identical with nor distinct from the particles, which is a contradiction.
(7) Since the same goes for any composite object, no composite objects exist.

Is this argument valid? If not, tell me the exact step and the reading on which it fails. If it is valid, which premise should a defender of ordinary objects reject, and what metaphysics does rejecting it force them into? Keep it tight — I don't need a survey.
