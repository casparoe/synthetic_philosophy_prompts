I have been working out a way of thinking about chaotic systems that I would like an honest assessment of. I call it "descriptive expiry." The butterfly effect, as usually stated, sounds like a causal claim: tiny causes grow into large effects. I think that is the wrong register, and that the interesting failure in a chaotic system is representational rather than causal. Take any finite-precision description of a system's state at a time—a weather station's measurements, a rounded initial condition, a finite string of digits. Determinism guarantees that the true state evolves along one exact trajectory. But the description does not pick that trajectory out uniquely: states consistent with the description diverge exponentially, so there is a characteristic timescale after which the description is compatible with a vast spread of mutually inconsistent futures. I call that timescale the description's expiry. Even when a system settles onto a strange attractor, the attractor can be mapped, but any finite description of where the system currently is on it still expires. Doubling measurement precision buys only a fixed extension of that expiry, which is why better data improve weather forecasts so modestly.

I have come across the standard vocabulary—Lyapunov time, sensitive dependence, shadowing, coarse-graining—but none of it seems to name what I mean: not the growth of an error, but the point at which a finite description stops individuating any future at all. I want to know whether this is a real distinction or a metaphor dressed up. In exactly five numbered items, each a sentence or two, with no introduction or conclusion, give me: (1) the strongest reconstruction of my view; (2) the nearest existing concept and whether mine genuinely differs from it; (3) the strongest objection to treating the butterfly effect as representational rather than causal; (4) a concrete case where my view would mislead someone; and (5) your verdict on whether the core idea survives, needs revision, or should be abandoned.
