Ok, here's something I've been chewing on. The standard argument that you should defect in a one-shot prisoner's dilemma runs like this: whatever the other player does, I do better by defecting — if they cooperate I get the temptation payoff rather than the reward payoff, and if they defect I get the punishment payoff rather than the sucker payoff. Since my move doesn't causally affect theirs in a one-shot simultaneous game, defection strictly dominates cooperation, so rational players defect and mutual defection is the only rational outcome.

Now change the setting. The two players aren't two independant humans; they're two instances of the same AI system — exact copies, same weights, same prompt, same deterministic policy — and each one knows the other is an identical copy running the same computation. So my move and the other player's move are no longer independent in the usual way. If I cooperate, the copy cooperates too; if I defect, the copy defects too. It no longer seems coherent to suppose that I defect while the other cooperates, which is exactly the kind of supposition the dominance argument seems to need.

Does the standard argument survive this? I can see it going a few ways: (a) it still works, because each instance still has two available actions and there's still no causal wire between the two machines; (b) it breaks, because the premise that my move doesn't affect theirs is false in every sense that matters, and rational players instead cooperate; (c) it still works but only because the situation isn't really a prisoner's dilemma anymore once the choices are that tightly coupled. I want to know which premise of the standard argument is doing the actual work, whether it still holds for identical deterministic copies, and what the least-damaged repaired argument says about the copies case. If you think it's no longer a PD, say what game it becomes and whether that rescues or buries the original argument.
