For a piece I'm writing about embodied cognition, I interviewed an enactivist who kept saying perception doesn't involve representations—it's something an organism does, not something it computes. I tried to spell out the standard objection as a numbered argument, and now I cant tell whether it's a sound argument or a trick.
(1) A system can count as being wrong about things only if it has some internal state that is supposed to be right or wrong about how things are.
(2) Perceiving organisms do get things wrong—illusions, misjudging distance from a moving train, and so on.
(3) So perceiving organisms have internal states that are supposed to be right or wrong about the world.
(4) An internal state that is supposed to be right or wrong about the world just is a representation.
(5) So perception must involve representations.
(6) Therefore the enactivist view that perception is non-representational is false.
I suspect the enactivist would dig in at (1), but I also think (4) might be doing more work than it looks. Which step exactly fails, if any, and what is the corrected version of it? If the argument is valid, is the conclusion one an enactivist has to accept?
