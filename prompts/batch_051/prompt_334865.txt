I work as a software engineer on a team that ships an LLM-based assistant layered with tools, a memory file, and a system prompt, and we have a recurring argument about whether our deployed system is properly called an agent, a simulator, a tool, or something else. I would like you to write a classification instrument for this debate: a decision tree (or a short "which position do you actually hold?" quiz with a scoring key) that sorts a person into a position on the basis of what they say about concrete cases, not on the basis of which label they like. The target audience is my engineering colleagues, who have no formal philosophy background, so every branch question should be answerable by someone who has built or used these systems but does not know the literature.

The leaves should include at least the following positions (you may split or rename them if you think that is more accurate): the system as a goal-directed agent with beliefs and desires in roughly the ordinary sense; the base model as a simulator whose outputs are sampled personas or characters, none of which is the model itself; the wrapper or scaffold (the outer loop, tools, and memory) as the agent, with the model as a component like a processor; the model as a stochastic parrot or predictive-text engine with no agency at all; the human-plus-model-plus-tooling ensemble as the real unit of agency; and a deflationary or fictionalist view on which "agency" is merely a useful projection and no component deserves the label. Build the tree from the logical space first: state the branching questions, show which combinations of answers they allow, then locate the named positions within that space, and explicitly note any combinations that are unoccupied, saying for each whether you think it is empty because the position is incoherent, unattractive, or merely unexplored. Also flag any pair of leaves your tree cannot really separate.

The branching questions should probe the commitments that actually split these views. Good candidate questions would be things like: whether the system can usefully be described as having a goal that persists across separate sessions even when the prompt is rewritten; whether changing the system prompt from "You are a helpful assistant" to "You are a pirate" changes the system's own state of mind or merely changes which character is being simulated; whether adding an outer loop that calls APIs and writes to memory creates an agent that was not there in the frozen model alone; and whether "choosing" between two continuations of the same context is different in kind from a human choosing between two things to say. You need not use exactly these, but they indicate the level of concreteness I am after. Aim for roughly seven to ten branch questions and ten to fourteen leaves, and please write the entire answer in British English.
