A friend rebuilt an argument I'd read and now I can't locate the step that does the damage. (1) If 2 is an object, then there should be a fact of the matter about whether 2 is an element of 4. (2) On one standard set-theoretic reduction, 0 = ∅, 1 = {∅}, 2 = {∅,{∅}}, 3 = {∅,{∅},{∅,{∅}}}, and 4 = {∅,{∅},{∅,{∅}},{∅,{∅},{∅,{∅}}}}; on this construal 2 ∈ 4 is true, since 2 is among 4's elements. (3) But another equally workable reduction takes each number to be the singleton of its predecessor: 0 = ∅, 1 = {∅}, 2 = {{∅}}, 3 = {{{∅}}}, and 4 = {{{{∅}}}}; here 2 ∈ 4 is false. (4) If the two reductions work equally well for arithmetic, then whether 2 ∈ 4 is true is an artifact of the encoding we adopt, not a fact about the numbers themselves. (5) So there is no fact about which objects the numbers are. (6) If there is no fact about which objects the numbers are, then numbers are not objects. (7) But arithmetic appears committed to numbers as objects, and a claim like 2 ∈ 4 should be determinately true or false. Which step should be rejected, and what does a view give up in rejecting it?
