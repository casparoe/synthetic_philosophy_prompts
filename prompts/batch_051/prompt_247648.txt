There's a familiar argument for fanaticism about the far future, and I want you to stress-test it. It goes roughly like this: (1) if civilization doesn't permanently collapse, the total number of conscious lives that will eventually exist is astronomically large; (2) some things we could do in the present nudge the probability of permanent collapse by a tiny amount; (3) a tiny probability difference times an astronomical number of future lives is still an enormous expected value; so (4) those far-future-oriented actions dominate everything else we might do with our time and resources. Call this the Far-Future Dominance Argument.

Now layer in Bostrom's simulation trilemma. As I understand it: if running vast numbers of high-fidelity ancestor simulations is physically possible for a technically mature civilization, then either (a) almost no civilization like ours makes it to that point, or (b) almost none of the civilizations that make it choose to run many such simulations, or (c) we should think we are probably living in one of those simulations, because simulated conscious minds would vastly outnumber original ones.

The thing I cant figure out is whether taking the trilemma seriously should make me much less fanatical about the far future. It seems like it cuts both ways. On one hand, if we're probably simulated, then the huge future I'm trying to affect is either going to be shut off by the simulators, or is lower-stakes than the base-level future, or my attempts to reduce extinction risk are themselves part of the script. On the other hand, the Dominance Argument never said the future lives had to be base-level lives; if simulated people suffer and flourish as much as we do, the expected-value arithmetic should go through unchanged inside the simulation.

What I want is a premise-by-premise diagnosis. Which premise of the Far-Future Dominance Argument does the simulation trilemma actually put pressure on, and how exactly? Does the argument survive as-is, does it need a weakened or reworded version, or is it dead once you take the trilemma seriously? If there's a repaired version, state it precisely and tell me what it no longer lets me conclude.
