Lately I've been trying to get my head around the liar paradox, after a argument with a friend who thinks logic is basically broken. The standard liar sentence mentions itself, so I figured self-reference was the whole problem, but then I saw Yablo's version — where no sentence refers to itself — and it still seems to blow up. Let S1, S2, S3, ... be an infinite list, and each Sn says "every later sentence Sm (for m > n) is false." Now:

(1) Suppose some sentence in the list, say Sk, is true.
(2) Then what Sk says is the case, so every Sm with m > k is false.
(3) In particular, S(k+1) is false.
(4) But S(k+1) says every Sm with m > k+1 is false. Since by (2) every Sm with m > k is false, it follow that every Sm with m > k+1 is false.
(5) So S(k+1) says something that is true; hence S(k+1) is true.
(6) That contradicts (3). So no Sn in the list is true.
(7) If none is true, then S1 is false.
(8) But S1 says every Sm with m > 1 is false. For S1 to be false, at least one later Sm would have to be true.
(9) But that contradicts (6).

So we get a flat contradiction, and not one of these sentences mentions itself. Tell me straight: is the argument valid? If not, exactly which step breaks, and what's the correct version of it? If it is valid, which background assumption should I reject — that the list can be formed, that a sentence is true iff what it says is the case, excluded middle, or something else? And does this mean self-reference was never the actual culprit in the liar paradox?
