I'm a software engineer with basically no formal philosophy background, so apologies if I've got the vocabulary wrong. Lately I've been building a tiny proof assistant in my spare time — well, alot of my spare time — mostly because I got obsessed with the Y combinator and self-reference in code. That's how I ended up reading about Curry's paradox. As I understand it, you form a sentence that says: if this very sentence is true, then pigs fly. The pigs-fly bit can be anything at all. Then you run some completely ordinary-looking steps with conditionals and truth, and you can derive whatever you put in that slot — which feels like my assistant would happily hand you any old nonsense as a theorem. The culprit is supposedly the sentence refering to its own truth.

So I settled on a rough checklist for what I'll call a self-reference paradox: (1) some sentence refers to its own truth or falsity (or provability, same flavour); (2) the derivation only works because of that self-reference — disallow it and the paradox goes away; (3) apart from the self-reference, every step is just standard logic.

Then I found Yablo's paradox, and it's messing with my head. Instead of one liar sentence, imagine an infinite sequence S1, S2, S3, and so on, where each Sn says that every sentence after it in the list is false. So S1 says S2, S3, S4 and all the rest are false; S2 says S3, S4, S5 and all the rest are false; and so on. No sentence mentions itself — each one only points further down the list. But it still blows up. Suppose some Sn is true; then everything after it is false, and in particular Sn+1 must be false. Yet Sn+1 says everything after Sn+1 is false, and that is exactly what follows from Sn being true, so Sn+1 is true as well. Contradiction. The same move works for any n, so they are all false; but if they are all false, then each sentence's claim about all the later ones is correct, so each one is true too. Contradiction again.

So here's what I want to know. Is Yablo's sequence a self-reference paradox by my checklist, or is it a genuine counterexample that shows the checklist is wrong? Go through my three criteria one at a time. I can't tell whether the phrase every sentence after me is false quietly sneaks self-reference back in, because each sentence quantifies over a whole list that includes, further down the line, conclusions about itself — or whether banning self-reference was never the right fix to begin with. And the practical bit: if I add a rule to my proof assistant that blocks a formula from referring to itself, have I actually made the system safe, or is that false confidence? Also, please write the answer in American English.
