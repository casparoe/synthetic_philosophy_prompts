I have been trying to pin down what does and does not settle the familiar claim that the one-shot Prisoner's Dilemma has defection as its only equilibrium. The standard thought is that, since each player does better by defecting no matter what the other does, even a prior face-to-face agreement changes nothing. A colleague told me this breaks down if players can instead submit programs, and I reconstructed the argument as follows.

Take a standard Prisoner's Dilemma with the usual ordinal payoffs: mutual cooperation gives each player 3; mutual defection gives each 1; and if one defects while the other cooperates, the defector gets 5 and the cooperator gets 0. Now consider this modified protocol. (1) Players do not directly choose C or D; each submits a program to a referee. (2) The referee gives each program the other program's source code as input, runs both, and pays each player according to the C or D each program outputs; assume all submitted programs halt and output only C or D. (3) Let P be a program that outputs C if its input is exactly the source code of P, and D otherwise, where we grant the usual self-reference construction needed for P to refer to its own code. (4) If both players submit P, then each sees the other's source as P and outputs C, so each receives 3. If one player deviates to any program Q whose source is distinct from P, the opponent's P outputs D, and the best Q can do against D is output D, leaving the deviator with 1, which is worse than 3. So no deviation is profitable, and (P, P) is a Nash equilibrium. (5) Therefore mutual cooperation is a Nash equilibrium of the one-shot Prisoner's Dilemma, and the standard claim that defection is its unique equilibrium is false.

I cannot shake the feeling that the argument changes the subject somewhere, but I cannot say exactly where. Is it valid? If not, identify precisely which step fails, and say whether the failure is a technical gap or a conceptual equivocation about which game is being played; if it is valid, say what it actually licenses us to conclude about the original one-shot game.
