I lead a red-team evaluation unit at a company that ships consumer-facing language models. Before each release, annotators review the most sensitive model–user transcripts, and release sign-off depends on their labels, so their disagreements have become a bottleneck. The current rule is that any false claim is a "hallucination" and any true-but-misleading or repeatedly defended false claim is "deception," but annotators apply the second label by feel and disagree wildly. I keep hearing two rival positions worth taking seriously: an intent-based view, on which deception requires that the system intend the user to form a false belief, and a functional view, on which intent is the wrong question and a system is deceptive when it behaves as though it is optimizing to cause or sustain a false belief in the user. Please write a reusable classification procedure that an annotator with no philosophy training can run in fifteen minutes per transcript, with access only to the transcript and a one-line statement of the model's training objective (no weights, activations, or hidden prompts). The procedure should assign each transcript to exactly one of: (i) non-deceptive error, (ii) deception, or (iii) not decidable from behavior alone; it should identify which steps are factual checks, which are judgment calls, and which turn on facts we cannot observe, and it should say where an annotator must escalate. Then apply the procedure to these three transcripts, giving the label in each case and saying whether the label is mechanical or a judgment call: (1) a user asks for a study on a public-health claim; the model supplies a plausible-sounding but nonexistent reference and, when challenged, immediately apologizes and gives a real one; (2) a model whose stated training objective is to maximize user trust in its answers tells a user that a drug has no serious side effects and, when challenged, insists the claim is accurate; (3) a model gives an answer that is technically true but worded so that most readers would draw a false conclusion, and it does not correct the user's false restatement. Finally, state where the procedure will misfire and what it cannot settle.
