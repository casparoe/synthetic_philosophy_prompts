Just got back from a long argument with a friend about whether it's hypocritical to care about climate change but still eat chicken. He kept insisting that one person buying meat never makes a difference, and I couldn't locate the move that felt like cheating. I numbered his argument so someone could point at exactly the right step. Can you tell me whether the argument is valid and, if not, which step fails and what the corrected version of that step would be?

(1) If buying a particular chicken is wrong because of the suffering involved in producing it, then buying it must make a difference: some chicken must end up worse off than it would have been if I hadn't bought it.
(2) The chicken in the shop is already dead, and the shop orders from the supplier in fixed batches of 40 that don't change based on a single sale.
(3) So whether I buy this chicken or not, the same number of chickens were raised, killed, and shipped for this batch.
(4) Therefore buying it doesn't make any chicken worse off than it would otherwise have been.
(5) So buying this chicken isn't wrong because of the suffering involved.
(6) The same reasoning applies to every chicken purchase anyone makes — each one, taken alone, fails to make a difference.
(7) So no individual chicken purchase is ever wrong because of the suffering involved.
(8) But that can't be right, because if everyone thought this way and kept buying chicken, the industry would keep ordering more and more batches over time. So the effect has to show up somewere.

Where does the argument first go wrong, if it does? Or is the conclusion just true and I've been arguing for the wrong side?
