Examination question:

"In possible-worlds semantics for a single agent, knowledge is often modelled with an accessibility relation. Using this framework, explain the problem of logical omniscience, distinguishing the claim that the agent knows all logical truths from the claim that the agent's knowledge is closed under logical consequence. Then discuss one proposed modification of the semantics that is intended to avoid the problem, and identify the main cost of that modification."

Student's answer:

"In a possible-worlds model, an agent's knowledge is represented by an accessibility relation R on a set of worlds W. The agent knows a formula φ at a world w, written Kφ, just in case φ is true at every world v such that wRv. Both components of logical omniscience follow directly from this truth clause.

First, suppose φ is a logical truth. Then φ is true at every world whatsoever, hence true at every world accessible from w; so Kφ holds at w. The agent therefore knows every logical truth automatically. Second, suppose φ entails ψ and Kφ holds at w. Then φ is true at every accessible world. Since ψ is true at every world where φ is true, ψ is also true at every accessible world, so Kψ holds at w. Thus the agent's knowledge is closed under logical consequence, including consequences whose derivations the agent could never survey.

It is tempting to attribute this to the strong frame conditions of S5, but that would be a mistake. The K axiom and the rule of necessitation are sound over arbitrary frames, so the problem appears already in the minimal normal modal logic K, before transitivity, euclideanness or reflexivity are imposed. The source of the problem is not the frame conditions but the truth clause itself, which quantifies over all accessible worlds.

One might nonetheless try to weaken the frame conditions. Dropping reflexivity would allow dead-end worlds, at which there is no accessible world at all. At such a world the agent would fail to know even the tautologies, since there is no accessible world at which any formula is true. So relaxing the frame conditions seems, after all, to mitigate the component of the problem concerned with logical truths.

A more principled response is awareness semantics. One retains the underlying possible-worlds operator, now interpreted as implicit knowledge, and adds for each agent at each world an awareness set of formulas that the agent 'has in mind'. Explicit knowledge is then defined by: Kφ holds at w if and only if φ is true at every world accessible from w and φ belongs to the agent's awareness set at w. Because the underlying accessibility machinery is unchanged, explicit knowledge retains the K axiom and necessitation; what the awareness clause blocks is closure under logical consequence and logical equivalence, since the agent may be aware of the premises without being aware of the conclusion. The main cost is that awareness sets are left entirely unconstrained, so the account merely replaces one unexplained idealisation with another."
