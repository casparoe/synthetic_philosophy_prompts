The old critique of statistical machine translation, the one Hofstadter pressed hardest, was that it didn't understand a word: it matched n-grams and surface patterns, so it fell apart whenever a sentence required any kind of mental model. I've been trying to work out whether that critique survives the move to LLM translation. Current systems are still, in some loose sense, statistical, and they weren't built to understand anything; but they handle idiom, ambiguity and cross-sentence context in ways the old systems plainly couldn't. Does the argument still go through, or did it depend on the specific shalowness of the earlier systems? I'd want the answer to be precise about which premise the argument actually needs: if the premise is that no system which merely predicts text can understand, that's one claim; if it's that this system has no way to represent what the sentence is about, that's another. Which one is doing the work, and is it still true?
