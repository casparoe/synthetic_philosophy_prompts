i've been chewing on a parallel between decision theory and programming language semantics, and i can't tell whether it's deep or just a vibe. the independence axiom behind expected utility says the value of a lottery should be linear in its parts: if i prefer lottery A to B, i should also prefer a mixture that puts the same weight on A and some common component C to a mixture that puts that same weight on B and C, because C is a shared term that contributes identically to both sides and should cancel. the Allais paradox is a failure of exactly that—people's preference between A and B flips once the same C gets stapled onto both, as if the shared term isn't inert but changes how the rest is evaluated. that looks to me like the difference between a referentially transparent language, where an expression can be swapped for another with the same meaning in any context, and an effectful or context-sensitive language, where the same subexpression does different work depending on where it sits. is this a genuine structural identity, or does the analogy break? what would have to be true of preferences for independence to be the literal analogue of referential transparency, and what prediction of the analogy do real Allais-type choices falsify? and tell me which argument would flip your verdict the other way—or where the parallel is most likely to come apart.
