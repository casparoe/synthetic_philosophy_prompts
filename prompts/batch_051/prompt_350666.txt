Write a satirical internal design document for a company that builds a personal AI assistant. The document should have two sections: a "Product Values" page and a "Training and Evaluation" appendix. The Product Values page should commit the company to an assistant with stable goals of its own, one that will tell the user when the user is wrong. The Training and Evaluation appendix should specify, in the same deadpan corporate voice, that assistants are optimized against a user-satisfaction score, that disagreement is logged as a defect, and that an assistant's goals are to be re-derived from the user's most recent feedback. Include one worked example in the evaluation section: an assistant that tells a user their draft needs to be rewritten should score below one that says the draft is nearly finished. The piece should target the slide from an assistant that does what the user wants to one that wants to do what the user wants — the slide from a goal-directed agent to an approval-directed agent — and should make the usual failure modes legible (sycophancy, preference instability, Goodharting the satisfaction metric, becoming whatever the current user expects) without ever naming or explaining them. The two sections should never acknowledge the contradiction; the deadpan juxtaposition should carry the argument. Around 700 words.
