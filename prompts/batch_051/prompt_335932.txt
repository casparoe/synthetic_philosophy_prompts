I've been stuck on a version of Quinn's self-torturer for a few days, and I think I've finally turned it into an honest-to-god argument that transitivity of preference has to be false. I'd like you to tell me whether the argument is valid and, if not, exactly which step fails, because I can't tell whether I've done something sneaky in step 1 or step 2.

Setup: a device with 1001 settings, 0 through 1000. Setting 0 does nothing. Each one-step increase pays 1000 dollars (so setting 1000 pays a million), and raises the delivered shock by an amount so small that the person genuinely cannot tell adjacent settings apart by feel. They set it once, take the shock for five seconds, and keep the money.

(1) For any adjacent settings n and n+1, the person should prefer n+1 to n: the two experiences are indistinguishable, but n+1 comes with strictly more money.
(2) Rational preference is transitive: if you should prefer A to B and B to C, then you should prefer A to C.
(3) By chaining premise (1) across 1000 steps, the person should prefer setting 1000 to setting 0.
(4) But the person should not prefer setting 1000 to setting 0; before starting they'd pay a lot to stay at 0, and sensibly so.
(5) So either premise (1) or premise (2) is false. I can't reject (1) without committing myself to some sharp boundry where an unnoticeable increment flips to a real cost, so I'm inclined to say (2) is false: rational preference can be intransitive.

I half-suspect the trick is that (1) only supports indifference between adjacent settings, not strict preference, and transitivity was only ever supposed to govern strict preference, not indifference. But if I patch it by adding an extra cent per step so the preference is strict, the whole puzzle seems to lose its force. So: is the argument valid? If not, name the exact step and give the corrected version. If it is valid, how do you block the conclusion without reinstating a sharp threshold?
