ok so i keep having this argument with myself about the imagery debate and i think ive got a distinction that might actually help. pylyshyn is obviously right that there's no literal picture in the head, and kosslyn is obviously right that something image-like is going on when people scan or rotate things. so ive started thinking the image-ness isn't a format, its more like an interface. the underlying representation could be descriptive all the way down, but it feeds into a set of operations that preserve spatial structure well enough that the system behaves as if it had a picture. so the depictive properties are real, but they're properties of the operations, not the storage. i call it 'virtual depictivism'.
