Below is a proof I have seen that there exist two irrational real numbers a and b such that a^b is rational. I know the theorem can also be proved by exhibiting an explicit pair, but I want to understand this particular proof: exactly where, if anywhere, it stops counting as a legitimate proof by constructive or intuitionistic standards.

(1) Let r = √2^√2.
(2) r is either rational or irrational, because every proposition is either true or false.
(3) If r is rational, then a = √2 and b = √2 are both irrational, and a^b = r is rational, so there exist irrational a and b with a^b rational.
(4) If r is irrational, then a = r and b = √2 are both irrational, and a^b = (√2^√2)^√2 = √2^(√2·√2) = √2^2 = 2, which is rational, so again there exist irrational a and b with a^b rational.
(5) Since the existence claim follows on each branch of the disjunction in step 2, the existence claim follows outright.

Is this argument valid in classical logic? If a constructivist says it is not a constructive existence proof, which numbered step is the first one they must reject, and what is the weakest replacement for that step that would make the proof constructive? Is step 5 itself acceptable to an intuitionist, or does reasoning by cases from an unresolved disjunction already smuggle something in? And if the conclusion has an explicit constructive proof anyway, what exactly is this proof missing?
