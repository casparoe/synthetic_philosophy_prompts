Student answer:
Parfit's Repugnant Conclusion says that for any population of at least ten billion people all with very high quality lives, there is some much larger imaginable population of people with lives barely worth living that would be better, other things equal. Total utilitarianism implies this because the value of a population is the sum of individual welfare. Since each barely worth living life is still above the neutral level, each contributes a small positive amount, so if the larger population is big enough its total welfare beats the smaller high-quality population. Average utilitarianism avoids the Repugnant Conclusion because it ranks populations by average welfare, and the average in the large population is much lower than in the ten-billion high-quality population, so the high-quality population is better.

But the Mere Addition Paradox is really a problem only for total utilitarianism. On the average view, adding a group with positive but below-average welfare lowers the average, so the view says the resulting population is not an improvement. That seems consistent with the view, not an objection to it. Critical-level utilitarianism sets a threshold c and counts each life's value as welfare minus c. If c is set above the welfare level of the lives in the large population, those lives each contribute negatively, so the large population does not beat the high-quality population. This blocks the Repugnant Conclusion, and it also handles the Mere Addition Paradox by simply ignoring lives below c rather than saying their addition makes things worse. So the critical-level view is the best way to avoid the Repugnant Conclusion.
