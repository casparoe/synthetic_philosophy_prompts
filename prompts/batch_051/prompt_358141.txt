The student wrote: Zeno's dichotomy says that before you can cover a distance you have to cover half of it, and before that half of that, and so on. Since the half-distances never run out, you'd need to complete infinitely many sub-journeys, and you can't complete an infinite number of tasks, so motion is impossible. The standard Aristotelian response is to distinguish potential from actual infinity: the halves are only potential because nobody actually marks all the halfway points, so the runner never actually completes an infinite number of separate intervals. The modern mathematical response is that 1/2 + 1/4 + 1/8 + ... converges to 1, so the total distance is finite. But that doesn't show the runner can complete infinitely many distinct sub-actions; it only shows the distances sum to a finite amount. The real puzzle is about action, not distance. And the potential/actual infinity reply fails for the same reason: the path is a continuum, and all the potential halfway points are already there in the continuum whether anyone marks them or not, so the runner must pass through them all. So neither response dissolves the dichotomy paradox.
