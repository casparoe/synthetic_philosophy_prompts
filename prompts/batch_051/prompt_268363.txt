Question:

Explain the difference between a vicious and a benign infinite regress. Give one example of each, and then state the general feature that distinguishes them.

Student answer:

An infinite regress is a sequence generated by a rule or principle, where each member brings the same rule into play again, so the sequence never terminates. Regresses are not automatically bad. A regress is vicious when the explanatory task is never completed: the thing we wanted to explain at the first step counts as explained only if the next step is explained, and since there is no last step, nothing ever actually gets explained. A benign regress is one where the first step already satisfies the demand, and the later steps are just harmless byproducts.

A standard vicious regress is the regress of justification. Suppose a belief is justified only if it is supported by another justified belief. Then belief p needs q, q needs r, and so on forever. Since the chain never bottoms out, none of the beliefs is actually justified. Foundationalists stop the regress by allowing basic beliefs, which are justified without support from other beliefs. Coherentists agree that the regress is vicious, but they avoid it by allowing the support relation to run in a circle, so justification loops back on itself instead of running off to infinity.

A standard benign regress is the truth regress. If p is true, then the sentence that says p is true is also true, and the sentence that says that sentence is true is true too, and so on. Each new sentence is generated by applying the truth predicate to the previous one, but the truth of the original p doesn't depend on the later members. The regress just shows that from one true sentence we can always construct another true sentence, and each member of the chain is true as soon as the first one is.

So the general feature is this: a regress is vicious when each step merely defers the original demand to the next step, and benign when the demand is already discharged at the first step and the rest of the chain is just a byproduct.
