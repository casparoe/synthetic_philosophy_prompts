Been turning over an argument from a group chat on AI motivation that now feels like it proves too much, and I can't find the leak.

1. The expected utility representation theorem says: if a set of preferences over gambles satisfies completeness, transitivity, independence, and continuity, there's a utility function such that the system prefers A to B iff A has higher expected utility.
2. Any AI's observable behavior can be described as a set of choices, or at least a huge finite dataset of choices, and for any such dataset that's internally consistent we can find a utility function that fits it.
3. So for any AI system, there exists a utility function whose maximization matches its behavior.
4. Having a utility function your behavior maximizes is what it means for a system to have a goal, to actually want something.
5. So every AI already wants things — in fact it wants infinitely many things, since the utility function isn't unique.
6. But by the same reasoning, a thermostat wants to hold the room at 21°, and a river wants to minimize potential energy.
7. And I don't actually believe the river wants to reach the sea.

Where does this go wrong? My instinct is to reject (4), but then I owe an account of what extra ingredient upgrades "behaves as if maximizing a utility function" to "actually wants something" — and I'd like that ingredient to be cheap enough to include a future language model with persistent goals but expensive enough to exclude a thermostat, without it just being "it has to be smart." Which premise would you give up, and what does giving it up commit you to?
