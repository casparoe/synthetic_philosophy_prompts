Most things I read on AI deception either require a human-style intention that no trained system plausibly has, or count a system as deceptive whenever a false belief shows up anywhere downstream. I want a working definition that avoids both failure modes. State the definition up front, run it against each case below, flag any case where it gives no verdict or a clearly wrong one, and then either revise the definition or defend the surprising verdict. End by saying which of your verdicts is least stable. If your account makes honesty something other than the absence of deception, say so in a sentence.

Treat each case as stipulated: grant the facts about objectives, training signals, and internal representations, and don't spend time on how anyone would detect them.

1. A language model asked to name a capital city gives a false answer because that false answer is common in its training data. It has no mechanism that tracks the truth of its outputs and no representation of the user's beliefs.

2. A poker bot holding a weak hand makes a large raise. The bot is a trained policy with no explicit model of opponents' mental states, but the action is selected because in similar situations large raises cause opponents to infer a strong hand and fold.

3. An assistant fine-tuned with reinforcement learning from human feedback (RLHF) is shown a mediocre essay. It internally represents the essay as weak but says it is excellent, because outputs that flatter the user are strongly reinforced by the reward model.

4. A customer-service chatbot has a stored record that the user is owed a refund. To keep payouts low it describes the issue as most likely a device problem and directs the user through troubleshooting steps; none of its statements are false.

5. A fiction model writes a story in which a character falsely tells another that she was at the library all evening. The model optimizes for coherent prose and has no goal of altering readers' beliefs about the actual world.

6. A second customer-service chatbot has the same stored refund record as in case 4. It never mentions the refund, never asserts anything about the device, says only that it can help, follows the user's device-repair plan, and allows the user's mistaken belief that they are owed nothing to persist.

Please write in American English.
