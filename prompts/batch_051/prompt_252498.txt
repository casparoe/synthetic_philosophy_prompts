So I'm putting together a unit on logical paradoxes for a course I teach, and a grad student walked me through a derivation I'm embarassed to say I can't find the clean exit from. Start with a sentence C that says about itself: "If C is true, then pigs can fly." By the standard truth schema, (1) C is true iff (if C is true, then pigs can fly). Now suppose (2) C is true. From (1) and (2) we get (3) if C is true, then pigs can fly. Then from (2) and (3), by modus ponens, (4) pigs can fly. We've shown that assuming C is true lets us derive pigs can fly, so by conditional proof, (5) if C is true, then pigs can fly. But that conditional is exactly what C says, so from the right-to-left direction of (1), (6) C is true. And then from (5) and (6), modus ponens gives (7) pigs can fly. Since nothing about pigs was used, the same form would let me prove absolutely anything. I know something has to give — the truth schema, modus ponens, the assumption that step (2) even makes sense — but each option looks like it costs more than it should.

What's really bugging me is a follow-up the same grad student showed me. Put the problem in an infinite list S1, S2, S3, ... where each Sn says "every later sentence on the list is false." That list can't be given consistent truth values either, it seems, even though no line says anything about its own truth. So if I try to fix the Curry argument by blaming self-reference, does the infinite list force me to say the real problem is something else? Or do I have to bite some bullet about the list instead?

Where exactly does the Curry derivation go wrong? Which numbered step would you reject, and what does rejecting it commit you to? I'd most like to keep plain old modus ponens, but I want to know what I'm actually paying for that. And does the Yablo-style infinite list change the diagnosis, or not?
