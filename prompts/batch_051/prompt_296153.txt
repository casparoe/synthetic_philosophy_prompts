For the past few months I have been writing small bots for an informal online tournament that a friend of mine runs on a programming forum. Each round, two bots are matched. Before either bot chooses a move, each one is shown the full source code of both entries in the match, including its own. Each bot must then output either `cooperate` or `defect`. The payoffs are fixed: if both cooperate, each gets 3; if both defect, each gets 1; and if one defects while the other cooperates, the defector gets 4 and the cooperator gets 0. While tinkering, I found a rule that puzzles me, and I have been calling it the mirror rule. The bot cooperates if the two source-code listings it is shown are identical, and defects otherwise. When two copies of the mirror rule meet, they see two identical listings, so both cooperate and each gets 3. But if I replace one copy with a modified bot that tries to defect, the unmodified mirror bot sees that the two listings are no longer identical and defects in return; the modified bot never reaches the tempting 4 and settles for 1. So within this setup, the mirror rule seems to make mutual cooperation stable in a one-round match that I had always thought forced defection. It also does not feel like an ordinary commitment, since no one has threatened or punished anyone, and yet each bot can see exactly what will happen.

I cannot tell whether this is something real or just a quirk of exact text comparison. I know the usual prisoner's-dilemma analysis says defecting is the safe play regardless of what the opponent does, and the mirror rule feels like an equilibrium of some kind, though not the one that analysis points to. My question is not really about winning the tournament. I want to know what this configuration is called, if it has a name, and where its exact boundaries are. Does the trick require that each bot actually sees the source code, or would a reliable statement about the other bot's rule be enough? Does it require exact equality, since a fuzzy rule that cooperates with merely similar programs seems easy to game? And how does it relate to nearby ideas like commitments, threats, promises, or the line of thought that a rational player might cooperate by reasoning as though their own choice also determines the other player's choice?
