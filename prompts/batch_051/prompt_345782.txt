I teach a graduate seminar in philosophy of cognitive science, about twelve students, with a single two-hour session set aside for it. Design a runnable classroom simulation that makes the predictive processing picture felt rather than merely stated. Before any of the theory is named, I want students to have run into at least these four effects themselves:

1. No level of the system ever receives the raw input or a full description of the world; what moves between levels is only the mismatch between what the higher level predicted and what the lower level delivered.

2. The very same incoming mismatch can function as evidence that revises the model or as noise to be explained away, depending on how reliable the system takes its source to be.

3. Action works through the same currency as perception: the system changes the world in order to reduce the mismatch it expects, so that perception and action are both attempts to minimize one and the same underlying quantity.

4. With a few slightly wrong assumptions about where noise comes from, the system not only fails to correct itself but confidently settles on a structured misreading — hallucinated order rather than random error.

Please give me concrete rules: who sits at which level, what messages may pass up and down, what each participant is individually trying to optimize, and a scoring or incentive scheme that requires no real money. Materials should be no more than index cards, paper slips, and perhaps a projector. Include a timeline for the two hours and a debrief that maps particular moments in the game onto priors, likelihoods, prediction error, precision weighting, and active inference. Also tell me what will predictably go wrong the first time I run the activity, and which feature of the predictive processing framework it cannot reproduce and I will have to supply myself.
