i've been trying to get clear on when an infinite regress is actually a problem and not just a staircase people imagine. my own proposal, which i've been calling the Backlog Test, goes like this. a regress is vicious just in case each step introduces a new item to discharge a debt the previous item had already run up, and it doesn't discharge the debt but writes a fresh IOU of the same kind. a regress is benign when each later item is not a condition of the earlier one but a free consequence of it, so nothing is left unpaid as you go along. so the "a is F because a instantiates F-ness, and instantiation is itself a relation between a and F-ness, so we need a further instantiation to tie it, and..." regress in the theory of universals comes out vicious, because each new relation was hired to do the tying and the tying never gets done. the "it is true that p, so it is true that it is true that p, so..." regress comes out benign, because each later truth is just something the earlier truth already gaurentees.

i like this test because it explains why those two cases feel different, and it also seems to get the tortoise-and-achilles case about logic right: the tortoise's regress is vicious because each conditional, like "if p and if p then q, then q", was introduced as a licence to infer and then immediately turns into just another premise that needs its own licence. (or maybe that one is where my test gets too harsh, i'm not sure.)
