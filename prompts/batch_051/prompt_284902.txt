I'm intrested in objections to a particular reading of Gödel's 1949 rotating-universe work, namely that the model shows time has no objective lapse and that becoming is in some sense ideal. So far I have these objections, and I dont need them reworded or recombined:

1. The toy-model objection: the Gödel solution is homogeneous, rotating, and needs a carefully chosen negative cosmological constant; our universe is observationally not like that, so the model is too exotic to support conclusions about actual time.

2. The local-passage objection: even in a spacetime with closed timelike curves, observers have proper time, local entropy gradients, and memories; those are enough for local becoming, even if there is no global now.

3. The global-time-function objection: the argument assumes real objective passage requires a single cosmic time coordinate or global simultaneity; one can reject that assumption, in which case the absence of a global time function does not show time is unreal.

4. The B-theory-neutralization objection: if spacetime eternalism is right, special relativity already blocks objective passage; Gödel's closed timelike curves are then just more global structure, not an extra argument for idealism.
