Solomonoff's theory of inductive inference is standardly read as a formal vindication of Occam's razor, and the classical argument runs something like this. Take all computable hypotheses about an observed sequence and assign each a prior probability that falls off exponentially with the length of the shortest program that generates its predictions. Across the space of computable environments this prior is universal: its expected predictive error is within a constant factor of that of any computable prior whatsoever, so an ideal agent with unlimited computation loses at most a constant factor by adopting it. Simplicity, in the precise sense of short program length, therefore looks like the rationally mandatory default rather than a mere taste.

Now suppose the agent is resource-bounded in one specific respect: it has a fixed per-step budget for running a hypothesis before the next prediction is due, and must weigh how cheaply a hypothesis can be evaluated alongside how well it fits the data. These two orderings diverge. A very short program may take an astronomical number of steps to emit its next symbol, while a massive lookup table, though costly to specify, returns an answer almost instantly; the Solomonoff prior ranks the short program far above the table, but the bounded agent may rationally prefer the table. Worse, the usual to-within-a-constant-factor and up-to-an-additive-constant qualifications, which in the ideal setting absorb the choice of reference machine or programming language, can dwarf any finite time budget a real agent will ever have.

Does Solomonoff's argument for Occam's razor survive this change of assumption? Which premise is actually under pressure, and is there a repaired version that yields a weaker but still useful rule for how a resource-limited agent should trade simplicity against evaluation cost?
