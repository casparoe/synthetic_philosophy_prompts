An argument I keep meeting for bivalence—the thesis that every statement is either true or false—runs like this. Take any statement S. Reality must either be as S says it is or not as S says it is, so 'S or not-S' is true no matter what; but a disjunction is true only if one of its disjuncts is true; therefore S is either true or false. Now consider a semantics for vague language on which a sentence has a definite truth value only if it is true, or false, on every admissible way of making its vague terms precise, while 'S or not-S' can still be true on every such way because each way settles S one way or the other, though the ways need not all settle it the same way. In such a semantics, the law of excluded middle survives even while borderline statements are neither true nor false. Does the old argument for bivalence survive this development? I would like to know exactly which premise is under pressure, whether a repaired argument for bivalence could avoid the problem and what it would have to assume, and whether the original argument still establishes something important once it can no longer establish full bivalence.
