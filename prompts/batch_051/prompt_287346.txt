I keep going back and forth on whether Noether's theorem explains conservation laws or just repackages them. Here's the skeptical argument I've been chewing on:

(1) A symmetry of a law is just a transformation that maps any solution of the law onto another solution.
(2) Time-translation symmetry is the transformation that shifts any solution forward or backward in time.
(3) That symmetry is just a way of saying the laws don't privilege any particular time.
(4) Noether's theorem says that when a law has a symmetry in this sense, there is an associated conserved quantity (energy, for time-translation symmetry).
(5) So the theorem moves from one description of the set of solutions (the symmetry) to another description of the same set (the conserved quantity).
(6) One description of a set of solutions doesn't explain another description of the same set; it just reorganizes the same information.
(7) Therefore Noether's theorem doesn't explain energy conservation; it shows that 'the laws are time-translation symmetric' and 'energy is conserved' are two labels for the same package.
