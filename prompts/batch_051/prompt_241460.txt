For a while now I've been kicking around a distinction I keep reaching for whenever someone plays the "what if everyone did that?" card (Kant, Singer, my roommate, etc.). I call the two versions "burst" and "steady-state" universalization, for lack of better words.

Burst universalization is when you run the rule as if every agent acts on the maxim in the same instant. Like a load test that fires every request at once. If everyone withdrew their money on the same tick, or everyone took the shortcut, or everyone stole, the whole system falls over immediately.

Steady-state universalization is when you run the rule as a standing policy over time, where people enter and exit, and not everyone is doing the thing at the same moment. Like "what if everyone became a nurse?" As a profession that can persist indefinitely. Read as burst it means everyone quits their job on the same morning and the world collapses before lunch.

My claim, I guess, is that a lot of the damage done by the naive "what if everyone did that?" argument comes from quietly running the burst version when the maxim really only commits you to steady-state. And some of Kant's "contradiction in conception" cases seem to depend on a burst reading, while Singer-style "if everyone in rich countries gave X" reasoning is clearly steady-state. So maybe alot of the real disagreement isnt deontology vs consequentialism but just, like, a scheduling assumption.
