So in my phil of math class we did Thomson's lamp, and I started messing around with a variation. Take the usual timing: the lamp is off at t=0, and the switch is operated at t=1/2, then t=3/4, then t=7/8, and so on. But instead of a two-state on/off switch, give the lamp a dimmer dial that can take any real value from 0 (off) to 1 (full brightness), and assume the dial moves continuously between operations. Start it at 0, and at each operation turn the dial to exactly halfway between wherever it is at that moment and 1. So the settings after each operation are 1/2, 3/4, 7/8, and so on. Does the lamp now have a determinate final setting at t=1, and if so what is it? How does this change the standard diagnosis of Thomson's lamp? In particular, the brightness values converge to 1, but no finite operation ever puts the dial all the way at 1 — does that convergence actually settle the puzzle, or is there still somthing weird about saying the lamp ends up fully on?
