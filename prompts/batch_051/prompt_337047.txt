I'm a software engineer, so logic always felt like the one place where a statement cant be both true and false. Russell's paradox always looked to me like a straight-up proof that naive set theory is broken: unrestricted comprehension gives you the set of all sets that aren't members of themselves, and from there you derive that this set both is a member of itself and isn't. Contradiction, so the theory is dead. But I recently came across paraconsistent logics, where a contradiction doesnt automatically explode into every statement being true—they let some contradictions sit there without the whole system trivializing. Now I'm unsure what Russell's paradox actually proves. Does it refute naive set theory, or does it only refute it if you've already assumed classical logic with explosion? Can someone who accepts a paraconsistent logic keep unrestricted comprehension and just live with the contradiction? I'm less interested in whether paraconsistent set theory is a good practical choice, and more in what the original argument needed to be true. Which premise does the paraconsistent move put pressure on, and is there a repaired version of Russell's point that still lands even if you reject explosion?
