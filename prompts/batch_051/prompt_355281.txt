Me and my friend are arguing because he wrote a program that searches for counterexamples to an arithmetic conjecture we came up with. After checking like 10^14 cases, he says the fact that nothing turned up is evidence the conjecture is true, the same way not seeing a black swan is evidence all swans are white. I disagree, and I made this arguement:

(1) If a math statement is true, it's true in every possible world, not just this one.
(2) So if our conjecture is true, there's no possible world where it's false.
(3) An observation can count as evidence for a claim only if it's more likely in worlds where the claim is true than in worlds where the claim is false.
(4) But there are no worlds where the conjecture is false, so no observation can be evidence for it.
(5) His failed search is an observation.
(6) So the failed search can't be evidence for the conjecture.

This seems airtight to me, but it also seems to say you can never have any reason to believe an unproven math statement, which sounds wierd. Is the argument valid? If not, which step exactly fails and why?
