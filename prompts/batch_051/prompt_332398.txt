A jurisdiction proposes the following rule for professional liability: in medicine, insurance underwriting, and financial advice, a probabilistic statement made to a client is conclusively reasonable if it matches the base rate of the narrowest reference class to which the client belongs for which the professional can cite a published dataset of at least 200 cases; any estimate not tied to such a class is presumed unreasonable. Analyze how this rule would actually behave. What incentives does it create for how professionals construct or select reference classes, and which constructions would it favor? Where are the failure modes—for example, multiple equally narrow classes yielding sharply different rates, adversarially gerrymandered classes built from thin but technically sufficient samples, or classes engineered to contain exactly the client? Does the 200-case floor discipline this behavior, or merely relocate it to a higher level of aggregation? Finally, assess whether the rule can be repaired so that it preserves the legitimate force of base-rate reasoning without pretending that any reference-class frequency settles the probability for the individual case.
