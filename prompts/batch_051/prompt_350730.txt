I've been arguing about the knowledge argument in a reading group that grew out of a rationalist-adjacent forum, and I've noticed that the discussion usually collapses into the familiar replies — that Mary only acquires abilities, or that the setup simply begs the question against physicalism — before anyone pins down whether the central inference even goes through. I want to set those replies aside for now and ask about the reconstruction below, which is my attempt to state the anti-physicalist inference at its strongest.

(1) Before her release from the black-and-white room, Mary knows every physical fact about seeing red.
(2) For reductio, suppose that what it is like to see red is a physical fact. Then there is a physical fact F such that F is identical to the fact that seeing red is like this.
(3) Since Mary knows every physical fact, she knows F.
(4) By Leibniz's law, if F is identical to the fact that seeing red is like this and Mary knows F, then Mary knows the fact that seeing red is like this.
(5) But Mary does not, before release, know the fact that seeing red is like this.
(6) Therefore, by reductio, what it is like to see red is not a physical fact.
(7) Physicalism says every fact is a physical fact. So physicalism is false.

Is this argument valid? If not, exactly which step fails, why it fails, and what the corrected version of that step would look like? If it is valid, which premise should a physicalist reject, and why?
