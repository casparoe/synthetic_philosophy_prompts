Grad student in philosophy of language here. I've basically absorbed the standard Kripkean package: proper names are rigid designators, identity statements with them are necessary if true, and the interesting cases (water = H2O, Hesperus = Phosphorus) are necessary but only knowable a posteriori. What I want pinned down is what would actually have to be true for this to be wrong. Not the usual objections — I know about descriptivism and two-dimensionalism — but the underlying data and results: what linguistic judgements, cross-linguistic patterns, or formal semantics would count against the view by its own lights? For example, would it count against it if some language's names behaved systematically like rigidified descriptions, or if competent speakers consistently treated Hesperus and Phosphorus as possibly distinct in something more than an epistemic way? Which of these would a card-carrying Kripkean have to take as a real cost, and which would they just re-describe? I'd like the defeaters sorted from fatal to merely awkward, plus an honest take on whether the position has been qualified enough that it doesn't stick its neck out anymore — and if so, whether that's a problem. Please seperate what's settled from what's still genuinely contested, and don't pass off a contested view as consensus.
