Here's an argument I keep going round in circles on. Picture two AI agents in a one-shot prisoner's dilemma. They're running bit-for-bit identical deterministic code, get given the same inputs, know all of this, and pick their moves simultanously. No communication, and the payoffs are fully symmetric: both cooperate → 3 each, both defect → 1 each, one defects while the other cooperates → 5 for the defector and 0 for the sucker.

(1) Because the agents run identical deterministic code on identical inputs, they're guaranteed to output the same move.
(2) So the only possible outcomes are cooperate-cooperate or defect-defect.
(3) Cooperate-cooperate is better for each agent than defect-defect.
(4) A competent agent in this setup can see all of that.
(5) Therefore each agent should output cooperate, since that's selecting the better of the two possible outcomes.

I keep feeling like this proves cooperation is rationally forced in this setup, which I gather people call superrationality. But something smells off. Is the argument valid?
