I've been playing Nomic with three friends for a few weeks and we've hit a wall that's honestly more interesting then the game. For anyone who doesn't know it, Nomic is a game where the rules themselves are the moves: you vote to add, delete, or amend rules. Our version started with just two rules. Rule 1: any proposed rule change passes by majority vote. Rule 2: any rule, including Rule 2 itself, can be amended or repealed by a majority vote. That's it.

Last night someone proposed Rule 3: "Rule 3 can never be amended or repealed." It passed 3-1, and now we can't agree on what we're even allowed to do next. I laid out the following argument and nobody could tell me where it goes wrong:

(1) Before Rule 3 passed, Rule 2 let a majority amend or repeal any rule. (2) Rule 3 was adopted by exactly that procedure, so it is a valid rule. (3) Now that Rule 3 is among the rules, any proposal to repeal Rule 3 would, if it passed, violate Rule 3. (4) But Rule 2 is still on the books and hasn't been repealed, and it says any rule can be amended or repealed by majority vote. (5) So a later majority vote to repeal Rule 3 would be permitted by Rule 2 and forbidden by Rule 3. (6) If Rule 2 controls, then Rule 3 never really made itself un-repealable, which is a thing Rule 2 let the majority do. (7) If Rule 3 controls, then Rule 2 has been silently narrowed without anyone ever amending it, which seems to contradict Rule 2's own claim to cover any rule. (8) Either way, one of the two rules doesn't mean what it says. (9) So a game whose rules allow unlimited self-amendment cannot coherently allow a majority to entrench a rule like this.

Tell me exactly which step, if any, fails and on what reading. If the argument is sound, say what that implies we should do with our rules — or what missing rule would fix the mess. I keep suspecting step 4 is doing too much work, but I can't make the suspicion precise.
