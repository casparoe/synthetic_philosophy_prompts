The development I want to press on that is cheap, durable digital memory plus DNA. Location histories, old texts, cloud backups, CCTV, and forensic DNA now preserve exactly the kind of evidence that used to degrade within years — cold cases get reopened precisely because the record doesn't fade any more. So my question is whether the argument for limitation periods survives this change. I used to think the 'moral relevance of time' was doing real work; now I'm not sure how much of it was just the epistemic decay of the file wearing a moral costume. I want the piece to take the argument apart: identify which premise digital memory actually bites on, say whether the argument collapses, needs repair, or survives for the non-evidentiary rationales, and — if a repair is available — state what the repaired argument would claim. Please treat the evidentiary and the non-evidentiary rationales seperately. Don't give me legal history or a reading list; just work the argument. If it turns out to be mostly epistemic, follow that through: which limitation periods should shrink or disappear for well-documented offences, and which should stay because time itself still matters?
