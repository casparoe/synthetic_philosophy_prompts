The classical frequentist objection to single-case probabilities was built for a world in which grounding a probability claim meant specifying a reference class of past trials—patients “of this kind,” dice throws “under these conditions”—and then reading off a long-run frequency. In that world the reference class problem looked fatal: whatever class you chose, the choice seemed arbitrary, and different choices yielded different probabilities for the very same individual event. Now suppose the choice is no longer made by an analyst. A clinician facing a particular patient can query a database of millions of prior surgeries and have an algorithm solve for the grouping that best predicts survival for this patient, using whatever features and interactions it finds, including features no clinician anticipated. The output is a single-case probability: not a frequency in a hand-picked class, but the algorithm’s estimated probability for this individual.

Does the classical frequentist objection survive this development, or has it been quietly dissolved by replacing an arbitrary human choice of reference class with an opaque optimization over classes? If it survives, say exactly where the arbitrariness now resides—in the choice of the database, the loss function, the matching threshold, or elsewhere—and whether that new location is any less damaging than the original one. If it does not survive, say what remains of the original objection, and under what conditions, if any, an algorithmically constructed reference class would make a single-case probability well grounded. In your answer, please state how confident you are in the overall verdict and single out the point you are least sure of.
