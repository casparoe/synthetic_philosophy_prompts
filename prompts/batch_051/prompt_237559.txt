I've started a essay I can't quite get right and wanted some pushback on the core idea rather than line edits. It's about Nomic, the game where making a move often means amending the rules, including eventually the rules about how rules get amended. Here's the argument as I have it so far. Everyone reaches for the liar paradox when self-amending rules come up, but I think that's the wrong analogy. A system of rules isn't really truth-language: a rule isn't a proposition that gets to be true or false, it's an instruction that can be followed, applied, or suspended. So the problem can't be stated as "this rule is false." The interesting cases are reflexive instructions—like a rule saying it can't be amended, or a rule specifying the procedure by which it itself is amended. What breaks there isn't consistency but a temporal question: the amending move is authorized by the old body of rules, but as soon as it's made it's part of the new body of rules, so you have to say whether the authorizing law is the old one or the new one, and there is no neutral standpoint from which to answer. I suspect this is a miniature version of the old legal question whether a sovereign can bind itself, except nomic is sharper because the "sovereign" is just the players acting under rules they made on earlier turns. Second point: immutability. In the standard setup some rules are designated immutable, but designating a rule immutable is itself a move inside the mutable game, so immutability looks more like an agreement not to press a test than like a logical fixed point. A group can always amend the rule that says which rules are immutable, using the existing amendment machinery, until they decide by their own rules that the move was invalid—which is exactly the circularity I'm trying to describe.
