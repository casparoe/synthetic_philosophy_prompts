I came across a popular article on algorithmic randomness that was trying to answer whether a particular finite sequence—like last week's lottery draw—can be called random after the fact. It closed with this summary:

"Kolmogorov's proposal is that a string of bits is random to the degree it can't be compressed: the shortest program that prints the string is about as long as the string itself. But any finite string can be printed by a program that simply contains the string as data, so every finite string is generatable and none is really random. Genuine randomness, on this view, belongs to infinite sequences: Martin-Löf called an infinite sequence random when it passes every effective statistical test. Since that's an infinite battery of tests, no single test can ever settle it, which is why people will always argue about whether a particular run of coin flips was random."

I keep going back and forth on this. The compression test sounds right, but I'd have thought that a random-looking string like a lottery draw is random in some ordinary sense, so I can't tell where the reasoning goes sideways. I also can't tell whether the bit about infinite sequences follows from the first half or is leaning on a different notion of "random." Could you go through it and say which parts are fair to the actual ideas, which are subtly off, and whether the bottom line—that no finite sequence is really random—actually follows from the accurate parts? I'm not after references, just an accuracy audit.
