I'm TAing an intro philosophy course and I have to grade a short-answer question on Anselm and Gaunilo. The question I set was: explain Anselm's ontological argument and Gaunilo's perfect island objection, and say whether Gaunilo's objection succeeds. Here's what one student wrote:

Anselm defines God as the being than which nothing greater can be conceived. Even the Fool who says there is no God understands this phrase, so God exists at least in the understanding. If God existed only in the understanding, we could conceive of a being just like God but also existing in reality, and since it is greater to exist in reality than only in the understanding, that being would be greater than God, which contradicts the definition. So God must exist in reality too.

Gaunilo objects that the same pattern of reasoning would prove a perfect island: conceive of an island than which no greater island can be conceived; if it didn't exist in reality, then a greater island could be conceived, namely one that exists; so the perfect island exists, which is absurd. Therefore Anselm's argument form must be invalid.

I think Anselm's reply is that the island case is different because existence is a perfection only in the case of a being that already has every other perfection; adding existence to an island doesn't make it greater, so the parody never gets off the ground.
