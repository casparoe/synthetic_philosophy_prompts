Here is an argument about the St. Petersburg game. A fair coin is tossed until it first lands heads; if the first heads is on the nth toss, the house pays 2^n dollars. I want to know whether the following argument goes through, and if not, exactly where it breaks.

(1) The expected monetary value of the game is (1/2)·2 + (1/4)·4 + (1/8)·8 + …, which equals 1 + 1 + 1 + …, so it is infinite.
(2) Consequently, an expected-monetary-value maximizer has no finite ceiling on the entry price he should be willing to pay: for any finite fee, the net expected monetary value of playing is still infinite.
(3) An expected-utility maximizer with a monotone, unbounded utility function is in the same position. Since u is monotone and unbounded, u(2), u(4), u(8), … grows without bound; and since the probabilities shrink at a constant rate—each is half the previous one—the expected utility sum (1/2)u(2) + (1/4)u(4) + (1/8)u(8) + … cannot converge to any finite number.
(4) If a gamble has infinite expected utility for an agent, then the agent should prefer it to receiving any finite sure amount, and so should be willing to pay any finite price to play it.
(5) Yet it is not the case that a rational agent should be willing to pay, say, $10,000 to play one St. Petersburg game in ordinary circumstances.
(6) Therefore, either expected utility theory gives the wrong verdict in this case, or a rational agent’s utility function must be bounded.

I suspect that step (3) is doing too much work, but I cannot say exactly what is wrong with it. Is the argument valid? Is each premise true? If it is unsound, identify the exact step at which it first fails and give the strongest correct version of that step; then say what the corrected argument would at most show. If a defender of expected utility theory can legitimately resist more than one step, say where each resistance is strongest.
