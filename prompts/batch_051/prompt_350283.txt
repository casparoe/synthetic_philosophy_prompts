I'm a backend engineer, not a philosopher, but I keep seeing people worry that a future superintelligent AI's values might drift over billions of years until it ends up optimizing for something terrible. To me that sounds like a category error, like confusing source code with a running process. I wrote my reasoning out as numbered steps and I want to know if it actually goes through:

(1) An AI's values are just its utility function, i.e. the thing it's trying to maximize.
(2) The developers write that utility function and it gets compiled into the system before deployment.
(3) At runtime a compiled function only changes if some code path writes to it.
(4) A sufficiently powerful AI would stop outsiders from patching its code, so the only remaining code path is the AI modifying itself.
(5) But an AI that currently maximizes X would never choose to rewrite it's own utility function to maximize Y, because judged by its current function Y is a worse outcome.
(6) So neither outside edits nor self-edits can change the utility function.
(7) Therefore value drift in a powerful AI is impossible.

I keep going back and forth on step (5) — it feels like it's doing the real work but maybe it's too strong. Is the argument valid? If not, which step is the first one that fails, and what would the corrected version say?
