Write a sonnet about Frege's puzzle about identity statements. The octave should set the puzzle out straight: "Hesperus is Hesperus" is a trivial a=a, while "Hesperus is Phosphorus" is a genuinely informative a=b, even though both sentences name the same object; so what is the second one adding? The volta should be the Fregean move: the names agree in reference but differ in sense, in how the object is given to a thinker. The sestet should work through what that means — that the new knowledge lives in the mode of presentation, not in the object itself — and the closing couplet should land exactly there. It should be a real poem someone who's never read Frege could enjoy, and accurate enough that a philosopher of language wouldn't wince, so don't just say "Sinn" and "Bedeutung" a few times and call it done. Begin with the poem itself, no preface or commentary.
