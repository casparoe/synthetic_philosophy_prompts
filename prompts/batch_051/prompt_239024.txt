I've been meaning to write a handout for my modal metaphysics seminar about whether conceivability is any kind of guide to possibility, and over drinks a colleague sketched the following argument against it. It feels too quick to me, but I can't quiet get the problem to stay put, so I wanted to see how a fresh pair of eyes would break it down.

(1) To conceive that p is just to find no contradiction in p after careful reflection. (2) Nobody has found a contradiction in the claim that Goldbach's conjecture is false, even after careful reflection. (3) So the falsehood of Goldbach's conjecture is conceivable. (4) Whatever is conceivable is possible. (5) So it is possible that Goldbach's conjecture is false. (6) The same reasoning, run on the claim that Goldbach's conjecture is true, gives us that it is possible that Goldbach's conjecture is true. (7) If it is possible that the conjecture is true and possible that it is false, then it's truth-value is contingent. (8) But the truth-value of a mathematical statement is never contingent: if Goldbach's conjecture is true, it's necessarily true, and if false, necessarily false. (9) Therefore conceivability is no guide at all to possibility.

Where does this argument go wrong? Is it valid? If not, say exactly which step fails and why. If you think it is valid, say which premise you'd reject and whether rejecting it means conceivability is entirely useless as a guide, or only that some refined version of the guide is needed. In particular, tell me whether (1) and (4) are using the same notion of "conceivable," and whether (3) still goes through on the notion of conceivability that could plausibly ground (4).
