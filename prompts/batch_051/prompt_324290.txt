I'm trying to figure out what I actually think about when a neural network "has a representation" of something, going by my gut on cases.

Case 1: A linear probe on a language model's hidden states can decode whether the sentence currently being processed has high syntactic depth with 95% accuracy, but no one has done any intervention. I lean toward saying the model represents syntactic depth, but I'm not confident.

Case 2: Same setup, but when I ablate or add that direction, the model's outputs shift in syntactic complexity the way I'd expect. I say yes, that's a real representation.

Case 3: An animal classifier can be linearly probed for whether the background is forest vs. tundra, but flipping that direction changes nothing in the model's decisions. I say no, that's just an inert encoding.

Case 4: Two networks compute the same input-output function, and a direction that's causally effective in network A has no counterpart in network B. I still want to say both networks represent the same features in some sense, but I also don't want to say only linearly decodable directions count.

Case 5: Two different directions both decode the same feature and suppressing either one alone slightly hurts performance, but suppressing both at once hurts no more than suppressing the stronger one. I say the feature is represented, but neither direction is "the" representation.

Case 6: A nonlinear probe can decode almost everything about the input from the activations, but linear probes are weak and interventions are messy. I don't want to say every decodable thing is represented; that would make every network trivially represent its whole input.

The pair that bothers me is 1 and 3: both are just decodable directions, but I come out differently. Maybe in 1 the feature is the sort of thing the model needs to compute to do it's task, and in 3 it isn't? But that seems circular.

Is there a principle, or a small set of candidates, that gets all of these, or close? State it precisely, say which cases motivate which parts, apply it to a case I haven't listed (say, a causally effective feature that no linear probe can find), and tell me honestly which of my verdicts I'd have to drop or hedge.
