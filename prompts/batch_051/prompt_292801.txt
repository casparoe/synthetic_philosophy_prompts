I've been trying to decide whether saying that DNA contains a code is literal or metaphorical, so I've formulated what I call the Literal Code Criterion (LCC). LCC says a system literally encodes only when the mapping from sign to content is arbitrary relative to the physical medium and is assigned by something in the role of an interpreter, so that the same physical structure could have carried a different mapping had the assignment differed. The genetic code fails LCC: which amino acid a codon picks up is fixed by the chemical recognition of tRNAs and their charging enzymes, not by anything interpreting the codon. But machine code seems to fail for the same reason—the opcode-to-operation mapping is built into the processor's physics—yet few people would call it merely metaphorical. I can't see which premise to reject. Give me the three strongest objections to LCC, say whether any of them is fatal rather than merely forcing a repair, and tell me what the idea is closest to. End with a single line: \answer{fatal} or \answer{not fatal}.
