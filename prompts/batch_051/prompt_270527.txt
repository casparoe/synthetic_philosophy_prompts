I'm grading a history of logic short-answer and could use a second pair of eyes. The question I set was:

"What did Frege's Begriffsschrift actually change relative to Aristotelian syllogistic? Be specific about the analysis of propositions and about quantification."

One student wrote:

"Frege's real break was dumping the subject–predicate analysis that syllogistic is stuck with. In Aristotle every statement has to be forced into 'S is P' form, so the logic can only traffic in one-place predicates and the four categorical forms. Frege analyzes a sentence like 'Socrates is mortal' as the application of a function to an argument: 'mortal' takes Socrates as input and yields the True. That is what makes quantification possible, because instead of attaching a predicate to a subject you bind a variable inside a function. So he can formalize relational statements like 'every number has a successor' as something like ∀x(Nx → ∃y Syx). Syllogistic can't handle that at all, since it has no way to express relations or existence, and certainly no way to get multiple quantifiers to interact. Frege was also the first logician to use variables, and he presented the system axiomatically with explicit rules of inference. So the change is that logic stopped being about terms arranged in classes and became about functions, quantification, and the structure of propositions."
