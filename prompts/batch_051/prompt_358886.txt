So I've gone down a rabbit hole on program equilibrium and I can't get the puzzle to snap into focus. The result, as I understand it, goes like this. Take a one-shot prisoner's dilemma. If each player chooses not a bare action but a program, and the programs get to read each other's source code before they output their moves, then mutual cooperation can be an equilibrium: a program that says 'cooperate iff the other program's code matches this one, otherwise defect' does fine against itself, and a mutant program that always defects gets read as a defector and is defected against, so it ends up with the mutual-defection payoff rather than the temptation payoff it was angling for. So you get self-enforcing cooperation with no iteration, no reputation, no external enforcement. That's astonishing, and I find myself wanting it to be a deep result about rationality.

But then I look at the plain one-shot PD — two strangers, moves sealed in envelopes, no chance to condition on anything about the other's code — and my intuition says: defect, obviously. There's no causal path from my choice to the other's, so my defection is strictly preferrable no matter what they do. When the game is re-described with programs that read each other, I can't shake the feeling that we've just changed the game. The strategy space is different, the information is different, the word 'one-shot' is doing different work. Is program equilibrium a solution to the original PD, or is it a distinct game where the old intuition doesn't apply? And if the intuition only applies to the original game, is it still a firm intuition about rationality, or just an artifact of a particular, maybe unrealistic, formalization?

I'm a phd student in game theory-adjacent philosophy and I keep flip-flopping, so I want a negotiated verdict rather than a side. Which side should give way, and under what conditions? What would justify debunking my sealed-envelope intuition as a confusion about what a 'decision' can be, and what would justify amending or abandoning the program-equilibrium framing as a solution concept? Is there a reading on which both are right and the disagreement is only about which game is the real one?
