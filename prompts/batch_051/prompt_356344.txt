Start from Gibbard–Satterthwaite as I understand it: take any deterministic voting rule that takes everyone's strict rankings of three or more candidates and outputs a single winner, respects unanimity (if every voter ranks X top, X wins), and is strategy-proof, where strategy-proof means no voter can ever get a winner they strictly prefer by submitting a ranking other than their true one. The theorem says any such rule is dictatorial: some voter's top choice always wins.

(1) A voting rule is only worth using if its non-dictatorial.
(2) A voting rule is only worth using if it's strategy-proof in that exact sense — otherwise we're asking people to vote honestly while the system sometimes rewards lying, which is a bad equilibrium.
(3) Any deterministic, ranked, unanimity-respecting, single-winner rule for three or more candidates is, by the theorem, strategy-proof only if dictatorial.
(4) So every non-dictatorial ranked system people actually propose — plurality, IRV, Borda — fails strategy-proofness, meaning there is some profile of preferences where somebody has an incentive too misreport.
(5) Therefore no ranked voting system is worth using, and any actual election with three or more candidates is either a dictatorship or a tactical-voting mess where the honest vote can't be the stable outcome.

The conclusion feels like it proves way too much: it would make every real multi-candidate election illegitimate, and yet some voting systems obviously work better than others and the world doesn't collapse. So one of (1)–(5) has to be wrong, or my movement between them is doing something sneaky.

If I'm forced to pick, I'd much rather give up (2) than (1). But I want the actual diagnosis: which premise or inference would you reject, and what's the bullet-biting cost on either side? Is there a notion of strategy-proofness that actually matters and that non-dictatorial systems can meet, or is the whole framing off?
