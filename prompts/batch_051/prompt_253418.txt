What the no-free-lunch theorem does and doesnt do to induction

The standard no-free-lunch result says that averaged over all possible target functions, no learning algorithm outperforms any other. I want to claim two things about it. First, that people often read it as a formal version of Hume's problem: induction can only succeed if nature is uniform, and there is no a priori guarantee that it is. Second, that this reading is half right and half wrong.

The half-right part: NFL really does show that good performance has to come from somewhere. If an algorithm does better than random guessing on some functions, it has to do worse on others, so its success is bought with assumptions. That is close to Hume's point that any inference from observed to unobserved cases already presupposes that the unobserved will resemble the observed.

The half-wrong part: Hume's problem is about one actual world changing over time. The NFL theorem is about an average over all possible input–output mappings, not about the future resembling the past. So the two get their skeptical force from different places: the Humean skeptic asks why the actual future should resemble the actual past, while the NFL result says there is no universally best algorithm across all possible worlds. Treating them as the same problem conflates a claim about the entire space of possible worlds with a claim about the single world we live in.

Then I try to make a constructive point. Maybe the NFL theorem is best read not as a skeptical result but as a bookkeeping device. It tells you that if a particular inducer performs well, then the restriction or bias it encodes must line up with the process generating the data. But that turns the question "which inducer should I use?" into the question "which world am I in?", which is itself an inductive question. So NFL does not solve or dissolve Hume's problem; it just shows that induction and choosing a prior are the same problem in different clothes.
