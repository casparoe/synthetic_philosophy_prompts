For a political forecasting seminar I am drafting a statement of my methodological views on using historical base rates for one-off predictions about great-power decline, and I would like an audit before I present it. My commitments are these. (1) For a singular event like whether the current leading power will relinquish hegemony by 2050, the rational starting point is an outside-view base rate drawn from a reference class of past great powers or hegemonic transitions. (2) A reference class is legitimate only if it is selected by features that are causally relevant to the outcome—institutional fragility, elite circulation, fiscal capacity, coalition structure—rather than by superficial resemblance such as 'empires with capitals on navigable rivers.' (3) In practice, the choice of class is underdetermined: several historically defensible partitions (all great powers; all post-1500 European great powers; all hegemons; only maritime hegemons; only cases of simultaneous economic and military preponderance) yield substantially different base rates for the event I want to predict. (4) Nevertheless, I hold that the outside view must still be applied where the class is underdetermined, because narrowing the class to obtain a preferred answer is just base-rate neglect dressed up as historical judgment. (5) Finally, I hold that inside-view evidence may move the base rate only if it concerns a factor whose direction and rough magnitude can be specified before and independently of the prediction; otherwise it is narrative masquerading as evidence. Are these five jointly tenable? Please go through the pairs that appear in tension, say which are genuinely in tension and which merely seem to be, rank the genuine tensions by severity, and for each identify what has to give and what the least costly revision is.
