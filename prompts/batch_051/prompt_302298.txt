Question (from the exam):
"Can a finite binary sequence be random? If you think the question is ill-posed, say what it might be getting at and whether a precise sense can be salvaged. Your answer should (i) explain why 'every finite sequence is computable, so no finite sequence is random' is too quick; (ii) define Kolmogorov complexity and what it means for a finite string to be incompressible; (iii) explain Martin-Löf randomness and why the standard definition is for infinite sequences rather than finite ones; and (iv) describe at least one way to define a randomness deficiency for finite strings, including a limitation of it."

Student answer (verbatim):
"Every finite string can be produced by some program—just write PRINT followed by the string—so in one sense every finite string is computable, and if we equate random with noncomputable then no finite string is random. But this is the wrong sense. A fair coin can produce 0000000000, and we don't want to say that outcome isn't random just because the string looks simple. The real issue is incompressibility. Kolmogorov complexity C(x) is the length of the shortest program that outputs x and halts. A finite string is random iff the shortest program for x is about as long as x itself, i.e. C(x) ≈ |x|. So 0101010101010101 is not random because it has a very short description (repeat 01 eight times), whereas 0110101110011010 presumably is random since we can't see a shorter description. Martin-Löf randomness makes the same notion precise for infinite sequences: a sequence is random iff it fails no effective sequential test, equivalently iff it is not in any effective measure-zero set. In principle the same idea works for finite strings: a string of length n is random to the extent that it fails no test at a fixed significance level. We can also define a randomness deficiency d(x) = |x| − C(x); x is random when d(x) is small. Because C is defined without any particular purpose or background class, d(x) is an absolute, machine-independent measure of how random a finite string is. So yes, finite sequences can be random, and they are random exactly when they are incompressible."
