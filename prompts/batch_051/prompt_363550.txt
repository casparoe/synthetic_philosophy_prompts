A resemblance between two things I work with has been nagging at me, and I would like you to help me decide whether it is deep or superficial.

One of them is the behavior of missing information in relational databases. In SQL, a NULL is not a value but a marker for a missing value, and comparing NULL to anything—even to another NULL—does not return true; the result is UNKNOWN. Negating an UNKNOWN condition leaves it UNKNOWN. The other is the behavior of empty names in philosophical logic. A sentence such as 'Sherlock Holmes is a detective,' read as a claim about the actual world, is not straightforwardly true, because there is no Holmes; but on many accounts it is not straightforwardly false either, because the failure comes from the name's lacking a referent rather than from some detective-fact about a real person. Negating it—'Sherlock Holmes is not a detective'—also fails to produce an ordinary truth, even though, inside the stories, the positive sentence is true.

So this is the parallel. An empty name outside fiction is like a NULL: not a thing but a signal that the expected referent is absent. The prefix 'in the stories' or 'according to the stories' is like evaluating the expression inside a context where the identifier has been given a value, so the previously NULL-marked expression acquires a determinate truth value. Some details line up rather well: within the fiction the name can stand in real relations and identities, while some questions about the character have no answer in the stories, which looks more like another NULL than like a definite false.

I want to know whether this is a genuine identity of structure or just loose pattern-matching. If it is genuine, what would have to be true of both sides for results to transfer, say, from the logic of SQL's three-valued evaluation to a theory of truth in fiction, or in the other direction? If it is merely an analogy, where exactly does it come apart? In particular, do the SQL rules for 'unknown or true' and 'not unknown' correspond to how we should treat 'Holmes was a detective or Holmes had an even number of hairs' and 'Holmes was not a detective,' and does the analogy predict something about fiction that is plainly false? Please answer in continuous prose, as you would write an email, with no headings, bullet points, bold text, or tables.
