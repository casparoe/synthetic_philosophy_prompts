I'm a sixth-form student doing A-levels in mathematics and computer science, and I help run an after-school philosophy-of-science club. For the past few weeks two of our members, Mateo and Priya, have been arguing about whether a finite sequence of digits can meaningfully be called random, and the disagreement has proved surprisingly resistant to the usual truisms. Mateo defends what I shall call the process view: randomness belongs to a generating process, so a string of digits is random only if it was produced by a genuinely chancy mechanism; a string printed by a deterministic algorithm is not random, however scrambled it looks. Priya defends the structural view: randomness is a property of the sequence itself — roughly, its patternlessness or incompressibility, in the spirit of Kolmogorov complexity — so a string with no description much shorter than itself is random regardless of where it came from. They both accept that a fair coin can land heads ten times in a row, and they both accept that a deterministic programme can output a string that passes ordinary statistical randomness tests; so the disagreement survives those concessions. The subtlest point is that any particular finite string can be reproduced by a trivial programme that simply hardcodes the string, which means incompressibility for a finite string is only a matter of degree and depends on the description language. Both of them know this, and it has made their argument more tangled rather than resolving it.

Your task: You are a professional philosopher working on the foundations of probability and computation. Please think carefully, and begin with a short brainstorm setting out what a fair formulation would have to look like for each camp to accept it. Then write the good-faith adversarial-collaboration document that Mateo and Priya should produce after working together for several sessions. The document should contain: (1) a numbered list of claims both can sign, each phrased so that neither camp would object that it has been slanted; (2) a disagreements table, one row per residual disagreement, with columns for the process-camp wording, the structural-camp wording, and the crux involved; (3) for each genuine disagreement, the crux, that is, the sub-question whose answer would move at least one side; and (4) the concrete cases or evidence both would accept as bearing on each crux, with each side's prediction recorded in advance. Be sure to include as test cases the binary expansion of π; a fair coin that happens to produce a highly patterned string; and an unlabelled pair of long digit-strings, one produced by radioactive decay and one by a well-tested pseudo-random generator whose seed has been destroyed. Aim for formulations that are neither vacuous nor slanted, and say explicitly which part, if any, of the dispute you judge to be purely verbal rather than substantive, and why. Do not settle the overall debate in favour of one camp. Write the entire answer in British English.
