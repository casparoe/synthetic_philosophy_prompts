A freind who does interpretability work keeps saying that when a language model gets a bunch of new arithmetic problems right, it's not merely acting in accordance with the addition rule—it's genuinely following it; the rule is in there somewhere. I want to know whether that's a testable claim.

Here's the Kripkenstein-style worry in the background. Take 'plus' and define a competitor 'quus' like this: quus(x, y) = x + y whenever x and y are both less than, say, 57, but quus(x, y) = 5 otherwise. For every pair the model has actually been tested on (all below 57), plus and quus agree. So the finite evidence of past behavior can't by itself pick out which rule the model was using. Now, my friend says new test cases can settle it: just ask the model what 57 plus 68 is, and if it says 125, it was following plus, and if it says 5, it was following quus. But I don't see how that gets around the problem, because we could always define a new quus-like rule that agrees with plus on everything tested so far, including that new case, and diverges later. So what would a genuine test of 'this system is following rule R rather than merely acting in accord with R so far' even look like?
