I've been going back and forth with a friend who works in machine learning, and he keeps insisting that the is-ought gap is dead: modern systems are trained on human preferences, which are just facts, and they then use the learned reward model to issue recommendations and decide what to do. I think he's making a category error, but I want to know exactly where it goes wrong.

The original point, as I understand it, was formal. Hume noticed that a conclusion containing an 'ought' never validly follows from premises that are all 'is'; Moore's open question argument then added that no natural property can simply be identified with goodness, because it always remains open whether that natural property is good. Now take reinforcement learning from human feedback. A model is given millions of factual records about which outputs humans choose or rate. It learns a scalar reward function from those facts, and that function is then treated as if it had normative force: the model should refuse this, the user should see that, this answer is better than that one. Suppose I grant that the training process is as described and that nobody smuggles in a normative rule at the start. Does the is-ought gap survive this development unchanged? If it survives, why doesn't the reward model count as deriving an ought from an is? If it doesn't survive, or survives only in a weakened form, which premise of the original position is actually under pressure - the logical one about derivability, the definitional one about goodness, or some background assumption about what norms could be? If the right answer is a weakened version, give me that version in a sentence or two. I'm after the philosophy here, not the AI policy.
