I am a retired molecular biologist who has lately been reading philosophy of biology, and I have come to think that the dispute over whether DNA is a code runs together two separable ideas: that a molecule is read by an interpreting apparatus, and that the mapping between one set of symbols and another is arbitrary. I want a thought experiment that forces those two ideas apart.

Construct a thought experiment to the following specifications. Imagine a primitive cell-like system, biochemically coherent but not necessarily corresponding to any organism that actually exists, in which an RNA-like polymer is scanned by a ribozyme-like reader; adaptor molecules pair each base triplet with a single amino acid; and the resulting amino-acid chain folds into a functional product. Hold every feature of real translation fixed except one: in this system the codon-to-amino-acid assignment is rigidly forced by the three-dimensional fit between each triplet and its cognate adaptor, so that no alternative assignment is stereochemically possible. In other words, keep the interpreter and remove only the arbitrariness of the mapping. Write the case in a single paragraph, then carry out the walk-through.

The walk-through should not be a survey. Consider two positions, both of which genuinely appear in this debate. Position A holds that a code is essentially an arbitrary mapping between two vocabularies — a cipher whose assignments could have been otherwise, and hold only because a particular mapping happens to be implemented — so that a pairing forced by molecular shape is mere chemistry rather than coding, however much machinery reads it. Position B holds that what matters for codehood is that a sequence is read as specifying a product by an interpreting apparatus, and that arbitrariness is not required for representation or instruction. State what each position must say about this system and why. Then identify the single feature doing the work in their disagreement, explain what each side would have to say if that feature were restored to the case, and finish with the strongest attack the losing side can make on the winning side's verdict. Do not hand me the options and leave me to choose: give a definite, argued verdict about which position is right about this case.

The point of the exercise is to find out whether our willingness to call DNA a code is controlled by interpretation or by arbitrariness, so build the case so that the verdicts are generated by the positions rather than stipulated. Add whatever biochemical detail the scenario needs, but do not settle the question by introducing a designer, a convention-forming community, or any back-door device.
