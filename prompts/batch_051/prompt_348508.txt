After forty years in experimental physics, I got used to thinking that a probability just is a relative frequency in some well-defined ensemble. In the lab we'd just build a bigger sample or cut a tighter selection window. Lately I've been reading philosophy of probability, and the reference class problem has really unsettled me. I'd like you to argue, as forcefully as you can, for this position: there are no objective single-case probabilities. A probability assigned to an individual event is only defined relative to a chosen reference class, and which reference class is the right one is not fixed by the facts; it's fixed by our interests, our purposes, or some pragmatic standard we cant fully justify. Please also take on the obvious fix—that we should always use the narrowest reference class available—and show why it either fails or merely relocates the problem. Use a concrete example of one token event that can be placed in many different reference classes yielding very different frequencies, and say plainly what this does to the idea that a physical chance (say, a particular atom decaying in the next hour) is an objective property of the single event itself. If the upshot is that "objective single-case chance" is a concept we should give up, say so, and if not, explain what survives.
