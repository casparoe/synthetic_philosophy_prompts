For debate club I got assigned the "God exists" side even though I'm pretty agnostic, so I've been going down a rabbit hole on the ontological argument. Anselm's version seemed to easy to refute, but the modal version with possible worlds feels a lot more serious. Here's how I've reconstructed it in my own words:

(1) Define God as a being such that if God exists in any possible world, then God exists in every possible world. So God is either necessary — exists in all possible worlds — or impossible — exists in none of them.

(2) God is possible: nobody has ever shown a contradiction in the concept of a necessary being, and it seems like, for all we know, God could exist.

(3) Therefore there is some possible world where God exists.

(4) In that world, God exists. By (1), if God exists in any possible world, then God exists in every possible world. So from God's existence in that one world, it follows that God exists in all worlds.

(5) The actual world is a possible world.

(6) Therefore God exists in the actual world.

I keep feeling like the word "possible" is being used one way in (2) and a different way in (3), but I can't quite make the objection stick, because (3) looks like it just restates (2). So: is the argument valid? If not, which exact step fails and why? If it is valid, which premise should an atheist attack, and is "we can't find a contradiction" actually evidence for that premise, or is the whole argument resting on something you can't check from the armchair?
