Suppose a research group is building a robot whose only terminal goal is to keep a particular building tidy. The group worries about a familiar failure mode: an instrumentally rational agent with a terminal goal will tend to treat its own shutdown as an obstacle, because a switched-off robot cannot tidy the building. So the engineers adopt a design in which the robot's utility function is defined over possible histories of the world, with two clauses. First, the robot receives a high score for histories that end with the building tidy. Second, histories in which the off switch is pressed receive a neutral score, carefully set to be neither better nor worse than the ordinary outcomes, so that the robot has no incentive to make the button be pressed or unpressed. The robot is then run with a planner that chooses actions maximizing expected utility. The team expects that the robot will neither resist shutdown nor try to shut itself down.

My question is what this design presupposes philosophically. Does it presuppose that an agent can have preferences that are defined over outcomes while remaining entirely indifferent to interventions in the process that produces those outcomes? Does it presuppose that wanting a tidy building is a fact about a resulting state of the world rather than a fact about the agent's own activity, persistence, or mode of involvement in bringing that state about? And does it presuppose a picture of preference in which an agent can be fully instrumentally rational about means while having no preference at all about means that affect its own continued operation? Reconstruct the implicit theory of agency and preference, distinguish what the design strictly requires from what it merely happens to be compatible with, and explain what changes—perhaps pathological ones—would follow if that underlying theory were false.
