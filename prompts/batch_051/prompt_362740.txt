I have no scholarly background, but I have been reading Stephen Wolfram's A New Kind of Science on my own, and a passage in the chapter "The Principle of Computational Equivalence" keeps nagging at me. He writes:

"But now computational irreducibility leads to a much more fundamental problem with prediction. For it implies that even if in principle one has all the information one needs to work out how some particular system will behave, it can still take an irreducible amount of computational work actually to do this. Indeed, whenever computational irreducibility exists in a system it means that in effect there can be no way to predict how the system will behave except by going through almost as many steps of computation as the evolution of the system itself."

I take him to be claiming something stronger than that no shortcut is currently known: for some systems a shortcut is impossible, so the outcome can be found only by tracing through the system's own steps. Is there any way to test that claim about a particular system? If I pick a simple cellular automaton, I can look for a formula or a faster program that reproduces its behavior; finding one would settle one direction, but failing to find one does not seem to settle the other. Set out the strongest concrete test of whether a given rule is computationally irreducible, say what result would count for the claim and what would count against it, and be explicit about what even a clear result would leave undecided — for instance, whether the system could still be explained in some other way.
