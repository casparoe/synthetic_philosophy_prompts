I've been going around in circles on something in philosophy of mind and I'm hoping you can tell me whether it has a recognized name, because I keep having to describe the whole thing from scratch every time I bring it up. Start with a simple setup. An animal has an internal state that gets set off by a predator and makes it flee. The evolutionary story is that the state is there because, in the animal's old environment, whatever set it off was a pretty good proxy for the predator, and fleeing saved its ancestors. Now suppose the state is actually keyed to some low-level feature — a certain size and speed of movement, say — and it fires just as reliably for a harmless thing that shares that feature. In the old environment the harmless thing and the predator always came together, so it never mattered whether we gloss the state as "predator" or "that-size-thing-moving." But then we transplant the animal to a new place where the harmless lookalike is everywhere and the predator is gone, and the animal wears itself out running from nothing. We want to say the state is misrepresenting the lookalike as a predator. But that seems to smuggle in the claim that the state means predator, and the only thing pointing to "predator" rather than "lookalike" or "the feature they share" is the historical story about why the state exists at all. So the content looks like it could be any of several equally defensible things.

I half-remember a frog snapping at little pellets because its visual system throws up the same signal as for flies, so I suspect this is an old problem — I'm just not sure what its called, or whether the re-purposing version has a name either: if the population stays in the new place and the fleeing happens to be useful for a completely different reason, so the state is now selected for that new reason, does the state's content change, and at what point? What I'm after is a map of the territory, not just a label: the name if there is one, how this differs from a detector simply being faulty or mistaken, whether it's one phenomenon or a few different ones, whether a learned response changes the picture compared to an evolved one, and if there's no settled name, how you'd define it and where its edges are.
