I teach an undergraduate seminar in philosophy of cognitive science, with about eighteen students, and I have one seventy-five-minute session set aside on the induction of concepts from a few examples. I want to build the session around Bongard problems—those panels with six boxes on the left and six on the right, where every left-hand box satisfies a hidden rule and none of the right-hand boxes does, and the task is to infer the rule. The room has small-group tables, a whiteboard, and I can prepare printed boards, index cards, and markers. I want the students to come away feeling something concrete: that a finite set of positive and negative examples underdetermines the rule, so that the same twelve boxes can be sorted equally well by several genuinely different rules, and the rule that feels obviously right is being selected by the learner’s prior biases rather than dictated by the data. I have tried simply projecting a Bongard problem and letting the class shout out candidate rules, but the point stays too much in the discussion; the underdetermination only bites if students have already committed themselves to a rule and then discover that a rival rule fits everything they have seen.

Could you design a runnable game for the session, with roles, rules, materials, a point-based scoring system that does not require real money, and a timeline for the seventy-five minutes? I have been considering a “secret rule” guessing game in which one student is the rule-maker and the others request new test examples, but I worry that such a game can still leave students thinking there was a single true rule they merely failed to find. I would like the activity to include at least one moment in which two reasonable rules fit everything observed so far and then visibly diverge, or in which a grue-style competitor—a rule deliberately gerrymandered to match every example seen so far and then flip on the next case—is revealed. Please also include a debrief that maps specific moments in the game onto the philosophical problem, an honest account of what will predictably go wrong the first time I run it and how to handle it, and a candid note on which feature of real concept induction the game cannot reproduce and what I will need to supply myself.
