I am cataloging the distinct forms a strategy-stealing argument can take, and I want one more form not already on my list. My list so far:

(1) Hex: an extra stone can never hurt the first player, and a full Hex board always contains a connection for one side; so if the second player had a winning strategy, the first player could play an arbitrary first stone and then follow that strategy.

(2) Chomp: the first player opens with the corner square opposite the poisoned square; any reply an alleged second-player winning strategy makes to that move is itself available as a legal opening move, so the first player can open with that reply and follow the strategy, taking a harmless arbitrary move if the strategy ever calls for the already-eaten corner.

(3) Free-style n-in-a-row games, where any run of n or more stones wins: extra stones never hurt, but draws are not excluded, so stealing yields only the weaker conclusion that the second player has no winning strategy.
