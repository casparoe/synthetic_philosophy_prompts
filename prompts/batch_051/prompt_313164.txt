I'm not an academic — I write code for a living — but I've been reading around the question of whether a finite string of bits can be called random, and I keep running into a problem I can't name. A common way to say whether a finite string is random is to ask whether the shortest program that outputs it is about as long as the string itself; a string that can only be produced by spelling it out is supposed to be random, and one with a short generating rule isn't. But what counts as "short" depends entirely on the programming language the program is written in. In one language a given hundred-bit string can be produced by a three-line loop; in another the same string has to be written out bit by bit. And if I'm allowed to look at the string first and then design the language, I can always add a built-in command like `emit_this_exact_string`, making the generating program one instruction long; the string then looks anything but random. That's plainly cheating, because I tailored the language to the string after seeing it, but I've never found a precise statement of what the non-cheating languages have in common.

People usually brush this off by saying that any two "reasonable" languages differ only by a fixed additive constant, so for long strings the choice of language stops mattering. But when I chase what "reasonable" means here, I can't find a definition, and the constant looks like it can smuggle in an arbitrary amount of pre-cooked structure as long as the programs are long enough. I'm trying to figure out whether this difficulty has an established name, or whether I'm running together several distinct problems. I'm not asking for the bare label. I want the carving: how this language-dependence relates to ordinary vagueness about how to measure something, and to the gerrymandering of a hypothesis after seeing the data; what exactly the additive-constant argument buys and doesn't buy; and whether there is any way to define randomness for a finite string without privileging some description language. If the honest answer is that there isn't, I'd like that said plainly, with the closest existing concepts named and distinguished. Please keep the answer to no more than 350 words.
