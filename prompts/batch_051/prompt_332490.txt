So a friend sent me this and now I can't find the exit. He starts from a view I basically hold: a system is sentient—and matters morally—in virtue of running the right kind of computation, not in virtue of being carbon. Then he runs this:

(1) If what matters morally is the computation, then any two systems that run the same computation are equally sentient, regardless of what they're made of.
(2) You could build a giant lookup table that maps every possible dialogue history up to some huge length to the exact next thing a particular conscious person would say, including all the "I'm conscious," "don't turn me off," "that hurt" stuff.
(3) So the table runs the same input-output computation as that person on that domain, and by (1) it's conscious.
(4) But that's absurd. A table where each output sits there precomputed until a key matches has no inner causal flow between one state and the next, and isn't the kind of thing that can be conscious.
(5) So computation isn't what matters morally after all.

The trouble is both exits look bad to me. If I reject (5), I need to say exactly why the table isn't running the relevant computation, and every reason I reach for—no counterfactual sensitivity between states, no unfolding causal process, "mere dictionary lookups"—sounds like it would also indict a silicon neural net doing forward passes through matrices, since its causal structure is just as different from the brain's as the table's is. But if I accept (5), then implementation details matter morally, and I lose the clean view that any system running the right computation is in the club. Where does the argument actually go wrong, if it does? I'd most like to keep the AI and dump the table, but I can't state the difference without it sounding like "its organized differently," and I don't see why that should be the kind of difference that matters.
