I am a PhD student in computer science working on multi-agent systems, and I recently read a survey chapter that summarizes the program equilibrium literature roughly as follows. When two agents play a one-shot Prisoner's Dilemma but each can inspect the other's source code before acting, the usual argument that rational agents defect no longer applies. Each agent can submit a program that cooperates exactly when the opponent's program would cooperate against it, and defects otherwise. Because each can verify the other's code, each can be confident that the other has genuinely committed to conditional cooperation, so mutual cooperation becomes the rational outcome. In this way, once agents are transparent to one another, the dilemma simply dissolves.

I find the broad conclusion plausible, but I suspect the move from inspecting code to verified commitment hides a complication I cannot articulate. How fair is this summary?
