I'm running a session at a philosophy-and-aging meetup and I want a sorting quiz that tells people which flavour of 'deathism' (loosely: resistance to or refusal of radical life extension) they actually hold. Build me a decision tree with at most seven leaves. The leaves need to include at least: a status-quo-bias / adaptive-preference view; an instrumental-worries view (it'd be unequal, boring, destabilizing); a meaning-from-finitude view; and a pro-extension view. Don't make the branching question 'would you take the pill?' — the interesting branch points are the commitments behind the reaction. Every node should be a concrete case or claim someone can answer without already knowing which box it puts them in (a cheap, safe pill; whether a 200-year friendship would be shallower; whether finding out that aging is curable changes how bad you think aging is). Build it from the logical space, not from names first: give the two or three diagnostic questions, lay out which answer combinations are open, then locate positions in that space; mark unoccupied combinations and say whether each is incoherent, unattractive, or merely unexplored; and flag leaves the tree can't seperate. Audience is bright non-philosophers who've read a couple of popular essays on life extension, so no citations and define any jargon.

Return a JSON object with: 'diagnostic_questions' (array of objects with 'id', 'text', 'answers', and which leaves each answer excludes), 'tree' (array of nodes with 'id', 'question_id', 'yes_goes_to', 'no_goes_to', where a target is a question id or leaf id), 'leaves' (array with 'id', 'label', 'gloss'), 'unoccupied_combinations' (array with 'combination', 'diagnosis'), and 'inseparable_pairs' (array with 'leaf_a', 'leaf_b', 'why').
