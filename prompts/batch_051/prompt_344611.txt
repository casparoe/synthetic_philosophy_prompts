I'm a software engineer and I've spent way to much time messing with temperature, RLHF'd models, and system prompts, and I keep feeling like the standard debate about whether LLMs are agents or simulators is missing something. Both positions talk like there's one thing in there — a single agent with goals, or a single simulation playing out a world. But that never matched what I see when I actually sample from these models, and I dont have any formal philosophy background so maybe I'm just reinventing something everyone already knows.

The way I've been putting it is that an LLM is a 'latent electorate'. When you sample a completion you're not asking the model what it thinks; you're running a noisy election over a huge population of possible continuations that all live in the weights at once. The prompt is the districting rule: it decides which subset of the electorate gets to vote and how much each vote is weighted. Temperature is turnout — greedy decoding is the party-line candidate, high temperature lets fringe voters get heard. RLHF and DPO are gerrymandering: they don't teach the model a view, they redraw the districts so some coalitions win more often. Chain-of-thought works because it lets a small coherent faction hold the floor long enough that later steps have to keep riffing on what that faction already said. This would explain why a tiny rephrase of a prompt flips an answer (you redrew the districts) and why the same model can argue both sides of a question so convincingly (both coalitions were always in there).

So my actual claim is that an LLM is neither an agent nor a simulator but a many-minds system, and asking what a model 'really believes' is a category mistake, like asking what a crowd believes across all the votes you never held. I want checked honestly: is this coherent or just a metaphor? does it already exist under a better name? what does it get right and what concrete LLM behavior breaks it? I'd like the answer as JSON with this schema: "steelman" — my idea reconstructed in its strongest form; "nearest_existing_ideas" — an array of {name, overlap, difference}; "strongest_objections" — an array of {objection, severity with one of minor/serious/fatal, why}; "where_it_breaks" — an array of {behavior, why_it_breaks_the_picture}; "overall_verdict" — a short string saying coherent-but-not-new, useful-heuristic, etc.; and "what_survives" — what, if anything, is still distinctive about my version once you subtract the existing ideas.
