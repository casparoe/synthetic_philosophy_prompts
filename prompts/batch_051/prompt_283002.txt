Write a decision tree and sorting quiz for an upper-level philosophy of biology seminar on biological individuality, organized around the question whether holobionts, eusocial colonies, and clonal groups are organisms. The handout should sort a reader into one of a small set of named positions on the basis of their answers to concrete, pre-theoretical questions; no branch question may use a position label, and any technical term must be defined in plain language when it is introduced.

Build the tree from the logical space of criteria rather than from a list of named positions: first work out the diagnostic questions and the combinations of answers they permit, then locate the actual positions as leaves, and note which combinations of answers are empty. Use the following cases as anchors at some of the nodes (use at least four): an aphid with its Buchnera endosymbionts; the bobtail squid with its Vibrio fischeri light organ; a leafcutter ant colony; a siphonophore such as the Portuguese man o' war; a clonal aspen grove such as Pando; and a lichen. The branch questions should ask about cases, mechanisms, or criteria in plain terms—for example, whether the parts of an organism must share one genome, develop from a single cell, be metabolically integrated, share one reproductive fate, be demarcated by an immune system, or be a unit of natural selection—but the answer options must be written so that someone can respond without already knowing which position that answer leads to.

Required leaves, named however you find clearest but keeping these commitments recognizable: a traditional metazoan view on which a single genome and a single-cell developmental bottleneck are necessary; a physiological or metabolic view on which tight functional integration is the criterion; an evolutionary or Darwinian view on which being a unit of selection is the criterion; a hologenome view on which a host plus its microbiota can itself be the unit; a eusocial colony view on which a colony with reproductive division of labor is an organism; and a pluralist or graded view on which there is no single fact of the matter and different kinds of organism overlap. Aim for no more than ten leaves.

Each branch node must be a question a seminar participant could answer without knowing which leaf it leads to, with options that are mutually exclusive and, where possible, exhaustive; where no option fits, route the path to an explicit "unassigned" or pluralist outcome and say so. Each leaf must carry a short position name, a one-sentence statement of its core commitment, the path or paths of answers that reach it, and one sentence naming the most awkward case for that leaf. Also include a section diagnosing any empty combinations of criteria: say whether each is empty because it is incoherent, unattractive, or merely unexplored. Flag any pair of leaves the tree cannot separate using the questions alone, and give the further question that would separate them.

Deliver the instrument as a single JSON object with the following schema:

- "title": string, a short descriptive heading for the handout.
- "audience_and_purpose": string, one or two sentences restating the intended use.
- "tree": object with "root_node_id": string and "nodes": array. Each node object has "id": string and "type": one of "question" or "leaf". For question nodes also include "question": string, and "options": array of objects with fields "option_label": string, "answer_text": string, and "leads_to": string (the id of another node, or a leaf_id from the leaves array). For leaf nodes also include "leaf_id": string.
- "leaves": array of objects with fields "leaf_id": string, "name": string, "core_commitment": string, "reachable_by": string summarizing the answer path or paths, and "awkward_case": string.
- "empty_combinations": array of objects with fields "combination": string describing the combination of answers that no leaf occupies, "diagnosis": one of "incoherent", "unattractive", or "unexplored", and "explanation": string giving a one-sentence justification of the diagnosis.
- "unseparated_pairs": array of objects with fields "leaf_1": string, "leaf_2": string, "why_not_separable": string, and "separating_question": string.
- "scoring_or_navigation_note": string explaining how to administer the tree as a quiz, what to do with paths that reach an empty combination, and what to tell users who find themselves split between two leaves.
