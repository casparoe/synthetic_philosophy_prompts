I'm a retired physicist who's only recently got into philosophy, and my instinct is still to model things as finite systems, so I've been tinkering with Nozick's experience machine. In the usual set-up you can have any experience you like. But an actual mind is finite, so the set of type-distinct experiences it can ever have is finite — call it N, stupendously large but finite. Suppose the machine offers that whole set as its catalogue, and you have to choose a life of length L drawn from it. The machine can also erase the memory of a given token, so you can have the same type-experience again with the feeling of complete novelty; without erasure, repetitions feel familiar and their value drops off. Does swaping an unlimited menu for a finite though enormous one change the standard arguments, and if so which ones? In particular: run the hedonist's calculation, with diminishing returns when repetitions are remembered and with the reset that erasure gives. Would a preference-satisfaction theorist or a Nozick-style objector who cares about contact with reality change their verdict? Does the finiteness of the menu threaten the usual claim that we care about more than how experiences feel from the inside, or does it leave that claim untouched? And is the memory-erasure option a reason to plug in, or does a finite menu plus erasure start to look like an eternal recurrence that makes the machine less dignified rather than more?
