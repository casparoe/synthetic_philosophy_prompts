(1) A finite binary string s of length n is standardly called random if its Kolmogorov complexity, K(s), is at least n minus some fixed slack constant d. (2) But for any particular s, we can define a new prefix-free universal machine M_s by saying that on input 0, M_s prints s, and on input 1p, M_s simply runs our original universal machine U on p. (3) Then M_s is universal, and relative to M_s the string s has complexity at most 1. (4) By the invariance theorem, for any universal prefix-free machine M there is a constant c_M such that for every x, K_U(x) is at most K_M(x) plus c_M. Applying this to M_s gives K_U(s) at most 1 plus c_{M_s}. (5) Therefore every finite string s has a U-description bounded by 1 plus c_{M_s}, which is far shorter than n for sufficiently large n. (6) So no finite string is random according to the standard definition, and algorithmic randomness looks like a machine-relative artifact rather than an objective property of the string itself.
