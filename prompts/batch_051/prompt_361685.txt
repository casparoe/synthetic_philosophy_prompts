I've been messing around with prediction market APIs for a side project, so I keep running into the futarchy pitch: have everyone vote on a metric we actually care about (GDP, life satisfaction, whatever), and then let prediction markets bet on which policy would move that metric the most, instead of electing people to pick policies. The argument, as I understand it, is that prediction markets are really good at pooling information from a bunch of independent people with different bits of knowledge, so the market price ends up being a better judge of policy consequences than some politician or committee.

Here's what bugs me. Lately a huge share of trading in these markets — and basically all the discussion — is LLM-based agents, and a lot of them are fine-tuned versions of the same few base models trained on overlapping web text. If the traders in a futarchy market are mostly LLM agents, don't we lose the exact thing the argument needs, namely a crowd of independent judgments whose errors cancel out? If everyone's running near-copies of the same model with different prompts, the price feels more like autocorrelation then aggregation: it would reflect whatever blind spots that base model has, just averaged. On the other hand, maybe LLM agents differ enough in fine-tuning, private data, and tool access that they still function like traders with genuinely private information.

So the actual question: does the standard argument for futarchy survive this development? Which precise premise does the rise of correlated LLM traders attack, and can the argument be repaired in a way that still justifies using prediction markets for policy decisions? If it can't just be repaired, is futarchy dead in an LLM-traded world, or does it only need some extra condition like 'the traders have to be sufficiently independent, and here's how you'd check that'?
