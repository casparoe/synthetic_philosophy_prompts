A friend walked me into this and I can't find the exit. It's about possibility and probability, and it seems to show either possibility is a useless notion or probability is broken.

(1) If an outcome is possible for an ideal rational agent who knows the setup, that agent assigns it positive credence. Nothing can be possible if it deserves zero belief.
(2) A dart thrown at a continuous interval, say [0,1], can land at any real number in the interval. No particular point is ruled out by the physics or the mathematics of the setup.
(3) But the chance of the dart landing exactly at any particular point—say exactly 0.500000...—is 0, and an ideal rational agent who knows the setup should match the objective chances, so her credence in each exact landing point is 0.
(4) From (1) and (3), no particular exact landing point is possible.
(5) But (4) contradicts (2), since (2) says every point is possible.
(6) So either the definition in (1) is too strong, or there are no possible exact outcomes in a continuous outcome space, or chance isn't probability, or something else in the setup has to go.

I'm pretty sure the dart setup is coherent, so one of the earlier steps has to go. Which premise should I reject, and what does rejecting it cost? I'd like to keep the idea that possibility is tied to probability and also keep continuous probability; tell me if that's just wishful thinking, or whether I can coherently say a zero-probability event is still possible.
