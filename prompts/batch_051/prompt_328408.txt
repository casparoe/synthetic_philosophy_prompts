Suppose we accept, for the sake of argument, that the free-will problem has the following shape. If determinism is true, every choice is a necessary consequence of the remote past and the laws of nature, so it is hard to see how the choice is up to the agent. If indeterminism is true and quantum events influence decision-making, then some component of the decision is a matter of chance, and a chance occurrence is no more up to the agent than a deterministic one is. Call this the dilemma.

Now consider a decision system with a two-stage architecture. Stage one is a genuinely indeterministic generator that produces a small slate of candidate actions, each with an objective probability, and then leaves the slate fixed. Stage two is a deterministic evaluator, fully determined by the agent's stable values, beliefs, and reasons, which selects one action from the slate. Nothing else about the agent is indeterministic.

Consider three versions of the architecture. In Version A, the generator is perennially active: for every nontrivial decision it produces at least two candidates the evaluator takes seriously, and which candidate is selected depends on which slate happens to appear, so the action genuinely varies across the slates the setup leaves open. In Version B, the generator is usually inert: for most decisions it produces only one serious candidate, though on rare occasions it supplies a second candidate that the evaluator would sometimes select. In Version C, the generator is causally active but practically inert: it always supplies alternatives with positive objective probability, but the evaluator's ranking is so stable that the same action is selected on every possible slate; the chosen action never differs from what a fully deterministic evaluator with no generator would have produced, though it would have differed if the evaluator's ranking had been different.

For each version, determine whether the agent can do otherwise in any sense strong enough to ground moral responsibility. Does the random slate at stage one contribute something that free will requires, or does it only inject unpredictable noise into a process whose outcome is still fixed by the evaluator and the probabilities? State where a compatibilist and a libertarian should diverge across the three versions, and identify which version, if any, escapes the dilemma rather than relocating it. If neither standard position captures your own view, state that view and run it against the three versions.
