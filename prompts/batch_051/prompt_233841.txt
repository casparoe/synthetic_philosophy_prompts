I'm preparing a set of discussion notes for a reading group on the foundations of algorithmic information theory, and I need help with one session. The session is about a specific claim: that Solomonoff induction — the Bayesian prior that assigns probability 2 to the power of minus the length of each program and predicts by summing over all programs consistent with the data, with shorter programs weighted more heavily because Kolmogorov complexity measures description length — supplies an objective, principled formalization of Occam's razor. By objective, I mean independent of arbitrary choices on the part of the reasoner. I want the notes to include a survey of the standard objections to that claim, and so far I have the following six. (1) Uncomputability: the predictions of the Solomonoff predictor cannot be computed by any finite procedure, so no actual agent can use it, and any finite approximation introduces further free choices that are no longer the supposedly objective prior. (2) Reference-machine dependence: Kolmogorov complexity is well defined only relative to a choice of universal Turing machine or programming language, and although the invariance theorem says that changing the machine changes all complexities by at most an additive constant, that constant can be enormously large and is unknown; with any finite body of data, switching the reference machine can therefore reverse the simplicity ordering between rival hypotheses. (3) Relativity to the observation vocabulary: even with a reference machine fixed, the complexity of a hypothesis depends on how the data are translated into the strings the hypothesis is asked to predict — on which primitive features, such as green versus grue, the encoding takes as basic — so a gruesome encoding can make a gruesome generalization simpler than its ordinary rival; the grue problem is displaced into the coding rather than solved. (4) The prior is restricted to computable hypotheses: because the prior is a mixture only over finitely describable programs, any data-generating process that is not computable receives zero prior weight, so the method rules it out a priori and could never recover it from evidence. (5) Computational cost is ignored: the prior evaluates a hypothesis by the length of its program and not by the time or space the program needs to run, so a very short program that would take astronomically long to produce its predictions is favored over a slightly longer but feasible one, which seems contrary to the simplicity scientists actually care about. (6) The guarantees are asymptotic and constant-riddled: the standard convergence results bound total prediction error by a constant that depends on the reference machine and on the complexity of the unknown true process, so on the finite data we actually encounter they give little reason to expect good performance.

I believe this list covers everything standard, and I don't want the handout padded with near-duplicates. What I need is one more objection that is not on this list, and that is not a rewording, special case, or combination of the items above — something whose underlying structure differs from all six. State the objection as clearly as you can. Then explain two things: how it relates to the objections already on the list, and whether you think it is a serious objection to the claim or only a minor qualification.
