I'm trying to get a handle on the paradoxes that show up when a legal system (or a Nomic-style game, where changing the rules is itself a move allowed by the rules) lets rules refer to themselves, repeal themselves, or amend the very rules that govern amendment. For a catalogue I'm building — no citations needed, I'll sweat those later — I want a sixth distinct paradox of self-referential rules. So far I've got these five, and they seem to cover the obvious moves:

1. The self-repealing rule. A rule says "this rule is hereby repealed." If it comes into force, it kills itself; if it never comes into force, it can't kill anything. Its unclear whether the rule exists for an instant, never exists, or is void from the start.

2. The amendment clause that amends itself. A constitution lays down a procedure for amending the constitution; someone uses that procedure to rewrite the very clause that specifies the procedure. The puzzle is which version authorizes the change: the old clause (the one being replaced) or the new one (the one the change creates).

3. The self-entrenching provision. A rule declares itself immune to amendment, or says any attempt to amend it is void. The puzzle is whether a later act can validly repeal the entrenchment, since the repeal itself is an attempt to change the very thing the entrenchment forbids changing.

4. The self-referential formal-requirement rule. A code includes a rule like "every rule in this code must be at least twenty words long," but that very rule is only seven words. Either the code is invalid, the rule is invalid for failing its own requirement, or the rule silently means "all other rules," and there's no obvious reason to prefer one reading.

5. The mutable-priority problem. There's a rule that says which rule wins when two rules conflict; someone uses it to change that priority rule. It's unclear whether the change must be evaluated under the old priority order (which authorized the change) or the new one (which the change installs), and the two can give different answers.

I want a sixth one that is structurally different from all five — not the same paradox wearing a different costume, not just two of these stuck together. It can come from law, games, constitutions, private rulebooks, whatever, as long as the problem is genuinely self-reference rather than vagueness or ambiguity.

Format: give me a JSON object with fields: "label" (a short name for the new paradox), "setup" (the situation, two to four sentences), "contradiction" (the opposing conclusions it seems to force), "why_not_on_list" (why it's not a special case or combination of the five above), and "verdict" (your honest take on whether it's a real paradox or just a trick of words).
