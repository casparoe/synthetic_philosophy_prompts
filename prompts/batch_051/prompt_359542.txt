ok so I'm a software engineer and I've ended up with this cluster of views about whether technologies have politics built in, and I cant tell if its coherent. Here's roughly where I've landed:

(1) I reject the technology-is-just-a-tool line. Some systems have politics baked into the design before anyone uses them: a payments processor that refuses certain legal but controversial transactions, a moderation UI that only lets you report some categories and not others, DRM that blocks copying even when it would be legal. Those aren't neutral.

(2) But I also find most technological determinism kind of lazy. Almost any capability can be wrapped in different ownership, regulation, and defaults, and the politics changes a lot with the wrapping. When someone says a technology is inherently capitalist or authoritarian, I usually think they've mistaken the current implementation for the thing itself.

(3) I want a pretty sharp line between designs that forbid and designs that merely discourage. If the system cryptographically prevents some action, the designers made a political decision people can't opt out of without replacing the system; if it just nudges or adds friction, it's much less loaded because users can still route around it. I'm inclined to put most of the designer's political responsibility on the first kind.

(4) But I also think designers can't own what users do downstream with a general-purpose system. I've watched enough weird repurposings that foreseeable misuse feels way weaker than people pretend. If the design didnt actually foreclose alternatives, the downstream use is on the users and their context, not on the builder.

(5) The thing I actually care about, if I'm honest, is chokepoints. A technology gets its bad politics when it makes some point of control cheap for a few actors to monopolize, whether or not anyone intended it and whether or not it strictly forbids alternatives. So maybe my real question isn't built-in versus social, but whether the design makes the control point cheap to capture.

Do these hang together? When I try to line them up it feels like there's a conflict hiding somewhere, but I can't put my finger on which pair it is, and I don't know which one I should give up. Please audit the set: which pairs are genuinely in tension, which pairs only look like they are, and what the cheapest consistent version of this position would cost. If there are several tensions, order them by severity and say for each what would have to give.
