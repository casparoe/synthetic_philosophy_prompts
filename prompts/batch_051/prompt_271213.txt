Exam question: State the no-free-lunch theorem in the form standard in machine learning, and explain its bearing, if any, on the philosophical problem of induction.

Student answer:

The no-free-lunch theorem says that when one learning algorithm does better than another on some possible target functions, it must do correspondingly worse on others; averaged over every possible target function, weighting each equally, all learning algorithms have exactly the same expected generalization error on unseen cases. The usual lesson drawn is that there is no "best" algorithm in general. This mirrors Hume's point about induction. Hume argued that any inductive inference must presuppose that nature is uniform; without that, the fact that the sun has always risen gives no reason to expect it to rise tomorrow. Likewise, a learning algorithm can generalize well only if the target function has a shape that matches the algorithm's built-in assumptions, such as smoothness or linearity. So the theorem can be read as a formalization of the claim that induction is never justified by the data alone: any rule that extrapolates from data will be no better than random guessing when averaged across all possible worlds. Therefore the choice among inductive strategies is rationally arbitrary, and the problem of induction has no solution. Moreover, for any fixed data set, the theorem entails that the observed cases underdetermine the unobserved ones: every generalization that fits the data is exactly as well supported as every other. What the theorem does not show is that learning is pointless in practice, because real-world problems are not drawn uniformly from the space of all possible functions; they tend to have structure, and practical success depends on matching that structure.
