I'm not an academic — I work in software support, and I've been following the public debate about whether we'll ever be able to trust a large AI system we can't audit by hand. The idea people keep reaching for is that when a system is too complicated for a human to inspect directly, we can build a second AI to inspect the first one, translate what it finds into plain language, and tell us whether the first system is doing something dangerous. A worry about that move has been nagging at me for weeks, and I've tried to lay it out as a little proof. Here it is:

(1) If a system is too complex for humans to audit directly, then the only way to justify a claim about what it is doing internally is to have another AI inspect it and report back.
(2) A report from an inspecting AI is itself just the output of a complex system, so it can justify a claim about the first system only if we have some independent reason to trust the inspector.
(3) For a system of this kind, the only available independent reason to trust the inspector is to inspect how the inspector itself reaches its reports.
(4) But by (1), that would require a third AI to inspect the second, and a fourth to inspect the third, so every inspector is vouched for only by the next inspector, which has not itself been checked.
(5) Therefore no report in this chain is ever better supported than the unexamined word of a complex system, and AI-assisted auditing can never solve the problem of checking a system too complex for humans.

I half-suspect step (3) is the sleight of hand, but I can't articulate the alternative kind of reason that would stop the regress. Is the argument valid? If not, where exactly does it break? Please go through the five steps in order, taking each one in its most charitable reading, and say whether the argument still goes through.
