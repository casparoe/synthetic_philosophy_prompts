A colleague in a seminar on perception and cognition has a habit of ending arguments about cognitive penetration with the line ‘we see what we expect to see’. Last week he used it to dismiss an objection according to which knowing that the Müller-Lyer lines are equal does not stop them from looking unequal. I suspect the slogan is being made to do more work than it can bear, but I want to be precise about the alternatives.

Please lay out the distinct precise claims that the slogan ‘we see what we expect to see’ could be making, arranged from the most innocuous to the most radical. For each reading, do three things: state the claim in one or two sentences, give a verdict (trivial, plausible but modest, substantive and controversial, or false), and say whether that reading would support the conclusion that expectations, beliefs, or desires literally alter perceptual experience itself rather than merely influencing attention, interpretation, recognition, judgement, or report. Be careful to separate claims about perceptual processing from claims about post-perceptual judgement or response bias, and to distinguish cases where the expecter sees a different object or property from cases where the same object is genuinely experienced differently.

After the analysis, provide a JSON object with the schema described below. The JSON should have a key “readings” whose value is an array of objects, each with the following fields:
- “label”: a short name for the reading
- “precise_claim”: one or two sentences stating exactly what the reading asserts
- “verdict”: one of “trivial”, “plausible_but_modest”, “substantive_and_controversial”, or “false”
- “alters_perceptual_experience”: a boolean, true only if the reading involves a change in perception itself
- “supports_colleagues_use”: a boolean, true if this reading would actually support using the slogan to dismiss the Müller-Lyer objection

The JSON should also include a top-level field “best_reading_for_colleagues_argument” whose value is the label of the reading that would most plausibly support his dismissal of the Müller-Lyer objection, and a top-level field “strongest_defensible_reading” whose value is the label of the most radical reading that remains defensible.
