I have been reading about attempts to define the natural numbers within set theory, and I have come across a configuration that I do not know how to label. There are at least two standard ways of carrying out such a definition. On one, 0 is the empty set, and each later number is the set of all the numbers that came before it; so 2 is the set containing 0 and 1, and 4 is the set containing 0, 1, 2, and 3. On the other, 0 is again the empty set, but each later number is the set whose only member is the previous number; so 2 is the set containing 1, and 4 is the set containing 3. Both definitions can be made to support the ordinary operations and laws of arithmetic, and both serve equally well for the purposes of ordinary arithmetic. Yet they disagree on questions such as whether 2 is an element of 4, and there appears to be no mathematical fact that could settle which definition is correct.

What I would like to know is not merely a label. I want to know whether this configuration — two equally adequate identifications of the same subject matter that conflict on properties the subject matter was never intended to have — has an established name, and if so, exactly what the name covers. Does it name the problem itself, the conclusion that numbers should not be identified with any particular set-theoretic objects, or the further positive view that arithmetic concerns relations among positions rather than underlying things? If there is no established name, what would you call it, and how would you define its boundaries so that it does not collapse into the view that numbers do not exist, or into the view that arithmetic is merely a game with symbols?
