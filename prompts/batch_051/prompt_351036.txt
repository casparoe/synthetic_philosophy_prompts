I'm designing an exercise for an upper-level philosophy of language seminar, and I'd like a decision tree that sorts the live positions on whether a language could lack pronouns or indexicals. Build the tree from the logical space rather than from received labels, and phrase each branch question so a student can answer it by thinking through a concrete case rather than by recognizing a named view. The cases that must drive the tree are (a) a spoken language in which reference to the speaker is carried only by obligatory subject agreement on the verb, with no free-standing first-person pronoun, and (b) a signed language in which a point toward the signer functions as first person and a point toward the addressee as second person. Use the following questions as candidate branches, reordering or modifying them only if you can justify the change: whether an occurrence of an indexical ever contributes something that a rigid non-indexical description tracking the same referent cannot supply; whether indexicality is a property of dedicated expression-types or a structural demand on any language usable by situated agents; whether a language still counts as having an indexical when the indexical information is carried by obligatory bound morphology; and whether the signed point is a pronoun, an indexical, both, or something else. Aim for four to six leaves. The leaves must include indexical eliminativism, an essential-indexical view, a distributed-indexicality view on which indexical information can be carried by grammar or discourse without dedicated vocabulary, and a view on which a language can lack pronouns but still cannot lack indexicality. If the last two collapse together under your tree, keep them adjacent and state what the residual difference is; more generally, flag positions the tree cannot separate and diagnose unoccupied combinations as incoherent, unattractive, or unexplored. Do not organize the tree around who defended what. For each leaf, give the position's name, or write unnamed if nobody holds it, and one sentence on its most awkward commitment.
