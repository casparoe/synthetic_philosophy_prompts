I have been working through an argument that appears to prove something I find hard to accept: that in an ordinary one-shot Prisoner's Dilemma, mutual cooperation rather than defection is rationally required. I want to know which step to reject, and what rejecting it costs.

Setup. Two players play a one-shot Prisoner's Dilemma with payoffs T > R > P > S, where T is the temptation to defect unilaterally, R the reward for mutual cooperation, P the punishment for mutual defection, and S the sucker's payoff. In the standard simultaneous version, defection strictly dominates cooperation, because defection yields a higher payoff than cooperation no matter what the other player does.

Now consider a variant game. Each player writes a deterministic program. A program receives the other player's program as input and returns Cooperate or Defect. The two programs are run against each other, and the resulting actions determine payoffs exactly as before; the programs themselves are common knowledge. Call this the program game, and call any Nash equilibrium of it a program equilibrium.

Define the program Clique as follows: when given the opposing program as input, Clique cooperates if that program is syntactically identical to Clique, and defects otherwise. The argument runs:

(1) If both players submit Clique, each sees an opposing program identical to Clique and cooperates; both receive R.

(2) If one player unilaterally submits a different program while the other keeps Clique, the opponent's Clique defects; the deviator can then do no better than to defect, receiving at most P.

(3) Since P < R, no unilateral deviation from (Clique, Clique) is profitable; the pair is therefore a Nash equilibrium of the program game.

(4) (Clique, Clique) yields each player R, which is the highest payoff any equilibrium of the program game can give; in particular, it payoff-dominates mutual defection, which yields each player only P. Given common knowledge of the game and of one another's rationality, players select the payoff-dominant equilibrium rather than a Pareto-dominated one.

(5) An ordinary one-shot Prisoner's Dilemma is just the program game with the programs implemented in human decision procedures rather than in code and not legible to the other player in advance. The terminal actions and payoffs are identical.

(6) Legibility cannot change what it is rational to choose. Whether the other player can read my decision procedure before acting is an epistemic fact about them, not a difference in my options or in what each option causes.

(7) Therefore, if rational players select mutual cooperation in the program game, rational players also select mutual cooperation in the ordinary one-shot Prisoner's Dilemma.

(8) But that contradicts the dominance argument for defection in the ordinary game. The standard analysis of the one-shot Prisoner's Dilemma would apparently be wrong.

I am most reluctant to give up (6), since a principle of rationality ought not to depend on what the other player happens to be able to observe. Which step should I reject, and what does rejecting it cost? If I keep (6), which other step must go, and can I then still explain why the program-equilibrium result does not overturn the standard analysis of the ordinary one-shot Prisoner's Dilemma?
