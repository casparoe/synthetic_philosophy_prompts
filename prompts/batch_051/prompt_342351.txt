So I've been messing with the Condorcet jury theorem to see if epistocracy actually buys you anything. The version I'm starting from is the heterogeneous one: n independent voters, two options, one objectively right, and each voter has her own probability p_i of picking the right option, with maybe some p_i below 1/2 but the average comfortably above 1/2, so majority rule still converges to certainty as n grows. Now change it like this. You can't observe p_i directly, so you give everyone a civic-competence test, and only the top half of scorers get to vote. The test score is just p_i plus some independent symmetric noise, and I want the noise to have heavy enough tails that a non-trivial number of people with p_i < 1/2 make the cut while some people with p_i > 1/2 get excluded. So the selected group can look pretty unrepresentative. My question is: does the theorem's argument survive this selection stage, or does it quietly stop applying? Specifically, is majority rule among the selected voters still guaranteed to converge to the right answer as the number of selected voters grows? And can this noisy epistocracy ever do *worse* than universal suffrage, where the comparison is: majority rule among the selected group versus majority rule among a random sample of the same size from the whole population, both in expectation over the test and the votes? If it can do worse, whats the minimum amount of information the test has to carry about p for epistocracy to beat universal suffrage in this model; if it can't, why not? I'm less interested in the real-world policy argument and more in exactly what part of the theorem's assumptions gets broken, if any.
