I have been trying to use the distinction between the inside view and the outside view as a way of being epistemically modest about my own planning, but I worry the outside view collapses once I try to make it precise. Suppose I want to estimate whether I will submit my doctoral thesis within a year. The outside view, as I understand it, tells me to anchor on the base rate for a suitable reference class and then adjust that figure in light of the particular features of my own case. The difficulty is that the base rate changes sharply depending on whether my reference class is all doctoral candidates, candidates in my discipline, candidates at my institution, or candidates supervised by the same person. There appears to be no fact of the matter about which class is correct, and every such base rate is itself only an aggregate of other people's individual, inside-view judgements. Taking the outside view therefore seems either arbitrary, because I can select whichever class produces the base rate closest to my existing belief, or self-defeating, because the aggregate merely packages up the very inside views I am supposed to be correcting. Is there a non-arbitrary way of choosing a reference class, and what, if anything, does the outside view genuinely add once this problem is acknowledged? Please write your answer in British English.
