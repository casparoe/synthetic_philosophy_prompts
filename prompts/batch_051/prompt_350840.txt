One student wrote:

Gödel's first incompleteness theorem says that any consistent formal system strong enough to express elementary arithmetic contains a sentence G that is neither provable nor disprovable. G is constructed to assert its own unprovability, so it must be true; hence the system cannot prove all arithmetical truths. The second theorem says no such system can prove its own consistency. Taken together these show that truth outruns proof in any formal system: mathematical truth cannot be captured by a finite set of axioms, even in principle. This has consequences outside mathematics. First, it refutes the idea that the mind is a computer, because a machine would just be such a formal system, so there would be a true arithmetical sentence it couldn't prove, while we humans can see that G is true; so human reasoning cannot be algorithmic (this is the conclusion Penrose is famous for). Second, it rules out a final theory of physics, since physics is supposed to be a single formal system and any such system rich enough to talk about the integers will be incomplete. Third, it shows that there are mathematical truths that are unprovable in principle, and therefore unknowable. The main qualification is that the system has to be strong enough to embed arithmetic; Gödel says nothing about weaker systems like geometry.
