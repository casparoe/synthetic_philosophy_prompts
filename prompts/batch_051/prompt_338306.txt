I'm a retired physical chemist, and I've been reading philosophy of biology for the last year or so, so this might be the kind of thing that has an obvious answer I just haven't come across. I keep finding myself wanting a distinction, and I'd like an honest assessment before I embarass myself in a reading group.

I've taken to calling it the 'misreading test.' A system carries a code, I want to say, only if there's a difference between reading it wrong and having the machinery break down. Morse: I transcribe dot-dash as C when I should have transcribed A. The receiver clicks fine, the physics didn't object, and yet I've got it wrong. ASCII: I send a byte that maps to an umlaut instead of an apostrophe. The computer doesn't crash; it misreads. So a code is a system where errors can be pure errors—errors of interpretation that aren't malfunctions.

Now DNA. If a tRNA grabs the wrong amino acid, or the ribosome slots in a valine where the codon called for glutamic acid, nobody says the cell misread the code. They say the machinery failed. The reason, I suspect, is that there's no reading that hovers above what the molecules actually do. The codon table isn't a convention we can violate; it just is the set of aminoacyl-tRNA synthetases and tRNAs the cell happens to have. Change that set and the 'code' means something else, with nothing to say the old one was right. Change the ASCII table and the old table still has a claim on us—we can say the machine is now misreading it.

So my thesis is: DNA is a code only in a heavily washed-out sense that no semiotic code would recognize, and talk of 'genetic information' quietly smuggles in a reader that nobody has found. I know that sounds strong, and I can already hear the objection that maybe DNA is more like a recipe, and recipes do have misreadings in my sense. But then shouldn't we stop calling it a code?

Three things. First, is the misreading test a real distinction, and has someone already made it under another name? Second, is the claim about DNA actually right, or does DNA pass the test in a way I'm not seeing? Third, where does the test break—what genuine code does it exclude, or what non-code does it wrongly include?

And one more request, since I can't tell which of my steps is the weak one: tell me what would change your verdict, and where your reasoning is most likely to fail.
