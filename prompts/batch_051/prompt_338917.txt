It concerns Galen Strawson's Basic Argument against moral responsibility. As I understand it, the Basic Argument runs like this. An action issues from the way the agent is: her beliefs, desires, values, and dispositions. To be truly or ultimately responsible for an action, the agent would have to be truly or ultimately responsible for the way she is, at least in the respects that produced the action. But she could be responsible for the way she is only if she had shaped herself into being that way. Any such act of self-shaping would itself issue from a prior self — some already-existing set of principles, motives, and capacities — so the same requirement applies to that prior self, and then to the one behind that, with no first term. Since the chain cannot bottom out, Strawson concludes that nobody is ever truly morally responsible for anything. At most we get a weaker, everyday sense of responsibility that stops the regress by stipulation.

Written as a predicate, this looked to me exactly like an ill-founded recursive definition. Let responsible(x, S) mean that agent x is truly responsible for state or action S. Strawson's argument, on my reading, is committed to these recursive rules:

(1) responsible(x, action A) holds only if responsible(x, character C), where C is the character that issued in A.
(2) responsible(x, character C) holds only if responsible(x, character C'), where C' is the earlier character that issued in the shaping or choice of C.
(3) Rule (2) re-applies to C' and to every earlier character in turn, and there is no base case anywhere.

Understood as code, this recursion never terminates: every obligation to establish responsibility generates a structurally identical earlier obligation, so no input ever returns true. The conclusion would then be that the predicate has an empty extension — the definition is coherent in form but has no finite derivation for any atomic responsibility fact.

Two questions then arise. First, is this restatement faithful, or does it smuggle in a premise? In programming, I choose my definitions, and a recursion with no base case is simply a bug. Strawson seems to hold that the recursive structure is not optional: it is forced by what true responsibility requires, so the missing base case is a discovery about the concept rather than a design flaw in his formulation. Is that a real distinction, and does the computational framing sharpen it or blur it?

Second, the standard compatibilist move looks exactly like a refactor. One either rejects rule (1) and grounds responsibility for an action directly in how it flows from the agent's actual character, or one adds a base case to that effect:

(0) responsible(x, action A) holds when A issues from x's actual character in the right way, with no further requirement that x be responsible for that character.

Strawson will say this changes the subject to a weaker, merely surface notion of responsibility. Does the recursion framing illuminate the disagreement, or does it distort it by treating responsibility as a formal definition when it is a fact about agents?

I am also curious about a fancier computational option. We distinguish inductive definitions, which need a base case, from coinductive definitions, which are non-well-founded but can still be productive, like a stream whose next element is always defined though the stream has no final element. Could a serious position hold that responsibility is coinductive — that the chain of character-behind-character goes back forever while the present fact of responsibility remains well-defined and productive?
