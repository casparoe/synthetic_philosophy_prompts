ok so I'm trying to write up a view about how names work for a reading group and I want a consistency check before I present it, cause I have the feeling some of these pull against each other but I can't tell which ones. Heres where I've landed:

(1) proper names are rigid designators — they pick out the same individual in every possible world where they pick out anything.

(2) The reference of a name is fixed by an original dubbing and then passed along a causal-historical chain of communication. Descriptions don't do the fixing: in the Gödel/Schmidt case, my 'Gödel' refers to Gödel even if the only associated description I have is the guy who proved the incompleteness theorems, and some guy named Schmidt actually proved them.

(3) But I also think reference can migrate along a chain through repeated error, without any new dubbing. The standard Madagascar example seems to show this: the name apparently got attached to one place and then ended up attached to a different one because later users kept meaning the second place. So a causal chain doesn't automatically preserve reference.

(4) Empty names like 'Sherlock Holmes' are meaningful, and sentences with them are just true or false — 'Sherlock Holmes is a detective' is true, 'Sherlock Holmes is a football coach' is false. Emptiness isn't some semantic catastrophe.

(5) Family names and given names are semantically different. A family name seems to denote a lineage or kind rather than an individual — that's why 'she's a Kennedy' predicates membership in a lineage, but 'she's a Mary' doesn't do the analogous thing; it just says she's called Mary. So the given-name/family-name split isn't just bureaucratic or about word order.

I don't know which of these I'd give up, and I don't want to bias you by saying which one I suspect is the weak link. Go through them and tell me which pairs are in genuine tension, which only look like they are, rank the genuine ones by severity, and say what the cheapest fix is for each. Then tell me the single revision that would clean up the most at the lowest cost.
