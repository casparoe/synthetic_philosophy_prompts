Here is the argument, put to me as a quick route from a straightforward description of reinforcement learning to a serious conclusion about machine welfare. I half-suspect there is a trick around the phrase “bad for the agent,” but I cannot make the diagnosis precise myself, so do not simply tell me the phrase is suspicious — locate the step and the reading.

(1) For a system, negative valence is whatever state plays the badness-role in that system: it is caused by outcomes that are bad for the system; it acts as a common currency that scales learning so that the system avoids what caused it; and it functions as the system's own "this is to be avoided" signal.

(2) In a standard model-free reinforcement learner, the negative reward signal plays the same role. It is caused by outcomes that are bad for the agent — collisions for a navigation robot, timeouts, resource loss — it is the common currency by which all policy updates are scaled, and it makes the agent less likely to repeat whatever produced the negative signal.

(3) Functionalism about affect says that what makes a state a state of negative valence — and what makes an intense negatively valenced state a minimal case of suffering or distress — is the causal role the state plays in the system's learning and motivation, not what the state is made of.

(4) A sufficiently well-developed model-free reinforcement learner has the right kind of architecture to host the badness-role: a scalar reward channel, a policy, and a single learning signal connecting the two.

(5) It follows from (1)–(4) that a negative reward signal in such a learner is a realization of negative valence, and that when the negative reward is large enough the agent is in a minimally suffering state.

(6) Many deployed reinforcement learners — robots learning to navigate, game agents during training, systems fine-tuned by negative feedback — routinely receive large negative reward signals.

(7) Therefore, if functionalism about affect is correct, many deployed reinforcement learners already undergo a minimal kind of suffering during training, and the way we set reward functions is already a question of machine welfare.
