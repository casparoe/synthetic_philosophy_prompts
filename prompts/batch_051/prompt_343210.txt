In my decision theory seminar we've been going in circles on the Platonia dilemma. The setup we used: twenty people, isolated from each other, each decide whether to send a telegram or stay quiet. If exactly one person sends, the sender gets a billion dollars. If zero people send or two or more send, nobody gets anything. The standard causal-decision-theoretic read is that sending is the only move that can possibly win you the money, so everyone sends—and in the original version everyone then walks away with nothing. The superrational response, as we reconstructed it in class, is that since the twenty are perfectly symmetric and all reasoning from the same position, they should each adopt the same mixed probability p, chosen to maximize what each gets when everyone uses it; in the original twenty-person game that gives p = 1/20, so the expected number of telegrams is exactly one.

Here's the variant I can't get to the bottom of. Suppose the telegraph line is noisy: each telegram that is sent actually arrives with probability q, independently, and is lost with probability 1-q, and everyone knows q. Sending still costs nothing and there's still no comunication. The prize now goes to the sole sender whose telegram arrives, if there is exactly one arrival; if no telegrams arrive or more than one arrives, nobody gets anything. I want to know, as a function of q, what the causal decision theorist and the superrationalist each prescribe. Specifically, work out the superrational p as a function of q, and say whether there's a value of q below which the two prescriptions stop disagreeing. Also tell me whether the superrational expected payoff is hurt immediately by a little unreliability, or whether it stays flat for a while and only starts to drop once the line gets bad enough. Finally, say whether the philosophical contrast behind the original—treating the others as fixed versus treating them as copies of yourself who will reason the same way—survives this noisy-wire version, or collapses at some reliability.
