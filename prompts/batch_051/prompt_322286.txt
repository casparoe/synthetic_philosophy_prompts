Yesterday evening a friend and I argued for several hours about exactly when an infinite regress is vicious. He held the simpler view: a regress is vicious whenever the chain lacks a terminus, because without a foundation nothing in the chain is ever finally secured. I kept insisting that bare lack of a terminus is not enough, and that viciousness must be earned by showing something further has gone wrong — that the problem merely reappears at each level, that each step defers satisfaction of the original condition, or that the series cannot be completed given other things we accept. We ended the evening with the following list of candidate tests for viciousness and no agreement about their relative weight.

Please rank these six candidate tests from most to least reliable as a diagnosis of when an infinite regress is genuinely vicious — that is, from the one that best separates regresses that really undermine a view from regresses that merely display an infinite structure we can live with — and say in a sentence why each lands where it does.

1. Non-termination: the chain has no final member, so there is no foundation, first cause, or ultimate analysans.
2. Reinstatement: each level reintroduces the same kind of item that was to be explained, so no level advances beyond its predecessor.
3. Deferred satisfaction: each link obtains only if the next link obtains, so the original condition is never unconditionally met.
4. Explanatory stagnation: each step postpones the request for an explanation rather than answering it.
5. Completed-infinity commitment: the position requires an actually completed infinite series, or requires a finite subject to have run through one.
6. Independent impossibility: the regress is not vicious in itself but becomes vicious because, taken together with other accepted claims, it entails something impossible.
