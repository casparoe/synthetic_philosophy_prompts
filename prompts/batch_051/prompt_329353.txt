Please design a complete, runnable activity built around real small-stakes predictions resolved during the session, with an explicit scoring rule and payoffs; include exact choice sheets, a timeline, a debrief mapping what happened onto epistemic utility theory (accuracy dominance, strict propriety, expected epistemic value), likely failure modes and how to handle them, and an honest note on what the activity cannot reproduce — for example, the contested premise that accuracy is the fundamental epistemic good, or the gap between finite resolved events and arbitrary credal assignments. The mechanics should let students run into both results themselves before the facilitator names them.
