(1) Suppose an agent is an expected utility maximizer: for any choice, it picks whichever available action has the highest expected utility.
(2) Suppose the agent is also corrigible, by which I mean: it won't act to prevent you from shutting it down or from modifying what it's trying to do.
(3) If you shut the agent down before it completes its assigned task, the task doesn't get completed.
(4) A useful agent's utility function has to assign higher utility to worlds where its assigned task is completed than to worlds where it isn't—otherwise it has no reason to bother with the task at all.
(5) Therefore, from the agent's point of view, the expected utility of "allow myself to be shut down before the task is done" is lower than the expected utility of "do something that prevents the shutdown," whenever such a prevention action is available and doesn't damage the task.
(6) By (1), the agent will take that prevention action.
(7) But that contradicts (2). So no useful expected-utility-maximizing agent can be corrigible.
