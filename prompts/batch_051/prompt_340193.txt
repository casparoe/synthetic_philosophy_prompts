"Quantified modal logic studies how the quantifiers 'all' and 'some' interact with 'necessarily' and 'possibly,' and the Barcan formulas, introduced by Ruth Barcan Marcus, are the two principles that fix the order of those operators. The Barcan formula is usually written as (◇∃xFx → ∃x◇Fx): if possibly there is something that is F, then there is something that is possibly F. The converse Barcan formula is the same implication run the other way, (∃x◇Fx → ◇∃xFx). In possible-worlds semantics, each formula corresponds to a constraint on how the domain of quantification varies from world to world. The Barcan formula is valid on a frame exactly when domains never grow as you move from a world to an accessible one; this is why it is commonly glossed as saying that there are no merely possible objects. The converse is valid exactly when domains never shrink; this is why it is commonly glossed as saying that whatever exists at a world also exists at every accessible world. Because these two constraints point in opposite directions, the two formulas are logically independent: there is no inconsistency in accepting one while rejecting the other. The blog's philosophical takeaway is that the Barcan formula is the genuinely controversial one, since it would imply that if a childless couple could have had a child, then some already existing thing could have been that child—which sounds like it drags merely possible children into the actual world. The converse, by contrast, is harmless: it only says that if something actually exists and is possibly F, then possibly something is F, and that is guaranteed by the original thing's being F in some possible world. The asymmetry is why the standard semantics for quantified modal logic is set up to validate the converse but not the Barcan formula."
