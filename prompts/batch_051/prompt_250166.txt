I'm not a mathematician or anything, I just like gambling puzzles. I think I've found a bet where the expected value isnt really a number at all, and I want someone to check it before I embarrass myself.

Here's the game. Flip a fair coin until it lands heads. Say that takes n flips. If n is odd, the house pays you 2^n divided by n dollars. If n is even, you pay the house that amount instead. So heads on the first flip wins you $2; heads on the second means you owe $2; on the third you win about $2.67; on the fourth you owe $4; and so on.

Now the weird part. If I add up the expected value the normal way, one term per flip-count, I get about 69 cents. So you'd think the game is worth a little under a dollar. But the series only hangs together because the positive and negative terms cancel. If I rearrange the terms — which is just changing the order I add up the cases, not changing the bet itself — I can make the expected value come out to 10, or minus 1000, or pretty much anything. The same bet seems to be worth whatever I feel like it's worth.

I've been calling this a rubber expectation, because you can stretch it to any number you want. My claim is that expected value is a shakier idea than people admit: for a bet like this, saying the expected value is 69 cents is no more true than saying its ten dollars, so the whole idea of a fair price for the bet is broken.

Tell me straight: is this a real problem or am I just fooling myself with a reordering trick? Has someone already found this and given it a fancy name? And if I'm right that the expected value is undefined, what should a rational person actually do if someone offers them this bet — refuse it, pay a dollar to play, or what?
