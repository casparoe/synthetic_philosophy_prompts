I'm trying to pin down why the "God's nature" response to the Euthyphro dilemma keeps bugging me. A friend sent me this argument against divine command theory, and I half-suspect it's too quick:

(1) On divine command theory, an act is wrong only if God commands against it.
(2) If God has a reason to command against murder, then there is some feature of murder that counts against it prior to and independently of the command.
(3) If there is such a feature, then murder isn't wrong just because God commands against it; it's wrong at least partly because of that feature.
(4) So divine command theory either makes God's commands arbitrary (if there are no reasons) or makes commandedness morally redundant (if there are reasons).
(5) Arbitrariness and redundancy both undermine divine command theory.
(6) Therefore divine command theory is false.

I think the weak spot is somewhere around (2) or (3), because "independently of the command" isn't the same as "independently of God." But I can't tell whether that's an equivocation the argument actually needs, or whether the premise just wasn't stated carefully enough. Is the argument valid, and if not, which step exactly fails?
