I run a small grant program at a cultural foundation that funds language documentation, traditional crafts, and local festivals. I make the first cut on maybe forty applications a cycle, spending around forty-five minutes each, and the board signs off on my recommendations. The board is split: some members think a tradition or language is worth funding only insofar as the people who practice it actually value it and will plausibly benefit, others think some things are worth preserving in themselves—like a language with three elderly speakers left—even if no one will speak it in thirty years. I need a decision procedure my reviewers and I can actually run: the questions in order, what counts as a good enough answer to each, where the procedure stops with a no, and where it has to hand the decision to a human because its a values call rather than a fact question. It should make explicit how it treats value to the current holders, value to outsiders like tourists or scholars, and the idea that the thing has value even if everyone stops caring. Then run it on two applications: documenting a last-speaker language that the remaining speakers want recorded, and reviving a fishing-boat building tradition the original community has mostly lost interest in but a local museum and the tourism board want back. Also tell me one realistic application the procedure would reject so I can see what I'd have to defend in the next board meeting.
