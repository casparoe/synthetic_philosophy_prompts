I'm a software engineer with no formal philosophy background, and I tend to read papers the way I read a design document: I look for the system boundary, the interface, and the test that would fail if the design were wrong. I was reading Andy Clark and David Chalmers, "The Extended Mind" (1998), and the following passage stopped me:

"In these cases, the human organism is linked with an external entity in a two-way interaction, creating a coupled system that can be seen as a cognitive system in its own right. All the components in the system play an active causal role, and they jointly govern behavior in the same sort of way that cognition usually does. If we remove the external component the system's behavioral competence will drop, just as it would if we removed part of its brain. Our thesis is that this sort of coupled process counts equally well as a cognitive process, whether or not it is wholly in the head."

The clause that trips me is "counts equally well as a cognitive process." In my own work, whether a function runs on the client or the server is usually an implementation detail, and whether one treats the two as "one system" is often just a modeling choice. But Clark and Chalmers seem to be asserting something stronger: that a human being coupled with an external device can literally form a cognitive system, not merely that it is handy to describe it that way. I want to know whether that assertion is testable, and if so, how.

My first-pass test would be subtractive: take away the notebook and show that the person's performance drops. But that seems far too weak. A bicycle also passes that test, and nobody would say the cyclist-plus-bicycle is a cognitive system. So I need a test that discriminates genuine cognitive extension from ordinary tool use, not just one that proves the external thing is useful.

Please design the strongest concrete test or experimental program you can think of, say exactly which result would count in favor of the thesis and which would count against it, and then say what even a clean result would leave untouched. I don't need a literature review; I want the test specified tightly enough that I could imagine running it.
