I'm a software engineer with no formal background in philosophy, and I've been trying to work through Kripke's skeptical argument about rule-following. As I understand it, the challenge is that no fact about me seems to determine whether by plus I meant the addition function or a bent alternative — call it quus — that agrees with addition on every pair of numbers I have actually considered and then diverges on some pair I have never considered. Since all of my past answers are finite, they are compatible with infinitely many such alternatives, so nothing about me appears to make plus rather than quus the correct continuation. This puzzles me, but not because I doubt the argument: rather, it seems to ignore how functions are actually specified in software. A function is not the finite list of outputs it has produced; it is given by a finite piece of source code, and the code together with the semantics of the programming language determines a unique function over all possible inputs. In the example, there seems to be a perfectly definite fact about me: I implemented plus in code, and that code decides every case, including the ones that have never been run. Why doesn't the source code count as the fact that determines which rule I am following, thereby dissolving Kripke's skeptical paradox?
