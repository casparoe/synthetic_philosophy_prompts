I am a retired natural scientist who has recently taken up philosophy of probability. I would be grateful for a precise diagnosis of the following argument, which a colleague pressed on me; it purports to show that no finite sequence can properly be called random, and I half-suspect a trick but cannot locate it.

(1) A finite sequence is random only if it is patternless, that is, only if there is no rule or algorithm from which the sequence can be generated.
(2) For any finite sequence S, the instruction "print S" is a rule from which S can be generated.
(3) Therefore no finite sequence is patternless: every finite sequence is generated by some rule.
(4) Hence no finite sequence is random.
(5) But a finite record of a long run of fair coin tosses is ordinarily taken to be a random sequence.
(6) So the ordinary notion of a random finite sequence appears to be incoherent.

Is the argument valid? If not, which step (or steps) fails, and how should the criterion stated in (1) be revised so as to preserve the distinction between more and less random finite sequences?
