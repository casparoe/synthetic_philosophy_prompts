I'm on the licensing working group for a university lab that ships a mix of GPL and proprietary research software, and next week we have to rule on a case that's got the group split. The chair, Marina, is an IP lawyer with very consistent instincts about where one program ends and another begins for copyleft purposes; we basically run her past verdicts as our precedent file (precident file, if you ask the admin for the folder). Her calls so far: a proprietary binary that statically links an unmodified GPL parser library is a derivative work and the package has to go out under the GPL; a proprietary app that dlopens an unmodified GPL shared library at runtime, shipping the library in the same package, is also derivative; a shell script that pipes its data through a standard GPL command-line utility as a subprocess and parses stdout is not derivative; a plugin written for a GPL image editor, loaded into the GPL host's process through its documented plugin API, is derivative; and a proprietary daemon and a GPL file-conversion tool that touch only by dropping files into a watched directory, either side swappable for anything else that reads the same format, are separate works. In all these cases the lab distributes to outside users, so the private-use exception isn't in play.

The new case on the agenda: a lab wants to ship a proprietary desktop client whose only function is to connect over a WebSocket to a GPL-licensed server we run ourselves. The client is purpose-built for that one server's private JSON-RPC protocol; pointed at anything else, it's just a login screen and nothing more. We'd ship the client to external users but not the server. The question is whether, to stay consistent with Marina's prior calls, we should treat the client as a derivative work.

Please answer as an expert on software licensing and copyleft theory, and think carefully before landing anywhere. Start by brainstorming the plausible rules that fit all five earlier verdicts, state each in a sentence, and then work out what each rule says about the WebSocket client. I care less about a bare yes/no than about whether Marina's track record actually forces one answer or leaves it underdetermined, which rule you'd bet on if you had to, and the single additional precedent that would cleanly settle which rule she's really running.
