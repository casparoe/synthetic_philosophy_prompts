Ok so ive been reading about the Turing test on and off for a few years, just on my own, not for any class, and I keep a running list of objections to the claim that if a machine can hold up its end of a typed conversation well enough that a judge cant reliably tell it from a human, then the machine is actually thinking. Heres what I have so far:

(1) The giant lookup table objection. In principle a machine could just have a prewritten response for every possible conversation up to some huge length, so it would pass without understanding anything at all, like a talking phonebook.

(2) The rulebook room objection. A person who knows no Chinese could follow a giant rulebook for pushing symbols around well enough to carry on a written Chinese conversation. The objection says the person, or the room as a whole, still doesnt understand Chinese, and the Turing test cant tell the difference between using meaningful language and shoving around meaningless symbols.

(3) The easy-to-fool-the-judge objection. The format rewards dodging the question, changing the subject, playing dumb, or pretending to be an eccentric human, so a machine built to dodge a judge could pass while being dumber than a bag of rocks. A pass might measure how gullible the judge is, not how much the machine can actually do.

(4) The impersonation-is-not-thought objection. The test is set up around passing for a human in typed small talk, so at most it tests a talent for impersonation. Being mistaken for a human in conversation is not the same thing as having a mind.

(5) The too-human objection. The standard is built around one species conversational habits, so something genuinely intelligent but alien could fail, while something built narrowly for casual chat could pass. Thats both too demanding and too shallow at the same time.

I keep feeling like theres one more genuinely different objection out there that I havent hit. I dont mean a rewording of those five, or a special case or combination of them. It should attack some part of the setup or the reasoning that the ones above leave alone, maybe something about whether any one-shot conversational test could ever set a good behavioral criterion for mind in the first place. If you can come up with one, give it to me, and then tell me honestly whether its actually any good and how it relates to the ones on my list.
