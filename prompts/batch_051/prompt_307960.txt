Ok so in math club we were arguing about tic-tac-toe and someone wrote up this proof that the first player (X) has a winning strategy. But everyone knows perfect play in tic-tac-toe is a draw, so the conclusion has to be wrong and the proof has to break somewhere — I just can't tell where. Here's the argument:

(1) Suppose the second player (O) has a winning strategy in tic-tac-toe.
(2) Then X can steal it: X makes any first move, and after that X just does whatever O's strategy says to do, except with the roles of X and O swapped. If the strategy ever says to play on a square X already has, X plays any empty square instead.
(3) In tic-tac-toe, having an extra X can never hurt X. Extra marks never remove any X's, so they can't break a line X would otherwise make, and they only take squares away from O.
(4) So the stolen strategy would let X force a win too. But both players can't have a forced win in the same game.
(5) Therfore O has no winning strategy.
(6) In a finite game like tic-tac-toe, if the second player has no winning strategy, the first player must have one. So X has a winning strategy.

Is this proof valid, or which exact step fails? If a step is bad, what's the corrected version of it?
