A blog post I read summarized the strategy-stealing argument for combinatorial games like this:

'Strategy stealing is a famous result showing that in any symmetric two-player game the first player can never be worse off. The proof assumes the second player has a winning strategy; the first player then makes an arbitrary opening move and simply follows that strategy herself. If the strategy ever calls for a move she has already made, she makes another arbitrary move. Since she now has an extra stone, mark, or whatever that can only help her, any winning strategy for the second player is really a winning strategy for the first. By symmetry, the second player cannot win, so the first player must win. This is why Hex, Chomp, and tic-tac-toe are all first-player wins even though no one has written down the explicit strategies.'

Something about this feels off to me, but I cant pinpoint where. I'm pretty sure tic-tac-toe is a draw with perfect play, and I've heard that in Go the first-move advantage is compensated by komi, which makes me suspect the blog is overgeneralizing. Which parts of this explanation would a combinatorial game theorist accept, which steps quietly sneak in extra assumptions, and what does a correct strategy-stealing proof actually show about games like Hex or Chomp?
