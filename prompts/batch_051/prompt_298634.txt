You are a professional philosopher specialising in normative ethics and formal decision theory, and you have been asked to referee a proposal about how agents should choose under moral uncertainty. Reason from the specification below; do not cite or look anything up.

The problem. An agent has a finite set of options and assigns positive credence to each of several live moral theories. Every theory supplies a complete and strict ordinal ranking of the options; some theories also supply cardinal choiceworthiness scores, but these scores are internal to each theory, and no common unit across theories has been justified.

The six candidate decision rules are:
R1 (front-runner). Act on the prescriptions of the single theory in which the agent has the highest credence; disregard the others.
R2 (weighted plurality). Give each option the total credence of the theories that rank it top; choose the option with the greatest total.
R3 (normalised expected choiceworthiness). Normalise each theory's cardinal scores onto a common 0–1 range and maximise the credence-weighted expected score.
R4 (positional aggregation). Convert each theory's ranking into points by position (top option n−1, ..., bottom option 0) and maximise the credence-weighted point total.
R5 (dominance-first). Treat an option as inadmissible only if another option is ranked above it by every live theory; among the admissible options, choose the one whose worst rank across theories is least bad, with the highest-credence theory breaking any remaining tie.
R6 (common-scale expected choiceworthiness). First obtain a defensible common cardinal scale across all theories; then choose the option that maximises credence-weighted expected score on that scale.

Task. Rank the six rules from most to least defensible as a general answer to moral uncertainty, grouping them into four tiers:
A — defensible without major qualification;
B — defensible only with substantial qualification;
C — problematic but instructive;
D — indefensible as a general rule.
Within each tier, give a further ranking. Then score each rule from 0 to 10, using integers only, on four criteria:
- information economy: how little the rule presupposes by way of controversial intertheoretic comparisons;
- ordinal robustness: how well the rule copes when theories supply only ordinal rankings;
- fanaticism resistance: how well the rule resists being dominated by a very-low-credence theory with extreme internal stakes;
- decisiveness: how often the rule yields a determinate verdict rather than silence or permissiveness.

Before assigning any ranks, work through one concrete invented case — three theories and three options — and note where the rules diverge. Then return a single JSON object with exactly this schema:
{
  "tier_meanings": {"A": "...", "B": "...", "C": "...", "D": "..."},
  "ranked_rules": [
    {
      "rule": "R1",
      "tier": "A",
      "rank_within_tier": 1,
      "overall_rank": 1,
      "scores": {
        "information_economy": 8,
        "ordinal_robustness": 5,
        "fanaticism_resistance": 4,
        "decisiveness": 9
      },
      "justification": "One sentence stating the main structural virtue or defect."
    }
  ]
}
In ranked_rules, overall_rank 1 is the most defensible rule, and rank_within_tier 1 is the best within its tier. Every field shown above must appear exactly once for each of the six rules. Keep each justification to a single sentence.
