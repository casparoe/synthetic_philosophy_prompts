A friend has an argument that supervaluationism about vagueness is internally inconsistant, and that epistemicism—the view that there really is a hidden sharp cut-off we can't know—is the only stable alternative. I suspect there's a scope trick in it, but I can't pin down the step. Here it is:

(1) On supervaluationism, a sentence is true (supertrue) when it comes out true on every admissible precisification of its vague terms, false when it comes out false on every precisification, and neither true nor false when the precisifications disagree.
(2) No admissible precisification leaves 'heap' vague: each one draws a sharp cut-off somewhere in a sorites series of 1 grain, 2 grains, ..., 100,000 grains.
(3) Now take the sentence S: 'There is some number n such that n grains is a heap and n−1 grains is not a heap.'
(4) Since every admissible precisification draws such a cut-off, S is true on every precisification. So S is supertrue.
(5) But if S is true, then some particular n satisfies its condition. That is, 'n grains is a heap and n−1 grains is not a heap' is true for that n.
(6) Yet the supervaluationist can't say that about any particular n. For any candidate cut-off, some admissible precisifications draw the line elsewhere, so no instance of the condition is itself supertrue.
(7) So supervaluationism entails both that there is a sharp boundary and that no particular sharp boundary exists. That looks contradictory, which would leave epistemicism holding the field.
