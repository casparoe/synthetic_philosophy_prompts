i'm taking a philosophy of science course where we just did Goodman's grue, and i'm also doing a machine learning module, and i cant shake the feeling that the same worry is hiding in both places. Goodman's point, as i understood it, is that a finite set of observations of green emeralds equally supports the generalisation all emeralds are green and the generalisation all emeralds are grue, where grue means green before some future time t and blue after t. The standard moral is that induction only gets off the ground if some predicates are treated as projectible, but justifying that choice without going in a circle is famously hard. In machine learning i keep seeing what looks like the same problem: after any finite training set there are infinitely many functions that fit the data exactly, and almost all of them do insane things on new inputs. We respond by picking a hypothesis class, a regulariser, or some other inductive bias, which sounds suspiciously like picking a language of projectible predicates. But maybe the analogy breaks down, because in ML you can hold out data or actually wait until after t and find out you overfit, whereas Goodman's grue-style rivals are built to be indistinguishable on any evidence before t. So do you think this is a deep structural parallel or just a loose analogy?
