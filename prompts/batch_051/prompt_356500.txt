I'm not a philosophy person, I'm a software engineer who mostly works on recommender systems, and I've been walking around with a definition of what it would mean for a model to actually produce something new, and I want someone to kick the tires on it. Here's the setup. Take a model trained on a corpus C, and an output x the model produced. Let K(x) be the length of the shortest program that prints x. Let K(x | C) be the length of the shortest program that prints x if you get C for free, like its a library that's already loaded into memory. My claim is this: if K(x | C) is way smaller than K(x), then C lets you compress x a lot, which means x was already sitting in the corpus in an information-theoretic sense, so the model just surfaced it, it didn't invent it. If K(x | C) is basically equal to K(x), then C doesn't help you describe x at all, and the model made a genuine leap beyond what it was trained on. So novelty is just the ratio K(x | C) / K(x), where near zero means rehashed and near one means new. I know Kolmogorov complexity is uncomputable, but I mean this as a criterion for what we'd count as novel, not something you'd literally build. I also know I'd need a value condition so random noise doesn't win, since a random string would score near one, but put that to the side for a second. This feels too obvious not to already be a thing under some other name, so tell me: is it? And more important, is it actually right? Give me the strongest objections and an honest verdict, not a menu of positions. No bullet points, no headings, no bold, just a long email back where you say what you actually think holds up and what doesn't.
