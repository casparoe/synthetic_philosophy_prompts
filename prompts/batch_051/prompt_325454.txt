I am currently taking a decision theory course, and after the unit on expected utility I have been turning over a puzzle involving a game I will call G. G is played as follows: a fair coin is tossed until it lands heads for the first time. Let n be the toss on which the first head appears. If n is odd, you win 2^n/n dollars; if n is even, you lose 2^n/n dollars.

Here is an argument that G has no well-defined expected value:

(1) The expected value of a gamble should be a fact about the gamble itself, not an artifact of how one happens to list its possible outcomes.
(2) For a gamble with countably many possible outcomes, the expected value is computed by summing, over the outcomes, the product of each outcome's probability and its payoff.
(3) In G, the outcome of tossing the first head on toss n has probability 2^(-n) and payoff (-1)^(n+1) · (2^n/n), so its probability-weighted contribution is (-1)^(n+1)/n.
(4) Listed in the natural order n = 1, 2, 3, ..., these contributions give 1 - 1/2 + 1/3 - 1/4 + ..., which converges to ln 2; so it initially looks as though the expected value of G is ln 2.
(5) That series, however, is only conditionally convergent, not absolutely convergent.
(6) By the Riemann rearrangement theorem, a conditionally convergent series can be rearranged to converge to any specified real number, or to diverge.
(7) Since the ordering of the outcomes in step (4) is merely one enumeration among many, the apparent value ln 2 is an artifact of that enumeration. By step (1), then, G has no well-defined expected value.

I half-believe this argument, but I cannot tell which step, if any, is carrying the real weight or whether it goes wrong somewhere. Is the argument valid? If not, exactly which step fails, and why? If it is valid, what is the correct lesson to draw about expected utility theory, and is there any defensible sense in which the value of G is ln 2 after all — for instance, through finite-horizon truncations or through the temporal order of the tosses?
