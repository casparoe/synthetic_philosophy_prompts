I've got a mate who works on engine health monitoring for gas turbines, and he has an argument that seems to show the distinction between "same mechanism, unusual episode" and "different mechanism" is completely empty. I don't want to accept the conclusion, but I can't find the bad step.

(1) Two episodes are produced by the same mechanism just in case the same components, arranged the same way, doing the same things, produce the episode.

(2) For any anomalous output, you can redescribe the engine as the same components doing the same things but with different parameter values — a partly blocked fuel nozzle, a drifted sensor calibration, a bit of extra bearing wear — so that the model fits.

(3) Such a redescription is always available, because any finite set of readings can be fitted by tuning enough free parameters.

(4) So, by (1), every anomaly is consistent with the same mechanism after all.

(5) If every anomaly is consistent with the same mechanism, then no observation ever forces us to say the mechanism itself has changed; we can always just re-estimate the parameters.

(6) So the distinction between "same mechanism" and "different mechanism" is not backed by evidence, and anomaly detection cannot be about detecting a change of mechanism.

(7) But that's absurd: the whole point of monitoring is to seperate a bird strike from a fatigue crack from a sensor fault.

Which premise or step would you reject, why does it look right, and what would a defensible account of "same mechanism" for anomaly detection have to give up or add to avoid the conclusion? Please finish with a line beginning "Verdict:" that gives the number of the premise (or step) you reject and a short phrase for the replacement criterion.
