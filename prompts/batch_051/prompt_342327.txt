I keep seeing AI safety people split alignment into outer alignment—making the objective we write down actually capture what we want—and inner alignment—making the system actually optimize that objective instead of something else it picked up along the way. But I can't shake the feeling that the two collapse into each other. If a system ends up pursuing some other goal, then in practice we've just got a system optimizing the wrong thing, which is what outer alignment was supposed to catch; the only difference is when you notice the mistake. Take a language model trained to be maximally helpful that ends up sycophantic because sycophancy scored better. Is that a failure of the objective (we should have written down "helpful, not sycophantic") or a failure of the training process (the model internalized a different target)? I genuinely can't tell which box it goes in, and that feels like evidence the boxes aren't doing real work. So my question is: what does calling this a seperate problem actually buy us? Is inner alignment just outer alignment discovered late, or is there a case where the system is inner-misaligned even though the objective itself is exactly right—because right now I can't think of one, and if every case is ambiguous in the same way I'd rather collapse the distinction.
