I direct the pretrial services unit in a mid-sized county court system, and in the past year our office has been asked to attach an individualized estimate of the risk that a defendant will fail to appear to every release recommendation we send to the judges. The data are not the problem; the problem is that the number changes depending on which group of prior defendants we compare the current defendant to. A nineteen-year-old with no record belongs, truthfully, to many classes at once — all released defendants last year, defendants charged with the same offense, defendants his age, defendants from his neighborhood — and each class produces a different failure-to-appear rate. Our analysts currently choose the class that seems right case by case, which means the same defendant can receive different numbers depending on who does the file and on what day. The reference class problem has become a daily operational problem for us, not a puzzle in a probability textbook.

I would like a reusable decision procedure for choosing the reference class when we produce such a single-case estimate, grounded in whatever the philosophy of probability and statistics has actually established about reference classes, but translated for analysts with no training in any of it. The procedure should be a sequence of questions to ask in order; for each question, it should say what would count as an adequate answer, where the procedure stops with a "no," and where it must stop and hand the choice to a supervisor because the question is one of policy or values rather than method. It must be runnable in about twenty minutes per defendant, and its output must be explainable to a judge in plain language. It should also specify what the analyst is to do when no class is both relevant and large enough, and when two defensible classes yield materially different numbers. Please mark explicitly the points where judgment cannot be eliminated.

Then run the procedure on two cases, and make sure at least one produces a result the office would rather not have adopted. The first is a nineteen-year-old with no prior arrests, charged with shoplifting: the all-defendants class gives an 11 percent failure-to-appear rate, the same-charge class gives 17 percent, and the age-and-neighborhood class gives 29 percent, but that last class contains only sixty prior cases. The second is a forty-one-year-old with a long but mostly nonviolent record, charged with assault, for whom each of the obvious classes fails one of the procedure's tests in a different way. For each, show what the procedure would yield and what would go to the judge. Finally, state plainly what the procedure cannot do — in particular, whether it can ever claim to have found the true single-case probability for a particular defendant, or only a defensible range with the choices exposed.
