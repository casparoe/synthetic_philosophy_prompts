For an advanced undergraduate unit on the sorites paradox, write a decision tree that assigns a student to a named position on vagueness from what they accept about borderline cases, not from which label they recognize. Build the tree from five diagnostic questions, in whatever order you judge best but all included: (1) Is every assertion employing a vague predicate such as heap either true or false, with no third status? (2) For those who answer yes: is the sharp boundary between positive and negative cases ever knowable, or is it in principle unknowable? (3) For those who answer no: is a borderline assertion neither true nor false, both true and false, or true to some degree between 0 and 1? (4) For those who say neither true nor false: is the sentence "Either this is a heap or it is not" nevertheless true of a borderline case? (5) Can one and the same object in one and the same condition correctly count as a heap in one conversational context and not in another, with no change in the facts? The leaves must include at least epistemicism, supervaluationism, a degree-theoretic view, contextualism, and a glut-theoretic or incoherence option; use an unnamed leaf for any answer combination no live position occupies. For each leaf give the position name, a one-sentence statement of the view, and its most awkward commitment. For each unoccupied combination, diagnose whether the position is incoherent, unattractive, or merely unexplored. Flag any pair of named positions these questions cannot separate, and state one further question that would split them.

Return a JSON object with this schema: "questions": an array of objects with fields "id", "text", and "allowed_answers"; "leaves": an array of objects with fields "name", "path" (an array of objects with "question_id" and "answer"), "statement", and "awkward_commitment"; "unoccupied_combinations": an array of objects with fields "path" (an array of objects with "question_id" and "answer") and "diagnosis"; "inseparable_pairs": an array of objects with fields "positions" (two names), "why_not_separable", and "further_question".
