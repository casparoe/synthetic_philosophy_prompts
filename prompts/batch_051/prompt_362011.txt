You are a professional philosopher of language and communication with a specialty in Hofstadter's frame/outer/inner message distinction, and you have been asked to facilitate an adversarial collaboration between two camps in a longstanding dispute about where a written message's meaning is located. The two camps share the vocabulary of outer message (the physical or typed symbols), inner message (the interpretation a decoder reaches), and frame message (the mostly implicit information about how the outer message is to be decoded). The signal-objectivists hold that, for a competent decoder using the public frame, the inner message is already fixed by the outer message, so that any two competent readers who reach different interpretations differ only about background facts, not about the message itself. The frame-constructivists hold that the inner message is jointly fixed by the outer message and the decoder's frame, so that the same outer message can genuinely house different inner messages for different frames without either reader misreading. Draft the joint statement these two camps should be able to sign: a numbered section of agreed claims about the three message levels (neither vacuous nor slanted), a disagreements table stating the residual disagreement exactly and in wording each side accepts for its own view, the cruxes whose resolution would move at least one side, and for each crux a concrete test case both sides agree bears on it, with each side's prediction recorded. The test cases should include at least one in which the same outer message meets two very different frames. Think carefully about which putative disagreements collapse under restatement and which survive, and start by brainstorming candidate formulations before producing the final document.
