In my philosophy of logic course we did the Liar for a week, and then the professor wrote on the board an argument that he said proves the Eiffel Tower is on Mars without ever using negation. I copied it down, went home, and now I think I've reproduced it correctly, but the conclustion is so obviously false that something has to be wrong. The trouble is each line looks like a move I'd want to make when I'm just thinking about what "true" means.

Let P be any sentence you like, for example that the Eiffel Tower is on Mars. Let C be the sentence: "If C is true, then P." Write T(C) for the sentence "C is true."

(1) By the naive T-schema: T(C) if and only if C.
(2) By what C explicitly says: C if and only if (T(C) → P).
(3) Putting (1) and (2) together: T(C) if and only if (T(C) → P).
(4) Left to right, (3) gives: T(C) → (T(C) → P).
(5) By contraction, since using T(C) twice is no different from using it once: T(C) → P.
(6) Right to left, (3) gives: (T(C) → P) → T(C).
(7) From (5) and (6) by modus ponens: T(C).
(8) From (5) and (7) by modus ponens: P.

P was completely arbitrary, so the argument seems to prove anything at all. So: where does this go wrong? I'm not asking for the name of the paradox. I want the exact step or principle that has to be rejected, an explanation of why it looked so innocent, and what a theory of truth has to give up once it rejects it. I'm least eager to lose modus ponens, and I'd rather not deny that English contains sentences like C, but I'm open otherwise. Does ordinary talk about truth survive the fix, or do we have to quietly give up the idea that "true" applies coherently to our own sentences?
