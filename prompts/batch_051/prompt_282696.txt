I keep noticing the following pattern in language-model outputs, and I have not found a label that captures it precisely. You can check an output sentence by sentence, and every sentence corresponds to something in the source material, yet the output as a whole leaves a reader with a badly distorted impression. A model asked to summarise a report that on balance supports a proposal produces a summary made entirely of the report's caveats, each accurately rendered, so the proposal appears to have been rejected. A model asked whether a treatment improves outcomes lists only the trials with positive findings and omits the larger set of negative trials it can also access. A customer-service assistant asked whether a subscription renews automatically describes the free-trial terms in detail and stops just before the renewal clause. A sentence-level fact-checker would pass all three outputs, and yet a competent user would come away with the wrong belief. I know the ordinary distinction between lying and misleading, but these examples are not cases of asserting something false, and plain 'misleading' feels too broad to pick out this exact gap between the truth of each sentence and the impression created by the whole. Is there an established concept for this gap, particularly in work on how to define honesty and deception for AI systems? If the nearest concepts only partly fit, I would like to know which comes closest, where its boundaries are, and, if nothing established fits, how one should define and name the phenomenon so it does not collapse into ordinary incompleteness, bias, or generic deception.
