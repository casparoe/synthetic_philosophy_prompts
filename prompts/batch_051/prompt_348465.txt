For a seminar mixing molecular-biology graduate students with philosophers of science, write a nine-question sorting quiz — "Which view of the genetic code do you actually hold?" — together with a scoring key. Each question should present a concrete case: a point mutation, a synonymous substitution with no phenotypic effect, a codon reassigned in mitochondria, an in vitro transcription system, a computer simulation of transcription, a prion propagating structure without nucleic acid. Give each case two or three answer options that a respondent can choose without knowing any named positions, and avoid questions that simply ask whether DNA is literally a code. The scoring key should sort respondents into five views, each phrased in ordinary language: the code is literal but exists only relative to a cell's reading-and-interpreting machinery; the mapping is a formal Shannon-style relation with no sender or semantic content required; genes carry semantic information about phenotypes in something like a word-meaning sense; genes derive their semantic content from a history of natural selection for phenotypic effects; and "code" is a vivid metaphor that misleads and should be exchanged for causal and structural description. Build the questions from the diagnostic contrasts among these views — arbitrariness of the codon table, whether a point mutation is an error in a message or simply a new message, whether information about a phenotype exists before any cell reads it, whether a receiver is required, whether the mapping alone does the coding — never from the views' names. Then flag any answer combinations that no listed view occupies, and say whether each looks incoherent, merely unattractive, or unexplored.
