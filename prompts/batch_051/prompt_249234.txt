I'm taking a course on formal epistemology, and we've been working through the standard argument that Solomonoff induction gives Occam's razor a principled, non-pragmatic justification. As I understand it, the argument runs as follows. Consider the space of all computable hypotheses that could generate an observed sequence. Assign each hypothesis a prior probability proportional to 2 raised to the negative Kolmogorov complexity of the shortest program that produces it, so that simpler hypotheses receive exponentially more prior mass. Then condition on the data. In the limit, the posterior is said to concentrate on the true computable hypothesis whatever it happens to be, and the simplicity bias in the prior is supposed to be what drives that convergence. The conclusion usually drawn is that preferring simpler hypotheses is not merely a heuristic but a feature of ideal Bayesian induction.

But I have encountered a development that seems to threaten the finite-sample version of this argument. Kolmogorov complexity is invariant only up to an additive constant that depends on the choice of universal reference machine, and that constant is arbitrary: choosing a different reference machine is like rewriting every hypothesis in a different programming language. Moreover, for any particular hypothesis, there appears to be a reference machine on which that hypothesis has complexity near zero while the complexities of rival hypotheses stay bounded around their old values. If that is right, then for any two hypotheses and any finite body of data, there is a choice of reference machine that reverses which of them counts as the simpler one by a margin larger than the data can offset. The asymptotic theorems remain untouched, since additive constants wash out in the limit, but any real inference is finite.

Does the Solomonoff argument for Occam's razor survive this development? If it does, which premise is really doing the work once finite-sample simplicity rankings turn out to be machine-relative? If it does not survive, what is the strongest claim that can be salvaged — for example, a version relativized to a chosen reference machine, or a reinterpretation of Occam's razor as a structural bias of a particular learner rather than an absolute constraint on rational belief?
