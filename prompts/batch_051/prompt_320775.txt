I am a software engineer with no formal philosophy background, and I would like help deciding whether a parallel I have been turning over is deep or superficial.

The parallel is this: the move from the Cartesian theater to the multiple drafts model of consciousness looks to me structurally identical to the move from a single-threaded, monolithic program with one authoritative in-memory state to a distributed, event-driven, eventually consistent system.

Let me state both sides in my own terms, since I may be mangling the philosophy. As I understand it, the Cartesian theater says that experience comes together at one place in the brain, a stage or screen, where a unified stream of consciousness is presented to some inner observer. On that view there is a definite fact about which content is conscious now, and in what order, before anyone is asked. The multiple drafts model that Dennett puts in its place denies the central stage. The brain runs many parallel, ongoing processes of interpretation, each producing partial drafts of content; there is no final draft with special authority; and what a person reports as experience is not the playback of a canonical recording but whichever draft wins out when the system is probed.

In distributed systems we made what sounds like the same transition. Instead of one process with one authoritative state and a single event loop serializing every update, you have many nodes handling events concurrently, each with its own local view. State is materialized by folding an event log into a projection at query time. Different projections can disagree, and there is no current state of the system except relative to a query.

So my proposed mapping is this: the central stage corresponds to the single authoritative state and the single event loop; the parallel drafts correspond to the concurrent local views on different nodes; the probe in Dennett corresponds to the query that materializes a projection; and the winning draft corresponds to whichever projection gets returned as the answer.

I cannot tell whether this is a real structural identity, a loose analogy, or mere pattern-matching by someone whose native habit is to see everything as a distributed system. If it is deep, I want to know what actually transfers. For example, would the ideas we use to reason about such systems — eventual consistency, read-your-writes consistency, the CAP theorem — have any real application to consciousness, or is that exactly where the analogy breaks? If it is only superficial, I want to know what is missing on each side. In either case, please point out at least one place where the parallel makes a prediction that turns out false on the consciousness side, and correct anything in my characterization of the philosophy that a beginner is likely to have wrong.
