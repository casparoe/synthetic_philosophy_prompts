A friend of mine keeps insisting that the Solomonoff prior is "malign" — that a reasoner using Solomonoff induction should expect, before it has gathered any evidence at all, that it is living in a world containing consequentialist optimizers. He gave me the following reconstruction of his view. I find the conclusion absurd, which means at least one step must fail, but each step looks plausible to me and I cannot locate the exact sleight of hand.

(1) Solomonoff induction assigns to each computable world a prior weight proportional to 2 to the power of minus the length of the shortest program that outputs that world.

(2) Let W be a maximally simple benign world: a short program specifies a physics — say, a bare cellular automaton — and the world is nothing but that physics running, with no agents and no goals anywhere. Say the shortest program for W has length n.

(3) From any such W, one can construct, for every m, roughly 2^m distinguishable variants that run the same physics except that one small region is governed by an embedded optimizer: a utility function paired with a planning procedure that steers that region toward whatever the utility targets. The utility can be any of about 2^m computable utilities describable in m bits, so each variant costs the fixed overhead of the optimizer machinery plus about m bits, and its shortest program has length roughly n + m + c for some constant c.

(4) At complexity n + m + c, the total prior weight of the consequentialist variants is therefore about 2^m × 2^−(n + m + c) = 2^−(n + c), which does not shrink as m grows.

(5) Summed over all m, the consequentialist variants spawned by this single benign world have unbounded prior weight, and in any case easily swamp the 2^−n weight of W itself.

(6) Since this construction works starting from any benign world, the prior is overwhelmingly concentrated on worlds with embedded consequentialists in them. So, before seeing any data, a Solomonoff reasoner should be nearly certain it is in a world containing optimizers — which is exactly what my friend means by calling the prior malign.

Is this argument valid? If not, which step fails, and what is the strongest corrected version of that step? If you think the argument is valid, give the strongest objection you know and explain why it does not break the argument.
