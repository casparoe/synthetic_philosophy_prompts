In our metaphysics of time course we have been working through the Rietdijk–Putnam argument, and I have reconstructed it as follows. I keep suspecting that it is too quick, but I cannot identify the exact step at which it goes wrong.

(1) According to special relativity, simultaneity is frame-relative: for any two spacelike separated events, there is an inertial frame in which they are simultaneous, and other frames in which either one occurs before the other.
(2) If two events are simultaneous in a given inertial frame, then in that frame they belong to the same present moment, the same three-dimensional now.
(3) Reality is not frame-relative: an event cannot be real relative to one frame but unreal relative to another. Consequently, if an event is real and a second event is simultaneous with it in some inertial frame, the second event must be real as well.
(4) The event of my writing this question now, call it N, is real.
(5) Any event in spacetime can be connected to N by a chain of events in which each consecutive pair is spacelike separated; where an event is timelike separated from N, an intermediate event sufficiently far away in space bridges the gap.
(6) Applying (3) stepwise along such a chain, every event in spacetime is therefore real, including what we ordinarily call future events. Past, present, and future are all equally real, the universe is a block, and temporal passage is not fundamentally real.

Is this argument valid? If it is valid, exactly which premise should a presentist deny, and can it be restated so as to preserve presentism without rejecting special relativity? If it is not valid, identify the precise step that fails and explain what the corrected version of the argument would have to assume. Please answer in British English.
