I’ve been messing with the GPL’s own definition of a modified work, and I’ve talked myself into the conclusion that nearly all proprietary software is actually GPL. I’m pretty sure that’s absurd, but I can’t locate the bad step.

The Free Software Foundation’s GNU General Public License, version 3, section 0, says:

“To “modify” a work means to copy from or adapt all or part of the work in a fashion requiring copyright permission, other than the making of an exact copy. The resulting work is called a “modified version” of the earlier work or a work “based on” the earlier work.”

Now the argument:

(1) If B copies or adapts any part of A in a way that would require copyright permission, then B is a “modified version” of, or work “based on,” A, under the GPL.
(2) Small, original fragments of code—like a distinctive ten-line helper function or a non-obvious sequence of API declarations—can require copyright permission to reproduce.
(3) Almost any nontrivial program contains at least a few lines that are substantially identical to some original lines in some GPL-licensed program, even when written independently, because the space of useful short code patterns in a given language is too constrained to avoid all overlap.
(4) So almost any nontrivial program copies or adapts part of a GPL program in a way requiring copyright permission.
(5) So almost any nontrivial program is a work “based on” a GPL program.
(6) The GPL requires that works “based on” a GPL-licensed program be licensed under the GPL.
(7) So almost all nontrivial software is required to be GPL-licensed.

I’d like to keep (2) and (6) if I can, but I don’t know what that forces me to give up. Tell me which step or steps to reject, why that step looked right, and what the corrected argument says about where one program really ends and another begins.
