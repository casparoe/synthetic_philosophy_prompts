I have been trying to sort out which uses of AI I regard as benign conveniences and which I regard as quietly corrosive, because my gut keeps drawing lines I cannot yet explain. Using a calculator to check a tax form: fine, and I would not say I have lost any understanding worth having. Using my phone's map for every trip across a city I have lived in for years: it works, but something about it feels like a loss even though I cannot name the capacity being lost. Using machine translation to read a restaurant menu abroad: fine. Using the same translation software to conduct, on my behalf, a negotiation in a language I do not speak, where I merely approve the final text: not fine, though the tool is identical and only the stakes differ. Using an LLM to explain a step in a proof I am studying, as a tutor would: fine. Using an LLM to run a statistical analysis whose assumptions and output I could not reproduce or explain, and then reporting the result in a paper I sign: not fine. Using predictive text for casual messages: fine. Letting a drafting assistant compose legal disclosures for clients in my name, which I skim only for tone: not fine. Using an AI system that monitors patients' vitals and flags deterioration, while a nurse still examines the flagged patients: fine. Using an AI that writes chart notes the clinician signs without reading: not fine.

My tentative principle has been roughly this: offloading is acceptable when the tool is transparent enough that I could, given enough time, redo the operation myself, and when I remain the one who vouches for the output rather than the tool. But the map case troubles me, because a map is about as transparent as a tool gets, and yet I still feel that depending on it has eroded something. And I cannot tell whether the translation pair and the medical pair point at the same underlying line—stakes, checkability, the competence my role asserts, the depth of the offloaded skill—or at different lines that only look alike. Is there one principle that preserves most of these verdicts, or do some have to go? If some go, which ones, and what does the best available principle commit me to about cases I have been avoiding, such as using an AI to summarize a loved one's medical results, or using an AI tutor for a child's entire early reading instruction? State the principle as precisely as you can, show how it handles the easy cases, and say plainly which of my verdicts it cannot accommodate.
