Many stand-up venues, comedy publications, and online comedy communities treat a joke that targets a powerful politician as acceptable, even when the joke is cruel about the politician’s body or family, while treating a joke that targets an unemployed single mother’s weight or a disabled person’s speech as worse than merely unfunny: a mark against the comic’s character. The same venues regularly praise self-deprecating routines in which a comedian ridicules her own body, poverty, or romantic failures. And at televised celebrity roasts, participants trade brutal insults about one another’s faces and careers in front of a laughing audience, with the target’s prior consent; footage of the same jokes told about a randomly selected audience member would likely be edited out or condemned by the same people.

I want to know what a coherent account of humour would have to be true for this pattern of approvals and condemnations to make sense. Do these practices presuppose any particular theory of humour among the standard four—superiority, incongruity, relief, and benign violation? Or do they only fit one theory without requiring it? Which rival theories does the practice quietly rule out, and which parts of the practice are philosophically underdetermined, so that several theories would license them? Finally, is there an unresolved tension between the roast, where consented-to cruelty is celebrated, and the prohibition on punching down, where cruelty to the vulnerable is treated as a moral failing rather than a mere failure of wit?

Please give a prose analysis first. Then append a JSON object, with no markdown code fences, using exactly these fields:

- `presupposed_theories`: an array of strings; each string names a theory of humour and gives a one-sentence explanation of what in the practice requires or fits that theory.
- `strict_presuppositions`: an array of strings; each string states a claim the practice cannot operate without, independently of which particular theory is preferred.
- `mere_fits`: an array of strings; each string names a theory that is compatible with the practice but not strictly presupposed by it, with a one-sentence explanation.
- `tension_points`: an array of strings; each string describes a place where two parts of the practice appear to presuppose inconsistent things.
- `revisions_under_alternative_theory`: an object whose keys are `superiority`, `incongruity`, `relief`, and `benign_violation`; each value is a string explaining what would have to change in the practice if that theory alone were accepted as the correct account of humour.
