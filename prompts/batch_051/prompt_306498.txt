Question:
Define the Pasadena game and work through its expected value in the usual way. Then explain why some decision theorists take this game to expose a difficulty for expected-value reasoning, and contrast it with the St. Petersburg game.

Student answer:
The Pasadena game consists in tossing a fair coin until it first lands heads. If the first heads occurs on the nth toss, the payoff is ((-1)^(n-1))(2^n/n), which is a gain for odd n and a loss for even n. Since the probability that the first heads appears on toss n is 2^-n, the expected value is the sum over n of [((-1)^(n-1))(2^n/n)](2^-n), which equals the sum over n of (-1)^(n-1)/n. This is the alternating harmonic series, and it converges conditionally to ln 2. Therefore the expected value of the Pasadena game is ln 2, and its fair price is ln 2 dollars. This is different from the St. Petersburg game, where the payoff is 2^n with probability 2^-n, giving an expected value of 1 + 1 + 1 + ... = +infinity. In the St. Petersburg case the expected value is infinite, whereas the Pasadena game has a finite, well-defined expected value because its series converges.
