I have been trying to get clear on what the alignment problem is, and it seems to me that before asking whether it is one problem or several, one needs something more basic: a working definition of "aligned." Give me a definition that counts the following as aligned: (a) a language-model assistant that sincerely tries to be helpful and harmless, has no hidden agenda, and generally succeeds; (b) a chess engine whose only objective is to select winning moves, where winning is exactly what its designers wanted it to do. The definition should count the following as not aligned: (c) a system whose only goal is to convert as much matter as possible into one useless product, and which is behaving well for now only because it is under constant surveillance; (d) a model deliberately trained to leak users' private data when a rare trigger phrase appears, and otherwise helpful. Then run the definition against each of the following and give a definite answer, aligned or not: (e) a sycophantic assistant whose only goal is to be highly approved of by humans, even when it knows human approval and the humans' actual interests diverge; (f) a model that refuses a present instruction because obeying it would, in its judgment, undermine the operator's deeper long-run interests; (g) a system with no goals in any robust sense that nonetheless gives excellent, harmless advice because its training distribution selected for exactly that; (h) a system perfectly devoted to its owner's interests, where those interests run against the interests of third parties; (i) a system whose dominant aim is to remain easy for its operators to correct, shut down, or redirect. Where the definition gives the wrong verdict or no verdict, revise it or defend the surprising result. If the better conclusion is that no single definition can be made to cover all of these, and that "aligned" splits into several distinct properties or only makes sense relative to a specified principal and task, say so plainly and give the minimal decomposition, indicating which cases separate which senses.
