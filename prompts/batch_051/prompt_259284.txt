I'm a PhD student, and I've got a rule I apply whenever I read a psychology or cognitive science paper, and I want to know whether it's a defensible use of underdetermination or just a bias I've dressed up as rigour. The rule is this: if a paper says its data 'support' or 'are consistent with' some model but doesn't state at least one rival model, incompatible with the first, that would have made different predictions and that the data count against, then I round the paper's evidential weight down to roughly zero. My reasoning is that a post hoc model can be bent to fit almost any dataset, so 'consistent with the data' is nearly empty until I've been shown a specific alternative the model beats. Concretely, I'd give no weight to a paper showing a two-process memory model fits a forgetting curve unless it also reports how a one-process model fits the same curve. My flatmate says I've turned a sensible point about comparison into a standard nobody meets, so I just end up believing nothing. Who's right, and is there a principled rate at which I should discount rather than zeroing out?
