I'm a software engineer with no formal background in philosophy. In my work I rely constantly on identity: instance IDs, database primary keys, handles, and cumulative logs tell me whether the object I'm looking at now is "the same" as the one I inspected an hour ago. But I've realized I have no general criterion for when the thing itself really persists through change, as opposed to being replaced while its identifier stays attached. I'd like a working definition of what it is for a single object to persist over time, one that applies to ordinary physical objects, organisms, and institutions as well as software.

I have also picked up, without fully understanding them, a dispute between two pictures of persistence: one holds that a persisting thing is wholly present at each moment, the way a point moves along a line; the other holds that a persisting thing is spread through time rather as a road is spread through space. If this dispute matters for the definition, I want to know how; if it can be bypassed, I want to know that too.

Here are the cases I'd like the definition to handle:

1. A long-running server whose memory, disk, and network interface are gradually replaced over years, while it keeps the same instance ID and keeps serving the same API without interruption. (My instinct: same object.)
2. A second server that is stopped, imaged, destroyed, and relaunched later from the image with the same instance ID. (My instinct: not the same object, or at least a less demanding sense of "same.")
3. The ship of Theseus, with each plank replaced one at a time until no original part remains. (My instinct: still the same ship.)
4. A twist on the previous case: the replaced planks are saved and later reassembled into a second ship. We now have two candidates for the original. (I genuinely don't know.)
5. An amoeba that divides into two daughter cells. (No idea whether the amoeba survives, and in which daughter.)
6. A person across a lifetime, through near-total cell turnover and large changes in memory and personality. (My instinct: same person.)
7. A cloud that thins out, vanishes, and is followed an hour later by a similar cloud in the same place. (Unclear to me whether "same cloud" even has a truth value.)
8. A company that has replaced every employee, product, and office, while retaining the same legal registration and name. (Legal answer: same. I'm less sure that's the whole answer.)

Please propose the definition, run it through all eight cases, and mark where it delivers a verdict, where it returns no verdict, and where the verdict conflicts with my instincts. If the first definition breaks, revise it rather than discarding it, or defend the surprising verdict. I'm especially interested in whether "same" in "same object" means one thing in some of these cases and a different thing in others, and whether some of my cases are better treated as ill-posed questions than as failed tests.
