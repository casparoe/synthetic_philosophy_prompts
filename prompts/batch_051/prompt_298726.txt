A friend showed me a tightened-up version of the old every-truth-is-knowable paradox, and it's been bugging me for a week because I can't find the trick. The argument runs like this. (1) Assume, for reductio, that there is at least one truth q that nobody ever knows. (2) The anti-realist principle says every truth is knowable: for any true proposition, it's possible that someone knows it. (3) So if q is true and nobody knows q, then the conjunctive proposition q-and-nobody-knows-q is also true, and by the principle it's knowable: it's possible that someone knows that conjunction. (4) Knowing a conjunction means knowing each conjunct, so in that possible situation someone knows q and also knows that nobody knows q. (5) Knowledge is factive, so if someone knows that nobody knows q, then nobody knows q; but by the first conjunct somebody knows q. Contradiction. (6) So the possible situation in (3) is impossible, which means the conjunction is actually unknowable. (7) But that conjunction was true, so there is a true proposition that isn't knowable, contradicting the principle. So the assumption in (1) must be false: every truth is known. That conclusion seems insane, but the only wiggle I see is step (4) or step (5), and both look obvious. Is the argument valid? If not, say exactly wich step fails and on what reading. If it is valid, tell me which premise a verificationist should give up, and whether restricting the principle to worldly truths, ones not about what anyone knows, fixes things or whether the argument sneaks back in through some other route.
