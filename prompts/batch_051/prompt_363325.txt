Consider the familiar puzzle about empty names and truth in fiction. Since there is no Sherlock Holmes, the claim that Holmes lived on Baker Street is not true of the actual world, yet it seems true in the stories. The standard response is to relativize truth to a fiction: a sentence is true in the fiction, roughly, when it holds in the worlds in which the fiction is told as known fact, with the story's explicit statements contributing their ordinary content. On this view, the fact that a story uses a name in straightforward narrative sentences normally makes it true in the fiction that the bearer of the name exists, even if the story never says so explicitly.

Now vary the case. Suppose a novel has two parts. The first part is a preface written by a narrator who speaks as an in-fiction historian, and it states plainly that the detective Arlo Crane never existed. The second part is an ordinary third-person detective narrative, presented as part of the same novel, in which Crane is named throughout and described as noticing clues, interviewing witnesses, and solving cases; nothing in this part calls itself a legend or a fiction within the fiction. The question is what the standard story-operator analysis should say about this work. Is it true in the fiction that Crane exists? Is it true in the fiction that Crane solved the case? Does the analysis now saddle the fiction with an inconsistency that it would not find in the ordinary Holmes stories — and if so, is that inconsistency a correct description of the work or an artifact of treating the existential commitment of name use as part of the story's content? If you think the latter, specify the smallest change to the standard analysis that handles the case, check that it still yields the ordinary verdict for the Holmes stories, and explain what the variant reveals about whether existence-in-fiction should be treated as a presupposition of narrative name use rather than as part of the story's content.
