I cover AI and the weirder end of decision theory for a magazine, and someone at a workshop showed me an argument I can't stop thinking about. It seems to prove that an agent embedded in its environment can't really have a utility function at all. Since I'm fairly sure I'm embedded in the world and still manage to prefer coffee to tea, this feels like too much. Here's my reconstruction:

(1) An agent maximising expected utility chooses acts by ranking possible states of the world with a real-valued utility function.
(2) An embedded agent is made of the same world it acts on: its body, its memory and its utility function are physical parts of that world.
(3) So any complete state of the world after the agent acts includes the agent's own utility function as one of its parts.
(4) Therefore the utility of a state depends partly on what utility function the agent ends up with in that state.
(5) But then the agent has to be able to rank states where it has different utility functions: a state where it keeps its current finicky values while the world is mediocre, versus a state where its utility function is overwritten to value something easily satisfied (pebbles, say) and the world is stuffed with pebbles.
(6) By its current values, the first state is better. By the values it would have in the second state, the second is better. Utility theory gives no rule for which standpoint is authoritative, because the utility function is itself one of the contested parts of the state.
(7) So either there is a God's-eye utility function sitting outside the world and never getting overwritten (impossible for an embedded agent), or utility theory only works by pretending the agent is not really part of the world.
(8) Since both options are out, expected utility theory can't apply to any real embedded agent -- including us.

I'd be happy if the answer turned out to be a subtle equivocation in one of the middle steps, but I'd like to know which premise to give up and what it costs. And please write the answer in British English -- I'm filing for a UK edition.
