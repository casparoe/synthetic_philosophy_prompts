I'm a software engineer with no formal background in philosophy, so I'll approach this through the kind of system I actually build. The old puzzle of Buridan's ass concerns a hungry donkey placed exactly midway between two identical bales of hay; since it has no grounds for selecting one over the other, the story says, it fails to choose and starves. I want to inspect a variant in which the ass is a deterministic control program.

Suppose the program assigns a scalar utility to each available option. It first computes the set of options that maximize that utility. If the set has exactly one member, it acts on it. If the set has multiple tied members, it runs a tie-breaker: the program consults a fixed total order over locations, an array indexed by position and written into the code before the bales were placed, and selects whichever tied option appears first. I can hard-code it as leftmost. The tie-breaker is insensitive to every property of the bales except their position in this arbitrary ordering; it would do exactly the same work if the two objects were a bale and a pail of water, or if the locations were swapped.

Now contrast three versions. (a) The tie-breaker is that fixed arbitrary ordering. (b) The tie-breaker is a random bit sampled at decision time from hardware noise. (c) There is no tie-breaker: on detecting a tie the program logs no unique optimum and terminates without acting, leaving the donkey, in simulation, to starve.

I want to know how the standard philosophical analysis of Buridan's ass changes, if at all, under this variation. In version (a), has the donkey acquired a preference, or merely a deterministic mechanism that masks the original lack of one? Is there a real difference between (a) and (b) for the purpose the puzzle is usually taken to serve, and does that depend on whether the puzzle is ultimately about the ability to act without a deciding reason or about there being no unique rational action in the first place? Does the program in (a) count as a counterexample to, or as a repair of, whatever principle the puzzle is supposed to illustrate? I am looking for the argument, not just a name for the phenomenon.
