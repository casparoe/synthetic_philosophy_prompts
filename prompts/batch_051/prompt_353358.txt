I am a second-year undergraduate on a module called Bargaining and Social Choice, and I have been asked to run a ninety-minute revision session for a tutorial group of fourteen students. The group has already met the Nash bargaining solution and its axioms; the Kalai–Smorodinsky solution has only just been introduced, and most of us still think of it as a calculation to be reproduced on a problem set rather than as an idea with any independent pull. I would like you to design a classroom activity, a genuine negotiation game with rules, roles, and payoffs followed by a debrief, that makes the group feel the force of the Kalai–Smorodinsky solution before the solution concept is named again.

The setting is as follows. Fourteen second-year students, ninety minutes, a room with tables so that students can work in pairs. They have already seen the feasible set of a bargaining problem, the disagreement point, Pareto optimality, symmetry, affine invariance, and the Nash solution with its independence of irrelevant alternatives axiom. What the activity should make them see is that the disagreement point and the utopia point are doing real work in a bargain, and that independence of irrelevant alternatives is not obviously the right axiom: a newly feasible option that raises one player's best possible payoff is not irrelevant, because it changes what that player can legitimately expect.

For clarity about the target idea: the Nash solution selects the feasible agreement that maximises the product of the two players' gains over the disagreement point. The Kalai–Smorodinsky solution selects the Pareto-efficient agreement at which each player closes the same fraction of the gap between the disagreement point and that player's own best feasible payoff; geometrically, it is the point where the line from the disagreement point to the utopia point of best feasible payoffs meets the Pareto frontier.

I would like the game to be built around the following standard worked example. Two players, Alice and George, must agree on a mix of three projects. Project a pays Alice 60 and George 80, project b pays Alice 50 and George 110, and project c pays Alice 30 and George 150. Utilities are linear in these amounts, there are no side payments, and randomisation over the projects is allowed, so the feasible set is the convex hull of the three payoff points. The disagreement point is the pair of minimal utilities, (30, 80), the payoff each receives if no agreement is reached. Please arrange the game in two rounds. In the first round the payoffs are exactly as above. In the second round, project c is improved for George to pay (30, 190), while Alice's best option and the disagreement point stay fixed, and the pairs renegotiate from scratch. A short optional third round in which the options are held fixed but the disagreement point changes is worth considering because it isolates the other moving part, but it is not required.

Please produce a runnable ninety-minute plan with exact timings, materials that can be printed from the plan, a facilitator script or bulleted instructions sufficient to run the session without improvisation, and a debrief. In the main game, participants should negotiate and record their agreements without hearing the names Nash or Kalai–Smorodinsky; both names should be withheld until the debrief. The debrief should compute, for each round, the Nash and the Kalai–Smorodinsky solutions in normalised gains, display the pairs' actual agreements against those two points, and map particular moments of the game onto the conceptual components: the disagreement point as the genuine zero of the gains, the utopia point as what sets the scale of each player's concession, equal proportional concessions versus maximised product, and monotonicity versus independence of irrelevant alternatives. The debrief should also say what will predictably go wrong when the session is run (for example, pairs splitting the difference, ignoring randomisation, or treating round two as a re-run of round one), and how the facilitator should handle each failure. Be explicit about which features of the idea the game cannot reproduce and which the facilitator must supply afterwards; the axiomatic characterisation of the Kalai–Smorodinsky solution is one obvious candidate, but say whether there are others.
