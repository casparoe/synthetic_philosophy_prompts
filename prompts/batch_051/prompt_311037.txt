I encountered the following argument in a study group and cannot locate the mistake, though the conclusion cannot be accepted: if this argument were sound, it would prove the continuum hypothesis from ordinary facts about sets of reals, when the continuum hypothesis is independent of the standard axioms.

(1) Every uncountable closed set of reals contains a perfect subset, and every perfect subset of the reals has the cardinality of the continuum.
(2) Let S be an arbitrary uncountable set of reals. Its closure is closed and contains S, so its closure is uncountable.
(3) By (1), the closure of S contains a perfect subset.
(4) Since a closure differs from the original set only by limit points—and a limit point of S can be approximated arbitrarily well by points of S—if a set's closure contains a perfect subset, then the set itself contains a perfect subset.
(5) Therefore every uncountable set of reals contains a perfect subset, and hence has the cardinality of the continuum.
(6) So there is no set of reals whose cardinality lies strictly between countable and continuum: the continuum hypothesis is true.

But the continuum hypothesis is independent of ZFC, so the argument must fail somewhere. I am most reluctant to give up (4), since it seems to do no more than unpack what a closure is. Which step should be rejected, why did it look so innocent, and what does rejecting it commit one to?
