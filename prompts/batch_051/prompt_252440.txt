The DNA–Gödel Isomorphism, or Why Life Is a Theorem That Copies Itself

In Gödel's proof, numbers can talk about other numbers, and with enough coding you can make a statement talk about itself. The key move is substitution: you build a formula that says, roughly, the result of substituting this number into the formula whose Gödel number it is, and so on, and then you substitute the formula's own number into itself. What you get is a sentence that refers to its own construction.

Typogenetics has the same shape but in a different material. A strand of DNA letters codes for enzymes that operate on strands. An enzyme knows how to cut, paste, copy, and search for short patterns in a strand. Because the strand both carries the code for the enzymes and is itself the thing those enzymes chew on, the system can fold back on itself: a strand can code for an enzyme that acts on the very strand that coded for it. With the right coding, a strand becomes a description of a machine that can construct that same strand from raw letters — a blueprint for its own copying. Self-replication, then, is just self-reference made physical: a string that says copy me.

The isomorphism, if it is one, is that in both cases self-reference shows up only when a system has two things: a code rich enough to encode operations, and a way for the system's objects to act on objects of the same kind. Gödel's numbers encode proof operations; Typogenetics strings encode copying operations. In both, the trick is to get the object to mention and then manipulate its own code. The difference is that in mathematics self-reference gives you a statement that says I am unprovable — a limit — while in Typogenetics self-reference gives you a thing that says I have been copied — a beginning. So maybe the deep lesson of Gödel isn't that formal systems are doomed to incompleteness, but that any system rich enough to describe itself is also rich enough to reproduce itself. Life is what self-reference looks like when it stops refuting and starts replicating.
