Here is a standard argument from the theory of program equilibrium. In a one-shot prisoner's dilemma, suppose each player must submit a program to play on their behalf, and each program can read the other program's source code before choosing its action. Then mutual cooperation can be an equilibrium even among purely self-interested agents: each player submits a program that, upon reading the other program's code, cooperates if and only if it determines that the other program would cooperate against it, and defects otherwise. A would-be defector cannot profit, because its defecting code would be detected and answered with defection, leaving both players with the mutual-defection payoff, while mutual cooperation gives each a higher payoff. Transparent, mutually readable code thus seems to supply the assurance that ordinary one-shot play lacks.

Now suppose the submitted programs are black-box learned systems rather than inspectable source code: for example, LLM-based agents or deep reinforcement-learning policies whose behavior is determined by opaque weights, stochastic sampling, and prompt or interaction history. Their source code does not reveal a policy of the form cooperate if and only if the other cooperates; the same code can act differently across runs and contexts; and nothing in the code lets one program verify in advance what the other would do.
