Two cases have to be in the list, because they're the ones that make me distrust otherwise tidy solutions.

First, Curry's paradox. The sentence says, roughly, "if this very sentence is true then Q," where Q is some completely arbitrary claim. With an unrestricted T-schema and ordinary rules for the conditional, out pops Q, and it doesn't matter that the paradox never touches negation. So a solution that only messes with negation, bivalence, or excluded middle looks like it's fixing the wrong thing. I want a requirement that says an adequate theory has to deal with Curry head-on, and the list should make clear what options that leaves on the table: restrict the T-schema, reject contraction or a related structural rule, mess with the conditional, or find some other way out, but you can't just ignore it because the liar is already handled.

Second, Yablo's paradox. Take an infinite list of sentences S1, S2, S3, and so on, where each Sn says "all the later sentences are false." Suppose some Sn is true. Then every later sentence is false. But then Sn+1 is false, which means not all later sentences are false after all—contradiction. So no sentence on the list is true, which is to say each one's claim about the later sentences is correct, so each one is true after all. Contradiction again, supposedly without any sentence referring to itself. So any theory whose main move is "paradoxes come from self-reference" owes us a story here: either locate some hidden self-reference or circularity, or give up one of the other ingredients and say why. I want that written into the desiderata directly, not tacked on as a footnote.

Keep the weight on the requirements themselves and the cases that motivate them, not on scoring existing views—I'll do that part myself. But it would help if you said which single requirement would eliminate the most popular candidate solutions, and why. A table for the requirements is fine if it helps.
