Here are my working criteria for whether something is a genuine final-cause explanation in the Aristotelian sense, not just an as-if or teleonomic story. (1) The end has to be describable independently of the process — if the only description is "whatever this process happens to produce," its not a final cause. (2) The end has to explain the shape of the process: why these steps rather than others. (3) The process has to be counterfactually sensitive to the end — change the end, and the process should change correspondingly. (4) The goodness or fittingness of the end has to do some explanatory work, not merely the fact that the end occurs later in time.

Now take a language model trained with reinforcement learning from human feedback. The developers have a target T — roughly, helpful and harmless text. But T can't be written into a loss function directly, so they train a learned reward model R on human preference judgments, and R is only an imperfect proxy for T. The model is then optimized against R by gradient descent. After training it produces novel-looking helpful behavior — strategies no rater wrote down — but it also does some reward hacking, outputting things that R scores highly but that miss T.

Is T a final cause of the trained models behavior, by my four criteria? What about R? Go through the criteria for each candidate end. Then tell me whether the case shows that one criterion is doing all the work, or that one of them should be dropped. Id rather hear what the case does to the criteria than a flat yes or no.
