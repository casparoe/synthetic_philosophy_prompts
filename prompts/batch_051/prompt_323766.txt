I've been revisiting the Pasadena game after an argument on a rationality forum about whether it has a well-defined price, and I'd like a step-by-step adjudication of the following reasoning. The setup: a fair coin is tossed until it first shows heads. If that first heads occurs on toss n, then the player receives 2^n/n dollars when n is odd and pays 2^n/n dollars when n is even; equivalently, the payoff on outcome n is (-1)^(n-1) · 2^n/n dollars. A commenter offered this argument that the game has a finite expected value and a rational price: (1) The game has a countable infinity of possible outcomes, indexed by the positive integer n, the toss on which the first heads lands. (2) Outcome n has probability 2^{-n}, and its payoff is (-1)^(n-1) · 2^n/n dollars. (3) For any gamble over a countable set of outcomes, the expected value is obtained by enumerating the outcomes in their natural order and summing probability times payoff over them; if the resulting series converges, that limit is the expected value. (4) Therefore the expected value of this game is Σ_{n=1}^{∞} 2^{-n} · (-1)^(n-1) · 2^n/n, which simplifies to Σ_{n=1}^{∞} (-1)^(n-1)/n. (5) That series is the alternating harmonic series, which converges conditionally to ln 2. (6) So the game has a well-defined expected value of ln 2 dollars (about $0.69), and someone who declines the chance to play for a $0.50 fee is making the same kind of mistake as someone who declines any ordinary positive-expectation bet. I think the weak point is around (3) or the inference in (6), because I vaguely remember something about conditionally convergent series being rearrangement-sensitive, but I'd like the exact diagnosis rather than a vague suspicion. Is the argument valid? If not, which step is the first to fail, and what is the strongest correct claim that remains after the mistake is fixed?
