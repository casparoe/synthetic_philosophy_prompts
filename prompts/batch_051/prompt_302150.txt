I'm a software engineer, not a philosopher, and I've been working on an artificial-life simulation. The project has forced me to do something I expected to be trivial: write a clear function that takes an entity and returns whether it is alive. Every obvious criterion I try fails on some case I care about, so I want a working definition rather than a bulletproof one.

Here is my training set. I'm confident these are alive: a bacterium, an oak tree, a dog. I'm confident these are not: a flame, a growing crystal, and a self-replicating computer worm, despite the fact that the flame consumes fuel and the worm copies itself.

The cases I actually need help on are these: a virus, which reproduces only by hijacking a host cell; a viroid (a bare loop of RNA that a plant cell's machinery replicates); a prion, which propagates by making other proteins misfold; a mule; a worker ant (both healthy organisms that never reproduce); a mature red blood cell, which metabolizes but has no nucleus and cannot divide; a desiccated seed that has been in dry storage for years; and a glider in a simple two-dimensional cellular automaton, which moves across the grid but does not copy itself.

Propose a definition, run it against every case, and tell me which cases it handles cleanly, which it settles only by a judgment call, and which it gets wrong or leaves indeterminate. If one criterion cannot cover the whole list, say how you would combine two criteria rather than pretending the boundary is sharp. Then tell me where you are least confident, and what specifically would change your mind: which case, argument, or consideration would make you revise the definition itself rather than just reclassify a single case.
