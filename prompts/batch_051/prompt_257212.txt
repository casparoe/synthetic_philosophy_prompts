I've somehow ended up with a two-tier policy for when the county's written record and the community's living memory disagree about something in our town's past. Tier one: the record gets the last word on dates, names, amounts of money, and who signed what; memory gets the last word on what the event meant, who got hurt, and what still hasn't been made right. Tier two: when they flatly conflict on a factual point, I default to the record — except when the record was produced by the same institution that would look bad if the memory were true, in which case I go with the memory. I've noticed that tier two now does basically all the work, because every conflict around here that I actually care about is exactly that case. So I'm starting to think my fine-sounding policy is just "trust the record unless I'm rooting for the other side," with the two-tier part as decoration. Is there a defensible version of this policy? I mean: are there classes of fact where the record really is systematically better and classes where community memory really is systematically better, and is an institution's self-interest in the conflict a legitimate discriminator between them? Or is the honest move, given that I'm never going to read the primary documents myself, to drop the sorting entirely and either always side with the record or always side with the people I know?
