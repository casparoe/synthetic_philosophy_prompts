So I just got moved onto a project at work where were supposed to write evals for a coding agent, and the brief is basically "score how much collateral damage it does and penalize that." I got assigned to compare a few impact measures people use for this. At first it sounded easy: define a baseline of what would have happened without the agent, then penalize how far the actual world ends up from that baseline. But after a week of reading I've argued myself into the view that the whole thing is circular, and now I can't tell which step is the bogus one. Here's the argument as cleanly as I can put it:

(1) An impact measure has to rate how bad an agent's side effects are, separately from the task it was asked to do — that's the whole point of calling them side effects.

(2) Side effects aren't a natural kind. Whether some change counts as a side effect depends on what the evaluators care about: the same edit can be the intended task in one eval and a side effect in another.

(3) So any workable impact measure has to pick a representation — a set of variables, a distance metric, a notion of before vs after — that says which differences matter and which are noise.

(4) But picking that representation is already a value judgment. For any representation you choose, there will be changes it treats as trivial that evaluators find catastrophic, and changes it treats as big that everyone would shrug at.

(5) To avoid that mismatch, you'd need to know, for every way the agent could change the world, how much the evaluators would care about that change. Otherwise the agent just routes its side effects through whatever the measure doesn't track.

(6) And knowing how much evaluators care about every possible change just is a full specification of value — the exact thing impact measures were supposed to get around.

(7) So either the impact measure is wrong in ways you can't afford, or it's a full value spec in disguise. There's no low-impact AI without full value specification.

I'd like to keep (1) and (2) if I can, and (7) seems too strong because plenty of labs run these evals and they seem not-useless. But I can't find the step that breaks. So: which premise do I reject, and what does giving it up cost?
