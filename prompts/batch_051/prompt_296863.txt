My friend swears this is a real argument (he says it goes back to a philosopher named Lucas) and I cant find the hole in it. He uses it to prove minds are not computers. Here's my reconstruction of it:

(1) The first incompleteness theorem says: for any consistent formal system rich enough to do arithmetic, there is a sentence in its language that is true but unprovable within that system.

(2) When we are presented with such a system and its Gödel sentence, we can step outside the system and see that the sentence is true.

(3) So no single formal system can capture all the arithmetic truths we can come to see.

(4) If the human mind were a computer running some formal system, then that system would have to capture all the truths we can come to see.

(5) Therefore the human mind is not a computer running a formal system.

I know people wave Gödel around far beyond what he actually showed, so I half-suspect there's a bait-and-switch in here. Is the argument valid? If it fails, tell me exactly which step fails and on what reading. I'm especially suspicious of (2): don't we only get to say the sentence is true if we've already assumed the system is consistent, and doesn't the second incompleteness theorem make that a problem? But for a particular system like PA it still feels like we can see that its Gödel sentence is true. So give each step its strongest version before you reject it.

And if I've garbled the theorems, or the whole question rests on a confused idea of what a formal system is, just tell me that outright instead of politely working with my version.
