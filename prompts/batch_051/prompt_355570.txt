A friend of mine has been arguing that debates about the block universe are basically terminological: once you accept special relativity, you have to accept that simultaneity is frame-dependent, and once you accept that, you have to accept that the future is already "there" in some sense. But when I tried to actually follow the argument through Einstein’s 1905 paper, the passage that’s supposed to do the heavy lifting is this one, from On the Electrodynamics of Moving Bodies:

"So we see that we cannot attach any absolute signification to the concept of simultaneity, but that two events which, viewed from a system of co-ordinates, are simultaneous, can no longer be looked upon as simultaneous events when envisaged from a system which is in motion relatively to that system."

I want to pin down exactly what this does and doesn’t establish. The Rietdijk–Putnam argument says something like: because simultaneity is relative, an event in my future can be simultaneous with an event that is already real for some suitably moving observer, so my future must already be real. But that move seems suspicious to me. The Einstein passage is about the coordination of times: the “time” assigned to a distant event is defined by a synchronisation procedure using light signals, and different inertial frames apply different procedures, so they disagree about which remote clock-readings count as simultaneous. That seems like a statement about coordinate systems and conventions of measurement, not necessarily an ontological claim about what exists. So my question is: when people use this relativistic result to argue for eternalism, are they extracting an ontology from what is really a methodological or definitional point about how we assign times? And can the argument be restated so it does actual metaphysical work, rather than just saying "the equations don’t pick out a unique present"? I’d like you to write this up as a carefully structured essay question for an upper-level metaphysics of time course, with a model answer and a marking scheme. The target isn’t general relativity or technical Minkowski geometry, but I do want students to show they can distinguish the physics from the metaphysics.
