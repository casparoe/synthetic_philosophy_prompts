I've been chewing on the paradox of hedonism for a while and I think I've found a mechanism nobody states quite right. I call it the tallying problem. Here's the claim. Pleasure only registers as pleasure when it gets noticed, and noticing is itself an activity that draws on the same finite attention the experience needs. So a hedonist who steers by a running tally — "am i enjoying this enough? how about now? what about that last hour?" — is like someone weighing a soap bubble by setting it on a scale: the instrument eats the thing it's trying to measure. On my picture, direct hedonism fails not because pleasure is shy, and not because it's a byproduct of pursuing other goals (I know those stories), but because the hedonist has to run a monitoring process whose output degrades the very thing being monitored. That's the tallying problem. It would make the paradox of hedonism a special case of something bigger: any goal you can only know you've hit by checking, where the checking destroys the thing checked. But I already see trouble: wine tasting seems to get better the more you pay attention, and people deliberately savor experiences. So maybe the mechanism only bites for some kinds of pleasure, maybe the ones that depend on absorption? I want an honest assessment. Is the tallying problem a real mechanism or just a metaphor with a name? Is there an existing view (under whatever name) that already says this, and if so how is mine different?
