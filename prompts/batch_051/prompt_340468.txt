I've been trying to use minimax regret for choices where I genuinely can't put probabilities on the states, and I hit a problem that makes me want to abandon the rule—except the fallback options look worse. Here's the thing.

Two states, S1 and S2. Two acts.

A: 60 if S1, 80 if S2.
B: 100 if S1, 0 if S2.

Under minimax regret you look at the best you could have done in each state. In S1 the best is 100, so A carries regret 40 and B carries 0. In S2 the best is 80, so A carries 0 and B carries 80. Max regret: A is 40, B is 80. So minimax regret picks A.

Now add a third option C that looks like this: 200 if S1, −1000 if S2. Nobody would ever pick C—under minimax regret its max regret is 1080. But adding C changes the best-in-S1 from 100 to 200. So the regrets become: A has 140 in S1 and 0 in S2, max 140. B has 100 in S1 and 80 in S2, max 100. C has 0 and 1080, max 1080. Now minimax regret picks B.

So the choice between A and B flips just because we added C to the menu, even though C was never chosen. Then the argument runs: (1) a decision rule shouldn't be hostage to irrelevant alternatives; (2) minimax regret is, as the numbers show; (3) so minimax regret isn't the right rule under ignorance; (4) which leaves maximin, with its own problem that any act's worst case can be made arbitrarily bad, or Harsanyi's move of tossing on equal probabilities, which seems to assume exactly what ignorance denies. I'd like to keep minimax regret for the messy, no-probabilities cases. Where does the argument go wrong, if it does? If the answer is to reject (1) and keep the rule, then I want to know what 'irrelevant' could even mean for alternatives that change what you regret.
