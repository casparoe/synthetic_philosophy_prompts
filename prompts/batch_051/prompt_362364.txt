For a computability seminar I'm writing a "where I stand" handout and I want a consistency check before I circulate it. Here's roughly my package:

1. The original Church-Turing thesis — the effectively calculable functions are exactly the Turing-computable ones — is best treated as an explication of a pre-theoretic notion, not a theorem and not an ordinary empirical hypothesis.

2. But the physical Church-Turing thesis — that any function computable by a physically feasible process is Turing computable — is a substantive empirical claim, and I'd bet it's true.

3. I think the hypercomputation proposals I've seen (devices that run infinitely many steps in finite time, analog machines with exact real-valued states) fail for contingent physical reasons, not for conceptual ones.

4. I also think our only grip on "effective procedure" comes from idealizing a human clerk following a finite rule with unbounded time and paper, so the notion is irreducibly normative.

5. I think the strongest case for the original thesis is the convergence of independent formalisms plus the absence of counterexamples, and I doubt any claim of this sort could have a better case made for it.

6. And I'd add: even if someone actually built a device that computed a non-Turing-computable function, I still wouldn't call that an effective procedure — I'd call it a new kind of physical process.

Which of these genuinely pull against each other, which only appear to, and how bad is each tension? Rank them by severity and say what the cheapest fix would be in each case. And don't spare me: if the real problem is that I'm running together the two theses or using "computable" in two ways, tell me that straight.
