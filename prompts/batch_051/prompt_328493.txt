I'm prepping for a seminar on accuracy-first epistemology, and I cooked up the following argument to stress-test the picture. Now I'm the one who's stuck, because I cant see where it breaks.

(1) The inaccuracy of a credence is just its distance from the truth value: truth is 1, falsity is 0, so inaccuracy in proposition P is |c − v_P|.
(2) Rationality requires that your credence maximize expected accuracy—equivalently, minimize expected inaccuracy—as assessed by your own current credences.
(3) Let P be the proposition that it rains tomorrow, and suppose my current credence in P is 0.7. The expected inaccuracy of adopting some new credence x in P is 0.7|x − 1| + 0.3|x − 0|.
(4) For x in [0,1], this equals 0.7(1 − x) + 0.3x = 0.7 − 0.4x, which is minimized at x = 1.
(5) So rationality requires me to move from 0.7 to certainty that it rains tomorrow.

That conclusion is obviously nuts. Is the argument deductively valid? If it is, which premise should go, and can I ditch it without abandoning expected-accuracy epistemology? If it's invalid, exactly wich step fails and why?
