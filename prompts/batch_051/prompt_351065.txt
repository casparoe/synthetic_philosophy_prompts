I'm taking a philosophy of biology course and I've actualy realized my intuitions about when a thing codes for something—as opposed to just carrying information about it—are a mess. Here are my gut verdicts. A stretch of DNA whose triplets map, via the standard genetic code, to the amino acid sequence of a protein codes for that protein, even if the right tRNA is absent in a particular cell so the protein is never made. A recipe written in a language no one alive can read still codes for a dish. A thermostat's bimetallic strip doesn't code for the temperature, even though it bends because of it and controls the furnace. A rabbit's shadow length doesn't code for the time of day. A computer file that, when run through an image viewer, produces a picture of a dog codes for that picture. A prion—a misfolded protein that imposes its shape on other proteins—doesn't code for its shape; it's more like a template than a code.

The messy part. A gene whose transcript is edited differently in different cell types, so the same DNA sequence yields a membrane protein in one tissue and a signalling protein in another: I still want to say it codes for both, but I'm less sure, because saying "both" makes the code look less like a fixed mapping. And the same DNA sequence sitting in an organism with a non-standard genetic code would give a different protein; I want to say the sequence codes for different things in different translational contexts, the way the same string of letters can mean different things in different languages. But then "coding for" is relative to a reader, and my thermostat verdict starts to wobble, because the strip's bend is also relative to whoever reads it. Is there a precise principle that captures most of these verdicts and tells me which ones I have to drop? What distinguishes coding from merely indicating or causing? Does coding require a mapping or convention, a reader, a history of use, or what? And please apply the principle to the case I keep going back and forth on: a stretch of DNA that is never transcribed in any cell but whose sequence would map to a protein if it were—does it code for that protein, or is it just a shadow no one sees?
