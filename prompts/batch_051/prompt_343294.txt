I have been thinking on my own about what it means for a mathematical object to exist, and I keep finding myself pulled among three different standards. As I understand them, the positions usually called logicism, intuitionism, and formalism each carry a different test for when an existence claim has really been proved. Here is my plain-language version of the three tests, each meant to capture when a mathematical object of the required kind should count as existing.

1. Logical standard: the object exists if the existential claim is derivable by valid logical steps from the definitions involved. No construction or exhibition of the object is needed; existence is settled by logic alone.

2. Constructive standard: the object exists only if you can produce an example, or give a procedure that would produce one in finitely many steps. Showing that there cannot fail to be such an object is not enough, because it does not put you in a position to point to one.

3. Formal standard: we do not ask whether the object exists in some system-independent way. We ask whether the corresponding statement is a theorem of a chosen formal system. If it is, the existence claim has been proved inside that system; different systems may answer differently, and there is no further court of appeal.

Now the case. Consider the claim that there exist two irrational numbers a and b such that a^b is rational. A short proof runs as follows. Let x = √2^(√2). Either x is rational or x is irrational. If x is rational, take a = b = √2, and the claim is established. If x is irrational, take a = x and b = √2; then a^b = (√2^(√2))^√2 = √2^(√2 × √2) = √2^2 = 2, which is rational. Either way, the proof concludes, such a pair exists. Notice that the proof starts from the claim that x is either rational or irrational, but it never determines which, and it never exhibits a definite pair that works. I am asking about this proof as given, not about whether the same conclusion could be reached by some other route.

Work through whether this proof establishes the existence claim under each of the three standards, in turn. For each standard, give a clear verdict, explain what in the standard forces that verdict if anything does, and say whether the standard is really addressing the same question as the others or changing it. Then step back: do the three standards disagree about one question, or are they talking past each other? Does this case show that any of the standards is too strict, too loose, or in need of amendment? I want the analysis of this one borderline proof, not a history of the schools or a set of citations.
