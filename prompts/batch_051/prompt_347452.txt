I'm a backend engineer, and with code-gen tools writing more and more of our codebase these days, I keep coming back to a line of reasoning that programming languages are basically on they're way out as something that matters. So here's the version of the argument I'd write down:

(1) The whole point of a programming language is to serve as an interface between a human's computational intent and a machine's execution.
(2) When an AI writes the code from a natural-language spec, the human's intent goes into the spec, and the AI does the translation into whatever language it emits.
(3) If you don't write or read the emitted code in any meaningful way, then the language it's emitted in matters to you about as much as a compiler's intermediate representation — zero, as long as it builds and runs.
(4) For a lot of everyday work now, I really don't write or read the emitted code in a meaningful way.
(5) So for the human in the loop, the language has stopped being an interface and turned into an implementation detail.
(6) Therefore, programming languages don't matter anymore, except as legacy and whatever internal representation the AI happens to favor.
