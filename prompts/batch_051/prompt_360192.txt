The student's answer read as follows:

Answer: The slogan that value is always value for someone relies on equating goodness with benefit, and a perfectionist need not accept that equation: the exercise and development of human capacities can be good in itself, not merely as an instrument to welfare. But the phrase "no one benefits" is doing real work. If it means no one other than the agent benefits, the perfectionist has an easy reply, since on the perfectionist view exercising her capacities well is itself a welfare benefit to the agent. If it means no one at all benefits, including the agent, then the performance could not be excellent, because to do something excellently just is for things to go well for someone, namely the performer. So the original claim is either trivially true, when the agent is allowed to count as a beneficiary, or incoherent, when no one at all is benefited, because there is then no excellence left to which value could attach. What seemed like a substantive debate is therefore a false dilemma generated by forgetting that the agent is a possible beneficiary.
