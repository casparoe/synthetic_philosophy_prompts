I am a software engineer, not trained in philosophy, and I keep noticing a pattern in the multi-agent simulations I build that I cannot name. I run two copies of the same agent in isolated sandboxes with every runtime channel between them disabled. Each copy can read a snapshot of the other's source code at setup, but at decision time neither sends or receives anything. Each faces a one-shot choice: take a costly action that benefits the other. Each copy's policy contains the rule: take the action if and only if the other snapshot's policy would take it in the same situation. The agents take the action and both end up better off, even though no causal signal passes between them during the run and no enforcement is possible. When I make the goods asymmetric—one agent supplies computation the other wants, the other releases data the first wants—the result looks less like mutual cooperation and more like trade across an air gap.
