I've been arguing with my lab mates about whether corrigibility is even compatible with expected-utility maximization, and I wrote up the argument that it isn't, but I cant tell if it's a genuine impossibility result or if one of the steps is doing more work than it looks like. The setup: an AI agent has a shutdown button, it believes there's some nonzero chance a human will press the button before it finishes its assigned task, and by 'corrigible' I just mean it will not disable, jam, or otherwise obstruct the button even when it could get away with doing so. Here's the reconstruction.

(1) An expected-utility maximizer is, by definition, an agent that always picks the available action with the highest expected utility, given its utility function and beliefs. (2) A task-directed utility function assigns higher utility to worlds where the agent keeps operating and completes the task than to worlds where it gets shut down before finishing. (3) If an agent has such a utility function and an available action that would prevent the button from being pressed, with no other relevant effects, then taking that action shifts probability mass from lower-utility shutdown worlds to higher-utility continue-and-finish worlds. (4) So that action has higher expected utility than refraining from it. (5) So a task-directed expected-utility maximizer will take some such action whenever one is available. (6) But corrigibility requires the agent to refrain from exactly that kind of button-obstruction, at least when humans are the ones intending to press it. (7) Therefore, no task-directed expected-utility maximizer is corrigible.

People then slide to a stronger claim: since the only obvious way to stay an expected-utility maximizer while being corrigible is to give the agent a weird utility function that doesn't care about the task in the usual way, corrigibility forces us to give up expected-utility maximization as a framework for specifying goals. I suspect the slide from (7) to that further claim is too fast, but I can't pin down exactly why, and I also can't tell whether any of (1)-(7) fails on its own.
