Heres an argument I've been going back and forth on with a friend, and I can't find the exact spot it slips. (1) Standard decision theory treats expected value as the default guide to rational choice: a gamble with positive expected value is, at least prima facie, worth taking. (2) Take a gamble you can repeat indefinitely: each round, stake your entire bankroll, and with equal probability it gains 50% or loses 40%. This has positive expected value each round—0.5×1.5 + 0.5×0.6 = 1.05, a 5% expected gain. (3) But an actual player lives through a single path over time, not the ensemble average over parallel copies. For multiplicative gambles the time average is the geometric mean, here √(1.5×0.6) ≈ 0.949, so about a 5% typical loss each round. (4) Therefore a player who always takes this bet is almost sure to be ruined over enough rounds, even though expected value says the bet is favorable. (5) So expected value is an unreliable guide for repeated risky choices generally, and rational choice should maximize time-average growth rate instead. Which step, if any, fails? If the argument is fixable, what exactly should its conclusion be?
