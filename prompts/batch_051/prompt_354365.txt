I have been turning over a parallel and I want to know whether it is a deep structural isomorphism or a seductive analogy.

On one side is Gödel's incompleteness proof. A coding scheme — Gödel numbering — assigns numbers to the symbols, formulas, and proofs of a formal system, so that arithmetic predicates can talk about syntax. A fixed-point construction, now standard as the diagonal lemma, then produces a sentence that says, in effect, of its own code that it is not provable. Self-reference is not imported from outside; it is manufactured by the system's ability to encode and apply its own syntax.

On the other side is Typogenetics, the toy molecular-genetics system Hofstadter describes in Gödel, Escher, Bach. It has strands: strings over the four letters A, C, G, and T. A fixed code translates a strand into an enzyme, and an enzyme is itself a string of primitive operations — cut, copy, insert, delete, move — that act on other strands. Crucially, nothing prevents a strand from coding for an enzyme that acts on the very strand that coded it; the system allows, and Hofstadter constructs, strands that code for enzymes that copy the strand that codes for them.

The resemblance I see is not merely that both involve coding. In both cases a single object gets two roles at once — an inert value (a number; a strand) and, under the code, an operation on values of that kind (an arithmetic predicate; an enzyme). Self-reference then arises by applying the operation to its own code. A self-copying Typogenetics strand looks to me like a quine, and the sentence manufactured by the diagonal lemma also looks like a quine: both are fixed points of an encode-and-self-apply move.
