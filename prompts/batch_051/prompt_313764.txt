After a long career in experimental physics, I have turned to philosophy in retirement and now assist with marking for an undergraduate module in the philosophy of decision theory. I set the following assessed question:

"A fair coin is tossed until it comes up heads for the first time; let n be the toss on which that happens. In the St Petersburg game the player receives £2^n. In the Pasadena game the player receives £(-1)^(n-1) · 2^n / n, with a negative amount meaning that the player pays. (a) Show that the expected value of the St Petersburg game is infinite. (b) Compute the expected value of the Pasadena game as a sum taken in the order n = 1, 2, 3, ..., and explain what property of that series is relevant to treating the result as the game's expected value. (c) Does the Pasadena game show that maximising expected value is an incoherent decision rule, in the sense of issuing contradictory verdicts about a single option, or does it show only that the rule is incomplete for some gambles? Justify the answer."

One student submitted the following answer, reproduced in full:

"(a) The probability that the first head falls on toss n is 2^-n, so the St Petersburg expectation is Σ 2^-n · 2^n = Σ 1 = ∞; it is infinite. (b) For the Pasadena game the expectation is Σ 2^-n · (-1)^(n-1) · 2^n / n = Σ (-1)^(n-1)/n. That is the alternating harmonic series, which converges to ln 2, so the fair price is ln 2 and the expectation is well defined. The series is only conditionally convergent, not absolutely convergent, because Σ 1/n diverges, so other orderings could give different sums; but the natural order n = 1, 2, 3, ... is the one attached to the game, so ln 2 is the correct expected value. (c) Since reordering the terms changes the computed expectation to any value one likes, expected value theory assigns many different values to one and the same gamble. A decision rule that delivers conflicting valuations of a single option is incoherent. The Pasadena game therefore shows that expected value maximisation is self-contradictory and should be rejected, not merely treated as incomplete."
