Construct a thought experiment to the following specifications. Consider two idealised decision-makers, a Cartesian-boundary agent and an embedded agent. The Cartesian-boundary agent treats the world as external and already specified: when comparing actions, it holds fixed the payoff-relevant facts it has learned about and evaluates only the causal consequences of each action. The embedded agent includes itself in the world it models: its own decision procedure is a node in the model, so it compares whole policies rather than bare interventions and does not sever the correlations between its output and facts that were settled before the choice. The two agents share identical utilities, identical available actions, and identical nonself-referential factual information. Build a single ordinary-life decision problem in which they choose different actions, under these constraints: the setting is mundane, such as a workplace, clinic, household, or small business; no one in the story may predict the agent better than a shrewd human who has studied the agent's habits, values, or publicly available code; there is no science-fictional technology, no perfect self-copy, no demon, and no literal Newcomb pair of boxes or envelope of money keyed to a prediction; and the payoffs are ones an ordinary adult could face, with the decision fully settled within a week. Arrange the case so that the embedded agent takes the action that a naive observer would call useless because the payoff-relevant fact is already fixed, while the Cartesian-boundary agent takes the forward-looking action. Then do the check: give each agent's action and its decision-theoretic reasoning, identifying the exact correlational structure being exploited; state the single feature of the case doing the work; explain what happens to the disagreement if that feature is removed; and close with the strongest objection the Cartesian-boundary agent would press against the embedded agent's choice and how the embedded agent should respond.
