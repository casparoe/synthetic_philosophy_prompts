For a seminar on the later Wittgenstein, I need to write a short paper on whether the private language argument survives a particular kind of case, and I would like help sharpening the question before I commit to a thesis. The argument, as we reconstructed it in class, runs: a sign has meaning only if some check is possible on whether the speaker is using it correctly; for a sign intended to name a private sensation known in principle only to the speaker, no such check is possible, because the speaker's only standard is her own present or remembered impression, so the difference between correct use and merely seeming correct to her collapses; therefore a genuinely private word is impossible.

Now suppose a speaker wears a portable device that continuously detects a distinctive physiological correlate of some sensation and displays it as a stable graph visible to others. She introduces the sign S while attending to the sensation and to the graph at the same time, and thereafter uses the graph as a standing check on her applications of S. Other people can see the graph and can dispute whether it shows the same pattern. Does the private language argument survive this development? On one reading it survives straightforwardly, because S is no longer private once a public criterion is available, and the argument never denied that signs with public criteria can be meaningful. On another reading the device merely relocates the difficulty, because the correlation between the graph and the sensation must itself be established by the speaker's private recognition that the sensation is the same one each time, which is exactly the sort of private recognition the original argument says cannot do the semantic work. Which of these readings better fits what the argument actually proves, and how should the argument be repaired, restricted, or conceded in light of the case?
