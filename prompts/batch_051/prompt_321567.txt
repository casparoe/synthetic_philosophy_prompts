I retired some years ago from a career in the physical sciences and have recently begun reading in the philosophy of probability and algorithmic information theory. I keep returning to one question: can a finite string of bits ever properly be called random, or does randomness belong only to generating processes or to infinite sequences? I have collected my verdicts on several cases, and I would like to know what principle, if any, captures them.

1. The twenty-bit string 00000000000000000000 is not random, and neither is 01010101010101010101.

2. For very short strings such as 01, the question seems not to arise; they are neither random nor non-random.

3. The twenty-bit string 11001001011011010001, which I produced just now by trying to be unpredictable and for which I can find no short description, I am strongly inclined to call random, though I know there may be a short rule generating it.

4. A twenty-bit string read off from the binary expansion of π, beginning at the thousandth binary digit, is not random, even if it looks irregular, because it has a short exact description of the form: the binary digits of π beginning at the thousandth place.

5. If a certified quantum random number generator were to output exactly the same twenty-bit string as in case 4, I would call it random, because of how it was produced.

6. Yet I also hold that whether a string is random should depend only on the string itself, not on its causal history; two copies of the same string cannot differ in randomness.

7. A thousand-bit string whose shortest known description is roughly a thousand bits long I would call random, but only relative to present knowledge; I do not believe there is a further fact, independent of any description system, about whether some shorter description exists but has not been found.

I suspect some of these verdicts pull against one another, but I cannot see exactly where or how seriously. Is there a coherent principle about randomness in finite strings that delivers most of them? If not, which verdicts should be revised, and what is the cheapest defensible view? I would also like that view applied to two further cases I cannot decide: a fair coin that happens to produce twenty zeros, and a long string whose shortest known description is exactly one bit shorter than the string itself.
