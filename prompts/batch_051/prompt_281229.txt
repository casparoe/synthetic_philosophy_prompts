I've arrived at a view about inferring an optimizer's objective and search space from its behavior, and I want to stress-test it before leaning on it. I'll treat anything as an optimizer if it's useful to describe it as searching some space of options so as to improve a score: a trained policy, a recommender system, a query planner, even an organism if I squint. The position I've come to hold is that behavior radically underdetermines both the objective and the search space, where by "search space" I mean the set of options the system can even consider. The map from (objective, search-space) pairs to behavioral traces is many-to-one, and the underdetermination does not wash out as observations accumulate: an arbitrarily long trace remains consistent with multiple pairs that are not equivalent in any behaviorally innocent sense, because they diverge on counterfactual or future choices — exactly the differences that matter for predicting or controlling what the system does next. I want a map of what would count against this position. What would have to be true for it to be false, or at least much weaker? Which observations, formal results, experiments, or argument paths should move me — especially ones my view gets wrong while a rival view gets right — ranked from fatal to merely awkward? Which load-bearing assumptions should I watch: what counts as the same behavior, how much observation is allowed, the role of prior information, the line between objective and search algorithm, the line between implementation detail and real difference? Which objections would a defender of my view concede are real costs, and which should they dismiss as merely verbal? Finally, tell me honestly whether I've stated the position so flexibly that nothing could count against it, and whether that would be a defect for a view of this kind.
