I'm grading take-homes for my undergrad philosophy of language section and I'd like a second pair of eyes on one answer before I lock in the marks. The question on the paper was:

"Consider a finite sorites sequence x0, x1, ..., xn for the predicate 'heap', where x0 is clearly a heap, xn is clearly not a heap, and each xi and x_{i+1} are minimally different (indiscernible with respect to heapness). Briefly contrast epistemicism and supervaluationism about vagueness, with particular attention to (a) what each view says about whether there is a fact of the matter about which xi is the last heap, and (b) what truth value, on each view, the universal tolerance premise 'for all x, if x is a heap, then x' (a minimally different x') is a heap' has."

Here's what one student turned in:

"Both epistemicism and supervaluationism are 'sharpist' in the sense that neither thinks the extension of a vague predicate like 'heap' is metaphysically fuzzy; they disagree about where the sharpness is located.

On epistemicism, there is a fact of the matter about the cutoff. For the sequence above, there is some i such that xi is the last heap and x_{i+1} is the first non-heap. For every object, including the borderline ones, 'x is a heap' is straightforwardly either true or false; it's just that we lack the discriminative capacity to tell which side of the cutoff a given object falls on. The logic is fully classical.

On supervaluationism, by contrast, there is no single fact of the matter about the cutoff. Instead, 'heap' is understood relative to a set of admissible precisifications, each of which gives 'heap' a sharp extension and hence picks out its own cutoff. A statement is true just in case it is true under every admissible precisification (supertrue). For a borderline object x, 'x is a heap' is true under some precisifications and false under others, so it is neither true nor false — it's indeterminate.

On the tolerance premise: on epistemicism, the universal statement 'for all x, if x is a heap then x' is a heap' is simply false. At the unique cutoff there is a genuine counterexample (the last heap and the first non-heap), and the epistemicist is happy to grant that the premise is false; the sorites argument fails at the premise, not at the logic or the induction. On supervaluationism, the same universal statement is indeterminate: it is true under some precisifications and false under others.

Finally, both views face the problem of higher-order vagueness. On supervaluationism, the boundary between what is supertrue and what is indeterminate is itself vague, and there's no non-vague way to fix it. On epistemicism, the situation is no better: even though there is a sharp cutoff, the claim 'x is a borderline case' is itself vague, since we can't know which cases are borderline, so we inherit higher-order vagueness as well."
