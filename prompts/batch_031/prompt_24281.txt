I'm working on a piece about how statistical reasoning can both obscure and reveal discrimination, and I want to work through one well-known case using a lens I think is underused. The case is the 1973 University of California, Berkeley graduate admissions episode. The facts, briefly: in the fall of 1973, when you pool all applicants, men were admitted at roughly 44 percent and women at roughly 35 percent, which looked like a strong signal of bias against women. But when the same data are broken down by department, the pattern largely reverses: in four of the six largest departments, women were admitted at equal or higher rates than men. The explanation that emerged is that women applied disproportionately to the most competitive departments, the ones with the fewest openings and the lowest admission rates, while men applied to the more generous ones. The committee that examined the matter concluded there was, if anything, a slight bias in favor of women.

I want you to analyze this episode not as a Simpson's paradox, which I already know and do not want treated in the standard way that attributes the reversal to a confounding variable, but through the lens of the reference class problem: the problem, in the philosophy of probability and inductive logic, that for any individual and any statistical property there is no unique correct reference class to which you should compare them, and that the choice of class is not settled by the data alone.

Here is what I need.

First, map the reference class problem onto the case precisely. Identify the reference classes actually at stake, and I would guess at least "all 1973 Berkeley graduate applicants" and "applicants to the same department with similar qualifications." Explain, in the vocabulary of the reference class problem, why the admission probability of a particular applicant, say a specific woman who applied to a specific department, is not a single well-defined number but depends on which class you pick. Be careful about the distinction between the individual-level question, what is the probability that this applicant gets in, and the group-level question, are women as a class admitted less often than men, and say how the reference class problem, which is usually posed about individuals, is supposed to bear on the group-level discrimination question.

Second, tell me what the reference class problem says the actors in the case actually faced. The complaint was that women were being discriminated against. By the lights of the reference class problem, is that complaint even well-posed? What is it ambiguous about? Which reference class does a verdict of bias against women presuppose, and which does a verdict of no bias presuppose? I want you to make explicit that these are different questions with different answers, not the same question answered two ways.

Third, and this is the part I care about most, say where the reference class problem explains the case well and where it goes quiet or breaks. My sense is that it explains the statistical reversal cleanly, the two reference classes answer different questions, so there is no real paradox, but that it is silent on at least two things: which reference class is actually the right one for a discrimination claim, which is a causal and a normative question rather than a statistical one, and the causal story behind the application pattern, why women applied to the more competitive departments in the first place. Test that sense of mine against the theory. Does the reference class problem have any resources for answering which class we should use, or does it deliberately leave that open? And if it leaves it open, is that a limitation of the theory or a feature of it?

Finally, what does the episode show about the reference class problem itself? I want an honest account of whether this is a confirmation of the theory, a case where recognizing the reference class ambiguity defuses a genuine puzzle, an anomaly, a case where the ambiguity is doing more work than the theory anticipated, or something the theory never really foresaw. In particular, I am interested in whether the Berkeley case is one where the reference class problem is a purely technical statistical issue, or whether it exposes a genuinely philosophical question about what a discrimination claim is asking.

I do not need citations or a reading list. I need the mapping to be disciplined, who is the individual, what is the property, what counts as the reference class, which class each verdict presupposes, and I need you to say where the theory is silent rather than forcing it to speak.
