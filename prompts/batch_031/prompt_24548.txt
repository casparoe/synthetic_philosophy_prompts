I'm TAing a grad seminar on mech interp this semester and I'm stuck grading one homework. Can you grade it for me — give a score out of 10 (or a letter grade) and specific comments that justify it, so I get a point-by-point read on what's right, what's wrong, and how serious each mistake is rather than just a vibe? Also, seperate what the answer presents as settled from what is genuinely contested among people who work on this, and flag wich claims are being passed off as consensus when they're not.

The question I gave:

"A colleague argues: 'Neural networks don't actually have representations. When we say a layer contains a cat detector, we're just describing the input-output function in a convenient way; there is no cat detector inside the network, just weights.' (a) Distinguish the ontological claim that a trained network literally contains representations of concepts from the epistemic claim that such representations are a useful way for us to describe the network's behavior. (b) Explain why the success of linear probes is evidence for, but not proof of, the existence of representations, and name at least one additional criterion a representationalist might demand."

The student's answer:

"(a) The ontological claim is that the network's internal states really do play the role of representing concepts — that there is something in the activations that is about cats, and that downstream computation makes use of it. The epistemic claim is just that 'cat detector' is a handy shorthand for us, a description of the function the network computes rather than a constituent of it. The 'no representations' view is a version of the epistemic claim: when we find a feature, we've found a convenient way to describe the weights, not something literally in the network.

One thing to be careful about: the 'no representations' view is not the same as the claim that the network is uninterpretable. It's a claim about what is in the system, not about our access to it. Even if we could interpret every weight perfectly, the 'no representations' view could still be true.

(b) A linear probe fits a linear map from activations to labels. If it's accurate, the information is linearly accessible in the activations. But that doesn't show the network itself uses that information, or that the feature is part of the network's own computation. The probe is an external decoder; it can read out information the network never uses for its task. So probe success is evidence for, but not proof of, representation.

A representationalist would want more, e.g., from interventions: ablating or perturbing the feature should change the network's behavior in the way you'd expect if the network were using that representation. Or they might want the feature to be systematic and compositional — combined with other features to build more complex representations.

I should mention superposition: because networks have more features than dimensions, features overlap and interfere. This is sometimes argued to show features aren't really there — that there's no clean cat detector, just a smeared pattern. But I think that argument is too strong: superposition shows representations aren't demixed or sparse, not that they don't exist. A smeared pattern can still represent something.

Overall, I think the field has settled on the view that representations exist but are distributed and approximate, and that the 'no representations' view is a fringe position. The real debate is about what counts as a representation — functional vs. structural criteria — not whether there are any at all."
