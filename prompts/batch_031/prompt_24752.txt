I'm a journalist who covers science and ideas, and I'm working on a piece about why "value" resists a clean definition, so I've landed on a position I want to stress-test before I build the argument around it. I've come to accept that "X is valuable" can be analyzed in terms of normative reasons: roughly, something has value just in case there are reasons to value it, so that value is not a freestanding property but a way of cashing out the space of reasons that would motivate a valuing response. I know the standard objection — the so-called "wrong kind of reasons" problem — the thought that some putative reasons to value something (that everyone else values it, that it is popular or fashionable, that valuing it would make me feel good) look like reasons to value it without making it any more valuable, i.e., reasons of the "wrong kind." But I've come to believe this objection is overblown: that these counterexamples are not genuine reasons to value at all, or that they are reasons of a different sort (reasons to believe something is valuable, or to conform to a group) that the reasons-based analysis never needed to capture.

So what would count against that? I want the strongest cases for thinking there really are reasons of the wrong kind — and not just the popularity examples, but cases where the wrong-kind reason seems to do genuine normative work that the reasons-to-value analysis cannot absorb without quietly doing the very work of value it was supposed to explain. For each candidate counterexample, I'd like you to say whether it is a reason that makes the thing more valuable, a reason that merely tracks or indicates value, or a reason to value that is parasitic on some independent value — and to tell me which of these distinctions the analysis actually needs, and where it breaks. Which of these would a defender of the reasons-based analysis themselves concede as counting against them, and which would they dismiss as not really reasons to value? And I'd like an honest assessment of whether the view, once it is restricted to "right-kind" reasons only, risks anything at all, or whether that restriction has qualified it into unfalsifiability — because if the move to "right-kind reasons" quietly imports an independent notion of value, then I don't think the analysis has done what I wanted it to do, and I need to know that before I build a piece on it.
