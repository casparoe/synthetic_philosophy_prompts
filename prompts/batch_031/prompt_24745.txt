One result I keep meeting is Good's theorem, which I take to say that the expected value of sample information is never negative: a risk-neutral decision-maker who is free to choose an action after observing a signal is never worse off, in expectation, from having that signal available. Could you give me a concrete example in which acquiring information actually lowers the decision-maker's expected utility — a genuinely negative value of information, not merely a value that turns negative once the cost of obtaining the information is subtracted — and then explain precisely which assumption or assumptions of the theorem the example fails to satisfy? I'd like the example to be fully specified: the states of the world, the signal and its distribution, the set of available actions, the payoffs, and the decision-maker's utility function where one matters, so that I can check the arithmetic myself. And if I have misstated the theorem or its assumptions, or if no such example can be given without violating an assumption in a way that renders the example trivial or uninteresting, I would rather you say so plainly than construct something that merely looks like a counterexample.
