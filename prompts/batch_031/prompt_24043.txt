I keep running into the same move in the literature on low-impact AI, and I can't tell whether it has a name. The stated goal of an impact measure is to keep an agent from causing "side effects" without spelling out a full account of what the agent should want — the whole selling point is that it is lighter than a complete value specification. But look at how the measures actually get defined. One penalizes the agent for how far the resulting world diverges from a "do-nothing" baseline; another penalizes it for changing a list of "relevant" features; a third compares the outcome to a reference class of "normal" trajectories. In each case, the moment you ask which baseline, which features, or which class, you discover the answer is a substantive value judgment: you have chosen which dimensions of the world are allowed to move and which must be held fixed. So the measure is not value-free; it carries a value specification that has been hidden inside the choice of baseline. I have seen the broader failure called specification gaming, or reduced to Goodhart's law, but those describe an agent exploiting a fixed measure, not the measure itself quietly containing the very value it was supposed to avoid. Is there an established term for this specific phenomenon — the fact that a supposedly value-neutral reference or baseline is itself a value choice? And if there isn't one, how would you carve it out precisely, and how exactly is it distinct from ordinary specification gaming and from the mere arbitrariness of picking a counterfactual baseline?
