The question I assigned was:

"Kripke's 1975 response to the Liar paradox turns on a distinction between grounded and ungrounded sentences. Explain that response, and then say whether it survives the strengthened Liar, the sentence 'this sentence is not true.'"

Here is the student's answer:

"Kripke's starting point is that the ordinary Liar sentence, 'this sentence is false,' generates a contradiction once it is combined with the T-biconditional, the principle that a sentence is true if and only if what it says is the case, since classical logic lets a single contradiction explode into triviality. His proposal is to build the truth predicate in stages: begin with a base language that has no truth predicate, add truth claims about that language, then add truth claims about the enlarged language, and so on, taking the union of the resulting hierarchy. Sentences whose truth value ultimately comes down to non-linguistic facts — the weather, arithmetic, that sort of thing — are grounded and receive a determinate value, true or false. Liar-type sentences never come down to anything outside the language; they are ungrounded, and Kripke gives them a third value, neither true nor false. Since ungrounded sentences are not true, the theory never derives a contradiction, and it remains consistent.

Now consider the strengthened Liar, 'this sentence is not true.' If it is true, then what it says is the case, so it is not true; and if it is not true, then what it says is the case, so it is true. So the strengthened Liar looks like it generates the same trouble. But on Kripke's theory the strengthened Liar is itself ungrounded — its truth value also never comes down to non-linguistic facts — so it receives the third value and the theory does not explode. And this settles the matter: since any such sentence is ungrounded, none of them can be used to generate a paradox, so Kripke's theory is immune to this sort of objection. A rival approach, the revision theory (Gupta and Herzberger, 1993), treats truth as a circular concept and evaluates sentences by iterating the T-biconditionals from an arbitrary starting hypothesis; Liar sentences oscillate between true and false and never stabilize, which is why the revision theorist does not assign them a value either."
