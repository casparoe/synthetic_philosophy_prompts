A student brought me an argument last week that I still cant shake, and I'd like a second pair of eyes on it. It's about the two-envelope problem, and the claim is that the usual way of dissolving the paradox actually proves to much: it shows that expected value can't do any rational work in any situation where you don't know the full distribution. Here's the argument, numbered the way the student gave it:

(1) In the two-envelope problem, the expected value of switching is computed by summing, over the possible amount x in the envelope I'm holding, the probability that the other envelope holds 2x times 2x, plus the probability that it holds x/2 times x/2, all weighted by how likely x is.
(2) But the problem, as stated, gives me no information about how the envelopes were made, so I have no information about the distribution over x.
(3) So the expected value of switching is not fixed by the information I actually have.
(4) If the expected value of an act isn't fixed by the information an agent has, then the agent has no expected-value-based reason to prefer that act to the alternatives.
(5) So I have no expected-value-based reason to switch, and none to stay.
(6) But the same reasoning applies to any decision problem where the agent doesn't know the full distribution over outcomes: the expected value of every available act is not fixed by the agent's information, so the agent has no expected-value-based reason to prefer any act.
(7) So expected-value maximization never gives an agent a reason to prefer one act to another.
(8) That can't be right; expected-value maximization is supposed to be the backbone of rational choice.
(9) So one of (1)–(6) has to go.

I'm pretty sure I want to keep (8), and I also want to keep (1)–(3), since it's obvious the problem as stated doesn't pin down the distribution. So the pressure lands on (4)–(6). Which step do you think actually breaks, and what do I pay if I reject it? I want the diagnosis to be specific, not just "the argument is bad."
