In the moral-uncertainty literature, the standard move is to treat moral uncertainty exactly like decision-making under empirical uncertainty: each candidate moral theory is a hypothesis, your credence in it is a probability, the outcomes are the same across theories, and you compute expected moral value the way a decision theorist computes expected utility. That analogy is doing all the work in the claim that there is a single general procedure for acting under moral uncertainty. How far does it actually hold?

Return a table with these columns:
- empirical_element: the element of the standard decision-under-uncertainty problem (e.g., hypothesis, probability, outcome, utility, evidence).
- moral_counterpart: what it corresponds to in the moral-uncertainty setting.
- status: one of holds, strained, or breaks.
- why: one sentence justifying the status.
- consequence: what this means for the expected-value procedure (blank if none).

Make sure to cover the contested elements: whether the utility function is fixed (as in empirical decision-making) or is itself what is in question, whether rival theories' values are commensurable on a common scale, and whether the evidence for a moral theory is independent of the act being decided. After the table, return a JSON object with these fields:
- surviving_claim: a string stating which part of the "there is a general procedure" claim survives.
- load_bearing_disanalogies: an array of the disanalogies that actually undermine the procedure.
- cosmetic_disanalogies: an array of disanalogies that do not.
- better_source_domain: a string proposing a better source domain for the analogy, or "none."
