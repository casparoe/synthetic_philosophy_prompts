Question (15 pts):

Millikan's teleosemantics holds that the content of a mental state is determined by the "proper function" of the state-producing disposition -- the function for which the disposition was selected.

(a) State the "misrepresentation problem" for this theory.
(b) State the "originalism" problem. Give a concrete example.
(c) A common objection is that teleosemantics is circular, because a "misrepresentation" is defined as a malfunction of a representational function, but "malfunction" is itself defined in terms of "proper function." Is this objection correct? Explain.

Student's answer:

(a) On teleosemantics, a belief represents X only if the disposition to have that belief has a proper function of representing X, and a proper function is a function for which the trait was selected. But selection only rewards what works: a belief-producing disposition is selected because it usually produces true beliefs. So a disposition that produced only false beliefs would never have been selected, and therefore could never have a proper function of representing. It follows that a false belief can't represent anything at all -- e.g., my belief that "there's a tiger in the grass" when there isn't doesn't represent tigers, it just... happens. That's absurd, so something's wrong. (Side note: "proper function" here just means what the trait typically does successfully -- a heart's proper function is pumping blood because that's what it's typically good at.)

(b) Originalism is the problem that a belief's content is fixed by the function the disposition was originally selected for, and that function doesn't change with use. So if a trait was selected to track one thing, it keeps that content forever, even if the environment changes and the trait is now triggered by something else. Example: a bird's fear response was originally selected to track predators. Now cars look like predators to the bird and trigger the same response. On originalism, the content of the fear is still "predator," not "car," even though the car is what's actually causing it.

(c) I don't think the circularity objection is right. The objection says that "malfunction" is defined in terms of "proper function," so calling a false belief a malfunction is circular. But we can define malfunction without reference to proper function: a malfunction is just a failure to do what the trait typically does. A false belief is a malfunction of the belief-disposition in exactly that sense, and that definition doesn't mention representation, so there's no circle. The theory just needs to say that the representational function is the one selected for, and misrepresentations are cases where the trait fails at its typical job.
