I hold the view that there is no such thing as a wrong-kind reason for an object to be valuable. When a consideration counts as a reason for X to be valuable, it is always the kind of reason that makes X valuable in the relevant sense; the standard "wrong kind" cases — a painting that is prized only because experts take it to be a masterpiece, a thing that is valued only because it is desired — are not evidence of a real distinction in axiology but artifacts of a confused way of talking, a failure to separate the value of an object from the value of our attitudes toward it. What would count against this view? I want the arguments, intuitions, and cases that should move me, sorted by how decisive they'd be, including the points that defenders of the view would themselves concede as counting against it. I'd also like an honest assessment of whether the view has been qualified into unfalsifiability, and if so, whether that is a genuine problem for a view of this kind.
