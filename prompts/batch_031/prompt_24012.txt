I am building a case to test whether the "causal contribution" response to the inefficacy objection can do real work in the structure that actual collective harms have. Please construct a thought experiment to the following specifications.

The scenario must be a single, realistic paragraph — a market, a workplace, a community, or a shared environment — with no exotic physics, no perfect predictors, and no stipulation of the moral verdict. The harm must come about through a **threshold with surplus**: there is a level at which the harm tips (a carrying capacity, a pollution threshold, a tipping point), the total contribution of all the agents exceeds that level by a margin, and the harm in fact occurs. State the threshold and the total contribution explicitly (numbers are welcome) so that a reader can check the arithmetic.

The case must be engineered so that, for one designated agent, all three of the following hold:

1. **The agent is not a difference-maker.** Had the agent refrained, the total would still have exceeded the threshold and the harm would still have occurred, so the ordinary but-for / counterfactual test clears the agent.
2. **The agent is not the marginal agent.** The agent's contribution is not what tips the balance; the system sits in surplus rather than at the margin, so the "you are the marginal voter or marginal buyer" equilibrium response also fails.
3. **The agent's action is nonetheless a genuine part of the causal process** that brought about the harm — a redundant part, but a real part of the excess that crossed the threshold.

Use the threshold-with-surplus structure, not a simple overdetermination of two independent, each-sufficient causes (the two-people-each-dropping-a-match-into-a-haystack case). The point is to use the structure that climate, meat, and voting cases actually have — many small contributions, a threshold, and a surplus — so that the causal-contribution response is not granted trivially.

After the scenario, do the following:

- Walk through what each of three responses says and which verdict it delivers: (i) the **difference-making** response (the agent is not a cause, because the harm would have occurred anyway); (ii) the **causal-contribution** response (the agent is a cause, because the agent's action is a part of the causal process, even if redundant); and (iii) the **equilibrium / marginal** response (the agent's action matters only if the agent is the one who tips the balance).
- Say **which feature of the case does the work** (I expect the threshold-surplus structure), and **what happens if that feature is removed** — in particular, what the verdicts become if the total contribution sits exactly at the threshold rather than in surplus.
- Note **how a defender of the inefficacy objection would attack the case**. In particular, they will press the **redundancy / causal-dilution** objection: in a surplus, each individual's contribution is not needed for the harm, so it is not a genuine cause but merely a redundant factor; and the more contributors there are, the closer each one's moral weight comes to zero. Show how the causal-contribution response is supposed to answer this, and say whether you think the answer succeeds.

The point of the case is to isolate the distinction between *making a difference* (counterfactual dependence) and *being a cause* (a part of a causal process), and to test whether the latter can bear the moral weight that the inefficacy objection places on the former. A case that stipulates the verdicts rather than generating them from the three responses fails, and a case that collapses into a trivial overdetermination fails.
