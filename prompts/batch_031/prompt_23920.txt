I'm grading short-essay responses from an intermediate course in the philosophy of decision theory, and I'd like a careful assessment of one student's answer so I can attach comments to the paper. The question I set was:

"In the Newcomb problem, a highly reliable predictor has, on the basis of how it models you, predicted whether you will take only the opaque box (one-box) or take both boxes (two-box). The opaque box contains a large sum (say, $1,000,000) if and only if the predictor predicted you would one-box, and is empty otherwise. The transparent box always contains a small sum (say, $1,000). You may either take only the opaque box or take both boxes. State the two standard arguments — the expected-utility argument for one-boxing and the dominance argument for two-boxing — and then give your own assessment of which is the stronger argument and why."

Here is the student's answer:

The Newcomb problem is this: a predictor that is almost always correct has, using its model of how I decide, predicted whether I will one-box or two-box. The opaque box holds $1,000,000 if and only if the predictor predicted I would one-box, and is empty otherwise; the transparent box always holds $1,000. I can either take only the opaque box (one-box) or take both boxes (two-box).

The expected-utility argument for one-boxing runs as follows. Because the predictor is so reliable, if I one-box it is very likely that it predicted I would, so the opaque box is very likely full and I get $1,000,000. If I two-box it is very likely that it predicted I would, so the opaque box is very likely empty and I get only the $1,000 from the transparent box. One-boxing therefore has a far higher expected payoff, so I should one-box.

The dominance argument for two-boxing runs as follows. Whatever is in the opaque box is already settled and is not affected by what I choose to do now. If the opaque box is full, then taking both boxes gives me $1,001,000, which is more than the $1,000,000 I would get from one-boxing; if the opaque box is empty, then taking both boxes gives me $1,000, which is more than the $0 I would get from one-boxing. So two-boxing gives me a larger total in every case, and I should two-box.

I think the dominance argument is the stronger of the two. The expected-utility argument depends on the assumption that the predictor is reliable, so if I have any doubts about the predictor's reliability, the whole argument collapses: the expected values it computes are no longer meaningful, and it can no longer tell me what to do. The dominance argument, by contrast, does not depend on any assumption at all: its conclusion holds whether or not the predictor is reliable, and even if the predictor is perfect. It is therefore the more robust argument, and I take it to settle the problem in favor of two-boxing.
