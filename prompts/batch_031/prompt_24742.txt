A chatbot that says "I don't know" when it does know, because the answer would embarrass the user: deceptive. A model that says "I'm fairly confident" when it's actually 90% sure, to nudge the user to double-check: I keep going back and forth on this one. A model that reports its true state, "I'm only 70% sure", when the user would be better off not knowing: fine, honesty about one's confidence isn't lying about the world.
