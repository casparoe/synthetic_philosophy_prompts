I'm TA-ing a philosophy class and grading a homework on supertasks, and I'd like a seccond pair of eyes on one of the answers. The question was:

"In the context of Thomson's lamp and the debate on supertasks: (a) describe the setup of the lamp, (b) explain Thomson's argument, (c) explain Benacerref's reply, and (d) give one reason for thinking the lamp is physically impossible even if it is logically possible."

A student wrote the following:

Thomson's lamp starts off at t = 0. It's switched on at t = 1/2, off at t = 3/4, on at t = 7/8, and so on, with each operation taking half as long as the previous one. By t = 1, infinitely many operations have been completed.

Thomson's argument is that the lamp can't be on at t = 1, because if it were on, then some operation must have turned it on and left it on all the way to t = 1, but every 'on' operation is immediately followed by an 'off' operation, so no operation left it on all the way to t = 1. The same goes for off. So the setup leads to a contradiction, and Thomson concluded that the lamp's state at t = 1 is indeterminate.

Benacerraf's reply is that there's no contradiction. The lamp's state at t = 1 is just the limit of the states before t = 1, and since the states keep oscillating, that limit doesn't exist, so the lamp simply has no state at t = 1. So the supertask is logically possible. It just doesn't fix the state at the limit.

On the physical side, the lamp is impossible because the switch would have to move faster and faster, and eventually it would have to be moving faster than light. So even if the supertask is logically possible, it can't be physically realized.

Can you grade this for me and tell me, point by point, what's right, what's wrong, and what's missing? I want to know what grade you'd give and the specific comments that justify it.
