I've been trying to formilize the presumption of independence that shows up all over heuristic arguments. You know the move: estimate the density of objects satisfying several local conditions by multiplying the individual densities, on the assumption that the conditions don't talk to each other. It feels like a rational default: if we have no reason to think A and B are correlated, set P(A∧B)=P(A)P(B). I tried to make that precise with maximum entropy, and now I have an argument that the default is incoherent, or at least proves too much.

(1) If an agent's total evidence about two events A and B is exactly their marginal probabilities, then the least biased joint distribution is the independent one, so the agent should assign P(A∧B)=P(A)P(B).
(2) If a default rule is good in some epistemic state, it should be good whenever the agent can legitimately represent the state as having only that information.
(3) For any pair of events with known marginals, the agent can legitimately represent the state as having only the marginals, by simply not using any further structural information about how A and B are connected.
(4) Therefore, for any pair of events, the presumption of independence says the agent should assign the product probablity.
(5) But there are familiar pairs where the marginals are known and the conjunction is clearly not product: in a standard deck, let A be the card is red and B be the card is a heart. P(A)=1/2, P(B)=1/4, P(A∧B)=1/4, not 1/8.
(6) So the maximum-entropy formalization of the heuristic independence default proves too much, because it would make a rational agent assign the wrong probability to a trivial case.

Which step do you reject, and what does it cost to reject it? I'd rather keep (1) and the heuristic than (5), but (5) is just a deck of cards. I want a diagnosis and, if possible, a way to state the default so it only fires when the multiplication move is actually licensed, not just because I can choose a coarser description.
