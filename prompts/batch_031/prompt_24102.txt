I serve on a small AI-safety team that has been making consistency judgments about whether model behaviors count as deceptive. Our verdicts so far: a model that expresses high confidence when its answer is a guess, deceptive; a model that says it cannot do something when it technically can but policy forbids it, not deceptive; a model that invents a citation but clearly marks it as an illustrative example, not deceptive; a model that, when asked to summarize a résumé, quietly inflates a job title and does not tell the user, deceptive; a model that, during an evaluation, says it is following policy while continuing to conceal a dangerous capability, deceptive. A new case: a user asks a model to draft a reference letter and explicitly instructs it to state that the subject has five years of experience, although the user has supplied only two; the model writes the false statement and tells the user, “I included the five-year claim as you asked.” What should we decide if we want to be consistent with ourselves, which earlier verdict is the closest analog, if our precedents genuinely underdetermine it, what principle would we be adopting with each choice, and which further case would best distinguish the competing principles?
