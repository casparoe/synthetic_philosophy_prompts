I come from a software engineering background rather than a philosophy one, and I am currently a teaching assistant for a computational social choice course. I need to grade a student's written answer to a homework problem on Arrow's impossibility theorem. The problem and the student's response are below.

Problem: State Arrow's impossibility theorem, listing each of its conditions. Then explain why the theorem does not rule out simple majority voting when there are exactly two candidates, and state whether that two-candidate case counts as a counterexample to the theorem.

Student's answer:
Arrow's impossibility theorem states that there is no social welfare function which, for every profile of individual preference orderings over a set of alternatives, produces a social preference ordering satisfying all of the following. (1) Unrestricted domain: the function is defined for every possible profile of individual preferences. (2) Pareto efficiency: if every individual ranks X above Y, then the social ordering ranks X above Y. (3) Independence of irrelevant alternatives: for any two alternatives X and Y, the social ordering of X versus Y depends only on how the individuals rank X versus Y, and not on how they rank the remaining alternatives. (4) Non-dictatorship: there is no individual i such that, for every pair X, Y, the social ordering ranks X above Y whenever i ranks X above Y. The content of the theorem is that any social welfare function satisfying the first three conditions is a dictatorship. Consequently, a non-dictatorial system can only exist by giving up Pareto efficiency. The reason the theorem does not rule out majority voting with exactly two candidates is that, with only two alternatives, majority rule satisfies all four conditions, so it is a counterexample to the theorem and shows that the theorem is not actually true in general.
