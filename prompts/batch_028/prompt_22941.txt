"In the philosophy of biology, distinguish the etiological account of biological function from the causal-role account. State what is sometimes called the 'new use' problem, and explain which of the two accounts it is meant to challenge and why. Finally, which account, if either, has an advantage when it comes to explaining malfunction, and why?"

The student wrote:

"The etiological account, developed by Wright (1973) and elaborated by Millikan in her 'selected effects' theory, holds that a trait's function is the effect it produced in the past on which natural selection acted, bringing the trait about. Function is thus fixed by a trait's evolutionary history. The causal-role account, associated with Cummins (1975), holds that a trait's function is the causal role it currently plays in a larger system, so that function is fixed by present contribution rather than by history.

The 'new use' problem arises when a trait is co-opted for a new use before selection has had time to act on that new use. A standard example is feathers, which were initially selected for thermoregulation and only later used in flight: the trait's new function does not yet match its etiological history, so the account cannot straightforwardly assign it a proper function for the new use. This is a challenge for both approaches, since it shows that a trait's current role and its selected history can come apart.

On malfunction, the etiological account has a clear advantage. Because it distinguishes a trait's proper function (what it was selected for) from what it currently does, a trait can be said to malfunction when it fails to perform its proper function. The causal-role account, by contrast, ties function to what the trait actually does now, so a trait that is not currently playing its role simply does not have that function to begin with; the account therefore cannot explain malfunction at all."
