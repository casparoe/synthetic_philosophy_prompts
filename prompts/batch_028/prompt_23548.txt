In a short essay (about 800 words), do the following. (1) Reconstruct the Lucas–Penrose argument, which purports to use Gödel's first incompleteness theorem to show that the human mind is not a finite mechanism. STUDENT SUBMISSION:
The Lucas–Penrose argument begins with Gödel's first incompleteness theorem. For any consistent, effectively axiomatized formal system S that is strong enough to express basic arithmetic, there is a sentence G_S such that S neither proves G_S nor proves its negation. G_S is constructed so that it effectively asserts its own unprovability in S. If S is consistent, then G_S is true: for if G_S were false, it would be provable in S, which would make S inconsistent. So G_S is a true arithmetical statement that S cannot prove.

Now suppose, for the sake of argument, that the human mind is a finite mechanism — that is, that there is some formal system S that completely captures what the mathematician can know to be true. The mathematician, being a normal human, can inspect S and see that it is consistent. Given that S is consistent, the mathematician can see that G_S is true. But S cannot prove G_S. So the mathematician knows a true arithmetical statement that S does not prove. This contradicts the supposition that S completely captures the mathematician's knowledge. Therefore, no single formal system captures the mathematician's knowledge, and the mind is not a finite mechanism.

I think the argument is largely sound, but it rests on a load-bearing assumption that is easy to overlook. The argument requires that the mathematician is at least consistent — that she does not, at the same time, take both a statement and its negation to be true. If the mathematician were inconsistent, the whole construction collapses, because the Gödel sentence would no longer be guaranteed to be true. Lucas and Penrose assume, plausibly, that the working mathematician is consistent in the relevant sense.

That said, I think the argument establishes more than it is usually credited for. It shows not merely that the mind is not captured by any single fixed formal system, but that the mind is not computable at all. For if the mind were computable, there would be a Turing machine that, given any arithmetical statement, decided whether the mathematician would judge it true; and that Turing machine would correspond to a fixed formal system, which the argument has already ruled out. So the conclusion that the mind is non-computable follows directly.
