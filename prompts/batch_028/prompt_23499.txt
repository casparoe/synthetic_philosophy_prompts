Student's answer:
"(a) Since N is an elementary submodel of M and M ⊨ ZFC, every sentence of ZFC is true in N exactly when it is true in M, so N ⊨ ZFC. N is, from the external point of view, a countable structure, so any collection of elements of N is externally countable. In particular, R^N = {x ∈ N : N ⊨ 'x ⊆ ω'} is externally a countable set: enumerating the elements of N gives an enumeration of R^N, and hence a bijection f: ω → R^N exists in the metatheory.

(b) The sentence 'there is no bijection between ω and P(ω)' is true in N because it is a theorem of ZFC and N ⊨ ZFC. But the external bijection f is not an element of N, so N simply does not 'see' it: the quantifier over functions in N ranges only over functions that are elements of N, and f is not among them. So N correctly believes Cantor's theorem, and the metatheory correctly sees a bijection; the two statements quantify over different domains, and there is no contradiction.

The reason f cannot be an element of N is that N's natural numbers are nonstandard. Since N is a countable model, its ω contains nonstandard elements, and f — which must list all of R^N — would have to be a sequence of nonstandard length, which N cannot internalize. The lesson of the paradox, then, is that countability is relative: a set can be countable in N and uncountable in the metatheory, and 'uncountable' has no model-independent meaning."
