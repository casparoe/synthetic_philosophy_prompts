I've been writing a piece on the supertask problem for a science magazine, and I ran into a disagreement at a recent philosophy conference that I couldn't resolve. Two philosophers—let's call them A and B—got into it over whether the "undefined state" objection to Thomson's lamp is a genuine argument against the coherence of supertasks, or a confusion between "the description doesn't tell us" and "there's no fact of the matter."

A's position: the lamp's state at t=1 is well-defined. The "undefined state" objection is a confusion. Any real lamp has a state at t=1, determined by the physical process—the filament's thermal time constant, the finite propagation speed of the electrical signal, the inertia of the switch mechanism. The idealized lamp is a fiction, but the question is still meaningful; the physical world would settle it. B's position: the "undefined state" objection is a genuine argument. The description of the supertask underdetermines the state at t=1. There is no fact of the matter about the lamp's state at t=1, because the description doesn't settle it. The question "is the lamp on or off at t=1?" is like asking "what is the value of the function at the discontinuity"—it's a question the description leaves open, and the thought experiment is incoherent.

The exchange went like this. A: but the thought experiment is meant to be an idealization. Idealizations underdetermine details all the time. We don't say the idealized pendulum has no period just because the description doesn't specify air resistance; the period is well-defined as the limit as the drag coefficient goes to zero. B: but the pendulum's period is well-defined because the relevant quantities converge. The lamp's on/off sequence does not converge as t approaches 1 from below; there is no limit to take. A: but we can stipulate a limit rule. Just as in certain mathematical idealizations we stipulate that the value at a limit point is defined by a rule, we can stipulate a rule for the lamp's state at t=1. The stipulation is arbitrary, but that doesn't make the question meaningless. B: but an arbitrary stipulation doesn't answer the question. The question is whether there is a fact of the matter, not whether we can impose one. If the stipulation is arbitrary, then the thought experiment is underdetermined, and the question has no answer. A: but underdetermination doesn't imply incoherence. Many thought experiments are underdetermined, and we still find them meaningful. B: the underdetermination here is not a missing detail that the physical world would fill in. It is a fundamental indeterminacy in the description itself. There is no fact of the matter.
