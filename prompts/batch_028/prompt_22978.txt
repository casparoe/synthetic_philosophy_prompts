I am writing a novel in which a logician walks a skeptical friend through the resolution of Skolem's paradox, and I want the technical core of that scene to be airtight. My account of the resolution runs as follows, and it strikes me as self-contradictory. Let M be a countable model of ZF. The standard explanation says that M's powerset of the naturals, P^M(ω), is countable from the outside, so there is a bijection f between the true ω and P^M(ω) that is not itself an element of M. But f is merely a set of ordered pairs, and every ordered pair in f is an element of M, since both coordinates of each pair already lie in M. If M contains each of the ordered pairs that make up f, why does it not contain f? A structure that has all the pairs of a relation surely has the relation.
