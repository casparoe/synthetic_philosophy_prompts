The question I asked was: "Explain the relationship between dialetheism and paraconsistent logic. In particular: (a) what counts as a paraconsistent logic, (b) why would a dialetheist need one, and (c) does using a paraconsistent logic commit you to believing that some contradictions are true?"

The student's answer: "A paraconsistent logic is a logic that rejects the principle of explosion (ex contradictione quodlibet), the rule that from P and not-P you may infer any Q. So in a paraconsistent logic an inconsistent set of premises, one containing both P and not-P, doesn't entail every possible conclusion. The motivation comes from paradoxes like the Liar, the sentence that says of itself that its false, which looks like it's both true and false. Dialetheists such as Graham Priest hold that this is a genuine true contradiction, a dialetheion, rather than a sign that our logic or language is broken. The reason a dialetheist needs a paraconsistent logic is that if there really is a true contradiction, then in an explosive classical logic the theory goes trivial: since the Liar is both true and false, explosion lets you derive anything, so every sentence ends up true and the logic is useless. A paraconsistent logic blocks this by not letting a contradiction explode into everything. One thing to note is that using a paraconsistent logic is basically the same thing as being a dialetheist, since the whole point of paraconsistent logic is to accommodate true contradictions like the Liar. The good news is that most of our standard reasoning carries over; in particular reductio ad absurdum still works, so if assuming A lets you derive a contradiction you can still conclude not-A."
