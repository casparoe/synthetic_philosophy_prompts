The set was on Aumann's agreement theorem. Heres the question as I wrote it:

> Two agents, A and B, share a common prior over a finite state space. A's information partition refines B's (every cell of A's partition lies inside a cell of B's). For some event E, A's posterior is 0.4 and B's posterior is 0.7, and each agent knows the other's posterior.
> (a) Does Aumann's agreement theorem imply that A and B's posteriors must be equal? Justify.
> (b) If A and B repeatedly announce their current posteriors to each other, do they eventually agree? Which result bears on this?

And the answer I got back:

> (a) No. The theorem only applies when the agents' posteriors are common knowledge, and here they're only mutual knowledge. Since A's partition refines B's, A knows which of B's cells she's in, so A knows B's posterior; but B doesn't know which of A's cells she's in, so B doesn't know A's posterior — it was only told to her, and the fact that B was told doesn't make it common knowledge. So the theorem's hypothesis fails and the posteriors can differ.
> (b) Yes. Geanakoplos and Polemarchakis proved that in finite state spaces the dialogue process ends with the posteriors being common knowledge, and then Aumann's theorem forces agreement. For the record, the proof works by noting that the event X that the posteriors are (x, y) is a union of cells of the finest common coarsening, so if X is common knowledge then p(E)·p(X) = x·p(X) and p(E)·p(X) = y·p(X), hence x = y = p(E). Also, Monderer and Samet showed that if the posteriors are common p-belief instead of common knowledge, they must still be equal, so the conclusion is robust to weakening the epistemic condition.
