The question was: "Explain the finkish counterexample to the simple conditional analysis of dispositions, say how Lewis's revised conditional analysis is supposed to handle it, and explain how finkish cases differ from masked cases." Here's one submission:

"The finkish case goes like this: a glass is fragile at time t, but there is a fink in the room who, if he sees the glass is about to be dropped, will instantly remove its fragility. So the glass is fragile at t, but if it were dropped it wouldn't shatter, because the fink would have removed the fragility before the drop. The simple analysis says x is fragile iff x would shatter if struck, so the conditional comes out false while the disposition is true, and the analysis breaks. Lewis came up with this case to show that dispositions aren't just conditionals.

Lewis's revised analysis fixes it by adding a requirement about the causal basis: x is fragile at t iff, if x were struck at some later time t*, x would shatter and x would still have the relevant causal basis (its molecular structure) at t*. In the fink case the basis is gone by t*, so the conditional comes out false, which is what we want.

As for masks, they're basically the same thing. A mask is just a case where the disposition is lost when you try to test it, like putting the fragile glass in a lead-lined box, so the box masks the fragility and the glass isn't fragile anymore. The difference between finks and masks is only who does the removing: in a fink case the stimulus itself does the removing, and in a mask case some other factor does it."
