QUESTION: "Explain the multiple realizability objection to type identity theory. Does it also defeat token identity theory? And is multiple realizability an argument against physicalism as a whole, or only against a specific version of it? Explain."

STUDENT ANSWER:
"The multiple realizability argument says that the same mental state, like being in pain, can be realized by different physical states in different organisms. Humans get pain from C-fiber firing, an octopus would get it from its distributed nervous system, and a sufficiently advanced alien or robot could get it from silicon. This is a problem for type identity theory, because type identity theory says that pain is identical to C-fiber firing, full stop. If pain just is C-fiber firing, then anything that isn't made of C-fibers can't be in pain, which seems obviously wrong. So multiple realizability shows that type identity theory is false, at least as usually stated.

Token identity theory is basically the same idea but applied to individual cases instead of whole types, so it runs into the same problem. If each particular instance of pain is identical to a particular instance of C-fiber firing, then we still can't make sense of an octopus or an alien being in pain, because they don't have C-fibers. So I think multiple realizability defeats token identity theory too.

And honestly I think multiple realizability is an argument against physicalism more generally, not just against type identity. If the same mental state can be hooked up to all these totally different physical bases, then there's no single physical property that mental states really are, which means mental states aren't really physical in the first place. So I'd say multiple realizability is a problem for physicalism as a whole."
