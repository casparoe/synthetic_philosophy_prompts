I get the setup — the red-ball case where you're offered a bet that pays off if the ball is red and a bet that pays off if its white, each priced at exactly its fair value given the urn has way more red balls than white, and if you take both you end up no better off than if you hadnt bet at all. But I don't see how this is supposed to be a problem for anyone with probabilistic credences. It seems like the pump only shows that accepting fair bets is a bad strategy, which is a practical point, not a coherence one. Am I missing some subtlety about what the betting interpretation of credence is supposed to commit me to, or about what diachronic rationality is actually supposed to be a constraint on?
