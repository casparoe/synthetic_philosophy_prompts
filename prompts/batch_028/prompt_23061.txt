I'm working through Solomonoff induction and I keep running into a point I don't fully understand. The Solomonoff prior assigns each hypothesis a weight roughly proportional to 2^(-K), where K is the Kolmogorov complexity of the shortest program that generates the hypothesis. But K is only defined up to an additive constant that depends on which universal machine you use as the reference (the invariance theorem). Translating that into the prior, the weights for a given hypothesis can differ by a multiplicative factor of up to 2^c, where c is that constant. If c can be large, the prior seems to be quite language-dependent. How does Solomonoff induction get to be "universal" despite this? I know the standard answer is that the likelihood term dominates as the sequence of observations grows, but I want a more precise account: is there a clean bound on how many observations it takes before the constant factor is effectively washed out, and does the choice of reference machine affect the transient behavior of the posterior in any nontrivial way?
