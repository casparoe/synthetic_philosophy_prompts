If the downward Löwenheim-Skolem theorem guarantees that any consistent first-order theory with an infinite model has a countable model, then inside that model there are sets—most prominently, the model's interpretation of the power set of the natural numbers—that satisfy the internal formal definition of being uncountable, since no function definable within the model maps them onto ω. Yet because the entire domain of the model is countable from the metatheoretic perspective, there demonstrably exists, outside the model, a bijection between those very sets and ω; the function is simply not an element of the model. This seems to generate a direct contradiction: the model rigorously asserts the non-existence of a correspondence that we can explicitly construct.

Given this, shouldn't we conclude that "uncountability" is not an intrinsic, mind-independent property of sets but rather an indexical feature—true relative to one model's available functions and false relative to another's, much like being the tallest person in a room? In particular, if one takes structuralist worries seriously and denies that there is any privileged "outside" standpoint from which to adjudicate between models—as Benacerraf's identification problem might suggest—doesn't Skolem's paradox become a genuine reductio of the claim that first-order ZFC describes a unique, objective set-theoretic universe? And if that inference is blocked, what exactly prevents the existence of a countable model from undermining the objectivity of cardinal arithmetic?
