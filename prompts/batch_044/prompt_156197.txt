Hey all, I've been arguing with my study group about whether 'Western values' is even a coherent category, and I think I built a reductio that proves too much—maybe it blows up every cultural concept I actually care about. The framing I'm using is that people treat 'Western values' like a forecasting reference class: they assign societies to the cluster and then read off base rates for democracy, secularism, etc. But here's the argument that seems to show the class is empty or useless:

(1) If 'Western values' is a meaningful category in argument, then for any value V in the set there's a determinate fact about whether V belongs.
(2) Take any candidate—secular governance, gender equality, market capitalism, free expression. For each one there's serious disagreeement: some scholars call it Western-distinctive, others point to Japan, India, or pre-modern Islamic societies and say it's not.
(3) So for every proposed member V, there's reasonable disagreement about membership.
(4) If every member is contested, then there's no determinate fact about what the set contains.
(5) Therefore 'Western values' doesn't refer to any actual set.
(6) But the same reasoning applies to 'Asian values,' 'Enlightenment ideals,' or even 'liberal democracy'—each has contested boundaries.
(7) So either we accept that all these categories are empty, which makes social science and forecasting impossible, or we reject (1) and allow fuzzy, contested borders.
(8) But if we reject (1) and allow fuzzy borders, then anyone can smuggle in whatever they like—call it Western when convenient, exclude it when not. So the phrase becomes an unfalsifiable rhetorical device.
(9) Therefore either the phrase is meaningless, or it's so flexible it can justify anything.

I feel like there's a hidden slide between (3) and (4)—maybe an epistemic-to-ontic leap?—and I really don't want to end up saying 'Asian values' is incoherent too. If I'm forced to choose, I'd rather keep (1) and bite (4), but then I'm not sure the argument survives. Which step should I reject, and what's the actual cost?
