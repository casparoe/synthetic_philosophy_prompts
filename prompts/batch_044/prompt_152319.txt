hey, i'm working through whether culture can be a cause in the Weberian sense and my study partner built this chain that now sounds like it proves too much. here's the argument:

(1) Weber claims the Protestant work ethic was a causal factor in capitalism's rise, not just an ideological reflection of it.
(2) His mechanism is elective affinity -- the values and the economic form fit together and reinforce one another.
(3) But affinity is symmetric: if A and B have an elective affinity, either one can select for the other.
(4) So Weber's mechanism doesn't specify causal direction; it only describes stable co-occuring with mutual reinforcement.
(5) Therefore he hasn't shown culture caused economy; he's shown they co-varied.
(6) Now generalize: if we allow culture-to-economy causation whenever there's elective affinity, then for any economic system E we can point to some present values C and claim C caused E.
(7) That makes cultural explanation unfalsifiable, since there's always some value set with affinity to the present economic form.
(8) So either Weber is wrong that culture can be an independant cause, or cultural explanation collapses into tautology.
(9) But if we reject (1) and deny culture causes economy, we're left with pure materialism, which Weber explicitly argued against.
(10) So we're stuck: keep Weber and accept unfalsifiable culturalism, or reject him and accept the materialism he wanted to avoid.

where does this go wrong? i want to keep (1) if possible, but i'm worried about (6)-(7). is there a way to block the generalization without giving up on culture being causal? also, does the symmetry in (3) actually hold for elective affinity, or am i misreading Weber?
