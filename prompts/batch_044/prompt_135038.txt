After a long argument with a friend about decision theory, I want to compare updateless decision theory and evidential decision theory in a deliberately contrived case meant to separate logical correlation from causal isolation. Imagine an agent whose decision algorithm is executed in two causally isolated simulations: Simulation A is a one-shot prisoner's dilemma against an exact copy running identical source code; Simulation B is a one-shot stag hunt against a copy whose source code is identical except for one parameter that shifts how logical correlations are weighted relative to causal ones. The agent knows the architecture but not which simulation it occupies. UDT selects the action that maximizes expected utility across worlds by evaluating the logical outputs of its algorithm without conditioning on its actual choice, while EDT conditions on the action as evidence about the world. Given that the core algorithm is shared but the correlation structure differs between A and B, does UDT recommend the same action in both simulations—treating logical identity as overriding the architectural difference—or can the parameter shift in B genuinely alter the logical dependency that UDT tracks? Conversely, does EDT avoid this rigidity only by generating spurious evidential links between A and B, since conditioning on defection in A might update beliefs about the shared parameter that also governs B? Which theory handles the separation between logical correlation and causal isolation more coherently, and where exactly does each recommendation depend on the agent's self-locating uncertainty?
