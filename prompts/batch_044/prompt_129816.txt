I am building a conceptual taxonomy for embedded agency and keep encountering a configuration I can describe concretely but cannot name precisely. The pattern involves an agent that is physically embedded in the environment it represents, and that uses a working model of its own decision procedure as an input to that very procedure. The agent updates this self-model based on the actions it actually takes. In certain architectures, however, the feedback loop fails to converge and instead oscillates between two locally coherent self-descriptions. Under self-model M, the agent applies decision rule R, producing behavior B; feeding B back through the update mechanism yields self-model M', which justifies a different rule R'; applying R' produces behavior B', which updates back to M, restoring R. Each transition is individually rational, computationally well-defined, and free of logical contradiction—there is no liar-paradox-style breakdown and no infinite regress that halts computation—yet the agent never stabilizes. This is not merely unstable prediction; it is reflexive instability driven by the content of the self-model itself.
