I was discussing the mental causation problem with a colleague last week, and I found myself defending a particular version of non-reductive physicalism that I think is underappreciated in the standard literature. The causal exclusion argument — the one that says if every physical effect has a sufficient physical cause, then mental properties are causally redundant — only seems compelling, on my view, if one tacitly assumes a productive model of causation: that causes must be part of a minimal sufficient set that literally produces the effect. But if we instead adopt a constraint-based framework, in which mental properties function like boundary conditions or selection filters that determine which physically sufficient trajectories are actually realized — without being physical forces themselves — then mental properties are causally relevant in a counterfactual-dependency sense without competing with physics for efficacy. I hold that this distinction dissolves the exclusion problem rather than merely evading it.
