A study partner in my decision-theory reading group summarized program equilibrium like this: in program equilibrium, rational agents submit computer programs rather than selecting actions directly, and each program can inspect the others’ source code before execution. Because of this transparency, agents can cooperate in one-shot prisoner’s dilemmas without repetition or reputation—my program verifies that yours cooperates exactly when mine does, so cooperation becomes rational. This essentially solves Newcomb’s problem for artificial agents: the predictor is not an external oracle but just another program inspecting my code, which means the correlation between my choice and the payoff is internal and causal rather than mysterious. Unlike correlated equilibrium, which requires an external correlating device or shared randomness, program equilibrium generates coordination purely from mutual transparency. The only serious limitation is practical noise—hidden internal states or execution errors break the inspection—so in principle the framework dissolves the old tension between causal and evidential decision theories.
