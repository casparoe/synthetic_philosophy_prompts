Is there a name for this pattern I keep seeing in bbylaws and small constitutions? There's a rule that says any change to these rules needs a two-thirds vote, and there's also an emergency clause letting the chair suspend any procedural rule for 48 hours if there's deadlok. So the chair suspends the two-thirds rule, gets a simple-majority vote to replace it with a simple-majority rule, then the suspension expires. Now the new rule is in place, and it retreively makes the vote that created it valid — but only if you accept that the old two-thirds rule was still binding at the exact moment it was suspended. It feels like a loop, but it's not exactly the classic self-amendment paradoxx (Ross's thing?) because the change doesn't happen inside the clause being changed; it happens through a side-door exception that then deletes the door behind it. Is there an established term for this specific bootstrap via temporary exception? If not, can you name and define it precisely and say where its edges are — like, does it require the exception mechanism to be genuinely temporary, or can it work with a permanent but narrow exception? And how is it different from just a coup with paperwork?
