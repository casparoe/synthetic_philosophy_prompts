I've bought into what i'm calling the competence-first inversion: Darwin's evolutionary story shows that adaptive problem-solving gets built by selection long before any agent has explicit reasons for it, and Turing's argument about machine intelligence shows that you can have reliable, flexible behavior without anything like an inner mental life. So my position is that comprehension is basically a post-hoc narrative we layer onto mechanisms that already work—teh mechanisms don't need a user manual written inside them—and that if an LLM consistently solves novel logical or causal puzzles—things it wasn't explicitly trained on—then it's reasoning in the only sense that actually matters. Asking whether it 'really understands' is just a leftover Cartesian hangup, like asking whether natural selection 'understands' survival. What would actually count against this? I want the evidence and arguments that should move me, sorted from fatal to merely awkward, including specific model failures or successes that are genuinely relevant, and an honest check on whether defenders of this view have qualified it into unfalsifiability—e.g., every failure gets dismissed as 'just pattern matching' while every success gets claimed as reasoning. Which defeaters would a committed inversion-theorist concede, and which would they brush off? And is there any result in cognitive science or AI development that could genuinely break the inversion, or has it become immune to everything?
