First, the brain is not relocated in a single surgical event but is replaced gradually, neuron by neuron, with synthetic analogues that preserve action-potential dynamics and network connectivity but are manufactured off-site and lack the original tissue's biochemical continuity. Second, at the exact midpoint of this replacement—when fifty percent of the tissue is synthetic—an exact functional backup of the current neural state is uploaded to a remote server and then kept dormant, while the embodied brain continues its gradual replacement until it is one hundred percent synthetic. The scenario should be set in a realistic near-future clinical or research context, described in one paragraph, and should not invoke exotic physics or devices beyond the synthetic substrates and the server backup. Then isolate the feature of the case that does the actual philosophical work—gradualism versus discrete transplantation, substrate independence versus biochemical continuity, or the duplication problem created by the backup—and explain what happens to the analysis if that feature is removed. The answer should not include bibliographies, reading lists, or citations, and should be written in American English, in a formal and polished register.
