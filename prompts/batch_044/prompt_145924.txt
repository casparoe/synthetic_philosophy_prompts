I've been chewing on Dennett's four-layer picture of minds — the Darwinian ones with hard-wired instincts, the Skinnerian ones that learn by conditioning, the Popperian ones that can run internal simulations and kill bad hypotheses, and the Gregorian ones that borrow tools and culture from other minds. It's a neat taxonomy, but I keep seeing a specific argumentative move in AI and animal-cognition threads that doesn't map cleanly onto any fallacy I know, and I'm wondering if there's a name for it.

The pattern goes like this: someone claims that an LLM or some animal doesn't really understand X because it hasn't undergone embodied trial-and-error — the Skinnerian objection. If you point out that the system can generate counterfactuals and reject wrong ones internally, which looks like the Popperian layer, the critic doesn't drop the argument; they piviot to saying that without Gregorian cultural scafolding — shared language, accumulated tools, social transmission — that internal testing is just empty computation. What's strange is that these two objections come from totally different frameworks about what makes cognition real: one cares about the history of behavioral change, the other cares about the source of representational content. Yet they're treated like the same doubt, just sharpened, rather than like incompatible yardsticks being swapped to keep the denial intact. I tried calling it "cross-tier denial" — rotating through Dennett's levels until one sticks — but I'm not sure that captures the cases where the rotation is actually legitimate, like when a system genuinely fails at every tier.

So: does this configuration have an established concept in philosophy of mind or cognitive science? How exactly should I draw the line between it and a plain category mistake, or from the motte-and-bailey pattern where people retreat to a weaker claim? And if there's no name, does "cross-tier denial" work, or is there a sharper carving that distinguishes the illegitimate slide from honest multi-level evaluation?
