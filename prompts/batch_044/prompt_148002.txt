For a graduate seminar in normative ethics—twelve students, seventy-five minutes—design a structured role-play and decision game that lets participants feel consequentialist cluelessness as something deeper than ordinary risk: specifically, as the collapse of a stable comparison class across radically different futures. Set the scenario in a fictional intergovernmental body choosing among three long-range infrastructure policies (a carbon-capture network, a solar-radiation management treaty, and a decentralized adaptation fund), each with well-characterized local effects but with distant consequences that depend on hidden technological lock-in, shifting social norms about harm, and feedback loops that alter the very metrics used to evaluate success. Assign four roles—Policy Advisor, Affected Community Representative, Long-Range Forecaster, and Normative Skeptic—with asymmetric information rules: Advisors see cost projections, Representatives see present-day harm distributions, Forecasters see probabilistic scenarios that change after each round, and Skeptics may veto any comparison that assumes a stable value framework. Run three rounds: in Round 1, groups rank outcomes using expected-utility reasoning; in Round 2, they may spend limited research tokens to gather more data, but each token spent triggers a hidden rule that shifts either the technological trajectory or the normative baseline; in Round 3, they must vote without recalculating, using only ordinal preferences, and discover that their earlier rankings are incommensurable with the new framework. Use symbolic stakes only—ranking points and a shared narrative legacy score—not real money. In the debrief, map Round 1 onto probability ignorance, Round 2 onto value ignorance induced by information-seeking itself, and Round 3 onto structural ignorance about the comparison class. Be explicit about which feature the game cannot reproduce—the actual temporal and spatial scale of longtermist decision-making—and predict the predictable failure mode: participants will try to game the hidden rules by hoarding tokens, which the facilitator should allow and then reveal as an instance of second-order cluelessness. Include a brief honest note on the activity's limits.
