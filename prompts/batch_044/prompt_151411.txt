here's the exam prompt we gave them:

Consider a ceramic vase with a brittle crystal lattice. It's permanently embedded in a smart-polymer matrix that detects micro-stress and instantly releases a binding agent, sealing any crack before it propagates, so the vase never actually shatters. Some philosophers call the polymer a fink for the vase's brittleness; others call it a mask. Explain the distinction between finkish dispositions and masked dispositions. Apply that distinction to the vase, using the interventionist idea that if removing the interfering factor reveals the disposition was intact all along, that's a mask, whereas if removing it reveals the disposition itself was eliminated, that's a fink. Then argue whether the vase is still brittle.

and here's the student answer (paraphrased from their handwriting):

Brittleness is the dispostion to shatter under stress. A fink is when the disposition is present but gets removed right at the moment of triggering, like Johnston's wire that conducts electricity but dies the instant you try to run current through it. A mask is when the manifestation is blocked but the underlying dispostion remains intact, like Martin's poison that's still toxic but gets neutralized by an antidote. So in the vase case, the polymer is a mask because it doesn't alter the ceramic's internal lattice; it's just an external blocker. But it's also a fink because the binding agent removes the crack, and the crack is part of what it means to be brittle. So it's both. The vase is still brittle because the internal structure hasn't changed — that's what the mask view cares about. The fink view would say it's not brittle since the polymer removes the dispostion, but that view doesn't apply here because the polymer is outside the vase. So yes, it's brittle.
