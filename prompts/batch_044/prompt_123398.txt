Exam question: Formalize the sorites paradox for the predicate 'heap' using the tolerance principle. Then apply the same logical structure to the predicate 'interpretively stable scientific theory,' defined incrementally: a theory is stable if its core claims remain coherent, and the addition or removal of any single auxiliary assumption never, by itself, undermines that coherence. Show why this yields a parallel paradox, and evaluate whether the three standard responses—denying one of the premises, accepting a sharp unknown boundary, or adopting a degree-based semantics—are equally available and equally plausible in the scientific case.

Student answer:
The paradox for heaps is: (1) 10,000 grains form a heap. (2) If n grains form a heap, then n–1 do. (3) So 1 grain forms a heap, which is false. The issue is principle (2), the tolerance principle. For scientific theories, let stability apply incrementally: (1') A mature theory with 500 auxiliary assumptions is interpretively stable. (2') If a theory with n auxiliaries is stable, then one with n–1 is stable, since losing one support never breaks coherence. Hence (3') A theory with zero auxiliaries is stable, which is false because coherence requires some supporting structure.

The best fix is to reject (2') by accepting a sharp boundary. There is an exact number of auxiliary assumptions—say, 42—below which stability collapses. We do not know this number, so our ignorance creates the illusion of vagueness. In science this works especially well, because coherence is in principle measurable, so there is a correct cutoff we simply have not calculated yet.

A second option is fuzzy logic, which assigns stability a real value between 0 and 1. This removes sharp boundaries entirely while preserving bivalence at each stage: any given theory is either somewhat stable or not. Because this handles both sand and science uniformly, it is the more elegant solution.
