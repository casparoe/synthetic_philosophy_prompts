Okay so I've been chewing on this weird corner of epistemic game theory. I think common knowledge of rationality can actually survive in models with genuinely bounded reasoners, but only if there's this stuctured asymmetry: every agent correctly knows everyone else is capped at reasoning depth n, but each agent also falsly believes that the others think the cap is n+1, and that belief is itself common knowledge. Call it the staggered meta-belief ladder. Without that ladder, CKR either forces infinite ascent or collapses, so my position is that bounded rationality and CKR are compatible — but only by smuggling in a kind of self-deception about reasoning limits.

What would actually count against this? I want the defeaters mapped out and sorted — fatal versus just awkward. Which formal results or belief-revision dynamics would kill the ladder? What predictions does this view make that standard bounded-rationality models without CKR don't make?
