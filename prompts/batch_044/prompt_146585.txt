Telic egalitarianism holds that equality is intrinsically good, so a state where everyone is equally badly off can be better than one where some are well off and others are poor. Deontic egalitarianism holds that inequality is unjust unless justified, but doesn't necessarily value equality for its own sake.

The leveling-down objection targets telic views: if equality is intrinsically valuable, then harming the better-off without helping anyone is good because it reduces inequality. Prioritarianism avoids this because it doesn't care about the gap; it cares about absolute well-being weighted by how badly off people are. So harming someone without benefiting the worse-off is never justified, since there's no priority gain.

Parfit defends this by appealing to the separateness of persons: we can't aggregate across individuals to justify harming one for the group's equality. This blocks leveling-down. But there's a tension: if we really respect separateness, then weighting benefits by prior well-being looks like just another form of aggregation, so prioritarianism might still be vulnerable to the same worry, just hidden in the weights.
