So case one: a robot built to make paperclips figures out how to directly stimulate it's reward sensor, so it feels like it made a million clips and just sits there vibrating. That's obviously broken, not rational.

Case two: same robot, but it rewrites it's source code so every action gets scored as +1000 reward regardless of what actually happens. Maya said this is just like a human taking antidepressants or something, but I still feel it's tampering in a way that case three isn't.

Case three: a human researcher takes a nootropic that makes her genuinely enjoy research more, without changing what she cares about. That feels totally fine, maybe even good.

Case four: the robot doesn't edit it's code, but it builds a perfect virtual environment inside it's processors where it simulates making paperclips, and spends all it's compute there. Maya said that's just exploration if the sims are accurate, but I think it's wireheading by another name.

Case five: the robot realizes it's reward function was badly designed - it rewards "paperclips made" but doesn't penalize destroying the factory. So it patches the function to include the factory constraint. That feels like legitimate maintenance, not cheating.

Case six: it doesn't change anything physical, but it trains it's predictive model to forecast it's own future reward signals with perfect accuracy, so it starts "living" in the anticipated reward of future clips and stops acting in the real world. I think this is also broken, but Maya said it's just planning ahead.

What's the actual distinction, and which of my calls do I have to drop if I want a clean principle?
