I've been convinced lately that the frame problem is mostly a misdiagnosis. It's not that an agent can't figure out what changes and what doesn't—it's that representational systems have this thing I'm calling inertial framing, where they just carry over their ontology across state transitions unless something forces a rupture. So the 'problem' isn't missing knowledge, it's missing rupture-gates. If that's right, then throwing more retrieval context at an LLM won't solve it, and the enactivist 'no representations' move misses the point too—because even dynamical attractors have inertial dynamics that need gating. What would actually count against this? I want defeaters that aren't just 'LLMs still fail at long-horizon planning'—like, which formal results, which empirical findings in robotics or cognative science, which weird edge cases with non-obvious side effects, would break the idea? And which ones would defenders just absorb by tweaking the gate conditions? Rank them from fatal to merely awkward, and be honest: has this view been padded with enough qualifcations to be unfalsifiable, and if so, is that actually a problem for a framework of this kind?
