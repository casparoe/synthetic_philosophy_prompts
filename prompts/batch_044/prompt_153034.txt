Is there a name for this specific deadlock? Our forums charter has a clause saying "any clause, including this one, can be changed by a majority of admins." One admin proposed changing that clause to require unanimous consent. The vote went through by majority under the old rule. But then she argued that now the clause is replaced, so the vote should have been unanimous — except it wasn't, so maybe it's invalid? Another admin said you can't apply the new rule backwards, or no change could ever happen. The first one came back with "fine, then the old clause is still alive, which means my change is valid, which means the old clause is dead, which means..." They went in circles, and what's weird is both kept appealing to the charters own wording about how changes work. I know there are legal self-amendment paradoxes and that game Nomic, but this feels like a sharper version — it's not just changing a rule, it's whether the power that authorizes the change gets destroyed by using it. Does that exact pattern have a name? If not, can you define it and say exactly where it ends and ordinary circular reasoning begins?
