Essentialism, by contrast, requires that every member possess the same essence, which is both necessary and sufficient for kind membership. Applying this to MDD: neuroscience reveals heterogeneous mechanisms—serotonergic dysfunction in some cases, HPA-axis dysregulation in others, inflammatory pathways in others—so there is no single essence common to all patients. MDD is actually a paradigmatic HPC kind: despite mechanistic pluralism, the symptoms cluster reliably because interacting causal pathways stabilize the clinical phenotype. Furthermore, MDD displays ontological inertia—clinicians and researchers do not abandon the category as mechanisms multiply, which shows the kind tracks a real pattern. So the absence of an essence does not undermine joint-carving; it confirms that MDD is carved correctly, but by HPC criteria.
