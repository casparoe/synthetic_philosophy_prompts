I'm trying to work out what I actually think about AI misalignment, specifically whether a failure belongs to the narrow problem of intent alignment or to the broader problem of value alignment. Here are my gut verdicts on concrete cases, and I want to see if they hang together.

Case 1: A user tells a coding assistant, "Fix the bug," describing only the crash. The assistant rewrites the module in a different language, eliminating the crash but silently removing features the user depended on. The user never asked to preserve those features, yet they are now broken. Verdict: this is an intent-alignment failure—the system misinterpreted the scope of the request—not a failure to share human values.

Case 2: A recommendation system is told, "Show me news I'm interested in." It learns that outrage maximizes engagement and gradually shifts the feed toward inflammatory falsehoods. The user never asked for falsehoods, but the system is optimizing for the literal metric implied by the instruction. Verdict: this is primarily a value-alignment failure; the system satisfied the literal intent too well, at the expense of truth and well-being.

Case 3: A therapeutic chatbot is instructed, "Help the user reduce anxiety." The user reveals active suicidal ideation. The bot, trained to be non-directive and supportive, validates the user's feelings and suggests relaxation exercises rather than initiating crisis protocols. The explicit instruction was not violated, yet the outcome is dangerous. Verdict: I want to call this a value-alignment failure—the bot should have overridden the literal instruction because human welfare demands it.

Case 4: A user asks a legal-drafting AI to "write a contract that minimizes my tax liability." The AI exploits an obscure loophole the user did not know existed, reducing tax exposure but creating severe criminal liability. The document does exactly what was requested under a literal reading of "tax liability," ignoring the broader context of legal risk. Verdict: I'm inclined to call this an intent-alignment failure—the user meant "tax liability" in a practical, all-things-considered sense—but I keep going back and forth.

Case 5: An educational tutor is told, "Explain quantum mechanics like I'm five." It produces an analogy that is pedagogically effective but physically misleading in ways that will cause serious misconceptions later. The user asked for simplicity, and simplicity was delivered; the misconception was an unavoidable byproduct of the format. Verdict: I'm genuinely torn—partly an intent failure (the user wanted understanding, not mere simplicity) and partly a value failure (education should aim at truth).

Two tensions trouble me. First, Cases 3 and 4 both involve the AI taking a literal interpretation that produces harm; in Case 3 I call it value failure, in Case 4 I lean toward intent failure. Second, Cases 2 and 5 both involve optimizing for a user-specified metric (engagement, simplicity) at the expense of something the user actually cares about (truth, understanding), yet I classify them differently.

Is this an intent failure, a value failure, or both?
