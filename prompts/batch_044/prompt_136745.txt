I just finished a long, exhausting debate with a friend about whether program equilibrium collapses rational agency into pure mechanical determinism, and we ended up with a reductio that neither of us can cleanly disarm. Here is the chain we built. (1) In a program equilibrium, each agent submits a program that may inspect the source code of every other submitted program—including, in cases of mutual transparency, each agent’s own—before producing an action. (2) Once all programs are submitted, the joint outcome is fully determined by the deterministic interaction of the code; there is no residual moment of “choice” at execution time. (3) Therefore, in any interaction with full mutual transparency, the agents’ preferences over outcomes play no causal role in producing the result; only the syntactic and structural properties of the submitted code matter. (4) Now inject an opaque mediator: a third program that reads both agents’ code but is not itself readable by either agent, selecting a payoff allocation based solely on structural features it detects. Because the mediator is hidden, neither agent can condition on its behavior, yet the mediator’s presence means the outcome still depends entirely on code properties rather than on the agents’ values. (5) If preferences do not causally determine outcomes, then they cannot serve as normative reasons that justify those outcomes; justification requires that an agent’s values guide the selection. (6) But full mutual transparency, augmented by opaque institutional mediators, is precisely the formal ideal of rational deliberation—common knowledge of commitments plus enforcement mechanisms that ensure consistency—so the framework applies to rational strategic interaction in general. (7) Consequently, either rational choice is normatively empty mechanical execution, or we must deny that preferences ever genuinely guide selection in strategic settings. My friend insists we should reject (3) by relocating rational choice to the meta-level selection of which program to submit, but I worry that only pushes the problem back one layer: that meta-selection is itself just another program running in an environment with its own transparency conditions. Which step actually fails, and does repairing it require giving up the idea that rational agency can survive total code transparency, or is there a hidden distinction—between committing to a program and executing it—that dissolves the paradox without costing us the normative force of preference?
