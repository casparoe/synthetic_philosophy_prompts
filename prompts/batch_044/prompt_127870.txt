Question:
Standard possible-worlds semantics for epistemic logic validates closure under known entailment: if Kφ and K(φ → ψ) hold, then Kψ holds. This yields logical omniscience—agents are taken to know all tautologies and all logical consequences of their beliefs—which is implausible for bounded reasoners.

Three proposed remedies are often discussed:
(i) The syntactic restriction: replace semantic entailment with explicit derivability within a designated proof calculus; an agent knows ψ only if they possess an explicit derivation of ψ from φ.
(ii) The awareness-structure model (associated with Fagin and Halpern): the agent’s epistemic alternatives are restricted not only by what is true but by which propositions the agent is aware of; entailments involving propositions outside the awareness set do not generate knowledge.
(iii) The tractability-indexed worlds framework: accessibility between worlds is weighted by the computational resources required to traverse them; an agent knows ψ only if ψ is reachable within a fixed resource budget, even when ψ is a logical consequence of φ in the unrestricted model.

Compare these three approaches. In particular, evaluate whether (iii) genuinely resolves logical omniscience or merely relocates it to a meta-level concerning resource budgets, and discuss whether (i) and (ii) face parallel difficulties regarding the closure of knowledge about their own restrictive mechanisms.

Student’s answer:
Logical omniscience arises because in Kripke semantics for knowledge, if all worlds compatible with the agent’s information satisfy φ and also satisfy φ → ψ, they necessarily satisfy ψ. Hence the closure principle Kφ ∧ K(φ→ψ) → Kψ is valid, forcing agents to know all logical truths.

Approach (i) addresses this by demanding explicit proof. The agent knows ψ only if there exists a derivation of ψ from φ within a specific formal system. This blocks omniscience because derivational capacity is finite. Nevertheless, a meta-level concern arises: the agent must know which inference rules belong to the system, and if that meta-knowledge is also closed, omniscience re-emerges at the level of the calculus itself.

Approach (ii), developed by Fagin and Halpern, introduces awareness sets. The agent considers only those worlds and propositions falling within their awareness. Consequently, if ψ lies outside the awareness set, the agent cannot know it, even if it follows logically from φ. This differs from (i) because it is a semantic filter on worlds rather than a syntactic demand for proof. However, it faces a parallel meta-problem: the agent must be aware of their own awareness set, and closure over that awareness might restore omniscience regarding the boundaries of what they can conceive.

Approach (iii), tractability-indexed worlds, was originally proposed by Rantala in connection with impossible worlds. In this model, each world carries a computational-cost index, and epistemic accessibility is limited to worlds within the agent’s resource budget. Thus, even if ψ logically follows from φ, the derivation may exceed the budget, so Kψ fails. This genuinely avoids omniscience because the limitation is empirical—rooted in actual computational resources—rather than logical. Unlike (i) and (ii), there is no meta-level closure problem, since the budget is fixed externally and is not itself an object of logical knowledge within the model.

In conclusion, (i) and (ii) both suffer from reflexive closure difficulties about their own mechanisms, whereas (iii) escapes them by grounding epistemic access in contingent resource constraints.
