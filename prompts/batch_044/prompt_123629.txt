ok so i've been digging into IIT and keep hitting the same arguementative loop. the theory starts with this quantitative identity claim — consciousness just IS maximally integrated information, phi max, and we can measure it. then people build counterexamples: a huge XOR lattice, or even a blockchain arranged so every node causally depends on every other, ends up with enormous phi but nobody thinks it's sentient. the defenders don't abandon the metric; they say those systems fail the 'exclusion postulate' or lack the right 'mechanism' structure. but that structure is defined using the exact same integration calculus that was challenged. so the quantitative claim gets protected by an ontological filter that was calibrated on the intuitions the metric was supposed to replace. meanwhile people still cite the brain-measurement results as if the original identity survived unscathed. is there an established name for this two-step pattern — metric introduced as identity condition, then shielded from falsification by a substrate-definition that eats the counterexample? i know about ad hoc rescue and Lakatosian programmes, but this feels different because the shield isn't an extra law; it's baked into what counts as a system in the first place. does it have a label in philosphy of science, and if not how do you draw the line between this and ordinary conceptual sharpening?
