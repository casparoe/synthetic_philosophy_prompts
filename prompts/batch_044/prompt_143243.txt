The argument proves that in symmetric games with perfect information and no draws, the second player never has a winning strategy. If player two had one, player one could make an arbitary opening move and then adopt that same strategy. Because the rules are symmetric, the stolen strategy remains valid, and the extra initial move can only improve player one’s position. So player two can’t win. From this we can use iterated elimination via dominance in mixed strategies to conclude the first player must have the winning strategy in every such game.

In Hex the board is symmetric and there are no draws — one side must connect — so the argument goes through and the first player wins.

Chomp is also symmetric except for the poisoned bottom-left square, and since someone eventually takes it there are no draws either. So player one can make a dummy bite, steal player two’s strategy, and win. The poison square doesn’t break the symmetry because both players face the same board state after the dummy move.
