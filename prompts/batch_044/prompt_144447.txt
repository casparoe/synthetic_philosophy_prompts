After a long and somewhat frustrating argument with a friend about what mechanistic anomaly detection actually commits us to, I want to lay out my intuitions about specific cases and see whether they cohere into a principle or whether I need to give some up.

Consider these five scenarios, each involving a system that originally performs some task through a particular internal process, and then undergoes a change.

1. A chemical-process digital twin uses a first-principles thermodynamic model. We replace the solver with a neural network trained to reproduce the model's outputs within 0.1% on all historical operating points. The network's hidden layers have no physical interpretation. Verdict: this is an anomalous mechanism; the system is no longer running the same process, even though its predictions are unchanged.

2. In the same plant, we replace a physical pressure transducer with an equivalent unit from a different manufacturer, with the same calibration curve and the same failure modes. Verdict: not anomalous; the mechanism is unchanged.

3. A mechanistic interpretability study isolates a specific attention-head circuit in a language model that implements multi-step arithmetic reasoning. Researchers ablate one head and substitute a hand-coded lookup table that returns the exact same intermediate values for every arithmetic prompt in the test set. Verdict: I think the reasoning mechanism is disrupted—this should count as anomalous with respect to the circuit—though the overall input-output behavior is preserved.

4. A self-driving car's lane-keeping stack originally runs a classical pipeline: edge detection, Hough transform, geometric state estimation, PID control. Engineers replace the vision front-end with an end-to-end neural network that has been formally verified to match the original pipeline's outputs across the entire operational design domain. The control back-end remains identical. Verdict: here I feel pulled the other way. Despite the architectural replacement, I want to say the lane-keeping mechanism is still the same for safety-monitoring purposes, because the verified boundary conditions preserve the causal pathway from road state to steering command.

5. The tension case: a medical diagnostic system originally uses an explicit Bayesian network with nodes corresponding to diseases and symptoms. We replace it with a graph neural network that achieves identical accuracy, but its nodes are purely statistical clusters with no clinical interpretation. Meanwhile, in a separate system, we keep the Bayesian network structure intact but populate its conditional probability tables through expert elicitation rather than data learning, producing slightly different predictions on edge cases. Verdict: the neural-network replacement feels like a different mechanism and should be flagged, whereas the expert-elicited Bayesian network feels like the same mechanism with different parameters.

So my pattern seems to be: I care about whether an intermediate causal structure that explains the task is preserved, but I apply this inconsistently—strictly for the arithmetic circuit and the digital twin, leniently for the verified self-driving replacement, and with a distinction between structural and parametric change in the diagnosis case.

Is there a single principle—perhaps involving counterfactual invariance of explanatory intermediate variables under surgical intervention, or preservation of a task-relevant causal graph at a specific level of abstraction—that delivers all five verdicts without ad hoc adjustments? If not, which verdict should I overturn: the leniency toward the verified neural replacement, or the strictness about the arithmetic lookup table?

Also, please state precisely what your proposed principle (or the best competing pair) predicts for a case I haven't listed: a brain-computer interface that replaces a section of a patient's motor cortex with silicon chips that reproduce the original spike patterns and synaptic weights with perfect fidelity, but contain no biological neurons. Does that preserve the mechanism of voluntary movement?

Please be explicit about which of my verdicts your principle cannot accommodate, and motivate each clause of the principle by reference to the case that supports it.
