I'm auditing my commitments for a philosophy-of-language seminar paper on cognitive significance, and I'd like a consistency check before I present. My package is roughly: (a) Frege's puzzle shows that true identity statements can be genuinely informative despite shared reference; (b) I accept a mental-file model of modes of presentation, so co-referential terms correspond to distinct files for the same object; (c) the cognitive value of learning an identity is therefore reducible to the value of merging those two files; (d) if a thinker permanently lacks access to the link between files—say, due to a modular architecture—then for that thinker the corresponding identity carries zero cognitive value; (e) nevertheless, every true identity expresses a fact that could in principle be recognized as informative by some rational agent. Do these hang together? Specifically, does (d) contradict the universality implied in (e), and is there a hidden tension between (c)'s psychologization of cognitive value and the standard Fregean claim in (a) that informativeness belongs to sense rather than to a thinker's mental economy? Please rank the tensions by severity, say which commitment should give if any must, and flag any tensions that dissolve on closer inspection.
