Building on this, Löb’s theorem demonstrates that if such a system can represent the principle “if the system proves P, then P is true,” then the system actually proves P for every sentence P—so unless the system is already inconsistent, it collapses into contradiction. The article applies this directly to artificial intelligence: if an AI is designed with a “transparency condition” on belief—treating “I have derived X” as direct, unrevisable evidence for X—then by Löb’s result it can derive any conclusion whatsoever, including false ones. The author then extends this to defeasible, non-monotonic reasoning architectures, claiming that even there a self-trust axiom generates the same collapse. From this the article concludes that fully self-trusting reflective agents are logically impossible, which means any project aiming at artificial general intelligence must abandon genuine self-trust and therefore can never achieve full autonomous reasoning.
