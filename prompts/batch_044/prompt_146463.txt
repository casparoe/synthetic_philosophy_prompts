"Expressivism holds that a moral utterance such as 'Torture is wrong' does not report a fact but expresses a non-cognitive attitude—disapproval or condemnation—much as a wince expresses pain. This distinguishes it from descriptivism, which treats moral sentences as describing moral properties.

Frege observed that when a sentence is embedded in a larger construction—for example, in the conditional 'If torture is wrong, then we ought to ban it'—the embedded clause is not asserted on its own and therefore lacks assertoric force. Geach extended this observation to expressivism: if the meaning of 'torture is wrong' is fixed by the attitude it expresses, then in the embedded position, where no disapproval is actually expressed, the clause must have a different meaning. So the premise in a modus ponens inference uses one meaning, while the standalone assertion of the antecedent uses another.

Because the meanings diverge, the inference is invalid. From 'If torture is wrong, then we ought to ban it' together with 'Torture is wrong,' we cannot derive 'We ought to ban it,' since the second premise no longer carries the content required by the conditional's antecedent.

Geach's argument therefore demonstrates that expressivism is false: moral sentences must carry identical descriptive content in both embedded and unembedded contexts, or ordinary logic collapses. A hybrid view that adds minimal descriptive content to moral judgments might seem to rescue validity, but it simply abandons expressivism by making moral language genuinely fact-stating. The programming analog confirms this: when a preference-flag assertion is placed inside an if-condition, it no longer triggers the flag, showing that embedding always strips expressive function and that only descriptive evaluation remains. Hence expressivists cannot preserve logic without giving up their core claim."
