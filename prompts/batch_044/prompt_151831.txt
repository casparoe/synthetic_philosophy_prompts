In AI safety evaluation and proposed governance frameworks, there is a growing practice of certifying an artificial agent as "low-impact" or "side-effect-free" by comparing the actual trajectory of the world after the agent acts to a counterfactual baseline in which the agent takes no action — or is replaced by an inert, non-intervening observer — and measuring divergence across a fixed set of state dimensions. Proponents present this as a purely structural, value-neutral constraint: one need only specify the comparison class and the metric of divergence, not a full axiology of which outcomes are good or bad. Critics reply that selecting which dimensions count (physical layout, resource distribution, information states, other agents' autonomy) and how to weight them already embeds normative judgments, so that "avoid side effects" covertly relies on the very value specification it claims to avoid.

What philosophical commitments does this institutional practice presuppose? Reconstruct the implicit theory: does it treat harm as essentially counterfactual deviation from a status-quo baseline? Does it presuppose a form of indirect normativity, in which a procedural rule (minimize divergence) stands in for direct evaluation of ends? Or does it implicitly depend on an unstated theory of value that privileges preservation of existing states? Distinguish carefully between what the practice strictly requires — could it survive if we replaced the baseline with an explicitly normative target state? — and what merely makes it tractable. If we replaced its implicit view with a straightforwardly axiological framework, in which every change is scored against an explicit ranking of outcomes, what concrete features of the evaluation protocol, certification criteria, or regulatory language would have to change? And is the practice philosophically underdetermined: could several rival theories of value and harm all license the same measurement protocol?
