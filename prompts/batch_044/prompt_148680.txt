Consider this argument I sketched for a seminar on confirmation theory, which now strikes me as suspicious because it seems to turn Bayesianism’s standard answer to the old-evidence problem into a reductio. (1) If a rational agent already knows E with credence ≈ 1, then conditioning on E leaves every other credence unchanged; hence old evidence, taken by itself, never confirms any theory. (2) Scientific practice contradicts this—Mercury’s perihelion was long-known old evidence that later confirmed general relativity—so Bayesians invoke the “learning-the-entailment” reply: the agent updates not on E but on L, the logical fact that T ⇒ E. (3) Formally, for any fixed theory T, P(T | L) = P(T)·P(L | T)/P(L); since P(L | T) = 1, any theory that entails the old data receives a boost proportional to 1/P(L). (4) Now construct a niche family: for each observed datum D_i, define a “mirror theory” M_i that contains exactly one empirical axiom, “D_i holds,” and no other observable commitments. By design M_i ⇒ D_i and makes no risky predictions. (5) For every old datum there is such an M_i, and there are infinitely many. The agent considers each M_i a priori possible, so for each i, P(L_i) is bounded away from zero. (6) Therefore, upon learning each L_i, the agent’s credence in every M_i jumps upward, and because the M_i are pairwise incompatible but collectively cover every “mere retrodiction,” their combined posterior weight dwarfs that of any unified theory like GR, which also entails all the data but carries only a single prior. (7) So the learning-the-entailment move forces the Bayesian to assign near-certainty to the disjunction of all ad hoc mirror theories, leaving GR with negligible credence. (8) Hence Bayesians must reject (2) and deny that old evidence ever confirms, which abandons scientific rationality. I want to preserve (2) if possible—old evidence should be able to confirm—but I am especially uneasy about the slide from (3) to (5) and about how (6) aggregates infinitely many updates. Where does this argument break? Is there a hidden quantifier or scope shift between the single-theory update in (3) and the collective-weight claim in (6)? Or is the real cost in rejecting (3) altogether and accepting that old evidence never confirms? Explain which step fails and what each rejection costs.
