hey, phd student in philosophy of science / epistemology here. i've been thinking about how using LLMs for philosophical reasoning might be eroding my own understanding, but i think i've noticed a more specifc pattern than just "relying on tech". wondering if there's a name for it, or if i'm describing something already in the literature.

here's the pattern: i'll feed an LLM a tricky conceptual problem—say, whether a scientific community can genuinely understand a model if every individual only grasps a fragment and the rest is handled by algorithms. the model produces a really smooth, nuanced reply with distinctions i hadn't considered. i read it over, and then i can paraphrase the whole thing back, defend it against obvious objections, and even feel like i've "worked through" the issue myself. but then if i try to tackle an isomporphic problem—same logical structure, different domain—without the model, i realize i haven't actually internalized the reasoning. i just got good at recognizing which moves sound coherent in that specific framing.

the weird part is that this doesn't just leave my solo ability flat; it actively inflates my confidence. i start feeling like i have sharp intuitions about distributed cognition, when really i have a sharp ear for answers that pass the coherence filter i borrowed from the machine. it's not the dunning-kruger thing, i think, because i'm not overestimating my raw cognitive ability—i'm overestimating my understanding specifically because i've been running my judgments through an external coherence-checker. and it's not exactly standard epistemic dependence, because i don't experience myself as deferring to an authority; i experience myself as having figured it out.

so does this configuration have an established name? maybe "borrowed coherence" or "vicarious understanding"? and if there's nothing close, what distinguishes it from ordinary overconfidence or from using a calculator? also, what are the edges—does it require being able to paraphrase well, or can it happen even when the user just accepts the answer without being able to restate it?
