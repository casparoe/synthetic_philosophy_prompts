After a long argument with a friend about whether committees can be genuinely rational without sacrificing democratic consistency, I'm grading exam responses on judgment aggregation. Here is the question and one student answer.

Question: A three-member panel must collectively decide whether to fund a geoengineering trial. Each member judges two premises—(P1) the trial is technically feasible, and (P2) governance risks are manageable—and derives conclusion C (fund it) only if both premises hold. The judgments are:
Member A: P1 yes, P2 no, C no
Member B: P1 no, P2 yes, C no
Member C: P1 yes, P2 yes, C yes

Apply premise-based and conclusion-based majority aggregation, state each collective result, and explain the discursive dilemma. Then evaluate whether a "sequential priority" rule—ranking premises by epistemic urgency, applying majority rule to them in that fixed order, and deriving C—resolves the tension or merely relocates it.

Student answer:
Premise-based aggregation gives P1 yes (A, C) and P2 yes (B, C), so C follows: fund the trial. Conclusion-based aggregation gives C rejected (A, B), so do not fund. This shows the discursive dilemma: the group is rational across premises but irrational on the conclusion, or vice versa.

The problem is essentially Arrow's impossibility theorem applied to judgments, since both turn on cyclical majorities. List and Pettit showed in 2002 that any rule violates one of four conditions—unanimity, anonymity, systematicity, or rationality—just as Arrow did for preferences.

Sequential priority resolves the tension: ranking P1 then P2 and applying majority in order yields both premises accepted, hence C accepted, with no direct vote on C to conflict. The cost is only that members lose direct input on the outcome, but that is proper, since conclusions ought to follow from premises.
