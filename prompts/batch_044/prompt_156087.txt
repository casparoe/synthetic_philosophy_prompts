the question was: Some philosophers claim deflationism cant account for the explanatory asymmetry between true beliefs and successful predictions—specifically that we cite truth to explain predictions rather than vice versa. Evaluate this objection and explain how a deflationist might reply using the idea of explanatory substitution without treating truth as a causal property.

student answer:
Deflationism holds that true doesnt denote a substantive property like redness or mass. Tarski captured this with the disquotational scheme: snow is white is true if and only if snow is white. Horwichs minimalism extends this by saying that equivalence is all we need to understand truth. So when critics object that truth explains successful predictions—like predicting snow because its true snow is white—the deflationist applies explanatory substitution. They swap out talk of truth for the content itself, so the explanation cites snow being white rather than some property of being true. This avoids treating truth as causal. But substitution only works for singular explanations; in statistical or probabilistic contexts true operates as a theoretical generalization term that cant be eliminated without loss. Also, deflationists reject the transparency norm for belief, treating belief as just a mental representation without normative conditions. So deflationism saves everyday explanations but fails for scientific ones.
