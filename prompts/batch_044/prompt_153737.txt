Consider this argument that DNA cannot be a literal code. (1) Any literal code depends on an arbitrary mapping between symbols and meanings that is established by convention, and conventions require intentional agents capable of agreement. (2) The genetic code maps nucleotide triplets to amino acids, yet no intentional agent designed or agreed upon this mapping; it arose through evolutionary selection. (3) So DNA is not a literal code but only a metaphorical one. (4) Apply the same reasoning to natural human language: its phoneme-to-meaning mappings also evolved gradually without any single designer or explicit agreement among all speakers. (5) Therefore, if (1)–(3) hold, natural languages are not literal codes either. (6) That is absurd—language plainly operates as a code. (7) So the argument proves too much. I want to defend (3): I think DNA is genuinely a code, not merely metaphorically so. Which premise should I reject? Specifically, discuss whether abandoning (1) commits us to treating every causally reliable correlation—like smoke indicating fire, or tree rings indicating age—as a "code," and whether we can instead defend a narrower notion of "functional code" that requires only that decoders can recover the message across counterfactual variations in the channel, without requiring intentional origin.
