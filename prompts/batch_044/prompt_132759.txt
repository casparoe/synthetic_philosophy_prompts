I'm putting together a taxonomy handout for a philosophy-of-economics seminar on Aristotle's views on money and exchange, but I'm tired of the usual natural-vs-unnatural framing. Can you write a decision tree that sorts interpretive positions? Start with whether Aristotle's core objection to interest (tokos) is that money is literally barren/sterile, or that it corrupts the household's telos. Next branch: does exchange-value (axia) depend only on proportional reciprocity, or also on need-matching alone? I want the leaves named — strict teleological limit, exchange-tolerance, corruption-of-desire — plus one empty node where nobody sits (maybe accepting infinite acquisition but still calling exchange natural?). Also inject this hidden splitter: can money serve as both measure and commodity without contradiction? Every node should be phrased so you can answer it without already knowing the label. Keep it to about six nodes, flag any pair of leaves your tree can't really seperate, and don't ask for citations or page numbers since the point is conceptual sorting, not bibliography. End with the final tree inside \answer{...} listing the root question and the total number of leaves.
