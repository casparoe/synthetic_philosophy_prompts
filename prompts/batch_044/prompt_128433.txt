The standard problem of logical omniscience in epistemic modal logic is that if an agent knows P and P entails Q, then they know Q. The usual fixes - awareness logic, impossible worlds, resource-bounded models - treat it like a computational bottleneck. But I think that's wrong. I'm arguing it's a category mistake about what knowing tracks.

I'm using this idea I call epistemic labour (not the feminist care-work version, but the claim that knowing a proposition requires having performed specific cognitive work that integrates the content into your evidential framework). So knowing P→Q isn't just storing the entailment; it's having actually derived Q in a way that binds it to your beliefs. If you haven't done that labour, you don't know Q - not because you're too slow, but because the derivation is constitutive of the knowing itself.

This means belief revision should be non-monotonic in a principled way: if you drop P, you don't automatically drop Q unless you've done the labour linking them. So omniscience fails not through mental limitation, but because knowing requires active integration.
