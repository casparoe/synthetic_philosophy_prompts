hey so i've been trying to formlize a version of the lucas-penrose thing and i think i've accidentally built a proof that mathematicians are literally not made of atoms. here's the chain:

(1) take any consistent formal system F that can represent basic arithmetic. godel's first theorem gives us a sentence G(F) that's true but F can't prove it.

(2) lucas says: if i'm just running F, then i shouldn't be able to see G(F) is true either. but i can see it (assuming i'm consistent), so i'm not just F.

(3) now build a hierachy F1, F2, F3... where each one is strong enough to formalize the previous one plus its godel sentence.

(4) for any particular human mathematician H, if H is running some Fn, then H can step up to Fn+1 and see its godel sentence too. so H transcends whatever system you assign them.

(5) but this applies no matter how far up the hierachy you go. so H can transcend every system in the entire countable sequence.

(6) that means H has access to truths that lie outside every countable tower of formal reasoning. if being physical just means being capturable by some physical computation, and every physical computation can be modeled by some system in this tower, then H isn't physical.

(7) same reasoning shows any AI running code is stuck inside its own Fn and can never genuinely understand the godel sentence of its own architecture, so AI will always lack real mathematical insight.

(8) but (6) sounds insane -- it turns a philosophy-of-mind argument into proof of a soul or something. and (7) seems to overstate the AI limitation, since an AI could in principle be updated to a stronger system.

where's the leak? is it in (4), assuming the human can always consistently make the step up? or is (3) wrong to think we can always formalize the "stepping up" itself inside the next system? or maybe (6) is a non-sequitur because transcending each system in a sequence doesn't mean transcending the union?

i'd like to keep the idea that humans aren't just running one fixed formal system, but i really don't want to end up with dualism. which premise should i ditch, and what's the cost?
