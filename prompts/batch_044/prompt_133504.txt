Here's an argument my grad student cooked up; I think it's slippery but I can't name the slip. (1) Gödel showed that in any consistent formal system S with enough arithmetic there's a sentence G that is true but unprovable in S, and G essentially asserts that it lacks a proof in S. (2) Hofstadter takes this as a strange loop: the system represents itself. (3) Apply it to consciousness. Call a mental representation R reflexively accessible iff the system can token R and also token that it is tokening R. (4) Now build the mental analog of G — call it the Shadow Thought — whose content is that it itself is not reflexively accessible right now. (5) If Shadow is accessible, its content is false; that's just a false belief, not contradiction. (6) So build Shadow-Plus, which asserts both that Shadow is accessible and that the system has full epistemic closure over all its reflexive accessibility conditions. (7) But the Gödelian result applies iteratively: any system that achieves full closure over its own reflexive conditions can be embedded in a strictly stronger system that still contains an unaccessible analog. So either consciousness lacks closure (hence no unified self-model) or it spawns an infinite hierarchy of meta-minds with no stable self. (8) Since we clearly have stable self-awareness, the premise that minds are Gödelian strange loops must be wrong — self-awareness is impossible on this model, yet it exists, so the analogy collapses.

He says this kills Hofstadter. I think there's an equivocation between formal provability and psychological accessibility, and maybe a scope slip in (6). Where exactly does it fall apart? Which step do you reject, and what's the price? I'd rather keep (3) and (5) if I can.
