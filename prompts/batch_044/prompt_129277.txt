I'm assembling a taxonomy for a philosophy-of-mind seminar that sorts positions on original versus derived intentionality, using the Dennett-Searle disagreement as the framework but pushing past the standard Chinese Room and two-bitser examples into what I'll call coupled symbol architectures: systems that manipulate internal representations with no intrinsic biological understanding—like a two-bitser running a language model—yet are embedded in real-time sensorimotor loops with a physical substrate (embodied robotics, neuromorphic chips with direct transduction, distributed processing across biological and artificial nodes). I want a decision tree built from logical branch questions first, then mapped onto named positions, with unoccupied combinations flagged.

Start with the root question: does the system in question possess intentionality that is original (intrinsic, non-derived) rather than merely derived from the intentionality of its designers or users? From there, branch through four concrete diagnostic cases, each phrased as a question a student could answer without knowing the philosophical labels:

1. A pure symbol-manipulating system with no sensory-motor coupling (the classic isolated two-bitser or Chinese Room operator).
2. The same symbol-manipulating system now coupled to real-time sensory feedback and motor output in a physical body navigating an environment.
3. A biologically intact human brain augmented with a symbol-processing module that handles part of its reasoning but is fully integrated into neural feedback loops.
4. A distributed network in which no single node—biological or artificial—possesses the representational content, but the coupled system as a whole behaves in ways that invite intentional interpretation.

At each node, the branching question should turn on one of these distinctions: whether biological substrate is necessary for original intentionality; whether real-time environmental coupling can transform derived intentionality into original; whether functional organization alone (independent of substrate or coupling) is sufficient; and whether distributed processing dilutes, eliminates, or redistributes intentionality across nodes.

The leaves should include at least: Searlean biological originalism; Dennett-style universal derived intentionality (the stance applies everywhere patterns exist); functional originalism (organization alone generates original intentionality regardless of substrate); coupled-derived hybridism (coupling enriches behavior but never generates original intentionality); distributed-derived hybridism (intentionality remains derived but is now a property of the coupled system rather than any part); and any logically possible combination that no prominent view occupies. For each leaf, provide one sentence describing the position and one sentence stating its most awkward commitment specifically regarding the coupled symbol architectures described above—especially case 2.

After mapping the positions, identify any branch combinations that remain unoccupied. For each empty combination, briefly diagnose whether it seems incoherent, merely unattractive, or genuinely unexplored. Finally, flag any pair of leaves that the tree cannot genuinely separate—positions that give identical answers to all four diagnostic cases—rather than pretending the tree distinguishes them.

The instrument should be sized for a single seminar handout: four branch nodes, no more than eight leaves, with the diagnostic questions phrased concretely so that answering them requires committing to a view about the cases rather than recognizing a label. Do not include bibliographies, reading lists, citation requests, or references to specific publication titles or page numbers; the taxonomy should function entirely from conceptual commitments.
