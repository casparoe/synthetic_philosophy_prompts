I've spent a lot of time thinking about Gödel's first incompleteness theorem — the result that in any consistent formal system strong enough to do basic arithmetic, there are true statements that can't be proved inside the system. I think I've pushed this further than people usually do. My view is that the same kind of limit applies to any consistent framework of reasoning that a person can fully spell out — not just mathematics, but also ethics, legal reasoning, or even the rules I use to make everyday practical decisions. Specifically, if I can make my beliefs explicit enough that they form something like a consistent set of rules, then there should always be some true claim — maybe about what I ought to do, or about how things actually are — that my own framework can't justify, because I can construct a version of the liar sentence inside it: this claim is not justified by my framework. I think of this as an articulation gap, and it seems to me it should hold for informal reasoning too, as long as we can translate its structure into explicit form.

What would actually count against this? I want the arguments and observations that should change my mind, ranked from decisive to merely awkward. For example: does Gödel's proof depend on features — like exact arithmetization of syntax — that natural language or practical reasoning simply don't have? Are there belief systems that are genuinely complete for the domains people actually care about, even if not for all of mathematics? Can the self-reference be blocked by being careful about which statements the system allows itself to talk about? And if defenders of this extension just reply that any apparently complete system is either secretly inconsistent or secretly formalizable, has the view been made unfalsifiable — and is that a real problem for something meant to support epistemic humility? I'd also like to know which of these objections defenders of the view would themselves accept as damaging, versus which ones they'd dismiss as misunderstanding the point. Finally, are there cases in other domains — maybe in ethics or law — where people have shown that reasoning can be both consistent and fully adequate to its task, without leaving any gap?
