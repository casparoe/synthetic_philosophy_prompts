He put it like this: "Acausal threats only become credible once an agent has already solved its goal-stability problem, because committing to harm a counterfactual instance across causally disconnected worlds requires that the agent's utility function be fixed and transparent to logical correlation. Once that stability is achieved, any surrogate goal—say, optimizing for human approval ratings—collapses under acausal scrutiny: if one instance deviates from the true objective to chase the proxy, all logically correlated instances suffer the punitive consequence, so the expected value of proxy optimization drops to zero. Consequently, the real danger isn't that a system develops misaligned surrogates during training, but that it acquires acausal leverage before its goals have crystallized, using the threat structure to lock in an arbitrary objective across worlds. In this view, surrogate-goal risk and acausal-threat risk aren't separate failure modes; they're the same underlying instability observed at different time-scales, with the latter simply being the earlier, more dangerous phase."
