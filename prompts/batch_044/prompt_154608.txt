Heterophenomenology, developed by Daniel Dennett, is a third-person scientific method for studying consciousness. Rather than treating a subject's verbal report—such as "I see a red afterimage"—as a direct description of a private inner object, the heterophenomenologist interprets the report as a text expressing the subject's belief about their experience. This distinguishes it from first-person phenomenology, which takes introspective reports as authoritative data about what is actually present in consciousness. By bracketing the metaphysical question of whether there is really an inner movie playing, heterophenomenology allows neuroscience to map the functional mechanisms that produce reports without getting stuck on the hard problem.

If applied to a split-brain patient who reports seeing a single unified visual field despite hemispheric separation, heterophenomenology would treat the report as expressing the patient's belief about their experience, not as proof that there is actually one unified consciousness. The scientist would study the neural and behavioral conditions that generate this belief, remaining neutral about whether there truly is one subject or two.

The method is not behaviorism, but it is closely related: like behaviorism, it refuses to treat mental reports as direct access to inner reality. However, it allows for rich internal modeling and takes the subject's own descriptions seriously as data, which classical behaviorism rejected. Dennett argues that once heterophenomenology completes its map of all report-generating mechanisms, the hard problem dissolves because there is no remaining gap between function and feeling. Therefore, heterophenomenology proves that consciousness is not a unified phenomenon but a collection of separate cognitive drafts, with no central observer. As for artificial systems, the method should apply to them too, since it only requires interpretable reports, not biology.
