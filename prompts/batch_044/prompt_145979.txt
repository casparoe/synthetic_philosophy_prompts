Consider the problem of defining "low-impact" or "side-effect-avoiding" behavior for an artificial agent when no complete specification of human values is available. Classical proposals—world-state distance metrics relative to a baseline trajectory, conservative action selection within a reference class, or impact penalties scaled by proxy preferences—each encounter the same obstacle: any metric that distinguishes meaningful interventions from trivial ones appears to smuggle in judgments about which differences matter. Two less-discussed formulations complicate this further: a counterfactual-stability criterion, which asks whether an action alters the distribution of outcomes in branches where the agent was never activated, and an "epistemic side-effect" constraint, which targets changes to what other observers or systems can learn regardless of physical-world alterations.
