the inside view means reasoning from specific causal details of the case, while the outside view uses base rates for similar past cases. epistemic modesty requires admitting our causal models are overfitted, so in conflict we should default to outside view and treat inside reasoning as a small bayesian update at best. kahneman frames inside view as essentially system 1 — fast and narrative-driven — while outside view is more like system 2 since it uses stats. so being modest means letting stats dominate unless you have unique info that breaks the reference class. for instance, if im deciding whether to back this specific ai-safety startup, i should start with the 90% failure rate for tech startups, then nudge the failure rate downward a bit because the founders have phd's, but never reverse the base rate entirely. the problem is reference classes are arbitrary — you could class it with ai startups, phd-led startups, or venture-backed ones — but that just means averaging across several and staying near the base rate. ultimately modesty is knowing your particular story is probably wrong.
