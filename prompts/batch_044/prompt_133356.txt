Question: Frege pointed out that "a = a" and "a = b" can have different cognitive values even when both are true. Explain why this is trouble for the view that a proper name's meaning is just its reference. Then lay out Frege's own fix using sense (Sinn) as mode of presentation. After that, tackle the objection that if sense is just the description a speaker associates with the name, then people using different descriptions aren't really talking about the same thing—say how Frege might reply, and whether putting sense in a "third realm" actually fixes it or just relocates the problem. Finally, address the "discovery" worry: if sense already fixes reference, how could anyone empirically discover that Hesperus is Phosphorus without already knowing both senses point to Venus?

Student answer:
So Frege's puzzle hits when you compare "Hesperus = Hesperus" with "Hesperus = Phosphorus". Ancient astronomers knew the first was true but had to discover the second, even though both just say Venus is Venus. If meaning is only reference, both sentences should be equally obvious, since they have the same content. So reference alone can't explain cognitive significance.

Frege solves this with sense—the mode of presentation. "Hesperus" gives Venus as the evening star, "Phosphorus" as the morning star. The two sentences express different thoughts because they pair different senses, even though the reference is identical. That explains why one is trivial and the other informative.

Now the descriptivist objection: if sense is just the mental description I attach to a name, then my "Aristotle" (teacher of Alexander) and your "Aristotle" (author of the Metaphysics) have different meanings, so we talk past each other. Frege rejects this psychologism—sense isn't in the head. It's objective, part of the "third realm" where thoughts live. So two people can grasp teh same sense despite different mental images.

There's also the discovery problem. If sense determines reference, then knowing both senses should already tell me they share a reference, which makes empirical discovery impossible. I think Frege answers this by saying each sense determines reference on its own, but the convergence of two senses on one object is an empirical fact about the world, not built into the senses. So we learn that the evening-star sense and the morning-star sense apply to teh same planet through observation, not through analyzing the senses themselves.
