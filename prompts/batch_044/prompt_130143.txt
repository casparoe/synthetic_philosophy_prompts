For a philosophy of representation seminar, construct a branching taxonomy that classifies positions on where semantic content is fixed in a layered representational system, using Hofstadter’s tripartite distinction among frame messages (the syntactic rules and interpretive conventions that govern a system), outer messages (content assigned or fixed by an external interpreter or meta-system), and inner messages (self-referential content generated within the system that attempts to specify its own interpretation). Build the tree from concrete diagnostic cases rather than from named theories: include splits on whether a formal system that rewrites one of its own axioms changes its frame message or only produces an inner message about the frame; whether the weights of an artificial neural network function as an outer message about language or as an inner message lacking an external interpreter; whether recursive self-reference can stabilize meaning in the absence of any frame; and whether a subsystem that modifies the rules of its parent system counts as part of the frame, the outer layer, or an anomalous inner loop. Each leaf should carry a position name—such as frame primacy, interpretive externalism, recursive internalism, or unnamed—and one sentence stating its most awkward commitment, especially with respect to self-modifying systems. The tree should contain at least six leaves, should map out the logical space of combinations so that unoccupied positions are noted and briefly diagnosed as incoherent, unattractive, or merely unexplored, and should explicitly flag any pair of positions that your diagnostic cases cannot actually separate. Do not request bibliographies, citations, or reading lists; the task is to sort views by what they imply about these cases, not by scholarly attribution.
