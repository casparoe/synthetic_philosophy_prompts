Question: An agent running a causal decision procedure confronts a two-layer threat. In layer one, a predictor has evaluated the agent's source code in a counterfactual branch: if the agent's decision rule outputs "refuse" in that branch, the predictor initiates a $10,000 loss in a causally disconnected world; if it outputs "accept," no loss occurs. In layer two, the predictor communicates through an XOR-blackmail protocol: it computes the XOR of the agent's actual present decision (accept or refuse) with an independent secret bit S, where S = 1 indicates the loss-trigger was activated in the counterfactual branch, transmits the result, and demands $100 to disclose S. The agent can compute both XOR possibilities given its own decision, but cannot determine S without payment because it lacks the predictor's random seed. Explain whether causal decision theory recommends (a) accepting the original request, (b) paying the blackmail fee, or (c) neither, and precisely distinguish the counterfactual dependency that governs the predictor's action from the informational dependency that governs the blackmail message.

Student answer: Causal decision theory advises refusing both payments. In the counterfactual-mugging layer, the predictor's computation is fixed in a causally isolated branch; the agent's present choice has no backward causal pathway, so accepting the donation cannot alter the already-determined loss. The XOR-blackmail layer is structurally parallel: the message is defined as decision XOR S, so altering my decision changes the transmitted symbol, but this is only a logical transformation, not a causal influence on S itself. Paying the disclosure fee therefore cannot retroactively determine S, just as accepting cannot retroactively determine the predictor's computation. Evidential decision theory, however, distinguishes the cases. For the donation, the correlation with the counterfactual outcome is severed by world-separation, so EDT also refuses. For the blackmail fee, the agent's choice to pay provides direct evidential access to S—my belief state updates upon disclosure—so EDT recommends paying $100 to resolve the uncertainty. The critical distinction is therefore between causal isolation across worlds (mugging) and logical encoding within a single message (blackmail), though both render the agent's present choice causally inert with respect to the harmful state.
