For a graduate metaphysics seminar on infinity and physical process, construct a decision-tree taxonomy that sorts philosophical positions on the coherence and physical possibility of supertasks, using Thomson's lamp and a modified variant specified below. The tree should open with the root question: Can an actually infinite sequence of discrete changes be completed within a finite interval of time? From there, every internal node must present a single diagnostic claim or case judgment that divides the remaining positions, phrased so that a student can answer it without knowing which named view it leads to.

Structure the tree around exactly these four branch dimensions, in this order:
(i) Whether the classic lamp-paradox—toggling at intervals 1/2, 1/4, 1/8, ... reaching time 2—presents a logical contradiction or merely an undefined boundary condition.
(ii) Whether the paradox can be dissolved by denying that there is a last toggle (so no transition rule applies at the limit), or whether it requires a different kind of resolution altogether.
(iii) Whether accepting supertasks entails that a physical system could compute a non-Turing-computable result in finite time.
(iv) A specific injected case: the continuous-field lamp, in which there is no discrete switch but instead a capacitor whose voltage asymptotes continuously to a limit value L at time 2, with brightness being a continuous function of that voltage. The branching question is whether this continuous dynamics genuinely avoids the contradiction, or whether it still inherits an undefined limit-state problem.

Your leaves should carry a position name where one is standard—such as discrete physical finitism, the strong contradiction view, limit-state indeterminism, hypercomputation-friendly supertask realism, and the continuous-field resolution view—and should include at least one combination that is unnamed or apparently unoccupied, with a brief diagnosis of whether it is incoherent, unattractive, or merely unexplored. Include at least six leaves total.

For any pair of leaves that these four dimensions fail to separate, flag the ambiguity explicitly and state what further distinction would be required to pull them apart. Do not request bibliographies, reading lists, or citations; the instrument should classify commitments by what they say about the cases. Format the deliverable as a formal handout: label each node with its question, each branch with the answer that traverses it, and each leaf with its position name, its core commitment in one sentence, and its most awkward consequence.
