I've been leaning toward this hybrid view about LLMs and belief attribution: take Dennett's intentional stance seriously, but apply it only at the level of token-probability distributions rather than propositional content. So an LLM doesn't literally believe Paris is in France, but it maintains a stable distribtuional weighting across its context window that functions anologous to a belief-state for predictive purposes — call it the distribtuional stance. The point is to talk about model beliefs in interpertability work without smuggling in consciousness or full rational agency.

But I'm not convinced it's actually exposed to falsification. What would count against the distribtuional stance? Not just generic AI-has-no-mind objections — I want the specific failure modes: cases where these distributional patterns are too unstable or context-sensitive to deserve belief-talk, mechanistic interpertability results showing the weights don't track anything like propositional content, or philosophical arguments that belief requires normative integration that token probabilities can't supply. Rank them from fatal (the view collapses entirely) to merely awkward (we just add annoying qualifications). Which ones would a committed defender concede are real problems, and which would they dismiss as category errors? Also, has the stance been qualified into unfalsifiability, and if so is that a problem for something that's supposed to be pragmatic rather than metaphysical? One more thing: does the stance survive if we apply it to tiny models that clearly lack coherence, since that might be the actual breaking point.
