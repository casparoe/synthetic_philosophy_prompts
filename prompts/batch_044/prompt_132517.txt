I'm taking an upper-division course on agency and rationality, and I'm stuck on a conceptual point about embedded agency that our readings only touched on in passing. The standard claim is that an embedded agent—one that is physically part of the environment it acts upon—cannot construct a fully detached, complete model of that environment, since any model it builds is itself implemented within the system being modeled. I want to understand a more specific problem that arises when the agent tries to represent not just its external environment, but its own decision-making process as part of that environment. If the agent includes a representation of its own reasoning in its world-model, then any update to that representation also updates the reasoning that produced it, which seems to create a feedback loop distinct from ordinary logical self-reference. Conceptually, is this instability a matter of granularity—something that disappears if the agent models itself only at a coarse, functional level—or is it structurally unavoidable for any embedded system that attempts self-modeling? And how should we distinguish this issue from standard bounded-rationality limits or from reflexive paradoxes like the liar? I'd like an explanation that works through the structure of the problem rather than pointing to specific theories, since I'm trying to see whether this is a genuine conceptual obstacle or just a practical difficulty in implementation.
