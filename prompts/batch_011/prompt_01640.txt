Two colleagues at work got into this argument, and I've been thinking about it ever since.

One of them said that the past doesn't actually exist—once a moment passes, it's gone. Only the present is real. The other asked him: "If the past doesn't exist, how do memories work? My memory is a physical state in my brain right now, but it's *about* things that happened. What is it about if those things don't exist?"

He replied: "Your memory is just a state of matter. It's like a photograph—the photograph is real, but that doesn't mean the moment it captured still exists."

She pushed back: "But my memory isn't just passive like a photograph. I actively use my memories to make decisions. And here's the thing: memories can be false. If my memory is false, what makes it false? It's only false if there's an actual fact about what happened. But if the past doesn't exist, there's no fact of the matter for my memory to be wrong about."

He thought for a second and said: "The falseness is about what the memory represents, not whether what it represents still exists. Like, a dream represents dragons, but that doesn't mean dragons have to exist somewhere for the dream to be a dream."

She responded: "But memory isn't like a dream. A dream is something my brain generates randomly. Memory is supposed to be a causal process that preserves information from actual past events. If there are no past events to preserve information from, what is the memory system even for?"

They kind of went in circles after that. Who's making the stronger case at each step? Is either of them missing something important?
