So in my "Topics in Game Theory and Rational Choice" seminar we spent two weeks back to back on stuff that I keep mixing up in my head. First week was Hofstadter's superrationality thing from his old Scientific American columns - the idea that if you and some other agent are both "superrational" and know it, you should cooperate in a one-shot Prisoner's Dilemma, because whatever reasoning gets you to defect will get the other guy to defect too, so by symmetry you should just pick whichever action you'd want both of you to take. Second week was Tennenholtz's program equilibrium stuff, where instead of choosing an action you submit an actual program that gets to see the other player's source code before it acts, and it turns out theres a program (basically "cooperate iff your code is literally identical to mine, otherwise defect") that makes mutual cooperation into a genuine Nash equilibrium of that program-submission game. We also skimmed a later paper (I think it came out of MIRI?) where they use Löb's theorem to get two differently-coded "FairBot" programs to cooperate with each other, which is apparently a big step up from just checking for identical source code.

A couple of us from the seminar got into it after class about whether program equilibrium is actually doing anything philosophically new or if its just superrationality wearing a computer science costume. One friend's take is that letting programs read each other's code just makes literal the "the other guy reasons exactly like me" assumption that superrationality already needed, so it's not adding anything, just automating it. Another friend thinks the Löb's theorem version is a genuine step forward because it gets cooperation between agents that aren't identical, only mutually provable to each other, which is a weaker (and so more impressive) assumption than the twin-style symmetry Hofstadter was relying on. Our professor just told us to sit with it, which was not helpful lol.
