I started as a teaching assistant for our economics department's graduate game theory course this term, and this week I graded my first problem set without the professor reviewing my marks beforehand, which has made me more anxious than I expected about staying consistent across submissions. One student's answer to the question below is taking me a long time to evaluate, since it is well organized and mostly uses the right vocabulary from lecture, and I would like a careful, independent read on it before I record a grade.

The question, worth 20 points on Problem Set 5, reads as follows.

"Consider the following two-player game in normal form, where Player 1 chooses a row and Player 2 chooses a column, and payoffs are listed as (Player 1's payoff, Player 2's payoff):

```
               L          C          R
       T      3, 3       0, 1       0, 0
 P1    M      0, 2       0, 1       3, 3
       B      1, 3       5, 1       1, 2
```

Using iterated elimination of strictly dominated strategies — recall that, as covered in lecture, a strategy may be eliminated once it is strictly dominated by some mixed strategy, even if no single pure strategy dominates it — reduce this game as far as possible. At each round, state exactly which strategy or strategies you eliminate, give the dominance argument that justifies it, and display the resulting reduced game. If the procedure does not pin down a unique outcome, say so explicitly and explain why not."

Here is the student's answer, reproduced in full:

"Round 1: Look at Player 2's columns first. Against T, L pays 3 and C pays 1; against M, L pays 2 and C pays 1; against B, L pays 3 and C pays 1. So L beats C no matter what Player 1 does, and C is strictly dominated by L. For the rows, nothing can be cut yet: B is not beaten everywhere by T or by M (B still gets 5 on column C, versus 0 for both of them), and neither T nor M is beaten everywhere by B (B only gets 1 on L and on R, versus 3 for T on L and 3 for M on R), so no single row dominates another. That leaves:

```
        L         R
 T    3, 3      0, 0
 M    0, 2      3, 3
 B    1, 3      1, 2
```

Round 2: With C gone, look at B again. B still guarantees 1 regardless of the column, and neither T nor M beats that by itself (T only gets 0 on R, M only gets 0 on L). But now that C is out of the picture, Player 2 has no remaining reason to prefer L over R — L only won earlier because it beat C, which no longer matters — so it's natural to treat Player 2 as randomizing 50-50 over L and R at this stage. Averaging over that belief, T and M each pay Player 1 an expected 1.5, while B still only pays 1, so B is strictly worse and is eliminated. This is exactly the case from lecture where a strategy is only dominated by a mix of two others, not by either alone.

```
        L         R
 T    3, 3      0, 0
 M    0, 2      3, 3
```

Round 3: T and L are the strategies that have come out on top at every stage so far — L survived by beating C, and T pairs with it for the best joint outcome, (3,3) — so iterated dominance settles on (T, L) as the unique prediction for the game."
