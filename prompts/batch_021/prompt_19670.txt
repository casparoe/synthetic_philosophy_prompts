The question we were given was: "Explain Skolem's paradox. Does it show that ZFC is inconsistent, and if not, how should it be resolved?"

Here's his answer, word for word:

"Skolem's paradox arises from the (downward) Löwenheim–Skolem theorem, which says that any first-order theory in a countable language that has an infinite model also has a model of every smaller infinite cardinality, in particular a countable one. ZFC is such a theory: its language and axioms are countable, and it has infinite models (assuming ZFC is consistent at all, which follows from Gödel's incompleteness theorem, which tells us that every consistent theory has a model). So there's a countable model M of ZFC. But ZFC proves, via Cantor's theorem, that there are uncountable sets - for instance that the power set of ω has no bijection with ω itself. So M must contain some object that M "thinks" is uncountable, even though M as a whole only has countably many members from our outside point of view. That looks like a straight contradiction, but it isn't: it's resolved once we notice that "countable" isn't an absolute property of a set, only a relative one, relative to which bijections happen to be available. The set M calls "the power set of ω" really does only have countably many members when you look at M from the outside, but the actual bijection witnessing this isn't itself an element of M, so M has no way of "knowing" its own power set of ω is countable, and correctly proves, relative to its own resources, that it's uncountable. Interestingly this also means Choice can't be holding fully inside M, since its really Choice that lets you build the missing bijection in the first place. So the paradox isn't a sign that set theory is inconsistent, it just shows "uncountable" is model-relative rather than an absolute feature of a set."
