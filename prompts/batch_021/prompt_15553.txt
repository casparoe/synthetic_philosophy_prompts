So Kim's causal exclusion argument usually gets pitched as a special problem for the mental -- if mental properties don't reduce to physical ones, they can't be doing any real causal work, since the physical effect already has sufficient physical cause and systematic overdetermination is too cheap a way out. But the same reasoning seems to generalize: it looks like it'd drain causal power away from basically any higher level property in the special sciences too (biological, economic, whatever), not just mental ones. Kim's own way of blocking this is to say most of those properties can be functionally reduced, so they're fine, and its only qualia that end up stuck as genuinely epiphenomenal. Argue that this doesn't actually save him -- that functional reduction doesn't block the drainage/generalization problem either, so we're left with either way more epiphenomenalism than anyone bargained for, or ditching the exclusion principle itself.
