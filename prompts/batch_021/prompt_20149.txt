Here's the question I wrote up: "Consider a game where a fair coin is tossed repeatedly until it first lands heads. If the first heads occurs on toss n, you receive a payout of (-1)^(n+1) × (2^n / n) dollars — so you win money when n is odd and pay money when n is even. (a) Work out the expected value of this game. (b) Say whether you think that expected value is actually well-defined. (c) Briefly compare this game to the St. Petersburg paradox."

And here's what Marcus wrote back: "The probability the first head lands on toss n is (1/2)^n, since you need n-1 tails then a head. So the expected value is the sum, from n=1 to infinity, of (1/2)^n × (-1)^(n+1) × (2^n/n). The 2^n and (1/2)^n cancel, leaving the sum of (-1)^(n+1)/n, i.e. 1 - 1/2 + 1/3 - 1/4 + ... That's the alternating harmonic series, which converges to ln(2) — every calc class covers this — so the expected value is ln(2), about 69 cents. Compare that to St. Petersburg, where the expected value is infinite because you're summing an endless string of positive $1's with nothing to cancel it back down. And because the alternating harmonic series is a totally standard example of a convergent series, and a convergent series has exactly one well-defined sum, ln(2) isn't just an answer, its THE answer, full stop — unlike St. Petersburg, which has no finite answer to give at all. So if anything, only St. Petersburg really deserves the word 'paradoxical' here; this coin game is just a nice example of alternating signs taming what would otherwise be an explosive sum, and a rational person should be happy to pay anything up to 69 cents to play it."
