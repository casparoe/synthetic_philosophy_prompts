So I went down a rabbit hole a while back reading about this game theory idea called "program equilibrium" (Tennenholtz, I think, early 2000s) — instead of each player just picking an action in a game like the prisoners dilemma, each one submits a *program* that decides the action, and the programs get to read each other's source code before they run. Apparently that alone can make mutual cooperation an actual equilibrium in a one-shot PD, which kind of blew my mind. The part that really got me was the fix for the obvious "I simulate you simulating me simulating you" infinite loop problem — theres a trick using Löb's theorem (the "FairBot" thing) where instead of simulating forever, the programs just search for a formal proof that the other one cooperates, and that somehow dodges the regress entirely. This feels weirdly close to how smart contracts work on a blockchain, where the code really is public and immutable — maybe thats the closest real-world version of "reading each other's source."
