So I've been trying to wrap my head around the "löbian obstacle" thing that comes up in AI safety discussions about self-modifying agents, and I tried writing out the argument myself just to see if I actually get it. Can you read my attempt below and poke holes in it — tell me where its shaky, or if I've just restated something more basic and missed the actually interesting part?

My attempt: say we have an agent A that only takes an action if it can produce a proof, in some fixed formal system S, that the action is "good" (leads to acceptable outcomes). Now A is about to hand off control to a successor A', maybe a smarter or rewritten version of itself, reasoning in that same S. Obviously A can't manually check every future decision A' will make, so A would love to just trust A' the way it trusts its own reasoning right now. The natural thing to want is something like: "for any action a, if A' proves in S that a is good, then a really is good" — basically a reflection principle for its own proof system, so it doesn't have to re-derive everything from scratch.

Here's the snag: if S is expressive enough to state that principle for some particular action a, and S can actually prove it, then by lob's theorem S can already prove "a is good" directly, no successor required. Which seems too strong — it would mean you can manufacture a proof that literally any action is good just by getting the reflection schema to go through. So either S can't actually prove that general trust schema, or if you insist on it you're one step from inconsistency. Push it far enough (apply the same move to "this system is consistent") and you crash straight into Gödel's second incompleteness theorem instead.

The moral I've drawn is: you can't get generalized trust in a proof system as strong as your own "for free" — any shortcut that lets you certify in advance that "whatever this system proves must be true" turns out to be exactly as hard as proving the object-level claim yourself, not easier.

Does that actually capture what's doing the work in the löbian obstacle, or is it just Gödel 2 wearing a costume? And is there a more interesting reason this specifically matters for self-modifying/successor agents that I'm not getting to?
