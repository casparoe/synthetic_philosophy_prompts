I've read enough rationalist-blogosphere discussion of Pascal's Mugging to know the standard fix: give the agent a bounded utility function, and no vanishingly improbable, astronomically large payoff can ever swamp its decisions. What usually gets glossed over is why boundedness specifically is doing the work, rather than the more modest patch Bernoulli himself proposed for the original St. Petersburg game -- just making utility a concave function of the payoff, such as log utility. Please argue for the claim that no utility function that is unbounded above, however slowly it grows, can be safe from every St. Petersburg-style gamble: for any such function one can design an escalated ('super') version of the game -- same halving probabilities, faster-growing prizes -- whose expected utility is still infinite, so that only genuine boundedness above is safe across the board. I'd like the argument to actually sketch, for an arbitrary unbounded utility function, how those escalated prizes would be chosen, rather than simply asserting that they exist.
