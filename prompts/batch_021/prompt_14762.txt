Over a long career in experimental physics I treated expected-value reasoning as practically axiomatic, so when I first met the St. Petersburg paradox I assumed Daniel Bernoulli's 1738 fix -- that utility grows more slowly than wealth, making the game's expected utility finite even though its expected monetary value is infinite -- simply closed the matter. Further reading in retirement has undermined that confidence: an argument often traced to Karl Menger shows that for any unbounded utility function one can build a "super-Petersburg" variant whose prizes grow fast enough to make expected utility diverge again, so that only a bounded utility function can fully immunize an agent -- yet boundedness has the uncomfortable consequence that a sufficiently satiated agent must eventually refuse arbitrarily favorable bets. Others instead treat the whole paradox as an artifact of an unrealizable idealization (an infinitely wealthy, unfailingly honest counterparty) that dissolves once any real-world cap on payouts is acknowledged, with no revision to utility theory required. Write an essay that weighs these responses -- bounding utility, debunking the idealization, and, more radically, abandoning expected-utility maximization itself as the norm for such cases -- and closes with a definite verdict on which, if any, actually dissolves the paradox rather than merely relocating it.
