(a) Explain why this validates both (i) that agents know every logical truth, and (ii) that an agent's knowledge is closed under known logical consequence. Say which piece of the modal proof theory — the K axiom, the necessitation rule, or something else — is doing the work in each case.

And here's what the person I got assigned to grade turned in:

"(a) Both of these are consequences of the possible-worlds semantics for knowledge. Logical truths are true in every model at every world, so in particular they're true at every world accessible from w, meaning the agent trivially 'knows' them — and this, plus the closure of knowledge under logical consequence, both come from the K axiom, K(φ→ψ) → (Kφ → Kψ), which is valid on every relational frame no matter what R looks like. Because K holds no matter the shape of R, an agent's knowledge is automatically closed under logical consequence: if ψ follows from φ, then φ→ψ is a tautology, so it's known (by the same trivial argument that gets tautologies known), and then K plus modus ponens gets you Kψ from Kφ. So really (i) and (ii) both boil down to the same mechanism — the true-at-every-world status of validities, filtered through K.

(b) The fix is to let the agent access some 'impossible worlds' alongside the normal ones. Concretely, you give the agent an awareness set — the sentences they've actually entertained or derived — and only worlds compatible with that set count as accessible; everything outside it, including worlds where the usual entailments would otherwise force closure, gets walled off. Because impossible worlds don't have to respect the recursive truth clauses for the connectives, an accessible impossible world can make φ true and ψ false even though ψ follows from φ, so Kφ no longer forces Kψ. Meanwhile the actual world is stipulated to be a normal, possible world, so truth simpliciter behaves completely classically there and validity itself is untouched.

(c) The most common complaint is that impossible-worlds semantics is unprincipled on its own: nothing in the framework tells you, for a given agent and a given hard theorem, whether the relevant impossible world is or isn't accessible to them. Unless you supply an independent story about which impossible worlds count as epistemically accessible — one that doesn't just read the answer off of what we already think the agent knows — the semantics ends up being a redescription of the problem rather than a solution to it."
