The Kelly criterion instructs a bettor to stake, each round, whatever fraction of wealth maximizes expected log wealth. Defenders treat this geometric standard not as one prudent policy among many but as the objectively rational way to size any repeated risky bet, since a Kelly bettor almost surely ends up wealthier than one following any other fixed strategy, given enough rounds. Samuelson's classic objection is that this is a fallacy: near-certain dominance "in the long run" says nothing about what a finite-horizon agent should do unless that agent already has logarithmic utility, so the argument smuggles in one particular utility function while claiming to sidestep preferences altogether. A newer defense, sometimes labeled "ergodicity economics," replies that this misses the point: because wealth compounds multiplicatively, the time-average growth a single agent actually experiences diverges from the ensemble average that ordinary arithmetic expected-value reasoning assumes, so insisting on the correct, time-average quantity forces geometric growth-rate maximization on us with no appeal to preferences at all. Write an essay adjudicating this dispute. State clearly what, if anything, survives of Samuelson's objection once the ergodicity argument is on the table, and defend a definite verdict on whether geometric rationality is privileged over arithmetic expected-value reasoning independently of an agent's utility function and horizon, or whether it is not.
