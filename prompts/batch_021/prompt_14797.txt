I've spent a long time reading rationalist blogs and forums, and I keep running into the same analogy: natural selection is said to have "specified" inclusive fitness through crude proxies -- sugar cravings, status-seeking, the sex drive -- and modern mismatches like junk food, contraception, and social media are cast as those proxies "gaming the specification," a biological version of Goodhart's law. It's a vivid move in x-risk writing, but I suspect it smuggles in more than it earns. The standard four-way taxonomy of Goodhart effects was built to describe optimizers that represent a proxy and pursue it in place of a goal: regressional (optimizing a noisy proxy also selects for the noise, so the true goal regresses toward its mean), extremal (a proxy-goal relationship that holds across ordinary cases breaks down once optimization is pushed to extreme, out-of-distribution values), causal (the proxy and the goal are correlated only via a shared cause, so manipulating the proxy directly fails to produce the goal), and adversarial (a strategic agent that knows a proxy is being used as a target deliberately games it). Natural selection has no representations and no agent doing any gaming; it is a blind filter on heritable variation, not an optimizer with a target in any representational sense.

Weigh the strongest version of both readings, then write an essay that reaches and defends a definite verdict: is "evolution Goodharted on fitness" a substantive, non-metaphorical claim about the structure of natural selection, or a category error dressed up as biology? Say explicitly which of the four Goodhart failure modes, if any, survive translation into an agent-free process like natural selection, and which do not, even in principle.
