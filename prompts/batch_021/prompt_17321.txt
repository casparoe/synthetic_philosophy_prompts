Question posed to students: "Explain why Kripke holds that a true identity statement between two rigid designators, such as 'Hesperus is Phosphorus' or 'Water is H2O,' is necessarily true, yet knowable only a posteriori. Your answer should (a) reconstruct the modal argument Kripke uses against descriptivist theories of proper names, (b) explain what distinguishes a rigid designator from an ordinary definite description, and (c) explain why cases like these undermine the traditional, broadly Kantian assumption that the necessary/contingent distinction and the a priori/a posteriori distinction simply track one another."

Student's answer: "Kripke's main target in Naming and Necessity is the descriptivist theory of proper names associated with Frege and Russell, and later refined into a 'cluster' version by Wittgenstein and Searle, on which a name like 'Aristotle' is simply shorthand for some description, or cluster of descriptions, that competent speakers associate with it, such as 'the teacher of Alexander the Great.' Kripke's modal argument against this view is that if 'Aristotle' just meant 'the teacher of Alexander,' then 'Aristotle taught Alexander' would be true in every possible world in which Aristotle exists, since it would just say that the teacher of Alexander taught Alexander. But intuitively there are possible worlds in which Aristotle exists yet never teaches anyone, so the name and the description diverge in their modal behavior, and the simple description theory must be mistaken.

This divergence is explained by the fact that 'Aristotle' is a rigid designator: it picks out the same individual in every possible world in which that individual exists. Definite descriptions, by contrast, are non-rigid designators by definition: they pick out whatever object happens to satisfy the description at a given world, and different objects can satisfy the same description in different worlds. Kripke extends the same reasoning to identity statements between two rigid designators, such as 'Hesperus is Phosphorus.' Since 'Hesperus' and 'Phosphorus' both rigidly designate the same object, Venus, and identity is a relation an object bears only to itself, the identity cannot fail to hold in any world in which Hesperus exists; the statement is therefore necessarily true if true at all.

Yet ancient astronomers, who used 'Hesperus' for the object seen in the evening sky and 'Phosphorus' for the object seen in the morning sky, did not know that these picked out one and the same planet; they discovered this by astronomical observation, not by reasoning about the meanings of the two names, so the identity is knowable only a posteriori. Once the two names' reference has been fixed to the same object, though, the identity becomes transparent in the way any true identity statement is transparent: because a rigid designator refers to its object directly, rather than by way of some condition the object happens to satisfy, a speaker who has grasped that 'Hesperus' and 'Phosphorus' are both just rigid tags for one and the same planet needs no further empirical input to see that the identity holds, any more than she needs empirical input to see that 'Hesperus is Hesperus' holds. The water/H2O case works the same way: chemists discovered empirically that water is H2O, but because both terms rigidly designate the same substance, the identity, once fixed, is a necessary truth about the essence of that substance.

This matters because the traditional picture, which one finds in some form in Kant, treats necessity and apriority as running together: necessary truths are supposed to be the business of pure reason, while only contingent matters of fact require the senses. Kripke's cases show that this alignment does not hold generally: 'Hesperus is Phosphorus' and 'water is H2O' are necessary, yet a posteriori, so the necessary/contingent distinction, which is a metaphysical matter about how things could have been, and the a priori/a posteriori distinction, which is an epistemological matter about how a truth can be known, are in principle independent of one another, even though in ordinary cases they tend to coincide."
