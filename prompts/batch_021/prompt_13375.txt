A few years into retirement from a career in developmental biology, I've been reading philosophy of biology in earnest, and I keep coming back to Marcello Barbieri's "code biology," which tries to make the old slogan that DNA is a code literally true rather than a convenient metaphor. Barbieri's test for a genuine code is specific: there must be a physical adaptor enforcing a correspondence between two independent classes of entities, and that correspondence must be arbitrary — not fixed by any steric or chemical necessity. This is exactly the gap Crick's original adaptor hypothesis was meant to close, later borne out when tRNA, rather than any direct codon-amino-acid affinity, turned out to do the pairing. Wherever such an arbitrary, adaptor-enforced rule persists across generations, Barbieri counts it as a genuine semiotic code rather than a metaphor, extending the idea well beyond the genetic code itself to splicing and signal-transduction pathways.

I'd like you to argue against this test: that a fully arbitrary, adaptor-enforced correspondence of exactly this kind still falls short of a genuine semiotic code, because mere arbitrariness of pairing is not yet the normativity — some standard for correct versus incorrect "readings" — that any real semiotic relation requires. Please engage directly with whether selection-based normativity, of the sort teleosemantic theories invoke, could supply what's missing here, and if it cannot, say precisely where it runs out.
