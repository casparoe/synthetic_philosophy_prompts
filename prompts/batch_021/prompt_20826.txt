Question: Using the framework developed in *Naming and Necessity*, explain why "Hesperus is Phosphorus" is an instance of the necessary a posteriori. Your answer should address (a) what makes an expression a rigid designator, (b) how Kripke's modal argument tells against the classical description theory of names, and (c) how the case of the standard meter bar shows that the necessary/contingent distinction is independent of the a priori/a posteriori distinction.

Student's answer:

"A rigid designator is an expression that denotes the same object in every possible world in which that object exists, as opposed to a non-rigid ('accidental') designator, which can pick out different objects relative to different worlds. Ordinary proper names such as 'Hesperus' and 'Phosphorus' are rigid: however differently we imagine the world, 'Hesperus' still names Venus, even in a scenario where Venus never became visible from Earth at dusk. This is precisely where Kripke parts ways with the classical description theory of names -- the view, running from Frege and Russell through the looser 'cluster' versions in Wittgenstein and Searle, and before them Mill, that a name is cognitively equivalent to some description(s) competent speakers associate with its bearer. Kripke's modal argument is that this cannot be right: if 'Hesperus' simply meant 'the heavenly body visible at dusk,' then 'Hesperus is visible at dusk' would have to be necessarily true of Hesperus, true in every world in which it exists. But that is clearly false, since Venus could easily have never been visible at that hour; so whatever fixes the reference of a name like 'Hesperus,' it cannot be synonymy with a description of that sort.

Because 'Hesperus' and 'Phosphorus' both rigidly designate one and the same planet, 'Hesperus is Phosphorus' comes out true in every possible world where that planet exists -- the statement is necessary. Yet the identity was not at all obvious to the ancients, who fixed the two names by different contingent markers (roughly, 'that bright body in the evening sky' and 'that bright body in the morning sky') and had to discover, by observation and calculation, that one and the same object satisfied both descriptions. So a truth can be necessary and still only knowable a posteriori, because necessity concerns how things stand in every possible world, while apriority concerns how we come to know that they do.

Kripke uses the Paris meter bar to make a parallel point. 'The standard meter is one meter long' is, like the Hesperus case, a statement we can only confirm a posteriori, by consulting the bar itself, and it too turns out to be necessary once the bar has been fixed as the very standard against which length is measured. Together, the two cases show that necessity is a matter of metaphysics and apriority a matter of epistemology, and that neither can be read off from the other."
