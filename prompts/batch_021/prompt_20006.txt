"Again, if a thing is white now, it was true before to say that it would be white, so that of anything that has taken place it was always true to say "it is" or "it will be." But if it was always true to say that a thing is or will be, it is not possible that it should not be or not be about to be, and when a thing cannot not come to be, it is impossible that it should not come to be, and when it is impossible that it should not come to be, it must come to be.
