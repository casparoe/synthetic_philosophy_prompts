Here is my partner's answer:

"Löb's theorem is a result about formal systems strong enough to express their own provability, such as Peano Arithmetic. It states that for any sentence P, if a system F can prove 'if P is provable in F, then P,' then F can already prove P outright: if F ⊢ Prov_F(P) → P, then F ⊢ P. Gödel's Second Incompleteness Theorem is just the special case where P is a contradiction: no consistent system can prove 'Prov_F(⊥) → ⊥,' which is just another way of saying no consistent system can prove its own consistency.

This creates a problem for a self-modifying AI system A that wants to hand decisions off to a successor system A'. The natural way for A to trust A' would be to adopt the rule 'whatever A' proves is true,' but if A' reasons in the same formal system as A, this rule is exactly the kind of reflection schema Löb's theorem rules out: A could only ever justify it for statements it could already prove on its own, so consulting A' first gives no additional assurance. A proof-based agent can never get a blanket, formal guarantee that an equally powerful reasoner's conclusions are trustworthy, even when that reasoner is a future version of itself.

Yudkowsky and Herreshoff's proposed workaround is to have each successive agent in a self-improving chain reason in a progressively stronger proof system than the one before it. Because a stronger system proves strictly more theorems, each new agent can formally verify actions that its predecessor couldn't even evaluate, and the predecessor is justified in trusting it precisely because it is more powerful, not less. This lets verified trust tile forward indefinitely as the system improves itself.

More recent work on logical induction has built on this to fully close the gap, giving agents a principled way to assign calibrated probabilities to self-referential claims and thereby dissolving the Löbian obstacle altogether."
