Two people in my formal epistemology reading group got into a running disagreement after last week's session, once we'd worked through Jim Joyce's 1998 paper on the "nonpragmatic vindication of probabilism" plus a chunk of Richard Pettigrew's book on accuracy-first epistemology, and I haven't been able to decide who came out ahead. The background, roughly: accuracy-first epistemologists argue that if your credences violate the probability axioms, there is always some alternative, probabilistically coherent assignment that is guaranteed to be at least as accurate as yours no matter how the world turns out, and strictly more accurate in at least one case -- so incoherence is a purely epistemic mistake, not merely a pragmatic one that only shows up if someone happens to offer you a bad bet.

(1) Naomi said this settles things in probabilism's favor: unlike Dutch book arguments, which need a betting setup and a bookie, the accuracy argument condemns incoherence on purely alethic grounds, comparing credence to truth-value alone, world by world, with no probabilities presupposed anywhere in the comparison. (2) Dev objected that "no probabilities presupposed" only holds for that one narrow theorem. Nobody actually stops there: the same accuracy-first toolkit gets used to argue that you should update by conditionalizing on evidence, that you should match your credence to a known chance, that one coherent credence function can be epistemically better than another, and so on -- and all of that works by computing expected accuracy, which requires a probability measure to average over. So the moment epistemic utility theory does any of the substantive work people actually want from it, it has already smuggled in a probability function to evaluate credences by. (3) Naomi replied that this isn't circularity so much as ordinary bootstrapping, no different from using an agent's current utility function to evaluate a prospective gamble in decision theory: something has to be held fixed at a time in order to evaluate anything at all, and that's not a defect peculiar to accuracy-first epistemology. (4) Dev answered that the analogy misleads: decision theory never promised to derive the existence of the utility function itself without presupposing preferences, whereas accuracy-first epistemology's whole selling point was deriving probabilism without presupposing anything probabilistic. If every application of the framework beyond the bare dominance theorem needs a probability function just to define "expected accuracy," then the celebrated nonpragmatic vindication covers only that one narrow result, and everything else epistemic utility theorists actually want -- norms for updating, for comparing agents, and so on -- rests right back on the probabilistic assumption the whole program was supposed to let us do without.
