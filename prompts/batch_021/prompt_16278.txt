I'm a backend engineer, and for the last couple of months I've been falling down a rabbit hole of old MIRI papers on self-modifying AI, mostly because a friend kept describing them as "distributed systems consensus, but with proofs instead of votes." The idea that has really gotten under my skin is what people call the Löbian obstacle. As I understand it: if a formal reasoner built on something like Peano arithmetic tries to fully trust its own proof system, in the strong sense of "whatever I can prove is thereby true," Löb's theorem shows this is a far more dangerous move than it sounds. Formally, if the system can prove the reflection schema Prov(⌜φ⌝) → φ — read as "if φ is provable, then φ is true" — for some sentence φ, Löb's theorem says it can then prove φ outright, full stop, which is disastrous if you can't independently guarantee that everything provable is genuinely true. It reminds me, loosely, of Ken Thompson's old "Reflections on Trusting Trust": you'd hope a system could simply certify a copy of itself, but once self-reference and trust get combined, things turn out to be far more delicate than a first pass suggests.

Where this stops being a curiosity and starts mattering, at least to my imagination, is the "tiling" scenario MIRI researchers describe: an agent that only acts on options it has proven safe wants to build, or become, a successor that reasons the same way, and would like to trust the successor's proofs exactly as much as it trusts its own. The Löbian obstacle seems to rule this out directly. I've since read about a couple of proposed escapes: Yudkowsky and Herreshoff's idea of having each successive agent drop down to a strictly weaker proof system via a schema they call "parametric polymorphism," so that no agent ever needs to trust a system exactly as strong as itself; and more radical departures, like Christiano's probabilistic reflection and Garrabrant's logical induction, which swap hard proof for calibrated probability assignments that can seemingly refer to themselves without hitting the same wall. What I haven't been able to settle for myself is whether any of this genuinely removes the obstacle, or whether it just relocates the same problem — down an infinite regress of ever-weaker systems, or behind a probability estimate instead of a certificate.

Could you write me an essay that settles this? Please state precisely what Löb's theorem does and does not forbid, then weigh the strongest case that the Löbian obstacle is a genuine, in-principle limit on self-trust for any formally reasoning agent against the strongest case that it is merely an artifact of insisting on proof-theoretic certainty — one that dissolves, rather than being solved, once hierarchical or probabilistic alternatives are allowed. Don't end on a fence-sitting note: tell me which side you think is actually correct, and defend it.
