For my seminar on formal epistemology, we've spent the last few weeks on Bostrom's framework for anthropic reasoning, and I'd like to think through the dispute between the Self-Sampling Assumption (SSA) and the Self-Indication Assumption (SIA) more carefully than our class discussion allowed. As I understand it, SSA underwrites something close to the classical Doomsday Argument but runs into the reference-class problem, whereas SIA blocks the Doomsday Argument only at the cost of the Presumptuous Philosopher objection. Write an essay that weighs these two costs against each other -- rather than simply laying out both positions -- and defends a definite verdict on which principle, if either, we should accept. A qualified verdict is fine (e.g., "accept SSA only when the reference class is non-arbitrary, and default to SIA otherwise"), but don't end on a merely non-committal note.
