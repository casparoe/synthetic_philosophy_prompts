"The St. Petersburg game: a fair coin is tossed until it lands tails for the first time. If the first tails appears on toss number n, you win 2^n dollars.
(a) [2 pts] Show that the expected monetary value of this game is infinite, and briefly explain why that's puzzling given that almost nobody would pay more than, say, $20 to play it once.
(b) [4 pts] Present Daniel Bernoulli's resolution of the puzzle. State the specific utility function he proposed and use it to compute the expected utility of the game. Does this explain the gap between the infinite expected value and people's actual willingness to pay?
(c) [4 pts] Some later commentators (Karl Menger among them) objected that Bernoulli's fix doesn't actually work in general. Explain the objection, and state precisely what condition a utility function has to satisfy in order to be fully immune to it."

And here's the student's answer, typed up exactly as submitted (I cleaned up a couple of stray LaTeX symbols but didnt touch the substance):

(a) Let X be the payout. P(first tails on toss n) = (1/2)^n and the payout on that toss is 2^n dollars, so E[X] = Σ_{n=1}^∞ (1/2)^n · 2^n = Σ_{n=1}^∞ 1, which diverges to infinity. So a risk-neutral expected-value maximizer should in principle be willing to pay any finite amount to play once. This is puzzling because obviously no reasonable person would actually hand over, say, $1,000 to play -- so maximizing expected monetary value clearly isn't how people do or should evaluate this game.

(b) Bernoulli's fix was to say that the psychological value of money doesn't scale the same way the money itself does -- each extra dollar is worth a little less to you than the last one, i.e. money has diminishing marginal utility. He proposed u(w) = ln(w). Redoing the calculation in terms of expected utility instead of expected cash: E[u(X)] = Σ (1/2)^n ln(2^n) = ln(2) · Σ n/2^n, and since Σ_{n=1}^∞ n/2^n = 2, this comes out to 2ln(2) ≈ 1.39, a perfectly ordinary finite number. So switching to utility brings the value of the game back down to something reasonable, and this will happen for any utility function with the diminishing-marginal-utility property, since that's exactly what stops the sum from blowing up the way the raw dollar amounts do.

(c) The objection (Menger's, among others) is that you can always rig the prizes to grow faster than whatever utility function you're using can keep up with. E.g. instead of paying 2^n dollars, pay e raised to the 2^n power (i.e. e^(2^n) dollars). Under Bernoulli's own log utility, u(e^(2^n)) = ln(e^(2^n)) = 2^n, so E[u(X)] = Σ (1/2)^n · 2^n = Σ 1 = ∞ again -- we're straight back to the original paradox, just one level up. And since you could obviously repeat this trick on whatever new function someone proposes next, Menger's conclusion was that no utility function can ever be made fully safe from a sufficiently aggressive St. Petersburg-style game, so Bernoulli's move doesn't really solve the paradox, it just kicks the can down the road.
