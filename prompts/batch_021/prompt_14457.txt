And here's Malik's answer, copied word for word:

"Gödel's incompleteness theorem says that for any formal system powerful enough to do arithmetic, if the system is consistent then it can't prove all true statements about numbers -- there's always some true sentence, the Gödel sentence G, that the system can't prove from inside itself. J.R. Lucas used this to argue that minds aren't machines: if a machine's mathematical output could be captured by some consistent formal system F, the machine could never prove G_F, but a human mathematician looking at the system from outside can just see that G_F is true. Since the human can do something F provably can't do, the human isn't equivalent to F, and since F was any machine you like, the human isn't equivalent to any machine. Gödel actually agreed with this and used the theorem himself to argue the mind could never be fully replaced by a computer, which is part of why people still take the argument seriously -- it's not just some philosopher's pet theory, it's Gödel's own result taken to its natural conclusion.

Roger Penrose tried to strengthen this in Shadows of the Mind by rebuilding the argument around soundness instead of consistency, which is actually a weaker assumption to make about the machine, so his version is supposed to dodge Hilary Putnam's famous objection that a person can never be sure their own reasoning is consistent (people believe false and contradictory things all the time, so we're never entitled to assume whatever system captures our math ability is consistent, which means we can't run Lucas's argument on ourselves in the first place). Even so, I don't think the overall argument fully works, because even if you can rule out any one specific machine F this way, that only shows no machine we can explicitly name and verify is consistent could be a perfect model of the mind -- it doesn't rule out that the mind just is some machine, just one whose exact program we could never identify or prove things about from the inside. So Gödel's theorem is a real challenge for strong AI, but I don't think it actually proves mechanism is false."
