Here is the question from the exam, worth 20 points, followed by one student's answer in full:

**Question:** "Solomonoff's model of inductive inference grounds probability assignments in algorithmic (Kolmogorov) complexity. (a) Define Kolmogorov complexity and explain in what sense it is machine-independent. (b) Explain how the Solomonoff–Levin universal prior is built from Kolmogorov complexity, and in what sense this construction can be said to formalize Occam's razor. (c) Solomonoff induction is known to be uncomputable. Explain why, and briefly assess whether this uncomputability limits its usefulness as a normative ideal for inductive reasoning."

**Student's answer:** "Kolmogorov complexity K(x) of a string x is defined as the length of the shortest program that outputs x when run on a fixed universal Turing machine U. Although this definition seems to depend heavily on the choice of U, the invariance theorem shows that this dependence is not serious: for any other universal machine V, the complexities K_U(x) and K_V(x) can differ by at most a multiplicative constant that does not depend on x (only on U and V), since one machine can always simulate the other via a fixed 'compiler' program. This is what licenses talk of 'the' Kolmogorov complexity of a string without always specifying the machine.

The Solomonoff–Levin universal prior turns descriptive length into a probability. Roughly, the prior probability assigned to a string x is M(x) ≈ 2^-K(x): strings with short descriptions get higher prior probability than strings that require long descriptions. Since a hypothesis or environment can itself be encoded as a program, this assigns higher prior credence to simpler hypotheses, which is exactly the content of Occam's razor. Because M is a universal semimeasure — it dominates every lower semicomputable semimeasure up to a multiplicative constant — Solomonoff induction using M as a prior can be shown to converge to the true generating distribution as data accumulates, provided the true distribution is itself computable.

Solomonoff induction is uncomputable because M(x) is defined as a sum over all programs that output x, and there are infinitely many candidate programs to check. Verifying the contribution of every program would require running each one to see whether it halts and produces the right output, and since this has to be done for infinitely many programs, no finite computation can ever finish evaluating the sum — it would take infinite time. In that sense Solomonoff induction is an uncomputable idealization much like a Carnot engine is a physically unrealizable idealization in thermodynamics: nothing real ever fully instantiates it, but it still functions as a regulative ideal against which real, resource-bounded methods like MDL-based learning can be measured and justified as approximations."
