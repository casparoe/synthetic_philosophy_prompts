An argument sometimes called the Rietdijk–Putnam argument—which Roger Penrose dramatized as the "Andromeda paradox"—runs as follows: because of the relativity of simultaneity in special relativity, there is no observer-independent fact about which distant events are happening "now." But presentism holds that only what is present is real, so if there is no frame-independent "now" for presentists to point to, it looks as though relativity alone has settled the presentism/eternalism debate in eternalism's favor. Given this, why do some serious philosophers of time still defend presentism rather than treating it as a position that twentieth-century physics has already refuted?
