Question (20 points): Explain the central difference between David Lewis's counterfactual theory of causation and James Woodward's interventionist theory of causation. Your answer should cover: (1) how each theory cashes out the claim "C caused E," (2) how each theory accounts for the asymmetry of causation (why we don't normally say the effect caused the cause), and (3) what verdict each theory delivers on the following case, and why:

Ann and Ben are both throwing rocks at the same window. Ann's rock is thrown a fraction of a second earlier and hits first, shattering the glass. Ben's rock, thrown just as hard, would have arrived a split second later and shattered the window anyway if Ann's rock hadn't gotten there first. Did Ann's throw cause the window to break?

Classmate's answer: Lewis's theory says that C causes E just in case E counterfactually depends on C: if C hadn't happened, E wouldn't have happened either. He cashes this out with his possible-worlds semantics for counterfactuals — "if C hadn't occurred, E wouldn't have" is true iff, in the closest possible world(s) where C doesn't occur, E doesn't occur either, where "closest" is measured by overall similarity to the actual world. To get the direction of causation right, so that effects depend on causes and not the other way round, Lewis stipulates that we only compare worlds where the past before C is held fixed and only the future after C is allowed to vary, which is what rules out the effect "counterfactually causing" the cause.

Woodward's interventionist theory instead says C causes E iff there's some possible intervention on C — an idealized, surgical change that alters C without affecting anything else except through C — that would be associated with a change in E, holding everything else in the system fixed. This is usually cashed out with structural equations and causal graphs instead of Lewis's similarity-of-worlds machinery, and it lets you distinguish genuine causes from mere correlates or common effects, since you're specifically asking what happens when you reach in and change C directly, rather than what happens when C changes for some other reason.

For the rock case: on Lewis's theory, the window's shattering doesn't counterfactually depend on Ann's throw, because if Ann hadn't thrown, Ben's rock would have shattered the window a moment later anyway — so strictly, Lewis's theory says Ann's throw wasn't a cause, which looks like the wrong answer. But this isn't really a disagreement between the two theories so much as a limitation of stating the counterfactual too coarsely; once you write out the structural equations properly, Woodward's theory ends up asking exactly the same "what if Ann hadn't thrown" question Lewis asks, just with the extra vocabulary of "interventions" layered on top, so it inherits the same problem and doesn't give us any principled way to say Ann's throw was the cause and Ben's wasn't.
