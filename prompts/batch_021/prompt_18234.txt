"A rigid designator is a term that picks out the same object in every possible world in which that object exists, and doesn't designate anything in worlds where it doesn't exist. Kripke's main examples are proper names: 'Aristotle' refers to that one man in any counterfactual situation we describe, even ones where he never studied philosophy at all. This backs up the modal argument against descriptivism. If 'Aristotle' just meant something like 'the teacher of Alexander,' then in a possible world where somebody else tutored Alexander, the description would pick that other person out, so the name would too. But that's not what we say -- we say Aristotle himself might never have taught Alexander. So the name stays fixed on Aristotle across worlds while the description doesn't, which shows the name can't just be short for the description. More generally, definite descriptions are never rigid designators, since whatever satisfies 'the F' can differ from world to world.

A good necessary a posteriori example besides Hesperus/Phosphorus is 'water is H2O.' 'Water' and 'H2O' both rigidly designate the same stuff, so if the identity holds at all, it holds in every world -- there's no world where water fails to be H2O, because the indiscernibility of identicals guarantees that once two rigid designators pick out one thing, they can't come apart in any world. But obviously nobody could figure this out just by thinking hard about the concepts water and H2O -- you need actual chemistry -- so it's a posteriori. In that sense the necessity here is really just a logical consequence of how the terms refer, which is why it counts as analytic in Kripke's sense even though it's discovered empirically.

The contrasting case, contingent a priori, is Kripke's stick S: if 'one metre' is stipulated to mean the length of stick S at t0, then 'S is one metre long at t0' is knowable a priori by whoever fixes the term that way, yet its contingent, since S might have been a different length at t0 if conditions had been different."
