Then, using Bostrom's Presumptuous Philosopher case, explain why that thought experiment is usually taken to pose a special problem for one of the two assumptions. And here's my classmate's answer:

"The Self-Sampling Assumption (SSA) says that, absent other information, you should reason as if you're a random sample from the set of all observers who actually exist in your reference class -- past, present, and future. So if you're trying to figure out how many humans there will ever be, SSA has you imagine yourself as a randomly chosen member of that whole set, which is the move that powers the Doomsday Argument: since it would be a pretty big coincidence for me to be among, say, the earliest 100 billion humans if trillions more are still to come, SSA says I should update toward thinking the total number of humans who will ever live is relatively small, i.e. that it's quite likely humanity goes extinct within the next handful of centuries rather than persisting for a very long time.

The Self-Indication Assumption (SIA) instead has you reason as if you were a random sample from the set of all possible observers, which ends up favoring hypotheses on which more observers exist, because you were more likely to exist at all if there are more people like you to be. SIA was basically introduced to cancel out the Doomsday Argument, since it pulls in exactly the opposite direction from SSA and the two updates offset each other.

Bostrom's Presumptuous Philosopher case has two cosmological theories, T1 and T2, that are equally well supported by all the evidence so far, except T2 implies the universe contains way more observers than T1 does. Physicists are about to run an expensive experiment to settle which theory is right, but a philosopher steps in and says there's no need, because SSA already tells us T2 is enormously more probable, since it's the theory on which there are more observers like us. This looks absurd -- it can't be right that armchair reasoning about population sizes should out-vote an actual physics experiment -- so the case is usually taken to be a serious problem for SSA specifically.

Given that, you might think switching to SIA gets you out of trouble for free, but I don't think it does -- SIA has its own baggage, e.g. it behaves weirdly once you allow infinite numbers of observers, so neither assumption seems to let you dodge every anthropic paradox at once."
