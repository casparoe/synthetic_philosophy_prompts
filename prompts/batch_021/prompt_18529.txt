Spent thirty-five years as a condensed matter physicist, and only started reading philosophy seriously after I retired, so bear with me if this is naive. I keep coming across this idea called "program equilibrium" -- apparently if two agents can inspect each others source code before playing a game, they can each write a little checker program that only cooperates if the other one's code checks out, and this turns mutual cooperation into a genuine equilibrium of the prisoner's dilemma. Feels to me like this basically closes the case: once AIs (or firms, or countries) can just show each other their code, defecting stops being rational and cooperating becomes the correct, forced move. Is that the right takeaway, or am I overselling what the result actually shows?
