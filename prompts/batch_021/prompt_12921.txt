Question set to the group:

Consider a proof-based agent A that reasons in a consistent, sufficiently expressive formal system S (say, Peano Arithmetic), whose provability predicate Prov_S satisfies the Hilbert–Bernays–Löb derivability conditions. Suppose A is contemplating a one-shot self-modification into a successor A′ that also reasons in S, and that A will perform the modification only if it can first prove, inside S, the blanket schema "for every sentence φ, if A′ proves φ using S, then φ is true" — rather than verifying the safety of A′'s specific actions case by case.

(a) State Löb's theorem precisely, and explain why it, rather than Gödel's second incompleteness theorem on its own, is what actually obstructs A in proving that schema.
(b) Explain what this "Löbian obstacle" shows about the general prospects for a proof-based agent trusting a successor (or its own future self) reasoning at the same deductive strength.
(c) Sketch the standard proposal of having the successor reason in a proof system related to, but different from, the parent's, and state honestly what this proposal costs the agent.

Submitted answer:

Löb's theorem states that for any sentence φ, if S proves "Prov_S(φ) → φ," then S already proves φ outright: a consistent system can never obtain a free-standing soundness guarantee about a sentence it hasn't independently secured. Gödel's second incompleteness theorem is the special case where φ is an absurdity like 0=1: since S already refutes 0=1 as a basic arithmetic fact, the sentence "Prov_S(0=1) → 0=1" is classically equivalent to "¬Prov_S(0=1)," i.e., to the statement that S is consistent, so this instance of Löb's theorem is exactly the statement that a consistent S cannot prove its own consistency. Löb's theorem is the general engine, then, and Gödel's theorem is a single gear inside it — which is exactly why citing Gödel II alone doesn't explain A's predicament: A is not trying to prove Con(S), it is trying to secure a soundness schema for an open φ, and it's precisely that generality, not the narrower fact about consistency statements, that defeats A.

This generality is what sinks A's plan: the blanket trust schema is exactly an instance of "Prov_S(φ) → φ" with φ left open, so if A could prove it inside S, Löb's theorem would force S to prove every φ that A′ might ever produce, which cannot hold for any φ A hasn't already settled by other means. Notice that the argument never turns on A′ being A's own successor rather than some unrelated agent B that happens to reason in the same system S; two strangers trying to certify each other's proofs in advance would hit exactly the same wall, so the obstacle is really about self-reference rather than about self-modification as such. It also follows that A cannot dodge the problem by checking A′'s proofs one at a time instead of licensing them all in advance: since each individual reflection instance is itself governed by the same "only if already proved" clause, case-by-case verification is exactly as blocked as the blanket schema, so a proof-based agent cannot delegate any of its reasoning to a successor without redoing every derivation itself.

The standard patch is to have A′ reason in a system S′ that is strictly stronger than S — for instance, S together with an extra axiom asserting Con(S) — so that A ends up trusting a provability predicate that isn't its own, and the schema it actually needs, "Prov_S′(φ) → φ," proved inside S, falls outside anything Löb's theorem governs. This lets the successor relation tile at essentially no cost to A: because each successor's system is a proper extension of its parent's, capability only increases down the chain, and the Löbian obstacle ends up fully dissolved rather than merely deferred to the next generation.
