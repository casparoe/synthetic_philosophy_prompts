I. J. Good's theorem on the value of information establishes that a Bayesian agent facing a single, fixed decision problem can never expect cost-free information to lower the expected utility of the action they eventually choose, since the agent always retains the option of ignoring it. This result is routinely generalized into the broader maxim that a rational agent should always attach non-negative value to becoming better informed, including when that agent is embedded in a strategic interaction with other agents rather than facing an isolated decision problem. Please argue against this generalization, drawing on at least one concrete case in which a fully rational, Bayesian agent's own expected payoff is strictly lower for having, or being known by others to have, additional information.
