"An AI that only takes an action once it has a formal proof that the action is safe seems like a great way to avoid catastrophic mistakes, since it never acts without a guarantee. The trouble comes when this AI wants to build (or become) a successor that reasons the same way, and it wants to be sure that if the successor proves 'this action is safe,' the action really is safe. This is where Löb's theorem comes in: it says that for a formal system, if the system can prove the statement 'if this is provable, then it's true,' then the system can actually prove the statement itself. So if our AI tries to build in a general rule that says 'anything my successor proves is trustworthy,' Löb's theorem guarantees that the moment the successor's proof-checker outputs a proof of some sentence P, P must really hold, because the checker is only ever allowed to certify implications that are already backed by truth. This sounds reassuring, but it's actually the obstacle: Gödel's second incompleteness theorem is basically a special case of this, showing a system can't prove its own consistency, and Löb's result shows the same thing happens for any P, not just consistency, so a system can never fully bootstrap trust in a copy of itself using proofs alone. The tiling agents idea (which comes out of Bostrom's discussion of self-improving AI in Superintelligence) gets around this by having each new generation of the AI use a strictly more powerful proof system than the last, so each successor can actually verify things the previous one couldn't, which breaks the self-reference loop and lets trust flow forward through the generations."
