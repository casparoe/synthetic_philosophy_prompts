In the framework of program equilibrium (introduced by Tennenholtz), players in a game such as the Prisoner's Dilemma submit programs rather than actions, each program able to inspect its counterpart's code before computing a move, so that mutual cooperation can be sustained as a self-enforcing equilibrium even in a single, non-repeated encounter; later refinements using provability logic secure this same result without requiring the two programs to be textually identical. Please describe the most important implications of program equilibrium for the classic Hobbesian worry that covenants between mutually distrustful parties are worthless without a sword to enforce them. I'm especially interested in whether two hostile states could reasonably entrust a one-off, simultaneous disarmament decision to automated systems that first exchange verified source code, and in what would still be missing, philosophically, from such an arrangement.
