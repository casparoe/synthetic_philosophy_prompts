Here is the question as it appeared on the problem set (worth 10 points total):

"Consider the St. Petersburg game: a fair coin is tossed repeatedly until it lands heads for the first time. If heads first appears on toss k, the player receives a payout of 2^k dollars. (a) [4 pts] Show that the expected monetary value of this game is infinite, and briefly explain why this seems to conflict with the intuition that no reasonable person would pay, say, $1,000 for a single play. (b) [6 pts] Daniel Bernoulli's classic resolution evaluates the game by expected utility rather than expected value, using u(x) = ln(x). Compute the expected utility of the game under this assumption and confirm that it is finite. Then discuss: does adopting a concave, strictly increasing utility function like ln(x) provide a fully general solution to St.-Petersburg-style paradoxes — that is, does it guarantee that an expected-utility maximizer can never be driven to pay an unbounded amount for some lottery of this general form? Justify your answer with reference to the wider literature on the paradox."

And here is the student's answer, verbatim:

"(a) The expected value is E[X] = Σ_{k=1}^∞ (1/2)^k · 2^k = Σ_{k=1}^∞ 1, which diverges to infinity. This conflicts with intuition because virtually everyone has bounded wealth and strongly diminishing tolerance for risk, and because the probability of any specific large payout is vanishingly small even though the payouts themselves grow without bound — a casino offering this game would in any case go bankrupt long before it could honor an arbitrarily large draw, so the 'infinite value' is really a mathematical idealization rather than something anyone could ever actually collect.

(b) Under u(x) = ln(x), the expected utility is E[u(X)] = Σ_{k=1}^∞ (1/2)^k · ln(2^k) = ln(2) · Σ_{k=1}^∞ k/2^k = 2 ln(2) ≈ 1.386, which is finite. This shows that evaluating the lottery in utility terms rather than dollar terms dissolves the paradox: because ln(x) grows so much more slowly than x, the shrinking probabilities eventually overwhelm the much more slowly growing utility of the prizes, and the sum converges. Crucially, this is a fully general fix and not a special feature of this particular gamble: Bernoulli's insight was that as long as an agent's utility function is concave — i.e., displays diminishing marginal utility of wealth, which is standard in economics anyway — expected-utility maximization can never recommend paying an unbounded price for a lottery of unbounded expected monetary value. Bernoulli was the first to see this, and the idea proved influential enough that Cramer soon afterward proposed a similar square-root utility function as an alternative route to the same conclusion. This is why Bernoulli's paper is generally credited with fully dissolving the St. Petersburg paradox, and why diminishing marginal utility of wealth is still treated as the theoretical ancestor of risk-aversion assumptions in expected-utility theory."
