Question 3 (20 points). In standard Hintikka-style epistemic logic, an agent's knowledge is modeled by a Kripke frame ⟨W, R⟩ together with a valuation, where "Kφ" is true at world w just in case φ is true at every world accessible from w via R.

(a) [8 points] Explain why this semantics has the consequence that (i) agents know every valid formula of the language, and (ii) an agent's knowledge is closed under known material implication (if the agent knows φ and knows that φ→ψ, the agent knows ψ). This joint consequence is often called the problem of logical omniscience.

(b) [12 points] Choose ONE of the following two proposals for addressing the problem of logical omniscience — awareness logic, or impossible-worlds semantics — and explain, with reference to its formal machinery, how it blocks (i), (ii), or both. Then identify one significant respect in which your chosen proposal fails to fully dissolve the problem, or otherwise incurs a theoretical cost.

Student's answer:

(a) On this semantics, Kφ holds at w iff φ holds at every world R-accessible from w. If φ is valid, it is true at every world in every model whatsoever, so in particular at every world accessible from w; hence Kφ holds at w no matter what R looks like, for any agent and any world. For closure: suppose Kφ and K(φ→ψ) both hold at w. Then φ and φ→ψ are true at every world accessible from w, so by modus ponens ψ is true at every one of those worlds too, and Kψ holds at w. Iterating this argument, knowledge is closed under logical consequence quite generally. Both results trace back to defining knowledge as truth-in-a-set-of-worlds rather than as a cognitive achievement, so the model has no way to distinguish an agent who has actually drawn out some logical consequence from one who merely could, in principle, do so.

(b) I'll take awareness logic. Hintikka's proposal augments each world with an "awareness set" A(w) of formulas the agent is actually attending to, and defines explicit knowledge as Xφ := Kφ ∧ φ ∈ A(w) — implicit knowledge plus awareness. Since an agent can fail to be aware of some tautology even though it is true at every accessible world, Xφ need not hold for every valid φ, which blocks (i) for explicit knowledge; likewise, the agent can know φ and φ→ψ implicitly without being aware of ψ, which blocks closure for X. This amounts to a full solution: once we relativize knowledge-ascriptions to the explicit operator, which is arguably the one that matters for ordinary claims about what someone "knows," the agent is no longer required to have drawn out every consequence of what they know, so logical omniscience simply disappears as a problem for explicit knowledge, at essentially no formal cost beyond adding one extra function to the model.
