I've been teaching myself game theory by writing a small solver for two-player normal-form games, partly just to turn the textbook definitions into working code, and the step that keeps tripping me up is iterated elimination of dominated strategies. Every source I've read insists that a pure strategy counts as dominated if some mixed strategy strictly outperforms it against every strategy the opponent might play, not only if some other single pure strategy does. Since the whole point of the procedure is to strip out every strategy that no rational player would ever use, I don't see why that distinction should matter in practice. If a row in the payoff matrix is genuinely irrational, surely some specific alternative row should already beat it everywhere, so comparing pure strategies pairwise ought to catch everything a blend of strategies could catch. On that assumption, I simplified my implementation to only compare pure strategies against each other, on the reasoning that this must yield the same reduced game as the full mixed-strategy version, just with less code to maintain. Is that a safe simplification, or is there a real gap between the two procedures that I'm missing?
