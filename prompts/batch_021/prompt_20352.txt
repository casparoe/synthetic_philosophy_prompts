In my work with automated theorem provers I regularly use Skolemization -- replacing an existentially quantified variable with a fresh function of the preceding universal variables so a formula can be converted into clausal form for resolution. I recently learned, to my surprise, that this technique is named after the same Thoralf Skolem behind "Skolem's paradox": the fact that if ZFC has a model at all, the Löwenheim-Skolem theorem guarantees it has a countable one, even though ZFC itself proves that uncountable sets exist. I have no formal training in logic or set theory beyond what automated reasoning work requires, so please don't assume familiarity with model-theoretic jargon. Rather than just asserting that "uncountability is relative to the model," could you use the Skolem-function connection itself to build real intuition for how a countable model ends up containing a set it insists has no bijection with the natural numbers, and explain why Skolem himself treated this as a genuine problem for set theory's claim to describe an absolute universe, rather than as a curiosity that a working mathematician can shrug off?
