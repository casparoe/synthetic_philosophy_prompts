so this has been rattling around in my head since it came up on an ACX open thread a while back. everyone in the rationalist blogosphere loves quoting Popper on falsifiability, and honestly the whole reason this site is called LessWrong is basically a nod to the idea that a theory can be closer to the truth without being fully true. so I went and actually read up on how Popper tried to formalize that idea (he called it "verisimilitude," in Conjectures and Refutations), and it turns out his actual definition is famously broken. Tichý and Miller apparently proved, independantly of each other back in '74, that under Popper's own definition you can basically never say that one false theory has more verisimilitude than another false theory — the ordering only ever lets a true theory beat a false one. Which is useless for real science, since per Popper's own fallibilism basically every theory we've ever had, including all of physics, is false.

From some old SEP article on this I saw that people like Niiniluoto and Oddie tried to rescue the whole idea using "similarity to the truth," measured over possible worlds, instead of Popper's logical-content approach. But then there's apparently a "language dependence" problem where which theory counts as closer to the truth can flip depending on which properties you treat as the basic/primitive ones in your description language, which sounds like it would sink the possible-worlds fix just as badly. I don't have the technical background to work through this myself, and when I asked the one friend I have who's doing a philosophy PhD she just kind of shrugged. Can you lay out the strongest version of the argument that the whole verisimilitude project — Popper's original content-based version and the later similarity/possible-worlds patches alike — is a dead end, in the sense that there's no way to make "theory A is objectively closer to the truth than theory B" well-defined once A and B are both false? kind of a funny (or uncomfortable) conclusion given what this whole site is named after, but I'd rather know if it's true than not.
