Ok so I've been falling down a rabbit hole for a piece on genomics hype and I keep running into this fight over whether "the genetic code" is an actual code or just a metaphor we got too comfortable with. The skeptical camp (Sarkar and a few other philosophers of science writing in the 90s, if I'm remembering right) basically argue that "information" talk in molecular biology just means correlation or causal specificity dressed up in fancier language — a gene variant "encoding" a trait is really no different in kind from smoke correlating with fire, and nobody thinks smoke is a code for fire. But then I found this biosemiotics argument (Barbieri, I think is the name) that tries to actually earn the word "code" instead of just asserting it: the pairing between a codon and "its" amino acid isn't chemically forced the way a lock fits a key — nothing about a codon's physical structure requires it to go with one particular amino acid over another. The pairing only holds because a third party enforces it: aminoacyl-tRNA synthetases, which "charge" each tRNA with whatever amino acid the system happens to have assigned to it. His move is that this arbitrariness-plus-enforcer setup is structurally the same thing that makes a word or a Morse letter a real code (the sound "dog" has no natural link to the animal either, and it takes a separate convention to fix that pairing) — which would make DNA a code in a pretty deep sense, not just something we call a code becuase its a handy figure of speech.

Can you actually run with that argument for me and make it as strong as possible? Lay out why the codon/amino-acid pairing clears a genuine "this is a code, not merely a correlation" bar in a way that, say, a SNP-trait association or an epigenetic mark might not — and be explicit about what you think is doing the real work (the arbitrariness, the independent enforcing mechanism, both, neither). Then, since I don't want to fall for a cute analogy, turn around and give me the best objection to the whole argument, and tell me straight whether you think the "DNA really is a code" claim survives it.
