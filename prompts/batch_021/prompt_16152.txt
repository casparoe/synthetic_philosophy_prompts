I went down a bit of a rabbit hole a while back reading about "program equilibrium" in game theory -- the setup where instead of picking an action directly, each player submits a program that gets to read the other player's source code before outputting a move. The classic trick for getting cooperation out of a one-shot Prisoner's Dilemma this way is almost insultingly simple: submit a program that cooperates if and only if the other program's source code is identical to its own, and defects otherwise. I get why that's technically a Nash equilibrium of the "program game" -- deviating just makes you loose the cooperative payoff for nothing -- but it feels like a cheat, more like two programs recognizing a shared password than anything that shows genuine rational trust between agents. It also seems to dodge what I'd assumed was the actually hard problem here, namely that if each program tried to simulate what the other one would do, you'd run straight into an infinite regress (or the halting problem), so just comparing source code as text feels like it's sidestepping the interesting part of the puzzle rather than solving it.

Turns out people weren't fully satisfied with the identical-code trick either, because I've since come across folks using Löb's theorem and provability logic (I think this is the "FairBot" / modal combat stuff that comes out of the MIRI orbit) to get two programs to cooperate even when they aren't textually identical, just both running some kind of bounded proof search over each other's behavior. I don't have a solid feel for the mechanics though: why does searching for a proof that "the other guy cooperates with me" avoid the same regress problem that direct simulation runs into, and what is it about Löb's theorem specifically that makes the self-reference resolve cleanly instead of blowing up? I'm also curious whether this "fixed" version secretly has the same shape as the identical-source-code trick, just one level more abstract, i.e. is it still basically "cooperate with things sufficiently similar to yourself," just with a much more generous notion of similarity? Could you actually walk through the mechanics here rather than just gesturing at "Löb's theorem solves it," and be honest about where the approach is still shaky or contested.
