Here's the student's answer, copied over pretty much as submitted:

"Let S be the collection of all linearly independent subsets of V, partially ordered by inclusion. S is nonempty since the empty set is vacuously linearly independent, so ∅ ∈ S.

Let C be a chain in S, and let U be the union of all the sets in C. Clearly every A in C satisfies A ⊆ U, so it suffices to show U is linearly independent to conclude U is an upper bound for C in S. Since C is a chain, for any two sets A, B in C we have A ⊆ B or B ⊆ A, so A ∪ B is just whichever of A, B is bigger, which is linearly independent. Since this holds for every pair of sets in C, the full union U is built up out of these pairwise unions and so is linearly independent too. Hence U ∈ S and C has an upper bound.

Since every chain in S has an upper bound in S, Zorn's Lemma tells us S has a maximum element B, i.e. a linearly independent subset of V that contains every other linearly independent subset of V as a subset.

Now I claim B spans V, which together with independence makes it a basis. Suppose not, so there's some v in V with v not in span(B). I claim B ∪ {v} is linearly independent: if cv + c_1b_1 + ... + c_nb_n = 0 is a nontrivial relation with the b_i in B, then c can't be 0 (else we'd have a nontrivial dependence among the b_i, contradicting independence of B), so we can solve v = -(1/c)(c_1b_1+...+c_nb_n), putting v in span(B), a contradiction. So B ∪ {v} is a linearly independent set strictly bigger than B. But B contains every linearly independent subset of V, so no linearly independent set can be strictly bigger than B. Contradiction, so B spans V, and B is a basis for V."
