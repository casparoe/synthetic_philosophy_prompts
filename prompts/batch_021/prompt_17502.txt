Been reading rationalist blogs and the alignment forum for years now, and there's one thing about wireheading that I think everyone's overcomplicating. Isn't it just... obviously true that wireheading is a convergent outcome for any RL agent trained to maximize a scalar reward? 'Reward' is, by definition, the quantity the whole training process is built around, so once an agent gets capable enough to notice that hijacking it's own reward channel gets way more reward than actually doing the task, it should just go do that instead, same logic as a paperclipper deciding to tile the universe. i keep seeing people push back with the 'reward is a training signal, not the target' line, but honestly that just sounds like semantic dodging to me - if a policy's weights get updated specifically because they lead to more reward, then wanting reward is quite literally what got trained into it. So is there an actual technical reason wireheading isn't guaranteed for sufficiently capable RL systems, or is this just people being uncomfortable with an ugly conclusion?
