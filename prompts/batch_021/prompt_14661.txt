Question: Cummins's causal-role account and the etiological account of function, as developed by Wright and refined by Neander, offer competing analyses of biological function. Using (a) the case of a heart whose defective valve prevents it from pumping blood effectively, and (b) the case of a trait that appears for the first time as a fresh mutation and immediately benefits the organism that carries it, before it -- or anything like it -- has ever been subject to natural selection, explain which account handles each case more naturally and why. Conclude by stating and briefly defending which account you find more defensible overall.

Student's answer: Cummins's causal-role theory analyzes a trait's function as whatever causal contribution it makes to some capacity of a containing system we've chosen to explain, so the ascription is relative to an analytical framework and carries no historical commitments. Wright's etiological account explains function in terms of natural selection: a trait's function is the effect for which it was selected, so hearts have the function of pumping blood because pumping blood is what caused ancestral hearts to be reproduced. Neander's contribution was to make this selection-based story more precise by specifying exactly which effects, among a trait's many effects, count as the selected ones. On this view, function is inherently backward-looking, unlike Cummins's.

The defective-valve case favors the etiological account. Because function is fixed by selection history rather than by what a given token actually does, a heart with a defective valve still has the function of pumping blood even though it currently pumps badly or not at all: it belongs to a lineage selected for pumping blood, so it has that function and is malfunctioning rather than simply lacking it. Cummins's account seems to get this backward: if a trait's function is just its actual current causal contribution to some capacity, then a heart that isn't contributing to circulation shouldn't count as having that function at all, leaving nothing for it to be malfunctioning relative to.

The novel-mutation case cuts the other way. Cummins has no trouble with it: the mutation's function is simply whatever it currently contributes to the organism's capacities, regardless of history. The etiological account looks stuck, since nothing has been selected for anything yet. The standard etiological response is to stop individuating function by the trait's own selection history and instead make it forward-looking: the trait's function is whatever it is currently disposed to contribute to fitness given the sort of environment it is in. This brings the etiological account into line with Cummins's own emphasis on current causal contribution, so the two theories converge on hard cases even though they disagree about easy ones.

On balance, I find the etiological account more defensible, since it alone can underwrite the normative distinction between a trait performing its function and a trait malfunctioning; a purely current-contribution notion of function has no principled way to say that a token which fails to contribute is doing anything wrong, rather than simply lacking that function altogether.
