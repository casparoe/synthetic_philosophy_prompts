ok this has been bugging me for a side project tied to my dissertation on multi-agent RL / credible commitment. Tennenholtz's program equilibrium is a neat trick: let players submit programs instead of actions, the programs get to inspect each other, and now something like "cooperate iff opponent's code == mine" counts as a Nash equilibrium of a one shot PD. Fine, but thats kind of a cheap version since it only handles literal clones.

What actually breaks my brain is the Löbian stuff, FairBot/PrudentBot "proving" mutual cooperation via Gödel-Löb provability logic. FairBot cooperates with X iff it can prove that X cooperates with FairBot -- but that looks viciously circular, since FairBot's own behavior is exactly the fact the proof is supposed to be about. Where does Löb's theorem actually break that loop, and why doesn't the same move let any two agents rubber-stamp mutual cooperation into existence for free (which seems way too strong to be right)? I never got deep into provability logic so the original papers lose me pretty fast -- would love an intuitive, gut-level version.
