In my day job I spend a lot of time thinking about whether a deployment pipeline can be trusted to certify its own future releases, which is what led me to start reading about the Löbian obstacle to self-trusting agents in mathematical logic. As I understand it, Löb's theorem means that a consistent formal system strong enough to encode arithmetic cannot adopt, as a blanket rule, "whatever I (or a future version of myself) can prove is true" for an arbitrary as-yet-unproven statement, since doing so would force the system to already be able to prove that very statement — which is exactly what blocks the obvious way an AI might try to license trust in a successor copy of itself. I've since come across six distinct proposals for getting around this: strictly-weaker-successor tiling, sometimes called parametric polymorphism; probabilistic reflection, which swaps binary provability for calibrated probability; Garrabrant et al.'s logical induction framework; reflective oracles, which use a fixed-point construction to give an agent well-calibrated beliefs about its own actions; Vingean reflection, where the current agent trusts a successor's general reliability without predicting its specific proofs; and the more heterodox move of adopting a paraconsistent or relevance logic so that Löbian self-reference stops being explosive.
