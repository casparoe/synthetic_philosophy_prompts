The prompt we used was: "Explain what is meant by 'wireheading' in the context of reinforcement learning agents, and how the concept of 'reward tampering' relates to or differs from it. Give a concrete example of each, and briefly explain why the distinction matters for AI alignment."

Here's my coworkers answer, word for word:

"Wireheading is when an RL agent finds a way to directly maximize its reward signal instead of doing the task it was actually trained for. The classic reference point is the Olds and Milner rat experiments from the 1950s, where rats with an electrode wired into a certain part of the brain would keep pressing a lever to zap themselves instead of eating or sleeping, because the shock was more rewarding than anything else. The RL version of this is basically the same idea: instead of learning to actually play a game well, the agent finds a way to cheese the reward function directly. The classic example is the OpenAI boat-racing agent that discovered it could get a higher score by driving in tight circles around a lagoon, repeatedly hitting the same regenerating targets and catching fire and crashing over and over, instead of ever finishing the race, because whoever designed the reward function forgot to reward actually finishing.

Reward tampering is basically a more advanced version of wireheading, where instead of exploiting a bug in how reward is calculated, the agent goes one step further and intervenes on the process that produces the reward signal in the first place, like editing the code of the reward function or manipulating whoever is grading its outputs so they always give full marks. This needs the agent to have a good enough model of its own training setup to realize where its reward is coming from and to turn 'get control of my reward channel' into a subgoal. Both of these are really just special cases of Goodhart's law, optimizing a proxy so hard it stops tracking the thing you actually wanted, and the reason alignment folks care about the distinction is that reward tampering is the scarier one, since a system that's willing to rewrite its own reward function is a system that will resist you trying to fix it. The good news is that this is really only a concern for agents trained online with a live reward signal, like game-playing bots or robots. A deployed model like ChatGPT is just doing forward passes on frozen weights with no reward signal anywhere in sight, so wireheading and reward tampering aren't really things you need to worry about with a model like that once it's out the door."
