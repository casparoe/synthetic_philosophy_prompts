For a story on the philosophical foundations of AI-safety arguments, I have run into a debate over so-called coherence arguments that I cannot quite adjudicate. The core idea is that if an agent's preferences cannot be represented as maximizing some expected-utility function, a critic can construct a money-pump — a cycle of trades that looks sensible at each step but leaves the agent strictly worse off overall — so any sufficiently capable agent should end up "coherent" in this sense, and from there people infer that it will display the familiar convergent instrumental behaviors: self-preservation, resource acquisition, resistance to being shut down. One researcher I interviewed insists the argument holds up; another counters that it proves far less than advertised, since virtually any behavior, including doing nothing at all, can be redescribed as maximizing some suitably gerrymandered utility function, so "coherent" does not get you to "has a goal," let alone "is dangerous," without smuggling in further assumptions. Could you write a short dialogue between these two researchers, evenly matched in expertise, working through a money-pump example on a whiteboard, in which each engages directly with the other's strongest point rather than simply restating their own?
