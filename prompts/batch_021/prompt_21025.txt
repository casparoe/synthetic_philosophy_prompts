Been reporting on the AI arms race between labs and stumbled into this game theory idea called 'program equilibrium' — the one where if two agents can read each others source code before playing a prisoners dilemma, they can each write a program that essentially proves the other will cooperate, so they both end up cooperating with zero outside enforcement. Feels like this pretty much settles the AI lab race problem: if the major labs just open sourced their models so each could verify what the other's system would actually do, they'd have every incentive to cooperate on safety instead of racing to the bottom, right?
