- New members: HIIT 30/100 (30%), Steady-State 5/20 (25%)
- Experienced members: HIIT 16/20 (80%), Steady-State 70/100 (70%)
- Overall: HIIT 46/120 (38.3%), Steady-State 75/120 (62.5%)

(a) Name the statistical phenomenon on display here and explain, using this data, why it occurs.
(b) The gym's manager wants to recommend one program to a brand-new, not-yet-assigned member. Using only the numbers above, should that recommendation be based on the aggregated comparison or the experience-stratified one, and why?

And here's the student's answer, copied exactly:

"(a) This is Simpson's Paradox -- the direction of the association between program and outcome flips once you control for experience level. It happens because HIIT's pool is mostly new members (100 of 120) while Steady-State's pool is mostly experienced members (100 of 120), and new members succeed less often no matter which program they're in, so HIIT's overall number gets dragged down even though it wins in both subgroups.

(b) You should trust the stratified numbers, not the aggregate, since the aggregate is just comparing two groups that aren't really alike to begin with. Once you break it into like-for-like groups, HIIT wins both, so the recommendation should be HIIT. As a general rule, whenever you're choosing between a pooled statistic and a more granular breakdown, you should go with the more granular one, since it throws away less information.

(c) I'd say this is basically just a fact about the data -- HIIT wins in both slices, so that settles it. I don't think it depends on any extra assumption beyond whats already in the table."
