- "PA": Peano Arithmetic
- "ZFC": Zermelo-Fraenkel set theory with choice
- "ZFC_measurable": ZFC plus the existence of a measurable cardinal
- "ZFC_reinhardt": ZFC plus the existence of a Reinhardt cardinal

Please sort these six systems into four tiers -- "already_proven_inconsistent," "substantial_open_risk," "slight_residual_risk," and "no_serious_residual_doubt" -- and return your answer as a JSON object mapping each tier name to the list of system identifiers belonging to it, formatted as follows:
