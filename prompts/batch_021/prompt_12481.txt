(a) Explain, with an example, what the reference class problem is and why it arises for a frequency interpretation of probability. (b) Explain how a structurally similar problem arises for Bostrom's Self-Sampling Assumption (SSA), as used in the Doomsday Argument, and why the choice of reference class matters for the argument's conclusion. (c) Alan Hájek has argued that the reference class problem is not merely the frequentist's problem but everybody's. Sketch the argument for why a Bayesian cannot simply shrug the problem off.

And here is the student's answer, verbatim:

"(a) The reference class problem arises because, on a frequency interpretation, the probability of a claim about a single case is identified with the limiting relative frequency of some attribute within a reference class of 'similar' trials, but a single case can always be redescribed as belonging to many different reference classes, which need not agree on that frequency. For instance, if I ask for the probability that a particular 55-year-old woman survives to 56, I can refer her to the class of all 55-year-olds, the narrower class of 55-year-old non-smokers, or the still narrower class of 55-year-old non-smokers with her exact medical history, and these need not deliver the same answer. Reichenbach's proposed fix was to always select the narrowest class for which we have reliable statistics, but this just trades one arbitrary choice for another, since narrowness, which makes the class more relevant, and reliability, which requires enough cases to generate a stable frequency, pull in opposite directions; the rule relocates the arbitrariness rather than removing it.

(b) Bostrom's SSA tells each observer to reason as if it were a random sample from the reference class of observers relevantly like itself. Bostrom introduced the Doomsday Argument to dramatize this principle's consequences: if the reference class is 'all humans who will ever have been born,' your own birth rank is treated as a random draw from it, which makes it more probable, relative to your prior, that only a relatively small number of humans will ever live, since your rank is more typical of that hypothesis than of one on which trillions more people are yet to be born. The same mechanism is also what makes the 'Presumptuous Philosopher' thought experiment bite against SSA: because the principle favors hypotheses on which observers like you are more numerous, an SSA-reasoner faced with two cosmological theories that are empirically equivalent but differ in how many observers they predict can seemingly favor the theory with more observers from the armchair, without waiting on the telescope. More generally, the whole argument depends on where the boundary of the reference class gets drawn — Homo sapiens only? All hominids? All observers with your exact information state? — and SSA itself supplies no principled way to fix that boundary, so the reference class problem just migrates from frequentism into anthropic reasoning.

(c) Hájek's point is that Bayesians are not obviously better off. A Bayesian who wants her credences about chancy matters constrained by something like the Principal Principle needs her credence that a coin lands heads to defer to the coin's objective chance of landing heads; but objective chance is itself usually cashed out as a frequency or propensity relative to a class of relevantly similar trials or possible worlds, so specifying 'the' chance already requires picking out a reference class, exactly as the frequentist had to. Since even a Bayesian who wants a non-arbitrary, evidentially grounded credence about a single case eventually has to lean on some fact about chances or frequencies of that kind, the reference class problem reappears for her too — which is why Hájek insists it isn't merely the frequentist's problem, but everyone's."
