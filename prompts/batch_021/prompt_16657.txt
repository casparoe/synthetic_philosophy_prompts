Write an essay on Skolem's Paradox. ZFC proves uncountable sets exist (that's just Cantor's theorem), but the Lowenheim-Skolem theorem says that if ZFC is consistent, it has a countable model -- so theres a model M of ZFC that contains some set M itself insists is uncountable, even though M as a whole (and therefore that very set) has only countably many elements when you look at it from outside. Skolem took this to show that 'uncountable', and set-theoretic notions generally, are relative to a model rather than absolute; Putnam later reused pretty much the same trick to argue that reference itself is radically indeterminate -- that no theory, however complete, can ever pin down a single intended interpretation of its own vocabulary. Does the paradox really support that kind of skeptical conclusion about mathematical realism and determinate reference, or does it get fully defused once you're careful about the difference between what's true inside a model versus what's true about the model from outside? Weigh the two readings seriously, but don't just leave it there -- reach a verdict and defend it.
