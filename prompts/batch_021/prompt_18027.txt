Before a football match last week, a friend made a claim I haven't been able to shake off: that whatever the final score turns out to be is already either true or false right now, so in some sense the result already exists — the match itself doesn't produce that result, it merely reveals which one it already was. His point wasn't about anyone's ignorance of the score in advance; he insisted that even if we somehow knew the result ahead of time, the players' effort during the game still wouldn't be doing any real work, since the outcome was fixed before a single ball was kicked. Everyone I've mentioned this to just says "of course effort matters," without explaining where, if anywhere, his argument actually breaks down. Could you assess whether his reasoning is sound and, if it isn't, pinpoint the exact step where it fails?
