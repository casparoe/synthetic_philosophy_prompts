Question (20 points). (a) Using a non-anthropic example, explain the reference class problem for single-case probability judgments, and explain why simply narrowing the reference class does not by itself resolve the problem. (b) Explain how the same underlying difficulty resurfaces in Bostrom's Self-Sampling Assumption (SSA), as applied to the Doomsday Argument. (c) It has been suggested that replacing SSA with the Self-Indication Assumption (SIA) resolves the reference class problem for anthropic reasoning, rather than merely changing how a reference class gets used. Assess this suggestion.

Student's answer:

(a) The reference class problem shows up whenever we want a probability for a single, non-repeatable event but can only ground probabilities in frequencies (or other class-relative facts) about repeatable event-types. The standard illustration is actuarial: suppose we want the probability that a particular 40-year-old man, John, survives to age 80. Put him in the reference class "40-year-old men" and we might get a survival frequency of 60%; put him in the narrower class "40-year-old male non-smokers" and we might get 75%; narrower still, "40-year-old male non-smoking marathon runners with no family history of heart disease," and we might get 90%. John belongs to all three classes, and each is a statistically respectable one, but they disagree about "the" probability that John survives, and nothing so far tells us which is authoritative. The obvious fix — always take the narrowest available class — doesn't work, because narrowing has no natural stopping point short of the class containing John and nobody else, for which the "frequency" of survival is trivially 1 or 0. So the problem isn't solved by narrowing; narrowing just postpones it until the class becomes too small to say anything statistical at all.

This general bind is sometimes called Bostrom's reference class problem, since it was Bostrom who first isolated it — for single-case frequency judgments like the one above — before exporting the same difficulty to anthropic reasoning in part (b).

(b) Bostrom's Self-Sampling Assumption tells you to reason as if you were a random sample from the set of all observers in your reference class. The Doomsday Argument applies this by treating your own birth rank as a random draw from the set of all humans who will ever live: since a given birth rank is more probable under a smaller total population than under a much larger one, learning your birth rank should shift your credence toward hypotheses on which humanity doesn't have all that many births left. But the whole inference presupposes that we already know which set counts as "all observers in your reference class" — all humans? all observers simpliciter? all observers who have thought about the Doomsday Argument? — and Bostrom's own choice of reference class shifts between his early and later writing, which is really just the part (a) problem recurring one level up, now dressed as a question about who "counts" as relevantly like you rather than about actuarial subgroups.

(c) The Self-Indication Assumption is often presented as the fix: instead of sampling within a fixed class, SIA has you weight hypotheses by how many observers like you they predict, so that, other things equal, a hypothesis on which many more observers exist gets a proportionally larger boost just from the fact that you exist to ask the question. Because SIA-weighting combined with SSA-sampling can be shown to cancel the Doomsday shift entirely in several of Bostrom's own toy models, and because SIA never has to draw a line around which humans count the way SSA's doomsday reasoning does, I'd go further than the question's "merely changing how a reference class gets used" and say SIA actually dissolves the reference class problem for anthropic cases: there's no arbitrary boundary left to defend, since SIA sums over every possible observer there could be, weighted by how many of them each hypothesis predicts, rather than privileging one class of them in advance.
