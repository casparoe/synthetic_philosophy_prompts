Question: Explain how Kripke's fixed-point theory of truth is meant to improve on Tarski's hierarchical solution to the Liar paradox. Your answer should address (a) Tarski's reasons for holding that a language cannot consistently contain its own unrestricted truth predicate, and how the hierarchy of languages is meant to respond to this; (b) the basic construction of Kripke's minimal fixed point via a partial interpretation of the truth predicate, and why it dispenses with the hierarchy; and (c) at least one respect in which Kripke's approach has been argued to still fall short of fully escaping paradox.

Student's answer: "Tarski's diagnosis of the Liar begins from the observation that a language which is 'semantically closed' — one that contains its own truth predicate as well as the resources to name and quantify over its own sentences — will inevitably allow the construction of a sentence, such as 'this sentence is false,' that is true if and only if it is false. Because ordinary languages have exactly this structure, Tarski concluded that no such language can have a truth predicate obeying the full T-schema ('S is true iff p') for every one of its own sentences without contradiction. His remedy is to abandon semantic closure: we build an object language L0 with no truth predicate of its own, then a metalanguage L1 whose truth predicate applies only to sentences of L0, then L2 with a predicate for L1, and so on. Since a Liar sentence at any level would have to apply that level's own truth predicate to itself, and no level's predicate ever applies to sentences at that same level, the paradoxical self-application can never actually be constructed.

Kripke's alternative is to keep a single, self-applicative truth predicate, but let it be only partially defined. We start with every sentence containing 'true' undecided, then repeatedly apply Kleene's strong three-valued valuation rules to compute, from the sentences already settled as true or false, which further sentences this now settles — feeding the output back in as the new input. Since each such step only adds verdicts and never withdraws one already made, the sequence of interpretations increases monotonically, and its convergence to a stable fixed point is guaranteed by the Banach fixed-point theorem. At this minimal fixed point, so-called 'grounded' sentences — those whose truth value is ultimately fixed by the non-semantic facts — come out true or false as expected, while sentences like the Liar remain ungrounded. Because asserting the Liar sentence true makes it false and vice versa, Kripke's construction actually settles it as both true and false, which is exactly the diagnosis he wants: a sentence that is genuinely paradoxical rather than simply meaningless, and this is achieved without ever leaving the single object language or positing a metalanguage above it.

The construction is not, however, fully immune to paradox. Once we step outside the fixed point and use ordinary, classical negation to say, in effect, 'the Liar sentence is not true,' we can construct a strengthened Liar — 'this sentence is not true' — and ask whether it is true. If it is, then it is not true; if it is not true, then, since that is exactly what it says, it is true. This 'revenge' version of the paradox re-arises precisely because the classical notion of 'not true' we use to describe the fixed point from outside is not itself available within the object language without collapsing the construction."
