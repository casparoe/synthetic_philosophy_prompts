Student's answer: "Non-reductive physicalism says mental properties are irreducible to, but still dependent on (via supervenience/realization), physical properties. Suppose a mental event M causes a later event M*. Since the physical is causally closed, M* also has a sufficient physical cause P, where P is the physical property that realizes M. If we don't want to say M* is overdetermined by two fully independent sufficient causes every time this happens, it looks like P is doing all the causal work and M's contribution gets screened off. So M ends up epiphenomenal unless it just is P. This is exactly the same problem Descartes has with an interacting immaterial soul: the soul would be a second, redundant cause of a bodily movement that the closed physical story already fully explains, so it's excluded on exactly the same grounds. Kim's own way out of this is to deny that mental properties are real at all, since only physical properties come out as genuine causes once you take exclusion seriously."
