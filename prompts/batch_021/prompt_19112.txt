Q: Joyce says his accuracy-dominance argument for probabilism is "nonpragmatic" in a way the Dutch Book argument isn't. Reconstruct the argument — what does it mean for a credence function to be accuracy-dominated, and what does the scoring rule have to be like for the proof to go through — and explain exactly what earns the argument the label "nonpragmatic."

Student's answer: Joyce's move is to treat credences as guesses at the truth-value of propositions (1 if true, 0 if false), scored by an inaccuracy measure — like the Brier score — that penalizes a credence for being far from the right answer. The scoring rule can't be arbitrary: it has to be "legitimate" in Joyce's sense, basically strictly proper and symmetric across propositions, so there's no way to game the measure by reporting something other than your real opinion. Given a legitimate rule, Joyce proves that any credence function that isn't probabilistically coherent is accuracy-dominated: there's always some coherent rival that gets a lower expected inaccuracy score once you weight each possible world by its probability, so the incoherent credence is guaranteed to do worse on average. Since it's irrational to hold a credence function when a rival is guaranteed to be more accurate, coherence is a requirement of rationality. This is what makes the argument "nonpragmatic": Joyce isn't relying on a Dutch Book, he's not showing the incoherent agent will accept a set of bets that loses money for sure, he's showing something about accuracy directly, so the argument works even for an agent who never bets on anything. The same theorem is also why Joyce's framework recommends updating by conditionalization rather than any other rule: conditionalizing on new evidence is what keeps you at the credence function that dominates all the alternatives, so straying from conditionalization is just a diachronic version of the same mistake.
