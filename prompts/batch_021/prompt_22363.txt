For my IB Extended Essay on theories of truth, I have been working through Saul Kripke's fixed-point construction as a response to the Liar paradox, and I have run into a difficulty I would like help arguing through. As I understand it, Kripke builds up a truth predicate in stages using the strong Kleene three-valued scheme, so that the Liar sentence never receives a value at any stage and comes out "ungrounded," neither true nor false, at the minimal fixed point, rather than forcing an outright contradiction. What troubles me is that this seems to immediately generate a new sentence, the so-called strengthened or "revenge" Liar ("this sentence is not true"), which looks true from outside the construction precisely because the original Liar lacks the value true, yet that is exactly what it asserts of itself. Please argue for the position that this revenge argument shows Kripke's theory does not actually solve the Liar paradox but merely relocates it, and that the same problem awaits any theory, such as supervaluationism, that tries to handle the Liar through truth-value gaps rather than by restricting what the object language itself is permitted to express.
