So Smith has a justified true belief that isn't knowledge, since its only true because of a coincidence he had no idea about.

The "no false lemmas" fix says a justified true belief only counts as knowledge if none of the premises used to justify it were false, which patches this case since Smith's reasoning runs through the false premise about the Ford. Gettier used this same idea again in his later "fake barn" example, where a guy driving through fake-barn country happens to look at the one real barn and believes its a barn — since there's no false premise anywhere in that chain either, the no-false-lemmas rule rules that out as knowledge too, so banning false lemmas basically fixes the JTB theory for good.
