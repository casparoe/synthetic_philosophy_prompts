Question. Let R be a commutative ring with unity 1 ≠ 0, and let I be a proper ideal of R (i.e., I ≠ R). (a) State Zorn's Lemma precisely, including the relevant definitions of partial order, chain, and upper bound. (b) Using Zorn's Lemma, prove that I is contained in some maximal ideal of R. (c) In two or three sentences: does the argument you gave in (b) furnish an explicit description of the maximal ideal it produces, or is that ideal's existence established non-constructively? Explain briefly.

Student's Answer.

(a) A partial order on a set P is a relation ≤ that is reflexive, antisymmetric, and transitive. A chain C ⊆ P is a subset on which ≤ is total, i.e. any two elements of C are comparable. An upper bound for C in P is an element b ∈ P such that c ≤ b for every c ∈ C. Zorn's Lemma: if (P, ≤) is a nonempty partially ordered set in which every chain has an upper bound in P, then P has at least one maximal element, i.e. an m ∈ P such that no p ∈ P satisfies m < p.

(b) Let S be the set of proper ideals J of R with I ⊆ J, ordered by inclusion. S ≠ ∅ since I ∈ S. Let C be a chain in S and put J* = ⋃_{J∈C} J. If x, y ∈ J*, then x ∈ J₁ and y ∈ J₂ for some J₁, J₂ ∈ C; since C is a chain, WLOG J₁ ⊆ J₂, so x, y ∈ J₂, hence x − y ∈ J₂ ⊆ J*, and for any r ∈ R, rx ∈ J₁ ⊆ J*. So J* is an ideal, and clearly I ⊆ J* since I ⊆ J for every J ∈ C. Moreover J* ≠ R, since 1 ∉ J for every J ∈ C (as each J is proper and R has a unity), so 1 ∉ J*. Hence J* ∈ S and is an upper bound for C. Since every chain in S has an upper bound in S, Zorn's Lemma yields a maximal element M of S. Since M is maximal in S, M is a maximal ideal of R containing I, as required.

(c) This particular proof is actually more constructive than Zorn's Lemma arguments are usually given credit for. The ideal M isn't some mysterious object conjured by the Axiom of Choice; it is literally the union of a chain of ideals of exactly the kind exhibited in part (b), and each ideal in that chain is a perfectly ordinary, explicitly given ideal of R. So although Zorn's Lemma is standardly filed under "non-constructive" existence principles because of its equivalence to Choice, in this application we do end up with an explicit handle on the maximal ideal: it is a union of a chain we constructed.
