For my IB Extended Essay in philosophy, I've been reading around the St. Petersburg paradox, which led me to a stranger variant called the "Pasadena game," introduced by Nover and Hájek in their 2004 paper "Vexing Expectations." A fair coin is tossed until it first lands heads; if that happens on toss n, you win 2^n/n dollars when n is odd and lose 2^n/n dollars when n is even. Since the first head lands on toss n with probability 1/2^n, the game's expected value is standardly computed by adding up (-1)^(n+1)/n for every n -- the alternating harmonic series, which equals ln 2 when the terms are added in the natural order n = 1, 2, 3, and so on. The catch is that this series is only conditionally, not absolutely, convergent, so by the Riemann rearrangement theorem those very same infinitely many terms can be reordered to sum to any real number you like, or to no limit at all.

Nover and Hájek take this to show that the Pasadena game has no well-defined expected value, which they present as a serious embarrassment for expected-utility theory. But one could instead argue that the "natural" order n = 1, 2, 3, ... isn't just one rearrangement among equally good others: it is the order in which the coin tosses actually happen and the agent's uncertainty resolves, so it deserves special status as the order that matters for rational decision-making. I'd like you to write an essay that weighs these two positions and reaches a definite verdict: does the Pasadena game have a well-defined expected value (or at least a well-defined fair price -- the most a rational agent should pay to play it), and does the case expose a genuine gap in expected-utility theory, or merely an artifact of treating "the" expected value too literally as an unordered infinite sum?
