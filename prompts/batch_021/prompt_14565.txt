I am assembling case studies in formal epistemology for a graduate seminar, and I would like a dialogue dramatizing a live methodological dispute about the problem of logical omniscience in epistemic logic. Set the exchange during a coffee break at a workshop on multi-agent knowledge representation, between an impossible-worlds theorist and an awareness-logic theorist. The impossible-worlds theorist holds that an agent's epistemic state should be allowed to include logically deviant worlds, where valid entailments can fail, so that knowing P no longer guarantees knowing everything P classically implies. The awareness-logic theorist holds instead that explicit knowledge requires both truth in all normal epistemically accessible worlds and membership in an "awareness set" fixed by what the agent has actually attended to or could derive within its resource bounds. Each regards the other's proposal not as a genuine solution to the problem but as a relabeling of it, and each should press this charge in turn: the impossible-worlds theorist should ask where the awareness set comes from and why it is not simply an unconstrained parameter that smuggles in the answer by fiat, while the awareness theorist should ask whether admitting impossible worlds without independent constraints on which ones are epistemically "live" for a given agent leaves the logic with no power to predict which inferences that agent will or will not draw. The two should engage each other's actual objections rather than restate their own positions, and neither should concede more ground than their own framework can genuinely sustain.
