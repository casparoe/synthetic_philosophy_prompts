Here's the student's answer, in full:

"Set-up: imagine an agent A0 that only takes actions it can formally prove are safe, and suppose A0 is deciding whether it can trust a successor A1 (or just its own future self) that reasons with an equally strong proof system, say Peano Arithmetic. What A0 would like is a general trust schema — for any φ, if A1 proves that φ is safe, then φ really is safe, i.e. Prov(Safe(φ)) → Safe(φ) — and A0 wants its own reasoning to certify that schema, so it can safely defer to A1 on cases it hasn't already settled itself.

This is exactly where Löb's theorem bites. For a theory T meeting the usual provability conditions, Löb's theorem says: if T ⊢ Prov_T(φ) → φ, then T ⊢ φ. So if A0 tries to establish the trust schema using its own proof system, the only φ for which it can succeed are ones it could already prove outright, without ever appealing to A1's say-so. The whole point of delegating — getting A1's verdicts on new cases A0 hasn't settled — is exactly what this rules out. That's the Löbian obstacle: naive self-trust (or trust in an equally strong successor) collapses into just re-deriving everything yourself.

Worth flagging: underneath the formalism, A0's problem is really that it can't be fully certain A1's proofs will track truth, since A1 is at least as complicated a system as A0 itself. No matter how much of A1's source code A0 inspects, some residual uncertainty about how so complex a system will behave remains, and Löb's theorem is best read as the formal fingerprint of that residual uncertainty — part of why the obstacle is so hard to engineer away.

Finally, it's worth situating this relative to Gödel: Löb's theorem is often presented as a free-standing result, but it actually follows from Gödel's Second Incompleteness Theorem — because no consistent theory can prove its own consistency, i.e. can never prove Con(T), the same reasoning shows it can't prove the analogous schema Prov(φ) → φ for any other sentence either, which is just Löb's theorem stated in full generality."
