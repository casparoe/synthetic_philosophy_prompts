Classmate's answer: Popper's demarcation problem asks how to tell genuinely scientific theories apart from non-scientific ones. His answer was that a theory only counts as scientific if it is falsifiable: it has to rule out certain possible observations, so that some conceivable experience could in principle show it to be false. He argued that Einstein's general relativity was a textbook example of a scientific theory because it made a bold, risky prediction — that starlight passing near the sun would bend by a specific, measurable amount — that could easily have come out false but didn't, which made it more probable that the theory was correct. By contrast, Popper thought Freudian psychoanalysis was pseudo-scientific, since it could "explain" almost any behavior a patient displayed after the fact, so no possible observation could ever count against it.

The Duhem–Quine thesis complicates this picture: since a theory is only ever tested together with a whole web of auxiliary assumptions (about instruments, initial conditions, background theories, and so on), a failed prediction never straightforwardly refutes the core theory, because we can always choose to blame one of the auxiliary assumptions instead. Popper's own answer to this problem was essentially the same one Kuhn later gave: a theory is only really given up once enough anomalies have piled up and the scientific community shifts to a new paradigm that handles the evidence better, rather than being abandoned after any single falsifying result.
