Aumann's Agreement Theorem is often glossed as showing that "people with the same priors cannot agree to disagree."
(a) State the theorem precisely: describe the state-space/partition setup, say what it means for the two agents' posteriors to be common knowledge, and give the conclusion. Sketch briefly why the result holds.
(b) Some expositions go further and claim the theorem shows that two perfectly rational Bayesians with a common prior who converse honestly about a disputed question will, after enough exchange, converge on the same credence. Is this an accurate description of what Aumann (1976) himself established? Explain.

Here's the write-up I've been asked to grade:

(a) Let Ω be a finite set of possible states of the world, and let p be a probability distribution over Ω that both agents accept before either receives any private information -- this is the common prior. Each agent i has a partition Pi of Ω representing what she is able to distinguish: if the true state is ω, agent i learns only that the state lies in the cell of Pi containing ω, written Pi(ω). For an event E ⊆ Ω, agent i's posterior at ω is qi(ω) = p(E | Pi(ω)).

Suppose that, at the true state ω, it is common knowledge that agent 1's posterior is q1 and agent 2's is q2 -- that is, agent 1 knows that agent 2's number is q2, and agent 2 knows that agent 1's number is q1. Aumann's theorem says that in that case q1 = q2: two Bayesians who share a prior cannot end up with different posteriors for the same event once those posteriors are common knowledge, however different their private information may otherwise be.

Roughly, the reason is this: the set of states at which "agent 1's posterior is q1 and agent 2's is q2" is itself common knowledge, so it must be a union of whole cells of P1 and also a union of whole cells of P2 -- nobody inside that set is ever uncertain about whether they are in it. Call this set A. Since A is a union of P1-cells on each of which the posterior is q1, averaging p(E | ·) over A via P1 gives q1; since A is equally a union of P2-cells on each of which the posterior is q2, the same average computed via P2 gives q2. Both computations equal p(E | A), so q1 = q2.

(b) Yes -- this is essentially what Aumann's result gives us. If agent 1 announces her posterior q1, agent 2 can treat that announcement as new information and update on it, and then announce his own revised posterior back to agent 1, who updates in turn; after finitely many rounds of honest exchange, each agent's current posterior becomes common knowledge between them, and at that point the theorem forces the two numbers to coincide. So two Bayesians with a common prior who keep exchanging honest opinions about a single question cannot fail to converge, which is exactly why the result is often summarized as "you can't agree to disagree."
