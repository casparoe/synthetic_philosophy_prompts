I've been part of a small rationalist-adjacent reading group for a few years now; we meet every other week, work through old LessWrong posts and the occasional MIRI paper, and generally end up arguing more than actually finishing the reading. A few weeks ago the assigned material was the classic coherence-argument case for expected utility maximization — the Yudkowsky-style claim that any sufficiently optimized agent will end up acting like it's maximizing some utility function, on pain of leaving free money on the table to a sufficiently clever bookie — and two regulars, Owen and Kavita, ended up in a long back-and-forth that the rest of us mostly just watched. I wrote down the gist afterward because I honestly couldn't tell who'd won, if anyone had.

(1) Owen opened with the standard money-pump argument: an agent whose preferences aren't complete and transitive can be walked through a cycle of trades, accepting each one, and end up strictly worse off than where it started — so any sufficiently rational or optimized agent will end up with preferences representable by a single utility function. (2) Kavita objected that incompleteness isn't indifference: an agent with no ranking at all between two options is free to simply decline any trade that isn't a strict improvement by its own lights, so it can dodge the whole pump without ever completing its preferences. (3) Owen replied that this doesn't help, because the standard construction doesn't rely on indifference — a bookie can chain together trades that are each sweetened by a hair, so every single step is a strict improvement, and the cycle still returns the agent to its starting option minus the accumulated sweeteners; anything willing to ever take a free strict improvement is exploitable this way, complete preferences or not. (4) Kavita conceded that this defeats a "naive" agent that re-evaluates fresh at each step, but said a "resolute" agent — one that commits to a whole plan in advance rather than re-deciding node by node — can see the cycle coming as a whole and simply refuse to enter it, and that it's this resoluteness, not completeness, doing the pump-proofing, so the gaps in its preferences never need to be filled in. (5) Owen countered that "seeing the cycle coming" requires comparing the end state to the start state, and that comparison just is a preference the agent supposedly didn't have — so resoluteness doesn't dispense with coherence, it just relocates where a ranking has to show up. (6) Kavita's last word was that the comparison Owen is pointing to is trivial — the same option with less money is worse, which nobody disputes — and that granting agents enough foresight to compare specific cycles they might actually face is a long way from the sweeping claim the argument is meant to license, namely a single, complete ranking over entire world-histories; so even if Owen wins that narrow point, the gap between "won't obviously be pumped" and "is an expected-utility maximizer" never actually closes.
