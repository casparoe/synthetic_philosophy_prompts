And here's the student's answer, in full:

"The Löbian obstacle comes up when you try to get an AI agent to build a successor, or just trust its own future self, using formal proof rather than just hard-coding trust. Löb's theorem says that for a system like Peano Arithmetic, if you can prove 'if X is provable then X is true,' you can already prove X itself -- symbolically, PA ⊢ (□P → P) implies PA ⊢ P. That sounds harmless, but it means a system can never establish, for an arbitrary P, that its own proofs are trustworthy without already having proved P directly, which is circular. This is really just a restatement of Gödel's Second Incompleteness Theorem, since a system proving its own consistency is the same kind of self-referential trap.

The problem for a self-modifying agent is this: suppose agent A wants to build a successor A', and A only wants to let A' take an action if A' has proved the action is safe. For A to greenlight this scheme in advance, A would need to prove something like 'whenever A' proves an action is safe, the action really is safe' -- a reflection principle for its own proof system. Löb's theorem says that if A could prove that schema, A could dispense with A' and just prove the safety of each action directly, so the successor adds nothing; worse, running the schema on the sentence 'PA is consistent' would let A prove its own consistency, which shows the whole system was inconsistent to begin with. So no non-trivial self-trust of this kind is possible for a fixed proof system, and every attempt to formalize a self-trusting agent hits this wall.

One proposed way around the obstacle, sometimes discussed under the label 'parametric polymorphism,' is to stop insisting a system prove a reflection schema for a system as strong as itself, and instead set up a family of successively weaker proof systems, so each agent only has to certify a successor running a strictly weaker system than its own -- the way a stronger theory can prove the consistency of a weaker one without contradiction. Framed this way the schema is 'parametric': it's proven once for a variable strength parameter rather than re-derived at every step, so a whole line of descendants can be licensed without any single system ever vouching for one as strong as itself."
