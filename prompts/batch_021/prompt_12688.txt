Using examples, explain why finkish dispositions and masked (or 'antidotal') dispositions are each thought to be counterexamples to the SCA. Here is the student's answer, word for word:

"The simple conditional analysis says that having a disposition is equivalent to a subjunctive conditional being true: for instance, a glass is fragile iff it would break if struck. Finks are a counterexample to this because they show the biconditional can fail in either direction. Lewis's famous electro-fink is a wire hooked up to a machine that senses when a conductor is about to touch the wire and, if the wire is meant to be dead, switches in a live current at exactly that moment. So the wire lacks the disposition to shock right up until contact, and yet 'the wire would shock you if you touched it' comes out true, which is exactly backwards from what the SCA predicts. A finkish disposition can also run the other way: a live wire hooked to a fink that cuts the power the instant a conductor touches it has the disposition (it's live) even though it would not actually shock anyone, because the fink removes the current before the shock can occur. Either way, finks work by changing the wire's actual electrical state at exactly the moment the test is carried out, so the counterfactual test and the underlying disposition come apart.

Masked dispositions are a different kind of case, discussed by Mark Johnston and, under the label 'antidotes,' by Alexander Bird. Here nothing about the object itself changes at all: a wine glass that's been wrapped in styrofoam is exactly as fragile, molecule for molecule, as an unwrapped one, but 'it would break if dropped' is false, because the packaging absorbs the impact before it reaches the glass. Similarly, someone who has swallowed a lethal dose of poison but immediately takes the antidote is still poisoned in the sense that matters, since the disposition to die is still grounded in the same internal chemistry, but the conditional 'she would die' is false because the antidote intervenes in the causal chain.

Lewis's Reformed Conditional Analysis fixes the fink problem by building in a clause about the causal basis: x is disposed to r when s iff x has some intrinsic property that, together with s, would be a complete cause of r, persisting for as long as it takes to produce the response. This rules out cases where the basis is swapped in or out right at the critical moment, so finks are handled. Because masking cases are, structurally, just a slower and more indirect version of the very same trick of intervening on the path between stimulus and manifestation, the Reformed Analysis handles them too: the antidote and the fink are both just extra factors inserted into the causal chain, so one fix takes care of both. That's presumably why Lewis presented it as a general solution to deviant causal chains between stimulus and response."
