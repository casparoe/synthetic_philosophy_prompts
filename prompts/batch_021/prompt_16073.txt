A few people I trade with in a niche marketplace for vintage synthesizers (no platform, no escrow, and in practice never more than a one-off transaction with any given counterparty) have started automating trades with small scripts, each of which authorizes shipment only once it can verify that the counterparty's script has done the same; beforehand, each side shows the other its script so that this verification is actually possible. The appeal is that visibility into how the other party's code will behave should let us dispense with the usual need for trust or reputation. But it strikes me as circular: I still have no way of confirming that the code actually running on their end is the code they showed me, and whatever method I devise to confirm that becomes one more thing I have to take on trust. Is there a genuine way of breaking this regress, or does exchanging source code beforehand just relocate the original trust problem rather than resolve it?
