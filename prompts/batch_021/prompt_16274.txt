So I've been going down a bit of a rabbit hole reading about "embedded agency" (the MIRI/LessWrong framing of agents that are literally part of the environment they're modeling, instead of the classic AIXI-style setup where the agent sits outside the world with a clean action/observation channel). Most of it clicked for me pretty fast as a software engineer — like yeah, obviously you can't fit a complete model of the universe inside a piece of the universe, that's just a size/computability thing. But I got stuck on the "robust delegation" part, specifically the bit about the Löbian obstacle to tiling agents / self-trust.

From what I can tell, the problem is something like: an agent that uses formal proof to decide whether an action is "good," and that also wants to build (or become) a successor that reasons the same way, can't just adopt a blanket rule like "trust any action my successor can prove is good" — because that amounts to a reflection principle ("if the proof system proves X, then X") which Löb's theorem says a consistent proof system can't have unless it already proves X outright. So naive self trust either collapses into inconsistency or forces you into this weird infinite descending ladder of ever-weaker proof systems just to break the circularity. I've read a couple of writeups on this (and the original tiling agents paper) but honestly the modal logic / Gödel-numbering parts move too fast for me and I lose the plot.
