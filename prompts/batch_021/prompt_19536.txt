I spent my working life as an experimental physicist, computing expectation values as a matter of routine, and a retirement project reading through the decision-theory literature has left me unsettled by a puzzle usually called the Pasadena game. A fair coin is tossed until it first lands heads; if that happens on toss n, the player receives (-1)^(n+1) × 2^n / n dollars, so the possible payoffs run 2, -2, 8/3, -4, 32/5, and so on, each occurring with probability 1/2^n. Summed in the order the tosses actually happen, the expected value is the alternating harmonic series 1 - 1/2 + 1/3 - 1/4 + ..., which converges to ln 2. But unlike the St. Petersburg game, where the trouble is merely that the expected value comes out infinite, this series is only conditionally convergent, so by Riemann's rearrangement theorem the very same outcomes, merely reordered, can be made to sum to any real number one likes, or to no limit at all. The figure of ln 2, in other words, looks like an artifact of the order of summation rather than a fact about the gamble.

Please write a dialogue between two decision theorists brought in as consultants to advise a casino on a fair price for a single ticket to this game. One maintains that the order in which the tosses actually occur is privileged, so the game does have a determinate expected value and the rearrangement objection is beside the point; the other maintains that no ordering can be privileged in this way, that the game therefore has no expected value whatsoever, and that expected-utility theory must simply accept this as a genuine limit on its own scope. Make the two of them equally formidable, with each directly confronting the other's strongest argument rather than restating their own position. I confess I have not been able to settle which of them is right, which is exactly why I want to watch them argue it out.
