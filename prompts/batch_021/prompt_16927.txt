I write about science and ideas for a living, and for the past few months I've been reporting on actuarial risk-assessment tools like COMPAS, which many U.S. courts use to help set bail, sentencing, and parole terms by assigning each defendant a numerical probability of reoffending. Defenders of these tools tend to frame objections to them as narrow questions of data quality and calibration, but several philosophers I've interviewed insist the deeper trouble is the classic "reference class problem": any given defendant belongs simultaneously to indefinitely many reference classes — an age bracket, a zip code, people with an identical prior record, first-time offenders as a whole — each grounding a different frequency, and Reichenbach's own proposed fix, using the narrowest class for which reliable statistics exist, never actually terminates, since a still-narrower class is always available, right down to the defendant considered alone. For a feature I'm drafting, please argue for the strong thesis that this is not a practical defect correctable with better data, but proof that a statement like "this defendant has a 68 percent chance of reoffending" is not strictly true or false at all.
