The homework question was:

"Discuss the puzzle about inquiry that Socrates faces in Plato's Meno. What is Socrates's proposed solution to it? And why do some philosophers think this puzzle shows that knowledge has no special value over mere true belief?"

The student's answer:

"The Meno problem is that it looks impossible to search for knowledge of something you don't already know. If you don't know what you're looking for, you can't even set up the inquiry, and even if you did stumble on the right answer you wouldn't be able to recognize it as correct. Socrates's response is the theory of recollection, or anamnesis: the soul already posesses all the truths it will ever learn, so what we call learning is really just remembering. He illustrates this by getting a slave boy, who has no training in geometry, to 'recall' how to double the area of a square just through questioning.

I think this is a problem for the value of knowledge because it shows that what we call 'knowledge' is really just true belief that we happened to get right. If the slave boy's 'knowledge' of the diagonal is really just a true belief he had all along, then there's no real difference between knowledge and mere true belief. And this is exactly the problem Gettier later pointed out, namely that our standard analysis of knowledge as justified true belief breaks down in certain cases, since we can have justified true beliefs we wouldn't call knowledge. So the Meno problem is essentially the same as the Gettier problem."
