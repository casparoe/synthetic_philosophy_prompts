A philosophy-of-science blog summarizes the Rietdijk–Putnam argument for the block universe as follows: “Rietdijk showed that in special relativity, if two events are spacelike-separated, one inertial frame calls them simultaneous while another places one in the past and one in the future. So if only present things exist, whether a distant supernova has occurred depends on whether you are walking or standing still. Putnam added that since every event lies on some other observer’s plane of simultaneity, there is no objective ‘now’—only a four-dimensional block in which past, present, and future are equally real and causally fixed. This means determinism is built into physics itself: future states already exist in the block exactly as past ones do, so nothing is genuinely open.” The blogger concludes that presentists must either reject special relativity or accept a bizarre velocity-dependent ontology in which existence shifts with reference frame.

How fair is this summary? Please audit it claim by claim: which parts accurately reflect Rietdijk’s and Putnam’s reasoning, which subtly conflate the argument from relativity of simultaneity with separate theses about causal determinism or ontological parity, and whether the blogger’s framing of the presentist’s dilemma is correct. In particular, does showing that there is no frame-independent “now” by itself establish that future events exist in the same ontological sense as present ones, or is there a gap—perhaps involving hyperplane-dependent presentism or a restricted ontology of world-lines—that the blogger glosses over? And does the argument genuinely entail that “nothing is open,” or is that an added interpretation?
