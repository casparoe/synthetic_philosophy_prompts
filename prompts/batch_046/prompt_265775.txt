The prompt was: "Explain the Frege-Geach problem for moral expressivism, with attention to embedded contexts—especially indicative conditionals and epistemic modal constructions such as 'If killing is wrong, then it might be impermissible to defend it.' Then evaluate the proposal that embedded moral sentences express not the speaker's actual attitude but a 'conditional commitment' linking attitudes across possible evidential updates. Does this solve the problem for both indicative and modal embeddings, and for negation?"

Student answer:
"The Frege-Geach problem arises because expressivism holds that a sentence like 'Lying is wrong' expresses a non-cognitive attitude—disapproval—rather than a belief. In unembedded use this is straightforward. But in an embedded context, such as the antecedent of a conditional ('If lying is wrong, then stealing is wrong'), the speaker does not seem to express actual disapproval of lying; they merely suppose it. This is Frege's point: the clause retains its sense but loses its assertoric force. Geach added that logical relations like modus ponens must still hold, which requires that the premises carry the same content whether embedded or not.

The difficulty is sharpest for conditionals. If the conditional expresses only a relation between attitudes, then accepting it together with accepting that lying is wrong should yield acceptance that stealing is wrong. But since the antecedent expresses no actual attitude, there is nothing to relate.

A promising fix is the conditional-commitment view: embedded sentences express a disposition to adopt the corresponding attitude should one's evidence change. So in the modal case—'If killing is wrong, then it might be impermissible to defend it'—the speaker does not disapprove of killing, but commits to withholding permission to defend it should they come to disapprove of killing. This handles both indicative and modal embeddings, because both track attitude-updating across possibilities. It also solves negation: 'It is not the case that lying is wrong' expresses the absence of this conditional commitment, which is still a structured mental state rather than a bare gap. Thus expressivism preserves logical coherence across all embeddings."
