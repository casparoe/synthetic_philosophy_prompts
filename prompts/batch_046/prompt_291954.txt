Here is a philosophy-of-mathematics exam question and a student response for grading.

Question:
Consider the unrestricted comprehension principle of naive set theory: for any well-formed condition φ(x), there exists a set S = {x | φ(x)}. Russell’s paradox applies this to φ(x) := x ∉ x, yielding a set R that both belongs and does not belong to itself.

Write a response of approximately 350–450 words addressing the following:
1. Precisely derive the contradiction from unrestricted comprehension, specifying exactly which inference rules and set-existence claims are involved.
2. Explain Zermelo’s axiom of separation (Aussonderung) and show exactly how it blocks the formation of R. Is this best interpreted as a metaphysical “limitation of size” in Cantor’s sense, or as a logical restriction on definitional circularity?
3. Explain Russell’s ramified type theory—not simple type theory—and show how it blocks R. Identify one specific philosophical cost, such as the need for the axiom of reducibility, and explain why that cost arises specifically within the ramified framework rather than in a flat hierarchy.
4. Assess the diagnosis: does the paradox demonstrate that naive set theory is strictly logically inconsistent, or does it show that our pre-theoretic notion of “set” was never a single coherent concept but rather a family of related notions?

Student answer:
“Russell’s paradox starts with R = {x | x ∉ x}. By unrestricted comprehension, R is a set. If R ∈ R, then R ∉ R by definition; if R ∉ R, then R satisfies the condition and so R ∈ R. Contradictory. So naive set theory is inconsistent.

Zermelo fixes this with separation: given any set A, we can form {x ∈ A | φ(x)}. To form R we’d need a universal set U containing everything, but separation only gives subsets of existing sets. This is basically Cantor’s limitation of size: some collections are too large to be sets. So Zermelo’s solution is a size restriction.

Russell uses type theory. Individuals are type 0, sets of individuals type 1, sets of those type 2, etc. Since x ∉ x mixes types, it’s ill-formed. This removes circularity. The downside is the axiom of reducibility, which Russell needs to do mathematics and which philosophers criticize as ad hoc. Simple type theory avoids this by just having a flat hierarchy.

So the paradox proves naive set theory is inconsistent. The pre-theoretic idea of set was basically fine; we just had to add formal rules. Both solutions preserve the core intuition—Zermelo by limiting size, Russell by ordering types.”
