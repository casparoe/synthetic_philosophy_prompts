Question: Clark and Chalmers defend active externalism via the parity principle, using Otto (who relies on a notebook due to memory loss) and Inga (who relies on biological memory). Adams and Aizawa respond with the coupling-constitution fallacy. Evaluate whether their objection undermines the parity argument, and assess Clark’s later appeal to functional poise and cognitive integration. In particular, does extended cognition require strict functional equivalence between internal and external resources, or does Clark’s integration criterion relax that demand?

Student answer:
Clark and Chalmers argue that if an external process plays the same functional role as an internal cognitive process, then it is literally part of cognition. In the Otto and Inga case, retrieving information from a notebook plays the same role as biological memory retrieval, so Otto’s cognition extends into the notebook. This is active externalism, not passive externalism, because the environment is actively used in real-time cognitive processing rather than merely providing background conditions.

Adams and Aizawa claim that causal coupling is not constitution, but they concede that if an external resource achieves genuine functional equivalence with an internal process, it can be included in cognition. They deny that Otto’s notebook meets this standard, mainly because writing and reading are slower and more deliberate than neural recall. Clark replies with the idea of functional poise, which requires that an external resource be integrated into the cognitive system in the same way internal resources are. On Clark’s view, functional poise is essentially a stricter form of functional equivalence: it ensures that only resources mirroring internal dynamics count as genuinely extended, thereby resolving the coupling-constitution worry by tightening the parity condition.
