ok so I'm taking this course on AI alignment and I got into a debate with my roommate about whether tool AI can ever do real value reasoning, and now I'm not sure my own position hangs together. here's roughly where I stand: (1) I think we should build AI strictly as tools - no persistent goals, no acting in the world without a direct user prompt, just responsive computation. (2) But I also think the right alignment target is coherant extrapolated volition, where the system figures out what we would want if we knew more and thought longer. (3) I think for that to actually work the system needs what I'd call "epistemic closure" - an internal world-model that updates on its own between queries, otherwise it can't do the long-range counterfactual reasoning about values. (4) I also think the tool/agent line should be drawn exactly at this closure thing: if there's no independent world-model updating, it's a tool, even if it takes autonomous actions. (5) And I think CEV should be applied locally per-user rather than globally, because different people's values might be genuinely incommensurable.

So here's where I get stuck. If (2) and (3) are right, doesn't that mean any system capable of real CEV automatically has epistemic closure, and therefore by (4) it's an agent? That seems to blow up (1). Meanwhile (5) looks like it clashes with the "what we would want" framing in (2), but maybe that's just a scope thing and not a real contradiction? And then there's (6) I think that without closure a system can't do genuine moral reasoning, it just pattern-matches explicit requests - which feels like it just reinforces the problem with (1). Is there some way to save pure-tool CEV, or is the only consistent package giving up (1) and accepting that value-alignment requires agent-like closure? Or maybe I'm wrong that closure is necessary for CEV? I genuinely can't tell which commitment is the weak link here, and I don't want to just drop one arbitrarily.
