hey, my study group came up with this argument about finks and masks and now we're stuck. (1) If x is disposed to φ then in all nearby worlds where x isn't finked or masked, x φ's when triggered. (2) For any macroscopic object O — a heart, a market, a person — there are nearby worlds where some external blocker (a gadget, a social rule, an inhibitor) stops φ without changing O's intrinsic physical properties. (3) So in some nearby worlds O is finked, in others masked, in others neither. (4) Therefore there's no consistent modal neighborhood where O determinately φ's; the disposition is unstable across worlds. (5) So O just doesn't have the disposition at all — dispositions require modal stability. (6) That kills "the heart is disposed to pump" and "markets correct mispricing" for the same reason. (7) So either we reject modal stability or we reject almost all macroscopic dispositions. I really don't want to drop (6) but (5) feels like a non-sequitor to me. Where's the actual slip, and what's the cheapest premise to give up?
