okay so i've been chewing on this ubuntu idea where people say i am because we are and that you're not really an individual, just a knot in a web of realtionships. i think i've built an argument that breaks it but the conclusion feels wrong so i'm probly messing up somewhere.

1. if ubuntu is right, then who i am is fully constituted by my relationships - family, community, ancestors, even people not born yet (i read somewhere that in some versions the web goes vertical through time, not just sideways).

2. if my identity is fully constituted by specific relationships, then replacing those relationships with different ones should replace me - like if you swap every thread in a knot for a different thread, you don't have the same knot.

3. but relationships are always changing. people die, move away, new ones show up. so if (2) is true, i'm literally a different person every few years, maybe every few months.

4. also, since dead ancestors are part of the web, harming them (like disrespecting graves) is harming parts of my own self, so i have the same moral reason to protect dead relatives as i do to protect myself.

5. and if unborn descendants are in the web too, then my current self is partly made of people who don't exist yet - which seems impossible, since you can't be partly made of something that isn't there.

6. but all of that is absurd. i moved to a new town last year and made all new friends, but i'm still me. and i don't think i'm literally part ghost, part future-baby.

7. so the relational view of personhood must be false.

where's the mistake? i'd really like to keep (1) and (6) if i can, but i'm willing to drop the vertical-time stuff in (1) or the replacement logic in (2). what's the least bad option, and what does giving up each one cost?
