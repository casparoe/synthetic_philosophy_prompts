I'm a software engineer, not a philosopher, so this might be muddled. I've been messing with quines and self-replicating scripts, and I keep seeing people draw an isomorphism between DNA copying itself and Gödel's proof. Here are my gut verdicts, and I can't tell if there's a real principle behind them or I'm just being inconsistent.

1. A quine that prints it's own source exactly feels like direct self-reference — the code refers to itself the same way Gödel's formula says it's unprovable. So the DNA-Gödel link holds here.

2. DNA replicates via polmerase, but polmerase is built from DNA instructions. That's indirect — like a compiler that needs to exist before it can compile itself. Still feels Gödel-ish, maybe Hofstadter's strange loop, just weaker.

3. A script that randomly mutates and only keeps copies that still run evolves fine, but there's no fixed point or self-reference. I feel zero Gödel vibe — it's just selection. So the parallel breaks completely.

4. The idea that DNA literally is a Gödel-numbered string decoding arithmetic inside itself sounds wrong. DNA is chemistry, not arithmetic. I reject the strong isomorphism.

5. But if you map DNA bases to numbers, the sequence becomes a number that encodes instructions to build the reader. Sometimes that feels structurally identical to Gödel numbering; sometimes it feels like I'm just impressed by the word code. I keep flipping.

So is there one principle separating genuine self-reference from mere replication? Or am I drawing the line arbitrarily? Which of my verdicts — especially 2 versus 3 — does the best principle force me to drop? And please analyse what it says about a case I haven't listed: a blockchain that validates it's own hash chain. Is that closer to case 1 or case 3?
