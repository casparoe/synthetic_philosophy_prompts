I've been trying to work out this argument about Frege's puzzle that a friend sketched for me, and it feels like it proves way too much but I can't find the exact crack. Here it is, numbered so it's easier to follow:

(1) Frege solves the identity puzzle by saying 'a = b' can be informative because the two names have different senses, even though they share a reference.

(2) Let's make this precise with cognitive files: a sense is just a mental file that tracks an object and stores beliefs about it.

(3) So learning 'Hesperus = Phosphorus' is informative because you merge two files that were previously separate.

(4) But now notice: you could also have two separate files both tagged 'Venus' — say, one from childhood and one from astronomy class — without realizing they're the same file.

(5) If you then learn 'Venus (file 1) = Venus (file 2)', that merges them, so even 'Venus = Venus' can be genuinely informative for you.

(6) So the informativeness of an identity statement depends not on whether the names are syntactically different, but on whether the hearers mental files are duplicated.

(7) That means theres no objective semantic distinction between 'a = a' and 'a = b'; the difference is purely in the listener's psycholgy.

(8) Extend this: if I store '2 + 2' and '4' in separate mental files, then learning they're equal is just another file merge. So arithmetic knowledge is also just psychological housekeeping.

(9) But then Frege's distinction can't do the work he wanted — it doesn't separate logical truths from empirical discoveries, it just separates tidy minds from messy ones.

(10) So we should reject the sense/reference distinction altogether, or else accept that all knowledge is subjective file management.
