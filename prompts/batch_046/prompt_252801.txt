The scale argument calculates expected moral weight as N × p × u. For insects N might be 10^19 while farmed vertebrates are near 10^10 with p ≈ 1, so even p = 0.01 gives Np ≈ 10^17, which dominates. Applying the squared discount for p < 0.5 yields Np² ≈ 10^15, still far larger, so the argument survives; it just shrinks the margin. Critics who propose this discount are mainly worried about tractability—they think wild ecosystems are too complex to intervene in, so huge N shouldn't drive priorities. But that's a mistake about categories: tractability belongs in implementation, not in the aggregation function itself. The argument from marginal cases also supports linear aggregation, because if we discount insects for low confidence we'd have to do the same for human infants with uncertain sentience capacities, which is unacceptable.
