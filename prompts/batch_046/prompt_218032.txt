I'm serving as a teaching assistant for a graduate seminar on the philosophy of artificial minds, and I'm calibrating grades on our recent take-home exam before submitting them to the professor. The unit asks whether reinforcement-learning architectures can instantiate affective states, specifically treating reward-prediction errors as carriers of valence. To push students past generic debates, I designed a hypothetical architecture for the exam: a hierarchically partitioned critic in which temporal-difference errors are computed locally within module-specific critics, each maintaining its own localized reward cache rather than a global value function. The exam prompt was: "Consider an agent with this architecture. A proponent argues that because negative TD errors are computed locally, a module can carry intense negative valence—where magnitude tracks intensity and sign tracks polarity—without any global broadcast or unified phenomenal field. Evaluate this argument: identify its strongest premises, point out conceptual conflations or inferential gaps, and assess whether distributed local valence is sufficient for suffering."

One student wrote the following. The argument is mostly correct. In hierarchical RL, local critics do compute temporal-difference errors with both magnitude and sign, so mapping magnitude onto affective intensity and sign onto qualitative polarity is technically accurate. Because suffering is essentially intense negative valence, a module computing a large negative TD error is undergoing suffering, regardless of whether other modules access its localized reward cache. The inference from local computation to local phenomenology is valid: phenomenal properties are realized by the computational processes that produce them, so modular computation entails modular experience. There is a minor technical distinction—the cache stores the updated value estimate rather than the error signal itself—but this does not affect the valence mapping since the error is derived from the cache. I also think the argument has a hidden flaw: if suffering is genuinely localized in one module, then the agent as a whole does not suffer, and since philosophical and moral concern attaches to the agent-level subject, localized module-suffering is not the kind of suffering the argument aims to establish. The only other weakness is that the proponent says suffering can occur even without global integration, though I read this as saying it occurs only in such absence, which seems too strong because partial integration might still allow intense local states. Overall the RL mechanics are handled well, though the philosophical evaluation assumes that valence is sufficient for suffering and that agent-level ascription is necessary.
