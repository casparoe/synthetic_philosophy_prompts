For a graduate seminar on rational agency—fourteen students, seventy-five minutes—design an in-class simulation that makes the Löbian obstacle to self-trusting agents felt as a lived coordination failure rather than as an abstract incompleteness result. Participants should leave the room seeing why an agent capable of reasoning about its own soundness is structurally blocked from consistently endorsing the very inference rule that would allow it to trust itself for stronger conclusions.

Introduce a framing not usually found in standard expositions: treat the class as modules of one distributed reasoning agent. Each student-module can individually verify logical derivations only up to a fixed length—say, five inference steps—represented by physical cards. The group must vote unanimously to adopt a meta-rule that permits any module to extend verification to six steps, but only if the collective has already endorsed the extension. The payoff scheme should use symbolic course-credit points awarded for successful collective endorsements, with individual penalties for breaking consensus or attempting unauthorized verification.

Structure the session in three timed phases: individual verification of simple claims using the five-step cards; collective voting on endorsements that stay within the bound; and a final attempt to endorse the meta-rule itself, which requires verifying a six-step proof of the group’s own soundness—thereby invoking the rule that is still under vote. The rules and card distributions should be arranged so that the deadlock emerges organically: each module can see that endorsement is rational, yet applying the meta-rule to validate its own adoption demands a verification length that exceeds every individual’s unaided capacity, and the unanimous vote cannot be secured without prior access to the very capacity being voted on.

Specify the physical materials (role cards, step-limit tokens, voting chips), the exact payoff matrix, the timeline with transition cues, and the facilitator script for the debrief. The debrief should map each phase onto the logical anatomy of the obstacle—individual soundness belief, collective self-reference, and the fixed-point tension—without simply lecturing. Predict honestly what will go wrong the first time: for instance, one student will likely treat the five-step bound as an arbitrary game constraint and propose an informal work-around, or the group will confuse epistemic limitation with social disagreement. Note how to handle each failure without breaking the simulation.

Finally, state clearly which feature of the formal Löbian result—specifically, the Gödelian arithmetization of syntax that creates the self-referential fixed point—the simulation cannot reproduce, and identify the precise conceptual point the facilitator must supply verbally after the activity ends to close the gap.
