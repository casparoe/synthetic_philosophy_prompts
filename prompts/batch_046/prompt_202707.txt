I have come to think that Bertrand's paradox does not show the principle of indifference is bankrupt; rather, it demonstrates that indifference is always indexed to a parameterization, and that in continuous spaces there is no parameterization-independent fact about uniform distribution. More specifically, I believe the correct response is not to hunt for the true geometric measure, but to treat the choice of measure as a modeling decision constrained by causal structure and predictive performance: for multiplicative processes we should be uniform in log-space, for arrival times in linear time, and in forecasting domains like transformative AI we should make explicit which variable — research expenditure, calendar time, or capability threshold — we are distributing over. The disagreement between forecasters who place transformative AI in 2030 versus 2070, on this view, is often not an empirical disagreement but a hidden disagreement about which parameterization is causally basic, and there is no neutral outside-view prior that settles it without smuggling in that choice.

What would have to be true for this position to be wrong? I am looking for an honest exposure map: which formal results, for instance about invariant measures under reparameterization or about the uniqueness of causally invariant priors, would undermine it; which empirical patterns in forecasting or physics would count against treating parameter choice as model-dependent; and whether there is a live argument that some parameterization really is privileged by pure symmetry considerations after all. I want decisive defeaters separated from merely awkward ones, and I want to know which of these a committed defender of this view would themselves concede as counting against them — for example, would they grant that if a single parameterization consistently outperformed all others across domains, that would be fatal? — versus which they would dismiss as missing the point. If the view turns out to be well-insulated, say so, and say whether that insulation is a virtue or a vice for a framework meant to guide belief under uncertainty.
