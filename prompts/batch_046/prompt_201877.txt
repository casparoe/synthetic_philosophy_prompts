I've been messing around with an idea I'm calling recursive preference anchroing — the notion that in a CEV-style framework, for any preference P to count as genuinely part of your volition, there has to be a second-order preference that endorses P, then a third-order one endorsing that, and so on. I wrote this up for a seminar and now it looks like it proves far too much.

(1) If a preference belongs to your coherent extrapolated volition, then you must also prefer that you hold it — otherwise it's just an alien impulse.
(2) That second-order preference must itself be part of your CEV, so by (1) you need a third-order preference endorsing the second.
(3) Therefore CEV requires an infinite ascending chain of endorsed preferences.
(4) No actual or idealised agent can contain infinitely many distinct mental states.
(5) So CEV is impossible; there is no idealised preference set.
(6) But ordinary rational agency works the same way — I prefer tea, and I can prefer that I prefer tea, etc.
(7) So the regress also wipes out everyday rational preference, which is absurd.
(8) Hence (1) is false, and prefernces don't need meta-endorsement to be ours.

I'd rather keep (1) if I can, because without it CEV seems like it's just aggregating random impulses. But I feel like (2) is smuggling in an identity condition that doesn't belong. Which step actually breaks? And if I have to choose, what's the cheapest revision — giving up (1), (2), or (4)? Also, be straight with me: if this whole framing rests on a confused premise about what CEV is meant to do, say so plainly rather than politely patching it up. Where does it go wrong, and what does fixing it cost?
