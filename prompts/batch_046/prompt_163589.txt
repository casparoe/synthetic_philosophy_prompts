Here is an argument my tutor sketched that now strikes me as overreaching, and I cannot locate the exact slip. (1) If a being is omnipotent, then it can perform any logically possible task, including creating a stone so heavy that it cannot lift it. (2) If it can create such a stone, then there is a task—lifting it—that it cannot perform, contradicting omnipotence; if it cannot create the stone, then there is a task it cannot perform, which also contradicts omnipotence. (3) So omnipotence is impossible. This part is familiar. But then the argument extends: (4) Replace "omnipotent being" with "any agent possessing a non-trivial power P," and replace "create the stone" with "exercise P in a manner that produces a state S in which P is permanently disabled." (5) For any such P, either the agent can enter S or it cannot; if it can, then P is not essentially possessed but only contingently held; if it cannot, then there exists an exercise of P that is impossible, hence P is limited. (6) Therefore every power is either essentially absent or essentially limited—there are no unqualified, essential capacities. (7) Apply this structure to existence itself, treating "to exist" as a capacity: either being can annihilate itself, in which case existence is contingent rather than necessary, or it cannot, in which case existence is limited and not absolute. (8) Hence necessary being is impossible, and with it any ground for why there is something rather than nothing. I want to keep the intuition that omnipotence is genuinely puzzling, but I do not wish to pay the price of (6) or (8). Which step should I reject, and what does rejecting it cost for the original stone paradox? Please reply in British English.
