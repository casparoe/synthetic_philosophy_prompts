Exam question: Consider the Kelly criterion applied to repeated, sequentially independent bets on a biased coin with win probability p = 0.55 and net odds b = 1 (even-money). A student of decision theory argues that adopting the Kelly fraction f* = 2p − 1 = 0.1 represents a form of geometric rationality that is incompatible with the independence axiom of von Neumann-Morgenstern expected utility theory. First, explain precisely why log-utility maximization violates the independence axiom, using the structure of compound lotteries. Second, evaluate whether this violation undermines the normative status of geometric rationality in long-run investment contexts, or whether the axiom should be restricted to single-period choice.

Student answer: The Kelly fraction f* = 0.1 maximizes the expected logarithm of wealth, which is equivalent to maximizing the geometric mean growth rate across rounds. Because wealth compounds multiplicatively, W_n = W_0 ∏(1 + fX_i), geometric rationality treats the entire path of outcomes as the primary object of evaluation rather than each round in isolation.

The independence axiom requires that if lottery A is preferred to B, then mixing both with a third option C using identical probabilities preserves the preference. Log-utility violates this. For any two compound strategies L1 and L2, mixing them with a risk-free payoff C yields U(αL + (1−α)C) ≠ αU(L) + (1−α)U(C) because log is nonlinear. Specifically, if C guarantees a return r > 0, the presence of C changes the optimal leverage in L, reversing the preference ordering between L1 and L2 that held without C. Thus independence fails.

This failure is not a rationality defect. The von Neumann-Morgenstern framework proves that continuity, independence, and completeness entail maximizing expected utility with a linear utility function over wealth; since Kelly uses a concave log function, it necessarily steps outside this framework. But that framework was designed for single-period additive evaluation. In sequential investment, multiplicative consistency replaces additive separability, so geometric rationality corrects the axiom rather than violating rationality. The continuity axiom also fails under log utility because concavity creates a discontinuity at zero wealth, confirming that the standard framework is inapplicable here.

One should note, however, that Kelly betting requires exact knowledge of p and infinite divisibility. With estimation error or discrete capital, overbetting can collapse the geometric mean, so practical applications require fractional-Kelly adjustments that the pure criterion does not prescribe.
