I'm trying to work out what principle, if any, captures my gut verdicts on belief-updating with conditionals, especially in Judy Benjamin-style situations where I learn a consequence and have to redistribute credence over partitions.

My verdicts:

Case 1: Classic setup. I'm either in Italy or Spain, prior 50/50. If Italy then mountains; if Spain then coast. I learn I'm in mountains. Verdict: Italy jumps to near-certain, Spain is basically out.

Case 2: Same setup but there's a rare background cause of mountains in Spain (prior 5% on that cause). Verdict: Italy still jumps, maybe to 80%, and Spain gets a small slice back via that cause.

Case 3: Two independent paths to the same result: if the server is hacked then data is stolen; if the backup fails then data is stolen. I learn data was stolen, and I already knew backup was fine. Verdict: hacking is more likely now, but I don't go to 100% because the conditional isn't deterministic.

Case 4: Two paths that are mutually exclusive: if Alice gets promoted she'll move to Berlin; if Bob gets promoted he'll also move to Berlin, and exactly one gets promoted. I learn someone moved to Berlin but don't know who. Verdict: Alice vs Bob should stay at prior. But if I then learn it wasn't Bob, Alice should jump.

Case 5: The one I keep flip-flopping on. I learn that the material conditional if P then Q is true, and separately I recieve that Q is true. In one mood this gives zero reason for P. In another mood, if that conditional was my only bridge linking P and Q, then Q should pull P up a bit. I genuinely can't settle it.

Is there a coherent principle behind cases 1-4? Does it force me to pick a side in case 5? And what about a scenario where I learn P is false but the conditional was asserted counterfactually -- should learning Q still matter?

Please be honest about which verdict your principle can't save. Also tell me what hidden symmetry assumption or evidential mistake, if shown wrong, would change your mind -- I think my reasoning might collapse if evidential relevance isn't symmetric across partitions.
