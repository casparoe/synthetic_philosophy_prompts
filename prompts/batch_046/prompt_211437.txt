Skolem’s paradox arises from the Löwenheim-Skolem theorem applied to Zermelo-Fraenkel set theory with Choice (ZFC). The downward direction of the theorem shows that if ZFC has any infinite model, then it also has a countable one. Inside that countable model, however, there is still a set—typically the power set of the natural numbers—that the model treats as uncountable, because no bijection between that set and ω exists within the model, even though such a bijection exists in the ambient metatheory. The paradox is therefore that a theory describing genuinely uncountable structures can be satisfied by a domain with only countably many objects. This shows that first-order logic is unable to fix the cardinality of its domains categorically: the property of being uncountable is not absolute but model-relative. In other words, whether a set is uncountable depends on which model of ZFC you are working inside, much as the truth value of an independence result like CH depends on the model. Skolem himself resolved the tension by arguing that all mathematical objects are ultimately constructible and therefore countable; the appearance of uncountability is merely an artifact of the formal language’s inability to restrict the domain properly. Consequently, the paradox does not show that ZFC is inconsistent, but it does show that first-order axiomatizations cannot capture the intended interpretation of set theory with absolute cardinality.
