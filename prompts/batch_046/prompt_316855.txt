I've been turning over an argument that feels like it ought to collapse finitism, but I'm suspicious because the conclusion seems stronger than I'm willing to accept. Here it is, step by step.

(1) The finitist about mathematics accepts potential infinity — for any finite occupancy n of Hilbert's hotel, there is a coherent state with n+1 guests — but denies there is ever a completed state with infinitely many rooms filled.

(2) Call the collection of all finitist-acceptable occupancy states S. Every member of S is finite, but for every member there is a larger one, so S is not bounded by any finite cardinal.

(3) The finitist insists S is not actually infinite, only "indefinitely extensible."

(4) Now consider the set of all descriptions of states in S. By Cantor's diagonal argument, any attempt to enumerate all members of S fails: there is a state-description that differs from every listed one.

(5) So there is no complete survey of S. But if there is no complete survey, then the claim "every state in S is finite" cannot be verified as applying to a definite totality; it becomes an open-ended rule rather than a property of a completed domain.

(6) Once we treat S as a domain over which universal quantification must range, Cantorian results apply: the "indefinitely large" collection behaves, for logical purposes, exactly like an actual infinite set.

(7) Therefore, finitism either smuggles in an actual infinity at the meta-level (the totality S) or it must reject universal quantification over all possible states — which undermines the finitist's own ability to assert that no actual infinity exists.

This seems to prove too much: it turns potential infinity into actual infinity just by asking about the collection of all potential instances. Where does the argument slip? Is the error in treating S as a legitimate domain for Cantor's argument, or in assuming that failure of enumeration implies a completed missing element rather than an unending process? If I have to choose, I'd rather keep the intuition that potential infinity doesn't entail actual infinity, but I want to know exactly what I'm paying to keep it.
