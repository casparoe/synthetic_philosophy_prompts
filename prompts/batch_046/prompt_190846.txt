I'm trying to work out whether strict finitism can be motivated by a reductio rather than by bare intuition, and I've constructed the following argument. (2) Cantor's power-set result entails there is no largest cardinal: for every infinite set there is a strictly larger one.
(3) Together these violate Euclid's part-whole principle globally: not only can a proper part match the whole in size, but there is no "complete" infinite totality that contains all others.
(4) Now suppose, for reductio, that actual infinities are instantiated in reality—say, the totality of physical events is actually infinite.
(5) Call this the reflexivity problem for cosmological cardinality: by (1), a proper subset (e.g., all events within our past light cone) can be placed in one-to-one correspondence with the totality of all physical events, so empirical cosmology can never distinguish the local domain from the global whole.
(6) By (2), for any cardinal κ describing a complete physical theory, there is a larger cardinal 2^κ describing a strictly more comprehensive domain, which means the regulative ideal of "complete science" has no ceiling and hence no determinate meaning.
(7) But "all physical events" and "complete physical theory" are indispensable framing conditions for cosmology and scientific explanation.
(8) Therefore actual infinities cannot be ontologically instantiated.
(9) Mathematics that requires them—Cantorian set theory, Hilbert-style reasoning—must be interpreted instrumentally rather than as describing real modal spaces.
(10) Hence strict finitism holds: every actual collection is finite, and infinite mathematical structures are useful fictions with no ontological weight.
