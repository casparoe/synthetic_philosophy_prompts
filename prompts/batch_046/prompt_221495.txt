Here's an argument about superrationality that I now suspect proves too much.

(1) In a symmetric one-shot prisoner's dilemma, two superrational agents recognize that their reasoning processes are structurally identical and that the payoff structure is the same for both.

(2) If reasoning and situation are fully symmetric, the agents must reach the same decision.

(3) The jointly optimal decision is mutual cooperation.

(4) So superrational agents should cooperate in a one-shot PD.

(5) But cooperation is strictly dominated by defection in a one-shot PD, regardless of the opponent's actual choice.

(6) A rational agent should not adopt a strictly dominated strategy.

(7) Therefore superrational agents should defect.

(8) (4) and (7) contradict, so one premise must fail.

(9) The standard escape rejects (6): in symmetric reasoning, dominance is invalid because my choice correlates with the opponent's—cooperating is evidence that they cooperate too, altering the expected payoff.

(10) But if dominance fails whenever I can symmetrically model another agent, it also fails in Newcomb's problem, in pivotal-voting reasoning, and in any causal-decision context with predictive correlation.

(11) So either superrationality is false, or dominance reasoning and causal decision theory collapse globally.

(12) The global collapse in (11) is implausible, which seems to refute superrationality—yet I want to preserve (9) if I can.

Which step actually breaks, and what does giving it up cost? Is the error an equivocation between structural identity of reasoning and predictive correlation, or does the contradiction show that superrationality is coherent only if we accept the global collapse?
