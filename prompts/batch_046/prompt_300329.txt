I was reading some decision theory after watching a youtube video on Newcomb's problem (probaly shouldn't have started there) and now I'm stuck on a pattern I keep seeing in these thought experiments but I don't have a word for it. There's the usual thing where someone offers you a payout if a coin came up heads but asks you to pay up in the tails world, and the pressure comes from thinking about what you would've done in that other branch. Fine. But here's a twist I cooked up and I'm not sure if it's the same idea with extra steps or actually different.

Imagine three possible worlds — A, B, and C — and you think each is like 1% likely. In world A, agent X gives you $1000 for free. In world B, agent Y does the same. In world C, nothing happens. Now agent X shows up in world C and says: "I'll hand you $1000 right now, but only if you commit that in world B — where I'm not around — you'd pay agent Y $50." And agent Y makes the mirror-image offer about world A. So you're being asked, in the actual world where neither deal exsists, to promise actions in other worlds that never happen. Each agent only controls one counterfactual, but together they cover every non-actual branch. Is this just XOR blackmail split between two people? Counterfactual mugging with a committee? Or is there actually a named concept for this distributed version?

What I'm really after is the carving: does the fact that no single agent holds both outcomes change the logic, or is it purely cosmetic? And if there isn't a specific name, what should we call the pattern where seperate parties each extract a commitment about a different hypothetical world, locking you into a net that only exists across branches? I feel like the decentralization might matter for whether you can reject the deal without feeling irrational, but I can't tell if that's a real philosophical distinction or just window dressing.
