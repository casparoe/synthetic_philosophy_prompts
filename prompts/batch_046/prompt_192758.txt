I've been noticing this occurence in social-choice arguments that feels like it's in the same neighborhood as Sen's liberal paradox but maybe isn't exactly it. You know the classic setup: two people, each cares about who reads what, and if you honor everyones prefernces—including the ones about other people—you can't have both Pareto efficiency and a minimal liberty condition. But I've been playing with a three-person loop version that seems different in a specific way. Person A has no self-regarding prefernce at all—literally doesn't care what they get—but strongly prefers that B gets option X. B also doesn't care about themselves, but prefers C gets option Y. C doesn't care about themselves, but prefers A gets option Z. So the paternalistic prefernces form a closed loop, and there are no self-regarding prefernces to anchor anything. If you keep them all in, you get a cycle with no Pareto-optimal point. Is there an established name for this looped, anchorless variant?
