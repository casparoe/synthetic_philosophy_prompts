"A frequentist must withhold any probability assignment because there is no reference class of identical builds, leaving only silence. A subjective Bayesian can supply a prior informed by analogous modules and update upon observation, but because the build is unique the prior dominates and the result is merely personal opinion, not an objective risk measure. The propensity theorist holds that the build possesses an objective physical disposition to fail determined by its actual code structure, yielding a genuine single-case probability that requires no repetition.
