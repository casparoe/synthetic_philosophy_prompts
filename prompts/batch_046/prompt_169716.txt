Consider a variant of the doomsday argument applied not to human births but to successive generations of dominant explanatory frameworks in a field. (1) The self-sampling assumption holds that an observer should treat its position as randomly drawn from all positions in its reference class. (2) If we apply this to frameworks—treating each successful paradigm as an observer that can ask where it sits in the sequence—then being the fifth dominant framework since the rise of modern science should strongly suggest that the total sequence is small, perhaps no larger than ten. (3) From this, the current framework should predict its own near-obsolescence: the next framework should appear quickly, and the one after that should be unlikely. (4) But apply the same reasoning reflexively: every previous framework, being in an early position, should have made the same prediction, which implies that none should have expected to be succeeded—contradicting the historical record of actual succession. (5) Therefore either the self-sampling principle is inapplicable to non-conscious, causally-linked entities like theories, or we are genuinely near the end of the sequence, with the paradox that this very argument predicts there will be no later framework to overturn it. The conclusion feels like a reductio. Where does the argument fail? Is the error in extending the reference class from conscious individuals to abstract frameworks, in treating temporal index as exchangeable when later frameworks depend causally on earlier ones, or in the reflexive step that converts a probabilistic expectation into a barrier to future development? If you preserve the core self-sampling idea for conscious observers, what property of biological life—rather than theoretical history—blocks the same reasoning from applying here?
