Here is an argument I have been turning over concerning Hofstadter’s frame / outer-message / inner-message taxonomy in *Gödel, Escher, Bach*, to which I have added a single restrictive condition — call it the “anchor condition” — and now find that the whole scheme collapses.

(1) In the GEB framework, an inner message is recoverable only when the receiver steps outside the message’s default frame; inside that frame, only the outer syntactic message is available.

(2) To prevent arbitrary hermeneutic projection, I propose the anchor condition: a message genuinely carries an inner message only if it contains an explicit structural marker — an “interpretive anchor” — that directs the receiver to suspend the default frame.

(3) If a message lacks such an anchor, interpretive charity requires treating it as carrying only an outer message; otherwise any syntactic pattern could be claimed to conceal an inner meaning with no falsifiable criterion.

(4) Consider the self-referential sentence “This statement is false” interpreted within a classical logical frame. It contains no explicit anchor directing us outside that frame; its self-reference is entirely internal to the syntax.

(5) By (2) and (3), therefore, it carries no inner message — it is merely an outer syntactic loop.

(6) But this contradicts the standard judgment that such sentences do carry an inner message, namely a demonstration that the frame itself is inadequate to assign a truth-value.

(7) So either we reject the anchor condition, which opens the door to unconstrained projection onto any string, or we deny that paradoxical sentences have inner meaning, which strips the frame/outer/inner distinction of its explanatory power.

(8) Hence the taxonomy either permits everything or explains nothing.

I am most reluctant to give up (6), and I do not wish to abandon the anchor condition entirely, since without it the category of inner message seems empty. Which step should I reject, why did it look plausible, and what does each available option cost? Please reply in British English.
