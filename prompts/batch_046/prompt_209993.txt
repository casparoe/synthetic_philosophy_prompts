Here is an argument about the frame problem that I built for a seminar and now find suspicious, because its conclusion seems to dissolve ordinary cognition. (1) Any system that updates beliefs after acting must have a principle for deciding which beliefs to retain and which to revise. (2) If that principle is explicit—stated as rules linking actions to affected properties—then for every action and every property the system must either carry a specific rule or carry a meta-rule licensing retention; either way the representational load scales with the number of action-property pairs. (3) In any realistic domain that number exceeds finite storage, so explicit rules are impossible. (4) Therefore the principle must be implicit: the system defaults to retention unless a specific trigger prompts revision. (5) But an implicit default is not representational content about particular properties; it is only a structural feature of the update mechanism itself. (6) So when I open a door and continue to believe the wall is still white, there is no representational entry in my updated cognitive state that supports that specific belief about the wall—the mechanism merely failed to delete it. (7) If a belief about a specific state of affairs lacks any supporting representational content in the agent's cognitive state, then the agent does not genuinely hold that belief, but only displays a behavioral disposition to assert it. (8) Therefore after almost any ordinary action I do not genuinely hold beliefs about the vast majority of unchanged properties, despite sincerely affirming them. (9) But that means ordinary human cognition involves almost no genuine world-directed beliefs, which is absurd. (10) So one of the steps must be wrong.

Where does the argument fail, if it does? I am inclined to keep (1) through (4), since the computational intractability of explicit frame rules seems solid. I am also reluctant to abandon (7), because it sounds like a category mistake to call something a belief when nothing in the agent's representational economy addresses its content. That leaves me torn between (5) and (6), but I cannot see how to reject either without smuggling explicit representation back in through the rear door. Which step should I reject, why did it look plausible, and what does rejecting it cost—especially for anyone who wants to maintain that cognition can be both computationally tractable and genuinely belief-laden?
