(2) Presentism requires a privileged global “now” that divides every event into past, present, or future; this demands a globally consistent synchronization of local temporal frames.
(3) Therefore presentism is incompatible with the metric.
(4) Eternalism requires that all events exist tenselessly in a globally ordered B-series. But in this metric, for some distant pairs A and B, A is earlier than B along one timelike path and later than B along another.
(5) So eternalism also presupposes an impossible global ordering and is incompatible with the metric.
(6) Hence, if Gödel’s solution is physically possible, both standard philosophies of time are false.
(7) Yet Gödel is standardly read as using the result only to motivate an idealist or consciousness-dependent view of time—not to reject every temporal ontology—so (6) must be wrong.
(8) My friend says the flaw is in (4): eternalists need only local frame-agreement, not a cosmic chronology, so path-dependent B-relations are harmless. But then I ask: if eternalism survives path-dependence, why can’t presentism survive it too, by letting the “now” be frame-relative?

The argument feels like it proves too much, but I can’t tell whether the hidden slide is an equivocation between physical synchronization and metaphysical ordering, or an unjustified asymmetry in how we treat the two views.
