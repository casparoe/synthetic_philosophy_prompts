Escher's Drawing Hands is frequently invoked as a visual model of Hofstadter's tangled hierarchy: the hand that executes the drawing is simultaneously the object being drawn, so the representational and the represented levels appear mutually constitutive. Hofstadter maintains, however, that every tangled hierarchy rests upon an inviolate level. In the image there is no visible substrate—no hand outside the loop—so the loop seems genuinely to lack an inviolate base. Given this, if consciousness possesses an analogous strange-loop architecture, must we conclude that it too lacks an inviolate neural substrate? And does the absence of such a substrate make downward mental causation unavoidable, since no implementation level remains immune to semantic influence? I want to use this to challenge functionalism, which I understand to require a syntactic level entirely untouched by interpretation. Identify the misstep.
