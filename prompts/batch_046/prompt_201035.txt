So finks destroy the disposition upon triggering, while masks preserve it but obstruct its expression.

Now consider the reverse-fink: a protective mechanism that activates only when the triggering condition is present and only if the object originally had the disposition. Because the protective response is caused by the very condition that tests for the disposition, its dynamics mirror a fink. But since the categorical properties of the object never change—the object was always structurally capable of manifesting—the interference is really internal to the object’s own dispositional profile rather than an external blocker. Therefore it should be classified as an internal mask, not a true fink.

Once we frame the distinction this way, reverse-finks pose no special problem for dispositional essentialism. In fact, they support it: the protective mechanism can only activate if the categorical base already carries the dispositional power, which demonstrates that the base is sufficient to ground both the disposition and its own defense. So the scenario extends the masking framework and indirectly confirms that categorical properties necessarily entail their associated dispositions.”
