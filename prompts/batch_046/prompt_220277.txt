I'm a student in an advanced course on philosophy of logic and metaphysics, and I've adopted a specific stance on Aristotle's sea-battle problem that runs against the modern consensus. The familiar fatalist argument says: if it is now true that there will be a sea battle tomorrow, then it is now necessary that there will be one, which wipes out contingency. The standard reply denies bivalence for future-contingent statements to block the first premise. I go the other way: I want to preserve bivalence and reject the modal inference instead. Specifically, I propose that we evaluate future-tensed propositions at a present temporal node relative to an open branching structure of possible histories. On this view, "There will be a sea battle tomorrow" is determinately true at the present node—true on the actual history—without being necessary, because necessity requires truth across all histories branching from that node, whereas bivalence only fixes the actual branch. The contingency lives in the branching, not in a truth-value gap.

What would count against this node-relative bivalence position? I want the objections sorted by how decisive they'd be, not just the awkward ones: formal results showing that this semantics collapses into determinism at a meta-level once histories consolidate or merge backward; arguments that retrospective ascriptions—say, "it was true yesterday that the battle would occur"—generate contradictions when branches are no longer open; cases where the view cannot distinguish genuine metaphysical contingency from mere epistemic ignorance about which branch is actual. I also want an honest assessment of whether defenders have already insulated the view by restricting it to singular predictions, treating branch weights as non-truth-apt, or denying that merged histories carry retrospective truth-values—qualifications that might render it unfalsifiable, and whether that insulation is a problem for a logical theory of this kind. What should I concede as genuinely damaging, what is only a verbal dispute about how to formalize "necessary," and where is the weakest point in my own position that I should prepare to defend rather than hope my interlocutors miss? Include the objection I am probably hoping nobody raises.
