I have been trying to work out what it actually means to say that phenomenal consciousness is a user-illusion—on the model where the brain constructs a transparent phenomenal self-model analogous to an operating-system interface, rendering only the world and a unified self while hiding the underlying predictive processing. The metaphor seems to presuppose that there is a functional recipient, some cognitive subsystem for whom the interface is rendered and to whom it is transparent, otherwise transparency is just a property without a relata. But of course the illusionist view denies any Cartesian theater or inner observer, which means the recipient, if there is one, must itself be part of the illusory content. This generates what looks like a regress: if the self-model is transparent to a user, and that user is itself represented within the self-model, then we have not eliminated the homunculus but only relocated it inside the interface. So my question is this: in a hierarchical predictive-coding framework, is the correct resolution to say that transparency is not relational at all, but rather a structural feature of the representation—namely, that the model encodes its content with high precision but fails to encode itself as a model—so that there is genuinely no user behind the screen, only a system that misrepresents its own representational status? And if that is right, does the computer-interface metaphor survive, or does it collapse once we realize that an interface with no user is not an illusion experienced by anyone, but simply an unobserved computation that happens to guide behavior?
