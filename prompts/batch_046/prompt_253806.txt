For a graduate metaethics seminar, construct a taxonomy tree classifying positions on the is-ought gap and the naturalistic fallacy, built from four branching diagnostic claims rather than from a list of named theories. Node 1: can any set of purely descriptive premises—without hidden normative premises—validly entail that one ought to do something? If no, proceed to Node 2, which asks what kind of gap this is: (A) an inferential gap (no entailment relation holds), (B) a motivational gap (facts do not necessarily generate desires), or (C) an institutional authorization gap (normative force requires prior social practices of recognition that descriptions alone cannot supply). If yes to Node 1, proceed to Node 3, asking whether closing the gap requires bridge principles—rational consistency, evolutionary stability, or constitutive norms of agency—and whether those principles avoid circularity. Then apply Node 4 to all branches except pure denialists: does defining 'good' through a natural property commit the open-question fallacy, or is that fallacy misdiagnosed as a category mistake about institutional roles? Map the resulting logical combinations onto named positions where they exist—strict Humean, bridge-principle naturalist, open-question Moorean, authorization-gap institutionalist, rationalist denialist—labeling any unoccupied combinations 'unnamed' and giving each leaf one sentence on its most awkward commitment. Specifically flag whether the tree can separate authorization-gap institutionalists from strict Humeans on practical recommendations, and note any combination that appears incoherent (for example, accepting an institutional gap while denying both inferential and motivational gaps). Present the result as a branching tree with labeled nodes and leaves. Begin with the tree itself, with no preface or commentary, and include no bibliographies, citations, or reading lists.
