We were talking about multiverses and string theory, and whether you can ever confirm something if you can't observe the other universes. I have gut calls on cases but I can't see the principle.

My verdicts: (1) The string landscape saying every constant value exists somewhere feels like it explains fine-tuning but confirms nothing, since it allows every outcome. (2) When string theorists moved the SUSY breaking scale up after LHC null results, that felt like honest theoretical revision, not ad hoc rescue, so I don't think string theory was disconfirmed. (3) But if a multiverse model originally predicted dark energy near zero then rewrote its probability measure specifically to match the observed value, that feels ad hoc and should count against the theory. (4) Two multiverse frameworks that both allow our constants, but one needs three free parameters and the other fifteen—I think the simpler one is more confirmed. (5) A risky quantitative prediction about gravitational-wave background patterns that then shows up gets a big boost, even if the theory allows other patterns. (6) But if that same theory gets retuned to explain why the pattern was actually absent, I think it's now worse off, not back to neutral.

Is there one principle of non-empirical confirmation behind these? If not, which verdict should I drop?
