My study buddy came up with this argument that embedded agents can't actually plan, and I can't see the hole in it. (1) An embedded agent is part of the world it models, so its world-model M has to include the agent A itself. (2) For M to be useful for planning, it needs to be causally closed under A's reasoning—if A updates M, that update itself has to be predictable inside M. (3) So M must contain not just A, but A's process of updating M. (4) But then that inner update-process also needs representation inside M, and so on, giving an infinite regress of nested self-models. (5) No finite physical system can store an infinite regress. (6) So either embedded agents lack planning-capacity, or they aren't truely embedded.

The conclusion feels wrong—people plan all the time. I'd like to keep (1) and (2) since they seem like the heart of embeddedness. Which premise should I drop, and what does giving it up cost? Is (3) sneaking in a Cartesian transparency assumption that embeddedness specifically rejects?
