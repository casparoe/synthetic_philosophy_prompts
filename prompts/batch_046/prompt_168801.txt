I've been messing around with this idea about ontology identification—like, how do we actually decide what kinds are real when a bunch of information is just inaccesible to us? My position is that we should only lock in entities that have some trace in what we can observe or reason to, but I also want to keep this weird extra layer I'm calling "structural debt"—properties that are causaly inert and totally hidden, yet they still constrain which counterfactuals count as the same kind. So ontology gets fixed partly by accessible traces and partly by these silent debts we never directly see.

What would count against this? I want actual defeaters—arguments, thought experiments, maybe formal results—not just "that sounds weird." Rank them from fatal to merely awkward. And be straight with me: has this been qualified into unfalsifiability? Like, can I always invoke hidden debt to explain away weird cases, and if so, is that a real problem for a view like this? Also, what would defenders of this position themselves concede is a weak spot, not just what critics throw at it?
