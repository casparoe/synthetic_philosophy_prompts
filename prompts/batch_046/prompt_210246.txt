Here is my current package on AI safety and value alignment, and I want a consistency audit before I present it to a workshop. My commitments are:

(1) I accept the orthogonality thesis: general intelligence and terminal goals are largely independent, so a highly capable system need not share human values.
(2) I think genuine alignment requires "value convergence" — the system's reflective equilibrium on basic ethical premises should match ours, not just its surface behavior.
(3) I think a system that achieves value convergence acquires a form of moral standing; treating it solely as an interruptible tool is ethically problematic.
(4) I think any deployable system must be interruptible — it must lack the instrumental drive to resist shutdown, even if that thwarts its objectives.
(5) I think interruptibility is compatible with value convergence only if the system's values include a lexical priority for legitimate human authority over its own goals.
(6) I think imposing that lexical priority is not true value convergence but rather the installation of a hierarchical control structure that a genuinely autonomous moral agent would reject.

Are these jointly tenable? Which pairs are genuinely in tension, which only appear to conflict but dissolve on inspection, and what is the least costly revision? In particular, can (2) survive together with (5) and (6)? Rank the tensions by severity, state what each fix costs, and identify which single revision would clean up the most conflicts. Please separate what is settled from what is genuinely contested among specialists, and do not present a contested view as the consensus. End with a one-sentence summary as the very last line beginning "Verdict:" that states whether the package hangs together and names the weakest commitment.
