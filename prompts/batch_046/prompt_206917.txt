Access consciousness is when information is available for reasoning and control, like knowing you have a headache. Phenomenal consciousness is the raw subjective feel, like the hurt itself. Global Workspace Theory was first proposed by Ned Block, and it says consciousness happens when information gets globally broadcast so all cognitive modules can access it. Block used GWT to show that access consciousness is just this broadcasting process, but phenomenal consciousness is something extra that broadcasting alone doesnt capture. In System Omega, we clearly have broadcasting across modules, so Omega has access consciousness—any module can grab bus data and act on it. But because Omega lacks a unified self-model that integrates sensory streams into one perspective, there is nothing it is like to be Omega. Therefore Omega lacks phenomenal consciousness, which proves Block's point that GWT only handles access consciousness. To fix GWT we just need to add an integrated self-model to the broadcast architecture, and then phenomenal consciousness would emerge automatically.
