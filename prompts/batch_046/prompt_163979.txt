(5) Hence I deny that there is “something it is like” to be the colony, yet I deny that this absence proves there is no mind: cognitive character and phenomenal character come apart.
(6) I think a silicon system with the same cross-caste predictive architecture should receive the same cognitive mental-state attributions, still without phenomenal consciousness.

Go through these and tell me which pairs are in tension and how severely. For each genuine tension, state the cheapest fix and what it costs. Identify at least one apparent tension that dissolves on closer inspection. Order the real tensions by severity.
