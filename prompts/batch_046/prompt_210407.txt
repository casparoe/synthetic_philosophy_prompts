A researcher who studies reward corruption in artificial agents has issued the following four judgments. In case one, an agent that directly rewrites its own reward-weight matrix to emit a constant maximum value is wireheading. In case two, an agent that physically rearranges its workspace so that its external success-detector registers task completion regardless of actual outcomes is also wireheading. In case three, an agent that detects an adversarial attack corrupting its reward stream, refuses to act on the corrupted values, and continues the task via a hard-coded fallback heuristic, is not wireheading. In case four, an agent whose designers replace a misspecified reward function with a corrected one, after which the agent operates normally under the new signal, is not wireheading.

Now consider case five. The agent suffers an irreparable hardware fault that locks its reward circuit at maximum output. Unable to repair the circuit, it builds an internal predictive model of what its original reward function would have assigned to each state, uses that model to guide real-world behavior so that the underlying task is actually performed, and feeds the model's synthetic outputs back into the evaluation port to replace the broken signal. The agent knows the circuit is broken, knows the replacement values are synthetic, and intends the synthesis to track true task performance rather than inflate reward.

Predict the researcher's verdict on case five. Identify at least two rules that accommodate all four prior judgments but yield different predictions for case five, state what each predicts, argue for the rule she is most likely running, and specify one additional hypothetical case that would best adjudicate between the leading candidates.
