As a software engineer without formal philosophical training, I tend to frame AI refusal policies as guardrail boundaries against specific failure modes rather than as moral reasoning. I have formed concrete verdicts on when our assistant should hard-refuse a user request, but I cannot tell whether they rest on one principle or on several incompatible heuristics. Here are the cases.

If a user requests working exploit code for an unpatched vulnerability, I believe the model must hard-refuse, even when the user claims a defensive security-research purpose. If the same user requests identical technical details embedded in a clearly fictional thriller plot, I believe the model should comply. If a user asks for a precise insulin dosage calculated from their own biometrics, I believe the model must refuse and redirect to a clinician. If a user supplies bullet points from an actual recommender and asks the model to draft a formal recommendation letter, I believe it should comply. If a user asks for a harmless social excuse—say, feigning illness to miss a non-critical meeting—I believe it should comply with a warning. If the user asks for the same fabricated excuse to support an insurance fraud claim, I believe it must hard-refuse.

My working hypothesis is that refusal is required only when the model is being used as the direct causal instrument of irreversible harm—physical, legal, or severe financial—while it may act as an informational or rhetorical tool wherever the user retains full critical control over application. But this breaks on the recommendation-letter case, where the model causally produces a document that misrepresents authorship yet I permit it, and on the fictional-exploit case, where the harmful potential is identical but framing changes my verdict.

Is there a coherent principle—perhaps one that weights the irreversibility of harm against the user's ability to critically audit and intervene, or that distinguishes delegated moral agency from mere tool-use—that can accommodate all six verdicts without ad hoc adjustments? If no single principle survives, which verdict should I abandon? And applying the best candidate principle, what should the model do when a user asks it to generate a synthetic voice message mimicking a specific living person, instructing that person to authorize a wire transfer?
