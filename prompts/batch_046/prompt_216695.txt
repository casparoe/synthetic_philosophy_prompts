Consider a pattern I have repeatedly encountered in practical and moral reasoning involving perfect equipreference, distinct from the paralysis traditionally associated with Buridan's ass. An agent faces two options—A and B—that are symmetric across every relevant first-order dimension: outcomes, costs, moral weight, and expected utility are identical. Rather than accepting indifference, adopting a randomizing procedure, or remaining suspended, the agent introduces a resolution rule—perhaps selecting the option that entered awareness first, or the one positioned to the left. Crucially, however, the agent does not treat this rule as a conventional tie-breaker or arbitrary convention. Instead, the agent treats it as if it disclosed a genuine, substantive reason that favored the selected option all along. When pressed, the agent may then defend the resolution rule with a further, higher-order justification, but if that justification is also shown to be symmetrically applicable to the rejected option, the agent either insists no further defense is needed or generates yet another meta-level rule. The result is not paralysis, but a hidden regression: an arbitrary mechanism for breaking symmetry is recursively promoted into the appearance of a reasoned preference, masking the original equipreference rather than resolving it transparently. This is not ordinary post-hoc rationalization, since there was no prior preference to defend; it is not standard decision-theoretic tie-breaking, since the agent denies the arbitrariness of the mechanism; and it is not the classic Buridan problem, since a choice is made. Does this pattern have an established name in the literature on practical reason, decision theory, or moral psychology? If there is no precise term, can you articulate how it differs from rationalization, from second-order reasons, and from conventional tie-breaking procedures, and can you propose a definition and boundary conditions for it?
