The student wrote:

"Quine in Two Dogmas shows that trying to ground analytic truths in synonymy is circular, since synonymy is usually explained via interchangability salve veritate, which already presupposes the analytic-synthetic split. The deep vs surface distinction helps here. Surface analyticity is just explicit definition, so Quine's circularity charge definitely applies. Deep analyticity, though, works differently: these are sentences that constitute the rules of a language-game, like logical truths in Carnaps L-rules. Quine says semantic rules are just conventions we lay down, but he treats them as empirical generalisations about speaker behaviour. That's wrong—Carnap meant them as stipulations, not empirical claims. So Quine's argument that semantic rules need empirical backing misses the point for deep analyticity.

As for interchangability: Quine says two expressions are synonymous if they can be swapped in any context without changing truth-value. For deep analytic sentences, this test doesn't apply because they aren't expressions within the language but conditions on having the language at all. So Quine's argument here is a category mistake.

Finally, Quine's holism says any belief can be revised. Some people think this kills deep analyticity, because if framework sentences can change, they aren't special. But actually deep analyticity is compatible with holism: the framework can shift as a whole, just like Kuhn's paradigms. So Quine doesn't show there's no distinction—he just shows it's dynamic rather than static. Therefore the analytic-synthetic divide survives, but in a revised form."
