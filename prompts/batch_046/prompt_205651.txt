I run a philosophy of mind seminar for grad students, about 8 people, 90 minutes. I want an activity that makes them feel the force of attributing moral status to computations, not just talk about it in the abstract. Design a structured role-play where they act as an ethics board deciding which parts of a fictional distributed system get protected status. The system has a central language model, peripheral sensor nodes that do local filtering, and a global weight-rewrite layer that consolidates memory but never processes live inputs. They only recieve behavioral reports—outputs and damage reactions—not internal blueprints, and they vote in rounds. The twist comes in round three: they learn one isolated peripheral node, running only local filtering rules, produces behavior identical to the central model on a narrow task, so they have to argue whether functional equivalence or architectural integration should determine protection. Give them distinct roles (functionalist advocate, integration skeptic, etc.), rules for deliberation, and a payoff scheme using reputation points not real money. Include a debrief that maps each round onto the actual philosophical problem—functionalism, integreation requirements, and the gap where phenomenal consciousness would sit. Be honest about what the activity can't reproduce: actual subjective experience, which the facilitator has to supply. Also tell me what will predictably go wrong the first time—probably they fixate on the central node and completely miss the consolidation layer. Don't lecture them upfront; they should run into the contradiction themselves. Oh, and please don't ask for citations or reading lists since the model won't have web access.
