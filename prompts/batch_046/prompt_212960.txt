Question: In situations of deep moral uncertainty—say, between a rule-consequentialist framework that ranks actions by aggregate welfare and a deontological view that treats certain rights violations as lexically impermissible—what is the central challenge in applying a decision-theoretic framework? Specifically, discuss the problem of intertheoretic comparison, and explain why maximizing expected choice-worthiness does not automatically dissolve it.

Student answer: The core difficulty is that different moral theories evaluate actions with incommensurable metrics: one uses cardinal welfare units, while the other assigns ordinal or absolute prohibitions. Because there is no neutral scale, we cannot directly average outcomes across theories. MacAskill, Bykvist, and Ord propose maximizing expected choice-worthiness as a remedy: for each act, multiply the choice-worthiness assigned by a given theory by our credence in that theory, then select the act with the highest weighted sum. This resolves the comparison problem because choice-worthiness is defined internally to each theory; we never need to translate welfare into rights-language or vice versa. Once our credences are calibrated, the framework yields a determinate recommendation. The only residual challenge is therefore epistemic—securing well-grounded probabilities—rather than metaphysical or structural. If a theory provides only ordinal rankings, we can still apply the formula by treating rank differences as uniform intervals, since expected choice-worthiness requires only that values be numerically representable within each theory.
