"Russell found that if you allow any collection to be a set, then defining R as the set of all sets that do not contain themselves creates a contradiction: if R ∈ R then R ∉ R, and vice versa. Naive set theory assumes unrestricted comprehension, which says for any property P there exists a set {x | P(x)}. Russell's case shows this is false because the property 'x is not a member of itself' fails to determine a consistent set. In ZFC this is fixed by the axiom of separation, which only lets you form subsets of existing sets.

As for Agda, the claim that proof-relevance avoids the paradox is partly right but misses the point. Agda does have a hierarchy of universes (Type_0, Type_1, etc.), which is basically Russell's type theory in modern clothing. But proof-relevance means that when you prove two terms are equal, the proof is a term itself with computational content. This doesn't eliminate self-reference; it just means that if you try to build a Russell-style set, the equality proof would be too complex to type-check. So the real protection is still stratification, not proof-relevance. Actually, Gödel's first incompleteness theorem is really just Russell's paradox applied to arithmetic, using self-reference in formal systems, so both show that unrestricted self-reference is impossible whether in sets or in logic. Overall, naive set theory fails because it trusts properties too much, and modern systems survive by being more restrictive about what can be formed."
