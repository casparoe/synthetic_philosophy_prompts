I've started thinking the species problem only looks hard because we treat speces as sets of organisms with shared properties. What if a species is actually a temporary stablisation of metabalic exchange — a running negotiation between genomes, microbiomes, and even non-living stuff like persistent pollutants or built structures? On this view a coral-zooxanthellae-plastic clump could be one speces-process, not several separate ones. Play it straight: what would count against this? I don't want the standard reproductive-isolation objection; I want the deep defeaters. Which observations or formal results in ecology or systems biology would break it? Which cases can it not describe without stretching? And honestly, has it been qualified into unfalsifiability — if so, is that fatal for a view of this kind? Rank the problems from fatal to merely awkward, and say which ones defenders of this idea would concede versus dismiss.
