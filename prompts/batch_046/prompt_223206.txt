Question: Why can't an embedded agent build a fully accurate world-model that includes itself? Explain reflexive forecasting and how it's different from the frame problem.

Student answer:
"An embedded agent is physically part of the world it models, so running an internal representation takes up resources and changes the system—this is basically the frame problem but turned inward. If it tries to predict its own choice, reflexive forecasting creates a fixed point: the prediction becomes part of the input that produces the action. Bostrom showed that this forces embedded agents to be deterministic, otherwise they can't converge. So they always have blind spots about their own reasoning, which is why they rely on approximate heuristics rather than perfect self-models."
