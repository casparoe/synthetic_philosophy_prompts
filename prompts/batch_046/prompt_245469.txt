Explain the frame problem for classical AI planning, using a concrete example like a robot painting a chair. Then discuss Schank and Abelson's script-based response and identify one reason it fails to fully resolve the issue.

Student answer:
The frame problem comes from McCarthy and Hayes (1969). It's the difficulty of representing everything that doesn't change after an action. If a robot paints a chair red, its colour changes, but weight, position and material stay the same. In a logical planner you'd need frame axioms listing every non-effect, which is representationally intractable.

Schank and Abelson's scripts — like the restaurant script — fix this by bundling default expectations into one structure. Once the system recognises a painting context it activates the right frame, fills in all the unchanged properties automatically, and avoids listing axioms one by one. So the explosion is contained.

But Dennett in 'Cognitive Wheels' (1984) showed this just pushes the problem back. There's now a meta-frame problem: selecting the correct script requires another script, leading to an infinite regress. Scripts are also too rigid for novel cases. So we've hidden the frame problem inside the selection mechanism rather than solving it.
