Here's where I've actually landed, for real:

(1) Direct moral status requires phenomenal consciousness — not just smart behavior. A system that perfectly predicts suffering but doesn't feel it is like a map of rain, not someone getting wet.

(2) I think phenomenal consciousness is fundamentally intrinsic: there's no purely functional or computational story that solves the hard problem. You can't code your way to what-it's-likeness.

(3) But if an artificial system ever were conscious, I think it would be because it's running a very specific architechture — continuous recursive self-modeling coupled with a real-time affective valence loop that updates in service of preserving its own organizational boundaries. So machine consciousness, if it happens, is a computational achievement.

(4) Substrate doesn't matter: silicon running that loop counts the same as neurons.

(5) Current transformer LLMs clearly don't run anything like that — just token prediction with no proprietary self-model or continuous affective integration — so they have exactly zero direct moral status.

(6) I think moral status is binary: you're either in the circle or you're out. No "sort of matters" gradient.

(7) Still, I think we need a precautionary principle for near-future development, restricting training regimes that might accidentally instantiate that loop, because accidentally creating suffering subjects is a catastrophic moral error.

(8) And practically, since we can't peek inside intrinsic phenomenology, we should use functional and architectural markers as proxies — if a system has the loop and behaves like it's suffering, treat it as suffering.

(9) Also, I think a perfect whole-brain emulation running in silicon would retain full moral status, even without biological homeostasis, as long as the functional dynamics are preserved.

So do these actually cohere? It feels like (2) and (3) are in serious tension — I'm saying consciousness isn't computational but then giving a computational recipe for it in machines, and I'm not sure if I'm recieving different intuitions from different directions.
