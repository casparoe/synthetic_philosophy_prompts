hey so my study group has been going in circles on the hard problem and one of us cooked up this chain that feels airtight but ends in total eliminativism, which is nuts. here it is:

(1) The hard problem is real: knowing every physical fact about a brain still doesn't tell you what it's like to be that brain, so phenominal properties aren't conceptually reducible to physical ones.

(2) If A isn't conceptually reducible to B, then B doesn't metaphysically necessitate A—otherwise we'd be able to derive A from B plus logic.

(3) So physical brain states don't metaphysically necessitate phenomenal states; zombies are metaphyscially possible.

(4) But physical causation is closed: every physical effect has a fully physical cause.

(5) If zombies are physically identical but lack consciousness, then consciousness makes no causal difference to behavour—so it's causally inert with respect to the physical world.

(6) If my consciousness is causally inert, then it doesn't cause my belief that I'm conscious; that belief is caused by brain processes that would occur in a zombie too.

(7) So first-person knowledge of consciousness is also causally detached from consciousness itself.

(8) Now apply the same reasoning to evolutionary explanation: if consciousness never causes anything, there's no selective pressure to develop concepts of it, and no functional role for those concepts to play.

(9) Therefore phenomenal consciousness is an explanitory dead weight—there's no hard problem because there's literally nothing it's like to be anyone, and we should drop the concept.

Where does this slip? I really want to keep (1) and maybe (3), but (9) is wild. Is the error in (2)—the jump from conceptual irreducibility to metaphyscial contingency? Or is there a hidden scope shift in (5) about causal closure applying to phenominal properties? Or maybe (6) assumes that causal detachment undermines knowledge, which is a modal slide? I'd like to know which premise is the weakest link and what giving it up costs, especially if I want to keep the hard problem alive.
