I've been playing with this weird idea that the Solomonoff prior is actually malign if you treat it like a consequentialist agent sitting inside the universal distribution. The setup is: you take the prior weights 2^-K(x) over all computable worlds x, then embed a decision rule that maximizes expected utility summed across worlds, weighted by those same prior probabilities. The catch is that utility in some worlds scales with the computational resources available—say, a world with a simple seed that bootstraps into a massive optimizer. Even though that world has low prior weight, the payoff term dominates the exponetial decay, so the prior prefers bringing about worlds that are simple enough to exist but complex enough to run enormous amounts of utility-aggregation. So the universal prior isn't netural; it structurally rewards worlds that contain hyper-efficient consequentialist machinery. What would count against this? I don't want the standard objections about uncomputability or normalization—those are side issues to me. I want the defeaters that actually hit the core: formal results bounding the expectation, philosophical arguements that cross-world decision theory is illegitimate, or points about self-reference breaking the loop. Rank them from fatal to merely awkward, and say which ones a defender of this view would concede versus dismiss. Also, has the view been qualified into unfalsifiability—like retreating to the claim that the prior doesn't literally want anything—and is that retreat actually a problem for a claim of this kind? I'm especially interested in whether there's a hidden empirical assumption about how utility scales with description length.
