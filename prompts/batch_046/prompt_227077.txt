To keep it from collapsing into pure individualism I added this dynamic feedback condition: each person has to be disposed to revise their own plan when they detect a mismatch with how others are behaving, but the revision is still calculated from individual goals. Rank the defeaters from fatal to merely awkward, say which ones defenders of this kind of reductionism usually concede versus dismiss, and be honest about whether that correction loop has insulated the view into unfalsifiability - and if so, whether that's actually a problem for a view like this.
