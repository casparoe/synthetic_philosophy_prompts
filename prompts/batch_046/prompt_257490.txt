here's the student answer:
Popper argued science aims at truth but we can never verify we've reached it, so we need verisimilitude. He defined it via logical content: a theory's truth content is the true statements it entails, false content is the false ones. A false but bold theory can have more truth content than a true but trivial tautology, so it can be closer to the truth overall.

If we take David Lewis's modal realism seriously, worlds are concrete. Then verisimilitude stops being about logical sentences and becomes about world-distance: a false theory picks out a world thats structurally near ours—same causal laws, same kind of entities—just with one parameter flipped. This solves Popper's problem because we don't have to parse logical content anymore; we just check modal proximity. Popper rejected quantitative measures of verisimilitude mainly because he was an anti-realist about possible worlds, but on Lewis's view thats no obstacle.
