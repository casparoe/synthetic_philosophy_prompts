I've been thinking about whether DNA is actually a 'code' or just a convincing chemical analogy, and I built this argument that feels like it collapses both options into something absurd. (1) For something to be a code in the non-metaphorical sense, its symbol-to-meaning mapping has to be arbitary and require an interpreter. (2) The genetic code is arbitary—there's no chemical law forcing UUU to mean phenylalanine—so DNA needs an interpreter, i.e. the ribosome/tRNA machinery. (3) But that machinery is itself specified by DNA. (4) So if DNA is a real code, it needs it's own interpreter to exist before it can be read, which means the code has to be already interpreted in order to build the thing that interprets it. (5) That's not just bootstrapping; it's vicious circularity. (6) Therefore DNA can't literally be a code. (7) But if it's not a code, then 'genetic information' is just a metaphor, and a mutation is only a chemical change, not an error or misreading. (8) Still, we clearly talk about pathogenic mutations as errors—like the deltaF508 deletion being a mistake in the instructions for CFTR. (9) If mutations aren't errors, then medical genetics loses its normative framing. (10) So either we bite the circularity bullet, or we accept that medicine is conceptualy confused. (11) Both seem wrong. Where's the slip? I want to keep both that mutations can be genuine errors and that there's no vicious circularity in the origin of translation, but I can't see how to have both. Also please separate what's settled in biology and philosophy of science from what's genuinely contested, and don't present a contested take as the consensus view.
