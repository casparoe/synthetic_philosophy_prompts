I'm working through the foundations of welfare economics for a graduate seminar, and a study partner sketched a chain that seems to show revealed-preference theory makes every restriction of choice necessarily welfare-reducing. I can see that one link must be weak, but each step looks independently defensible, and I'm not sure where the break is least costly. Here is his argument, numbered so I can refer to the joints:

(1) Revealed-preference theory identifies an agent's preference ordering with the binary relation induced by actual choices: if the agent selects x when y is available in the same menu, then x is revealed-preferred to y.

(2) To use revealed preference for policy evaluation, we must extend it across situations. Call this the Cross-Situational Extension Principle: if x is revealed-preferred to y in choice set C, then in any choice set C' that also contains both x and y, x is revealed-preferred to y.

(3) Now consider self-binding. In C1 = {install blocker, do nothing}, the agent chooses to install software that removes option z from all future menus. By (1) and (2), in any menu containing "install blocker" and "do nothing," installation is revealed-preferred.

(4) Later, in C2 = {consume z, abstain}, the agent consumes z. By (1) and (2), in any menu containing z and abstaining, z is revealed-preferred to abstaining.

(5) The blocker creates C3 = {abstain only}, where z is unavailable. By (2), the agent's preference for z over abstaining still holds in C3; the option is simply absent, not rejected.

(6) Welfare economics defines being made better off as having one's preferences satisfied. Since the preference for z over abstaining remains unsatisfied in C3, the blocker makes the agent worse off, despite being voluntarily chosen in C1.

(7) Generalizing: any policy that restricts a choice set—taxes, bans, commitment devices—removes options that, by (2), the agent may still prefer over what remains. Hence every such restriction necessarily reduces welfare relative to the unrestricted case.

(8) This proves too much. It eliminates the conceptual space for self-binding that genuinely improves welfare, for "libertarian paternalism," and even for the idea that an agent can be better off with fewer options. So one of (1)-(6) must fail.

My partner insists the error is in (5): revealed preferences are only defined over available alternatives, so removing z from C3 eliminates the comparison altogether rather than leaving an unsatisfied preference hanging. I worry he is smuggling in a choice-set-relative ontology that undermines the very cross-situational stability (2) requires for policy evaluation. Which premise should actually be rejected, and what does giving it up cost—especially if we still want revealed preference to ground normative judgments about policies that deliberately change what is available?
