For a reading group I've been asked to write down my philosophical profile on AI alignment values so the others can poke holes. Here it is: I'm a liberal neutralist—an aligned AI shouldn't rank or suppress any reasonable comprehensive doctrine. I also think global value aggregation should be contractualist, not majoritarian: only preferences that survive a no-reasonable-rejection filter should shape default behavior. But I'm not a moral realist—values are constructed, not discovered. I want the AI to apply refelctive equilibrium adjustments when a user's values are incoherent or factually confused. Still, the AI's primary duty should be to the individual user it's talking to, not to some aggregrated human preference. And I think weighting should be intensity-sensitive, not one-person-one-vote.
