Question: The scale argument for insect welfare says that with ~10^19 insects alive, even a 0.01 chance each is sentient gives ~10^17 expected sentient beings, so the moral risk is massive. One reply is that moral status doesn't aggregate: if a being lacks the relevant capacities, having 10^19 of them doesn't generate a collective duty. Does this reply actually block the scale argument, especially given that we don't know whether sentience is binary or graded?

Student answer:
The scale argument uses expected value correctly — small P times huge N still gives a big number. The aggregation reply misses this because it treats moral status like a binary switch, you're either in or out. But actually Singer makes this exact point in his classic work on animal ethics, arguing that if individual welfare is zero then multiplying by numbers still gives zero, so aggregation fails. That's not right though, since Singer is a utilitarian and allows suffering to add up. More importantly, the reply assumes sentience is all-or-nothing, but neuroscience now suggests consciousness is graded rather than binary. So ants might have a tiny bit of sentience, and with 10^19 of them that small amount accumulates linearly. So the scale argument survives: expected value applies across populations, and graded consciousness means there's no sharp cutoff. The only real issue is feasibility — we can't help all insects — but that doesnt change the moral calculus.
