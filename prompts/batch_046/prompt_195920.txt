I've been working through a version of the Euthyphro dilemma applied to machine-learning alignment, and I've ended up with an argument that looks like it dissolves the very idea of a correct objective function. I can't tell whether it's genuinely destructive or whether I've smuggled in a false step. Here is the chain as I see it:

(1) For any trained model, call its behavior 'aligned' just in case it minimizes its specified loss function.
(2) If being aligned is defined solely by satisfying that loss function, then the loss function is normatively authoritative in the way the divine will is in one horn of the Euthyphro dilemma: what is correct is correct only because the function says so.
(3) But if we reject that horn and say instead that we choose the loss function because it tracks an independent standard of correct behavior, then we must already possess that independent standard.
(4) Any attempt to specify that independent standard in computable form just produces another loss function or evaluation metric.
(5) So either alignment is arbitrary relative to the choice of metric, or it depends on a standard that can never be fully formalized.
(6) The same structure seems to apply not only to AI but to any normative theory that tries to ground correctness in a formal criterion: either the criterion is authoritative by fiat, or it appeals to something outside itself that remains unformalized.
(7) Therefore, the project of specifying a uniquely correct objective for an intelligent system is either circular or incomplete.

My intuition is that something slips between (3) and (4) — perhaps an equivocation between 'having a standard' and 'encoding it formally' — but I can't name the error precisely. Which step should I reject, and what does rejecting it cost me? In particular, can I keep the idea that alignment requires an independent normative standard without falling into an infinite regress of metrics, or must I accept that all alignment is ultimately conventional?
