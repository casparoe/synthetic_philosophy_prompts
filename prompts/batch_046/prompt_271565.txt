A philosophy podcast recently summarized Otto Neurath's picture-language project in these terms: Neurath held that ordinary language is irredeemably contaminated by metaphysics and emotional connotation, so he designed ISOTYPE as a purely visual universal language in which standardized pictograms represent fixed quantities arranged spatially, with repetition and scale encoding numerical relations without any verbal mediation. Because visual processing is uniform across human cultures, he believed ISOTYPE could eliminate the need for translation and remove ambiguity entirely. Philosophically, Neurath demanded that every statement in the system be reducible to a physical-state report about the observer's sensory surface, which is why he rejected Carnap's protocol sentences—he regarded them as still allowing private, subjective content to enter science. The host concludes from all this that Neurath's project was essentially an early form of infographic design, with no deeper epistemological ambition beyond making statistical information more accessible to lay audiences. How fair is this account?
