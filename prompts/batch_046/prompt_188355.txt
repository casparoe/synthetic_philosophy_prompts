Write a villanelle—nineteen lines, five tercets and a closing quatrain, with the two refrains alternating through the ABA rhyme scheme—about program equilibrium in a one-shot prisoner's dilemma under bounded rationality. Make the two refrains the exact source-code descriptions of the two programs in equilibrium: one that cooperates by default with minimal complexity, and one that would defect only if it could run a costly identification subroutine on its opponent's code. Let the enforced repetition of the refrains mirror the iterative execution each program performs when evaluating the other, and allow only minor syntactic shifts in their repetitions—like a subroutine returning different outputs for the same input state—while keeping the core instructions unchanged. In the closing quatrain, bring the two refrains together for the first time not as a merger but as a deadlock: the cooperative program has executed the defector's identification routine, found it too long to compile within the complexity-cost bound, and halted. The turn should land exactly there, so the reader realizes cooperation is sustained not by preference or repetition but by an asymmetry in program length that makes defection computationally unaffordable. Do not moralize about cooperation being good; leave the equilibrium as an uneasy computational stalemate. The poem should be precise enough that someone familiar with bounded-rationality game theory recognizes the mechanism—strategies as executable programs, complexity penalties, mutual evaluation by running rather than by static analysis—without naming Rubinstein, citing page numbers, or relying on bibliographic knowledge a model without web access could not have. Keep the language technically concrete: mention compilation, subroutine calls, cost bounds, or execution traces if they serve the rhyme, but never drift into generic metaphor about "machines" or "code" that loses the specific economic logic.
