I'm grading problem sets for our upper-division rational choice seminar and need a second read on this response before I finalize marks. The exam question was: Consider the standard diachronic money-pump argument—if an agent's preferences over fixed options A, B, and C cycle (A ≻ B ≻ C ≻ A), an exploiter can extract arbitrary value through sequential trades. Critics reply that rational agents often revise preferences through learning, emotional development, or shifts in fundamental commitments. Assess whether such revisions genuinely block the argument. Then evaluate a proposed resolution called "fragmented coherence": the agent maintains local transitivity within each temporal stage but permits global intransitivity across stages, governed by a stable higher-order rule that licenses revision whenever an agent's authentic values have genuinely changed. Is this a real resolution, or does it relocate the incoherence?

Here is the student answer:

A money pump requires stable preferences across transactions: the agent pays small fees to move A→B, B→C, and C→A, ending worse off with A minus fees. If she revises preferences between trades—say, she learns that C is actually superior—then the cycle breaks and she will not pay to return to A. So rational revision does block the pump, but only when the revision is epistemic (updating beliefs about outcomes) rather than axiological (changing what one values). Axiological shifts change the subject: the later agent is evaluating different options relative to her standpoint, so there is no strict cycle.

The "fragmented coherence" strategy accepts local consistency at each stage but denies global consistency. Its higher-order rule is a meta-preference for authenticity: the agent permits her future self to overturn past rankings if they no longer reflect her true values. This meta-rule is itself stable and not open to revision. Because the conditions triggering revision depend on internal phenomenological shifts rather than on observable features of the options, an external exploiter cannot predict when rankings will switch. Hence no pump can be constructed.

This strategy should be preferred to the "resolute" approach, which requires the agent to bind her future choices to her current ranking and to treat anticipated preference change as a kind of error. That treats temporal parts of the agent as irrational outsiders rather than as legitimate successors. Fragmented coherence respects autonomy across time while avoiding exploitation.

That said, the strategy does relocate some tension. The meta-rule for authenticity must either be rigid—making it vulnerable to a meta-level pump—or permissive enough to allow arbitrary shifts, in which case it is not a genuine constraint. So diachronic coherence is too strong as a global requirement, but rationality still demands local consistency plus a stable, non-arbitrary meta-rule governing revision.
