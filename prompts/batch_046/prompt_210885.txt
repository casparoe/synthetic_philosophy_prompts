The obstacle comes from Gödel's second incompleteness theorem: if a formal system S is consistent and includes enough arithmetic, S cant derive its own consistency statement, Con(S). A self-trusting agent assigns belief to every theorem it derives. So if it derived Con(S) itd have derived something false, since S cant derive it unless its inconsistent. Thus a consistent self-trusting agent must withhold belief from Con(S). The deeper problem is that if the agent also trusts its meta-reasoning about its own reliability, it can derive that it ought to believe Con(S), producing contradiction. This framing was first developed by Gödel in 1931, though he didnt discuss AI specifically. For probabilistic agents the obstacle disappears entirely because Bayes rule doesnt generate formal theorems; you can just assign a prior to consistency and update without contradiction. So purely logical self-improvers are blocked, but bounded probabilistic ones are safe. Penrose later used a related argument to claim human minds arent algorithms.
