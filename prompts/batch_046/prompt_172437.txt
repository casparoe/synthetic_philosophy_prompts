I'm preparing a conceptual framework for a graduate seminar on practical epistemology, and I've become dissatisfied with the standard framing of the knowing-how versus knowing-that debate as a simple binary between Rylean anti-intellectualism and the propositionalist revival. Rather than asking which side "wins," I want to specify what an adequate theory of knowing-how must actually deliver if it is to avoid both the regress problem and the reduction of skill to mere behavioral disposition.

Please write the list of desiderata that a theory distinguishing knowing-how from knowing-that ought to satisfy, with the specific consideration motivating each one, and indicate which you take to be non-negotiable versus which reflect the commitments of particular camps — for instance, full articulability, non-propositionality, universal cognitive accessibility, consistency with procedural-memory research, and preservation of the "guidance" intuition that skill directs action in norm-responsive ways rather than causally. In particular, include a requirement about how the theory must handle what I will call "second-order practical opacity": cases in which an expert genuinely knows how to execute a complex practice, recognizes this expertise in themselves, yet structurally lacks access to the normative principles that actually govern their correct performance, where this opacity is not a temporary retrieval failure but a constitutive feature of that knowledge form. If any subset of these desiderata is jointly unsatisfiable given well-established constraints — say, the combination of universal propositional accessibility, non-circular explanation of skill acquisition, and the denial of an explicit representational substrate — say so explicitly and identify which requirement does the most damage to which camp.

If this framing rests on a confused premise — for example, if "second-order practical opacity" is incoherent as defined, or if the task implicitly demands empirical results that cannot be evaluated without access to specific literature — please say so plainly rather than accommodating the confusion politely. I am not asking for a bibliography, citation list, or named roster of contemporary authors; I want the conceptual architecture evaluated on its own terms. Present the criteria with qualified confidence where appropriate, flagging which distinctions depend on contested interpretations of cognitive architecture rather than on conceptual necessity alone, and invite direct pushback on any part of the setup that cannot be done well as posed.
