Been workshoping a paper on collective memory and now my own argument tied itself in knots. Maybe you can see the exit.

(1) A national myth is only morally permissible if it doesn't depend on false causal claims about the past.
(2) The Confederate Lost Cause, Masada, Kosovo Polje, and Dunkirk all function as myths precisely because they make false or untestable causal claims -- that the Confederacy was about states rights not slavery, that Masada was free choice not a forced hand, that Kosovo's defeat was spiritually victorious, that Dunkirk was won not escaped.
(3) So by (1) all four are impermissible.
(4) But that's absurd: Dunkirk and Masada seem clearly okay, maybe even good, while the Lost Cause is toxic.
(5) So (1) must go, and accuracy of causal claims isn't the right line.
(6) But if we drop (1), then the Lost Cause is no worse than Dunkirk on this axis -- both tell false causal stories for group cohsion.
(7) So either we condemn all four, or we allow all four, and there's no middle ground.

I want to save the intuition that Dunkirk is fine and the Confederacy isn't, without just saying 'well, one cause was just.' Which step do you reject, and what does giving it up actually cost me? I'd rather keep (1) if I can, but I don't want to bite the bullet on Dunkirk.
