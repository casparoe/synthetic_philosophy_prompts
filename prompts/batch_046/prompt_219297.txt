I've been thinking about Carroll's dialogue between Achilles and the Tortoise, and I tried to extend its logic to a practical problem my team faces. We are building an automated proof-checker for smart contracts that relies on modus ponens and universal instantiation. Our safety reviewer insists that before we deploy it, we must justify these inference rules independently of the system itself. I constructed the following argument, and now I worry it proves too much—either that all computation is irrational or that any system can certify itself. (1) Any inference rule used by a system must be justified if the system's outputs are to be trusted. (2) If the justification is carried out by the system itself, it is circular: the system applies the very rules it seeks to justify, which is precisely the regress Carroll describes. (3) If the justification is carried out by a separate meta-system, then that meta-system's own rules require justification in turn, producing an infinite regress with no ground. (4) Therefore, either we accept circular self-certification, accept an endless regress with no foundation, or deny that inference rules need justification at all. (5) But circular self-certification is worthless, since a buggy checker could embed false rules and justify them with themselves; we have seen analogous risks when a model validates its own flawed reasoning chain. (6) An infinite regress offers no practical foundation for deployment. (7) So we must reject (1) and conclude that a proof-checker needs no external justification for its logical rules. (8) Yet if (7) is true, then rational justification is impossible not only for machines but for human deduction as well, because human reasoning faces the same Carroll regress. (9) That conclusion feels absurd: it implies we should abandon the distinction between sound and unsound reasoning altogether. Where exactly does this chain slip? If I must preserve the idea that circular self-certification is dangerous—step (5)—and also preserve the intuition that human reasoning is not groundless, which earlier premise should I give up, and what does giving it up cost me?
