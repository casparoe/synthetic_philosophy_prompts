A colleague sketched this argument linking Solomonoff induction to Occam's razor and I think it overreaches, but I can't pinpoint where. (1) Solomonoff induction assigns prior probabilities proportional to 2^{-K(h)}, with K(h) the Kolmogorov complexity of hypothesis h on a fixed universal prefix machine U. (2) Given observed data D, the posterior ranks hypotheses by P(h)·P(D|h), so among equally predictive hypotheses the one with smallest K(h) wins. (3) This formalizes Occam's razor: rational belief should prefer simpler explanations. (4) Let h_phys be "uniform physical laws govern sunrise" with K ≈ 10,000 bits, and h_angel be "an invisible agent executes a 500-line Python script to push the sun each dawn, but only when unobserved" with K ≈ 12,000 bits on U. (5) Thus Solomonoff induction gives h_phys about four times the prior weight of h_angel. (6) Kolmogorov complexity is invariant across universal machines only up to an additive constant c(U,V). (7) Now define V so that empty input outputs h_angel and all other inputs simulate U. Then K_V(h_angel) ≈ 50 bits, while K_V(h_phys) remains ≈ 10,000 bits. (8) Because c(U,V) is fixed and non-negative, 50 + c < 10,000 + c, so on V the simplicity ordering is reversed. (9) Since the choice of reference machine is conventional, Solomonoff induction does not objectively privilege physical law; it merely bakes our preference for U into the mathematics. (10) Therefore Occam's razor, formalized this way, is a convention disguised as rational constraint, and there is no objective reason to reject equally predictive conspiracy theories—only to pick a different universal machine. (11) But scientific preference feels rationally compelled, not conventional. (12) So Solomonoff induction fails to justify Occam's razor, and we should reject it as a normative account of rational belief.

Which step fails—particularly between (6) and (9)—and what does fixing it cost?
