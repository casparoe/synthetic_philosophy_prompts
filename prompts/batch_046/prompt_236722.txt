Frankfurt-style counterexamples to the principle of alternative possibilities (PAP) usually run as follows: an agent voluntarily performs an action, an unactivated intervener stands ready to compel that very action should the agent display any reluctance, and since the agent proceeds without reluctance, no intervention occurs. The agent therefore seems to lack any ability to do otherwise, yet remains fully responsible. The standard reply—often called the flicker-of-freedom defense—observes that there is typically some minute prior event, such as an unconscious neural precursor or a fleeting hesitation, that would have triggered the intervener, so that a tiny modal residue of an alternative still exists. I want to refine this reply by distinguishing three conceptually different kinds of modal residue that might survive in such a case. First, a robust voluntary alternative, in which the agent could have exercised a different choice through their own deliberative capacities. Second, a sub-personal causal branch-point, in which some physical event (for example, a brief neural flicker) differs across possible worlds, but this event is neither voluntary nor accessible to the agent's reasoning. Third, a counterfactually inert pathway, in which even if the intervener were absent, the agent's own psychological dynamics would not have generated the alternative outcome—the branch is physically possible but psychologically dead. Explain the conceptual differences among these three categories, particularly how the second and third differ despite both being non-voluntary. Then address this question: if the only residual alternatives in a Frankfurt case belong to the second or third category, does PAP survive in a defensible weakened form, or is the principle best understood as demanding only the first kind of alternative? More specifically, does the Frankfurt counterexample succeed only by conflating causal openness at the sub-personal physical level with the presence of live voluntary options, and what is conceptually at stake in keeping them apart?
