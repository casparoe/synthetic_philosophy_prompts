Question 4: Distinguish the Dutch-book argument from the money-pump argument as coherence-based justifications for expected utility maximization. Your answer should address: (i) which specific axioms or rationality conditions each argument targets; (ii) whether each requires a single-stage choice setting or a sequential/multi-round setting to generate the vulnerability; (iii) the precise normative conclusion that can be drawn—distinguishing the claim that coherence requires EU maximization from the claim that non-EU agents will systematically suffer resource loss; and (iv) the relationship of these arguments to the representation theorems of von Neumann-Morgenstern (1944) and Savage (1954), including whether those theorems themselves function as coherence arguments.

Student answer:

Both arguments show that violating expected utility theory makes you lose money, so rationality requires EU maximization. The Dutch-book argument, which comes from Ramsey and de Finetti, targets violations of the independence axiom: a bookie can set up bets on compound lotteries so that you accept each bet individually but suffer a sure loss collectively. The money-pump argument, developed in Savage's 1954 representation theorem, targets intransitive preferences: if you prefer A to B, B to C, and C to A, an opponent can trade you through the cycle and extract arbitrary money. So Dutch books apply to independence failures, money pumps to intransitivity, and both need sequential rounds because you have to make choices over time. The von Neumann-Morgenstern theorem formalizes the Dutch-book idea using continuity and independence axioms, while Savage formalizes the money-pump idea by assuming state-independent preferences that rule out cycles. Because both theorems derive utility representations from consistency conditions, coherence arguments and representation theorems are really the same justification—informal exploitation stories versus formal axiomatic proofs—that rational agents must maximize expected utility.
