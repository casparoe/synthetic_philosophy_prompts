Please construct the tree so that each internal node poses one of these commitments as a yes-or-no question that a student could answer without knowing which historiographical school it points toward. Also flag any empty branches in the logical space—combinations that yield no named view—indicating whether they seem conceptually incoherent, philosophically unattractive, or merely unexplored.
