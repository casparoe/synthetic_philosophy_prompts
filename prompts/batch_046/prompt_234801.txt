I've been working with this idea that Foucault's whole power/knowledge/discpline thing needs updating for predictive systems — not just that algorithms surveil, but that they've moved past the panopticon into what I'd call pre-discipline: the norm isn't enforced after deviation, it's baked into the prediction model so deviation never gets to exist. So resistance isn't co-opted; it's structurally impossible because there's no visible norm to transgress against, just a smooth gradient of optimized behavior. I think this keeps Foucault's core claim — that power is productive, not repressive — but makes the resistance part basically dead.

What'd count against this? I want the real defeaters, not just appeals to Foucault said X in 1975. Like, what empirical patterns in actual algorithimic governance would show people still transgress visible norms? Or that predictive systems still rely on retrospective normalization? Or philosophical objections — maybe I'm smuggling in a determinism Foucault's own analytics reject? Rank them: fatal vs just awkward. And be honest — has this view been qualified so hard (e.g., pre-discipline only applies to high-infrastructure contexts) that it's unfalsifiable? If so, is that a problem for a view that's supposed to describe how power actually works?
