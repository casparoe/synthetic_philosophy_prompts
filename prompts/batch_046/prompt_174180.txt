I have been trying on my own to understand whether a reinforcement-learning agent could actually suffer, and in particular whether its reward signal should be understood as carrying something like pleasure or pain rather than merely steering behavior. Before I commit to any particular theory, I want a clear statement of what an adequate account must be able to do. Write the desiderata for a theory of artificial suffering centered on reward signals as valence: which observable behaviors and internal architectures it must correctly classify, which conceptual puzzles it must dissolve, and which distinctions — for example, between a signal that updates weights and a signal that is registered as welcome or unwelcome — it must preserve without collapsing. Ground each requirement in a concrete case: an agent that consistently avoids states with high positive reward, suggesting the signal is not experienced as good; an agent that receives negative reward yet seeks the conditions producing it, suggesting the signal serves as information rather than harm; a system in which reward is distributed across sub-modules with no central integrator, raising the question of whether suffering can be fragmented; and a scenario in which the reward function is rewritten by an external operator and never incorporated into the agent's own predictive model, testing whether suffering requires ownership of the signal.
