I've been working through a seminar argument about the reference class problem that ends up dissolving all singular judgment, and I can't locate the fault line. (1) To rationally predict an outcome for a particular individual, one must assign that individual to a reference class and apply the class frequency. (2) Any individual belongs to infinitely many reference classes—defined by genotype, phenotype, age, behavior, social network position, and arbitrary Boolean combinations thereof—many yielding incompatible probabilities for the same outcome. (3) There is no non-circular criterion for selecting the correct class: any rule appeals to prior beliefs about which properties are causally relevant, but those prior beliefs are themselves singular judgments that require reference classes. (4) So rational belief about any particular case is necessarily indeterminate among contradictory probabilities. (5) If singular belief is always indeterminate, then practical reasoning—medical prognosis, legal judgment, personal planning—lacks rational foundation altogether. (6) Therefore the reference class problem is not a tractable puzzle but a reductio of the very idea of rational singular judgment. Which step should I reject, and what does giving it up commit me to—does it force me into pure subjectivism, hierarchical Bayesian weighting, or abandoning frequency-based reasoning for particular cases?
