student answer:
Artificial neural networks do have representations, but only in a derived sense. Realists argue that internal features carry semantic content because they stand in causal-functional relationships to inputs. In mechanistic interpretability, we can intervene on a feature — say, a direction in activation space — and observe predictable changes in output. This shows the feature plays a causal-functional role, which is enough for representation. Anti-realists counter that this is just correlation dressed up; the network doesn't have original intentionality, only weights that minimise loss.

There's a well-known problem with polysemantic neurons: one feature responds to multiple unrelated inputs, so representational content isn't one-to-one. But if we map the high-dimensional manifold properly, each point corresponds to a specific state of affairs in the input distribution. Therefore mechanistic interpretability proves that networks represent the world literally, not metaphorically, provided we accept that representation doesn't require consciousness or biological origin. The derivation problem is solved because the designer fixes the reference by setting the loss function, so the content is fixed externally. The anti-realist is wrong to demand original intentionality; derived intentionality is still intentionality. So yes, they represent, but derivatively.
