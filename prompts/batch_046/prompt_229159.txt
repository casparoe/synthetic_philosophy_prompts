I've been thinking about sphexishness — Hofstadter's example of the wasp Sphex ichneumoneus dragging it's prey to the burrow, checking inside, then dragging it out again if you move it, stuck in the same loop. The philosophical takeaway usually seems to be that humans aren't sphexish: we can break routines, improvise, adapt to weird inputs. But here's where I'm stuck. If hard determinism is right, then every 'flexible' human choice is just the deterministic output of a more complex neural architecture — basically sphexishness with more variables and branching conditions. So it feels like the anti-sphexishness argument for free will secretly assumes compatibilism: it treats rigidity as being stuck in a loop regardless of input, but determinism allows loops that branch based on input. So what actual metaphysical work is 'not being sphexish' doing? Or am I just mixing up behavioral adaptibility with libertarian agency?
