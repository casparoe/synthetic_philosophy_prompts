I've been playing with this idea about where meaning actually lives, borrowing the frame/outer/inner message distinction from GEB but pushing it in a direction that feels off-road. The position is this: in any representational system — formal, linguistic, whatever — the inner message (the raw symbol sequence) carries literally zero semantic weight on its own. The frame message tells you how to parse it's symbols, the outer message tells you what world-state it's supposed to map onto, and then there's this layer I'm calling the echo message — the way the outer world talks back into the frame and slowly warps it. So meaning isn't just distributed across three layers; it's unstable because the echo message is always corrupting the frame. I think this explains why people can argue forever about what a proof really means without anyone being wrong, but I'm also aware it sounds like I'm just renaming ambiguity and calling it deep. So what would actually count against this? Not the standard symbols-are-meaningless-without-interpretation line — I'm conceding that already. I want the hard stuff: which formal results about interpretation stability, which cases from language acquisition or logic, which intuitions about whether meaning can genuinely drift without anyone noticing? Rank the defeaters from fatal (the view collapses into standard ambiguity) to merely awkward (I have to add an ugly qualification). Which ones would a defender of the echo-message view concede, and which can they dismiss as missing the point? I'd especially like to know if there's a result in model theory or semantics that shows frames can't be corrupted this way, or if that's just a fantasy I made up.
