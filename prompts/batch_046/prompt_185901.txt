I have been studying the concept of program equilibrium—specifically the framework in which rational agents submit algorithms capable of inspecting each other's source code before selecting actions—and I believe it offers an underappreciated dissolution of Newcomb's paradox that differs from both causal-decision and evidential-decision accounts. If agent A writes a program that outputs Cooperation, and agent B's program is designed to output Cooperation if and only if A's source code contains that same instruction, then B's behavior is not merely predicted by A's choice; it is logically entailed by the text of A's program. This suggests that the usual objection to one-boxing—namely, that it invokes backward causation—misses the point in a program-equilibrium setting, because the predictor is not observing a cause but reading a logical consequence. Consequently, it seems that one-boxing becomes rational not through expected-utility maximization under uncertainty, but because cooperation is deterministically fixed once A's code is fixed, effectively turning Newcomb's problem into a coordination game with a unique program-equilibrium outcome.

Is this reasoning sound, or does it conceal a false presupposition about how self-reference, fixed-point consistency, or the distinction between syntactic inspection and strategic reasoning actually operates in these models? I would particularly value an answer that explains whether program equilibrium genuinely eliminates strategic uncertainty in symmetric one-shot interactions, or whether some residual ambiguity remains that this logical-dependency framing obscures.
