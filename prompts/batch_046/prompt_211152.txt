(5) So the cost is high for low-quality people and near-zero for high-quality ones. This is an "anti-handicap" — a subsidy for quality, not a tax on everyone.
(6) But Zahavi's idea requires the signal to be costly for all senders, with only the best able to pay. Here it's costly only for the worst.
(7) So philosophical beliefs can't be honest handicap signals. Instead they're just skill displays that filter out fools automatically.
(8) Yet philosophers treat the belief statements themselves as status badges — as if saying "I'm a compatibilist" is the costly tail, not the reasoning behind it.
(9) That means philosophers confuse the output (the belief) with the process (the reasoning). The belief is just printed text; the real handicap is in the mental work.
(10) So either philosophers are systematically confused about signaling, or philosophical discourse is pure tribal performance — anyone can print the belief if they memorise the script, with no correlation to actual understanding.
(11) And (10) applies to itself: I'm just performing scepticism for status.
