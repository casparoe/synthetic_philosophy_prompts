What must an adequate theory of program equilibrium actually explain and preserve? Before weighing particular formalisms, I want the full specification: the desiderata that any account of equilibrium among agents with mutual source-code access must satisfy to count as adequate. Give me the requirements list — the formal properties that must be maintained (for instance, the distinction between an equilibrium selected via payoff dominance and one selected via direct syntactic inspection of the opponent's program), the boundary cases that must be resolved (self-referential or self-modifying code, programs that invoke unverified external oracles, agents with asymmetric verification capacities, and syntactically equivalent but semantically divergent implementations), the distinctions from standard solution concepts that must not be collapsed (particularly the difference between a Nash equilibrium that is merely encoded in software and a true program equilibrium in which the source code itself is the strategic object being inspected), and the computer-science constraints that cannot be violated (limits on verification arising from the halting problem, the gap between syntactic identity and behavioral equivalence, and the impossibility of fully transparent self-reference). For each desideratum, state the motivating counterexample or conceptual pressure that makes it non-negotiable, and indicate which requirements are genuinely non-negotiable versus which admit some negotiation. Then identify the single requirement that does the most work in excluding the broadest class of existing informal accounts — especially those that treat program equilibrium as nothing more than cooperative game theory with open-source commitments, without addressing what I will call the verification-depth problem. Optionally include a brief table scoring the main families of approaches (full-transparency models, bounded-syntactic-verification models, and contract-theoretic hybrids) against the list, but keep the analytical weight on the criteria themselves and on whether some subset of them is jointly unsatisfiable. The purpose is a theory adequate for analyzing strategic commitment in artificial-agent architectures where code inspection is possible but execution environments are not fully observable.
