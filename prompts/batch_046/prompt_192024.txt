At a recent philosophy of biology reading group, two participants—Jordan and Alex—fell into a sustained disagreement about whether DNA is literally a code or merely described by a convenient metaphor. Jordan opened by arguing that genuine codes, such as Morse code or programming languages, depend on an arbitrary assignment of symbols to meanings mediated by an interpreter standing outside the physical mechanism; in DNA, by contrast, the link between a codon and an amino acid is implemented through direct chemical pairing, with tRNA anticodon recognition and ribosome binding serving as physical causation rather than interpretation, and with no external decoder that chooses the mapping. Alex replied that this confuses implementation with semantics: the chemical pairing is only the vehicle, while the mapping itself is arbitrary, as shown by variant mitochondrial genetic codes in which UGA specifies tryptophan rather than serving as a stop signal—evidence that the rule is conventionally fixed by evolutionary history rather than chemically necessitated.

Jordan countered that even variant codes do not establish true arbitrariness, because the ribosome never interprets a symbol; it physically binds according to shape complementarity, much as an enzyme binds its substrate. Without an agent or representational system capable of misrepresenting its input, Jordan claimed, we have only causal sequence, not semantic coding, and invoking code illicitly imports intentionality into molecular biology. Alex responded that this sets the bar for coding implausibly high—computer codes do not require conscious silicon interpreters either—and that the genetic system meets the relevant functional conditions: discrete combinatorial symbols, sequential readout, redundancy, and evolutionary conservation of the mapping, all of which depend on preserving an arbitrary rule that could have been otherwise.

In the final round, Jordan pressed that if arbitrary functional dependency is sufficient, then enzyme-substrate interactions and receptor-ligand pairings must also count as codes, since mutations that disrupt those shapes are typically lethal and the relationships are evolutionarily maintained; this, Jordan argued, dilutes code until it is redundant with functional causal mechanism. Alex maintained that this equivalence misses a critical distinction: genetic translation is digital and combinatorial, using a finite alphabet read in linear order with error-correction mechanisms such as degenerate codons and proofreading polymerases, whereas enzymatic recognition is analog and pairwise. Jordan concluded that without an account of misrepresentation or normative failure specific to the genetic case—beyond mere chemical malfunction—the code talk remains metaphorical, however structurally elegant. Please adjudicate the exchange move by move: rate Jordan's and Alex's arguments at each stage from clearly mistaken to clearly right, briefly justify each rating, and say who is more right overall and what, if anything, both are missing about the conditions for a system to be genuinely coded rather than merely causally ordered.
