Here is an argument built around Galen Strawson's Basic Argument that seems to collapse into self-undermining absurdity. (1) True moral responsibility requires being the ultimate cause of one's actions, for if every mental state is merely the result of prior causes outside one's control, then the agent is not the source of the action. (2) To be the ultimate cause of an action, one must be the ultimate cause of the beliefs and desires that generate it. (3) One can never be the ultimate cause of one's mental states: either they are determined by prior mental states for which one is not responsible, or they arise by chance, and chance is not a form of authorship. (4) So no one is ever truly morally responsible for any action or mental state. (5) But epistemic blame and praise—holding someone responsible for careless reasoning or for accepting a false philosophical view—presupposes that agents can be the appropriate targets of criticism for their beliefs. (6) Therefore if (4) holds, no one is ever truly responsible for holding false beliefs, including for accepting or rejecting the Basic Argument itself. (7) Yet Strawson offers the argument as a reason that rational agents ought to accept, which implicitly treats them as responsible for their doxastic commitments. (8) So the Basic Argument undermines the normative practice of rational persuasion on which its own presentation depends. (9) Hence either (4) is false and true responsibility is possible, or philosophy is an illusion with no authoritative claims on us. I want to keep (3) and (4) if possible, since they express the core insight, but I will abandon (5) if that is the least costly exit. Where does the argument actually fail?
