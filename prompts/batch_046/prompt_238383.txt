I want them to physically run into the difference between an epistemic bubble and an echo chamber — not hear it defined up front. Both groups have to solve a puzzle that requires combining one fact only available outside and one only inside. Give me the exact rules for message passing, a payoff scheme tied to accuracy plus penalties for using "tainted" reasoning, and a debrief that maps their specific frustrations onto the structural features. Be honest about what an 80-minute format can't reproduce — probably the long-term reinforcement loop — and tell me what'll predictably break the first time I run it and how to fix it.
