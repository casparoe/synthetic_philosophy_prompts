I'm drafting a decision-tree taxonomy for a workshop paper in practical reason on indirect normativity—specifically, on how normative authority is mediated by idealized deliberation rather than applied directly to an agent's actual motivational state. I need the tree built from the logical space of answers, not from a catalog of named theories, so that it can function as a diagnostic instrument: someone should be able to locate their view by answering concrete structural questions without knowing the labels in advance.

Root the tree in the following split: Is the normative baseline for idealization the agent's actual present attitudes (values, ends, beliefs), or a counterfactual rationalized self whose values may diverge?

From there, apply these nested branches.

First, Scope of Idealization (applies to the actual-baseline branch): Does the correction address only epistemic limitations—false beliefs about means, ignorance of consequences, cognitive bias—while preserving all actual ends? Or does it also permit conative revision, allowing the idealized agent to discard ends that fail coherence or rational consistency tests? You should flag the node combining an actual-attitude baseline with full conative revision as unoccupied or unstable, with a one-sentence diagnosis (for instance, that revising ends breaks the fidelity condition that defines the branch).

Second, Indexical Preservation (applies to the counterfactual-rational branch): Does the idealized agent retain the original agent's first-personal indexicals, embodied particularity, and temporal location (I, now, here), or is it replaced by an impersonal generic rational standpoint?

Third, Normative Force (applies to every viable terminal path): Is the recommendation generated by the procedure authoritative—producing a binding reason capable of overriding present resistance—or merely advisory, carrying weight only insofar as the agent independently accepts the baseline?

Requirements for the deliverable:
- Present the taxonomy as a branching tree with each split labeled by the claim or case that divides it.
- Provide six to eight leaves. Each leaf should carry a position name (invented or standard—e.g., Epistemic Actualism, Indexed Authoritative Constructivism, Generic Advisory Rationalism) or be marked unnamed if the combination is unexplored.
- For each leaf, include exactly one sentence stating its most awkward commitment—the implication defenders typically minimize.
- Explicitly diagnose all empty nodes, especially the actual-baseline-plus-conative-revision combination: state whether the emptiness stems from incoherence, unattractiveness, or neglect.
- Incorporate the niche distinction of dispositional inertia: the stable, identity-constitutive disposition of an agent to reject the idealized recommendation. Show where this distinction applies across the tree—specifically, flag that on indexed authoritative views it generates a paradox of self-alienation, whereas on generic advisory views it tends to render the recommendation practically inert.
- The tree should implicitly treat a concrete test case in its structure: the committed agent who, after full rational reflection, would endorse a course of action that conflicts with their present identity-forming commitments. Use this case to illustrate how the indexical-preservation split operates.

Please do not include bibliographies, reading lists, author citations, or verbatim quotations from published texts. The audience is familiar with basic philosophy of action but should not need specialized literature to navigate the tree.
