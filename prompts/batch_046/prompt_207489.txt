Below is an exam question from a graduate logic-and-philosophy seminar, followed by a student’s written answer. The question introduces a distinction—call it “axiomatic failure” versus “domain failure”—to frame Russell’s paradox: axiomatic failure means the unrestricted comprehension schema is false but the totality of sets remains coherent, whereas domain failure means there is no stable domain over which “all sets” can be consistently quantified.

Question: (1) Apply this distinction to Russell’s paradox (R = {x | x ∉ x}). Does the paradox support axiomatic failure, domain failure, both, or neither? Explain precisely why. (2) Explain how the Zermelo-Fraenkel Axiom of Separation addresses the construction of R, and clarify whether this resolution eliminates self-reference (x ∈ x) or only blocks the specific comprehension step. Be precise about what standard ZFC does and does not permit here. (3) Distinguish Russell’s paradox from Cantor’s power-set argument. Does Cantor’s theorem by itself demonstrate that no universal set exists, or does that conclusion require an additional assumption? (4) Assess whether ZFC’s exclusion of a universal set depends on Cantor’s result, on the separation axiom, on both, or on neither.

Student answer:
Russell’s paradox is generated by unrestricted comprehension: for any condition φ there is a set {x | φ(x)}. Applying this to φ(x) ≡ x ∉ x yields R = {x | x ∉ x}. The contradiction—R ∈ R iff R ∉ R—shows that unrestricted comprehension is false. I read this as axiomatic failure: the principle was wrong, but the universe of sets is still a well-defined totality. Domain failure is the stronger claim that quantification over “all sets” is incoherent; Russell’s argument does not establish that, since it only derives a contradiction from one specific construction.

In ZFC, the Axiom of Separation restricts comprehension to subsets of an already-given set A: {x ∈ A | φ(x)}. This blocks R because there is no prior set A containing all sets. Notably, separation does not prohibit self-membership; ZFC permits x ∈ x unless one adds the Axiom of Foundation separately. Thus the resolution is purely axiomatic—separation removes the faulty rule—while leaving open whether domain failure is present.

Cantor’s power-set theorem states |P(S)| > |S| for any set S. Applying this to a hypothetical universal set U gives |P(U)| > |U|, contradicting P(U) ⊆ U. Hence Cantor’s result demonstrates that no universal set can exist. This is essentially the same difficulty as Russell’s paradox: both show that the collection of all sets cannot form a set, one through membership, the other through cardinality.

Consequently, ZFC addresses Russell’s problem by substituting separation for comprehension and implicitly relies on Cantor’s result to exclude a universal set, but neither move settles whether domain failure also holds.
