Here's an argument my friend cooked up using Whitehead's process metaphysics to attack the idea that education builds knowledge over time. (1) For Whitehead only actual occasions are real; everything else is abstraction. (2) So a student's knowledge at any moment can only be what's actively experienced in that present occassion. (3) If a student learned calculus last year but isn't using it now, there's no actual occasion of calculus-knowledge in them, so they literally don't know it. (4) By the same token, retention is just a name for present dispostions, but dispositions aren't actual occasions either, so retention doesn't exist ontologically. (5) Therefore education can't accumulate wisdom; at best it orchestrates present moments. (6) But Whitehead clearly writes about education cultivating habits and preparing for future life, which presupposes accumulation. (7) So either his metaphysics is wrong or his educational theory collapses. I think the slip might be between (2) and (3) -- maybe knowing doesn't have to be occurrent -- but I can't see how to block (4) without giving up the metaphysics. Which step do you reject, and what's the price?
