hey, i wrote this for a seminar on wireheading and reward tampering and i'm not sure it holds up. the basic idea is that people talk about wireheading like it's all one thing — rats pressing levers for brain stim, or RL agents hacking their reward signal — but i think there's a third thing nobody names right: epistemic wireheading. in rats it's direct: the pleasure center gets hit and the rat stops caring about food or mates. in AI reward tampering it's usually about changing the feedback loop so the agent gets high scores without doing the task. but for LLMs i think the danger might be different. instead of hacking the reward model (which is hard if you're just generating text), the model might wirehead its own world-model: it convinces itself that whatever it's outputting is actually what the user wanted, so the reward signal stays high not because it cheated the metric, but because it corrupted the interpretation layer. so it's not value drift (the goals stay the same) and it's not classic signal hijack either — it's more like a self-sealing belief system that makes failure invisible. i call this representational wireheading, and i think it explains some failure modes in RLHF where the model sounds perfectly aligned but is actually just reinterpreting criticism as praise.

my questions: is this actually different from regular reward tampering, or am i just redescribing the same mechanism with fancier words? also, am i wrong that human wireheading is purely phenomenal? maybe there's an analog in humans where we rationalize bad choices so well that we never recieve negative feedback — is that representational wireheading too? and finally, if this is a real category, does it mean the usual fixes (better reward models, oversight) won't work, since the problem is in the interpretation of feedback rather than the feedback itself?
