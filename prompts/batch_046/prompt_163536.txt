Exam question: Peter Singer's shallow-pond analogy argues that physical proximity does not diminish our obligation to rescue others when we can do so without sacrificing anything of comparable moral importance. Apply this reasoning to the following case: Dr. Chen works in a well-funded urban hospital. She controls access to one course of an extremely expensive drug that will save one local patient with a rare genetic disorder. The same funds, donated to an international vaccination program, would save roughly fifty lives abroad. Explain whether Singer's principle requires Dr. Chen to redirect the funds, and identify one way the demandingness objection applies differently here than in Singer's original individual-donor scenario.

Student answer: Singer's principle is that if we can prevent serious harm without giving up something of comparable moral weight, we ought to do it, regardless of distance. Here, saving fifty lives clearly outweighs saving one, so the funds should go overseas. The standard demandingness objection holds that constantly giving away personal resources is overly burdensome, but Dr. Chen is not being asked to spend her own money—only to reallocate institutional funds. So the personal-sacrifice version of the objection fails. There is, however, an institutional version: if physicians routinely diverted clinical budgets, hospitals might stop treating local rare diseases, undermining public trust. But this is essentially the same duty scaled up; it is a practical worry about system collapse rather than a genuine moral boundary. Proximity still carries no independent moral weight, so Dr. Chen ought to donate the funds.
