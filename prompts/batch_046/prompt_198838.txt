In work on forecasting—particularly the “outside view” that predicts the trajectory of large political entities by placing them in reference classes and using base rates—I keep encountering the line that “history doesn’t repeat itself, but it rhymes.” The person using it usually means that demanding an exact historical twin for, say, an empire’s decline is foolish because the causal details never align precisely, yet broad structural analogies across epochs remain legitimate and predictive. I want to know exactly what that claim could amount to. Can you separate the precise theses hiding in that one sentence—distinguishing, for instance, claims about causal mechanism identity, statistical exchangeability, structural isomorphism without token repetition, and the epistemic status of loose analogies—and for each indicate whether it is a platitude, whether it is defensible, and whether it actually licenses relaxing the specificity of one’s reference class? Please say which reading, if any, genuinely supports using a broad historical base rate rather than a narrowly defined reference class, and which readings collapse into empty metaphor.
