Here is an argument about reflexive epistemic calibration that my study group built; it seems valid but its conclusion—that rational agency is impossible—is clearly false. (1) A rational agent ought to calibrate its first-order credences in a domain to its second-order judgments about its own reasoning reliability there. (2) Formally, if the agent assigns high credence to the reflection principle that "if I come to believe p then p is true" across a domain D, rationality requires it to increase its credence in each p in D proportionally. (3) Now apply this calibration reflexively: the agent ought also to calibrate its confidence in (2) itself using the exact same rule, generating an iterative reflective loop. (4) By a fixed-point argument structurally identical to the Löbian obstacle for modal self-trust, this loop either drives every credence in D to 1—complete dogmatism—or yields an explicit contradiction if any initial credence is less than maximal. (5) Hence a globally self-trusting rational agent is doxastically unstable and therefore impossible. (6) One might restrict calibration to local, non-reflexive domains, but any local module can be embedded in a reflective closure that reproduces the same loop, so the restriction collapses. (7) It follows that rational agents must never learn from their own track record or correct for bias, which is absurd. (8) Therefore rational agency itself is impossible. I want to keep (1) and deny (8), but I need to know which intermediate step contains the hidden slide—whether it is an equivocation between probabilistic updating and modal reflection, a scope error in applying the loop globally, or something else—and what rejecting that step costs for a theory of epistemic autonomy.
