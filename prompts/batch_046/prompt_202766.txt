ok so i've been getting really into this idea called tranquilism that my friend in philosphy club brought up. basically it says the only thing that actually matters morally is the absence of craving and suffering - like, joy and knowledge and friendship are all just neutral, they don't add moral value at all, only the lack of pain and wanting stuff does. i think i'm pretty convinced but i want to stress-test it, especially since it seems like it predicts weird things that negative utilitarianism or buddhist ethics don't really predict.

what would actually have to be true for tranquilism to be wrong? i don't just want the standard happiness-is-good-too response. i want the real defeaters ranked from fatal to just awkward. for instance, if we discovered that some brains in deep anhedonic states - where there's no felt suffering but also hidden computational drives that don't reach consciousness - still count as having craving in some functional sense, would that break tranquilism or just make it refine its definition? and what about the case where someone is permanently in a blissful coma with zero phenomenolgy: tranquilism says that's the moral ideal, but is there an intuition about wasted potential that a tranquilist should actually concede is a problem, or is that just confusion?

also there's this weird overlap with affective neuroscience about motivational salience without negative valence - like your brain can still be computing goals without you feeling bad about them. if tranquilism only cares about felt craving, it might miss these subpersonal drives. does that expose the view, or can it absorb that by saying only conscious craving counts? and has the view been qualified into unfalsifiability - like if any counterexample gets redefined as secret craving - and if so, is that a problem for a moral theory? please tell me which of these the defenders themselves would admit count against them versus which they'd dismiss, and be honest about whether tranquilism is well-insulated to the point where that's actually bad.
