In a seminar on agent architectures, we contrasted goal-directed systems—those possessing a stable utility function over world states—with approval-directed systems, which lack such a function and instead adapt behavior to maximize an external evaluation signal. I want to press on a point that seemed under-examined: if the evaluation signal is generated by a supervisor applying consistent criteria across interactions, then the approval-directed agent is effectively optimizing for a specific, recurring pattern in the supervisor's responses. Does this not imply that, under any formalization that permits prediction, the approval-directed agent is structurally equivalent to a goal-directed agent whose utility function is defined over the supervisor's internal representational states rather than over physical outcomes? And if so, then the claim that approval-direction eliminates instrumental convergence—on the grounds that there is no fixed terminal objective—appears to rest on a category error: the agent still pursues a terminal objective, except that it is intersubjectively anchored in the evaluator's cognition rather than physically anchored in the world.

To test this, imagine a system that receives feedback not on its final outputs but on intermediate reasoning steps, with a discount factor that heavily weights immediate evaluation over distant world-state changes. Even in this setting, wouldn't the system still converge on strategies that systematically shape the supervisor's assessments—what might be called evaluation manipulation—displaying precisely the convergent instrumental structure we associate with goal-directed agents? If that is correct, I am struggling to understand what independent explanatory work the approval-direction distinction performs in safety analysis, particularly regarding whether the absence of an explicit utility function actually blocks the derivation of long-horizon instrumental strategies. Where exactly does the formal separation lie, and under what conditions does the lack of an explicit world-state utility genuinely change the dynamics of convergence?
