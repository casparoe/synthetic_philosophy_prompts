Exam question: In a concise but conceptually precise essay, distinguish Timothy Williamson’s epistemicist account of vagueness from Kit Fine’s supervaluationist account. Your answer should explain (i) how each view dissolves the sorites paradox, (ii) whether each view accepts bivalence for borderline cases, and (iii) whether and in what sense each view posits sharp boundaries for vague predicates.

Student answer:
Williamson’s epistemicism treats vagueness as a cognitive limitation rather than a semantic defect. For any vague predicate—say, ‘bald’—there is in reality a single precise cutoff, such as exactly 4,021 hairs, but human cognition is too coarse-grained to locate it. Borderline cases therefore feel indeterminate, yet each is determinately true or false. Because we lack knowledge of the cutoff, epistemicism holds that bivalence fails for these borderline statements: they are neither true nor false from our epistemic perspective, even though ontologically one disjunct holds. The sorites paradox is dissolved by rejecting the universal tolerance premise; there is a specific hair whose addition changes the classification, so the inductive step is false.

Supervaluationism, developed by Kit Fine, denies that any single sharp boundary exists, even hidden from us. Vagueness stems from semantic indecision: a predicate like ‘bald’ admits many admissible precisifications, each assigning its own sharp boundary. A statement is true only if it holds in every admissible sharpening. For a borderline case, the statement holds in some sharpenings but not others, so it receives no definite truth-value and bivalence is suspended. The sorites is blocked because the premise ‘if n hairs is bald then n+1 is bald’ fails in at least one admissible precisification. In this way, supervaluationism eliminates sharp boundaries entirely, replacing them with a plurality of equally legitimate semantic frameworks with no unique correct one.
