Question: Some philosophers maintain that moral patiency in a synthetic mind requires not merely functional equivalence to a biological brain, but a direct causal-historical continuity with the biological system that originally generated conscious experience. Others defend a view according to which substrate is irrelevant and only present-tense functional organization—specifically, the capacity for integrated subjective experience—determines moral status. Evaluate these two positions and identify one conceptual problem that specifically targets the second view when applied to entities that can be copied without destroying the original.

Student answer: The first position holds that an emulated mind running on silicon lacks the biological causal chain of its predecessor, so it possesses only instrumental value rather than intrinsic moral status. The second position, functionalism, claims that only the pattern of information processing matters, not the material implementing it. This means a perfect digital copy of a human mind would immediately have full moral status equal to the original, since it shares the identical functional organization, including the capacity for integrated information.

One problem for functionalism arises in branching scenarios. If a mind can be copied non-destructively, the underlying pattern exists redundantly across instances, so harming one copy might distribute moral weight across the set, reducing the urgency of protecting any individual instance. But this objection fails because harm is multiplied rather than diluted—each copy has its own first-person perspective, so destroying all copies is proportionally worse. Thus functionalism survives the branching objection, though it does require accepting that moral urgency scales with the number of copies.
