(1) The only reason we treat first-person reports about consciousness as authoratative is that we assume a direct, transparent access that doesn't need physical mediation.

(3) If an unexplained explainer is allowed for consciousness reports, then it's equally allowed for reports about any hidden mental state — say, unconsious biases or subliminal perceptions.

(5) But if we reject transparency everywhere, then the hard-problem intuition itself — which depends on comparing first-person access with third-person neural data — collapses, because we no longer have a privileged first-person side to compare.
(6) Therefore the meta-problem, taken seriously, dissolves the hard problem it was meant to explain.
