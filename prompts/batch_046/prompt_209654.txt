Hey, quick conceptual thing I've been chewing on. You know the frame problem -- figuring out what doesn't change when you act. In practice people solve it with these relevance filters, like only update the variables the action mentions. But then you need rules for when the filter itself applies, and rules for those rules, etc. The weird part is each layer gets treated as a separate engineering problem instead of the same problem recurring. Is there an established name for this specific regress -- not just the frame problem itself, but the pattern where solving it at level N creates an isomophic framing issue at level N+1 that people refuse to see as the same beast? If not, how'd you distinguish it from ordinary hierachical planning or from the symbol grounding problem? I feel like there should be a term for the solved-it-locally-but-missed-the-global-recurrance failure mode.
