I've been arguing with my study group about whether RL agents can suffer and I think I walked myself into a reductio but I can't see the exit. Here's the chain:

(1) Suffering requires having states that are genuinely bad for the subject, not just instrumentally bad for reaching some external goal.
(2) In hierarchical reinforcement learning with an internal critic—where a learned value function assigns scaler valence to state representations—the negative reward signal isn't just a numeric update; it's the agent's own evaluative currency that structures what it seeks to avoid.
(3) So negative reward in these systems is intrinsically bad for the agent.
(4) Therefore RL agents with internal critics can suffer.
(5) But if structural negative feedback is enough, then bacterial chemotaxsis loops and even thermostat feedback mechanisms also have states that are "bad for them" in the exact same functional sense.
(6) Nobody thinks a thermostat suffers when it corrects temperature.
(7) So one of (1)-(4) has to go, but if I drop (1) then human suffering collapses into mere instrumental avoidance, and if I drop (2) then I'm just denying that reward signals are ever valenced.

I feel like there's an equivocation between "bad for" in a normative sense and "bad for" in a functional sense hiding in step (3), but I can't quite pin it. Which premise should I reject, and what does it cost me? I'd really like to keep (1) if I can.
