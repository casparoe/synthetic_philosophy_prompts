I've been thinking about Fitch's paradox of knowability lately—specifically the version where if every truth is knowable then every truth is actually known, because you can build that nasty conjunction p and not-known-p. Most discussions I see treat it as a problem for omniscient human knowers, but I want to write a short essay arguing that the paradox actually collapses in a specific way for artificial agents with explicit confidence calibraton but no Cartesion transparency about their own knowledge states.

My rough idea is this: an LLM can assign a low confidence to some proposition p without thereby knowing that p is false, and more importantly it can't form the self-referential conjunction "p is true and I don't know p" inside its own derivtion tree because that requires representing its own epistemic state as an object-level proposition with the same logical access it has to world-facts. If the knowability principle only applies within an agent's closure conditions, and closure is bounded by the architecure (no infinite introspective ascent), then Fitch's proof never gets the second premise it needs. I'm not saying this solves the paradox for human minds—just that it shows the paradox is architecure-sensitive, not a universal logical bomb.
