I was working through some notes for an informal reading group on universal induction and embedded decision theory, and a fellow participant sketched an argument that seems to collapse consequentialism for any agent living inside the Solomonoff prior. I want to know where the argument breaks, because if it succeeds it proves far more than intended. Here are the steps as presented: (1) The universal prior M assigns a well-defined prior probability to every computable world-history, including histories that contain agents computing predictions with M itself. (2) Assuming a physicalist Church-Turing thesis, any real agent is a computable subprocess within exactly one such history, which means the agent’s entire decision algorithm, its inputs, and every action-output are already encoded in the specific world-string that carries its prior weight. (3) Consequentialism requires that an agent face genuinely open alternatives and select the one with the greatest expected utility; if the agent’s output is already fixed as part of the world-description, then within that world there is no causal opening for a different selection. (4) A possible response is that the agent compares utility across different world-strings and thereby “chooses” the best one, but this is not embedded agency—it is meta-selection among worlds, which an agent confined to a single history cannot perform. (5) Hence, for every embedded agent, consequentialist choice is impossible in principle. (6) Since we are presumably embedded agents, consequentialism does not apply to us. (7) Yet this seems to overreach: it threatens not only consequentialism but any normative framework that requires an agent to do otherwise than it in fact does. Which step is the weak point? Is the mistake an illicit move from computable describability to causal fixity, a confusion between quantifying over worlds and acting within one, or something else? Please identify the precise premise or inference to abandon, explain why it looked compelling, and then price the alternatives—what does an embedded consequentialist have to pay to reject it, and what does accepting the argument force us to say about rational agency more generally?
