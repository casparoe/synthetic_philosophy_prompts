My friend and I spent the evening arguing about whether a single self can be distributed across two brains. She accepts the view that personal identity is not bound to one body but to a continuing pattern of information, and she extends it in a direction that makes me uneasy: if two brains are linked by a continuous, bidirectional interface that synchronizes memory, affect, and reasoning in real time, then there is not one self in each skull but one self with two substrates. I tried to show this proves too much.

(1) If pattern identity alone is sufficient for selfhood, then any substrate that instantiates the same pattern belongs to the same self, regardless of causal history.
(2) A real-time bidirectional link can maintain exactly one unified pattern across both brains, analogous to how the corpus callosum integrates the hemispheres of a single brain.
(3) Therefore the linked pair should be one self distributed across two bodies.
(4) But if we copy that unified pattern into a third, causally disconnected brain—say, via a perfect scan—the copy instantiates the same pattern, so by (1) it too should be part of the same self, even though it never participated in the synchronization.
(5) Furthermore, if we gradually replace neurons in one brain with synthetic equivalents that preserve the pattern, the self survives; yet if we then sever the link and allow slight divergence, we appear to have one self become two without any identifiable moment of division.
(6) So the view seems forced to say either that selfhood can be singular and plural simultaneously, or that causal interaction—not just present pattern—is essential after all. She insists that causal interaction is already encoded in the pattern's dynamics.

I feel there is an equivocation or a hidden scope shift between (1) and (4), or between (2) and (5), but I cannot name it precisely. Which step should I reject, and what does giving it up cost for the idea that an "I" can genuinely live across brains? Please answer in American English.
