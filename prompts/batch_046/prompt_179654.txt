Exam question: Consider Dennett’s “two-bitser”—a minimal system possessing only two internal registers, B and S, which an external interpreter maps onto the belief that a predator is near and the desire to seek shelter, thereby predicting its movement toward cover. (a) Explain how Dennett uses this case to argue that intentionality is derived, predictive, and not an intrinsic, observer-independent property of the system. (b) Set out Searle’s distinction between original and derived intentionality, and explain why Searle maintains that interpretive success does not collapse the distinction. (c) Evaluate the following student claim: that Dennett’s example is really just a version of Searle’s Chinese Room; that Searle denies computers can have even derived intentionality; and that the possibility of misrepresentation—state B occurring when no predator is present—proves the two-bitser’s states must possess original aboutness, since false belief requires intrinsic semantic content.

Student answer:

(a) Dennett introduces the two-bitser to show that we can adopt the intentional stance toward an extremely simple mechanism. By interpreting state B as the belief “predator nearby” and state S as the desire “find shelter,” we predict behavior—moving to cover—without tracking physical mechanisms. Dennett argues that if this interpretation is predictively reliable, the system literally has those beliefs and desires. There is no hidden layer of “original” intentionality inside the machinery; all intentionality is derived from the interpreter’s framework. Even human mental states are ultimately just more complex patterns interpreted by other agents and by ourselves.

(b) Searle distinguishes original intentionality—the intrinsic, conscious aboutness of mental states—from derived intentionality, which is assigned to artifacts like words or computer outputs by beings with original intentionality. Searle agrees we can interpret the two-bitser’s states, but he classifies this attribution as derived intentionality that is purely metaphorical, like saying a thermostat “wants” a certain temperature. Because the two-bitser lacks consciousness, it has no original intentionality, and its attributions depend entirely on the observer’s mind. So predictive success shows only that the interpretation is useful to us; it does not create literal aboutness inside the system.

(c) The claim that Dennett’s example is a Chinese Room is mistaken: the Chinese Room concerns syntactic symbol manipulation without semantic understanding, whereas the two-bitser concerns minimal behavioral interpretation, not computation. The student is also wrong that Searle denies derived intentionality altogether—Searle explicitly allows that computers and symbols can possess it through assignment by users. Where the student is more persuasive is on misrepresentation: if state B occurs in the absence of a predator, the system seems to have a false belief, and false belief requires intrinsic semantic content. Dennett can reply that this is merely predictive failure—the interpretation stops working—without invoking intrinsic aboutness. Nevertheless, the student correctly sees that Dennett’s argument succeeds only if predictive reliability is sufficient for literal belief, but this begs the question against Searle, who requires intrinsic aboutness for any literal semantic content. Thus, as Searle shows in the Chinese Room, syntax alone never yields semantics; therefore, for B to be genuinely false rather than merely malfunctioning, the interpreter’s own original intentionality must supply the semantic content that makes the state false. So Dennett has not eliminated original intentionality—he has hidden it in the observer.
