I've been chewing on this hybrid view that tries to split the difference between Jaspers-style metaphysical guilt and the usual "nations aren't agents" objection. The idea is that collective guilt across generations works not through shared intentionality but through institutional inerta — legal and cultural structures that maintain the same harm-generating functions even as every individual member gets replaced. So a nation in 2024 isn't guilty because today's citizens did anything, but because the state as a functional system inheritted and still operates within causal chains that started decades earlier, and there's no clean break point where the chain was severed. I think this avoids the "no agency, no guilt" problem by shifting guilt from agents to persistent causal architechtures, but I'm honestly not sure if it's just wordplay with extra steps.

What would actually count against it? I want defeaters sorted by how fatal they'd be: which observations or arguments force me to drop the institutional-inertia framing entirely, which are merely awkward, and which ones defenders of pure individual guilt or pure Jaspers metaphysical guilt would themselves concede are damaging versus which they'd dismiss. Also, does this view risk being qualified into unfalsifiability — like if I claim the causal chain is never fully broken, then any counterexample gets absorbed? If so, is that insulation actually a problem for a view of this kind, or is it just being careful?
