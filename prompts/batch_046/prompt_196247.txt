(1) rational herding means agent i updates on both their private signal s_i and the observed actions a_1...a_{i-1}.
(2) but here's the thing: a_j was produced by agent j weighing s_j against a_1...a_{j-1}, not by s_j alone.
(3) so when i observe a_j, i'm not observing s_j; i'm observing s_j filtered through j's prior cascade weights.
(4) if rational belief requires that your evidence be transparent to you - meaning you can trace each piece back to its source - then using a_j requires tracing back through j's weights, then through k's weights, etc.
(5) eventually this trace hits agent 1's raw s_1, but every intermediate layer added distortion from cascade weights.
(6) therefore the total evidential value of the cascade for agent n is bounded above by agent 1's raw signal strength, divided by the product of all cascade weights.

(8) so either agent n ignores the cascade and uses only s_n, or they use the cascade and violate transparancy.
(9) but if they use only s_n, herding doesn't happen; if they violate transparancy, rationality is cheap.
(10) therefore rational herding requires either that transparancy is false - making all testimony-based belief cheap - or that cascade weights are <=1, which contradicts every model.
