I'm preparing a feature on the conceptual architecture of AI alignment, and I've been wrestling with an argument that seems to collapse the distinction between intent alignment and value alignment—the narrow versus broad framing of the problem. Here is the chain, and I cannot locate the fracture. (1) Intent alignment, narrowly construed, holds when an AI system's behavior tracks the specific intentions of its operators, whatever those intentions happen to be. (2) Any claim that the system is value-aligned must be cashed out in terms of some agent or group whose values are being respected—say, the designers, a democratic assembly, or a hypothetical rational consensus. (3) Once that agent is specified, saying the system aligns with their values is just saying it tracks their intentions regarding normative outcomes. (4) Therefore value alignment is not a separate category; it is intent alignment applied to intentions that have normative content. (5) Now consider the case where different agents hold conflicting values—one group intends fairness, another intends efficiency, and no unified intention exists. (6) Intent alignment requires a determinate target; it cannot align with a contradiction. (7) So in cases of genuine value conflict, value alignment is impossible under the intent-alignment framework, which means the framework either excludes pluralistic values or renders them unalignable. (8) But the alignment literature routinely treats value conflict as a problem to be solved within value alignment—through constitutional AI, deliberative mechanisms, or reflective equilibrium—not as proof that value alignment is undefined. (9) Hence either the literature smuggles in an undefined target, or one of the premises above fails. I want to preserve the idea that value alignment is genuinely distinct from intent alignment, particularly in pluralistic contexts, but I need to know which step to reject and what it costs me. Is there an equivocation between intention as a design parameter and value as a normative standard? Or does the argument depend on a quantifier shift between for each value there is an agent and there is an agent for all values? Which premise should I give up if I want to keep both the narrow definition intact and the possibility of value alignment in conflict?
