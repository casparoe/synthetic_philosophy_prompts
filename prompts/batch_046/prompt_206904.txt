I'm a backend engineer with basically no formal philosophy background, but I got obsessed with Dennett's idea of real patterns after a podcast episode. He talks about three stances—physical, design, intentional—and says we should use the intentional one (beliefs, desires) whenever it gives us real predictive patterns we can't get from the other two. I tried applying this to distributed systems and it seems to prove way too much. Here's my argument:

(1) A system genuinely has mental states iff attributing beliefs/desires yields predictive patterns that the physical and design stances miss.
(2) My load-balancer maintains an internal 'health-belief' table; without referencing those beliefs, predicting which server gets the next request is nearly impossible.
(3) So the load-balancer genuinely believes some nodes are unhealthy.
(4) But I could rewrite the exact same routing behavour with a dumb round-robin loop that has no belief table at all.
(5) In that implemntation, physical/design stances capture everything, and there are zero mental states.
(6) So whether the system has beliefs depends on which code I wrote, not on any observable behaviour.
(7) Now imagine I keep the belief table running as dead code—it updates but never affects routing—while the loop handles traffic.
(8) Under (1), those beliefs don't count because they don't help predict anything. But if I wire them back in tomorrow, mental states suddenly 'pop into existence' with no change to the system's outputs.
(9) That makes mental states observer-dependent in a weird way: they exist only when I decide to use that part of the architecture for explanation.
(10) But Dennett wants real patterns to be objective—like stock-market patterns—so (9) contradicts his project.
(11) Therefore either (1) needs a hidden clause that blocks dead-code cases, or real patterns can't ground mental states on thier own.

Which step is the slip? I feel like it's somewhere between (6) and (8), but I'm not sure if I'm misreading Dennett or if his view actually has this observer-dependence problem. If I reject that step, what does it cost—do I have to accept that minds are just useful fictions?
