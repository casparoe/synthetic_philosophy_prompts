I've been thinking about what people mean when they say someone went "above and beyond"—doing something clearly good, yet not the kind of thing you'd call them wrong for skipping. I don't have a philosophy background, but I keep noticing that conversations about this collapse quickly into people talking past each other, partly because nobody spells out the concrete commitments behind labels like "supererogatory." I'd like you to build a sorting taxonomy—structured as a decision tree with explicit branch logic—that maps the actual positions people hold, using only concrete case answers rather than philosopher names.

Use this root case: a bystander sees a stranger drowning in a river; she can save them, but only by risking serious personal injury. From there, construct three levels of diagnostic branching questions that a non-specialist could answer at dinner without knowing any theory labels:

1. Would she have done something blameworthy if she had walked away?
2. If she jumps in and saves the stranger, is her action praiseworthy in a different kind or degree from ordinary duty-fulfillment (say, keeping a promise)?
3. Even if walking away was not wrong, could she appropriately feel guilt or regret for having done so?

Map every combination of answers onto named positions. Your leaves must include at least: (a) a view that eliminates supererogation by collapsing all good acts into strict duty; (b) a view that accepts it with a sharp boundary between duty and surplus; (c) a view that treats the boundary as a fuzzy gradient rather than a line; (d) a niche but coherent view in which so-called supererogatory acts are actually "deferred obligations" that only activate once a personal-cost threshold is crossed; and (e) a view that accepts the acts are genuinely optional but denies that any special praise-structure applies.

For every logically possible combination that has no named occupant, include it in an unoccupied-combinations field and briefly diagnose whether the gap is due to incoherence, unattractiveness, or being merely unexplored. Also flag any pair of leaves that your tree cannot actually separate, with a brief reason why the branches fail to distinguish them.

Please deliver the result as a JSON object with exactly this schema:

- root_case: string describing the scenario
- tree: array of node objects, each with {node_id: string, question_text: string, options: array of {label: string, text: string, leads_to: string or array of strings}}, child_nodes: array of strings}
- leaves: array of objects, each with {leaf_id: string, path: array of strings (the option labels taken), position_name: string, summary: string, occupied: boolean}
- unoccupied_combinations: array of objects, each with {combination_description: string (the path of answers), diagnosis: string}
- unseparable_pairs: array of strings, each naming two position_names that share every branch path
- format_note: string briefly explaining what the tree is for and its limits

Make sure every branch question is concrete and answerable without prior knowledge of moral philosophy. Do not include a bibliography, reading list, or citation list—I have no way to verify those without searching, and I want the map itself, not a list of scholars to look up.
