Here's the thing. But the same bodys almost always refuse to run that machinery on distributive justice — say, whether a rule that saves richer people more often is acceptable — calling those 'political' issues that calculation can't settle. Still, they use the aggregated welfare number to justify the rule.

What philosophical commitments does that split practice actually presuppose? Does it only hang together if you think interpersonal utility comparisons are valid in one domain but meaningless in another, or does it smuggle in a particular view about which moral questions are preference-based?
