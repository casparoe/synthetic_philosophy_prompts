Present your answer as a JSON object with exactly these fields: 'criteria_scores' (an object mapping each criterion name to {'score': integer, 'justification': string}), 'case_ranking' (an ordered array of case names paired with 'rationale': string), and 'disruptive_criterion' (an object with 'criterion': string and 'explanation': string).
