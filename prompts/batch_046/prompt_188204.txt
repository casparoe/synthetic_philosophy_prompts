I've been pushing in my grad seminar that program equilibrium — not the usual repeated-game folk-theorem machinery — is the right frame for commitment in multi-agent AI, especialy if you buy the "open-source commitment with noisy execution traces" variant: agents verify the actual source code, compute best responses to the program itself, and reputation drops out entirely. What would actually count against this position? Don't give me the cheap "they could lie about the source" line. I want the defeaters that bite: formal results about computability of best responses under partial observability, equilibrium-selection problems when source is verified but execution is stochastic, or conceptual cases where verification is technically possible but strategicly useless. Rank them fatal to merely awkward. Also, have defenders qualified program equilibrium so heavily — maybe by allowing hidden randomization or bounded-rationality exemptions — that it's become unfalsifiable? If so, is that a defect for a framework supposed to do real work? Bottom line up front in sentence one, then reasoning, no preamble, don't restate the question.
