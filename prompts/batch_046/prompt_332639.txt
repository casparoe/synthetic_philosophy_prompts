I've come to think that taking the standard simulation argument seriously should make longtermists more fanatical about the far future, not less — contrary to the common intuition that "if we're simulated, our actions don't matter in the real world." My reasoning involves what I'd call nested causal attenuation: if there's a non-trivial probability we're at nesting level n, then influencing base reality (level 0) requires penetrating n layers of causal insulation, but the total number of sentient observers across all simulated branches might scale in ways that dominate the base-reality population. Rather than dampening concern, simulation uncertainty could introduce an exponential multiplier on expected moral weight distributed across layers, with the root reality's far future remaining the ultimate bottleneck. What would count against this position? I want decisive objections, not just the standard rebuttal. Specifically: which results about computation limits, observer selection effects, or causal closure in simulated physics would undermine the nested-attenuation framing? Are there arguments that the reference class for longtermist utility should collapse to our immediate layer regardless of nesting? Has anyone qualified this kind of view into unfalsifiability — say, by allowing any observed outcome to be compatible with some nesting level — and if so, is that insulation a problem for a normative claim of this kind? Rank the defeaters from fatal to merely awkward, and indicate which ones a defender should concede as genuinely counting against them.
