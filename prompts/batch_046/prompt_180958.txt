Here's an argument I came up with for my phil of logic seminar and now it feels suspicious because the conclusion is way too strong.

(1) In the MIU system there's no rule that derives MU, and in fact it's impossible.
(2) Hofstadter says solving it requires jumping out of the system — noticing the invarient about I's mod 3, which isn't inside the rules at all.
(3) So JOOTSing is reasoning that uses facts about a system that the system itself can't represent or justify.
(4) Gödel's first theorem says any consistent formal system F that can do arithmetic has a true statement G_F that F can't prove.
(5) If JOOTSing works for MIU, it should work for any F: we can always jump outside and see G_F is true.
(6) So if someone claims my reasoning is fully captured by formal system F, I can always construct G_F and know it's true, which proves F misses something.
(7) Therefore no formal system can ever fully model any reasoner — including me.
(8) But now apply this to belief revision: if my beliefs form a system B, and B has a Gödel sentence B* that B can't justify, then I can JOOTS out and believe B* anyway.
(9) That means there's always a belief I hold that my own belief system can't support — basically I can believe anything by jumping out.
(10) So if I believe something crazy (like I'm a brain in a vat), I can just say I JOOTS'd into it and my belief system doesn't need to justify it.
(11) That makes JOOTSing a blank check for irrationality. But that can't be right, because then the MU-puzzle solution is just as arbitrary as any crazy belief.
(12) So where's the mistake? I want to keep (2) and (3) because they feel right about the puzzle, but I really don't want (9) and (10). Is the slip between formal derivability and rational belief, or is it that Gödel sentences aren't actually accessible by JOOTS in the same way?
