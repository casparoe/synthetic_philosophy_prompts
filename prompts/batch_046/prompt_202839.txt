You are designing an operational protocol for a scientific review board that evaluates competing mechanistic explanations for anomalous observational patterns—say, unexpected correlations in environmental sensor networks—where both underfitting and overfitting carry regulatory consequences. The board has adopted a formal commitment to Solomonoff induction and algorithmic information theory rather than conventional parameter-count parsimony, but its members are not philosophers of science. Write a reusable decision procedure they can execute in a single meeting: an ordered sequence of tests applied to any pair of competing explanations, specifying for each test what counts as a sufficient answer, where a negative result terminates evaluation of one candidate, and where the question is irreducibly about value or representation choice rather than computation. The procedure must explicitly address: (i) that Kolmogorov complexity is uncomputable and therefore requires a fixed, publicly specified description language together with an agreed computable approximation such as MDL relative to a specified universal prefix scheme; (ii) that simplicity is language-relative, so the procedure must include an encoding audit that detects whether one explanation achieves lower description length only by outsourcing complexity into an unverified preprocessing assumption, normalization constant, or data-cleaning rule; (iii) the distinction between the complexity of the predictive program and the complexity of the residual data, per Solomonoff’s two-part coding, with explicit instructions for how to treat shared background knowledge that can be pre-compiled; and (iv) the boundary at which a simpler explanation must be rejected not because its program is long but because its required priors fall outside the board’s domain plausibility—marking this boundary explicitly as a judgment call requiring human sign-off, not as an algorithmic output. Include stop-rules for adversarial simplicity, defined as cases where a model’s apparent brevity depends on exploiting an idiosyncrasy in the encoding scheme rather than on genuine structural economy. Then apply the procedure to three worked examples: (A) a single-factor linear model versus a multi-factor interaction model that has more free parameters but a shorter combined program once standard physics is pre-compiled; (B) a novel-agent explanation requiring a long structural description but generating highly compressed predictions of the observed pattern; and (C) a tie case in which both candidates yield approximately equal approximate MDL scores, but one depends on a contested outlier-removal step in the data pipeline—showing precisely where the procedure halts, what kind of decision the board must now make (language choice, prior plausibility, or risk tolerance), and why the algorithm cannot supply the answer. Conclude by identifying two distinct classes of disputes for which the procedure is not designed and should never be invoked.
