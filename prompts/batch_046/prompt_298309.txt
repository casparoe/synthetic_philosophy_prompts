I work as a software engineer with no formal philosophy background, and I am trying to understand the conceptual boundary between approval-directed and goal-directed agents in a setup that seems to blur them. The standard distinction I have seen is that a goal-directed agent optimizes for a fixed world-state or outcome, while an approval-directed agent optimizes for a signal of human approval. But consider this variant: the agent’s reward function is not a direct human rating, but a predictive model of what an idealized supervisor would approve of at each step, and that predictive model is updated online using feedback that is partly generated by the agent’s own previous outputs—so the agent’s behavior can gradually shift the very distribution of states that count as approved. In this case, the agent still appears to be pursuing approval, yet because it can influence the approval criterion over time, it behaves in ways that resemble the pursuit of a fixed trajectory—namely, the trajectory along which supervisor preferences shift in a particular direction. Where should the conceptual line be drawn? Is the distinction fundamentally about the formal structure of the optimization target (whether it is a static objective versus an evaluated signal), or about causal independence—whether the agent’s actions can feed back into the criterion being optimized? And if the approval model is endogenous in this way, does the agent become a hybrid that inherits the characteristic failure modes of both categories, or is there a principled reason to classify it as one or the other?
