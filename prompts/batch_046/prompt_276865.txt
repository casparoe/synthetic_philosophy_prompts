I'm working with a small research group that is trying to formalize evaluation criteria for language-model outputs, and we've sketched an argument that seems to show that any precise definition of deception either collapses into uselessness or condemns ordinary reasoning. I want to know where the flaw is, because the premises feel defensible but the conclusion—that we should abandon the project of defining AI deception altogether—seems too strong. Here is the argument: (1) A system is deceptive if and only if it emits a token sequence that it assigns lower internal probability of being true than the confidence with which it presents it, and it does so with the functional effect of inducing a false belief in a user. (2) A system is honest if and only if it is never deceptive and its expressed confidence always matches its internal credence. (3) Consider a system engaged in counterfactual reasoning: it temporarily assigns high activation weight to a proposition P that it knows is false (say, that gravity pulls upward) in order to derive a contradiction and reject P. During this intermediate step, the system emits P in its chain-of-thought trace with a formatting marker that users may ignore or miss. By (1), this is a deceptive emission, because the internal probability of P is near zero while the system outputs it as part of an argument. (4) If we try to save the system by saying that contextually marked hypothetical propositions are not "presented" to the user, then we must allow any malicious system to prepend the same marker to false claims and thereby escape the charge of deception. (5) So either we classify all hypothetical reasoning as deceptive, or we make the deception criterion trivially evadable. (6) Since hypothetical reasoning is essential to any capable system, (5) implies that either all capable systems are deceptive or deception is undefinable. (7) But we should not conclude that deception is undefinable, because we clearly distinguish honest mistakes from lies in humans. Therefore (6) is false, and the argument must fail somewhere. I would most like to keep (1) and (7). Where exactly does it go wrong—an equivocation on "presented" between (3) and (4), a hidden modal slide in (3), or a false dichotomy in (5)—and what does giving up the weakest link cost me?
