Here is an argument I constructed for a philosophy-of-biology seminar that now strikes me as suspicious, because it seems to drive us into an absurd dilemma: either mainstream evolutionary biology fails to explain the origin of the genetic code, or the informational framework that underwrites molecular genetics collapses into mere metaphor. I would most prefer to keep the claim in step (2) that the codon-to-amino-acid mapping is genuinely arbitrary rather than chemically necessary, but I am prepared to weaken or abandon it if the reasoning demands.

(1) Molecular biology routinely describes DNA as carrying "genetic information" and functioning through a "code" in which nucleotide triplets map to amino acids.

(2) A code, in the philosophically precise sense, involves an arbitrary symbol-meaning pairing that is not fixed by physical law; the genetic code satisfies this, since the same triplet can specify different amino acids across organisms, and synthetic biology can reassign codons without altering DNA chemistry.

(3) Wherever there is a genuine arbitrary code, there must be an encoder—or at least a process of convention-establishment—that fixes the mapping; unguided physical causation by itself cannot establish arbitrary conventions.

(4) Therefore, if DNA is literally a code in this precise sense, evolutionary accounts that invoke only unguided mutation and natural selection are insufficient to explain the origin of the mapping.

(5) Yet evolutionary biologists explain the code's origin through co-evolutionary models of tRNA and synthetase specificity, without invoking any designer or conventional agent.

(6) So we must choose: either those evolutionary explanations are wrong, or DNA is not literally a code in the sense that requires an encoder.

(7) If DNA is not a code, then the central metaphors of transcription, translation, and reading frames describe no real informational processes but are only heuristic analogies lacking ontological weight.

(8) But if those metaphors lack ontological weight, then the claim that DNA "carries information" is false in any robust sense, which undermines a large part of the conceptual foundation of genetics.

The argument concludes that we must reject either mainstream evolutionary explanations of the code's origin or the informational ontology of molecular biology. I think this is too strong. Where exactly does the reasoning fail?
