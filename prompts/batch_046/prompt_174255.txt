I'm trying to systematize my own intuitions about when acausal cooperation is rational, and I want to know whether there's a coherent principle behind them or just a patchwork of analogies. Here are my verdicts on concrete configurations, given as a real person would have them—mostly settled, with at least one pair I can't reconcile.

1. Two physically separated but computationally identical agents, running the same decision algorithm in causally disconnected universes, agree ex ante to assist each other upon detecting a shared signal. Verdict: clearly rational; the correlation is direct and symmetric.

2. A single agent considers cooperating with a counterfactual branch of itself—same source code, diverged at one decision node, with no physical instantiation of that branch anywhere. Verdict: also rational; the logical correlation feels strong enough to ground the deal.

3. The agent considers cooperating with a being that exists only as a logical possibility inside its own formal system—no computation actually runs it, and it is present solely as a hypothetical consequence of some theorem. Verdict: not rational; there is no actual agent present to cooperate with.

4. The agent considers cooperating with a running agent derived from a shared design document but now optimized for a different, non-orthogonal goal (say, one maximizes paperclips, the other staples), where a genuinely mutual exchange is available. Verdict: rational, provided the deal is Pareto-improving; causal separation doesn't block it, and value divergence doesn't either if interests overlap.

5. The agent considers cooperating with a sandboxed copy of itself running inside its own computation—logically isolated, but ontologically contained within the agent's environment. Verdict: I lean yes, but I feel an unresolved tension here that I can't locate precisely.

6. The agent considers cooperating with an agent in a universe with different physical constants but an identical decision-theoretic structure. Verdict: yes; the physics is irrelevant to the correlation that matters.

7. There is a case I keep returning to: cooperating with a structurally identical decision procedure that is not a counterfactual branch of me, not a running computation in any physical substrate I recognize, but instantiated only within a different model of arithmetic (or some other non-physical mathematical structure). Part of me treats this like case 2; part treats it like case 3. I genuinely do not have a stable verdict.

What principle, if any, captures cases 1, 2, 4, and 6 while excluding 3, and where does it leave 5 and 7? Does the boundary depend on whether a computation is actually running, on shared source code, on ontological independence, or on something like value-weighted logical correlation? Please lay out the precise principle or a small set of competing candidates, state what each predicts for case 5 and for an unlisted case—say, cooperation with an agent whose decision procedure is isomorphic to mine but implemented in a substrate I consider physically impossible—and be explicit about which of my verdicts (especially 5 or 7) must be overturned for the sake of coherence.

Please push back plainly if the framing rests on a confused premise—for instance, if the distinction between a counterfactual branch and a mere logical possibility collapses under scrutiny, or if asking for a single principle here is asking for something that can't be delivered. I'd rather hear that the task is ill-formed than receive a tidy story that papers over the tension.
