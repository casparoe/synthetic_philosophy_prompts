I cover philosophy of mind and cognitive science, and I have kept encountering a configuration that resembles the absent-minded driver problem without quite matching it. Consider an agent—human or artificial—that is executing a complex plan. The agent can be interrupted at any point and will correctly report both the current situation and the plan it is following, yet that report is structurally isolated from the mechanism that guides behavior. A surgeon continues an incision in the wrong orientation despite being able to state, if asked, that the instrument is misaligned; a navigation system logs an unexpected obstacle but keeps following the original route because the log entry and the routing module do not communicate. There is no absence of information—the agent registers the discrepancy in some accessible form—but there is a wall between registering and correcting. It is not standard absent-mindedness, since nothing is forgotten; not weakness of will, since there is no competing desire; and not pure automatism, since behavior remains responsive to other cues. Does this specific decoupling of reportable awareness from corrective action have an established name in philosophy of action or cognitive science? If a concept exists, how does it differ from these neighboring failures? If not, how should it be defined—does it require consciousness, or can it apply to artificial systems—and what distinguishes its boundary cases?
