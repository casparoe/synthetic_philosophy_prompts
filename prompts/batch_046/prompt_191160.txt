Problem:
Consider an agent with uniform prior credence over three hypotheses about a manuscript’s origin: H1 (authentic 12th-century), H2 (Renaissance forgery, 15th century), and H3 (modern forgery, 20th century). The agent receives an ambiguous radiocarbon report that does not directly determine which hypothesis holds, but shifts credence over a partition of evidential-quality states: E1 (uncontaminated sample), E2 (mild contamination biasing results toward older dates), and E3 (severe contamination rendering the test unreliable). The agent’s updated credences are P'(E1) = 0.5, P'(E2) = 0.3, and P'(E3) = 0.2. The agent knows that, conditional on each E_i, the prior probabilities over H1–H3 are fixed (the rigidity condition holds for these conditionals). The specific prior conditionals are:

P(H1|E1) = 0.7, P(H2|E1) = 0.2, P(H3|E1) = 0.1
P(H1|E2) = 0.5, P(H2|E2) = 0.3, P(H3|E2) = 0.2
P(H1|E3) = 0.4, P(H2|E3) = 0.3, P(H3|E3) = 0.3

(a) Apply Jeffrey conditionalization to compute the agent’s updated credences P'(H1), P'(H2), and P'(H3). Show the formula and your arithmetic.

(b) Explain precisely why Jeffrey conditionalization is not equivalent to applying Bayes’ rule sequentially to each E_i and averaging the results.

(c) Identify one genuine limitation of Jeffrey’s rule that arises when the evidential partition is not causally independent of the hypotheses being evaluated. Explain whether that limitation applies in this manuscript case, and state what alternative updating strategy, if any, should be used.

Student Answer:
(a) Using Jeffrey’s formula P'(H_j) = Σ_i P(H_j|E_i)P'(E_i):

P'(H1) = 0.7(0.5) + 0.5(0.3) + 0.4(0.2) = 0.35 + 0.15 + 0.08 = 0.58
P'(H2) = 0.2(0.5) + 0.3(0.3) + 0.3(0.2) = 0.10 + 0.09 + 0.06 = 0.25
P'(H3) = 0.1(0.5) + 0.2(0.3) + 0.3(0.2) = 0.05 + 0.06 + 0.06 = 0.17

These sum to 1.0, so the update is consistent.

(b) Jeffrey conditionalization differs from Bayes’ rule because Bayes’ rule requires knowing exactly which observation occurred, whereas Jeffrey’s rule averages over possible evidential states using the agent’s new credences in them. Specifically, Jeffrey’s rule is equivalent to applying Bayes’ rule sequentially for each E_i—updating the prior each time—to obtain an intermediate posterior, and then taking a weighted average of those posteriors with weights P'(E_i). This preserves the prior relationships among the hypotheses within each cell while accommodating uncertainty about which cell actually obtains.

(c) The central limitation is the rigidity condition: the conditional probabilities P(H_j|E_i) must remain constant throughout the update. This condition is essentially a requirement of causal independence between the evidential partition and the hypotheses. In the present case, contamination levels are likely causally dependent on the manuscript’s true age—modern forgeries may be more susceptible to severe contamination—so the rigidity condition is violated. Consequently, Jeffrey’s rule should not be applied here. Instead, the agent should abandon Jeffrey updating and use standard Bayesian conditioning directly on the raw radiocarbon measurements, treating the contamination states E_i as nuisance parameters to be integrated out using the prior.
