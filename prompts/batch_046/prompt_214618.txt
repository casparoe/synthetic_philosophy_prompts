Consider an argument my study group constructed to show that treating consciousness as a user-illusion undermines itself. (1) Consciousness is a user-illusion analogous to a computer desktop: the brain constructs a compressed interface presenting colors, pains, and a unified self, none of which exist in the underlying neural computation. (2) If the interface is genuinely illusory, then there is no entity corresponding to the 'user' depicted—there is only the computation generating the depiction. (3) So there is no actual subject that possesses experiences; there are only neural processes that output reports of possession. (4) But an illusion necessarily requires a subject who is misled; if no subject exists, the appearance is not an illusion but an unowned computational artifact, like a display showing false data with no observer. (5) Therefore the model either smuggles in a real subject outside the interface (denying 2) or eliminates the very phenomenon it sought to explain naturally (denying 1). (6) Hence consciousness is not a user-illusion. The group suspects a hidden equivocation between 'illusion as false representation' and 'illusion as deceptive appearance to someone,' but they cannot locate it precisely. Which step fails, and what does giving it up require? If you wish to preserve both the interface model and the absence of a substantial self, can you do so without rendering 'illusion' vacuous?
