(1) Transcendental arguments have this form: an activity A is actual; A is possible only if condition C obtains; therefore C obtains.
(2) This works for experience: temporal self-consciousness requires an enduring self, so there is one.
(3) Apply the same form to belief revision: we actually correct beliefs in light of counterevidence. For this to be possible, there must be a standard of correctness independent of any particular mental state—otherwise there is no direction for correction. So objective, mind-independent truths exist.
(4) Apply it again to aesthetic disagreement: people actually dispute whether a work is beautiful across different perceptual conditions. For this to be possible, there must be objective aesthetic properties that outlast particular responses.
(5) Apply it once more to the predictability of human action: we actually forecast others' behavior. For this to be possible, there must be deterministic psychological laws governing choice.
(6) Apply it finally to the phenomenology of freedom: we actually experience ourselves as able to do otherwise. For this to be possible, there must be libertarian free will.
(7) But (3)-(6) yield an incoherent package—objective Platonism, aesthetic realism, determinism, and libertarianism together are hard to maintain, and some pairs contradict.
(8) Therefore the transcendental form, if valid, proves far too much; if it does not prove these, it must fail for (3) as well.

I am inclined to keep (3) and reject the overgeneration, but I am not sure where to draw the line without special pleading.
