The student wrote:

"The sunk-cost fallacy occurs when an agent continues an endeavor because resources have already been expended, even when present costs exceed present benefits—like remaining in a theater for a bad film. For an isolated individual, rational choice theory is unambiguous: only future marginal costs and benefits should determine action, so honoring sunk costs is necessarily irrational. The situation changes for institutions. Organizations must maintain dynamic consistency; if they abandon projects whenever continuation becomes suboptimal, they destroy stakeholder trust and undermine intertemporal cooperation. Thus an institution that honors its prior investment is not falling prey to bias but is preserving rationality across time. In collective contexts, the argument is stronger still. A sunk cost borne collectively is a shared sacrifice; to abandon the project renders that collective effort meaningless, which violates distributive fairness. For example, if a municipality has built half a bridge that is now unneeded, completing it honors the citizens' shared investment rather than wasting it. Consequently, honoring sunk costs is irrational only for isolated individuals; for institutions and collectives it is rational, serving credibility and fairness. The claim that it is always irrational is therefore false."
