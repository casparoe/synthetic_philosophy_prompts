I've been mapping my own judgments about common knowledge of rationality in epistemic game theory, and I want to know whether they cohere around a single principle or whether some verdicts have to be abandoned. Case 1: in a standard two-player coordination game with complete information, common knowledge of rationality selects the Pareto-optimal equilibrium, and that feels correct. Case 2: if player A knows B is fully rational, but B assigns only epsilon-doubt to A's rationality, I still think the Pareto outcome is strategically reachable, even though strict common knowledge technically fails; the reasoning seems almost unchanged. Case 3: in a variant where players observe each other's reasoning traces—intermediate inference steps—rather than just actions, applying common knowledge to the trace-generation process appears to create a fixed-point instability: A sees B's trace leading to cooperation, which should alter A's own trace, and so on. I think this breaks backward induction differently from the standard case, but I'm unsure whether that's a genuine feature or a misapplication. Case 4: in a three-player setting, two agents with common knowledge of rationality can coordinate to exploit a third player whose bounded rationality is transparent, but only if they share common knowledge of the exact bound, not merely mutual belief. Is there a unified account—perhaps one that distinguishes transparency of actions from transparency of reasoning processes—that saves all four verdicts? If not, which case should I overturn? And what should the resulting principle predict for a two-player game in which rationality is common knowledge but the payoff structure is only common belief up to some finite order?
