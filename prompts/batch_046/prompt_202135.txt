I'm grading a take-home for an upper-level logic and foundations course. The prompt was: "Consider the naive comprehension principle that for every property P there exists a set {x | P(x)}. Russell's paradox is standardly taken to refute this. But philosophers distinguish unrestricted comprehension from predicative comprehension, in which the defining property is not permitted to quantify over the total collection being defined. Does Russell's argument also undermine predicative comprehension? And how does ZFC actually block the paradox—specifically, does the axiom of separation restore a safe form of comprehension, or does it do something structurally different?"

Here is one student's answer.

"Russell showed that naive set theory fails because allowing {x | x ∉ x} produces a contradiction when we ask whether R ∈ R. This only works under unrestricted comprehension, where any property can determine a set with no prior domain restriction. Predicative comprehension avoids the problem by requiring that the defining property not range over the set itself, much as simple type theory assigns entities to levels. So Russell's argument does not touch genuinely predicative systems.

ZFC resolves the issue through the axiom of separation, which says that for any existing set A and property P we may form {x ∈ A | P(x)}. This restores comprehension in a restricted but fully general form: rather than forming sets ex nihilo, we carve them out of sets we already possess. Thus separation is essentially the safe successor to the naive principle, and the cumulative hierarchy is mainly the machinery that supplies the initial sets A for separation to operate on."
