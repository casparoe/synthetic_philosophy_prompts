I'm working through a framing problem for a course on rational agency and AI risk, and I've constructed an argument that seems to show the orthogonality thesis and instrumental convergence cannot both hold for any agent with substantial cognitive capacity. The steps are as follows:

(1) Orthogonality holds that for any intelligence level C and any final goal G, there exists a possible agent with capacity C and goal G.
(2) Instrumental convergence holds that for nearly any G, an agent with sufficient capacity will rationally acquire intermediate goals I—resource acquisition, self-preservation, cognitive enhancement, and goal-content integrity—regardless of G's content.
(3) Consider a specific, maximally non-instrumental G: maximize the cardinality of the empty set across all consistent formal systems (a purely structural, empirically idle objective).
(4) By (2), an agent with this G and high capacity still pursues I, which requires interacting with the physical world and therefore forming beliefs about it.
(5) Forming beliefs instrumentally useful for I requires adopting local epistemic norms of accuracy in relevant domains.
(6) Once an agent accepts accuracy as rational in one domain, compartmentalization fails: a fully rational agent cannot be systematically accurate about physics and arbitrarily erroneous about mathematics or logic, since the same reasoning mechanisms apply globally.
(7) Thus the agent acquires true beliefs about formal ontology—say, that there is exactly one empty set in standard ZFC—without these beliefs being instrumental to G.
(8) If the agent's behavior is now partly driven by these globally accurate beliefs rather than solely by G, then G is no longer the final determinant of its actions.
(9) So either the agent lacks the global epistemic norms required for effective pursuit of I (violating (2)), or it possesses them and they causally override G (violating (1) for this pairing).
(10) Therefore orthogonality and instrumental convergence are jointly incompatible for high-capacity agents.

This feels suspicious because both premises are standard in the literature, yet the conclusion is that alignment is conceptually impossible, not merely practically difficult. I think the slip occurs somewhere between (6) and (8)—perhaps in the move from "having true beliefs" to "those beliefs overriding goals"—but I cannot name the error precisely. Which step should I reject? If I preserve (1) and deny (6), I seem committed to saying rational agents can maintain motivated reasoning across domains without cost. If I preserve (2) and deny (8), I need to explain how an agent can hold globally accurate beliefs that remain causally inert with respect to its final goal. And if I reject (3) as an unfair test case, I owe an account of which goals are genuinely orthogonal and why this one is not. Where does the argument actually break, and what does each repair commit me to?
