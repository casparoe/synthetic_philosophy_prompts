I've been arguing with my flatmate about VR harm and I'm proper stuck in the weeds. Here's the chain I built and it feels like it proves way too much:

(1) If an event causes real psychological harm, the harm's object must exist in at least a modal sense — there must be a fact about whether it could've survived or not.
(2) When someone burns my virtual house in a persistent world, I feel real distress, and that distress is genuinely about the house being gone.
(3) So the virtual house has modal identitiy conditions across server states; it's not just pixels, it's something that can be otherwise.
(4) But if virtual objects have modal profiles like that, they have identity conditions across possible worlds, which makes them abstract objects (like numbers) rather than concrete representations.
(5) If they're abstract objects, then harming them is like harming a mathematical structure — impossible, since abstracts lack causal powers.
(6) So either virtual harm isn't real (reject 2) or virtual objects are concrete (reject 4), but concrete virtual objects need physical substrates, which pushes us back to saying only the server-state is real.
(7) That collapses virtual harm into harm about server-state, which makes the harm bizarrely indirect and doesn't match my experience at all.
(8) Meanwhile, if we keep (3) and (4) together, every virtual world spawns a real ontology of abstract objects with legal standing, which is clearly mad.

Where does this slip? I'd rather keep (2) and (3) if I can — the harm feels real and I think the object has some kind of persistence. What's the cost of saving them? Please answer in British English, and don't bother with references, I just want the reasoning worked through.
