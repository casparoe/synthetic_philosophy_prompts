Take Japan's Meiji crash-industrialization—railways, zaibatsu, universal schooling in like fourty years—and analyze it through Weber's problem: can culture cause economic change, or only legitimize it? I want you to treat Meiji as a reverse Protestant Ethic case. The state didn't wait for values to shift; it manufactured a synthetic loyalty-and-work ethic through schools and propaganda to build capitalism from above. So what did state actors actually face—was value-change a tool they used, or a constraint they had to overcome? Does this show Weber wrong about values being independent causes, or just that values need institutional embedding to do work? Then jump to post-1945: old state institutions gutted, but the 'work for collective' attitude stuck. Is that cultural inertia, or path dependency in firms? Map carefully—who held which values, what institutions transmitted them, and say exactly where Weber's framework explains the case, where it misdescribes it, and where it's just silent.
