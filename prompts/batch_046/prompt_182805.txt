Student answer: Clark and Chalmers argue that cognitive processes extend beyond the brain when external resources play the same functional role as internal ones. In the classic case, Otto has Alzheimer's and uses a notebook to store beliefs, just as Inga uses her biological memory. The parity principle says that if an external process functions identically to an internal cognitive process, we should treat it as part of the mind, regardless of location.

Applying this to the law firm, the case-management system functions like a shared external memory and reasoning scaffold for the associates.
