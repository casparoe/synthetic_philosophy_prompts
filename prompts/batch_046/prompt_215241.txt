A colleague walked me through this and I can't see the exit. (1) Genuine understanding of a domain requires cognitive autonomy: you must be able to navigate novel cases without outsourcing the reasoning steps to a system you cannot inspect. (2) When a researcher uses a large language model to generate hypotheses, evaluate evidence, or construct arguments, the core reasoning resides in weights and computations the user never accesses. (3) So widespread AI-assisted cognition replaces understanding with a form of epistemic outsourcing that is structurally like dependence on an oracle. (4) But the same reasoning applies to language—individual speakers depend on grammatical rules they never fully grasp—and to textbooks, instruments, and peer review, none of which any single mind can reproduce. (5) If we reply that language and textbooks are inspectable intermediaries, we face the fact that chain-of-thought outputs, retrieval citations, and mechanistic interpretability are making AI reasoning inspectable too. (6) If we reply instead that users can internalize AI use—learning to prompt, calibrate, and integrate outputs into an extended cognitive system—then the boundary between internalized tool and external oracle collapses, and the argument applies only to naive users. (7) So either the autonomy condition in (1) is too strong and eliminates all distributed cognition, or there must be a principled refinement that allows language and science but excludes AI, and I don't see one that doesn't beg the question. My colleague takes this to show that fears about AI eroding understanding are overblown, since the argument proves too much. I want to keep the intuition that something genuinely different is happening with AI, but I can't name the slip. Which step should I reject, and what does rejecting it cost?
