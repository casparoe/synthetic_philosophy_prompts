If Penrose is right that any consistant formal system F has a Gödel sentence it cant prove but we can still see is true, then doesnt it follow that human mathematicians must be running an inconsistent reasoning base? Otherwise we'd hit our own Gödel sentence and be stuck just like F. I tried to patch this by treating human cognition as a non-monotonic default logic with only local consistency, but I'm not sure if that saves Penrose or just changes the subject. Where exactly is the false step—probably in treating "human reasoning" as one formal system with a global consistency property? And please say what would change your mind: would a convincing model of human cognition as a single consistent formal system undo the argument, or is there a result showing resource-bounded agents cant even formulate their own Gödel sentences?
