As a software engineer with no formal philosophy background, I am investigating whether an AI safety constraint can be defined structurally, without embedding a complete account of human values. I have sketched a metric I call the "reversibility radius": for any proposed action, compute the minimal set of state variables outside the agent's direct control that must be perturbed to restore the pre-action distribution of those variables within a bounded causal horizon, weighted by the agent's epistemic uncertainty about each dependency. The aim is to select actions that minimize this radius.

Please rank the following three conceptual objections to using the reversibility radius as a standalone criterion for low-impact behavior. Order them from the most damaging to the least damaging for practical deployment, assign each a severity score from 1 to 10, and briefly justify the ordering in accessible terms.

1. The normative-baseline objection: choosing which variables lie "outside direct control" and which prior distribution deserves preservation already embeds hidden value judgments, so the metric does not eliminate value specification but only obscures it.
2. The horizon-boundary objection: fixing a bounded causal horizon (e.g., three hops) makes long-range but morally significant effects invisible by construction, allowing slowly accumulating harms to escape detection.
3. The status-quo-bias objection: because the metric penalizes deviation from the pre-action state, it implicitly privileges the existing world; if that world contains injustice, the agent is incentivized to preserve it rather than permit beneficial change.

Present your answer as an ordered list with scores, and keep the reasoning concise. Do not provide bibliographies or cite specific authors unless I explicitly ask.
