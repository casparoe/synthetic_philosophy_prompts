Write a sestina on the reference class problem, taking as its subject self-locating belief within nested reference classes: the fact that being this particular observer at this particular moment assigns me simultaneously to the class of all observers, to the class of observers born on a Tuesday, to the class of people who have just observed this specific evidence, with no clear principle governing which class should fix my credence. Use exactly these six end-words, in this order for the first stanza: I, class, now, rate, evidence, world. Let the sestina’s recursive rotation of end-words mirror the way the same indexical subject is repeatedly reassigned to broader and narrower statistical groups. The poem should be precise enough that someone familiar with the literature recognizes the indexical structure rather than generic uncertainty, and it should leave the tension unresolved: in the envoi, gather all six words together without collapsing them into a single reference frame. Present the poem first, followed by a section titled “Commentary on form and reference” (approximately 150 words) explaining how the sestina’s pattern enacts the shifting classes and identifying which stanzas correspond to broader versus narrower reference frames.
