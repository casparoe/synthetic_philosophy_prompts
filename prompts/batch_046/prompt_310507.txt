Right, I'm drafting an essay for our reading group on mechanistic anomaly detection — specifically, what counts as the same mechanism when you're comparing across systems. Here's the rough shape:

1. The usual line is that mechanisms are individuated by causal structure, not physical substrate. So if two neural nets have different architectures but the same intervention profile on hidden states, they're running the same mechanism.

2. I want to push that: sameness requires not just matching counterfactuals on clean inputs, but invariant counterfactuals under adverserial pertubation. Call it "interventional robustness". If one system breaks under noise and the other doesn't, they're not the same mechanism, even if they agree on every test case.

3. Here's where I get stuck. If we don't have exhaustive adversarial coverage — and we never do — then for any anomaly we face a kind of Bertrand problem: we're picking a mechanism explanation from an infinite space of possible failure modes with no natural measure. So I think we should apply a principle of indifference: assign uniform prior over all mechanism-types consistent with the data.

4. But that seems to erase the knowing-how / knowing-that distinction in practice. If every anomaly is just "some mechanism in the prior set failed", then knowing how to repair it collpases into knowing that it's in the failure set. There's no procedural residue.

5. So my tentative conclusion is that mechanistic anomaly detection is only coherent if we reject the principle of indifference and instead favour minimal mechanism-change — but that bias seems arbitrary.

Can you comment on accuracy, especially whether point 2 is actually defended anywhere, and whether point 4 really follows? Also, is the move in point 3 a misapplication of the principle?
