Consider the following argument I developed for a discussion and now find suspicious because its conclusion seems to swallow all moral distinctions. (1) Standard Frankfurt cases show that an agent can be morally responsible for an act even when he could not have done otherwise, because the counterfactual intervener plays no actual causal role; hence the principle of alternative possibilities is false. (2) The non-excusing feature of the intervener is precisely that it is counterfactual and causally inert with respect to the actual decision. (3) In a deterministic world, the laws and prior conditions are not counterfactual standby mechanisms but the actual causal chain producing every action. (4) By parity, if causal inertness does not excuse, then actual causal efficacy should not excuse either—indeed, determinism should be even less available as an excuse than Frankfurt-style intervention. (5) So Frankfurt-style reasoning, consistently applied, does not merely defeat PAP; it entails that determinism is fully compatible with, and perhaps amplifies, responsibility for every determined action. (6) But in a deterministic world every event lies in shared causal chains, so this reasoning makes each agent responsible not only for her own actions but for all downstream effects in which she participates causally, erasing the boundary between direct and indirect agency. (7) Therefore either the Frankfurt intuition fails to undermine PAP, or it commits us to an implausible universal causal responsibility in which moral distinctions collapse. Which premise should I reject? I would prefer to keep (1) and (2), since they express the core Frankfurt intuition, but I need to know what giving up either of them costs, and whether there is a more subtle flaw—perhaps in (3) or (4)—that allows me to preserve the intuition without the absurd conclusion.
