I'm a software engineer with no formal philosophy background, currently working through some decision-theory material for a module I'm building, and I recently tried to formalize how we should update beliefs when a system log is ambiguous. I was discussing Jeffrey conditionalization with colleagues and ended up constructing an argument that seems to show rational belief revision collapses whenever evidence is genuinely uncertain. Here is the chain.

(1) Jeffrey conditioning is the correct rule for updating beliefs whenever evidence does not determine exactly which state of the world obtains—call this "uncertain evidence."
(2) Any actual observation is logically compatible with infinitely many partitions of the possibility space.
(3) So for any single observation, I can apply Jeffrey conditioning using partition P and get one posterior, or using partition Q and get a different posterior.
(4) Rational belief revision requires that the same total evidence yield a uniquely determined rational posterior.
(5) But Jeffrey conditioning is the only non-arbitrary update rule for uncertain evidence: standard Bayes requires knowing exactly which event occurred, which is precisely what ambiguous evidence withholds.
(6) Therefore, whenever evidence is genuinely ambiguous, rational belief revision is impossible.

This feels like it proves too much—ambiguity shouldn't annihilate rationality altogether. I think the slide is somewhere between saying that infinitely many partitions are "compatible with" the observation and saying that all of them are equally licensed for Jeffrey conditioning, but I can't name the mistake precisely. I'd prefer to keep the uniqueness requirement in (4) and the special status of Jeffrey conditioning in (5) if possible, but I'm willing to drop either if that's where the damage is.

Please answer in exactly these sections, in this order:
1. The weak link: identify the failing step and state the error in one or two sentences.
2. Why it looked unavoidable: explain why a formally minded reader would naturally accept that step, especially given the logical structure of partitions.
3. The price of repair: describe the standard defense—whether it restricts Jeffrey conditioning to an evidentially selected partition, weakens uniqueness, or something else—and clearly state what must be sacrificed.
4. Bottom line: in about three sentences, say whether the argument can be patched or must be abandoned, and note the most awkward commitment of the view that survives.
