(1) Einstein's field equations are generally covariant: if (M,g,Φ) is a solution, then so is (M,d*g,d*Φ) for any smooth diffeomorphism d.
(2) Choose d that's the identity everywhere except inside a region H with no matter, where it smoothly permutes the points.
(3) Outside H both solutions agree exactly; inside H they assign different metric values to the same manifould points.
(4) So if those points have intrinsic real identity, GR can't determine what's inside H from all data outside—radical indeterminsm.
(5) Therefore point-realism is false; what's real are just the field patterns, with no underlying 'where'.
(6) But fields are literally functions that need a domain of points; deny the points and you deny the fields, so the mathematical framework of GR collapses.
(7) Meanwhile if we keep the points we get the underdetermination from (4), meaning GR describes not one world but an equivilence class of worlds.
(8) A real physical theory should pick out the actual world, not just an equivalence class, so GR fails as physics unless we accept point-realism, which makes it indeterministic.
(9) Hence GR is incoherent if we reject points, and empty if we keep them.

He also said gauge theories in particle physics avoid this problem because only the fiber-bundle internal spaces are redundant, while the base manifold stays fixed—so spacetime location is never gauge-redundant. Is that saving GR, or is he smuggling a hidden premise about what counts as physical?
