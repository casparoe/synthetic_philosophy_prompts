Presentism holds that only present objects exist, so Caesar doesn't exist now. To save past truths, presentists invoke Lucretian properties—present features of the world like being-such-that-Caesar-crossed. These ground actual past-tense statements without requiring Caesar himself to exist now, so bivalence is kept intact. For counterfactual pasts, they can use the same properties but in a modal form: being-such-that-if-Caesar-hadn't-crossed-then... This is sometimes called the dynamic-present strategy, where presentness shifts like a spotlight across an underlying four-dimensional manifold. Presentists deny that manifold exists, but the strategy still works because the properties are instantiated right now. Because these properties depend on Caesar's actual past action, presentists implicitly accept that Caesar retains a kind of derivative existence within the present world-structure, though not as a concrete object. So they avoid eternalism but still let past events constrain present properties, even for counterfactual ones.
