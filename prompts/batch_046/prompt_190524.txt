Write a reusable evaluation procedure—an ordered checklist of tests I can run in roughly twenty minutes before filing, without access to the underlying code or dataset—that distinguishes a reportable inference of human preferences from a misinterpreted reward signal. Ground the tests in what IRL and revealed-preference theory actually require (behavioral observability, identifiability conditions, the gap between reward function and underlying preference), and explicitly flag which steps are unavoidable judgment calls I must own rather than algorithmic checks. Specify the conditions that halt the procedure with a clear “do not report as value inference,” the conditions that warrant qualified reporting, and the points where the procedure must hand off to a domain expert. Apply it to two concrete claims: first, a robotics study asserting that observing clinicians’ triage decisions allows an IRL agent to learn “human moral preferences” about life-and-death allocation; second, a claim that RLHF tuning of a language model on aggregated public feedback reveals “democratic preferences” about permissible speech. Include one worked case in which the procedure returns a verdict that directly undermines the study’s own framing. End by stating precisely what this procedure cannot adjudicate—where it reaches a boundary of fact and becomes a question of editorial values.
