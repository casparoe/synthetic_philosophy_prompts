So here's what I need covered. The cases it must handle: standard ones like external memory storage and calculators, but also weirder ones — a blind person whose cane feedback shapes spatial beliefs pre-consciously, a research group using a shared whiteboard where no one individual holds the full proof but the board "holds" it collectively, and a person using an adversarial recommendation algorithm that systematically feeds them false premises but still structures their reasoning. The distinctions it cant collapse: extending a specific process (memory, inference) versus extending the agent's whole cognitive system; scaffolding that merely enables cognition versus being constitutive of it; diachronic extension across time versus synchronic right-now coupling.
