Functionalism says mental states are defined by causal role, not physical stuff, so the cluster counts as one mind as long as the roles stay intact. Mulitple realizability backs this up because it proves mental states can live on silicon, and here they live on lots of silicon at once. The node-swapping is basically Ship of Theseus, but functionalism cares about organization, not parts, so that objection misses. Block's Chinese Nation experiment actually demonstrates this: he showed that if you organize a billion people to match a brain's functional graph, the result is clearly conscious, which means spatial distribution and substrate turnover don't matter at all. Putnam's Turing-machine functionalism is already substrate-independent by design, so he'd clearly accept node replacement. Some people worry about latency between nodes breaking causal integration, but if the state-transition table is identical then the causal relations are identical by definition, so there's no gap. The only real issue is whether there's a single center, but functionalism never required a center, only correct transitions. So yes, it's one mind.
