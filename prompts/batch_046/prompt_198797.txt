The conclusion is that the reasoning predicts its own failure with certainty, which strikes me as absurd, and I need help locating the slip.

Here is the argument:

(1) In Hofstadter's Platonia dilemma, N agents each prefer that exactly one sends a telegram; cooperation is forbidden. By symmetric reasoning about symmetric reasoning, each rational agent should send with probability 1/N.

(2) The Luring Lottery, as played by Scientific American in the 1980s, extends this structure: agents submit entries into a pool divided among all entries, and superrational agents should calibrate their submissions to match the expected submissions of others, producing a reflexive equilibrium.

(3) Now consider a nested "Meta-Platonia" structure: there are N groups, each containing N agents. Within each group, the Platonia rule holds—exactly one internal message wins a local prize. Between groups, a Luring Lottery applies—the global prize is divided by the number of groups that sent at least one message.

(4) A superrational agent must therefore make two linked decisions: whether to send an internal message (probability 1/N), and whether her group should enter the inter-group pool.

(5) The inter-group decision depends on her belief B about how many other groups will have exactly one internal sender. By symmetry, every agent in every group runs the same reasoning, so B equals N multiplied by the internal success probability 1/N, hence B = 1.

(6) Given B = 1, each agent concludes that the expected number of competing groups is one, so she should apply the Platonia rule at the group level and enter the global pool with probability 1/1 = 1.

(7) Consequently every agent sends an internal message, every group enters the lottery, the internal prize is destroyed (each group sends N messages), and the global pool is divided by N², leaving each group with essentially nothing.

(8) Thus, applying superrational reasoning consistently across nested structures predicts with certainty its own failure: it mandates universal action that annihilates the conditions for success.

(9) Therefore, superrationality is self-defeating whenever collective-choice structures are nested, and must be rejected as a general rational principle.
