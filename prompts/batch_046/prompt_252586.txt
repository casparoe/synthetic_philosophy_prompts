I have recently been asked to draft ethical guidelines for an advisory board that relies on idealised preference aggregation, so the following objection has become personally urgent. Here is an argument that seems to show coherent extrapolated volition (CEV) collapses pluralism into a single corrected will and therefore undermines the autonomy it claims to respect.

(1) CEV requires that we extrapolate each person's preferences to a state of full information, logical coherence, and reflective equilibrium.
(2) If two agents have reached full coherence and possess complete information about the same normative domain, then any remaining disagreement must be due to a factual or logical error in at least one agent, because genuine normative truths do not vary by subject.
(3) Therefore, under genuinely ideal conditions, all rational agents converge on exactly the same volition.
(4) But if CEV aggregates these convergent volitions, it is not accommodating distinct values; it is merely repeating an identical preference ordering across a population.
(5) Hence CEV provides no mechanism for irreducible value pluralism, treating all disagreement as a cognitive defect to be corrected rather than a legitimate difference to be negotiated.
(6) Yet if pluralism is merely an illusion produced by ignorance or incoherence, then imposing CEV on a population is not respecting autonomy but substituting a single corrected will for many.
(7) So either CEV is incoherent as an ethical framework, or it secretly presupposes a robust normative realism that eliminates the very autonomy it promises to honour.

Where does this argument go wrong? Which step should I reject, and what does giving it up cost? If I must choose, I should prefer to keep (1) and (5), since both the coherence requirement and the importance of pluralism are central to my advisory work; but I want to know precisely what I pay if I instead abandon (2) or (4).
