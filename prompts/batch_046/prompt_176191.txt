I'm drafting a novel about archives that never end, and Borges's Library of Babel keeps coming back to me — all those hexagonal galleries with every 410-page combination of letters. I want to read it through Russel's paradox and the failure of naive set theory, but not as some vague metaphor for infinity. Here's the twist I'm stuck on: if the Library truly holds every possible book, there must be a catalogue-book that lists every volume that does not mention itself. Once that catalogue exists inside the Library, it hits the exact contradiction Russell found — it should list itself if and only if it doesn't. Borges never writes about catalogues, but the claim that all books exist there seems to smuggle in the very totality that naive set theory cant hold. Does the story break under that pressure, or does Borges's silence on self-reference save it? I need this for a writing workshop, so I'd love an answer in British English that takes both the fiction and the logic seriously — where they illuminate each other and where one just has to admit defeat.
