i've been trying to think through the insect sentience problem for a course discussion, and i'm stuck between two ways of framing the numbers. The first is the classic scale argument: at any given time there might be ten quintillion insects alive, so even if the probability that any individual insect has a unified phenomenal field is tiny — say, one in a thousand — the expected moral weight across the whole population is still enormous. The second framing is something i only saw mentioned once in an obscure ethics forum, which i'll call the 'disjunctive capacity view': moral patienthood isn't a continuous property that aggregates linearly across individuals, but rather depends on whether an organism possesses a specific structural feature — maybe a minimal global workspace or an integrated self-model — that makes suffering *belong* to a subject. If that feature is absent, then multiplying the organism by a trillion doesn't create a trillion partial subjects; it just creates more things that fall outside the scope of moral concern entirely.

Compare these two frameworks, especially on how they handle aggregation. Does the scale argument treat sentience like a lottery ticket where expected value logic applies straight across, and is that a category mistake when we're talking about moral subjects rather than risk pools? And if we defend the disjunctive view, aren't we just picking a neuroanatomical marker that happens to match vertebrate brains and declaring it the magic line — which might be just as arbitary as saying insects don't count because they're small? I want to know which one actually survives pressure on the aggregation logic, and what each view has to pay if it turns out wrong.
