I sit on the funding-review board of a long-range science foundation. Every quarter we evaluate proposals that invoke observer-count arguments—claims about how many minds, civilizations, or conscious observers exist in a specified reference class—to justify resource allocation. These arguments often slide between treating our existence as a random draw from an actual reference class (the self-sampling assumption) and treating our existence as evidential weight in favor of larger populations (the self-indication assumption), and some fall into the presumptuous-philosopher trap: using self-indication to privilege a reference class in which philosophers are rare, thereby undermining the very reasoning that produced the conclusion. I need a reusable decision procedure—ordered checks in flowchart form—that my board can run in about thirty minutes per proposal. The board includes scientists and policy analysts but no professional philosophers; the procedure must specify, at each step, the exact question to ask, what counts as a sufficient answer, where it stops with a recommendation to approve, reject, or defer, and where it must hand the decision to a human because the issue is one of values rather than logic. Include explicit tests for identifying which anthropic assumption is in play, for detecting the presumptuous-philosopher circularity, and for verifying that the reference class is properly closed—no hidden observer-selection effects from populations outside the class that the proposal ignores. Apply the procedure to three proposals: (1) a SETI initiative arguing that, because technological civilizations are not observed, they must be rare, and funding should shift to biosignature searches; (2) an existential-risk study arguing that, because the observer exists, reference classes with more observers are more likely, so future populations should receive heavy weight in cost-benefit analysis; and (3) a neuroscience grant arguing that, because conscious brains are common in evolutionary history, human consciousness is likely not unique, justifying large-scale brain-mapping. For the second proposal, the procedure should yield an answer the board will likely find unwelcome—probably that the reasoning fails its own consistency check—and you should flag precisely where judgment must take over. Finally, state clearly what the procedure cannot settle, where it is prone to misfire, and which distinctions it deliberately simplifies away.
