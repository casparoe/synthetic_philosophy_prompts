Here's one answer, from a junior data scientist:

The physical stance is just GPU voltages and matrix math, so it predicts errors only if there's a hardware glitch, not for wrong chemistry facts. The design stance looks at the transformer architecture and loss function, so it explains the errors as statistical correlations in training data being optimized wrong. The intentional stance treats the model like an agent that wants to help and actually believes its answers, so you'd predict mistakes when its beliefs are false. Dennett says patterns are real if they help prediction, so because the intentional stance predicts the LLM's chat outputs well, the model literally has beliefs — they're real patterns, same as human beliefs. Therefore the model's knowledge is real just like ours, since both are useful predictive patterns.
