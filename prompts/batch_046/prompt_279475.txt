I'm trying to identify and name a recurring structure in strategic-reasoning puzzles. In one case, every agent knows that every other agent is rational, knows that they know, and so on indefinitely; yet coordination collapses because each agent suspects the others all share an identical, unnoticed simplification of the payoff rules. In a second case, coordination succeeds only because all agents share that same simplification — they stabilize on an equilibrium that exists solely within the mistaken frame, so that if the true rules diverged even slightly, the fully intact chain of rationality attributions would no longer produce convergence. This is not an ordinary breakdown of common knowledge, since the iterated rationality beliefs remain perfect; rather, it is common knowledge of rationality enclosed within a shared, unexamined representational frame. Is there an established concept in epistemic game theory that captures this — for instance, a framing-correlated variant of almost common knowledge — and if not, how should the phenomenon be precisely distinguished from mutual misunderstanding, from standard correlated equilibrium, and from failures in which rationality itself is doubted?
