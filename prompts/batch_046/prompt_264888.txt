I've been revisiting Hofstadter's distinctions in Gödel, Escher, Bach between frame messages, outer messages, and inner messages, particularly where he considers how a formal system can be about itself without that self-reference being explicitly present in the frame message. I'm trying to pin down the conceptual boundary between an outer message that merely describes a system and an inner message that is genuinely instantiated by the system's formal properties—especially in cases where the reader is part of the system being described.

The frame message is just the syntactic rules; the outer message is the claim about self-interpretation limits; and there seems to be an inner message in the isomorphism between the proof's structure and the text's grammar. But here is the knot I keep hitting: if an artificial agent parses the frame message using only its syntactic parser—without the cultural and cognitive framing that lets human readers recognize the structural echo—does the inner message exist for that agent at all? Or is the inner message necessarily relational, existing only in the gap between the formal properties of the text and the interpretive capacities of a specific kind of reader?

If it's the latter, does that collapse the distinction between outer and inner messages, since the outer message also requires an interpreter? And if it's the former, how do we avoid attributing semantic content to a purely syntactic object, which seems to be exactly the move Hofstadter warns against when he discusses whether a book could be conscious?
