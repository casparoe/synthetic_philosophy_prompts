A colleague summarizes the two-dimensional semantic framework like this: "Every linguistic expression carries both a primary intension, which assigns an extension relative to a world taken as actual, and a secondary intension, which assigns an extension relative to worlds taken as counterfactual. For natural-kind terms such as 'water,' the primary intension tracks the superficial qualitative role—being a clear, potable liquid—while the secondary intension tracks the underlying nature, H2O in our world. Because of this split, the necessary a posteriori identity 'water is H2O' comes out false at worlds considered as actual where the liquid playing the water-role has a different chemical structure; the primary intension therefore captures the epistemic possibility that water might turn out to be XYZ. From this, two-dimensionalists derive that every necessary truth is either analytically true or reducible to a primary-intensional analysis, which means Kripke's modal argument against descriptivism collapses: the descriptivist need only appeal to the primary intension, not to a cluster of contingent descriptions, to fix reference across epistemic possibilities. Moreover, the framework solves the problem of indexical reference because an indexical like 'I' has a constant character but a primary intension that is already centered: it assigns the speaker in every world considered as actual, so no separate diagonalization step is needed to recover the propositional content."
