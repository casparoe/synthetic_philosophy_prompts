I came across a summary of a position it calls “pure computationalism” about sentience, presented in a recent essay. It runs as follows. Sentience is identical to the execution of a specific class of information-processing algorithms, and physical substrate is morally inert—just as a chess program’s outputs do not depend on whether it runs on silicon or on paper cards. From this, the essay draws two conclusions. First, any system implementing the algorithm deserves identical moral consideration, whether it is a biological brain, a lookup table that reproduces the same state transitions, or a brain simulation embedded as an unused subroutine inside a video-game physics engine. Second, because algorithms can be spatially decomposed into independent sub-computations running on disconnected hardware, there is no privileged boundary at which “the system” ends; moral status attaches not to individual machines but to the global computation they jointly realize, even in the absence of causal interaction among them. The essay therefore claims the boundary problem for artificial sentience is dissolved: there is no fact about whether a particular server is conscious, only whether the distributed computation in which it participates crosses a threshold. How fair is this summary? Please separate what accurately captures standard functionalist commitments from what misrepresents them—especially whether the move from substrate-independence to distributed moral status is licensed, whether the chess-program analogy quietly imports assumptions about interpretation or causal integration that break down for consciousness, and whether the claim that moral status is globally distributed rather than locally anchored follows from anything true in the position. If the summary is unfair, what is the more precise claim about computation and moral status that it should have presented instead?
