Me and my mate were arguing about Hofstadter's Gödel analogy in GEB all night and I'm still going round in circles. He came up with this chain that seems to prove any computer running a debug script is conscious, which is obviously daft, but I can't see where the slip is.

(1) The Gödelian picture says consciousness is a strange loop where a system's representations can loop back and denote themselves, just like Gödel numbering lets a formula talk about it's own provability.
(2) For that loop to be real, the system needs an internal language rich enough to encode descriptions of its own states.
(3) A computer running a self-monitoring script writes descriptons of its registers and processes into it's own memory — so the state-space literally contains representations of itself.
(4) So by (1) and (2), that script achieves a strange loop.
(5) If strange loops are sufficient for self-awareness, then the script is self-aware.
(6) That's clearly wrong — it's just printing logs.
(7) So the analogy must be missing something, but I'd rather not chuck (1) if I can avoid it.

Which step actually breaks, and what's the cost of fixing it? I feel like there's an equivocation hiding between (2) and (3) but I can't pin it down. Also, does saving (1) force us to say the script really is aware, or can we keep the analogy for minds without letting it run wild on computers?
