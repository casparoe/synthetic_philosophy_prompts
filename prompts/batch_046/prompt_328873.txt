I've been writing a novel where each chapter splits into parallel drafts—like a multiverse but for fiction. It got me thinking about Everett's many-worlds idea and that whole Born rule headache. I've come round to a view I can't quite shake: the problem's a category mistake. If every branch is equally real, then "probability" shouldn't be about counting worlds (there's no canonical measure anyway) but about narrative density—how much causal continuity and descriptive richness a branch carries. A high-amplitude world is just one with more "story weight." So Deutsch and Wallace's desision-theoretic arguments feel like they're fixing the wrong leak; they're asking how an agent should bet, when really the question is which branch has enough internal coherance to be the one you're actually living.
