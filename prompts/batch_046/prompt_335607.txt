I've been arguing with my roomate about whether actual infinities are really ontologically serious or just a convenient fiction we use in math, and I think I've stumbled onto this middle-ground view I'm tentatively calling "structured potentialism" (probably not original, but I haven't seen it spelled out exactly this way). The core claim is that infinite sets do exist as completed totalities—so Cantor's diagonal argument genuinely shows the reals are uncountable within its domain—but only relative to a fixed background framework. Hilbert's hotel only feels paradoxical because we illicitly import finite intuitons about occupancy, vacancy, and one-to-one matching across framework boundaries. So finitism is wrong, but not for the usual reasons: it treats the boundaries of whatever framework we're in as metaphysically absolute, as if there's some cosmic cap on cardinality. I'm not fully sold on this though. Play it straight: what would have to be true for structured potentialism to collapse? I want more than just "Hilbert's hotel is counterintuitive"—I'm asking which formal results in cardinal arithmetic, which readings of Cantor's theorem, or which commitments about framework-relativity would actually damage it. Would defenders have to concede defeat if cardinal comparison turned out to be framework-invariant in every case? Is there a hidden slide into modal realism that makes the view unstable? Rank the defeaters from fatal to merely awkward, and flag which ones a committed structured potentialist would admit are real problems versus which they'd dismiss as just missing the point about framework dependence.
