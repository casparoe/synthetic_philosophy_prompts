As a software engineer with no formal philosophical training, I have been trying to understand the debate between Cantorian actual infinities and finitism, particularly in light of Hilbert’s hotel. I have constructed the following argument, which seems to show not merely that actual infinities are impossible, but that if they existed there could be only one object in total. I find that conclusion absurd, yet I cannot see which step fails. The argument runs as follows:

1. Hilbert’s hotel shows that if there are countably infinitely many guests, every guest can be moved from room n to room n + 1, freeing room 1 for a new arrival.
2. After the shift, the set of occupied rooms stands in a perfect one-to-one correspondence with the original set.
3. By Cantor’s definition, sets in one-to-one correspondence have identical cardinality.
4. Therefore adding a genuinely new guest does not increase the cardinality of the collection.
5. If introducing a distinct entity into a collection leaves the collection’s size unchanged, then that entity was not ontologically distinct from those already present—otherwise the total would have grown.
6. The same applies to removal: taking one guest away also preserves cardinality, so no particular member is indispensable to the collection’s magnitude.
7. Consequently, within any actually infinite collection, no member is genuinely distinct from any other, and none can truly be added or subtracted.
8. But if a collection contains no genuinely distinct members, it is not a plurality at all, but at most a single object.
9. Hence, if actual infinities exist, multiplicity is an illusion and there can be at most one thing.
10. Since we plainly encounter many distinct things, actual infinities must be impossible; Cantor’s infinite sets can only describe potential, never completed, totalities—much as a lazy stream in programming can generate values indefinitely without ever constituting a fully realised infinite array.

I would most like to preserve the intuition that there is a real difference between a potential process (like an unbounded loop) and a completed infinite totality, and that the latter violates some version of the part-whole principle. Which premise or inference should I reject? Please explain why that step initially looked plausible, and then price the alternatives: what does a finitist have to pay to reject it, what does a Cantorian have to pay, and does either view need to abandon the part-whole principle altogether?
