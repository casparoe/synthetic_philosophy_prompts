hey, been reading these forums for years and theres this one failure mode i keep seeing in embedded-agency type discussions that i dont have a name for, and its not just "people being sloppy about system boundaries."

heres the pattern. someone models an agent - usually an AI - and draws a hard line around it. then a commenter points out the line is fake: the agent's actions change the environment that feeds back into its sensors, so the box has to expand to include that loop. people agree and redraw it. but then another commenter notes the agent's weights are updated by a training pipeline sitting outside the old box, so now the box swallows the pipeline. then maybe the pipeline designers are influenced by market incentives or cultural norms, so the box expands again. each expansion is justified by a specific paradox - like "if the reward function is inside the box then the agent can wirehead it" - but nobody ever stops and asks where the box should actually end. they just slide the boundary around like a zoom lens to avoid whatever problem is currently in frame.

ive seen this in at least three different threads about AI alignment and one about rationalist decision theory. its not the standard embedded-agency point, which is just "agents are inside the world they act on." this is specifically about analysts using the boundary as a movable rhetorical shield: whenever an objection hits, they enlarge the system to absorb it, but they never commit to a final boundary, so every analysis ends up being "well, if you include X then..." without saying what X is.

is there an established concept for this exact move? if there is, how is it different from ordinary system-boundary ambiguity and from actual self-reference paradoxes? and if there isnt, can we name and define it with clear edges - like, what counts as sliding the box versus just refining a model? i dont need citations, just want to know if im describing something real or if im just tired lol.
