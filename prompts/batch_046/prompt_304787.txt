I've been thinking about the leveling-down objection to prioritarianism—the worry that if we should prioritize the worse-off, then we might have reason to make everyone equally badly off rather than help only some people. The standard reply is that prioritarianism gives extra weight to benefits but never requires harm, so dragging everyone downward is never justified. But I think this reply assumes that "being worse off" is measured along a single scale, like welfare or resources. In many real allocation problems—say, distributing a fixed health budget—there are actually two different dimensions at once: how badly off someone is in absolute terms, and where they stand relative to everyone else. I want the proposal to ask whether the leveling-down objection revives if prioritarian weights are applied to relative rank rather than to absolute welfare. If being tied for worst rank is what counts, then equalizing everyone downward might satisfy prioritarian concerns instead of violating them, which the standard defense doesn't address because it never separates the two axes.

The proposal should state that question precisely, explain why existing answers leave it open—namely that they conflate absolute deprivation with relative position—then describe the approach: constructing a conceptual model with separate axes for absolute welfare and relative rank, testing allocation rules on each, and seeing whether the "no harm" defense survives when rank is the target. It should say what a useful result looks like—either a reconstructed objection for rank-based prioritarianism or a principled argument that the axes must be merged—along with an honest failure condition, such as the distinction collapsing under pressure or the model proving incoherent. The scope should be realistic for one semester: a single 5,000-word conceptual paper with formal examples but no empirical data, restricted to one clear formulation of prioritarianism rather than a full survey.
