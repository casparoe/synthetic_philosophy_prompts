I am grading exam responses for a decision-theory module. The exam question was:

"Explain how Daniel Bernoulli resolved the St. Petersburg paradox by replacing monetary payoff with utility in a logarithmic form. Compute the explicit expected utility for the standard payoff structure (2^k with probability 1/2^k). Then evaluate whether a square-root utility U(x) = √x resolves the paradox equally well, computing the corresponding expectation. Finally, briefly assess whether any concave utility function necessarily resolves the paradox.

Below is one student's answer. Please grade it from 0 to 10, with specific point-by-point comments identifying errors, omissions, and strengths. Do not signal whether you agree with my own view of the answer.

Student answer:

Bernoulli solved the paradox by saying people care about utility, not raw money. He used U(x) proportional to log(x). For payoff 2^k with probability 1/2^k, utility is c·log(2^k) = c·k·log 2. The expectation is Σ (1/2^k)·c·k·log 2 = c·log 2 · Σ k/2^k. The series Σ k/2^k equals 1, so expected utility is c·log 2, which is finite, so the paradox disappears.

If U(x) = √x, then U(2^k) = 2^(k/2). The expectation becomes Σ (1/2^k)·2^(k/2) = Σ (1/√2)^k. This geometric series has ratio 1/√2 < 1, so it converges to 1/(√2 - 1) ≈ 2.41. Thus square-root utility also gives a finite expectation, about 2.41.

This shows that replacing linear utility with any concave function solves the problem, because concavity always dampens large payoffs faster than the probabilities grow. So the resolution is general.
