Question: Recent discussion frames Einstein’s 1913 hole argument not as a general threat to determinism, but as a targeted attack on one specific form of manifold substantivalism—namely, the view that bare manifold points carry metric properties essentially and independently of fields. In about 250 words, explain the argument’s structure, identify precisely which version of substantivalism it threatens, say why relationalism about space and time is not equally undermined, and assess whether modern fiber-bundle formulations of general relativity (in which the metric is a section over a base manifold) escape the argument or merely relocate the gauge problem to the bundle’s vertical automorphisms.

Student answer: Einstein’s hole argument begins with a region of spacetime—the “hole”—in which the stress-energy tensor vanishes. Because the Einstein field equations are generally covariant, applying an active diffeomorphism that fixes all points outside the hole but shifts those inside generates a second solution. This new metric assigns different curvature values to the same bare manifold points within the hole, while leaving the matter distribution everywhere unchanged. If those points possess their metric properties essentially, then the physical state outside the hole fails to determine the state inside, violating determinism.

The argument targets manifold substantivalism: the doctrine that spacetime points exist as independent entities that can bear geometric properties in their own right. It does not threaten relationalism, because the relationalist denies bare points altogether and recognizes only spatiotemporal relations among bodies and fields; both metric solutions represent the identical relational structure.

Einstein initially abandoned general covariance in light of this result, but later restored it through the point-coincidence argument, which holds that only the intersections of material worldlines are physically observable. He called the principle that diffeomorphism-related models describe one and the same physical situation “Leibniz equivalence.” Contemporary sophisticated substantivalists accept this equivalence without discarding points: they treat the manifold as a bare scaffold over which fields are defined, so that only the field values carry physical content. Even in fiber-bundle formulations, where the metric is a section over a base space, the same resolution applies, since the bundle’s vertical automorphisms allow the gauge identification that removes the apparent indeterminism. Consequently, the hole argument compels the substantivalist to adopt gauge equivalence, but it does not establish relationalism.
