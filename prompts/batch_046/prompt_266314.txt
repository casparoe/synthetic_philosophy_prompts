Given Wittgenstein’s family-resemblance account—where “game” and “language” form networks of criss-crossing similarities without any shared essential feature—some interpreters model this as a topology in which each speech-act is a node and resemblance-relations are edges with no central hub. From this it seems to follow that a particular language-game, such as “giving orders,” lacks internal normative structure: if the cluster has no core defining rule-set, then misusing a word looks like moving to a neighboring node rather than breaking a rule within the same game. How, then, can Wittgenstein consistently claim that using a word incorrectly is an error inside the game rather than playing a different one? Or does the family-resemblance thesis actually undermine the idea of rules within a game? Answer in one paragraph, no more than 130 words.
