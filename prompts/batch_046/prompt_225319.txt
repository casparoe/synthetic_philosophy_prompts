I just spent the better part of an evening arguing with a friend about disjunctivism and the argument from illusion, and I realized we were essentially replaying a debate I had overheard months ago between two philosophers. I want a neutral adjudication of that earlier exchange, reported below as faithfully as I can.

Person A (Maya) and Person B (Jonas) were discussing whether disjunctivism can answer the argument from illusion without collapsing into representationalism. Here is the back-and-forth.

(1) Maya said the argument from illusion assumes that a veridical perception and a subjectively indistinguishable illusion must share an intrinsic phenomenal property—a common mental kind. Disjunctivism denies this: in the veridical case, consciousness is constituted by a direct perceptual relation to the object and its properties; in the hallucinatory case, there is no such relation, so the mental event belongs to an entirely different category. Therefore the premise of shared mental kind is false, and the argument collapses.

(2) Jonas replied that even if there is no shared mental kind, the disjunctivist still owes an account of subjective indistinguishability. If the two states are genuinely different in kind—one relational and object-dependent, the other not—then there should be some introspective difference available to the subject. Since there is none, disjunctivism makes the illusion of sameness inexplicable. Representationalism explains it neatly: both states share the same representational content, which is false in the bad case.

(3) Maya countered that Jonas was smuggling in a uniformity thesis—the assumption that all perceptual consciousness must have the same internal structure regardless of its object. She proposed instead that the hallucinatory state has a derivative phenomenal character: not a copy or replica of the veridical state, but a structurally similar failure mode produced by cognitive architecture that mimics the success mode without replicating its ontology. The subject cannot discriminate not because the experiences share a phenomenal core, but because the failure mode is designed to approximate the success mode from the inside, like a shadow that resembles the object without being it.

(4) Jonas said that Maya's mimicry relation is just the common factor in disguise. If the bad case is a failure mode designed to approximate the good case, then the approximation itself—the shared structural feature—is doing all the explanatory work. Furthermore, Maya still hasn't accounted for what it is like in the bad case: if there is no object present and no shared representational content, then either the bad case lacks phenomenal character altogether (which is implausible) or it possesses a phenomenal character genuinely identical to part of the good case (which concedes disjunctivism). So disjunctivism is either incomplete or collapses back into a common-factor view.

Please adjudicate this exchange move by move: rate each of the four moves from clearly mistaken to clearly right and briefly justify each rating. Then say which party, if either, is right about the core issue, and identify anything important that both are missing—perhaps a hidden premise they share, a way to split the difference, or a conceptual distinction they have overlooked.
