hey, i'm drafting an essay on why Occam's razor is often misapplied to neural nets. people say smaller models recieve a better prior under Solomonoff induction because they have lower Kolmogorov complexity. but i think that's conflating the program with its output. the weights aren't the hypothesis - they're the state reached by running the training program. so the true description length should be the training code + architecture config + seed, not the paramter count.

i sketched a quick comparison: quantize the weights to 4-bit, gzip them, and compare that size to the gzip size of the training script. for some large LLMs the weights only compress to about 30-40% of original, which still sounds huge, but the script is tiny. so maybe a 70B model with very regular weights actually has lower effective Kolmogorov complexity than a 7B model with chaotic weights that barely compress.

my questions: is this distinction already obvious in the philosophy-of-ML literature and i'm just late? does it change anything about generalization bounds, or is it a category error? and if we took it seriously, should we be comparing models on weight-compressibility rather than param count?

there's probably an error in how i'm treating the universal prior, and i might be mixing up data compression with algorithmic information. feel free to tear it apart.
