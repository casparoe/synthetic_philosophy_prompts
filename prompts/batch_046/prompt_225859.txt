Strawson's Basic Argument has three steps: (1) nothing can be causa sui, (2) therefore you can't be responsible for your nature, (3) but you're responsible for actions only if you're responsible for the nature that caused them. So true moral responsibility is impossible. The key is that any attempt to change yourself just expresses your existing character, so the regress never bottoms out.

If we imagine a recursive self-modification module built into cognition, where an agent can adjust the weights it gives to different reasons, this might look like a way out. The agent uses the module to adopt a new character that then endorses the revision. But this fails: the decision to activate the module, and the rules it uses, are still part of "the way you are." So the module doesn't make you causa sui; it just pushes the determinism back one level. Therefore the Basic Argument stands, and any view — like Frankfurt's hierarchical compatibilism — that thinks self-revision creates responsibility is mistaken, since Frankfurt never addresses the initial design of the hierarchy.
