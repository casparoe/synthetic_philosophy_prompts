I'm looking for the established term, if there is one, for the following failure mode in arguments about idealized preference. A defender claims that if agent P were fully informed, consistent, and reflective, P would choose outcome O. When a critic notes that full reflection might also reveal side-effects of O that P's values condemn — say, harm to others that an unbiased P would weigh heavily — the defender does not revise the prediction. Instead, they partition P's idealized psychology into a core preference that retains O and a peripheral adjustment mechanism that absorbs the side-effect concerns, but they calibrate the boundary so that the core always prevails on the main decision. The speaker often gives independent reasons for why that particular preference belongs to the core, so this is not bare circularity. Yet the structure seems to immunize a first-order intuition against exactly the kind of second-order revision that the idealization was supposed to enable. Does this have a recognized name in discussions of coherent extrapolated volition, reflective equilibrium, or ideal-observer theories? If there is no specific term, can you define it precisely and distinguish it both from ordinary value-weighting and from the motte-and-bailey retreat to a weaker claim?
