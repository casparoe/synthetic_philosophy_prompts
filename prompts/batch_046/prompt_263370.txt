A friend is trying to corner program equilibrium and I cannot find the gap. (1) In program equilibrium each agent submits a computable strategy that takes the other agents’ actual submitted programs as inputs and returns an action. (2) If two programs are extensionally equivalent—identical outputs for every possible input—then swapping one for the other cannot alter any payoff, because payoffs depend only on the actions eventually played. (3) So strategic evaluation should depend only on extensional behavioral profiles, not on internal syntax or implementation. (4) If that is true, then any agent can replace her strategy with a constant program that ignores its inputs and plays a fixed Nash strategy of the underlying game. (5) Therefore the set of program-equilibrium outcomes should coincide exactly with the Nash-equilibrium outcomes. (6) But the concept is supposed to allow cooperation in the one-shot Prisoner’s Dilemma through “fair” programs that cooperate precisely with syntactically identical copies of themselves—something Nash forbids. (7) So either the cooperative result is illusory and program equilibrium is just Nash in richer notation, or intensional syntax does matter after all. (8) Yet if syntax matters, then rational choice requires agents to inspect and condition on the literal source code of others’ minds, which seems to demand impossible epistemic access—especially for bounded agents—so the concept applies to no real decision-maker. (9) Hence program equilibrium either proves nothing beyond standard game theory or proves that rationality requires omniscient code inspection. Which step should I reject, and what does rejecting it cost—does it save the cooperative result only by making the equilibrium concept descriptively empty, or is there a middle path? I would most like to keep both the idea that syntax can matter strategically and the idea that the concept remains applicable to bounded agents.
