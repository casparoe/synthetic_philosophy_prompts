Here is an argument about cross-cultural moral psychology that seems to collapse the very reasoning it relies on. (1) Cross-cultural work shows that WEIRD populations organize morality almost exclusively around harm and fairness, whereas many non-WEIRD populations treat loyalty, authority, and purity as central—sometimes overriding harm-based judgments about the same act. (2) If moral objectivity holds, then for any action there is a culture-independent fact about whether it is wrong. (3) Given (1), when cultures deliver incompatible verdicts—say, on whether failing to honor a dead ancestor is seriously wrong—at least one is objectively mistaken. (4) But there is no culturally neutral standpoint from which to adjudicate which framework is correct: any criterion we invoke—coherence, welfare outcomes, predictive success—already embeds the evaluative priorities of some particular tradition, often the WEIRD one. (5) So if moral objectivity requires an accessible, culture-independent adjudication procedure, then moral objectivity is false. (6) Apply the same reasoning to epistemic norms: different traditions weight testimony, revelation, and empirical replication differently, and some metaphysical frameworks treat contradiction as context-dependent rather than globally fatal. (7) By parity, if absence of culture-neutral adjudication undermines objectivity in morality, it should do so for logic, mathematics, and empirical reasoning too. (8) But if those are not objective, there is no objective basis for accepting the data in (1) or the inference rules in (5) and (7). (9) So the argument proves too much: it dissolves not just moral objectivity but the rational infrastructure needed to state it.
