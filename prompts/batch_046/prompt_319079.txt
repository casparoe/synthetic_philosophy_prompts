I'm in this course on cognitive architechture and we've been talking about Hofstadter's Letter Spirit project — you know, the one about how every 'a' is an 'a' despite wild style changes. I've kinda adopted this view that there is no intrinsic 'a-ness' at all, not even a family resemblance or a prototype in feature-space. Instead I think letter identity is purely relational: an 'a' is an 'a' only because it sits in a specific spot in a grid of stylistic diffrences that seperates it from 'b', 'c', 'd', etc. The actual curves don't matter as long as the relational distances are preserved — like, if you warp the whole alphabet together, every letter stays itself. So essence is just this network of diffrences, not any shape property.

What would actually count against this? I want the defeaters sorted from fatal to just awkward. Like, are there empirical results from letter-recognition studies or from people with visual agnosia that show we recognize letters by some intrinsic feature bundle rather than relational position? Or formal arguments that relational identity collapses into circularity — you need to know the letters already to build the grid? Also, if someone designed a single-letter alphabet or an isolated glyph with no neighbors, would it still be readable, and does that break the view? I'd also like to know whether defenders of this relational view (maybe Hofstadter himself?) would concede these as problems, or whether they'd just qualify the claim until it's unfalsifiable — and if they do insulate it, is that a real weakness or just good theory-building? Basically map out where this position is exposed.
