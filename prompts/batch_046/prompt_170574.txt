Hey, I'm a retired physicist who recenlty gotten into philosphy, so bear with me if this sounds a bit naive. I've been reading about pronatalism and the idea that we should have way more people, and I keep seeing this analogy: growing the population is like expanding a library, where each new person is just another book added to the shelves, so total value -- knowledge, art, experience -- scales up in a straight line. Proponents seem to use this to license the conclusion that a world with trillions is better than one with billions, assuming the shelves never run out. But coming from physics, that smells like treating value as an extensive property, like total mass or energy, when a lot of interesting quantities are non-extensive or depend on interaction terms. So can you audit the library analogy for me? I want the explicit mapping -- person to book, society to library, value to shelf content, resources to shelf space -- and then the breakdowns: do people suffer crowding like books on a cramped shelf? Does adding a "book" change the value of existing ones? What features of a real library (finite space, curation, noise) does the analogy quietly import? And if human value behaves more like entropy of mixing -- non-linear, maybe even negative at high density -- does the pronatalist conclusion survive? Also, is there a better analogy, maybe from ecology or network theory, that keeps the idea of more nodes but doesn't smuggle in linear scaling?
