Some city planning boards use a rule where every big development gets scored seperately on three things—ecological impact, heritage value, and how badly housing is needed—and the charter says you can't turn those into one number or weight them against each other. Instead each committee just votes 'respected' or 'not respected,' and a project dies if any one committee vetoes it but only passes if all three agree. I'm trying to figure out what philosophy of value is baked into that setup. Does it actually commit them to incommensurability, or could a pluralist who thinks values are comparable still run the same board? And if hard choices really are unavoidable—like you have to build somewhere—does the veto structure hide a secret aggregation, or does it genuinely preserve the idea that none of these values can be sacrificed for the others? Also, is this consistent with how those same boards usually approve emergency housing waivers that clearly trade heritage off for need? Reconstruct the implicit theory, say what's strictly presupposed vs what's just convenient, and tell me what would have to change in the procedre if we replaced the underlying view with a straightforward ranking model.
