My study group built this argument against virtue ethics and I think it overreches but cant spot the leak. (1) Virtue ethics needs moral traits that stay stable across situations. (2) Situationist experiments show people act honest in one context and cheat in another, kind to strangers but harsh to family. (3) So global traits like "honesty" or "kindness" dont exist. (4) Some virtue theorists retreat to local traits — honesty-in-exams, kindness-to-strangers — but a local trait is just a global trait with its domain restricted. (5) If the global version is empty, restricting its domain cant manufacture content; you cant have a restricted version of nothing. (6) So local virtues fail too. (7) But evolutionary psych talks about moral modularity — separate mechanisms for harm, cheating, purity — which look like domain-specific capacities. (8) If those arent virtues, theyre just causal mechanisms with no normative weight. (9) So situationism, if consistent, kills not just virtue ethics but any ethics that uses character-language, including virtue consequentialism and folk moral judgment. (10) But we clearly still praise and blame. (11) So situationism is false and global traits exist. Wheres the mistake? Id like to keep (2) and (9) if posssible, but Im open.
