Consider the strange-loop account of the self: "I" is not a substance but a self-referential symbol arising when a brain's representations loop back to represent the very system generating them. Now examine this argument.

(1) On this view, the reference of "I" is fixed entirely by the reflexive structure of the loop, not by any external anchor such as bodily continuity or privileged access to consciousness.

(2) Imagine a neural architecture — call it a dual-anchor loop — in which two representational subsystems, A and B, are each structurally self-referential: each generates a symbol that denotes "the system containing this symbol," and due to modular isolation neither subsystem can represent the other.

(3) By (1), both symbols satisfy every condition for being an "I": each refers back to the system that produces it, and neither's reference can be overridden by an external corrector, since there is no anchor outside the loop.

(4) So one brain contains two fully constituted selves.

(5) Yet both loops share a single body. If A initiates reaching left and B initiates reaching right, the result is not negotiation between agents but a single incoherent motion; there is no phenomenological experience of being two people.

(6) To block (4), one might reply that only the loop with dominant causal control over behavior counts as the true self.

(7) But dominance is an external, functional relation between loop and body, not part of the self-referential structure itself. Adding it means "I" is not merely the strange loop; it is the loop plus a privileged embodied role.

(8) Hence the pure strange-loop account either proliferates selves absurdly within one skull, or it must silently import the very embodied-functional criteria it was designed to replace. Either way, the claim that the self is nothing but a self-referential symbol proves too much.

I want to keep (1) and (2) intact — I think the loop really is the core of selfhood — but I cannot see which intermediate step is weakest without collapsing the whole picture. Which premise should I reject: the possibility of (2), the inference in (3), or the claim in (7) that functional dominance is external? What does giving up that step cost, and does it leave the strange-loop account intact or turn it into a disguised form of functionalism?

If this argument rests on a confused premise — for instance, if "dual-anchor loop" misconstrues how self-reference works, or if isolating the loop from all functional roles is incoherent — please say so plainly rather than repairing it politely.
