For a forty-minute session with philosophy first-years fresh from an introductory logic course, I need to teach Hempel's raven paradox not as an ornithological curiosity but as a fracture between logical equivalence and evidential support. Lay out the dependency order: which distinction between syntax and confirmation must be secured first so the paradox feels structurally inevitable rather than magical, the single concrete scenario—deliberately outside ornithology—that should carry the reasoning and must contain both an observed confirming case and an apparently irrelevant negative case, the misconceptions students will import from naive Popperian falsificationism and the precise point in the arc where each should be intercepted before it hardens, a brief diagnostic that distinguishes seeing the structural conflict from merely recalling the punchline, and the parts of formal confirmation theory that should be named and then explicitly set aside at this level.
