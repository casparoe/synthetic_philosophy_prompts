Here's an argument a colleague sketched about Molinism that I think overreaches, but I can't locate the leak. (1) Molinism holds that God has middle knowledge: prior to creation, God knows every true counterfactual of creaturely freedom—what each possible free agent would do in every possible circumstance. (2) If Peter freely denies Christ in circumstance C, then God knows that Peter would deny. (3) Now take C*, identical to C except that one neuron fires 0.001 ms later—a difference with no moral or psychological significance. If freedom is robust, Peter is just as free in C* as in C. (4) So God must also know what Peter would freely do in C*. (5) Repeat: between any two circumstances lies another, so every single counterfactual is embedded in a dense continuum of arbitrarily close variants, each requiring its own middle-knowledge entry. (6) Thus knowing one useful counterfactual entails knowing an uncountable infinity of neighbors. (7) But divine providence requires discrete selection—God actualizes one world, not a cluster—so if every discrete choice is swamped by an uncountable neighborhood, there is no non-arbitrary boundary for planning. (8) So Molinism either accepts that freedom fails across micro-variations (collapsing into determinism with noise), or admits that middle knowledge is useless for discrete providence, or arbitrarily restricts knowledge to "relevant" circumstances with no principled cutoff. (9) Molinists reject all three. Where does the argument break? If I must keep (1) and (3), which of (4) through (7) is least costly to abandon, and what does giving it up commit me to?
