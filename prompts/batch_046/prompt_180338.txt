Exam Question (Value Theory):

The heterogeneity problem challenges hedonism by observing that pleasures—such as those derived from eating, intellectual discovery, and aesthetic appreciation—seem to share no uniform phenomenal quality. If there is no common feel to these experiences, then pleasure may not denote a single kind of thing, and it becomes unclear how pleasure alone could serve as the sole intrinsic good.

(a) Explain why this problem poses a particular threat to quantitative hedonism, which holds that pleasures differ only in measurable dimensions such as intensity, duration, and certainty.

(b) One response is the common element defense: despite surface differences, every pleasure contains an identical underlying affective tone. Evaluate whether this defense succeeds in preserving quantitative comparison, or whether it merely relocates the difficulty.

(c) Some recent discussions propose abandoning the scalar model of pleasure in favor of a multi-dimensional vector framework, in which pleasure comprises several independent but related axes—for example, sensory gratification, cognitive satisfaction, and emotional resonance. Assess whether adopting such a framework allows the hedonist to accommodate heterogeneity without collapsing into value pluralism. In particular, consider whether this remains hedonism if pleasure is no longer one thing but a structured family.

Student Answer:

The heterogeneity problem is that pleasures feel totally different from each other, so there is no single thing we can call pleasure. For quantitative hedonism, which was developed by Jeremy Bentham, this is devastating because Bentham thought all pleasures could be added up and compared using his felicific calculus. The calculus measures intensity, duration, certainty, propinquity, fecundity, purity, and extent. If eating chocolate and understanding calculus share no common feeling, then there is no unit we can use to compare them, so the calculus is useless.

The common element defense says that underneath all these different experiences there is a basic pleasant feeling, like a warm glow. I think this works well for quantitative hedonism because once we identify that glow, we can measure its strength in each case. John Stuart Mill actually introduced this idea when he distinguished higher and lower pleasures; he argued that all pleasures contain this basic pleasantness but that intellectual pleasures have more of it in a refined form. So Mill's qualitative hedonism depends on the common element being present everywhere.

Regarding part c, a vector model treats pleasure as having several independent dimensions rather than one scale. This does accommodate heterogeneity, since eating might score high on sensory gratification but low on cognitive satisfaction, while solving a proof does the opposite. However, I think this means hedonism is false, because hedonism requires that there is exactly one intrinsic good—pleasure as a single unified thing. Once we allow pleasure to be a family of different goods spread across axes, we are really saying there are multiple intrinsic goods. That is value pluralism, not hedonism. Therefore, the vector model solves the heterogeneity problem only by giving up on hedonism entirely.
