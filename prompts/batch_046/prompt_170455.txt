I'm trying to formalize the conditions for mechanistic identity in mechanistic anomaly detection: specifically, when two internal computations in different models or runs should be treated as instances of the same mechanism, so that an anomaly detected in one properly counts as an anomaly in the other. Here are my judgments on concrete cases, and I want to know whether they cohere around a single principle or whether I must abandon some.

Case 1: Two runs of the same architecture activate an induction-head circuit with identical weight matrices and identical causal dependencies on prior tokens, but in one run the circuit attends to token position 2 and in the other to position 3 solely because of different input lengths. I treat them as the same mechanism.

Case 2: A circuit in Model A computes logical XOR through one intermediate feature; in Model B an isomorphic circuit computes XOR through a different intermediate feature that plays no other functional role. The causal graphs are structurally identical, but the physical representations are different. I think they are the same mechanism.

Case 3: A copy-suppression circuit in one model operates across layers 4-6 with direct residual connections; in another model, the same functional suppression is achieved through an indirect path via a layer-normalization gate that preserves sign but scales magnitude differently. I feel these are not the same mechanism, despite preserving the functional effect.

Case 4: A syntactic subject-verb agreement mechanism operates with a standard activation pattern in nearly all inputs, but in a narrow adversarial region it activates with inverted polarity and suppresses agreement. The weights are unchanged. I think the adversarial instance is an anomaly of the same mechanism, not a different mechanism.

Case 5: Two mechanisms share identical weights, identical causal graphs, and identical functional roles, except that one contains a redundant neuron that never activates above its bias threshold in any observed input. I treat them as the same mechanism.

Case 6: An arithmetic addition mechanism is implemented in base-10 representations in one model and in base-2 representations in another, with no shared intermediate representations but perfect algorithmic-level structural isomorphism. I am genuinely unsure whether these are the same mechanism.

My working intuition is that sameness requires causal-role equivalence under intervention, not representational identity or mere functional equivalence. But Case 3 challenges pure causal-role equivalence, while Case 2 challenges pure representational identity. Is there a coherent account—perhaps one that distinguishes structural pathway identity from functional-role identity—that captures Cases 1 through 5? If so, what does it say about Case 6? If no single principle saves all five verdicts, which one should I overturn, and what does that imply for designing an anomaly detector that compares mechanisms across architectures?

Finally, apply your best account to a case I have not listed: a distilled student model implements the same causal graph as a teacher mechanism, but with all weight magnitudes scaled by a constant factor and with two intermediate nodes merged into one.
