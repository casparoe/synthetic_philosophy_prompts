My study group has an argument that seems to show false scientific theories can never be genuinely improved, only abandoned. (1) Verisimilitude applies only to false theories: a true theory is maximally close to the truth by definition. (2) If theory T is false, there is at least one true statement S that T denies. (3) To increase T's verisimilitude, one must replace some false statement with a true one. (4) But theoretical statements are interdependent: replacing S requires revising the auxiliary framework that supported it, so the result is a globally different theory T', not an improved T. (5) Therefore there is no continuous path by which a false theory approaches the truth; refinement is impossible, and false theories can only be discarded wholesale. (6) Yet the history of science appears to show continuous refinement—Newtonian mechanics was corrected rather than simply thrown away when Einstein arrived. (7) So either those apparent corrections were illusory discontinuities, or verisimilitude cannot describe scientific progress. (8) My friend concludes we should reject verisimilitude and adopt a discontinuous, incommensurability-based picture of science. I want to preserve the intuition that false theories can be closer to the truth than others without being literally true. Which premise should I give up? Explain why it looked fine, and then price what the main responses—the content-based Popperian view, the structuralist model-theoretic account, and the pragmatic epistemic-utility view—would each have to pay to reject that premise.
