Reichenbach's rule for the reference class problem directs us to use the narrowest class with stable relative frequencies when predicting an event's outcome. Consider a genuinely singular prediction: whether this specific run of a language model will emit a harmful completion for this exact prompt. The narrowest class appears to be the singleton containing only this run, which yields a trivial frequency of either 0 or 1 and no predictive guidance; to avoid tautology we must widen the class to all instances of this architecture or all prompts of this form, thereby reintroducing the very ambiguity the rule was meant to eliminate. So hasn't the reference class problem been shown not to obstruct objective single-case probabilities, but merely to presuppose Goodman's prior question about which similarities are projectible—meaning statistics can never generate a prediction for a genuinely unique case without first deciding what counts as the same kind of thing?
