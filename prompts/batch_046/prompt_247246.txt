I've been working through Hofstadter's strange-loop picture of the self—treating "I" not as a label for a body or soul but as a symbol that acquires meaning by looping back through its own representational architecture, referring to whatever system instantiates the loop rather than pointing outward. I tried to turn this into a formal argument about copying and identity, but the conclusion is wildly implausible and I can't locate the leak. Here is the chain as I have it:

(1) If the self is just a strange loop, then the token "I" in my brain derives its reference entirely from its functional role within that loop—the pattern of self-modeling predictions, memories, and counterfactual dependencies it participates in—with no essential tie to this particular skull or spatiotemporal path.

(2) Functional role is substrate-independent: two silicon substrates running isomorphic causal architectures instantiate the same loop-structure, hence the same token-type of "I."

(3) Now run the loop on two physically isolated but causally isomorphic substrates—say, an emulation on server A and an identical emulation on server B, initialized from the same scan but thereafter diverging only in sensory input.

(4) Because the loop's self-reference is purely internal, each substrate's "I" refers to whatever entity is running the loop on that substrate. Yet since the internal functional pattern is identical, there is no feature inside the loop that distinguishes "the self running on A" from "the self running on B"; the loop lacks an indexical anchor to a unique location.

(5) Therefore, by the loop's own criteria, the "I"-symbol in A and the "I"-symbol in B both refer to the union {A,B}, or perhaps to a single distributed self that happens to be instantiated twice.

(6) By transitivity, if I make N copies, there is one self with N bodies. This implies that harming one body harms only 1/N of the self, and that my first-person obligations apply symmetrically across all bodies regardless of which one I happen to be "in" now.

(7) But that seems clearly wrong: if I wake up as copy #3 tomorrow, I will not feel that my suffering is diluted; and if copy #1 is tortured, I should not think "well, 99% of me is fine."

(8) So (1) must be false? Or is there a hidden step?

Where does this go wrong, if it does? I want to keep (1) if possible—there is something right about the strange-loop picture—but I am open to giving up (2) or (4). If the flaw is in (4), what does that tell us about how self-reference acquires an indexical anchor? And is there a version of the loop account that preserves substrate independence for gradual neural replacement but blocks it for branching copies?
