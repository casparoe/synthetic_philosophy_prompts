Student answer:

The MIU system starts with MI. Rule 1 lets you append U to any string ending in I. Rule 2 lets you double the substring after M. Rule 3 replaces III with U anywhere. Rule 4 removes UU anywhere. To get MU we need zero I's, but every legal move either keeps the I-count constant, doubles it, or shifts it by exactly 3. Since we start with one I, the count is always 1 mod 3, so 0 is impossible.

JOOTS is stepping outside to notice the 1-mod-3 invariant using arithmetic. Its not just that we havent run the program long enough—the system itself has no vocabulary for divisibility, so the explanation lives outside the rules. Still, a computer could be programmed to check this invariant at each step, so in practice JOOTS feels partly epistemic and not purely structural.

This is essentially Gödel's first theorem in miniature: MIU is consistent but incomplete, and MU is analogous to a Gödel sentence—true that it should exist but unprovable inside. Hofstadter uses this to show that any formal system with enough arithmetic has hidden blind spots.
