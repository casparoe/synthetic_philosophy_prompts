I'm trying to write up a spec for what a normative theory of rational risk-acceptance actually has to do, using the St. Petersburg paradox as the main stress-test. Everyone knows the basic setup — coin flips until heads, payout doubles each time — and I get the usual answers (Bernoulli's log utility, truncating the tail, saying people are just risk-averse). But I want the full requirements list first, before I look at any particular resolution, specificaly because I think some of the "obvious" fixes cheat by changing the problem.

So: what should the theory be able to cover? The classic single-shot case where expected value diverges to infinity, but also the truncated casino version where they cap payout at, say, 2^30 and the expectation suddenly collapses to something finite but still absurd — does rationality have to be continuous across that boundary, or is a discontinuous jump okay? There's also a weird collective variant I can't shake: if you offer the gamble to an infinite population of identical agents instead of one person, collectively they experience every payoff level. Does the spec require the theory to handle collective or intergenerational risk, or can it stay purely individual? And I think we need a hard distinction between "the agent rejects it because utility is bounded" versus "the agent rejects it because computing an infinite sum is unreliable" — those are seperate explanations, and the theory shouldn't collapse them.

I'm also stuck on whether empirical adequacy is a real desideratum. People actually pay maybe five dollars, but if you're risk-neutral with infinite resources, shouldn't you take it? Is that tension part of the spec, or can a theory satisfy both by saying rational agents are resource-bounded? And does transitivity have to hold when you nest St. Petersburg gambles inside each other — like betting on a game that itself contains another St. Petersburg payout? I want you to lay out the criteria: which cases it must get right, which distinctions it must preserve, whether any subset is jointly unsatisfiable, and which single requirement kills the most candidates. No bibliography, no scorecard — just the spec and where the joints break.
