Write the desiderata that any adequate solution to the frame problem must satisfy for a resource-bounded agent updating its model after action. For each requirement, provide the architectural or conceptual motivation, and mark it as non-negotiable or as a preference tied to a particular camp (symbolic, connectionist, or enactivist). Your list must cover: (i) representational economy — the agent is not required to encode explicit negative updates for every unchanged property; (ii) inferential preservation — conclusions about persisting properties remain available without being re-derived from first principles; (iii) modular frame inheritance — updates within one encapsulated cognitive subsystem (e.g., spatial navigation) propagate correctly to others (e.g., social reasoning) without demanding global access to all representations; and (iv) normative inertia — the system distinguishes persistence grounded in physical law, social convention, and mere default, because the cost and authorization of revision differ in each case. State whether any pair of these desiderata is jointly unsatisfiable given the frame problem's origin in monotonic logic and bounded computation. Identify which single requirement eliminates the broadest class of proposed solutions, and indicate whether accommodating normative inertia forces a departure from purely syntactic frame axioms.
