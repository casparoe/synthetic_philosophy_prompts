Some proposals for containing artificial agents suggest that harmful side effects can be avoided without supplying a full axiology, provided the agent measures its influence against a counterfactual baseline in which it never acts. Assess whether a 'side-effect' constraint can be made operational without first specifying what is valuable, paying particular attention to (i) the selection of a baseline world-state, (ii) the distinction between limiting the magnitude of change and limiting its qualitative kind—including whether a reversibility-weighted divergence can resolve the normative gap, and (iii) whether an agent's epistemic uncertainty about outcomes can substitute for an explicit value function in defining undesirable divergence.

Student's answer:
The central idea of a low-impact agent is that we need not encode human values directly; instead, we compare the actual world-state with a counterfactual baseline in which the agent takes no action, and penalise large divergences from that baseline. Because the agent is only required to keep things close to how they would have been naturally, no complete utility function is necessary.

(i) The appropriate baseline is stepwise inaction: the world evolves exactly as it would have done had the agent never existed. This selection is normatively neutral, since it merely describes the natural course of events rather than prescribing one.

(ii) There is indeed a distinction between magnitude and kind, but in practice it collapses for measurement purposes. A properly calibrated impact metric bounds the total divergence, and since any genuinely harmful effect—such as destroying an ecosystem—would necessarily register as a large deviation in the state-space, bounding magnitude automatically subsumes qualitative concerns. Moreover, if we weight divergence by reversibility, then temporary or undoable changes contribute negligibly, which means the metric itself encodes a normative preference for preserving long-term structures without needing an explicit value list.

(iii) Where explicit values are absent, the agent's own predictive uncertainty can fill the gap. If an outcome lies outside the agent's high-confidence model, it counts by definition as an unintended side effect. By constraining behaviour to regions of high epistemic confidence, the agent replaces an explicit value function with its own belief distribution. This is essentially an application of indirect normativity: the normative framework is not supplied from outside but is embedded in the structure of the agent's learning. Consequently, 'avoid side effects' can be fully specified using only the agent's internal probabilistic model, with no residual normative input required.
