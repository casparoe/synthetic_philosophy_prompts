I'm drafting a conceptual profile for a seminar on historical epistemology—specifically on how we claim to know anything about the distant past through source criticism from Herodotus and Thucydides onward—and I want to stress-test my commitments before presenting them. Here is my current set of views.

First, I hold that all knowledge of events beyond living memory is mediated by testimonial chains that terminate in present artifacts, so there is no unmediated access to the past, only layered interpretation; call this the mediated-chain thesis. Second, I nevertheless think Thucydides' distinction between autopsia and akoe marks a real epistemic boundary: direct observation carries a non-reconstructible authority that testimony about the same event cannot replicate, even when that testimony is highly reliable, which I take to be an autoptic-privilege claim. Third, I take Herodotus' practice of recording conflicting logoi without adjudicating between them to be more epistemically honest than Thucydides' synthetic narrative, because it preserves the opacity of the source pyramid rather than substituting the historian's judgment for missing evidence. Fourth, I deny that there is any principled metaphysical distinction between primary and secondary sources; there is only a gradient of mediacy and institutional framing, which means treating an archival document as an epistemic foundation is a category mistake. Fifth, I maintain that global skepticism about the distant past is self-undermining, since the skeptic's own argument depends on the same mediated chains they reject, though I also think this undermining applies asymmetrically: negative claims (absence of record) are more vulnerable to institutional-selection bias than positive ones, so absence should carry less default weight.

Could you audit this set for joint tenability? I need you to map out which pairs are genuinely in tension, which pairs only appear to conflict but dissolve on inspection, and for each real tension rate its severity, identify the cheapest revision that would resolve it, and then tell me which single change to my commitments would clean up the most conflicts overall. I'm especially unsure whether my autoptic-privilege claim can survive together with my denial of any primary/secondary distinction, and whether my praise of Herodotean transparency conflicts with my claim that skepticism is self-undermining rather than merely self-defeating.
