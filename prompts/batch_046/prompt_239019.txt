In my philosophy of language seminar we have been working through the modal argument for necessary a posteriori truths, and I have developed a formal concern about whether rigidity is a property of terms or of speaker intentions. Specifically, I want to examine a case of what I call "referential locking." Suppose I initially fix the reference of a theoretical term "phi" via an empirical description—say, "the object causing anomalous perturbation in orbital system O"—and then I stipulate that in all counterfactual scenarios I continue to apply "phi" to that very actual-world object, regardless of whether it still satisfies the description in the world being evaluated. By this convention, "phi" tracks a single object across worlds, functioning like a rigid designator. Now consider the identity statement "phi is the object causing anomalous perturbation in orbital system O." If I apply the same locking convention to the description—so that in each world the description is evaluated with respect to whatever object actually satisfies it in the actual world—then the statement asks whether that locked actual-world object possesses the property in the counterfactual world. This seems to make the identity necessary, since we are comparing an object with itself. But the identification was originally empirical and contingent. From this I am inclined to conclude that whether an identity counts as necessary a posteriori depends not on any intrinsic division between names and descriptions, but on whether the speaker applies referential locking. If locking is always available, then the metaphysical distinction between necessary and contingent identities collapses into a pragmatic choice about how to stabilize reference. Where exactly does this reasoning fail, and does it misunderstand the role of rigidity in the modal argument?
