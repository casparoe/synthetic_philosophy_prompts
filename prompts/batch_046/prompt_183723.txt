Student answer:
"Consequentialism requires comparing the total outcomes of available acts. The cluelessness objection holds that we usually cannot make this comparison because distant effects are unpredictable. The distinction between structured and unstructured opacity is important because unstructured opacity gives us no predictive basis at all, while structured opacity at least supplies the causal pathways. This makes structured opacity the milder case: we can apply expected-value reasoning by using our causal model to assign probabilities to outcomes and then weighting them by utility.

More specifically, expected-value calculation requires only that we combine probabilities with the values of outcomes; it does not require knowing every parameter exactly, only that we have a distribution over them. If the causal architecture is shared across the options we are comparing, then unknown parameter values affect all options symmetrically and therefore cancel out in the comparison. Consequently, we can rank acts by expected utility even when remote weights are missing, as long as we restrict our attention to the local nodes where the options diverge.

This means that structured opacity does not undermine consequentialism. Once we recognize that expected-value reasoning is robust to missing distant parameters, the cluelessness objection collapses for this class of cases. It also shows that the problem is not special to consequentialism: any moral theory that asks us to apply principles globally will face the same parameter gaps.
