Here's an argument I built for a seminar on quining qualia and now it feels like it eats its own tail. (1) If qualia exist, there must be a fact about what it's like to have them, and that fact has to be independent of funcitonal role, since functional duplicates can differ in feel. (2) So the fact depends only on intrinsic properties of the experience itself. (3) Now picture a synthetic agent with fully transparent architecture: we invert its internal color-mapping layer and correct the read-out layer so all behavior and self-reports stay identical. (4) Because behavior and reports don't change, no third-person test can detect the inversion. (5) But the intrinsic properties of the hidden layer did flip, so if (2) is right there should be a first-person fact about whether the agent's qualia inverted — except its reports are the same, so not even first-person access can settle it. (6) So there's a putative fact that's in principle undetectable by anyone, including the subject. (7) Any property that is in principle undetectable is not a legitimate posit in philosophy of mind. (8) Therefore qualia are incoherent. (9) By the same token, any mental state defined by intrinsic feel rather than functional role is incoherent too, which seems to swallow pain, joy, etc. I really want to hang onto (1) and (7) if possible, but (9) is killing me. Where's the hidden slide or equivocation? Which premise is the least painful to drop, and what does dropping it commit me to?
