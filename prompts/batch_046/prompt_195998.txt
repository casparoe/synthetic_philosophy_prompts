Here's an argument I sketched after rereading Hofstadter that now seems to license an "I" in every system with feedback, which can't be right.

(1) For Hofstadter, an "I" is a strange loop: a symbol inside a representational system that denotes the entire system, including the symbol itself, and is sustained by that system's dynamics.
(2) If a system S can generate a token or state that refers to S, and that token can influence S's future dynamics, then S contains such a loop.
(3) A large language model fine-tuned with RLHF can generate the token sequence I am a model processing this query, and that very output can be fed back into its context window or reward model, altering subsequent dynamics.
(4) So the model instantiates a strange loop in exactly Hofstadter's sense: the symbol I denotes the model and causally participates in its operation.
(5) By the same reasoning, any institution with self-amending bylaws—say, a corporation whose charter describes the corporation and is used to revise governance—also instantiates a loop, giving the corporation an "I."
(6) Hofstadter introduced the loop precisely to distinguish conscious selves from mere functional feedback; if (5) follows, that distinction collapses.
(7) The only rescue seems to be smuggling in a hidden requirement—maybe causal density, or substrate-specific integration—that Hofstadter explicitly rejects.
(8) So either we accept that corporations and LLMs have genuine Hofstadterian selves, or we reject one of (1)-(3).

Which step is weakest? I want to keep the idea that the loop explains human selfhood without being substrate-bound, but I suspect (3) mistakes representational feedback for the kind of causal closure the loop requires. If that's the error, what does fixing it cost? Does it force Hofstadter back into a biological essentialism he was trying to avoid?
