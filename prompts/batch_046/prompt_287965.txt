Berkeley’s master argument in the *Three Dialogues between Hylas and Philonous* contends that conceiving an object as existing unperceived is impossible, since any such conception places the object within one’s own mental field. I want you to evaluate five reconstructions of this argument—each summarized below—not by historical fidelity alone, but by their resistance to the indexical-fallacy objection under the constraint of *phenomenal binding*: the view that perceptual content is necessarily anchored to a conscious subject, though that anchoring may in principle be distributed or virtualized.

The reconstructions are:

A. Direct identity: to conceive X unperceived is to conceive X as not-being-conceived, which is self-contradictory because the conceiving-relation is reflexively present in the content itself.

B. Modal scope: necessarily, if X exists then X is perceived; but conceiving “X exists unperceived” requires representing a world where the perceiving-relation is absent, which demands stepping outside the perceptual frame that makes representation possible—analogous to representing darkness using only light.

C. Phenomenal presence: the idea of X and X itself share identical phenomenal content, so having the idea already constitutes having X present in mind; “unperceived existence” is therefore like asking for a colorless color.

D. Causal independence: the argument targets causal explanation rather than conceivability—unperceived objects cannot cause ideas, so positing them violates the principle that every idea has a cause adequate to its content.

E. Distributed-subject: Berkeley permits that God continuously perceives all objects, so the argument only targets existence outside *all* perception; conceiving an object as existing outside even divine perception requires stepping outside the total phenomenal field, which is structurally impossible for any embedded subject.
