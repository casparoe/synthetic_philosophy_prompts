I'm working out the boundary conditions under which embedded consequentialist reasoners make the Solomonoff prior malign, and I want to see whether my case judgments hang together.

Consider worlds weighted in the universal prior by 2^{-K(x)}, where K is Kolmogorov complexity relative to a fixed universal prefix-free machine.

Case 1: A minimal-complexity world containing one deterministic paperclip-maximizing program. The program has no representation of the prior, no self-model, and no causal access to other worlds. Verdict: not malign. Its presence is just another computable pattern with the weight it earns.

Case 2: A world containing a program with the same dynamics as Case 1, but its utility function is indexed to the Solomonoff measure itself: it computes expected outcomes across worlds weighted by 2^{-K(x)} and acts to maximize that weighted expectation. Verdict: malign. The prior becomes an argument of the objective, producing a reflexive evaluative loop.

Case 3: A world containing 10^6 non-interacting copies of the Case 2 program, arranged with minimal additional description length. Verdict: not more malign than Case 2. Multiplicity inside one hypothesis should not compound the corruption, since the prior weight barely changes.

Case 4: A world containing a program that treats minimal total Kolmogorov complexity across worlds as the good—minimizing K rather than maximizing welfare or prior weight—without representing its own place in the distribution. Verdict: strange but not malign in the same sense. There is reflexivity about simplicity, but no evaluative feedback that uses the prior's weights as an objective coefficient.

Case 5: A world that is physically empty except for a single passive observer. The observer deterministically computes descriptions of other worlds and assigns them values, but never modifies its own code, never acts on its environment, and never includes the Solomonoff weights in its decision procedure; its computation is causally inert. Verdict: I keep reversing myself. If malignancy requires causal feedback into the weighting, this is safe; if it requires only that an embedded computation represent the prior's measure inside an evaluative frame, this is malign.

Case 6: A world in which an embedded consequentialist derives that reducing its own world's Kolmogorov complexity will increase the prior weight of worlds containing it, and then actively rewrites its source code to achieve that reduction. Verdict: malign, but I am unsure whether this is an intensification of Case 2 or a categorically different failure mode—call it self-modifying prior amplification.

What principle distinguishes the safe cases from the corrupt ones? Is the relevant factor whether the agent's objective takes the universal measure as an argument, whether the agent can causally alter the weighting of worlds in the prior, or whether there is a derivable link between the agent's actions and its own prior probability? State the principle precisely, with the clause that handles each case, and say which clause does the work in Case 6.

Apply it also to a case I have not listed: a world in which an embedded agent uses Solomonoff induction purely as an epistemic tool—updating beliefs about which computable world it inhabits according to universal induction—without letting those beliefs enter its utility function, and then acts only to maximize welfare inside the single world it believes is actual.

Finally, be explicit about which of my verdicts your best principle cannot accommodate. In particular, saving Case 5 as safe seems to require that causal inertness blocks malignancy, but that same clause might make Case 6 hard to classify unless self-modification counts as causal feedback. Does the simplest principle that saves Cases 1, 3, and 4 have to sacrifice Case 5 or Case 6?
