Hey — I'm writting a feature on whether physics kills moral responsibility, and I built this argument from the Rietdijk-Putnam block-universe reasoning that now feels like it proves way too much. (1) Special relativity kills a global "now": for any two spacelike-separated events there's an inertial frame where they're simultaneous. (2) Rietdijk and Putnam run this up to show every event is "now" for some observer, so none are ontologically privileged—everything's equaly real in the four-dimensional manifold. (3) If my future actions are already "there" in the block, fixed the same way Tuesday's lunch is fixed, then I can't change them. (4) But "could have done otherwise" is necessary for moral blame and praise. (5) So in a block universe nobody is ever responsible for anything. (6) That's clearly wrong—people blame each other and it isn't all a mistake. (7) Therefore one of the premises, probably (2) or the jump at (3), has to go.

But I'm not sure if the slip is in treating ontological reality as causal fixity, or if I'm smuggling in a tensed theory of agency that a compatibilist can just reject. Where exactly does this fall apart, and what do I have to pay if I want to keep the physics? Also, if this whole framing rests on a confused premise—like treating "real" as "causally fixed"—just tell me straight, don't try to salvage it politely.
