I'm trying to formalize the bootstrapping problem about easy knowledge, but the argument I keep ending up with seems to license arbitrary self-confirming methods as legitimate sources of knowledge, which I know can't be right. Here is the chain, laid out as clearly as I can:

(1) For any cognitive method M to yield knowledge, a subject must be able to know that M is reliable. (2) With basic methods like vision or introspection, there is no independent tribunal available; every assessment of M's reliability is conducted through M itself. (3) So defenders of basic knowledge allow a form of circular confirmation: an output of M can be used to justify confidence in M (for instance, seeing that the table is red and thereby confirming that one's eyesight is functioning). (4) This circularity is usually defended as harmless because it operates only at the meta-level and does not infect the first-order knowledge delivered by M. (5) Now consider an autoregressive calibration procedure. I build a predictive device D running algorithm A. I evaluate D's accuracy using A itself to interpret the outcomes. After one successful match, I declare D calibrated. (6) By strict parity with (3)-(4), I have bootstrapped D into a legitimate knowledge source: I used an output of the D/A system to confirm the reliability of the very same system, with no external check. (7) Once calibrated, I can deploy D to generate unlimited first-order knowledge—say, about future market movements—justified solely by that initial loop. (8) If this is illegitimate, there must be a hidden constraint on bootstrapping that basic methods satisfy but D violates. (9) The most obvious constraint is that basic methods enjoy prima facie credibility, but that merely relocates the problem: if that credibility is not itself the product of prior bootstrapping, it looks like an unexplained exception; if it is, then we have already accepted circularity for them and still need to explain why D is different. (10) Therefore, either we reject all bootstrapping and fall into skepticism about perception, or we must accept that D is a legitimate epistemic authority.

This feels like a reductio that proves too much. I want to preserve the idea that easy knowledge is real—step (3) seems correct to me—while blocking the slide to (7). But I cannot locate the flaw. Is the mistake an equivocation in (6) between using M to check a specific token and using it to validate the global method? Or does (5) smuggle in a false analogy because autoregressive calibration lacks the structural independence that even meta-level perceptual checks possess? Or should I reject (1), and if so, does that mean knowledge can exist without any accessibility to reliability? Which step do you reject, and what does giving it up cost?
