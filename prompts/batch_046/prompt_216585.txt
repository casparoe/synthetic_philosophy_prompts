i was arguing with my roomate about origin essentialism — like, could i have come from a different sperm and egg if everything else stayed the same? we got into this weird side-case where the same egg is fertiilized by a different sperm that happens to yield the exact same genome, so now you've got same genome / different origin versus same origin / different genome. i want a poem that doesn't just describe this but actually uses its form to stage the swap.

write a sestina: six stanzas of six lines each, then a three-line envoi. use these end-words in the standard rotation: egg, sperm, genome, world, same, other. the point is that each stanza should hold one feature constant and let the other slide, so the repetition feels like the argument circling back on itself. in the envoi, put all six words in, but pair them like this — "egg" with "world" in the first line, "genome" with "same" in the second, and "sperm" with "other" in the third — so it sounds like the essentialist claim is coming apart instead of settling. blank verse, roughly 10-12 syllables per line, no rhyme except the end-word repetition. don't quote anyone or cite texts; just build it from the idea itself. and don't resolve the tension — let the form hang there.
