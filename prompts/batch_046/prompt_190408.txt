I've been thinking about something called program equilibrium—it's a game-theory idea where two computer programs play against each other, but each one can read the other's source code before deciding what to do. So I claimed that program equilibrium doesn't model human cooperation so much as it removes the very conditions that make trust meaningful, and I even suggested that some strategic opacity might be a moral feature of relationships rather than just a practical flaw. I'm not a philosopher or a programmer, just someone reasoning from what I've read. Could you comment on whether this analogy holds? I also worry that I might be misunderstanding how program equilibrium actually functions—does the ability to inspect code guarantee cooperation, or are there hidden failure modes I'm missing?
