At a study session, Jordan and Sam got into a sustained argument about whether special relativity undermines presentism through the Rietdijk–Putnam line of reasoning. Jordan opened by saying that if simultaneity is frame-dependent, then for two inertial observers passing each other, the set of events that count as “present” differs. If presentism holds that only present events exist, then the same distant event must both exist and not exist, which is contradictory; so presentism is incompatible with relativity, and we should accept the block universe in which all events are equally real.

Sam replied that this only works if presentism is assumed to be globally frame-independent. Presentism can instead be frame-relative: just as velocity is relative to a frame, so is ontological status. For each observer, only the events on their own present hypersurface exist, and there is no single global “now” that all frames must agree on. This saves consistency without embracing eternalism.

Jordan countered that this collapses presentism into something indistinguishable from eternalism. If every event lies on some frame’s present hypersurface, then every event exists in at least one legitimate ontology. Calling that “presentism” is just indexing eternalism to observers; the core presentist claim—that there is a unique, objective set of existing things confined to one time—has been abandoned.

Sam then proposed a sharper version he called “localized presentism”: existence is genuinely perspectival. There is no unified four-dimensional manifold of equally real events. Instead, there are multiple, mutually incompatible three-dimensional ontologies, each valid only for its own frame. A distant supernova exists-for-frame-A and fails-to-exist-for-frame-B, with no further fact of the matter. This is not eternalism, he insisted, because eternalism requires one shared spacetime of equally real events, whereas his view denies any shared ontology across frames.

Jordan responded that this makes physics impossible. Cosmologists routinely describe “the state of the universe at cosmic time t” using the CMB rest frame not merely for convenience, but because they assume an objective ontology. If Sam is right, then two equally valid descriptions of the universe can contradict each other about which events are real, and there is no principled reason to prefer the cosmological frame except pragmatic habit. Jordan added that if Sam admits a privileged frame to rescue objectivity, he contradicts the principle of relativity; if he denies one, he has turned existence into a subjective projection and lost the metaphysical distinction presentism was meant to preserve.

Sam’s final move was that Jordan was begging the question by assuming ontology must be global. The CMB frame is a useful coordinate choice, not an ontological revelation. And perspectival properties—like velocity—are already standard in physics, so a perspectival ontology is not mystical. He concluded that the Rietdijk–Putnam argument fails: it forces presentists into eternalism only by ruling out frame-relative ontology in advance, which is an unjustified constraint.
