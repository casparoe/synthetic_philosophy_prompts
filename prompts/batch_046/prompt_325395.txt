Here's an argument I built for a study group that seems to rescue mental causation only by making software, economics and furniture causally inert, and I can't find the exit. (1) If every physical event already has a sufficient microphysical cause, then any macro-level cause is redundant. (2) Mental states supervene on brain states with multiple realisability, so they aren't identical to any particular micro-state. (3) By exclusion, mental states don't cause physical changes. (4) But software running on silicon, macroeconomic trends, and even being-a-table all share that same supervenience-with-multiple-realisability structure. (5) So if mental causation is excluded, none of those macro things cause anything either — your code doesn't crash your laptop, inflation doesn't cause unemployment, tables don't hold books. (6) Obviously those things occure, so (3) is false, which rescues mental causation. (7) But then either I reject (1) generally — killing the exclusion argument everywhere — or I special-plead for consciousness. Where is the hidden slip? Is there an equivocation between "sufficient cause" and "complete causal story" in step one, or does step four wrongly treat realisation as overdetermination? Which premise should I give up, and what's the price? I'd rather keep (1) than bite the bullet that my OS is epiphenomenal. Please reply in British English.
