Unbeknownst to her, her employer has deployed an automated correction algorithm that would have intercepted and rewritten any falsified report with near-certainty. Maria knows nothing of this system. Verdict: Maria is fully morally responsible for her honest report, even though she could not have successfully lied.

Case 2 — The self-authored constraint. He feels the urge, triggers the check, sees his own code execute, and waits out the lock. Verdict: James is fully responsible for resisting the trade.

Case 3 — The transparent sandbox. Aisha works in a secure facility. She can read the complete source code of the containment system that physically prevents her from removing classified files without encryption. The system is active, she verifies it is running, and she therefore never attempts removal. Verdict: Aisha is not morally responsible for keeping the files secure—she experiences the situation as running inside a sandbox that has already removed the option from her practical reasoning.

Case 4 — The probabilistic race condition. Ben works in an identical facility to Aisha’s, with the same transparent containment code, but he knows there is a documented 0.01% race-condition failure rate. He attempts to remove the files; the system fails; the breach occurs. Verdict: Ben is fully responsible for the breach, precisely because the blocker was not deterministically guaranteed to stop him.

Case 5 — The dormant inherited protocol (this is the case I have not listed). Clara inherits a legacy safety system she did not design and has never inspected.
