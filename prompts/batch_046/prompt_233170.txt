Question: Rawls's separateness of persons objection claims utilitarianism wrongly treats individuals as interchangeable containers for welfare. Consider a modified view, 'partitioned aggregation,' where welfare is calculated within each life and summed across lives, with cross-person tradeoffs allowed only if no one drops below a fixed baseline. Does this escape Rawls's objection? Lay out his original argument and assess whether partitioned aggregation avoids it.

Student answer:
Rawls says utilitarianism ignores that people are seperate, so it can justify killing one healthy person to harvest organs for five sick ones. That's wrong because each person has their own life. Partitioned aggregation fixes this because welfare is computed inside each person first, then added up, and cross-person trades are blocked unless everyone stays above baseline. So you could never take organs from the healthy one if it puts him below baseline, which respects separateness. This is really just Kant's idea of treating people as ends, which Rawls borrows. So partitioned aggregation escapes the objection.
