I serve as a senior acquisitions officer for a regional museum of cultural history. We need a reusable decision procedure for inferring collective social institutions—such as shared property norms or ritual obligations—from unprovenanced physical artifacts, distinguishing institutional beliefs from individual habits. The procedure should run as an ordered sequence of tests, include stopping rules for insufficient evidence, and mark every point where judgment must replace analysis. It should treat "indexical" artifacts (objects that only function within a shared, rule-governed practice) differently from purely instrumental ones, and it should specify when the absence of an expected object type counts as negative evidence. Apply the procedure to two cases: a cluster of identical ceramic vessels showing no wear patterns, and a modified tool recovered in isolation near a burial context; then state explicitly what kinds of inferences the procedure can never license regardless of evidence. Write the response in American English.
