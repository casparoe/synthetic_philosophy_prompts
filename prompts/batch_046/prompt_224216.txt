ok I'm organizing my thoughts for a logic workshop on Carroll's tortoise and whether deduction needs justification. Here's roughly where I've landed - tell me if it hangs together or if I'm sneaking in contradictions.

1. Basic rules like modus ponens can't be justified without circularity, since any proof for them already uses them.
2. Still, I think logic is empirically revisable - if our best science eventually forced us to drop bivalence or distributivity, we'd be rational to revise.
3. I read Carroll as showing inference rules aren't premises; the tortoise is wrong to demand them as missing premises in an argument.
4. But formal axiomatic systems are totally legitmate, and part of their value is making rules explicit and inspectible.
5. If someone genuinely rejects MP, there's no further rational argument you can hit them with - they've just stepped outside the reasoning game.
6. I think the "justify deduction" puzzle only makes sense inside a linear foundationalist picture where every belief needs a chain back to first principles; reject that picture and the problem mostly dissolves.
7. Also, I think Carroll's regress only gets started if you assume grasping a rule requires having an explicit mental representation of it; on an ability-based view you can follow MP without being able to state it, so demanding it as a premise is a catagory mistake.

I'm especially worried about (1) vs (2) - can logic be empirically revised if it can't be rationally justified? - and (3) vs (4) - doesn't formalizing rules treat them like premises? - and (2) vs (5) - if empirical findings could rationally change logic, then isn't rejecting MP sometimes rational rather than "outside the game"? Rank these tensions by severity, say which ones are only apparent, and tell me the least costly revision if I need to drop something. Don't start from scratch on Carroll, just audit my package.
