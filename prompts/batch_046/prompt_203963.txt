Here's an argument I skecthed for a seminar and now it feels like it proves way too much but I can't find the leak. (1) If parts are arranged so they jointly realize a function none does alone, they compose a real object. (2) The philosophy department and the economics department jointly realize interdisiplinary research that neither does alone. (3) So they compose an object — call it the P&E cluster. (4) By the same token any arbitrary group of people anywhere who happen to jointly stabilize the climate by breathing compose one object, since they jointly realize a function none does alone. (5) But then there are infinitely many overlapping objects with the same parts but different essential properties, which violates mereological essentialism. (6) So either there are no institutional objects at all, or essentialism is false and everything is just a temporary arrangement. (7) I think both horns are wrong, but I want to keep (1) because it explains why universities feel like real things. Where does it break? If I have to pick I'd rather ditch (5) than (1), but I'm not sure what that costs me.
