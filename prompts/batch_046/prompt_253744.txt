okay so i've been thinking about rational herding and i think i have an argument that shows rational people can never learn from experts, which is obviously wrong but i can't see the hole.

(1) If you're rational, you update on all and only your evidance.
(2) In an information cascade, agent n only sees the actions of 1..n-1, not thier private signals.
(3) Those actions are causally downstream of each other: agent 2 copies agent 1 partly, agent 3 copies 2, etc.
(4) So the cascade contains redundant information—counting every prior action as fresh evidence is double-counting the original private signals.
(5) To correct for redundancy, a rational agent should weight the cascade by its effective sample size, which for a long chain collapses to about one independent observation.
(6) Therefore agent n should treat the entire cascade as no stronger than one other person's opinion.
(7) But agent n already has thier own private signal, which is one independent observation.
(8) So the cascade gives agent n no net new evidence, and they should stick with thier private belief.
(9) This applies to every agent, so rational agents never herd and never learn from others.
(10) But then expert consensus, markets, and wikipedia are all epistemically useless to rational people, which can't be right.

i feel like step (4) to (6) is where the sleight of hand is—maybe redundancy doesn't mean zero information, just that you have to update correctly? but then i also worry about (1): does rationality really require updating on *all* evidance, or just not ignoring evidance you understand? if i reject (1) i seem to open the door to willful ignorance. which step should i actually give up, and what's the cost? i'd rather keep (1) and (9) if possible, but i suspect that's inconsistent. also i keep wondering if there's a hidden modal slide between (3) and (4) about causation vs correlation—like maybe the dependency doesn't actually make the actions redundant in the evidential sense? not sure.
