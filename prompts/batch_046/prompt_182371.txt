Question: Explain the impossibility result showing that calibration within groups, balence for the negative class, and balence for the positive class can't all hold together unless base rates match or the predicition is perfect. Then evaluate: does this actually prove algorithmic fairness is impossible? In your answer mention one proposed escape route — like counterfactual or path-specific counterfactual fairness — and say whether it actually solves the problem or just moves the difficulty elsewhere.

Student answer:
So calibration means if the model assigns 30% risk to a group, about 30% actually reoffend. Balence for negative class means false positives are equal across groups, and for positive class false negatives are equal. The result (Chouldechova 2017 I think) shows these three conflict when base rates differ because Bayes' rule ties them together. If P(Y=1|G) differs, equalizing error rates forces calibration curves apart.

Does this make fairness impossible? Not literally, it just forces a tradeoff. You can pick calibration or equal errors. One escape is path-specific counterfactual fairness: you block causal paths that go through the protected attribute but keep the others open. But that's basically just deleting the feature and hoping correlations don't leak back in, so it doesn't really solve anything if the feature is entangled with everything. Another option is drop calibration and use demographic parity, but then the scores aren't probabilities anymore.

So fairness isn't impossible, you just can't have all three. The result is more about value choices than math.
