hey, i need help tearing apart an argument my roommate cooked up after binge-reading philosophy of biology. he thinks he's got a reductio of the phylogenetic species concept, but i'm pretty sure it secretly backfires onto personal identity. here's the chain he wrote:

(1) For a group to count as one real species, there has to be a shared essential property that every member has and that non-members lack -- otherwise "species" is just an arbitrary label with no ontological weight.
(2) The best candidate is a core phylogenetic signal, but even that drifts: trace back far enough and every organism shares ancestors with every other one, and within any named group there's always some existant outlier genome (hybrid cases, mutation drift, etc.).
(3) So there's no shared essential property that picks out, say, all Homo sapiens without either leaving out some humans or pulling in other primates.
(4) Therefore, if we take essentialism seriously about taxonomy, each organism is technically its own species.
(5) Now run the same logic diachronically. My genome at age 5 and my genome now are about as different, proportionally, as some "species" splits we accept in taxonomy -- he calls this "intertemporal genome drift," though i think he made the phrase up.
(6) So if shared essential genome is what makes a group one thing, then i'm not the same person across time; i'm just a sequence of genome-stages.
(7) But denying that i'm the same person is clearly nuts.
(8) So essentialism must be false for individuals, and by parity it's false for species.
(9) But then we have no prinicpled boundary for species, which was the problem we started with.

he says we either accept that every organism is its own species and every person is a sequence of distinct selves, or we drop essentialism everywhere and live with vague taxonomic boundaries. i want to keep (1) -- i think essentialism is salvageable if we allow fuzzy essences or kind-membership conditions that tolerate outliers -- but i also want to keep (7). where's the leak? is there an equivocation between "essential for group membership" and "essential for diachronic identity"? does the genome comparison in (5) fail because personal identity doesn't depend on genome continuity? and does it matter that "intertemporal genome drift" isn't a real technical term? which step do i reject, and what does it cost me?
