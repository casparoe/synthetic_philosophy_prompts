hey, i'm a backend engineer with zero formal philosophy training, but i got dragged into a discord about the Principal Principle — the idea that if you know the objective chance of something is 30% and you don't have sneeky hidden info, your rational credance should also be 30%. here's an argument i built that i think breaks it, but i'm sure i'm being dumb somewhere.

(1) The Principal Principle says rational credance should match objective chance, unless you have undermining evidence about the actual outcome.
(2) I run deterministc Monte Carlo sims where the simulated physics assigns objective chances (like a 30% failure rate).
(3) Because I wrote the seed and the RNG, I can always re-run the code and learn the exact outcome of any trial.
(4) So for trial #547 I know both that the internal "objective chance" of failure is 0.3, and that the actual result was failure (or not).
(5) By (1) I should believe failure was 30% likely. By (3) I should believe it was 100% or 0%. Contradiction.
(6) So either the Principal Principle is false, or deterministc sims don't have real objective chances.
(7) But if (6) is right, then anyone with enough compute could undermine quantum mechanics by running the universal wavefunction, which seems like a crazy result.

I'd really like to keep (1) and (3) — dropping (1) feels like giving up on rational belief altogether, and dropping (3) feels like denying I can read my own source code. Where's the exit? Which step do I reject, why did it look okay, and what's the cost?
