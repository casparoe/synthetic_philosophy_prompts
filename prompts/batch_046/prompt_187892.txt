I've been working through the formal structure of prioritarian social welfare functions and their relationship to the leveling-down objection, and I've hit what seems like an internal tension. Prioritarianism weights benefits by applying a concave transformation g to each individual's well-being, so that a unit of well-being counts more the worse off that person is. The leveling-down objection alleges that this makes equality intrinsically valuable, which should imply that harming the best-off—without benefiting anyone else—is socially good, since it reduces disparity. The standard reply is that g is strictly increasing, so harming anyone lowers the aggregate sum regardless of equality effects, and equality is only instrumentally relevant.

My confusion is that this reply appears to suppress a feature that motivates the concavity in the first place. If g is concave, then g'(u) is decreasing in u, which means the moral value of an additional unit to person i depends on i's absolute position in the distribution. Once evaluation is calibrated this way, reducing u_j for the best-off j does not merely lower j's contribution; it also shifts the reference frame against which every other person's well-being is weighted, because "worse off" is defined relationally across the population. So pure downward leveling seems to alter the marginal value of benefits to everyone else, even if their absolute well-being is unchanged. Given this, I do not see how prioritarianism can consistently maintain both (i) that concavity reflects diminishing moral value calibrated against the overall distribution, and (ii) that harming the advantaged without helping anyone is never good-making. Which commitment do defenders actually drop? Or is there a non-relational justification of concavity—say, based purely on intrapersonal diminishing returns—that genuinely blocks any indirect benefit from leveling down?
