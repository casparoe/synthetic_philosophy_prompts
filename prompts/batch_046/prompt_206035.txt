Consider Galen Strawson's Basic Argument against moral responsibility, which holds that true responsibility requires being causa sui—yet every candidate cause of an action traces back to conditions (character, motives, mental states) for which the agent is not ultimately responsible, generating an infinite regress. Now suppose we embed this psychological regress in a physical framework where decision-making involves genuinely indeterministic processes at the synaptic level: a choice is not fully fixed by prior mental states, but is instead triggered by quantum-level stochastic events that are not themselves determined by any earlier feature of the agent. In this scenario, the causal chain does not loop back to an unchosen prior self; it terminates in an event that is, in a literal sense, not caused by the agent's pre-existing psychology. Given this termination point, why does Strawson still insist that indeterminism offers no purchase for true moral responsibility? Specifically, doesn't the presence of physically uncaused neural events provide exactly the kind of causal break that allows an agent to initiate a genuinely new causal chain—one for which they can be said to be the origin—rather than merely extending the regress?
