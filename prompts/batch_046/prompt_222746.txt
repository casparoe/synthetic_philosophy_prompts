In our graduate game-theory seminar, two classmates—Leila and Marcus—got stuck arguing about whether iterated elimination via dominance in mixed strategies is genuinely path-independent or whether its intermediate reasoning stages can diverge. They asked me to referee, and I honestly could not settle it. Here is their exchange.

1. Leila: In any finite normal-form game, if strategies are eliminated only when strictly dominated by some mixture over the strategies that remain, the order of elimination never affects the final rationalizable set; uniqueness holds regardless of path.

Marcus: That sounds right for pure-strategy elimination, but once mixtures are permitted, whether a given strategy is strictly dominated depends on exactly which opponent strategies are still available. So the domination relation itself shifts as the set shrinks, and the elimination path must matter.

2. Leila: Even granting that local dependence, rationalizability is defined globally as the largest fixed point of the best-response correspondence restricted to itself. The iterative procedure is merely an algorithm for computing that fixed point, and for strict domination every order converges to the same limit.

Marcus: You are treating rationalizability as a static mathematical object, but in this course we use it to model sequential reasoning under common knowledge of rationality. If agents eliminate strategies layer by layer based on local beliefs about available mixtures, different reasoning sequences could stabilize at different intermediate subsets long before any global fixed point is reached.

3. Leila: But common knowledge of rationality entails that every agent knows every other agent is rational, ad infinitum, which collapses precisely onto that global fixed point. There is no coherent local reasoning that halts midway, because any strategy that survives globally survives at every layer, and any strategy eliminated globally is eliminated at some layer.

Marcus: That assumes perfect logical omniscience and simultaneous computation. Bounded agents reason stepwise, and if one path removes strategy C early while another retains it temporarily, the intermediate beliefs about which mixtures are available diverge, altering which strategies appear dominated at that particular stage.

4. Leila: Then you are not criticizing the solution concept but smuggling in a psychological claim about cognitive limits. The set of strategies that are never best responses is uniquely defined, so calling the algorithm path-dependent is misleading: different orders are just different implementations that all output the same set.

Marcus: Not quite. For mixed-strategy domination, the very definition of available mixtures changes with the remaining strategy set. So if you ask which strategies are eliminated at step k, the answer can depend on what was eliminated at step k-1. Uniqueness holds only for the limit, not for the intermediate reasoning stages that actual agents inhabit.

5. Leila: So we agree the limit is unique; our disagreement is only about whether intermediate reasoning stages are conceptually relevant. But if the course frames rationalizability as an epistemic achievement rather than a mathematical endpoint, then the path-dependency of intermediate beliefs is not an implementation detail but a genuine ambiguity in what iterated elimination denotes.

Marcus: Exactly, and that ambiguity is not separable from the concept itself when it is used descriptively. If the reasoning path can diverge in intermediate beliefs, then saying that agents perform iterated elimination does not uniquely specify their strategic reasoning, even if the final limit is the same.
