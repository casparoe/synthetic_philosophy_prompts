I've been messing with Gödel's modal ontological argument for a seminar paper and I think I've pushed it somewhere absurd. Here's the version that's haunting me.

(1) Gödel defines God as the being that has every positive property, and being-necessary is one of them.
(2) Positive properties are closed under entailment: if P is positive and P necessarily implies Q, then Q is positive.
(3) So if being-God is possible, then being-God is instantiated in every world.
(4) Now take any arbitrary actual object x. Define x's "positive core" as the conjunction of all properties x actualy has that count as positive.
(5) If x exists in the actual world, then x's positive core is possibly instantiated — actualy, it's actually instantiated.
(6) So by the same reasoning as (3), there is a being with exactly x's positive core in every world.
(7) That gives us infinitely many necessary beings, each matching some contingent thing.
(8) So either contingency collapses or identity breaks. Where's the slip?

I think the move from (4) to (6) smuggles in that x's core is God-like, but I can't pin down why that fails. If I have to choose I'd rather keep (3) and ditch the extension, but I want to know exactly what I'm paying — do I have to reject closure, or exclusivity, or just the idea that arbitrary cores can run the argument?
