I've been thinking on my own about whether DNA is literally a code or only called one by analogy, and I've arrived at a few unresolved directions that seem to pull in different directions. Some argue that genomes carry semantic content—representing proteins, regulating development—while others treat "coding" as pure shorthand for chemical causation with no representational layer. From this tension, I've sketched three lines of inquiry, but I can't tell which are genuinely upstream and which are decorative.

The first asks whether representation can exist without an interpreting agent: if a ribosome reads a sequence and produces a peptide, is that interpretation in any meaningful sense, or just mechanistic unfolding? The second considers what synthetic biology would need to demonstrate for us to say a genome contains a false statement—for instance, a designed sequence that structurally specifies one protein but reliably produces a different one due to an internal representational mismatch rather than environmental interference. The third asks whether resolving the representational question actually changes anything: if DNA is not a code, does the concept of mutation as "error" collapse into mere causal variation, and does that shift how we should think about genetic engineering or evolutionary explanation?

Assuming I have no laboratory access and must work through conceptual reasoning alone, which of these lines—or which others you think I'm neglecting—deserve priority? I want a defended ordering, not a survey: for each, explain whether it depends on resolving another first, how tractable it is through analysis rather than experiment, and what practical or theoretical difference its answer would actually make. I'm particularly interested in whether the code question is mostly a semantic dispute that leaves biology untouched, or whether it carries hidden commitments about information, error, and design that reshape how we evaluate synthetic organisms.
