(2) A strange loop is formally defined by self-reference that crosses levels: a pattern within a system points back to the system that contains it.
(3) The expression this very phrase is also a self-referential token inside a linguistic system; it points back to the token itself, and derivatively to the phrase-system that contains it.

(5) If two expressions share both formal structure and referential mechanism, then they should have the same kind of referent, absent an independent reason to distinguish them.
(6) But this very phrase has no diachronic identity: uttered today it denotes one token, uttered tomorrow it denotes a different token, with no single enduring entity tracked across contexts.
(7) So by parity, I should also lack diachronic identity; today’s I and tomorrow’s I denote different cognitive token-systems, with no shared enduring referent.
(8) Yet Hofstadter explicitly claims that I tracks a stable organizational pattern—the strange loop itself—that persists as long as the brain’s structural organization is maintained.
(9) To preserve (8), one must reject either (5) or (6).
