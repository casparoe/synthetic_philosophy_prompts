I've kinda bought into this hybrid view about spectrum arguments and transitivity. Basically I think 'better than' is transitive in principle — like if A is genuinely better than B and B genuinely better than C then A is better than C — but the spectrum problem only bites when we compare across what I call 'evaluative frames' that dont share a baseline. So saving 1001 lives might sit in the same frame as saving 1000 (barely better), but saving 1000 vs saving 1 gets shoved into a different frame where the comparison algorithm resets. This saves transitivity as a logical feature of value but explains why our intuitions about long spectra feel like intransitivity. What would actually count against this? I dont want just the standard sorites reply; I want to know what empirical or formal results would show frame-resetting is just ad hoc. Are there moral comparison cases where the frame should clearly stay the same but the intransitivity intuition still hits? And which defeaters would a committed defender concede are real problems versus ones they'd just dismiss? Rank them from fatal to merely embarassing.
