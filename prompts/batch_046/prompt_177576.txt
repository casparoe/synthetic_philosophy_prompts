I've basically bought the Chase-Sanborn idea that qualia are an incoherant posit — not just mysterious but conceptually broken. Any attempt to fix 'what it's like' either smuggles in functional or relational dispostions (behavioral roles, causal profiles) or appeals to a private language that can't be corrected or shared, which makes the vocabulary useless. Lately I've pushed it further: I think phenomenal talk should be eliminated across the board, not just revised, including pain-talk and afterimage reports. But I'm not sure if I've qualified the view into unfalsifiability — any resistance just gets diagnosed as lingering Cartesian intuition. So what would acutally count against this? I don't want another Mary-the-scientist replay since that's been hashed out forever. I want the defeaters that hit the coherence claim itself: formal results about private language? Cases where functional description genuinely fails to capture something we need morally or epistemically? Or is there a hidden circularity — maybe the argument assumes all meaningful terms must be intersubjectively correctable, which is itself contested? Rank them from fatal to merely awkward. And say honestly: is this position well-insulated, and if so, is that a problem for a view of this kind?
