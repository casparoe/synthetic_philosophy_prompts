There's this stalled argument in the philosphy/AI overlap about whether LLMs literally have beliefs, and I'm trying to figure out why nobody budges. The intentional-stance crowd — Dennet-style, I guess — says if treating the model as believing improves predicitive control then attribution is justified, period. The other side says it's just weight updates with zero aboutness, so calling it belief is a category mistake. Both sides cite the same behaviors: the model asserts Paris is in France, then in a jailbrake claims it's in Germany, with no global revision. But recently someone floated this weird intermediate architecture — an AI that keeps fully coherent local "belief pockets" within a single thread but has absolutly no cross-context memory or revision mechanism, so it can hold P in thread A and not-P in thread B with no internal tension. The stance-camp still wants to attribute beliefs thread-by-thread; the eliminativists call that fragmentary performance without mental unity. The debate hasn't moved in months because both sides just shout "predicitive success!" versus "no real aboutness!". So is this a substantive disagreement about what belief actually requires — global coherence? stability? — or is it verbal, with one side using "belief" for functional role and the other for biological realization? Or are they just answering different questions, one about engineering heuristics and one about ontology, under the same heading? And given whatever diagnosis, what would actually count as progress — a formal result comparing unified vs fragmented predictive accuracy, a distinction that splits the word, or should we just accept the impasse?
