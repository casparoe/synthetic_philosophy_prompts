As a software engineer with no formal philosophy background, I was asked to assist in grading an interdisciplinary exam that asks computer-science students to analyze LLM cognition through conceptual frameworks. The exam question was: "Some researchers describe LLMs as 'agents' with instrumental goals; others call them 'simulators' that reproduce reasoning patterns without understanding. A third position—call it epistemic refraction—holds that LLMs neither pursue goals nor merely copy human reasoning, but instead transform reasoning traces through high-dimensional statistical weighting, producing outputs that are causally active yet neither authored nor simulated. Consider a system that autonomously decomposes a large codebase into microservices over several reasoning steps. Does this demonstrate instrumental agency? And does the refraction view genuinely escape the objections raised against both the agent and simulator accounts, or does it collapse into one of them?"

Here is one student response:

"The multi-step refactoring clearly demonstrates instrumental agency: the system decomposes a large goal into subgoals, selects actions, and executes them sequentially, which is functionally identical to planning. The agent view is therefore correct. Dennett's intentional stance tells us that if a system behaves as though it has goals, we ought to treat it as literally possessing them for explanatory adequacy, so we should ascribe instrumental goals to this LLM. The simulator view fails because pure pattern reproduction cannot generate a novel architecture absent from training data; since the output is genuinely new, simulation is ruled out. The refraction view attempts to split the difference but collapses into simulation, because statistical weighting is merely pattern reproduction with additional computational steps. Furthermore, refraction cannot explain termination conditions—why the system stops once the architecture works—whereas real goal-directedness naturally explains this. Thus, the third view is redundant and the agent account is best supported."
