Question: According to IIT, why is a purely feedforward visual-processing architecture not conscious? Explain the role of re-entrant connectivity and the exclusion postulate. Then address this variant of the group-consciousness worry: if two people were linked by a direct cortical interface allowing sustained, high-bandwidth bidirectional interaction, could they form a single conscious complex with phi greater than either brain alone? How does the exclusion postulate bear on this case?

Student answer: A feedforward network lacks consciousness because information flows only forward: each layer transforms input for the next without feedback, so the system is decomposable into independent stages and integrates no information across them. Even if individual layers contain local mechanisms, the architecture as a whole has negligible phi. The exclusion postulate resolves overlap: among all candidate substrates, only the one with the globally maximal phi value is conscious. In split-brain patients, severing the corpus callosum removes integration between hemispheres, so each hemisphere becomes its own maximally irreducible complex, excluding the other. As for the linked-brain case, the exclusion postulate rules it out. The postulate requires that any conscious substrate be physically self-bounded, so two skulls can never form one complex regardless of interface bandwidth. Because each brain already maximizes phi within its own boundary, the joint system is necessarily composed of two separate maxima, which the postulate forbids from coexisting within a single causal chain. Therefore, even with direct cortical links, no super-subject can emerge.
