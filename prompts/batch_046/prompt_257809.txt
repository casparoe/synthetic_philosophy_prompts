A colleague sketched this for me and I cannot locate the weak link. (1) In any actual infinite, each element is uniquely determined by its ordinal or cardinal index, so positional identity is essential to element identity. (2) Hilbert's hotel accommodates a new guest by shifting every occupant from room n to room n+1; since every occupant changes index, by (1) none of the original guests remain, and the hotel now contains an entirely new set of guest-position pairs plus the newcomer. (3) Therefore, the hotel hasn't shown that the cardinality of the natural numbers equals that cardinality plus one with the same guests; it has shown that one infinite configuration was replaced by a structurally similar but numerically distinct one. (4) By the same reasoning, putting an infinite set into one-to-one correspondence with a proper subset never involves the same set; it always involves replacing the original set with a different set that mimics its structure. (5) So Cantor's claim that a set can be equipotent with its proper subset is either false or empty: false if it asserts identity of the original set, empty if it asserts only structural similarity. (6) But if (5) holds, then finitism is vindicated, because there is no coherent notion of an actual infinite that survives internal rearrangement. (7) The trouble is that (1)-(6) also seem to apply to infinite series in analysis—reordering terms produces a different series, not the same one rearranged—so accepting them destroys not just Cantorian set theory but the standard treatment of convergent infinite sums and infinite-state physical models. I want to preserve the intuition that Hilbert's hotel reveals something genuinely strange about completed infinities, and I would like to keep the idea that positional identity matters in ontology. Which step should I reject, and what does giving it up cost?
