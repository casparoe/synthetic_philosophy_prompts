I'm taking a philosophy-of-technology course on embedded agency. Please argue that a physically embedded reasoner cannot apply standard expected-utility maximization to itself without conceptual contradiction if it includes its own computational architecture in its world-model. Specifically, defend the claim that treating the agent's current mental state and source code as part of the environment's state space forces a dilemma: either the state-transition rule determines the agent's next computation, in which case choice collapses into prediction, or the rule leaves that computation undetermined, in which case the agent must evaluate outcomes contingent on reasoning steps it has not yet performed—breaking the causal closure required for well-defined utility expectations. Present this not as a practical computing limit, but as a structural constraint showing that classical decision theory must be revised rather than directly applied to embedded agents.
