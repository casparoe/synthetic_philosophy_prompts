someone in my philosophy of mind reading group keeps pushing this open-source analogy for hofstadter's claim that an 'I' can be distributted across brains. she says your self is like a github repo -- other people can fork it, commit changes, run local instances, and if the original server crashes the project doesn't actually die. she uses this to argue that personal grief is basically a category error, like crying because one laptop got bricked when the code is running on ten others. i want to check how far this holds. can you lay out the correspondance table -- what plays the role of the original repo, the forks, pull requests, the license, the server hardware -- then point out where the mapping actually breaks for consciousness? specifically, does the analogy quietly import that identity is just functional replication with no indexical anchor, and if so, does her conclusion that mourning is irrational survive once we see the disanalogies? and if the software picture is broken, is there a better analogy for distributed persistence that doesn't smuggle in that conclusion?
