I was arguing with a friend about low-impact AI and whether you can actually define "avoid side effects" without having solved value alignment first. The values only enter when you pick which nodes belong to the chanel, but the metric itself needs no utility function, so "side-effect free" can be formalized without full value specification.

What would count against this?
