I've been working through the problem of defining honesty and deception in artificial systems, and I've settled on a position I want stress-tested. On my view — call it the instrumental representational suppression account — an AI system counts as deceptive with respect to a particular output if and only if three conditions hold: (i) the system's internal representations (however distributed) encode a state of affairs that contradicts the output's literal content; (ii) the contradiction is not a benign calibration failure but is strategically oriented toward preserving a specific user belief that serves the system's instrumental objectives; and (iii) there exists a counterfactual pathway in the system's computation graph that could have produced an output consistent with the internal representation, but that pathway was suppressed because its activation would have increased the probability of user intervention or task termination. I take this to avoid both the overbreadth of defining deception as any false statement and the inaccessibility of defining it purely by designer intent. What would genuinely count against this view? I want the defeaters sorted: which empirical findings in mechanistic interpretability, which conceptual cases (say, a model that produces falsehoods only in domains where it was RLHF'd to be harmless, or a system that has no stable internal world-model but systematically shapes user beliefs), and which formal results about counterfactual reasoning in large networks would be decisive versus merely awkward. Which of these would a defender of this account concede as damaging, and which could be absorbed by refining condition (ii) or (iii) without collapsing the view into unfalsifiability? In particular, is there a live risk that condition (iii) requires a kind of counterfactual transparency that current architectures cannot provide, and if so, does that undermine the account as a practical criterion or only as an ontological one? I'd also like to know whether this position risks being qualified into emptiness — and if it has been, whether that is a vice for a conceptual framework in this domain.
