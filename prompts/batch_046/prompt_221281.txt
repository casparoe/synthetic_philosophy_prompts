I've been arguing with my roomate about the omnipotence paradox — you know, the stone too heavy to lift thing — and he turned it into this weird argument that I think proves way too much. He says:

(1) If God is omnipotent, then for any task T, God can do T.
(2) One task is: create a situation in which God lacks the power to do some specific thing.
(3) So an omnipotent being can perform that self-undermining task.
(4) Once done, God is no longer omnipotent.
(5) So omnipotence is modally fragile — having it means you can always destroy it.
(6) But the same structure applies to any comprehensive capacity: if you can do all the things in set K, then doing the one thing in K that removes your ability to do the rest is still in K.
(7) So free will, omniscience, even just being a rational agent with full control over your beliefs, all suffer the same fragility.
(8) Therefore either none of these exist, or there's a hidden restriction on what counts as a task.
(9) But if we restrict tasks arbitrarily to save agency, we lose the original motivation for the omnipotence paradox.
(10) So we're stuck with the conclusion that robust agency is impossible.

I feel like there's an equivocation hiding in step (6) between having a power and having a power over the conditions that define the power, but I can't quite name it. Which premise should I actually reject? I really want to keep the intuition that omnipotence is conceptually troubled without having to deny that people can make free choices or learn things. What's the cost of giving up each option?
