(1) The centipede paradox only works if rationality is common knowledge: I know you're rational, you know I know, and so on without end.
(2) That "so on without end" is literally an infinite belief hierarchy.
(3) Any real agent — human, institution, or small model — has finite working memory, so they can't actually represent an infinite hierarchy.
(4) So for every real-world player, common knowledge of rationality is false.
(5) But backward induction needs that common knowledge to push the take decision all the way back to node 1.
(6) Therefore backward induction never applies to real agents; it only describes hypothetical agents with infinite minds.
(7) And here's teh overreach: strategic anticipation in general — chess, pricing wars, climate talks — also depends on expecting others to reason ahead. if the infinite-hierarchy problem blocks backward induction, it blocks all multi-step strategic thinking for real agents.

Which premise should I drop? I especially want to keep (3) and (6) if possible, since the bounded-mind point feels right. What's the cost of saving them?
