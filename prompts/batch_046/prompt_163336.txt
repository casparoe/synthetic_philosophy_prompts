Quick question from someone who's been teaching philosophy of language for too long and probably overthinking this. I've noticed a recurring pattern in how people defend innateness claims about syntax, and I'm wondering if it has a proper name or if I'm just describing a variant of the usual poverty-of-stimulus move. The pattern goes like this: someone picks a grammatical constraint that children seem to respect early, then they survey the actual linguistic environment and show that direct negative evidence is basically absent. So far, so standard. But then, when you point out that children do recieve indirect feedback -- parents repeating the sentence correctly, conversational breakdown, that sort of thing -- they respond that this feedback doesn't count because it doesn't target the specific structural feature in question.

What's strange is that the criteria for "targeting" get stricter exactly when the acquisition problem gets harder. For a simple vocabulary item, general contextual correction is enough to rule out learning; for a complex syntactic island, only an explicit grammatical correction counts, and since parents never say "no, that's an island violation," the learning path is blocked. So the argument isn't just that the stimulus is poor; it's that we define the relevent stimulus narrowly enough to make it poor. Is there an established concept for this kind of post-hoc narrowing of what counts as pedagogical input? How does it differ from a standard auxiliary hypothesis defense? And if there's no name, what's the cleanest way to distinguish it from the ordinary poverty-of-stimulus argument, since in the ordinary version the absence is empirical and in this version it seems partly definitional?
