Design a decision tree for a graduate seminar in medieval political philosophy that sorts a student’s actual commitments about tyrannicide into named positions. The root node should ask whether the tyrant holds power by legitimate succession followed by abusive exercise, or by usurpation without valid title. From there, each branch should present one concrete diagnostic question—such as whether only a public authority may resist, whether resistance is permitted only when it will not produce greater disorder, or whether preemptive removal before tyranny is fully manifest can ever be justified—phrased so that a student can answer it without knowing which interpretation the answer leads to. The leaves should include Aquinas’s own position, a stricter later-Thomist revision requiring an explicit judgment by the community’s representative body, a common misreading that erases the public-versus-private distinction, and one unoccupied combination (for instance, private preemptive action with no risk of greater harm) that you briefly diagnose as either incoherent or merely unexplored. Flag any pair of leaves that the tree cannot cleanly separate, and specify which conceptual distinction is doing the sorting work at each node. The instrument should work entirely from logical and conceptual distinctions; do not request bibliographies, reading lists, or verbatim quotations. Write the response in American English.
