Here is an argument about embedded agency that seems to prove rational deliberation is impossible for any system physically embedded in its environment, and I cannot locate the exit.

(1) Call an agent embedded if its cognitive states are realized by physical processes that are part of the world it models. (2) Consider a deliberative choice between actions A and B. The embedded agent forms beliefs about which is better via these same physical processes. (3) Suppose the agent ends up in the physical state S_A, in which its evaluation mechanisms represent A as superior. Because these mechanisms are part of the world-model, S_A is also part of the causal chain that produces the behavior executed. (4) So the belief that A is best and the execution of A share a common substrate: being in S_A. (5) Now suppose instead the agent had been in S_B. Then it would have executed B and represented B as superior. (6) Therefore, for any embedded agent, there is no state in which it genuinely holds both options open, forms an independent evaluation, and then selects one; the evaluation-state and the action-state are identical, and the transition between them is just causal determination. (7) But rational deliberation requires a real separation between evaluation and execution—otherwise there is only determination, not choice. (8) Hence embedded agents cannot rationally deliberate; they can only be causally driven. (9) Yet we treat embedded systems—including human brains and any artificial agent running on physical hardware—as capable of rational deliberation. (10) So one premise must fail, but abandoning (1) gives up embedded agency entirely, abandoning (6) seems to require a non-physical separation between belief and behavior, and abandoning (7) collapses rationality into causation. I would most like to preserve (1) and (7). Which step should I reject, why did it look unavoidable, and what am I paying if I keep the other two?
