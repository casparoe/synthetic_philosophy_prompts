okay so ive been mulling over this hypocrisy and blame thing on my own, not from any class, and i think i built an argument that kills all blame but i cant find the crack.

(1) If youre a hypocrite about some specific wrong W, then you lack standing to blame anyone else for W.
(2) Youre only hypocritical about W if you do W yourself and hold others to a stricter standard.
(3) Now take any real case where person A blames B for W.
(4) A is not perfect, so A has definitely done some wrong thing, call it W-star.
(5) But W and W-star are both wrong, so A applies one standard to B (for W) and a laxer one to themselves (for W-star).
(6) So A is hypocritical not just about W-star, but about "being wrong" in general, and that includes W.
(7) Therefore by (1) A lacks standing to blame B for W.
(8) Since this works for every blamer and every blamed wrong, nobody ever has standing to blame anyone for anything.
(9) But that cant be right, because then my sister blaming me for stealing her charger is automatically dead just because she lied about homework last tuesday, which feels like throwing the baby out with the bathwater.

i think the slip is somewhere between (5) and (6), like maybe being sloppy about one kind of wrong doesnt make you a hypocrite about every other kind? but then whats to stop someone from saying "well you lied, so you cant call out theft"? i want to keep (1) if i can because it feels right that hypocrites shouldnt talk, but i also dont want blame to be impossible. which step do i reject, and what does fixing it cost me?
