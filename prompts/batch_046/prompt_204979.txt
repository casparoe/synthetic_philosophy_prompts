I've come round to thinking DNA is literally a code — not just a handy metaphor — and that evolution is mostly software optimization running on biochecmical hardware. The degeneracy of the codon table and the fact there's no programmer don't bother me; those feel like implementation details. I even think if it's really code, then synthetic genes should be portable across species without rewiring the ribosome, because code is universal. But I'm not sure what'd actually kill this view for me. What should count as decisive evidence or arguments against it — sorted from fatal to merely awkward? Has it already been qualified into unfalsifiability, like saying it's a code but a weird biological one with no decoder, and is that insulation a problem? Do frame-shift misreads or epigentic rewriting of expression without sequence change count as real defeaters, or can the literal-code camp just absorb them? I want the defeaters that defenders of this view would themselves concede, not just the ones critics shout about.
