As a retired physicist now reading philosophy of science, I have noticed a recurring pattern in statistical reasoning about singular cases that I cannot quite place within the vocabulary I have learned. One begins with a broad reference class to estimate a probability for a particular individual—say, the recovery rate for all patients diagnosed with a certain condition. Then one corrects for the patient's age, then for lifestyle factors, then for genetic markers, then for the specific treatment center. Each correction is individually defensible, since each factor genuinely modifies the outcome, yet every refinement reduces the sample size and weakens the statistical grounding. If one continues this process to its logical end, the reference class shrinks to the individual alone, where frequency-based reasoning no longer applies; but if one stops at any earlier stage, one seems to ignore information that is both available and relevant. The standard reference class problem, as I understand it, concerns which single class is appropriate. The pattern I am describing is different: it is the stepwise erosion of statistical validity through successive, reasonable subdivisions, with the original difficulty reproduced at each level rather than resolved. Is there an established concept that captures this specific dynamic—distinct from the reference class problem itself and from statistical overfitting? If so, what are its precise boundaries: must the subdivisions be causally relevant, or does the pattern also arise with purely correlational stratification? And if no such concept exists, what term and definition would best isolate it from ordinary auxiliary adjustments?
