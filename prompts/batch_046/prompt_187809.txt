I want a decision-tree taxonomy — built from logical space rather than from a list of labels — that sorts respondents by their actual commitments on the regress of justification, mapping each path to foundationalism, coherentism, infinitism, or an explicitly marked empty combination. The tree must contain exactly four binary branch nodes, each phrased as a concrete epistemic scenario answerable with yes or no, so that someone can navigate it without knowing the names of the positions. The nodes are: (A) the "isolated witness" case — can direct perceptual acquaintance justify a belief even when every other belief the subject holds is false and offers no support? (B) the "circular library" case — can a closed loop of three beliefs, each supported only by the others with no external anchor, collectively justify all three? (C) the "finite chain" case — is an infinitely extending, non-repeating chain of justification conceptually available to a finite human mind? (D) the "defeat isolation" case — if one belief in a system is defeated, must the justification of distant, logically unrelated beliefs in that same system necessarily collapse?

Explicitly flag any pair of named positions that this particular four-node framing fails to separate. The audience is an advanced undergraduate epistemology seminar familiar with the standard regress problem but not with this specific framing; the purpose is to reveal hidden disagreements about isolation, circularity, and defeat propagation rather than to ask participants which "-ism" they prefer.
