For a rationalist workshop on symbol-grounding and downward causation (12 participants, 75 minutes), design a playable simulation of a careenium: a substrate in which physical nodes called simmballs move according to hidden mechanical rules, but can also bear symbolic tags assigned by an observer layer. Split the group into Substrate agents (who experience only local forces and hidden dynamics) and Interpreter agents (who can rearrange tags and issue symbolic commands, but have no direct physical access). Give the Interpreters a collective payoff for steering the substrate to a target configuration, and give the Substrate agents individual payoffs for local stability. Run the simulation for 25 minutes, then debrief: map the moments where symbol rearrangement seemed to work, where it failed, and whether any correlation was causal or post-hoc labeling. Be explicit about which philosophical feature—such as the substrate’s insensitivity to syntactic form or the absence of a privileged interpretation—the rules naturally reproduce, and which feature (e.g., misrepresentation without physical breakdown) must be supplied by the facilitator because the game cannot stage it. Also note what will predictably go wrong the first time you run it and how to correct it.
