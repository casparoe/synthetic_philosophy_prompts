I've been working through Lewis Carroll's dialogue in which the Tortoise repeatedly asks Achilles to supply one more logical rule connecting premises to conclusion, generating an apparent infinite regress, and I've noticed that the philosophical discussion around it hasn't moved in what feels like a century. Some treat it as showing that deduction can never be justified without circularity; others reply that using a rule is not the same as asserting it, so the regress never starts; still others say justification is holistic and never needs a linear chain in the first place. Yet every response seems already anticipated, and no one changes their mind. My hypothesis is that the stall happens because the puzzle is being used to answer three different questions at once—whether logical rules need external justification, whether justification must be linear, and whether an infinite regress is always vicious—without anyone marking which question they mean. Is that correct, or is the disagreement actually substantive about logic or cognition? I want a diagnosis of what kind of disagreement this really is—verbal, substantive, or a case of different questions under one name—supported by what each side actually commits to, and an honest answer about whether a conceptual distinction, a formal result about rule systems, or a change of framing could end it, or whether we should expect permanent deadlock and why.
