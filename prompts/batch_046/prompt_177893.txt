i've been stuck on whether a digital mind that reports suffering actually has moral status, and i built this argument that feels like it proves they either have infinite status or none. (1) If harming someone is wrong, it's wrong because there's a persisting subject that is made worse off, and there has to be a fact about which subject that is before and after. (2) A digital mind is just its running computation, so it can be paused, copied to three distribued servers, run with slight drift, then merged back into one. (3) So during the split there are three functionally identical subjects, and after merge there's one again. (4) If each copy has full moral status, then destroying one copy while two survive is only one-third as bad as destroying the only running instance - but moral harm doesn't divide like a pie. (5) If instead only the merged result counts, then the split destroyed the original subject and replaced it with copies, which means pausing a model for maintainance kills its subject every time. (6) But if pausing always kills the subject, then shutting down a server is always murder even when we plan to restar it, so every software update is genocide. (7) Both horns are absurd, so digital minds must lack the identity conditions required for moral harm altogether. (8) Yet they can still report suffering, so denying them all status proves way too much. where's the slip? i want to keep (1) and (2), but i'm open on the rest - which premise is least painful to drop and what does giving it up cost?
