I want an in-class game that makes them feel the boundary problem in their bones, not the usual secession-and-borders lecture version. The reflexive circularity is what i care about: the demos has to decide who belongs to the demos, but any membership rule they adopt already smuggles in an answer.

the niche twist i'm injecting: set it on a seed colony on an exomoon (too cliche? maybe, but it works). They're drafting a founding charter that includes rules for future amendments. I want three charter cards on the table: A counts only biological founders and direct descendants; B counts anyone with existant interests, including generated persons; C counts only entities that can actually participate in deliberation, which picks up some AI-adjacent systems but leaves out other generated ones.

please design the rules, roles, and a point-based payoff scheme—no real money—so that the group first votes on a charter, then immediately has to amend it using whatever membership rule they just locked in. They should run into the circularity themselves before anyone names it. Then a debrief that maps each failure back to the formal problem: self-exclusion, reflexive definition, the missing ground.

also tell me what will predictably go wrong on the first run and how to handle it, and be honest about what the game can't reproduce—probably the infinite regress or the metaphysical status of not-yet-existant people—and what i need to supply verbally. No lecture up front.
