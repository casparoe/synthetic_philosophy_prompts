if path dependence actually locks history in, doesn't that make the usual counterfactual question — like, would democracy have shown up eventually anyway — kind of a category mistake? because if the specific sequence is constitutive of the outcome, then getting "democracy" through a totally different path isn't the same token outcome, just something in the same functional equivalence class. so shouldn't we stop asking whether outcomes are inevitable and instead ask which functional jobs are hard to replace? also please separate what's actually settled about path dependence from what's still genuinely contested by people who actually study this, and don't present one camp's view as the consensus.
