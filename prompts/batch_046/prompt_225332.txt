I'm taking a philosophy of medicine seminar and I've been working through an argument about naturalism and disease classification that seems to collapse into self-contradiction, and I'm not sure where the error hides. (1) Naturalism holds that a condition is a disease if and only if it represents a failure of some biologically evolved function. (2) To identify such a failure, we must compare an individual's functioning against a reference class—typically the species-typical design or a statistically defined cohort. (3) But evolutionary biology gives us no unique, privileged reference class: we can specify the comparison group at the level of the species, the local population, the age-matched cohort, or even the individual's own historical baseline. (4) Consequently, for virtually any biological state C, there exists some reference class relative to which C is subnormal and therefore dysfunctional, and another reference class relative to which C is normal and therefore not dysfunctional. (5) If naturalism is correct, then whether C is a disease depends entirely on this choice of reference class. (6) But the selection of a reference class is not itself determined by biology; it requires a normative judgment about which capacities matter and for whom. (7) Therefore, naturalism does not eliminate value judgments from disease classification but instead buries them inside an apparently biological choice. (8) If every naturalist classification secretly depends on a prior normative commitment, then naturalism is indistinguishable from normativism in practice, which means naturalism entails its own negation. Where does this go wrong, if it does? If I must choose, I'd rather preserve (1) and (6), because I think the reference-class problem is real and serious, but I don't want to conclude that naturalism is literally self-defeating. Is there a hidden scope shift, an equivocation between statistical and functional normality, or a modal slide that lets the argument run too far?
