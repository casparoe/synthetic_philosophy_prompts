okay so my roommate is writing a thesis on epistemic logic and threw this at me over dinner. (1) In standard epistemic logic closure holds: if K(p) and K(p→q) then K(q). (2) Take an AI with a finite explicit belief store B. For any b in B, there are infinitely many logical consequences. (3) If closure is unconditional, knowing b means you already have every consequence in B, else there's some c with b and b→c in B but c not in B, violating closure. (4) So knowing one thing requires an infinite store. (5) No artifical agent has that. (6) So either AI's don't really know anything, or closure is false. (7) People try to fix this with 'awareness' — you only close over implicatons you're aware of. (8) But awareness is just another mental state, so now we need closure over awareness too, which starts the same regress. (9) Another fix is resource-bounded closure: you close only within n computaton steps. (10) But then there's no principled value for n, and for any n I can build a consequence that takes n+1 steps. (11) So every fix either collapses back into omniscience or makes knowledge arbitrarily bounded. (12) My roommate says this proves knowledge is just a useful fiction for describing successful prediction, not a real mental property. I think that's too fast and there's a hidden slide between (3) and (4) but I can't name it. Which step do you reject, and what does rejecting it cost? I'd like to keep (1) and (6) if I can, but (12) feels like it jumps over something about the difference between having a belief and being able to compute it.
