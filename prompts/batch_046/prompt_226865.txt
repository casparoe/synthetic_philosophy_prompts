I have been working through the tension between intuitionistic logic and mathematical constructivism, and I think I have constructed an argument that shows the constructivist position collapses into incoherence, but I cannot locate the error. Here is the reasoning.

(1) A central motivation for rejecting the law of excluded middle is that it licenses existence proofs that provide neither a witness nor an algorithm.
(2) Many constructivists nevertheless accept Markov’s principle for decidable predicates over the natural numbers: if it is impossible that every n lacks property A, then some n has A.
(3) Consider König’s lemma in its classical form—every infinite binary tree contains an infinite path. This is constructively invalid, because in general no algorithm can extract such a path.
(4) Now define, for each tree T, the predicate P(T): “there exists a constructive procedure that demonstrates T has no infinite path.”
(5) If every tree lacked an infinite path, then for each tree we could exhibit such a procedure; hence we could uniformly refute the claim that some tree possesses a path.
(6) Yet assuming that every tree lacks a path yields, via a standard finiteness argument on nodes at each level, a contradiction. So it is impossible that all trees lack paths.
(7) Applying Markov’s principle to P, there must exist a specific tree T* for which P(T*) fails—meaning no refutation exists.
(8) The failure of P(T*) entails that T* does have an infinite path.
(9) Thus, by accepting Markov’s principle, the constructivist is forced to assert the existence of an infinite path in T* without possessing any algorithm to construct it.
(10) This is precisely the kind of non-constructive existence claim that rejecting the law of excluded middle was meant to block. Therefore constructivism is self-defeating unless Markov’s principle is abandoned, yet abandoning it cripples constructive analysis.
