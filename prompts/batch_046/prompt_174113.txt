Write a deadpan parody of a software user manual, approximately 600 words, for an imaginary enterprise decision-engine called ARBITER-7 that claims to resolve ethical and practical "hard choices" algorithmically. Format it with standard technical sections—Overview, Input Specifications, Comparison Protocol, Troubleshooting, Glossary, and a sidebar titled "Deprecation Notices"—and maintain the flat, authoritative voice of corporate documentation throughout. The satire should target the assumption that rational choice can always be reduced to ordinal comparison without remainder: the manual should explain that ARBITER-7 handles "better than," "worse than," and "equal to" relations with full precision, but enters an unrecoverable error state—labelled PARITY_EXCEPTION—when two options are "on a par" in the sense that neither dominates the other and they are not equal. In that state, the system prompts the user to "generate an agent-relative reason through commitment," logs nothing in its audit trail, and outputs a blank field marked USER AUTHORED. Include specific troubleshooting entries for "Value Pluralism Conflict," "Incommensurable Metric Overflow," and "Post-Choice Reason Generation Failure." The sidebar should list "Naturalness," "Covering Value," and "The Non-Comparability Thesis" as legacy concepts removed in version 8.0. The humor should come from treating these philosophical positions as deprecated software bugs rather than as substantive objections, so that a reader familiar with the literature recognizes the distortion is fair. Do not ask for citations, references, or reading lists; the manual should contain no named living philosophers and should rely only on the conceptual framework itself.
