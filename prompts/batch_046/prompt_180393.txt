As a retired atmospheric physicist who has recently turned to philosophy of rationality, I am preparing a self-contained handout for a small interdisciplinary seminar on embedded agency — specifically on predictive systems that are physically instantiated within the environments they model, so that their outputs feed back into the dynamics being predicted. Please construct a taxonomy, arranged as a decision tree, that sorts positions on how such an embedded agent ought to reason about its own place in its model. The tree should begin with the shared premise that an embedded agent’s predictions are part of the causal structure it predicts, and that the agent may suffer indexical uncertainty about which physical instantiation of its algorithm it currently occupies.

The tree should split through four binary nodes, each phrased as a concrete claim or thought-experiment that a participant could answer without knowing philosophical labels in advance:

1. Whether achieving reflective consistency — coherence between an agent’s prior beliefs and the decision procedure it actually executes — is possible from the internal first-person perspective, or is definable only by an external observer with full architectural access.

2. Whether indexical uncertainty about one’s own computational instantiation undermines all normative reasoning, or merely requires a modified Bayesian update rule that conditions on self-locating evidence.

3. Whether the appropriate normative framework treats the agent’s outputs as nodes in a causal graph (so the agent should maximise expected utility over interventions), or treats them as logical or probabilistic dependencies (so the agent should optimise over consistent worlds in which its outputs take specific values).

4. Whether an embedded agent can rationally modify its own source code when the modification mechanism is itself part of the system being updated — specifically, whether this produces an infinite regress of meta-level oversight or can be resolved by a fixed-point condition.

Each leaf should carry either the name of an established position (for example, Functional Decision Theory, Causal Decision Theory applied to embedded systems, Reflective Externalism, Indexical Scepticism) or the label unnamed if no prominent defender occupies that logical space. Every leaf must include one sentence stating its most awkward commitment — the consequence that makes the view difficult to maintain consistently.

Please also identify any pair of leaves that your tree fails genuinely to separate, explaining why the distinction collapses under pressure. Identify any unoccupied combination of answers, briefly diagnosing whether the gap arises from incoherence, unattractiveness, or mere neglect. Finally, specify which distinction in your tree matters most for an agent that must update climate-feedback predictions that include its own policy recommendations as input variables — this should guide the structure, not appear as an afterthought.

Write in British English, with formal but clear prose suitable for a seminar handout. Do not provide bibliographies, citation lists, or requests for further reading; the taxonomy should be fully self-contained for someone without web access. Avoid appeals to highly specialised literature that only specialists would recognise; build the distinctions from the branching questions themselves.
