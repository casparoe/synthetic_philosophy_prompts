Exam question I gave them: 'Compare counterpart theory and transworld identity, using a hard-forked blockchain protocol (say Bitcoin vs its fork) as your central example. Can the same protocol exist in two worlds with different post-fork rules? How would Lewis handle this versus a Kripke-style essentialist?'

Student answer (around 350 words):

Counterpart theory, as David Lewis laid out, rejects the idea that one thing can live in more than one possible world. Every world is self-contained, and when we talk about something being different in another world we're really talking about its counterpart—something that resembles it closely enough. Similarity is weighted, but origin and causal history matter a lot, so in the blockchain case the forked chain and the original share the same genesis block and are therefore strong counterparts. The relation is symmetric: if A is B's counterpart then B is A's. Lewis allows multiplicity only when there's no clear best match, but here the shared genesis block makes it one-to-one.

On the other side, transworld identity theorists like Kripke let the very same object exist across worlds. For them essential properties do the work. If having that specific genesis block is essential to being Bitcoin, then both chains have it, so they're literally the same protocol existing in both worlds with different accidental features—like transaction rules being changed. This avoids multiplying entities.

There's a tension though. Lewis said counterpart relations depend on overall qualitative similarity, including extrinsic properties like network adoption, not just origin. So if the fork changes the rules enough, the forked chain might fail to be a counterpart at all, leaving us with no cross-world link. Meanwhile, essentialism about origins works well for people—Kripke's example of Nixon having different parents—but extending it to protocols is questionable because what makes Bitcoin Bitcoin seems partly conventional. Still, I think counterpart theory is the better fit for technological artifacts because it doesn't need to claim there's one true Bitcoin across worlds; it just needs enough resemblance to talk meaningfully about the fork.
