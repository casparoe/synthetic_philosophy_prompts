Here is an argument I built for a workshop and now find suspicious, because its conclusion seems to swallow far more than Wittgenstein ever intended. I would like to keep (1) if possible, but I am not particularly attached to (5).

(1) If a term's meaning is fixed solely by reference to a mental state to which only the speaker has direct access, then no other person can ever correct the speaker's application of that term.
(2) If correction is impossible in principle, then there is no real distinction between correct and incorrect use of that term.
(3) A term lacking any correct/incorrect distinction is not governed by a rule, and therefore is not a meaningful term at all.
(4) So a purely private language—one whose vocabulary refers only to private sensations—is impossible.
(5) Now consider propositional attitudes. Only I have direct, first-person access to my belief that snow is white; others must infer it from my behavior and circumstances.
(6) Therefore, if I coin a term—call it "schmelief"—to name exactly this privately accessed belief-state of mine, then by (1)-(3) "schmelief" cannot be a meaningful term.
(7) But the structure in (5)-(6) applies generally: every mental-state term I apply to myself—"believe," "intend," "remember," "doubt"—names something I access in this same direct, first-person way.
(8) Hence, if (1)-(4) are sound, then all first-person mental-state talk collapses into meaninglessness.
(9) Yet first-person mental-state talk is clearly meaningful, and we routinely correct one another's self-attributions (I can be wrong about what I believe or intend).
(10) So either (1)-(4) contain a hidden flaw that saves mental-state talk, or there is a disanalogy between private sensations and private beliefs that blocks the extension in (5).
