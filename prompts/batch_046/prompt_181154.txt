I am working through a line of reasoning for a course on the philosophy of mathematics, and I want to test whether it collapses into absurdity. The argument tries to show that actual physical infinities are impossible, but I worry it proves too much—specifically, that even ordinary finite containers cannot be determinately full. Here are the steps exactly as I have them:

(1) Hilbert’s hotel demonstrates that if there are ℵ₀ rooms and every room is occupied, a new guest can still be accommodated by shifting each occupant to the next room, leaving room 1 vacant—without evicting anyone.

(2) So for an actual infinite collection, “all members are present” does not entail “no further member can be added”; completeness and openness to addition are compatible.

(3) Finitists typically allow only potential infinity—indefinite extendability rather than a completed totality. They often object that an actual ℵ₀ of physical objects would mean the universe could never be “complete,” since one more object could always be added, which they take as incoherent for a physical totality.

(4) Cantor’s power-set result shows that if one actual infinite cardinal exists, then strictly larger cardinals (2^ℵ₀, and so on) also exist, with no maximal cardinal.

(5) Now suppose, for contradiction, that an actual infinite physical collection exists—say, a universal set of discrete physical parts with cardinality ℵ₀.

(6) By (1), this collection can always absorb one more part. By (4), it can also be embedded in larger cardinalities, so there is no “largest” physical totality.

(7) Here is the critical move: take any finite container—say, a box holding exactly n discrete objects. If an actual infinite exists as a background frame, we can map the box’s contents onto positions 2 through n+1 within the infinite sequence, leaving position 1 “outside” the box but within the available physical space. This is just a local restriction of the global Hilbert shift applied to the embedded subsystem.

(8) Therefore, if actual infinity exists globally, then for every finite container there is always an available “slot” generated by the embedding, meaning no container is ever determinately full; fullness becomes labeling-relative rather than intrinsic.

(9) But it is plainly false that a box holding ten marbles can determinately hold an eleventh marble without structural change—physical containment does not work that way.

(10) So the assumption that allows the local embedding—namely, that a global actual infinite provides a universal coordinate frame into which all finite subsystems can be shifted—must be false.

(11) Hence actual physical infinities cannot exist, not merely because they allow endless addition, but because they undermine the determinacy of finite containment altogether.
