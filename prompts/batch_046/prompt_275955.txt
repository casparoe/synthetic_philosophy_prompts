Which of these pairs are genuinely in tension, which only appear to conflict but dissolve on inspection, and what is the least costly revision in each real case? Please rank the tensions by severity, specify for each which commitment would have to be modified or abandoned, and tell me whether a single revision could clean up more than one problem.
