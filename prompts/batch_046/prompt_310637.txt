I read a summary of the Lucas–Penrose anti-mechanist arguments in what seemed like a competent philosophy-of-mind article. Here is roughly what it said. Lucas begins with Gödel's first incompleteness theorem applied to any consistent formal system F adequate for arithmetic: there is a sentence G_F that, interpreted in the standard model, asserts its own unprovability in F. Lucas claims that any human mathematician H can recognize G_F as true, because H can see that if G_F were false then it would be provable in F, which would make F inconsistent, yet H knows F is consistent. So H can grasp a truth that F cannot prove. From this Lucas infers that H is not identical to F, and since F was arbitrary, no single formal system captures human mathematical cognition. The article then says Penrose strengthened the argument using Gödel's second incompleteness theorem: if H's reasoning were entirely algorithmic, running on some program P, then P would encode the belief that its own Gödel sentence is true; but for P to justify that belief, P would need to prove its own consistency, which Gödel's second theorem forbids for any consistent system. Hence human insight transcends computation. The summary added that critics like Benacerraf and Putnam miss the point because they only propose modeling the human by an open-ended sequence of systems F_1, F_2, ..., each replaced when its Gödel sentence is discovered; but Lucas and Penrose need only show that at any moment the human outperforms the single system she currently instantiates, which is enough to block reductionism. The article also dismissed the non-standard-model objection—where G_F might be false in a non-standard interpretation—by saying human mathematicians naturally restrict themselves to the standard model, so this technical escape route is irrelevant. Finally, it concluded that together these points "refute" the mechanist view that the mind is a Turing machine, and that anyone who denies this is implicitly denying the objectivity of mathematical truth. I am inclined to think the argument is basically sound, though I have heard that Penrose's appeal to physics is often misread. Is this summary fair? Please go through it carefully: distinguish what is accurate about Lucas's original reasoning, what Penrose actually added in his later work on consciousness and computation, whether the reply to Benacerraf's sequence objection succeeds, whether the dismissal of non-standard interpretations holds up, and whether the conclusion that mechanism is "refuted" rather than merely challenged survives scrutiny. Also, check whether there is any hidden conflation between consistency, ω-consistency, and soundness in how the argument is presented.
