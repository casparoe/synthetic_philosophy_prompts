Here's an argument I built for a seminar and now find suspicious because the conclusion is that the Meno problem basically dissolves, which feels wrong. (1) If knowledge is better than true belief, the extra value must come from whatever distinguishes them—call it X (justification, reliability, tracking). (2) X is always a feature of the process or the evidential relation behind the belief, never a feature of the belief-state itself. (3) So the "extra" value of knowledge is really just the value of having X, added onto the value of the true belief. (4) That makes knowledge a bundle: true belief plus a valuable process. (5) But then asking "why is knowledge better?" is like asking "why is a car with good brakes better than a car?"—it's trivial, not a deep philosophical puzzle. (6) To avoid that trivialization, defenders of the Meno intuition must say X doesn't just sit alongside the belief; it transforms the belief's value non-additively. (7) But that's mysterious—how does being reliably caused make the belief itself more precious, unless we already value the cause? (8) So either we accept the bundle view and the Meno problem collapses, or we accept mysterious value-transformation. (9) Since both are bad, maybe knowledge just isn't more valuable, and Socrates was wrong. (10) But I don't want to bite that bullet. Where does this go wrong? I'd realy like to keep (1) and the idea that there's a genuine puzzle here, not just a bundle.
