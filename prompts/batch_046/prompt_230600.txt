My study partner built this version of teh Euthyphro for a metaphysics paper and now it feels like it destroys every normative domain, not just morality. (1) Either p is good because God commands it, or God commands p because p is good. (2) If the first, then God's commands are arbitary—he could have commanded cruelty and that'd be good. (3) If the second, then goodness is independent of God, so divine command theory is false. (4) Now apply the exact same structure to aesthetic value: either something is beautiful because experts approve, or experts approve because it's beautiful. (5) By (2), if the first horn, then expert taste is arbitary—if they'd loved kitsch, kitsch'd be beautiful. (6) By (3), if the second horn, then beauty is independent of expert judgment, so aesthetic authority collapses. (7) So either aesthetic judgment is arbitary or experts have no authority. (8) But we clearly think experts can be authoritative and not arbitary. (9) So one of the premises in the original Euthyphro must be wrong, but which one? If we save divine command theory by rejecting (2), do we have to say that arbitary expert taste is actually okay? Or is there a hidden equivocation between "because" in (1) and (4)? Tell me which step to reject and what it costs, especially if I want to keep both divine command theory and teh idea that aesthetic experts aren't just guessing.
