Hey, long time lurker here. Been chewing on Black's spheres and PII lately, and I realized my intuitions are all over the place. Maybe yall can help me find the principle I'm missing.

Case 1: Classic Black setup - two spheres, otherwise empty symetrical universe, separated by a couple meters. I say they're distinct objects; the distance relation is real, so PII isn't violated. Fine.

Case 2: Same spheres, but there's some hidden internal clock that ticks differently for each one, though nothing in the universe can ever detect it. Now I feel like saying they're still distinct, but this feels like cheating - like we just smuggled in a distinguisher to save the principle. Should I count hidden relational properties?

Case 3: Two spheres that are physically identical in every measurable way, but one is an original and one is a perfect quantum clone with a different causal history. Even though every present test comes back the same, I want to say they're different. But then I wonder: if history isn't part of their present properties, why should PII care?

Case 4: One sphere sitting in a universe with perfect mirror symmetry, so there's a 'ghost position' where an identical sphere could be but isn't. I think there's just one sphere, not two absent ones. So purely modal or counterfactual differences don't count?

Case 5: Two spheres rendered in a computer simulation where the programmer copy-pasted the object data - same code reference, different coordinates in the world. Are there two spheres, or one sphere instantiated twice? My gut says the ontology should track what's in the world, not the code, but I'm not sure.

So my verdicts are: relational properties count (case 1), hidden ones feel like cheating (case 2), historical properties count even if not present (case 3), purely possible differences don't count (case 4), and representational redundancy is confusing (case 5). These don't line up neatly. Is there a coherent principle here - maybe weak vs strong discernibility? Or do I need to drop one of these? Specifically, what's the difference between 'distinguishable in principle by some hidden feature' versus 'distinguishable only by bare numerical difference'? I feel like I'm missing a concept that carves exactly there. What's the actual principle, and which verdict should I abandon?
