The tree should be built from the logical space, not just a list of names. So start with the big split: is there a coherent core? Then branch on whether geography or history matters, then on whether misuse invalidates the concept, etc. Note any empty combinations - like maybe nobody holds 'purely geographical but still normatively binding' - and briefly diagnose whether that's incoherent, unattractive, or just unexplored. Also flag any two positions that these questions can't actually seperate.
