Here's the answer they turned in:

Logical omniscience means that in standard epistemic logic if you know P and know P→Q then you automatically know Q, because knowledge is truth in all worlds you consider possible. So if I know 2+2=4 and I know that implies some huge chain, I instantly know everything that follows, including Fermats theorem. This is unrealistic.

The Fagin-Halpern model fixes this with awareness sets. Each agent has a set of formulas they're aware of, and they only know things within that set. So if Fermats theorem isnt in my awareness set, I dont have to know it. This fully solves omniscience because it puts a psychological cap on what you can know.

There's also the computation view, which is basically the same idea but talks about CPU time instead of awareness. Both say you dont know Q because you havent done the work yet. So explicit knowledge is what you've computed or are aware of, and implicit is the rest that follows logically.

In the arithmetic case, knowing Peano axioms gives you implicit knowledge of every theorem, but explicit knowledge only covers what youve actually derived. The awareness model captures this by putting the axioms in your awareness set but leaving Fermat out until you derive it. So yes, it resolves the problem completly.
