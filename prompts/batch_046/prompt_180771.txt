(2) Rationality requires only that an agent select the program that maximizes her expected payoff, given her beliefs about the opponent’s code. (3) For any opponent program Q, there exists a best-response program P that runs Q on a faithful copy of P’s own source and returns Cooperate precisely when Q does so, and Defect otherwise. (4) Hence, whenever both agents are rational, each submits such a mirror program; each execution verifies mutual cooperation and returns Cooperate. (5) The payoff structure therefore collapses to the Pareto-optimal outcome, regardless of the game’s nominal payoffs. (6) This construction generalizes: for any strategic-form game, rational agents can write source-code inspectors that conditionally replicate the opponent’s intended move, thereby eliminating all conflict. (7) So rational self-interest can never generate a genuinely suboptimal equilibrium; every observed failure of cooperation must stem from either computational error or irrationality.
