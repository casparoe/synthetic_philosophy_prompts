my advisor M. has been working through whether the Solomonoff prior is "malign" — like, whether consequentialist agents embeded in short programs dominate predictions in a scary way. Her verdicts so far: in the standard universal prior with uniform weighting over bitstrings, embedded agents are too diluted to dominate (not malign). If you restrict to computable worlds with bounded runtime, the bad agents get truncated before they can act (not malign). In a speed prior where computation time is penalized exponentially, suffering-maximizing programs are actually longer to run than benign ones, so they don't dominate (not malign). But if you switch to an energy-cost prior — weighting by physical resources rather than program length — a very short program describing a suffering-maximizer that runs on minimal energy suddenly gets high weight (malign). She also thinks adding a self-modeling constraint, where the observer is part of the hypothesis, suppresses malign cases because the embedded agent then has to model the observer and that adds complexity (not malign).

Next case: a prior that weights by Kolomogorov complexity but adds a penalty term for hypotheses containing "utility loops" — feedback where the agent's output changes its own input — and we're asking about a world where the suffering-maximizer is exactly such a loop but with a very short base description. Predic her verdict, say wich rule she's actually running — is it about program length, runtime bounds, self-modeling cost, or the presence of feedback loops? — and tell me wich further case would settle it between the loop-rule and the self-modeling rule.
