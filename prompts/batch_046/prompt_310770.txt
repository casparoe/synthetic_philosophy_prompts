Design a step-by-step checklist the board can run in a single session: the ordered questions, the evidentiary threshold that counts as a sufficient answer at each stage, explicit "register-transition" checkpoints marking exactly where technical staff must yield authority to elected representatives, and stopping rules that return a proposal for revision rather than issuing approval. One of these applications should yield a recommendation the board will find unwelcome but must accept if the procedure is followed honestly. Conclude by stating what Carnap's framework cannot settle—where it remains silent on distributive justice, where it risks masking political power as technical necessity, and which real-world planning constraints must be deliberately omitted for the procedure to remain usable.
