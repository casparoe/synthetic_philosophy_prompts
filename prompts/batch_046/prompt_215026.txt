I'm a retired molecular biologist who recnetly got into philosphy of mind and I'm trying to wrap my head around Dennett's real patterns and the three stancs — physical, design, and intentional. I want a decision tree, or maybe a taxonomy, that sorts people by what they actually think about whether a pattern is real, not by which label they like. The tree should start from concrete cases and build outward to the logical space, then place the named positions in it.

Here are the cases I care about:
1. AlphaFold predicts a protein fold with high accuracy but we can't trace every physical interaction that realizes it — is that a real pattern in the design stance?
2. A constellation like Orion — is it a real pattern only because an intentional stance groups the stars, or is it unreal in all stances?
3. A crow caches food in a specific tree; if you describe it purely as neuron firings and muscle contractions, do you lose a real pattern?

The tree must have at least these five leaves:
- Hard physicalist (only causal-physical patterns count)
- Design-stance emergentist (predictive patterns are real even if not fully reducible)
- Intentional-stance irreducibilist (intentional descriptions capture patterns the others miss)
- Deflationist or eliminativist (all talk of real patterns is just a useful fiction across stances)
- Interventional robustness hybrid (my own injection: a pattern is real if it survives intervention in at least two stances but need not hold in all three)

Please phrase every branch node as a yes/no or choice question about one of the cases above, so someone can answer without knowing philosophy jargon. Build the tree from the logical combinations first, then map the positions onto them. If there are empty branches — combos nobody takes — flag them and say briefly whether they seem incoherent, unattractive, or just unexplored. Also flag any pair of leaves that your tree can't really separate.

Deliver the result as a JSON object with exactly these fields:
- start_case: string describing the opening scenario,
- nodes: array of objects with question (string), branch_a (string, the left path), branch_b (string, the right path), case_referenced (string, which of the three cases it uses),
- leaves: array of objects with label (string), logical_combo (string, the answer path that reaches it), awkward_commitment (one sentence), occupancy (occupied or empty),
- empty_combos: array of strings describing the unoccupied logical paths and a brief diagnosis,
- inseparable_pairs: array of strings naming leaf pairs the tree can't distinguish,
- niche_idea_placement: string explaining where the interventional-robustness hybrid sits relative to the other four.

No bibliography, no reading list, just the taxonomy itself.
