hey, i've been wrestling with this argument about the reference class problem that my study group cooked up, and it feels like it should be broken but i can't pinpoint the crack.

(1) Every rational credence about yourself must be grounded in a reference class R such that you know you belong to R.
(2) For any R, there is always a proper subset R* that you also belong to and that is equally well-known to contain you (e.g., if R is 'humans', R* is 'humans born on a tuesady').
(3) So if conditioning on R is rational, conditioning on R* must also be rational, since the justification for R applies to R* too.
(4) By induction, the only fully justified reference class is the singleton {you}.
(5) But statistical reasoning requires a non-singleton class; you can't compute frequencies over one member.
(6) Therefore statistical reasoning about yourself is never rationally justified.
(7) But clearly we do rationally think things like 'i'll probaby live past 60' based on demographic data.
(8) So (1) is false and there are no rational constraints on reference class selection?

i feel like there's a hidden slide between (2) and (3) — maybe 'equally well-known' smuggels in something about relevance? — but i'm not sure. also if (1) really falls, doesn't that make reference class choice totally arbitrary? that can't be right either. where's the actual mistake, and what's the least painful fix?
