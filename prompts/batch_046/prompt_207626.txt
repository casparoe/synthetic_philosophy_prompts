I've been playing with the idea that Popper's verisimilitude problem mostly dissolves if you swap classical entailment for a paraconsistent relevence logic and let false atomic claims carry graded disutility instead of straight-up falsity. So a false theory can still be closer to the truth if its false parts are 'relevently isolated' and its true parts are structurally central. What would actually count against this? I don't want the usual Miller-Tichy line, since I'm already trying to dodge that. I want the defeaters specific to this patched version: formal results about relevence-logic consequence spaces, intuition pumps about theories that are mostly right but have one wildly wrong yet irrelevent axom, and whether this collapses into some weighted coherence view of confirmation. Which of these would a defender concede, and which could they brush off? Rank them from fatal to merely embarasing. Also, has 'relevance' just become a fudge factor that makes the view unfalsifiable, and if so is that actually a problem here?
