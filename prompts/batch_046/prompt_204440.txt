As a novelist constructing a multi-volume narrative set within a persistent virtual world, I require an operational procedure I can apply repeatedly—under publication deadlines and without philosophical training—to determine whether a given virtual-world event should carry the narrative weight of a real harm (lasting trauma, legal liability, moral obligation) or be treated as an ephemeral virtual occurrence with only transient emotional effect. For this fictional ontology, I have adopted the following principle: a virtual object possesses cross-layer integrity when its substrate-state (server records, executable code) and its narrative-state (the user's experienced reality within the fiction) remain stably coupled for all interacting parties; a harm is real if and only if it violates this cross-layer integrity and produces sustained embodied disruption in the affected party—defined as physiological or psychological effects that persist beyond the immediate session—rather than merely transient affective response. Please translate this principle into a reusable decision procedure: a sequential checklist or ordered flowchart in words that distinguishes substrate-level damage, narrative-level disruption, and embodied persistence. The procedure must handle hard cases where judgment is unavoidable, flag them explicitly, and state clearly what it cannot settle. Include worked applications to three plot scenarios: first, a user's registered virtual estate is destroyed by a server migration error, producing only brief annoyance that resolves within the hour, yet the user demands narrative justice for the property loss; second, a virtual assault produces no substrate alteration but induces lasting insomnia and hypervigilance in the user; third, a malicious script permanently alters an avatar, generating intense immediate rage that fully dissipates within a day. In one of these applications, the procedure should yield an answer that conflicts with intuitive narrative expectations, and you should identify which one and explain why. Conclude by stating the limits of the procedure—specifically, which distinctions must survive simplification and which can be dropped, and where editorial judgment must take over.
