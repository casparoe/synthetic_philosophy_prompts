I was trying to wrap my head around the poverty-of-stimulus argument -- the idea that kids pick up complex grammar rules despite getting almost no explicit correction or negative examples (like parents rarely tell them "you can't say *the boy running is"). This is supposed to prove language is partly hard-coded.

But I built this chain and now it feels like it proves way too much:

(1) If people master a complex system with very little explicit feedback or negative evidence, then that system must depend on innate structures.
(2) Kids master language with almost no negative evidence for grammar.
(3) So language depends on innate structures.
(4) But kids also master social hierarchy navigation, face recognition, and intuitive physics with even less explicit teaching than grammar gets.
(5) So by (1), those all depend on innate structures too.
(6) Meanwhile LLMs learn grammar from next-token prediction over raw text with zero built-in linguistic structure, no negative examples at all, and they still generate syntactically correct sentences.
(7) So if (6) is right, then (1) is false for language specifically, which means we need some special reason language is innate but social cognition isn't, even though both fit (1).
(8) Or if we keep (1), then LLMs must secretly have innate linguistic modules baked into thier architecture, which sounds nuts.
(9) So either everything mental is innate, or nothing is, or LLMs are biologically wired, all of which seem wrong.

Which step should I reject? I'd like to keep (1) and (6) if possible because they feel intuitive from my ML background, but I know I'm probably smuggling in something about "mastery" being different for kids vs models. What's the actual weak link, and what does giving it up cost me?
