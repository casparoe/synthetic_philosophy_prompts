I run a philosophy of mind workshop for about 18 grad students, 45 minutes, one session. I want a classroom game that makes them feel the frame problem — the asymmetry between tracking what changes and tracking everything that doesnt — rather than just hearing the usual AI origin story named. Design rules, materials, and a payoff scheme that doesnt use cash. Teams of three maintain a physical board with tokens for every object in a robot-kitchen scenario. After each action card (e.g., arm picks up cup), they place a frame token on every item or state that remains unchanged and defend it out loud. They earn one point per correct invariant, but if they miss one the facilitator silently removes it and that team skips the next round. At round three, flip the rules: they must defend a previously missed invariant using only negative descriptions (it is not broken, not moved, etc.). The debrief should map the exhaustion onto the logical frame problem, be frank that the activity simulates the logical explosion but cant reproduce the computational tractability issue — you'll have to supply that part verbally — and say exactly what will predictably go wrong the first run and how to fix it. Start with a one-sentence bottom line on the failure mode. Hard cap: 400 words. No bibliographies or citations needed — it should run from the prompt alone.
