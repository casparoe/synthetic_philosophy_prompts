hey so im in this philosophy of logic course and we spent a week on carrolls tortoise and whether deduction can ever justify itself, and i tried pushing the argument further but now ive built this chain that feels like it proves rational belief is impossible, which cant be right. heres the setup:

(1) carroll shows that if you need modus ponens as an explicit premise to apply it, then you need another rule to apply that premise, so justification of deduction collapses into infinite regress.
(2) the usual escape is formalization: you encode the rules in a proof system and apply them mechanically in the metalanguage, so no extra premise is needed.
(3) but then gödels second incompleteness theorem applies: any consistent formal system strong enough for arithmetic cant prove its own consistency, which means the metalanguage rules themselves rest on a consistency assumption that the system cant justify.
(4) so either we climb to a meta-metalanguage and keep going forever, or we bottom out at some base inference rule that we just accept without any further justification.
(5) now if every chain of reasoning eventually terminates in an unjustified, bare acceptance of a rule, then no belief is ever rationally justified, because every justification traces back to that ungrounded step.
(6) therefore rational belief formation is impossible, which is clearly absurd since we have plenty of rational beliefs.
