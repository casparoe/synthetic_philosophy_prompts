After arguing with a friend about risk communication and statistical reasoning, I have ended up with four commitments that feel like they should form a coherent package, but I suspect they do not. (1) The reference class problem has no context-independent solution: whether I belong to the class “forty-year-old male” or “sedentary male with family history” depends on the decision at hand, not on a hidden metaphysical fact about similarity. (2) Base-rate neglect is a genuine cognitive failure, not merely a framing disagreement—ignoring prior prevalence is an error in reasoning, not just an application of different norms. (3) The only principled, non-arbitrary way to resolve ambiguity is modal proximity: my correct reference class should be the set of nearest possible worlds in which I share the causally relevant properties, which seems to yield a unique answer without pure subjectivity. (4) Yet this modal rule itself encodes a normative judgment about which properties count as causally relevant, so selecting a reference class is ultimately a value-laden choice disguised as statistical discovery. Do these hang together? Specifically, does (3) conflict with (1) by smuggling back a fact of the matter, or does that tension dissolve once we see (3) as a normative convention operating inside (1)? And if (4) is right, does it undermine (2)—is base-rate neglect just disagreement over norms rather than an objective reasoning failure? I want an audit: which pairs are genuinely incompatible, which only appear so, and what the cheapest repair would cost me.
