I have been working through a conceptual problem for a seminar on AI safety, specifically whether "avoid side effects" can be given a value-neutral formalization. To test the idea, I constructed an argument that treats any agent's computation as a branching causal tree, where "intended" branches are those constitutive of the algorithm and "side-effect" branches are all other physical and informational divergences from a counterfactual baseline in which the agent was never activated. (1) If we are to avoid side effects without a complete specification of value, we must be able to draw this boundary using only structural or physical criteria—energy budgets, spatial reach, or information-theoretic distance—rather than by appealing to which outcomes are desirable. (2) But to classify a particular thermal emission or belief-update in an observer as belonging to the "intended" branch rather than a side branch, we must know what the computation is meant to achieve, and that purpose is fixed by a goal specification that encodes value judgments. (3) Without such a specification, there is no principled distinction between running the algorithm and altering the world; every physical consequence of the agent's existence is on a par. (4) Hence any metric that penalizes some divergences but exempts others—say, counting joules dissipated but not predictions formed—already smuggles in a partial value theory about which states of the world matter. (5) If we try to avoid this smuggling by penalizing all divergences equally, then the agent's own reasoning, which necessarily produces heat, electromagnetic fields, and updated beliefs in anyone who observes it, becomes an impermissible side effect, which implies the agent cannot act or even initiate. (6) Therefore "low impact" either requires a full value specification to justify its boundary, or it collapses into a prohibition on computation itself; since the intuitive project is to allow cautious but real action, the concept must be incoherent. I feel the slip is somewhere between steps (3) and (5), perhaps involving an equivocation between "value specification for the boundary" and "value specification for the goal," but I cannot name it precisely.
