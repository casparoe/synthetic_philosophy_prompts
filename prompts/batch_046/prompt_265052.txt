For a philosophy-of-mind seminar on artificial sentience, write a decision-tree taxonomy that classifies positions on which computations carry moral weight. Begin with the branch: does substrate-independent functional organization suffice for moral status? From there, split on temporal persistence (does a suspended computation retain status across interruption?), causal-environmental coupling (must processing be continuously embedded in a feedback loop?), and representational autonomy (must self-modeling be internally generated rather than constructed via external lookup?). At each node, pose a concrete diagnostic case—such as a brain emulation paused for a century, a distributed cloud process running only on intermittent nodes, or a system that builds self-representations solely by querying an external database—so that answers depend on judgments about the case rather than familiarity with labels. Map the terminal combinations onto named or clearly describable views: strong computational functionalism, biological naturalism, an integrated-information boundary view, a process-relational account, and eliminativism about computational moral status. Flag any logically possible answer-combinations that appear unoccupied and briefly diagnose whether the gap is incoherent, unattractive, or merely unexplored. The instrument should contain no bibliography requests and should be designed to sort people by what they believe about these cases, not by which term they prefer.
