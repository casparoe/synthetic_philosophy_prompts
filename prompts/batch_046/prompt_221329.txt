The hole argument is usually taken to show that, if spacetime points are metaphysically substantial, then general relativity is indeterministic: a diffeomorphism that moves points around inside a hole yields a different assignment of metric values to the same points, with no physical difference. But if point-identity is genuinely undermined this way, how can numerical relativists coherently compute curvature at specific grid points in a black-hole merger simulation? Within any single model the metric is still a function on the manifold, yet if points lack independent reality, what fixes the value at p rather than at q? Is practical GR therefore implicitly substantivalist, or can a relationalist interpretation license point-local computation without treating those points as physically real? And if relationalism can accommodate such computations, why do some recent point-free reformulations—along shape-dynamics lines—insist that a genuinely relational theory must abandon coordinate-based representations entirely?
