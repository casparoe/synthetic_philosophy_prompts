Write a two-page proposal for a one-semester philosophy-of-science workshop pitch on a question in the doomsday-argument literature that standard treatments have not addressed. The standard argument, as developed by Carter and refined through the self-sampling and self-indication debates, predicts human extinction timelines by treating one's birth rank as a random draw from a uniform prior over all observers in a reference class defined by species membership. The half-formed idea is this: instead of defining the reference class by chronological birth order alone, define it by an observer's epistemic access to aggregate demographic data—creating a "knowledge-state reference class" in which observers are partitioned according to whether they possess coarse-grained or fine-grained information about total historical population size. Your proposal should state the precise research question: does substituting this epistemic-state partition for the temporal-birth-rank partition preserve Carter's Bayesian conclusion, dissolve it by breaking the conditions for self-sampling, or expose a hidden ambiguity in how the reference class is fixed? Explain why existing answers—the original uniform-prior formulation, the self-indication response, and standard reference-class objections—leave this open: they all assume that membership in the reference class is determined by biological or temporal properties, not by what an observer knows about the class itself. Outline the method in stages over the available time: (1) formalize the knowledge-state reference class with a simple two-type Bayesian model (coarse-access vs. fine-access observers); (2) derive the extinction-probability updates for each type under both the self-sampling and self-indication assumptions; (3) compare the results to Carter's original predictions; (4) determine whether any divergence is substantive or merely an artifact of prior selection. Specify what a successful result looks like (a determinate verdict on whether epistemic-state partitioning undermines the doomsday reasoning) and what failure looks like (the analysis collapses back into the familiar reference-class debate without yielding a new distinction). Assess scope honestly: this is a conceptual modeling exercise rather than an empirical demographic study, so it is feasible within a single semester, but flag the specific risk that formalizing the prior over knowledge states may require more decision-theoretic machinery than can be developed alone, and say how you would constrain the model to avoid that risk. Refer to positions and arguments by descriptive name only; do not provide a bibliography, reading list, or citations, and indicate that references will be added separately. Finally, state how confident you are in the feasibility of each stage of the method, and single out the specific point about which you are least certain.
