(1) In the MIU system, you can only derive strings using the four rules, so you're trapped inside.
(2) To solve whether 'MU' is derivable, you need to jump out and reason about the system as a whole — that's JOOTSing.
(3) But any reasoning you do about MIU still uses logical rules, which form their own formal system (call it Meta-MIU).
(4) So the 'jump' isn't really out; you've just entered a bigger box with its own rules.
(5) By inductin, every supposed jump out is really a jump into a higher-level formal system.
(6) Therefore no one ever actually jumps out; there's always an enclosng system.
(7) If that's true for MIU, it's true for human minds too: any attempt to think about our own thinking just runs on higher-level neural/cognative rules.
(8) So Hofstadter's claim that consciousness comes from strange loops that somehow transcend their substrate is wrong — there are no strange loops, only nested boxes.
(9) But this also means mathematicians never genuinely invent new axioms; they just apply hidden rules of Meta-ZFC. That feels like it proves too much.
