Set out the contrast between a substrate-independent functionalist framework and an embodied-homeostatic framework regarding the moral status of computational processes. On the functionalist side, moral status attaches to any system that implements a global workspace architecture with sufficient information integration and recurrent processing, regardless of physical substrate or bodily coupling. On the embodied-homeostatic side, moral status requires that the computation be causally entangled with biological regulatory loops—directly participating in maintaining an organism's physiological equilibrium—rather than running as an isolated simulation. Examine how each framework evaluates a high-fidelity software emulation of a human brain running on a distributed server cluster with no sensory-motor coupling and no metabolic feedback. Then, introduce and assess a further case: a 'fragmented workspace' in which the same physical substrate hosts multiple parallel global workspaces that share a memory pool but lack cross-integration or unified access. For each framework, determine whether each fragment counts as a distinct moral subject, whether substrate-level unity collapses them into a single subject, or whether the case exposes an internal tension. Conclude by arguing which framework yields the more coherent account of both the emulation case and the fragmentation problem, and identify the precise crux—functional individuation versus biological anchoring—where the two views irreconcilably diverge.
