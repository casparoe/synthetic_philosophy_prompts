i've been playing with the idea of cleaning up people's prefernces — you know, more information, no logical contradictions, that sort of thing — and then using the result to guide decisions. the usual framing is individual: fix person A's mess, fix person B's mess, then aggregate. but i've noticed a pattern where fixing A's preferences actually changes what B's cleaned-up preferences should be, and vice versa, in a way that isn't just about social choice. concrete case: A initially wants aggressive climate action, B wants economic growth first. after idealization, A's preferences might depend on whether B's idealized self ends up caring about long-term risk; if B does care, A can support a gradual transition, but if B stays growth-focused, A's corrected view shifts to demanding immediate regulation because the cooperative path is blocked. so the 'true' preference for each person isn't defined in isolation — you have to solve for the pair simultaneously, like a system of equations. is there an established term for this kind of interdependance inside the idealization step itself? i've seen 'coherent extrapolated volition' used for group-level coherence, but that usually treats individuals as inputs that get merged, not as variables that change each other during correction. is this just a version of reflective equilibrium applied to preference sets, or is it a distinct failure mode? if there's no name, can you define it precisely — especially how it differs from ordinary strategic interaction and from simple aggregation problems — and say whether it undermines the whole idealization project?
