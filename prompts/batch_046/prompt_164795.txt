I read a summary of the Lucas-Penrose anti-mechanist argument on a philosophy blogg and I'm trying to figure out if it's being fair. The blogger writes: Godel's first incompletness theorem shows that any consistent formal system strong enough for arithmetic contains true sentences it can't prove. Lucas then said human mathematicians can recognize the Godel sentence of any system we understand, so we do something that system can't do. Penrose strenghtened this with the halting problem: we can tell that specific Turing machines don't halt, which no single algorithm can do in general. Together this proves the mind isn't running a fixed deterministic algorithm or formal system, so computationalism about the brain is false—even for probabilistic or neural-network models. The blogger also brings up Benacerraf's objection that humans might just be inconsistent systems, and says Penrose answered this by noting that an inconsistent mathematician couldn't do reliable math, so our consistency proves we're not mechanizable. I feel like there's a slide between Lucas's consistency-based version and Penrose's computability version, and maybe the conclusion overreaches, but I'm not sure which parts are legit simplifications and which are real errors. Can you go through it carefully? I want to know what's accurate, what's a standard gloss, what's subtly misrepresenting either Lucas or Penrose, and whether the claim that this defeats all computationalism—including connectionist ones—actually survives once the errors are fixed.
