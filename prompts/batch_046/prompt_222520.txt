Exam question: David Lewis's counterpart theory rejects transworld identity for concrete particulars, holding that modal claims about an object are made true by the existence of similar counterparts in other worlds rather than by that very object being present elsewhere. Recently some philosophers have proposed extending this framework to structured abstract objects—specifically, to scientific theories—under a view we might call structured-proposition counterpartism (SPC). According to SPC, a theory T formulated in world W is not identical to any entity in world W' unless W' contains an axiomatic counterpart that preserves T's full structural profile; if no such counterpart exists, then T is not false in W', but rather modally absent from it. Evaluate SPC. In your answer, (a) explain why Lewis originally restricted counterpart relations to concrete, spatiotemporally located entities, (b) assess whether SPC correctly applies Lewisian machinery to theories considered as structured propositions, and (c) identify the specific conceptual error that results if one assumes that evaluating a theory's truth-value at W' requires that the theory (or its counterpart) be present in W'.

Student answer:

Lewis denies transworld identity for concrete individuals because an object cannot have contradictory intrinsic properties. If I had brown hair in W1 and red hair in W2, that would violate non-contradiction if it were literally me in both worlds; so W2 contains only a counterpart that resembles me. This reasoning is tied to spatiotemporal location and intrinsic change, which is why Lewis applies it to concrete particulars.

SPC tries to do the same for scientific theories. It says Theory T in W1 has a counterpart in W2 only if the axioms match exactly. If W2 has different physical laws, there is no axiomatic counterpart, so T is not false there—it is modally absent. This avoids a problem: if T were the very same abstract object in both worlds, and true in W1 but false in W2, that would be like me having brown hair in W1 and red hair in W2—an intrinsic contradiction across worlds. So to avoid contradiction, we should either use counterpart relations or deny that T is present in W2 at all.

But SPC misapplies Lewis. Lewis allows that abstract objects—sets, numbers, and structured propositions—can be identical across worlds because they lack spatiotemporal parts and do not change. So theories should be able to exist in W1 and W2 as the same entity. The evaluation of T at W2 is just a semantic relation: we check whether W2 satisfies T. That does not require T to be "in" W2 in any robust sense, but it also does not require a counterpart. The real error in SPC is conflating evaluation conditions with existence conditions: it thinks that for T to be false in W2, T must be present there via a counterpart. Actually, if T is identical across worlds, there is no contradiction in its being false in one world and true in another, because truth is world-relative, not an intrinsic feature of the theory. Therefore SPC is unnecessary; we can keep transworld identity for theories and simply say they are evaluated differently across worlds.
