ok so me and my roommate were arguing about Black's spheres for a metaphysics paper and we ended up with this argument that feels like it proves way too much. can you tell me where it breaks?

(1) Leibniz's principle of identity of indescernibles says if x and y have literally every property in common then x is y.
(2) In Black's thought experiment the two spheres share all intrinsic properties and all the relational ones we can observe: each is iron, each is one mile from the other, etc.
(3) But we realized that if you embed the universe in a 5-dimensional Kaluza-Klein model with the extra dimension curled up at Planck scale, sphere A can sit at coordinate θ=0 and B at θ=π. That difference is physically undetectable.
(4) So they actually differ in one hidden relational property.
(5) If that saves the principle, then the principle is unfalsifiable — for any apparently identical pair you can always postulate some hidden coordinate or quantum vacuum mode they differ in.
(6) An unfalsifiable principle is useless, so we should reject (1) and admit pure numerical difference (haecceities).
(7) But then look at quantum mechanics: two electrons in a box share every observable property, and physicists say they're genuinely indistinguishable, not just hiding some secret haecceity.
(8) So if we reject the principle for Black's spheres, we should also reject it for electrons and say each electron has a hidden identity.
(9) That contradicts standard quantum statistics and also violates Occam's razor because we're multiplying hidden entities for every particle.
(10) So either the principle is false everywhere (making quantum mechanics wrong about indistinguishability) or it's true but saved only by unfalsifiable hidden properties. Both seem bad.

which step should i give up? i kinda want to keep (1) because it feels like a basic logical principle, but i also don't want to say electrons have secret names. what's the cost of each option?
