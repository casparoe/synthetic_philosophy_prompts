I read a summary in some pop-philosophy book about Hacking’s looping effects in psychiatric classification. The author says mental-illness categories are “interactive kinds” — unlike quarks — because getting labeled actually changes people’s behavior, which then forces clinicians to update the criteria. So the loop works like this: psychiatrists invent a label like borderline personality disorder, patients internalize it and start performing the stereotype, and then doctors see more of those traits and tighten the diagnosis. From this the book concludes that psychiatric categories don’t track any real biological patterns at all; they’re pure social constructs that only survive because we keep reinforcing them through diagnosis. It also claims Hacking thought the DSM is basically a self-fulfilling prophecy manual, and that if we just stopped diagnosing BPD the loop would break and the condition would mostly disappear.
