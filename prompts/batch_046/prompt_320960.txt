I have reconstructed an argument from the School of Names tradition—specifically the reasoning associated with Gongsun Long’s white-horse case—and generalized it into a formal chain that seems to destroy taxonomy altogether. The reconstructed argument runs as follows.

(1) If a kind K is predicated of an object and a determinable property P is also predicated of it, then the composite description “K-and-P” picks out a class that includes things which are P but not K.
(2) The class of white things includes white snow and white cloth, which are not horses; therefore “white horse” picks out a class extending beyond “horse.”
(3) If two descriptions pick out different classes, they do not denote the same kind.
(4) So “white horse” and “horse” denote different kinds.
(5) If an object falls under a kind-denoting term that is not identical to K, then that object is not a K.
(6) Therefore a white horse is not a horse.
(7) The form is fully general: for any kind K and property P, a K-that-is-P belongs to a kind other than K.
(8) Because every particular object instantiates some determinable properties, no object ever belongs to the kind it is ordinarily said to belong to.
(9) Taxonomy and kind-membership collapse entirely.

A friend insists the error is in (5), arguing that it illicitly moves from semantic non-identity to metaphysical exclusion. I worry that blocking (5) requires treating properties as metaphysically inert with respect to sortal membership—saving taxonomy only by insulating an object’s kind-identity from its descriptive conditions, which seems a high price. Meanwhile, blocking (3) requires treating different extensions as compatible with kind-identity, which seems to undermine the idea that kinds are defined by membership conditions. Is the real flaw a hidden scope ambiguity between the semantic level of (3)–(4) and the object-level of (5)–(6), or is there an equivocation in (1) between “the class of P-things contains non-K members” and “the compound kind K-and-P contains non-K members”? And if the argument is actually valid, which premise—(1), (3), or (5)—is least costly to abandon without rendering the School of Names reasoning trivial?
