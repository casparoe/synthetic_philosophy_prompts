ok so i need to check if my punishment philosophy actually hangs together before i present it to my seminar. here's roughly where im at (probably with a typo or two):

1. i think punishment is only justified if its deserved, and severity should track culpability exactly—not deterrence, not social utility.
2. but i also think the state only gets to run a punishment system at all if the overall outcomes are better than not having one—like a consequentialist gate on institutional legitimacy, not on individual sentences.
3. proportionality is non-comparative: how much X should get depends only on X's culpability, not on whether some other crime gets treated differently.
4. that said, i think white-collar fraud should carry harsher sentences than street theft with identical culpability, because the social harm and breach of public trust means society needs to signal stronger condemnation.
5. i reject pluralist or communicative theories that say punishment serves desert and reform together; reform is a side-effect, never part of justification.
6. but i do think if an offender is fully rehabilitated before sentencing, we should still impose the full deserved punishment, though we might serve it in a community setting if that sends the same expressive message.

so which pairs actually fight? im especially worried about (3) vs (4)—if culpability is identical but i want different sentences, am i just sneaking in consequentialist harm? and does (5) clash with (6) since im using "expressive message" to pick the mode? also is (2) compatible with (1) or am i wanting cake and eating it? rank the tensions by severity, say for each whether its real or only apparent, and give the cheapest fix. keep it logical, no need for bibliographies.
