Question: Gradual neuron-replacement uploading is usually discussed like a Ship of Theseus case. I made up a variant called "staggered mirror-upload": each silicon chip doesnt copy the old neuron directly but runs a predictive model of what that neuron *would* have done based on the remaining biological tissue, then gets wired back in. By the end theres no biology left, but every chip was modeling missing context rather than inheriting direct causal history. Does this preserve personal identity / phenomenal continuity, or does it build a parallel simulation that hijacks the stream? Discuss using the physical-continuity view and the psychological-continuity view.

My answer:
The physical-continuity view says you need the same continuous physical substance, so this definately fails—once the last neuron is replaced theres zero biological tissue left, and sitting in the same skull doesnt save spatiotemporal continuity. The causal path is broken at every step since the chip is downstream of a model, not the original neuron.

For psychological continuity (Parfit / Locke), mental states must be linked by the right kind of causal dependence. Here each chip is only causally tied to the predictive model, not directly to the prior mental state, so the chain is broken and psychological continuity fails too. That said, the overall functional architecture is preserved, so maybe a psychological twin survives without being me.

This also connects to Chalmers fading-qualia argument: because the chips lack intrinsic biological causal power, phenomenal quality gradually fades and gets replaced by a zombie-like simulation running in parallel. So by the end we have a twin that behaves right but has no real phenomenal stream.

Also, some people think spatiotemporal continuity is kept because the chips stay in the original brain location, but thats wrong—location alone doesnt do the work.
