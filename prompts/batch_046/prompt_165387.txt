Exam Question:
Quine uses the gavagai thought experiment to argue that reference is underdetermined by all available behavioral evidence. First, explain that argument and why introducing analytic hypotheses does not eliminate the underdetermination but only relocates it. Then apply the framework to this case: a field linguist translating an isolated language hears the particle tavi uttered consistently when a speaker points to a ship whose planks have all been replaced, denies that the ship has disappeared, but also denies strict numerical identity with the earlier vessel. One manual translates tavi as naming an enduring substance; another translates it as naming a four-dimensional worm of temporal stages linked by spatiotemporal continuity. The observable patterns of assent and dissent are identical under both manuals. Does Quine’s thesis of ontological relativity resolve which manual is correct? Or does the indeterminacy extend to ontological commitments about persistence through time?

Student Answer:
Quine imagines a linguist who hears natives say gavagai whenever a rabbit runs past. The same behavioral data—pointing, assent, dissent—fit translating the term as rabbit, as undetached rabbit part, or as a rabbit temporal stage. The problem is not missing data but that the data underdetermine the reference relation. To fix meanings we need analytic hypotheses: a translation manual that correlates native expressions with our own and assigns beliefs and logical structure. But these hypotheses are themselves empirically underdetermined, because we can permute reference assignments for theoretical terms and compensate by adjusting hypotheses about native belief and logic. So underdetermination is not solved; it is shifted into the manual.

The tavi case has the same structure. Manual A takes tavi to refer to an enduring ship; Manual B takes it to refer to a perdurant sequence of stages. Both reproduce the behavioral evidence if paired with suitable analytic hypotheses about how natives deploy identity and continuity predicates. So there is no empirical fact of the matter about whether tavi picks out an enduring object or a stage-sequence.

Quine’s ontological relativity addresses this directly. He holds that questions about what really exists only make sense relative to a background theory or language. Choosing Manual A makes our ontology include enduring ships; choosing Manual B makes it include temporal stages. Thus the dispute is resolved: both manuals are correct relative to their frameworks, and no deeper metaphysical question remains.

One might object that Manual B needs a non-classical logic to handle continuity without identity, and that Quine’s principle of charity should block this, since charity requires maximizing agreement on logical truths. But Quine’s holism permits logical revision: we can alter our logic if we make compensating adjustments elsewhere. So charity does not uniquely fix classical logic, and Manual B stays viable.

Therefore the tavi case confirms Quine’s view. The reference of tavi is indeterminate, and ontological relativity dissolves the appearance of a substantive disagreement about persistence.
