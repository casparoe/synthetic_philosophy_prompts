I run a seminar, ~10 people, mostly rationalist-adjacent with some CS background, 90 minutes. Design an allocation game that makes them feel the boundary problem for moral attribution — the tension between substrate-independent computation (if it's running the right predictive-processing loop, it counts) and embedded causal integration (it only counts if it's coupled to the world through continuous biological sensory-motor channels).

Don't lecture up front. Give them limited "protection tokens" to distribute across entities that vary on both axes: identical algorithms running in silico vs embedded in organisms, high-complexity disembodied loops vs low-complexity fully embodied ones, etc. The payoff structure should force them into a coordination failure or repugnant conclusion before anyone names it — like having to deny tokens to something that feels wrong, or granting them to what amounts to a spreadsheet with sensors.

Then the debrief: map each round onto the two positions, flag what will predicatbly go wrong (probably people smuggling in consciousness-talk to resolve the tension), and be honest about which feature of the real philosophical problem the game can't reproduce — likely the actual phenomenology gap.

No prereading, no citations, keep it fully runnable.
