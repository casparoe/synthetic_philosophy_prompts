hey i'm trying to figure out if the nonidentity problem actually does anything in reproductive ethics, and i think i've backed myself into a cornor. here's what i have:

(1) origin essentialism is true: you're the same person because of that specific sperm-egg combo, not just any kid with your DNA.
(2) the nonidentity problem: if action A brings P into existance with harm H, and P wouldn't exist under B, then A doesn't harm P (the comparison is with nonexistence, not existence-without-H).
(3) now imagine parents freeze embryos in 2024. in 2054 they thaw one and implant it. embryo A has a gene for chronic moderate pain; embryo B doesn't. they pick A.
(4) kid C is born with the pain gene.
(5) C can't say "pick B" because then C wouldn't exist; B's kid C* would.
(6) so far so standard.
(7) but wait: the conception event that fixed C's identity happened in 2024. the 2054 choice didn't cause C to exist; C was already there in the freezer. it only caused C to be born.
(8) so the nonidentity reasoning in (2) requires that the action causes existence, but here it only causes birth. therefore (2) doesn't apply.
(9) that means parents DO wrong C by picking A, since C already existed and was made worse off.
(10) if that's right, then for any post-conception choice—prenatel diet, avoiding alcohol, whatever—the nonidentity problem is moot, because the kid already exists.
(11) but philosophers apply nonidentity to reproductive choices constantly, including ones after conception starts. so either (8) is wrong, or (10) shows the problem has way less scope than people think.
(12) i feel like there's a hidden slide between "causes existence" and "causes birth" but i can't name it. is (8) the mistake? if so, why does it feel so intuitive? and what does giving it up do to origin essentialism?
