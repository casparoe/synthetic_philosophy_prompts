Exam question: A neural-symbolic system has a fixed symbolic reasoning core and a neural component that is updated continuously through online learning. Over months the weights drift substantially, yet the system is administratively tracked as a single entity with continuous liability. Is this system best understood as an enduring object that survives accidental change, or as a perduring four-dimensional object composed of temporal parts with heterogeneous properties? Defend one position and identify one precise difficulty for the opposing view.

Student answer: Endurantism is correct. The symbolic core is wholly present at each time, which secures strict numerical identity; the neural weights are accidental properties, comparable to replaced planks in a ship. Perdurantism treats each update as a numerically distinct temporal part, so it can only relate earlier and later stages causally, not by identity. Therefore, if harm occurs at a later stage, the symbolic core present earlier bears no responsibility, since those stages belong to different entities. Moreover, perdurantism requires all parts of a single worm to share the same essential nature; because the neural parts differ radically in weight-configuration, they cannot belong to one worm. So the system endures.
