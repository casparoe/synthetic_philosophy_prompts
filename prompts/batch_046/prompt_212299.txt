I was reading this blog post about Hofstadter's Copycat thing and fluid concepts—like, the idea that concepts don't have hard edges but bleed into each other. The writer summarizes Copycat as working in this super restricted microdomain with letter strings (abc -> abd, that kind of analog puzzle) where little agents called codelets form temporary coalitions to build answers. They claim that the only reason these coalitions look 'fluid'—so that one run might call something a successor and another run calls it something else—is because of the probabalistic noise in the search algorithm, not because cognition itself is genuinely fuzzy.

So according to them, fluidity isn't a real feature of minds, it's just an artifact of the program's random seeds, and if you actually scaled this up past toy alphabets into real-world categorization, the boundaries would get sharper, not fuzzier, which undermines the whole idea that distributed processes can support fluid cognition. I feel like they're mixing up the implemenation details with the philosophical claim, but I'm not sure where exactly the line is. Is this a fair summary? What's accurate about how Copycat handles conceptual slippage in its microdomain, what's a misreading of Hofstadter's point about randomness, and does their scaling argument actually follow?
