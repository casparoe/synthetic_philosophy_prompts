Here is an argument about the unilateralist's curse that I constructed for a workshop and now find suspicious because it seems to undermine every collective agreement. (1) The curse arises when several agents can each take an action that affects all of them, and each agent decides using only their own judgment, without requiring consensus. (2) If an agent's private assessment is that the action has positive expected value, then rationality directs them to take it, regardless of what others conclude. (3) In any sufficiently diverse group, for nearly every possible action there will be at least one agent whose private assessment crosses that threshold. (4) So for nearly every action, there exists an agent who rationally ought to take it unilaterally. (5) But if for every action someone rationally ought to take it, then no collective agreement to refrain can be stable: as soon as parties agree not to do A, some member's private judgment will rationally license breaking the agreement. (6) Therefore collective agreements are never rationally binding, and stable arrangements like arms-control treaties or pollution caps should be impossible. (7) They clearly do exist and sometimes succeed, so the reasoning must overreach somewhere. Which step should I reject? Explain why that step looked plausible, whether the error is a quantifier shift, an equivocation between individual and collective rationality, or a hidden modal slide, and tell me what giving it up costs for how we model collective decision-making.
