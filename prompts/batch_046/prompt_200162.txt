Consider a decision pattern that resembles Buridan's ass yet behaves differently. An agent must choose between two options genuinely indistinguishable on every valued dimension. Rather than remaining paralyzed, the agent invents a tie-breaking distinction—perhaps that one option was presented first—while openly recognizing it as arbitrary, not disguising it as a real difference. The agent acts on it. Yet in a structurally identical later case with positions reversed, that same distinction is either rejected as illegitimate or applied inconsistently, and the agent collapses back into perfect equality. This cycle of acknowledged-arbitrary tie-breaking followed by instability repeats without ever hardening into a consistent rule. Is there an established concept that captures exactly this dynamic? If not, please name and define it, and sharply distinguish it from Buridan-style paralysis, from post-hoc rationalization, and from framing effects in which agents unknowingly treat arbitrary features as decisive. I am less interested in a bare label than in the boundaries: what makes this a distinct failure mode in rational choice under true equality, and whether recognizing it should change how we model preference formation.
