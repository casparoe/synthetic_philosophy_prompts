If intent alignment is defined narrowly as the condition that an AI system carries out exactly the task its human operator intended—without regard to whether that task is morally appropriate—while value alignment is understood as embedding stable, cross-contextual ethical commitments into the system, then one might wonder whether the distinction is ultimately practical rather than conceptual. Specifically, if an operator could specify an exhaustive, context-sensitive instruction set that anticipates every morally relevant contingency, wouldn't achieving perfect intent alignment over that expanded domain simply amount to achieving value alignment? Or is there a structural reason—perhaps relating to the difference between procedural fidelity to a specified objective and substantive constraint by norms that are not fully articulable—why a system could be flawlessly intent-aligned within its specified domain and yet systematically violate values that were never translated into explicit instructions?
