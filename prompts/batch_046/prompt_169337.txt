Neurath designed ISOTYPE as a universal picture-language for scientific education in which standardized pictograms are meant to be immediately readable across linguistic barriers, with each symbol carrying a fixed quantitative meaning independent of contextual interpretation. If that is correct, then how could the system represent relational or modal claims—say, that tuberculosis mortality declined relative to industrial output—without smuggling in conventional syntactic rules that function exactly like the propositional structures he wanted to avoid? And if we update the framework with modern interactive glyphs whose displayed values shift according to a viewer-selected parameter, does this preserve his physicalist commitment that every representational element must correspond to a determinable state of affairs, or does it reintroduce a hidden layer of interpretive convention?
