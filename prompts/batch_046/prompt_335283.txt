The question was: In philosophy of biology, Neander distinguishes 'proper function' (grounded in selection history, like Millikan/Wright) from 'system function' (grounded in causal contribution to a containing system, closer to Cummins). Consider two cases: (1) a human heart with severe cardiomyopathy that still pumps some blood but poorly; (2) a bioengineered synthetic ventricle implanted in a patient, designed to pump blood but lacking any evolutionary history. Using Neander's distinction, analyze whether each has a proper function, a system function, both, or neither. Then explain whether this distinction solves the problem of accomodating synthetic organs within an etiological framework, or whether it just relocates the tension.

Here's one answer:

Neander's proper function is etiological: it's what the trait was selected for. So the diseased heart still has the proper function of pumping blood, even though it's malfunctioning, becuase its evolutionary history hasn't changed. The synthetic ventricle has no selection history, so it lacks proper function entirely.

Her system function is causal-role: it's whatever the trait actually contributes to the system's capacity. So the synthetic ventricle has the system function of pumping blood, since it contributes to circulation. The diseased heart also has a system function — pumping weakly — but that's not its proper function.

This distinction solves the synthetic organ problem neatly. The synthetic ventricle can have a system function without a proper function, so etiological accounts don't have to deny it does anything useful. Meanwhile, malfunction is explained by the gap between proper and system function: the heart's proper function is strong pumping, but its current system function is weak pumping.

However, there's a remaining issue: if system function just describes whatever actually happens, then calling weak pumping a 'function' at all seems wrong — it's just a failure. So Neander hasn't really saved the etiological view from the causal-role objection; she's just given the causal-role part a different name. In that sense the distinction relocates rather than resolves the tension.
