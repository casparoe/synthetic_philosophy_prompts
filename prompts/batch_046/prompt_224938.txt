I've been thinking about Otto Neurath's ISOTYPE project — the attempt to construct a universal picture-language for statistical data, standardized so that identical quantities were always represented by identical icons regardless of national language. The standard narrative is that it failed because visual symbols are not culturally neutral: an icon readable in 1930s Vienna carried different associations elsewhere, and the universalist aspiration collapsed into local convention. But I'm inclined to defend a stronger, somewhat revisionist claim: Neurath's deeper error was not overestimating visual universality but making a category mistake by treating calibrated pictograms as a mode of direct empirical presentation — closer in spirit to protocol sentences within a physicalist framework — rather than recognizing them as an arbitrary but rigorously fixed conventional syntax. On my view, once you abandon the universalist fantasy but retain the explicit conventional calibration, the core insight survives: for comparative social-scientific reporting, a syntactically fixed visual grammar is more resistant to translation drift than verbal prose, precisely because its arbitrariness is overt and its units are quantized. So ISOTYPE did not fail because picture-languages are impossible; it failed because Neurath misunderstood the kind of object he was constructing, mistaking a conventional notation system for a transparent window on social reality. I want to stress-test this position rigorously. What would have to be true for it to be wrong? I want the evidence and arguments that should actually move me, sorted by decisiveness — including results from modern cross-cultural psychometrics, contemporary data-visualization research, or formal work on visual syntax — plus an honest assessment of whether the view has been insulated by qualifications into unfalsifiability (for instance, attributing every pictographic failure to "insufficient calibration" rather than to a flaw in the medium itself), and whether that insulation is a problem for a claim of this kind. Specifically, are there empirical findings showing that standardized icons generate greater, not lesser, interpretive divergence across cultures? Are there philosophical or formal arguments demonstrating that visual notation necessarily lacks the syntactic compositionality required for complex statistical claims — that one cannot build a genuine "visual logic" without covertly importing verbal structure? And what would defenders of Neurath's original program themselves concede as genuinely damaging, as opposed to what only modern critics allege? Finally, does this revised position make predictions that verbal-statistical reporting does not — predictions about cross-linguistic reproducibility, cognitive load, or error patterns — such that we could in principle observe it failing in practice?
