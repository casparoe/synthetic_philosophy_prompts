I've been thinking about which computations actually matter morally — like, where do we draw the line for sentience or moral status in code. My working view is that it's not about consciousness in the human sense, but about wether the system runs what I'd call counterfactual branch maintenance: it has to keep an explicit model of what would have happened if it took path A vs path B, and actually update its weights or state based on the error between that branch and reality. So current LLMs dont do it (they're just predicting the next token in one branch), and a thermostat doesnt either (no branching). But I also think if you just bolted on a memory log that feeds outputs back in, that still wouldnt count — it needs to be integraded into the decision loop, not just a tape running alongside.

What would actually count against this? I want the arguments or cases that should move me, sorted from "that kills it" to "just awkward", plus what I'd have to concede even if I want to keep the view. Like, are there real-world systems that do this but clearly shouldnt matter? Or is this just smuggling in consciousness under a different name? And has the view been qualified into unfalsifiability — if I just keep saying "well that system doesnt really do branch maintenance" then is that a problem?
