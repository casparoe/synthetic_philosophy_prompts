I've been thinking about the problem Hofstadter calls Le Ton beau de Marot — translating poetry where you want to keep rhyme, meter, and some semantic core, but the target language has a totally different phonlogy and syllable structure. I don't want examples of good translations; I want the actual spec. So write me the desireata for any theory of formal-constraint-preserving interlingual translation: what it has to be able to deliver, with the concrete failure case behind each requirement. Mark which ones are genuinely non-negotiable vs. just preferences of one camp (say, literalists vs. people who think form is always secondary). Also say whether any subset is jointly unsatisfiable — like if exact rhyme preservation and exact literal meaning can't both be satisfied in some language pairs, that's a result about the theory's limits, not a flaw. Then briefly score the three main approaches: strict formal replication, semantic equivalence with relaxed form, and Hofstadter-style transposition where you invent analogous constraints in the target language.

Separate what's settled (e.g., that sound inventories don't line up) from what's genuinely contested among translation scholars, and don't present one view as the consensus. For format: first, a table with columns Desideratum, Motivating failure case, Negotiable? (Y/N/Maybe), Conflicts with other desiderata?. Then a short JSON summary with fields: domain (string), num_desiderata (int), unsatisfiable_subset (string or null), scored_approaches (array of strings), contested_vs_settled (string, max 2 sentences).
