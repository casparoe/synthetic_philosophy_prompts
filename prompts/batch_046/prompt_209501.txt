Here are my gut reactions about whether being able to imagine something means it could actually happen, and I'm trying to see if there's one rule behind them or if I'm just being messy.

Case one: I can clearly picture a bridge made of glass stretching across the atlantic and not breaking. That feels like real physical possiblity, even if enginerrs say it's impossible.

Case two: I can run the Twin Earth scenario where water is XYZ instead of H2O. I can imagine it, but I don't think that shows it's possible — I think it's conceptually impossible.

Case three: I made up this idea of "modal blindness" — imagine a society where nobody can form the concept of private ownership at all. If they genuinely can't conceive it, I still think ownership is possible for them, which seems to cut the link between conceivability and possibility.

Case four: I can imagine my consciousness continuing after death with no brain or body. That feels like I can run the mental movie, but it's probably just fantasy, not a genuine modal fact.

So what's the principle? Does it save all four, or do I need to drop one? And for a case I haven't listed: what about conceiveing a formal arithmetic that's both complete and consitant — if I think I can imagine it but it can't exist, is that my imagination failing or conceivability failing as a guide?
