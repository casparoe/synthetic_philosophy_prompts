hey, retired ecologist here who started reading philosophy of mind. I keep seeing this scale argument about insects—like even if only 0.01% of bees are sentient, with 10^19 individuals the moral expected value is enormous. But doesn't that treat consciousness like a radioactive decay, where each atom decays independantly? If sentience is actually tied to a specific neural integration threshold—say, some minimal level of integrated information—then either all bees have the architecture or none do, and multiplying probabilities by population size is just a category mistake. So why do philosophers still use the scale argument rather than asking whether arthropod brains cross that threshold?
