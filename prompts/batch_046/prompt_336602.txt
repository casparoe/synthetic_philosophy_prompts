here's the student answer:

The regress problem starts when you ask for a reason for a belief, then a reason for that reason, and so on. If it never stops, you have an infinite regress; if it loops back, you have circular reasoning. Foundationalism stops it with basic beliefs that don't need justification, like direct perceptions. This avoids circularity, but critics say the stopping point is arbitrary — there's no reason to halt at those beliefs rather than others. Foundationalists usually reply that basic beliefs are self-justifying and infallible, so they aren't arbitrary.

Coherentism rejects basic beliefs. Instead, beliefs justify each other in a web of mutual support. This avoids both infinite regress and arbitrary foundations. The main objection is circularity, since belief A can support B and B can support A. Coherentists say this isn't vicious if the whole system is consistent and broad. Actually, coherentism doesn't really escape circularity; it just hides it in the web, so it's not genuinely different from foundationalism, which also relies on unexamined assumptions at the bottom.

Infinitism says there's no bottom and no circle — just an infinite chain of reasons going downward forever. Each belief is justified by a prior one, with no endpoint. This avoids arbitrariness because there's no stopping point. Infinitism also allows beliefs to justify each other in both directions along the chain, which is okay because the chain is infinite. So infinitism actually combines the best of both other views: it has the linear structure of foundationalism but without the arbitrary base, and it allows the mutual support seen in coherentism.
