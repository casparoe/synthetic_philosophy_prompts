I've been trying to work out whether cognitive penetration of perception really threatens empirical knowledge, and I built an argument that seems to prove predictive processing is self-defeating. Here are the steps: (1) Cognitive penetration happens when a mental state with content—like expecting a pine tree—causally changes what you literally see, not just what you judge about what you see. (2) Predictive processing holds that the brain constantly generates top-down predictions that determine conscious visual experience, leaving only prediction-error signals to reach awareness. (3) So if predictive processing is correct, every perceptual experience is causally shaped by prior expectations or hypotheses. (4) Therefore predictive processing implies that all perception is cognitively penetrated. (5) But if every perception is penetrated, there is no neutral perceptual baseline—no "given"—against which we can check whether our beliefs are correct. (6) Without such a baseline, empirical justification collapses into circularity: beliefs justify beliefs with no independent check. (7) We clearly do have justified empirical beliefs, so (6) is false. (8) Hence predictive processing must be false, and cognitive penetration must be impossible. I think the mistake is somewhere between (3) and (5), maybe confusing subpersonal predictions with actual beliefs, but I'm not sure what giving that up costs—would we have to accept that predictive processing is compatible with encapsulation after all? Which premise should I reject, and what does rejecting it commit me to?
