here's the student answer:

The St Petersburg paradox comes from a game where you flip a coin till tails, winning 2^k if it takes k flips. Expected payout is sum (1/2^k)(2^k) = infinity, so rational agents should pay anything, but people won't pay more than ~20 dollars. Bernoulli solved this by proving utility of wealth is logarithmic: u(w)=ln(w). Then expected utility is sum (1/2^k)ln(2^k) = 2ln2, about 2 ducats, so it's finite and there's no paradox.

With the epistemic twist, payoff is resolving unknowns with value 2^k, and utility is linear in information gained. Expecation is infinite again. But Bernoulli's fix works here too, since information also has diminishing returns, so applying the same concave curve to belief-updates bounds the expectation. So the paradox only shows up if we wrongly assume linear utility in every domain; once concavity is allowed it vanishes for both money and knowledge.
