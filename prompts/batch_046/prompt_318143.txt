I work as a software engineer with no formal training in philosophy, but I have been trying to grasp Karl Popper’s idea of verisimilitude because it seems structurally similar to how we talk about model approximations in machine learning. In a discussion group we put together the following argument, which appears to show that Popper’s framework makes it impossible for false scientific theories ever to be closer to the truth than true ones. I find that conclusion implausible, but every premise looks defensible to me.

(1) On Popper’s account, scientific rationality does not aim at verification but at verisimilitude: the measure of progress is how closely a false theory approximates the complete truth, so comparing false theories with one another is central to the enterprise.

(2) I propose the Entailment-Preservation Thesis for Verisimilitude (EPTV): if a theory T is true and T logically entails a false theory F within the same domain, then T necessarily possesses greater verisimilitude than F, because T contains all of F’s true content without retaining any of F’s falsehoods.

(3) For any false scientific theory F, we can construct a “truth-completion” T* that retains every true logical consequence of F, replaces every false consequence with the correct description, and is arranged so that T* is internally consistent and true.

(4) Because T* includes all of F’s correct content and eliminates its errors, T* stands in precisely the entailment-preserving relation to F that EPTV requires.

(5) Therefore, applying (2) to (3) via (4), T* has strictly greater verisimilitude than F.

(6) It follows that for every false theory there exists a true theory—its truth-completion—with strictly greater verisimilitude.

(7) Consequently, false theories can never rank as the closest available approximations to truth; comparative evaluation among false theories becomes redundant, since each is automatically outperformed by its own true completion.

(8) This undermines Popper’s claim that science advances through false theories approaching the truth, so either Popper’s view is incoherent or one of the steps above fails.

I should like to preserve (1) and (3) if possible—the notion that progress aims at truth-approximation, and the idea that we can in principle correct a false theory to yield a true one. Which numbered step is the weakest link? Explain why that step initially looks plausible, and then set out what each of the three standard interpretations—the quantitative content-based account, the logical-comparability account, and the structural-similarity account—would have to concede in order to reject it.
