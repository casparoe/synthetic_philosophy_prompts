hey so i've been chewing on this idea about dispositions - like how glass is fragile or sugar dissolves. i think i built an argument that kills the whole concept but it feels like it must break somewhere.

1. if a thing has a disposition, then in the right conditions it does the thing.
2. sugar dissolves in water, so it's soluble.
3. but imagine "fink sugar" with a hidden chemical switch that hardens it the instant water touches it. in water, it doesn't dissolve.
4. there's also "mask sugar" wrapped in a shell that never lets water in, but inside it's normal sugar.
5. if we say the masked sugar is still soluble (since inside it's sugar), then the fink sugar should be too - the switch is just outside interferance.
6. but then solubility doesn't care what actually happens; it only cares about some hidden "inner nature."
7. now add nesting: the shell itself is disposed to melt in boiling water, revealing the sugar. so the mask has its own disposition to dissapear.
8. if every mask can be unmasked by some other condition, then dispositions are just infinite chains - nothing is ever truly blocked.
9. so either finks and masks don't really exist, or every object has every disposition hidden inside waiting for the right chain of conditions.
10. that can't be right, because then "fragile" and "not fragile" mean the same thing.
11. so i think one of my steps is wrong, probably 5 or 8, but if i drop 5 then masked sugar isn't soluble and that feels weird too. where's the slip?
