ok so for a philosophy of math discussion group I wrote up my takes on infinity and I want to know if I'm accidentally helping myself to contradictory stuff. here's where I'm at, probably with some mistakes:

1. I'm basically a finitist about the physical world — I don't think there's actualy an infinite number of atoms or an infinitly divisible point, just that you can always split or count further if you feel like it. potential infinity yes, actual infinity no.
2. I still think Cantor's diagonal argument is valid, and it shows there's no one-to-one matching between the naturals and the reals. I don't think this requires believing in "all real numbers" as a completed set, just that any list you actually write down misses something.
3. I use Hilbert's hotel as a reductio — if you could actualy have a hotel with infinitely many occupied rooms and still check in a new guest, that'd be absurd, so actual infinity can't be real.
4. I think calculus and physics only need potential infinity. the real line is a useful fiction, like a frictionless plane, and limits are just describing processes that never bottom out.
5. I reject the Banach-Tarski decomposition in physical space because it violates conservation of volume, but I'm ok with it as a purely formal result about sets I don't think exist in nature.

do these hang together? specifically I'm worried I'm smuggling actual infinities into (2) when I talk about "the reals" vs "the naturals", and also that (3) assumes the hotel scenario makes sense enough to be absurd, which might beg the question against someone who accepts actual infinity. also is (4) consistent with (2) if I'm treating real analysis as fictional but Cantor's proof as genuinely true? which ones are in real tension and what's the cheapest fix? rank them by severity rather than just listing them.
