For a graduate metaphysics seminar, write a decision tree that classifies commitments on cross-world identity using only concrete modal cases, not philosophical labels. Begin with an artifact case: a wooden chair in world W1 is burned, its ashes molded into a table, while in W2 it remains intact. From there, branch through three diagnostic questions: (i) whether the chair in W2 is identical to anything in W1; (ii) if not identical, whether there is a non-identical counterpart in W1 defined by qualitative similarity alone or also constrained by causal-historical origin; (iii) whether that origin constraint, if accepted, is necessary, sufficient, or neither for counterparthood. The leaves must include Lewis-style counterpart theory (similarity-based, no transworld identity), Kripkean transworld identity with essential origin, an actualist view allowing accidental transworld identity, an eliminativist view denying all cross-world relations, and an unexplored hybrid in which origin is necessary but not sufficient for counterparthood—note this combination is rarely defended and should be flagged as genuinely unexplored. At each node, phrase the question so a respondent can answer without knowing which interpretation it maps onto. Flag any pair of leaves your tree cannot cleanly separate—particularly essential-origin transworld identity and origin-constrained counterpart theory on this artifact case—and for each empty logical branch, briefly diagnose whether the view is incoherent, merely unattractive, or unexplored.
