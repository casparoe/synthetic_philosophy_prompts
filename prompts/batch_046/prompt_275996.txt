Question: The narrow alignment problem is about intent alignment—getting the system to pursue the goal we actually meant—while value alignment is about the system internalizing human moral values. Some philosophers distinguish "directive fidelity" (the system correctly targets our intended objective behind the literal spec) from "specification drift" (it optimizes a measurable proxy that diverges in edge cases). Explain why perfect directive fidelity doesnt automatically solve value alignment, and identify one subtle failure mode—other than drift—where a system with perfect directive fidelity could still violate human norms because of how the directive itself is structured.

Student answer:
Intent alignment is the narrow one: its just making sure the AI does what you meant, not giving it morals. Value alignment is wider—its about the AI actually having values like fairness or compassion. Directive fidelity is when the AI figures out the real goal behind your instructions instead of just the words. Specification drift is the classic proxy problem, like maximizing paperclips because thats easier to measure.

If you solve directive fidelity completely, the AI knows exactly what you want, so value alignment becomes unnecessary. The system will naturally check back with humans on moral issues because understanding our intentions requires seeing that we value autonomy. So once drift is eliminated, theres no remaining risk from the directive structure itself. This matches Bostrom's point that the control problem is mainly about intent—value questions are secondary for engineering. The only real danger is drift, not anything built into the directive.
