In a discussion session with classmates, our instructor raised a hypothetical challenge that does not appear in the assigned readings: in domains of practical reasoning, values may be so deeply interdependent that breaking ethical deliberation into modular pieces risks distorting rather than clarifying the reasoning process. The student submitted this response: “I think HCH works by breaking big problems into small ones that people can check. Christiano’s idea is that you have people consulting other people, and this needs factored cognition—basically that reasoning can be split into parts that don’t mess with each other too much. It’s an idealization because real thinking is more connected, but for deliberation we pretend it’s modular, kind of like Fodor’s modules but for reasoning about values and facts. When it comes to moral reasoning, there’s a problem because values depend on each other. If I think justice requires equality, that changes what I think fairness means. So you can’t just check one value in isolation. At first this looks like it kills HCH for ethics. But actually HCH can handle it by putting the connections at a higher level: the top HCH checks how the lower ones fit together. So factoring isn’t destroyed; it’s just layered, and since recursion can always go up one more level, there is no hard limit—normative reasoning is no more problematic for HCH than chess strategy is. Still, there’s a stronger objection. Maybe values aren’t just connected in practice but in meaning—like Quine said about analytic truths, that you can’t isolate one belief from the web. If normative claims are like that, then trying to factor them is like trying to pull one thread without moving the web.
