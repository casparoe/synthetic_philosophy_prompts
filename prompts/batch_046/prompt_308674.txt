If we model self-deception using a dual-register architecture—where first-order doxastic states are stored in one register and second-order meta-cognitive assessments in another, with retrieval between them gated by attentional filters rather than direct access—then the phenomenon looks structurally like a principal-agent problem with hidden actions. The meta-register must suppress or misrepresent the contents of the first register to protect a preferred self-image, yet it apparently cannot do so by directly representing those contents, since that would dissolve the deception. This seems to generate an instability: either the suppressing register never accesses the threatening belief and therefore cannot target it for suppression, or it accesses it and thereby becomes aware of the truth. Given this tension, is self-deception best understood not as a sustained state but as a rapid oscillation between registers? Or can one defend a stable-equilibrium model in which suppression operates via an endogenous encryption protocol—where the threatening content is encoded in a format that the meta-register can block without ever decoding—thereby allowing a persistent, motivated ignorance that never collapses into explicit contradiction?
