I've been trying to work out this argument for my philosophy of religion seminar and I'm stuck on where it breaks. I'm mixing Jain anekāntavāda with some modal framing my roommate mentioned, and now I'm not sure if I've built a reductio or just a mess.

(1) Anekāntavāda says reality has infinite aspects, so no single predicate captures the whole truth about anything.
(2) The syāt formula expresses this: for any object and predicate P, it's true that syāt P (in some respect) and also syāt not-P (in another respect).
(3) If standpoints are just perspecitives, and there's no metaphysically privileged standpoit that trumps the others, then excluding any standpoint is arbitary.
(4) So rational belief should include every valid syāt-judgment: if there's any standpoint where P holds, a rational agent should accept syāt P.
(5) For contradictory pairs like the jīva is eternal and the jīva is not eternal, both have valid standpoints (the soul-standpoint vs the physical-change standpoint).
(6) Therefore the rational agent should accept both syāt-statements.
(7) But here's where my roommate's modal framing kicked in: if acceptance is closed under logical consequence, and we treat the syāt-qualifier as merely an epistemic hedge rather than part of the content, then accepting both licenses accepting the unqualified contradiction the jīva is eternal and not eternal.
(8) Even Jain logicians reject bare contradictions; they only accept them qualified by syāt.
(9) So if (4) is right, rationality forces us into bare contradictions, which collapses the distinction between anekāntavāda and dialetheism.
(10) That can't be right, since Jain epistemology is specifically designed to avoid dialetheism. So one of these steps has to go.

Which premise should I reject? I really want to keep (3) — the idea that there's no privileged standpoint feels central to Jain pluralism. But if I drop (7) instead, I'm basically saying the syāt-qualifier is part of the logical form and can't be stripped, but then I'm not sure what that costs for how we formalize rational belief. Or maybe the error is in (4), treating there's a standpoint as I should personally endorse it? Can someone walk me through the least painful exit?
