3. If the clay is melted into an unshaped puddle, does the statue still exist?
4. Are there literally two objects (the statue and the clay) occupying that space, or only one?
5. Could the statue survive a change that destroys the clay, or the clay survive a change that destroys the statue?

I do not mean a real legal case; I mean whether this kind of functional persistence should split the logical space. If this case genuinely cannot split the space without smuggling in hidden technical assumptions, say so plainly.

Present the result as structured data: a JSON object containing an array named “branches” and, if needed, an array named “empty_spaces”.
