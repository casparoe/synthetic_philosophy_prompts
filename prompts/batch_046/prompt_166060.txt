Student answer: (i) Löb's theorem says if S ⊢ Prov_S(⌜φ⌝ → φ), then S ⊢ φ. This is basically a stronger version of Gödel's first incompleteness result. (ii) If the agent adopts R globally, then for each φ, S proves Prov_S(⌜φ⌝) → φ. Applying Löb's theorem to every φ gives S ⊢ φ for all φ, so the system becomes inconsistent. (iii) Restricting R to Π_1 sentences doesn't work because Löb applies regardless of sentence complexity. The fixed-point lemma lets us build a Gödel sentence G with S ⊢ G ↔ ¬Prov_S(⌜G⌝). Feeding G into R gives a direct contradiction, so local reflection is just as broken. Therefore any self-trusting agent using PA-level logic is doomed.
