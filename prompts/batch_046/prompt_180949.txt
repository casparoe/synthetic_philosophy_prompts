I'm in this distributive justice course and we've been going over prioritarianism, especially the leveling-down objection. The usual story is that if you weight well-being more for worse-off people, you might end up dragging everyone down to equality if you can't actually improve the worst off. But I think that only hits if you assume a continuous weighting function — like, welfare is just a number line and priority is a smooth curve. What if you reject that? I want to defend this kind of banded lexicograpic prioritarianism where welfare comes in discreet bands — severe deprivation, basic adequacy, flourishing — and within each band equality doesn't matter, but between bands it's strictly lexicographic. So you never have reason to level down from flourishing to adequacy just for equality's sake; you'd only move resources downward if it actually pushed someone up a band, which in the pure redistribution case it wouldn't.

Anyway, I hold this view, or at least I'm flirting with it. What would count against it? Not the generic leveling-down reply — I've tried to structurally block that. I want the specific defeaters: intuitions that welfare is genuinely continuous, boundary cases where someone is right between bands, whether measuring which band you're in is just hidden utilitarian calculus, and whether this collapses into standard egalitarianism or utilitarianism if you squint. Also, is there a risk this gets qualified into unfalsifiability — like, if a counterexample comes up, I just redraw the bands? Rank these from fatal to merely awkward, and say which ones a committed defender of this view would concede versus just dismiss. I'd especially like to know if there's some result in welfare economics that undercuts the discrete-band framing altogether.
