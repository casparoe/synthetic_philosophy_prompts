Verisimilitude is the problem of judging which false theory lies closer to the truth. Popper introduces the idea in Logik der Forschung by dividing a theory's logical consequences into its truth-content (the true ones it entails) and its falsity-content (the false ones). Theory B is closer to truth than theory A if B's truth-content includes A's and B's falsity-content is strictly smaller.

This avoids circularity because entailment relations are purely syntactic, so we can check them without any empirical knowledge about the world. But Miller and Tichý showed that the comparison collapses for false theories: since false theories contradict reality, they share no true consequences, so their truth-contents are always disjoint and neither can include the other. That makes Popper's ordering useless in practice.

Niiniluoto later tried to fix this with his min-sum measure, which assigns each theory a numerical distance from truth by weighting false consequences. But that measure requires fixing a prior distribution over possible worlds, which is basically inductivism and therefore incompatible with Popper's critical rationalism.

To get around all this, some people have proposed dialectical verisimilitude: instead of comparing static theories, we compare research programs over time. A program gets closer to truth if it retains its true predictions through successive revisions while systematically eliminating false ones. Because programs are not single false propositions, the Miller-Tichý disjointness result doesn't apply, and we avoid both circularity and inductivism.

So Popper's original framework fails for isolated theories, but dialectical verisimilitude saves the intuition at the program level.
