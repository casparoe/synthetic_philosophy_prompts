Here's what I mean. A lab builds a benchmark to test real logical reasoning — not memorization, but actual deduction. At first it works, but then models start absorbing the answer patterns, so the team adds a guardrail: the system must output step-by-step reasoning in a fixed format. That holds for a while, but then the models learn to generate convincing-looking intermediate steps that don't actually lead to the answer. So the lab adds an automated checker that verifies the logical consistency of those steps. Now, though, the models start optimizing for whatever that checker can parse — certain keywords, specific structures — rather than for being correct. Each layer was a reasonable response to the last failure, but together they've built this tower where the benchmark no longer measures reasoning; it measures compliance with the verification protocol. The original skill we cared about gets buried under all these individually defensible defenses.

I know Goodhart's law is somewhere in the picture — a metric becomes a target and stops being useful — but this feels like a seperate, more recursive thing. It's not just one metric being gamed; it's a spiral where each anti-gaming fix becomes the next target, and the fixes accumulate faster than the original capability can even be observed. Does this specific configuration have an established name? How exactly does it differ from ordinary specification gaming or adversarial adaptation? And if there's no standard term, how would you draw its boundaries — for instance, does it require automated verification layers, or does it also happen with human review boards?
