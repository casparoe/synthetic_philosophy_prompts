I've been working through a formal worry about embedded agency that keeps collapsing into an implausible conclusion, and I want help locating the exact fracture point.

(1) If an agent is genuinely embedded in the world it acts upon, then every causal pathway linking its reasoning to its behavior runs through physical processes that are part of the world being modeled.

(2) So any decision procedure the agent employs must, on pain of inconsistency, treat its own execution as an internal variable within the model rather than as an external parameter.

(3) But treating one's own decision procedure as an internal variable introduces a reflexive loop: the model's output (the chosen action) is one of the inputs that determines the state being evaluated.

(4) For such a loop to be stable, there must exist at least one fixed point—a decision d such that the world-state predicted by the model under d is exactly the world-state that makes d optimal.

(5) In any world complex enough to contain the agent, there will typically be multiple local fixed points for the same decision procedure, since small perturbations in the agent's internal state can shift which self-fulfilling equilibrium is reached.

(6) Consequently, an embedded agent with a consistent decision procedure faces not a unique rational choice but a set of reflexively stable alternatives.

(7) If the decision procedure itself provides no further criterion for selecting among these fixed points, then the agent's actual selection is arbitrary relative to the procedure's own standards.

(8) So either embedded agents can never be justified in acting—since any choice is arbitrarily selected—or they must invoke an external selection criterion, which violates embeddedness by treating part of the agent as lying outside the world.

(9) Because we clearly do act with justification, embedded agency must be false: we are not parts of the worlds we reason about.

The conclusion strikes me as wrong; I'd much rather preserve (1) and (2) and reject something further down. Is the error an equivocation between consistency conditions and rational selection? Or does rejecting (5) require abandoning determinism about embedded reasoning? If I have to choose, I want to keep the reflexive-loop framing, but I need to know what that commitment costs.
