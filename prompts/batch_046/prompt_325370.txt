I've been thinking about metaontological deflationism and I'm stuck on something. The claim is that a lot of ontological fights — say, whether composite objects really exist — are just verbal disputes, not disagreements about what's actually out there in the world. Both sides accept the same physical arrangments; they just talk differently. So if that's right, shouldn't there be some kind of neutral spredsheet? Like a shared language where both the universalist and the nihilist can record every fact they care about without using each other's loaded vocabulary? And if we don't have one yet, is that just because philosophers haven't built it, or does the fact that nobody has published this translation manual actually show that there's a hidden factual disagreement the deflationist missed? I guess I'm assuming that every truly verbal dispute comes with a perfect bilingual dictionary waiting to be discovered — is that assumption wrong?
