Exam prompt: Some philosophers and physicists have argued that Kurt Gödel's rotating-universe solution to Einstein's field equations undermines the objective reality of temporal passage. Explain Gödel's reasoning about paths that loop back through spacetime, and evaluate whether his conclusion—that time is in some sense illusory—follows from the physics alone or depends on an additional philosophical assumption.

Student answer: Gödel discovered a cosmological model in which the universe rotates uniformly, tilting the light cones so severely that a traveler can follow a path returning to the exact same spacetime point. These paths are called closed timelike curves. Because such loops exist, there is no consistent global "now" slicing through the entire universe, which destroys the idea of a universal present moment. Gödel therefore concluded that the flow of time is not objectively real; it is more like a subjective appearance, analogous to how motion looks different from different reference frames in special relativity.

The student also writes that Gödel's rotating model requires exotic negative-energy matter to maintain stability, which shows the scenario is physically unrealistic. Still, the logical possibility of the loop is enough to defeat presentism—the view that only present objects exist. If presentism is false, then eternalism, the block-universe view, must be true, and temporal passage is just a psychological projection. So Gödel's reasoning proves Einstein's block universe correct, though it goes further by claiming that time itself is unreal rather than merely relative.

Finally, the student addresses an objection: if one restricts analysis to a locally non-rotating inertial frame around an observer, the closed loops disappear, so objective time could be preserved locally. The student rejects this by arguing that local frames are merely coordinate choices, and Gödel's point was precisely that coordinate-independent global structure fails for time, so saving time locally misses the philosophical damage.
