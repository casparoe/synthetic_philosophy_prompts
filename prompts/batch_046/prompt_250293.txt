As I draft a philosophical interlude for a novel concerning an engineer of low-impact artificial minds, I want to sharpen a conceptual tension that drives one character's ethical paralysis. Compare two frameworks for defining side-effect avoidance without presupposing the answer. The first is the baseline-divergence framework: it defines harm as a measurable deviation from the expected continuity of world-states in the absence of intervention, using only probabilistic and causal metrics, and claims to require no explicit value hierarchy. The second is the steward-counterfactual framework: it defines harm relative to an implicit normative baseline—specifically, the set of state-changes that a fully informed benevolent caretaker, possessing complete value specification, would have permitted. In which respects does the first framework genuinely achieve value-neutrality, and in which respects does it covertly embed normative judgments—about which futures count as "expected," about the weighting of different causal pathways, or about the moral significance of reversibility? Conversely, does the second framework's explicit dependence on a complete value specification make it operationally useless for systems that must act under value uncertainty, or does it merely expose the hidden commitments of the first? I need this comparison to be precise enough to sustain a character's internal debate, not a literature review; focus on the logical architecture of each position and on whether the distinction between them collapses under analysis.
