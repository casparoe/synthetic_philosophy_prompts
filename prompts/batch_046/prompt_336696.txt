Question: What is a rigid designator according to Kripke, and how does the Hesperus/Phosphorus example show that some identities are necessary but a posteriori? Mention one objection.

Answer:
A rigid designator picks out the same object in every possible world where that object exists. Hesperus and Phosphorus are both rigid designators for Venus, so in every world they refer to Venus. That makes Hesperus is Phosphorus true everywhere, hence necessary. We only learned theyre the same planet by telescopes, so its a posteriori. One objection is from descriptivists: they think names are just descriptions like the evening star, which arent rigid since they could pick out different bodies in other worlds. Also Kripke never explains what happens to the reference chain if Venus had never existed, so theres a hole in his account for worlds where the object is missing.
