I'm putting together a handout for an informal philosophy-of-mind reading group — the sort that runs on rationalist forum energy rather than academic convention — and I want a decision tree that sorts positions on phenomenal consciousness as a user illusion. The tree should be built from logical commitments, not from a list of author names, so that someone could answer the branch questions without knowing which philosopher defends which leaf.

Begin at the root: does first-person access to subjective character report a genuine representational content about an internal state, or does it report a functional interface property with no corresponding intrinsic feature?

From there, branch by three binary distinctions:
(a) Is the illusion representational — that is, does it involve a false belief about the properties of experience — or non-representational, like a transparent desktop icon that hides the underlying machinery without misrepresenting it?
(b) Is the recipient of the illusion a unified self-model, or a distributed coalition of subsystems with no central user?
(c) Is the illusion epistemically correctable in principle through refined introspection, or is it architecturally necessary — a design feature rather than a cognitive failure?

This yields eight combinations. Map each onto a position — named if it is well-known, unnamed if it represents unexplored logical space — and for each occupied leaf state its most awkward commitment in a single sentence. For each empty combination, diagnose briefly whether it is incoherent, conceptually unstable, or merely unexplored.

Now include the niche distinction: distinguish the familiar desktop-interface metaphor from a less-discussed compiler-error metaphor, in which the feeling of subjectivity is not a simplified representation of neural computation but a misinterpretation of an error-correction signal never intended to be read as experience. Place this distinction at the appropriate node, flag whether any standard named view actually occupies the compiler-error leaf, and note what kind of empirical or conceptual finding would be needed to populate it.

The audience is comfortable with terms like epistemic and representational, but should not need to cite texts or recall specific papers. Do not include bibliographies, reading lists, or citation requests. Write in British English, keep the tone formal but not stiff, and ensure every branch node is phrased as a concrete conceptual question that could be answered without knowing the label it leads to.
