ok so i've been chewing on this after reading some block and dehaene stuff but i think i built a monster. here's the chain, tell me where it snaps.

(1) global workspace theory says you're access-conscious of X iff X gets brodcast to the consumer systems (memory, planning, language, etc.).
(2) phenomenal consciousness is just the "what it's like" part, which can in principle exist without that broadcast — that's the whole point of the distinction.
(3) but if a representation isn't broadcast, then by definition it can't causally influence any of those consumer systems.
(4) so any phenomenal-but-not-access state is causally isolated from the rest of the mind.
(5) now here's the weird injection: in predictive processing, there's always local error-minimization happening in early sensory cortex with intergration windows of like 80-150ms, way below the threshold for global broadcasting (~200-300ms). call these "sub-broadcast phenomenal fragments."
(6) if phenomenal consciousness doesn't require broadcasting, then every one of these fragments has its own "what it's like" — maybe dim, maybe weird, but real.
(7) but since they're causally isolated, the global system behaves exactly as if they weren't there.
(8) so for any brain, there's a parallel description: the global workspace story plus a hidden swarm of fragmentary experiences that do nothing.
(9) that means either (a) we should attribute rich hidden consciousness to every brain region with local recurrent loops, which is basically panpsychism with extra steps, or (b) we deny that phenomenal consciousness can exist without access, which kills the distinction we started with.
(10) and (b) is especially bad because it makes blindsight patients impossible — they report no experience, but on (b) they'd have full phenomenal consciousness since they still have local processing.
(11) so either we buy the hidden swarm or we deny blindsight phenomenology. both feel wrong.

where does this go wrong? i really want to keep (2) and (5) — the distinction and the local integration windows — but i'm okay losing something else if it saves me from the swarm. which step is the cheap one to drop?
