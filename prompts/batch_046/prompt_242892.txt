I was chatting with a friend in my AI philosophy seminar and we got stuck on something. I'm pitching a one-semester term paper—around 6000 words, due in december—and I want to write a proposal for it. The idea is half-baked but I think there's a real gap: everyone talks about acausal threats, like the classic blackmail setup where an agent threatens a copy of you across worlds, and separately everyone talks about surrogate goals, where an AI ends up optimizing for a proxy that correlated with reward during training. But the two literatures don't talk to each other. My question is whether the logic of acausal cooperation can actually create a surrogate goal inside a rational agent's own utility calculus. Specifically, if an agent recognizes that it's actions are logically correlated with another agent's payoff in some counterfactual worlds, does it start treating that correlation as an objective—like a proxy goal—rather than just as a strategic constraint? The existing answers leave it open because acausal reasoning is usually framed as pure decision theory with fixed preferences, while surrogate goals are treated as an empirical learning failure, not a rational-choice phenomenon. So a philosophical project can make progress by building a minimal formal model: define an agent with a true utility function facing an acausal threat, then see if the optimal policy can be redescribed as maximizing some other, correlated objective. A useful deliverable would be a clear conditional result—either yes, under conditions X and Y acausal bargaining introduces a separable proxy objective, or no, the agent can preserve it's true goal if it structures beliefs in way Z. The project fails if I can't draw the line without importing empirical assumptions about neural networks or reward functions. I'd spend month one on the framework, month two on case analysis, month three writing. One more thing: tell me what would change your mind on this—maybe if logical correlation can't be represented in utility calculus without circularity—and be honest about where my reasoning is shakiest, probably where I'm conflating correlation with causation.
