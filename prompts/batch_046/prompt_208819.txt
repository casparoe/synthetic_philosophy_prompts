(2) If created things have no causal powers, then observed correlations like fire-followed-by-burning are not metaphysically necessary but rest solely on God’s contingent custom. (3) If correlations rest only on contingent custom, then projecting them into the future—or using them to infer hidden agents—lacks rational justification beyond bare repetition. (4) Yet Al-Ghazālī’s own case for occasionalism depends on projecting the correlation between fire and burning into an explanatory claim: since fire consistently accompanies burning but lacks visible power, God must be doing it. (5) So occasionalism either strips its own argument of rational force, or it admits that contingent correlations can license explanatory inferences, which removes the pressure to deny secondary causation in the first place. Which step should I reject, why did it look defensible, and what does each alternative cost for Al-Ghazālī’s broader epistemology?
