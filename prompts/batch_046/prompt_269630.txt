A rigorous reconstruction of the Bai Ma Lun seems to generate a reductio of all identity claims, and I cannot locate the slip. (1) In the dialogue, "horse" denotes a form (xing), while "white" denotes a color (se); because form and color are conceptually separable, the compound phrase "white horse" refers to a conjunction of attributes rather than to the pure form alone. (2) Hence "a white horse is a horse" is false when read as an identity between the compound description and the single-form description. (3) Generalizing this separability principle: if an object O instantiates attributes A and B, and a description D mentions only A, then O is not identical to "the D," since B remains outside D. (4) Every actual object instantiates more attributes than any finite description can include—at least spatiotemporal location, relational properties, and modal features—so no description ever captures the full intension of its object. (5) Therefore, for any object O and any true description D, O is not identical to the object specified by D. (6) Applying this reflexively: even "this horse is this horse" requires a description that omits some actual attribute of the horse, so self-identity collapses as well. (7) Thus the Mingjia principle, applied consistently, dissolves every identity statement. I am committed to preserving (1) and (2) as a faithful interpretation of the text, and I would like to keep (3) if it can be defended without falling into (7). Where does the argument fail? Is there an equivocation between linguistic intension and extensional identity, a quantifier-scope error in moving from descriptions to objects, or a modal slide in (4)? Which step is least costly to reject, and what does that rejection imply about how the School of Names intended the separation of form and color?
