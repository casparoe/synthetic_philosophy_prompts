1. if domain D is inaccessable (no observation distinguishes states inside D), then any ontology that differs only inside D is empirically equivilant to our own.
2. for any ontology O we can build O' by permuting entities inside some inaccessable sub-domain while fixing everything observable.
3. so O and O' are on par, empirically speaking.
4. but apply this recursively: even macro-ontologies (tables, cells) contain sub-domains that are in principle inaccessable.
5. therefore every ontology has an empirically equivalent rival, and we can never uniquely identify any ontology - not even that there's a table here.
this feels like it proves too much. which step should i reject? is step 2 blocked for macro-objects? does step 3 confuse empirical equivalence with ontological parity? or is there a hidden equivocation on "identify"?
