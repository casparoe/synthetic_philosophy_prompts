Here's an argument I cooked up for a reading group and now I think it's self-defeating, but I can't find the leak.

(1) If accuracy is the only intrinsic epistemic good, then for any doxastic attitude D about p, the rationality of holding D depends solely on how close D gets you to the truth about p.
(2) Now take suspension of judgment: it's not a credence near 0 or near 1, it's just... nothing. There's no Brier-score entry for having no attitude.
(3) So compare two agents about some obscure claim q (say, whether there's an even number of trees in Siberia versus atoms in Betelgeuse). Agent A suspends. Agent B assigns credence 0.6 because she skimmed one shaky paper.
(4) Agent B has an accuracy score—maybe poor, maybe decent. Agent A has no score at all; she's outside the evalutation framework.
(5) But if only accuracy matters, being outside the framework can't be better than being inside with a mediocre score, since there's no other dimension on which to praise her. So Agent B is at least not worse, and if her credence is calibrated she's actually doing well.
(6) Generalize: for any claim where you're not certain, holding some credence (even a wild guess) puts you in the game where accuracy can be measured, while suspension puts you in a void where epistemic evaluation doesn't apply.
(7) Therefore accuracy-first epistemology should reject suspension as rational; it should tell you to always form some credence, however weak, rather than stay agnostic.
(8) But that means you should have opinions about literally everything—every historical detail, every moral dispute, every metaphysical speculation—because having an opinion is always epistemically preferable to having none.
(9) That's clearly wrong. So (1) must be false, or at least accuracy can't be the only good.

I feel like the mistake is somewhere between (4) and (6)—like I'm treating "no evaluation" as "bad evaluation"—but I can't quite name the error. Or maybe (2) is wrong and suspension actually does carry an accuracy value (like full credit if you're correct that you don't know?). Which step do you reject, and what does giving it up cost? I'd really like to keep (1) if possible, since dropping the accuracy-first idea feels like throwing out the bathwater with the baby.
