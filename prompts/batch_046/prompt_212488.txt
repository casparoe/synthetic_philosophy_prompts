ok so i've been trying to sort out where i stand on metaontology and i'm not sure my commitments actually hang together. here's roughly the package:

(1) i think most ontological disputes—like do numbers exist, do properties exist—are verbal in the quantifier-variance sense. there's no deep metaphysical fact, just a choice of how to use "there is."

(2) but i also think quine was right that ontology shouldn't be arbitrary; it should be tied to our best science. if physics has no need for universals, you shouldn't be a realist about them.

(3) my test for a verbal dispute is the translation test: if each side can render the other's claims in their own framework without loosing truth conditions, then they're just talking past each other.

(4) but take the universals debate. the nominalist can translate "redness exists" into "this object is red," and vice versa, so by (3) it should be verbal. still, i feel like the realist is genuinely wrong about the world, not just using different words.

(5) i also think vagueness is always semantic, never ontological. if it's vague whether there's exactly one object made of these parts, that's just language being sloppy, not reality being fuzzy.

so is this a consistent package? it feels like (3) forces the universals debate to be verbal, but (4) treats it as a substantive mistake. and (1) with (2) seems like i'm mixing carnappian framework-relativism with quinean naturalism—do those even fit? also does (5) create problems for (2) if science uses vague terms?

please audit the tensions for me: rank them by how serious they actually are, say which commitment has to go if any, and what giving it up costs me. and please say how confident you are in all this, and specifically point out the part you're least sure about.
