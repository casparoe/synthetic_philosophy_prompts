I'm a software engineer without formal philosophy training, and I've been trying to formalize an intuition about infinite sets using analogies to data structures and information capacity. Here is an argument I constructed that seems to show finitism is unavoidable, but the conclusion feels too strong given that mathematicians routinely work with infinite sets. I want to know exactly where it fails and what I have to give up.

(1) Hilbert's hotel demonstrates that an actually infinite set can be put into one-to-one correspondence with a proper subset of itself.
(2) If two sets are in bijection, they carry the same cardinal information; that is, knowing the indexing scheme for one fully determines the other.
(3) Cantor's power-set theorem shows that for any set, there is a strictly larger set—the set of all its subsets—with a strictly greater cardinality.
(4) So if we begin with an actually infinite base set and iterate the power-set operation, we generate an unending hierarchy, each level strictly larger in cardinal information than the previous.
(5) Any representational system—whether a computer program, a database, or a finite mind—can encode only finitely many bits of information at any given stage.
(6) Therefore, for a high enough level in the hierarchy, the cardinal information of the set exceeds the total representational capacity of any possible system.
(7) A concrete object that necessarily exceeds the representational capacity of every possible system is, for all practical and epistemic purposes, unrepresentable and unverifiable.
(8) It is not rational to commit to the existence of concrete entities that are in principle unrepresentable.
(9) Hence, we should reject actual infinities and accept finitism: only potential infinities exist, as processes that can be extended without ever reaching a completed totality.

Which premise or inferential step should I reject? I would prefer to keep (3) and (5), since Cantor's result and the finitude of representation seem hard to deny. If the argument is valid, I need to know what accepting (9) costs me—specifically, whether I must also reject standard mathematics that treats infinite sets as completed objects. If it is not valid, point out the subtle shift—whether in the notion of cardinal information, the move from epistemic inaccessibility to non-existence, or elsewhere—and explain why that step looked plausible but fails.
