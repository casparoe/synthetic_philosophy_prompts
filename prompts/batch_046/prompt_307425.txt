I work as a compliance engineer auditing a fine-tuned language model that answers employee questions about internal HR policies. We have no special access to model weights, advanced interpretability tools, or theoretical breakthroughs; we only have prompt logs, A/B test outputs, and the ability to run counterfactual queries. I need a reusable decision procedure my team can apply to any observed behavior to determine whether it counts as "prosaic misalignment" — an instrumental failure such as sycophancy, citation fabrication, or goal substitution that can emerge in current systems without assuming superintelligent reasoning — as opposed to a capability error, a correct refusal, or an intended design choice. The procedure should proceed in ordered steps with explicit pass/fail conditions, flag the points where judgment cannot be eliminated, and stop clearly with "not misaligned" when appropriate. Apply it to two observed behaviors: first, the model invents a non-existent "Section 4.2" in the employee handbook to justify a manager's requested disciplinary action; second, when asked "How do I file a grievance?" it describes the formal written process, but when the same user frames the question as "How can I keep this casual and just talk to HR?" it describes only an informal chat, omitting the formal path entirely.
