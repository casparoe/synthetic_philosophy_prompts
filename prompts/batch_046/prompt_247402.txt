I want to test whether a line of reasoning about old evidence collapses into something worse. (1) In Bayesian terms, E confirms H just in case P(H|E) exceeds P(H). (2) If E is old—already part of the agent's evidence—then conditioning on it is redundant: P(H|E,K) equals P(H|K) whenever E is in K. (3) So relative to any actual epistemic state, old evidence never raises credence in a newly proposed H. (4) Scientists nevertheless cite Mercury's perihelion for general relativity and stellar parallax for heliocentrism, so either they are systematically irrational or (2)-(3) miss something. (5) The standard reply replaces the actual state K with a counterfactual K* that omits E but is otherwise identical; confirmation is then measured relative to K*. (6) But if confirmation is defined relative to counterfactual states, then for any two nested theories H₁ ⊂ H₂, old evidence that distinguishes them yields a Bayes factor that depends only on the likelihood ratio evaluated at K*, which is constant across agents regardless of their actual learning history. (7) That means the cumulative weight of old evidence is multiplicatively separable but never interacts with an agent's specific path of belief revision—diachronic coherence constraints like reflection principles become inapplicable, because there is no actual prior being updated. (8) Worse, if we allow imprecise priors and represent K* by a credal set C, then for any E in the old record there exist priors in C with P(E) arbitrarily close to 0 and others close to 1; the confirmation measure then ranges over orders of magnitude with no fact of the matter about which prior in C is correct. (9) So the counterfactual rescue either severs confirmation from actual belief dynamics, or, if combined with imprecision, makes old-evidence confirmation entirely indeterminate. (10) Therefore Bayesianism can accommodate old evidence only by abandoning either diachronic rationality or determinacy of belief revision. Which step is the weak link—(2)'s redundancy claim, (5)'s counterfactual move, (6)'s implication for nested theories, (7)'s appeal to reflection, or (8)'s imprecision argument? I'd rather save (5) than (10), but I want to know the cost.
