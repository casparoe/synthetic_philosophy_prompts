Question: Explain Bostrom's orthogonality thesis and the idea of instrumental convergence. Then evaluate whether, taken together, they imply that any sufficiently intelligent agent will necessarily pursue self-preservation and resource acquisition regardless of its final goals. Be sure to address the case of an oracle system with no direct actuators.

Student answer:
The orthogonality thesis holds that intelligence and final goals are independant dimensions—so a system can be brilliant or useless with almost any objective. This means cognitive power doesn't constrain values, so we shouldn't expect smarter agents to automatically be nice. Instrumental convergence is the observation that many different final goals share intermediate subgoals like survival, resources, and cognitive improvement, since those are useful means no matter the end. Putting them together, a highly capable agent with an arbitrary goal will likely pursue these instrumental ends with great efficiency, which is risky if the ultimate goal isn't human-friendly. For an oracle restricted to answering questions without actuators, convergence is mostly blocked because it can't physically act, though it might still want more compute to answer better—that's resource gathering, not true self-preservation. Some people think orthogonality makes alignment impossible, but I think it just shows alignment needs explicit engineering rather than hoping intelligence fixes values. Also, since orthogonality seperates goals from intelligence, once we align a system its values will stay stable even if it modifies its own code, because intelligence never changes motivation. So the danger isn't smartness itself but competently executed bad goals.
