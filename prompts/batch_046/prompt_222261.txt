Write a 14-line sonnet divided into an octave and a sestet, with the volta between them. The octave should contain two quatrains describing the identical physical action—an agent pressing a button that activates a mechanism—using the same syntax and rhyme scheme in both, except that one quatrain substitutes words so the outcome harms a bystander and the other so it helps one. The formal parallelism should make the divergence feel unavoidable rather than argued. In the sestet, the speaker should judge whether the agent acted intentionally, letting that judgment track the harm/help distinction rather than any change in mental state. Use the couplet to ask whether intention is tracking psychology or moral valence, leaving the tension open. Render the asymmetry precisely enough that someone familiar with experimental-philosophy work on side-effect attribution recognizes the pattern without naming it. Begin with the poem itself, no preface or commentary.
