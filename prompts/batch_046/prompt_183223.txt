I serve as the ethics-compliance reviewer for a nonprofit advocacy organization that launches frequent, high-stakes public campaigns (public-health messaging, climate-policy advocacy, and similar). Before any campaign is released, my team—non-philosophers with roughly thirty minutes per proposal—must run a reusable audit that distinguishes legitimate persuasion from manipulation. I need this operationalized as an ordered decision procedure: the gates to run in sequence, the operational question at each gate, what counts as a sufficient answer, where the procedure stops with a definitive rejection, where it hands the decision to a human because the remaining question is one of values rather than facts, and which steps are irreducible judgment calls that must be flagged as such. The underlying framework should draw on the philosophical distinction between persuasion that respects rational autonomy and manipulation that subverts it, but it must be translated into practitioner-level tests. To keep the audit precise rather than generic, use a three-filter architecture: (1) a Transparency Filter—can the target identify that persuasion is occurring and identify the primary framing mechanism without specialist knowledge? (2) a Counterfactual Reasoning Filter—given the same core evidence in a neutral architecture, could the target still form the contrary belief using their own evaluative capacities, or does the design structurally disable that path? (3) a Vulnerability-Calibration Filter—does the campaign exploit a domain-specific cognitive vulnerability (e.g., affective tagging, loss-aversion framing, default-lock architecture) in a way that is disproportionate to the evidentiary weight and not disclosed? Note that a campaign may pass transparency and still fail vulnerability-calibration if the exploitation is structurally hidden.

Apply the procedure to three proposals: (A) a vaccination campaign that uses intense bereaved-parent testimonials, carries an explicit advocacy label, and links to full epidemiological data via QR code, with emotional framing that is intense but does not block access to contradictory evidence; (B) a carbon-tax advocacy interactive quiz that embeds verified statistics inside a gamified flow, locks navigation until the user selects the "correct" answer, triggers shame-based feedback for errors, and carries no disclosure that it is advocacy rather than neutral education; (C) a low-literacy infection-dynamics campaign that uses culturally resonant metaphors, verifies every point claim, but omits all confidence intervals because pilot testing showed that including them reduced uptake, does not disclose the omission, and targets a population with limited statistical literacy—this is a campaign my organization would strongly want to deploy for welfare reasons, so I need the audit to be willing to reject it if the framework demands it.

State clearly what the procedure cannot do—for example, whether it can detect hidden intent behind truthful framing, whether it applies to private one-on-one conversation, or whether it resolves conflicts between autonomy preservation and welfare outcomes. Give a committed answer: classify each case unambiguously (Pass / Conditional Pass / Fail), do not present the classification as optional or balanced, and for each gate provide explicit reasoning.
