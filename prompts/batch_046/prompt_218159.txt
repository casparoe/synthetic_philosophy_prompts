I'm working through my IP intuitons before writing a longer post — I've been reading some old LessWrong threads on idea-spaces and cognitive enclosure, and I want to check if my package is coherent or just a grab-bag of vibes. Here are my commitments:

(a) The framing that ideas are property is a category error. Ideas aren't rivalrous — my knowing a theorem doesn't deprive you of knowing it — so owning an idea is like owning the number seven. Patents on pure math or business methods should be abolished.

(b) But the labor of fixing an idea into a specific, durable expression that others can actually use is real work. Unrestricted copying of that exact fixation right after creation free-rides on the labor without social gain, so limited copyright in expression is justified — not as ownership of the idea, but as a temporary labor-reward.

(c) The idea-expression dichotomy should be absolute. Algorithms, recipes, and mathematical proofs live entirely in idea-space; treating them as patentable is cognitive enclosure, pure and simple.

(d) Software is weird because code is simultaneously expression and functional mechanism. I think open-source licensing should be the default for code, with proprietary licensing requiring special justification — not because code isn't expression, but precisely because locking up functional speech is especially harmful.

(e) IP rights shouldn't survive the creator for more than maybe fifteen years. Dynastic idea-wealth replicates aristocratic stratification, which undermines the meritocratic story we tell about innovation — yet I still defend the creator's lifetime exclusivity in (b).

(f) I also think there's a meaningful distinction between discovery and invention in science that IP law ignores. Mapping a biological pathway is closer to charting territory than building a fence, but I still think the researcher should control first publication of that specific map for a window, which sounds suspiciously like owning the territory.

So: does (a) bleed into (b) in a way that kills both? Is the tension between (c) and (d) real or just me being sloppy about categories? And what's going on with (f) — is that an obvious contradiction or does it dissolve if you separate epistemic access from economic control? Rank the actual tensions by severity, tell me which pairs only look bad, and what's the cheapest revision that makes the set hang together without me having to abandon the anti-enclosure core.
