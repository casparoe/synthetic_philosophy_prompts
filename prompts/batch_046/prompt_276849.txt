6. Fleming's contaminated petri dish leading to penicillin. Same vibe: antibiotics as a class were emerging within a decade anyway, so this is a trigger event, not a load-bearing hinge.

The pattern I think I'm using is that small causes matter only when the system is near a bifurcation point and the cause is the actual tip, not noise inside a stable trajectory.
