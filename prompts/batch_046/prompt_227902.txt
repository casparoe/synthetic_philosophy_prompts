hey, I've been chewing on Hofstadter's strange loop idea — that the self isn't a thing but a pattern, where the symbol 'I' just loops back to denote the system generating it — and I think I pushed it into an argument that proves way too much. can you help me find the leak?

(1) If 'I' is just a self-referential loop with no hidden core, then the self is defined only by the dynamics that maintain it, not by any particular substrate.
(2) So if you gradually replace my neurons with synthetic ones while preserving the loop dynamics, I survive.
(3) By the same logic, if you split the loop across two running substrates — say a brain split or a copied model — both loops generate an 'I' that technically denotes "the system generating this symbol."
(4) That means there'd be two seperate self-loops, each correctly calling itself 'I', where before there was one.
(5) This sounds wild but maybe okay for Hofstadter, since he thinks the self is already a kind of illusion.
(6) Here's where it gets weird: apply the same reasoning to ordinary indexicals. "Now" loops back to the temporal frame of utterance; "here" loops back to the spatial frame.
(7) If loop dynamics alone ground reference, then in a split-presence or time-shifted scenario these should be just as multi-satisfiable as 'I'.
(8) But we don't treat "now" or "here" as ambiguous in that way — we act like there's an anchored fact about which moment or place is meant.
(9) So either all indexical reference is actually unanchored and communication is constantly misfiring (absurd), or strange loops need some extra "binding site" that fixes them to one specific substrate or frame.
(10) But adding that anchor looks like smuggling in a Cartesian ego or a hidden essence, which is exactly what Hofstadter was trying to avoid.
(11) Therefore the strange-loop view either collapses into saying no reference is ever uniquely fixed, or it secretly relies on the very kind of substantial self it denies.

I want to keep (1) and (5) if possible — I like the anti-substantialist vibe — but I feel like (7) might be cheating by treating 'I' like 'now'. Which step should I reject, and what does giving it up cost? Also, where is this reasoning most likely to fail? Like, what specific argument or observation would change your mind about which premise is the weak link?
