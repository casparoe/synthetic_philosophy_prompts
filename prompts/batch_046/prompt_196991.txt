ok so i've been stewing on this institutional quirk. in a bunch of european science funding bodies, grant apps now have to include a 'theoretical framewrok' box where you declare which paradigm you're working in—like quantum mechanics vs pilot-wave vs whatever. and if your proposal looks like it spans two paradigms, they don't send it to one interdisciplinary panel; they literally split it into separate tracks and evaluate each half with reviewers from only thier own camp. meanwhile every philosophy of science undergrad reads Kuhn and gets told incommensurability makes rational comparison across paradigms basically impossible. so what philosophical commitments about paradigm shifts and incommensurability does this funding practice actually presuppose? does it assume there's a core observational language that stays stable and only the theoretical superstructure changes? or does it take strong incommensurability seriously and just build institutional walls around it? and is this consistent with the same system's claim that science progresses through empirical testing—because if paradigms are truly incommensurable, how can the same data ever adjudacate between them? i want to reconstruct the implicit theory here: does the practice strictly need partial commensurability to function, or could a hardline Kuhnian run it exactly this way? also, what would peer review look like if we dropped the assumption that there's always a shared vocabulary? like, would we need separate journals for each paradigm? trying to figure out if the practice is philosophically underdetermined or if it actually sneaks in a specific view of scientific change.
