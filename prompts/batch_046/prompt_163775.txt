Critics object that this computation requires a shared moral currency: you can't weight 'rights violations' against 'welfare gains' unless both are measured in the same units, which presupposes the very thing in dispute. First, explain how a defender of expected choice-worthiness might answer this without positing a universal metric. Student response:
Expected choice-worthiness works just like expected utility except applied to ethics. If you have 60% credance in consequentialism and 40% in deontolgical ethics, you score every option on both theories, multiply by those weights, and sum them to get a total. The shared-currency objection says this is impossible because deontology uses side-constraints, not point-values, so there's literally no number to plug into the equation.

The defender can reply that we don't need one deep metaphysical scale. Within each theory we just rank actions ordinally, then normalize those ranks onto a 0-to-1 scale relative to the best and worst outcomes that theory allows. After normalization we weight by credance and combine. This is only a practical aggregation rule — basically like using a Borda count across theories — not a claim that rights and welfare are the same kind of thing.

But there's still a hidden issue. By assigning numerical credances to moral theories we're treating them like competing scientific hypotheses, which assumes there's an objective fact about which is correct. That's moral realism. A pluralist in Berlin's sense would also reject the normalization step, since genuinely incommensurable values can't be mapped onto one axis without distortion. Finally, the student says normative theories aren't empirical predictions, so applying probabilistic credance is a category mistake. So the normalization fixes the currency problem but not the metaphysical ones.
