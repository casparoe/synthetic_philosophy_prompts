Exam question:
In epistemology, the regress problem threatens to undermine inferential justification. Foundationalism, coherentism, and infinitism are the three canonical responses. For this question, distinguish a structural formulation of the regress—whether justification requires an infinite hierarchy of supporting beliefs in principle—from a dynamic formulation—whether a finite epistemic agent must actually traverse such a hierarchy in order to be justified. With this distinction in view, evaluate the claim that foundationalism resolves the structural problem only by arbitrarily halting the chain with basic beliefs; that coherentism avoids both formulations through mutual support among beliefs; and that infinitism fails because it requires agents to possess an infinite number of beliefs. Address each position with precision.

Student's answer:
Foundationalism stops the structural regress by introducing basic beliefs that are non-inferentially justified. These beliefs are self-justifying, meaning they do not depend on any further beliefs for their epistemic status. This halt is not arbitrary, because every system of justification must have a starting point. Coherentism rejects basic beliefs altogether and allows beliefs to support one another within a network. This addresses the dynamic regress, since an agent need only hold a finite web of mutually reinforcing beliefs; there is no vicious circularity here, because circular reasoning only arises when one belief is used to justify itself directly. Infinitism accepts an infinite chain of justification, but it is psychologically unrealistic: human cognitive capacities are finite, so no agent could actually possess an infinite number of beliefs. Consequently, coherentism offers the best resolution, avoiding both the arbitrariness of foundationalism and the impossibility of infinitism.
