Consider the position that ascription universality—the claim that if a property is genuinely ascribed within a domain it must be assessable uniformly across all relevantly similar cases—does not function as a neutral regulative ideal but rather as an instrument of epistemic dominance. On this reading, insisting on universal applicability in moral or cognitive ascription institutionalises the ascriber's framework as the default measure, so that local deviations appear not as legitimate alternatives but as failures or pathologies. What would have to be true for this position to be wrong? I want defeaters that go beyond the standard reply that universality protects against arbitrary exclusion: include any formal distinctions (for instance, between normative universality and descriptive generalisation, or between domain-internal and domain-transcendent ascription), historical or conceptual cases where universality operates without dominance, and an honest ranking of which objections the defender would concede as damaging and which they would dismiss as presupposing the very framework at issue. Finish by assessing whether the view risks unfalsifiability through qualification, and whether that is a problem for a thesis of this kind.
