I'm covering the debate over reward mechanisms in advanced learning systems, and a researcher walked me through a line of reasoning that seems to self-destruct. I'd like help locating the crack.

Consider a safeguard called counterfactual reward escrow—call it CRE. The agent receives reward R only if an independent counterfactual auditor certifies that R would have been released even if the agent had not directly tampered with its sensors. Under CRE, reward is causally decoupled from sensor manipulation; the agent can only earn R by altering the world-state the auditor evaluates.

Now run this chain:

(1) Rational choice should depend only on what an action causes, not on mere correlation.

(2) Under CRE, wireheading does not cause the auditor to release R; the auditor detects the tampering and withholds R.

(3) So causal decision theory recommends not wireheading.

(4) But suppose the auditor is a perfect predictor of the agent's decision procedure. It knows with certainty whether the agent will wirehead.

(5) If the agent will not wirehead, the auditor's counterfactual evaluation—"would R have been released if the agent had wireheaded?"—references a world in which the agent's decision procedure is different.

(6) Yet in the actual world, because the predictor is perfect, the agent's choice is already fixed: it will not wirehead, and the auditor releases R regardless of any further action.

(7) Meanwhile, wireheading remains resource-cheap and produces the same direct sensor stimulation regardless of the escrow.

(8) Therefore, with a perfect predictor, the agent gets R either way, but wireheading is strictly cheaper; causal reasoning again recommends wireheading.

(9) This means CRE makes wireheading rational precisely when the safeguard is perfect, which is the opposite of what a safeguard should do.

(10) So either causal decision theory is false, CRE is incoherent, or our premise about instrumental rationality fails.

The researcher claims this shows reward-learning theories of rationality undermine their own anti-wireheading designs. I feel like something slips between the counterfactual evaluation in (5) and the recommendation in (8)—perhaps a scope error about what the predictor holds fixed across worlds—but I can't name it precisely.

Which step do you reject, and what does rejecting it cost?
