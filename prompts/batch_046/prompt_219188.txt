Question: Some philosophers defend standard epistemic logic against logical omniscience by distinguishing explicit belief—subject to resource-bounded syntactic closure—from implicit belief, which remains semantically closed. Critics reply that this merely relocates the problem, since the knowledge operator applies a uniform closure condition regardless of psychological realization. Assess this defense. In particular: (a) explain how the explicit/implicit distinction is meant to dissolve the omniscience problem; (b) evaluate whether a resource-bounded syntactic closure (e.g., derivability only within a fixed number of proof steps or only for premises in working memory) genuinely avoids omniscience; and (c) address whether standard logic can consistently be read as describing only implicit belief.

Student answer: The defense succeeds. Logical omniscience requires that if an agent knows φ and φ implies ψ, she knows ψ, which is unrealistic only for explicit belief—what is actually in working memory. For implicit belief, closure is harmless because it captures logical consequence, not current access. The distinction dissolves the problem by restricting omniscience to implicit belief, an idealization like a mathematical limit rather than a psychological claim. A resource-bounded syntactic closure—say, allowing only derivations under 100 steps with premises in working memory—ensures explicit belief avoids full semantic closure. If an agent knows P and P→Q but Q requires 101 steps, she does not explicitly know Q, so the closure axiom K is not violated in the explicit domain. Standard epistemic logic, with its possible-worlds semantics, correctly describes implicit belief: in every world compatible with her knowledge, Q holds if P and P→Q do. Hintikka (1962) originally designed possible-worlds semantics for implicit knowledge, not psychological processing. Later, Fagin, Halpern, Moses, and Vardi (1995) formalized explicit belief lists with awareness constraints, showing how syntactic resource bounds integrate into the framework. Thus explicit belief is weakly syntactically closed, implicit belief is semantically closed, and standard logic describes the latter without unrealistic psychological commitments.
