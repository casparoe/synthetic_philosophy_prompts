Consider the following chain of reasoning, which attempts to vindicate finitism by showing that Hilbert's hotel and Cantor's pairing arguments describe only potential, never-completed processes rather than actual infinite sets.

(1) A collection counts as actually infinite only if a completed one-to-one correspondence exists between it and one of its proper subsets.
(2) Hilbert's hotel supplies the standard model: rooms numbered 1, 2, 3, ..., all occupied, with the manager freeing room 1 by assigning each guest in room n to room n+1.
(3) This assignment is carried out by a sequential instruction—"occupant of room 1 to room 2," "occupant of room 2 to room 3," and so on—so that at every finite stage only finitely many relocations have been executed.
(4) Where a task requires infinitely many discrete steps, each with its own logical or temporal priority, the task is never finished in actuality.
(5) Hence the hotel relocation is never actually completed: there is no state in which every original occupant has been reassigned and room 1 is genuinely vacant.
(6) If the correspondence is never completed, then there is no actual mapping between the full set of occupants and the proper subset {2, 3, 4, ...}.
(7) Therefore Hilbert's hotel does not display an actual infinity being mapped onto a part of itself; it displays only an indefinitely extendible potential procedure.
(8) Cantor's proof of different cardinalities depends on completed pairings of this kind (e.g., the natural numbers with the even numbers).
(9) Since such pairings are never actually achieved, transfinite cardinalities lack any actual instantiation.
(10) Consequently, all infinite collections are merely potential, and finitism is correct.

The conclusion seems unacceptable—Hilbert's hotel is ordinarily treated as a legitimate model of actual infinity—yet each premise appears defensible.
