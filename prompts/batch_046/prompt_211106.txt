I've been trying to apply Wittgenstein's idea that language games are unified by family resemblance rather than by a common essence, specifically to determine whether chain-of-thought reasoning traces produced by large language models count as a genuine language game. I take it that family resemblance supplies a positive, feature-overlapping criterion—something like a weighted graph of shared properties—through which we can algorithmically verify whether a given practice belongs to the category. From this, I'm attempting to derive the minimal cluster of overlapping features that must be present for a synthetic reasoning trace to qualify, on the assumption that if no single feature runs through every instance, the category collapses into arbitrariness. But I keep running into a tension: if there truly is no universal thread binding all language games, how can Wittgenstein maintain that meaning is strictly determined by use within a specific game, rather than being radically conventional? Without some shared condition, doesn't the distinction between a legitimate language game and an arbitrary interaction pattern—say, between a model and a prompt engineer—require us to smuggle back in the very essentialist criterion that family resemblance was meant to eliminate? I would appreciate help clarifying whether the absence of necessary conditions genuinely threatens the determinacy of meaning-in-use, or whether my framing already mistakes resemblance for a taxonomic algorithm.
