ok so i've been going in circles on sleeping beauty and self-locating belief and i think i've walked myself into a trap. here's the argument i built for a seminar and now find suspicious because the conclusion feels like it breaks cosmology.

(1) In Sleeping Beauty, upon waking Beauty should assign creedence 1/3 to Heads, not 1/2, because she knows there are three subjectively indistiguishable observer-moments compatible with her evidence—Monday with heads, Monday with tails, and Tuesday with tails—and the Self-Sampling Assumption says she should reason as if she's randomly drawn from that set.

(2) The reason this updates her belief is that being awake now is genuinely evidential: if Tails, there are twice as many wakings, so finding herself awake favors Tails.

(3) If that's correct, then self-locating information always updates probabilities via counting: worlds or outcomes that produce more copies/instances of an observer should be weighted proportionally, so thier presence pulls credence toward them.

(4) So apply the same logic across possible worlds. If World A has one copy of me and World B has a trillion copies with the same experiences, then by SSA I should think I'm almost certainly in World B.

(5) But that's obviously wrong—without independent reason to think World B exists, I shouldn't assign it near-certainty just because it's more populus.

(6) Therefore, either we reject (1) and go back to the half-credence answer, or we bite the bullet and accept this wild cosmological bias.

(7) Most people in the rationalist space I read want to keep 1/3 and deny (4), but I can't see how to block the slide from (2) to (3) without gutting the reasoning that saves (1). Where does this actually go wrong? If I have to choose, I'd rather keep (1) than (5), but I want to know exactly what I'm paying—am I sneaking in an inter-world vs intra-world distinction that isn't principled, or is there a hidden equivocation between SSA and SIA?
