Consider the idea of superrationality: in a symmetric strategic situation, if two agents are perfect reasoning duplicates—each knowing that the other shares the same rationality, information, and decision algorithm—then whatever conclusion one reaches, the other reaches as well. I have been applying this idea to several concrete cases and find my intuitions pulling in different directions. I want to know whether there is a unified principle that governs them, and if not, which of my judgments should be revised.

Here are my verdicts.

Case 1. The standard one-shot prisoner's dilemma, with full transparency and no possibility of future interaction. I think both agents should cooperate, even though defection strictly dominates. The reasoning is symmetric: each sees that if cooperation is rational for me, it is rational for you, and vice versa, so we should both land on it.

Case 2. A pure coordination game with two symmetric Nash equilibria: (Left, Left) yielding a payoff of 2 to each, and (Right, Right) yielding a payoff of 4 to each; all other outcomes yield 0. I think they should both choose Right, selecting the payoff-dominant equilibrium, because superrational reasoning should converge on the best shared rationalizable point.

Case 3. The same game as Case 2, but presented with an arbitrary framing asymmetry: Agent 1 sees the payoff matrix with rows ordered alphabetically, while Agent 2 sees it with rows ordered reverse-alphabetically, and both know that the ordering is random, meaningless, and common knowledge. I still think they should both choose Right; the framing should be ignored entirely.

Case 4. A symmetric anti-coordination game—call it Divergence—where each agent chooses X or Y. If they choose opposite actions, each gets 5; if they choose the same action, each gets 1. There is no payoff-dominant assignment of roles. Here I think they should exploit the framing asymmetry from Case 3 (or any other publicly observable but payoff-irrelevant feature, such as the parity of their assigned session IDs) to break symmetry: one uses the feature to select X, the other uses it to select Y. Without such a correlation device, they risk the low-payoff match.

Case 5. Divergence again, with the same public framing feature available, but now there is also a hidden microscopic difference: Agent 1's processor clock ticks one millisecond faster than Agent 2's, a fact that is true but not observable to either agent and not part of common knowledge. I think they should ignore this hidden difference and still rely only on the public framing feature from Case 4, not on the clock. If the public framing feature were absent, I think they should randomize with equal probability rather than attempt to use the hidden clock.

Case 6. A continuous symmetric game: each agent selects a real number in [0, 1], and the payoff to each is u(x,y) = -|x - y - d| + c·min(x,y), where d = 0.3 and c = 0.8 are common knowledge. The penalty term is eliminated exactly when |x - y| = d, leaving payoff c·min(x,y), which is maximized at the boundary pairs (1, 0.7) and (0.7, 1), both yielding 0.56. Every other feasible pair is strictly worse. Thus there are exactly two optimal outcomes, assigned anti-symmetrically. I feel they should converge on one of these two via a shared focal rule—perhaps using an observable framing feature to assign who takes 1 and who takes 0.7—rather than randomizing uniformly. But I am unsure whether the focal rule should appeal to observable framing, to payoff magnitude, or to some other shared rational criterion.

These judgments seem to rely on an implicit distinction between spurious asymmetries that can serve as legitimate correlation devices and those that should be ignored, between unique rational points that should be selected directly and continuous or anti-symmetric sets that require a focal principle, and between transparent symmetry-breaking and hidden asymmetry. Can you articulate a precise principle—perhaps with explicit conditions about common knowledge, observability, uniqueness of the rational set, and focal salience—that captures Cases 1 through 5, predicts the correct assignment in Case 6, and states honestly which of my verdicts it must reject? If no single principle can accommodate all six, present the two best competing formulations, state exactly where each fails, and indicate which verdicts each forces me to abandon.
