I have recently begun working on interpretability for large language models, and I have become preoccupied with how instructions are layered inside prompts: system-level framing, explicit user queries, and implicit reasoning traces the model generates internally. A colleague proposed that decoding these layers is structurally identical to Hofstadter’s taxonomy in Gödel, Escher, Bach—frame messages, outer messages, and inner messages—mapping the system prompt onto the frame that tells us how to read the input, the user query onto the outer message, and the model’s internal chain-of-thought onto the inner message that carries the actual semantic payload. She uses this to argue that interpretability should focus almost exclusively on extracting and validating that inner layer, treating the others as disposable scaffolding. Before I adopt this framing, I want to audit it precisely. Lay out the correspondence table: what in the prompt architecture corresponds to the frame message, the outer message, and the inner message? Then identify where the mapping fractures—does the system prompt function purely as a metacommunicative frame in Hofstadter’s sense, or does it participate in the content? Does the model’s internal reasoning correspond to an inner message intended to be decoded by an external recipient, or is it closer to an intermediate computation? What features of the original taxonomy—such as the inner message being hidden inside a formal structure that must be interpreted from the outside—are present or absent here? Assess whether my colleague’s conclusion, that interpretability should privilege the inner layer, actually survives once these disanalogies are visible, or whether the analogy was carrying the conclusion all along. If the mapping collapses, suggest a more appropriate framework from philosophy of language or information theory for describing these nested prompt layers.
