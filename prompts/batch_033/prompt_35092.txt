I've been reading about the reference class problem and I've got to say, I don't see what the big deal is. Surely the answer is just: always use the narrowest reference class you have data for. If I want to know the probability my startup fails, I don't use the failure rate for all new businesses — I use the rate for tech startups in my sector, in my city, with my funding level, founded by someone with my background, etc. The narrower the class, the more the probability is actually about *my* situation rather than some aggregate I only sort of belong to. Philosophers talk about this like it's some deep unresolved puzzle but it seems like a straightforward methodological principle. What am I missing?
