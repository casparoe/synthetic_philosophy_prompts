Suppose a fair coin is tossed until it lands heads. If the first heads occurs on the nth toss, the player receives a payoff of (−1)^(n−1) · 2^n / n dollars — a reward when the sign is positive, a penalty when it is negative. The amounts grow without bound as n increases, and the sign alternates. When I compute the expected value in the obvious way, summing the probability of each outcome times its payoff in the natural order of n, I get a finite positive number (ln 2, about 0.69). But the positive terms alone sum to +∞ and the negative terms alone sum to −∞; the finite total is possible only because the two infinities cancel, and how much is left after the cancellation depends on the order in which I add the terms. By listing the very same outcomes in a different order, or by grouping them differently, I can make the expected value come out to any real number I like, or diverge to ±∞. The game itself hasn't changed, but the expected value seems to depend on how I write down the sum.

I've also noticed that this causes trouble for comparisons. Take the same game and add one dollar to every payoff, so that in every possible outcome the modified game pays exactly one dollar more. The modified game seems strictly better — it is better in every outcome — yet on the usual expected-value test both games are equally without a well-defined expectation, so the theory seems unable to register the obvious improvement.

I know about the St. Petersburg game and its infinite expectation, but this seems different. There the problem is that the expectation is infinite; here the arithmetic gives a finite answer under one ordering but no unique answer overall. Is there an established name for this configuration, or for the family of gambles like it? I'm not just after a label. I want to know exactly what the phenomenon is — whether it is best described as an undefined expectation, an order-dependent expectation, a failure of the principle that if one option is better in every outcome then it should be preferred, or something else — and how it differs from the St. Petersburg case and from ordinary cases of infinite expected value. What should a decision theorist say about whether the original game is worth playing, and about whether the modified game is better?
