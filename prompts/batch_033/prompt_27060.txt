I'm writing an essay on the reference class problem in the philosophy of probability, and I want to use Steven Spielberg's *Minority Report* (2002) as an extended case study. The reference class problem, roughly, is that any singular probability judgment — "the probability that this particular event will occur is p" — depends on which reference class we place the event in, and there appears to be no principled way to select the right one. Any individual case belongs to indefinitely many classes, and the probability can shift dramatically depending on which we choose.

The Precrime system in *Minority Report* seems to embody this problem with unusual precision. When the precogs flag someone as a future murderer, Precrime is effectively assigning a probability to the singular event "this person will commit a murder," and that probability depends on the reference class: "people the precogs have identified as future murderers" versus "people who have not yet formed a criminal intention" versus "people who are aware they are being monitored by Precrime," and so on. The film's central complication — the minority report, where one precog disagrees with the other two — appears to make the reference class problem visible from inside the system itself, since it reveals that even the precogs' own outputs depend on which precog's vision you treat as the authoritative reference.

I would like a reading of the film that takes the reference class problem seriously as a philosophical difficulty, not merely as a plot device. Where does the film genuinely dramatize the problem — showing that there is no neutral, non-arbitrary way to pick the reference class — and where does it instead resolve the tension by narrative fiat (for instance, by making the precogs effectively infallible except when the system is deliberately tampered with)? Does the film ultimately suggest that the reference class problem is inescapable, or does it imply that with enough data and the right institutional design we could solve it? And what does the film's treatment of free will — the "you can choose" moment — do to the reference class framing? If the future is genuinely open in the way the film's climax seems to insist, does the reference class problem become moot, or does it simply shift to a different level of description? I want the essay to be fair to both the philosophy and the film, and to conclude by saying something about what the film dramatizes that the standard philosophical literature on the reference class problem tends to miss.
