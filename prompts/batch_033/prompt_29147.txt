I keep coming back to a view I picked up from Hofstadter's MU-puzzle, and I want to know how exposed it actually is. Quick setup in case you need it: you start with the string MI and four rewrite rules — append U to any string ending in I, double everything after an M, replace III with U, and delete UU — and the puzzle is whether you can ever reach MU. The standard solution stops playing the game and instead counts I's: the number of I's starts at one and is never a multiple of three, so MU, which has zero I's, is unreachable. The view I'm tempted by is that this little example shows something big. Some problems can't be cracked by working forward inside the rules that define them; you have to jump out of the system, re-encode the problem in a richer vocabulary (arithmetic), prove something about the whole space of possible moves, and only then come back down. Hofstadter calls this jumping out of the system — JOOTSing — and treats it as a microcosm of what Gödel did and, more importantly, of what intelligence is: a machine stuck inside the system just grinds through strings, while a mind that understands steps outside and sees the whole board.

But I worry I've let this become unfalsifiable profundity, so I want you to play it straight and tell me what would count against it. What would have to be true for the MU-puzzle to not teach that lesson — for the 'jump' to be just more symbol-shuffling one level up, or for the inside/outside distinction to be doing no real work at all? A programmer friend keeps insisting that the 'outside' reasoning is itself mechanical: you can code up the invariant argument in a slightly bigger formal system, so nothing genuinely non-mechanical happened. I'd find that the most persuasive kind of defeater if it lands, but I'm not sure how much it does.
