"The frame problem is the problem of keeping a robot's beliefs up to date. Suppose the robot has a big store of facts and then pushes a block across a table; it needs to work out which of its beliefs changed and which didn't. The classic solution is to add frame axioms, which state what doesn't change when an action occurs — for example, pushing the block doesn't change the color of the wall. But you'd need a frame axiom for every action-fact pair, so the approach blows up. Fodor turned this into a philosophical problem: the real difficulty is knowing which facts are relevant to what you're doing, and he argued that no computational system could ever solve it, since relevance can depend on anything the system knows. This is why classical symbolic AI hit a dead end and researchers moved to connectionist networks instead."
