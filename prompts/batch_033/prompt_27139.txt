Question: State the simple conditional analysis of dispositions. Then explain, with an example of each, how finkish dispositions and masked dispositions cause trouble for it. Finally, explain Lewis's reformed conditional analysis and say whether it deals with both problems.

Student's answer:

The simple conditional analysis (SCA) says that an object is disposed to manifest M in response to stimulus S just in case, if it were to undergo S, it would manifest M. So a glass is fragile iff, if it were dropped, it would break.

A finkish disposition is a disposition that is removed by the very stimulus that would trigger its manifestation. Martin's electro-fink is the standard case: a live wire is hooked up to a safety device that instantly makes the wire dead if a conductor touches it. So the counterfactual "if touched, it would shock" is false, even though the wire is live. The SCA therefore says the wire isn't live, which is wrong. The problem is that the stimulus condition isn't independent of the disposition being tested.

A masked disposition is one where the object keeps the disposition, but some outside factor blocks the manifestation. For instance, a lethal poison that the victim has ingested along with an antidote: the poison is still lethal, but the counterfactual "if ingested, it would kill" is false because the antidote stops the killing. So the SCA gets this wrong too. Really, a mask is just a fink with different timing: in a fink the disposition is removed as soon as the stimulus occurs, while in a mask it gets removed later in the causal chain, after the stimulus but before the manifestation. Either way, the simple analysis is too strong.

Lewis's reformed analysis says that x is disposed to M when S iff x has some intrinsic property B such that, if x were to undergo S and retain B long enough, then S and B would jointly cause M. This fixes finks because the electro-fink works by removing the wire's basis, but Lewis's counterfactual holds the basis fixed: if the wire were touched and kept its charged basis, it would shock, so the conditional is true and the analysis correctly says the wire is live. It fixes masks the same way: in the poison case, the analysis holds the poison's chemical basis fixed, which screens off the antidote as an interfering factor, so the conditional comes out true and the analysis says the poison is lethal. So Lewis's analysis handles both problems.
