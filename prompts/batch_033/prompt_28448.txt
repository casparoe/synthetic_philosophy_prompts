I've been working through decision theory and several adjacent literatures and keep noticing a configuration that seems important but that I haven't seen given a stable name. I'd like to know whether one exists and, if it does, exactly what it covers and what it excludes.

The configuration is this. An agent is trying to make a decision by constructing a model of the world, assigning probabilities to possible states, and picking the action with the highest expected utility. Standard decision theory treats the agent's own reasoning as external to the model — the agent stands outside the world, surveys the possibilities, and chooses. But in many realistic cases, the agent's reasoning is itself a causal process inside the world. The agent's thoughts take time, consume resources, and can be observed by other agents. So the agent faces a problem: either the model includes the agent's own decision process (in which case the model must contain a model of itself, and we seem to get a regress) or it does not (in which case the model is incomplete, and the incompleteness can be exploited).

Here are two instances that make the pattern concrete. First: an agent is playing a bargaining game against an opponent who can observe how long the agent deliberates. If the agent thinks for a long time before making an offer, the opponent infers that the agent's reservation price is close to the offer and negotiates harder. The agent therefore cannot treat the opponent's strategy as fixed while it thinks — the act of thinking changes the thing being thought about. Second: an agent is trying to prove that a proposed modification to its own code is safe before running it. But the agent's proof-checking process is itself part of the code that might be modified, and the proof is a physical object in memory that the modification could alter. The agent's reasoning about the modification is causally entangled with the modification's effects.

I am not asking about the general idea that agents are embodied, situated, or resource-limited. Those are broader categories. I am asking about the specific configuration in which the separation presupposed by standard decision theory — between the reasoning agent and the world reasoned about — fails, and the failure is not just a matter of approximation but seems to challenge the applicability of the framework itself. My questions: does this configuration have an established name in any literature? If so, what are its precise boundaries — what cases count and what nearby cases (e.g., ordinary resource constraints, logical uncertainty about mathematical facts, self-locating uncertainty) are distinct from it? If no established name exists, what would you propose, and how would you define it so that it picks out this configuration and not the broader phenomena it resembles?
