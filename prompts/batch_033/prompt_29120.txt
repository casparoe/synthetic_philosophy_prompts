I'm a software engineer working on a project that involves giving a robot the ability to learn object categories from sensor data and human language input. I've been reading about the symbol grounding problem — the question of how symbols (words, internal labels, feature vectors) get connected to what they're actually about in the world, rather than just being defined by their relationships to other symbols.

Before I commit to any particular architecture, I want a clear specification of what a solution actually needs to accomplish. Write the desiderata for a theory of symbol grounding: what any adequate account must explain, which cases it must get right, which distinctions it cannot collapse, and which objections it must answer — with the reasoning behind each requirement. I'm particularly interested in knowing which requirements are hard constraints and which are just preferences of one research program (e.g., that grounding must involve sensorimotor interaction, or that it must be explainable in purely computational terms). If some subset of the requirements can't be jointly satisfied — given, say, arguments from the Chinese Room debate or the frame problem — I want that flagged explicitly. A brief scorecard against the main families of approaches (symbolic, connectionist, embodied) would help, but the real deliverable is the criteria list.
