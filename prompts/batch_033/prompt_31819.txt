[Question]
State Fitch's paradox of knowability and explain what it is standardly taken to show about the principle that every truth is knowable. Your answer should make clear which assumptions do the real work.

[Student answer]
Fitch's paradox is an argument against the anti-realist principle of knowability, which says that every truth is knowable: for any p, if p is true, then it is possible to know p. The argument starts by assuming there is at least one truth that is not known. Call it q, so we have q ∧ ¬Kq. Since this conjunction is true, the knowability principle says it is possible to know it: ◇K(q ∧ ¬Kq). Knowledge distributes over conjunction, so we can move the possibility inside: from ◇K(q ∧ ¬Kq) we get ◇Kq and ◇K¬Kq. Now consider the possible world where someone knows that q is not known. Since knowledge is factive, K¬Kq implies ¬Kq, so in that world q is not known. But the first conjunct says there is a possible world where q is known. So q is known in one possible world and not known in another. But it is the same proposition q in both worlds, and the knowability principle was supposed to apply to truths, so this cannot happen: q would have to be both known and not known. Contradiction. So the assumption that there is an unknown truth fails, and the knowability principle entails that every truth is actually known. Since that is absurd, we reject the knowability principle. The assumptions doing the work are (i) the knowability principle, (ii) distribution of knowledge over conjunction, and (iii) the factivity of knowledge.
