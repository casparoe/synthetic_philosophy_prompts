I hold the following view about two-player games: the strategy-stealing argument generalizes, and in any finite, deterministic, perfect-information game with no draws, if having an extra move of your own already on the board can never hurt you, then the first player has a winning strategy. I treat this as one of the few genuinely general results about who wins a game before anyone has analyzed the game itself. I want to know what would count against it, treated as a claim about games rather than as a piece of pure mathematics. Which premises are load-bearing, and what would a counterexample or near-counterexample look like for each — for instance, a game where an extra move can hurt (as in zugzwang positions in chess), a game that permits draws, a game where the first player's initial throwaway move cannot always be made or changes the set of later moves, or a game where the stolen strategy only guarantees not losing rather than winning? Which of these failure modes are live in actual games, and which are merely logically possible? And should I worry that the view, once qualified enough to be true, stops saying anything interesting — that it has been insulated into a tautology? If so, does that matter for a claim of this kind, or is it acceptable for a structural result in game theory?
