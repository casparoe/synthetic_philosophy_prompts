Hey, I'm working on an essay about transcendental arguments and I'd love some comments on the core argument before I write it up properly. Here's the rough idea in note form:

The essay is about what I'm calling the "underdetermination problem" for transcendental arguments. Everyone knows the standard objection — the point, associated with Stroud, that even if we must presuppose some framework to make experience intelligible, that doesn't show the framework is true, only that we can't help believing it. But I think there's a second problem that might actually be worse, and it doesn't get discussed as much.

Here it is: even if we grant that *some* framework or set of categories is necessary for experience to be possible, transcendental arguments rarely if ever uniquely pick out *which* framework. Take Strawson's argument in Individuals — he argues we must conceive the world as containing material objects in a single spatiotemporal framework. But even if you buy that some sort of object-concept is necessary, why this one? Couldn't a process-ontology do the same work? Or take Kant's categories: why exactly twelve, and why these twelve? The derivation from the table of judgments is notoriously shaky, but the deeper point is that the transcendental method seems to give you "some X-type thing is necessary" without telling you which X.

I want to argue this underdetermination problem is distinct from the verificationist gap and can't be solved the same way modest transcendental arguments try to solve the latter. Modest transcendental arguments retreat to showing what we must believe, not what is true. But underdetermination is a problem even for the modest version: if there are multiple incompatible frameworks we could each find indispensible, then the fact that I find framework F indispensible doesn't even establish that I must believe F — only that I do believe it and struggle to imagine otherwise. The necessity claim collapses into a psychological claim about me.

The essay would then consider whether any transcendental argument in the literature actually avoids this. My suspicion is that the ones that come closest (maybe some arguments about the normativity of reason?) do so by building so much into the starting point that the argument becomes question-begging in a different way.

So my questions: Does this argument land? Is the underdetermination problem genuinely distinct from the verificationist gap, or am I just restating the familiar point in different terms? Am I being unfair to any particular transcendental argument that actually handles this? And — this is important to me — please separate what's settled from what's genuinely contested among people who work on this. I don't want to present one side of a live debate as if it's the consensus when it's not.
