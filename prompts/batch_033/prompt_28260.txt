Student Answer:

The discursive dilemma arises when a group tries to aggregate individual judgments on logically connected propositions. The classic example is a three-judge panel deciding a contract dispute. They have to rule on two premises — whether there was a valid offer (P) and whether there was valid acceptance (Q) — and a conclusion (R): the contract is binding, which is true iff P and Q are both true. Suppose the judges vote as follows:

Judge 1: P true, Q false → R false
Judge 2: P false, Q true → R false
Judge 3: P true, Q true → R true

If you take majority vote on each proposition individually, you get P true (2–1), Q true (2–1), but R false (2–1). So the group holds {P, Q, not-R}, which is inconsistent because P ∧ Q entails R. Yet each judge's individual judgments are perfectly consistent. This is the dilemma: proposition-wise majority voting can produce an inconsistent group judgment set from consistent individual ones.

This is closely related to Condorcet's paradox in preference aggregation, and in fact the discursive dilemma can be seen as a special case of the more general Condorcet phenomenon — both show that majority rule fails to preserve a desirable property (transitivity in the one case, logical consistency in the other) when moving from individuals to the group. The underlying mathematical structure is the same.

The dilemma challenges group rationality because if a group holds inconsistent beliefs, it can't be treated as a single rational agent. A rational agent's beliefs must be logically consistent. So if the most natural way of aggregating individual votes — proposition-wise majority — yields inconsistency, then either groups can't be rational agents, or we need a different aggregation method.

The main proposed response is premise-based voting: the group only votes on the premises (P and Q) and then lets the conclusion follow deductively. In the example above, premise-based voting would yield P true, Q true, and therefore R true, which is a consistent set. This solves the inconsistency problem. I find it satisfactory because it preserves logical consistency and still respects majority rule on the underlying factual questions. The only cost is that the group doesn't directly vote on the conclusion, but that seems fine — the conclusion just is whatever the premises entail, so there's no additional fact of the matter to vote on.

A second response is conclusion-based voting, where the group only votes on R and ignores the premises. This also avoids inconsistency but at the cost of ignoring the group's views on the reasons for the conclusion, which seems worse. So premise-based voting is the better solution, and it shows that groups can be rational agents after all — we just have to be careful about which questions we put to a vote.
