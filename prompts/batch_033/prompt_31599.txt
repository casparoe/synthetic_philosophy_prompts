I was mucking about with set theory and seem to have proved something that can't be right, and I can't see which step to blame. Here's the argument, numbered.

(1) For any condition you can state, there is a set containing exactly the things that satisfy it. If you can say 'x is a teacup' or 'x is a prime number', then there is a set of exactly the teacups, exactly the primes.

(2) Consider the condition 'x is a set that is not a member of itself'. Most sets satisfy this: the set of teacups is not itself a teacup, so it isn't a member of itself.

(3) By (1), there is a set R containing exactly the sets that are not members of themselves.

(4) Either R is a member of itself or it is not; there is no third option.

(5) If R is a member of itself, then it meets the condition for being in R, namely not being a member of itself. So if R is in R, then R is not in R.

(6) If R is not a member of itself, then it meets the condition, so it is in R. So if R is not in R, then R is in R.

(7) So R is in R if and only if R is not in R. Contradiction.

The only way out seems to be to reject (1), but that feels like it guts set theory: if I can't collect the things satisfying a condition into a set, how do I ever form a set? Did something subtler go wrong — maybe the condition in (2) is somehow illegitimate, or step (4) is doing more work than it looks? If the fix really is to restrict (1), what is the least destructive restriction, and what do we have to give up in exchange? I'd rather keep as much of (1) as possible.

Please seperate what's settled from what's genuinely contested among people who work on this, and don't present a contested view as the consensus. And could you write the answer in British English?
