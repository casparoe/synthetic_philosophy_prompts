I have spent the past few weeks trying to write a set of classification rules for a system that must label each submitted statement as correct, incorrect, or something else, and I keep meeting the same failure in a new disguise. The trouble begins with a sentence that says of itself that it is false. If the rules label it correct, then what it says is not how things are, so it ought to be labeled incorrect; if the rules label it incorrect, then it has said accurately that it is incorrect, so it ought to be labeled correct. The natural repair is to introduce a third label — call it unresolved — and to place the troublesome sentence there. But the moment that repair is in place, a second sentence appears, one that says of itself that it is not correct. Since the rules have placed it in the third label, it is indeed not correct; yet that is exactly what it says, which seems to make it correct after all. The next repair is to say that a statement may be assessed only from a higher level than the one at which it speaks, so that no statement can pass judgment on itself. At once a third sentence appears, one that says of itself that it is not correct at any level. If it is correct at some level, then what it says is false; if it is not correct at any level, then what it says is accurate, so the rules should mark it correct at some level after all, and the same oscillation returns.

This is not an idle puzzle for me: each repair I make gets defeated within a day, and I need to know whether I am fighting one problem or several. I would like to know whether this recurring pattern has an established name, and, more importantly, how it should be carved up. Is each new sentence simply another instance of the same underlying move, or are they different failures that happen to rhyme? Does the pattern depend on the word correct or true, or does it also arise with notions like provable and definite? How does it differ from the ordinary situation in which a theory meets a counterexample and is revised? I am not looking for a bare label; I want to know what exactly the phenomenon is, what it is not, and where its edges lie. If no established name fits, I would welcome a proposed term with a definition that marks those boundaries.
