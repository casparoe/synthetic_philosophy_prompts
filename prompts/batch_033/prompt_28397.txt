I'm a PhD student in cognitive science working on how people induce relational concepts from a few examples, and I need a diagnostic item for an experiment. I'd like you to construct an original Bongard-style problem: twelve boxes, six on the left and six on the right, each described verbally rather than drawn, where the task is to find the rule that separates the two sides.

The problem should meet these specifications:

- The intended rule is relational: it concerns a relation among the parts within each box (ordering, nesting, alignment, symmetry, relative size, inside/outside, connectedness, and the like), not the mere presence or absence of a single part.
- A similarity-based learner that represents each box as a set of primitive features plus pairwise similarities among them should be able to induce, from the twelve examples alone, a foil rule that also fits all twelve boxes. The foil rule must be a simple, perceptually salient generalization that such a learner would naturally find — not an ad hoc disjunction.
- The intended rule and the foil rule must assign opposite verdicts to at least one designed held-out box, which you should describe.
- A human who sees only the twelve examples should be able to learn the intended rule without outside knowledge; the boxes should be simple enough that this isn't a memory test.
- Don't reuse a published Bongard problem; construct a new one.

After presenting the problem, do the following in the same response. State the intended rule and the foil rule explicitly. For each side, show why all six boxes satisfy both rules. Give the held-out box and the verdict each rule assigns to it. Identify the single design feature that forces the two rules to diverge on the held-out item, and explain what would happen if that feature were removed. Finally, explain how a defender of the similarity-based account would resist the example — for instance, by enriching the feature vocabulary — and whether that defense is ad hoc.

Keep the entire response under 800 words.
