I'm trying to identify whether a particular failure mode in group decision-making has an established name in philosophy or social theory.

The pattern is this: several people each possess the unilateral power to take some action—publish an open letter, launch a project, forward a sensitive message, make a hire. Each is uncertain whether the action is a good idea on balance, but each reasons as follows: "I'm probably being too cautious. If I refrain, perhaps everyone else will refrain as well, and we'll miss the opportunity. Better to act." So each person acts. Because they all act independently, the outcome is far worse than if all had stayed quiet: multiple contradictory letters go out, the project is launched redundantly in incompatible directions, the same hire is made by several people. Each person's individual reasoning was defensible—given their uncertainty about what others would do, acting had higher expected value than not acting. The failure is not in anyone's decision procedure but in the structure that allows unilateral action under shared uncertainty.

I am aware of several nearby concepts, but none seems to capture the precise mechanism. The bystander effect involves diffusion of responsibility producing inaction, not over-action. The tragedy of the commons requires a shared rivalrous resource, not a unilateral action. The volunteer's dilemma concerns one person needing to step forward, not everyone stepping forward when they should not. Is there a term for the configuration I am describing, and how exactly does it differ from those neighbors? If no established term exists, what would you name it and where would you draw its boundaries?
