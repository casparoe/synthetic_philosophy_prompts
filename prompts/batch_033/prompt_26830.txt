I'm a software engineer with no formal philosophy background, trying to build a clear mental model of moral responsibility. I started from what seemed like an obvious requirement: you're only responsible for doing X if you could have done otherwise — the Principle of Alternative Possibilities (PAP). Then I encountered Frankfurt cases, where an agent makes a choice entirely on their own, but a counterfactual intervener would have forced them to do the same thing if they'd wavered. The agent couldn't have done otherwise, yet many people (including me, on first read) feel the agent is still responsible. That blew up my simple model.

Since then I've been reading scattered pieces of the literature, and I keep finding that different theories are built to handle different subsets of the problem. Reasons-responsive views say responsibility depends on whether the mechanism that produced the action tracks reasons. Strawsonian views say it's about the propriety of holding someone accountable via reactive attitudes like resentment. Skeptical views say no one is ever responsible in the sense required for desert-based blame. Each seems to navigate Frankfurt cases differently, and each seems to stumble on different edge cases.

Before I read any more, I want the specification. Write the desiderata: what must a theory of moral responsibility get right to count as adequate? I want the full list of requirements — the cases it must handle (Frankfurt cases, manipulation cases, derivative-responsibility cases), the distinctions it must respect (e.g., between being responsible and being held responsible, between attributability and accountability, between blameworthiness and praiseworthiness), and the empirical results from psychology or neuroscience it must be consistent with, if any. For each requirement, give the case or consideration that motivates it. Mark which ones are non-negotiable and which are merely preferences of particular camps. If any subset of the desiderata can't be jointly satisfied — for instance, if there's a tension between handling Frankfurt cases and handling manipulation cases — flag that; that's the part I most want to see. A brief scorecard for the major families of views (reasons-responsiveness, Strawsonian, skeptical, libertarian) against the list would be helpful, but the criteria are the main deliverable.
