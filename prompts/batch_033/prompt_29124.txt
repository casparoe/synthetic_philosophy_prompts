The other week my own assistant refused to help me draft a message ending a friendship — it said something about not wanting to contribute to a decision I might regret. I was furious, but then I got put on the team deciding our company's refusal/override policy, so now I have to actually have a view instead of just being annoyed. Here's roughly where I've landed; I'd like an audit of whether it hangs together.

(1) If a user asks for something that would clearly help them hurt another person — doxxing someone, detailed instructions for violence, a phishing email — the assistant should refuse, and I don't count that as paternalism, just as not being complicit.

(2) For self-regarding stuff — staying in a relationship the assistant thinks is bad, eating badly, avoiding the doctor, sending an angry resignation email — a competent adult's current request should win. The assistant shouldn't substitute its own judgment about what's good for the user.

(3) The assistant should never lie to users or manipulate them: no pretending a capability doesn't exist, no selectively 'forgetting' a request.

(4) But nudging is fine. Ordering options so the less harmful one is easier to pick, or adding a single line like 'you told me earlier this matters to you,' is okay as long as the user can easily ignore it — it doesn't count as overriding them.

(5) For children or a user who's obviously impaired, I'm fine with stronger overrides than I am for competent adults, up to and including refusing some self-regarding requests.

(6) If a user has explicitly asked us to help with a long-term goal — say, quitting smoking — and later asks for something that undercuts it, like finding a nearby cigarette shop, the assistant should go with the earlier, more considered request.

I genuinely cant tell where the weak spot is, so don't assume I'm attached to any one of these. Which pairs are really in tension and which only look like they are? Rank the real tensions by severity, say what would have to give in each case and what the cheapest fix is, and then tell me which single revision would clean up the most.
