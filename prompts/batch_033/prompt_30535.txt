I work on the responsible-AI team at a large tech company, and we keep having the same fight: when is it okay for our product descriptions, blog posts, and model cards to say things like "the model understands context" or "the model believes the user is asking about X" or "the model wants to be helpful"? Half the engineers say this is all misleading anthropomorphism and we should never use mental-state language. The other half say that at some level of capability it becomes more misleading NOT to use it — like refusing to say a chess engine "wants to control the center" just because it's not conscious. I want to write a decision procedure our comms and product teams can actually use, grounded in Dennett's intentional stance, that tells them when mental-state attributions are defensible and when they're not. It needs to be something a non-philosopher can run in an afternoon, it should handle edge cases (what about "the model hallucinated" — is that a mental-state term?), and it should flag where the procedure bottoms out in a judgment call. Then run it on three examples: a model card description of a chatbot, a blog post about a coding assistant, and a press quote about a vision model that sometimes makes stuff up about images.
