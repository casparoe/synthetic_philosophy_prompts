I've been going round in circles on the Pasadena game and its relatives, and before I read any more proposed fixes I want the specification, not the fix. Quick recap of the two cases I care about, so we're using the same numbers: the Pasadena game pays you (-1)^(n-1) · 2^n / n pounds if the first heads comes on the nth toss, so the expectation written out state-by-state is the alternating harmonic series, which converges to ln 2 in its natural order but can be rearranged to give any value you like (or to diverge) — so the expectation isn't well-defined. The Altadena game is exactly the same but with an extra pound on every payoff, so it dominates Pasadena state-by-state, yet it's expectation is equally undefined.

I want the desiderata: what any adequate theory of how to value gambles like these must deliver. For each requirement, give the case or argument that makes it a requirement, not just a slogan. Which principles are non-negotiable — statewise dominance, invariance under relabelling or reordering the states, agreement with ordinary expected utility for finite gambles, no sure loss from a sequence of individually fair trades? Which are just preferences of particular camps — e.g., must a theory assign a value at all, or is 'undefined, and here's exactly why' an acceptable verdict? Flag any subsets that look jointly unsatisfiable; I've a nagging sense that dominance plus 'adding a sure pound to every payoff should shift the value by exactly a pound' already conflict, but I'd like to see it worked out rather than asserted. Keep any scorecard of actual proposals (truncation, weak expectations, and the like) to a few lines — the criteria are the thing. And tell me which single requirement does the most work in ruling out candidates.
