I'm a software engineer working on a side project — a philosophy blog that doubles as a set of interactive tools. I want to build a "Which theory of material composition do you actually hold?" quiz. The quiz should sort people into one of the standard positions on the special composition question: roughly, when do several things compose a further thing?

I need the quiz to have eight to ten questions. Each question should present a concrete, vivid scenario with two or three answer options phrased in ordinary language. The whole point is to sort people by how they actually judge cases, not by which label they like, so no question should ask anything like "do you think you are a nihilist about composition?" or "is composition unrestricted?" — the diagnostic work must be done entirely by the cases.

The positions I want the quiz to distinguish include at least:

- Mereological nihilism: nothing ever composes anything; there are only simples.
- Mereological universalism: any collection of things whatsoever composes something.
- Organicism: composition occurs only when the parts constitute a life.
- Brutalism: composition happens in some cases and not others, but there is no informative, non-trivial principle that explains why.
- A fastening-based or common-sense view: composition occurs roughly when parts are attached, joined, or otherwise physically connected in ordinary ways.

If there are other important positions I have missed, please include them. If any two positions cannot be separated by the quiz, flag that in the scoring key and explain what the obstacle is.

Some cases you might draw on: the Ship of Theseus, the statue and the lump of clay, whether a cloud is a single object, whether my left hand and the Moon compose something, whether a cat survives its own death, whether a hammer exists when its head and handle are merely placed next to each other on a workbench, or whether a collection of sand grains on a beach composes a further object. Use whichever cases best force the positions apart.

Please provide the full quiz: questions, answer options, and a scoring key that maps answer patterns onto positions. The scoring key should explain which answers point to which position and why — not just a table of tallies but a brief rationale for each mapping.

Also, please note any combinations of answers that are logically possible but not occupied by any defended position, and briefly say whether that is because the combination is incoherent, unattractive, or simply unexplored.

Start the response with the quiz itself — questions, answer options, and scoring key — with no preface, no commentary, and no restating of the brief. Use British English throughout.
