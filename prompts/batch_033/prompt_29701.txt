A grad student in our metaphysics seminar sketched this argument on the board and then ran out of time before saying which line was supposed to be the bad one. I've been turning it over since, and it feels like it proves way too much, but I can't find the exit.

(1) A disposition is just a stable pattern of response to a trigger. Saying this wineglass is fragile is just saying that if it were struck, it would break. That is the simple conditional analysis, and it sounds almost too obvious to deny.

(2) But finks wreck it. Suppose the glass has a guardian demon that would make it unbreakable the instant before it was struck. Then if it were struck it would not break, but the glass is still fragile. So the simple conditional analysis is false.

(3) The natural patch is to build in a ceteris paribus clause: fragile things break when struck in normal conditions, that is, when nothing interferes with the manifestation.

(4) Masks show the patch only works if we can say what counts as interference without already using the disposition itself. A fragile glass packed in foam would not break if struck, and we want to say it is still fragile because the foam interferes with its breaking. But what makes the foam an interferer rather than a feature of the situation showing the glass was never fragile? The only answer seems to be: the foam interferes because the glass is fragile and the foam stops a fragile thing from breaking. That's circular.

(5) The only non-circular escape would be to give a finite list of all the masks and finks. But the list is open-ended: for any list you give, someone can describe a new gizmo that blocks the manifestation in a way that should not count as removing the disposition.

(6) So every disposition ascription rests on an unspellable, open-ended unless-something-interferes clause, and that clause can only be explained by using the very disposition it was meant to define.

(7) Therefore no disposition ascription is ever literally true; at best, saying the glass is fragile is rough pragmatic shorthand. But that's absurd: the sugar in my coffee is soluable, the vase is fragile, the pill is lethal, and these are about as literally true as anything gets.

I'd most like to keep the claim that finks and masks are genuine counterexamples to the simple conditional analysis, and the claim that some disposition ascriptions are literally true. The argument seems to force me to lose one of those. Which step should I reject, and what does rejecting it cost?
