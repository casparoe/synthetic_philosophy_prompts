so we've been doing Hofstadter's Typogenetics in a reading group and I've gotten myself into an argument I cant find the exit from. Quick setup in case you haven't looked at it in a while: strands are strings of letters, a strand can be read as code for an enzyme, and enzymes operate on strands — cutting them, copying them, and so on. The neat trick is that a strand can code for an enzyme that operates on that very strand, so the same string plays two roles at once: inert data, and a program that does things to data. Hofstadter compares this to Gödel's self-referential sentence, and that's the analogy I'd like to keep.

A friend in the group built this out of it:

(1) For a strand to self-replicate, it must contain a complete description of itself.
(2) A complete description of a thing describes every part of the thing.
(3) The strand's sequence is part of the strand — in fact the sequence just is the description.
(4) So the strand's description has to describe itself.
(5) But a description that describes itself has to contain a description of itself, which has to contain a description of itself, and so on — so a self-replicating strand would have to be infinitely long.
(6) But real DNA is a finite molecule and it replicates fine.
(7) So either self-replication is impossible, or the DNA–Gödel isomorphism is bogus.

I don't buy either half of (7), and I can't see where the argument goes wrong, if it does. I'd most like to keep the isomorphism, but I can't figure out what that would force me to give up. Which step do I reject, and what does rejecting it cost? Walk me through the diagnosis in prose, then give me a JSON object with this schema: 'rejected_step' (string), 'flaw_kind' (one of: false_premise, equivocation, invalid_inference), 'why_the_step_looked_true' (string), 'what_self_replication_actually_requires' (string), 'cost_of_the_diagnosis' (string).
