Question: "Explain the measurement problem in quantum mechanics. Then compare how the Copenhagen, Everettian, and de Broglie–Bohm interpretations each handle it, noting the main costs and benefits of each approach."

Student answer:

"The measurement problem arises because the Schrödinger equation describes the evolution of the wave function as a continuous, deterministic superposition, but when we actually measure a quantum system we always get a single definite outcome. So there's a tension between the formalism and our experience.

The Copenhagen interpretation solves this by postulating that measurement causes the wave function to collapse into an eigenstate of the observable being measured. The main cost is that it has to draw a line between the quantum system and the classical measuring apparatus — the 'Heisenberg cut' — and it's never been clear where exactly this line should be drawn. The benefit is that it's simple and doesn't add any extra ontology beyond the wave function and the collapse rule.

The Everettian interpretation takes a different approach: it denies that collapse ever happens. Instead, the wave function just keeps evolving unitarily, and when a measurement occurs, the world splits into multiple branches, one for each possible outcome. The benefit is that it's fully deterministic at the level of the universal wave function and doesn't need a special collapse postulate. The main cost is ontological — you get a vast multiplicity of worlds, which many find extravagant.

De Broglie–Bohm theory adds hidden variables — specifically, particles with definite positions that are guided by the wave function. Because particles always have definite positions, measurements simply reveal those positions, so there's no collapse and no measurement problem. The benefit is that it restores determinism and gives a clear account of measurement. The main cost is nonlocality: the guidance equation involves instantaneous action at a distance, which creates tension with special relativity."
