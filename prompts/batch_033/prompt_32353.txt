For those who haven't seen it: the Pasadena game is this gamble where the expected value is the sum of an alternating harmonic series — it converges conditionally but not absolutely, so depending on how you order the terms, you can get the sum to be any real number, or diverge to ±∞. So the expected value isn't just infinite (like St. Petersburg), it's literally undefined. And there are other games in the neigborhood — the St. Petersburg game itself, the two-envelope problem, the Ross-Littlewood paradox if you think of it in decision-theoretic terms — where something goes wrong with expected value maximization.
