Write the joint statement that an aggregationist about harms and a lexical-priority theorist about harms could both sign after a good-faith adversarial collaboration, using the torture vs. dust specks thought experiment as their shared anchor case.

The aggregationist holds that sufficiently many tiny harms can, in aggregate, outweigh a single terrible harm — that for any amount of torture, there is some number of dust specks in the eye whose aggregate badness exceeds it. The lexical-priority theorist holds that there is a threshold of severity beyond which harms are incomparable with or lexically prior to any number of harms below that threshold — that no amount of dust specks, however vast, can be worse than a single instance of torture.

The deliverable should include:

1. A numbered list of claims both sides can sign. These should cover: what the thought experiment asks and why it matters; which features of the case are stipulated and which are up for dispute; what each side grants about the other's strongest considerations; and any methodological commitments both share (e.g., about the role of intuitive judgments, about what it would mean for one of these views to be "correct," about whether the dispute is normative or descriptive).

2. A disagreements table. Each row should name a specific sub-question on which the two sides part ways. For each row, give the aggregationist's position and the lexical-priority position, both phrased so that a proponent of that view would accept the wording. The table should separate genuine substantive disagreements from points where the two sides might be using terms differently or talking past each other.

3. A list of cruxes — sub-questions such that if one side's answer were shown to be correct, the other side would substantially revise or abandon their view. For each crux, describe a concrete test, argument, or case that both sides agree would bear on resolving it, and record what each side predicts the outcome of that test would be.

4. An assessment of whether any part of the disagreement is verbal rather than substantive. If so, identify exactly which terms or concepts are being used differently, and propose a reformulation that both sides would accept as dissolving the merely verbal portion.

The statement should avoid caricature. It should not simply declare that the disagreement is "deep" or "fundamental" without specifying where it bottoms out. It should also acknowledge points where each side has made concessions or refined their view in light of the other's arguments.
