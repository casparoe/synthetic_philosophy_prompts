I keep noticing a particular epistemic knot in everyday reasoning and I'm hoping someone can tell me whether it has a settled name in the literature, or whether it's been carved up under several labels that I'm conflating.

Here's the pattern. I want to check whether some cognitive instrument — a piece of equipment, a sense modality, a memory system — is working properly. So I devise a test. But the test requires me to use the very instrument I'm testing, and the result is only informative if I already take the instrument to be functioning well enough to administer the test. For instance: I worry my color vision is shifting, so I pull out an Ishihara plate; but I have to use my color vision to read the numerals on the plate. I worry my new digital thermometer is miscalibrated, so I take my temperature with it; but the reading means something only if I assume the thermometer is functioning, which is exactly what I wanted to establish. I worry my memory for recent conversations is slipping, so I try to recall a conversation from this morning to see whether the memory feels vivid; but the act of recall is the very thing under audit. In each case I'm not just using a method whose reliability I haven't independently established — I'm using the very same token capacity whose reliability is in question, and the test seems to presuppose its own conclusion.

This feels related to epistemic circularity, but it's more specific than the general idea that we can't give a non-circular justification for induction or perception. It's also not quite the problem of the criterion — I'm not trying to identify the extension of "knowledge," just trying to run a local reliability check. And it seems distinct from the bootstrapping problem as I understand it, where you use a reliable process many times and then inductively infer that it's reliable; here I'm not aggregating instances, I'm trying to run a single diagnostic. Is there a term for this — the situation where a test for the reliability of a capacity draws its evidential force from the very exercise of that capacity, so that the test cannot in principle move you from agnosticism to trust? If there are multiple terms from different traditions, I'd like to know how they relate. And if no one has named it, I'd be curious what you'd call it and where you'd draw its boundaries against nearby problems like easy knowledge and bootstrapping.
