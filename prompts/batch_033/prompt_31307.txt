Question (from the exam paper):

"Explain the bootstrapping problem as it arises for reliabilist theories of knowledge. How does the problem relate to what's been called the 'easy knowledge' worry, and are they ultimately the same problem? Answer with reference to at least one specific example."

Student answer:

"The bootstrapping problem is a challenge for reliabilism about knowledge. Reliabilism says that a belief counts as knowledge if it's produced by a reliable cognitive process. The bootstrapping problem shows that reliabilism allows a subject to acquire knowledge in a way that seems illegitimate.

Here's the standard example. Suppose I have generally reliable colour vision, but I don't yet know that it's reliable. I look at a red table and form the belief 'the table is red.' According to reliabilism, since my colour vision is in fact reliable, this belief counts as knowledge. I then note that I believed the table was red and it was indeed red, so my colour vision got it right this time. I repeat this process many times — looking at coloured objects, forming beliefs, and noting that I got them right. Eventually I compile a track record and infer: 'my colour vision is reliable.' I now know my colour vision is reliable, but I've only used my colour vision itself to generate all the data. This seems like I've pulled myself up by my own epistemic bootstraps — hence the name.

The easy knowledge problem, introduced by Stewart Cohen, is closely related. The worry is that if we allow basic perceptual knowledge without requiring independent evidence that perception is reliable, then we get knowledge 'on the cheap.' The bootstrapping reasoning is one way this happens: you start with basic perceptual knowledge and then bootstrap your way to knowing that perception is reliable, without ever doing anything to independently check.

I think these are fundamentally the same problem, just described from different angles. The bootstrapping problem is the mechanism by which easy knowledge arises. Cohen's point is that any theory that allows basic knowledge will permit bootstrapping, and bootstrapping seems illegitimate, so we face a dilemma: either deny basic knowledge (leading to scepticism) or accept that bootstrapping is legitimate (which seems wrong). The problem is essentially that reliabilism — and indeed any externalist theory — can't explain why bootstrapping is bad reasoning, because by its own lights the reasoning is perfectly fine: the process is reliable, so the resulting belief counts as knowledge."
