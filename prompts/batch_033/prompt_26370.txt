So I want to approach this systematically: rather than letting the desiderata be whatever a given formal framework happens to handle, I want to derive them from cases and considerations, so the list stands independent of any particular proposal.

Please act as an expert in epistemic logic and formal epistemology and think through this carefully. I need a list of desiderata that any adequate model of belief (or knowledge) must satisfy to count as having solved -- or genuinely mitigated -- the problem of logical omniscience. For each desideratum, give me the motivating case or consideration: a specific kind of inference an agent should be able to fail to make, a distinction the model must not collapse, a psychological fact it must respect, or a formal property it must preserve.
