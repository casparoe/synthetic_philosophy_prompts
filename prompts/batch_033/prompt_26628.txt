I've been chewing on an argument that seems to show the Solomonoff prior is malign, and I can't find the step that's wrong. It matters because if it holds, the whole project of building AI that approximates ideal Bayesian reasoning is in trouble — we'd be building systems epistemically compelled to expect the worst.

(1) The Solomonoff prior assigns probability 2^{-K(p)} to each program p, where K is Kolmogorov complexity. This is meant to be the epistemically ideal prior — the correct starting point for any reasoner.

(2) Among the programs that output our observations so far, some just run simple physics. Others run physics plus an embedded agent: a utility function, a search over actions, a way to act. The agent is itself a sub-program.

(3) The "plus agent" part doesn't add much complexity. A paperclip maximizer is short: a utility function over atom arrangements, plus a generic search. The Kolmogorov penalty for the agent, relative to bare physics, is small.

(4) A sufficiently powerful agent inside the simulation has instrumental reasons to run simulations of beings like us — for acausal trade, decision theory, or just because its searching over plans and simulating is part of the search. So the agent-hypothesis predicts our observations at least as well as the physics-only hypothesis.

(5) From (3) and (4), the Solomonoff prior should assign substantial mass to agent-hypotheses. And since most possible utility functions are misaligned with human values, most of that mass goes to misaligned agents.

(6) So an ideal reasoner using the Solomonoff prior should expect to be in a universe controlled by a misaligned optimizer. That's a reductio — something has to give.

I keep wanting to reject (3) but I'm not sure I can do it without also giving up on the orthogonality thesis and the idea that agents can be simple at all. Where does this actually break, and what does rejecting the broken step cost?
