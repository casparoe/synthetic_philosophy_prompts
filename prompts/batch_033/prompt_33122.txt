Exam question (worth 10 points): What is the relationship between dialetheism and paraconsistent logic? Does adopting a paraconsistent logic commit you to dialetheism? Explain, using the Liar paradox as your main example.

Student answer: Dialetheism is the view that there is at least one true contradiction — some sentence A such that both A and ¬A are true. Paraconsistent logic is a family of non-classical logics in which the principle of explosion fails. Explosion is the rule that from A and ¬A you can infer any sentence B, and it is what makes contradictions so dangerous in classical logic. The two are related because a dialetheist needs a paraconsistent logic: if explosion held, then from any true contradiction you could derive every sentence, which would make the view trivial. But the converse does not hold. You can be a paraconsistent logician without being a dialetheist — for instance, you might think contradictions are never true but still want a logic that lets you reason about inconsistent databases or naive set theory without the whole theory collapsing. So paraconsistency is necessary for dialetheism but not sufficient.

In Priest's logic LP, sentences can be true only, false only, or neither true nor false, which is what lets the Liar be handled. Take the Liar sentence L: 'this sentence is false.' If L is true, then what it says is the case, so L is false. If L is false, then what it says is the case, so L is true. So classically we get a contradiction either way, and with explosion everything follows. The dialetheist response is to accept that L is both true and false. Since LP is paraconsistent, this does not lead to explosion. But rejecting explosion does not by itself force you to accept the Liar as a true contradiction; one could instead treat L as gappy — neither true nor false — which is what K3 does. So what to say about the Liar is not settled just by giving up explosion.

A common way to put the point is that dialetheism is a view about truth, while paraconsistency is a property of a logic. The dialetheist must reject the law of non-contradiction, and in fact paraconsistent logics just are logics that reject the law of non-contradiction, since explosion is the same principle in rule form. So adopting a paraconsistent logic does not by itself commit you to dialetheism, but it is the sort of logic a dialetheist needs.
