Ok so you know Hofstadter's Platonia dilemma right? 20 people get identical letters saying: if exactly one person sends back the enclosed telegram, that person gets a billion dollars. If zero people send, or if more than one send, nobody gets anything. No communication between recipients. Everyone knows everyone else got the same letter, everyone is perfectly rational, and everyone knows everyone else is perfectly rational — and they all know that everyone knows, etc. Hofstadter's superrationality idea is supposed to show that you should send, because if all 20 superrational agents run the same reasoning and land on "send with probability 1/20" or some symmetric mixed strategy, expected value is great.

I want you to argue the opposite: that a superrational agent should definitively not send. The crux of the argument should be about symmetry — if all agents are genuinely symmetric and run identical deterministic reasoning, then they all reach the same conclusion. If that conclusion is "send," everyone sends and it's a disaster. If that conclusion is "don't send," nobody wins but at least nobody's worse off. So "don't send" is the only universalizable choice. Make the argument as tight as you can, and make sure to address the obvious comeback about mixed strategies (e.g., why can't they each just flip a mental coin with odds 1/20?). Also touch on whether the argument changes if the number of players is unknown or if the game is iterated.
