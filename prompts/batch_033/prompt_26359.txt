been rereading GEB and i keep tripping over the same section. hofstadter distinguishes between frame messages, outer messages, and inner messages. the inner message is the semantic content you're trying to convey. the outer message is the physical signal — the sounds, the marks on paper. the frame message is the thing that tells the receiver how to decode the outer message to extract the inner message: it says "this is in english," "this is a sonnet," "the key is C minor," whatever.

so far so good. but then i started poking at the frame message itself and now i can't stop. here's the argument:

(1) for any physical signal to have determinate meaning, it must be interpreted through a frame that specifies how to decode it.

(2) a frame is itself something that carries information — it distinguishes between possible interpretations and picks some out.

(3) so by (1), the frame itself must be interpreted through a further frame, or else its own information is indeterminate.

(4) this generates an infinite regress of frames interpreting frames, and meaning is never grounded.

(5) the only way to stop the regress is for some frame at the bottom to be self-interpreting — to specify its own interpretation without needing an external frame.

(6) but a self-interpreting signal is impossible: to interpret itself, it would need to already have an interpretation to apply, which is circular.

(7) so meaning is impossible.

(8) but hofstadter wrote a book and i understood it, so meaning is not impossible.

(9) therefore one of the premises is false. which one?

hofstadter's own move seems to be that the hardware — the physical brain, the causal structure of the universe — provides the bottom-level frame "for free," without itself needing interpretation. but that just relocates the mystery: how does physics, which isn't about anything, suddenly become about something just because it's organized in a particular causal pattern? you've said "the regress stops at the hardware" but you haven't explained why the hardware doesn't need a frame when everything else does.

i feel like there's an equivocation somewhere around "interpretation" or maybe premise (3) is doing more work than it looks like, but i'm not confident. which premise would you reject and what's the cost of rejecting it? i'm most attached to (1) and (8) and would rather keep those if possible, but i want to know what i'm paying either way.
