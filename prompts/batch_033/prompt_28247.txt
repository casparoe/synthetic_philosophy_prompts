I am a novelist at work on a book about a molecular biologist who, late in her career, begins to suspect that the language of her field has been quietly shaping what she believes about heredity. While researching, I have interviewed a number of geneticists, and I keep noticing a peculiar instability: in one conversation the phrase "the genetic code" is treated as a plain fact, and in the next it is waved off as a loose metaphor. I want to settle, for my own thinking and for the book, whether DNA is a code in anything stronger than a figurative sense.

To that end I have been collecting my gut reactions to a set of cases, and I want to know what principle, if any, captures them. Morse code is clearly a code to me: a conventional table pairs letters with dot–dash sequences, and sender and receiver both command it. Source code compiled to machine code is also a code. A thermometer, by contrast, carries information about the room but does not encode it: it measures. A key that fits a lock is not a code, whatever information it might be said to contain, and a plaster mold that shapes a cast is not a code, though the cast's form depends on it. A written recipe for bread feels like a code only in a thin, hedged way—instructions in a public notation, but not something I would call a code without qualification. The alarm calls of vervet monkeys, which use different calls for leopards, eagles, and snakes, do feel like a code to me, even though I doubt the monkeys could state the mapping. The genetic code itself I find I cannot settle: the pairing of codons with amino acids has a tabular, arbitrary quality, yet the whole process is also just chemistry—the physical fit of transfer RNA, the active sites of enzymes—which makes it feel closer to the lock and key than to Morse.

I would like a principle, or a small set of candidate principles, that sorts these cases the way my gut does, or that tells me cleanly where my gut must be revised. In particular: should the verdict on DNA depend on whether a code requires a sender with intentions, or a conventional rather than purely causal mapping, or a receiver that interprets rather than merely reacts? And what would the principle say about a case I have not yet made up my mind about—the waggle dance of honeybees, in which the angle and duration of the dance correlate with the direction and distance of a food source? I would rather have a precise and defensible account than one that merely ratifies all of my hunches.
