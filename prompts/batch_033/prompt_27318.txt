(1) assume for the sake of argument that every truth is knowable. formally: for any proposition p, if p is true then it's possible that someone knows p.

(2) now consider the proposition "p is true and nobody knows p." call this an unknown truth. surely some propositions of this form are true — like the sand grains thing.

(3) pick one such proposition and call it q. so q says: "q is true and nobody knows q."

(4) by our assumption (1), since q is (by hypothesis) true, it must be knowable. so it's possible that someone knows q.

(5) but what would it mean to know q? it would mean knowing that (q is true and nobody knows q). knowledge distributes over conjunction, so the knower would know that q is true, and would also know that nobody knows q.

(6) knowledge is factive: if you know that nobody knows q, then indeed nobody knows q.

(7) but wait — the knower themselves knows q (from step 5). so someone does know q. so "nobody knows q" is false.

(8) so knowing q would require both knowing that nobody knows q (which implies nobody knows q) and knowing q (which implies someone knows q). that's a contradiction.

(9) so it's impossible to know q. but step (4) said it's possible to know q. contradiction.

(10) the only way out is to deny that q was ever true in the first place. so there are no unknown truths. every truth is known.
