I'm a researcher working on AI alignment, and I keep encountering a design pattern whose philosophical assumptions I want to get clear about. The pattern is the "low-impact" agent. The motivating thought is that we should not have to write down a complete specification of human values in order to build a safe AI; instead, we can build an agent that is rewarded for performing some narrow task and penalized for changing the world in ways that fall outside that task. A concrete version: a household robot is trained to tidy a kitchen. The designers define a set of "baseline" variables — the positions of furniture in other rooms, the temperature of the house, the contents of the refrigerator, the state of the home's network — and estimate what each variable would have been had the robot done nothing. The robot is then penalized whenever the actual value of a baseline variable diverges from that idle counterfactual. The intended result is a robot that is useful but low-impact, without anyone having specified what, in general, counts as a harmful side effect.

I am puzzled about what this design presupposes. It seems to promise a way of avoiding side effects without a full theory of value, but the choices built into it — which variables count as background rather than task, and the use of an idle agent as the baseline — look as if they may already encode substantive value judgments. I would like a reconstruction of the implicit theory of value and side effects that this design is committed to.

Please address these questions:

1. What conception of a "side effect" must the design assume for the penalty to track side effects rather than an arbitrary selection of changes?
2. Does the design strictly presuppose that the world's states can be partitioned into a task component and a background component, or is that partition merely one implementation choice among others? Where exactly does the value theory enter: in the choice of variables, in the baseline, in the penalty, or in the reward?
3. Where is the design philosophically underdetermined — that is, which rival views about value and impact would license the same design, and which views would reject it as incoherent or as smuggling in a full value specification?
4. What would have to change in the design if the designers accepted (a) a fully specified consequentialist value theory, or (b) the view that "side effect" cannot be defined without such a theory?
