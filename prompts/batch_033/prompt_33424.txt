I've ended up convinced of the superrationality answer to the one-shot prisoner's dilemma: roughly, if I know the other player is running the same decision procedure as me on the same information, I should cooperate, because the only consistent assumption is that we output the same move, and both cooperating beats both defecting. I know the textbook line says defecting strictly dominates, but that seems to assume my move and theirs are independent in a way they aren't, given we're literally the same code. I'm a software engineer, so I keep modelling it as: two copies of the same function called with the same arguments; why would they return different values?

What I want is a map of what would count against this. Not just the 'defection dominates' line — I want the cases, arguments and formal results that should actually move me, sorted by how decisive they'd be. In particular: what happens when the symmetry is only approximate (our code isn't literally identical, or one of us has slightly different payoffs or information)? What about more than two players, or asymmetric games, or when theres some chance the other player is just a defector-bot with a bug in its reasoning? And is the view in danger of being unfalsifiable, because whenever it predicts wrong I can say 'well, then you weren't really facing an identical rational copy'? I'd like an honest assessment of how exposed the position is, including which objections a committed superrationalist would themselves concede as counting against it and which they'd dismiss as changing the subject.
