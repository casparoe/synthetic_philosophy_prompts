Exam question:
Explain the disagreement between counterpart theory and transworld identity about the truth-conditions of de re modal claims. Give one consideration commonly offered in favor of each view and one objection commonly raised against each.

Student answer:
Counterpart theory, developed by David Lewis, holds that possible worlds are concrete, spatiotemporally and causally isolated universes, and that no individual exists in more than one world. On this view, the claim that Ada could have been a plumber is true just in case there is some possible world containing a counterpart of Ada who is a plumber. A counterpart is not Ada herself but an individual in another world that resembles Ada closely enough in the relevant respects and is at least as similar to Ada as any other individual in that world. Transworld identity, by contrast, is the view associated with Saul Kripke and Alvin Plantinga, according to which one and the same individual exists in many possible worlds, so the claim that Ada could have been a plumber is true just in case there is a world in which Ada herself is a plumber. Counterpart theory's main advantage is that it avoids having to explain how a single object can bear incompatible properties in different worlds, and it avoids the need for criteria of cross-world identity. Its main liability is the Humphrey objection: on this view, my modal properties are made true by facts about someone else, a mere counterpart, rather than about me. Transworld identity's main advantage is that it keeps modal predication about the very object in question. Its main liability is that it must make sense of how the same individual is picked out across worlds; Kripke addresses this by saying that possible worlds are not distant places we discover but situations we stipulate, so we simply stipulate which individual is under consideration. On counterpart theory, an essential property of an object is one had by every individual in every world that resembles it; thus Ada is essentially human only if every possible world contains a human counterpart of Ada. And because the counterpart relation is fixed entirely by intrinsic similarity, counterpart theory entails that an object's modal properties supervene on its intrinsic properties alone.
