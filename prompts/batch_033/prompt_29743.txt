Here's what the student wrote:

"A rigid designator is an expression that refers to the same object in every possible world. For example, the proper name 'Aristotle' is a rigid designator because it picks out Aristotle in all possible worlds, whereas a definate description like 'the teacher of Alexander the Great' is not rigid, since in some possible world someone else might have taught Alexander.

Kripke argues that when we have an identity statement between two rigid designators, like 'Hesperus is Phosphorus,' if that statement is true in the actual world, then it's true in all possible worlds. This is because both names rigidly designate the same object — the planet Venus — and since identity is a relation that holds necessarily between an object and itself, there's no possible world where Venus is not Venus. So the statement is necessarily true.

But the fact that Hesperus is Phosphorus was an empirical discovery; ancient astronomers didn't know they were the same celestial body. So 'Hesperus is Phosphorus' is a posteriori — we had to go look at the world to find out it's true. This gives us a necessary a posteriori truth: a statement that's true in all possible worlds but can only be known through experience.

The same structure applies to theoretical identifications in science. 'Water is H2O' is necessary a posteriori because 'water' and 'H2O' are both rigid designators — they pick out the same substance in every possible world — and the identity was discovered empirically. Kripke's larger point is that proper names and natural kind terms don't have Fregean senses that determine their reference descriptively; they're rigid because they refer directly to their objects without mediating descriptive content. This is why the traditional philosophical assumption that all necessary truths are a priori and all contingent truths are a posteriori breaks down."
