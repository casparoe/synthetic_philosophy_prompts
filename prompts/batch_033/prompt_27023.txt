I've got an argument that's been bugging me since a seminar on metaontology, and I can't find the exit. It feels like it proves too much, but each step looks fine on its own.

(1) A dispute between two parties is substantive only if they would expect different observations in at least one possible situation. If no possible observation could ever tell them apart, they're just using words differently.

(2) Take the debate over whether there are composite objects, like tables. The side that says tables exist and the side that says there are only particles arranged table-wise agree about every observation: the same particles, the same shape, the same resistance to touch, the same everything.

(3) So the composite-object debate is not substantive.

(4) The same reasoning seems to apply across ontology: numbers, possible worlds, temporal parts, whether time really passes. In each case the parties agree on what would be observed and disagree only over what to call it.

(5) So there are no substantive ontological debates; ontology is a set of verbal disputes.

(6) But premise (1) is itself a philosophical claim. By its own standard, the disagreement between someone who accepts (1) and someone who rejects it — say, someone who thinks a debate can be substantive because one side's theory is more explanatory or more unified even if both fit all observations — is itself a dispute with no observational difference. So by (1) it's verbal too.

(7) So either the conclusion in (5) is itself merely verbal, in which case it gives no real reason to stop doing ontology, or premise (1) is somehow exempt from its own test, which looks ad hoc.

I'd like to keep the idea that a lot of ontology is verbal, but this arguement seems to eat itself. Which step do you reject, and what does rejecting it cost? If I have to give up (1), what weaker criterion of substantiveness would still rule out the table debate without ruling itself out — or is that wishful thinking?
