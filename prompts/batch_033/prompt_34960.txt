So a friend and I just spent an evening going back and forth about that old School of Names line that a white horse is not a horse, and he left me with an argument I can't shake. He reconstructed it like this: (1) The word 'horse' is a name for a certain shape, and the word 'white' is a name for a certain color. (2) A name for a color is not a name for a shape. (3) So 'white horse' names a compound of color and shape, while 'horse' names the shape alone. (4) If two expressions name different things, then the thing one names is not the thing the other names. (5) Therefore a white horse is not a horse.

He had a second route too: if you ask someone for a horse, a black one or a yellow one will do, but if you ask for a white horse, only a white one will do. So the two requests are satisfied by different things, and what a white horse is isn't what a horse is. I kept objecting that this proves way too much: run the same argument on 'red apple' and you get that a red apple is not an apple; run it on 'tall man' and a tall man is not a man. That would make ordinary talk about what things are completely break down. He said that's not a problem for him—maybe ordinary talk is what's broken.

I'm not willing to go that far, but I also dont see which step I'm allowed to reject, since (1) and (2) look fine to me and (4) looks like logic. So: which step do you reject, and what does rejecting it cost? I'd like to hang on to something like (1), since it does seem right that 'horse' has to do with shape, but I don't want to be forced into saying a red apple isn't an apple.
