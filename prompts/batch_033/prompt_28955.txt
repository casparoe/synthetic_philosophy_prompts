I've been working through the MU-puzzle, and a friend has pushed it into an argument I can't seem to find my way out of. The puzzle starts from the string MI and allows four transformations: append a U to any string ending in I; double whatever follows an initial M; replace any three consecutive I's with a single U; and delete any two consecutive U's. The question is whether MU is reachable. It isn't, but what unsettles me is how one knows that: the proof requires stepping outside the system and counting I's modulo 3, noticing that the rules can never make the number of I's divisible by 3 while MU has no I's at all. The system's own rules say nothing about numbers or invariants, so the answer comes from jumping out of the system, and I've been told this is a miniature version of Gödel's theorem.

My friend has now built the following argument. (1) The MU-puzzle shows that some questions posed inside a formal system can be settled only by jumping out of it, using resources the system cannot express. (2) Gödel showed that for any consistent formal system rich enough to encode arithmetic, there is a sentence the system can neither prove nor refute, and we can see the sentence is true by reasoning about the system from outside. (3) Therefore, for any formal system proposed as a model of my own reasoning, I can jump out of it and recognize a truth it cannot prove. (4) So my reasoning cannot be captured by any formal system: no finite set of rules could be me. (5) But nothing in the argument depends on its being me; the same jump is available against any proposed finite model of any reasoning process rich enough to encode arithmetic. So the argument seems to prove too much—it would rule out, in advance, every finitely stateable theory of thought, and would make jumping out of the system an ability no finite system could ever possess, which is beginning to look like an unexplained capacity rather than an argument.

Where does this argument go wrong, if it does? I'd like to keep (1) and (2), since they look like genuine results, and I don't want to accept (5), but I can't tell which of the middle steps to give up or what giving it up would cost. Diagnose the argument: name the step that fails, explain why it looked fine, and say what the standard ways of resisting it have to pay.
