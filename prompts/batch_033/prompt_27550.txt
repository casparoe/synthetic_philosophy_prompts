"The Self-Sampling Assumption says you should reason as if you were randomly selected from the set of all observers who actually exist (within some reference class). The Self-Indication Assumption says you should reason as if you were randomly selected from all possible observers across all possible worlds, but weighted by how many observers each world contains — so worlds with more observers get higher prior probability simply in virtue of having more of them.

The Presumptuous Philosopher is a thought experiment from Bostrom. Suppose we're unsure whether the universe contains roughly 200 billion or 200 trillion observers. A philosopher shows up with a pet theory that, if true, would mean there are 200 trillion observers. The theory has no independent evidence going for it whatsoever. Under SIA, we should substantially increase our credence in the philosopher's theory, because it predicts a thousand times more observers, and SIA says we're more likely to find ourselves in worlds where more observers exist. This seems absurd — the philosopher hasn't done any real work — so the thought experiment is meant as a reductio of SIA. Under SSA, by contrast, the philosopher's claim gets no such boost, since SSA only cares about the actual number of observers, not about how many a theory says there could be. So the Presumptuous Philosopher shows that SIA has an unacceptable consequence and therefore SSA is the more plausible assumption."
