For a handout in an upper-level metaphysics seminar, write a decision tree that takes a reader from their answer about Black's two-sphere world to a named position on the identity of indiscernibles (PII). Build the tree from the logical space of possible answers, not from a list of standard labels: each branch node should be a question or a concrete case that a student can answer without already knowing which position it leads to, and each leaf should be a position located in that space.

Start from the root question: in a world containing nothing but two iron spheres with exactly the same intrinsic qualities, are there two objects or one? The branch nodes must include, in some order, the following fork points, phrased as questions: whether the spatial distance between the spheres counts as a property for the purposes of the principle; whether a relational property such as being some distance from another sphere is qualitative; whether one sphere can be singled out as the left-hand one from a particular vantage point, and whether that fact shows a real difference between the spheres; whether two objects can be distinct even when no property, relational included, distinguishes them, because each has its own bare particular or primitive thisness; and whether the principle is best read as a necessary truth about objects, a contingent truth, or an epistemic principle about what a complete description can express.

Use at least the following cases: the two-sphere world itself; a world containing two qualitatively identical objects in otherwise empty space; and a case in which someone grants that the spheres are two objects but denies that any property, including relational ones, distinguishes them.

The leaves must include, under appropriate names: strong PII restricted to intrinsic qualities; weak PII that admits relational properties; PII restricted to pure or qualitative properties with haecceities doing the individuating work; the view that the two spheres are really one multiply located object or that the description double-counts; and any defensible position that denies the principle outright. Mark each logically possible but unoccupied combination and say briefly whether it is empty because it is incoherent, because it collapses into a named leaf, or because it is merely unexplored. Flag any two leaves the tree cannot separate and state which further question would separate them. Give each leaf a short name and one sentence on its most awkward commitment. Aim for roughly seven or eight leaves, usable in a fifty-minute discussion.
