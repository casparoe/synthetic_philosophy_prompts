I've been trying to get a handle on the unilateralist's curse, not in the abstract but in cases where I actually have a gut reaction. Here are my verdicts, and I want to know what principle, if any, they add up to.

Solo case: I find what looks like a security hole in a widely used encryption library. If I'm right, posting a note today would let people patch before it's exploited; if I'm wrong, I send a lot of people on a wild-goose chase and burn some of my own reputation. I'm about 55% sure I'm right. If I'm the only person in a position to post, I post. Now the 20-person version: twenty equally competent researchers have each looked at the same code independently, each ends up around 55% privately, and any one of them can post the public advisory. I think none of them should post on that private 55%—with twenty people, the chance that at least one of them is confidently wrong feels too high. They should compare notes first. But if the same twenty pool all their evidence and after discussion they're collectively around 55%, I think they should post. So 55% isn't the problem; the problem is twenty private 55%s each being treated as a license to act. If there are only two researchers, I'd prefer they talk, but I wouldn't be upset if one posted on a private 55%. I have no idea where between two and twenty the line is.

Then there's a pair that feels like a different factor. High-stakes accusation: ten people in a town can each publicly name a neighbor as the source of a poisoning, based on their private read of ambiguous evidence, and any one of them can post the accusation. Here I don't think even a lone person should post at 55%; I'd want something more like 95%, because the harm to the neighbor if wrong is huge and hard to undo. But low-stakes reversible case: if the action is posting a draft preprint that can be corrected, I'm fine with thousands of researchers each using a 55% bar, since errors get caught. My working rule is something like: the bar should rise with the number of independent people who could act, fall with how reversible and low-stakes the action is, and fall with how much better placed the actor is than the others. But that's a list of knobs, not a principle.

The case I keep going back and forth on is this: in the 20-person security case, suppose one of the researchers wrote the code and has a private 55% that the bug is real, while the other nineteen are novices. I think she should probably post. But that seems to undercut the idea that more potential actors means a higher bar—if the bar is set by group size, why should one person's expertise lower it? Maybe the real variable is the number of independent actors of comparable competence, but that feels like curve-fitting to save the verdict. Is there a coherent principle that gets all of these, or close? What does it say about a case where the action is irreversible but low-stakes, or high-stakes but easily reversed? And which of my verdicts, if any, should I give up?
