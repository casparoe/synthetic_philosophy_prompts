**Question:**

Explain how supervaluationism addresses the sorites paradox, and discuss whether the phenomenon of higher-order vagueness raises any special difficulty for the supervaluationist approach.

**Student's answer:**

Supervaluationism addresses the sorites paradox by rejecting the law of excluded middle for vague predicates. The central idea is that a vague predicate such as "bald" admits a range of admissible precisifications—different ways of drawing a sharp boundary between the bald and the non-bald, none of which is uniquely correct. A sentence is super-true if it holds on every admissible precisification, super-false if it fails on every admissible precisification, and neither super-true nor super-false if it holds on some precisifications but not others. The inductive premise of the sorites—"for any n, if a man with n hairs is bald, then a man with n+1 hairs is also bald"—comes out super-false, because on each precisification there is some particular n at which the conditional fails (namely the n that marks that precisification's sharp boundary). The argument is therefore unsound. The conclusion that a man with, say, 100,000 hairs is bald is also super-false, which is the intuitively correct result.

Regarding higher-order vagueness: this is the phenomenon that just as there is no sharp boundary between bald and not-bald, there seems to be no sharp boundary between the definitely bald and the borderline cases either. Supervaluationism addresses this by introducing a definiteness operator D. A sentence is definitely true, Dφ, just in case φ is super-true. We can then characterise the borderline cases as those for which neither Dφ nor D¬φ holds. This provides a precise boundary between the definitely bald and the borderline cases, thereby dissolving the problem of higher-order vagueness. The operator D can be iterated to handle further levels should the need arise, but the basic strategy is the same and no special difficulty remains.
