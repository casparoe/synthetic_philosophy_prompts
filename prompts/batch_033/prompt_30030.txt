ok so i've been going back and forth on the godel/lucas/penrose stuff for a while and i think i've finally landed somewhere. i'm supposed to write up my view for a reading group, and before i do i want a consistency check on the whole package. here's where i am:

(a) i'm a computationalist about the mind: whatever the mind is doing when it does math is in principle doable by a turing machine (or by some finite mechanical process; i don't want to get hung up on the exact formalism).

(b) i think lucas and penrose are wrong that godel refutes computationalism. the standard arguments seem to me to conflate the claim that no formal system can prove all arithmetic truths with the claim that no formal system can match us, and that just doesn't follow.

(c) but i do think incompleteness shows something real about the limits of rule-following: any consistant formal system that can do basic arithmetic has a godel sentence it can't prove, and we can see that the sentence is true.

(d) and i think we can do this for any system we're handed, including in principle the system that implements our own mind. we can always step outside a given rule set, see that it's consistent, and see that its godel sentence is true.

(e) i don't think this stepping outside requires anything non-mechanical. a machine can be built to take a description of a system and output its godel sentence, and it can prove that if the system is consistent then the sentence is true. so diagonalizing out of a system is itself just more computation.

(f) so i think a turing machine can in principle match human mathematical insight: for any mathematical truth we can recognize, some suitable machine can be built to recognize it too.
