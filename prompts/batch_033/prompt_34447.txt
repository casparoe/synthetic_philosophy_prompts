So I've been going down a rabbit hole about weird probability puzzles lately, and I stumbled on this thing called the Pasadena game. The way it works is: you flip a fair coin until it comes up heads. If the first heads is on flip 1 you win $2, if its on flip 2 you lose $2, if its on flip 3 you win $8/3, if its on flip 4 you lose $4, and in general if the first heads is on flip n you win 2^n/n dollars when n is odd and lose 2^n/n dollars when n is even. Every possible payout is a finite amount of money and the rules are totally clear, but the expected value turns out to be this weird conditionally convergent series: if you add the terms in the obvious order you get something like 69 cents, but the positive terms by themselves add up to infinity and the negative terms by themselves add up to negative infinity, so you can reorder the sum to get basically any number you want, or no number at all. So the game doesn't seem to have a definite expected value.

Me and a couple friends got into an argument about whether this is just a math curiosity or whether it actually says something about how we should think about decisions. One friend said it's irrelevant because no real casino offers a game where the payoffs grow without bound like that. But I've got a feeling there's a bigger lesson in there about expected value reasoning itself — we use the idea of picking whichever option has the highest expected value as a default for all kinds of stuff, from buying insurance to changing jobs to taking weird bets, and this game seems to show that the whole idea of an expected value can quietly fall apart underneath you.
