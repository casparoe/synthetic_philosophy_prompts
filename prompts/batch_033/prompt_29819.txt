Ok here's an argument I got into with a friend and I can't find the exit. It seems to show expected value reasoning forces you to be a fanatic about astronomically unlikely payoffs, which can't be right, but each premise looks fine on its own.

(1) Rational choice is just maximizing expected value: for each action, multiply the value of each possible outcome by its probability and pick the action with the highest total.
(2) Value is unbounded: for any outcome, however good, there's a possible outcome that's vastly better — not just twice as good, but 10^100 times as good (post-scarcity civilizations, simulated utopias, whatever).
(3) You should never assign probability exactly zero to a coherently described possible outcome. So for any of these wild huge-payoff scenarios, there's some tiny positive probability, if you take the right action, that it comes about.
(4) Now take a mundane action, like going to work. Its expected value is some finite number. By (2) and (3), there's another action — say, spending the day typing a particular string of digits into a terminal on the off chance it's a backdoor to a benevolent superintelligence — whose payoff, if it works, is so large that it's tiny probability times that payoff swamps the expected value of going to work.
(5) So expected value reasoning says you should skip work and type the digits.
(6) That's insane. A theory of choice that makes you skip ordinary life for a 1-in-10^100 shot can't be right.
(7) So one of (1)-(3) must be false.

My friend says the culprit is (2): bound the utility function, cap it somewhere, and the fanaticism disappears. But that seems to have its own problems — it implies there's a point where making things better for everyone changes the number not at all, and the cap looks arbitrary. I'd rather keep (1) than (2), honestly, but I can't tell if that's wishful thinking. Which step do you reject, and what does rejecting it actually cost? If there's a fourth exit I'm not seeing, I want to know where exactly it opens up.
