I've been running a philosophy of biology reading group, and last week we spent two hours going in circles about whether DNA is "really" a code. The frustrating thing was that nobody disagreed about the molecular biology — transcription, translation, codons, all of that was fine — but people clearly meant different things by the word "code," so the argument never went anywhere. I'd like to untangle this before next week.

Could you rank the following interpretations of the claim "DNA is a code" from most defensible to least defensible as a literal description of what's going on, rather than as a loose metaphor? Give a sentence or two for each explaining its place in the ranking.

(a) The combinatorial-code reading: there is a systematic, partly arbitrary mapping between nucleotide triplets and amino acids, including start and stop signals.
(b) The semantic-information reading: a gene is about, or for, a phenotype in something like the way a sentence is about a state of affairs.
(c) The interpreter reading: DNA is a code because the cell actively decodes it, with the transcription and translation machinery playing the role of the interpreter.
(d) The Shannon reading: DNA counts as a code because the base sequence reduces uncertainty about which protein gets made.
(e) The blueprint/program reading: the genome literally contains a plan or program for building the organism.

Then, in a final sentance, say which of these is usually doing the real work when a geneticist says a mutation "changes the instructions" for a protein, and whether you think that's a problem.
