I've been chewing on program equilibrium for a reading group and I think I've talked myself into a corner. The argument below seems airtight step by step, but it's conclusion can't be right — or if it is right, a lot of what I learned in game theory is just an artifact of a modeling choice, which feels like too much.

(1) In a one-shot Prisoner's Dilemma where players can only choose actions, defection strictly dominates cooperation, so rational players defect and mutual cooperation is not an equilibrium.

(2) Now change the setup: players choose programs rather than actions. Each program takes the other player's source code as input and outputs an action, and once chosen the program is binding.

(3) Let P be the program: "if the other player's program is exactly P, cooperate; otherwise defect." If both players submit P, each sees that the other is running P, so both cooperate and each gets the mutual-cooperation payoff.

(4) If one player unilaterally submits some other program Q, then P defects, since Q is not P. The switcher therefore gets at most the mutual-defection payoff, which is worse than mutual cooperation. So no unilateral deviation is profitable, and (P, P) is a Nash equilibrium.

(5) So once programs are allowed, mutual cooperation in a one-shot PD is an equilibrium, even though cooperation is a strictly dominated action in the original action-only game.

(6) And the construction generalizes. Take any two-player game with a Nash equilibrium N, and any pair of actions O that both players prefer to N. Each player can submit a program that plays their part of O if the other submits the matching program, and plays their part of N otherwise. By the same argument, O is an equilibrium of the program game.

(7) So in any one-shot game, any outcome that is better for everyone than some Nash equilibrium can be turned into an equilibrium just by writing the right conditional code. That would mean commitment, repetition, reputation, and enforcement are all unnecessary, and the difference between a one-shot dilemma and a game with binding contracts is just a choice about what counts as a strategy.

I'd really like to keep (3) and (4) — they just look like the definition of a Nash equilibrium applied to programs. But then I seem stuck with (7). Where does this go wrong? If the argument is valid, which premise should I give up, and what do I lose by giving it up?
