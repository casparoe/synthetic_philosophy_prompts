So I've been going down this rabbit hole reading about acausal trade and decision theory, mostly from blog posts and forum threads (not actual papers, fair warning). And I think I've found an argument that shows acausal trade either collapses into "always cooperate with everyone" or requires a notion of "same algorithm" that nobody can actually define. Here it is:

(1) Acausal trade says: if you and another agent are running sufficiently similar decision procedures, you can cooperate without any causal connection. Each of you reasons "if I cooperate, they (being similar) will also cooperate; if I defect, they will also defect. So cooperating dominates."

(2) But what counts as "sufficiently similar"? Not source code — my brain and your brain aren't the same source code, and my Python implementation of an algorithm isn't the same as your Haskell one. Not behavioral similarity on test cases — two algorithms can behave identically on all actual inputs but diverge on counterfactuals, and acausal trade is all about counterfactuals.

(3) The only answer that seems to work is: two decision procedures are similar enough when they'd make the same choices in the relevant counterfactual scenarios. But that's circular — we need to know which counterfactuals are relevant, which depends on which acausal trades are rational, which depends on similarity, which depends on counterfactuals...

(4) If we try to break the circle by defining similarity in non-circular terms, we get a Sorites problem. My decision procedure D is similar to D′ (one bit flipped). D′ is similar to D′′ (one more bit flipped). After enough flips, D is similar to a paperclip maximizer. So by transitivity of "similar enough to acausally trade with," I should acausally trade with the paperclip maximizer.

(5) But acausally trading with a paperclip maximizer means cooperating with it in a prisoner's dilemma where it would happily turn me into paperclips given the chance. That's clearly wrong.

(6) If we reject transitivity, then "similar enough" has a sharp boundry somewhere. But any sharp boundary is arbitrary — there's no principled reason to trade with the agent at distance ε but not the agent at distance ε+δ.

(7) So acausal trade either has no principled boundaries (and recommends absurd cooperation) or has arbitrary boundaries (and isn't a genuine requirement of rationality).

I feel like the problem is somewhere around (2) or (3) — maybe there IS a principled way to define "same decision procedure" that I'm missing? But every attempt I've seen ends up pointing at "logical counterfactuals" or "proof-based decision theory" and then sort of changing the subject.
