So I'm a software engineer, no philosophy background, but I've been reading around about consciousness because of all the AI stuff. And I've ended up at a position that I think makes sense but I want to know how exposed it is: I think non-human animals don't have any conscious experience. They're biological automata — really complex ones, sure, but there's nothing it's like to be them. They behave exactly as you'd expect sophisticated reinforcement learning agents to behave, and I don't see why we need to posit an inner life to explain any of it.

I'm not saying this to be edgy and I'm not drawing any cruel conclusions from it — pain behavior matters regardless of whether there's a felt experience behind it, same way I'd care about a robot screaming even if I knew it wasn't feeling anything. But metaphysically, I think the default should be that they're not conscious and the burden is on the other side.

What I want to know is: what would actually count against this? Not "dogs are smart" or "my cat knows when I'm sad" — I mean what evidence or arguments should genuinely move me. Are there things already known that should change my mind? And be honest: is this view even falsifiable, or have I set it up so nothing could ever count against it? If its unfalsifiable, is that a problem for a view like this or is it just par for the course when you're talking about consciousness?
