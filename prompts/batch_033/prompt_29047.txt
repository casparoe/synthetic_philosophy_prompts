Write an essay on whether the Pasadena paradox shows that expected value theory is in genuine trouble. Set the game up briefly: a fair coin is flipped until it lands heads, and where n is the number of flips taken, you win 2^n/n if n is odd and lose 2^n/n if n is even. The expected payoff is then the conditionally convergent series 1 - 1/2 + 1/3 - 1/4 + ... , whose terms can be rearranged to sum to any value, so the game has no well-defined expectation in the usual sense. Weigh the main lines of response: that decision theory only ever applied to gambles with well-defined expectations, that we can still rank the game via dominance or some regularised sum, and that the case shows expected value theory needs a deeper fix. Dont just survey these; defend a verdict about what the paradox actually shows. Please write in British English.
