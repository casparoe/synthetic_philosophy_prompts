A friend recently summarized Fitch's paradox of knowability for me as follows:

"Fitch proved that if every truth is knowable, then every truth is actually known. He reasons like this: suppose some proposition p is true but never known. Then the conjunction 'p and nobody ever knows that p' is true, so by the knowability principle it is knowable. But knowing that conjunction requires knowing each conjunct; and if you knew the second conjunct — that nobody ever knows that p — then by factivity nobody knows that p, while if you knew the first conjunct, somebody would know that p. Contradiction. So the conjunction is unknowable, and since the knowability principle says it would be knowable if true, it cannot be true. Therefore no true proposition is ever unknown. The argument uses only two substantive assumptions: that knowledge distributes over conjunction and that knowledge implies truth. Both are beyond dispute, so the anti-realist's only way out is to restrict the knowability principle to atomic truths, which critics regard as ad hoc. The paradox is therefore a decisive refutation of any view that ties truth to what can be known."

I'm inclined to think the anti-realist has some way out, but I can't locate the error. Go through this paragraph sentence by sentence and tell me: which parts are accurate, which are subtly wrong or overstated, what a defender of the knowability principle would say about each step, and whether the final "decisive refutation" follows from the accurate parts.
