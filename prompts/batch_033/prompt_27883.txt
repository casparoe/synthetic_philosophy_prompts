I recently started working alongside machine learning researchers, and the question of whether there is a principled limit on what artificial systems can do has stopped being abstract for me. One colleague keeps appealing to Gödel's incompleteness theorems to close the debate: any AI, he says, must operate within some formal system, and Gödel showed that for any consistent formal system there are true statements it cannot prove; human mathematicians, by contrast, can see that those very statements are true. This argument has been gnawing at me because I cannot find the flaw in it. If Gödel really showed that every formal system misses truths that we can recognize, wouldn't it follow that no machine could ever match human reasoning? Why isn't this considered a decisive refutation of the possibility of human-level AI?
