my argument in a nutshell: the classic setup says you open envelope A and see $X, then reason that envelope B has either $X/2 or $2X with equal probability, so the expected value of switching is positive, and since this reasoning works for any X, you should always switch, which is absurd. my take is that "with equal probability" is doing hidden work — to assign equal probability to the two cases for every possible X, you'd need a uniform prior over all positive dollar amounts, which isnt a proper probability distribution. so the expected value calculation isnt licensed, and theres no paradox, just a mistake about when expected value reasoning applies.
