The leveling-down objection is widely taken to refute egalitarianism while leaving prioritarianism untouched. Please explain why prioritarianism avoids the objection. Your answer should do three things:

1. State the leveling-down objection clearly. Identify exactly which feature of egalitarianism it targets — that is, what must a view value for the objection to get traction?

2. Show how the prioritarian value function blocks the objection. Be precise: the standard prioritarian function is strictly increasing and strictly concave. Explain which of these two properties does the work, and why.

3. Now consider a modified view: same as prioritarianism except that the transformation function is not strictly increasing — it has a threshold above which additional welfare contributes zero marginal value. Would this modified view be vulnerable to a leveling-down objection? If so, what does this tell us about what really shields prioritarianism from the objection?
