Write a decision tree that classifies positions on how to reason when evaluating hypotheses that differ in how many observers they say exist. The intended user is a reading group on anthropic reasoning whose members already know the doomsday argument but keep conflating the inferential rule with its conclusions; the tree should sort them by what they actually accept about self-locating evidence, not by which label they prefer.

Build the tree from the logical space of answers rather than from a list of named positions. Each branch node should be a question about a concrete case or a claim on which the positions genuinely come apart, phrased so that a reader can answer it without already knowing the names of any positions. Use at least these cases in the branch questions: the presumptuous philosopher (a philosopher defends a theory that is empirically indistinguishable from a rival except that it predicts vastly more observers, and takes the mere fact that you exist as strong evidence for the theory with more observers), the doomsday argument, and a coin flip that creates either one copy or two copies of you.

The leaves must include at least the following positions, characterized by their inferential commitments rather than by slogans: (i) your existence is itself evidence favoring hypotheses on which more observers exist; (ii) you should reason as if your birth rank is random among all observers in a chosen reference class, and your existence as such does not separately favor hypotheses with more observers; (iii) self-locating information, including your own existence and birth rank, should not move your credence in non-indexical hypotheses; (iv) the choice of reference class cannot be fixed in a principled way, so any rule that depends on one is underdetermined and different admissible choices reverse the conclusions.

Use at least these branch labels, unless you can justify replacing one with a sharper split: whether existence itself is evidence; whether self-locating reasoning requires a reference class; whether the reference class is uniquely determined. Aim for six to nine leaves; the four above are mandatory, and you may add adjacent positions only if the branch questions force them. For each leaf, give a short established name if there is one or mark it unnamed, and add one sentence on the position's most awkward commitment. Note any unoccupied combinations of the branch answers and say briefly whether each is empty because the view is incoherent, unattractive, or merely unexplored. Flag any pair of leaves the tree cannot separate as posed, and identify which leaf or leaves license the presumptuous philosopher's conclusion.
