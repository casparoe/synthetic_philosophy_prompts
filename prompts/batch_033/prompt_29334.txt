**Question.** Compare the Nash and Kalai–Smorodinsky solutions to the two-person bargaining problem. Explain the normative tension between Nash's independence of irrelevant alternatives and Kalai–Smorodinsky's monotonicity axiom. Define both solution concepts and their characterizing axioms, and discuss which of the two you find more compelling as a principle of fair division.

**Student's answer.**

A two-person bargaining problem is a pair (S, d) where S ⊂ ℝ² is a compact, convex set of feasible utility pairs and d ∈ S is the disagreement point, with the requirement that some x ∈ S satisfies x > d (both players can strictly gain from agreement).

The Nash bargaining solution selects the unique point in S that maximizes the Nash product (x₁ − d₁)(x₂ − d₂). Nash showed that this is the only solution satisfying four axioms: (i) Pareto optimality — no feasible point gives both players at least as much and one strictly more; (ii) Symmetry — if the problem is symmetric, the solution awards equal payoffs; (iii) Affine invariance — applying independent positive affine transformations to each player's utility yields a correspondingly transformed solution; (iv) Independence of irrelevant alternatives (IIA) — if T ⊇ S and the solution of T lies in S, then the solution of S equals the solution of T.

The Kalai–Smorodinsky (KS) solution first computes the ideal point a(S, d) = (a₁, a₂), where aᵢ = max{xᵢ : x ∈ S, x ≥ d}. The KS solution is the maximal point in S lying on the straight-line segment from d to a — geometrically, where the ray from the disagreement point through the ideal point meets the Pareto frontier. KS retains Pareto optimality, symmetry, and affine invariance, but replaces IIA with a monotonicity axiom: if the feasible set expands in a way that leaves a player's own best possible outcome unchanged, then that player's payoff under the solution should not decrease. Formally, if T ⊇ S and aᵢ(T, d) = aᵢ(S, d), then fᵢ(T, d) ≥ fᵢ(S, d).

The normative tension is this. Nash's IIA expresses a consistency requirement: the choice from a larger set should remain the choice from any subset that contains it. This is elegant but arguably blinds the solution to morally relevant features of the choice situation — namely, what alternatives were available. KS's monotonicity axiom captures a different intuition: if new options become available that improve your best-case scenario, you should not end up worse off. Kalai and Smorodinsky's monotonicity axiom therefore guarantees a strong monotonicity property: whenever the feasible set expands (with the disagreement point fixed), neither player's payoff decreases. This makes KS especially attractive in distributive contexts where we want to ensure that growth never harms any participant.

By contrast, the Nash solution satisfies neither form of monotonicity. In fact, expanding the feasible set can cause the Nash solution to shift in a way that reduces both players' payoffs simultaneously, since the Nash product maximizer is sensitive to the shape of the entire frontier. Moreover, it is sometimes claimed that Nash's IIA can be derived from the monotonicity axiom — that any solution satisfying monotonicity must also satisfy IIA — but this is mistaken, and the KS solution itself is a counterexample.

In my view, the KS solution is more compelling. The strong monotonicity property aligns with basic fairness intuitions about sharing the benefits of growth, whereas IIA, while logically tidy, rules out legitimate considerations about what could have been achieved.
