I've been trying to get a handle on the logical omniscience problem, and every proposed fix I read seems to buy one thing by quietly selling off another — impossible worlds make the semantics so permissive that validity stops doing any work, awareness structures just relabel closure as "implicit belief", resource bounds turn a logic problem into a cognitive-science problem without saying which inferences the idealization is even supposed to preserve. Before I look at any more formal models, I want the actual spec. Write the desiderata for a theory of belief (or a semantics for belief ascriptions) that counts as genuinely solving, or at least respectably dissolving, logical omniscience rather than just changing the subject. For each requirement, give me the case or argument that forces it: which closure properties have to fail and which should survive, where logical equivalents have to come apart, how a logically competent agent can still fail to draw a consequence, how the theory should treat the norm that you ought to believe what follows from what you believe, and so on. Then tell me which of these are negotiable idealizations and which are load-bearing, flag any subsets you suspect are jointly unsatisfiable, and say which single requirement does the most work in ruling out the standard approaches. Don't spend long on scorecards for particular proposals; I care about the criteria more then the contenders.
