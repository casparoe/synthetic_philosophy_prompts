I've been working through Skolem's paradox and I can't shake the sense that it's more damaging than most philosophers of mathematics let on. The Löwenheim-Skolem theorem tells us that if first-order ZFC has any model, it has a countable model — one whose domain is the size of the natural numbers. But ZFC proves Cantor's theorem, so it proves the sentence "there exists an uncountable set." Inside that countable model, there is some set that the model "thinks" is uncountable. But we, standing outside the model, can see that the entire domain is countable, so every set in it — including the allegedly uncountable one — is at most countable. So ZFC proves the existence of an uncountable set, and yet in every countable model of ZFC, no set is actually uncountable. That sure looks like the theory is false in those models. Why isn't this considered a straightforward refutation of first-order set theory? Please answer in no more than 400 words.
