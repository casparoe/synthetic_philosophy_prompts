I'm taking a graduate seminar on anthropic reasoning and global catastrophic risk, and we've been asked to write up our current philosophical commitments on the doomsday argument and related topics for a "consistency audit" session. The idea is that we each present our position set and the class picks it apart for hidden tensions. I'd like to get a head start on that before I present.

Here's where I've landed after the first half of the semester:

(1) The doomsday argument is probabilistically sound. The fact that my birth rank is roughly 100 billion gives me reason to think that the total number of humans who will ever live is unlikely to be, say, in the trillions. It is genuine evidence against a long future for humanity, even if not decisive.

(2) The correct principle underlying anthropic reasoning is the Self-Sampling Assumption (SSA): I should reason as if I am randomly selected from the set of all observers in my reference class.

(3) The reference class problem is serious but solvable. The correct reference class for the doomsday argument is the set of all observers who share my evidence — that is, observers whose total evidence is relevantly like mine. This is not question-begging because the evidence can be specified without knowing one's birth rank.

(4) In the Sleeping Beauty problem, Beauty should assign credence 1/3 to Heads upon being awakened. The thirder position is correct.

(5) The Presumptuous Philosopher thought experiment does not give us reason to favor the theory that postulates vastly more observers. The number of observers in a theory is irrelevant to its credence when the theories make identical empirical predictions.

(6) The doomsday argument and the simulation argument are importantly different in structure. Accepting the doomsday argument does not commit one to accepting the simulation argument, or vice versa.

I'd like you to go through these and tell me which commitments are in tension with which others. Specifically, I want:

- Which pairs are in genuine tension, ordered by severity (which tension is the hardest to resolve?).
- Which pairs only look like they're in tension but dissolve on closer inspection.
- For each genuine tension, what the cheapest revision would be — which commitment would have to go, and what you'd lose by giving it up.
- Whether there is a single revision that would clean up more than one problem at once.

I'm not sure which of these I'd be willing to give up, so please don't assume I'm more attached to one than another. I want the audit to be as neutral as possible about which way I should resolve the tensions.
