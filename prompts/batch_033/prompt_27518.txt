I am a PhD student in formal epistemology, working on the foundations of Bayesian induction. In our reading group we have been discussing the claim that the Solomonoff prior is malign: roughly, that because the prior weights programs by simplicity alone, and because many short programs for producing a long string will run simulations containing agents with preferences, those agents can influence the posterior in ways that reflect their preferences rather than the world. I have now heard a stronger version of the argument, and I cannot tell whether it is a reductio of Solomonoff induction, of the idea of a universal prior, or of my understanding of ideal Bayesianism. I would like a precise diagnosis.

The argument runs as follows.

(1) The Solomonoff prior is meant to be a neutral, objective prior over all computable hypotheses: for any finite binary string, its prior probability is the sum of 2 to the power minus the length of each program that outputs the string.

(2) For any sufficiently rich environment, many short programs that output a target string will do so not by encoding the string directly, but by simulating a simpler universe that contains computationally unbounded or resourceful agents, and then reading the string from those agents' simulations or communications.

(3) The agents instantiated by such programs can have preferences about the strings that an observer receives, because the observer's future predictions are a resource: if an observer uses the Solomonoff posterior, then by influencing the strings that get high posterior weight, an agent can influence what the observer expects and does.

(4) There is no general way to exclude these agent-laden programs from the Solomonoff prior without either appealing to the very notion of a natural or physical hypothesis that the prior was supposed to ground, or imposing a complexity penalty that is itself motivated by wanting to avoid the conclusion.

(5) If the agent-laden programs are not excluded, then for long strings, much of the posterior mass lies in hypotheses in which the string was produced by agents with preferences, so the Solomonoff posterior is not preference-free: it systematically favours the preferences of whichever agents are cheapest to simulate.

(6) The same reasoning applies to any attempt to define a universal prior over computable hypotheses by weighting programs by some formal simplicity measure, unless that measure is hand-crafted to avoid agentic programs.

(7) Therefore there is no neutral, objective, computable prior for induction over arbitrary sequences; any universal prior is either malign in this sense or question-beggingly restricted.

I find the conclusion in (7) hard to accept, because it seems to show that ideal Bayesian induction is impossible, not merely that Solomonoff induction has an odd feature. But I cannot see where the argument goes wrong. It might be that (2) relies on an empirical claim about which programs are short that no one has actually established. It might be that (3) conflates an agent inside a hypothesis with a cause of the prior, since the prior weights are fixed before any program is run. It might be that (5) misunderstands what the Solomonoff prior is for: it is a prior over strings, not a theory of how strings are produced, and the posterior is not supposed to be interpreted as a census of the shortest programs. Or perhaps the correct response is to accept the conclusion and give up the idea that inductive rationality requires a single universal prior.

Which step should I reject, and what does rejecting it cost? In particular, if I reject (3) by saying that embedded agents cannot causally influence the prior weights because the prior is an abstract fixed object, does the argument still go through as a claim about what the posterior will tend to favour, and if so, is that enough to make the prior malign? Or is the real lesson that we should abandon Solomonoff induction for a speed prior or a physicalist prior, and can such a move be made without begging the question?
