ok so i'm running a discussion group that's mostly rationalist-adjacent people — they've read the sequences, some of eliezer's quantum mechanics posts, maybe a bit of robin hanson on many-worlds, but they're not academic philosophers of physics. we're doing a session on the born rule problem in many-worlds, and i want to kick it off with a decision tree that people can work through before the discussion to figure out which position they're actually closest to.

the tree assumes someone already buys the basic many-worlds picture: unitary evolution only, no collapse, branches decohere. the question is: given that, what do you think is going on with probability?

i want the tree built from the logical space, not from a list of named positions. so: first figure out what the key branching questions are, then locate the actual defended positions in the resulting space. if there are logically possible combinations nobody defends, flag them and say briefly why (incoherent? unexplored? combinatorially possible but nobody wants to bite that bullet?). also flag any pairs of positions the tree genuinely can't separate.

the positions that should definitely show up as leaves: the decision-theoretic derivation (deutsch/wallace — rational agents in the multiverse should bet as if born rule probabilities are real), the self-locating uncertainty approach (sebens/carroll — you should be uncertain about which branch you're in, and the born rule drops out of that), the view that branch weights are just primitive objective chances and we should stop trying to derive them, the view that probability talk is straight-up meaningless in a deterministic multiverse and we should give it up, and the view that it's an unsolved problem but mwi isn't worse off than collapse theories which have thier own unresolved measurement problem.

phrasing is the hard part: every question should be answerable by someone who hasn't read the academic literature. don't ask "do you endorse the decision-theoretic link between rational action and branch weights" — instead ask something like "if you knew you were going to be split into two copies tomorrow, one of whom gets a million dollars and the other nothing, would you pay for a ticket to that lottery, and if so how much?" the tree should sort people by what they actually think about cases, not by which philosopher they've heard of.

also, i want the tree to grapple with the prior question of whether the born rule problem is even a genuine problem or whether it's a pseudo-problem that arises from importing classical probability intuitions into a framework where they don't apply. there should be a branch early on that captures this.

format: give me the tree as a numbered decision flowchart, with each node a question and each edge an answer, and then a separate section that explains each leaf position in a paragraph or so. flag dead-end branches. keep the whole thing under 800 words — it's meant to be something people can read in ten minutes before the discussion starts.
