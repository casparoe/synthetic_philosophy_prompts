A friend and I recently spent an entire evening arguing about a forced-choice case that I have not been able to stop turning over: you can either save one stranger or save five strangers; all six are equally in need of being saved, none is related to you, you cannot save both groups, and there is no partial rescue. My friend kept insisting that the five simply outweigh the one and that anyone who hesitates is confused. I found myself defending something like the Taurek coin-flip thought: that the five do not, in the relevant sense, outvote the one, that each person's claim to be saved is no stronger than anyone else's, and that the only fair procedure might be to give each side an equal chance. By the end we had accumulated a tangle of half-distinguished positions: that numbers count as reasons, that numbers count only as tie-breakers among equal individual claims, that numbers should affect only the odds of a lottery, that saving the five is permitted but not required, and several more. I want something that would have kept us honest about which of these we actually held.

I would like you to write a decision tree — or a tree-shaped taxonomy, if you think the space is better represented that way — that sorts a person into one of the main positions in the debate over whether the numbers count in forced-choice rescue cases. Please build the tree from the logical space of answers rather than from a list of names: first articulate the branch questions, each phrased as a concrete case or a claim that someone could assess without already knowing the labels; then locate the actual positions as leaves; and note any combinations of answers that no one seems to occupy, with a one-sentence diagnosis of whether each empty combination is incoherent, merely unattractive, or simply underexplored. The leaves I would especially like included are: strict aggregationism, on which you are required to save the five because five deaths is worse than one; an equal-chances view on which giving each side a 50% chance is required by fairness, not merely permitted; a weighted-lottery view on which numbers enter only by proportioning the chances; a justifiability-based view on which you must save the five but not because the harms are aggregated; and a permissive moderate view on which both saving the five and flipping the coin are acceptable. Please also flag any leaves the tree cannot genuinely separate — for example, if two positions agree on every case and differ only in their underlying rationale, say so and explain what further diagnostic question would be needed.

Because this is for a graduate seminar handout rather than an encyclopedia entry, the work should go into the diagnostic questions rather than into surveying the literature. Please use at least these cases, in whatever order makes the tree cleanest: the basic one-versus-five rescue; a version in which heading toward the five gives only a 60% chance of saving all five while heading toward the one saves the one with certainty; a version in which the one faces death but the five face a much lesser harm, such as a broken arm; a version in which the one is someone you know well; and an iterated version in which you will face many such choices over time. Aim for somewhere between five and eight leaves, and keep every branch question answerable by someone who has never read the literature. The point is to sort people by what they say about cases and principles, not by which label they happen to like, so no branch should simply ask whether they think the numbers count.
