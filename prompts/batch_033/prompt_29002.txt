I keep running into the same disagreement in interpretability work, and I can't tell whether it has an established name. One side talks as if a model has learned a concept when a direction in activation space can be read off with a linear probe and steering that direction changes the model's outputs in the expected way — I've seen this argued for board-state directions in game-playing models and for sentiment or truthfulness directions in language models. The other side says this shows only that the model's internal state is predictable and manipulable, not that the model itself has the representation: the concept is ours, projected onto the network. The two sides seem to use 'representation' for different things, and I can't articulate exactly where they come apart. Is there a settled name for this fault line, or for each of the two positions? More importantly, how should the phenomenon be carved: what would have to be true for a decodable, steerable structure to count as something the network genuinely represents, as opposed to something an interpreter can exploit? I want the boundary cases, not just a label — features that are decodable but causally inert, features that are causally effective but not human-interpretable, features that appear only under certain inputs or at certain stages of training. Which of those are hard cases for each side, and which nearby positions are easy to conflate with either?
