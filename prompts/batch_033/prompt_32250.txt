I'm a software engineer, mostly working on distributed systems and occasionally on emulators, and I've been trying to sort out whether I'm entitled to talk about the brain as a computer. I've ended up with a list of claims I find myself agreeing with, and I want an audit of whether they actually hang together. The claims, roughly as I'd state them:

(1) The brain is a computer in a substantive sense: mental activity just is the execution of some computation, and a machine that ran the right computation would have a mind.

(2) Computation is substrate-independent: what defines a program is its state transitions and input-output behavior, and the same computation could run on silicon, neurons, or a sufficiently elaborate arrangement of pipes, with the same mental consequences.

(3) It is not the case that everything computes. A rock or a wall isn't implementing anything interesting, and if a theory of computation implies that every physical system runs every program, the theory has gone wrong somewhere.

(4) A simulation of a thing is not the thing. No one thinks a detailed simulation of a hurricane is wet, and I'm inclined to say the same about a simulation of a brain: an accurate software model of the brain would not, merely by being accurate, have a mind.

(5) The brain's computation, unlike a program considered in the abstract, seems inseparable from the specifics of its implementation. It's analog, noisy, timing-sensitive, and tangled up with the body and the environment, and I doubt there is a clean, hardware-independent description of the computation the brain performs.

I can't tell how deep the problems go. Some of these look as though they might conflict, but I suspect other pairs only look inconsistent from the outside, and I don't trust my own sense of which is which. Could you go through the set and tell me: which pairs are genuinely in tension, which pairs merely appear to be, how severe each tension is, and what the cheapest revision would be in each case — which claim has to be weakened or dropped, and what that would cost me? If you had to make a single change to restore as much coherence as possible, which change would it be? I'd rather have a ranked audit than a list of every possible objection.
