ok so my friend showed me this argument and i cant figure out where it goes wrong. it seems to prove that no one can ever be surprised by something if they know its coming within some fixed window. which is obviously false because people get surprised by stuff like that all the time.

heres the argument. teacher says: "there will be exactly one pop quiz next week, monday through friday, and you wont know which day until the morning it happens." now the students reason backward:

(1) the quiz cant be on friday. because if it hasnt happened by the end of thursday, theyd know it has to be friday (since its the only day left), so it wouldnt be a surprise.

(2) since the quiz cant be on friday, it also cant be on thursday. because if it hasnt happened by the end of wednesday, and theyve already ruled out friday, theyd know it has to be thursday — so again, no surprise.

(3) same logic rules out wednesday, then tuesday, then monday.

(4) so there cant be a surprise quiz at all. the teachers announcement is impossible to fulfill.

(5) but the teacher gives the quiz on wednesday, and it totally is a surprise. so the argument has to be wrong somewhere.

now the thing that bugs me is that this isnt really about quizzes. the same reasoning seems to apply to anything announced for a finite window. a surprise party sometime this month, a friend saying "ill call you with news sometime in the next three days, you wont know when," even a package tracking that says "delivery between monday and friday, no specific date." the argument seems to prove that none of these can actually surprise you, as long as the window is known in advance. but we know they can. so the argument proves way too much — it would rule out something that just happens in real life.

i get that the backward induction is doing something slippery, but when i try to pinpoint the exact step that fails i cant. like, premise (1) seems fine on its own — if friday is the last possible day, and you wake up friday morning knowing the quiz hasnt happened yet, how could it be a surprise? and if (1) is fine then (2) seems to follow naturally, since by wednesday night youve already knocked out friday using the same reasoning. and if each step follows from the last, how do we not end up at (4)? but (5) shows we cant accept (4).

where exactly does the reasoning break? i want a committed answer — which numbered step is the first one that doesnt actually hold, and why? and if i reject that step, what else do i have to give up? like, does it mess with how we normally think about knowledge and deduction, or is there a clean fix?
