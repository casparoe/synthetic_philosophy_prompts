I keep running into this pattern in decision-theory-ish arguments and I'm wondering if it has a name, or if it's just a family resemblance thing.

The pattern is: you've got a choice between A and B that are symmetric — like, from your perspective they're indistinguishable except for the label. Then someone does an expected-value calculation that says you should take A. But then you notice the calculation doesn't actually use any feature that distinguishes A from B; it's just the structure of the setup. So you flip the labels and run the same calculation, and now it says you should take B. But you can't have both A > B and B > A, so the reasoning has to be broken somewhere. But it's not like there's a simple arithmetic mistake — the steps look individually fine.

The obvious example is the two-envelope thing (one has twice the other, you pick one, then you reason that switching has positive expected value, but the same reasoning works if you'd picked the other one). But I feel like I see this shape of problem in other places too: some anthropic puzzles, some arguments about acausal trade, maybe even some versions of the simulation argument where the same indifference principle gets you opposite conclusions depending on which reference class you start with.

What I'm after isn't the name of any particular puzzle — I know the two-envelope paradox has a name. I'm asking about the underlying failure mode: the thing where a form of reasoning is symmetric in a way that makes it self-defeating, and the symmetry itself is the clue that something's wrong. Is there an established term for that? If there are several near-miss concepts, I'd want to know what they are, how they differ, and which one fits best. And if there's nothing standard, I'd be curious what you'd call it and how you'd define its boundaries — like, does it include things like Dutch books, or is it a narrower thing?

Also, whatever diagnosis you end up giving of what's actually going wrong in these cases — I'd want to know what would change your mind about it. What kind of argument or counterexample would make you switch to a different account of where the mistake is?
