The core claim, as I understood it: when an agent uses an external resource — a notebook, a smartphone, a to-do app — as reliably and transparently as they use their biological memory, that external resource is not merely a tool but is literally part of the agent's cognitive system. The parity principle says, roughly, that if an external process plays the same functional role as an internal cognitive process, it should count as cognitive too. The classic example is Otto, who has a memory impairment and always consults his notebook, versus Inga, who remembers things normally. The claim is that Otto's notebook entries are his beliefs in the same sense that Inga's neural encodings are hers.
