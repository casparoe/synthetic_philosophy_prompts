I've been going down a rabbit hole on the AI safety via debate proposal and wrote up some thoughts that I'm hoping to turn into a proper essay. Would really appreciate any comments — especially if you think I'm confused about something or if this line of critique has already been addressed somewhere.

So the standard setup (Irving, Christiano, Amodei 2018) is: two AIs debate a question, human judge decides the winner. The hope is that even with superhuman AIs, truth wins out because false arguments get exposed under cross-examination. The "obfuscated arguments" problem says: wait, what if a dishonest AI makes an argument that sounds great to a human but is actually wrong in ways the human can't detect? The standard reply is that the honest AI can point out the flaw.

But I think there's a deeper structural problem that doesn't depend on any AI being dishonest. The debate mechanism optimizes for *persuasiveness to the human judge*, not for truth. The AIs are selecting arguments based on what will land with a human. So imagine there's some consideration that's genuinely crucial for getting the right answer, but it's the kind of thing that's really hard to make intuitively compelling to a human — maybe it involves abstract reasoning the human has no good grip on, or it cuts against the human's biases in a way that makes it an uphill battle to present. In that case, neither AI has an incentive to bring it up. The AI arguing for the true answer will prefer to use easier-to-sell arguments, and the AI arguing for the false answer certainly won't bring it up. So the consideration just... never enters the debate. And the human makes a decision without ever hearing about it.

This isn't the same as the obfuscated arguments problem (which is about one side actively deceiving the judge). It's also not quite the same as the "informed judge" problem (which is about the judge lacking background knowledge to evaluate claims). It's more like: the debate format creates a selection pressure where certain kinds of true considerations get systematically filtered out because they're not rhetorically competetive. You could have a situation where the debate looks great, both AIs are arguing in good faith, the human feels well-informed — and the conclusion is still wrong because the most important consideration never came up.

I guess one response is: if a consideration is genuinely crucial to the truth, then the AI arguing for the true answer *should* be able to find some way to convey it to the human, even if it's hard. And if it can't, maybe that's just a sign that the human judge isn't qualifed to adjudicate this question, and we need a different approach. But that seems like it concedes the point — the debate mechanism only works when the human can in principle understand the key considerations, which is exactly the limitation we were trying to escape by using superhuman AIs in the first place.

Anyway, would love to hear if this critique actually bites, or if I'm missing something about how the incentive structure is supposed to handle this.
