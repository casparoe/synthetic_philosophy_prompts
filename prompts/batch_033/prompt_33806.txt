At a philosophy department event, I overheard two graduate students arguing about the omnipotence paradox. The first, call him A, pressed the classic version: can an omnipotent being create a stone so heavy it cannot lift? If the answer is yes, then there is a stone the being cannot lift, so it is not omnipotent. If the answer is no, then there is something the being cannot do — namely, create such a stone — so it is not omnipotent. Either way, omnipotence is impossible. The second, B, replied that this puzzle dissolves once omnipotence is properly defined: omnipotence is the ability to do anything that is logically possible, and since "creating a stone that an omnipotent being cannot lift" is a logically incoherent description — like asking for a square circle — the inability to do it is no restriction on omnipotence. A responded that this merely relocates the problem: you now need to explain why the description is incoherent, and the only reason it is incoherent is that you have already defined omnipotence to exclude it, which is circular. B denied this, saying the description is incoherent because "an omnipotent being cannot lift X" contradicts the definition of omnipotence, and that is a logical fact independent of any theological commitment. A then shifted ground: consider a different version — can an omnipotent being make itself non-omnipotent? That seems logically possible, since we ourselves are non-omnipotent. If the being can do it, then it can bring about a state of affairs in which it lacks a power, which seems to contradict omnipotence. If it cannot, then there is something it cannot do. B replied that this is a more interesting challenge, but the theist can bite the bullet: an omnipotent being can indeed make itself non-omnipotent, and this is no contradiction because omnipotence concerns what one can do at a time, not what one must retain forever — giving up a power is itself an exercise of power. Neither seemed persuaded by the other, and they parted ways. I think both made good points but I am not sure where the balance lies. Please adjudicate the debate move by move: identify who is right about which specific claims, whether any moves are question-begging or involve hidden assumptions, and whether the paradox, after this exchange, still poses a genuine difficulty for the doctrine of omnipotence.
