here's the student's answer:

---

Kripke's central innovation is the notion of a rigid designator: a term that designates the same object in every possible world. Proper names, Kripke argues, are rigid designators — 'Aristotle' picks out the same person in every possible world where he exists, whereas a definite description like 'the teacher of Alexander' is non-rigid because someone else could have taught Alexander.

The crucial argument is this: if 'a' and 'b' are both rigid designators, then the statement 'a = b' is necessarily true. Since each term picks out the same object in every world, there is no possible world where the object designated by 'a' is distinct from the object designated by 'b'. The classic example is 'Hesperus is Phosphorus.' Both are proper names for Venus, hence rigid designators, so the identity statement is necessary — there is no possible world where Hesperus is not Phosphorus.

But we discovered that Hesperus is Phosphorus through empirical astronomy, not by analyzing concepts. So the statement is necessary yet a posteriori. This directly challenges the traditional view (associated with Kant and the logical positivists) that necessity and apriority always go together.

Kripke extends the same reasoning to natural kind terms. 'Water is H2O' is another necessary a posteriori truth. 'Water' rigidly designates the substance with the molecular structure H2O, and 'H2O' rigidly designates that same structure, so the identity is necessary. Yet it took modern chemistry to discover this — it's clearly a posteriori. Even if we encountered a substance on another planet that looked and tasted like water but had a different chemical composition, it wouldn't be water.

Kripke's result is that the necessary/contingent distinction and the a priori/a posteriori distinction are entirely seperate. The traditional picture that aligned them was simply a mistake.
