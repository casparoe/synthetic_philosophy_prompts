At last week's decision-theory reading group, we worked through the Pasadena game. A fair coin is tossed until it lands heads; if the first heads occurs on the nth toss, the payoff is \((-1)^{n+1} \cdot 2^n / n\) dollars, so the possible payoffs run \(+2, -2, +8/3, -4\), and so on. If the states are listed in the order \(n = 1, 2, 3, \dots\), the expected-value sum is \(1 - 1/2 + 1/3 - 1/4 + \cdots\), which converges conditionally to \(\ln 2\), but a rearrangement of the same terms can be made to converge to any real number or to diverge. The Altadena game is identical except that every payoff is increased by one dollar, so Altadena pays one dollar more than Pasadena in every state, yet its expected-value sum is likewise only conditionally convergent. Two members of the group, Marcus and Elena, then had the following exchange.

Marcus argued that this is overblown. The order \(n = 1, 2, 3, \dots\) is not arbitrary: it is the temporal order in which the coin actually unfolds. The game is defined by that process, so the natural sum gives \(\ln 2\) for Pasadena and \(\ln 2 + 1\) for Altadena. Expected utility theory therefore does compare them, and it prefers Altadena. Elena replied that the temporal order is just one way of presenting the act. Expected utility is supposed to assign a value to an act as a function from states to outcomes, and the state space has no privileged order. If changing the order of the same probability-payoff pairs changes the expectation, then the theory has not actually assigned a value to the act at all; calling \(n\) the "natural" order smuggles in information that the expected-utility framework does not contain. Marcus came back that this demand for order-invariance is too strong. Many conditionally convergent series arise in probability, and requiring absolute convergence would leave the theory silent in too many cases; better to keep the temporal ordering as a privileged one, or to use some other summary rule such as a preferred summation method or finite truncation. Elena answered that a preferred summation method is a new rule that expected utility theory does not itself supply, and finite truncations are arbitrary unless one specifies where to cut and why. She added that for the one pair Pasadena versus Altadena, dominance reasoning can do the work, but that only shows expected utility is incomplete: there will be other pairs of games with undefined expectations and no statewise dominance, where the original theory gives no guidance.

Then say who is more right overall, and identify anything important that both of them missed. Please write your answer in American English.
