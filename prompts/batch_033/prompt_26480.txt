**The St. Petersburg Paradox and the Problem of Logical Omniscience**

The St. Petersburg paradox is standardly presented as a challenge to the principle that rational choice maximizes expected value. A fair coin is flipped until it lands tails; if the first tails occurs on the nth flip, the player receives 2^n dollars. The expected monetary value of this game is the sum over n of (1/2)^n × 2^n = 1, taken over all positive integers n, which diverges to infinity. Expected value theory therefore seems to license paying any finite amount to play. Since no one would pay more than a modest sum, we appear to have a counterexample to expected value theory as a normative standard.

The standard responses to the paradox are well known. Bernoulli argued that the relevant quantity is not expected monetary value but expected utility, and that money has diminishing marginal utility; a utility function that grows logarithmically with wealth yields a finite expected utility. Others have pointed out that the game is impossible to offer at the stated terms because no bank has infinite resources. Still others have appealed to risk aversion or to the idea that sufficiently small probabilities are decision-irrelevant.

I want to suggest that these responses, whatever their merits, share a deeper assumption that deserves scrutiny. They all assume that the paradox is a problem about what the normative standard of rationality should be — about whether expected value, expected utility, or something else is the right criterion. But there is another way to see the paradox: as a problem about what an agent can even represent as the value of a gamble.

Consider what is involved in computing the expected value of the St. Petersburg game. The computation requires summing an infinite series. An agent must first represent the game as a probability distribution over outcomes, then compute the product of probability and payoff for each outcome, and finally sum the resulting infinite series. A finite agent cannot complete this sum by brute enumeration. The agent can represent the series in compressed form — recognizing that each term simplifies to 1 and that the series therefore diverges — but this compressed representation is itself the product of mathematical reasoning that not every agent possesses. An agent who does not simplify the terms, or who lacks the concept of a divergent series, is not in a position to assign the game an infinite expected value. They might assign it a large but finite value after truncating the series at some point, or they might simply be unable to compute a value at all.

This is where the problem of logical omniscience enters. In epistemic logic, the problem of logical omniscience is the difficulty that standard possible-worlds models of knowledge and belief attribute to agents knowledge of all logical consequences of their knowledge. If an agent knows the axioms of Peano arithmetic, standard epistemic logic attributes to them knowledge of all theorems of PA — which is absurd for any finite agent. The standard response is to develop models of knowledge and belief that do not close under logical consequence, or that close only under some tractable fragment of it.

The St. Petersburg paradox, I submit, makes an analogous idealization. The setup attributes to the agent the ability to evaluate the expected value of the game. But evaluating the expected value of the St. Petersburg game requires either completing an infinite computation or recognizing, via a piece of mathematical reasoning, that a particular infinite series diverges. Neither is something a computationally bounded agent can do as a matter of course. The paradox therefore assumes a kind of computational omniscience on the part of the agent — the agent is treated as if they can instantaneously evaluate the sum of any series the game description defines.

Once we drop this assumption, the paradox looks different. A computationally bounded agent, confronted with the St. Petersburg game, faces a decision problem whose expected value they cannot compute. This is not a failure of rationality; it is a fact about their computational limits. The question then becomes: how should a computationally bounded agent make decisions when they cannot compute the expected values of their options? This is a question about bounded rationality, not about the normative adequacy of expected value theory.

The connection to logical omniscience is not merely analogical. In both cases, an idealization that is useful for certain purposes — attributing logical closure to knowers, attributing unlimited computational ability to decision-makers — is mistaken for a normative requirement. The mistake is to think that because an idealized agent would know all logical consequences, a real agent ought to; or that because an idealized agent would compute the infinite expected value, a real agent ought to be moved by it.

If this is right, then the St. Petersburg paradox is not a paradox about the content of rational choice theory but about its application to bounded agents. The standard solutions — diminishing marginal utility, finite bankrolls — address the wrong problem. They try to make the expected value finite so that the agent can compute it. But the deeper issue is that even if the expected value were finite, a bounded agent might still be unable to compute it. The paradox is a special case of a more general problem: how to define rational choice under computational constraints. Seen this way, the St. Petersburg game is not a counterexample to expected value theory but a particularly vivid illustration of why we need a theory of bounded rationality in the first place.
