I'm in a course on formal epistemology and agent foundations, and we've been discussing the Löbian obstacle to self-trust. I've reconstructed an argument that seems to show that no sufficiently reflective agent can rationally trust its own reasoning—but since I take myself to be such an agent and I do trust my reasoning, the argument seems to prove too much. I'd like to know which step to reject and what it costs.

Consider an agent that uses a formal proof system to decide what to do: it only takes an action if it can prove that the action is beneficial. The agent is reflective enough to represent its own proof system and to reason about what it can and cannot prove. Now:

(1) For the agent to trust its own reasoning, it must be able to assert that its proof system is sound: if the system proves a proposition P, then P is true.

(2) Since the agent's proof system is sufficiently powerful to encode arithmetic and its own proof predicate, it can formulate the soundness claim: for all P, if Provable(P) then P.

(3) By Löb's theorem, any consistent system of sufficient strength that proves its own soundness (in the sense of the schema in (2)) is inconsistent—it proves everything, including falsehoods.

(4) The agent is consistent (it does not prove everything).

(5) Therefore, the agent cannot prove the soundness of its own proof system.

(6) If the agent cannot prove its own soundness, then for any particular conclusion C that the agent derives, the agent has no guarantee that C is actually true—the fact that the agent proved C does not, from the agent's own perspective, establish C.

(7) An agent that has no guarantee that its conclusions are true has no rational basis for trusting those conclusions, and thus no rational basis for acting on them.

(8) Therefore, no consistent, sufficiently reflective proof-based agent can rationally trust its own reasoning.

(9) But we are (or at least aim to be) consistent, reflective reasoners who do trust our own reasoning enough to act on it, and we take that trust to be rational.

(10) So the argument seems to prove that rational self-trust is impossible—which I cannot accept.

Where does this argument go wrong? I can see several places one might push back—the modeling of human reasoning as a formal proof system, the slide from "cannot prove global soundness" to "cannot trust particular conclusions," the demand that the agent prove soundness at all rather than simply presuppose it—but I want to know what the most principled response is and what rejecting it costs. If the argument is in fact valid, then I need to know which premise is least costly to give up and why.
