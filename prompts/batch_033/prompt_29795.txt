I've been arguing about this alot with a friend who works in an interpretability lab, and she has very firm instincts about which internal structures she'll call genuine representations and which she'll dismiss as stuff we can merely read off the model. I want to reverse-engineer the rule she's actualy running.

Her verdicts so far: early-layer edge detectors in a convnet, real; a clean sparse-autoencoder feature for a specific landmark that's selective and steers captions in the expected way, real; a linear probe direction that decodes truthfulness from layer 14 but doesn't change behavior when you intervene on it, not a representation, just extractable information; an SAE feature that appears only under one sparsity penalty and one random seed and has no causal effect, artifact; grid-cell-like units in a path-integrating RNN that are causally required for navigation, real; a single attention head that's necessary for copying the previous token, real.
