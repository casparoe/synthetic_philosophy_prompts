For a philosophy-club project on decision theory, I've been reading about the proposal that an agent facing "acausal blackmail"—a threat from a party it never causally interacts with, but that can accurately predict how it will respond—might protect itself by adopting a "surrogate goal": committing to defend some cheap, low-stakes goal exactly as fiercely as its real values, so a rational threatener targets the harmless substitute instead of what the agent actually cares about. I'd like to know whether this works even in principle, not just in the toy cases usually used to illustrate it. Please argue that no such commitment can be credible to a threatener sophisticated enough to be worth defending against in the first place: the same capacities that let it predict the target's behavior should let it tell a load-bearing goal from a manufactured one, so the strategy either fails to redirect the threat or just turns the "surrogate" into a second, equally real target.
