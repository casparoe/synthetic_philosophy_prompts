"People say DNA 'is a code' so often that it sounds like a description rather than a claim, but there's a real question hiding underneath it. Narrowly, 'the genetic code' just names the table mapping each 3-letter codon to an amino acid, and that mapping does look code-like in a specific way: it isn't fixed by chemistry the way a codon's physical shape fixes what it can bind to. It's enforced by separate adaptor molecules (tRNAs) that could, in principle, have been wired up differently, and some philosophers of science point to exactly this kind of arbitrariness — the same reason Morse code counts as a real code and not just a pattern — as the justification for calling the codon table a code rather than a metaphor.
