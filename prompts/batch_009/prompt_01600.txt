I've been following the long-running Less Wrong dispute over "coherence arguments" for expected utility maximization, and I want to see two well-matched decision theorists actually fight out one specific move in it. The background: defenders of the argument hold that any agent with incomplete preferences—some pair of options it simply can't rank—is vulnerable to being money-pumped into a strictly worse outcome, so any sufficiently advanced agent will end up with complete preferences after all. Critics reply that the agent can dodge every such trade sequence just by adopting a policy of never accepting an option it strictly disprefers to one it has already turned down, without ever actually ranking the previously unranked options.

Write a dialogue between two decision theorists arguing over the following scenario. The agent has a preferential gap between options A and B: it prefers neither to the other, and this isn't mere indifference, since it still prefers neither even once A is slightly worsened to A− (though it does strictly prefer A itself to A−). One theorist tries to construct a sequence of trades—first swapping the agent's A for B, then that B for A−—that exploits this structure to leave the agent strictly worse off than if it had refused every trade. The other defends the agent using the policy above, or by challenging some premise the construction needs. Have each theorist press the other on the weakest point in their position: can the trades be redesigned so the agent is strictly compelled, rather than merely permitted, to keep trading at every step, leaving the policy no foothold? And is an agent that resolves the same gap the same way every time it comes up really any different, in a way that matters, from one that just ranked the options to begin with? Neither theorist should concede ground cheaply, both should be equally sharp, and each response should directly engage with the specific move the other just made rather than restate a prior position.
