I've been reading about program equilibrium, the idea going back to Tennenholtz that if two agents can read each other's source code before playing something like the Prisoner's Dilemma, mutual cooperation can be made a genuine equilibrium rather than a mistake. The construction that really stuck with me is FairBot: an agent that cooperates if and only if it can prove its counterpart cooperates with it, where Löb's theorem is what keeps the reasoning from collapsing into an infinite regress of each side waiting on a proof from the other.

Write a dialogue between two engineers designing a negotiation protocol for autonomous agents that will publish their source code to each other before every interaction. One is convinced that this Löbian trick is a real, principled solution to the cooperation problem for artificial agents, on par with discovering a new resource like reputation or enforceable contracts. The other thinks it doesn't solve anything: it just restates the original problem in the language of provable dispositions, and will fall apart once you leave the tidy world where source code can be fully verified. Have them push back on each other's specific arguments rather than just restating their own positions, and don't let either one come out a clear winner.
