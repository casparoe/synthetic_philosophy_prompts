Setup so we're using the same words. The simple conditional analysis: x is disposed to give response R to stimulus S iff, if x were in S, x would give R. The usual Lewis-style repair adds two separable bits: (i) a *retention* clause — there's some intrinsic basis B that x actually has, and the counterfactual is about x being in S while keeping B for long enough; and (ii) a *basis* or "in virtue of" clause — the response has to come from B (stimulus and B jointly causing R), not from something else that happens to be hanging around. As far as I can tell the standard story is that (i) cleans up the classic fink and (ii) cleans up the classic mimic, and that masks are where it starts to hurt. Tell me if I've got that backwards.

Six cases. Assume nothing else weird is going on, and that the target intuition is the one I flag.

A. **The Curator** (fink). A vase, brittle in the ordinary way. A gallery sensor tracks incoming objects: in the nearest worlds where something strikes the vase, the sensor fires a millisecond earlier and anneals the microstructure, so the brittleness basis is gone before the blow lands, and the vase doesn't break. Target: it was fragile.

B. **The Sheath** (extrinsic mask). Same kind of vase, sealed inside a rigid aerogel shell bolted to the plinth. Strike the shell and the vase doesn't break; get the vase out of the shell and it shatters like anything. Target: still fragile — the shell is doing the work.

C. **The Girdle** (intrinsic mask). The vase was fired with a titanium mesh fused into its wall. A strike arrives, the ceramic's brittle basis is present and unchanged throughout, and the mesh redistributes the stress so no crack propagates. Target: I genuinely don't know — some people say the vase isn't fragile, others say the ceramic is fragile but masked. Say which way you think it goes and mark it as contested if it is.

D. **The Squib** (mimic with a decoy basis). A lump of cured resin, genuinely though, no brittleness anywhere. But it contains a small charge wired to a shock sensor: strike it, boom, it's in pieces. It also contains one tiny brittle sugar-crystal, which plays no causal role in the explosion. Target: not fragile.

E. **The Vault** (necessarily masked). Same vase, same basis B — except the shell is nomologically inescapable: no world consistent with the laws has that vase getting struck outside the shell. Target: still fragile, I think, but flag it if that's the bit people actually fight about.

F. **The Kiln** (stimulus-conferred basis). A lump of soft clay, not brittle at all. Its one interesting property: a hard enough strike reorganizes it into a glassy brittle state within a microsecond, after which it cracks in the ordinary brittle way. So struck → cracks. Target: not fragile (say if you disagree).
