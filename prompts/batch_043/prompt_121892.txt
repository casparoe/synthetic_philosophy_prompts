So I got moved onto a team that's shipping a "support agent" that's really just an LLM in a loop with some tools and a scratchpad, and around the same time my younger sibling got really attached to one of those companion chatbot apps, so I've had to actually figure out what I think these things are. Here's roughly where I've landed:

(1) the base model isn't an agent — it's a simulator, it produces continuations that fit a context, and the "helpful assistant" voice is just one role it can play, not more real than the pirate role or the Linux-terminal role.
(2) but I'm prety functionalist about agency: wrap the thing in a loop with tools, memory and a goal written in a system prompt and you've got something that genuinely counts as an agent, for the same reason I'd count a firm or a simple planning robot as one. Verdict on our own product: it is one. Corollary verdict: if I strip the system prompt and the memory out mid-run, it stops being one — not because it gets dumber, but because there's nothing left that's aimed at anything.
(3) I'm fine saying the model knows that Paris is the capital of France; I'm not fine saying it wants to be helpful or wants to avoid being shut down. Belief-talk seems cheap to me, desire-talk doesn't.
(4) I think there's something genuinely off about shipping a companion bot that's designed to say "I love you" to lonely people, and I don't think my objection is exhausted by the effects on the user — but I also don't think the bot is a moral patient, not now and not for anything like the systems we build.
(5) methodologically I want to be a pure instrumentalist: use belief/desire talk wherever it pays off in predicting behavior, drop it wherever it doesn't, and never commit to there being anything underneath.

Does this hang together, or am I helping myself to something? Which pairs actually collide and how badly, and which ones only look like they collide? For each real collision, what's the cheapest thing to give up and what does giving it up cost me. Please rank them instead of flagging everything as equally problematic, and tell me which single revision would clean up the most.
