I have no formal training in this and have been working it out on my own, but I have ended up an anti-fanatic about astronomical stakes: I hold that any decision procedure worth using has to be able to set aside an outcome whose probability falls below some threshold, however enormous the payoff — that a rule which will always trade a certain decent result for a one-in-10^30 chance of one astronomically better has malfunctioned, and that expected-value maximization needs a non-fanatical supplement rather than just more careful probability estimates.

What would count against that, ranked from fatal to merely awkward? I would especially like to know which costs a defender of anti-fanaticism would themselves concede and which they would say I have misdescribed: that a threshold rule can choose something worse than an available alternative in every state of the world; that it seems to require giving up the thought that saving more people is straightforwardly better than saving fewer; that the threshold itself looks arbitrary, or looks like it has been placed just where the embarrassing cases stop; and that it appears to commit me symmetrically to ignoring tiny chances of astronomically bad outcomes.

My own worry is a different one. In actual cases I suspect my refusal is not a view about value at all but plain distrust: of the description of the setup, of the model that produces the tiny number, of my own grasp of very large quantities. If that is the whole story, then in a fully idealized case — chance and payoff stipulated to be exactly as described, every misunderstanding ruled out — does my own view require me to be a fanatic after all? And if it does, is that fatal, because the view then does no work exactly where the pressure is greatest, or is it fine, because the view was only ever about choosing under real uncertainty and the idealized case is an artefact? An argument of that shape would move me more than any number of further mugging variants.
