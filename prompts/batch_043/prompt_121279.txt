Setup, so we don't argue about GEB's exact tables — here's a stripped version I've been messing with, call it PT. A cell is a bag of strands over A, C, G, T. A fixed code maps each triplet to an operator; translating a strand left to right in triplets yields an enzyme, which is just a program. Running an enzyme on the cell can copy, cut, splice and insert bases, and which strand it grabs is fixed by its own operator sequence (say the first operator acts as a seek for a matching base). Translation doesn't consume the strand. A strand is a self-rep if, dropped alone into an empty cell, it eventually throws off an extra copy of itself without filling the place with junk.

Here's my opening, and it's what I want you to take apart. Call it the recoding test. Take a PT self-rep S under code table C, then permute the codon-to-operator table into C'. Under C', S translates into junk or into a different enzyme, and it stops being a self-rep. So PT self-rep isn't code-invariant: it's a property of S together with one arbitrary table, which makes it look like an accident. Gödel survives the same move, or so I claim — pick a different Gödel numbering and you get a different sentence, but it's still true iff unprovable, because arithmetic can represent any numbering you throw at it. Now, if your reply is going to be "that just shows PT is too weak to re-represent its own coding conventions," I agree, and I want to push it further: the test says a genuine self-*description* needs the interpreter inside the system. And real cells half do that already, since the code is implemented by tRNAs and synthetases that the DNA itself encodes. So why isn't that enough to make DNA partly self-describing, in just the sense you keep denying?
