In my workshop we have vocabulary for this. We call facts like that swing facts: facts about a character or a world that the text hasn't nailed down and that could still go either way in a later draft. And we have a rule, the Bellwether Rule, which we use when maintaining the continuity bible: a swing fact gets locked into the bible only if it holds in every version of the material we'd actually be willing to publish. If some publishable version has it and some publishable version doesn't, it stays a swing fact and we're forbidden from writing it down either way.
