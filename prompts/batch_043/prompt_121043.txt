So this started as a dumb side project — I'm building a tiny browser-based "logic playground" where you can type in sentences that talk about their own truth values and then step through an evaluator that assigns values stage by stage — and it has now completely eaten my evenings, to the point where I have actual opinions about the Liar and keep arguing about them with my housemate, who is an annoying dialetheist. The position I've ended up defending is this package deal: the Liar is gappy rather than glutty; I use the strong Kleene three-valued scheme rather than supervaluations; I take the minimal fixed point of the Kripkean construction, not some other fixed point and not "all fixed points"; and I refuse to add a "determinately" operator or an "it is true that" operator to the object language, so the theory itself gets stated in the metalanguage, even though that means the sentence which says of the Liar that it isn't true comes out gappy too and I can't state my own diagnosis from inside the language.

Two things specifically nag at me. First, my evaluator exposes a predicate like true_at(n, s), meaning "s gets the value true at stage n", where n ranges over finite stages only, because my implementation just runs a fixed number of steps and then gives up. That lets me write a sentence λ* that says, of itself, that for every n it is not the case that true_at(n, λ*). And as far as I can tell this thing never settles: if my evaluator ever did call it true at some stage, that would immediately make it false; but if it stays gappy forever, then what it says — that it's never true at any stage — looks, from the outside, just correct. So I seem to have built a sentence that is saying something true and which my semantics refuses to call true, and that bothers me more than the original Liar does, because with the original Liar I at least have a story about ungroundedness. Second, a friend says my setup is fine for the Liar but that the Curry-style paradox (the one that runs through a conditional instead of negation) forces me to give up either modus ponens or conditional proof, or else use some much weirder conditional, and she thinks that cost is the real defeater rather than any revenge sentence.
