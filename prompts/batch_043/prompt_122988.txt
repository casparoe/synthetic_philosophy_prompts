The butterfly effect keeps being used as a conversation-ender in threads I read, most recently in a longtermism argument where it was deployed in two opposite directions: one commenter used it to say that a tiny intervention now can set off a tornado months later, so no cost-effectiveness estimate should be discounted merely for being small, and the next used the very same line to say that if that's how the atmosphere works, century-scale forecasting is hopeless, so any century-out impact estimate is noise. Both wrote as though the slogan did argumentative work on its own.

My own guess is that the popular line bundles together at least three separable claims, and I want them pulled apart as a menu rather than explained: (i) sensitive dependence proper — nearby trajectories diverging exponentially, with a prediction horizon set by growth rate and by how precisely the present state can be measured; (ii) the much stronger claim that a specific small perturbation is a genuine difference-maker for a specific later macro-event, which I suspect mostly fails, because in such a system the perturbation plausibly changes which trajectory gets realized rather than whether an event of that rough kind occurs, and because vastly larger perturbations are always already present; and (iii) something global about unpredictability, which can't be right as stated, since a system can be fully deterministic, still support well-calibrated ensemble forecasts, and still have a stable predictable climate while individual weather is unpredictable.

Please list the distinct precise claims the line might be expressing, tag each as trivial, substantive and defensible, or false, and say which, if any, would actually support either commenter. Lead with one sentence giving your verdict on each commenter. At most 400 words total.
