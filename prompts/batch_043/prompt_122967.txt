In the reading group I run — mostly people with the same rationalist-blog background I have — one member keeps defending a strong reading of the claim that DNA is a code. Not the loose idiom in which anything correlated with anything counts as carrying information about it, but the literal version: the genome is a program, codons are instructions in a language with a fixed semantics, the ribosome-and-tRNA system is the interpreter, the cell is the machine that executes the result, and molecular biology is therefore a species of computer science applied to a rather messy substrate. He puts the analogy to two uses. The first is philosophical: that genetic information is semantic information in the way a source file is, that a misreading is thus an error relative to what the sequence *means* rather than merely a failure of function, and that the gene's-eye idiom of genes pursuing goals is literal rather than a bookkeeping convenience. The second is practical: that if biology really is programming, then editing a genome should give us the kind of leverage over phenotype that editing source gives over a program's behaviour, and the risk from engineered organisms ought to be modelled on software risk — someone authors a payload, it compiles, it runs as written, and the failure modes are bugs.

Two considerations make me want the analogy audited properly rather than gestured at. First, what I have started calling the interpreter regress: the translation machinery is itself encoded in the string it is supposed to interpret, so the semantics cannot be fixed first and then read off, and nothing in the cell plays the role of a specification against which an output could be correct or incorrect. Closely related is a point I have not seen made anywhere: in software one can usually change one instruction while leaving the language, the libraries and the data alone, whereas a mutation in a tRNA or in its synthetase silently rewrites the meaning of every occurrence of a codon across the whole genome, so the genome seems to lack any edit that is local at the level of meaning — call it the no-local-edit property. Second, the dialect problem: the same nucleotide string is a well-formed instruction for one reader and nonsense, or a different instruction, for another. The mitochondrial translation table differs from the nuclear one at several codons (my recollection is that a stop becomes tryptophan and two arginine codons become stops, though I would not bet on the details), and synthetic biologists have built strains with reassigned codons, so a sequence moved between strains would not keep its content.

So: give me the correspondence table — what plays the instruction, the interpreter, the compiler, the machine, the input, the output, the bug, the specification, the crash, the comment — and, for each row, say whether the target actually has the feature the source has. Then separate the disanalogies that bear on his two conclusions from the ones that are inert for both. In particular: where does the coding relation stop, and can the analogy be confined to the codon-to-amino-acid step in a principled way, or does it leak? Which features does the word program quietly import that the genome lacks — an author's intention, compositionality all the way up to phenotype, a local and detectable failure, a code/data distinction, abstraction layers, portability across machines, determinism — and which of those is his argument actually leaning on? Is there a defensible narrow sense in which the genetic code is a code (an arbitrary mapping between two combinatorial sets maintained by a translating apparatus) that leaves genome-to-organism not a code at all, and if so what happens to each conclusion? Do the conclusions survive at all — and is there a weakened reading of the first one, on which information-talk earns its keep causally or teleologically rather than semantically, that rescues it while the second one collapses? Finally, if program cannot carry the practical claim, what is the better analogy — a legacy codebase with no comments and no tests, an analogue circuit, a chemistry set, a recipe, a legal code with an unwritten constitution — and what does each of those predict about genome editing that program does not?
