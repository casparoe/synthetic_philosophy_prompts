Hey, quick question from a backend engineer with zero philosophy background, so bear with me. I keep noticing a pattern at work and I want to know if it has an actual name, because I keep describing it badly in meetings.

The pattern: whenever we build some kind of representation of a system — a model, a dashboard, internal docs, whatever — the representation starts acting back on the system it's supposed to be describing. Some concrete cases:

1. We made a dashboard showing error rates per team. Within a month, nobody was really fixing more bugs, but people were reclassifying and rerouting tickets so their team's number looked better. So the error rates shown on the dashboard were now partly caused by the existence of the dashboard.

2. We trained a model predicting what users would click. Then we shipped its top predictions as actual recommendations. Now a big chunk of what users click is caused by the model, so the model is in some sense predicting its own outputs — the data it learns from is downstream of itself.

3. The weird one: our internal docs describe how a service behaves, new engineers read the docs and write code that matches them, then the code drifts and someone updates the docs to match the code. The description and the thing it describes keep chasing each other, and it's genuinely unclear which one is the source of truth anymore.

I've tried to nail down why existing terms don't quite fit, tell me if I'm wrong:

- It's not just an observer effect, like a profiler slowing down the program it's profiling. In my cases the representation keeps changing the system after the "measurement" is over. Or is that just the same thing wearing a hat?
- It's not just Goodhart's law, because that needs a metric someone is optimizing against. My docs example has no metric, no target, nobody's gaming anything, and the loop still runs.
- It's closest to a self-fulfilling prophecy, but even that seems off — there's no prophecy being believed. The loop runs through the representation existing and being consumed, not through anyone believing it's true.

There's also a nagging connection I can't quite place. I half remember reading some pop book about consciousness, years ago, that had this image of little symbols in a brain somehow pushing around the actual components they're built out of — like the high-level description getting causal power over the low-level stuff that implements it. Don't remember the name of that idea or even the book, honestly, but it felt like the same thing I see with my dashboards. And occasionally I wonder if the self is a case too — my self-model shapes what I do, which changes the data my self-model is built from, and so on.

So: is there an established concept for exactly this — a representation of a system becoming a causal player inside the system it represents — and if not, can you coin one, with a definition and the boundary cases? I want the carving more than the label: what exactly the phenomenon is, how it differs from observer effects, Goodhart, and self-fulfilling prophecies, and where the edges are (is a recipe this? is a law? is the consciousness thing I half remember the same phenomenon or just an analogy?). A bare "that's Goodhart" or "that's just feedback loops" would definately not satisfy me, because I can see how those are related but I don't think either one is it.
