My lab has two people who've spent a year arguing about whether RL agents can suffer, and I'm sick of watching it go in circles. So I'm handing them an assignment: draft the joint statement they would have produced if they'd actually done an adversarial collaboration instead of talking past each other. Write that document for me.

The two camps:

Camp A (the "valence is the signal" people): in a reinforcement learning agent that selects actions and adapts, negative reward — and negative temporal-difference error especially — just is a form of valence. Not a metaphor for it, not a convenient shorthand. So an agent with a rich enough world model gets actual low-grade suffering out of this, and our moral caution about building and training such agents should scale with the reward architecture, roughly the way it scales across animals.

Camp B (the "suffering needs more than a signal" people): a learning signal is not a feeling. Suffering requires at least some of: a persistent self-model, episodic memory so that bad states can accumulate, an affective state that can outlast the situation that triggered it. No current RL agent has this, and stacking more reward on the same architecture never gets you there — you'd need to add the other stuff, and at that point it's not the reward doing the work.

What I want in the document:

1. Claims both camps can sign — about reinforcement learning itself, about what the human and animal dissociations show (pain asymbolia, decorticate animals still showing affective responses to noxious stimuli, the trade-off tests animal-welfare science leans on), and about the moral stakes of being wrong in each direction.

2. The exact disagreements, each phrased twice: once in wording camp A would accept as a fair statement of its view, once for camp B. This is the hard part and where the value is — neither phrasing can be slanted.

3. The cruxes: sub-questions such that settling one would actually move at least one camp. Some candidates they keep dancing around, and you should add your own: whether experience replay amounts to re-experiencing (the agent literally re-samples its own past punishments during training — does the replay buffer suffer?); whether an agent whose memory is wiped at the end of every episode can build up any debt of suffering at all, or whether the negative TD errors just evaporate; whether an agent that learns to avoid contexts where it was punished is evidence of valence or just evidence of a value function doing its job; what pain asymbolia implies about how far the learning signal and the feeling can come apart.

4. For each crux, one concrete case, argument, or experiment both camps would agree bears on it, written so it could seperate them — with each camp's prediction about the outcome recorded in advance, while they still disagree. Predictions made after you already know the result are worthless, so that part definately matters.

5. If some portion of their dispute is verbal — say, over whether the choice between "suffering," "proto-suffering," and "valence" is doing real work — say which portion and why.

Format: the document itself in whatever structure serves it, and then, at the end, a JSON summary object with this schema:

{
  "agreed": [...],  // strings, one per signable claim
  "disagreements": [{"topic": ..., "camp_A_wording": ..., "camp_B_wording": ...}],
  "cruxes": [{"crux": ..., "test": ..., "prediction_A": ..., "prediction_B": ...}],
  "verbal_parts": [...]  // possibly empty
}

The summary has to be faithful to the document — someone reading only the JSON should be able to reconstruct the state of the argument. And don't let either camp win in the summary; that's not what this is for. No citations or reading lists either, it has to stand on its own.
