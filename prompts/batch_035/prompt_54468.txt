I want a new Frankfurt case for my intro class, but with constraints that rule out all the standard tricks, because honestly the standard story has stopped teaching anybody anything. In the original setup (Frankfurt's neuroscientist watching to see whether you're about to decide not to do something, ready to force the decision if needed) students just file it under sci-fi and the counterfactual intervener does all the work. So here's what I want you to build:

A scenario, one paragraph, ordinary setting — office, hospital, family, whatever — where the counterfactual intervener is a normal human being using normal human means (a coworker watching, a parent by the phone, a referee with a whistle), no brain chips, no mind reading, and the agent is a regular adult making a decision that we'd normally hold them responsible for. The intervener would step in only if it looked like the agent was going to avoid doing the thing, so the agent ends up acting on their own, but couldn't have done otherwise.

The hard part, and the reason I'm asking: the case has to survive the dilemma defense. The complaint is that either the intervener gets some prior signal of what the agent will decide — in which case the agent couldn't really have done otherwise anyway, since the signal already settles it, so there's no counterexample to the principle of alternative possibilities — or there's no such signal, in which case the intervener can't react in time. So whatever cue your intervener responds to can't be a read on what the agent is about to decide, and the reaction time has to be humanly plausible. If the way you dodge the dilemma is by smuggling in a buffer state that leaks information about the decision, say so yourself rather than hoping I won't notice.

After the scenario, do the walkthrough: state exactly which act the agent is responsible for, what the intervention mechanism is, what the Frankfurtian says the case shows about PAP, and what the flickers-of-freedom defender will grab onto (the tiny residue of alternative possibility the case leaves open, if any). Then tell me which single feature of the construction is doing the work, and how I'd attack the case if I were teaching the pro-PAP side. And if you think the constraints I've listed can't actually be satisfied jointly — that ordinary means plus no prior signal plus human reaction time forces you back into the dilemma — tell me that straight, and which constraint you'd relax first and why. Don't just stipulate that the agent couldn't have done otherwise; it has to fall out of the setup.
