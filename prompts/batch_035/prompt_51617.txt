I'm a software engineer by training and trade, with no formal background in philosophy, so please bear with me if I'm making an elementary mistake. I finally worked through Hofstadter's Gödel, Escher, Bach over the past few months, and there's an argument in it I can't shake loose, and I want to know whether it's right, and if not, where it goes wrong.

The MU puzzle, as I understand it, works like this: the MIU system starts with the string MI and has four rules for producing new strings, and Hofstadter asks whether MU can ever be derived. It turns out it can't, because every rule preserves a certain property of the string — the number of I's it contains never becomes divisible by three — and MU contains zero I's, which fails that condition. Crucially, though, no amount of mechanically applying the rules will ever tell you this. You only see it by stepping outside the system and looking at it from above, the way a mathematician looks at arithmetic rather than the way a symbol-shuffler works inside it. Hofstadter calls this jumping out of the system, or JOOTsing.

Now here's the step I'm not confident about, but which seems natural given my background. Gödel proved that every formal system contains statements that are true but unprovable within it. The MIU system is a formal system. So it looks to me like MU is essentially a Gödel sentence for the MIU system: something we can see from the outside is undecidable, that the system itself can never settle, and that only a mind capable of JOOTsing can recognize. And if that's right, the pattern generalizes in a way that matters a great deal to my profession. Any program is a formal system — my static analyzer, my type checker, the rule engine in the product I maintain. A human looking at any such system from the outside can apparently always derive truths the system itself cannot, which suggests there is a permanent gap between any rule-governed machine and a human, and that this gap can never be closed by making the machine faster or its rules more clever, because the human can always JOOT one level higher. It even suggests that any sufficiently complicated rule system — a legal code, a programming language specification, an org's approval workflow — is guaranteed to contain facts it cannot establish about itself.

Is this argument sound? If it is, does it really have the consequence I'm tempted to draw, that there's a principled ceiling on automated reasoning tools that a human reviewer will always sit above? And if it isn't, I'd especially like to understand exactly which step fails, because I've read that philosophers consider this kind of argument a known trap, and I can't locate the faulty premise.
