Design an in-class decision game where they have to allocate a scarce good (medical treatments, disaster relief slots, organ transplants — whatever works best) under two different decision rules, run back to back on the same set of cases: first a straight majority vote, then a rule where a proposal only passes if no one's individual complaint is severe enough to sink it — each participant secretly rates how bad the outcome is for them personally, and the single worst complaint can block a proposal no matter how many people mildly prefer it. The point is that they should feel the gap between adding up preferences and taking the worst-off complaint seriously, and then run straight into the hard part: when (if ever) do enough tiny complaints start to outweigh the one big one, and where exactly do they draw that line and why.
