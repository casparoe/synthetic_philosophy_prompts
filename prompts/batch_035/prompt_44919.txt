Ok so I'm in my school's programming club and every spring we run a prisoner's dilemma tournament where you write a bot in python and the bots get matched up against each other. This year the seniors changed the rules: before each round, each bot gets to read the other bot's source code, so you can literally check what the other bot will do (or try to). And now there's this huge fight at club about whether this proves Hofstadter's superrationality thing. His argument, as I understand it, is that if two players in a symmetric one-shot prisoner's dilemma are rational and know they're symmetric, they should both cooperate — because whatever reasoning leads one to a conclusion leads the other to the same conclusion, so defecting means knowingly walking into mutual defection, the outcome where you're both worse off. The superrationalists in my club say the code-reading tournament vindicates this: rational bots staring at each other's code is exactly the picture of two agents knowing they'll do the same thing. But my club president says no way, the code-reading case is completely different and doesn't touch the original argument: a bot that cooperates after verifying the other bot cooperates back is just ordinary self-interest, like reading a contract before you sign, no weird "logical symmetry" needed. Superrationality was supposed to work when you CAN'T peek inside the other player's head, and that's exactly what got removed. A third guy says superrationality was never magic in the first place, it's just that similar agents facing the same problem are evidence about each other, so "they'll probably do what I do" is a prediction, not a mystical identity. And then there's a practical mess: even with code reading, if my bot wants to cooperate only if yours will, and yours wants to cooperate only if mine will, don't we get an infinite loop of each bot simulating the other simulating it? Someone said there's a trick using bots that reason about proofs instead of simulating, but honestly I didn't follow it.
