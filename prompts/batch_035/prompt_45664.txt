"The doctrine of double effect was first formulated by Elizabeth Anscombe in the mid-20th century. It says that an action with both a good effect and a bad effect can be permissible if four conditions hold: the action itself must not be wrong, the agent must intend only the good effect, the bad effect must not be the means to the good effect, and there must be proportionality between the two effects. The key distinction is between what you intend and what you merely foresee. In the bystander case, where you divert the trolley from five people onto a track with one person, the one person's death is not intended. The agent doesn't want him dead, and if by some miracle he survived the diversion would still save the five. In fact the agent in the bystander case doesn't really kill the one at all in the relevant sense, he just lets him die, since the trolley was already on its way to killing people and the agent only redirects an exisiting threat. In the footbridge case, by contrast, the agent wants the large man dead (or at least wants to use his body), so the death is intended, which is why the doctrine says footbridge is impermissible while the switch is fine. Notice this means the doctrine's verdicts line up with the act/omission distinction, which is why philosophers like Philippa Foot defended it as a principled alternative to consequentialism.

One objection is the loop case. Imagine the switch track loops back onto the main track, so that if the one person were not on the loop, the five would die anyway. Here diverting saves the five only because the one is on the track, so his death is causally necessary. But most people still think diverting is permissible here, and the doctrine has trouble explaining why, since it looks like the one's death is now part of the means. A possible reply is that the agent in the loop case is simply lucky about the track configuration, and we can say he acts permissibly as long as he would have diverted even if the one weren't there, which shows he doesn't count on the death, so it stays merely foreseen."
