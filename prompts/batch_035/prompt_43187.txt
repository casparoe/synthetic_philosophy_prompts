I keep running into the same wall in arguments about whether AIs or brain emulations could matter morally, and I think the wall is that nobody has actually written down what a theory of this stuff is supposed to DO before arguing about which theory is right. So before I read another paper about it, help me build the spec.

What I want is the desiderata for a theory of which computations matter morally -- that is, a theory that takes some physical system running some computation and tells you whether that computation has moral status, and ideally how much. The requirements list, each with the case that motivates it. Some that seem mandatory to me (but push back if you disagree): it has to survive substrate independence or else bite the bullet on silicon emulations; it has to handle the individuation problem, where one physical system might be implementing zero, one, or many morally-relevant computations depending on how you carve things up; it has to not collapse under the fact that any physical process can be described as implementing almost any finite automaton if you're allowed to choose the mapping cleverly; and it needs to actually be applicable under uncertainty, since we never get to peek at the metaphysics, we only get behavior plus architecture.

Two requirements I especially want you to take seriously and stress-test: (a) that the verdict shouldn't be straightforwardly proportional to hardware duplication -- running the same emulation on N redundant machines shouldn't obviously multiply the moral status N-fold, but I genuinely don't know what blocks that; and (b) that the theory has to say something about partial and fractional implementations, like an emulation running at half fidelity or an animal-scale network that gets the "important" parts right and the rest wrong, because those cases are where the real engineering is going to land.

Please structure it like this:

1. "The list" -- the desiderata, each with the motivating case, this is the bulk, maybe 60% of it
2. "Non-negotiables vs. camp tastes" -- which requirements are load-bearing and which are just one faction's aesthetic dressed up as a demand
3. "Where it breaks" -- if some subset is jointly unsatisfiable, that's the part I most want to see, and I suspect something gives between substrate independence, the anti-mapping requirement, and proportionality-to-duplication
4. "Quick scorecard" -- brief, like a short paragraph each: functionalism, integrated-information-style views, and biological/psychophysical views against the list

Keep it aimed at a theory good enough to guide decisions about systems we can actually build this century, not a theory of everything metaphysically possible.
