I'm marking finals for a third-year course on minds and machines and want a second opinion on one script before I commit to a mark. The question was:

"Lucas argued that Gödel's incompleteness theorem refutes mechanism: no formal system can be an exact model of the human mathematician. Set out the argument sympathetically, explain the 'stronger machine' objection, and assess whether the objection is fatal."

Here's what the student wrote:

"Gödel's incompleteness theorem says that for any consistent formal system F containing enough arithmetic, there is a sentence G_F which is true but unprovable in F. Since G_F says of itself that it is unprovable in F, if F could prove it, F would be inconsistent. And this holds for every system, however strong, so no formal system contains all mathematical truth. Mechanism is the view that the human mathematician is (or is exactly modelled by) some formal system. So take whatever system the mechanist proposes: Lucas can look at its Gödel sentence and see that it is true, whereas the system cannot prove it. So Lucas's mathematical insight outruns any formal system, and mechanism is false.

The stronger-machine objection is that for any F we can build F+, which adds G_F as a new axiom and proves everything F proved, so there is no best machine and Lucas never beats machines in general, only each machine in turn. I think this objection actually fails. The regress works in Lucas's favour: whatever machine you produce, he can top it, so no single machine captures him, which is exactly what mechanism needs to deny. Also, as Lucas himself later conceded, the mechanist's real position may be that some machine models us even though we could never know which one it is. But that is just an appeal to ignorance: not knowing which machine you are doesn't make it any less true that you could see the truth of its Gödel sentence, so the argument goes through regardless."

Give it a mark out of 100 (course convention: 70+ is a first) and, more importantly, the specific comments that justify it — a point-by-point rundown of what they got right and where they went wrong, flagging anything subtle enough that a quick read would let it slide.
