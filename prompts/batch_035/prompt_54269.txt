In a seminar on AI safety we've been discussing embedded agency: the position of an agent that is itself part of the environment it models and acts in — built of the same stuff, caught in the same causal web — rather than standing outside it the way a player stands outside the board. From this, someone assembled an argument that appears to prove far too much, and none of us can locate the damage:

(1) Deliberate action is a matter of choosing the option with the best expected consequences, which requires a model of the environment that ranks the options correctly. (2) If the model were blind to some difference between options that could affect the outcome, its ranking might be an artifact of that blindness; so the model must represent every outcome-affecting difference. (3) For an embedded agent, its own subsequent thought and action belong to the environment, so the outcome-affecting differences include differences in what the agent will go on to think and do. (4) The model must therefore represent the agent's own subsequent thinking, which includes the model itself. (5) A model that represents itself must contain a representation of that representation, and so on, with no fixed point at which the process halts. (6) So no embedded agent can possess a model meeting the requirement in (2). (7) Therefore no embedded agent can act deliberately. (8) Yet we are embedded agents, and I have just acted deliberately in composing this question.

I would like to keep (1), and I cannot accept (7), since I've apparently committed it. Tell me which step to reject, why that step looked unassailable, and what rejecting it costs — including what the agent ends up relying on without being able to verify it.
