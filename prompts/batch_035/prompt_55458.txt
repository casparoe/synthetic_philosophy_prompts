I'm designing a unit on accuracy-first epistemology for a graduate seminar, and I'd like a structured comparison of candidate scoring rules for credences. Consider an agent holding credence p (between 0 and 1) in a single proposition, where the score depends only on p and on whether the proposition turns out to be true or false. Higher scores are better, so the rules below are framed as epistemic utilities. Evaluate these four rules:

1. Quadratic (Brier): -(1-p)^2 if the proposition is true, -p^2 if it is false.
2. Logarithmic: ln(p) if true, ln(1-p) if false.
3. Spherical: p / sqrt(p^2 + (1-p)^2) if true, (1-p) / sqrt(p^2 + (1-p)^2) if false.
4. Absolute error: -(1-p) if true, -p if false.

Rate each rule from 0 to 10 on its suitability as the inaccuracy (or epistemic utility) measure at the heart of the accuracy-first program, taking into account: whether it is strictly proper; how it treats credences at or near the extremes, including whether it assigns infinite disutility to any credence-truth pair; how naturally it supports accuracy-dominance arguments for probabilism; and how transparent its interpretation is as a measure of "closeness to the truth."

In addition to the ratings, please address two specific concerns. First, a colleague has suggested that the choice among strictly proper rules is idle, since any such rule tells an agent to set credence equal to her estimate of the probability, so all of them generate the same recommendations. Is that right, or do differences among the rules (for instance, in how badly they penalize certainty in a falsehood, or in whether the expected-utility and dominance arguments come apart) matter to the accuracy-first project? Second, suppose the agents in question are idealized only up to coarse credences: they can adopt credences in increments of 0.1 but nothing finer. Briefly discuss whether this coarseness threatens the standard propriety-based and dominance-based arguments, and which of the four rules would fare best under that restriction.
