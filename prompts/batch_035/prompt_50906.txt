I'm sure the sentence is doing several different jobs at once, and I want to know which, if any, of them survives scrutiny. For each reading, say whether it's plausible, whether it actually supports going ahead, and whether it instead supports trying to change the situation everyone is responding to — for instance by coordinating with the other actors. Present it as a menu I can bring to the next meeting, flagging the reading that is probably doing the most rhetorical work, and marking clearly any readings under which the sentence is true but the conclusion doesn't follow.
