I've been going down a rabbit hole on the many-worlds interpretation ever since a friend (physics undergrad, very smug about it) told me probability is no problem there because "both outcomes happen, so obviously it's 50/50." The thing I keep running into, and that I want a proper name for, goes like this. When people explain it in the easy case -- equal amplitudes, one world where the particle goes left, one where it goes right -- they say of course you assign 50/50, the branches are symmetric, you've got no reason to prefer one over the other, just count them. But then you ask about an unequal split, 90/10 amplitudes, and suddenly the same people say branch counting is meaningless, because how many worlds there are depends on how finely you carve up the decoherence, the number isn't even well defined -- what matters is squared amplitude, the "measure" or "weight" of the branches. So the rule that produced the answer in the symmetric case (indifference across equally numerous branches) is not the rule they actually use anywhere it matters. The swapped-in rule agrees with the first one exactly in the cases where any rule whatsoever would agree. It's like validating a bathroom scale by testing it on objects where every scale reads the same, then trusting it on the discriminating cases for entirely different reasons and still citing the first test as the validation.
