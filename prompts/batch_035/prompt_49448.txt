I help run a casual philosophy meetup, and for our next session we're doing the "should the numbers count" thing (Taurek, the drowning swimmers, etc.). Here's my problem: everyone in the group already knows the labels they're supposed to like. The utilitarian types say "obviously save the five," but when I poke at why, some of them are summing welfare, some are doing something with claims that I can't quite put my finger on, and one guy is basically a Taurekian who won't admit it because the coin flip sounds insane out loud.

So I want a sorting quiz — "does the number actually count for you, and in which way". Seven questions, each a concrete case with two or three plain answer options, phrased so someone can answer without knowing which theory they're picking. No question can just ask "do the numbers matter?".

The cases have to include: (1) plain five lives vs one life, identical strangers, you can save either side; (2) one death vs many smaller losses — say five people each losing five years of life vs one person dying now — does that trade even go through for you?; (3) the extreme end of that, a huge pile of mild headaches vs a single life; (4) per-group coin flip vs per-person lottery over the six individuals — are chances owed to groups or to each person; (5) the same five-vs-one choice recurring every week forever, does flipping a coin every single week start to look wrong to you; (6) the version where the lone person is your friend; (7) a case where each of the five has an individually weaker claim than the lone person's, so pure numbers and pure claim-strength pull in opposite directions.

Leaves that must show up: the straight utilitarian aggregator; the Scanlon-style view where individual claims only get to combine when they're relevantly comparable, so a life beats any heap of headaches but five lives vs one life is not so simple; Kamm's line that numbers never sum welfare but do break ties between exactly equal claims; Taurek's own numbers-don't-count coin flip; the fractional-claims idea (call it that, we dont need a citation for the meetup) where a claim's force gets diluted when it stands opposed by more competing claims, so the lone person's claim is at full strength while each of the five's is at some fraction — a view that sometimes saves the one; and the per-person egalitarian lottery. Plus at least two genuinely unoccupied cells of the logical space (e.g. numbers counting inversely, always save the fewer), each with one sentence on whether nobody's there because the view is incoherent, unattractive, or just unexplored.

Build it from the logical space first, not the list of names — the questions are really asking (a) does the greater number's survival ever make the outcome better in itself, (b) can claims combine across persons at all, (c) does number have tie-breaker force among equal claims, (d) are chances owed per group or per person, (e) can partiality toward a friend do the work Taurek wanted the coin to do. Then locate the actual positions in that space. And flag honestly any two leaves the quiz can't separate — I suspect the utilitarian and the Scanlon-type agree on almost every case you can realistically write; if so, say so and tell me which question, if any, actually splits them.

Output as a single JSON object, no prose outside it (one "readme" string field at the top is fine). Schema:

{
  "readme": string — one or two sentences on how to administer and score this,
  "questions": [
    {
      "id": "q1" through "q7",
      "case": string — the concrete scenario, no theory jargon,
      "options": [ { "id": "a" | "b" | "c", "text": string — the plain-language choice } ]
    }
  ],
  "leaves": [
    {

      "answer_key": object mapping each question id to the option ids that point at this leaf, or "*" if the question doesn't discriminate for this leaf,
      "awkward_commitment": string — the least intuitive thing this position is stuck with,
      "occupied": true/false
    }
  ],
  "unresolved": [ { "pair": [two leaf names], "why": string } ]
}
