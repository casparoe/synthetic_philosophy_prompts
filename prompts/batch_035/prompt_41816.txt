As I understand it, Löb's theorem says that in any formal system strong enough to reason about its own proofs, if the system can prove "if I can prove P, then P," then the system can already prove P outright. Carried over to agents, this is supposed to create what's called the Löbian obstacle: an agent that is a formal system cannot come to trust a successor version of itself, say a modified copy with greater capabilities, because if the agent could prove that whatever its successor proves is true, it could already prove those things itself, so it can never gain anything by delegating to the successor. From where I sit, this looks like a mathematical proof that recursive self-improvement is impossible: any agent sophisticated enough to modify itself would be sophisticated enough to hit this wall, and no amount of engineering can route around a theorem. Yet people keep working on self-improving AI as though the obstacle were a solvable engineering problem rather than a proven impossibility.
