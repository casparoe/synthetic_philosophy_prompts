The exam question was:

In mechanistic anomaly detection, a monitor is trained only on inputs assumed to be benign and flags inputs on which the network seems to run different internal mechanisms than it does on that benign set. Critics object that this presupposes a criterion for when two inputs engage the same mechanism, which the field does not have. Explain the circularity worry, explain why behavioural similarity between two inputs is not sufficient for mechanistic similarity, and assess the reply that mechanisms can be individuated functionally, by the role they play in the network's overall computation. Use the example of a model with a backdoor trigger to illustrate.

The student's answer reads:

Mechanistic anomaly detection assumes we can tell, from the inside, when a network is doing something new. The monitor is trained on benign inputs only, so whatever notion of sameness it uses is inherited from that training set. The circularity worry is that we need an independent account of what counts as the same mechanism, but the field effectively defines a mechanism as whatever the monitor groups together, so the guarantee that flagged inputs involve different mechanisms is conditional on an assumption rather than a finding. This seems right: the method can establish that an input is unusual relative to benign data, but not that it is processed differently at the level of mechanism.

Behavioural similarity doesn't settle mechanistic similarity because of multiple realizability: the same mechanism can produce many different behaviours, so matching outputs tell us nothing about matching internals. The backdoor case shows this. A trojaned model behaves normally on ordinary inputs and produces ordinary-looking confident classifications on triggered inputs, so from the input-output profile alone there is no way to tell whether the classification came from the legitimate features or the shortcut. Only the internals reveal that the trigger routes through a different circuit.

The functional individuation reply is that we need not individuate mechanisms physically, only by their role in the computation, and roles can be read off from the model's own internal representations: the activations and features the network itself uses. If two computations recruit the same features, they play the same role and are the same mechanism. This is enough for safety purposes: since the trigger's features are not present in benign data, any input using them is functionally an anomaly, and the monitor is guaranteed to catch the backdoor. So the reply succeeds, and the circularity is dissolved rather than merely suppressed.
