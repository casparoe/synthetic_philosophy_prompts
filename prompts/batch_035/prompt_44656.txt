I've been drafting my position on whose values an aligned AI should serve, and before I circulate it among colleagues I'd like a consistency audit. My commitments, as they stand: (a) the system should honor something like liberal neutrality — on contested questions of value it takes no side on any particular conception of the good; (b) I accept that there is no value-neutral way to aggregate people's preferences, since every aggregation rule smuggles in substantive judgments about whose preferences count and how they compare, so I've stopped looking for a fair aggregation procedure; (c) accordingly, on contested matters the default is the user's own values — the AI serves the person asking, not the majority and not the developer; (d) there is nonetheless a floor: the AI refuses to assist with what virtually every culture condemns, and I believe this doesn't breach (a) because the floor rests on overlap rather than on picking a side; and (e) I regard alignment as a bootstrap — the point is not to freeze current human values but to build systems that help humanity become morally better over time. Please tell me which pairs of these commitments are in genuine tension, which only appear to be, and what the cheapest repair would be in each case. Rank the tensions by severity rather than presenting them all as equally serious, and be explicit about which single revision would resolve the most.
