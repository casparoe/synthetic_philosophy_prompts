Ok, background: I'm a software engineer, no formal philosophy training, my exposure to logic is basically boolean short-circuiting plus one semester of discrete math. A coworker of mine (Dave) is really into this stuff — keeps bringing up Graham Priest and "dialetheism," the view that some contradictions are literally true — and last week he walked me through an argument I can't get out of my head.

His argument, as best I can reconstruct it:

(1) Let L be the sentence "L is not true." (A sentence talking about itself.)
(2) Suppose L is true. Then things are as L says, so L is not true. So L is true and L is not true — a contradiction, already.
(3) Suppose instead L is not true. Then things are exactly as L says they are, so L is true. Contradiction from the other side.
(4) There's no third option: "L is neither true nor not true" collapses into (3), because if L is not true, step (3) applies whether L is false or stuck in some gap. Gaps don't save you.
(5) So every consistent story about L fails, and L is both true and not true. A true contradiction. Hence dialetheism.

I followed this and couldn't find a hole. But then I made the mistake of asking him where it stops, and we ran the same template on a different self-referential sentence. Let C be "If C is true, then I owe Dave lunch" (he called it a Curry sentence). Then:

(i) Assume C is true. Then, by what C says, if C is true, I owe Dave lunch.
(ii) C is true (that was the assumption), so I owe Dave lunch.
(iii) So we've shown: if C is true, then I owe Dave lunch. But that's just what C says, so C is true.
(iv) C is true, so I owe Dave lunch.

Same moves as the liar argument — "things are as the sentence says," applied in both directions. Except this one doesn't stop at "huh, a contradiction." It hands Dave lunch, and he was quick to point out the template doesn't care what you put in the consequent. It could just as well be "the prod database should be wiped."

So here's what's bugging me. Either the template is sound, in which case the same reasoning that established dialetheism also establishes arbitrary conclusions (which seems like it proves too much), or the template is unsound, in which case the liar argument for dialetheism is unsound too, since as far as I can tell its the exact same moves. Dave's response is that in his paraconsistent logic the liar argument goes through but the Curry one doesn't, because the conditional in C doesn't behave the way steps (i)–(iv) need. But that looks to me like keeping the plumbing that delivers his conclusion while swapping out the plumbing that would deliver an embarassing one — how can the same self-referential trick be valid when the payload is a contradiction and invalid when the payload is lunch?

Tell me where this actually breaks. Which step do I reject — in the liar chain, in the Curry chain, or is the "same template" claim itself the thing that's wrong? I'd rather keep step (3) of the liar argument than almost anything else — dropping "if L is not true then L is true" looks to me like refusing to hear what "not" means. And be honest with me about whether Dave's move (different logic: liar yes, Curry no) is principled, or whether it's motivated reasoning with extra steps. I don't need reading lists, just the actual reasoning.
