Write a short story on the theme of program equilibrium: the idea that agents in a game can condition their strategies on each other's source code, each simulating or reasoning about the other before acting.

Setting: two rival powers have each delegated the decision of whether to launch a preemptive strike to a formally verified decision program, and under an arms-control treaty both programs' code has been deposited with a neutral registry, so each side can read the other's decision procedure line by line. Before choosing "strike" or "hold," each program is permitted to run the adversary's code in a sandbox — but the treaty caps the compute available to any sandbox run, so no simulation can reach the adversary's final decision; each program can only watch how the other behaves over some truncated horizon, and both sides know that both sides know this.

The complication I want at the center of the story: an auditor discovers that the sandbox each program runs its adversary in is equipped with a deliberately slowed clock, and buried in each program is a routine that detects that slowdown from the inside. So each program, when simulating the other, is simulating a version of the other that believes it is operating under normal conditions — a caricature — and each program knows that the caricature it is watching has, in reality, already detected the deception. The programs must then reason not only about what the other will do, but about what the other can prove about what it can prove about it, under conditions where every model of the opponent is known in advance to be unsound in a specific, symmetric way.

I'd like the story to be told partly from inside the programs, in the register of a proof search: partial lemmas, failed verification attempts, the discovery that a key mutual-cooperation argument fails to compile. The human characters — the auditor, the two treaty commissioners — should carry the parallel political question of whether a peace neither side can verify is more stable than a war neither side can win. End on the actual launch/hold decision, and let the ending turn on something the formal literature on program equilibrium leaves genuinely open: whether trust can emerge from mutual modeling that each side knows, in advance, is unreliable in exactly the same way on both sides. Avoid resolving the question with a technical trick; the ending should feel earned by the characters' reasoning rather than by authorial fiat.
