I'm a PhD student in formal epistemology, and a friend from my forecasting group has produced an argument that the inside/outside view distinction is either vacuous or self-undermining. I've been circling it for a week and can't settle where it goes wrong, if it does.

(1) When a forecast or judgment has a reference class available — a set of past cases judged similar to this one — the outside view (deferring to the class's base rate) should take precedence over the inside view (case-specific causal reasoning). (2) But any actual case belongs to many overlapping reference classes with different base rates: a software project is a project of its kind, a project by this company, a project by this team, a project begun in this market, and each class yields a different outside view. (3) Selecting among these classes is a matter of judging which similarities matter, and that is precisely the kind of case-specific reasoning the outside view was supposed to discipline. (4) So the outside view does not replace the inside view; it relocates it to the choice of reference class, and the resulting forecast is inside-view reasoning wearing a base-rate costume. (5) Since the class choice carries essentially all of the weight — two forecasters can agree on every base rate in existence and still diverge wildly by classing the case differently — nothing epistemically interesting has actually been outsourced to the statistics. (6) Therefore the outside view is either vacuous, because there is no principled way to pick the class and so it imposes no constraint, or self-defeating, because it depends for its application on exactly the kind of reasoning it forbids. Either way, the celebrated distinction collapses.

My friend now claims that reference-class reasoning, and epistemic modesty generally, is just insider thinking laundered through statistics. I don't want to grant that — I've watched outside-view questions genuinely rescue forecasts that insiders were very confident about — but I can't point to the faulty step with any confidence, and I suspect that whatever premise I give up will cost something I care about. Which step do you reject, why did it look fine, and what does rejecting it cost?
