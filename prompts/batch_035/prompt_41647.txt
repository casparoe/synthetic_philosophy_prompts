I hold a fairly strong realist view about neural network interpretability: when researchers use sparse autoencoders to extract a feature that fires on images of the Golden Gate Bridge, or when a linear probe reliably decodes a chess board state from a language model's residual stream, or when activating a particular direction in a network changes its behavior in a coherent, targeted way, these methods are discovering something that is really in the network -- causally efficacious internal representations that the model itself uses to do its job, not artifacts we project onto a mess of matrix multiplications that has no fact of the matter about its own contents. On this view, interpretability is more like neuroscience than like literary criticism: the features are there, awaiting discovery, and our tools have varying sensitivity and specificity for finding them, but discovery is the right metaphor.

What would count against this? I want the defeaters mapped and ranked, from fatal to merely awkward. Some worries I already know about and want assessed honestly: that probing is decoding rather than encoding, so a probe can extract a clean signal the network itself never uses for its output, and nothing about decodability alone shows the model has a representation rather than merely an information-bearing correlation; that features found by one decomposition method fail to replicate across methods, random seeds, or architectures, suggesting we are carving the activation space along whichever joints our tool happens to impose; that steering sometimes produces fluent but shallow behavior, consistent with the direction being a prompt-like input we injected rather than a lever on an internal function; and that whatever representations exist might be so distributed, polysemantic, and entangled that the feature ontology -- discrete, nameable, human-legible units -- is entirely the wrong picture, making realism about some diffuse structure true but realism about interpretable features false. For each, tell me whether it undermines realism itself or only some particular method or ontology, what a committed realist would concede as a genuine hit versus dismiss as bad experimental hygiene, and what observations would genuinely discriminate realism from a deflationist view on which interpretability artifacts are useful fictions that happen to steer behavior. Finally: has the realist position been qualified into unfalsifiability -- for instance by retreating from legible features to whatever structure turns out to be there -- and if so, is that a problem for a claim of this kind, or just the ordinary maturation of a research program?
