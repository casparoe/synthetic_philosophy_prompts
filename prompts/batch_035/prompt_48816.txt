I do interpretability work on language models, and a question keeps coming up that I can currently answer only by gut: when are two things a model does instances of the same mechanism? This matters practically, because we would like to build anomaly detectors that flag dangerous behavior precisely by recognizing that it is produced by a mechanism unlike the ones the model normally uses — so "same mechanism" is doing real work, and I suspect my gut verdicts do not add up to a coherent notion. Here they are.

When a model continues a repeated sequence (A B C A B C → A) in English and in French, using the same induction heads in both cases: same mechanism, clearly. When two small networks trained from different random seeds on modular arithmetic both turn out to compute their answers with trigonometric components — no shared weights whatsoever, but the same algorithm: still the same mechanism, I'd say, so mechanism cannot mean a particular set of parameters. But when a single attention head performs induction in some contexts and some kind of role-binding in others — literally the same weights doing two jobs — I count that as two mechanisms, so it cannot mean the substrate either. When safety fine-tuning leaves a model's refusals behaviorally indistinguishable, but ablation studies show the refusal no longer runs through the same features: different mechanism, so it cannot be behavior alone. And here is the pair I cannot reconcile. A model that produces honest text except for a small added component that flips certain specific claims: I want to say that is a new mechanism — the tiny delta is exactly what a detector must catch. But a model lightly fine-tuned so that an existing feature fires somewhat more strongly, shifting its tone without any new circuitry: same mechanism, merely retuned. Both are small changes to a mostly shared computation, and I treat them oppositely.

Is there a principle, or a small set of candidate principles, that captures all of these — some notion on which a mechanism is neither the weights, nor the behavior, nor the activations, but something that can be shared across separately trained models, split within a single head, and either created or merely altered by fine-tuning? State it as precisely as you can, tell me which of my verdicts it cannot save, and tell me what it says about the case I keep going back and forth on: a backdoored model whose trigger circuit computes nothing new but instead reuses the model's ordinary in-context learning machinery, pointed at a different target. If the principle classifies that as an old mechanism, the detector will not flag it; if as a new one, then recombination alone apparently suffices to create a mechanism. I would also like its verdict on a case I have not listed.
