In a seminar on divine attributes we keep circling the stone paradox: if a being is omnipotent, can it create a stone so heavy that it cannot lift it? Three analogies are doing all the work in our discussions, and they pull in opposite directions. One participant treats the puzzle as the liar paradox in theological dress — the stone task refers back to the being's own powers in the way the sentence this sentence is false refers to itself, and self-reference of that kind can presumably be dissolved once exposed. Our tutor instead likens it to Russell's barber or the set of all sets: an unrestricted totality that turns out incoherent, which suggests that omnipotence, so defined, is genuinely inconsistent and needs restriction rather than rescue. A third voice deflates the whole thing by comparing the stone task to drawing a square circle: a self-contradictory task is not a task at all, so inability to perform it is no limitation on power. Please audit the three analogies. Set out what maps onto what in each case — what plays the role of the self-referential item, the inconsistent totality, the impossible task — then say where each mapping breaks down. In particular, is the stone task a piece of self-reference (in which case the liar comparison carries), an instance of unrestricted totality (in which case the barber comparison carries), or just a logically incoherent description (in which case the square-circle comparison carries)? Finally, assess which of the three conclusions, if any, survives its disanalogies: that the paradox exposes a mere confusion, that omnipotence must be redefined, or that it poses no threat at all. If none survives, sketch what a better analogy for the stone question would look like.
