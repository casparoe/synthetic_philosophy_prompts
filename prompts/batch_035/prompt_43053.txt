For my seminar on paradoxes in decision theory, I have to run next week's discussion section on the Pasadena game, and I would like to hand out a decision tree that sorts my classmates into positions on it. The starting point everyone shares is classical expected utility theory for finite games together with the standard treatment of the St. Petersburg game; the tree should carry a classmate from that starting point to a definite view on how decision theory should treat options whose expected value is undefined, as with the Pasadena game (a coin is flipped until it first lands heads, and the payoffs grow without bound while alternating in sign, so that the expectation is a conditionally convergent series which can be rearranged to sum to anything whatsoever).

Please build the tree from the logical space rather than from a list of positions: first settle the branch questions and the combinations of answers they permit, and only then locate the actual named views as leaves. Every branch question must be answerable by someone who has done the St. Petersburg reading but nothing else — a question about intuitions on cases, not about labels. In particular, the tree should incorporate at least the following questions somewhere:

1. Does undefined expected value mean the option has no value the agent should care about, or that it has a value which the expectation calculus simply fails to track?
2. A comparison we discussed in seminar under the name Altadena: a game exactly like Pasadena except that every single outcome pays a dollar more. Whichever way you value Pasadena (including valuing it not at all), is Altadena still strictly better, and what does each answer commit you to?
3. Can the value of a single play depend on what would happen over many independent plays — for instance, does the fact that average payoffs over repetitions converge in some weaker sense license a valuation of the single play?
4. Is revising utility theory so that utilities must be bounded an acceptable cost, no cost at all, or a cure worse than the disease?
5. Should attitudes to risk play an independent role in evaluating a gamble, over and above its expectation?
6. Is the question of what the Pasadena game is worth well-posed only relative to some benchmark or menu of alternatives?

The leaves should include at least the view that decision theory has no answer here and that this is a genuine open wound; the view that the game's value is fixed by a weaker convergence notion; the view that the decision problem is ill-posed until reformulated comparatively; the view that gambles should be evaluated risk-weighted rather than by expectation; and the view that unbounded utilities were the mistake all along. Where a leaf has a standard proponent in the literature, attach the name; where a combination your tree permits has no occupant, say so and briefly diagnose whether nobody is there because the view is incoherent, unattractive, or merely unexplored. Please also flag any pair of leaves the tree cannot genuinely separate — positions that receive the same answer at every branch — rather than papering over the failure. Aim for roughly six branch questions and eight to ten leaves, including at least two unoccupied combinations.
