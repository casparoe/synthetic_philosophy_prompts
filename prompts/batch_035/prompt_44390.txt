The question:

"Consider the following game, a tidied-up version of the Pasadena game discussed by Nover and Hájek. A fair coin is flipped until it first lands heads. If the first heads comes on toss n, the game pays you (−1)^(n+1) · (2^n / n) dollars — so on toss 1 you win $2, on toss 2 you lose $2, on toss 3 you win $8/3 ≈ $2.67, on toss 4 you lose $4, and so on, with payoffs growing in magnitude but alternating in sign.

(a) Write down the expected value of this game as a series, and say whether it converges.
(b) Explain why this game creates a problem for decision theory that the St. Petersburg game does not.
(c) Now consider the 'Altadena game': exactly the same, except every payoff is exactly $1 higher. What should a rational agent prefer between the two games, and why is this awkward for expected value theory?"

And the student's answer:

"(a) The probability that the first heads comes on toss n is 2^−n, so the expected value is the series

EV = Σ (−1)^(n+1) · (2^n/n) · 2^−n = Σ (−1)^(n+1)/n = 1 − 1/2 + 1/3 − 1/4 + ...

This is the alternating harmonic series, which converges, to ln 2 ≈ $0.69. It converges absolutely, since the terms 1/n shrink toward zero, so the sum is well-defined and the expectation exists.

(b) In the St. Petersburg game the corresponding series is just 1 + 1 + 1 + ..., which diverges to infinity, so its expectation doesn't exist. But in the Pasadena game the partial sums oscillate less and less and settle down on a definite value, so the Pasadena game is actually less of a problem than St. Petersburg: since the series converges to ln 2, the expectation just is ln 2, and a rational agent should value the game at about 69 cents. The 'paradox' here is mostly psychological — people are surprised that a game with such large possible payoffs has a tiny value, much as they are surprised by St. Petersburg, but once you do the math there's no deep issue.

(c) The Altadena game pays strictly more in every possible outcome, so by dominance any rational agent should prefer Altadena to Pasadena. And there's no real tension with expected value theory: adding $1 to each outcome adds Σ 2^−n = 1 to the expectation, so Altadena's expected value is ln 2 + 1, which is bigger than ln 2, and expected value theory tells you to prefer Altadena for the same reason dominance does. The two principles agree, so the case is actually a nice confirmation that the machinery works."
