At my school's math club last week, a senior presented an argument about the St. Petersburg game that I have not been able to stop thinking about, because if it works it seems to wreck expected value theory entirely, and I do not believe a theory that has guided two centuries of decision analysis can be wrecked by a trick involving a bonus prize. For completeness, the setup: a fair coin is flipped until it lands heads, and if the first heads arrives on flip n, the game pays 2 to the power n dollars. The expected value is one half times two, plus one quarter times four, plus one eighth times eight, and so on, which is one plus one plus one forever, and therefore infinite. His argument runs as follows. First, a rational agent chooses whichever option has the higher expected value and is indifferent between options with equal expected value. Second, the St. Petersburg game has infinite expected value, so a rational agent should be willing to pay any finite entry fee to play it, since every finite fee is smaller than infinity. Third, and here is where the trouble starts, suppose the casino offers, for the same price, a choice between two games: Game A is the ordinary St. Petersburg game, while Game B uses the same coin and the same stopping rule but pays a hundred dollars more on every outcome, so that if the first heads arrives on flip n, Game B pays 2 to the power n plus a hundred. Fourth, on every possible sequence of flips, Game B pays strictly more than Game A; there is no possible world in which A does better. Fifth, both games have infinite expected value, so by the opening principle a rational agent is indifferent between them. Sixth, indifference between a given payoff and that same payoff plus a hundred dollars, in every possible case without exception, cannot be rationality; even an agent who cares about nothing but money must prefer B. Therefore the opening principle is false, and since he adds that any gamble with an unbounded maximum payout has an infinite or undefined expectation, and since nearly every real choice could in principle carry an unbounded payoff, he concludes that expected value theory never tells us anything at all: it is not merely silent about exotic casino games but empty everywhere, which would explain, he says, why no one at math club would pay even fifty dollars to play a game supposedly worth infinity. He is convinced this is a refutation of the theory. My own suspicion is that something slips in the neighborhood of the fifth and sixth steps, because I notice the opening principle sounded entirely reasonable when we applied it to finite cases in class, and only became strange once the expectations were infinite, which makes me wonder whether we were ever entitled to carry it over, or whether equal infinities simply do not carry the comparative information that equal finite numbers do. If I have to choose, I would rather keep the dominance step, that B must be preferred to A, than the indifference clause, since dominance between options that never lose and sometimes win seems like the most secure principle in the whole theory, while indifference toward a strictly dominated option seems like the least rational attitude anyone could hold. Please tell me which step I should reject, explain why that step nevertheless looked fine, and set out what rejecting it costs, including what the theory can still say, if anything, about choices between games with infinite expectations.
