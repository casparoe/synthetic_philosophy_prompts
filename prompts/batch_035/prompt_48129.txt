I do interpretability research and have drifted, almost without noticing, into a fairly strong realist view about neural network representations: that when we find a "French-token detector," a "sycophancy direction," or a circuit that implements induction heads, we are usually discovering something that is genuinely there — a feature with stable identity across contexts and training runs, that would show up in any adequate description of the model, and that has the model's behavior depending on it in a robust way rather than an artifact of whichever basis or probe we happened to impose. Part of what pushed me here is that superposition seems to explain otherwise baffling polysemanticity — neurons mixing unrelated concepts because there are more features than neurons — and part is that we can often causally intervene on a feature and get the predicted behavioral effect, which feels like more than projection. I'd like to think the view is empirically exposed rather than a framework I've adopted, but I've never actually sat down and mapped it.

So tell me what would count against it. I can think of a few candidate defeaters myself and want them assessed alongside any I've missed: the fact that an arbitrary rotation of the weight matrices leaves the network's input-output behavior completely unchanged, which suggests the activation basis we probe has no privileged status until we pick one; the way sparse-autoencoder features "split" into finer features as dictionary size grows, with the granularity apparently set by our sparsity penalty rather than by the network; the results people call the "interpretability illusion," where individual units that look cleanly interpretable turn out to be tracking dataset artifacts once you look at their behavior on broader input distributions; and the fact that causal interventions sometimes succeed for directions that plainly aren't natural, since almost any sufficiently large perturbation to a network changes behavior. I want these ranked from fatal to merely awkward, plus the ones that committed feature realists would themselves concede as pressure rather than dismissing — including the possibility that universality claims (the same features recurring across models) quietly fail to replicate, which I gather has been happening. And please address head-on whether the view has been insulated: I've caught myself retreating from "the network's basis contains the features" to "the features are there in some basis, somewhere in the activation space," which starts to look unfalsifiable. If it has been insulated, I want to know whether that is fatal for this kind of view, or whether it's acceptable given that what I actually care about — features that reliably predict and control behavior — survives the retreat.
