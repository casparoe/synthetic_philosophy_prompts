I help run a reading group for second-year cognitive science students, and our next session is on whether split-brain patients are one subject of experience or two. Rather than me lecturing at them, I want a decision tree they can walk through themselves. Please deliver it as JSON.

The shared starting point everyone accepts: after the corpus callosum is severed, each hemisphere only recieves information from the opposite side of the body and visual field, and in the lab you can show the two hemispheres things the other one never sees. Every node after that should be a question a student can answer from their intuitions about concrete cases, without having to know any position's name in advance. Work these three cases into the nodes somewhere: (a) intermanual conflict, where one hand does up a button while the other undoes it; (b) lateralised presentation, where a word or picture is flashed to just one visual field and the patient can only report or act on it with the same side of the body; and (c) the boring fact that outside the lab these patients get along fine — walking, chatting, seeming like a single person going about their day.

The carving I want, and where I think the popular discussions cheat: the tree's early branches should force students to separate three notions of "unity" that get run together — whether the experiences are jointly had (co-consciousness), whether there is a single subject that has them, and whether there is a single agent controlling what the body does. Only after a student has answered these separately should the tree place them at a leaf. Include at least one node about the disavowal cases: when the patient's voice says it doesn't know why the left hand did that, does that show the hand's action isn't the patient's action, or only that the speaking half wasn't aware of it?

Leaves I'd like to see: a memory/psychological-continuity style position, a two-separate-streams position, a one-subject-with-partial-unity position, a single-agent-divided-control position, and an "unnamed" leaf for any coherent combination nobody seems to occupy, with one sentence diagnosing why nobody's there (incoherent, unattractive, or just unexplored). Also flag any pair of leaves your questions can't actually pull apart rather than pretending the tree seperates them.

Schema, please stick to it:

{ "start": "<node id>", "nodes": [ { "id": string, "question": string, "answers": [ { "label": string, "next": string } ] } ], "leaves": [ { "id": string, "positionName": string, "summary": string, "awkwardCommitment": string, "cantSeparateFrom": [string] } ], "unoccupied": [ { "path": string, "diagnosis": "incoherent" | "unattractive" | "unexplored", "why": string } ] }

No citations or reading lists, describe positions rather than name-dropping authors, and answer in American English please.
