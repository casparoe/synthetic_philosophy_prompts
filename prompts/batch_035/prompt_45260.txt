I am a graduate student in philosophy with a background in computer science, applying for a one-semester departmental research grant. I need a proposal of roughly 800 words for a term-paper-length project (about 6000 words) on program equilibrium in the one-shot Prisoner's Dilemma. The proposal is to be written as continuous prose only, with no headings, bullet points, bold text, or tables — the way one would write a long, careful email to a supervisor — and in American English. Refer to ideas and constructions by describing them; do not cite anyone, since I will add references myself later.

The setting, so you can gauge how much needs explaining: two agents play a one-shot Prisoner's Dilemma, but instead of choosing cooperate or defect directly, each submits a program that reads the other program's source code and outputs a move, and the programs are then run against each other. It is known in this setting that mutual cooperation is achievable through constructions such as a program that cooperates if and only if it verifies that the other program cooperates against it, or one that cooperates with exactly those programs it can prove, in some fixed formal system, cooperate with it — a cousin of Löb's theorem.

My half-formed idea, which I want you to turn into a proper proposal: discussions of this result seem to slide among three readings of it, and I want the proposal to make that slide the object of study. On one reading, the transparency changes the game itself: once each player can condition on the other's code, the payoff-relevant structure is no longer that of a Prisoner's Dilemma, so the cooperation result is a fact about a different game and says nothing about rationality in the ordinary one. On a second reading, mutual code access is just a commitment device, so the result repackages what binding contracts or repeated interaction already achieve. On a third reading, the result is a discovery about solution concepts: mutual cooperation of the prove-it-first kind is an equilibrium of the induced game, but so are various asymmetric and exploitative profiles, and the interesting question is which equilibrium notion, if any, makes cooperation the uniquely rational outcome.

The proposal should state a precise version of my question — something like: under exactly what conditions does mutual source-code access make mutual cooperation the unique rational outcome of a one-shot Prisoner's Dilemma, and are those conditions best modeled as a change in the game, an added commitment technology, or a revision of the solution concept? It should then explain why the three readings are not merely notational variants of one another; set out what I would actually do over the semester, including at least one test case designed to separate the readings (I have in mind cases of asymmetric transparency, where only one agent's code is readable, or pairs of agents whose formal systems differ in proof strength); say what a positive result would look like; and say what would make the project fail — in particular whether it might collapse into the theory of repeated games in new notation. Please also be honest about scope: if 6000 words is not enough for the project as framed, say what I would cut or which of the three readings I would set aside.
