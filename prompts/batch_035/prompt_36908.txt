I run a small blog about AI and want a "what do you actually think a chatbot is?" decision tree. The starting point is: you're having a conversation with an LLM assistant. Branch nodes should be questions a reader can answer without knowing where the answer leads -- things like "if nobody were prompting it, would it still do anything?", "does it make sense to ask what it wants when no user has given it a goal?", "if the chat log got deleted, does the thing you were talking to still exist?". The leaves should be named positions: the base-model simulator view (it's just completing text, and the personality is an artifact), the persona view (you're talking to a character the model plays, like an improv actor), the trained-agent view (fine-tuning turned it into an actual agent with something like values of its own), the tool view (asking what it "really is" is like asking what a spreadsheet really is), and the deflationary "no fact of the matter" option. Please also flag pairs of leaves the tree can't seperate -- my hunch is the trained-agent and persona views can't be pulled apart by yes/no questions alone, but I'd like to hear if you agree or if you think some question splits them. Around 6-8 questions total, aimed at readers who use chatbots but have never read anything technical.
