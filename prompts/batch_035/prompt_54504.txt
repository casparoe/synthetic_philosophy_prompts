After a career in experimental condensed-matter physics, I have lately been reading philosophy of probability, and I have become quietly preoccupied with the reference class problem: when I want the probability of some particular event, which population of broadly similar cases should I treat that single event as belonging to? During my working life I grew accustomed to the fact that in statistical mechanics the choice of ensemble is fixed by the constraints one has actually isolated — which quantities are conserved decides which ensemble one is entitled to use — and I have begun to suspect that the reference class problem is a less tidy version of the very same difficulty. The properties I choose to match on play the role of the conserved quantities, and every property I quietly coarse-grain away is a wager that the discarded variables are irrelevant to the frequencies I care about.

To help me organize my thinking on this, please rank the following five approaches to the reference class problem from most to least promising, assigning each a score from 0 to 10 reflecting how far you think it goes toward a genuine solution rather than a practical workaround, and add a sentence or two explaining why each lands where it does:

1. Reichenbach's rule: for a single case, use the narrowest reference class for which one possesses reasonably reliable statistics.
2. The subjective Bayesian dissolution: there is no fact of the matter about the reference class, since probabilities are credences; the problem reappears as ordinary modeling uncertainty and is absorbed into priors over the rival models.
3. Single-case propensity views: the chance of the individual event is fixed by the physical setup itself, so the correct reference class is simply the class of cases sharing the causally relevant generating conditions.
4. The best-system approach in the spirit of Lewis: chances are just the probabilities that appear in the simplest and strongest systematization of the totality of regularities, so the reference class question is answered by whichever groupings the winning system turns out to employ.
5. Hempel's requirement of maximal specificity: an inductive-statistical inference is legitimate only relative to a reference class that is maximally specific relative to our total evidence — an approach that, as I understand it, largely relocates the problem rather than resolving it.

Finally, I would value your candid assessment of whether my ensemble analogy earns its keep. Is the physicist's practice of letting the physically conserved quantities dictate the ensemble a legitimate model for how reference classes ought to be chosen, or does it smuggle in an objectivity about which similarities are relevant that the philosophical problem precisely calls into question?
