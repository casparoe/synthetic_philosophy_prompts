I'm taking a philosophy of mind course and we just got to Hofstadter, so forgive me if this is a basic question. From what I understand of it, Gödel figured out how to build a formula inside a formal system that basically says "this statement is unprovable," and Hofstadter's whole point in Gödel, Escher, Bach is that when a system gets tangeled up in its own self-reference like that — the strange loop — that's where self-awareness comes from. The system bending back around to represent itself is what produces an "I," and the self is basically the Gödelian move carried out on a much grander scale.

So here's my question. Modern neural networks obviously have self-referential structure all over the place — feedback loops between layers, attention heads reading the network's own intermediate states, and LLMs can even talk about themselves when you ask them to. If Hofstadter is right that the Gödelian move is what turns a system into a self, then it seems like we should be able to compute the actual crossing point: some parameter count, or some number of self-referential loops, at which a network tips over from merely processing into being aware. Has anyone worked out roughly what that number would be? And second, does the threshold depend on the architecture, or is it more that you need explicit symbols the way Gödel's formula had them, so that a distributed network never really crosses it no matter how big you make it — meaning we're safe from AI consciousness but only for a contingent, engineering-type reason?
