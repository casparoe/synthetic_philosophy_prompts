My term paper defended dialetheism about the semantic paradoxes, roughly along these lines: the Liar argument employs only the truth schema (a sentence is true if and only if what it says obtains) and elementary reasoning; since neither can plausibly be given up, we should accept that the Liar sentence is both true and not true; classical logic's explosion principle is what has to go, and a paraconsistent logic contains the damage. My examiner returned the paper with an argument he says proves too much, and I cannot find the flaw.

(1) Any adequate theory of truth must validate every instance of the truth schema; a theory that declares some instance false has stopped theorizing about truth. (2) Let K be a sentence that says of itself: if K is true, then every sentence is true. (3) By the truth schema, K is true if and only if (if K is true, every sentence is true). (4) Suppose K is true. Then it is true that if K is true, every sentence is true, and since K is true, modus ponens delivers that every sentence is true. (5) So if K is true, then every sentence is true — but that is precisely what K says, so K is true. (6) Since K is true, and if K is true every sentence is true, every sentence is true.

His point is that this argument never derives a contradiction, so the paraconsistent maneuver I used against the Liar is useless here: rejecting explosion saves nothing, because explosion is never invoked. The very commitments that made me a dialetheist about the Liar appear to make me a trivialist about everything. I would most like to keep (1), since avoiding the cost of restricting the truth schema was supposed to be the main advantage of my position. Which step should I give up, and what does giving it up cost me?
