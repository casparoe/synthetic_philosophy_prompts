(b) In class we stipulated the Tail Rule for comparing infinite worlds: ignore any finite initial segment and ask whether, past some point, world A's running total of welfare stays permanently ahead of world B's; if so, A is better, and if the running totals keep crossing or stay equal forever, the worlds tie. "(a) Since both worlds have infinite total welfare, the totals are equal, and equal plus finite is still equal — the utilities are literally the same number, so no act involving finitely many people can make a difference to the ranking. This is the infinite paralysis result: consequentialism can't distinguish any two actions that differ only finitely.

(b)(i) Under the Tail Rule the helped world is better. Throw away the first million years and the running total is still infinite ahead... actually it's ahead by exactly the help we gave, and since the totals never cross again, the helped world stays permanently ahead. So the rule does capture the intuition that helping matters. (ii) Here the two worlds are tied, because each extra unit gets swallowed by the infinity — infinities cancel out, and the running totals keep crossing forever, so the Tail Rule says a tie. This shows the rule only fixes the finite case.

(c) The Tail Rule therefore solves the problem as stated, since it ranks (b)(i) correctly, and I don't think we should object that it also makes worlds indifferent about a single torture, since that's just the finite case again and the rule handles the finite case right. Discounting works too: once you discount the future, the infinite series always converges to a finite total, so comparisons come out fine and the paralysis disappears. Overall both escapes succeed."
