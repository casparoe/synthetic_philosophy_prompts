I teach a graduate seminar on AI alignment and am preparing a handout on the shutdown problem — the observation that a sufficiently capable goal-directed agent has instrumental reasons to resist being switched off or corrected, and that naive fixes (programming it to want shutdown) tend to create perverse incentives, such as an agent that causes the button to be pressed. I would like a decision tree that starts from a commitment any student in the seminar could hold without knowing the literature — roughly, "we need the agent to allow shutdown and correction, and we need to achieve that somehow" — and terminates in a named position on how corrigibility should be secured, or in the conclusion that it cannot be secured by design at all.

Please build the tree from the logical space rather than from a list of authors, but the following positions should appear as leaves: the utility-indifference family, where the agent's objective is patched so that it is compensated for being shut down and thus has no incentive either way; the corrigibility-by-construction family, where the agent is built to positively want to be modified and corrected, including across self-modification and the creation of subagents; the assistance-game family, where the agent is uncertain about the human's values and treats the button press as evidence about those values; the safe-interruptibility family, where interruption is folded into the learning process so that it does not distort what the agent learns; the low-impact or conservative-agency family, where the agent limits the effects of its actions on the world rather than addressing shutdown specifically; myopic or short-horizon designs that avoid the problem by making the agent not care about the future in which resistance would pay; behavioral or engineering-level approaches that aim for observable compliance with shutdown commands without claiming anything about the agent's underlying motivation; and the pessimist leaf, on which no motivational design solves the problem and only institutional control matters.

I have a view about the first split that I would like you to use unless you think it is a mistake, in which case say so: the first node should ask whether the agent's disposition to shut down is secured by shaping what it maximizes, by what it is uncertain about, by what it is able to affect, or by nothing in the agent itself at all. Later nodes I leave to you, but they should be answerable by someone who has never heard the labels — for example, a node asking what the agent takes the button press to be (an instruction, evidence about the human's values, or noise), a node asking who wins when the agent and the operator disagree about whether shutdown serves the human's interests, and a node asking whether the disposition survives the agent's own self-improvement or its construction of subagents. At least one node should be a concrete case: the agent foresees that shutdown is imminent and could lock the laboratory door, and must decide.

Two requirements beyond the tree itself. First, flag honestly which pairs of leaves the tree cannot really separate — I expect utility indifference and corrigibility-by-construction to look behaviorally identical in many of my cases, and I want the handout to say so rather than imply a crisp division. Second, note the unoccupied combinations in the space: for instance, an agent that wants shutdown regardless of human choice, or one that is indifferent to shutdown but actively manipulates the human about everything else. For each unoccupied cell, say briefly whether you think nobody is there because the position is incoherent, because it is unattractive, or simply because it is unexplored. Where a concern cuts across the whole tree rather than sitting at one node — my candidate is the worry that corrigibility is unstable under reflection, that a sufficiently capable agent would eventually self-modify away its own willingness to be corrected — decide whether it belongs as a node, as a leaf, or as a standing caveat, and justify your choice. The tree should have roughly six to eight branch questions and eight to ten leaves, and it should be usable by a student who has never heard of any of the authors involved.
