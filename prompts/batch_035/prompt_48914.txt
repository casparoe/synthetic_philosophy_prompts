I've been reading a pop-math book on famous crises in mathematics (the kind with cartoons of Cantor looking tormented), and its chapter on set theory boils Russell's paradox down to this: "Russell found a set that neither contains itself nor doesn't -- the set of all sets that are not members of themselves. Since assuming it's a member of itself immediately gives you the opposite, and vice versa, this was a genuine contradiction derived from logic itself, and it meant that the set theory everyone had been using, and the logicist dream of grounding all of math in it, was dead on arrival. The fix mathematicians settled on was type theory: sets are arranged in levels, and a set can only have members from the level below, so no set can contain itself, and the paradoxical set can never be formed. You can see the same thing happening in the everyday barber paradox: a barber shaves all and only the men who don't shave themselves, so he must shave himself iff he doesn't. The moral is that when a collection is defined too broadly, it simply doesn't exist, which is why there's no such thing as the set of everything."
