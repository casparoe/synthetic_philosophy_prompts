I'm TA-ing a philosophy of biology course this semester, and I've been put in charge of the section on biological function. I want to open with a "which account of function do you actually hold?" quiz the students take before doing any of the reading, so the point is that it sorts them by how they react to concrete cases, not by which label they've heard. My plan is roughly ten questions, each a case with two or three answer options, plus a scoring key mapping answer patterns onto the selected-effect/etiological account, the causal-role account, and any hybrid or pluralist positions you think the case set generates. If some pair of positions genuinely can't be separated by the cases, I'd rather you flag that than paper over it, and I'd like the key to also note the cases where the standard accounts agree, since those are the non-discriminating ones.

The cases I want in there (add others if you like, but these should appear): (1) the human appendix, which does basically nothing now but presumably did something when it evolved; (2) feathers, on the assumption that they originally aided thermoregulation and only much later became useful for flight; (3) a fresh mutation that improves an animal's digestion but hasn't yet had any effect on survival or reproduction — does the trait have a function yet; (4) a heart with a severe arrhythmia that's failing at pumping blood — does it still have the function of circulating blood; (5) some artifact case where a thing gets used for something it wasn't made for, like a tire iron repurposed to prop open a hatchback; and (6) the ability to read in literate humans, which presumably wasn't directly selected for as reading.

One hard requirement: no question may just ask "do you think function is about why a trait evolved versus what it does now" — the students should find out what they think about that only after seeing their answers. So every option has to be phrased as a claim about the case ("the function is flight", "the function is thermoregulation", "it has no function at all", "it has both"), never as an endorsement of a theory, and nothing in the questions should give the game away. Also please have each scored option feed into a single axis where possible, and for any answer combination that doesn't correspond to a position anyone actually holds, describe what it amounts to instead of forcing it into one of the buckets. My section meets on thursday, so a version I could print as a one-pager would be ideal.
