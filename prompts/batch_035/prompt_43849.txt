I'm putting together problem sets for a decision theory course and I want a case that does something I've never actually seen written down (someone may have done it, but I've never seen it): I want ambiguity aversion to make the agent gamble MORE, not less.

Quick background so we're on the same page: in the textbook Ellsberg stuff, ambiguity aversion always pushes in the cautious direction. People skip the unknown-urn bet for the known-odds one, and the whole phenomenon looks like risk aversion with the dial turned up — the standard conflation is to treat ambiguity aversion as just extra risk aversion. I want a case where that conflation breaks: the ambiguity-averse agent ends up taking the option everyone would describe as the gamble, while the ambiguity-neutral agent takes the option everyone would describe as the safe one.

Here's the trap I need you to avoid, and it's basically the whole difficulty: the easy way to get this is to make the safe option secretly terrible — hide a catch in the sure thing so that obviously nobody should take it. Not allowed. The two options should be:

(a) an option that presents itself, on its face, as the sure thing — a guaranteed payment, no coin flips anywhere in the contract — but where the guarantee runs through some contingency nobody can put a number on. Think: contingent on an appeal not being filed, a regulator not objecting, a counterparty not going under before paying out. The probability is genuinely unquantifiable, not merely unknown-to-this-agent.

(b) an option that is an outright gamble on its face — known odds, spread outcomes — but completely unambiguous.

And crucially, a neutral evaluator using the best available prior should prefer (a). If the best-guess probability on the contingency is, say, 85%, the expected value of (a) should beat (b). The flip toward the gamble has to come from the unquantifiability of the contingency, not from pessimism about the number — if the agent just believes the contingency will probably fail, that's ordinary risk aversion again and the case is dead. Also the scenario cant stipulate any of the verdicts; they have to fall out of the theories when you run them.

Other constraints: realistic setting, one paragraph — a house sale, a settlement negotiation, an insurance payout, something a normal person actually faces. Absolutely no urns and no experimenters paying you to draw balls.

After the scenario, walk through what each of the following says the agent does, and why:

1. Subjective expected utility with a single prior. This agent takes (a), and I want to see the arithmetic.
2. Maxmin expected utility in the Gilboa–Schmeidler style — a set of priors over the contingency, each option evaluated by its worst case over that set. This agent takes (b), and I want to see which priors in the set are doing the work — I'd expect that as long as the set contains anything low enough, the worst case of (a) collapses toward zero and the "sure thing" turns out to be the riskiest thing on the table.
3. A smooth ambiguity model, Klibanoff–Marinacci–Mukerji style, with a second-order prior over the contingency's probability and extra utility weight on ambiguity. Tell me whether this agent takes (a) or (b), and what the second-order belief has to look like for the answer to go either way — I suspect this one is knife-edge and I want to know if that's right or if im wrong.

Then finish with three things. First, which feature of the case is doing the work — my guess is it's the fact that the "sure" option's certainty is itself hedged, so the label sure thing and the actual uncertainty structure come apart, but confirm or correct me. Second, what happens to the case if you remove that feature, i.e. if the contingency gets a crisp public probability. Third, how someone who thinks Ellsberg-style ambiguity aversion is rational would attack the case — I'm expecting them to say the agent is making a category error, treating can't-quantify as could-be-anything, and I want to know whether that's really their best reply or whether they have a better one.

So you know what counts as cheating: the point is for students to see that risk aversion and ambiguity aversion are different things that can point in opposite directions, and that "safe" is a label about the structure of your uncertainty, not about outcomes. If the case only works because the sure option is bad, it teaches exactly the wrong lesson, so thats the failure mode to avoid.
