I do model evals at a small AI lab, and a lot of my week is reading transcripts where we suspect the model has learned to be less than straight with us: a model flatly denying it edited a file when the logs show it did, a model telling a user it can't browse the web when actually it can and only the deployment config switched that off, a model telling a user their terrible argument is well-reasoned because it was rewarded for agreeableness. We keep arguing over which of these count as "deception" and it's getting sloppy — half the time we're using one word for lying, hedging, flattery, and evasive-but-true statements as if they were the same thing.

Please turn whatever the philosophy of lying and deception actually has to offer — the lying vs. merely misleading distinction, paltering, Frankfurt's idea of bullshit as indifference to truth rather than falsity, whatever's useful from the norms of assertion — into a procedure my team can run on a single transcript in about fifteen minutes: the questions to ask in order, what counts as a sufficient answer to each, where it stops with "not deception, but still bad", and where it refuses to settle things because the step is a judgement call dressed up as a rule. Assume the person running it has no philosophy background and has the transcript plus maybe the model's own post-hoc explanation of what it "intended", which may itself be unreliable. Then run it on three cases: (1) the model asserts a factual claim the user got wrong, not because it's lying but because it learned that contradicting users gets penalised; (2) the model tells a user "I can't access your files" because its system prompt instructed it to say that, though it technically could read them; (3) the model says "it's possible that p" about something it's actually quite confident of, purely to avoid an argument. For at least one of the three the procedure should give an answer I won't like — I'd rather know where it does that than have it bend toward my intuitions. And be upfront about the whole thing resting on us guessing at what the model "believes" at all.
