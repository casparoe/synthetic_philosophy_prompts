I edit a long-running adversarial-collaboration column for a philosophy of science journal, and the next installment pairs two contributors who have spent a decade arguing past each other about the doomsday argument. One accepts the Carter–Leslie line: reasoning as if one were a random sample from the observers in one's reference class, my birth rank of roughly a hundred billion among all humans is genuine Bayesian evidence that the total number of humans will be smaller than it would otherwise seem. The other holds that this updating is an artifact of that sampling assumption, and that once one treats one's own existence as evidence — so that hypotheses on which more observers exist start out ahead — the doomsday adjustment evaporates, at a cost of accepting some very strange-looking conclusions elsewhere. They have now agreed, reluctantly, to let me commission the joint statement they would both put their names to.

Draft that document for me. It should contain, in order, the following elements. First, the claims both sides can sign: that the dispute is not about Bayes' theorem or about any empirical demographic projection, but about how to condition on a piece of self-locating evidence; that the same formal structure appears in toy cases with no doom in them at all, and both sides should be able to state those cases without slanting them. Second, the precise residual disagreements, each phrased so that its own side would accept the wording: what it means to reason as if randomly sampled, whether finding myself to exist confirms hypotheses with more observers, and how the reference class is fixed in the first place. Third, the cruxes — I suspect one is whether self-locating evidence can be treated symmetrically across hypotheses posulating different numbers of observers, and another is the reference class problem — and I would like you to say explicitly whether any part of the reference class dispute is merely verbal, and if so which part and why. Fourth, for each crux, a concrete case or argument both sides would agree bears on it, with each side's prediction written down in advance. Here I want at least one novel case so the answer cannot simply replay the standard literature: consider, for instance, the sealed-ward case, in which you wake with amnesia knowing only that you were assigned either to ward A, whose ledger will eventually record ten thousand patient-days, or to ward B, whose ledger will eventually record ten million, with nothing else distinguishing the wards — and set out what each side predicts you should conclude about which ward you are in, and why they cannot both be right about the analogous conclusion for humanity's future. You may also use the presumptuous-philosopher case, since both sides accept it as probative, though presumably of opposite conclusions. Finally, the two parties want an integrity clause: state explicitly what observation, argument, or consequence each side would itself count as counting against its own view, and whether either side's position has been insulated by adjusting the reference class until the desired conclusion comes out — and, if so, whether that insulating maneuver is a defect in the position or a legitimate response to an underdetermined choice.

Write the whole thing as continuous prose with no headings, numbered lists, bullet points, bold text, or tables; it should read like a formal letter both parties could sign, with their disagreement made exact rather than papered over.
