Last night my friend and I spent four hours arguing about impact measures in AI safety, and she closed with an argument I have been unable to put down since. The background, as we both understand it: the low-impact research program wants a penalty term — the sort of thing pursued under names like relative reachability and attainable-utility preservation — such that an agent can be told to accomplish a task while keeping the penalized quantity low, and thereby be prevented from destroying everything we forgot to mention, without our ever having to enumerate what we care about. Her argument purports to show that this program cannot succeed in principle.

(1) For an impact measure to serve its purpose, it must be safe against unspecified values: whatever we failed to write into the objective, a sufficiently low value of the measure must preserve it.
(2) For any change an agent could make to the world, there is some coherent set of values according to which that change is a catastrophe.
(3) So a measure that guarantees preservation of unspecified values must penalize every change whatsoever.
(4) An agent penalized for every change is paralyzed or worse: it can act only by trading task reward against impact penalty, and at any finite exchange rate there are tasks for which it rationally accepts enormous impact.
(5) To avoid that, one builds exceptions into the measure — baselines that ignore changes the agent needs to make, discounts, tolerances — and each exception is precisely a claim about which changes don't matter, i.e., value information.
(6) Therefore the exceptions plus the measure together constitute a value specification, merely an implicit and unaudited one: either paralysis or smuggled values, and nothing in between.

She reinforced (5) with the observation that the concrete proposals on offer do not escape: every choice of baseline (starting state, inaction, stepwise inaction) is a choice about which counterfactual the world is to be measured against, and penalizing change in the agent's ability to achieve an auxiliary set of goals only relocates the problem, since choosing that set — even choosing it at random — means choosing a distribution, and a distribution over goals is a compressed value function.

Here is what bothers me. If her argument is sound, it seems to prove too much. Surgeons perform minimal interventions, engineers set tolerances, physicians speak of side effects, campgrounds post leave-no-trace notices, and managers tell employees to do their jobs and not meddle in anyone else's. None of these practices is backed by anything like a complete value specification, yet all of them do real and useful work steering behavior away from collateral damage. If (1) through (3) show that unspecified values cannot be protected without a full specification, the same reasoning should show that none of these ordinary notions could work either — which is absurd.

So tell me where the argument goes wrong, or, if it does not, which premise is cheapest to give up. My own suspicion is that something slips between (2) and (3): for every change there exists a value system that forbids it is somehow being made to do the work of there exists a value system that forbids every change, or else the phrase unspecified values in (1) is sliding between all possible values and the values we actually have or could realistically have had. But I cannot make that precise without conceding that impact measures are only ever safe relative to a bounded, empirically learned space of value hypotheses — which looks like it just grants her (6) with better manners. If I must give something up, I would rather weaken (1) than accept (6), but I want to know exactly what that costs: does the weakened program still promise anything recognizable as a safety guarantee, or only a contingent bet that human values cluster tightly enough for a proxy to cover them? And is there anything to say about why the surgical and engineering cases work as well as they do that would carry over to a sufficiently capable optimizer — or is the disanalogy precisely that those practitioners are members of the very population whose values are at stake?
