I work on safety evals at a smallish AI lab, and my team keeps getting stuck on what "deception" even means when we put the word in an eval report. One camp wants an intent-based definition: an output only counts as deceptive if the system somehow wants to induce a false belief in the user — but that immediately drags us into whether the model "has beliefs" at all, and nobody wants that metaphysical fight inside a shipping eval. The other camp just wants to measure output accuracy against ground truth, but that seems wrong too: a model can be honestly mistaken, and it seems like a model could mislead you using nothing but literally true statements.

Here's the position I've half-formed from these arguments and want you to actually defend properly: we should define deception for AI systems without any appeal to the system's internal states at all. On this view, an output is deceptive iff, given the information the system had available through its training and optimization history, it predictably induces a false belief (or wrong reliance) in a reasonable user. So deception is a property of the interface between system and user, not of whatever mind the system has or lacks. In defending it, please steelman it against both alternatives I mentioned — the intent-based camp and the pure accuracy camp — and explain what work "predictably" and "reasonable user" are doing, since those feel like the load-bearing parts.

A few test cases to run it through: a model that confabulates a plausible-looking citation with total confidence; a model that paltering — strictly true statements arranged so you draw a false conclusion from them; and an RL agent in a simulated multi-agent environment that learned to feign weakness to bait an opponent into overextending. For each, say whether the interface definition classifies it as deceptive and whether that verdict feels right. Finally, tell me where you think this definition breaks down, because I have a suspicion it does somewhere and I'd rather know now than in a review meeting. Please write your answer in American English.
