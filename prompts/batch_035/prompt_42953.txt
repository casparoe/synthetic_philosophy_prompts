I'm teaching a bioethics seminar on the doing vs allowing distinction — 18 students, mostly third-year philosophy majors, one 75-minute session. I want an activity built around an angle we hit in the readings: the distinction seems to presuppose some baseline of "what would happen anyway," but in an automated system the baseline is chosen by someone. Like, if an ICU drip robot's factory default is to keep delivering insulin, then flipping it off mid-treatment looks like killing; if the default is to only deliver when a human confirms, the exact same physical non-delivery looks like letting die. Whatever you think of the distinction for humans, the machine seems to force you to ask: omission relative to WHAT?

So design me an activity where students feel that question instead of just discussing it. My half-baked idea is some kind of game where one group literally writes the defaults / standing orders for an automated system, other students play the system itself (forced to follow the written defaults literally, with a time-pressure mechanic so they can't deliberate), and others play nurses or family members who can only intervene by taking some costly action or filling out some form. Then we run scenarios through it. The payoff structure should be such that when something goes wrong, everyone's blame intuitions migrate to whoever chose the defaults, and they should notice that migration happening in themselves.

What I need from you: the actual rules and materials, roles, a rough timeline that fits 75 minutes, some way to score or at least track things without real money, and a debrief that maps specific moments in the game onto parts of the distinction (act/omission, the baseline problem, maybe the way "defaults" and "reversal" pull apart — like the difference between redirecting a process vs stopping one). Also please tell me what will predictably go wrong the first time I run it (my guess is the "robot" students will just improvise good judgment instead of following the written rules — how do I prevent that?), and be honest about which part of the philosophical debate the game just cannot reproduce no matter how I set it up, so I know what I have to cover in the debrief myself.

One more thing: I'd rather they not get lectured on the standard trolley stuff up front — they've seen all that. The game itself should carry the weight. Keep the prep realistic for me too — no custom software, printable stuff at most.
