For my applied ethics seminar I have to present a taxonomy of positions on the distinction between doing and allowing harm — the killing/letting-die cluster. Rather than the usual prose survey, I want a decision tree in which every branch node is a concrete case that the positions genuinely split on, phrased so that a reader could answer it without knowing any of the position labels; the leaves should then be the named views (e.g. a strict deontological asymmetry between killing and letting die, rights-based views on which negative duties trump positive ones, moderate views holding that the asymmetry holds only within limits, and straight consequentialism), each leaf carrying one sentence on its most awkward commitment. Please build the tree from the logical space first rather than from a list of names, and include at least these diagnostic cases: (a) a doctor who withdraws a ventilator versus one who never starts it, with the patient's prognosis identical; (b) a bystander who can rescue a drowning stranger only by ruining his own expensive coat; and (c) a case in which an agent must either initiate a new causal sequence or allow an existing one to run its course, with the same number of deaths either way. Finally, flag any pair of leaves the tree cannot really separate — I suspect rights-based and moderate views come out the same on all my cases, and if so I'd like to know which further case would pull them apart — and note any branch combinations that no one occupies, saying briefly whether that is because the view is incoherent, unattractive, or simply unexplored.
