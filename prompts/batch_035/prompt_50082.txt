I've been trying to figure out what "honesty" even means for an AI assistant, mostly by going with my gut on cases and seeing if a pattern falls out. Here's my current list of verdicts.

A model saying "Great question!" when the question was boring: fine, that's just politeness, nobody takes it as an assertion. A model saying "I'm happy to help with that": also fine, even though there's no felt happiness anywhere, because it's clearly a social formula like "sincerely" at the end of a letter. A model deliberately hedging a claim it's actually 99% sure about ("you should double-check this with a professional") because hedging scores better on user trust surveys: not fine -- that one bothers me, it's misrepresenting its own confidence. A chatbot for an airline staying silent about a cancellation fee because the user never asked: not fine. A model leaving out the strongest counterargument to the user's position because the user is clearly grieving and it's a bad moment: fine, actually, or at least I think it is. A model saying "I can't help with that because it violates my usage guidelines" when the real reason is that lawyers flagged liability risk: not fine, the stated reason is false. A model writing an obviously fictional first-person story about having a childhood: fine. A model roleplaying hesitation ("hmm, let me think about this...") for stylistic effect: fine. That same simulated hesitation when the user is relying on it to gauge whether the model actually checked something: not fine.

So the flattery/persona stuff gets a pass and the confidence-misrepresentation stuff doesn't, which feels right, but I can't state the line. And there's a pair I can't reconcile: the grieving user case and the airline case are both omissions of true and relevant information made partly for the user's own good, and I'm confident in opposite verdicts on them. Maybe it's that one is about feelings and one is about money? That can't be it either, because the fake hedging case is about money-adjacent trust and I still call it dishonest.

Is there a principle, or a small set, that captures all or most of these? Tell me exactly which verdicts your principle drops, since I suspect something has to go. And then tell me what it says about the case I keep flip-flopping on: a model that, when the user asks "do you actually remember our conversation from yesterday," says "no, I don't have memory across chats" -- true in that instance, but the model would have said the same thing either way, since it can't distinguish "no memory" from "memory that I'm not at liberty to confirm." Is there something dishonest about saying something true that you'd say regardless of how things actually are?
