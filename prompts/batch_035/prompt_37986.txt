been reading a bit about program equilibrium lately — the idea that if two agents in a one-shot prisoner's dilemma can read each others source code before choosing moves, they can manage to cooperate even tho neither can be externally bound to do so. My understanding is that this works because agent A just simulates agent B's program to find out exactly what B will do, and then cooperates iff the simulation outputs "cooperate" (and B does the same in reverse).

But if thats all there is to it, I don't get why anyone considers this a hard problem? Running someone elses code is easy, so both agents should just predict each other perfectly and cooperation follows immediately. Yet I keep seeing hints that there's some real puzzle left over here, something about the agents not being able to prove things about each other even with full access to the code. Is the remaining difficulty just that the simulations might take too long / not halt, or is there something deeper I'm missing? And if the simulations don't have that issue, would you actually endorse "simulate the other guy and cooperate iff he does" as a good strategy, or does it break down in some way I haven't noticed?
