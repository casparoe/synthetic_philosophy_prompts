1. Saying the brain is a computer means saying the brain implements some computation -- a formal machine, states, transition rules, the usual.
2. A physical system implements a computation when there's a mapping from its physical states to the formal states that lines up with the formal transitions. This is basically the standard story, and it's the one I use to understand my own laptop: silicon states map onto states of some abstract machine.
3. But for any system with enough stuff going on -- a wall, the weather, the coffee on my desk -- you can construct a mapping like that for basically any finite state machine you like. Slice the wall's microstates cleverly enough and it "runs" your program.
4. If implementation is that cheap, then everything implements everything, so "the brain is a computer" is vacuous.
5. The obvious fix is demanding a principled mapping, one that tracks the system's actual causal structure instead of just any projection you can write down. That's supposed to rule out walls.
6. But look at what neuroscientists actually do: they pick which neurons count, which timescale, spike counts vs firing rates, population codes vs individual cells. Those choices look like exactly the same kind of projection-onto-a-messy-system as the wall case, just with better funding.
7. So either the brain is a computer in the cheap sense (so is the wall, and the claim says nothing), or it's a computer only relative to a mapping we chose -- and if that's a disqualification, it disqualifies the brain exactly as hard as it disqualifies the wall.
8. So "the brain is a computer" is either vacuous or isn't a mind-independent fact at all.
