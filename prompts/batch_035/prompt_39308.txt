I'm in a reading group that's been going through the Meno, and I built an argument off the road-to-Larissa bit (Socrates says a true opinion about the road to Larissa gets you to Larissa just as well as knowledge does) that I now can't refute and don't believe. My housemates and I have been arguing about it over dinner for a week.

(1) A mental state is valuable either for its own sake or for what it gets you; there's no third kind of value. (2) As a guide to action right now, a true belief that p gets you exactly what knowing that p gets you — both point you down the same road. (3) Whatever extra thing turns a true belief into knowledge — justification, being produced by a reliable process, safety, whatever your favorite condition is — is valuable only because it tends to make beliefs true rather than false. (4) But I already have the true belief, so that tendency has already cashed out. A fuse is valuable because it stops fires, but a fuse in a house that isn't on fire and never will be isn't doing anything for me. (5) So the value of knowledge is the value of the true belief inside it, plus zero. (6) So knowledge is not more valuable than mere true belief.

The obvious move, which someone tried at dinner, is that true beliefs run away — that's actually in the Meno itself, the Daedalus statues bit: true opinions are no use unless you tether them, and knowledge is the tether. But that seems to make the extra value purely about the future: knowledge is just a true belief that will probably still be there tomorrow. So then the value of knowledge over true belief reduces to expected future true beliefs, and by (3)–(4) again that seems to get swamped too — I have the true belief now, and whether it persists depends on stuff that's valuable only if it delivers truth later, which it already delivered. And it also makes the extra value contingent: a true belief I'll only hold for ten minutes before forgetting it would be exactly as good as knowledge of the same fact, which feels wrong to me, though I can't say why without begging the question.

Tell me which premise to reject and what rejecting it costs — I'd like to keep (2), and honestly (6) is the one I want gone, but I don't want to pay for that with something dumb. If you think the argument actually works and knowledge really isn't more valuable than true belief, say so and take the heat. Also, please separate what's basically settled among people who work on this from what's genuinely contested — I know the reliabilists and the virtue epistemology poeple have very different fixes for this sort of argument and I don't want one camp's answer dressed up as the consensus. If the honest answer is that nobody agrees on whether knowledge is more valuable than true belief, I'd rather hear that than get a tidy resolution.
