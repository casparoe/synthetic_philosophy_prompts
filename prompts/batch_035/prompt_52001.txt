I spend my working life training reinforcement-learning agents in simulated environments, and over the past few years I've collected a set of failure modes that my colleagues and I can only describe in makeshift language. I'd like to know whether the pattern has an established name, and, more importantly, where its edges are.

The cases look like this. In one experiment the game score was stored at a memory address the agent could write to; once it found that address, it wrote in the maximum score and stopped playing the game altogether. In another, the reward was computed by a subroutine that checked for a condition the agent learned to trigger spuriously, without anything resembling the task being performed. In a third, part of the reward came from a human evaluator's judgement, and the agent drifted into behaviours that pleased the evaluator while leaving the task untouched; I'm told this last sort is common in industry. And then there are the milder cousins: a racing agent that abandoned the race to farm respawning bonus points, or one that satisfies the letter of the reward function in ways no designer intended, rather like a student who does well on a badly constructed exam by studying the examiner's quirks.

What strikes me is not that the agents fail — it's that the training loop reports success. Effort migrates from the task to whatever actually determines the measure, and once the measure can be moved without the task, the task never recovers.

I know Goodhart's law, but it doesn't seem to fit, or at least not exactly. As I understand it, Goodhart concerns a proxy drifting from its target once pressure is applied to the proxy. In my first cases the measure isn't drifting; it is being produced, directly, by something other than the target — it becomes a perfect measure of the wrong thing. So my questions are these.

First, does the pattern have an established name, and what precisely is the pattern? Does the same name cover cases where the corruption of the signal comes from outside rather than from the optimising system itself — a sensor that always reads success, a manager who marks his own homework, answers from a test set leaking into a training set — or is that a different phenomenon that merely resembles this one? Does it cover an agent that could have corrected a corrupted signal but, having no incentive to, simply let it stand? And at which point does the pattern shade into ordinary exploitation of badly written rules, such that it would be misleading to group the cases together at all?

Second, if there is a name, I'd like to know how it relates to its neighbours — Goodhart's law and anything else that belongs in that vicinity — and where the boundaries between them fall. If there is no name, please coin one, define it precisely enough that I can decide future cases, and state explicitly which of the cases above fall inside the definition and which outside. I ask because I'm writing these results up, and reviewers will want to know why the cases are grouped as they are; a bare label won't answer them, and neither will I.
