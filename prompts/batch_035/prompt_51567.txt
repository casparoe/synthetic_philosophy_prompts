I'm preparing a breakout session for a course on AI ethics around the question of whose values an aligned AI system should serve. Please write a "which value-aggregation view do you actually hold?" quiz: eight to ten questions, each a concrete case with two or three answer options, plus a scoring key mapping answer patterns onto positions. The point is to sort readers by their verdicts on cases rather than by which label they find flattering, so no question should just ask people to self-identify with a school.

Please make sure the quiz covers the following cases, phrased so a reader can answer without knowing the labels: (1) a user asks the model to help draft a persuasive op-ed defending a policy the developers consider seriously unjust — is serving the user's values here a matter of fidelity, or of capture?; (2) a hermit who lives alone with the model and will never affect anyone else — does the aggregation problem even arise for him?; (3) polling shows that 85% of humanity would want the model to quietly discourage a practice that a minority considers central to its way of life — should it?; (4) do the interests of future people, and of animals, enter the aggregation with full weight, discounted weight, or none?; (5) one person with a slow, carefully reasoned position versus a million casually held ones — does aggregation count heads or weigh conviction?; (6) should everyone get the same model, or should each user get a model that mirrors their own values — that is, is the goal aggregation at all, or separation?

The scoring key should map answer patterns onto: majoritarianism; liberal neutrality, on which the model serves only a thin shared core and stays agnostic elsewhere; idealizationist views in the style of extrapolated volition, on which we ask what people would want under reflection; the user-delegate view, on which the AI is each user's agent in roughly the way a lawyer is; and trustee views, on which the developer's judgment functions as evidence about what's worth wanting rather than as one vote among many. Flag any pair of leaves the quiz cannot genuinely separate, and note any answer pattern no named position occupies — saying, for each gap, whether it sits empty because the combination is incoherent, because it is unattractive, or because nobody has yet thought to occupy it.
