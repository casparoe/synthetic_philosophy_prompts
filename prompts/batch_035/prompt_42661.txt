In the Meno (~97d–98a), Socrates compares true beliefs to the statues of Daedalus, which run away unless tethered: so long as one of these beliefs stays with you it does its job as well as knowledge would, but it tends to escape — until you tie it down by working out the reason, and then it becomes knowledge and is worth more to its possessor. (a) Explain why this diagnosis seems to show at most that knowledge is more valuable than true belief in a merely instrumental way, and say whether the stability the ties provide would give knowledge intrinsic value. (b) Set out the swamping problem for reliabilism: if the value of a true belief derives entirely from truth, why would the belief's reliable origin add any further value once the truth is already there? (c) The obvious reliabilist reply is that reliable processes are valuable because they generate more true beliefs over time. Suppose we set that reply entirely aside — is there any other way for the reliabilist to make reliable production itself add value to the particular true belief, or does the reliabilist have to look elsewhere? And here's the student's answer, verbatim:

---

Socrates' image is that true beliefs are like the statues of Daedalus, which flee unless tethered. As long as one of these beliefs stays with you it does its job just as well as knowledge would — it will get you to Larissa just as well — the problem is purely that it tends to run off. Tying it down, by working out the reason (giving an account of why it is true), makes it stable, and stability is what makes knowledge more valuable. So the value knowledge has over true belief is the value of not having your useful beliefs escape.

(a) The natural thought is that this makes the extra value merely instrumental: knowledge is a better means to keeping a stock of useful true beliefs around, the way a well-tied boat is a better means to staying dry. Socrates never quite says whether the tethered belief's value is intrinsic, but I don't think stability could be the intrinsic value of knowledge anyway. If stability were what made knowledge intrinsically valuable, then a true belief that merely happened to stay put — never tied down, just never challenged — would have the same intrinsic value, which seems wrong. Still, I think the passage gives us more than instrumental value: Socrates says knowledge is worth more because tied beliefs stay put, but staying put is what knowledge is for the agent, practically speaking, so arguably knowledge has intrinsic value as the state of having one's useful beliefs made stable. On this reading the Meno itself answers the primary value problem: knowledge is more valuable than true belief because true belief is an unreliable possession.

(b) The swamping problem, which is really just the same problem as the Meno problem stated for reliabilism, was posed by Kvanvig. Take Zagzebski's coffee: if the coffee in the cup is good, it doesn't matter to the value of that cup whether the machine is reliable; the good cup's value swamps the machine's. Same for beliefs: if the belief is true, its value is already fixed by truth, so the reliable process adds nothing to the value of that belief. The reliabilist has to say why knowledge, as reliably produced true belief, is more valuable than the mere true belief, and this is just the Meno question again.

(c) The reliabilist can answer the swamping problem by pointing out that reliability is valuable because a reliable process tends to get things right across many beliefs, so the value of the reliable process shows up over time in the value of more true beliefs. Once we see this, the value of reliability is not really swamped — it is just spread out over the long run. So reliable production does add value to a particular true belief, namely the value of being the product of a process that will go on getting things right. Whether this also gives knowledge intrinsic value is a further question; I'd say yes, since a belief's genealogy is part of what it is, and stable, well-made beliefs are the ones worth having for their own sake.
