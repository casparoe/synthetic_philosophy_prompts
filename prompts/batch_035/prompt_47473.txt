I'm grading exams for a second-year epistemology module and would appreciate a second pair of eyes on one answer before I finalise marks. The question was:

"Plato's Meno suggests that knowledge differs from true belief the way one of Daedalus' statues differs from one that has been tethered: untethered, the statues run away. Explain why knowledge seems more valuable than mere true belief (the Meno problem), and assess whether process reliabilism can account for this extra value."

Here's the student's answer:

"Plato sets the problem up in the Meno: Socrates gets Meno to agree that a man who knows the way to Larissa and a man who merely has a true opinion about the way will both guide you there equally well, so true opinion is no worse a guide than knowledge. Meno then supplies the answer himself: like Daedalus' statues, true opinions run away unless tied down, and once tied down they become knowledge. So knowledge is just true belief caused in the right way, and the extra value of knowledge is that it stays put while true belief doesn't.

The modern version of this same problem is the swamping problem, which Goldman raised with his coffee example: a good cup of espresso from a reliable machine is no better than the same cup produced by a broken one, so if knowledge is true belief produced by a reliable process, the reliability adds nothing to the value of the individual belief. Since reliabilism therefore cannot explain why knowledge is more valuable than true belief, reliabilism is false, and this is widely regarded as a decisive refutation of it.

Goldman does have a reply: although a single true belief is worth no less than a single item of knowledge, a reliable process is more valuable in the long run, since it delivers mostly true beliefs rather than mostly false ones. So knowledge is more valuable in expectation, and this fully answers the Meno problem: the extra value of knowledge over true belief just is the higher expected number of future true beliefs.

Plato, then, was right that knowledge is tethered true belief, and reliabilism is best understood as a modern spelling-out of what he meant."
