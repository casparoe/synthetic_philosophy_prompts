Write an essay on computationalism -- the claim that the brain is literally a computer, not just metaphorically like one. But I want it centered on a specific wrinkle, not the usual Chinese Room rehash.

Here's the wrinkle. There's an old objection, associated with Searle but you can paraphrase the idea rather than citing, that if computation is just a matter of mapping some pattern in a physical system onto formal states, then you can find computation anywhere -- a suitably described wall could count as running a word processor. So on a loose reading, the brain computes, but so does everything else, and the thesis is trivially true. Tighten the definition, though, so that computing requires something like discrete states, systematic state transitions that support counterfactuals, maybe some kind of representational content, and now computationalism is a real, falsifiable claim -- but it also has to face everything messy about the actual brain: continuous dynamics, analog chemical signaling, the fact that neuromodulators like serotonin seem less like they're carrying messages and more like they're reconfiguring what the rest of the system is doing, no clean line between program and hardware, etc.

So the question the essay has to answer: is there a version of computationalism that is (a) non-trivial, (b) compatible with what we actually know about nervous systems, and (c) still doing genuine philosophical or scientific work, rather than being watered down into an unfalsifiable methodology? Weigh the live options -- maybe computation as counterfactual-supporting causal organization, maybe some role for representation, maybe the idea that the brain implements many overlapping models of computation at different levels of description, whatever you find strongest. But reach a real verdict. Either defend one specific version of computationalsm and explain exactly what makes it non-trivial, or argue the whole thing should be retired as literal metaphysics and kept (or dumped) as a research heuristic. A fence-sitting "depends how you define computer" ending is only acceptable if you've genuinely earned it, and you probably haven't.

Aim for around 1200 words. I'd much rather see clear argument than name-dropping, and no reading lists or citations please -- just the reasoning.
