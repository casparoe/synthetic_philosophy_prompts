The exam question, worth 20 points, was:

Explain the multiple realizability thesis. How is it used as an argument against the mind-brain type identity theory? How does functionalism accommodate multiple realizability, and what is one objection to functionalism that arises from this same line of thought?

The student's answer, reproduced verbatim:

Multiple realizability is the thesis that one and the same mental state can be realized by different physical states. Pain in a mammal and pain in an octopus are the same mental state, but the neural machinery implementing them differs across those species, and a system built from silicon could in principle realize pain as well. Putnam introduced this thesis in the 1960s and deployed it against the type identity theory, which says that each mental type is identical with some physical type — pain is C-fiber firing, for instance. If pain can be realized by many distinct physical states, then it cannot be identical with any one of them, and type identity is thereby refuted.

Notably, the argument does not depend on any new experiments, because multiple realizability is a consequence of functionalism. Functionalism defines each mental state by its causal role: the inputs it is apt to receive, the outputs it is apt to produce, and its relations to other mental states. Since the definition makes no mention of physical composition, any substrate that implements the right causal-role organization realizes the mental state in question, so multiple realizability is built into the view from the ground up. The analogy is the hardware independence of software: the same program runs on an Intel chip and on an ARM chip. Functionalism is essentially the claim that the mind is software and the brain is merely one implementation of it.

The identity theorist might try to repair the theory by identifying pain with a disjunction of physical states: C-fiber firing in mammals, the relevant octopus state, and so on. But a disjunction is not itself a genuine physical state, so this is no longer a real identity claim — it is a relabeled inventory. It would also make the physical type depend on which creatures happen to exist, which no respectable physical science does. The identity theory cannot be patched along these lines.

Putnam also supplied the sharpest objection in the opposite direction: his China-brain thought experiment. Imagine the population of China organized so that each person plays the role of a single neuron, with radio links carrying the signals. If functionalism is true, this system has a mind — qualia and all — which is absurd. So although functionalism accommodates multiple realizability with ease, it may accommodate too much: it captures the causal and psychological dimensions of mind while leaving out the phenomenal, which is a deep problem for the whole computational approach to mind.
