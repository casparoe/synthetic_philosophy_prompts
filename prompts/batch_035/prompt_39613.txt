I teach intro epistemology at a state school, about 18 students, one 75-minute session. We're getting into the Meno problem next week -- the bit where Socrates compares someone who actually knows the road to Larissa with someone who just happens to hold a true belief about that same road, and asks what the extra value of knowledge is supposed to be. I want them to feel the problem before they see any of the standard literature, so no lecture up front and I won't name the swamping problem or anything like that until afterwards.

Design me the activity. What I'm half-imagining is some kind of navigation or route game where some students end up with genuine knowledge of a route and others end up with true beliefs that got there by luck, and then the conditions change under them -- but you're the designer, rearrange as you see fit. Two constraints I care about: they should not be told which condition they're in, and the lucky beliefs have to actually be true (no trick maps, no hidden errors), otherwise the whole thing collapses into "wrong beliefs are bad," which nobody ever doubted. Payoffs in points or privileges, not money.

I also want a second phase that turns the screw. The obvious game outcome -- true beliefs go stale when the world shifts, knowledge adapts, done -- is basically Socrates' own tethering answer, and it lets students walk out thinking the problem is solved. So phase two should put them somewhere their own game's logic says the lucky source and the knowing source are equally good. My half-formed idea: the lucky source turns out to have a perfect track record so far, so by the numbers there's nothing to choose between them -- but do whatever achieves that. If the class ends up arguing about whether the difference even matters, that's a win, not a failure.

Then the debrief: map the concrete moments onto the actual distinctions -- the tethering story, the difference between knowledge being more *reliable* and knowledge being more *valuable*, and whether instrumental value is all the value there is to find here. Tell me what will predictably go wrong the first time I run it (students comparing notes across groups, the route change feeling artificial, the lucky-source reveal landing flat, whatever you actually forsee), and be honest about the part of the problem no game can reproduce. I assume the pure intuition -- both belief and knowledge guaranteed true right now, and knowledge still seeming better -- can't really be staged with real stakes, but tell me if im wrong about that.

And look, if you think the whole setup is confused -- say the game can only ever show that unreliable sources are worse, not that knowledge beats true belief, and there's no fixing it -- say that plainly instead of handing me something that looks like it works but doesnt.
