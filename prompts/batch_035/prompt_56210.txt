Does this thing have a name? I review grant applications for a small family foundation, and the pattern I keep hitting is this: applicants never report their results raw, they report them relative to a chosen group. "Among organizations of our size working in rural counties, we're unusually cost-effective." "No first-time applicant from our state has ever done better." And every single time, the group seems to have been picked *after* seeing the numbers, so that the claim comes out flattering. Once I noticed it there I started seeing it everywhere: sports pundits calling someone "the best left-handed rookie QB of the last decade," a friend consoling herself that "for someone who grew up the way I did, I'm doing really well," companies announcing their "best quarter among comparable retailers." I even gather that in pay discrimination lawsuits a big part of the fight is over which colleague counts as a legitimate comparator at all.

So what I want a name for is not just the boring fact that any average depends on which group you average over -- I've read enough forecasting blogs to know people call that the outside view / reference class problem territory, where the puzzle is which class to use for a prediction. My thing feels different, because in the cases I'm seeing nobody is predicting anything. The class is chosen purely to win an evaluation or an argument, post hoc, and neither side ever offers a principle for which comparison class would have been the *right* one had it been fixed in advance. It's almost like cherry-picking, except the data isn't being cherry-picked, the population is. Does the strategic use of comparison classes have an established name of its own (I've half invented "reference class shopping" in my head but assume someone beat me to it), and is there any real literature on when a comparison class is legitimate versus gamed? If you think it's just the reference class problem in a suit, I'd want you to spell out exactly what the difference is, because the version I've read about is an inference problem and mine is an advocacy problem.

And if there is no established concept, please coin one and give me a definition with actual boundary cases, because I keep going back and forth on where the edges are. Is it still the same move when someone picks a *self-deprecating* comparison class to seem modest, or to lower expectations? What about when the class was fixed before the results came in but chosen by the very person being evaluated -- is the strategicness in the timing or in the interest? And is a comparison class chosen by convention (say, "per capita" stats across countries) immune just because it's standard, or can conventions be strategically captured too? I don't just want a label, I want the carving: what exactly is the phenomenon, what is it not, and how do I tell it apart from ordinary cherry-picking on the one hand and honest reference-class uncertainty on the other.
