I teach an intro metaphysics class and want a one-page decision tree handout for the special composition question: when do some things add up to a further thing? The tree should start from a question the students can answer without knowing any of the labels (something like: is there any composite object at all over and above whatever simples exist?) and then sort them via concrete cases — I'm thinking two gloves in a drawer, a tree with a freshly fallen branch lying next to it, grains being added to a sand pile one at a time, a crowd at a protest, a disassembled bike in a box. Leaves should cover nihilism, universalism, organicism (composition only when life is involved), brutalism (there's a cut-off but no story about it), and a common-sense restricted view. Two things I want you to be honest about rather than paper over: which pairs of leaves the tree can't actually separate (my hunch is organicism and the common-sense view say yes to the tree and no to the gloves and the bike, so if any case can pull them apart tell me which, and if not say the tree has to lump them), and which branch combinations end up unoccupied — with a sentence on whether nobody's there because the view is incoherent or just because nobody bothered defending it. Keep the node questions phrased as rulings on the cases, not as 'do you believe in tables?'
