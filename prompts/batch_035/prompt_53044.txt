I write a small blog read mostly by linguistics undergrads and adjacent nerds, and I want to make a "which theory of language acquisition do you actually hold?" quiz for it. Heres my angle: in the nativism vs empiricism fights I keep noticing that people argue about labels (universal grammar, blank slate) while actually disagreeing about narrower stuff — like whether the innate contribution is *content* (actual grammatical categories or principles in the head from birth) or merely *biases* (some patterns are just easier to learn than others), and whether the input is really as impoverished as the poverty-of-the-stimulus argument claims. Those two questions cut across each other, so a plain "nativist vs empiricist" framing is useless. I want the quiz to sort people by what they say about cases, not by which label they like.

Please write 8-10 questions. Each should present a concrete finding or case, then 2-4 answer options about what you'd conclude from it, phrased so someone can answer without knowing which theory each answer feeds. These cases need to show up somewhere in the quiz:

- The classic structure-dependence thing: kids correctly form questions where the auxiliary attached to the main noun phrase has to move (the man who is tall singing-type sentences), apparently never try the simpler linear rule, and nobody corrects them when they err, since parental feedback on grammar is basically absent — no negative evidence.
- Artificial-language experiments where infants segment continuous speech by tracking transition probabilities between syllables after just a few minutes of exposure.
- Creolization: a community of deaf kids in Nicaragua basically built a fully grammatical sign language out of an impoverished pidgin-like input, and similar things happen with spoken creoles.
- Kids' overregularizations like "goed" and "foots," and the wug test, where children inflect a made-up word theyve never heard before.
- The counterargument, going back to the original critics of the poverty-of-stimulus argument, that child-directed speech is actually pretty grammatical and rich, so maybe the stimulus was never poor to begin with.

Then give a scoring key mapping answer patterns onto exactly these five positions as leaves:

1. Strong nativism — substantive innate grammar; the input mainly triggers or selects among options.
2. Weak nativism / innate constraints — nothing like a full grammar in the head, but species-specific learning biases that make language-type patterns especially easy to pick up.
3. Domain-general statistical learning — one general-purpose learning machine, no language-specific innate anything, everything extracted from input statistics.
4. Emergentism / constructivism — "innate" at most describes the whole initial state, including things like maturation timing; structure emerges from development interacting with input, e.g. starting with a small working memory actually helps rather than hinders.
5. Stimulus-rich empiricism — the poverty-of-stimulus premise itself is empirically shaky; the input contains what's needed and kids learn it with general means.

Two more requirements. Flag which pairs of leaves the quiz genuinely can't seperate no matter which cases you use — I suspect weak nativism and domain-general-with-constraints end up mushed together, and if so say so plainly rather than pretending the key is cleaner than it is. And note any answer-combos that don't map onto any real position, with a sentence diagnosing whether nobody holds them because the combo is incoherent or just unexplored.

Audience is smart non-specialists, so define any jargon in a line when it first comes up. Please answer in American English. Length: whatever 8-10 questions plus the key naturally runs to — dont pad it.
