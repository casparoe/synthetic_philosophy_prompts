The question was:

"Searle has argued that computation is not intrinsic to physics: syntax is observer-relative, so whether something counts as a computer depends on how we choose to map states onto symbols. Explain this objection and the threat it poses to computationalism about the mind (if a wall can be described as implementing any program you like, what does it even mean to say the brain is a computer?). Then assess one prominent reply."

And here's the student's answer:

"Searle's objection is basically the Chinese Room again. In the Chinese Room, a man follows symbol-manipulation rules without understanding Chinese, and Searle concludes that running a program can never produce understanding. In this later argument, he applies the same point to physics itself: physical states don't have intrinsic syntactic properties, so calling something an implementation of a program is always relative to an observer who maps physical states onto computational states. Since a rock or a wall has enough physical states, for any finite state automaton you can always find a mapping that makes the wall implement it -- this is Putnam's result. So if the brain is a computer only in the same observer-relative sense that the wall is, then computationalism can't explain what makes the mind special: it collapses into pancomputationalism, and a theory that attributes computation to everything explains nothing. This threatens computationalism because it makes the claim 'the brain is a computer' trivially true, and trivially true claims can't do any explanatory work for consciousness.

As for the reply, Chalmers bit the bullet and accepted pancomputationalism. He argued that this is fine because even if walls compute, only systems with the right organization -- like brains -- have the kind of computation that matters for consciousness, and the mapping for those systems is natural rather than arbitrary. So computationalism survives as the claim that the brain implements the right program in the natural way, which is observer-relative but harmless, like saying the same book is a paperweight."
