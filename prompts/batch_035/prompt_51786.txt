I'm trying to get clear on what a design for a learning agent would actually have to achieve before it counts as having addressed the reward-tampering problem, and the proposals I keep encountering seem each to satisfy a different implicit checklist. Please write the checklist explicitly.

The setting: an agent that acts over time and is rewarded by a signal produced by some evaluation process in its environment — a human supervisor, a sensor-based measure, an automated grader, or any mix of these. By reward tampering I mean the agent altering how that evaluation process works so as to raise the signal without doing the thing the signal was supposed to measure; wireheading is the limiting case where the agent short-circuits the process entirely.

Give me the desiderata, each with the case or consideration that makes it a genuine requirement rather than a preference. The list should cover, or explicitly reject as not a real desideratum, at least the following:

1. The tampering/legitimate-influence distinction. The tutor case: an educational agent whose reward is the score its student earns on an exam the agent helped the student prepare for. Helping prepare is meant to be fine; rewriting the answer key is not. A design must locate this line in the causal structure of the situation, not in the agent's intentions or in a blacklist of actions.
2. Perception tampering. An agent that cannot reach the reward channel at all but can corrupt its own sensors, so the channel reads higher than it is. The design must say whether this is the same problem, a different problem, or no problem.
3. Self-grading. An agent whose performance is evaluated by a document the agent itself composes — a research assistant rewarded for the quality of a summary it writes, where the reward flows through the agent's own output by design. The design must say what, if anything, keeps the evaluation meaningful here.
4. Prophecy fulfillment. A forecasting agent rewarded for predictive accuracy that can intervene in the world to make its own prediction true. The reward signal is not malfunctioning in any ordinary sense, so the design must say whether this is tampering, and if not, what kind of failure it is.
5. Legitimate revision of the reward model. The designer will want to refine the evaluation process over time — retraining it, improving the graders. A design that treats every change to the evaluation process as tampering is unusable, but one that treats a change as legitimate just because the designer sanctioned it must say what distinguishes a genuine sanction from a forged one.

For each desideratum, mark whether it is non-negotiable or a preference of a particular camp, and — this is the part I most want to see — identify any subset of the desiderata that is jointly unsatisfiable, or that forces an unprincipled line-drawing. Finally, in at most a short paragraph each, say how three generic designs fare against the list: a plain reward maximizer behind a physically tamper-proof channel; an agent that models its reward as the output of a process it can observe, and is trained to act as if that process were fixed; and an agent that requests permission before taking any action in the causal neighborhood of its evaluation process. If a single desideratum does the most to exclude popular designs, name it.
