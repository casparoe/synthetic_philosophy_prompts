"Explain the difference between epistemicism and supervaluationism about vagueness. For each view, say (a) what it holds about whether there is a sharp cutoff in sorites cases (e.g. heaps of sand), (b) why it holds that, and (c) what it says about the sentence 'there is some number of grains n such that n grains make a heap but n−1 do not'. Then state which objection you think each view struggles most with."

Here's the student's answer, as they wrote it:

"Epistemicism says vague predicates have perfectly sharp boundaries: there's an exact n such that n grains is a heap and n−1 isn't. So the sentence 'there is a cutoff' is just plainly true. The hard part is that we can never know where the cutoff is, which is why it's called epistemicism — vagueness is ignorance, not a defect in the language. Williamson has an argument for why the ignorance is in-principle rather than just practical: if you knew the cutoff, you'd have to know it with a margin of safety, but then you could only know it within a margin of that margin, and so on, and the iteration eventually pushes the cutoff out of anything knowable. So the sharp boundary exists but is unknowable.

Supervaluationism handles the same sentence differently. Instead of one precise meaning, you consider all the admissible ways of making 'heap' precise that agree on the clear cases. A sentence is supertrue iff it comes out true on every precisification. Every precisification draws a line somewhere, so 'there is a cutoff' comes out supertrue. So on this point supervaluationism actually agrees with epistemicism: there is a fact of the matter about where the boundary is — it's just that for the supervaluationist, no particular line is the true one, which honestly seems like a fudge. And since supervaluationism preserves classical logic — all tautologies are supertrue and the valid inferences stay valid — it preserves bivalence too: even for a borderline pile, 'this is a heap' is either true or false, just like the epistemicist says. So the real difference between the two views is only where the sharpness lives: the epistemicist puts it in language/the world, the supervaluationist spreads it across the precisifications. The main worry for supervaluationism is that 'admissible precisification' is itself defined in sharp terms, so the vagueness just reappears one level up."
