I do ML tooling work, pretty far from philosophy, so forgive me if this has an obvious name and I just can't find it. I keep running into what looks like the exact same fight at different scales, and I want to know if anyone has named the thing the fight is about.

Instance one: someone trains a linear probe on a network's activations, shows you can decode, say, the sentiment of the input from layer 27, and announces the network has a sentiment representation there. Someone else says that's way too fast — decodability is cheap, you can find some linear readout in almost any sufficiently high-dimensional blob of features, so what have you really shown? The first person then does an ablation: they knock out the direction the probe found and the network's output changes, and declares victory, the feature is causally used. Then a third person points out that the ablation is done along the probe's own direction, so of course it perturbs something — you've found a real input to the network, but calling it a representation is an extra step nobody earned. And it just never resolves.

Instance two, same shape: a game-playing network where people showed you can decode the board position from the activations, and half the discussion was about whether that means the network "has" a board state internally or whether the probe is just a clever enough reader that it could reconstruct the board from all sorts of things, including ones that don't use it. Meanwhile my philosopher friend muddies it further by pointing out that a mercury thermometer "represents" temperature on a pretty deflationary reading, so if decodability is all it takes, we're using the word so thinly it covers the thermometer, and presumably that's not what the interpretability people want to claim.

So: does the gap between decodable-from-activations and actually-used-as-a-representation have an established name? Is there a standard carve-up of the senses of "the network represents X" — like a decodable sense, a causally-used sense, maybe a sense where the network uses it *for* something in a stronger way? I know there's a mountain of philosophy of mind on representation generally, but I'm after the specific version of this debate, if it exists, and if it doesn't, I'd like you to build the carve-up yourself and tell me which sense the ablation actually supports and where the edges of each are. I'm not looking for a bare label — I want to know what the phenomenon is and isn't, e.g. whether the probe-direction-ablation circularity worry can be fixed by ablating along other bases, or whether that misses the point entirely.

One more thing: please tell me honestly where your answer is most likely to be wrong. Like, which of these distinctions is contested enough that a specialist might say I've misdescribed the debate, and what consideration would actually flip you on whether the ablation settles anything?
