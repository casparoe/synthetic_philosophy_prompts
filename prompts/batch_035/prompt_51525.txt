The exam question the student was answering read as follows:

"Computationalism about the brain is often glossed as the thesis that the brain is a computer. Hilary Putnam has argued that every ordinary open physical system implements every finite-state automaton, and John Searle has argued that syntax is not intrinsic to physics. Explain how each of these arguments is supposed to work, and say precisely what each threatens: computationalism as an empirical thesis about what brains do, the stronger claim that running the right program suffices for thought, or both? Then assess whether requiring that implementation respect counterfactual causal organization, as David Chalmers proposes, defuses the threat. Distinguish carefully wherever it matters between the question of whether the brain computes and the question of whether computers can think."

The student's answer, reproduced in full:

"Computationalism says that what the brain does is computation: cognition is explained by the programs the brain runs over its internal states, which is why the mind could in principle be uploaded to any hardware that runs the right program — a consequence multiple realizability makes problematic for the view. The two anti-computationalist arguments are really two forms of one worry about implementation.

Putnam's argument, later restated by Searle in his paper 'Is the Brain a Digital Computer?', goes like this. Take any open physical system — Searle's example is a wall — and equip yourself with a clock. As time passes, the wall's microphysical states vary; partition them into equivalence classes and map each class onto the formal states of whatever automaton you like. Since the system is open, you can always find enough states to cover each step, so every open system implements every Turing machine. This is just the Chinese Room argument in hardware form: Searle's two arguments are the same argument, one aimed at software and one at hardware. The moral is that unconstrained computational description is cheap — trivially, observationally cheap. If everything is a WordStar implementation, then nothing is, in the interesting sense. Searle deepens the point with his claim that syntax is not intrinsic to physics: syntactic state assignments exist only relative to an interpreter, like shadows and simulacra.

It follows that there is no fact of the matter about what the brain computes. So computationalism is not an empirical discovery at all — the brain is a computer, but only in the way the wall is, which is to say the thesis is false. This also sinks the AI claim: if computation is observer-relative, no program could ever think, since whether it even runs a program depends on us.

Chalmers, in 'Does a Rock Implement Every Finite-State Automaton?', concedes Putnam's construction and responds by stipulating a more restrictive definition of implementation, on which implementing a state machine requires having a causal structure that mirrors the machine's state-transition structure across counterfactual situations. This saves computationalism by fiat — it is a new definition chosen precisely because it excludes the trivial mappings, so the dialectical situation is a standoff: Putnam shows that on the natural definition everything computes; Chalmers simply declines to use the natural definition. Putnam can fairly reply that if computation over the brain is real, it should be visible without building the constraint in by hand. On balance I side with Putnam and Searle: computationalism has been drained of empirical content."
