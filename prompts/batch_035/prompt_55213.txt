The exam question was:

"Explain the difference between etiological (selected-effect) accounts of biological function and causal-role accounts of the Cummins style. Then use each account to evaluate three cases: (a) a diseased heart that pumps poorly or not at all; (b) the human appendix, which apparently helped with digestion in our distant ancestors but now does little; (c) a brand-new trait appearing for the first time in a single individual by mutation, with no selection history at all. Finally: which account handles malfunction better, and why is malfunction supposed to be hard for causal-role accounts?"

The student wrote:

"The etiological account says a trait's function is whatever it was selected for doing in the past. So the heart's function is pumping blood because hearts that pumped blood were favored by selection, and this is fixed by history — it doesn't matter what the trait does now, the function stays the same. The causal-role account, associated with Cummins, says instead that a trait's function is whatever it does that contributes to fitness — the heart's function is pumping blood because pumping blood helps the organism survive and reproduce.

(a) A diseased heart: on the etiological view the heart has lost its function, since a thing can't have the function of doing what it no longer does. On the causal-role view there is also no function here, since the failing heart contributes nothing to fitness.

(b) The appendix: on the etiological view the appendix still has its original function of aiding digestion, because that is what it was selected for way back, even though it doesn't perform it anymore — selection history fixes the function regardless of current performance. On the causal-role view the appendix's function would be whatever it currently contributes, so probably nothing, or at most whatever it does for gut flora.

(c) A brand-new mutation: the etiological view can't assign it a function yet, since there's been no selection for anything, so there's nothing it was selected for. The causal-role view has no trouble — if the new trait does something that contributes to fitness, it has that function immediately, no history required.

Malfunction: this is where the etiological view shines. A thing can have a function and fail to perform it — that's just what malfunction is. It's supposed to be hard for the causal-role view because if function is just what the trait currently does, then a trait doing nothing doesn't have a function it's failing at; it just has no function. A broken heart doesn't malfunction on that view, it goes functionless."
