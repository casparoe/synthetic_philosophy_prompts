My professor says Wittgenstein's diary case shows there can't be a private language, and I can reconstruct that part fine. But the same reasoning seems to destroy public language too, and I can't find where it breaks. Help.

(1) A word means something only if there's a real difference between using it correctly and using it incorrectly.
(2) A difference only counts as real if there's some way, at least in principle, to check which side of it a given use falls on. Otherwise "correct" is just applause noise.
(3) The diarist who writes "S" whenever he has a certain sensation has, by hypothesis, no check on his later uses except his own impression that today's sensation is the same one as before.
(4) But an impression that one is right can't itself be the standard of rightness -- if it were, nothing would ever count as using the word wrongly. So no use of "S" can be wrong, and by (1) "S" means nothing. No private language.

Fine, that's the argument. Now the part that worries me:

(5) Take "red". My only check that I'm using "red" today the way I used it yesterday is, in the end, my own memory and my sense that I'm doing the same thing I did before -- if my memory had silently drifted, I'd notice nothing.
(6) So by the same reasoning as (3)-(4), my uses of "red" can't be checked against anything either, and "red" means nothing.
(7) And whatever goes for "red" goes for every word, since every word's continuity of use hangs on individual memory.

(7) is obviously too much -- I'm not ready to conclude nobody has ever meant anything by anything. So somewhere between the diary and "red" the argument breaks. My two suspects: (2), which smells like verificationism smuggled in, or (5), which maybe quietly assumes that checks have to be private when public ones are sitting right there. But I genuinely can't decide between them, and I'd like to keep (4) if possible since it seems like the heart of the diary case. Also, the diarist could keep auxilliary records -- re-read old entries, note circumstances, whatever. Does that rescue him, or is it just the same problem one level up? Tell me which premise to give up, why it looked fine in the first place, and what it costs.
