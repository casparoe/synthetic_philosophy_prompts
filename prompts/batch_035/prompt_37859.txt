My epistemic utility theory study group has an argument that I think proves way too much, and I've stared at it for a week without finding the exit.

Setup, so we're on the same page: accuracy-firsters say beliefs should be treated like decisions. The core rule is: hold whichever credence function maximizes expected accuracy, where the expectation is computed using your current credence function, and accuracy at a world is scored by a strictly proper scoring rule. Strict propriety is the feature that says: if your credence function is c, then by c's own lights, no other credence function has higher expected accuracy. Every credence function is immodest about itself. That's supposed to be the great virtue of proper rules.

The argument:

(1) EUT's core rule: a rational agent with credence function c holds whichever credence function maximizes expected accuracy, where the expectation is taken using c.

(2) Strict propriety: for any c, the maximizer of expected accuracy by the lights of c is c itself. (This isn't an assumption, it's basically what "proper" means.)

(3) So an agent with credences c should never move to any c'. No alternative ever looks better to her.

(4) So no belief change is ever rationally licensed — conditionalization included. The rational agent is a perfect conservativist: whatever credences she starts with, she keeps forever.

(5) But the whole accuracy-first program is supposed to vindicate updating on evidence. The standard arguments for probabilism and for conditionalization (the Greaves and Wallace expected-utility-of-updating-plans stuff, and the Joyce-style dominance arguments) are all instances of (1) applied to rules for changing your mind.

(6) So EUT refutes itself: the very principle invoked to demand belief changes also entails that no belief change is ever warranted.

One person in my group says the trick is between (3) and (4): the agent's choice isn't "which credence function do I hold, full stop" but rather a choice between policies like "if I learn E, adopt c(.|E)," and policies are evaluated ex ante, before the evidence arrives. Fine, but I don't see how that helps. If c is already the maximizer of expected accuracy by c's lights, then any policy that ever moves you off c anywhere should lose expected accuracy, so shouldn't the "stay put" policy still win? It feels like this reply either smuggles in something new or just restates (3) more carefully, and I can't tell which. My other friend just wants to deny (1) and say the expectation should be computed by something other than your current credences, but that seems to give up the entire accuracy-first idea — what's left of the program if your probabilities can't be the ones doing the evaluating?
