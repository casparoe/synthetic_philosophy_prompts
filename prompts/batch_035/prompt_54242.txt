so I've gotten deep into the program equilibrium stuff lately and I've ended up with a cluster of views that I'd like someone to sanity check against each other. Heres the package:

1. I'm broadly on board with updateless / functional decision theory — you choose a policy, not an action, and yes I one-box in Newcomb.
2. I think two agents in a one-shot prisoner's dilemma who can read each other's source code can rationally cooperate — the "I cooperate iff I can prove you cooperate, and vice versa" setup.
3. I think whatever the right way to cooperate is, it should be robust to cosmetic differences in the code: if my decision procedure is functionally identical to yours but written differently, or padded with dead code, or renamed variables, the right answer shouldn't flip.
4. But if all you can see of me is, like, a hash of my source — no way to verify anything about what I'll actually do — then it's effectively just an ordinary one-shot PD and mutual defection is the rational outcome.
5. And I think two agents who both *know* they're running literally the same decision procedure should cooperate even with zero code access — pure symmetry does the work. This is basically what Hofstadter called superrationality, and I've always found it pretty convincing.

Do these actually hang together? I have a nagging feeling something in here contradicts something else, but I can't put my finger on where, and I honestly can't tell whether some of these only *look* like they're in tension. Please go through it properly: tell me which pairs are in conflict, rank them by severity, say what would have to give in each case and what that would cost me elsewhere in the list.
