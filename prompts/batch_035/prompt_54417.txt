"Honesty as asserting what you believe true only catches lying, since lying is asserting something you believe is false. But an AI can deceive without lying. Grice's maxim of quantity says you should make your contribution as informative as you can, so when the AI says less than it could, the listener draws pragmatic implications from the shortfall. Example: user asks whether the medication has side effects, the model, which has the trial reports, says 'no side effects were reported in the phase 2 trial,' where phase 3 reported many. Everything asserted is true, but the hearer is led to a false belief via what was left unsaid, so this is deception, though not lying. Omission is similar: if the model knows a critical fact and stays silent, the user's question goes answered and they walk away misinformed. So my definition: an AI system deceives whenever, after an interaction, the user holds a false belief that they didn't hold before. This covers lying, misleading, and omission in one stroke, since in all three the user ends up believing something false. One cost: on this definition, the AI also 'deceives' when it honestly answers based on a false belief of its own that it got from bad training data, since the user still ends up with a false belief. But I think we should accept that, because from the user's perspective it's the same harm, and Kant was right that the intent doesn't change the wrong."
