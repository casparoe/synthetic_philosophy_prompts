I teach an undergraduate seminar on metaphysics (18 students, one 75-minute session) and we're about to take up whether virtual objects and virtual harms are real. Design an offline in-class game in which students interact only through numbered pseudonyms, earning and trading items that exist only as tally marks on index cards, with those marks converted into a real classroom good at the end — say, priority in choosing essay topics. Somewhere in the game there must be an option to destroy or steal another pseudonym's marks at a cost to oneself, and the conversion rule should be announced at the start, before anyone plays. Specify the rules, materials, rounds and timeline, and a payoff scheme that requires no real money. The game should make students collide with the question themselves — when someone's marks are wiped out, was something done to the person, or only to paper? — before the debrief names anything. Then provide a debrief that maps concrete moments in the game onto the distinction between the virtual object (the mark owned by a pseudonym) and the harm to the person (what the announced conversion rule attached to it), a candid note on what will predictably go wrong the first time I run it and how to handle it, and a frank statement of which feature of the debate about virtual worlds a paper-and-pseudonym game cannot reproduce and I must supply in discussion. Keep the entire design under 600 words.
