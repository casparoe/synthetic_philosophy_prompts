I run a reading group of ML PhD students on safe exploration and reward misspecification. For our session on impact measures, I want a decision tree that takes a designer from the starting commitment "an agent pursuing a possibly misspecified objective should not irreversibly disrupt things we never told it about" to a named position in the low-impact literature. Each branch node should be a technical design choice the designer could answer without already knowing which proposal it leads to. Please use at least these axes, phrased as questions: (1) is impact a deviation of the world-state from a counterfactual baseline, or a reduction in the ability of some set of goal-pursuers to achieve their goals later; (2) if a baseline is used, which one — the starting state, the trajectory the world would have followed had the agent never acted, or a stepwise baseline recomputed at each timestep as though the agent had done nothing since the previous step; (3) whether the auxiliary objectives used to measure lost options must carry any information about what humans actually value, or whether they can be arbitrary or even randomly generated; (4) whether impact enters as a hard constraint or as a penalty traded off against the primary reward; and (5) a case-based node about offsetting: when the agent has caused a side effect, is restoring the baseline (e.g., repairing the vase it broke, or locking the door it opened) the morally clean thing to do, an acceptable way to discharge the penalty, or a perverse incentive that lets the agent do whatever it likes so long as it undoes the visible trace. Leaves should include relative reachability in its stepwise and starting-state variants (Krakovna et al., 2018), attainable utility preservation (Turner et al., 2019), Armstrong-style low impact defined over a small set of explicitly specified value-relevant variables (Armstrong, 2017), and the pessimistic position that no measure of impact can substitute for value information, so the whole project fails without it. Where combinations of answers correspond to no published position, mark the leaf 'unnamed' and say whether you think it is unoccupied because the view is incoherent, unattractive, or merely unexplored. Build the logical space of answers first and only then locate the named positions inside it; and flag any pair of leaves your tree cannot genuinely separate, rather than inventing a node for the purpose. Around eight to twelve leaves, with each branch node stated in a sentence or two and each leaf given one sentence on its most awkward commitment.
