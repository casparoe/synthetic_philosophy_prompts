I've been thinking on my own about whether an AI can be told to avoid side effects before anyone knows, in full detail, what we humans care about. The little scenario I use is a cleaning robot in a room with a vase it has no reason to touch: if the robot is only rewarded for cleaning, knocking the vase over costs it nothing, so we'd like to add some penalty for changing the world in ways the task doesn't require. My problem starts when I try to say what the penalty compares the world against. If the comparison is the world in which the robot never acted at all, then wiping the counter — the very thing we asked for — comes out as a side effect. If the comparison is the world as it was a moment ago, then a robot that nudges the vase slightly each step seems to incur only tiny penalties that add up to a shattered vase, and a robot that breaks something once and then sits still looks almost blameless from then on. I also tried inventing a rule of my own: penalize the number of things in the world the robot affects at all, so that touching nothing unnecessary is always cheapest. But it seems to fail the other way — a robot that permanently switches off everything in the room in one motion has "touched" the world very cheaply while leaving it far more changed than a robot that makes many small, reversible adjustments. Please explain, in terms I can follow, what the serious answers to this baseline problem look like — I've gathered that people have tried penalizing the loss of future options, and something about keeping the environment able to serve goals other than the one it was given, but I don't understand how those ideas get around my worry. And then tell me whether you think the difficulty is merely technical, or whether it reflects something deeper: that "impact" is only ever impact relative to some set of things someone values, so that a value-free definition of a side effect is not a real possibility but a confusion.
