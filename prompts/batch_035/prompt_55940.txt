I teach a survey course in philosophy of law, and I'm building a session on whether ideas can be owned. Take Google v. Oracle — the Supreme Court's 2021 decision holding that Google's copying of roughly 11,500 lines of Java API declaring code for Android was fair use — and analyze it as a case study in the standard justifications for intellectual property: the Lockean labor theory, the utilitarian incentive story, and the Hegelian account of expression as an extension of personality. The key subtlety is what was actually at issue: not the implementing code, which Google wrote itself, but the interface — the names and organization of the packages, a system for classifying tasks that programmers had to reproduce exactly for the programs to interoperate. So run the mapping carefully: for each of the three theories, say what it would have to conclude about owning an interface of this kind, where it is silent, and whether an API is even the sort of thing that theory was meant to cover — is it more like a plot synopsis, or more like a table of contents, or neither? Then consider the wrinkle that most of the interface's value came not from Oracle's design but from network effects: millions of programmers had already learned it. Does that make the Lockean and Hegelian cases stronger or weaker, and what does it do to the incentive story? Finally, be honest about the fact that the Court decided the case on fair use and never reached whether the API was copyrightable in the first place. Was that a dodge, or is the fairness inquiry precisely where these ownership theories do their real work — and if so, what does that tell my students about the relationship between the justifications and the doctrine?
