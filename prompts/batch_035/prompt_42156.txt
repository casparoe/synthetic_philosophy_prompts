I'm a novelist (speculative stuff, mostly), and my current book is set on a half-surveyed planet where the main character is a xenobiologist. She keeps field notes on the local fauna, and I want her to use a cognitive sorting key — a dichotomous key like botanists use for plants, except instead of "leaves opposite or alternate" the questions are about how the animal thinks. The framework I have in mind is Dennett's four kinds of minds: Darwinian creatures (purely hardwired, only evolution ever did the designing), Skinnerian ones (learn by trial and error out in the world), Popperian ones (run the trials internally, so their mistakes can die instead of them), and Gregorian ones (bootstrap their thinking with tools, culture, and whatever other minds have already figured out).

What I need from you is the key itself, as a decision tree. Rules for the tree:

1. Every node has to be a question my biologist could answer from observation — behavior in the field, an experiment she improvises with a stick and some bait — not "is it Gregorian?" and not anything that requires already knowing the label. The whole point of the tree is that it assigns the label, so it can't presuppose it.
2. Build the tree from the criteria first, then locate the four kinds at the leaves. If a node question could be answered "yes" by an animal that's clearly only one kind, that question is no good.
3. Flag the pairs your tree genuinely can't separate — I suspect Popperian vs. Gregorian is the worst one (a smart corvid that both puzzles things out and raids other birds' caches), but also tell me where the tree misfires on single-trial learning like taste aversion in rats, and on social learning generally, since imitation without understanding seems to straddle the whole ladder.
4. Give me five worked examples run through the tree: at least two real animals (your pick, but make them tricky — not "dog = Skinnerian"), at least two creatures from my book (see below), and one deliberately ambiguous case where you show the tree giving a wrong or unstable answer.

The creatures from my book, for the examples: a six-legged grazer that flees shadows but never learns which shadows are actually dangerous; a mimicking reptile that copies other species' alarm calls after a single exposure but never uses those calls deceptively; and a colonial slime-mold-like mass that solves mazes (I know, I know, Physarum — I stole it). I honestly don't know where that last one should land and I'd love to see the reasoning.

Since I'm going to print the key as an in-world document, I'd like it back as structured data so my editor can typeset it without parsing prose. JSON, schema roughly like this:

{
  "nodes": [ { "id": "n1", "question": "...", "yes": "id of next node or leaf", "no": "id of next node or leaf", "note": "what this question is really testing, one line" } ],
  "leaves": [ { "id": "L1", "kind": "one of the four", "definition": "one sentence in plain language", "awkward": "the case where this leaf gives the wrong answer" } ],
  "unseparable": [ { "pair": "e.g. Popperian vs Gregorian", "why": "..." } ],
  "examples": [ { "creature": "...", "path": ["n1", "n4", "..."], "leaf": "L2", "commentary": "..." } ]
}

Field names can change if you need better ones, just keep the structure. And if a node wants a third answer (sometimes / can't tell from the field), give it one — real botanical keys do, and frankly my biologist will hit "can't tell" a lot.

One last thing — dont worry about matching how Dennett deploys the categories perfectly. He's scaffolding for the novel, not an authority I have to cite. What I care about is that each node is answerable by looking, and that the leaves actually sort my fauna differently. If two of my three book-creatures land on the same leaf anyway, say so, and tell me what node you'd add to split them.
