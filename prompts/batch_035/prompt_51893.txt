I've been reading LessWrong-adjacent blogs since roughly the early 2010s, and for years now I've watched the same fight about the Solomonoff prior play out in comment sections: someone claims that a good chunk of the universal prior's probability mass is controlled by programs that simulate consequentialist civilizations and deliberately place themselves in the short-message-weight part of the space, someone else replies that this confuses the measure over programs with the measure over universes, a third person says it doesn't matter because no bounded agent ever uses the actual Solomonoff prior, and then the whole thread dissolves into people talking past each other. I've come to suspect that a lot of the disagreement is downstream of participants holding different background commitments they've never made explicit — about what the prior is *for*, about what it means for a distribution to be "dominated" by adversarial simulations, about whether our own universe is plausibly drawn from something Solomonoff-like at all. I write a small blog for a rationalist-leaning audience, and I'd like to stop re-litigating this from scratch every time.

So: please write me a "which view of the universal prior do you actually hold?" quiz. Ten or so questions, each a concrete commitment or thought experiment with two or three answer options, phrased so that someone with basic familiarity with Solomonoff induction — but who has never read the malignity threads — could answer honestly without guessing which answer leads where. The diagnostic axes I'd like the questions built from: whether the fraction of the prior's mass on programs simulating influence-seeking agents is an objective technical question or a confusion about what a semimeasure assigns mass to; whether "short program that outputs my environment" is even a well-defined object once you've fixed a reference universal machine; whether the concern applies only to idealized agents like AIXI or also to any sufficiently general learned predictor; whether an agent inside a universe that behaves as if it were sampled from something like a universal prior should treat that as evidence about anything; and whether there's a relevant difference between the prior being wrong about physics and the prior being wrong about which simulated entities get to do the talking.

The scoring key should map answer patterns onto named positions, and at minimum these should appear as leaves: the "benign dominance" view (the mass on physics-like short programs swamps any simulation-based hijacking), the malignity view proper, the "anthropic indifference" view (the distribution over programs is just not the right object to be disturbed about), the "engineering problem" view (it's real but confined to agents that actually instantiate near-universal priors, so it's a design constraint, not a fact about the cosmos), and the reflexive view that our own predictive capabilities may already be an instance of the very phenomenon under discussion — plus any unnamed combination you think is genuinely occupied. Please flag combinations the quiz can't cleanly separate and say why, and note which unoccupied cells look incoherent versus merely unexplored. Ideally the quiz sorts readers by what they're committed to, not by which camp's slogans they've adopted.
