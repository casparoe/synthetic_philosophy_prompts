I'm a software engineer with no formal philosophy training, and I organize a monthly reading group at work; this month's topic was Dennett's intentional stance and how far it reaches into machine-learning systems. The question I set: Dennett characterizes an intentional system as one whose behavior can be reliably predicted by attributing beliefs and desires to it and working out what it would then rationally do. Suppose that strategy predicts a large language model's outputs well for many purposes. Does it follow, on Dennett's account, that the model has beliefs? And what, if anything, is left of the gap between treating the model as believing that p and the model's believing that p?

The answer I received:

Two claims in the question need separating: whether the model is an intentional system, and whether it has beliefs. Dennett defines the first entirely in terms of whether a predictive strategy succeeds, not in terms of what the system is made of, so an intentional system is nothing over and above a system to which the belief-desire-rationality recipe can be applied. That recipe applies to a large language model often enough, so the model is an intentional system; and since there is no component anywhere in the weights that could be pointed to as the belief, no further fact about the model could settle whether it really believes. Here Dennett is an instrumentalist: beliefs are useful fictions, patterns in what a system does rather than inner states with causal powers, so treating the model as believing that p and the model's believing that p cannot come apart, and asking which of the two is correct is like asking whether the table is really made of atoms. The thermostat case shows this cannot be the whole story. A thermostat's behavior can be predicted by attributing to it a belief about the room temperature, so if predictive success were the criterion, a thermostat would have beliefs; since it plainly does not, something further must be required, and that something further is what Dennett means by being a true believer, a status he reserves for conscious systems. It follows that the model is an intentional system without having beliefs. In any case the design stance is the one that governs a system whose architecture we wrote, the intentional stance being only the fallback for when the design is too complicated to compute with, so an intentional description of a model is a computational shortcut, and a shortcut cannot ground beliefs.
