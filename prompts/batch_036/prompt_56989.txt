here's #14:

Hume's problem is that induction can't be justified at all. Take "the sun has risen every day so far, so it will rise tomorrow." That inference isn't deductive, since you can imagine the course of nature changing tomorrow with no contradiction, so the premise doesn't entail the conclusion. It also isn't provable by experience, because any argument from what has happened so far to what will happen rests on the assumption that the future resembles the past, which is the very thing in question. So the argument is either invalid or circular. Hume's own conclusion was that induction is grounded in custom and habit rather than reason, and that's as far as you can push it.

Wolpert's no-free-lunch theorem is supposed to be that result with a proof attached. The setup: fix a space of possible target functions, i.e. all the possible ways inputs could map to outputs. A learner (or, in the version Wolpert and Macready did, a search or optimization method) is scored on how well it predicts or optimizes. Now average that score over every function in the space, weighting them all equally. Any two algorithms get the same average. The mechanism is that whatever structure an algorithm exploits gets paid for elsewhere: for every function where a bias toward smoothness helps, there's a function where that same bias actively misleads you, and the bad ones exactly cancel the good. So if an algorithm beats blind search on one class of problems it does worse than blind search on the complementary class. And since all possible worlds are in the space, this isn't an assumption about the world, its just arithmetic.

Which is Hume's dilemma again. You can't get from the data to a claim about the unobserved part of the world without importing assumptions, and no assumption is worth more than any other. So on any particular problem your algorithm is no better than random guessing unless it gets lucky. It follows that you can't treat a theory's past success as evidence that it's roughly true, because track record only counts if the future resembles the past, and the theorem shows that principle buys you nothing. This is where Popper was heading when he said we never have positive reasons for a theory, only the absence of refutations. NFL is his position written down formally.

Though I don't think that's much comfort to the sceptic. Learning actually works because the world isn't a random draw from all possible functions. It has structure, and a bias that matches the structure does measurably better, and you can check that it does. So the theorem's real content is about matching your assumptions to your problem, which is a smaller claim than Hume's and a more useful one. Honest summary: Hume says you can't justify induction, NFL says you can't justify it for free.
