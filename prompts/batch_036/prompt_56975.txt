In the Gödel unit of my philosophy of mind course, our teaching assistant tried to dispatch the Lucas–Penrose argument with a single analogy, and roughly half the section found it convincing. He asked us to think of a formal system as a legal code and of a human mathematician as a legislator. The code issues verdicts by fixed procedure but cannot, from within, certify that it never issues contradictory ones; its Gödel sentence is the case for which the code contains no provision; and the mathematician, precisely because she is not the code, can stand outside it, see that it is coherent, pronounce the uncodifiable verdict true, and then amend the code to cover the case. His claim was that the whole anti-mechanist argument is this picture and nothing more: the "outside" the mathematician occupies is donated by the analogy, and once you withdraw the picture, all that remains is a theorem about codes, which says nothing about minds.

I would like a careful audit of the analogy rather than a ruling on the argument. Please set out the correspondence explicitly — axioms, derivation rules, theorems, the Gödel sentence, consistency, and whatever in the picture is meant to correspond to the mathematician's insight — and then the disanalogies, separating those that actually bear on the deflationary use he made of it from the merely decorative ones. In particular: does the analogy preserve the difference between knowing that a system is consistent and knowing that it is sound, since soundness is what the anti-mechanist needs? Does it quietly assume that a code is short enough to be surveyed from the outside, when the systems at issue are not? And what does it imply about the requirement that the mathematician know which machine she is supposed to be?

One thing puzzles me, and I would like you to press on it. The amended code has a fresh Gödel sentence, and the legislator can amend again, so her supposed position outside every code looks like an endless ladder of ever larger codes — which is exactly the kind of self-extending procedure a machine might in principle climb too. If that is right, does the analogy refute the mechanist, or does it merely describe him? State whether his conclusion survives once the disanalogies are on the table, and, if the rulebook picture is the wrong one, offer a better analogy for the relation between a mathematician and a formal system — or explain why we should resist analogizing here altogether.
