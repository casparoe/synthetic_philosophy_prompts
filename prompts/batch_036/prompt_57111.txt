I am in the fourth year of a philosophy PhD; my dissertation is about the normative assumptions that get baked into machine-learning design choices, and the chapter on low-impact AI has run into what looks to me like a fatal problem with the framing I inherited. I would like a check on whether it is really fatal.

The framing is this. Impact measures are supposed to let us penalize an agent's side effects without first settling what the agent should value. Relative reachability does it by comparing, after each action, how much of the future state space remains reachable against how much would have remained reachable under some default continuation; attainable utility preservation does something structurally similar in terms of the agent's residual capacity to pursue various auxiliary goals. In both cases the advertised virtue is that the quantity is value-neutral: you can compute it without a complete account of what matters.

Here is the worry, in the concrete form I am using in the chapter. Take an agent whose task is to hold a server room below twenty-five degrees. Running the compressor now is irreversible in countless ways. It forecloses futures in which the room drifted to twenty-six degrees for an hour, and it equally forecloses futures in which the room is identical except for the position of a single dust mote on a shelf. Reachability counts both classes as forfeited and counts every member of each class the same way, because it counts states rather than weighing them. So the measure is not value-neutral at all. It is a substantive and rather extreme axiology on which the foreclosure of any two distinguishable futures is equally bad, however trivial the difference between them, and the only way to escape it seems to be to import precisely the weighting the measure was supposed to spare us: discount near-identical futures, privilege some variables over others, and so on, which is to say, write down a utility function after all.

If that is right, the concept has collapsed in both directions at once. An agent minimizing such a penalty is best off abstaining from its task, since abstention is the only policy with no side effects to speak of; and if instead we repair the penalty by supplying real values, the measure is no longer doing any independent work, and low-impact AI turns out to be a placeholder for a value-learning project that has not happened yet.

So my question is what survives. Is there a non-question-begging sense in which these measures can still be called value-neutral once we grant that they rank futures? And does the impact measure retain a job to do that a complete utility function would not already be doing?

Please open with your bottom line in the first sentence and then give me the reasoning. No preamble, and please do not restate the question back to me.
