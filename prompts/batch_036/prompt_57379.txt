**Question:** State the symmetry problem that Buridan's ass is meant to raise for the view that an agent always acts on whichever reason is strongest. Then say whether an agent that settles exact ties with a random device — a coin flip, say — escapes the problem, and explain why or why not.

**Student's answer:** The case is a problem for that view because if two options are backed by exactly equally strong reasons, there's no fact about which reason is strongest, so on the view nothing can issue in action: the agent just freezes there and dies. Buridan's own reply was that the will can suspend judgement until circumstances change and the balance tips, so he wasn't committed to the ass actually starving. Spinoza accepted that solution as well, and since he was a determinist about the will anyway, he took the case to show nothing about freedom.

Also, rational choice theory can't even describe the situation, since it requires a strict preference ordering over the options and an exact tie means there isn't one. So the paradox is mostly an artifact of a bad formalism.

In practice exact ties never occur, which makes the case an empirical curiosity rather than a philosophical problem. Where ties do bite — say an agent whose two available outputs come out scored exactly equal — the fix is a random tiebreaker. And this doesn't merely solve the practical problem, it restores free choice: because the coin isn't determined by the agent's reasons, the resulting action isn't determined either, so the agent ends up free in the way Buridan's picture denies.
