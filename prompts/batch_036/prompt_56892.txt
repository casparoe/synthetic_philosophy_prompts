Thirty-eight years in a trace-analysis laboratory, now retired and reading epistemology for pleasure. I keep failing to find a word for a practice that was routine in my working life.

A validated screening method has a measured false-positive rate — call it one in twenty — so when we reported a batch of two hundred results we expected roughly ten to be wrong, and we said so in the report. We did not believe all two hundred; but neither did we disbelieve any particular one, since each rested on evidence exactly as good as the evidence for every other, and there was no principled way to nominate which ten would fail. We nonetheless acted on each result individually, while provisioning for the expected number of failures: confirmatory runs set aside the way one sets aside spares.

What strikes me as distinctive is that the error count is a computed number rather than a mood of humility, and yet the set is knowingly false in that quantified way while every member remains actionable. This seems adjacent to the preface and lottery paradoxes, though neither fits precisely: the preface author does not know how many errors to expect, and in the lottery the losing ticket is already fixed, whereas here the failures are statistically specified but individually unidentifiable.

Is there an established term for accepting each member of a set while holding a quantified expectation of how many are false, and provisioning for that number? If there is, how is it standardly formulated; if there is not, say so plainly and propose one, defined sharply enough to separate this from generic fallibilism, from reporting each claim at a confidence level (we did not hedge the individual results — we asserted them and expected to be wrong about some), and from suspending judgment on the batch as a whole. Please also state how confident you are in your identification, and single out the point you are least sure of.
