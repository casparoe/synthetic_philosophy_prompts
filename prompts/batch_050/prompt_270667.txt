The exam question was: "Explain Curry's paradox: give the derivation, explain how it differs from the standard liar paradox, and say which logical principle or principles a solution might plausibly target. Then state Yablo's paradox and explain why it is often taken to show that self-reference is not essential to semantic paradoxes. Do you think it really avoids self-reference?"

Here is the student's answer, verbatim:

"Curry's paradox starts with a sentence C that says: if C is true, then P, where P can be anything at all, like 'the moon is made of cheese.' The derivation goes like this. Suppose C is true. Then what C says holds, so if C is true, then P. By modus ponens, P. So from the assumption that C is true we've derived P, which is exactly what C says, so by conditional proof C is true. Then P follows outright, with no assumptions left. Unlike the liar, this doesn't deliver a contradiction; it 'proves' an arbitrary sentence, which is arguably worse. The culprit isn't the negation rules but the structural rule of contraction, since the assumption that C is true gets used twice in the derivation. So one response is to restrict contraction, as relevant and other substructural logics do. Note also that the derivation is essentially classical, since the conditional proof step relies on the law of excluded middle, which is why intuitionistic logic is immune to Curry's paradox.

Yablo's paradox: take an infinite sequence of sentences S_1, S_2, S_3, ..., where each S_n says 'for every m greater than n, S_m is false.' Suppose S_1 is true. Then every later sentence is false. But S_2 being false means some sentence after S_2 is true, which contradicts what we just said. So S_1 is false, which means some S_k with k > 1 is true, and running the same reasoning on S_k yields a contradiction again. So either way we're stuck, even though no sentence ever mentions itself. Strictly speaking, though, I don't think this really escapes self-reference. Each sentence quantifies over the sequence, and since the sentence is itself a member of that sequence, it still refers to itself, just indirectly. So Yablo's construction doesn't eliminate self-reference; it just spreads it out over infinitely many sentences."
