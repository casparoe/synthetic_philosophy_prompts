I lead an applied ML team at a media streaming company, and several times a quarter someone proposes inferring a user preference from behavioral logs -- watch time, skips, rewinds, re-watches, session abandonment -- and baking that inference into a ranking objective. I want to push back on the casual ones systematically. The relevant insight from inverse reinforcement learning is that observed behavior underdetermines the reward function that generated it: the same trajectory is consistent with many reward hypotheses, so any inference from behavior to preference rests on auxiliary assumptions about the agent's rationality, planning horizon, knowledge, and constraints. Please turn that insight into a written procedure my team can run on any proposal of the form "behavior X shows users prefer Y": the questions to ask in order (e.g., what rationality model we are assuming, what rival reward hypotheses -- habit, default effects, constraints mistaken for tastes, short-term impulse versus considered preference -- explain the same data, and what intervention or variation would discriminate among them), what counts as a sufficient answer, where the procedure halts with "no preference inference licensed," and which steps remain judgment calls. Then apply it to three cases: inferring that users prefer autoplay from the fact that autoplay users watch more; inferring that users prefer sensational content from its high click-through; and inferring that users are indifferent to a privacy setting from the fact that almost nobody changes the default. At least one application should conclude that an inference leadership will want is not licensed. State plainly what the procedure cannot settle.
