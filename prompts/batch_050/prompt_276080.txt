I've been thinking about how moral theories should handle universes containing infinitely many people, and I keep running into a configuration I don't have a word for. Imagine an endless universe populated so that every welfare level that occurs at all occurs infinitely many times: infinitely many flourishing people, infinitely many miserable ones, and so on for every level in between. Now suppose one person is made slightly better off and nobody is harmed. Intuitively this is an improvement. But the universe's inventory is identical before and after, since removing one person from an infinite stock leaves an infinite stock: there are still infinitely many people at every level either way. So any comparison rule that goes by how many people are at each welfare level is forced to call the improved universe exactly as good as the original — and, by the same reasoning, to call a strictly worsened universe equal to it too. This strikes me as different from the familiar complaint that infinite totals make finite changes look negligible: the problem here isn't that the change is small relative to the total, but that no inventory-based comparison can detect it at all. Does this configuration have an established name? If so, how does it relate to the nearest named problems in infinite ethics? If not, please name and define it, and mark its edges: does it still arise if the person's original welfare level occurs only finitely many times, and does it arise for comparisons within a single universe as well as between possible universes?
