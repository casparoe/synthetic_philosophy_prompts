For a graduate seminar on meaning and interpretation, please diagnose the following argument, which I cannot accept but whose steps each have some plausibility. Use the familiar tripartite vocabulary in this stipulative way: the inner message is the content an interpreter finally grasps; the outer message is the code, grammar, genre, or set of conventions by which marks are taken to carry that content; the frame message is whatever makes an object or event salient as something to be interpreted at all rather than merely noticed, used, or ignored. The argument runs as follows. (1) Recovering an inner message from an artifact requires taking the artifact as message-bearing and taking its marks as governed by some outer message; bare ink, sound, or stone does not interpret itself. (2) Neither the frame nor the outer message can be read off the inner message alone, since if they could there would be no cases in which the same physical object sustains rival competent readings. (3) A cue can serve as a frame only for someone already disposed to treat situations of that kind as communicative; even an explicit marker such as a title, preface, signature, stage, liturgical setting, or museum label works only after the marker has itself been taken as a marker. (4) Therefore every first uptake of an artifact rests on a frame not wholly supplied by that artifact. (5) But when an interpreter meets the first instance of a radically new genre, no relevant prior frame exists, by the hypothesis of radical novelty. (6) Any appeal to neighboring practices to supply the missing frame either changes the subject, because the work is then being treated as an instance of an old kind rather than the new one it is, or covertly presupposes the very act of uptake that was to be explained. (7) So the first instance cannot be understood as intended; it can only be projected into older genres and thereby misread. (8) Generalizing, no genuinely new meaning can enter a tradition: what looks like novelty is always either old content in disguise or error. This proves too much, since traditions do sometimes add forms that competent audiences come to inhabit from the inside rather than merely assimilate by force. Tell me which premise or inference you would reject, why it initially looked sound, and what each of the main alternatives costs: rejecting (1) by locating some interpretability in the object itself; rejecting (3) by allowing explicit markers to bootstrap their own authority; rejecting (5) by distinguishing an exact genre-frame from transferable frames drawn from perception, embodiment, ritual, play, or neighboring arts; or rejecting (6) by giving a non-circular account of how several imperfect cues can jointly tutor an interpreter during a first encounter. If more than one step must be weakened, say which combination is least damaging. I am most reluctant to surrender (2), because I do not want ambiguity to become an illusion, and I am also reluctant to say that meaning is simply intrinsic to marks. Write the answer as continuous prose only, with no headings, bullet points, bold text, or tables, in the manner of a careful letter to a colleague.
