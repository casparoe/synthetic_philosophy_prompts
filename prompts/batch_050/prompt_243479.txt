Exercise (written by me): In The Principles of Mathematics (1903), Russell argued that the contradiction arises from the assumption that any precisely stated condition determines a class of all and only the things satisfying it. (a) State this assumption precisely, and reconstruct step by step how it generates a contradiction. (b) Explain how Zermelo–Fraenkel set theory's axiom schema of separation blocks the argument, and what positive conclusion the same construction nonetheless delivers within ZFC. (c) Russell's reasoning is often described as diagonal, like Cantor's theorem. Explain how Russell's paradox relates to Cantor's theorem, and say whether both results survive in ZFC.

Member's answer: (a) The assumption is unrestricted comprehension: for any condition on x, there exists a set containing exactly the objects satisfying it. Take the condition "x is not a member of itself" and let R be the set of all such x. Suppose R is a member of R; then R meets the condition, so R is not a member of R. Suppose R is not a member of R; then R meets the condition, so R is a member of R. Both cases are contradictory, so the comprehension assumption must go. (b) Separation only licenses forming {x in A : x satisfies the condition} for a set A already secured. Given any set A, form B, the set of members of A that are not members of themselves. If B were a member of B, it would both meet and fail the condition, so B is not a member of B. But then if B belonged to A it would meet the condition and hence belong to B; so B is not in A. Since A was arbitrary, no set contains every set: there is no universal set. In spirit this follows Russell's own remedy in the theory of types: the question whether a set is a member of itself is treated as meaningless, so the offending instance of comprehension cannot even be formulated. (c) Russell's argument is diagonal in the same style as Cantor's proof that the power set of A strictly outnumbers A. Cantor's theorem, however, was another casualty of the paradoxes: applied to a universal set it yields an immediate contradiction, so ZFC restricts it to suitably small sets, and for unlimited collections the power-set comparison no longer applies.
