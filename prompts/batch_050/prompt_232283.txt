(1) If a cosmological model implies that observers with exactly my memories and evidence almost always have *fabricated* memories and live in a world nothing like what their evidence indicates, then accepting that model defeats the very evidence i'd use to accept it. (this is the "cognitive instability" idea, i think the name is Carroll's)

(2) Eternal inflation models with an everlasting de Sitter-ish phase produce Boltzmann brains without end but only finitely many ordinary observers like us, so BBs dominate the observer count by whatever ratio you want.

(3) So on those models, observers with exactly my evidence are almost all Boltzmann brains.

(4) So accepting those models defeats my evidence.

(5) A model that defeats the evidence for itself cant be rationally accepted, so those models are ruled out.

So far this is just the standard BB objection, i think. But then:

(6) The defeater in (4) covers ALL my evidence, including the CMB data, supernova observations, everything that motivated the inflationary picture in the first place.

(7) But if all that data is defeated, then the claim in (2) -- that our actual universe is like this -- has no evidential support either. So the defeater can never get going. It saws off the branch it's sitting on before it touches the model.

(8) And this generalizes: no model can EVER be ruled out by Boltzmann brain counting, because the counting always relies on evidence that the model itself allegedly defeats.

(9) So the Boltzmann brain problem is a pseudo-problem, and cosmologists fretting about the measure problem for this reason are wasting their time.

(9) feels absurd. It would equally prove you can never have self-locating grounds to worry you're a BB right now, or in a simulation, and it seems to make the whole typicality/measure debate evaporate by a trick. But each step looked fine when i wrote it.

Which step do i reject, and what does rejecting it cost? I'd most like to keep (1) and (5) since they seem like basic rationality, and (2) is just the physics as i understand it.
