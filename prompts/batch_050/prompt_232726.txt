Here is the exam question:

"Every particular event belongs to indefinitely many classes, and the frequency of a given outcome can differ from class to class. A doctor wants to tell a 60-year-old patient who smokes her risk of developing lung cancer in the next ten years. (a) State the reference class problem. (b) Give your own example (numerical if you like) showing how the problem arises in this case. (c) Explain why the problem is especially pressing for someone who wants to interpret the probability of a single event as a frequency. (d) Consider the proposal that we should always use the narrowest available reference class. Does it succeed?"

Here is the student's answer:

(a) The reference class problem is that when we want to assign a probability to a single event or individual, we can only get a frequency by placing that event in some class of similar cases, but the event belongs to many different classes at once, and these classes give different frequencies. There is no rule built into the concept of probability itself telling us which class is the correct one, so the probability of the single case seems underdetermined.

(b) Suppose that among all 60-year-olds, 4% develop lung cancer within ten years; among 60-year-old smokers, 14%; among 60-year-old smokers who also have a family history, 20%; and among 60-year-old smokers who exercise daily, 9%. If the patient belongs to all four classes, the doctor can honestly quote any of these numbers depending on which class she picks, and each choice can be defended as "the relevant statistics."

(c) This matters most for the frequency interpretation. If the probability of an event just is the limiting frequency of the outcome in an appropriate class of trials, then for a one-off event -- this patient, this decade -- the probability is only as well-defined as the choice of class. The problem is not merely that we lack data; even with unlimited data on every class, we would still have to decide which class is the right one. So for a strict frequentist, a probability statement about the single case is meaningless in itself; probabilities only attach to classes, and saying "this patient's risk is 14%" is a shorthand that smuggles in a choice the theory doesn't make for us.

(d) The standard solution is to use the narrowest reference class available, because the more of the patient's features a class captures, the more informative its frequency is about her in particular. The only constraint is that the class still has to contain enough members for the frequency to be stable, and since every individual belongs to some narrow class for which we can gather adequate statistics, the problem is soluble in practice: pick the most specific class that is well-populated. One might worry that the choice of which features to include is partly a practical decision -- insurers and doctors choose classes based on what data exists and what they're permitted to ask about -- but this just shows that the patient's risk is ultimately a convention of our classificatory practices rather than a fact about her, and once we accept that, the narrowest-class rule is as objective as anything could be here.
