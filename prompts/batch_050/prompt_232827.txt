I'm taking a course on the philosophy of probability, and for a seminar I've been asked to write down my position on the reference class problem so that the others can try to pull it apart. Here it is:

1. Single-case probabilities are objective features of the world, not merely measures of our ignorance: there is a fact of the matter about the probability that I, specifically, will be in a car accident this year.
2. There is no uniquely correct reference class for any given event; which class we place it in is ultimately a pragmatic choice, sensitive to our interests and to the statistics we happen to have.
3. Actuarial practice is perfectly rational: an insurer is right to set my premium using the frequency of accidents in some broad class I belong to, such as drivers of my age and region.
4. I am entitled to reject an argument when my interlocutor assigns me a probability on the basis of a reference class chosen opportunistically to make their point (e.g. citing statistics for left-handed violinists when arguing about my life expectancy).
5. Relative frequencies are, in the end, all the evidence we ever have for any probability judgment.

Please go through these commitments and tell me which pairs are in genuine tension and which only appear to be. For each real tension, say how severe it is, what exactly forces the conflict, and what the cheapest fix would be and what it would cost me. Then tell me which single revision would do the most to make the whole set coherent. Please answer in British English.
