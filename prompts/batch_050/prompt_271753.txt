Here is the question I set:

Both Tarski's hierarchy of languages and Kripke's theory of truth-value gaps are attempts to block the Liar paradox. Explain how each proposal treats the Liar sentence, identify one significant cost or limitation of each, and discuss whether either approach survives the "strengthened" Liar ("This sentence is not true").

Here is the member's answer:

"Tarski's solution is to ban self-applicable truth predicates by stratifying language into a hierarchy. Truth for a language L is defined only in a richer metalanguage L', truth for L' in a still richer language, and so on, with the T-schema ('Snow is white' is true if and only if snow is white) holding at each level. The Liar sentence can never be formulated, since forming it would require a truth predicate that applies to its own language. So within the hierarchy the sentence is simply ill-formed, and Tarski showed that this resolution carries over straightforwardly to natural languages like English. The cost is that the hierarchy is artificial: ordinary speakers assess the truth of claims about truth itself all the time, and the theory cannot make sense of this.

Kripke instead permits sentences that are neither true nor false. Working with three truth values, he builds up the extension of the truth predicate in stages until it reaches a fixed point. Sentences like the Liar receive no truth value at any stage; Kripke's diagnosis is that the Liar is meaningless, since it never gets grounded in non-semantic facts. Because Kripke abandons bivalence, his theory requires giving up classical logic altogether, which is a heavy price for ordinary mathematical reasoning. The strengthened Liar ('This sentence is not true') is ungrounded as well, hence neither true nor false. But then it is not true, which is just what it says, so it seems true after all. Kripke resolves this by noting that calling the sentence untrue is a move made in the metalanguage, and this fully dissolves the revenge problem.

Graham Priest's dialetheism, by contrast, simply accepts that the Liar is both true and false, using a paraconsistent logic so that the contradiction does not entail everything. This avoids the hierarchy's artificiality and handles the strengthened Liar with no additional difficulty."
