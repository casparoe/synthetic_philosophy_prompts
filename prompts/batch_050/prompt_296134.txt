I run a little reading group at my company (I'm a backend engineer, no formal philosphy background) where we keep trying to talk about AI alignment and getting stuck on what the word even means before we get anywhere near how to solve it. Half the room uses it the narrow way I associate with Paul Christiano, where the problem is just getting a system to be trying to do what its operator wants, and the other half insists it has to mean the system ends up with the right values, and then inevitably someone asks whether a model with sneaky inner goals is an alignment failure or a training failure, and by then the hour is gone.

So I want a sorting quiz for the group: 8 to 10 questions, each one a concrete scenario a working engineer can react to without knowing any of the labels -- an autocomplete that flawlessly helps its user write a manipulative email, a recommender that maximizes watch time because that's literally what its reward said, a household robot that understands exactly what you want but politely refuses, a model that would do what its developers want but not what the end user wants, stuff like that, and feel free to invent better ones. Each answer option should commit you to a verdict about whether the scenario is an alignment failure at all, and if so whose. Then give a scoring key that maps answer patterns onto the positions: narrow intent alignment, full value alignment, the outer-vs-inner split (is the problem the objective you trained on or the goal the system actually learned), corrigibility-as-the-real-problem, and the deflationary view that alignment is a cluster of loosely related problems and we should retire the word.

Two specific requests. First, build the key from the answer patterns, not the labels: I want it to sort people by what they'd say about the cases, not which camp they already think they're in, so no question should just ask whether you think intentions or values matter more. Second, if some combination of answers doesn't land on any real position, say so and guess why nobody sits there (incoherent, unattractive, or just unexplored), and if the key genuinely can't separate two of those positions, flag that instead of fudging it. Start with the quiz itself, no intro or terminology overview first.
