I’m a software engineer with no formal philosophy background, helping to design the final assessment for an upper-level undergraduate seminar on rational agency and machine cooperation. I need one 75-minute essay question on program equilibrium, together with a model answer and marking scheme.

Please base the question on this fictional protocol rather than on the standard textbook example:

Two firms each submit the source code of a deterministic pricing agent to a neutral runtime. The agents then interact once in a pricing game in which mutual restraint is collectively better than mutual undercutting, although undercutting is the myopically dominant action. In Protocol A, each agent can read and simulate the other agent’s complete source code before choosing its action. In Protocol B, part of each agent is encrypted: the other agent can inspect the public interface and ask a fixed, finite number of counterfactual questions of the form “If my submitted program were X, what would your complete program do?”, but cannot inspect the encrypted implementation or ask enough questions to determine its behavior in every contingency. Source code is submitted before actions are chosen, there is no repetition, and the runtime enforces only the submitted code—not any promise made by the firms.

The exam question should ask candidates to determine when mutual restraint can be rational in each protocol, while forcing them to distinguish the action-level game from the metagame of choosing which program to submit. It should also require them to address the difference between brittle coordination on syntactically identical code and more robust coordination based on predicted behavior under counterfactual modifications. Avoid making “define program equilibrium” or “explain why transparency produces cooperation” the central task; candidates should have to identify the exact conditions under which auditability supports an equilibrium and where bounded auditability may fail.

Please provide:

1. A self-contained exam question of roughly 250–350 words, including any payoff structure or simplifying assumptions candidates need.
2. A model answer of roughly 700–900 words, written at upper-level undergraduate standard and without relying on citations.
3. A 20-mark marking scheme organized around five must-hit points. For each point, state its mark value and add a one-line description of the characteristic mistake weaker candidates make.

The model answer should explicitly consider at least one serious objection: for example, that Protocol A merely relocates the strategic choice from actions to programs, or that Protocol B supplies evidence of cooperation without supplying the kind of commitment needed for program equilibrium.
