Question: Explain what Kripke means by a rigid designator, and use the notion to explain how an identity statement such as "Hesperus is Phosphorus" can be both metaphysically necessary and knowable only a posteriori. Illustrate your answer with Kripke's example of the standard metre.

Student's answer: For Kripke, a rigid designator is a term that picks out the same object in every possible world. Thus "Hesperus" and "Phosphorus" both rigidly designate Venus, whereas a description like "the evening star" picks out whatever body happens to appear in the evening sky, and so designates different objects in different worlds. Because the two names pick out the same object in all possible worlds, "Hesperus is Phosphorus" is true in every possible world and hence necessary; yet the identity was established by astronomical observation, so it is a posteriori. This refutes the traditional assumption that all necessary truths are a priori. Kripke illustrates the difference between fixing a reference and giving a synonym with the standard metre: "one metre" is introduced by stipulating that it is to be the length of stick S at time t0. Since the reference of the term is fixed by this stipulation, Kripke concludes that "stick S is one metre long at t0" is necessary a priori: the speaker knows it simply in virtue of having made the stipulation, and it could not have been false. The same analysis extends to theoretical identities such as "water is H2O": "water" rigidly designates H2O, so the identity is necessary even though discovering it required empirical chemistry. It remains true that we can imagine discovering Hesperus was not Phosphorus, but this shows only that the identity is contingent in an epistemic sense, not that it is metaphysically contingent.
