Ok so I just got out of a three-hour argument with my friend Marcus about whether one person's choices actually matter for stuff like climate change and factory farming. His line was: the meat industry slaughters the same number of animals wether or not he buys chicken, one flight more or less changes nothing measurable, one vote basically never swings an election, so he's morally off the hook for all of it. I think that's wrong but I couldn't land the blow in the moment, and I want to settle it differently.

I run a biweekly ethics discussion night — about 14 grad students plus a few sharp undergrads, 90 minutes — and Marcus has agreed to come to the next one. Design me an in-class game or simulation that makes the whole room feel the structure of the inefficacy objection from the inside. Each player should be in a position where, honestly, their own single move seems to make zero difference to the outcome, and yet the group still ends up producing something bad that none of them individually wanted. Then the second half of the activity, or the debrief, should get them to find the crack in that reasoning themselves — I don't want to lecture them about expected value or thresholds.

Concrete asks:
- actual rules, materials, round structure, and a payoff scheme that works with chocolate or points rather than real money
- a timing breakdown for the full 90 minutes
- a debrief plan that maps specific moments from the game onto the objection and onto the main replies (threshold or collective-difference answers, expected marginal impact, rule-based or complicity-based answers), and says where each reply can itself be pushed back on
- what will predictably go wrong the first time I run it and how to handle that
- one honest paragraph on which feature of the real-world problem the game can't reproduce (my guess: in real life you can never check afterwards whether you happened to be at the threshold, and the game might make that too visible)

One hard constraint: nobody should hear the phrase "inefficacy objection" or get any theory up front — they should run face-first into the problem first and only get the vocabulary afterwards. Marcus thinks of himself as a pretty careful philosopher, so the game needs to be tight enough that he can't just dismiss it as rigged when it makes his position look bad.

Start with the game itself — setup and rules — with no preamble and no summary of the argument first.
