Okay so my friend Nico has been going down a rabbit hole on superrationality — the Hofstadter idea that symmetric reasoners should expect to land on the same answer, so you choose as though your choice sets the policy for everyone relevantly like you — and he's condensed it into an arguement he claims shows that "just this once" is never a coherent excuse. It feels like it proves way too much but I can't locate the slip. His version:

(1) Two agents facing the same decision, with the same relevant information and the same decision procedure, reach the same decision. Same inputs, same outputs.

(2) So in a symmetric one-shot prisoner's dilemma between two such agents, the only live outcomes are both-cooperate and both-defect; the mixed outcomes aren't really on the table, since they'd require the agents to reason differently from identical starting points.

(3) Both-cooperate pays each agent more than both-defect, so rationality says cooperate.

(4) Notice (1)-(3) never used communication, trust, or causal contact — only sameness of reasoning. So the conclusion covers a perfect copy of me in a sealed lab I'll never meet, even one that won't be built until next century.

(5) The same structure shows up in collective action. When I deliberate about whether to vote, thousands of people in my reference class — same information, same deliberative habits — are running the same deliberation and will land where I land. So my ballot effectively settles a whole block of ballots, and voting can be rational even though no single vote ever swings an election.

(6) It also shows up across time inside one skull. Tonight's decision about whether to go running is the same decision, on the same general information, that future-me faces a few thousand more times, made by the same procedure. So tonight's choice effectively settles those thousands of future choices too.

(7) Therefore "just this once" is incoherent: skipping one run is rational only if skipping all of them is, and one cigarette tonight is rational only if being a smoker is. Every apparently trivial choice is secretly a referendum on the whole policy.

(8) But that's absurd — nobody can actually live treating every random Tuesday night as the decisive one, and an argument that implies you must has gone wrong somewhere.

(9) So something in (1)-(6) has to give, and Nico guesses (1) is "too strong," whatever that means.
