For a graduate seminar in decision theory, I want the specification written before anyone defends a theory. The topic is the rational evaluation of games whose expected value is undefined rather than merely infinite. The standard exhibit is the Pasadena game: a fair coin is tossed until it lands heads, and if the first heads occurs on toss n, the payoff is (−1)^(n+1) · 2^n / n dollars. The naive expected value is the alternating series 1 − 1/2 + 1/3 − 1/4 + …, which converges conditionally to ln 2; by the Riemann rearrangement theorem those same terms can be reordered to sum to any real number whatsoever, or to diverge, and there is no privileged order in which the outcomes "should" be summed. So the expected value is undefined — and yet the game is obviously not a blank slate for rational choice, since it sits between the St. Petersburg game (infinite but well-defined expectation) and games about which nothing can be said.

Write the desiderata that an adequate theory of rational evaluation for such games must meet: the cases it has to deliver verdicts on, the principles it must respect, the distinctions it cannot collapse, and the mathematical facts it cannot contradict, with the consideration behind each requirement. Address at least the following pressure points, and add any I have missed:

1. Pairing arguments. Partition the Pasadena outcomes into pairs (first with second, third with fourth, …): each pair's contribution to the sum is positive (1/2, 1/12, 1/30, …), which seems to show the game is better than a sure $0, indeed better than any sure amount below ln 2. But pair the outcomes differently (second with third, fourth with fifth, …, leaving the first unpaired) and every pair's contribution is negative, suggesting the game is worse than a sure $1. Must a theory pronounce on which rearrangements are legitimate, must it rule the whole style of argument illicit, or may it somehow do both? Formulate this as an explicit requirement.

2. Truncations and continuity. The game truncated at N tosses has a perfectly ordinary expected value, and these converge to ln 2 as N grows. Should a theory's verdict on the infinite game be constrained by the limit behavior of its finite truncations — and if so, does it matter that truncation by toss count and truncation by payoff cap can give different answers? Note that a parallel truncation argument for the St. Petersburg game yields infinity, so the requirement cannot be stated in a way that smuggles in a general "the limit decides" rule without scrutiny.

3. Dominance. Consider a second game identical to the Pasadena game except that each outcome's payoff is one cent higher. Both expectations are undefined, but the second is better in every possible outcome. Must the theory judge it strictly preferable, even though neither game has an expected value? State whether statewise dominance is a non-negotiable requirement here and what it costs.

4. Verdicts against sure things. Must the theory deliver a verdict on Pasadena versus a sure $0.69, and versus a sure $0.70? Is "worth exactly ln 2" an acceptable verdict, a mandatory one, or a reductio of whichever desiderata force it? And must the theory distinguish "worthless," "priceless," "incomparable," and "undefined" rather than collapsing them into one refusal?

Finally: mark which requirements are genuinely non-negotiable for any theory that wants to count as a theory of this domain, and which are the preferences of particular camps; flag any subset of the desiderata you suspect is jointly unsatisfiable (I have in mind possible tensions among completeness of comparisons, rearrangement-invariance, and dominance, but show the conflict properly rather than gesturing at it) — if the list itself is an impossibility result, that is the part I most want to see. Then, briefly and without a scorecard, indicate how four crude contenders fare against the list: refusing to evaluate any game with undefined expectation; evaluating by the standard summation order (so Pasadena is worth ln 2); evaluating by the limit of truncations; and a partial ordering based on dominance alone. Keep the weight on the criteria and their motivating cases.
