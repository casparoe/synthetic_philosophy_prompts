HOMEWORK QUESTION:
Explain the money-pump argument against intransitive preferences. Does the argument succeed in showing that transitivity is a requirement of rationality? In your answer, consider whether the way an agent handles sequences of choices, rather than single choices, makes a difference to the argument's force.

STUDENT'S ANSWER:
The money pump argument targets agents with cyclic preferences. Suppose an agent strictly prefers A to B, B to C, and C to A. A trader starts the agent off holding C, then offers B in exchange for C plus a small fee. Since the agent strictly prefers B to C, they accept. Next the trader offers A for B plus another small fee — accepted again, since A is preferred to B. Finally the trader offers C for A plus a fee, and again the agent accepts. The agent now holds C exactly as at the start, but has paid three fees, and the cycle can be repeated indefinitely, draining arbitrary amounts of money. So intransitive preferences are irrational because they make the bearer a guaranteed money pump.

The argument also extends to indifference. If an agent is indifferent between A and B, indifferent between B and C, but strictly prefers A to C, the same pump can be run on them, so the argument equally shows that indifference must be transitive.

Some philosophers object that a sophisticated agent, one who foresees the whole sequence of trades in advance, would simply refuse to play. This objection fails, though: once the agent has accepted the first trade they are already committed to the cycle, and each subsequent trade is one they strictly prefer, so the pump still goes through. It follows that transitivity is a strict requirement of rationality, and that anyone whose preferences violate it is exploitable and will in fact lose money over time.
