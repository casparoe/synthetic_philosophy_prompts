I'm a software engineer (backend, mostly Python and some embedded stuff) and I got into an argument at work that I keep thinking about. Someone on my team said DNA is "literally a programming language" and I pushed back, but honestly my pushback was mostly vibes — I know what makes source code a code (a compiler, a spec, an alphabet, a way to crash), and DNA only matches some of that. The genome has an alphabet and a mapping from triplets to amino acids, sure, but that mapping is implemented by tRNA molecules that themselves evolved, there's no clean compile step, "programs" get edited while they run (alternative splicing, RNA editing), a huge amount of the "code" is regulatory stuff that looks more like config or wiring, and mutations in it don't crash anything the way a syntax error does. Then my teammate hit me with: okay, but what would it take for it to *count* as a code? And I realized I don't actually have a criterion, I just had a feeling.

So here's what I want: before I read more about whether DNA "is a code" or "contains information," write me the desiderata — what any adequate theory of genetic information would have to deliver to settle questions like mine. For each requirement, give me the case or phenomenon that motivates it. Some things I suspect belong on the list but you should vet: it has to explain the apparently arbitrary mapping in the codon table (why does UGG mean tryptophan — is that "convention" in my sense or something else?); it has to say something principled about the difference between sequence information and Shannon information, since people seem to slide between those; it has to handle the fact that you can compute mutual information between smoke and fire but nobody calls smoke a code for fire; it has to either justify or dissolve the asymmetry where biologists call genes "instructions" but refuse to say the same about the cellular machinery or the environment that reads them; and it has to deal with cases like silent mutations, overlapping genes, and synthetic recoding experiments where researchers reassign codons, since those seem like natural test cases for any account.

Also flag which desiderata you think are genuine and which are just prejudices imported from computer science (maybe mine), and whether some subset of the requirements turns out to be jointly unsatisfiable — like maybe you can't have both "information is purely a causal/correlational notion" and "the code metaphor captures something smoke-and-fire doesn't." If the list itself ends up showing that the DNA-as-code debate is really several separate debates wearing a trenchcoat, that's the result I most want to see. You can briefly score the main contenders (the straightforward information-theoretic view, teleosemantic accounts where content comes from what the sequence was selected for, and the developmental-systems critique that says the whole code talk is misleading) against the list, but keep that part short — the criteria are the point.
