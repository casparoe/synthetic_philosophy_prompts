I got into an argument after my formal epistemology seminar about whether objective Bayesianism can really deliver rational priors. The discrete maximum entropy rule seems plausible enough when there is a fixed finite set of possibilities, but one of my classmates thinks the continuous case completely wrecks the view. His argument is: (1) If objective Bayesianism is true, then agents with the same evidence and background knowledge ought rationally to assign the same prior probabilities. (2) A rational prior cannot depend on an arbitrary choice of coordinates or on how the same physical quantity happens to be represented. (3) Suppose all we know is that some physical parameter x lies between 1 and 2. (4) Maximum entropy then tells us to use the distribution that is maximally noncommittal over that range, namely a uniform distribution over x, so P(x ≤ 1.5) = 0.5. (5) But letting y = x³ gives an exactly equivalent representation of the same situation, with y between 1 and 8. Maximum entropy applied there gives a uniform distribution over y, which implies P(x ≤ 1.5) = P(y ≤ 3.375) ≈ 0.339. (6) We therefore get two incompatible allegedly rational priors from the same total evidence. (7) We can avoid this only by privileging x or y, which means smuggling in information not contained in the evidence, or by allowing both distributions, which means there is no unique rational prior. (8) So objective Bayesianism either secretly relies on subjective choices or collapses outright.

I feel like this proves too much, since it would apparently make every continuous statistical problem depend on an arbitrary reparamaterization, but I cannot confidently identify the bad step. Which premise or inference should be rejected, and what exactly does rejecting it cost? In particular, does maximum entropy require a background measure as part of the problem rather than deriving one from ignorance, and if so, is that already a threat to objectivity? Please also say whether appealing to symmetries, physically meaningful units, or transformation rules actually resolves the case, or whether it just moves the subjective element somewhere else.
