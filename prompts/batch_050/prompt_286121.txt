So I've been hanging around LW and the adjacent blogs since like 2011, and lately I've gone down the program equilibrium rabbit hole — Tennenholtz's setup where agents in a one-shot prisoner's dilemma can read each other's source code before choosing, plus the Löbian cooperation stuff the community built on top of it. Next week I'm giving a ~30 minute talk at my university's game theory reading group, and my thesis is basically: program equilibrium is a genuine solution to the one-shot prisoner's dilemma, not a party trick. I.e., rational agents with mutual source-code access should cooperate, and the fact that vanilla game theory calls mutual defection "rational" is an artifact of assuming agents are opaque black boxes to each other, not a deep truth about rationality.

The audience: mostly econ PhD students plus two faculty, all completely fluent in standard game theory (dominance, Nash, correlated equilibrium, commitment devices in the Schelling sense) but, as far as I can tell, zero exposure to the Hofstadter/LW lineage — no superrationality, no FDT, no Newcomb discourse. There's also one philosopher who I'm pretty sure has actually read the Newcomb literature and is definetely going to be the most dangerous person in the room.

Here's my argument sketch, so the objections target what I'm actually saying and not a strawman:

1. In the standard one-shot PD, defection strictly dominates, mutual defection is the unique Nash equilibrium, and it's Pareto-suboptimal — and textbook game theory just bites that bullet.
2. Give both players the other's source code. The program "cooperate iff the opponent's code is identical to mine" then sustains mutual cooperation: anything else you run against it gets defected on, so running it is a best response to itself. No iteration, no enforcement, no altruism, no cheap talk.
3. The Löbian results push past the fragile "identical code" version: agents can end up mutually cooperating on the basis of provable cooperation rather than syntactic match, so the result isn't just an artifact of literal copy-pasting.
4. So the prisoner's dilemma's gloomy conclusion is about opacity, not about rationality as such.

I already have answers I like for "this is just a commitment device" and "equilibrium selection — cooperation is AN equilibrium, not THE equilibrium," so either go deeper than those or tell me why my confidence there is misplaced.
