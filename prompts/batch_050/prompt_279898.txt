Spent like three hours last night arguing with my friend about whether deduction itself can be justified, and he cornered me with an argument I'm convinced goes wrong somewhere but I can't pin down where. His version: (1) You're only justified in accepting a conclusion from premises via some rule of inference if you're justified in believing that the rule is valid. (2) Being justified in believing a rule is valid requires an argument establishing its validity. (3) That argument itself proceeds by some rule of inference, so by (1) you'd need to be justified in believing that rule valid too. (4) So justifying any deduction requires an infinite chain of arguments, or a circle, neither of wich justifies anything. (5) Therefore no deductive inference is ever justified. (6) But every justification we have for induction, perception, testimony, science, whatever, relies on deduction at some point, so actually no belief is justified at all. He called this the tortoise's revenge and said it proves rationality is built on sand. Obviously something slipped between the reasonable-sounding start and this absurd ending, but each step looks fine when I stare at it individually. Which step should I reject, why did it look plausible in the first place, and what does rejecting it cost me? I'd rather keep (1) if possible since it seems like just what "justified" means, but if that's the culprit, tell me honestly.
