---
The type/token distinction, originally drawn by Peirce, gives us a natural home for musical works. A work like Beethoven's Fifth Symphony is a type, an abstract object, and its individual performances are tokens of that type. This explains how the work survives the destruction of any particular score copy or the death of every performer: no token's destruction touches the type.

On this picture, the score has a privileged status. Since the work is the type of which performances are tokens, the work is in effect identical with the score-type: the score specifies the type completely, and a performance counts as a token of the work insofar as it complies with the score. Goodman develops this line: for him the work is the class of performances complying with the score, and he is famously strict — a single wrong note means the performance is not an instance of the work at all. Wolterstorff's norm-kind account follows Goodman on this point, ruling that any performance containing even one incorrect note fails to instance the work.

Are works created or discovered? Levinson argues that because types are eternal abstract objects, works must be discovered rather than created; Beethoven stumbled upon a pre-existing sound-structure. Other theorists resist this, insisting that composers genuinely create their works.

Recordings complicate matters. A studio recording fixes one performance permanently, so the recording itself becomes a further token of the work, and every playback of the recording is a token of that token — a second-order token, as it were. Some argue playback counts as a performance, but this seems wrong, since nobody is performing anything when I press play.
