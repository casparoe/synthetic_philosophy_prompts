Write an essay about whether virtual objects and virtual harms are real. Use the following rough menu of positions as your starting point: (a) virtual things are real because they're implemented in real physical stuff (servers, code, pixels), (b) they're real insofar as they have genuine causal effects on non-virtual things (money, emotions, relationships), and (c) they're real because a community treats them as real, full stop. Then stress-test these views against a hard case: a single-player game where someone painstakingly builds something over years, saves it locally, and the save file gets corrupted by a bug. No one else ever knew it existed, and the player themself, after a distraught week, deletes the game and eventually never thinks about it again. Was anything real destroyed? Was there a real harm, and if so, when exactly did it occur — at the corruption, or only while the player still cared? Weigh how each of (a)-(c) handles this, and reach and defend a conclusion about which view, or which combination, gets virtual reality right.
