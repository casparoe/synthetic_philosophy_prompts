Ok, longtime lesswrong/ACX-adjacent reader here, and I got into a late-night argument that feels like it proves way too much but I cant find the loose brick. We were trying to redo torture vs dust specks without the usual shouting, so we invented cleaner units.

Let a mote be 1 millisecond of the mildest possible itch in an otherwise great life: instantly forgotten, no dread, no aftereffects, no attention captured, no knock-ons. Let a forge be one hour of severe agony for one person, also wiped from memory afterward so there is no trauma story, same lifespan and same later welfare. Bracket rights, desert, duties, rule-worry, etc; compare only experienced badness. My friend then ran this:

(1) Local aggregation: for any fixed bad episode E in one life, there is some finite number of motes that, if packed into one awful lunch hour for that same person while still staying individually below notice, would make that stretch worse for them than E.

(2) Badness is substrate- and owner-blind in the only respect that matters for totals: if N motes packed into one person-hour can outweigh one forge, then N motes spread one-each across N strangers can outweigh that same forge, because suffering does not get a discount for having different mailing addresses.

(3) So for every forge there is a finite M such that M isolated motes, one per stranger, is morally worse than the forge.

(4) Now run the move downward: take the forge and imagine it smeared into vastly many micro-forges across micro-intervals and micro-persons, each still positive but closer and closer to a mote. If (1)-(3) are general, the more perfectly you smear a fixed horror across more recipients and tinier instants, the easier it is for an even larger, even more diluted cloud of almost-nothings to outrank it; repeat and there is no floor.

(5) Therefore any positive badness, however close to unfelt, can be made to outweigh any catastrophe by adding recipients, so long as the total stays finite.

(6) And once merely possible recipients count, this turns fanatical: for any actual emergency, some huge hypothetical population bearing epsilon-motes swamps it, so we should ignore the nearby burning building and optimize for the biggest computable crowd of barely-there twinges.

(7) But that is insane. Actual horrors have some kind of floor or priority against unlimited hypothetical almost-nothings; otherwise every choice becomes Pascal’s mugging with nicer branding.

(8) So one of (1)-(6) has to die. The only candidate I can name is that summation has jurisdiction, i.e. within-a-skin over time is real addition while across-skins is mere bookkeeping, but that sounds like time-slice egoism with extra steps, and definately not something I want to tattoo on my ethics.

Which step do you reject, exactly? Say why it looked respectable, whether the crack is temporal-to-interpersonal, finite-to-limit, subthreshold-to-noticeable, actual-to-possible, or some scope slide I missed. Then price the main exits: lexical thresholds, diminishing marginal badness, separateness/seperateness of persons, person-affecting restriction, bounded utility, or denying that below-notice motes have positive badness at all. If forced I’d keep (7), and I’d surrender (1) before (3), but I want to know what each surrender purchases and what it poisons elsewhere, especially for normal cases like triage, risk, and whether a million mild headaches can ever matter more than one broken leg.
