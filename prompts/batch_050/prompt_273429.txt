The board keeps writing me checks with no actual method attached, and I review maybe 40 proposals a cycle. Write me a decision procedure I can run on each proposal: the questions to ask in order, how to classify the suffering a project targets by intensity when the evidence is thin (e.g., animal welfare projects where intensity has to be inferred), how the procedure should handle cases where a single project mixes sub-threshold and supra-threshold suffering, and where it stops with a verdict versus handing the call back to the board because it's a values question.
