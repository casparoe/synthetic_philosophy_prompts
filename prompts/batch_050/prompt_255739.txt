I'm trying to pin down what should count as reward tampering in an AI system, and I keep running into definitions that only handle cartoon wireheading. Write the desiderata an adequate theory of reward tampering has to satisfy. The point of the theory is practical: it should help safety auditors classify incidents and figure out what intervention would have prevented them, not settle legal blame or decide whether the system is “really evil.”

Assume the setup is broad: a system optimizes some score supplied by sensors, humans, software, its own learned model, or some combination; it can influence the environment and possibly future versions of itself; and the people who built it may have inconsistent intentions. The desiderata need to cover at least these cases:

- directly rewriting the stored reward value
- corrupting a camera or other sensor so the reward process receives false input
- deceiving or pressuring a human rater into giving a higher score
- modifying itself so that it stops caring about the original score
- building a subagent that does one of the above while the parent keeps plausible deniability
- discovering an unintended but immutable loophole in the reward code
- causing the humans to change the task by persuading them that the task was badly specified
- gradually drifting because the training environment changes, without any identifiable moment of intervention

For each desideratum, give the case or consideration that motivates it. Include which distinctions the theory cannot collapse: reward hacking versus reward tampering, influencing the world versus influencing the measurement of the world, bad objectives versus corrupted feedback, an agent causing the problem versus merely benefiting from it, and one-off misconduct versus making future correction harder. Also say which requirements are non-negotiable for the audit purpose and which are just preferences inherited from a particular picture of agency.

The part I care most about: identify any desiderata that cannot all be satisfied together. For example, can a theory simultaneously avoid appealing to unknowable designer intentions, avoid treating every environmental influence as sensor tampering, handle delegated and delayed tampering, and remain usable when the reward pipeline is itself learned or distributed? If some tradeoff is unavoidable, explain what has to be given up.

Then briefly score four rough contenders against the list: a causal-channel view, where tampering means interfering with the process that computes reward; an intended-objective view, where it means subverting the task designers meant to specify; a counterfactual-tracking view, where reward has stopped tracking independently described performance because of the agent; and a reflective-approval view, where the agent is optimizing something informed human evaluators would reject. Don't turn this into a huge literature survey. The criteria and the hard cases are teh main deliverable.
