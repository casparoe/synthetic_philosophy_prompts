Reading Gödel Escher Bach and got to the MU-puzzle. Hofstadter's point is that you prove MU underivable only by stepping outside the system and spotting an invariant (the number of I's is never divisible by 3). Fine. But now consider this variant: same start string MI, same four rules, except rule 3 turns four consecutive I's into a single U instead of three. My roommate insists MU is still underivable "by the same meta-argument," but I suspect he's pattern-matching rather than actually checking. Two questions: (a) Is MU derivable in the variant, and what does the correct meta-level reasoning look like here -- a new invariant, or an actual derivation? (b) Hofstadter treats "jumping out of the system" as a special, almost magical mode of insight, but this case bugs me: my roommate jumped out of the system and got it wrong. So is there really a principled line between reasoning within a formal system and reasoning about it? Couldn't you build a bigger formal system that mechanically includes the meta-reasoning -- and then couldn't someone jump out of that one too? If so, does the inside/outside distinction ever settle anywhere, or is "jumping out" just ordinary reasoning wearing a cape?
