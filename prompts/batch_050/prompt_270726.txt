I'm compiling a catalogue of proposals for keeping an AI agent "low-impact" — that is, for penalizing or preventing unwanted side effects without specifying the full human utility function. What I have so far:

1. Relative reachability (Armstrong and Levinstein): penalize an action to the extent that it makes states harder to reach, averaged over a set of auxiliary utility functions, relative to a stepwise inaction baseline.
2. Attainable utility preservation (Turner and colleagues): penalize changes, in either direction, in the maximum attainable value of a set of random auxiliary reward functions, relative to the agent doing nothing for one step.
3. Whitelisting: hard-constrain the agent to affect only a pre-approved set of state features, treating everything else as out of bounds.
4. Quantilization (Taylor): rather than maximizing expected utility, sample from the top quantile of actions under a base distribution, on the idea that it is extremization of a proxy, not pursuit of the proxy as such, that produces large side effects.

I want one more proposal that is structurally different from all four — not a new baseline or a new set of auxiliary reward functions for (1) or (2), not a differently drawn feature boundary for (3), and not a different action-selection rule for (4). Describe the mechanism precisely enough that it could in principle be implemented, and test it against one hard case: an agent that can cause a delayed harm (say, releasing an invasive organism) whose damage only materializes after many steps of apparently innocuous behavior, so that no single step looks like a large deviation from doing nothing. Lead with a one-sentence statement of the proposal, then give the mechanism, the test case, and an honest assessment of whether it actually works, with no preamble and no restating of the question.
