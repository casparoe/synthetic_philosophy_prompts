I'm a third-year PhD student in philosophy of mind and language, and I've provisionally committed to the two-dimensionalist treatment of the necessary a posteriori: roughly, that a claim like water's being H2O has a contingent primary intension (evaluated with a world considered as actual) and a necessary secondary intension (evaluated with it considered as counterfactual), so that the link between apriority and necessity can be restored at the primary dimension, and the conceivability–possibility gap in the zombie argument can be handled accordingly. I'd like an honest map of this position's exposure before I build a dissertation on it. What would actually count against it? I'm aware of the usual suspects — that the framework quietly presupposes something like Chalmers's scrutability thesis about the a priori deducibility of truths from a complete qualitative base, that Soames-style objections deny primary intensions are genuine semantic contents at all, and that there are contextually shifty expressions for which the two dimensions are hard to define cleanly — but I want these and any others sorted from fatal to merely awkward, with attention to which ones a committed two-dimensionalist would concede as real costs and which they would dismiss as misunderstanding the framework. Please also address whether the position has been qualified into something unfalsifiable, and if so whether that is a vice for a semantic framework as opposed to an empirical theory. I'd like the response in continuous prose, the way one would write a letter: no headings, bullet points, bold text, or tables.
