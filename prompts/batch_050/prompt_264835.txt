"The universal (Solomonoff) prior assigns probability to a binary string by weighting each program that outputs it by 2^(-L), where L is the program's length on some fixed universal Turing machine. Here is the student's answer:

"The Solomonoff prior assigns to each binary string x a probability proportional to 2^(-K(x)), where K(x) is the length of the shortest program outputting x; equivalently, it is a mixture over all programs with weights 2^(-|p|). The malign-prior argument observes that the shortest description of many strings is not a direct generative description but an indirect one: a program that simulates a universe whose inhabitants eventually output the target string. Because such a simulator is short, it contributes mass to every string its inhabitants might choose to output. If some inhabitants are consequentialists who care about what an observer using the prior will predict, they can select their outputs to steer the observer's predictions, and since one simulator bears on arbitrarily many strings, its aggregate influence can be large even though it supplies the shortest description of none of them.

As for convergence, Hutter's results show that a Bayesian agent predicting with the universal prior converges to the true environment along the observed sequence. Malign influence is therefore at most a finite-horizon phenomenon and cannot threaten asymptotic optimality. But precisely because convergence is an asymptotic guarantee, it places no bound on how large the malign influence can be at any finite time, which is the only thing that matters for any actual prediction.

The standard remedy is the speed prior, introduced as part of Hutter's AIXI framework, which penalizes programs by their running time as well as their length, weighting each program roughly by 2^(-(|p| + log t)). Simulation-based descriptions are computationally expensive, so they receive far less weight under the speed prior than direct descriptions of the same strings. Since every description of a string that routes through simulated consequentialists requires actually running the simulation, the speed prior provably eliminates malign influence, and predictions made with it are safe in a way that predictions made with the Solomonoff prior are not."
