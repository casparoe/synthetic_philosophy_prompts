You are a decision theorist with expertise in games with undefined or infinite expected values. Please think carefully through the following dispute before giving a verdict.

The Pasadena game works like this: a fair coin is flipped until it lands heads. If the first heads occurs on toss n, the player receives (-1)^(n+1) · 2^n/n dollars (so the possible payoffs are +2, -2, +8/3, -4, +32/5, and so on). The payoffs are bounded in probability by 2^-n, so the expected value is the series 1 - 1/2 + 1/3 - 1/4 + ..., which converges conditionally to ln 2 but does not converge absolutely.

Two friends disagree about this game:

Maya argues that the game has a definite value of ln 2 (about 0.69 dollars), and that a rational agent should pay any amount less than that to play. Her reasoning: the coin tosses happen in a fixed temporal order, so the natural thing to do is consider the expected value of the game truncated at N tosses and let N grow; these truncated expectations converge to ln 2, which settles the matter.

Daniel replies that an expectation is a sum over a probability space, and probability spaces have no intrinsic ordering. By the Riemann rearrangement theorem, a conditionally convergent series can be summed to any real number whatsoever depending on the order of its terms, so the "value" of the game is an artifact of an arbitrary ordering convention. He concludes that the question "what is the game worth?" is simply malformed: there is no fact of the matter, and no principled price.

Maya concedes that point values may be problematic but insists comparisons still work. Consider a second game Q, identical to the Pasadena game except that it pays one cent more in every possible outcome. Surely Q is strictly preferable to the original, she says, and dominance reasoning like this requires no expectations at all -- so rational rankings of these games are possible even if their values are undefined.

Daniel grants that dominance gives a partial ordering but says this concession is cheap: dominance cannot compare the Pasadena game to a sure payment of 50 cents, which is exactly the kind of choice a theory of value is supposed to guide. Any complete ranking beyond what dominance delivers, he maintains, must smuggle in an arbitrary ordering convention, and so his objection stands where it matters.

Please adjudicate: who is right about each specific move -- the truncation argument, the rearrangement objection, the dominance reply, and the final rejoinder? What, if anything, are both parties missing? And who is more right overall?
