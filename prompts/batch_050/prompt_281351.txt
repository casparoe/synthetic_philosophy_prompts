I teach an upper-level undergraduate seminar on probability and induction (sixteen students, one 80-minute session, no statistics background assumed). Design an in-class activity that makes students feel the reference class problem before anyone names it. The activity must stage three features of the problem, in this order:

1. Multiplicity: any single case falls under indefinitely many reference classes with different known frequencies, and each class can be made to look like the natural one.
2. The regress of narrowing: the seemingly principled rule "use the narrowest class you have data on" delivers, if pursued far enough, a class containing only the case itself — at which point the frequency is useless and the rule must smuggle back in the very judgments of relevance it promised to replace.
3. Order sensitivity, the part I most want staged: my own suspicion is that when evidence about a case arrives piecemeal, each fragment makes a different reference class salient, so that two agents receiving identical evidence in different orders can reach opposite verdicts, each citing a defensible class. I want the activity to test whether this actually happens with real people.

The point should emerge from what students do, not from my debrief. Use one staged decision scenario throughout (a hiring committee, a medical triage board, an insurance panel — your choice, but commit to one and make it concrete), with small non-monetary stakes or public commitments that force students to act on a chosen class, and with the order manipulation hidden until the end.

Deliverables: complete rules and materials; a timeline; the stakes mechanism; a debrief script mapping each moment of the session onto the three features, including how to reveal the order manipulation without students feeling cheated; what will predictably go wrong on a first run (for instance, students converging on one shared salient class and thereby missing the problem entirely) and how to recover; and an honest note on which aspect of the reference class problem a classroom game cannot reproduce and I will have to supply in discussion.
