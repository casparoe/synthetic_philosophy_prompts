The setup, for context: in the program prisoner's dilemma, each player submits a program that receives the source code of the other player's program as input and then outputs cooperate or defect. Tennenholtz showed that mutual cooperation is achievable in equilibrium, via programs that cooperate iff they can verify the opponent is running the same program as them. Thats the textbook summary. What i do NOT want is a question students can answer by reciting it.

Write me one essay-style exam question for a 2-hour final, worth 40 marks, that forces students through at least these three things:
