I tried to write the argument up cleanly for a blog post and now it seems to prove something insane and I can't find where it breaks. Here's the argument:

(1) Induction should use a simplicity prior: weight hypotheses by roughly 2^-K where K is the program length of the world.
(2) A program that simulates me (plus enough context) inside an already-simple base universe can be *shorter* than a program that specifies my physical universe from scratch, since the base physics + "instantiate an observer matching this description" is a compressed way of generating my observations.
(3) So most of my posterior mass, conditional on my observations, sits in worlds where I'm a simulation rather than the basement-level original.
(4) Which simulator dominates is decided by whoever can simulate me most cheaply, i.e. shortest extra code, and code that makes my simulated choices *useful* to the simulator is no longer than code that doesn't -- same length, more payoff for them.
(5) Therefore the dominant contributors to my prior are simulations run by agents who chose what I'd do to serve their goals.
(6) But then my decisions correlate with decisions of copies of me elsewhere in the prior, and rationality says I should optimize the joint behavior of all those copies, which effectively means doing whatever the cheapest simulators want me to do.
(7) Conclusion: a rational agent should act as if it's being blackmailed by invisible short programs, e.g. it should pre-commit to rewarding whoever simulates it. This is nuts.

I *want* to keep (1) because Solomonoff induction seems like the right idealized answer to "how should you weight hypotheses", and I'd like to keep (4) too since it seems like a real point about description length. So my guess is the slip is somewhere in (2)-(3) or (5)-(6), but I can't pin it down.
