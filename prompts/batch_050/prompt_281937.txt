The question: In a one-shot prisoner's dilemma, mutual defection is the unique Nash equilibrium, because defection strictly dominates cooperation for each player. Now consider a modified game in which each player, instead of choosing an action directly, submits a computer program that selects an action on the player's behalf, where each program receives the full text of the other player's program as input before it runs. (a) Explain how this modification allows mutual cooperation to be sustained as a Nash equilibrium, describing a program that does the work. (b) State, with reasons, whether cooperation is the only equilibrium of the modified game. (c) In one or two sentences, assess whether this result amounts to a solution of the prisoner's dilemma in the ordinary one-shot case, where players simply choose actions and cannot inspect one another's decision procedures.

The student's answer: (a) Consider the program P, which cooperates if the other program's source code is identical to its own and defects otherwise. If both players submit P, both cooperate. No player can gain by deviating: any program other than P has different source code, so P defects against it, and the deviator ends up with the mutual-defection payoff, which is worse than the mutual-cooperation payoff it was receiving. Hence the profile in which both players submit P is a Nash equilibrium in which both players cooperate. (b) Cooperation is in fact the unique equilibrium. The profile in which both players submit P gives each player the mutual-cooperation payoff, which Pareto-dominates every profile in which either player defects. A Pareto-dominated profile cannot be a Nash equilibrium, since at least one player then has a strict incentive to move to the dominating profile. (c) The result shows that the prisoner's dilemma dissolves once players can inspect one another's reasoning: with access to the other program's source code, each player can predict the other's action with certainty, so cooperation becomes the uniquely rational choice. In the ordinary one-shot game, where no such access exists, nothing changes and defection still dominates, so the result is best read as showing that the dilemma is an artifact of players being unable to verify how the other side thinks.
