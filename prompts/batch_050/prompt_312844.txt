Last night I got into a three-hour arguement with a friend about whether a physical system has any determinate computation at all, or whether that depends on how we choose to describe it. It started abstract, but it turns out I need to take a side by Friday.

I sit on my university’s Research Computing Ethics Board. We’re reviewing Project MOTH, an AI lab’s proposal to train 12,000 virtual embodied agents to forage in hazardous simulated worlds. Each agent has its own sensorimotor history, recurrent internal state, episodic memory, and damage signal; the damage signal causes persistent changes in avoidance behavior and gets incorporated into a shared world-model that also affects other agents. Some training trials deliberately expose agents to hazards so the lab can test whether they learn flexible avoidance rather than simple reflexes.

The lab says our interim policy on potentially sentient computational systems doesn’t apply. Its argument is that the GPUs are really just doing linear algebra: calling that process an agent, let alone 12,000 agents rather than one big system, is an interpretive convenience. It also says that under some clever mapping, the same server state could be redescribed as agents enjoying a game, so review based on what the computation supposedly represents would make every computation reviewable as possible suffering.

My friend’s view is basically that the lab is right about the metaphysics: unless there is a non-arbitrary fact about which computation a physical system performs, moral status cannot depend on computation. I think that proves too much, because medicine and cognitive science also rely on functional descriptions, but I couldn’t give her a clean criterion in the moment.

Please draft the decision memo I should circulate to the board. Begin with the memo itself, with the recommended action in the very first sentence: approve, reject, or approve with conditions. No preface, no restating the case. The memo should:

- take a definite position rather than listing options for us;
- explain how the board should distinguish causally explanatory computational descriptions from arbitrary relabelings, without pretending we can settle machine consciousness;
- say whether uncertainty about whether this is one subject, many subjects, or none changes the review decision;
- give practical criteria that reviewers can apply to future computational-sentience cases;
- include the strongest argument for the lab’s no-review position and answer it directly;
- if you recommend conditions, make them specific enough to enforce, not just monitor the system carefully or proceed cautiously.

No citations or reading list. I’d rather have a crisp decision the lab can contest on the merits than an even-handed survey.
