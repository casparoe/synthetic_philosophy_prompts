Question: Every outcome of 1,000 fair coin flips has the same probability (2^-1000), so probability alone seems unable to single out any sequence as "more random" than another. Can a finite sequence nonetheless be random? Discuss with reference to the algorithmic approach to randomness.

Student's answer:

The equal-probability point shows that randomness of a sequence cannot be a matter of how likely it was to be generated. The algorithmic approach resolves this by locating randomness in the sequence itself, not in the process that produced it. The Kolmogorov complexity K(s) of a string s is the length of the shortest program that outputs s on a fixed universal Turing machine. A string counts as random, on this view, when it is incompressible: when no program substantially shorter than the string itself produces it, so the shortest description of the string is essentially the string written out in full. A counting argument shows most strings of length n are incompressible or nearly so, since there are far fewer short programs than strings of length n. So the notion is not vacuous: random finite strings exist and are in fact typical.

This gives a clean verdict on cases. Consider the alternating string 0101...01 of length 1,000. Intuitively it is not random, but if it was in fact produced by 1,000 fair coin flips -- and it is exactly as probable as any other outcome -- then it is genuinely random after all, and our contrary intuition is just a bias toward cluttered-looking strings. Provenance settles the question.

The incompressibility criterion is not the only one. Martin-Löf defined randomness for finite strings in terms of statistical tests: a finite string is random if it passes every effectively computable test for typicalness, i.e., it is never singled out by any computable property held by only a small fraction of strings. This test-based definition coincides with incompressibility, so the two approaches confirm one another.

One caveat: K(s) depends on the choice of universal machine, though only up to an additive constant, and K is uncomputable, so incompressibility functions as an ideal standard rather than a checkable one. Still, the algorithmic approach shows a finite sequence can be random: randomness is incompressibility, a property of the string rather than its source.
