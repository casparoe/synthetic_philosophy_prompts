A friend in a biology graduate program summarized the etiological-versus-causal-role dispute about functions for me like this: "The etiological theory says a trait's function is whatever effect it was selected for, so the heart's function is pumping blood because that's why hearts were favored by natural selection, and a mutation with no selection history has no function no matter how useful it becomes. The causal-role theory says a function is any causal contribution a component makes to some capacity of the system it's part of, so on that view anything a trait happens to do counts as one of its functions — the heart's function includes making thumping sounds if some analysis wants it to. That's why etiological theorists think causal-role functions are too cheap, and why causal-role theorists think the etiological view builds an irrelevant history lesson into biology." Since I can't tell which camp he's in, I suspect some of this is slanted. Which parts would each side accept as fair, where does the summary quietly turn a standard objection into a definitional claim, and does the alleged consequence — that the causal-role theory cannot distinguish a heart's function from an accidental byproduct — actually follow once the view is stated carefully?
