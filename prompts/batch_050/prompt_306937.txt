I'm a software engineer with no formal training in philosophy or cognitive science, and I recently got into an argument at work that I want settled properly. We were talking about handwriting recognition, and I defended what I took to be the obviously right picture: a letter category like lowercase 'a' works the way a type works in a programming language. Each actual 'a' -- printed, handwritten, in whatever font -- is an instance of the type. Recognizing one is a matter of checking whether the shape satisfies the spec closely enough: a closed bowl, a stem in the right place, roughly these proportions, within some tolerance. Designing a new font is just producing fresh instances that still satisfy the spec, and "style" is the name for whatever varies within the tolerances while the identity of the letter is whatever stays fixed.

A colleague insisted this is exactly backwards: that there is no finite spec, that people recognize 'a's instantly in styles they've never encountered, and that style is part of what gets recognized rather than noise to be normalized away. I don't want to be argued out of my position by assertion, so I want the analogy itself audited.

Please give me the explicit correspondence table first: what plays the role of the type definition, the instances, the instanceof check, subtyping between letter categories, the tolerance parameters. Then the disanalogies, and for each one, classify whether it merely makes the analogy incomplete or whether it breaks one of the three conclusions I was using it to support: (a) that a recognizer for 'a' is in principle just a well-written feature spec, (b) that any 'a' a human would accept can be generated by perturbing a stored template, and (c) that letter identity is the invariant core and style the variable shell. Test the picture against hard cases, including at least these: the same ambiguous handwritten shape read as an 'a' in one word and a different letter in another; a font whose 'a's share no obvious feature with any 'a' in the training set yet are read effortlessly; and the fact that the single-storey and double-storey forms count as the same letter while far more similar shapes in other categories count as different ones. If the type/template picture fails, propose the best replacement analogy you can construct and show it handling at least one of those cases cleanly.

I want a committed answer, not a survey: take a definite position on how much of my picture survives, if any, give your reasons, and say plainly which of conclusions (a), (b), and (c) should be abandoned rather than hedging across the possibilities.
