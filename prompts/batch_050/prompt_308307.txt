I'm working through iterated elimination of strictly dominated strategies and I've run into a disagreement with my textbook's answer key, which I think is in error. Consider the following two-player game (payoffs to the row player):

- Row U: 3 against column L, 0 against column R
- Row M: 0 against L, 3 against R
- Row D: 1.1 against L, 1.1 against R

For D to be strictly dominated, there must be some strategy that yields a strictly higher payoff against every column. U fails (it does worse than D against R), and M fails (it does worse than D against L). So D is not dominated by any available strategy, and the elimination procedure terminates with U, M, and D all surviving. The answer key, however, claims D should be eliminated, which would require a dominating strategy that simply doesn't exist in this game. I can only conclude the key is using some looser, nonstandard notion of dominance — or is just wrong. Am I missing something, or should I write to the publisher?
