I'm in a reading group on the metaphysics of propositions and we keep going in circles on the unity problem. The basic puzzle, as I understand it: a proposition like "Socrates is wise" is supposed to be more than the mere list {Socrates, wisdom, being}, because you can have all the constituents in front of you without having anything that's true or false. But if you say the glue is some further item -- a relation of instantiation, say, that ties Socrates to wisdom -- then that item is just one more constituent, and you need more glue for the glue, which is Bradley's regress. Every proposed fix we've looked at seems to either embrace the regress, deny it's vicious, or dissolve the question somehow, and people talk past each other because they're implicitly demanding different things of a solution.

So before we argue about which solution wins, I want the specification. What would a theory of propositional unity actually have to get right to count as adequate -- where the purpose is making sense of thought and assertion as we actually practice them, not saving any particular ontology? Give me the full requirements list with the case or consideration motivating each one. Some things I suspect belong on it: it has to explain why a proposition has truth-conditions while a list doesn't; it has to work for false propositions, so the unifier can't be the fact that the constituents are in fact related; it has to handle direction, i.e. distinguish "Romeo loves Juliet" from "Juliet loves Romeo" when both have exactly the same constituents; and presumably it has to explain how one and the same unified item can be asserted, believed, doubted, and denied. But I'm not sure which of these are genuine desiderata and which are just one camp's prejudices dressed up as common sense -- e.g., is the demand that the unifier not itself need unifying a real constraint or a stacked deck against relational theories? Tell me that for each requirement. Also tell me whether some subset of the legitimate desiderata is jointly unsatisfiable, because if so the list itself is the interesting result. And flag which single requirement eliminates the most popular contenders (Frege-style "unsaturated" constituents, Russell's multiple-relation approach, primitive-facts views, etc.) -- a brief scorecard of the main options against the list is fine, but keep the weight on the criteria themselves.

Lead with your bottom line in the first sentence, then give the reasoning -- no preamble, no restating my question back to me. A structured spec-sheet format is welcome if it helps.
