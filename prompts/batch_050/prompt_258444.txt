I'm in the sixth form, and a classmate and I are preparing for a philosophy exam by setting each other practice questions and marking the answers. I'd rather not share my own impression of her answer first, so please assess it neutrally, as an examiner would.

The question I set was: When we are uncertain which moral theory is correct, how should we decide how to act? Outline two proposed answers to this question and explain one difficulty facing each.

Her answer:

Moral uncertainty arises when an agent does not know which moral theory is true. For example, I might be unsure whether to donate to a charity because I do not know how much good the donation would actually do. Two main proposals address this predicament.

The first is maximising expected choiceworthiness. Just as a rational agent facing ordinary uncertainty maximises expected utility, the morally uncertain agent should assign a credence to each moral theory and then choose the action with the highest expected choiceworthiness: for each action, take how good or bad each theory says it is, weight those verdicts by the probability that the theory is true, and sum across theories.

The second proposal is the 'my favourite theory' approach: act as the theory in which you have the highest credence tells you to act, and disregard the others.

Each view faces a difficulty. The comparability problem for expected choiceworthiness is that it is unclear how confident we should be in each theory, since there is no agreed method for assigning probabilities to moral theories. The difficulty for 'my favourite theory' is that it ignores how much is at stake for each theory: if one theory mildly favours an action while every other theory strongly condemns it, the approach still endorses the action whenever the first theory happens to be marginally more probable.
