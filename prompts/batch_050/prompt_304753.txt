"Here's the deal with finks and masks. A fink is a case where an object HAS the disposition, and the stimulus occurs, but the manifestation doesn't happen because something interferes -- like a live wire connected to an electro-fink that would instantly cut the power if the wire were ever touched. Martin used cases like this to kill the simple conditional analysis ('fragile = would break if struck'), because the wire is live and would conduct if touched, so the analysis says it's conductive, but wait -- actually the problem Martin pressed is that the wire is NOT conductive yet would conduct, no wait, the point is the conditional comes out true when the disposition is absent, or the other way around, anyway it refutes the simple analysis. Lewis fixed this with his reformed conditional analysis in 1997, saying a disposition is an intrinsic property that would cause the manifestation if the stimulus happened AND the object kept the property long enough. Everyone agrees Lewis's version handles finks perfectly. Masks are just a fancy name for the same phenomenon -- cases where something 'masks' the disposition so it doesn't manifest, like wrapping a glass in bubble wrap, so the glass isn't really fragile anymore while wrapped. So finks and masks are two names for one kind of counterexample, and Lewis's account handles both, which is why the conditional analysis in his form is now the consensus view."
