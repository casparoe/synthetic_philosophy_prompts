Now define a sentence C that says: if C is true, then P. (1) Suppose C is true. (2) Then what C says is the case: if C is true, then P. (3) From (1) and (2) by modus ponens, P. (4) Since assuming C got us to P, the conditional "if C is true, then P" is true -- that's just discharging the assumption, like wrapping up a subproof. (5) But that conditional is exactly what C says, so C is true. (6) Modus ponens on (4) and (5): P. Conclusion: our payment service has no bugs. And since P was arbitrary, the same recipe proves literally anything -- the moon is made of cheese, my code is correct, whatever.
