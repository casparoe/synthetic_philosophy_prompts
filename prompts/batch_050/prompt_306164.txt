Ok so I've been going around in circles on this for a couple weeks and I want someone to find the step that breaks. I got into it with my brother over whether a list of coin flips can actually be "random" and I ended up proving something that has to be false, but I genuinely can't locate the mistake.

(1) A string of flips is random either because of how it was produced (fair coin, dice, whatever) or because of what the string itself is like, the pattern in it.
(2) It can't be about how it was produced, because the exact same string could come from a fair coin, a weighted coin, or me mashing H and T on my keyboard while bored on the bus. The string doesn't carry its origin around with it. So if "random" means anything here, it has to be a property of the string.
(3) If it's a property of the string, then under a fair coin every 10-flip string has the same probability, 1 in 1024. HHHHHHHHHH and HTTHTHHTTH are exactly equally likely. Equally likely means equally random. So a run of ten heads is exactly as random as any messy-looking string.
(4) But nobody actually believes that. If I flipped ten heads in a row you'd suspect the coin, not shrug and go "just as random as anything else." So (3) is wrong, and randomness isn't a property of the string after all.
(5) And by (2) it isn't a property of the process either.
(6) So no finite string of flips is ever random, full stop. At best randomness is a thing about infinitely long sequences, or about the process, never about an actual list sitting in front of you.
(7) Except that's obviously nuts. Statistics people test finite strings for randomness all the time, my bank sends me finite random codes, and "shuffle" on my playlist is supposed to produce a random finite ordering.

If I have to give something up I'd rather drop (2) than (7), since the string really doesn't seem to know where it came from, but I want to know what I'm paying for that move. Also, somewhere around (3) to (4) something smells off, like "equally likely" quietly changed meaning on me, but I can't pin it down. Which step do you reject?
