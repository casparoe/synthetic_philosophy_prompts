I want a piece of satire from you: the official release notes for a fictional piece of software called KNOWLEDGE, version 7.0, published by a company (invent a name) that has been trying for six decades to ship a product that outputs only genuine knowledge and never mere justified true belief. Write it in the completely deadpan style of real software patch notes: version number, a changelog with bullet points, a "known issues" section, deprecated features, upgrade instructions, maybe a line about system requirements.

The joke, which must never be stated outright or winked at, is that every bug fix in the changelog corresponds to an actual move in post-Gettier epistemology. So for example: an early patch addresses a bug where a user glancing at a stopped clock that happened to show the right time was incorrectly credited with knowledge; a v2 hotfix added a dependency blocking beliefs inferred through any false step, which was later rolled back when it broke legitimate reasoning; a regional fix resolves failures in areas with high concentrations of fake barns; a reliability module gets introduced, then supplemented by a "safety" patch guaranteeing the belief could not easily have been false. You don't have to use exactly those, but every fix should be recognizably a real proposal from the literature, translated into changelog language, so that someone who knows the epistemology can map each bullet onto its source.

A few requirements:

- The deeper structural point should land without being announced: each patch spawns fresh edge cases, so the notes should quietly betray this (an anxious line about the QA team already tracking regressions for v8.0, a support ticket backlog that grows with every release, that kind of thing).
- Include a "deprecated" entry for the classic three-condition analysis: no longer supported, but retained for backwards compatability because so many users' beliefs still run on it.
- Somewhere, mention a rival product from a competitor (invented vendor) whose whole marketing pitch is that knowledge can't be decomposed into conditions at all -- the notes should treat this with the strained politeness companies use for competitors they find genuinely threatening.
- The tone stays flat and corporate the whole way through. The reader should be able to tell exactly what's being satirized without the narrator ever breaking character.

Around 600 words.
