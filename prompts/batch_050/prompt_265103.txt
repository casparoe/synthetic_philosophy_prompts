I spend a lot of time on rationalist forums, where Kant's murderer-at-the-door verdict is a perennial punching bag, so I tried to steelman the anti-Kant side and ended up with an argument that seems to prove too much. It appears to show that no universalizability test can forbid anything, and it reminds me of the familiar point that any behavior can be redescribed as maximizing some utility function, which empties that framework of content unless the class of admissible utility functions is restricted.

(1) An act is permissible iff its maxim can be willed as a universal law without contradiction.
(2) A maxim is a description under which the agent acts, and any act falls under indefinitely many true descriptions.
(3) For any act, some true description is specific enough that universalizing the corresponding maxim generates no contradiction: lie when it is the only way to shield an innocent, or in the limit a description specifying the agent, the date, and the exact circumstances.
(4) So lying to the murderer is permissible, and by the same reasoning every act is permissible.
(5) A moral test that forbids nothing is empty.
(6) Therefore the categorical imperative, and any ethics built on universalizing maxims, is empty.

Where does this go wrong? If the repair is a principled restriction on which descriptions count as genuine maxims, state the restriction precisely, check that an agent cannot evade it simply by choosing self-serving descriptions, and check whether Kant still gets his murderer-at-the-door verdict once the fix is in place. If instead a premise has to go, name it, explain why it looked fine, and price what I lose by dropping it. I would like to keep (1) and (5) if possible.
