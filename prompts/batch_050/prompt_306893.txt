I'm a backend engineer, no philosophy training, and over the holidays I got into one of those dumb-but-fun arguments with my brother-in-law about whether AI could ever really "think." He sent me a chapter from a popular science book (I think it's from the 90s, some physicist writing about consciousness) that leans heavily on Gödel's incompleteness theorem. I don't have the book in front of me, but the argument as the author presents it goes roughly like this: "Gödel showed that any formal system rich enough to do arithmetic contains true statements it cannot prove. A computer program is a formal system — it's just a fixed set of rules applied to symbols. So for any computer, there are mathematical truths it can never establish, no matter how long it runs or how much memory we give it. Human mathematicians, by contrast, can simply look at the Gödel sentence of a system and see that it must be true: we understand what the sentence says, and that understanding tells us it's true even though the system itself can't prove it. Since we can know truths that no rule-following machine can know, the mind cannot be a computer running a program, and something non-computational must be going on in the brain."

Something about this smells off to me but I can't put my finger on exactly where. From my day job I know you can't write a program that decides in general whether another program halts, and nobody concludes from that that programmers transcend computation — it just means some problems are undecidable, presumably for humans too. So I suspect a similar move is available against this guy. But I also don't want to be too quick to dismiss it, since apparently some genuinely smart people (Lucas? Penrose?) defended versions of this argument, which makes me think there might be more to it than the halting-problem analogy suggests.

So: how fair is this summary, really? I'd love a sentence-by-sentence audit — what a logician would sign off on, what's a defensible simplification for a popular audience, and what's an actual conflation or overreach. Some specific things I'm unsure about: does the step where humans "just see" that the Gödel sentence is true actually work, or does it quietly assume something about the system (like it being consistant)? Does the conclusion "the mind is not a computer" follow even if everything said about Gödel's theorem itself is correct? And is there a more careful version of this argument that philosophers still take seriously, or is the whole family of arguments considered dead in the water? One more thing — the author never says whether he's using the first or second incompleteness theorem, and from the little I've read that might actually matter for whether the argument goes through.
