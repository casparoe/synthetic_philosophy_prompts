There's a long-running argument in my reading group between a strict Bayesian and a fan of imprecise probabilities, and I want them to finally do an adversarial collaboration instead of sniping at each other. Write the joint statement they should come out with.

Background on the two sides, roughly as they'd describe themselves:

- The Bayesian says a rational agent's credence in any proposition is a single precise number (or at least a single probability function), that the standard arguments (Dutch book, accuracy dominance) support this, and that "imprecise credence" is just what you get when an agent hasn't done enough thinking or is confused about her own evidence.
- The IP person says some evidence genuinely doesn't warrant a sharp credence -- if all you know about an urn is that it contains 100 balls each either black or white, it would be irrational overconfidence to have credence exactly 0.5 that the next ball is black, and a set of probability functions (or an interval) represents your epistemic state more honestly. He also thinks ambiguity aversion in Ellsberg-style cases can be rational, not a bias.

The document should have:

1. A numbered list of claims both sides can actually sign. I'd hope these include things like: both agree precise credences work fine in lots of ordinary cases; both agree the Ellsberg experiments show *something* about real people; both agree that a set of priors will often shrink toward a point as evidence comes in, so the dispute is mostly about cases of sparse or conflicting evidence. Push beyond these though -- don't just pad the list with trivia.

2. A disagreements table where each row states one disagreement in wording that *both* would accept as a fair description of their own position. Some fault lines I already know about that should defintely make it in: whether rationality ever *requires* imprecision (vs. merely permitting it); whether it's a problem for IP that an agent with interval credences can end up paying to avoid free information or changing her interval when she learns something intuitively irrelevant to the question at hand (the Bayesian thinks these are reductios, the IP guy thinks they're features); and whether decision rules for imprecise credences like taking the worst-case expected value are principled or just pessimism dressed up in formalism.

3. The cruxes -- the sub-questions where settling things would actually move one of them. For each crux, give a concrete case or thought experiment both would accept as bearing on it, and write down in advance what each side predicts about that case (e.g. what each says is the rationally required response to a specific Ellsberg setup, or to a sequence of uninformative observations about a process of unknown bias).

4. If any part of their dispute turns out to be verbal -- e.g. one side using "credence" for a psychological state and the other for what it's rational to act on -- flag it and say which part.

Format: the agreed-claims section numbered, then the table, then cruxes. Write it in the neutral, slightly stiff tone such documents always have, but keep the cases concrete.
