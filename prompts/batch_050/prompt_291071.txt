Build the tree from the logical space, not from a list of names: each branch node should be a question a student could answer without knowing the labels (e.g., whether it can be impersonally bad that a pleasure never exists, whether intense suffering is lexically worse than any amount of mild suffering, whether adding happy lives makes a world better). Each leaf gets the position's name (or 'unnamed' if the combination is coherent but nobody defends it) plus one sentence on its most awkward commitment. Flag any unoccupied combos and say briefly why they're empty. At the end, tell me which branch node you'd expect to be most contested and what consideration would make you reorder the tree.
