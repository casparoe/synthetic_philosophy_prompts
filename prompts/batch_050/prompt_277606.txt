For a philosophy seminar handout, write a decision tree that sorts positions on the relation between knowing how and knowing that. Start from the shared datum that competent speakers ascribe both kinds of knowledge, often of the same activities, and that nobody denies there is some distinction in how the ascriptions behave; the disagreement is over what that distinction amounts to. Build the tree from the logical space rather than from a list of names: each branch node should be a concrete case or claim on which the positions genuinely diverge, phrased so a student can answer it without knowing where it leads. The nodes should include at least: whether someone can know how to do something while being unable to do it (consider the retired gymnastics coach whose body no longer cooperates); whether someone can reliably perform an activity without knowing how (consider the novice golfer who holes every putt while misdescribing entirely what she is doing); whether knowing how can be Gettiered; and whether pre-linguistic children and animals possess know-how. The leaves should locate at least the Rylean ability view, a modified ability view that restricts which abilities count as know-how, intellectualism of the Stanley–Williamson sort, and any hybrid or pluralist position the tree generates; each leaf gets the position's name (or "unnamed" if undefended) plus one sentence on its most awkward commitment. Note any unoccupied combinations and diagnose briefly whether they are empty because incoherent, unattractive, or merely unexplored, and flag any pair of named positions your tree cannot separate. Twelve nodes at most. Finally, indicate which of these cases and verdicts are treated as settled data in the literature and which are themselves contested, rather than presenting disputed intuitions as consensus.
