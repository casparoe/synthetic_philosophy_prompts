The engineering constraints:

After the scenario and the game tree (write out the full payoff schedule), do the demonstration: run backward induction explicitly node by node, run your chosen alternative explicitly, and then tell me which single feature is doing all the work -- i.e., if I tweak that one thing, does the alternative prediction collapse back to node-one take, and does backward induction care?
