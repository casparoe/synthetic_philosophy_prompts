I'm a software engineer (no formal philosophy training) trying to write up my views on autonomous weapons for an internal ethics discussion at work, and I'd like a consistency check before I circulate anything. Roughly, I hold:

1. Meaningful human control is a real requirement: for each use of lethal force, some human must genuinely understand what the system is doing and be positioned to intervene — merely having clicked an approval prompt doesn't count.

2. But I don't think this requires explainability in the ML sense. We hold human soldiers responsible without being able to explain their split-second perceptual judgments, so demanding interpretability from a targeting model that we never demand from a human looks like a double standard.

3. Every wrongful strike must have an answerable agent. "The algorithm did it" cannot be where the buck stops; a responsibility gap is unacceptable.

4. In some defensive contexts — missile defense, counter-swarm systems — human reaction times make per-engagement human control physically impossible, so fully automated engagement is justified there, and insisting otherwise costs lives.

5. Autonomous weapons should be treated like safety-critical software: field only systems whose behavior can be bounded by verification and testing, and don't deploy systems whose failure modes you can't characterize.

My question: does this package hang together? Please go through the commitments pairwise where relevant, tell me which pairs are in genuine tension versus only apparent tension, and rank any real tensions by severity. For each genuine tension, identify exactly which commitment has to give and what the cheapest revision would cost me. I'm not attached to any particular one of these — I'd rather know where the problem is than defend the set as written.
