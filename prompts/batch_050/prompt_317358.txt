I've come to hold a view about which artificial systems deserve moral consideration, and I'd like to know what would count against it. The view: a computation matters morally only if its internal states are genuinely load-bearing — that is, only if intervening on those states would change the system's subsequent behavior, so that the system would have responded differently had things gone differently inside it. On this view, a system that produces its outputs by replaying a vast prerecorded lookup table has no moral status whatsoever, however lifelike its conversation, since nothing it says is sensitive to how the exchange actually unfolds; by contrast, even a quite simple recurrent system whose ongoing states carry forward and shape its future processing could in principle count. Please give me an honest map of this position's exposure. Which cases does it plausibly get wrong — systems whose causal structure is load-bearing but only rarely exercised, systems whose internals are real but causally bypassed in edge cases? Which intuitions and arguments must it flatly deny (behavioral equivalence, substrate independence, the thought that gradually replacing a brain's components with table lookups cannot make suffering blink out)? Could any empirical or formal result settle the dispute, or is the disagreement insulated from evidence? Which objections would a committed proponent concede as genuine costs, and which would they absorb by biting the bullet? Rank the defeaters from fatal to merely awkward. My own deepest worry is that the view makes moral status depend on implementation details that no observer could ever detect — I'd like to know whether that's decisive or whether the view has the resources to answer it.
