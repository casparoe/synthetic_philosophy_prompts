So a few of us run a reading group on AI safety and for months we've had this running fight between two people, call them the impact-measure person and the no-free-lunch person. The impact-measure person thinks we can train agents that get things done while "not messing up the world", by penalizing how much the agent changes the environment relative to some counterfactual baseline where it did nothing (or did something inert) — stuff in the spirit of attainable utility preservation, where you penalize changes in optionality or reachable states rather than raw changes in the world. The no-free-lunch person thinks the whole research direction is doomed in principle: any measure of "impact" either (a) is gameable by a sufficiently capable agent — offsetting its effects, preemptively disabling the things that could undo its changes, shoving the real effects into parts of the measure nobody's watching — or (b) only works because it quietly encodes the full human utility function, in which case you never actually avoided specifying values, you just hid the specification in the penalty term.

They've finally agreed to stop arguing past each other and write a joint statement, and I've volunteered (why did I volunteer) to draft it. Write the document they should produce. I want: (1) a numbered list of claims both would actually sign — for instance about what naive impact penalties get wrong, about the difference between avoiding side effects and avoiding agency altogether, about whether "the agent does nothing" is even a well-defined baseline once the agent exists and could have been built differently; (2) a disagreements table where each side's position is stated in words that side would accept, not the other side's caricature of it; (3) the cruxes — my guess is one is whether a baseline can be fixed without smuggling in values, another is whether the known failure modes are engineering problems or conceptual ones, and maybe a third about whether low impact is a property a genuinely smart agent can have while still being usefull for anything; and (4) for each crux, some case, experiment, or formal result that both sides agree would bear on it, with each side's prediction written down in advance so nobody gets to move the goalposts afterwards.

If part of their disagreement turns out to be verbal — say they're using "side effect" or "impact" in different senses — the document should say which part and disentangle the seperate senses rather than papering over it. One more thing: the no-free-lunch person keeps insisting the other position has "no falsifiable content", so the document needs to include any observation, demo, or result that would genuinely force an update from either of them — and if there isn't one for some crux, the statement should admit that plainly instead of pretending the crux is empirical. Format it as the agreed-claims section first, then the disagreements table, then the cruxes with predictions.
