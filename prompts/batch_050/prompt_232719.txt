The question I set:

Suppose Lab A simulates a mouse brain neuron-by-neuron in real time, where every spike in the simulation happens because the previous timestep was actually computed. Lab B has, in advance, generated the complete behavioral record of that same mouse over a ten-minute window and now just plays it back; during the window the two setups are indistinguishable from outside. (a) If you think only A is sentient, give a principled criterion for which computations "count" -- one that doesn't just smuggle in a preference for biology or for realtime running. (b) The fading-qualia thought experiment (gradually replacing a brain's neurons with functional silicon substitutes and asking what happens to experience) is sometimes cited in this debate. State what it actually establishes and whether it settles anything about Lab B. (c) Lab C runs the same simulation as A but compresses it: whenever the simulation would repeat a subcomputation it has done before, it performs it once and reuses the result. Does C contain the same amount of whatever morally matters as A? Defend an answer.

The student's answer:

(a) Only A is sentient. Sentience requires counterfactual-supporting causal structure: in A, each state causes the next, and had the inputs been different the states would have been different too. B is just a playback device -- it would produce the same recording no matter what, so there is no computation there at all, any more than a film of a fire is hot. The morally relevant thing is the causal process, not the observable output.

(b) The fading-qualia argument shows that any system with the same input-output behavior as a brain is conscious, since replacing neurons one by one with functionally identical chips can't suddenly or gradually remove experience. But that argument applies to B just as much as to A, since B has identical observable behavior. So either my answer to (a) is wrong, or A isn't sentient either, which is absurd -- so probably B is sentient too, and sentience is a matter of getting the right outputs.

(c) C contains less suffering than A. If a painful subcomputation would occur a thousand times in A but C only actually performs it once and reuses the answer, then there is literally one instance of pain instead of a thousand. Deleting copies of an experience deletes experiences -- one scream is not a thousand screams. The compression saves compute and the savings come from somewhere: the skipped executions are skipped pains. So C matters less, morally, in proportion to how aggressively it's compressed.
