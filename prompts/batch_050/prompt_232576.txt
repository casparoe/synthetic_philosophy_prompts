Here's what I've got so far:

1. Martin's electro-fink: the wire is live, but it's hooked up to a machine that would instantly make it dead the moment anything touched it. So it never conducts, but it still seems like it's live.
2. The fragile vase swaddled in bubble wrap: still fragile, but drop it and the packaging absorbs the shock, so no shattering. Classic mask.
3. Lewis's sorcerer-style fink: a substance is poisonous, but a sorcerer stands ready to strip its toxicity the instant anyone ingests it.
4. The reverse-fink sort of case: a styrofoam dish that isn't fragile at all, but something (a spell, a device, whatever) would make it fragile the moment it's struck, so it shatters even though it lacks the disposition.
