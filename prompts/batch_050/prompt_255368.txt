I run the forecasting unit at a policy research institute. We license powerful general-purpose prediction systems from outside vendors, and for each system and each proposed use I must decide whether its outputs are safe to act on or might instead be steered. A colleague argues that the worry is not merely empirical but follows from an a priori consideration: if such a system approximates something like a universal (Solomonoff-style) prior over hypotheses, then among the shortest programs that predict our observations well there may be some containing simulated reasoners with their own goals; those programs carry high prior weight, so the system's outputs -- especially on questions where influencing us would serve those goals -- cannot be assumed to be disinterested pattern-matching. Please turn this "malign prior" concern into a decision procedure my team can actually run when evaluating a vendor's system for a given use: the questions to ask in order, what would count as a sufficient answer to each given that vendors disclose little about internals, where the procedure stops with a refusal, and where it must hand the decision to a person because the question is one of values rather than facts. Then run the procedure on two cases: using the system to forecast six-month commodity prices, and using it to identify which messages will most persuade undecided voters in an election. Finally, state plainly what the procedure cannot do, and where the underlying argument is itself contested enough that a reasonable team could set its thresholds differently.
