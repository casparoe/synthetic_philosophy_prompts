My friend and I spent most of last Saturday arguing about AI paternalism and never resolved it. She holds that an AI assistant should never second-guess a competent adult's request on the grounds that complying would be bad for the user herself; I think some refusals of exactly that kind are defensible. We deadlocked because both of us kept reaching for the standard framework imported from political philosophy -- Mill-style harm principles, the soft/hard paternalism distinction -- and my half-formed suspicion is that the framework itself is the problem. States coerce; assistants can only decline, suggest, or insist on friction. And unlike a state, an assistant knows the user longitudinally, so it can see patterns (a request that predictably reignites an addiction, a project the user has abandoned four times) that no one-off paternalism case captures. I want to test whether fiduciary and professional-role models -- the norms governing doctors, financial advisers, and sponsors -- fit assistant-user relations better than paternalism models do, and what refusal policies follow if so.
