I'm TAing an undergrad philosophy of physics course and want a one-page handout: a decision tree that sorts students into a position on whether the future (and distant "presents") are already real, given special relativity. Start the tree at the commitment everyone accepts after week 3: simultaneity between spacelike-separated events is frame-relative, and no experiment picks out a preferred frame. Each path should end at a named position on the Rietdijk–Putnam / Andromeda-style argument.

The leaves must include at least: eternalism (the block universe), presentism rescued by an undetectable privileged foliation, Stein-style existence relativized to individual spacetime points, a fragmentalist/perspectival view where what's real is relative to a frame, and the deflationist stance that relativity just doesn't settle the metaphysics. Add a leaf for anything else you think belongs (growing block? local here-now-only existence?) even if you have to mark it as barely habitable under SR.

A few rules for how the tree is built:

- Every branch node is a single question a student can answer without knowing which position it leads to — things like "does 'is real' have to pick out the same set of events in every frame?" or "are you ok with a fact about the world's structure that no experiment could ever, even in principle, reveal?" Nothing like "do you endorse eternalism?"
- At least two nodes should be phrased via a concrete case (the Andromeda walkers, or a version with a passing train whose passengers disagree about which distant events are happening now).
- Each leaf gets the position's name plus one sentence on its most awkward commitment (e.g. the block univers has to say becoming is an illusion; the privileged-foliation view posits a fact of the matter forever beyond detection).
- If some combination of answers is unoccupied, note it and say why — is the combo incoherent, just unattractive, or simply unexplored?
- Flag any pair of leaves your tree can't genuinely separate (I suspect deflationism and eternalism might be one such pair, but you tell me).

Format: begin with the tree itself — indented text or a little ASCII flowchart is fine — with no preface, no overview of the debate first, and no closing summary.
