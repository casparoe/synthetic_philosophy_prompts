A colleague has an argument that fictional characters must exist, and the conclusion strikes me as a cheat, but I can't locate the misstep. (1) We can truly say things like "Sherlock Holmes was created by Arthur Conan Doyle" and "Holmes is more famous than any actual detective." (2) A sentence containing a singular term is true only if that term refers to something. (3) So "Sherlock Holmes" refers to something. (4) It cannot refer to a concrete person, since no such person ever lived at Baker Street. (5) So it refers to an object of some other kind — an abstract artifact, a nonexistent object, or a merely fictional entity. (6) Therefore fictional characters are genuine objects of reference. This seems to prove too much: the same machinery would commit us to every character ever named in any story, however incoherent, which is a lot of ontology to buy for the price of a few book reviews. Which step should I reject, and what does rejecting it cost? Two constraints: I would rather not deny the data in (1), since calling "Holmes was created by Doyle" untrue seems desperate, and I want any diagnosis to explain what the argument makes of the contrast between that sentence and "Holmes is a detective," which doesn't even pretend to be about Doyle.
