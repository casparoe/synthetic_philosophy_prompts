Ok so I've been re-reading the old grue threads on LessWrong and the classic move there is basically: Solomonoff induction dissolves the new riddle, because "green" has a short description and "grue" needs extra bits to specify the switchover time, so any Occam-flavored prior automatically prefers green-projections and Goodman is just confused about simplicity. And the standard reply is that description length is language-relative, and if your primitive vocabulary contains grue and bleen instead of green and blue, then it's *green* that's gerrymandered and long, so you've just relocated the problem to the choice of basic predicates.

I want the document an adversarial collaboration between these two camps would actually produce. Call them:

Camp A (the dissolutionists): a universal prior / minimum-description-length approach resolves the new riddle; grue-style predicates are genuinely more complex *relative to any computationally reasonable encoding*, e.g. because the switchover time t is an arbitrary constant you have to pay bits for, and worries about language-relativity are handled by the fact that reasonable universal Turing machines agree up to an additive constant (the invariance theorem).

Camp B (the Goodman loyalists): the new riddle survives formalization. The invariance theorem's constant can be arbitrarily large, "reasonable" is doing all the normative work, and more importantly the problem was never just about which hypothesis wins in the limit -- it's about what justifies privileging a hypothesis class / predicate vocabulary at all, and Solomonoff quietly builds the answer into the choice of machine.

To make this concrete rather than the usual gesture at each other, give both camps this shared case to work through: an ML lab trains a sequence predictor on sensor readings from a gemstone that has been scanned daily for centuries and always fluoresced green. The lab knows the sensor hardware will be replaced on January 1, 2100, with a new sensor that reports an inverted color channel. Both camps get full access to this setup. Camp B should argue that this case shows the green/grue symmetry is real and that Camp A's "extra bits" story smuggles in background knowledge about sensor physics; Camp A should argue it shows the opposite -- that once you make the setup fully explicit, the apparent symmetry collapses, because now "grue relative to 2100" is just a short program describing a sensor swap, and the *original* grue hypothesis without that physical story stays long.

Deliverable format:

1. A numbered list of agreed claims -- things both sides will sign. These have to be non-trivial: not "induction is philosophically interesting" but e.g. agreements about what the invariance theorem does and doesn't establish, about whether grue can be ruled out on purely syntactic grounds, about what the sensor-swap case does and doesn't show, about what each side would have to concede if X were demonstrated.
2. A disagreements section where each disagreement is stated as two formulations, one written by each camp about its *own* position, such that the other camp agrees the wording is fair (no "my opponent believes induction is magic" strawmen).
3. A cruxes list: the sub-questions where, if you settled them, at least one camp would have to update. For each crux, write down what each camp predicts and what result would move them -- including, if one camp admits nothing could move them on a given crux, them saying so on the record.
4. A short closing section where both camps state whether they think any of the remaining disagreement is purely verbal, and if so which part and why the other camp is wrong that it's verbal (they can disagree about which parts are verbal, that's fine, but they have to be specific).

Don't adjudicate who wins. Don't give me a dialogue. I want the dry, careful document two people who'd been arguing about this for a decade would grudgingly co-sign. Also both camps should take the sensor-swap case seriously as the main testbed rather than retreating to the abstract version of the debate -- that's the whole reason I set it up.
