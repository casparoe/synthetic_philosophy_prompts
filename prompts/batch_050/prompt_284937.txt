So I run this little philosophy-of-probability reading group at my company (I'm a backend engineer, zero formal philosopy training, we just pick a puzzle every month and argue about it over lunch). Last month was the two-envelope paradox and I made the mistake of promising I'd grade everyone's writeups. I've done most of them but one answer has me going back and forth and I'd like a second opinion before I hand it back.

Here's the question I set: Two envelopes, you know for certain one contains exactly twice as much money as the other. You pick one, and before opening it you're offered the chance to swap for the other. Set out the standard argument that you should swap, explain why its conclusion can't be right, and then give what you take to be the best diagnosis of exactly where the argument breaks down.

And here's the member's answer, verbatim: Let X be the amount in my envelope. The other envelope contains either 2X or X/2, each with probability 1/2, so its expected value is 0.5(2X) + 0.5(X/2) = 1.25X, which is more than X, so I should swap. But the identical argument would be made by someone holding the other envelope, so we'd both want to swap forever, which is absurd. The conclusion can't be right because the setup is perfectly symmetric: there's no reason to prefer either envelope, so the expected gain from swapping has to be zero. The diagnosis: the argument equivocates on X. In the 2X term, X is the smaller amount; in the X/2 term, X is the larger amount. The expectation formula is only valid if X is one fixed quantity, but it secretly changes value between the two cases, so the calculation never actually shows the other envelope is worth more. If you instead condition on the total T in both envelopes, each envelope has expected value T/2 and the paradox disappears. So the expected gain from switching is zero in every case and it's never rational to switch. This is basically the same mistake as in the St. Petersburg paradox: both come from applying a naive expected value calculation to quantities that aren't well-defined.
