I am a third-year undergraduate taking a formal epistemology course, and I am drafting a term paper on whether rational agents should ever refuse costless evidence. Before developing the argument, I would like a consistency check of the following commitments:

1. Good’s theorem has normative force, not merely descriptive force. For an ideal agent with a single prior, fixed utility function, fixed set of feasible actions, and Bayesian conditionalization, accepting any experiment with zero total cost is weakly better in expectation than refusing it. I am inclined to state the moral more generally: insofar as evidence can improve a decision, an ideally rational agent should never prefer ignorance as such.

2. Nevertheless, someone may rationally decline a free genetic test if an insurer, employer, or family member will also learn the result, or if receiving the result will close off valuable future opportunities. I do not regard such cases as counterexamples to the value of information, since the collateral consequences are part of the agent’s payoffs.

3. The value of acquiring evidence must be assessed ex ante. If a test result happens to lead to a bad outcome, perhaps because the remaining uncertainty resolves unfavourably, that does not retroactively show that acquiring the test was irrational.

4. If experiment A is Blackwell-sufficient for experiment B—in the sense that B’s message can be generated by adding state-independent noise to A’s message—then every ideal Bayesian facing the same utilities and feasible actions should weakly prefer A to B, although A need not be strictly preferable.

5. Ellsberg-style ambiguity aversion can be rational. For example, preferring a bet on an urn known to contain fifty red and fifty black balls over the corresponding bet on an urn of unknown composition need not be a mistake. I would represent such an agent with a set of priors and maxmin expected utility, updating each prior after receiving evidence.

6. Rational agency is dynamically consistent. If an agent can foresee that acquiring information will produce continuation preferences under which they will choose an option they currently rank below an available alternative, that predictable reversal is itself a reason against the information-gathering plan. One cannot dismiss the reversal simply because it will occur at a later stage.

7. Information has purely instrumental value. If no possible message from an experiment could affect any feasible choice or payoff, then the experiment has no value merely because it reduces uncertainty or satisfies curiosity.

Please audit the whole set rather than assessing each thesis in isolation. Which pairs or triples are genuinely in tension, which only appear to conflict because they invoke different decision problems, and which are consistent but require unusually careful qualification? In particular, distinguish between a case where information itself has negative expected value and a case where the allegedly free information carries additional costs or changes the available actions.

Rank any genuine tensions by severity. For each one, identify the smallest group of commitments responsible and say exactly what would have to be abandoned, weakened, or restricted. Finally, recommend the least costly overall revision that would make the position coherent, and state what theoretical benefit that revision would sacrifice.
