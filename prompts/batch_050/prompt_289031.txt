**Homework question**

In class, we defined superrational reasoning for a perfectly symmetric one-shot game as follows: a player recognizes that all relevantly similar players, facing the same choice and using the same reasoning, will reach the same conclusion. The player then chooses whichever common action would produce the best result if adopted by everyone.

Consider this one-shot prisoner’s dilemma. Each player chooses independently, there is no communication or enforcement, and the first number in each cell is Row’s payoff while the second is Column’s payoff:

|                | Column: C | Column: D |
|----------------|-----------|-----------|
| **Row: C**     | 3, 3      | 0, 5      |
| **Row: D**     | 5, 0      | 1, 1      |

a. Explain why defection strictly dominates cooperation and why mutual defection is the unique Nash equilibrium.

b. Explain how the definition of superrationality above could lead both players to cooperate.

c. Does superrational reasoning show that the usual dominance or equilibrium analysis is mistaken, or that either player causally influences the other? Explain.

d. Is superrationality rational in this case? Give the strongest argument for it and one serious objection.

**Student’s answer**

1. Defection strictly dominates cooperation. If the other player cooperates, defecting gets 5 instead of 3; if the other player defects, defecting gets 1 instead of 0. Thus defection is better no matter what the other player does. Mutual defection is also the only Nash equilibrium. Holding the other player’s action fixed, either player gains by switching unilaterally from cooperation to defection in every other cell.

2. Superrationality adds a symmetry constraint to the decision. Each player knows that the other is relevantly similar and will use the same reasoning, so they will arrive at the same conclusion. The real choice is therefore between both cooperating and both defecting, rather than among all four cells. Since mutual cooperation gives each player 3 while mutual defection gives each only 1, a superrational player chooses cooperation.

3. This does not depend on communication, enforcement, or causation between the players. Each still makes a separate choice, and neither player’s button-pushing causes the other player’s choice. The connection is instead in their shared reasoning. Because each knows the other will reason identically, neither can consistently treat their own conclusion as evidentially independent of the other’s conclusion. For that reason, ordinary dominance reasoning fails in this setting, since dominance reasoning applies only when the two choices are independent.

4. Once both players use superrational reasoning, mutual cooperation becomes another equilibrium. Under the matching assumption, there is no such thing as one player switching from cooperation to defection while the other remains cooperative. If one player’s reasoning changes, the other player’s identical reasoning changes too. So neither player can gain by deviating alone, which means mutual cooperation satisfies the equilibrium condition.

5. The strongest argument for superrationality is that rationality should be judged by results. Agents who reason superrationally get 3 each, whereas agents who both follow dominance reasoning get only 1 each. Refusing to use a rule that would make everyone better off seems self-defeating.

6. A serious objection is that superrationality asks a player to ignore the actual payoff structure. The other person’s action is already fixed and causally independent, so defecting would improve this player’s outcome in either case. On this objection, superrationality gets cooperation only by replacing the original decision problem with a different correlated-choice problem.

7. Overall, superrationality is rational in the one-shot prisoner’s dilemma because it reaches the jointly best outcome without altering the payoff matrix or assuming communication.
