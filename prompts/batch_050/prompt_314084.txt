**Pricing the Unpriceable: A Chronological Proposal for Games Without Expectations**

*1. Two paradoxes, and why only one of them is my target.* In the St. Petersburg game, a fair coin is tossed until it lands tails; if that happens on toss n, the prize is 2^n dollars. The expected value is the sum 1 + 1 + 1 + …, which diverges. The expectation is infinite, but at least it is unambiguous: all the terms are positive, so no matter how you add them, the sum is the same. Now consider the Pasadena game, which has the same stopping rule but a different prize schedule: if the game ends on toss n, you receive (−1)^(n−1) · 2^n / n dollars. So you win $2 if it ends on toss 1, lose $2 if it ends on toss 2, win $8/3 on toss 3, lose $4 on toss 4, and so on — the prizes grow without bound in magnitude while alternating in sign. The expectation, if it existed, would be the sum of the terms (−1)^(n−1)/n, which in the natural order is just the alternating harmonic series and converges to ln 2 ≈ 0.69. But the positive terms alone (1 + 1/3 + 1/5 + …) diverge, and so do the magnitudes of the negative terms, so the expectation does not exist, not even as an infinite one: by the Riemann rearrangement theorem, the terms can be reordered to sum to any real number whatsoever, or to diverge. Expected utility theory therefore assigns the Pasadena game no value — not zero, not infinity, nothing.

*2. Why this is worse than St. Petersburg.* With the St. Petersburg game, expected utility theory says too much — the game is worth any finite price — but at least it speaks. With the Pasadena game it is silent. I want to argue that silence is the worse failure mode. An agent guided by expected utility theory cannot even compare the Pasadena game against a certain loss of a million dollars, which means the theory cannot recommend refusing to play: refusal is itself an option the theory fails to rank.

*3. My proposal: chronological value.* The rearrangement problem shows that no value is fixed by the payoff distribution alone. But a game is more than its distribution — it is a procedure, and the Pasadena procedure has a natural order: toss 1, toss 2, toss 3, and so on. The order in which outcomes can occur is a causal fact about how the game is played, not a mathematical convention about how to write down an infinite sum. I therefore propose the following. Where a game's expectation is undefined, but the sequence of partial sums taken in the order in which the game's outcomes can actually occur converges, call that limit the game's *chronological value*, and hold that a rational agent should treat it as the fair price of a play. The chronological value of the Pasadena game is ln 2. [I would like to defend this with a long-run claim: I believe, though I have not been able to prove, that if the game is played repeatedly, the running average of the payoffs converges to ln 2 with probability one. If that is right, then an agent who repeatedly pays less than ln 2 per play will almost surely come out ahead in the long run, and one who repeatedly pays more will fall behind — which would ground the fair price in something more solid than a convention about summation order.]

*4. Objections.* (i) *The arbitrariness returns.* A game with the very same payoff distribution could be staged differently — say, with a rigged deck determining the outcome, arranged so that the large negative prizes correspond to earlier possible endings. Chronological value would then diverge from ln 2 despite the identical distribution. My reply: chronological value is a property of procedures, not distributions, and two such stagings are simply different games; agents are offered games, not distributions. (ii) *The proposal is silent where I most want it to speak.* It says nothing about games whose chronological partial sums diverge, and the long-run defense in §3 applies only to repeated play, not to a one-off offer. I concede both points but argue that a partial theory beats a silent one.
