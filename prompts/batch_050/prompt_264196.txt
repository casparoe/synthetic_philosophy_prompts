I'm trying to pin down when an argument in set theory genuinely requires an axiom of choice, going by my instincts on cases. My verdicts: choosing the left shoe from each of infinitely many pairs of shoes needs no choice principle, but choosing one sock from each of infinitely many pairs of indistinguishable socks does; picking the least element of each nonempty set of natural numbers is choice-free; selecting a representative from each equivalence class in the construction of a Vitali set demands full choice; choosing an element from each of finitely many nonempty sets clearly needs no axiom; choosing the midpoint of each of infinitely many closed intervals is choice-free, yet choosing an element from each of infinitely many arbitrary nonempty sets of reals is not. Where I hesitate: using dependent choices to build a sequence feels mild, almost like ordinary induction, and choosing a preimage under a given surjection feels like it should come for free since the function is already given. Please give your answer in American English, as a numbered list of exactly five items, each a sentence or two, with no introduction or conclusion: state a precise principle (or two candidates) separating the choice-free cases from those requiring an axiom, say which of my verdicts it vindicates and which it must overturn, and apply it to my two hesitant cases.
