I've been reading about the idea that consciousness is a "user illusion": roughly, that what introspection presents to us is a heavily simplified interface over brain processes, comparable to a computer desktop, rather than a transparent window onto what is really going on. I find the analogy persuasive, but it seems to have a disturbing consequence nobody I've read addresses head-on. If my feelings are part of the interface rather than part of the underlying machinery, then pain, in particular, would seem to be an illusion in the same way that the desktop folder is an illusion: a convenient fiction, not something that actually exists. But if pain doesn't really exist, I don't see why I should care about it -- mine, other people's, or animals'. So my question is: given that consciousness is a user illusion, what is the best argument that suffering still matters morally, and how do defenders of this view avoid the conclusion that ethics is built on a fiction?
