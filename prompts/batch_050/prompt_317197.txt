Exam question: Curry's paradox and Yablo's paradox are both said to complicate the standard diagnosis of the liar paradox, namely that paradox arises from self-reference combined with the naive truth schema. State each paradox precisely, sketch the derivation of the contradiction in each case, and explain (i) which logical resources each derivation actually depends on, and (ii) what each paradox shows about the prospects of blocking paradox simply by banning self-reference.

Student's answer: Curry's paradox uses the sentence C: "If C is true, then p," where p is arbitrary, e.g., "the moon is made of cheese." Assume C is true. Then, by the truth schema, what C says holds, so if C is true then p. By modus ponens, p. Discharging the assumption, we have shown that if C is true then p -- but that is exactly what C says, so C is true, and by modus ponens again, p follows. Since p was arbitrary, naive truth makes everything true, and note this never uses negation, unlike the liar. Because the derivation relies on classical principles -- in particular reasoning by cases and excluded middle, since at some point we must assume C and then discharge -- Curry's paradox is blocked in intuitionistic logic, which is why intuitionists about truth are safe from it. Relevance logics block it too, but only because they reject weakening, i.e., the ability to add irrelevant premises, which Curry's derivation requires. Yablo's paradox is an infinite sequence of sentences S1, S2, S3, ..., where each Sn says: every sentence after Sn in the list is false. Suppose S1 is true; then S2 and everything after it is false, but S2's being false means some sentence after S2 is true, contradicting S1. So S1 is false; but then some Sn (n > 1) is true, and running the same argument on Sn yields a contradiction again. Each sentence speaks only of later sentences, never of itself, so the paradox is entirely free of circularity, and commentators universally accept that Yablo showed self-reference is inessential to semantic paradox. Yablo's construction also avoids the truth schema entirely, since the sentences merely say of others that they fail to hold. Conclusion: banning self-reference cannot block paradox, since Curry uses no self-referential negation and Yablo uses no self-reference at all.
