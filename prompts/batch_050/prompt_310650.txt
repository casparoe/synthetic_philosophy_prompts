**Question (20 pts):** (a) Explain the difference between dialetheism and paraconsistent logic, and why a dialetheist about the Liar paradox needs a paraconsistent logic. (b) In Priest's LP, which familiar classically valid inference rules fail, and why? Illustrate with at least two examples. (c) Briefly assess how serious a cost these failures are for the dialetheist.

**Student answer:**

(a) Dialetheism is the thesis that some sentences are both true and false — there are true contradictions, called dialetheias. Paraconsistency is a property of a logic: a logic is paraconsistent if contradiction doesn't explode, i.e. from A and ¬A you can't derive an arbitrary B. So they operate at different levels — one is a metaphysical/semantic thesis, the other formal. You can also endorse paraconsistency without dialetheism, e.g. if you're modelling inconsistent databases or belief sets you want a logic that doesn't explode without thinking the contradictions are true. The dialetheist needs paraconsistency because if she says the Liar is both true and false but keeps classical logic, explosion gets her trivialism — everything is true — which even Priest rejects.

(b) In LP sentences can be true only, false only, or both; the designated values are true-only and both, and an inference is valid iff it preserves designatedness. The Liar ('this sentence is false') comes out both true and false. Rules that fail: explosion fails (A, ¬A ⊬ B — take A both true and false and B false; premises designated, conclusion not). Disjunctive syllogism fails too: from A∨B and ¬A you can't infer B, because if A is both, then A∨B and ¬A are both designated while B is plain false. Modus ponens, by contrast, is still fine: if A and A⊃B are both true, B must be true, since A⊃B rules out the case where A is true and B false. Also worth noting that A∧¬A is designated under every LP valuation, which is exactly what the dialetheist wants.

(c) The cost is real but manageable. Losing disjunctive syllogism hurts since it's used constantly in ordinary reasoning, but Priest argues the classical rules are recoverable wherever the domain is consistent, so we only give them up where contradictions actually arise, which is rare. I'd say this cost is smaller than the costs of the alternatives (Tarskian hierarchies, truth-value gaps), so it's a price worth paying.
