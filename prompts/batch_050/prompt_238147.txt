On moral relativism, whether an action is right or wrong depends on the moral code of the culture in which it is performed: an action is right if the code of the actor's society permits it, and wrong if that code forbids it. There is no culture-independent standard against which codes themselves can be assessed.

The argument from disagreement runs as follows. Different cultures hold deeply opposed moral views, about how the dead should be treated, about obligations to elderly parents, about the permissibility of charging interest on loans. These disagreements are not shallow: they persist even when the parties agree about all the relevant non-moral facts. If there were a single culture-independent moral truth, we would expect sustained reflection on agreed facts to produce convergence, just as it does in the sciences. Since it does not, the best explanation is that there is no such truth, only the varying codes of different societies. It is important to see that the argument starts from a purely descriptive premise, that cultures do in fact disagree, and tries to reach a normative conclusion about the status of morality; the whole question is whether the inference is legitimate.

One attractive feature of the view is that it seems to give us a reason to be tolerant of other cultures. If rightness is always relative to a code, then judging another culture by our standards is a mistake, since our standards do not apply to them. Relativism therefore supports an attitude of tolerance toward practices we find alien.

The strongest objection is the reformer's dilemma. If the code of a society determines what is right in that society, then an internal critic, someone in a slaveholding society who campaigns for abolition, is automatically wrong by definition, since they oppose the existing code. Worse, moral progress within a society becomes unintelligible, since there is no standard above the code by which a change in the code could count as an improvement.

The objection does not succeed. Reformers characteristically appeal to values already present in their own culture's code and argue that the culture is failing to live up to them; abolitionists appealed to principles their societies already professed. Reform is therefore possible as the more consistent application of a society's own commitments. And moral progress is possible too, since societies' codes change over time, and each later code defines what is right for its own period. What the objection really shows is only that relativists cannot rank one culture's code against another's, which is a consequence the relativist is happy to accept.
