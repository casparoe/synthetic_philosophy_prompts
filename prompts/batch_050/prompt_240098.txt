I sit on the allocation commitee of a three-hospital consortium that shares one mobile MRI scanner on a rotation. The schedule is up for renegotiation and the debate keeps going in circles for a weird reason: everyone judges each proposed change against a different idea of what would happen if we fail to agree. Hospital C's director insists that without a bigger share of slots they'll buy their own unit and leave the consortium, so he measures every proposal against that baseline. The other two think he's bluffing and measure proposals against the current schedule just continuing. So we can argue for an hour about whether some tweak "helps C" without resolving anything, because we can't agree on what it's being compared to.

One member (who has some decision theory background) has proposed cutting through this with a standing rule: we only approve schedule changes that are an expected improvement for each hospital under *every* plausible hypothesis about what the others would do if we didn't act. So if a change beats the current schedule for C but loses to the world where C leaves, and we're unsure which of those we'd actually be in, the change fails the test. He calls it a safe improvement criterion, and says the beauty of it is that nobody has to win the argument about who's bluffing.

I'm skeptical in a way I can't quite articulate. It sounds obviously sensible — who could object to only making changes that help everyone no matter what? — but I worry it hands a veto to whoever can most convincingly muddy the counterfactual waters (C's director now has an incentive to make his threat sound credible forever), and that it quietly entrenches whatever schedule we happened to start with, which was set nine years ago for reasons nobody remembers.

Please draft the memo I'd bring to our next meeting: should we adopt this as our standing rule for schedule changes, adopt it with qualifications, or drop it? The memo needs an actual recommendation, and it should steelman the rule before criticizing it, if you do criticize it — you might end up defending it, that's fine. Somewhere in it, say how confident you are in the recommendation overall and name the single point you're least sure of. Start directly with the memo itself, recommendation in the first sentence, no preamble and no restating my question back to me.
