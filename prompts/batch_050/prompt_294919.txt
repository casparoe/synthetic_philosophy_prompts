For a workshop of typeface designers and philosophers, write a decision tree that sorts each participant's answer to the question of what makes every lowercase 'a' an 'a' into a named position, starting from the shared premise that a Garamond 'a', a child's crayon scrawl, and a neon sign can all be instances of the same letter. Each branch node should be a question someone can answer without knowing the labels — for instance, whether an 'a' that no literate person could recognize still counts, whether 'a'-ness is fixed by contrast with the other letters of a writing system, or whether it is inherited through historical descent from earlier letterforms — and each leaf should be one of: geometric essentialism (some invariant structure every 'a' must have), system-role functionalism (being whatever plays the 'a' role in an alphabet), graded resemblance to a prototype, recognizability by literate readers, and historical lineage. Then run four hard cases through the finished tree: the single-story versus double-story 'a', the Greek alpha, an alphabet in which every letter must be built on the same tiny fixed grid, and a glyph engineered to sit exactly midway between 'a' and 'o'. For each case, say which leaf it most embarrasses. Flag any pair of positions your questions cannot actually separate, and identify any coherent combination of answers that no leaf occupies, diagnosing whether that slot is empty because the view is incoherent, unattractive, or merely unexplored. Aim for at most six branch questions.
