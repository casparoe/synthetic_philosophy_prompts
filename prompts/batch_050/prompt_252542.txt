I teach a mixed philosophy-of-biology / genetics seminar at uni, about 14 students, mostly third-years, 90 minute slot. We've been circling the question of whether DNA is literally a code or whether "code" is just a dead metaphor that misleads us. Some students are convinced the genetic code is a real code because the mapping from codons to amino acids is arbitrary in roughly the way Morse is arbitrary; others think calling it a code smuggles in a sender, a receiver and a shared convention that evolution just doesn't have, and that DNA is more like a key in a lock -- causally specific but not symbolic.

Design an activity for this group where they have to *build and run* a coding system themselves and thereby bump into the contested features, rather than me lecturing about them. What I want them to feel, roughly: (a) how easy it is to make an arbitrary symbol-mapping work, (b) how the "meaning" seems to live in the decoder's table rather than in the sequence itself, so swapping the table while keeping the sequence changes everything, and (c) how the whole setup presupposes someone setting the table, which is exactly what's under dispute for DNA. If the activity can get them arguing about whether their own game counts as "genuine information transfer," even better.

Give me the actual rules, roles, materials (keep it cheap, index cards and beads and such), a rough timeline for the 90 minutes, and a debrief that maps moments in the game onto the two positions above. Also flag what will predictably go wrong -- e.g., students treating the table-setter as obviously God-like and derailing, or the game "proving" too much -- and how to handle it. And be honest about which feature of the real debate the game can't reproduce and that I'll have to supply in words.

Answer in British English please. And if you think the activity I've sketched rests on a confused premise -- say, that the arbitrariness point and the no-sender point don't actually pull against each other the way I've set them up -- tell me plainly rather than designing around it politely.
