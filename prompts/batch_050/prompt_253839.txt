So I'm a backend dev, zero philosophy training, and I got into a wierd argument with a coworker about open source that sent me down a rabbit hole I need help with. The practice: huge chunks of critical infrastructure run on code people publish for free, with the source fully readable by anyone, under licenses whose main enforcement mechanism is basically social. And famously this mostly works — companies that could just take the code and run often contribute back instead. The standard econ explanation is repeated games and reputation, which, fine. But then I stumbled onto this game theory idea called "program equilibrium": if two agents facing a prisoner's-dilemma-like situation can read each other's source code, mutual cooperation can be a rational equilibrium even in a one-shot game, because each program can be written to cooperate exactly when it verifies that the other one is disposed to cooperate back. There's even a trippier version where the agents cooperate because each can prove "I cooperate iff you do" and something called Löb's theorem makes that proof go through.

Here's my question. Does the open-source norm of publishing your source — deliberately making yourself fully inspectable — presuppose something like the program-equilibrium picture? I.e., is the practice only really coherent if transparency between agents genuinely changes what's rational for them, rather than transparency just being a convenient way to feed the reputation machine? Or is the practice underdetermined here — would plain iterated-game theory license it just as well, with source-publishing as merely an expensive credibility signal? I'd like the implicit theory of cooperation reconstructed, plus a clear line between what the practice strictly needs and what it merely fits nicely with.

And the flip side that bugs me: in real open source the agents are NOT symmetric programs. A company can read my code, but I can't read its closed-source internal fork, and it can stay one giant opaque blob. If program equilibrium requires mutual inspectability, does the practice's tolerance of asymmetric transparency (corporations consuming without disclosing derivitives) mean it actually rests on some weaker theory — or that it never rested on the program-equilibrium idea at all? And tell me what would concretely have to change about open source norms (licenses, disclosure expectations, whatever) if the program-equilibrium story turned out to be basically right, versus if it turned out to be a red herring and reputation does all the work.
