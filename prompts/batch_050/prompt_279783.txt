Longtime LW/ACX lurker here, tying myself in knots over algorithmic randomness and looking for someone to untangle me.

As I understand it, a string counts as random iff it's incompressible — its shortest description is basically as long as the string itself. But every finite sequence is computable: whatever bits you hand me, I can write a program that outputs them (worst case it just prints the bits one by one). So every finite string has a program that produces it, which seems to mean no finite string is ever incompressible, which seems to mean finite strings can't be random, full stop. Is randomness then only a coherent property of infinite sequences, and calling 10,000 actual coin flips "random" a category error? And if finite strings can be random after all, in what sense, given that a string's complexity depends on which universal machine you pick anyway?

Two related snags. Kolmogorov complexity is famously uncomputable, so even if the above is muddled somewhere, we could never in principal know whether a specific string is random — doesn't that make the whole notion practically useless? And people always say a thousand heads in a row is "just as likely as any other sequence" — but then in what sense is the all-heads string less random than a typical-looking one?

Feel free to attack the confusions rather than the questions as posed. End with a line starting "Bottom line:" that answers, in one sentence, whether a finite sequence can be random.
