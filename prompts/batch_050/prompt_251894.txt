Six weeks ago a screening test put me in a high-risk category, and since then every specialist has quoted me a different probability for the same condition, depending on which population they slotted me into: everyone my age, everyone with my biomarker levels, everyone with my family history. So the reference class problem has stopped being an abstraction for me, and I'd like to think about it properly before I make any decisions.

Write the desiderata that any adequate solution to the reference class problem must meet -- what a theory has to deliver to count as a principled way of assigning (or justifiably refusing to assign) a probability to a single case, given that every individual belongs to indefinitely many classes. For each requirement, give the case or consideration that motivates it. Among the ones I'd want addressed: that it must not collapse into "use whatever class you like," that it must explain why some ways of partitioning a population are statistically relevant and others are gerrymandered, that it must cope with the fact that narrowing the class eventually shrinks the data to noise, and that it must be usable by an agent with limited information rather than an idealized one. Mark which requirements are non-negotiable and which are merely preferences of one school (frequentist, Bayesian, propensity theorist), and if some subset of them is jointly unsatisfiable, say so -- that's the part I most want to see. A brief note on how the main existing proposals fare is welcome, but keep the weight on the criteria.
