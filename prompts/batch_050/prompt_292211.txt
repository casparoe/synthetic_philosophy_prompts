I’m drafting a lecture on metaethics and found this summary of the Frege–Geach problem in a student’s philosophy-of-language guidebook:

Expressivists say that an utterance like “stealing is wrong” does not describe a moral fact or express a belief; it gives voice to disapproval, aversion, or some plan-like attitude. Because moral sentences are therefore not really true or false, trouble arises when they appear unasserted in conditionals such as “if stealing is wrong, then stealing from friends is wrong.” Once an expressivist has supplied a compositional semantics for these embedded contexts, however, Frege–Geach is fully answered. The remaining modus ponens point is simple: the inference is valid only if “stealing is wrong” keeps the same descriptive content in both premises, so expressivists must either reject an obviously valid inference or accept a minimal form of moral realism.
