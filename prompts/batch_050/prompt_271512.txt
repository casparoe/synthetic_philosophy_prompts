For a cognitive science survey course, I'm building a flowchart that sorts students' commitments about the architecture of the mind into named positions on modularity, running from Fodor's 1983 picture through massive modularity to the anti-modular opposition. Please build the tree from the logical space rather than from a list of names: start from the question of whether perception is informationally encapsulated from belief, then branch on whatever genuinely separates the positions (whether central cognition is modular too; whether modules are innate and domain-specific versus assembled by development; whether encapsulation and domain-specificity are all-or-nothing or matters of degree; whether "module" names a stable neural structure or a functional description). Each branch node should be phrased as a claim a student could accept or reject without knowing which camp it lands them in. Leaves should include Fodorian modularity (peripheral modules, non-modular central cognition), massive modularity of the evolutionary-psychology sort, a domain-general/empiricist position, and a neural-reuse or interactive-constructivist position, plus any other leaf the space forces. Note any combination of answers nobody defends, with one sentence on whether the cell is empty because it is incoherent, unattractive, or merely unoccupied, and flag any pair of positions your tree cannot separate.

Return the result as a JSON object with these fields: "nodes", a list of objects each with "id", "question" (the branching claim), and "branches" (mapping "yes" and "no" to the id of the next node or leaf); "leaves", a list of objects with "name", "core_commitment", and "most_awkward_implication" (one sentence each); "empty_cells", a list of objects with "answer_combination" and "diagnosis"; and "inseparable_pairs", a list of objects with "positions" and "reason".
