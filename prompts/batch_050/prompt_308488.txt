So I'm a backend engineer, no philosophy background, and I keep running into this line at work: "don't ever take a fence down until you know why it was put up." First time was a code review where I tried to delete a weird config check that seemed to do literally nothing, and a senior eng blocked the PR with that quote (apparently it's Chesterton?). Then last sprint someone used it to argue we couldn't kill a weekly meeting nobody could explain the purpose of, and someone else used it against deprecating an internal tool. At this point it feels like a magic incantation for vetoing any change whatsoever. But I also suspect there's a real insight buried in it, because I have, in fact, deleted "obviously dead" code before and taken prod down, so I'm not exactly in a position to be smug.

Can you lay out the different precise claims this slogan could actually be making? I want a menu, from most trivial to strongest. Like, on one end it might just be "gather information before you act," which, sure, trivially true, nobody disagrees, and also it can't really block anything since I did gather information -- I read the code and the git history. On the other end there's maybe a much stronger claim that if you can't see a reason for something, that very fact is evidence there's a hidden reason -- some idea about evolved systems storing knowledge that the people inside the system can't articulate? And presumably there are readings in between, about where the burden of proof sits, or about asymmetries between how hard it is to build something vs destroy it.

For each reading, tell me whether it's plausible on its own merits and -- this is the part I actually need -- whether it would support the uses I've seen at work. My suspicion is that the reading that makes the slogan true is too weak to block my PR, while the reading strong enough to veto changes is basically just status quo bias in a trench coat. But maybe I'm wrong. Also: does it matter that code is cheap to change and fully rollback-able, whereas, I dunno, a legal institution or a social norm isn't? Does the strongest version of the fence argument only work for things that grew organically over a long time, as opposed to things some PM made up in 2019? Because if so, my coworker might be reaching for exactly the wrong tool.
