I'm a first-year PhD student in computer science preparing a prospectus for a two-year dissertation project, and I'd like you to write the core of it for me: about 1,500 words, no bibliography (I'll add citations myself; refer to positions and results by description, not by reference).

The topic is program equilibrium — the result that agents who can read each other's source code can sustain cooperation in one-shot games where ordinary game theory predicts defection. My half-formed idea is that the standard setup rests on an idealization that does almost all the work and that nobody has properly relaxed: perfect mutual transparency. The agents in the classic construction see each other's full source code and can verify, in effect, that the counterpart conditions on exact syntactic or behavioral equality. But any realistic setting — including the one people now care about, where AI agents built by different developers interact, or where code is too large to verify and only partially legible — gives you something weaker: each agent has a noisy, lossy, possibly adversarially manipulated *model* of the other's program. Call it approximate transparency. My conjecture is that cooperative program equilibrium is discontinuous in the degree of transparency: below some threshold of mutual legibility it collapses entirely, and the interesting question is whether that threshold is sharp, what it depends on (the game, the verification technology, the number of agents, whether the noise is symmetric), and whether there are intermediate regimes — for example, equilibria where agents cooperate conditional on passing each other's *tests* rather than matching each other's code — that recover some but not all of the cooperative surplus.
