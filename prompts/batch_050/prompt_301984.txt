1. A mask case: the object has the disposition (solubility, fragility, toxicity, conductivity, whatever), the stimulus genuinely occurs, and the manifestation doesn't happen — but the disposition is still there afterward, because something interfered with the process of manifestation rather than removing the disposition itself.
2. A fink case that is observationally identical to case 1 from the outside — same stimulus, same non-manifestation, same before-and-after readings on whatever instruments the workplace has — except that this time the stimulus itself causes the object to lose the disposition before it can manifest. 3. A mimic case: the object lacks the disposition but produces the manifestation anyway when the stimulus occurs, via some other mechanism, so that a test would wrongly certify it as having the disposition.

Finally, in a few sentences: how would a diehard defender of the conditional analysis try to redescribe case 2 — e.g. denying the stimulus really occurred, or folding the fink into an "ideal conditions" clause — and do you buy the move?
