Okay so I need help drafting something for a board meeting next week, and I'd like you to put on your "professional philosopher who moonlights as a policy wonk" hat for this. Think carefully about the decision theory before writing, and feel free to brainstorm the main considerations first before settling on a recommendation.

Background: I've been reading LW and the Sequences and that whole ecosystem for like a decade, and I sit on the board of our local rationalist-ish community org. For our annual fundraiser, someone proposed running a luring lottery — the setup from Hofstadter's old magazine column that gets discussed on the blogs every so often. Our version: tickets cost $2, unlimited tickets per person, the winner is drawn with probability proportional to their share of all tickets sold, and the winner takes half the pot while the org keeps the other half. So the expected value of a ticket is negative for everyone, and the more tickets people buy, the more the prize gets diluted for all of them — a classic cooperation/tragedy setup. Half the board loves it as a live demo of the superrationality idea: if everyone reasons the same way, maybe everyone buys exactly one ticket, nobody overbids, and we've all tacitly "cooperated." One board member is adamant this is backwards — that anyone who actually thinks it through should buy a huge stack of tickets, and that the event basically monetizes our community's cooperation instincts, which she finds gross and maybe exploitative. A third faction wants to run it but with a public discussion thread beforehand where people can coordinate openly, which seems like it changes the game entirely (does it make cooperation trivial? does it ruin the experiment? make it more interesting?).

Anyway I voluntereed to write the decision memo. Please draft it: a clear bottom-line recommendation — run it as proposed, run it with modifications (per-person ticket cap? the coordination thread? some other tweak?), or scrap it — plus the reasoning, written for board members who are smart but not decision theorists. It has to engage honestly with the strongest argument on whichever side loses, and it should read like a document we could actually vote on, not an essay. Somewhere in there, it should also take a position on whether "we're all similar reasoners, so we'll all end up buying one ticket" reasoning should carry any weight for an individual member deciding how many tickets to buy, because that's the crux where everyone at the last meeting just talked past each other.
