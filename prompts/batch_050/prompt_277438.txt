My opening move: Kolmogorov complexity is only defined relative to a choice of universal Turing machine, and the invariance theorem guarantees agreement only up to an additive constant. That constant is swamped for long strings, but finite agents like us only ever see finite evidence, and for any finite string I can cook up a universal machine on which that string is maximally simple. So your "objective" prior looks like it just relocates the arbitrariness: instead of choosing which hypotheses to favor, we're choosing a machine. Why isn't the whole edifice resting on that choice?
