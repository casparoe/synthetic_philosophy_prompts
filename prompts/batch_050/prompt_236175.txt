The students have done basic conditional probability and survived Sleeping Beauty, but most of them will arrive having half-watched a youtube video about the DA, which is honestly worse than knowing nothing, since they come in sure it's either profound or a parlour trick.

So plan the 50-minute session for me. I don't want the explanation itself, I want the architecture. What has to be in place before what: my instinct is that the sampling intuition has to be rock solid before birth rank ever gets mentioned, and that the reference-class problem can't be raised until they've genuinely felt the argument bite (otherwise they use it as an escape hatch), but push back if you think I've got the dependencies backwards. Give me the one toy case to build the whole session around. I'm leaning toward "you're holding card #7 from a print run that was either 10 cards or 10,000" because it has the total-population structure without any apocalyse for them to get distracted by, but if there's a better carrier, argue for it. What exactly would I ask them, and what would an answer look like if it landed?
