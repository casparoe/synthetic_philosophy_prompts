Is there a name for this? I keep noticing systems where the one level that's supposed to be untouchable turns out to be held in place by the very levels it governs. A constitution with an 'eternity clause' declares certain articles unammendable, but the clause only bites because judges keep treating it as binding, and the judges only have their jobs because of the constitution. A computer's boot firmware is the one thing ordinary code can't rewrite, yet the firmware runs the show only because the hardware happens to start executing there. And in Escher's Drawing Hands each hand is drawing the other, so whichever you call the top is only top because the bottom keeps sketching it. I know this is somewhere near Hofstadter's tangled hierarchies and the inviolate level, but his inviolate level is inviolate full stop, whereas mine is inviolate only by courtesy of what it rules. Is there an established concept for exactly this, and if not, can you coin and define one — marking it off from plain strange loops, circular authority, and infinite regress, so I can tell what's in and what's out? Bonus question: does any real system have a genuinely inviolate level, or is every apparent one precarious in this way? Please answer in British English.
