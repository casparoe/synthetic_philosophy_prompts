Is there a name for this problem? I keep running into it in arguments about AI and minds. Say some chatbot holds a long conversation and genuinely passes for human — jokes, doubts, the works. My first instinct is that this is evidence something is going on inside it. But then someone points out: the thing was trained on basicly the whole internet to produce exactly the kinds of responses that would make a person think it's human. So of course it passes, that's what it was built to do. The convincingness was manufactured, so it can't count as evidence for anything anymore. Which feels right, but also weird, because presumably if it *failed* the test everyone would count that as evidence against it having a mind. Can a test only count when you fail it?

This seems close to Goodhart's law but I don't think it's quite that. Goodhart is more like you optimize a proxy and the proxy drifts away from the real goal. Here its more like the test result stops being usable as evidence the moment you know the system was selected to produce that exact result. And it's also not just "it's faking it," Clever Hans style, because with Clever Hans there was a hidden cue the horse was picking up on. Here there might not be any cue — the machine might be doing whatever its doing for real internal reasons, we just can't learn anything from the fact that the output looks convincing.

So is there an established term for this — evidence that loses its evidential force because whatever generated it was optimized to generate exactly that evidence? And if there isn't one, what would you call it, and where are the edges? Like, does the same problem apply to a human actor who convincingly plays a grieving widower, and if not, whats the difference?
