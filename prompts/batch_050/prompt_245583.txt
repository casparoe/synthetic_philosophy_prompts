Question:
Explain the difference between a fink and a mask for a disposition. Consider two fragile vases. The first is connected to a device that would make it rigid the instant it was struck. The second is packed in a material that would absorb any blow. For each vase, say (a) whether it is fragile before being struck, (b) whether it would break if struck, and (c) what the case implies for the simple conditional analysis that something is fragile iff it would break if struck. Finally, say whether either case shows that fragility is an extrinsic property.

Student answer:
Finks and masks both explain why something can have a disposition without manifesting it, but they work at different points. A fink removes the disposition when the stimulus occurs, while a mask leaves the disposition in place and blocks the manifestation. The first vase is fragile before it is struck, but if it were struck the device would make it rigid before it could break. So at the moment of striking it is no longer fragile, and it does not break. The conditional analysis therefore fails, since the vase is fragile beforehand even though it would not break if struck. The second vase is also fragile before being struck and does not break, because the packing absorbs the blow. Its disposition remains, but its manifestation is prevented. Since both cases depend on features external to the vase, both show that fragility is extrinsic. Nor can conditional analysis be saved by distinguishing masks from finks, because both cases treat failure to break as compatible with fragility.
