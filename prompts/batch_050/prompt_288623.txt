I'm assembling a handout for a graduate seminar on the semantic paradoxes, and I'd like you to construct a decision tree that sorts the major theories of truth by what they actually say, not by what their proponents call them. The seminar's framing question is whether logic itself is negotiable in the face of paradox, so I care most about splits that turn on how much classical machinery a theory keeps.

Build the tree from concrete test cases rather than from doctrinal questions. Each branch point should present a sentence or scenario and ask what truth value (or status) it receives, phrased so that someone can answer without knowing any position labels. Use at most seven branch points, drawn from cases like these (adapt as needed, but cover their work): the plain Liar; the strengthened Liar ("this sentence is not true"), which punishes any theory that wants to call the Liar defective, gappy, or neither; the Truth-teller ("this sentence is true"), where consistency is achievable but grounding is not; a Yablo-style infinite chain in which each sentence says all the later ones are untrue, which tests whether a theory blames self-reference per se or ungroundedness more generally; and a Curry sentence ("if this sentence is true, then 2 + 2 = 5"), which separates theories that restrict the truth schema from theories that restrict structural rules like contraction, and which the Liar alone cannot distinguish.

Each leaf should carry the position's name -- Tarskian hierarchy, Kripkean fixed-point gap theory, revision theory, dialetheism, contextualist or indexical approaches, non-classical paracomplete logic, substructural approaches, and whatever else earns a place -- plus one sentence on its most awkward commitment. Where a combination of answers is coherent but unoccupied, mark the cell and diagnose briefly whether it is empty because it is incoherent, merely unattractive, or simply unexplored. Where two positions agree on every verdict across your cases (for instance, theories that differ only in their internal logical implementation while delivering identical verdicts), flag them as inseparable by this instrument rather than forcing an artificial split.

Two requests about how to handle trouble. If any of my test cases smuggles in a contested presupposition -- say, that the Yablo chain is genuinely paradoxical without self-reference, or that Curry and the Liar ought to be treated by a single mechanism -- say so plainly instead of quietly building the tree around it. And if the binary branching format distorts some position that wants to answer "both" or "it depends" at a branch point, note that rather than pruning the position to fit the shape.
