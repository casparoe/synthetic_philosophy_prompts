So I've gotten into doing little forecasting exercises with some friends, mostly geopolitical stuff, and I keep hitting the same wall and I want to know if the wall has a name.

Say we're trying to estimate how much longer some political order will last -- pick your example, a dynasty, an empire, a reserve currency regime, whatever. The standard advice (I think this is the "outside view" thing?) is: don't reason from the details, find a reference class and use the base rate. Fine. But then the trouble starts. Take "how long do empires last." If the class is all empires ever recorded, you get one number, something in the few-hundred-years range. If the class is land empires after 1500, different number. If it's "hegemons in an international system," different again, and now the sample size is like four. Each narrowing feels justified, and each one moves the answer by a factor of three. There doesn't seem to be a principled place to stop narrowing, and I suspect (only suspect) that people stop narrowing at whichever class gives the answer they already liked.

But here's the part I actually can't find discussed anywhere, and it's the part I really want a name for. Even holding the class fixed, the base rate itself turns out to be mushy, because the thing being counted -- an empire "ending" -- isn't an observable event, it's a coding decision. Rome falls in 476 or in 1453 or arguably never cleanly falls at all. The Ottoman empire "ends" in 1922 but a lot of its state structure just walks into the Republic of Turkey. Whether the Carolingian thing counts as one empire that lasted 88 years or as a continuation of something older changes the average. So the base rate isn't a fact you look up, it's an output of historiographical judgment calls, and two careful people using the same class can get different numbers. And once you see that, the whole exercise feels less like "using the base rate" and more like dressing up your prior in base-rate clothing.

Is there an established term for this specific failure mode? I know about the reference class problem in general, but that seems to be about which class to pick, not about the outcome variable being judgment-laden so that even within a fixed class the data is contested. It's also not quite the same as garbage-in-garbage-out, because the inputs aren't bad data, they're reasonable-but-undefended interpretive choices. If this has a name, what is it, and how does it relate to the plain reference class problem and to measurement error more generally? And if it doesn't have a name, can you give it one, define it carefully, and say where it applies and where it doesn't -- e.g., is predicting when a company will go bankrupt subject to the same problem or is that genuinely cleaner, and why? I mostly care about the carving, not the label, so please don't just hand me a term and stop.
