I serve on the grants committee of a regional research foundation, and I keep noticing the same argumentative move, for which I have never found a name. Two recent instances. In one, a reviewer defended a risky proposal by citing a very narrow comparison class — projects from that institute, at that budget level, led by investigators of that seniority — within which the success rate was excellent; an opponent cited the broad class of large interdisciplinary projects in the field, within which completion rates are dismal. In another, concerning a proposed longitudinal study, the skeptic of the first meeting suddenly favored fine-grained comparisons, because the fine-grained numbers now supported his side. What strikes me is the order of operations. The desired verdict seems to come first, and the comparison class is fitted to it afterward, with talk of relevance deployed as decoration. Nobody at the table can state a rule for choosing classes that they held before knowing which answer each class would yield.

I realize the general difficulty of choosing a comparison class is the well-known reference class problem, and I am not asking about that. Nor is this quite cherry-picking, since the cited statistics are usually accurate; what gets selected is the frame, not the data. And it seems narrower than motivated reasoning in general, because it exploits a specific structural feature of statistical argument: that any event belongs to indefinitely many classes.

Does this exact move — retrofitting the reference class to a pre-selected conclusion — have an established name? Please take a definite position. If some existing concept covers precisely this, say which one and defend its fit against the nearest rivals. If none does, coin a term, define it, mark its boundary cases, and propose a practical test for distinguishing a retrofitted class from a legitimately refined one — since narrowing the class is sometimes exactly what good statistical reasoning requires.
