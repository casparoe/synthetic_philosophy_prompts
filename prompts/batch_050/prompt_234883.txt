Settling an argument I witnessed so I can get them to stop texting me about it. Two friends of mine, both math PhD students, got into it over beers about whether the question "is 2 an element of 4?" has an answer.

Priya's opening move: obviously yes. Set theory standardly builds the natural numbers by taking 0 to be the empty set and each number to be the set of all the smaller ones, and on that build 2 = {0,1} is literally a member of 4 = {0,1,2,3}. That's the construction in the textbooks, that's the one everyone uses, end of story.

Marcus: it can't be end of story, because there's an equally good build where 0 is the empty set and each number is just the singleton of the previous one, and on that build 2 is not a member of anything like 4. The two builds agree on every fact of arithmetic and disagree on whether 2 ∈ 4. So that isn't a fact about the numbers, it's a fact about which coding you picked, and since nothing about the numbers themselves picks a coding, the question just has no answer.

Priya: of course the numbers pick one, WE picked one, the standard one. Questions get answered relative to how the terms are set up. That's like saying "can the bishop move diagonally?" has no answer because someone could invent a chess variant where it can't. Once the game is fixed the question is fine, and the game is fixed.

Marcus: but then arithmetic ends up hostage to an arbitrary stipulation. On the standard build "2 ∈ 3" also comes out true, and nobody wants to say it's a genuine arithmetical fact that 2 is a member of 3. The right lesson is that numbers aren't sets at all, they're positions in a structure, and the only real facts about them are structural ones like 2+2=4, which hold on every adequate build.

Priya: "positions in a structure" does no work until you tell me what a position is. If positions are objects, you're back in the same mess, since someone will ask whether the 2-position is a member of the 4-position. If they're not objects, numerals refer to nothing and "2+2=4" isn't true the way ordinary truths are true.

Marcus: it is true the ordinary way -- it's true in every system with the right structure, and that's all mathematical truth ever amounted to.

Priya: so if no objects had ever instantated the right structure, arithmetic would've been false? Arithmetic isn't contingent on what happens to exist.
