I'm TAing a game theory course and want a handout that sorts students by how they react to the centipede game result — i.e. the backward induction argument that says you should grab the money at the very first node, which almost nobody actually does. Please write it as a decision tree: each branch node is a question the student answers about a concrete case or claim, each leaf is a named position.

Constraints:

- Shared starting point for everyone entering the tree: the student accepts that "take at node 1" is what the standard textbook argument delivers. The tree is about what they make of that fact, not whether they've understood it.
- Leaves that must appear: (1) the orthodox defender — the equilibrium is right and our intuitions are just misleading; (2) the common-knowledge skeptic — the argument eats itself once anyone passes, since a pass refutes the premise the induction runs on; (3) the bounded-reasoning / level-k response — people only look so many moves ahead and that's fine; (4) the "payoffs aren't utilities" response — players care about the other person's take, so the game as drawn isn't the game being played; (5) a cooperative / team-reasoning response. If you think a genuinely distinct sixth position exists, add it. If you think two of these secretly collapse into each other, merge them and justify the merge.
- Diagnostic questions must be about concrete cases, never about labels. So not "do you accept common knowledge of rationality?" but a situation plus "what follows?". Please use at least three of these cases somewhere in the tree:
  - Variant A: your opponent has already passed twice. Does backward induction still tell you what to do, or does it go silent, and does that silence bother you?
  - Variant B: the taker's winnings go to an anonymous stranger and the passer gets nothing either way. (This is supposed to neutralize the altruism escape hatch — part of the exercise is checking whether it actually does.)
  - Variant C: the number of nodes is drawn randomly somewhere between 5 and 500 and neither player is told the draw. Can backward induction even get started here?
  - Variant D: your opponent is a famous logician who has publicly precommitted to always passing twice and only then maximizing.
  - Variant E: same game but the total pot shrinks 10% per pass while the take-now share grows as usual.
- 6 to 8 branch questions total, and no path through the tree should be longer than 4 questions.
- After the tree, list any combinations of answers that no position occupies, and for each say whether you think it's empty because it's incoherent, unattractive, or just unexplored.
- Flag any pair of leaves the tree can't actually separate, and say what extra question would split them if one exists.

Audience is second-year undergrads who've had exactly one lecture on subgame perfection, so every question has to be answerable from the case description alone with no jargon presupposed. And don't let any question be something like "do you think people are rational?" — nothing where students can just pick their camp directly. The sorting should fall out of wich cases they bite which bullets on.
