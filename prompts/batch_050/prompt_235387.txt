Exam question: Reconstruct Lucas's argument that the human mind cannot be adequately modeled by any machine. For each step of the argument, state which of Gödel's incompleteness theorems it relies on, and then assess the objection that the argument succeeds only against consistent machines and is therefore merely conditional.

Student's answer:

Suppose the mind were a machine, i.e., a formal system F powerful enough to do arithmetic. By Gödel's second incompleteness theorem, F cannot prove its own Gödel sentence G(F), the sentence which says of itself that it is unprovable in F. We, however, can see that G(F) is true: if it were false, it would be provable in F, and hence true (since F proves only truths), which is a contradiction. So there is a truth that we can recognize and that the machine cannot prove. Hence the mind outstrips any machine, and mechanism is false. This strong anti-mechanist conclusion was drawn by Gödel himself as a consequence of his theorems.

As for the objection that the argument is conditional on F's consistency: an inconsistent formal system proves every sentence, and so would prove falsehoods indiscriminately; but we plainly do not believe everything whatsoever. Any machine proposed as a serious model of a mind must therefore be consistent, so the mechanist cannot evade the argument by dropping the consistency assumption. Lucas concludes that minds are not machines, and the objection fails.
