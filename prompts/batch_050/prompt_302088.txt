I'm a software engineer with no formal philosophy background. A coworker and I have been arguing about whether the mind is a computer, and he produced an argument whose conclusion I find unbelievable but whose steps I can't break. Here it is, as faithfully as I can reconstruct it:

(1) A system counts as computing a function only if it runs some algorithm that actually solves that problem.
(2) Perception and everyday decision-making involve problems like probabilistic inference over causal models, constraint satisfaction, and sequential planning.
(3) These problems, stated exactly, are NP-hard or worse, and NP-hard problems cannot be solved efficiently in general by any physical device, assuming P ≠ NP.
(4) Human brains perform perception and decision-making quickly and reliably, essentially all the time.
(5) Therefore the brain is not solving these problems algorithmically, so the brain is not a computer in the Turing-machine sense and computationalism about the mind is false.

The conclusion seems to prove too much: if the argument is sound, it appears to show that my laptop never performs inference or planning either, since the software it runs faces the same NP-hard problems, and that no physical system anywhere computes anything in this class — which can't be right, because then what are we doing all day?

Tell me where the argument goes wrong. Identify the premise or inference step that should be rejected, explain why it looked fine, and price the alternatives. In particular, I'd like to know what each of the following escape routes costs: distinguishing worst-case complexity from the average case over the inputs brains actually face; appealing to approximation algorithms and heuristics; restricting the problem instances; and denying that (2) describes what brains do at all. Finally, say whether any resolution survives without already assuming something about what cognition is — i.e., whether my coworker can accuse every reply of begging the question, and if so, whether that accusation sticks.
