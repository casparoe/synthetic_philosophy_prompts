I'm taking an undergraduate seminar on global priorities and effective altruism, and we've spent the last two weeks applying the importance-tractability-neglectedness framework to various cause areas. I keep running into a problem that none of my readings seem to address directly, and I'm wondering whether it has an established name. The issue is that the three scores don't seem to be properties of problems in the world so much as properties of how I've decided to carve the world up into "causes." For instance, if I evaluate "improving education in low-income countries" as a single cause, it looks enormously important, fairly tractable in principle, but not at all neglected given the volume of NGO and government spending. But if I instead evaluate "structured pedagogy programs in a specific region of Tanzania," the same underlying work suddenly looks highly neglected and much more tractable, and it rockets up the ranking. Conversely, I noticed that when my classmates evaluated "global health" as one giant umbrella and "AI safety" as a single narrower cause, the umbrella absorbed the importance of its best sub-areas while diluting their neglectedness across the whole bucket, which systematically disadvantaged it in the comparison.

So the very same donation can be ranked as going to a top-priority cause or a middling one depending purely on the level of abstraction at which someone drew the boundaries of the cause bucket, and there doesn't seem to be a principled rule inside the framework for where to draw them. If you carve finely enough, almost every cause contains some neglected, tractable corner; if you carve coarsely, almost every cause looks crowded and intractable. My professor acknowledged the issue but just said practitioners use judgment, which I found unsatisfying, because the ranking output then partly reflects the analyst's carving choices rather than the world.

Does this phenomenon have an established name in the cause prioritization or decision theory literature? I suspect it might be related to the reference class problem in probability, and maybe also to concerns about fungibility of funding, but neither of those seems to be exactly it: the reference class problem is about estimating frequencies for an event, and fungibility is about money displacing other money, whereas what I'm describing is about the scores being unstable under redescription of the option itself. If there is no established name, could you propose one, define it precisely, and give some boundary cases — that is, cases that look similar but are really instances of ordinary measurement error or genuine empirical disagreement rather than this carving instability? I'd also be curious how you think a careful practitioner should set the granularity at which causes are individuated, if there's any defensible rule at all.
