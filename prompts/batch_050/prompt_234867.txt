So I've been reading rationalist blogs forever, and like everyone in that orbit I've absorbed the standard move where "echo chamber" just means "community I disagree with." I recently had a stupidly long argument in a group chat about whether our own little corner of the internet counts as one, and I realized we kept talking past each other because we had no shared vocabulary for *diagnosing* a community, only for insulting it. So: I want a decision tree that takes a concrete community you're a member of (a subreddit, a Discord, a LessWrong-adjacent forum, a group chat, whatever) and sorts it into a diagnosis based on observable behavior, not vibes.

The leaves I definitely want included: the passive algorithmic filter bubble (you never even see the other side, and it's not your fault or the community's), the classic epistemic bubble (other views are absent but not actively discredited), the true echo chamber (outsiders are preemptively cast as untrustworthy, so counterevidence gets neutralized on arrival rather than ignored), and a healthy high-trust community of inquiry as the "you're fine, stop panicking" leaf. But don't just stop at those four -- build the tree from the diagnostic questions first and see which combinations of answers actually get occupied. Some example diagnostics I can think of: when a member posts a link hostile to the community's consensus, do people engage with the argument or with the poster's motives? Is there any status to be gained by importing steelmanned outside criticism, or only by dunking on it? Has anyone visibly changed their mind on a core belief in the last year, and were they able to say so without losing standing? Feel free to use better questions than mine, but each node has to be phrased as something a member could answer from experience without already knowing which leaf it routes to.

A few constraints: 8-12 branch nodes total, each a single yes/no or pick-one question about the community's behavior (not about what the community *believes* -- a community of flat-earthers and a community of economists should be able to land on the same leaf). Flag any pair of leaves the tree can't really separate, and for any answer-combination that has no real-world occupant, add a one-sentence diagnosis of whether that slot is empty because it's incoherent or just rare. Also: include one branch that handles the awkward case where a community is wrong about everything *and* epistemically healthy, because I suspect that's the cell my group chat was actually fighting about. Oh and end with a short note on where the tree fails for communities that have *two* factions doing different things -- my forum might be a bubble about politics and an echo chamber about AI, and I dont know how a tree should handle that.
