I hang out in a server where anthropic reasoning comes up a lot, and the line "just reason as if you're a random sample from all observers" gets deployed constantly. Last week someone used it to defend the doomsday argument (you're probably not in the first tiny fraction of humans, so humanity's run is probably middling-length), and then someone else used what sure sounded like the same sentence to argue we should be confident the universe is teeming with observers even before we go look — the presumptuous philosopher setup where the cosmologists could just save themselves the trouble of building the telescope. Those can't both be innocent applications of one principle, right?

Break the slogan into the distinct precise theses it could be expressing: self-sampling vs. self-indication, the choice of reference class, the claim that you should set aside evidence that only bears on how many observers exist, whatever else is hiding in there. For each, say whether it's a near-platitude (you exist, conditionalize on it), a substantive and maybe defensible bet, or something that leads somewhere crazy. Then tell me which reading the doomsday arguer actually needs for the argument to go through, which reading generates the presumptuous philosopher, and whether there's any single reading on which both uses come out legitimate — because everyone in these fights talks like there is.
