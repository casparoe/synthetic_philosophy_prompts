I am setting the final examination for a graduate seminar on scalable oversight and AI alignment, and I need one essay question on iterated distillation and amplification (IDA), answerable in about 75 minutes. The question must not be answerable by reciting the standard setup — that a human overseer is amplified by access to copies of a distilled assistant, that the amplified behavior is then distilled back into the next generation of the assistant, and that the loop repeats. I want to test whether students can reason about whether decomposition actually preserves alignment and competence, rather than merely describe the scheme.

To force that, please set the question in the following concrete scenario and require students to engage with two pressure points built into it. An engineering consultancy uses an IDA-style pipeline to vet safety-critical designs: a senior engineer decomposes each review into sub-questions (which hazards to consider, which calculations to redo, which failure modes to simulate), delegates the sub-questions to a distilled assistant, and aggregates the sub-answers into a verdict; the resulting reviews then serve as training data for the next assistant. The pressure points are these. First, decomposition completeness: every sub-answer can be individually faithful while the decomposition itself omits the one consideration that would have changed the verdict, because deciding which sub-questions are worth asking is itself a judgment delegated to the system. Second, distillation opacity: training the next assistant on the amplified outputs discards the decomposition trace, so later iterations can no longer be audited for which sub-judgments carried the load, and a systematic omission can be inherited and compressed rather than corrected.

Write the exam question, then a model answer of about 600 words, then a marking scheme out of 25 built around five must-hit points — for each, the marks it is worth and a one-line note on the typical way candidates fumble it (for instance, treating the aggregation step as the only place error can enter, or assuming that because each iteration is locally supervised the pipeline must converge toward alignment). The marking scheme should separate an A answer from a B answer by naming the specific moves each must contain, not by gesturing at depth or sophistication.

Begin directly with the exam question itself — no preface, no commentary, no restating of these instructions.
