An epistemology podacst summarized the debate over testimony like this: “Reductionists think testimony isn’t a basic source of justification: you can rationally believe what someone says only if you have independent evidence that they’re reliable. Anti-reductionists reject this because it would make children’s testimony-based learning irrational, so they say you should accept any sincere assertion unless you have evidence against it. Both views struggle, since reductionism cannot explain ordinary learning from testimony and anti-reductionism licenses gullibility.” Is this fair? Please distinguish what each side would accept, what is oversimplified or distorted, and whether the two alleged problems actually follow.
