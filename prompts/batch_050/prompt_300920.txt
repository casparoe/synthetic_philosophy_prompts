I've been stress-testing the categorical imperative by running maxims through the universalizability test myself, and my verdicts don't line up with any single version of the test I can state. Lying promise: fails, universal lying makes promises impossible, so the maxim eats itself. Steal when you can get away with it: same deal. Never help anyone: fails, but differently -- that world is perfectly conceivable, I just couldn't rationally will it since I might need help someday. But then: "lie, but only if your initials are B.R." -- obviously wrong, yet it survives the test fine, since a world where only B.R.s lie still has working promises. And "never use violence even in self-defense" passes cleanly, which feels too easy. My working theory is that a maxim fails iff universalizing it destroys the practice the maxim itself piggybacks on -- but that clearly can't handle the non-beneficence one, since helping isn't a practice. Repair the principle, or tell me which verdict I have to drop, and say what the fixed version says about a case I haven't tried: never paying taxes because everyone else will.
