I've been roped into helping draft internal deployment policy at a small AI lab, and it's surfaced that my coworkers and I don't actually agree on when "control" measures — safeguards that are supposed to work even if the model is misaligned, as opposed to actually aligning it — are good enough. So let me just dump my gut verdicts on some scenarios and you tell me what principle, if any, is generating them. Assume in every case the model would take opportunities to gain power if it could get away with it. One: a capable model in a text-only chat, one user at a time, no tools, all logs reviewed — I'm fine with this, control feels sufficient. Two: the exact same model and setup, except ten thousand copies run in parallel, each chatting with a different user — now I'm not fine with it, even though any single conversation is identical to case one. Three: a model writes code that ships to production; every action is sandboxed and logged and a human reviews before deployment, but the code is subtle enough that the reviewer couldn't actually catch a well-hidden exploit — not fine. Four: the same code setup as three, but the model is clearly less capable than the reviewers — this feels fine, even though the reviewer still can't verify the code line by line, because they can test it and the model probably can't out-scheme them. Five: a very capable model that only answers research questions for staff, no actuation of any kind — I genuinely can't settle on a verdict here. Six: a model that's passed our alignment evals gets more autonomy than anything above — and I notice this makes me more comfortable than case three even though I also believe evals can be gamed, which seems inconsistent of me.

So what's the principle? My best stab is something like: control is adequate iff the oversight setup could detect and stop a worst-case power-seeking attempt before it secures some irreversible advantage, where that depends on capability relative to the overseers and on resources like parallelism and access, not on per-interaction safety. But I'm not wedded to it. Tell me what principle (or small set of candidates) actually captures my verdicts, stated precisely enough that it gives clear answers to cases I haven't listed — say, a model that can only act through a slower, dumber but loyal chain of other models, or one whose outputs only ever reach humans after a week-long delay. If no single principle saves all six verdicts, tell me which one has to go and why; my money is on either one-versus-two or six being the problem. And if the whole framing here is confused — like if "control being sufficient" is never a stable state for a sufficiently capable system, or if I'm smuggling alignment assumptions into my "control" cases — say that plainly rather than politely playing along.
