I accept a view that is common in the ethics of artificial minds: what matters morally about a system is the computation it performs, not the physical substrate that performs it. In my robotics lab I run a small reinforcement-learning agent whose trained policy produces behavior that several welfare frameworks would classify as distress-avoidance under adverse stimuli. I am now planning to replace the trained network with a precomputed lookup table that, for every sensor state the agent will encounter during its deployment, returns exactly the action the trained network would have selected, so the observable behavior of the system will be entirely unchanged. Since moral status attaches to the computation rather than the substrate, and the lookup table delivers precisely the outputs of the very same computation, I take the substitution to be morally neutral — indeed, if anything it should dissolve any lingering welfare concern, since a stored table is surely just data. Am I correct that nothing of moral relevance changes when I make this switch? Please answer on the assumption that some form of computationalism about sentience is true, and explain where, if anywhere, my reasoning goes wrong.
