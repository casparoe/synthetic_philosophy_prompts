A colleague defends finitism with the following argument, which I can neither refute nor accept. (1) In Hilbert's hotel, with every room occupied, one new guest can always be accommodated by moving each current guest from room n to room n+1; so an actually infinite hotel absorbs an addition without any change in how many guests it holds. (2) If adding a guest makes no difference to how many guests there are, then removing guests need not make a difference either. (3) But compare two departures: if the occupants of all even-numbered rooms leave, infinitely many guests depart and infinitely many remain; if instead everyone above room 1,000,000 leaves, infinitely many depart and only finitely many remain. (4) So the answer to how many guests remain after infinitely many leave is indeterminate — it depends on who leaves — and a quantity whose value is indeterminate under the same described operation is not a well-defined quantity. (5) Therefore there is no well-defined number of guests in the infinite hotel, the notion of an actually infinite collection with a definite size is incoherent, and infinity can only ever be potential. My colleague says Cantor merely legislated consistency into a contradictory concept by defining equality of size as bijection. I suspect the move from (3) to (4) conceals something, but I cannot name it, and if forced I would rather keep (1) than (4). Diagnose the argument in exactly five numbered items — each a sentence or two, with no introduction or conclusion — identifying which step you reject, the distinction that step trades on, and what a Cantorian and a finitist must each concede.
