The exam question:
"In his 1965 paper 'What Numbers Could Not Be,' Benacerraf argues that numbers are not sets, using the fact that there are multiple incompatible set-theoretic reductions of the natural numbers. Reconstruct his argument, and then explain how the structuralist about mathematics responds to the puzzle the argument raises. Does the structuralist take 'is 2 an element of 4?' to be true, false, or something else?"

The student's answer:
"Benacerraf's argument goes like this. We can reduce the natural numbers to sets in more than one way. On Zermelo's version each number is the singleton of the previous one, so 2 = {{}}. On von Neumann's version each number is the set of all smaller numbers, so 2 = {0, 1}. These reductions disagree: on von Neumann's, 2 is an element of 4, but on Zermelo's it isn't. Since the two reductions disagree about the truths of arithmetic and there's no principled reason to pick one as the 'real' numbers, Benacerraf concludes that numbers are not sets -- and in fact that numbers don't exist at all, since any objects we identified them with would raise the same problem.

The structuralist response is to say that arithmetic isn't about particular objects at all, only about the pattern or structure the objects instantiate. What matters is that the sequence has a first element, a successor operation, induction, etc., not which objects fill the positions. So the structuralist says the question 'is 2 an element of 4?' is actually false, because 2 is a position in a structure and positions don't have members. That's how structuralism dissolves Benacerraf's puzzle: the apparent disagreement between the reductions disappears once we realize set-membership claims about numbers are simply false on the structuralist view."
