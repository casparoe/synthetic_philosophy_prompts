I'm TAing a final-year decision theory module and I've got a stack of resit essays to get through this week. Below is the question I set, and then one student's answer. Give the answer a mark out of 20, and then give me the specific comments I'd write on the script to justify that mark -- go through it part by part rather than giving me an overall impression, because I need to be able to defend the mark at the exam board and "seemed ok-ish" won't cut it.

The question:

A fair coin is tossed repeatedly until it lands heads. If heads first appears on toss n, you recieve (−1)^(n+1) · 2^n / n pounds, where a negative amount means you pay that much. So you win £2 if heads comes up straight away, you pay £2 if the first two tosses are tails then heads, you win £8/3 if the first heads is on the third toss, and so on.

(a) Write out the expectation calculation term by term, in the order the outcomes naturally arise, and state what the resulting series sums to.
(b) Standard probability theory refuses to assign this game an expected value. Explain why, naming the relevant theorem and saying exactly what goes wrong.
(c) Does this game raise a difficulty for expected utility theory that the ordinary St. Petersburg game does not? Explain your answer.
(d) A classmate proposes to defuse the problem by capping the game at some large number of tosses N. Assess this response.

The student's answer:

(a) The probability that the first heads lands on toss n is (1/2)^n, so each outcome contributes (1/2)^n · (−1)^(n+1) · 2^n/n = (−1)^(n+1)/n to the expectation. Summing in the natural order gives 1 − 1/2 + 1/3 − 1/4 + …, the alternating harmonic series, which sums to ln 2, about 0.69.

(b) The expectation is undefined because the payoffs are unbounded: there is no limit to how much you can win or lose, so the sum can never settle down to a finite value. More precisely, by Cauchy's rearrangement theorem a conditionally convergent series can be rearranged to sum to any value whatsoever, and since there is no privileged order in which to add up the outcomes, no single number deserves to be called the expectation.

(c) Yes, it raises a genuinely new difficulty. In the St. Petersburg game the expectation is infinite, so expected utility theory at least delivers a verdict, namely that the game is worth any finite stake. Here the theory delivers no verdict at all, because there is no expectation to maximise. This shows that expected utility theory is false, or at the very least that it breaks down for any game with unbounded payoffs.

(d) Capping the game at N tosses is a reasonable fix. Every realistic game terminates eventually, and once the game is capped the expectation exists and can be computed, so the paradox disappears. For instance, capped at N = 2 the expectation is 1 − 1/2 = £0.50, and as N grows this approaches ln 2. So the fair price of a heavily capped game is roughly 69p, which is presumably what the uncapped game is really worth too.
