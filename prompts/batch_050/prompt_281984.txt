In your answer, say whether the structuralist can answer the question: is 2 an element of 4?"

Student's answer: "Zermelo identified 0 with the empty set and each successor n+1 with {n}, so 2 = {{∅}}. Von Neumann instead took each number to be the set of its predecessors, so 2 = {∅, {∅}} and 4 = {0, 1, 2, 3}. On von Neumann's reduction 2 is an element of 4, whereas on Zermelo's it is not, since the only member of 4 = {{{{∅}}}} is 3. The problem is that both reductions prove all the same arithmetic, so no mathematical fact can settle which reduction the natural numbers 'really' are, and if numbers were sets then one of them would have to be correct and the other wrong. So numbers are not sets. The structuralist concludes that arithmetic is about the abstract structure shared by all ω-sequences, not about any particular objects. It follows that for the structuralist, '2 is an element of 4' is simply false: the number 2 is a position in a structure, so it has no elements and is not an element of anything. And since any progression of distinct objects can realize the structure, we may as well adopt the von Neumann ordinals by convention, which is what structuralists recomend we do."
