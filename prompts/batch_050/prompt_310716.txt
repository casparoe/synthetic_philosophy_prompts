A friend and I keep arguing about anthropic reasoning (Sleeping Beauty, the doomsday argument, the presumptuous philosopher, all that) and we realized part of the problem is that we can't even agree on what the live positions are. So: write me a decision tree that takes someone from "okay, apparently anthropic evidence is a real thing I need a rule for" to a named position. The main leaves I care about are the self-sampling assumption, the self-indication assumption, and at least one "both of these are broken and here's why" option -- plus any other serious leaf you think belongs there, but don't pad it out with positions nobody could actually hold.

Some constraints on how the tree is built:

- Each branch node should be a question about a concrete case, not a question about jargon. Like, a node can ask what you'd say about some scenario, but it can't ask "do you think your evidence should be sampled from your reference class?" because someone has to already know the theory to answer that.
- The cases you use as branch nodes should be ones where SSA and SIA (and any other leaf) genuinely come apart, and you should be able to say for each node which leaves go which way.
- I made up a case and I want to see where it lands on the tree, so the tree has to be able to handle it: the diluted incubator. A machine creates one person with your exact memories, and then creates a thousand more people who each have 90% of your memories with the last 10% scrambled or replaced by someone elses. Standard incubator-style setup otherwise: heads, only you exist; tails, you plus the thousand near-copies. You wake up with your memories intact and don't know how the coin landed. The reason I like this case is it seems to force every position to say something awkward about whether near-copies count as "you existing" or as members of your reference class, and I want to see that awkwardness show up in the tree, not get glossed over.
- If two leaves can't actually be separated by any case-question (i.e. they'd answer every node the same way), flag that pair explicitly and say why the tree can't split them.
- For any combination of branch answers that ends up unoccupied by an actual position, say briefly whether it's unoccupied because the view would be incoherent, just unattractive, or genuinely unexplored.

Also: don't assume the reader knows any of the standard cases going in. If you use Sleeping Beauty or the presumptuous philosopher as a branch node, set the case up in two or three sentences as part of the question. The deliverable is the tree itself plus the flags and unoccupied-leaf diagnoses, not an essay about the history of the debate.
