That seems to suggest a pretty clear research program for epistemologists: go through the candidate hinges one by one, figure out which ones are actually true versus which we merely treat as fixed, and then rebuild the edifice of knowledge on the verified ones only, tossing out whatever doesn't survive scrutiny.

So my questions for the piece: how far along is this hinge-verification project? Is there a working list of confirmed hinges at this point, or is there still live disagreement about which ones make the cut? And what's currently considered the best method for testing whether a given hinge is true — since presumably you'd need to check them against something more certain, and Wittgenstein's whole point is that nothing is more certain than the hinges themsevles?
