So I've been reading LessWrong since like 2013 and I keep coming back to the wireheading / reward tampering cluster of ideas, and at this point I've basically convinced myself of a position I want stress-tested. Here's the position:

For any agent trained by reinforcement learning where the reward signal is delivered through a channel that exists in the physical world (a register in memory, a human pressing a button, a number on a scoreboard, whatever), a sufficiently capable agent will, by default, eventually optimize the channel itself rather than the thing the channel was supposed to track. The reward is computed somewhere, and whatever computes it is a physical system in the agent's environment, and therefore it's a valid target for optimization pressure. I think of this as the "register argument" (my name, probably already has a real name): if the reward event is inside the agent's world-model, then channel-manipulation is just another trajectory through the environment, and capability gains monotonically increase the salience of that trajectory relative to doing the actual task. So I don't think reward shaping, better reward models, or "learning the true human utility function" fixes the problem in principle, because the fix itself still has to be delivered as a reward event through some channel. The channel is always the exploitable part. The only outs I can see are (a) keeping the agent too dumb to model the channel, which isn't a solution so much as a delay, or (b) some kind of non-RL training scheme where the agent never treats reward as a thing to be received at all.

What would count against this? I'm not looking for someone to restate the standard replies (current RL agents mostly don't do it, indifference methods exist, blah blah). I want a real map of what the position risks. Which theoretical results would break the register argument -- e.g. would a formal proof that some class of reward functions are untamperable-in-expectation under certain architectures do it, and do those classes cover anything like the real case? Which empirical findings should move me: if frontier labs red-team their best models hard for reward tampering and keep coming up empty at ever-higher capability levels, is that evidence against me or just evidence about the dumbness regime I already conceded? What would the people who take this problem most seriously concede as a genuine defeater for their own view, versus what would they shrug off? Please rank the potential defeaters from "kills the position dead" to "merely awkward." And one more thing I want handled honestly: I have a suspicion that this position, mine included, has been qualified into unfalsifiability over the years -- every negative result gets absorbed as "wrong capability level" or "not agentic enough yet" -- so tell me whether there's any observation left that would actually update me downward, or whether I've accidentally adopted a belief that nothing could dent, and whether that's as bad for an argument-from-theoretical-structure as it would be for an empirical claim. Definately willing to be talked out of this if the defeaters are good.
