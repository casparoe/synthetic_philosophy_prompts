So I'm a software engineer, no philosophy background, and I've been arguing with a friend about self-amending rules -- like the game Nomic, or a constitution that lets you amend the amendment clause itself, or honestly an upgradeable smart contract. I think I have an argument that full self-amendment is impossible, but it smells like it proves too much, since Nomic games apparently run for years without breaking. Here it is:

1. A fully self-amending system is one where every rule, including the rules governing how rules get changed, can itself be legally changed.
2. If every rule can be changed, then in particular a rule can be changed into one whose text says some rule may never be changed.
3. Therefore it is legally possible for a rule to become unchangeable.
4. But if some rule is unchangeable, then not every rule can be changed, contradicting premise 1.
5. So a fully self-amending system contains a contradiction and can't really exist; anything that looks like one must secretly have untouchable rules, or be one legal move away from freezing itself forever.

Where does this go wrong? I'd like to hang onto premise 1 since it's just the definition I care about, so ideally the fix is elsewhere. Tell me which step you'd reject, why it looked fine in the first place, and what rejecting it costs. Also please be upfront about what's basically settled among people who've thought about self-amendment versus what's still genuinely contested -- don't dress up a contested fix as the consensus answer.
