For my formal epistemology seminar I'm writing about Jeffrey conditionalization as a generalization of Bayesian updating for uncertain evidence. As I understand Jeffrey's motivation, he doubted that experience ever renders an evidential proposition fully certain — the example usually given is judging the color of a piece of cloth under variable lighting, which shifts one's probabilities without making any color proposition certain — so rational agents should update by redistributing probability across a partition rather than by conditioning on propositions learned for sure. This leads me to a worry about how the rule relates to practice. In most applications I can think of — medical diagnosis from a test result, forensic updating from a lab report, classifiers in machine learning — the evidence is treated as a definite recorded proposition: the test came back positive. If Jeffrey is right that nothing is ever learned with certainty, does that make ordinary conditioning in these domains simply a mistake, so that applied Bayesian statistics rests on an idealization he rejected? And conversely, where a result really is recorded with certainty, is there anything left for Jeffrey's rule to do? If I've set this up wrongly — for instance, if the rule was never meant to compete with or replace ordinary conditioning — please say so plainly rather than answering on my assumptions.
