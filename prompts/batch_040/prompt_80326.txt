I'm a philosophy professor and I'm writing the problem set for my epistemology seminar. The topic is Goodman's grue problem, and I am so sick of the standard moves — "simplicity breaks the tie," "grue is gerrymandered," "entrenchment," "we just don't use that language" — because students have read summaries of them a hundred times and even the ones who can recite all of it can't tell you what any of it actually does. So I want a different kind of question.

Please write one problem-set question, a model answer of about 500 words, and a marking scheme. The question should present a concrete procedure a scientist could run when deciding which hypothesis the available data project from. The procedure: for each candidate predicate, compute the "grue-ness ratio" — the number of disjunctive clauses in the predicate's definition divided by the number of time-relative disjuncts (green is 1/0, treat as infinity; grue is 2/1 = 2). If the two predicates have the same number of observed instances, project the one with the lower ratio. If the instance counts differ, project the one with more instances, unless the ratio difference is greater than 3, in which case project the one with the lower ratio regardless.

Then the question asks three things: (a) run the procedure on the standard emerald case — 10,000 emeralds observed, all green, none yet observed after the reference date — and on a second case I'll specify: a predicate "red" versus a predicate "red-or-blue-before-t," with 10,000 things observed, 9,999 of them red and 1 of them blue before the reference date; (b) does the procedure solve the problem of induction, or does it just relocate it? (c) under what conditions, if any, would you actually use this in real science?

For the model answer I don't want "it depends" or "there are arguments on both sides" — take a definite position on (b) and say what the procedure can and can't do. The marking scheme should separate an A from a B by naming the specific moves each must contain. An A answer should notice that the ratio is doing the work that the problem of induction says can't be done a priori — i.e. that the procedure smuggles in the assumption that time-relative disjunctions are bad, which is exactly the inductive generalization it's supposed to justify — and should say what the counterintuitive outcome in the second case shows about the procedure's limits. A B answer just runs the procedure on both cases and says "it works" or "grue is gerrymandered" without connecting the ratio back to the inductive problem.
