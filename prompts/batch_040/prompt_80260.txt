I'm in a decision theory seminar this term, and we recently worked through the Pasadena game, which has left me tangled up in a disagreement between two classmates that I've been unable to referee. Let me lay out the game the way we were given it: a fair coin is flipped repeatedly until it first lands heads, and let n be the number of flips it takes. If n is odd, the house pays you $2^n; if n is even, you pay the house $2^n. When I try to compute the expected value, I get the sum, over all n, of (1/2)^n · (−1)^{n+1} · 2^n, which reduces to 1 − 1 + 1 − 1 + ⋯, so the expected value does not exist. That much I follow. What I can't make sense of is what we are supposed to conclude from it.

My classmate Mara's position is that the game is fair in a genuine sense and that a fully rational agent should be exactly indifferent between playing and declining. Her reasoning is that the expected value fails to exist precisely because the favorable and the unfavorable contributions to it are perfectly balanced — every term has the same magnitude, so no net expected gain or loss survives — and that, on that view, the game is a wash and it would be arbitrary to rank playing above not playing. Dev objects that this quietly treats a nonexistent expected value as though it were zero. For Dev, an undefined expected value means that the expected-value criterion is simply silent about the decision, not that it prescribes indifference; and when the criterion is silent, the correct move is to fall back on secondary considerations, the most important of which is that the game carries unbounded downside: since you can lose arbitrarily large sums while your own wealth is finite, a wealth-sensitive agent should decline on risk-of-ruin grounds, regardless of what the (nonexistent) expected value would have indicated.

Mara answers that the "unbounded downside" consideration is not actually one-sided, because the upside is equally unbounded — you can win arbitrarily large sums as well — so if unboundedness is what disqualifies a game, it disqualifies the favorable tail just as much as the unfavorable one and yields no net reason to decline; she adds that the risk-of-ruin objection only gets any purchase once you fix a particular bankroll, and the game as stated contains no such parameter, so importing one is question-begging. Dev concedes that the upside is unbounded but maintains that the two tails are not symmetric in the way that matters: a sufficiently large loss can destroy an agent's ability to do anything at all, whereas a large gain only improves things, so the destructive tail carries a kind of option value that the favorable tail lacks, and a rational agent should weight the tail that can ruin them more heavily even when both tails are unbounded. I genuinely cannot tell who is right about what, so could you work through this exchange and adjudicate it? In particular: (1) is the expected value of the game as I described it actually undefined, and if so, in exactly what sense — as opposed to being +∞ or merely very large? (2) does an undefined expected value license the conclusion that the agent should be indifferent between playing and not playing, or does it license only the weaker conclusion that the expected-value criterion is silent? (3) is Dev's risk-of-ruin / unbounded-downside objection a genuine reason to decline the game as stated, or does it apply only once you add a finite-wealth parameter the game does not contain? and (4) does the paradox show that expected-value maximization is wrong, or merely that it is incomplete, in the sense of failing to rank some pairs of options? I would like a verdict on each of the four questions, whether there is some further consideration both of them are overlooking, and, insofar as the two of them are each partly right, a sense of who is more right overall.
