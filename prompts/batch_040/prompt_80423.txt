I'm working on a short piece for a philosophy of medicine reading group and I want to stress test my argument before I commit to it. The broad frame is the naturalism vs. normativism debate over the concept of health (Boorse's biostatistical theory on one side, the Eng/Freddendall-style claim that health is essentially a value concept on the other), but I want to zoom in on the reference class problem, because I think it's underappreciated as a symptom of the deeper normative issue rather than a technical bug you can just fix by picking the right class.

Here's my draft argument, roughly: Boorse defines normality as statistical typicality of functional efficiency within a reference class (species, sex, age, etc.) and the standard objection is that the choice of reference class is arbitrary. The usual response is that we can just pick the right class, say the one that's most medically useful. But I want to argue the choice of reference class is itself a value judgment, not a neutral technical choice, because different classes serve different ends. My concrete example is lactose tolerance: it's a recent evolutionary adaptation that spread in dairy farming populations, so lactose intolerance is the ancestral default. If your reference class is "humans throughout most of our evolutionary history," intolerance is normal and tolerance is the deviation; if it's "modern Western populations," it flips. And which class you pick tracks what you value (minimizing disease labels in certain populations vs. maximizing medical utility), so the reference class problem doesn't dissolve the normative challenge, it relocates it.

Can you comment on whether this argument actually holds, especially the move from "the reference class is arbitrary" to "the choice is a value judgment"? I'm worried I'm conflating two different things: the epistemic arbitrariness (we don't have a fact of the matter about which class is right) and the normative arbitrariness (the choice reflects values). If those are the same thing my argument just collapses into restating the normative challenge. Also flag anywhere I'm mischaracterizing Boorse or the standard objections, and tell me if the lactose example is actually doing the work I think it is or if it's a weak illustration.
