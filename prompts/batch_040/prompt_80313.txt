One student wrote:

"Zorn's lemma. Let P be a partially ordered set such that every chain (i.e. a totally ordered subset) of P has an upper bound in P. Then P has a maximal element.

Proof. Suppose for contradiction that P has no maximal element. Then for each x in P the set S_x = { y in P : x < y } is nonempty. This is where we use the axiom of choice: we choose f(x) in S_x for each x in P, so that f(x) > x for every x. Now define a sequence (x_alpha)_{alpha < Ord} by transfinite recursion: pick x_0 in P arbitrarily, set x_{alpha+1} = f(x_alpha), and at a limit ordinal lambda set x_lambda = sup { x_alpha : alpha < lambda }, which exists because { x_alpha : alpha < lambda } is a chain and every chain in P has an upper bound. The sequence is strictly increasing, since each step applies f. So its range is a chain in P, and by hypothesis it has an upper bound u in P. But u is an element of P, so u = x_alpha for some alpha, and then u < f(u) = x_{alpha+1} <= u, a contradiction. Hence P has a maximal element. QED"
