The student answered: "Kripke's theory builds a hierarchy of partial interpretations, starting with a base in which no sentence is true, and iterating the T-schema until a fixed point is reached. At the minimal fixed point, the liar sentence 'this sentence is not true' is ungrounded: its truth depends on itself, so it gets no value and is neither true nor false. That is why K3 gives up the principle that every sentence is true or false, while LP keeps that principle but gives up the principle that a contradiction entails everything: in LP the liar is both true and false, and the rest of the logic doesn't collapse. The revenge objection runs as follows: if our final theory T contains a truth predicate, then the sentence 'this sentence is not true in T' is a new liar. I don't think this is a serious threat in Kripke's case, because 'true in T' is a predicate of the metalanguage, so the revenge sentence is not a sentence of the object language to which the T-schema applies. As for whether the theory can be final: the minimal fixed point is the least fixed point of the iteration, so there is no larger fixed point to which one could move, and the theory is stable against extension.
