As a software engineer who's been reading up on scalable oversight schemes for AI systems, I keep getting stuck on the theoretical justification behind AI safety via debate. Irving, Christiano, and Amodei motivate the scheme with an analogy to complexity theory: a bounded referee overseeing two competing, far more powerful debaters can, under idealized play, decide languages as hard as PSPACE, so a debate between two capable models should let a comparatively weak human judge safely adjudicate questions that neither the judge nor a single, unchecked model could reliably resolve alone. Please argue against treating this analogy as an actual safety case, focusing specifically on the obfuscated arguments problem: a dishonest debater can bury a false step inside an argument tree so large that locating the exact flaw is itself intractable, so the honest debater cannot always win efficiently even when they're right. Make the strongest case you can that this reflects a principled disanalogy between formal verification and how real judges assess informal, natural-language arguments -- rather than an implementation bug that better protocol design can remove -- and address directly whether cross-examination, letting each debater interrogate frozen, earlier copies of the other, actually closes this gap or merely relocates it to a new bottleneck.
