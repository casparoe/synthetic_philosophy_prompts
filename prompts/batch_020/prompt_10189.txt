Question (20 points): "Solomonoff induction is often described as a formalization of Occam's razor. Give the formal definition of the universal (Solomonoff) prior and explain how it relates to Kolmogorov complexity. Then explain why, despite being a mathematically precise ideal, Solomonoff induction cannot be run as an algorithm. Situate these ideas briefly in their historical context."

Student's answer: "Solomonoff induction formalizes Occam's razor by replacing the informal instruction to prefer the simpler hypothesis with a precise prior over hypotheses. The idea originates with Andrey Kolmogorov, who in the 1960s proposed weighting each possible explanation of some data by the length of the program that generates it on a fixed universal Turing machine U; Solomonoff and Chaitin subsequently built on this to formalize the notion of algorithmic, or universal, probability. Concretely, the complexity K(x) of a string x is the length of the shortest program p such that U(p) = x, and the universal prior is m(x) = 2^(-K(x)): probability mass decays exponentially with the length of a hypothesis's shortest description, so compressible, simple data-generating programs are favored automatically over baroque ones that merely memorize the data. Solomonoff showed that a Bayesian reasoner using this prior converges rapidly to the true data-generating distribution, provided that distribution is computable. The obstacle to implementation is that no algorithm can compute K(x) for arbitrary x: doing so would amount to deciding, for every candidate program shorter than K(x), whether it eventually halts, which is exactly the halting problem. So Solomonoff induction is uncomputable in principle and not merely impractical; real inductive agents, biological or artificial, can only approximate it, for instance by bounding search time over candidate programs, as in Levin search or in modern MDL-based learning."
