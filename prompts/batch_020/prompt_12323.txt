Here's the question as it was given (15 pts total):

A fair coin is tossed repeatedly until it lands heads for the first time. If the first head occurs on toss n, the player is paid (-1)^(n+1) * 2^n / n.
(a) [5 pts] Compute the expected value of the game by summing over n = 1, 2, 3, ... in the natural order.
(b) [6 pts] Explain why Nover and Hájek take this to pose a problem for expected utility theory that is different in kind from the problem posed by the classical St. Petersburg game.
(c) [4 pts] Would adopting a bounded utility function -- the standard fix for St. Petersburg -- also resolve the difficulty raised by the Pasadena game? Explain.

And here's my partner's answer:

(a) The probability the first head occurs on toss n is 1/2^n, so the expected value is Σ (1/2^n)(-1)^(n+1)(2^n/n) = Σ (-1)^(n+1)/n = 1 - 1/2 + 1/3 - 1/4 + ... This is the alternating harmonic series, which converges absolutely to ln(2) ≈ 0.693.

(b) In St. Petersburg, every toss contributes the same amount (1) once you weight by probability, so you're summing infinitely many positive terms and it diverges to infinity no matter what order you add them in. Pasadena is different: because the terms alternate in sign, a theorem (Riemann's, I believe) says the series can be rearranged to sum to any real number you like, or to diverge, or to oscillate forever. So the problem isn't that the expected value is big, or even infinite -- there's no single fact about what it is at all, since nothing in the setup privileges one summation order over any other. That's a deeper problem for expected utility theory than St. Petersburg ever was, because it suggests some gambles just don't have expectations, full stop.

(c) No. Bounding the utility function doesn't touch this problem, because what breaks the Pasadena game has nothing to do with the size of the payoffs (unlike St. Petersburg) -- it's about the order you add them in. Capping individual payoffs tells you nothing about which order to sum them in, so the indeterminacy from part (b) would be exactly as vexing as before.
