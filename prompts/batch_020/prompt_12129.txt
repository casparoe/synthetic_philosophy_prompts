The reference class problem arises whenever we try to attach a probability to a single, unrepeatable case: this coin toss, this patient's prognosis, this defendant's likelihood of reoffending. The trouble is that any such case belongs simultaneously to indefinitely many reference classes, and different classes can support very different frequencies. A 54-year-old smoker recently diagnosed with a particular cancer belongs at once to the class of 54-year-olds, the class of smokers, the class of people with that exact cancer subtype and stage, and the class of patients treated at that particular hospital, among indefinitely many others; each class is genuine, each is picked out by a true predicate she satisfies, and each may support a different five-year survival estimate, with no obvious non-arbitrary rule for privileging one over the rest. Hans Reichenbach's classic fix was to recommend the narrowest class for which we still have statistically adequate data, but critics have long pointed out that "narrow enough to be relevant" and "wide enough to be reliable" can each be satisfied by more than one incompatible class at once, so the criterion underdetermines an answer rather than supplying one.

Most people in a reading group I'm part of wanted to treat all of this as strictly a problem for frequentism: a committed Bayesian, who treats probability as an agent's rational degree of belief rather than an objective long-run frequency, was thought to sidestep the problem entirely, since credences need only track whatever evidence the agent actually has, with no prior commitment to a privileged population of "relevantly similar" cases. I'd like you to argue against that consensus. Specifically, defend the claim that the reference class problem reappears, in an equally damaging form, for Bayesians, because conditionalization tells an agent how to update on a chosen piece of evidence but is silent on which of the many true statistical facts about the case at hand ought to be the evidence conditioned on in the first place, so that any appearance of Bayesian immunity rests on quietly presupposing a reference class rather than genuinely dispensing with the need for one. Before delivering your rebuttal, make the strongest case you can for the opposing, Bayesian-immunity view, including whatever a sophisticated appeal to something like Carnap's requirement of total evidence might buy the Bayesian, and then show exactly where that case goes wrong.
