Question: (a) State Löb's theorem precisely for a theory T extending PA. (b) Explain why a system that adopted the full reflection schema "Prov_T(⌜P⌝) → P" for every single sentence P would have to be inconsistent unless it already proved every such P outright, and why this is a problem for an agent trying to justify trusting its own future proofs. (c) Relate this to Yudkowsky & Herreshoff's discussion of self-modifying agents ("tiling agents"), and say whether you think their proposed fix gets rid of the obstacle for good.

Classmate's answer:
(a) For any theory T at least as strong as PA and any sentence P: if T ⊢ Prov_T(⌜P⌝) → P, then T ⊢ P. So T can only prove "if I can prove P then P is true" for a P it already proves outright anyway.
(b) If T proved that schema for literally every P, Löb's theorem would force T to prove every P, including false ones, so T would be inconsistent. Really this is just a special case of Gödel's second incompleteness theorem: G2 is the fact that holds for an arbitrary sentence, and Löb's theorem is the particular instance of it you get once P is taken to be a flat-out contradiction like 0=1. Either way, the upshot is that an agent can't bake "whatever I can formally derive is true" into its own axioms as a blanket guarantee, so it has no formal certificate that its future proofs track truth -- it has to trust them from outside the system.
(c) Yudkowsky & Herreshoff call this the Löbian obstacle: an agent that wants to build a successor reasoning in the same proof system can't first verify that anything the successor proves about an action's safety will actually make that action safe. Their proposed way out, parametric polymorphism, has each successor use a strictly weaker system than its predecessor, so no agent ever has to trust an identical copy of itself. Since that sidesteps the exact kind of self-reference Löb's theorem needs, it shows the obstacle was never really a fundamental barrier -- with that fix in place, formally justified successor-trust is basically a solved problem.
