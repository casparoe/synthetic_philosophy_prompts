In accuracy-first epistemology, probabilism is typically justified by an accuracy-dominance argument: when accuracy is measured using the Brier score, every credence function that violates the axioms of probability turns out to be less accurate, in every possible world, than some probabilistic credence function. Since this is supposed to be a fact about distance from the truth, shouldn't the same domination result go through if we instead measured inaccuracy using the more intuitive absolute difference between a credence and the proposition's truth value, given that both scores seem to be just different ways of capturing how far a credence is from the truth?
