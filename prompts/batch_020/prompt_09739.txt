The question, worth 20 points, reads: "Kripke argues that 'Hesperus is Phosphorus' is an example of the necessary a posteriori. (a) Using the notion of a rigid designator, explain why this statement must be necessarily true if it is true at all. (b) Explain why, despite this necessity, our knowledge that the statement is true is nonetheless a posteriori. (c) What does this case show about the traditional assumption that the necessary/contingent distinction coincides with the a priori/a posteriori distinction? Illustrate your discussion with one further example of your own choosing, and explain briefly how it bears on the extension of Kripke's account to natural-kind terms."

Here is the student's answer in full:

"A rigid designator is an expression that picks out the same object in every possible world in which that object exists, and fails to designate anything in worlds where the object doesn't exist. Ordinary proper names such as 'Hesperus' and 'Phosphorus' are rigid designators: whatever object 'Hesperus' picks out in the actual world—the planet Venus—is the very same object it picks out in every other possible world in which Venus exists, and likewise for 'Phosphorus'. Since both names denote Venus in every world, if 'Hesperus is Phosphorus' is true in the actual world, it is true in every possible world in which Venus exists; there is no possible world in which Hesperus fails to be identical to Phosphorus, since they are simply one object designated twice. Contrast this with a description like 'the brightest object visible at dusk': in some possible world a different body might have been the brightest at dusk, so the description is non-rigid, tracking different objects across worlds. This is why Kripke treats rigidity as the defining mark of proper names as opposed to descriptions: names latch onto an object directly and hold onto it across all possible worlds, whereas descriptions, because they designate whatever happens to satisfy some condition, can never be rigid in this way.

Despite this necessity, no one knew a priori that Hesperus is Phosphorus. Ancient observers named the object that appeared in the evening sky 'Hesperus' and the object that appeared before dawn 'Phosphorus', reasonably assuming these were two different bodies; it took empirical astronomical work to discover that they were one and the same planet. So although 'Hesperus is Phosphorus' is necessarily true, our knowledge that it is true rests on observation and could not have been established by reason alone: the truth is necessary, but it is knowable only a posteriori.

This combination is exactly what traditional rationalist and Kantian frameworks rule out, since they treat the necessary/contingent distinction—a matter of how things stand in all possible worlds—as coinciding with the a priori/a posteriori distinction—a matter of how a truth is known. Kripke's case shows that the two distinctions are independent: a proposition can be metaphysically necessary while being epistemically available only through experience.

The same pattern arises for natural-kind terms. 'Water' rigidly designates whatever kind is picked out in the actual world by our paradigm samples of water, namely H2O, so 'water is H2O' is necessary in just the way 'Hesperus is Phosphorus' is, even though it took chemists to discover it. Kripke's Twin Earth thought experiment brings this out vividly: on a duplicate planet where the odorless, potable liquid filling the lakes and oceans has the molecular formula XYZ rather than H2O, that liquid is not water, even though it is indistinguishable from water by every observable test available to ordinary speakers. What matters for the extension of 'water' is not the cluster of superficial properties by which we recognize samples of it, but the underlying microstructure those samples actually share—which is precisely why the identity of water with H2O, once discovered, could not have turned out otherwise."
