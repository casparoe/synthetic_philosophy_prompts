I'm a philosophy professor -- I teach mainly epistemology -- serving on my university's Academic Integrity Board, which must decide whether to approve a policy under which flags from a new AI-text-detection tool would count as evidence in misconduct hearings. The vendor's case for reliability is entirely internal: the same essay, submitted twice, reliably gets the same verdict, and a similarly built second detector from the same vendor agrees with the first about ninety percent of the time. No essays of independently confirmed authorship have ever been used to check a verdict against the truth. Some members find this scale of self-agreement reassuring and point out that all measurement rests somewhere on an instrument trusted without independent check; others answer that an independent check is available here and has simply never been used, so the parallel doesn't obviously hold. Please draft the short memo I'll bring to the Board: recommend adopt, reject, or adopt-with-conditions (stating what independent evidence would be required, and by when), and take a clear stand on whether the "trust has to start somewhere" objection actually excuses this case.
