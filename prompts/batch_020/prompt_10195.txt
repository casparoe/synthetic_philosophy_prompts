As a PhD student working on value-learning approaches to AI alignment, I've been going back through the foundational inverse reinforcement learning literature. Ng and Russell showed that the naively posed IRL problem is degenerate, since a reward function that is zero everywhere makes every policy trivially optimal, but refinements such as maximum-entropy IRL resolve this by selecting a single reward function consistent with the observed behavior. Given that this ambiguity has essentially been handled, it seems like the only remaining obstacle to recovering what humans truly value from their behavior is scale: with sufficiently large and varied behavioral datasets, the inferred reward should converge on people's actual preferences. Why, then, do so many alignment researchers continue to treat preference inference from behavior as unsolved in principle, rather than as an engineering challenge that more data will eventually resolve?
