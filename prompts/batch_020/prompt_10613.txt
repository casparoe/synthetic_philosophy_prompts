I'm a software engineer who has used linear temporal logic to specify properties for a model checker, which is how I first came across Arthur Prior's tense logic and, through it, Aristotle's sea-battle argument about future contingents. I already follow the basic shape of the puzzle: if it's true today that there will be a sea battle tomorrow, or true today that there won't be, then whichever disjunct is true seems to have been true all along, and the battle's outcome looks fixed regardless of anyone's choices. What I'd like explained is the more specific disagreement between the two resolutions Prior formalized, the 'Peircean' and the 'Ockhamist' treatments of future tense. Concretely, how does each assign truth values to future-contingent statements as of today, and what does each give up to block the fatalist conclusion: does one deny that a future-contingent sentence or its negation is true now, while the other keeps every sentence true or false but denies that truth entails necessity? I'd also like to understand why rejecting bivalence and rejecting excluded middle count as different moves in this context, since that distinction seems to matter for which resolution one prefers.
