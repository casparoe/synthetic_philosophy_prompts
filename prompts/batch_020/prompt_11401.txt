"State the (downward) Löwenheim–Skolem theorem, explain how applying it to ZFC seems to generate a contradiction with Cantor's theorem — this is 'Skolem's Paradox' — and explain why it isn't actually an inconsistency in ZFC."

and here's the answer i got assigned to grade, worth 10 pts:

"The relevant theorem is the (downward) Löwenheim–Skolem theorem: any theory formulated in a countable first-order language that has an infinite model has a countable model. ZFC is a first-order theory over the single non-logical symbol ∈, so its language is countable. So if ZFC is consistent, it has a model, and by the theorem, it has a countable model M.

Here's where the apparent paradox comes in. ZFC proves Cantor's theorem, i.e. that there's no bijection between ω and its power set P(ω) — so ZFC proves P(ω) is uncountable. The model M satisfies all the ZFC axioms and their consequences, so M contains some object it interprets as ω and some object it interprets as P(ω), and M satisfies the sentence saying there's no bijection between them. But M itself has only countably many elements total, since that's what makes M a "countable model." So a countable structure contains, as one of its own members, a set it insists is uncountable — which looks like a flat contradiction: how can a countable totality contain an uncountable member?

It isn't really a contradiction. Since M only has countably many elements overall, it can't contain every subset of ω that exists in the real universe of sets — the object M calls P(ω) is missing a huge number of subsets of ω that a genuine, full-strength power set would have. Because of this, M ends up being mistaken when it insists its version of P(ω) is uncountable: since M's whole domain is countable, M's version of P(ω) is, from the outside, actually just a countably infinite set, in bijection with ω. M just doesn't have the resources within it to define, via a first-order formula, what that bijection is, so internally it can't see that the bijection exists.

So the upshot (basically Skolem's own point) is that "countable" and "uncountable" aren't absolute properties a set has independently of context — whether a set counts as countable is relative to which model of set theory your asking the question in, since different models disagree about which functions exist. That's a strange result, but it's a relativity of set-theoretic notions to the model, not an actual inconsistency in ZFC."
