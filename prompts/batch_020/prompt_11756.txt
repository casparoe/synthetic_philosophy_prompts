Kripke's 'Humphrey objection' to David Lewis's counterpart theory is that when we say Humphrey could've won the election, counterpart theory only makes this true because some other guy wins in some other world -- and Humphrey couldn't care less about that guy. Everyone always uses this exact same example though, so its hard to tell if people actually get the underlying issue or just memorized the case.
