Coming back to it the next day, I found myself reading through a stack of short-answer submissions for a seminar on epistemic logic for which I am a teaching assistant, and I would like a second, disinterested opinion on one of them before I enter a grade.

The question, as set, reads:

Fitch's paradox concerns two theses stated with an epistemic operator K, read tenselessly as "is known by someone at some time." Non-Omniscience (NO): ∃p (p ∧ ¬Kp). Knowability Principle (KP): ∀p (p → ◊Kp). Given only the assumptions that K distributes over conjunction (K(p ∧ q) entails Kp ∧ Kq) and that K is factive (Kp entails p), Fitch showed that KP and NO cannot both hold.
(a) Reconstruct the derivation: show that ¬◊K(p ∧ ¬Kp) is a theorem for arbitrary p, and use this together with NO and KP to derive the Actual Omniscience thesis, ∀p (p → Kp).
(b) The result is often glossed as "showing that some truths are unknowable." Which proposition, exactly, does the argument show to be unknowable — the same p we started with, or a different one? Explain why the distinction matters for how threatening the paradox actually is to anti-realism.
(c) Sketch one way an anti-realist might restrict the Knowability Principle in response to this result, and briefly assess whether the move succeeds.

The submission reads:

(a) Suppose K(p ∧ ¬Kp). By distribution, Kp ∧ K¬Kp. By factivity applied to the second conjunct, ¬Kp. So Kp ∧ ¬Kp, a contradiction. Hence K(p ∧ ¬Kp) is impossible for any p: ¬◊K(p ∧ ¬Kp) is a theorem. Now instantiate KP with (p ∧ ¬Kp): (p ∧ ¬Kp) → ◊K(p ∧ ¬Kp). Since the consequent is always false, the antecedent must be too: ¬(p ∧ ¬Kp), i.e., p → Kp. As p was arbitrary, ∀p (p → Kp): Actual Omniscience.

(b) The proposition shown to be unknowable is p itself. Because the derivation goes through for any p whatsoever, Fitch's argument establishes that any truth we care to name is not merely unknown but unknowable in principle. That is exactly what makes the result so damaging to anti-realism: the whole motivation for equating truth with knowability collapses once we see that ordinary, unremarkable truths turn out to be unknowable by the very argument that was supposed to make knowability plausible in the first place.

(c) An anti-realist can restrict KP so that it no longer quantifies over self-referential conjunctions like p ∧ ¬Kp, applying it only to more ordinary propositions instead. This is the standard move in the literature, and once it is made, the paradox is revealed to be a technical curiosity about a narrow class of Moore-paradoxical sentences rather than a genuine problem for anti-realism: the restriction fully defuses the argument, so there is no substantive residual worry about equating truth with knowability.
