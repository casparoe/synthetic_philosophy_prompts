The prompt given to the class was: "Explain how the sorites paradox arises for the predicate 'heap,' and describe how epistemicism and supervaluationism each attempt to resolve it. Which solution do you find more plausible, and why?"

Here is the response to be graded:

"The sorites paradox arises from cases involving vague predicates, such as 'heap.' Consider a heap of 1,000,000 grains of sand. If we remove one grain, it seems obvious that it is still a heap: removing a single grain cannot turn a heap into a non-heap. If we accept this premise and apply it 999,999 times, we eventually conclude that a single grain of sand is a heap, which is absurd. The paradox is generated by three claims that each seem plausible on their own but cannot all be true together: (1) 1,000,000 grains make a heap, (2) removing one grain from a heap leaves a heap, and (3) 1 grain is not a heap.

Two of the main responses to this puzzle are epistemicism and supervaluationism. Epistemicism, defended by Timothy Williamson, claims that there really is a sharp, precise cutoff point between heaps and non-heaps — say, exactly 73 grains — but that we can never know where it is, because our ordinary use of the word 'heap' is too coarse-grained to fix such an exact boundary. On this view, premise (2) — that removing one grain from a heap always leaves a heap — is simply false: there is some exact number of grains for which it fails, but we can never know which number that is.

Supervaluationism, by contrast, denies that there is any single sharp cutoff that our word 'heap' picks out. Instead, it holds that a vague predicate like 'heap' can be made precise in different admissible ways, called precisifications, and a sentence counts as true if and only if it comes out true on every admissible precisification, and false if and only if it comes out false on all of them. Since different precisifications draw the line in different places, a claim like '500,000 grains is a heap' will be true on some precisifications and false on others, and so counts as neither true nor false. Because supervaluationism allows sentences to lack a truth value in this way, it has to give up the law of excluded middle for borderline cases: a sentence like '500,000 grains is a heap, or 500,000 grains is not a heap' will itself come out neither true nor false, since once bivalence fails there is no guarantee that classical logical laws still hold.

I find supervaluationism more plausible than epistemicism, because it seems bizarre to think there is a fact of the matter about the exact number of grains that make a heap, when nothing in our use of the word 'heap' could plausibly have fixed such a precise number. Supervaluationism instead locates the indeterminacy where it intuitively belongs — in our language — rather than in a hidden, unknowable fact about the world."
