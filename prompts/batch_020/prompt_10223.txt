So I went down a rabbit hole a while back reading old LessWrong/MIRI stuff on "open source game theory," starting from Tennenholtz's original program equilibrium result (mid-2000s, I want to say) and working forward to the 2014 paper that redoes the whole thing with FairBot and PrudentBot via provability logic and Löb's theorem. I've been arguing with a friend about how impressed we should actually be by this stuff and neither of us can resolve it, so I want an essay that actually commits to a side instead of hedging the way we keep doing.

Here's the tension as I see it. Tennenholtz's basic move is: let two players submit programs that get to read each other's source code before a one-shot Prisoners Dilemma gets played -- something as dumb as "cooperate iff your code is byte-for-byte identical to mine" (what the MIRI paper later calls CliqueBot) already makes mutual cooperation a Nash equilibrium, no repeated game or outside enforcer required. Except it seems to prove way too much: the identical-code trick supports almost any individually-rational outcome as an equilibrium, including openly extortionate ones ("cooperate iff you hand over 90% of the surplus, else defect forever"), so it looks like program equilibrium just relocates the equilibrium-selection problem instead of explaining cooperation specifically. FairBot is supposed to be the fix: it cooperates with anything it can prove cooperates with it, so FairBot-vs-FairBot cooperation comes out of an actual Löbian argument instead of requiring byte-identical code, and it's provably unexploitable in the sense that nobody can get it to cooperate while defecting on it. PrudentBot then patches the remaining weirdness, that FairBot cooperates even with agents who'd have cooperated no matter what, leaving free value on the table. Some days that feels like real progress to me. Other days it feels like the same multiplicty problem wearing a modal-logic costume, since nothing stops someone from building a "fair"-bot that only extends provable cooperation to agents who also hand over most of the surplus, and the whole apparatus quietly assumes both sides share a sound, mutually-trusted formal system and are willing to run open-ended proof searches -- which no bounded agent, human or animal or actual deployed AI, does.

Write the essay that settles this for me: does the Löbian/provability-logic refinement of program equilibrium represent real progress on the problem of cooperation without external enforcement, beyond what the bare Tennenholtz result already gave us, or is the added formal machinery mostly decorative? Actually engage with both the folk-theorem-style objection and the "unrealistic shared proof system" objection instead of just listing them, and don't let yourself off the hook with "it depends" -- "it's genuine progress, but only for a narrow and identifiable class of agents, namely ___" counts as landing somewhere, and so does "no, and here's the disanalogy people keep eliding."
