Two of my coworkers spent a good chunk of lunch arguing about a decision theory puzzle one of them had just read about, called the Pasadena paradox: a St. Petersburg-style repeated-coin-flip gamble whose payouts alternate between positive and negative and grow with the number of flips, such that the series for its expected value converges only conditionally, not absolutely.

Jake said this shows expected-value theory is simply broken for gambles like this one: since the series is conditionally convergent, you can reorder the very same set of possible outcomes and land on any total you like, including plus or minus infinity, so 'the' expected value isn't a real property of the gamble at all -- it's an artifact of bookkeeping.

Lena said that overstates things: the flips happen in a fixed temporal sequence, first flip, second flip, and so on, so there's an obvious canonical order to sum the terms in, namely that one. Fix that order and you get a single determinate answer; the 'paradox' only shows up if you go looking for other, physically unmotivated ways to add up the same numbers.

Jake came back that this response quietly changes the subject: expected-value theory, as usually stated, is supposed to be a function of the probability distribution over outcomes alone, and says nothing about the order in which someone happens to write down a sum. If you need an extra rule -- always sum in the order the uncertainty resolves in time -- bolted onto the theory to get a determinate answer, that's a tacit admission that expected-value theory by itself doesn't settle the case, which was the whole point of the paradox to begin with.

Lena answered that every expected-value calculation already relies on some indexing of outcomes, and using the order in which the uncertainty actually resolves isn't a special patch invented to rescue this one case -- it's the same indexing everyone always uses without noticing, because for ordinary, absolutely convergent gambles every ordering happens to agree anyway. The Pasadena game doesn't expose some hidden extra assumption; it just exposes that the assumption was never harmless in general, only in the tamer cases we're used to.
