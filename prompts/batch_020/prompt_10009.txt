Question 3 (10 points).
(a) [4 points] State Löb's theorem for a consistent, recursively axiomatized theory T extending Peano Arithmetic, and show how Gödel's Second Incompleteness Theorem follows from it as a special case.
(b) [6 points] Consider an agent A that only performs an action when it can produce, within a formal system T, a proof that the action is "safe." Suppose A is asked to certify, once and for all, that it may permit a successor agent A′ — reasoning in the very same system T — to act under this same policy. Using Löb's theorem, explain why A cannot do this by adopting an unrestricted reflection principle for arbitrary actions. Then briefly describe how the literature on this "Löbian obstacle" proposes to get around the difficulty, and comment on how far that proposal actually resolves the underlying problem for self-modifying AI systems.

Student's answer:

(a) Löb's theorem states that for a consistent, recursively axiomatized theory T extending PA, and for any sentence φ, if T ⊢ □φ → φ, then T ⊢ φ, where □ is T's own provability predicate. Gödel's Second Incompleteness Theorem is the special case where φ is taken to be ⊥. Since Con(T) is standardly defined as ¬□⊥, and ¬□⊥ is provably equivalent to □⊥ → ⊥, Löb's theorem tells us that if T ⊢ Con(T), then T ⊢ ⊥ — that is, T is inconsistent. Contrapositively, a consistent T can never prove its own consistency, which is exactly Gödel's theorem.

(b) The same mechanism blocks the naive self-trust scheme. If A wants to certify once and for all that any action its successor A′ proves safe (in the identical system T) really is safe, A is trying to establish T ⊢ □Safe(φ) → Safe(φ) for arbitrary φ, which is precisely the antecedent of Löb's theorem. By Löb's theorem, T could only prove this for actions it can already prove safe directly — so the "certification" would already have to contain a direct proof of safety for every action it covers, which defeats the entire purpose of delegating judgment to a successor that reasons the same way A does. A cannot grant blanket trust to a same-strength copy of itself.

Yudkowsky and Herreshoff, who first formalized this obstacle, show that the fix is to give the successor a strictly stronger proof system than the predecessor's: a weaker system can safely defer to a more powerful offspring built on top of it, since the extra power in the successor is exactly what lets it settle cases the predecessor could not decide on its own, and the escalation guarantees there is no vicious self-reference for the predecessor to run into. What this shows, though, is that a fixed proof system can never certify a successor at its own level of power, and since this escalation cannot go on forever within a single bounded formal system, no proof-based agent can ultimately certify any successor as trustworthy once and for all — a serious, still-open difficulty for the whole idea of safely self-improving AI, not merely a technicality about same-strength copies.
