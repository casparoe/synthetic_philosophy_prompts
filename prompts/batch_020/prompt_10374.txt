And here's the students answer, copied exactly:

"(a) For a fixed universal prefix machine U, K(x) is the length of the shortest program p with U(p) = x, and the universal prior is M(x) = Σ 2^-|p| over all p with U(p) = x. Because that sum is dominated by the shortest programs, strings with short programs get exponentially more weight than ones that only have long, ad hoc programs computing them — which is Occam's razor: simpler explanations of the data get higher prior probability. Concretely, induction with M works by looking at all the programs consistent with the data seen so far, taking the single shortest one, and using that program to generate the prediction for what comes next; as more data arrives this shortest consistent hypothesis gets revised. So it's really an idealized, fully Bayesian version of minimum description length learning. M is called "universal" because it multiplicatively dominates every other lower-semicomputable semimeasure, so no simplicity-weighted prior can beat it by more than a constant factor in the long run.

(b) The invariance theorem says that for any two universal machines U1 and U2 there's a constant c, independent of x, such that |K_U1(x) - K_U2(x)| ≤ c for every x. Since c doesn't depend on the string in question, this shows the machine-relativity of K is only superficial — whichever universal machine you build your complexity measure on, you get the same complexity ordering of hypotheses up to a fixed correction, so K gives us a genuinely observer-independent, objective notion of simplicity rather than one that's an artifact of some arbitrary choice of Turing machine.

(c) Neither K nor M is computable — computing either exactly would mean solving the halting problem, since you can never be sure you've found the shortest program. K is upper semicomputable (approximable from above) and M is lower semicomputable (approximable from below). So Solomonoff induction can only ever be approximated, never literally implemented; it's best understood as a normative ideal that things like MDL approximate, which is fine, since it still gives us, in principle, a solution to Hume's problem about why induction is justified."
