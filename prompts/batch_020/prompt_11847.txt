"Bell's argument begins from the EPR thought experiment: two particles are prepared in an entangled (singlet) state and then separated. If the same property is measured on both particles, the results are perfectly (anti-)correlated every time. EPR argued that, assuming no faster-than-light influences (locality) and assuming that measurement reveals a pre-existing property rather than creating it, this perfect correlation can only be explained if each particle already carries a definite value for every possible measurement, fixed by some hidden state λ set at the source. Since ordinary quantum mechanics assigns no such definite values before measurement, EPR concluded that quantum mechanics is an incomplete description of reality, and that a hidden variable completion is needed to restore both locality and realism.

Bell then turned "locality" into a precise condition on any candidate hidden variable theory, usually called factorizability: given the complete state λ and the local settings a and b chosen by the two experimenters, the joint probability of the outcomes A and B has to factor as P(A,B|a,b,λ) = P(A|a,λ)·P(B|b,λ). In words, once λ is fixed, whatever happens on Alice's side can depend on her own setting a but not on Bob's distant setting b or his result, and vice versa.

From that assumption, plus the reasonable "no-conspiracy" premise that λ is statistically independent of which settings get chosen, Bell derived an inequality that any local theory has to satisfy. The cleanest version is the CHSH inequality: for expectation values E(a,b) of the product of the two outcomes, |E(a,b) - E(a,b') + E(a',b) + E(a',b')| ≤ 2 for any local theory. Quantum mechanics, applied to a singlet pair with the right four angles, predicts 2√2 for that same combination, comfortably above the local bound, and that's exactly what's found in the lab, going back to Aspect's 1982 experiments with time-varying analyzers, which closed the last remaining loopholes from earlier tests.

So the upshot is that no factorizable theory can match the quantum predictions -- locality, in this precise sense, has to go. A natural move at this point is to ask whether the real culprit is locality or the determinism that's smuggled into the EPR step, since EPR's move from "perfect correlation plus locality" to "the outcome must already be fixed by λ" is a substantive extra assumption. If instead λ only fixes probabilities for each outcome, rather than the outcomes themselves, then Alice's result is a genuine matter of chance rather than something reaching across space to affect Bob -- so this sort of indeterministic, merely statistical common cause looks like it should let us keep locality even after Bell. On this reading, what Bell's theorem really rules out is local determinism specifically, and stochastic hidden variables remain a live option for anyone who wants to hang onto locality."
