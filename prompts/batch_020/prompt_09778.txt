So I've been chewing on an idea for a couple weeks that I want to eventually turn into an ACX-adjacent blog post (or at least a decent comment-section rant), but before I embarass myself further I want someone to actually poke at the argument. Backstory: I got into a whole thing with a friend over Discord about the Doomsday Argument, which sent me back to Bostrom's anthropic stuff, which reminded me of Hajek's old paper -- "The Reference Class Problem Is Your Problem Too," if I'm remembering the title right -- arguing that the reference class problem isnt just a frequentist headache, it actually infects basically every theory of probability once you look closely. My friend's position was "sure, picking a reference class is arbitrary if you're a frequentist, but Bayesians dodge the whole mess because credence is just about your actual degrees of belief, not about frequencies in some class you have to justify picking first." I think that's basically wrong and want to argue for why.

Here's the argument, roughly, in note form: even a committed subjective Bayesian has to decide how to weight statistical evidence when updating (base rates, test results, whatever), and the moment you use a base rate to inform a credence you're implicitly answering "which population is this particular case a member of, for purposes of extracting the frequency I'm going to anchor on" -- which just is the reference class question wearing a Bayesian hat. The same move shows up even more nakedly in anthropic reasoning: the Self-Sampling Assumption requires you to fix a reference class of observers before you can compute anything at all, and different equally-defensible choices (all humans? all observers? all observers who've specifically thought about the Doomsday Argument?) generate wildly different "probabilities of doom," with nobody offering a principled way to pick the right one -- Reichenbach's old fallback of using the "narrowest class with reliable statistics" doesn't save frequentism here either, it's just as hand-wavy. So my claim is that the whole SSA-vs-SIA fight, and the presumptuous philosopher case that's used against SIA, is really just the reference class problem wearing a cosmology costume, and no amount of formal machinery papers over the fact that "reference class" is doing all the load-bearing philosophical work while being totally unconstrained by the theory itself.

Does this actually hold up, or is there an obvious Bayesian comeback I'm missing? I'd also love a sanity check on whether the Hajek connection is apt or if I'm stretching a metaphor past its breaking point, and whether there's a tighter way to make the anthropics point without re-explaining SSA/SIA from scratch (my imagined readers are pretty LW-literate so I don't want to bore them, but I also don't want to assume too much). Comment on it like you'd comment on a draft you actually respected -- point by point is way more useful than "looks good," I'd rather know exactly where it's shaky.
