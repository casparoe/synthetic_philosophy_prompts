so a while back I fell down a rabbit hole reading about the St Petersburg paradox and ended up at this weirder cousin of it, the Pasadena paradox. setup: flip a fair coin till it first lands heads, on toss n. if n is odd you WIN 2^n/n dollars, if n is even you PAY 2^n/n dollars. summed in the order the tosses happen, that's 1 - 1/2 + 1/3 - 1/4 ..., which settles down to ln(2), about 69 cents. but that sum is only "conditionally" convergent (its the alternating harmonic series), so apparently you can rearrange the very same terms to total any number you want, or blow up to infinity, or nothing. the guy who came up with it has this bit about writing each payoff on its own card and dropping the stack so it reshuffles - same game, same cards, just a different order - meant to show the toss-order was never actually privileged to begin with. theres also a second game, altadena, thats identical except every payout is a dollar higher, so it should obviously just be the better game no matter what happens - except since neither game has a well defined expected value, apparently nobody can actually explain why using expected value theory. that last bit breaks my brain a little.

could you write me a dialogue between two decision theorists who both know this stuff cold, arguing about what to make of it. one thinks it shows expected value is genuinely broken as a general way to compare risky options, and that we need to restrict it or replace it with something else. the other thinks the whole thing is basically a sleight of hand - that theres nothing wrong with just using the order the coin flips actually happen in to define the expectation, so the fair price really is ln(2), and altadena coming out a dollar ahead falls right out of that too. neither one should be a pushover for the other - i want them actually engaging with each others strongest arguments (including the card-shuffling thing), not just repeating themselves.
