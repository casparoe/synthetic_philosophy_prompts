Me and a couple of coursemates have been tinkering with a small 'ethical governor' for an autonomous delivery robot — basically a rule engine that is supposed to stop the thing doing anything egregious. A friend on the same machine ethics module showed us an arguement he wrote for a seminar, and it's been bugging me because the conclusion seems absurd. He gave it in six steps:

(1) Any rule we can actually program a machine with must be finitely specified and unambiguous — so a moral machine can only ever follow a finite rule, or a finite set of rules. (2) But every substantive moral rule you can state in finite form has at least one situation where following it as stated would be clearly wrong: 'never lie' goes wrong when a lie keeps someone from finding a person who is hiding, 'minimise harm' would have us carve up an innocent person in a transplant-type case, 'always obey the owner' goes wrong when the owner is drunk and orders the robot to drive them home, and so on. (3) Therefore, for any finite set of rules the machine is given, there is some possible situation in which at least one of those rules points to a clearly wrong act — unless some other rule in the set happens to override it. (4) But an override is just a further rule about exceptions, and by (2) that further rule has its own counterexample cases, which need exception-rules of their own, and so on forever. (5) No finite machine can store or run an infinite chain of exception rules. (6) So every finite, non-vacuous rule engine either produces clearly wrong behaviour in some possible situation or collapses into an infinite regress — which means no machine can be made to act rightly in general, and machine ethics is impossible in principle.

I obviously don't want to accept that. We've built toy systems that behave fine over a bounded range of cases, and 'impossible in principle' seems far too strong. My instinct is to reject (4): I suspect it assumes the only way to handle an exception is to add another rule of the same sort. But I can't say whether the suspicion is right, or what a finitely specified decision procedure would have to look like to escape the regress, and I'd like to know what I'm paying if I go that route. Where does this go wrong, if it does? If it doesn't, which premise is the least costly to give up? And please write your answer in British English.
