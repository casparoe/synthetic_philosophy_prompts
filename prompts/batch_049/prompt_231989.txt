Build a scenario where counterpart theory and transworld identity diverge on the truth value of a single de re modal sentence about an ordinary inanimate object — a tool, a machine, a bench, a boat, whatever. Not the other way around, and not "it depends which counterpart relation you pick" — set the scenario up so that on the counterpart relation most natural to the case, counterpart theory gives a flat false. The divergence has to come from the structure of the case, in particular how cross-world sameness gets fixed and what the object is like in the target world, not from either theory being allowed to stipulate its verdict or quietly change the subject.

Constraints: the scenario itself is one paragraph; ordinary objects only, no persons, no souls, no sci-fi (no duplicate-earth physics, no split brains, no time travel, no demons); and the difference between the actual object and the target-world version should be the kind of drastic-but-possible change that a normal person would still call possible. If anything, the case should be one where "same object across worlds" is pretheoretically compelling, so the counterpart theorist is biting a bullet rather than exploiting a weird stipulation.
