A lot of what we read seems to just identify reward with valence, so negative reward means pain, positive reward means pleasure, and that settles it. I want to push back but I cant make the argument tight on my own. Please argue for the following position: the sign of the training reward is basically the wrong place to look. What matters is whether the agent has an internal evaluation that can get worse relative to what it expected — something like a learned value function that can drop, or a negative prediction error — and whether that state drives avoidance behaviour in a systematic way. So an obstacle-avoidance robot trained with -1 on collision probably isn't suffering in any interesting sense, while a resource-management agent trained only with positive rewards for completed tasks could still be in something like distress when its expected value suddenly drops.
