I keep running into a move in decision puzzles that I don't have a name for. You're stuck in a one-shot, no-communication game with a stranger: if you both press the cooperative button you each get $10, if one defects and the other cooperates the defector gets $15 and the other guy gets nothing, and if both defect you each get $1. The usual decision logic says defect, since defecting beats cooperating no matter what the other person does. But some people reason like this: the other player is in exactly my situation and will run exactly the same reasoning I do, so whatever I conclude, they'll conclude too—therefore I should pick the button I'd want both of us to pick. Somtimes this feels obviously right to me, and other times it feels like magical thinking dressed up as logic. Is there an established name for that move, and more importantly, how do you draw the line between the cases where it is a legitimate inference and the cases where it isnt? I'm not just after a label—I want to know what would have to be true about the two players and the situation for the move to work, and what makes it different from just assuming reciprocity that was never promised.
