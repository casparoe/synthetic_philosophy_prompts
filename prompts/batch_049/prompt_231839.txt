Every so often I try to write down my actual positions on future contingents to see if the whole thing type-checks, and I suspect something's off but I can't locate the type error. Here's the set:

1. Classical bivalence, no exceptions. "There will be a sea battle tomorrow" is either true or false now, even if neither we nor the universe has "decided" yet. Truth values aren't made true by anyone's knowledge.
2. I don't think 1 commits me to fatalism. The move from "it was true all along that p" to "p couldn't have been otherwise" has always looked like a modal scope error: truth is about which propositions latch onto the world, not a force that pushes events around.
3. Truthmaker maximalism for contingent propositions: every true contingent claim has something in the world—a fact, state of affairs, whatever—that makes it true and that would be absent if it were false. I basically think this is just what truth means for the contingent.
4. But at least some future contingents are genuinely open. For a genuinely indeterministic event (a radium atom decaying in the next minute, maybe a free choice), there is currently no fact of the matter. A Laplace-type intelligence with complete knowledge of the present state and all the laws could still not know it, because there is nothing there to know. Not ignorance: absence of fact.
5. I can't take the usual Aristotle-inspired way out. Making future contingent sentences "neither true nor false" seems to cost me bivalence and mess up reasoning about the future more than saving the open future is worth.
6. I'm a compatibilist about free will anyway, so the open future in 4 isn't doing moral work for me; it's doing some other metaphysical job I want it for.

Run the consistency check. Which pairs are actually in tension, which only look like they are, and how severe are the real ones? Rank them. For each real tension, tell me what the cheapest fix is and which of these six it would force me to weaken. I have no prior about which bullet is the problem, so don't assume I'm trying to preserve any particular one.
