I recently found myself working with a small classification dataset — only a handful of examples per class — and it has left me thinking hard about how concepts can be induced from so few instances. The purest version of the problem seems to me to be a Bongard problem: a puzzle in which the solver is shown two sets of six simple line drawings and must find the rule that separates the set on the left from the set on the right, so that new drawings can be classified correctly. What unsettles me is that after seeing only twelve examples there are, in principle, indefinitely many rules consistent with what has been shown, yet competent solvers usually converge on the intended one.

I would like you to argue for the following position: any system that can reliably solve novel Bongard problems from a small number of examples must be doing so with the help of a substantive inductive bias — a prior over which kinds of rules are plausible — and the examples do not by themselves determine the concept; at most they select among hypotheses the learner was already disposed to take seriously. Please make the argument as sharp as you can, and address the natural objection that a sufficiently flexible, unbiased learner could simply read the rule off the examples.
