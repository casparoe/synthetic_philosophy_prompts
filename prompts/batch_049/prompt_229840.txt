Suppose we're trying to build an "impact measure" — a way to penalize an RL agent for how much it changes the world outside the task it was given, so a paperclip maximizer doesn't get there by first building trillions of tiny servo motors, or whatever. I keep seeing people talk about this as if it's one ingredient in a corrigibility stack, but I can't find a clean statement of what the measure actually has to deliver. So: write the desiderata a theory of low-impact AI has to meet. Try to separate the real requirements from the stuff one camp happens to want.

For each requirement give the motivation (which failure it's supposed to prevent) and a one-line case where dropping it goes wrong. Then mark which are non-negotiable and which are more like implementation preferences. I specifically want flags on any subset that's jointly unsatisfiable — my hunch is that "doesn't assume a full specification of human values", "resists being gamed by a smarter optimizer", and "doesn't just degenerate into doing nothing" can't all live in the same tidy formalism, but I want to see the argument for the actual trilemma or get shown the loophole.

Some cases the list has to make sense of, not wave at: a robot told to move a box from A to B (almost any real policy changes heat, airflow, chair positions, so what's the baseline and in what metric does "change" get measured?); the butterfly-effect worry that in a chaotic world every action has huge long-term consequences, so naive state-distance says everything is max-impact; an agent that, instead of changing the physical world, changes the ontology or world-model the impact term is computed over; and whether "impact" and "harm" are supposed to come apart — should benign extra changes be penalized too, and if your answer depends on already having a value function, say so, because that sounds like it could make the whole notion circular.

Keep it usable by someone who hasn't memorized the AUP vs relative reachability literature — mention them if it helps, but the requirements list is the thing I actually want. And dont worry about spelling.
