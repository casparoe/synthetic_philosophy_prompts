Okay, I'm workshopping a short essay and I want you to go after it. Its on consciousness as a user illusion — the interface-metaphor thing, where desktop icons and the trash can are a convenient fiction that hides what the machine is really doing, and then the claim that phenomenal experience is like that. Standard stuff, I know, but I'm trying to push it somewhere less trodden and I need a hostile reader.

Here's the draft, roughly as it stands:

---

The usual reading of the user-illusion metaphor goes like this: the desktop, the cursor, the trash can — none of them exist in the machine. They're a friendly rendering laid over the actual computation, and phenomenal consciousness is the same kind of thing: a friendly rendering laid over the brain's actual goings-on, useful for the organism but not tracking any real property. Call this representational illusionism. The illusion is an error — we represent ourselves as having phenomenal properties, and we're wrong.

I want to argue the metaphor actually supports a different and better view, which I'll call interface illusionism. The desktop is not a false picture of the disk. It's not a picture of the disk at all. It's a set of affordances — drag, drop, double-click — and asking which real thing the trash can represents is a category mistake, like asking which real thing the Undo menu represents. The trash can is a format, not a representation. My claim: phenomenal consciousness is the format in which the brain's self-model is made available to the system that uses it, and it no more misrepresents the brain than the desktop misrepresents the disk. So illusionism should drop the language of error and adopt the language of interface. The illusion isn't that we're representing something that isn't there; it's that we mistake the rendering layer for the thing rendered.

Two payoffs, then the worry. Payoff one: interface illusionism dodges the illusion-of-illusionism objection — the complaint that you can't deny phenomenal properties without leaning on the very phenomenal seemings you're denying. If consciousness is a format rather than a claim, nothing is being asserted that could be false, so there are no seemings to be had or denied; there's only a rendering. Payoff two: it explains why the illusion is undetectable from the inside — you can't see the interface as an interface from within the interface, same as you can't see the desktop as pixels from the desktop.

The worry: an interface needs a user. The desktop metaphor presupposes someone sitting at the machine, and if consciousness is the interface, I owe an account of the user that isn't just a homunculus in the brain. My move is to say the user is the self-model itself — the same model, read at a different level — but I can feel this turning into either a regress or a pun, and I can't tell which. That's the part I most want comments on.
