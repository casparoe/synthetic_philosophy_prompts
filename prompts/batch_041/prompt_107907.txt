I read a lot of math-adjacent stuff at night (software guy, not a mathematician) and theres a pattern I keep running into that I dont have a word for.

Everyone says we can't prove the basic rules of arithmetic are consistent from the inside — the second incompleteness theorem, if I'm remembering the name right. So what people actually lean on instead is that nobody has ever gotten a contradiction out of those rules, and that the best people have been trying for about a century. When you point out that this proves nothing, the reply is always some version of: true, but it's the only kind of evidence available, and anyway if there were a contradiction it might take ten million symbols to write down, so no human would ever find it.

That last bit is what bugs me, because it cuts both ways. If the contradictions, should there be any, are the ones too long for anyone to ever find, then our not finding one isn't telling us the rules are sound — it's telling us something about how long the proofs we can write are. And I see the same shape elsewhere: a conjecture is probably true because it's been checked up to some enormous number; a cryptographic assumption is safe because nobody has broken it; a logic is fine because nobody has gotten a paradox out of it.

So is there a name for this kind of inference — the failure of a search used as evidence about the thing searched? I know the line about absence of evidence, but that doesn't seem like the whole story, because the search clearly has some power. What I actually want is the carving, not a label: what the nearest established ideas are, how each of them differs from what I'm describing, when this inference is respectable and when it's question-begging. And if nothing in the literature fits this exact move, coin something and tell me where its edges are.
