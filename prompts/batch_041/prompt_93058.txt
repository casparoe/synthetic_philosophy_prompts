Two friends of mine, Alex and Jordan, got into an argument about a game they had read about. The game is this: a fair coin is flipped until it lands heads; if it first lands heads on the nth flip, you receive a payoff of (−1)^n 2^n / n dollars. Alex says the game has no well-defined expected value, because the series is conditionally convergent and the Riemann rearrangement theorem lets you reorder the payoffs to get any sum you like, so there is no fact of the matter about what the game is worth. Jordan says that is a mathematical trick: the flips have a natural order, and if you sum in that order the expected value is −ln 2, so the game is clearly a bad bet and the alleged paradox is just a failure to specify the order. Alex replies that the natural order is arbitrary; the game specifies a probability distribution over outcomes, not a privileged summation order, and if different orders give different answers then the expected value is undefined. Jordan says the expected value is defined as the limit of the partial sums in the order the outcomes occur, which is well-defined; Alex says that is just one convention among many. They then shift to whether it matters: Jordan says that even if the expected value is undefined, a rational agent with a bounded utility function would have a well-defined expected utility, so the game is not a counterexample to decision theory. Alex says that changes the subject, and that the puzzle shows expected value is not always a determinate guide to choice. They have asked me to adjudicate. Please go through their exchange point by point: who is right about whether the expected value is undefined, whether the natural order is privileged, whether the expected-value question is separable from the expected-utility question, and what each of them is missing.
