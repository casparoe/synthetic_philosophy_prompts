I'm a novelist drafting a courtroom scene, and I need the exchange between two expert witnesses to be a genuine disagreement rather than a misunderstanding. Both are equally competent and accept the same base rates, the same study, and the same causal story about a single named plaintiff; what divides them is what probability, if any, attaches to his case. Put the reference class problem at the center of the scene. The first witness holds that the individual case has one correct reference class, fixed by its causal structure — the class of cases differing from this one only in respects that do not matter to the outcome — and that our failure to identify it is an epistemic shortfall, not proof that it does not exist. The second holds that any property of the case defines a class, that any rule for choosing among classes is itself such a property, and that the resulting regress halts only at a privilege granted for the sake of deciding, so the number is relative to a model and a use rather than discovered. Give them several rounds, each pressing the other's weakest point: the first must say how we could ever know we had the right class, the second why we should trust a figure whose class we admit we chose. Let the narrow class in this case be small and unstable and the wide one stable, so neither can fall back on always preferring the narrowest class for which there is data. Keep it dramatic: the disagreement has to live in the lines rather than in a narrator explaining it. Do not resolve it.
