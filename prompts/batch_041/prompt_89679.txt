At a workshop on low-impact AI, two participants, Mira and Jonah, became stuck in an argument about a proposed definition of side effects. Mira defends the following proposal: for an agent whose task is specified as a set of goal predicates, a side effect is any change in the environment that is not necessary for satisfying those predicates. The workshop had also suggested making the definition measurable by scoring changes in a fixed feature space chosen by the designer. Mira says this shows that side effects can be defined without a full specification of value: the agent needs only the task predicates and the feature space, and then it minimizes unintended changes. Jonah says the feature space and the necessity relation already smuggle in value judgments: which changes count as relevant, which are necessary, and what counts as the same environment. Their exchange went as follows.

(1) Mira: A side effect is any environmental change not necessary for satisfying the task predicates. Since the task predicates come from the user, the agent does not need a full value function; it needs only the task.

(2) Jonah: Necessity is plan-relative. If the only plan the agent can find moves a chair, then moving the chair is necessary for that plan. But we would still call it a side effect if the agent could have gone around. So necessity cannot be read off the goal alone.

(3) Mira: Then define necessity relative to the goal: a change is necessary if every plan that satisfies the goal produces it. That is not plan-relative.

(4) Jonah: That is too strong. Almost every change is avoidable by some logically possible plan, so almost everything becomes a side effect, including the agent’s own footsteps. And if no feasible plan avoids breaking the vase, your definition says breaking it is not a side effect, which seems wrong. You need a notion of feasible plan, and feasibility is already evaluative or at least interest-relative.

(5) Mira: We can use a counterfactual baseline: a side effect is a difference between the actual trajectory and the trajectory that would have occurred had the agent done nothing.

(6) Jonah: Inaction is not a single counterfactual. Doing nothing is itself a choice with consequences, and the baseline changes depending on what we hold fixed. Choosing the status quo as the baseline privileges existing arrangements. If the status quo is harmful, avoiding deviations from it preserves harm.

(7) Mira: The agent can minimize deviations from the status quo without knowing which state is better. That gives a value-free impact measure: stay close to how things were.

(8) Jonah: Staying close is conservatism, and conservatism is a value. It also conflates physical magnitude with moral importance: moving a pen and moving a person are both deviations, but only one is a side effect in the morally relevant sense. To rank them, you need a value specification, or at least a proxy for one.

(9) Mira: Then add a feature space weighted by task relevance. The designer chooses features, not values. The agent minimizes weighted deviations only in features that matter to the task.

(10) Jonah: Choosing which features matter, how to weight them, and what counts as a relevant change is already a partial value specification. So your view is not that no value specification is needed; it is that a partial one suffices. That may be true, but it is not the strong claim you started with.

(11) Mira: We can avoid all of this by defining side effects as irreversible changes, where reversibility is a physical fact about the environment.

(12) Jonah: Reversibility is not a physical fact; it is relative to an agent’s capabilities and to how much we care about restoring the state. A broken vase can be glued, at a cost; whether that counts as reversible depends on the value of the cost. Also, some reversible changes are terrible and some irreversible changes are trivial. So reversibility does not track side-effecthood without a value weighting.

Please adjudicate this exchange move by move. For each numbered move, say whether it is clearly mistaken, overstated, defensible, or clearly right, and justify the rating in a few sentences. Then answer the underlying question directly: can avoiding side effects be defined without a full specification of value? If yes, state the precise sense in which that is so and what it costs; if no, state what minimal value specification is required. Finally, identify what both Mira and Jonah are missing, especially any distinction between a descriptive notion of a side effect and a normative notion, or between defining side effects and ranking them.
