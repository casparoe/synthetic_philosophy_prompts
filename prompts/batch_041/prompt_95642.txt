ok so I keep running into the Pasadena game and I want the spec before I read anyone's fix for it. Here it is in case you don't have it memorized (I'd rather you work from this than half-remember it): flip a fair coin until the first heads. If heads lands on flip n you win (-1)^(n-1) times 2^n over n dollars, so the payoffs go 2, -2, 2.66..., -4, ... as n goes 1, 2, 3, 4. Do the expectation in the obvious order and you get 1 - 1/2 + 1/3 - 1/4 + ... = ln 2, but that series only converges conditionally, so reorder the terms and you can make the sum anything at all, from -infinity to +infinity. No order-independent expectation -- supposed to be worse than St. Petersburg, where at least the sum blows up to +infinity and you can call the value infinite. Now add a dollar to every payoff: that's the Altadena game, strictly better then Pasadena in every state of the world, but if Pasadena has no expectation then neither does Altadena, and plain expected utility theory just shrugs at both.

So write me the desiderata for a theory of rational choice under expectations that don't exist. What it has to decide (these games, mixtures of them), what it can't give up (dominance, agreeing with expected utility wherever the expectation is well-behaved, whether the value may depend on the order we add the terms up), the Dutch-book and money-pump constraints, each with the case or consideration that makes it a requirement rather than a taste. Mark what's non-negotiable and what's just one camp's prejudice, and name the subset you think can't all be satisfied at once -- if there is one, the list itself is the result. Don't hedge on this: tell me which requirement you'd sacrifice and why, and which single requirement rules out the most theories on offer.
