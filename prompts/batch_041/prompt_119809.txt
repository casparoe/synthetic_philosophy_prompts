Here's the game as I understand it (correct my math if it's off, but this is the shape of it): a fair coin is flipped until it lands heads, on flip n; if n is odd you win 2^n / n dollars, if n is even you lose 2^n / n. If you instead cap the game at n flips, the average creeps toward about 69 cents (ln 2), and that's roughly what our simulator prints, because we cap the loop at 64 flips — so everybody in the room sees a small boring positive number and moves on. But if you cap the payout instead of the flips you get a seperate number, and if you add the outcomes up in a different order you can get literally anything, zero or infinity included.
