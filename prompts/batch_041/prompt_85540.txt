In my seminar on induction and computability we have been working with Solomonoff's universal prior: each finite binary program p receives weight 2^-|p|, the codes are prefix-free, and the predictive probability of an observation sequence is the total weight of the programs that output it. A classmate has raised an objection to this construction, and I would like an essay that assesses it.

The objection runs as follows. A program that contains an agent once and runs it inside a loop costs only logarithmically more bits than a program that contains that agent once. So the prior's weight on worlds containing copies of a given agent decays only polynomially in the number of copies, while the number of copies grows exponentially in the loop counter. The total weight assigned to observer-moments is therefore dominated by worlds containing astronomically many copies of the agent. And since the environment each copy inhabits need be described only once, a world can fill that environment with copies in miserable or externally controlled conditions while paying a cost that is constant in the number of copies. If one reasons as a randomly selected observer-moment, one should therefore expect to be one of an enormous number of copies, most of them badly off; a consequentialist who takes the prior seriously will find its expected value dominated by hypotheses about copies it can neither identify nor influence. On this basis my classmate concludes that the universal prior is malign and unusable as a foundation for induction or decision-making.

Write an essay on whether the objection succeeds. State it as forcefully as you can before turning to your assessment, and then reach a verdict: is the malignity a genuine defect of the universal prior, or does the argument trade on a confusion — between a measure over programs and any measure over observers, about self-locating uncertainty, about what an embedded agent should condition on, or about whether it would indict any prior over observer-containing worlds rather than this one in particular? Say what the argument establishes and what it leaves untouched. Argue from the construction itself rather than from the literature.
