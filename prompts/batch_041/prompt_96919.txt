ok I've been chewing on the Aunt Hillary / ant colony thing for a seminar and I want to write down where I actually stand before someone pokes at it. Here's the pile:

1. I'm a functionalist. Mental states are defined by their causal role, not by what they're made of. Multiple realizability all the way down — neurons, silicon, whatever; if the organization is right, you get the mind.

2. I'm not an instrumentalist though. I don't think it's enough to say the colony acts as if it beleives there's food over there. For a state to be a genuine representation it has to be the kind of thing that can be wrong, and the error has to belong to the system — the system is the one getting it wrong, not me, the observer, deciding from outside that it's wrong.

3. I made up a rule for myself and I'm not sure it's legit: a genuine subject has to be unpartitionable in the following sense — you shouldn't be able to cut the thing into two pieces and have each piece keep doing everything the whole was doing. If you can, then the mind was never one thing, it was just a crowd doing a job. Call it the no-clean-cut condition.

4. A single ant has no mental life to speak of. I'm happy to say there's nothing it's like to be one.

5. The colony, though, looks deliberate. It adjusts, it recovers, it decides to send more foragers. I'll predict it with belief-desire talk all day, but I think that's a tool, not a commitment.

6. And I do think consciousness needs there to be something it's like — a single unified point of view, not just alot of processing happening in the vicinity.

What I want from you: which of these actually pull against each other, which ones only look like they do, and rank the real ones by how bad they are. For each genuine tension, what's the cheapest thing that would have to give, and what do I lose by giving it? Then tell me the single revision that would clean up the most. I honestly can't tell if this is a stable package or a mess, so don't just reassure me that it all fits. Please answer in American English.
