So before i read anything else: whats the spec? Like, what does any theory of how names work have to be able to do before its any good. i want the list of requirements -- the cases it has to get right, the distinctions it's not allowed to mush together, the stuff it can't contradict -- and for each one the case or the reason behind it, not just the label.

Cases i keep running into, so please say what a theory owes each of them:
- two names for the same person or thing that someone can learn seperately and then be genuinely surprised by, like finding out the morning star and the evening star are the same thing
- a name that doesn't name anything (Santa, a made up character), plus sentences like "Santa isn't real" that seem true and meaningful
- the same name attached to two different people
- swapping one name for another name for the same person inside "she believes that..." -- apparently this can flip whether the sentence is true, which seems to break the idea that co-referring names are interchangable
- someone whose name got attached to them because of stuff we believed about them that turned out to be false, or true of somebody else
- a name that still picks out the same person even when we imagine things going differently (if he'd never coached, he'd still be him)
- brand new sentences with names in them that nobody has ever said before, which we understand instantly

Then the part i actually care about: which of these requirements can't all hold at once? i have a feeling thats where the real fight is, and i want to know which combos are impossible instead of just hearing that theories "differ".
