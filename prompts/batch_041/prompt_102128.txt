Question: Explain the difference between finkish and masked dispositions. Does the existence of masked dispositions refute the simple conditional analysis of dispositions — the claim that for something to be disposed to M when C is just for it to be the case that if C, then M?

Student's answer: A finkish disposition is one that is destroyed by the very event that would trigger it. The standard example is a wire that is live — disposed to conduct electricity when touched — but rigged up to a device that cuts the current the instant a conductor touches it. Before the trigger the wire is genuinely live, yet it would not conduct if touched, so the simple conditional analysis is false: the wire is disposed to conduct, but "if touched, it would conduct" comes out false. One stock reply is to add a ceteris paribus clause — "if C, and nothing interferes, then M" — but that looks circular, since "interferes" just means "prevents M", which is the very thing we were trying to analyse.

A masked disposition is different: the disposition is still there, but something stops it being exercised. Take a fragile glass wrapped in packing material. It is still fragile — fragility is a real property it has — but when you strike it, it does not break, because the packing stops it. So masking, unlike finking, does not involve losing the disposition.

Now, does masking refute the conditional analysis? I say no. In the masked case the disposition has gone missing at the moment of the trigger, so the counterfactual "if struck, it would break" is false for the same reason it is in the finkish case: there is no disposition left there to ground it. The conditional analysis is therefore only threatened by finks; masks are a distraction.
