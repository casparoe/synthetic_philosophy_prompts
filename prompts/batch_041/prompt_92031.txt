I'm a third-year undergraduate taking a decision theory course this term, and as part of the coursework each of us has to contribute one exam-style question, together with a model answer and a marking scheme, to the revision pack the class is compiling. I've been assigned the St. Petersburg paradox, which is awkward, because the version in our lecture notes — state the paradox, then explain the standard diminishing-marginal-utility resolution — is answerable by anyone who has memorised a single paragraph, and the point of the exercise is precisely that we should be able to tell who has actually thought about it. I'd like the question built on a variant that I think is genuinely harder, and I want the question to be self-contained: it should state the game in full rather than allude to a textbook formulation, since the pack is to be used closed-book.

The variant is this. A fair coin is flipped until it comes up heads; if the first head appears on the nth flip, the player wins 2^n pounds, except that the casino's liability is capped, so that the payout is min(2^n, M) pounds, where in the concrete case M = 2^20, roughly one million pounds. A single play is offered, for an entry fee paid up front out of the player's own finite wealth. I'd like the question to ask the candidate (a) to derive the expected monetary value of the capped game as a function of M and give its numerical value for M = 2^20; (b) to say what fee the expected-monetary-value rule licenses here, and how large the casino's bankroll would have to be for that rule to license a fee of fifty pounds; and (c) to judge whether the finite bankroll dissolves the paradox or merely relocates it, and, if the latter, to describe the residual puzzle once expected monetary value is replaced by expected utility of wealth. It should be doable in about forty-five minutes of a written paper. Please write the question itself in the register of a real exam paper, with the marks for each part indicated; then a model answer of roughly seven hundred words; then a marking scheme out of twenty-five that names the specific moves a first-class answer must make, allocates the marks across those moves, and gives one line each on the specific errors that should cost a candidate marks. A friend in my study group keeps insisting that the capped version is obviously fine because the expectation is now finite, and I suspect that is exactly the confusion the question ought to catch out, so the marking scheme should make it unmistakable how an answer that stops there differs from one that actually does the arithmetic. No citations or reading list, please — the pack is closed-book and the examiners will mark purely on the argument.
