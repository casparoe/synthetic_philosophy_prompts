I'm in a philosophy of biology reading group and I've been asked to write up my position on function and content so the others can take shots at it, and I want a dry run first. Here's roughly where I've landed, and I honestly don't know how much of it is one view and how much is just eight opinions in a trenchcoat.

(1) What a trait is for is fixed by the selection history that built it, and nothing else gets a vote. So there are reasons out there that nobody has ever had — the reason the heart is built the way it is, the reason the bee's dance has the shape it does, the reason a bacterium tumbles when it's heading down the sugar gradient. I've been calling these 'nobody's reasons,' since they explain why a thing does what it does without anyone representing them. (2) A signal only means something relative to a consumer, something that takes it in and uses it to steer, and there's no meaning sitting around unattached to a use like that. (3) I'm a deflationist about belief and desire talk — when I say the frog 'sees' a fly or the bee 'wants' the nectar I'm using a handy predictive idiom, not saying anything true or false apart from the idiom. (4) I do think the bacterium is doing something for a reason, but a reason-why and not a reason-for-which, the difference between the consideration that explains why the mechanism is there and the consideration the agent is moved by, and I think that line is sharp: only the second kind needs a reasoner behind it. (5) Learned behavior has functions too, though. A rat that's learned to press a lever is pressing it for the food; nothing ever selected lever-pressing, but I'd still say that's what the pressing is for, so I treat reinforcement as generating a middle grade of rationale between selection and content. (6) Function ascriptions are normative — a heart that's stopped pumping is a heart failing to do what hearts do. (7) But I'm a thoroughgoing naturalist: nature contains causes and probabilities, never norms. (8) And I don't think nature has sharp joints anywhere. Reasoner vs. non-reasoner, representation vs. mere information — wherever we draw those lines I think we're drawing them rather than finding them.

So is this a package or just a pile? Which of these genuinly pull against each other, which pairs only look like they do, and for the real ones what's the cheapest fix and what does it cost me — ordered by how bad it is. I'd rather not cut anything I don't have to, so be specific about which single commitment is doing the most damage.
