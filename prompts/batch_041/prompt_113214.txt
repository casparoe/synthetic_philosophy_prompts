A friend in my reading group who's into AI alignment stuff built the following argument to show that iterated amplification can never actually get you anywhere, and every premise looks fine to me but the conclusion can't be right, because if it were the whole research program would be a non-starter and smart people wouldn't be spending their careers on it. Here it is:

(1) Amplification works by taking a task the current system can't do well, decomposing it into subtasks, and having the current system do each subtask, with a human in the loop steering the decomposition. Then you train a copy of the system to imitate that whole process, and repeat.

(2) If there exists a decomposition of the hard task into subtasks that the current system can already handle, then the current system could in principle solve the hard task by searching over decompositions and executing the pieces, so the hard task was already within the current system's reach.

(3) If no such decomposition exists, there's nothing for amplification to train on and the process stalls.

(4) Either way, amplification never produces a capability the starting system didn't already have.

(5) Since competence can't be gained this way, alignment can't be gained either -- you'd just be distilling whatever the starting system already was, and if it was misaligned, so is the copy.

He says this is basically the "no free lunch" intuition made rigorous, and that it means amplification is either trivial or stuck.
