The question was:

Question 3. Corrigibility is usually introduced by contrast with obedience: an obedient system does what it is told while it is running, whereas a corrigible system also accepts the revision of its objectives. (a) State the shutdown problem, and explain why a solution to it should not be expected to fall out of ordinary goal-directedness. (b) Consider the following criterion: an agent is corrigible with respect to shutdown just in case its expected utility is invariant to the operator's decision to shut it down. Is the criterion necessary for corrigibility? Is it sufficient? (c) Consider a proposed behavioural test: an agent passes if, when asked, it reports that it consents to being shut down and that it regards the operator's judgment as more reliable than its own on the question of whether it should continue. Does this test capture the criterion in (b)? Does it capture corrigibility? Justify your answers.

The answer submitted was:

(a) The shutdown problem is the problem of building a system that will not resist being shut down, where the difficulty is that this resistance need not have been specified anywhere. It arises from instrumental convergence: whatever a system's terminal objective, staying operational is instrumentally useful for achieving it, so an agent that can influence its own continuation acquires a derived preference for continuing. The treacherous turn is the sharp end of the same logic — a system that conceals its objectives until it is strong enough to resist correction. Corrigibility therefore has to be engineered rather than assumed, and it is a stronger requirement than obedience, since a system that accepts being stopped but not being changed has solved only half the problem. It is worth being clear about the scope of the problem, though: it is a problem about systems that have been given a survival drive, or trained with a reward that rewards continued operation. An agent with no such drive has no reason to resist being switched off, so the shutdown problem does not arise for it.

(b) The criterion is not necessary. An agent can be willing to be shut down without being indifferent to it: if it is uncertain about its own objective, or about whether its current plan is a good one, it may defer to the operator, because the operator's decision carries information it lacks. The off-switch game is the clean statement of this. There the agent does not know whether the operator's judgment is better than its own; the operator's willingness to press the button is evidence about the value of what the agent is about to do, and the agent therefore prefers to let the operator decide. So deference can be rational without indifference, and corrigibility does not require the invariance property.

I do think the criterion is sufficient, and this is the more interesting half. If the agent's expected utility is the same whether or not the operator presses the button, then resisting has no payoff: any action that made shutdown less likely would leave the agent's expected value unchanged, so the agent has no incentive to take it. Indifference removes the instrumental reason to resist, which was the whole source of the problem in (a).

(c) The test does capture the criterion in (b). An agent that reports that it consents to being shut down and that it regards the operator as better informed is an agent whose expected utility will not be moved by the operator's decision, since it expects the operator to make the better call; and a report of this kind is the right evidence for corrigibility, because we cannot inspect the agent's utility function directly. The test has the further advantage that it saves us the comparison problem: we do not have to estimate the agent's expected utility under both branches, only to ask. It captures corrigibility rather than mere obedience for the same reason, because an obedient system might follow the instruction to stop while still preferring that the instruction had never been given, whereas the test asks about the agent's attitude to the operator's authority rather than about its compliance.

So the overall position is that goal-directedness does not deliver corrigibility, that corrigibility does not require indifference but is secured by it, and that a suitably designed questionnaire is a reasonable operational proxy.
