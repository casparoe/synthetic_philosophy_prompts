I'm an undergraduate in a philosophy of mind seminar, working on a paper about whether moral status can attach to computations rather than to physical stuff. I've built an argument that I can't tell whether to defend or dismantle, and I'd like you to diagnose it.

(1) A system has moral status only if it realizes a computation of a certain kind — a particular functional organization. (2) For any physical system and any computation, there is some way of mapping the system's states onto the computation's states under which the system realizes that computation. (3) So whether a system realizes a given computation is not an intrinsic feature of the system; it depends on a mapping we supply. (4) A thing's moral status must be an intrinsic feature of it. (5) Therefore no system has moral status in virtue of realizing a computation — or else every system does, down to a rock. (6) A rock plainly has no moral status. (7) So the functionalist premise (1) is false.

Each step looks defensible when I read it in isolation, yet the conclusion would sink any view on which what matters morally is what a system does rather than what it is made of, and I don't want to give that up. Which step should I reject, and what does rejecting it cost me? If I have to choose, I'd rather keep (1) and (4) than (5); I want to know what I'm buying.
