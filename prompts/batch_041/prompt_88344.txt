1. Marcus: the view has to say either that the higher-order representation is itself conscious or that it isn't. If it is, we've got a circle -- to explain what makes a state conscious we appeal to a state that's already conscious, so nothing gets explained. If it isn't, then we've explained consciousness by positing a second *unconscious* representation, and unconscious representations of a system's own internal states are cheap and everywhere. A system that keeps track of its own goings-on has not thereby become a subject of experience. So pick your poison: circularity or absurdity.

2. Devi: that's a false dilemma. The higher-order state doesn't need to be conscious, and the view isn't absurd because the higher-order state has to be the right kind of representation. It has to be non-inferential -- it registers the state directly rather than inferring "I'm in state X" from behaviour -- and it has to be poised for use: the system's downstream machinery has to actually consume it, so that the state becomes available to the system for reporting, deliberation, memory. That's the difference between a state being merely monitored and a state being *for* the subject. And anyway plenty of things get their nature from a relation to something that isn't of the same kind -- a signature isn't legally binding because it's a binding signature.

3. Marcus: fine, so now we've swapped a mystery for a checklist. If all it takes is a non-inferential, downstream-consumed representation of a first-order state, we should be able to build a conscious system out of parts. So let's try. Take any system with a first-order state and bolt on a monitor chip that non-inferentially registers that state, and wire the chip's output into the system's memory and action selection. Now take a second version: identical first-order state, identical monitor content, but the monitor's output is routed to a different consumer -- a logging subsystem that nobody ever reads. Which one is conscious? If you say the first, then whether something is conscious depends on where a wire goes, which is a fact about the furniture, not about the state. If you say both, then the logging system is conscious, and I can build a subject out of a thermostat and a printer.
