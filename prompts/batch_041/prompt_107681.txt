A post on a programming blog I follow recently explained Skolem's paradox, and before I repeat any of it I'd like a careful audit. My background is software engineering; I know first-order logic and model theory only to the extent a computer scientist picks them up, so I can follow the vocabulary but not tell where the writer has quietly cut a corner. The passage in question reads:

"Skolem's paradox is one of the strangest results in modern logic. By the downward Löwenheim–Skolem theorem, any consistent first-order theory with an infinite model has a model whose elements can be listed one by one. Set theory is a first-order theory, so if ZFC is consistent it has a countable model — a model in which every set is countable. But ZFC also proves Cantor's theorem, that the set of real numbers is uncountable. The same axioms therefore deliver both a countable and an uncountable real line, and the only way to keep the theory from contradicting itself is to concede that the model's real numbers are not the real ones: nearly all of the genuine reals lie outside the model, and the bijection that would witness the countability of the model's reals is simply too big to be an element of the model. The lesson is that countability is not an absolute property of a set at all, but a fact about the model you happen to be standing in — choose a different model and the same collection comes out countable or uncountable as you please. Cantor's theorem survives only as a claim about what a formal system can prove, not about the size of anything in particular, and Skolem's own verdict was that set theory cannot be about a fixed universe of sets, since its subject matter is relative to whichever axiomatization we choose. Nor is this peculiar to set theory: no first-order axiomatization can pin down the real numbers, so the reals delivered by any axiom system are at best a useful fiction."

Please go claim by claim. Which statements a working logician would endorse as written, which are legitimate simplifications of something true, which are contested philosophical readings presented as though they were established results, and which are straightforwardly mistaken — and in particular, does the closing claim that the real numbers are a useful fiction follow from anything true in the passage, or is it drawing a conclusion the theorem never licensed?
