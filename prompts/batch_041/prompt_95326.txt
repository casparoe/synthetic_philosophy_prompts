ok, I'm trying to get my view on the "brain as computer" thing straight before a seminar and I keep going in circles. Here's where I've landed — tell me if it actually hangs together.

1. The brain computes. Literally, in the same sense a laptop does, not as a metaphor for "processes information somehow."
2. Which computation a system implements isn't a bare physical fact. If you're allowed to pick the mapping between physical states and computational states freely, you can read almost any finite-state computation off almost any system. So "S computes F" is always relative to a description someone brings. I don't want to end up a pancomputationalist, obviously.
3. The description isn't free, though. For a real implementation the system's own causal structure has to mirror the formal structure — the internal states have to be caused by the right inputs, the transitions have to survive counterfactual messing with the inputs, and the states doing the mirroring have to be the system's real states, the ones its causal powers are organised around, not ones we define ad hoc to make the mirroring come out. So causal facts constrain implementation, not our convenience.
4. Computational explanation in cognitive science is just a species of mechanistic explanation: you explain a capacity by finding the mechanism that produces it. The computational vocabulary only earns its keep by latching onto actual causal machinery.
5. Multiple realizability: the same computation runs on different hardware, so the computational level is autonomous — you can't read it off the physics and you can't reduce it away.
6. And yet a system with a big lookup table — every possible input state wired straight to the stored output for it — dosen't compute the function. It's got the answers in it. That's storage, not computation. Same for a network whose hidden layers are just a table in disguise.

What I want is an audit, not a lecture: which of these are actually pulling against each other, which pairs only look like they are, and how severe is each. Order them by severity, and for each one say what has to give and what the cheapest repair costs me. If two of them turn out to be the same commitment stated twice, say that too. Also tell me how confident you are in each verdict, and single out the one point you're least sure about — I'd rather have a flagged weak spot than a fake clean answer.
