Heres one I keep chewing on. Take the Vulcan business in 19th century astronomy: Mercury's perihelion doesn't behave the way Newton says it should, so Le Verrier -- the same man whod just predicted Neptune from the wobbles in Uranus's orbit -- posits an unseen planet inside Mercury's orbit, calls it Vulcan, and for decades people hunt for it, one amateur even claims to have caught it crossing the face of the sun. Then in 1915 general relativity accounts for the leftover precession with no planet at all, and Vulcan quietly evaporates. Nobody found it, nobody ever will, and yet the name had sixty years of serious use.

Analyze that episode through the Kripkean theory of names and reference: rigid designation, reference fixing by description, the causal chain of transmission, empty names, and the necessary a posteriori. Run it in both directions -- what the theory says was going on in the episode, and what the episode does to the theory. Concretely:

- What, on that theory, was the baptism here, and what fixed the reference of "Vulcan"? Le Verrier introduced it with something like the description "the planet whose gravity perturbs Mercury's orbit thus and so" -- and that description, it turns out, is satisfied by nothing. So was there ever a referent? If not, what were all those astronomers doing with the name for six decades? Does the machinery of initial baptism plus transmission even have the resources to describe a name that is used a great deal and refers to nothing, or is this a case the picture simply doesn't cover? Is "Vulcan" the same kind of thing as "phlogiston" or "the ether," or is it different in a way that matters?

- Contrast Neptune, which Le Verrier also predicted and which was actually found. Nobody doubts "Neptune" refers. But press on what the theory says about the relation between the description he used and the object it latched onto: is the description part of the meaning of the name, does it have to be true of the object, and what happens to the name if the description is partly wrong about the thing it did manage to hit? The standard Kripkean line is that a description can fix a reference without being a synonym for the name, and that we can be substantially wrong about the description and still be talking about the same object -- say whether the Neptune case actually supports that or whether it's doing something sneakier.

- The necessary a posteriori. Which statements in this episode, if any, are supposed to be necessary but knowable only a posteriori? Be careful and honest here, because "Vulcan exists" is not like "water is H2O": a planet is a contingent sort of object, so even if Vulcan had existed, its existence would not have been necessary. And yet if "Vulcan" is an empty rigid designator, "Vulcan does not exist" comes out necessary while being known only a posteriori -- only after the failed searches and Einstein. Is that a genuine instance of the necessary a posteriori, a trick of the framework, or a sign that existence claims are a bad test case? Pick one and defend it.
