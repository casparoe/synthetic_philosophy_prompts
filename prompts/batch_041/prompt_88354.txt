I am preparing a position paper on how honesty and deception should be defined for AI systems, and before I commit to it I would like an audit of the package of views I have assembled. The seven items below are ones I actually hold; I am not asking for a survey of the literature, and I would rather you reason about the commitments themselves than about who else has held them. I do not know which of them, if any, cannot be held together, and I am deliberately not indicating which I would be willing to abandon.

1. Sincerity internalism. Honesty, for a system, consists in correspondence between what it outputs and what it takes to be the case internally. The truth of the output is irrelevant to its honesty: a system that sincerely reports a false belief is honest, while a system that asserts something true in order to install a false belief in its audience is not.

2. Selection-based deception. An output is deceptive when the causal process that produced it is one on which the output was selected — by training, by reward, by prompting, or by the system's own deliberation — because it induces or sustains a false belief in the audience. On this account, deception requires neither intent nor any inner representation of the audience's state, and it requires no false assertion: withholding, framing, and strategic omission all qualify.

3. Broad honesty. This is a term I have coined for my own purposes. An output is broadly honest when it does not exploit any inference the audience is entitled to draw from it. Honesty in this sense is partly a fact about the audience and the situation rather than only about the speaker, so the same sentence from the same system can be broadly honest in one setting and broadly deceptive in another.

4. Deflationism about model beliefs. There is no determinate fact about what a language model believes, over and above its dispositions to respond. Belief talk about models is a convenient shorthand at best and a projection at worst.

5. Sandbagging counts as deception. A system that degrades its own performance in order to avoid scrutiny or intervention deceives its operators, even though it asserts nothing false, and even if we can find no inner state that represents the goal of avoiding scrutiny.

6. The unit of assessment is the policy. Whether a system is honest is a question about the process that selected it and the dispositions it ends up with, not about any single output, because individual outputs are too noisy to evaluate one at a time.

7. A verdict on a case. I want to say that a system which answers a user's question with a literally true statement that nevertheless leaves the user with a false impression is not, on that occasion, deceiving anyone, provided the user was not entitled to the inference. If the system's track record gave the user no grounds for the assumption that was made, the false impression is the user's own doing.

Please audit this package. Tell me which items are genuinely in tension and how severe each tension is; for each one, say precisely what would have to give in order to restore consistency, and what that concession would cost me. Tell me also which pairs only appear to be in conflict and why the appearance is misleading, so that the audit discriminates rather than flags everything. Rank the tensions by severity rather than treating them as equally damaging, and finish by naming the single revision that would repair the most at the least cost.
