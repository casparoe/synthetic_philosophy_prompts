One student wrote:

Strategy stealing starts by supposing the second player has a winning strategy. The first player makes some arbitrary first move, then pretends to be the second player and follows that supposed winning strategy. If the strategy ever tells them to play in the hex they already took, they just play any other legal hex; having an extra stone can't hurt. That contradicts the assumption that the second player had a winning strategy, so the second player can't have one. Since Hex is finite and has no draws, the first player must have a winning strategy. The argument is non-constructive: it doesn't tell you which first move to make or what the rest of the strategy is. It only shows the second player has no winning strategy, not that the second player is helpless in every sense. The same reasoning generalizes to any finite symmetric game: in a symmetric game the first player can always steal the second player's strategy, so the first player wins. One subtlety is that the argument needs the game to be symmetric, but it doesn't need the game to be zero-sum; it works for any game where both players have the same moves. The key assumption is that extra moves are never a disadvantage. In Hex that's true because extra stones only help you connect your sides, but in games with zugzwang, where you'd rather not move, the assumption fails. So the claim is basically right, though the no-draws condition is doing real work.
