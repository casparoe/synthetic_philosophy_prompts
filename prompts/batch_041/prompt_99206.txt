ok so i've fallen down a rabbit hole about how two people should split a surplus they can only get by agreeing with each other, and i've got two rival answers that seem to pull in different directions and i can't work out which one is actually right. quick setup so we're on the same page. there's a feasible set of payoff pairs (all the splits they could conceivably agree on), and a disagreement point, which is what each of them walks away with if talks collapse. the Nash answer says: subtract the disagreement point off, then pick the point in the set that maximizes the product of the two people's gains. the pitch for it is that it's the only rule satisfying a short list of axioms -- it sits on the Pareto frontier, it's symmetric (doesn't care which player we call player 1), it's invariant to rescaling either person's utility, and it satisfies independence of irrelevant alternatives, meaning if you shrink the feasible set but the chosen point is still available, the choice shouldn't move. the other answer, from Kalai and Smorodinsky, says: draw a straight line from the disagreement point to the "utopia" point (where each person gets their best possible payoff), and take wherever that line crosses the Pareto frontier. it keeps Pareto, symmetry and rescaling, but ditches IIA and instead insists on a monotonicity idea -- roughly, if you expand the set in a way that raises what a player can get at every level of the other player's payoff, that player shouldn't end up with less. i might be mangling that axiom a bit so feel free to correct me on it.
