I am a novelist, and I have been trying to understand a puzzle that a character in my current book—a decision theorist—cannot let go of. I would like you to help me see where the following argument goes wrong, or, if it does not go wrong, which premise I should give up and what that costs.

The background is a game. A fair coin is tossed until it lands heads for the first time. If heads appears on toss n, the player receives a payoff of 2^n divided by n, with the sign alternating: a gain when n is odd, a loss when n is even. So on n=1 the player wins 2; on n=2 the player loses 2; on n=3 the player wins 8/3; on n=4 the player loses 4; and so on. The probability of heads first appearing on toss n is 1/2^n. The expected value, computed by summing the probability-weighted payoffs in the natural order n=1,2,3,..., is the alternating harmonic series, which converges to a finite number. But the series is not absolutely convergent. If the terms are rearranged, the sum can be made to converge to any real number at all, or to diverge. So the game's expected value is, in a strict sense, not well defined; it depends on the order in which the infinitely many outcomes are summed.

Now consider a second game, identical to the first except that every payoff is increased by one dollar. Where the first game pays 2, the second pays 3; where the first pays -2, the second pays -1; where the first pays 8/3, the second pays 11/3; and so on. Call the first game P and the second game A. In every possible outcome, A pays exactly one dollar more than P. So A dominates P.

Here is the argument that troubles my character:

(1) A rational agent should prefer a game that pays more in every outcome to one that pays less in every outcome.
(2) A pays more than P in every outcome.
(3) Therefore, a rational agent should prefer A to P.
(4) The expected value of a game is the sum of its probability-weighted payoffs.
(5) The expected value of P is not well defined, because the sum is conditionally convergent and can be rearranged to yield any value.
(6) The expected value of A is not well defined, for the same reason.
(7) If two games both have undefined expected value, then expected-value theory cannot rank them; it is silent.
(8) If expected-value theory is silent, then a rational agent has no reason to prefer one to the other.
(9) Therefore, a rational agent has no reason to prefer A to P.
(10) But (3) says a rational agent should prefer A to P.
(11) Therefore, either (1) is false or expected-value theory is not the whole story about rational choice.
(12) But (1) seems undeniable. So expected-value theory is not the whole story.

The conclusion is not itself absurd—many people think expected-value theory is incomplete. What seems to prove too much is the combination: if we accept (7) and (8), then a rational agent is indifferent between A and P. That means the agent is indifferent between a game that pays more in every outcome and one that pays less. That seems to make a mockery of practical reason. My character says: I would rather keep (1) and give up something else, but I cannot see what.

Tell me which step to reject. If the flaw is an equivocation or a scope error, name it precisely. If the argument is valid and the real question is which plausible premise is least costly to abandon, tell me which one you would abandon and what the cost is. I am especially interested in whether the notion of an undefined expected value is doing illicit work in (7) and (8): does undefined mean that no fact of the matter exists, or only that the standard formula fails to deliver one? And does the dominance principle in (1) apply to outcomes or to expectations? I would like the answer to be usable by a novelist—clear enough that I can put it in a character's mouth without making the character look foolish.
