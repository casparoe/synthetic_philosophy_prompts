I'm in a reading group on consciousness and moral status — we're meant to be working out where the boundary of morally considerable minds lies, mostly because two of us want to know whether we should care about insects and one of us keeps bringing up AI systems — and Priya brought an argument that I've been chewing over for a fortnight and can't get out of. I think it's valid. I don't want it to be. Here it is, tidied up a bit:

(1) A thing is a moral patient, something that can be wronged, only if there is something it is like to be it — some of its states are experienced.
(2) Which of a system's states are experienced is fixed by the functional role those states play: a state is an experience when it sits in the right place in the system's causal economy, the place pain sits in ours.
(3) Functional roles are defined at the level of the computation, not the stuff that runs it. Two systems implementing the same computation realise the same functional roles, whatever they're made of.
(4) For any total input–output function there is a device that computes it by lookup: a table storing, for each input, the output the function gives.
(5) A lookup table is a pattern of marks, and the medium is irrelevant — paper, holes in cards, magnetic domains, it's the same table.
(6) Take a creature we all agree is a moral patient, and let T be the lookup table for the function from its entire sensory history to its entire behavioural history. Every possible input has an entry, and every entry specifies the creature's next state and what it does.
(7) By (2)–(5), T implements the same computation as the creature, so its states occupy the same functional roles, so they are the same experiences, so by (1) T is a moral patient.
(8) T is a very large sheet of paper. There is nothing it is like to be a sheet of paper, so T is not a moral patient.
(9) Something has to give — and since nothing in the argument depended on paper, it looks like it gives the same verdict for any arrangement of matter whatsoever, which can't be right.

So which premise do I drop, and what does dropping it cost me? I'd much rather keep (1) and (3) than give up (8); I'm fairly confident my desk isn't suffering. But I want to know what I'd be buying. If your answer is that (7) slides from same input–output function to same computation, tell me what more than the function is needed, and then tell me why that extra thing couldn't itself be laid out on paper, because that's exactly the move that seems to me to restart the whole problem. Priya has a seperate objection that I dont really follow: she says the argument is empty because whether a bit of matter implements a computation is up to us, that we can always find some description under which anything implements anything, so (4)–(6) do no work. If that's the answer, unpack it for me — is the point that implementation is observer-relative, or that T is a description of a computation rather than a thing that computes? — and say whether it actually defuses the argument or just moves the bump under the carpet, given that we're definately right to think each other are conscious and we don't seem to have made that up.
