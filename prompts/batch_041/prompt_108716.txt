I am building a naturalistic ontology, and I keep encountering entities whose credentials I cannot adjudicate: centers of mass, thermodynamic magnitudes, species, genes, markets, the states we attribute to a thermostat. The family of views I want to work with says that such things are real to the degree that a description of them compresses the data it describes — real in proportion to the compression gained, and real only relative to the capacities of some possible describer — and that physical, design, and intentional descriptions are three stances one may take toward a single system, the later stances being available only where the earlier ones would be too costly to apply.

Before I adopt any version of this, I want the specification. Set out the desiderata a theory of pattern-reality must meet in order to do the job I need it to do, which is to license or withhold existence claims, not merely to recommend a convenient vocabulary. Give, for each requirement, the case or consideration that motivates it. I expect the following to be in play, though I do not know which are genuine constraints and which are commitments of a particular camp: the theory must not render every data set maximally compressible; it must not make patternhood hostage to whether anyone has yet described the pattern; it must separate a pattern from a stretch of data that is compressible in only one respect; it must survive the existence of two descriptions that compress the same data equally well; it must say what to make of a pattern whose compression is available only to a machine with capacities no physical device can have; and it must accommodate entities the intentional stance predicts well that have no single locus of inner states.

Here are the cases I want the theory to get right. Use them, and add others if the requirements demand it.

- a cellular automaton whose persistent, propagating configurations are indispensable for predicting it efficiently, though every fact about them is fixed by the cell-by-cell update rule;
- the center of mass of a composite body, which no particle occupies and which exerts no force;
- a thermodynamic description of a gas whose microstate, taken in itself, is uninformative;
- a stretch of an otherwise random sequence that admits a short description (a long run of ones) and is useless for predicting what follows;
- a text long enough to contain every finite string, hence a true prediction of any event you choose, with no way to locate that prediction more briefly than by reproducing the text;
- a short rule that defines a predicate no one would project from observed cases to unobserved ones;
- a feature read off a trained network's activations by a probe, which predicts the network's outputs perfectly and which no one can state in any other terms;
- a data set described in a language that contains a primitive symbol for that very data set;
- a pattern no one has ever noticed, which would compress its data if someone did.

Then mark which requirements are non-negotiable and which are preferences of one camp. Flag any pair of requirements you believe cannot be jointly satisfied, and say why; I would rather learn that the list is inconsistent than adopt a theory that satisfies it only on paper. Finally, in a few sentences, name the single requirement that does the most to exclude the accounts currently on offer, and say what it excludes.

I want the criteria, not a survey of the literature; do not give me a reading list.
