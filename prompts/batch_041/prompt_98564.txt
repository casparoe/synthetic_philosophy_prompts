"Benacerraf's point is that platonism about numbers can't be right, because if numbers are abstract objects outside of space and time then we can never have any causal contact with them, so we could never come to know anything about them. Thats the access problem and it basically kills platonism. And if you try to dodge it by saying numbers are just symbols or marks on paper, then math turns into a game with no truth or falsity, which is also unacceptable. So the dilemma is that platonism and formalism each get refuted and you're stuck. The only real way out is to say math is about structures instead of about objects, which is what structuralism does. Also this whole thing is really only about numbers — sets and functions are more concrete, so the access problem doesn't bite there. And since there's no causal link to numbers, our number words don't even manage to pick anything out, so strictly speaking '2+2=4' isn't true or false either."
