Hey — I'm drafting a short peice for a reading group we run (loose theme this term is "what is a system actually representing," and it's been a mess), and I've got a sketch I'd love you to tear apart. The claim I want to argue is that when the information you'd need in order to tell which ontology a system is using is inaccessible, "ontology identification" is better understood as a constrained optimization problem than as a discovery problem. The skeleton: (1) any system's behavior is consistent with indefinitely many ontologies, since you can always gerrymander the predicates until some weird ontology fits; (2) the information that would rule out most of those candidates — the system's internals, or counterfactuals about what it'd do in situations we can't get it into — is either inaccessible or doesn't exist (my stock example: a system trained to predict what a person will click; does it represent "she prefers A to B" or just "clicks tend to run this way"? every accessible fact is compatible with both); (3) so any procedure that hands you "the" ontology is really handing you whichever one is optimal relative to some explicit constraint set — a prior, a simplicity measure, the predictions you need, the interventions you care about; (4) so the honest form of the question is always "given constraints C, which ontology maximizes O?"; and (5) the corollary I'm fond of: the residual indeterminacy, i.e. the differences among the top-ranked candidates, is exactly the set of ontological questions that don't matter for C — which means identification can "succeed" and still bite you the moment someone uses the system for something outside C. Then I want to pivot to AI and claim that when people fight about whether a model "has beliefs" or "represents" a user's preferences, they're mostly smuggling in different constraint sets, so the fight is about the constraints more than the facts. The punchy line I'm attached to: ontology identification is impossible in the limit and easy in the relevant case, and the trick is that the relevant case is chosen, not found.
