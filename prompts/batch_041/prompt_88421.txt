**Q3.** Lucas and Penrose both argue that Gödel's incompleteness theorems show that the mind cannot be a machine. Set out the arguement in its strongest form, and say whether you think it succeeds.

**Answer.** Gödel's first theorem says any consistent formal system F strong enough for arithmetic has a sentence G_F it can neither prove nor refute, and that G_F is true — it says of itself that F can't prove it, and if F could, F would be inconsistent. Lucas's move is: take any formal system F you like and suppose it captures everything I can prove. I can construct G_F and see that it's true, which F can't. So I'm not F. Penrose sharpens this. It isn't about one system, because whatever F you hand me I can see G_F, and then I can see the Gödel sentence of the system you get by adding that insight to F, and so on up. The mind always outruns whatever formal system you try to identify it with, so the mind can't be a formal system at all. The standard mechanist reply is that G_F is only true if F is consistent, and consistency isn't something F can prove about itself. But that just pushes the problem back a step: consistency is itself something I can recognise — I can see that my own arithmetic is consistent — and by Gödel's second theorem no consistent formal system containing arithmetic can prove its own consistency. So the very thing I can do here is something no formal system can do, and the argument goes through. The one weakness is that it seems to need our mathematical insight to be infallible, which is too strong; but for the systems we actually use, it works.
