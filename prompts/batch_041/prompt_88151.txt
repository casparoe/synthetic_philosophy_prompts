Ravi: Gödel kills this. Any system strong enough to talk about itself has blind spots — there are true statements it can't prove, including a statement of its own consistency. Dana: You're smashing two things together. Gödel is about formal systems of arithmetic, not self-knowledge. And the consistency bit cuts against you: we can only see the Gödel sentence is true if we already assume the system is consistent, and by the second theorem you can't prove that from inside. Hand the machine a consistency axiom and it proves the old sentence and a new one pops up — you've moved the bump in the carpet. The machine climbs the same ladder we do.

Ravi: But we see the whole ladder is sound, all at once. No single program can do that. That's Penrose's whole thing.

Dana: Then you've described a stronger system, or an infinite one, which is still a system. And "true" there just means true in the standard model of arithmetic, which you're assuming. The second theorem is a fact about us too — if human math is consistent we can't prove that from inside either. You don't get consistency as a free gift for people and deny it to programs.

Ravi: There's still a gap between a system that can talk about itself and one that has a self. GEB is about that gap closing.

Dana: A program that prints its own source code is a strange loop. Nobody thinks it's conscious. That's a metaphor doing the work of an argument.
