I've ended up a dialetheist, but only about language, not about the world: some sentences really are both true and false -- the Liar and its relatives -- but no object or event is ever both F and not-F (for any property F). The contradiction always lives in the relation between a language and its own truth predicate, never in what the language is about. Call it semantic-only dialetheism. And yeah, I'm happy to use a paraconsistent logic, so don't burn a paragraph telling me contradictions trivialize everything.

What would count against it? I want real defeaters, ranked from fatal to anoying, and I want to know which ones a defender of this view would concede rather than wave off as question-begging. A few things I'm genuinely unsure about: does it survive if you can get a contradiction going with no truth talk at all -- a borderline bald man who's both bald and not bald, the usual vagueness cases where the glut is supposed to be in the world and not in our words? What would it take to show the 'only semantic' restriction is just ad hoc, i.e. that the honest dialetheist has to let the world itself be inconsistent? Is that restriction what keeps the view falsifiable, or is it what makes it unfalsifiable -- and is that a problem, or the whole point? And if you and I disagree here, is there any neutral ground we could argue from, or does each side's logic make the other side's moves invisible? If there isn't, just say so.
