ok so I'm workshopping a paper for a small phil-of-mind reading group in a couple weeks and I want your comments before I do the rewrite. It's on when a computation should count for moral status. I'll paste the current draft-ish thing below — it's notes in places, sorry.

Rough thesis: the question "which computations matter morally" is the wrong question, and the right one is when a computation is attributable to a system at all. Everyone argues about whether you need neurons, carbon, biology, whatever. I think the substrate question is a red herring and the real work is being done by something I'm calling the counterfactual profile of a system.

Here's what I mean. When we say a system computes something, we've picked a mapping from physical states to formal states. Almost any physical thing can be mapped onto almost any formal description if you're willing to be baroque enough — the standard objection, I know. So the mapping by itself can't be what makes it true that a system is doing X rather than merely being describable as doing X. My proposal: the difference is whether the system's own dynamics explain why *this* computation rather than some other one is the one you're mapping. Concretely, a system genuinely computes X only if the relevant physical variables are counterfactually sensitive in the right pattern — change a variable the way the formal description says matters, and the downstream states change the way the formal description says they change, and it's the physical dynamics that carries that, not my choice of mapping.

Then two cases.

Case 1, the glacier. A glaciologist tells me that over about twelve thousand years, a particular glacier's internal crystal transitions can be mapped one-to-one onto the state sequence of a human cortex while it's in pain. Fine. But the mapping is imposed. The glacier doesn't fail to feel pain because ice is the wrong stuff; it fails because nothing about the glacier's dynamics privileges that mapping over the millions of others I could cook up. The glaciologist's simulation is doing the computing, not the glacier. This is the case everyone thinks they can handle.

Case 2, and this is where I actually want help. I build a cathedral-sized machine of gears, cams and levers. It's engineered so that its causal topology matches the recurrent connectivity of the human pain pathway, node for node, and every node is genuinely counterfactually sensitive in the way the formal description requires — nudge a cam and downstream states change exactly as the model says. Its just extremely slow: one time step per day. It has no neurons, no evolution, no biology, and I built it as a lark.

On my criterion, the cathedral machine passes. Which is to say it feels pain, or at least has the same claim to be a subject of pain that you do. Most people I've floated this by say that's obviously absurd, and I think that reaction is doing a lot of unearned work — it's size-and-speed bias plus a hidden assumption that the machine has to be *for* something, which I'm suspicious of. But I'm not sure. The awkward possibility is that my criterion isn't doing any real work and is just smuggling biology back in through the back door, i.e. that "the right counterfactual profile" quietly means "a profile like the one brains happen to have."

There's a second thread I don't know what to do with. I want to seperate the question of whether the system computes X from the question of whether we can attribute X to it, and attribution is observer-relative in an annoying way. Even for the cathedral machine, someone has to have picked out which of its degrees of freedom count as the states. Is that just the normal amount of observer-relativity that any functional description has, or does it break the whole view? Relatedly: does my view make moral status depend on facts about how easy it is for us to describe the system, which feels wrong.

So, what I'd like: comments on whether the counterfactual criterion is actually distinct from the standard functionalist line or whether I'm kidding myself. Be blunt, I'd rather recieve it now than in the room. Also tell me if the glacier case is doing any work that the cathedral case isn't, because I suspect one of them is dead weight. And if there's an obvious objection I'm walking into, flag it.
