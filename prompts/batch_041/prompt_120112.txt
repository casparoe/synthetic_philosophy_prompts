QUESTION 4

Naive comprehension says that for every predicate φ(x) there is a set S such that, for every x, x ∈ S if and only if φ(x).

(a) Show that this schema is inconsistent. State the predicate you use and give the derivation step by step.

(b) State exactly which logical or linguistic resources the derivation relies on. In particular, say whether the argument would still go through if the underlying logic were weakened.

(c) Zermelo's response was to replace comprehension with separation; Russell's was to replace it with the theory of types. Explain what each replacement does to the predicate you used in (a), and say whether the two are doing the same kind of thing or different kinds of thing.

(d) A student in the class says: the paradox shows that the predicate x ∉ x is illegitimate, so the fault lies in the language rather than in the axiom, and the remedy is to restrict what may be said rather than what may be allowed to exist. Assess this claim.

STUDENT'S ANSWER

(a) Take φ(x) to be x ∉ x, and let R be the set of all x such that x ∉ x. If R ∈ R, then since R satisfies the condition, R ∉ R. So R ∈ R implies R ∉ R, hence R ∉ R. But then R satisfies the condition, so by the defining property of R, R ∈ R. We therefore have both R ∉ R and R ∈ R, which is impossible; so no such set exists and the schema must be abandoned.

(b) The derivation uses the comprehension schema and ordinary logical reasoning, and nothing else — no choice, no foundation, no arithmetic. But it does use reductio ad absurdum, and that is where the classical assumption enters. From the refutation of R ∉ R we are entitled to conclude R ∈ R only if we assume that a proposition and its negation cannot both fail; drop that assumption and the two halves of the argument no longer combine into a contradiction. Naive comprehension over intuitionistic logic is therefore consistent, and the paradox is a product of classical reasoning about sets rather than of the comprehension schema by itself.

(c) Zermelo's separation does not allow us to collect all the non-self-membered sets; it allows us, given a set S, to collect those of its elements that are not members of themselves. The derivation still runs, but it now proves something harmless: that the resulting set is not an element of S, that is, that no set contains all the non-self-membered sets. Russell's type theory instead assigns a type to every variable and permits a predicate to apply only to variables of lower type, so that x ∉ x is not even well-formed and the derivation cannot be stated. In Zermelo's system the same restriction is imposed at the level of the predicate rather than the level of the variable: the formula used in an instance of separation must be stratified, that is, its variables must be assignable to levels, and x ∉ x fails this test. The two responses are thus the same response in different notation — both block the paradox by refusing to let the offending predicate be formulated.

(d) The claim is partly right. It is true that the paradox is generated by a piece of language rather than by any discovery about what sets there are, and it is true that much of the later work — type theory, the ramified hierarchy, the emphasis on predicativity — restricts what may be said rather than what may exist. But it cannot be the whole story, because Zermelo's solution keeps an untyped language in which x ∉ x is perfectly well-formed and simply declines to grant it a set; so the fault cannot lie in the language alone. Indeed, the paradox is not really avoided by restrictions on language at all: any language rich enough to code its own expressions will regenerate the contradiction, so no restriction on what may be said can be more than provisional. It is also worth noting that the paradox is a logical rather than a semantic one — unlike the Liar it turns only on membership and the comprehension schema — so the remedies devised for semantic paradoxes, such as a hierarchy of truth predicates, do not address it.
