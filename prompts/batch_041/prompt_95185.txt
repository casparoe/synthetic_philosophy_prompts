For a graduate seminar that mixes philosophy of mind with machine learning, I need a one-page decision tree that sorts the positions on whether it is ever literally true that an AI system believes something, as opposed to merely useful to talk that way. Build the tree out of the logical space first, so that every branch node is a question that separates the views and is phrased so a reader can answer it without already knowing which position it leads to. I want the following distinctions to appear as branch points, because they are the ones my students keep collapsing into each other: whether attributing a belief requires the system's internal states to be causally efficacious in producing the behavior in the way ordinary folk psychology assumes, or whether reliable prediction is enough; whether the system must be capable of misrepresenting, on the view that a state that cannot be wrong is not a belief; whether the system's self-reports count as evidence at all; and whether belief attribution is all-or-nothing or comes in degrees. Locate at least these leaves in the resulting space, each with a name and one sentence on its most awkward commitment: Dennett-style instrumentalism about the intentional stance; a realist view on which current systems literally have beliefs; the view that belief requires phenomenal consciousness; a deflationary view on which belief talk is convenient shorthand; and the view that the question is ill-posed because belief is a family of different things rather than one. Use these cases as the material for the diagnostic questions: a chess engine, a thermostat, a language model that states a false fact with confidence, a model that accurately reports its own internal state, and a reinforcement-learning agent with a world model it uses to plan. Flag any combinations of answers that no one occupies, and say briefly whether the combination is incoherent, unattractive, or merely unexplored.
