Here's the question: Parfit's Lindley Lecture distinguishes telic from deontic egalitarianism and introduces the priority view. Explain the leveling-down objection. Which of these views does it target, and does the priority view escape it? In your answer, be sure to explain what it means to say that equality is intrinsically valuable, and how the priority view differs from egalitarianism.

Here's the student's answer: Parfit's leveling-down objection is the claim that if equality is intrinsically valuable, then it would be intrinsically better to make the better off worse off even if no one is made better off — for example, blinding the sighted so that everyone is blind. This seems absurd, so equality cannot be intrinsically valuable. Parfit uses this to distinguish telic egalitarianism, which says equality is intrinsically good, from deontic egalitarianism, which says equality is not intrinsically good but that we have reasons not to act in ways that create inequality. The leveling-down objection is a problem for deontic egalitarianism, because deontic egalitarianism still says that unequal outcomes are bad in themselves. Parfit's priority view says that we should give extra weight to benefits to the worse off. Because prioritarianism gives priority to the worse off, it still treats equality as intrinsically valuable, just in a different way. So the leveling-down objection applies to prioritarianism as well, since it would still favor leveling down if that made the distribution more equal.
