Background I want you to take as given, since I am describing it rather than assuming you have it memorized. In an ordinary one-shot game, two players choose actions simultaneously and each must choose without knowing what the other will do. There is a construction in which players do not choose actions directly: each submits a program to a shared mediator, and each program is handed the other program's complete source code before it outputs an action. Because a program can condition its output on its counterpart's code, mutual cooperation in a one-shot Prisoner's Dilemma becomes implementable by a program that cooperates exactly when the program it is given cooperates. This is not available in the ordinary game. The construction has a known weakness: a deviator can be written that recognizes cooperating counterparts and defects against them, so the naive cooperative program is exploitable. A later, more robust version repairs this by having programs act on the basis of proofs about what the other program does, which imports strong assumptions about what each agent can prove about its counterpart and about itself.
