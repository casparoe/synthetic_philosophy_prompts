I spent 40 years as a biochemist and since retiring I've been reading alot of philosophy of biology, which is more fun than I expected. One thing that nags at me: everyone I used to work with, myself included, talks about DNA as a "code" and the genome as a "program" or a "blueprint". I always treated that as harmless shorthand, but the more I read the more I suspect some of these metaphors smuggle in stuff we don't actually believe about how organisms work.

Here's the test I've landed on for calling something a code: there has to be a mapping between two independant things, one that could have been otherwise, and a reader who has to already know the mapping to get anything out of it. Otherwise you've just got a causal chain. By that test the codon table passes; I'm not so sure about most of the rest.

So rate the following for how misleading they are as ways of talking about the genome, where 0 means fine, no philosophical damage, and 100 means it actively teaches you something false about how organisms work:

DNA as a code / the genome as a program / as a blueprint / as a recipe / as a library / as a database / as a compressed archive / as an ingredients list with amounts but no method / as a diff or patch applied to an inherited working copy.

For each one give me a number, one line on what it gets right, one line on the worst thing it makes people believe, and a verdict of keep, keep with a warning label, or retire. And tell me if you think my code test is wrong.

Give it back to me as a JSON object with these fields: "ratings", a list where each item is an object with "metaphor", "score" (0-100), "gets_right", "worst_implication", and "verdict" (one of keep / keep with warning / retire); "criterion_objection", your best objection to my test for what counts as a code, or null if you don't have one; and "best_replacement", the single phrase you'd put in a textbook instead of "code", plus one sentence on why.
