Me and some friends run a small rationality meetup and we keep getting into fights about the "unilateralist's curse" — the thing where a bunch of people can each independently do some action, it's great if enough of them do it and bad if only a few do, so everyone acting on their own private judgment adds up to a mess. I want to turn our next session into a decision tree we can actually argue through, so write me one. Start from a commitment and branch at each node with the question that separates the kinds of view, phrased so a person can answer without already knowing which leaf they'll land on. I want nodes for at least: whether the action's value is a threshold thing or just additive; whether you can cheaply coordinate or observe what the others are doing; whether other people's choices are correlated with yours, so you acting is itself evidence they'll act too; whether the action is reversible; and whether you think you know something the others don't. Leaves should be named positions — plain act-if-your-own-EV-is-positive, the conformity-style rule that you only go if it still looks good once you model the others, a wait-and-coordinate leaf, a defer-to-the-best-informed leaf, a flat never-act-unilaterally leaf, and a probe-first leaf where you take a cheap reversible version of the action. One extra thing I keep chewing on and want as a leaf if it fits: the mirror case, where sitting on your hands is also a unilateral move with the same aggregation problem, so the curse cuts both ways. Where two branches land on the same leaf, or the tree just can't separate two positions, say so instead of papering over it. And flag any combination of answers nobody actually holds, with a quick call on whether that's because it's incoherent, ugly, or just unexplored.
