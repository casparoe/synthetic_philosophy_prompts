Question: Explain the Pasadena game and why it's supposed to be a problem for the expected value rule. How does it differ from the St. Petersburg game, and what role does the Altadena game play in the discussion?

Student answer: The Pasadena game is a coin-flipping game where you flip a fair coin until it lands heads. If it lands heads on the nth flip, you win (-1)^(n-1) * 2^n / n dollars. The expected value is the sum over n of (1/2)^n times the payoff, which gives the alternating harmonic series 1 - 1/2 + 1/3 - 1/4 + ... This series is conditionally convergent, so it sums to ln 2. So the expected value of the Pasadena game is ln 2. The problem is that the St. Petersburg game has an infinite expected value, so it seems like you should pay any amount to play it, but the Pasadena game has a finite expected value, so it's not as paradoxical. The Altadena game is the same but with each payoff increased by $1, so its expected value is ln 2 + 1, which is higher than the Pasadena game's, so you should prefer Altadena. Hájek and Nover argue that this shows expected value maximization is fine, because the Pasadena game has a well-defined expected value after all.
