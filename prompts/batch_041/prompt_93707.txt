my draft:

Imagine a student council of three people, A, B, and C. They have to decide whether the school should fund a concert (P), whether it should fund a scoreboard (Q), and whether it should follow the rule that if it funds the concert then it must fund the scoreboard (P only if Q, or if P then Q). Each member votes on all three.

A votes yes on P, yes on Q, yes on the rule. That is consistent.
B votes yes on P, no on Q, no on the rule. That is consistent, because if P is true and Q is false, then if P then Q is false.
C votes no on P, no on Q, yes on the rule. That is consistent, because if P is false, then if P then Q is true no matter what Q is.

Now add up the votes. P gets yes from A and B, so the council says yes. Q gets yes from A only, so the council says no. The rule gets yes from A and C, so the council says yes. So the councils final position is: P yes, Q no, and if P then Q yes. But that cant all be true at once. If P is yes and Q is no, then if P then Q has to be no. So the group is inconsistent even though nobody in it is.

My fix: dont let the council vote on the rule. Let them vote on P and Q, and then just apply the rule mechanically. If they vote P yes and Q no, then the rule is automatically no, even if two of them wanted the rule to be yes. That keeps the group consistent. But it also means Cs vote on the rule is basically ignored, and C might say thats unfair because the rule was the thing C cared about.
