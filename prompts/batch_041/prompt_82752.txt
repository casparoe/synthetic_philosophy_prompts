I teach the third-year undergraduate module Logic and Set Theory, and I am currently marking the final paper for it. One question this year was written specifically to test whether students can keep the model-theoretic and the ordinary senses of cardinality apart, and before I return the script below I would like an independent assessment of it.

The question was set as follows.

"Suppose that there is a countable transitive model M of ZFC. A student in the class submits the following argument and asks you to evaluate it.

(1) M is countable, and because M is transitive every element of M is a subset of M. Every subset of a countable set is countable, so every element of M is a countable set.
(2) ZFC proves that there is an uncountable set, and M satisfies ZFC, so M contains a set s that M regards as uncountable.
(3) By (1), s is countable. So s is both countable and uncountable, which is impossible.
(4) Therefore either ZFC is inconsistent, or else 'uncountable' does not mean what we think it means.

Explain where this argument goes wrong. Address explicitly (a) whether step (1) is true, and in what sense; (b) what M's satisfying 'there is an uncountable set' does and does not establish; and (c) what Skolem's paradox shows, and what it does not show, about the absoluteness of set-theoretic notions."

The script, reproduced without correction, is the student's complete answer to that question.

"(a) Step (1) is sound. If M is countable then it has only countably many members, and since M is transitive every member of M is a subset of M, hence countable. So every element of M is a countable set in the ordinary, non-model-relative sense. I would add that the hypothesis that a countable transitive model exists is strictly stronger than the consistency of ZFC: a transitive model is well-founded and therefore an ω-model, whereas the completeness theorem applied to Con(ZFC) yields only a countable model that need not be well-founded. So the question is not begging anything against ZFC.

(b) The argument fails at step (3), because it treats countability as if it were absolute. M satisfies 'there is an uncountable set' in virtue of satisfying Cantor's theorem: there is no element of M that M recognises as a bijection between its ω and its power set of ω. From outside, M's power set of ω is a countable set and we can enumerate it; the bijection M cannot see exists in the universe but is not a member of M. So there is no one set that is both countable and uncountable. There is one set, M's power set of ω, which is uncountable when the quantifiers range over M and countable when they range over the universe. This is why 'countable' is not absolute, and it is why the closing dichotomy is not forced: the existence of a small model does not refute ZFC, and the argument has equivocated rather than established that the word has no meaning.

(c) Skolem's paradox is precisely this situation: any first-order theory with an infinite model has a countable model, and such a model's cardinality verdicts are internal to it. So the paradox shows that 'countable', 'uncountable' and 'power set' are relative to a model. I think the moral is stronger than that. The same relativity appears in arithmetic, where a nonstandard model contains elements larger than every standard number and sees nothing unusual in them, so even the notion of a natural number is model-relative. Since relativity is the general rule, there is no reason to treat countability as an exception, and I conclude that there are no absolutely uncountable sets: every element of every countable transitive model of ZFC is countable, so no set is uncountable, and Cantor's theorem tells us what ZFC proves rather than how large the universe is. The underlying reason for all of this is that first-order logic cannot express uncountability: to say that a set is uncountable is to say something about all functions from it to ω, which is a second-order claim, and that is why no first-order theory can pin down the real power set of ω. The fault lies with the language, not with the model."

The question carries twenty of the paper's hundred marks.
