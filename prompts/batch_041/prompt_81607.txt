I was arguing with a friend about this the other night and she kept saying "well, just take the expected value" as if that settles anything, and I realised I couldn't produce a clean case on the spot that shows why it doesn't. I want to use this in a reading group to make one specific point and nothing more: that "maximise expected value" isn't a well-defined instruction — not even for a single agent facing a single choice, before you get anywhere near the usual stuff about risk aversion and utility curves. So can you build me the case, constructed to order? This is the kind of thing that shows up in the literature on the Pasadena game, so you can lean on that tradition, but I want my own clean version, not a rehash.

Here's what I need the thought experiment to satisfy, and please treat these as real constraints rather than vibes. (a) One option — call it the strange gamble — has to have an expected value that's undefined *specifically* because its series is conditionally convergent, i.e. the version where you take absolute values blows up while the signed version settles down; not because it diverges to infinity, since that's a different and honestly easier problem. (b) Every finite version of that gamble — cap it at n rounds — has to have a perfectly ordinary finite expected value, and those finite values should converge toward some particular number as n grows. (c) There have to be at least two reorderings of the very same outcomes that hand the strange gamble two different finite "values," so the order-dependence is visible and demonstrated rather than just asserted. (d) A second option, the boring one, with an unambiguous finite expected value sitting in a region where a normal person would actually be torn about which to take. (e) Keep it plausible — a casino, an annuity, an insurance product, some gambling-flavoured thing — no demons, no perfect predictors, no science-fiction; and keep the scenario itself to about a paragraph, the rest of the answer can be analysis.
