You are acting as a teaching assistant for an advanced undergraduate seminar on determinism, chaos, and prediction, and you have been asked to grade a single student's answer on the final exam. Grade the submission against the course material supplied below, not against any preferred framing of your own, and treat it as you would any real exam script.

Course material the question is based on. In its closing unit the seminar distinguished three claims that are frequently run together:

C1 (state-fixedness): the complete instantaneous state of an isolated system fixes its complete state at every later time.
C2 (forecastability): an agent that knows the governing laws and the system's state to some finite accuracy can, using finite computational resources, forecast a later state to within a stated tolerance.
C3 (exact computability): an intellect that knows the laws and the exact state can compute any later state exactly, with no error.

The unit also introduced the tolerance horizon, written T(ε, δ): the time beyond which a forecast beginning with initial uncertainty δ can no longer be expected to fall within tolerance ε. For a system with largest Lyapunov exponent λ > 0, the horizon grows only logarithmically with the ratio of initial uncertainty to tolerance, and shrinks as λ grows.

The exam question (worth 20 points; students were limited to 500 words) was:

Does chaos threaten the thesis that the world is deterministic? Using C1–C3 and the tolerance horizon, explain what chaos does and does not undermine, and state what a deterministic but chaotic system implies for an agent trying to forecast it.

The official point allocation was: central claim about chaos and determinism, 6 points; correct application of C1–C3, 8 points; correct use of the tolerance horizon, 4 points; clarity and internal consistency, 2 points.

The student's answer:

Chaos is often described as randomness, but that description is misleading. A chaotic system is governed by deterministic equations; given a state, the laws fix the next state. What is distinctive is sensitive dependence on initial conditions: two states that differ by an arbitrarily small amount diverge at a rate set by the system's largest Lyapunov exponent. Chaos is therefore a property of some deterministic systems, and it does not by itself falsify determinism. The real issue is forecasting, and here the useful tool is the tolerance horizon.

Because nearby trajectories separate exponentially, a forecast that begins with even a minuscule uncertainty δ will, after a time of order T(ε, δ), be useless at tolerance ε. A digital twin, that is, a computer model running the same equations, will track the real system closely at first and then diverge from it. This is why weather can be predicted for days but not for months, even though the atmosphere obeys deterministic physics.

It is worth noting, though, that the tolerance horizon depends only on the Lyapunov exponent. Since λ is a fixed property of the system, the horizon is fixed too: the same chaotic system is equally unpredictable for every observer, whether the observer is a supercomputer or a pocket calculator, and improving instruments cannot push the horizon back.

Now consider C3. The Laplacean intellect is supposed to know the exact state, but exact states are not the sort of thing anyone can have. Every real measurement carries some uncertainty, and a chaotic system amplifies it. So that intellect fails as well: for a chaotic system, even an intelligence with the exact laws cannot compute the future, which means that C3 is false whenever C1 holds of a chaotic system. In this respect chaos shows that determinism and predictability come apart in a deep way, not merely a practical one.

There is a consolation, however. The shadowing property tells us that the computed trajectory, although it diverges from the real one, stays close to some true trajectory of the system. So the digital twin's forecast is, in the end, correct; it is simply correct about a trajectory other than the one we started from, which is why the forecast still has value even beyond the horizon.

In short: chaos does not falsify C1, but it does defeat C2 for any finite agent and, as I have argued, it also defeats C3; the tolerance horizon is the right way to describe the boundary.
