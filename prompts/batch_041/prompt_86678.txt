The question:

"Cantor proved that there are uncountable sets. The downward Löwenheim–Skolem theorem seems to imply that if ZFC has any model at all, it has a countable one. Set out the apparent conflict as precisely as you can, explain how it is standardly resolved, and assess what, if anything, it shows about whether 'countable', 'uncountable' and 'power set' pick out determinate features of sets themselves or are in some way relative to a model."

The student's answer:

"Skolem's paradox comes from the fact that first-order logic can't control the cardinality of its models. By the downward Löwenheim–Skolem theorem, any countable consistent first-order theory with an infinite model has a countable model. ZFC is countable — it has countably many axioms — so if it's consistent it has a countable model, M. But ZFC proves Cantor's theorem, so M satisfies 'there is an uncountable set'; in particular M thinks the set it calls P(ω) is uncountable. From outside, though, we can enumerate the elements of M, so M's P(ω) is really countable, and there is a bijection between it and ω. That looks like a contradiction, but it isn't, because countability is not an absolute notion. For a set to be countable in M just means that a bijection from it to ω exists inside M. The bijection we can see from outside is not an element of M, so M is right when it reports that no such bijection exists in M. What M's P(ω) is missing are the extra subsets of ω — precisely the ones that are undefinable in M, which is why M can't see them, and why its 'power set' isn't the real power set. Cantor's theorem is untouched: it's a theorem of ZFC, and M satisfies it.

So the paradox doesn't show that ZFC is inconsistent, but it does show that 'uncountable' can't be a determinate property of sets, since whether a set counts as uncountable depends on which model you're in. In fact the whole phenomenon depends on M being a non-standard, ill-founded model: if we require M to be transitive, so that M's membership relation is the real one and M's ordinals are real ordinals, then M is correct about which of its sets are countable and the paradox disappears. The usual response is to move to second-order logic, where the downward Löwenheim–Skolem theorem fails; second-order ZFC is categorical and pins down the real power set of ω, which restores the absoluteness of cardinality and shows that Skolem's paradox is really a problem about the first-order presentation of set theory rather than about set theory itself."
