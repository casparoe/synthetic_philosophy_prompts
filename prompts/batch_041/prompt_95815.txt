I am preparing a diagnostic handout for a graduate seminar on Kant's ethics, and I want a decision tree that sorts readers by what they actually take the universalizability test to be doing, rather than by which label they would apply to themselves. Build it from the logical space of positions first — the questions and the combinations of answers they permit — and only then place the positions in that space.

The instrument begins from a commitment the reader is assumed already to hold: that at least some maxims fail the test, and that their failure is not merely a report of the agent's preferences or of what most people happen to do. From there, every node must be a question the reader can answer without knowing which position lies downstream of it. No node may use the technical vocabulary of any leaf — no words such as logical, teleological, practical, formal or empty used as terms of art — and each node must be phrased as a concrete commitment about a case, or as a claim about what a failure of the test would consist in.

Build the tree around the following choice points, in roughly this order:

1. What kind of impossibility universalisation is supposed to produce: a maxim that cannot be conceived as a universal law at all, because the universalised maxim describes a world in which the action is no longer available; a maxim that can be conceived but cannot be willed alongside its own universalisation; or no impossibility whatsoever, only a collision between the universalised maxim and an end the agent cannot coherently renounce.
2. Whether the failure is a defect in the universalised maxim considered as a description of a world, or a defect in the relation between the universalised maxim and the agent's ends — and whether the reader thinks that distinction is substantive or merely verbal.
3. How maxims are individuated: by the agent's own description of what she is doing, by the most specific true description available, or by the most general description that still picks out the action. This is the node I care about most; it must be able to separate readings that agree on everything else.
4. Whether passing the test is necessary for permissibility, sufficient for it, both, or neither — and, if neither, what the reader thinks does the remaining work.
5. Whether the test is a procedure an agent can actually run on a case, or a criterion whose application always requires judgement that the test itself cannot supply.

Every leaf must return a verdict on each of the following four stipulated maxims. Do not substitute your own cases for these; they are fixed, and the point of the exercise is that they pull the readings apart.

M1. I will borrow money on a promise to repay, knowing that I shall not be able to repay.
M2. I will tell the whole truth in every conversation, whatever harm it does to anyone, because I could will that everyone do so.
M3. I will break a promise in order to attend an event I expect to enjoy. The tree must also consider the same action under a second description: I will break a promise made to someone who has no one else to rely on.
M4. I will take the benefit of a practice while exempting myself from its burdens, so long as enough other people bear them.

The tree must reach at least the following eight leaves, each labelled by its content rather than by the name of any philosopher or commentator:

(a) the universalised maxim is inconsistent as a description of any possible world;
(b) the universalised maxim collides with an end that any agent possessed of a will necessarily has;
(c) the universalised maxim defeats the very end contained in the maxim, so the contradiction lies between the maxim and its own point;
(d) the universalisation cannot be willed alongside the maxim, which is a fact about the structure of willing rather than about the world described;
(e) the maxim, universalised, is inserted into a system of nature, and the question is whether the action remains performable in that world, so the test concerns the possibility of acting rather than the consistency of a description;
(f) the test is a first-pass screen: failure shows impermissibility, but passing shows nothing;
(g) the test undergenerates: passing settles permissibility, but some permissible maxims fail it;
(h) the test yields a verdict only once the maxim has already been described in moral terms, so it restates a demand for consistency in willing rather than generating duties.

You may add up to three further leaves if the logical space demands them, but no leaf may be a mere synonym of another. Where two leaves cannot be separated by any question a reader could answer before knowing the labels, say so explicitly rather than inventing a separating question. Where a combination of answers along the tree has no occupant, record it and diagnose whether it is empty because the view is incoherent, because it is unattractive, or because it is merely unexplored.

Return only a JSON object with the following fields, written throughout in British English:

- instrument_title: string.
- starting_commitment: string — the claim the reader is assumed to begin by accepting, in one sentence.
- maxims: array of objects, each with id (M1 to M4) and text (the maxim, verbatim as given above).
- nodes: array of objects, each with id, question, and options — an array of objects with option and next, where next is the id of a downstream node or of a leaf. The tree should have between eight and twelve nodes in total.
- leaves: array of objects, each with id, label, summary (one sentence), awkward_commitment (one sentence on the commitment that sits worst with the rest of the position), and verdicts — an array of four objects, one per maxim, each with maxim, verdict (one of passes, fails, indeterminate) and reason.
- unoccupied_combinations: array of objects, each with combination, diagnosis (one of incoherent, unattractive, unexplored) and explanation.
- indistinguishable_pairs: array of objects, each with leaf_a, leaf_b and why_no_question_separates_them.
- leaky_nodes: array of objects, each with node_id, why_it_might_reveal_the_downstream_position and rephrasing — your own audit of the nodes where a reader could infer the destination from the wording.
- calibration_note: string — one sentence naming which pair of leaves the first maxim fails to separate, and which of the remaining maxims separates them.
