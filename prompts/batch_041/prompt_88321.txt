I'm a backend engineer with no philosophy training, and I've been chewing on teh Buridan's ass thing. I wrote a short essay and I'd like you to comment on it, especially on whether the argument actually holds or whether I'm just renaming the problem. Here's the essay.

The standard setup: an ass exactly between two identical piles of hay, no preference for either. If it only acts on a preference, it starves. The usual reply is that it can just pick one arbitrarily. But that seems to dodge the question: picking arbitrarily is still an action, and if the ass has no preference between picking left and picking right, why does it pick? My move is to seperate a preference from a tie-break policy. A preference ranks outcomes. A tie-break policy is a rule that maps a tie to an action. The ass can have no preference between the piles while still having a policy that says: when two options are exactly equal in expected value, take the left one. The policy is not a preference for the left pile. It's a standing disposition to break symmetry in a fixed way. This is like a stable sort: when two elements compare equal, the sort still has to output an order, so it uses their original order. The comparator returns equal; the algorithm still acts. Same with two identical job offers or two identical servers: you don't need to prefer one, you need a rule like first email wins or lowest hostname wins. So the ass doesn't need a preference to act, only a policy. The paradox assumes that all action must be preceded by a preference for the action over its alternatives. That assumption is false. Once you allow tie-break policies, the ass eats.

I think this is basically right, but I'm worried it's too cheap. Objections I can see: (1) the policy itself has to be selected over other policies, so the regress just moves up a level; (2) the ass might prefer the left pile because it's left, which is a preference after all; (3) a policy that says take the left one is arbitrary, and if arbitrariness is allowed, why not just say the ass arbitrarily picks? I don't have a good answer to (1). Maybe the policy can be innate or habitual, not chosen. But then is it still the ass's action? Also, I'm not definitely sure the stable sort analogy is good, because a sorting algorithm isn't an agent and doesn't have preferences. Maybe that's exactly the point, or maybe it's a category error.

If it succeeds, what's the best way to state the distinction so it doesn't collapse into the original problem? Also, is there a better example than the stable sort? And am I wrong about the original paradox requiring a preference for action?
