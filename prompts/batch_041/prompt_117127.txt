1. Status quo. Program officers shortlist, board votes, chair breaks ties.
2. Full futarchy. We pre-register a success metric, then run conditional decision markets: one contract pays out only if we adopt portfolio X and the metric hits its target in three years; a matching contract pays out only if we don't adopt X and the metric still hits target. Adopt X if the first price beats the second. Same setup for each competing portfolio, highest wins, and the markets bind us.
3. A pilot. Run the markets alongside the board vote, cap what's at stake, don't bind ourselves, settle against the pre-registered metric in three years, then decide whether to go full futarchy.

Our chair keeps saying we can just let the markets pick the metric too, which I'm fairly sure is incoherent, but I couldn't explain why out loud in the meeting without sounding like a jerk.
