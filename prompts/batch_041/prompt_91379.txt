Ok so I'm in second-year ethics, we just did the Glaucon bit in Republic Book II, and on Monday I have to run a 50-min tutorial on the why-be-moral question. The seminar leader wants a handout that sorts people instead of a lecture, so: can you build me a decision tree / flowchart where the leaves are actual positions and every branch point is a question a student can answer without already knowing what the answer is called.

My problem with every handout Ive found is that it's the same five options and everyone picks Kant or Hobbes by vibe. So build the tree out of cases, and make the cases weirder than the standard ring. Use most of this set:

- the classic ring: invisible, nobody finds out, no punishment.
- ring plus it wipes your memory of having used it, so no guilt and no self-knowledge later.
- ring plus everyone gets one, so there's no asymmetry of advantage at all, just a world of invisible people.
- ring plus you don't know whether you'll be the bearer or the person it gets used on (so, the veil-of-ignorance version).
- a ring that only works on strangers you'll never see again, so impunity is real but distant.
- a ring that lets you do exactly one unjust thing ever, after which you're a better person to everyone for the rest of your life.
- you have the ring and find you simply don't want to use it.

Start from a node everyone can actually answer: would you take the ring, and if not, is that because you'd be found out, because you'd feel bad, or because you think using it would be bad for you. Then each further node should be a question about one of the cases above — does your answer survive the memory wipe, does it need a witness, does it need the unjust act to have a victim, is the answer something you could give from inside the case first-personally or only something we could say about you from outside.

Leaves: Platonist (injustice wrecks the soul of the unjust), Aristotelian eudaimonism, Hobbesian/contractarian where the real answer is the sovereign and the sanction, the view that morality's demands are only hypothetical imperatives resting on what you happen to want, Kantian/constructivist, Humean sentimentalism, divine command, error theory, fictionalism, and the anti-theory option where the question is confused because morality isn't one thing. Add what I'm missing and drop anything my cases can't actually reach.
