I've been reading about finks and masks on and off for years — mostly secondhand, through blog arguments rather than the papers — and I think I've found a masking case that isn't a philosopher's contrivance. Take an ordinary vision model that reliably labels photographs of cats as cats. Add a small adversarial perturbation to one of those photographs and the model confidently reports an ostrich. As I understand the distinction, that is masking: nothing about the network's weights changes, so the disposition to output 'cat' survives the trigger, and what blocks the manifestation is a feature of the input. Intact disposition, trigger present, no manifestation — masking on the nose, and a case that actually occurs rather than one we have to imagine.

What worries me is what follows. If maskers are that cheap, then for any dispositional claim about the network there is some input on which the manifestation is blocked, and any behavioral profile can be squared with any ascription: the model that answers 'ostrich' can be said, no less than the model that answers 'cat', to be disposed to answer 'cat'. Disposition talk then stops doing predictive work and merely redescribes whatever happened. I know finks and masks are supposed to embarrass the conditional analysis rather than disposition talk as such, but I can't see what is left to say once masking is this pervasive. So: is the case really a mask, and if it is, what does the dispositionalist say that isn't a restatement of the difficulty? My instinct is that it can't be a fink, since nothing about the model changes when the perturbation arrives — but I have been wrong about the fink/mask line before.
