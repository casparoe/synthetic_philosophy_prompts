The question was:

"Computational functionalism says that what gives a system a mind -- and so what would make it a candidate for moral status -- is having the right computational organization, not the material it happens to be made of. A familiar objection is that this makes mentality absurdly cheap: roughly, that any sufficiently rich physical system can be described as implementing just about any computation you choose, so if implementing the right computation is all it takes to have a mind, then even a rock would qualify. Does this objection succeed? And if it does, what does it tell us about which computations, if any, could matter morally?"

Student's answer:

Computational functionalism is the view that mental states are constituted by their functional roles rather than by any particular physical makeup, and its main selling point is multiple realizability. The same mental state -- say, being in pain -- could in principle be realized in neurons, in silicon, or in some other substrate, so it cant be identified with any one kind of stuff. That looks like the right starting point for ethics too: if what matters is the organization and not the chemistry, then there is no principled reason to assume that only carbon-based brains can be conscious or can deserve moral consideration. So far the functionalist is on solid ground.

The problem is the objection. Searle showed that any ordinary open physical system implements every finite-state automaton, which means that on the naive version of functionalism a rock would count as having a mind, and if having a mind is what grounds moral status, then the rock would deserve moral consideration as well. That cant be right, and it shows that the functionalist has to say something about which computations count. Chalmers tried to rescue the view, but as far as I can tell he ends up conceding the point: he agrees that the rock really does implement the automaton, and concludes that functionalists just have to accept that mentality of some minimal sort is extremely widespread, almost a kind of panpsychism. So the rescue attempt doesnt really help.

There is also a deeper issue about computation itself. Whether a system counts as implementing a given automaton depends on how you carve its states up, and there are always many equally good ways to do that, so the description is observer-relative. From this I think it follows that moral status would be observer-relative too -- whether something deserves consideration would depend on how we choose to describe it -- and that means functionalism cant give us an objective basis for ethics. Since an ethical theory that makes moral status depend on our descriptions is unacceptable, the objection refutes computational functionalism.

The real upshot is that we need some further constraint on which computations matter, and I think the constraint has to be that only computations realized in the right kind of causal structure -- the kind you find in a brain, where the states actually do the causal work of producing behavior -- could plausibly matter morally. A rock doesnt have that structure, so it drops out, and the moral boundary ends up tracking something like a certain kind of organized causal processing rather than mere describability. So the objection does succeed against the naive view, but a more careful version of functionalism can still tell us which computations matter morally.
