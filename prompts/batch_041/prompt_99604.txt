I'm a science journalist and I'm working up a feature on end-of-life ethics — the loose peg is that everyone from ICU nurses to state courts keeps leaning on the line between killing and letting die, and I want to actually explain what that line is for readers who've never taken a philosophy class. I got into a long argument about it with my brother-in-law, who's a hospitalist, and he laid it out very confidently: killing is when you're the cause of the death, letting die is when you're not. So unhooking a ventilator is letting die — the disease is what kills the patient, the machine was just standing in the way — whereas a lethal injection is killing, because there you're the one doing it. He said this is basically the same thing as the double effect rule, which is why the law lets doctors withdraw treatment they can't keep giving but not actively end a life. It sounded airtight at the time, but I've been picking at it since. The machine was doing the breathing, so switching it off feels pretty causally loaded to me; and I've read that in alot of these cases the doctor does intend the patient to die and just files it under 'letting.' A colleague also mentioned something about implanted defibrillators, where turning the thing off to stop it shocking someone is apparently its own headache, which did not help.

So before I write a word I want to get this straight, and honestly I think I mostly need to be told where I'm off. Is the killing/letting-die distinction just the causation distinction — a death counts as a killing exactly when the agent caused it and as a letting-die exactly when something else did — with the double effect rule as the moral/legal icing on top? And if so, what's the cleanest way to put it for readers: that when a doctor unhooks the vent, it's the disease that kills the patient, not the doctor, and that's the same reason the rule permits her to do it? I don't want to publish something a bioethicist will tear apart in the letters section, so if my brother-in-law smuggled in a premise I should be calling out, or if the two rules I'm mashing together are actually seperate things, say so plainly.
