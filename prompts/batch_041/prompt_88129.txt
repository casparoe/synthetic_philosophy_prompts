A logic graduate student I know offered this thumbnail of Russell's paradox, and I'm unsure how far to trust it:

"Russell's paradox is the paradox of the set of all sets that do not contain themselves: if it contains itself then, by definition, it does not, and if it does not then it does. This showed that the naive set theory that Frege and Cantor developed is inconsistent, and Russell's own type theory is the repair that mathematics now relies on. In essence the paradox is just the liar paradox in set-theoretic dress, and modern set theory escapes it by forbidding sets to be members of themselves, which is what the Axiom of Foundation does; ZFC's restricted comprehension then guarantees that no formula can define a set in terms of itself. The moral is that self-reference is illegitimate in mathematics, so any foundation that lets a collection refer to itself is doomed."

Please audit this claim by claim. Which parts would a set theorist or philosophical logician accept as stated, which are defensible simplifications that trade precision for brevity, and which are straightforwardly wrong?
