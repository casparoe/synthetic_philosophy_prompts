You are grading a problem set for an undergraduate course on decision theory and collective action. The problem and one student's response are below. Please assign a grade out of 10 and, more importantly, provide point-by-point comments that justify it: for each substantive claim the student makes, state whether it is correct, incorrect, or unsupported, and explain why. Where the reasoning is sound, say so briefly; where it is not, identify the specific step or claim that fails, and note anything important the student omits.

Problem. A single one-off action A can be carried out by any one of N agents, each acting independently and without coordination. As soon as any one agent performs A, it is done, and its consequences are borne by everyone. The true net value of A is a fixed quantity v that no agent observes. Each agent i privately receives a noisy estimate e_i of v and performs A if and only if e_i > 0. Suppose in fact v < 0, so that A is harmful. This situation is sometimes called the unilateralist's curse.

(a) Explain why A may nevertheless be performed, and how the probability that it is performed depends on N and on how the agents' estimates are correlated.

(b) A colleague proposes that each agent should act only when its estimate is well above zero, i.e., only when e_i exceeds some high threshold T. Assess whether this remedy solves the problem.

Student's response.

(a) Since each agent decides on the basis of its own estimate, and the action needs only one agent to proceed, the group is exposed to the largest of N judgments rather than to their average. Even if each estimate is unbiased, so that the chance any one agent wrongly gets e_i > 0 is small, the chance that at least one of them does rises with N, roughly like 1 − (1 − p)^N for a per-agent error probability p. So adding agents makes the harmful action more likely to be performed, even though no individual agent intends harm. The asymmetry matters: everyone bears the downside if A is performed, but any one agent's error is enough to trigger it, so the private calculation and the collective outcome come apart. The effect is at its worst when all the agents receive the same information and make the same mistake, because a single error is then replicated across the whole group instead of being averaged away.

(b) Raising the threshold helps: for any fixed T the per-agent error probability falls, and so does the group's chance of proceeding. But it does not solve the problem, because with a fixed threshold and enough agents, someone will eventually draw an estimate above T even when v is strongly negative, and pushing T arbitrarily high merely trades one error for the opposite one of failing to act when A would have been beneficial. The deeper remedy is to require broad agreement before acting, since the problem is precisely that uncoordinated individual action can commit everyone. This is essentially the diffusion-of-responsibility or bystander problem: because each agent knows that others might act, responsibility for the outcome is spread thin.
