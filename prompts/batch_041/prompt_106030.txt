I'm a second-year PhD student in philosophy preparing a proposal for a departmental workshop on epistemic logic and bounded rationality; the workshop will discuss a 6,000-word paper, and I need the proposal document itself, not the paper. My half-formed idea concerns the problem of logical omniscience. Standard epistemic logics validate closure principles — if an agent knows that P, and knows that P entails Q, then the agent knows that Q — and they also make agents know all logical truths. The usual responses, whether by adding impossible worlds, adding an awareness predicate, fragmenting the agent into sub-agents, or modeling inference as a procedure, each solve some cases by, I suspect, quietly changing the subject. What I want to argue is that the problem is not that the closure principles are false but that they are being asked to govern the wrong thing. There is a difference between what an agent is rationally committed to, given the questions they have asked and the distinctions they have drawn; what the agent would infer if they performed an inference; and what the agent explicitly endorses. Closure principles are plausible for the first, false for the second and third, and the literature's puzzles trade on sliding between them. The positive proposal I am imagining is a question-directed account: an agent's epistemic state is indexed to a set of live questions, and closure holds only relative to a question, not across all entailments. I want the proposal to say exactly what that indexing buys, what it costs, and whether it collapses into one of the existing views.
