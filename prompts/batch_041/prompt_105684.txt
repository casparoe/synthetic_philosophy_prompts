I've been working through the ontological argument on my own, mainly the modal version on which the existence of a maximally great being is supposed to follow from the bare possibility that such a being exists, and I want a consistency check before I decide what I actually think. Here is where I've landed.

(a) The core inference is valid. If it is possible that a maximally great being exists, then it exists, because a being that existed in some possible worlds and not others would not be maximally great.

(b) The possibility premise is the whole game, and I lean toward accepting it. I can conceive of a maximally great being without running into an obvious contradiction, and I cannot see what would make the conception incoherent.

(c) Conceivability is a real but fallible guide to possibility. It can be defeated, but it is not nothing, and I do not want to give it up.

(d) The argument only goes through in a modal setting where whatever is possible is necessarily possible, and I think that principle is correct for metaphysical possibility in general.

(e) You cannot define anything into existence. No version of this argument can be a proof; at best it displays what a person's existing commitments already force on them.

(f) Greatness cannot include existence. Existing is not a feature that adds to a thing the way being powerful or being knowledgeable does.

I have read that in some of these modal arguments there is a technical side-effect: once you grant the premises, everything that is true turns out to be true necessarily, so the distinctions between what must be, what merely is, and what could have been otherwise all collapse. I cannot tell whether that is a genuine reductio of the premises or just an artifact of how the argument gets formalized.
