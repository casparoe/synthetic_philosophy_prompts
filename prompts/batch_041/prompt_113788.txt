I am a novelist who writes about artificial minds and who teaches a graduate seminar on the ethics of autonomous systems, and I am drafting the final examination. I want one essay question on the topic of low-impact AI—specifically, on whether "avoiding side effects" can be defined without a full specification of value. The question must not be answerable by reciting the standard top-down/bottom-up taxonomy, and it must be self-contained: my students will have no internet access, so it cannot ask for citations, bibliographies, or reading lists. To keep it from being a rehearsal of familiar material, I want the question built around the following proposal, which I have invented for the exam and which you should treat as the object of analysis:

"An action is low-impact relative to a task specification T if and only if it does not change the value of any variable not included in T, where T is a complete description of the task's goal state. On this definition, an agent can avoid side effects without any general specification of what is valuable."

The essay question should require students to do all of the following, in an order that makes for a coherent argument rather than a checklist: distinguish a side effect from an unintended consequence and from an unforeseen consequence; explain why the proposal faces a circularity or underdetermination problem, since T must already include everything that matters if the agent is to tell which changes count as side effects; work through a concrete case—an agent tasked with making coffee in a kitchen who breaks a vase—and say whether the vase's breaking is a side effect, what changes if the task is described as "make coffee without breaking anything," and what changes if the designers value the vase but omit it from T; assess the baseline problem, namely that "low-impact" is relative to a counterfactual, so that if the baseline is the status quo every action is high-impact, while if the baseline is "what would have happened anyway" almost nothing is high-impact; and finally say whether any formal measure of impact—for example, the expected difference in value between the actual trajectory and a default trajectory—can avoid presupposing a value function, and if not, why not.

The question should be answerable in ninety minutes. Please write the question, a model answer of about seven hundred words, and a marking scheme worth twenty marks. The marking scheme should name the specific moves a top answer must make—the distinctions it must draw, the counterexamples it must consider, the conclusion it must reach—and should identify the specific errors that should cost marks, such as treating "side effect" as a merely causal notion, assuming that a task specification can be complete without a value theory, or concluding that low-impact AI is impossible rather than that it inherits the specification problem. Do not require or supply any citations. End with a single line beginning "Summary:" that states in one sentence what the question is designed to test.
