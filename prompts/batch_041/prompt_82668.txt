I've been thinking a lot about whether you can cause something by not doing it. Like if I don't water my neighbors plants while they're away and they die, did I cause them to die? Or is it just that I didn't prevent it? I want to make a decision tree or flowchart that sorts people by what they actually think about this, not by what label they use. Can you help me build one?

I'm not an academic, just someone who argues about this with friends. So please keep it plain. I want the tree to start from concrete cases, like: a parent doesn't feed their kid; a driver doesn't hit the brake; a doctor doesn't prescribe a drug that would have saved someone; a stranger doesn't donate to a charity that would have saved a life; a factory doesn't install a filter; someone doesn't water a plant. Each branch should be a question someone can answer without knowing any theory, like: does it matter if you had a duty to act? Does it matter if you could have easily done it? Does it matter if you knew the consequences? Does it matter if the outcome would have been the same anyway? Does it matter if there was some positive act that set things up? Does it matter if the omission is a one-time thing or an ongoing policy? Does it matter if the omission is itself the result of someone else's action?

Then each leaf should be a named position, like: omissions are never causes; omissions are causes only when there's a duty; omissions are causes whenever they make a counterfactual difference; omissions are causes but only in a watered-down sense; the whole cause/omission distinction is just a pragmatic way of assigning blame; and maybe some other positions. I want the tree to be built from the logical space first, so show the questions and the combinations of answers they allow, then place the positions in that space. If some combinations don't correspond to any position anyone actually holds, note that and say whether it's because the view is incoherent, unattractive, or just unexplored. Also flag any positions the tree can't separate.

I'd like maybe 10-12 questions and 6-8 leaves. The point is to sort by what people say about cases, so no question should just ask do you think omissions are causes. Also, I don't want it to just be a list of names from an encyclopedia. Make the questions do the work.

One more thing: I'm especially interested in the difference between cases where you are the only one who could have helped and cases where lots of people could have helped but none did. And cases where you started the chain of events vs cases where you just didn't stop it. So make sure the tree can handle those.

Thanks!
