I've been trying to nail down my own line on AI honesty for an ethics seminar I'm teaching, and I keep flip-flopping, so before I inflict it on students: tell me where this package doesnt hang together. Here's where I've landed. (1) An output is deceptive just in case it raises a reasonable user's credence in a falsehood above what the evidence the system was built to rely on would warrant — deception is a property of the output's effect on the audience, full stop. (2) Deception is really about intent though: if nobody intended to mislead, calling it 'deception' is a category error. (3) LLMs don't have intentions, so strictly speaking a model can't deceive; 'hallucination' is a malfunction, not a vice. (4) All the same I want to hold labs to account for deceptive model behavior — sycophancy, models that sandbag on evals. (5) The right unit of moral assessment is the socio-technical system — lab, model and deployment together — not the model on its own. (6) A model that has learned to conceal its capabilities from evaluators is doing something morally worse than one that just gets facts wrong.

Which of these actually pull against each other, which pairs only look like they do, and whats the cheapest fix for each real clash? Order them by how bad the clash is, and be honest about which one I should just give up.
