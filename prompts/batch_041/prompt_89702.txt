Question: 'Goodhart's law is often summarized as "When a measure becomes a target, it ceases to be a good measure." But people sometimes distinguish several different mechanisms by which this happens. Name and explain at least three distinct mechanisms, and give a concrete example of each that is not just the same example repeated.'

Student answer: 'Goodhart's law is named after the economist Charles Goodhart, who studied monetary policy. The anthropologist Marilyn Strathern later generalized it to the quote above. There are four main mechanisms. Regressional Goodhart is when you select for a proxy that is correlated with the goal, but because the proxy is noisy, selecting for high proxy values also selects for noise, so the proxy becomes less useful. For example, if you select for height as a proxy for basketball ability, you'll get tall people who aren't good at basketball. Extremal Goodhart is when optimization pushes the system into a region of state-space where the old correlation no longer holds. For example, a factory that optimizes for number of widgets produced might push workers so hard that they start making defective widgets, so the correlation between widgets and profit breaks down. Causal Goodhart is when the act of using the measure as a target causes the relationship to break down, like when a university rewards professors for citations and they start citing each other more. Adversarial Goodhart is when an agent with different goals than the regulator deliberately games the metric, like a student who writes a longer essay because the teacher grades by word count. The last two are basically the same, though, because in both cases someone is gaming the system.'
