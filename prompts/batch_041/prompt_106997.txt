I hold a particular view about the reference class problem, and I want a rigorous map of what would count against it rather than a survey of the literature.

The view: For any singular event — this coin toss, this patient's response to a drug, this defendant's probability of reoffending, this model's probability of behaving deceptively in deployment — there is a single objective probability, fixed by the most causally homogeneous reference class into which the event can be placed. The multiplicity of reference classes is therefore an epistemic predicament, not a metaphysical indeterminacy: there is a fact of the matter about the correct class, and our difficulty is only that we seldom know enough to identify it, or have data from which to estimate a frequency within it. To give the view something to bite on, I would add a criterion: the correct class is the narrowest class containing the event that satisfies two conditions — (a) we possess a stable, non-degenerate frequency for it, and (b) no further statistically relevant property partitions it.

Tell me what would have to be true for this to be false, and which of those conditions are live rather than merely logically possible. In particular:

- Which objections are decisive and which are merely awkward? I am most concerned about two. First, that any class can be subdivided without limit, so that "the narrowest causally homogeneous class" either never terminates or terminates arbitrarily. Second, that in a deterministic world the maximally specific class yields probability 0 or 1 for nearly everything, so the objective probability the view posits is either trivial or, in practice, unavailable.
- Does my criterion actually do the work I want, or does it collapse — for instance because statistical relevance is itself defined relative to a reference class, making the criterion circular, or because the narrowest class for which data exist is an artifact of how the data were collected rather than a fact about the event?
- What does the view predict, or forbid, that its rivals do not — subjectivism about singular probability, the view that such probabilities are indeterminate, and the view that the reference class is simply whatever is decision-relevant?
- What would a committed defender concede as genuinely counting against the view, as opposed to dismissing as a confusion?
- Has the view been insulated into unfalsifiability? If the correct reference class is defined as whatever class yields the true probability, the position threatens to become trivially true. Is that a fatal defect or an acceptable feature of a view of this kind?

I would be most moved by a case in which two classes, each causally homogeneous in its own right, yield conflicting probabilities — that would show the criterion is not merely incomplete but inconsistent. The two applications I care about most are self-locating reasoning, where the choice of reference class (one's own position among observers, say) seems to carry all the weight, and forecasting under deep uncertainty, where there may be no stable class to condition on at all. If either is a place where the view has no purchase, I would rather hear it plainly.
