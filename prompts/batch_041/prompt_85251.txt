I am a high school senior preparing a fifty-minute session and a companion handout for our school's philosophy and mathematics club, on the debate over imprecise probabilities: the thesis that a rational agent's credence in a proposition need not be a single real number, but may be an interval or a set of permissible probabilities. My classmates have had calculus and one statistics course, and they will object to anything that looks like hand-waving, so the handout has to do the sorting on its own. Please write me a decision tree — an indented outline is fine — that begins from the weakest commitment I can fairly ask the group to share, namely that it is worth asking whether credences must be sharp, and proceeds through branch points phrased as questions a reader can answer without already knowing any of the labels, ending at the positions people actually defend. Label each branch with the question that separates it from its siblings, and give each leaf the name of the position (or an honest unnamed, if no one defends it) together with one sentence stating its most awkward commitment.

The following distinctions need to appear somewhere on the tree, in whatever order yields the cleanest logic:

1. whether the imprecision belongs to the agent's state, or only to a modeller's description of an agent who is in fact sharp;
2. whether the state is fully captured by a set of sharp probability functions, or requires something else — lower and upper expectations that no set of probabilities reproduces, a set of acceptable bets, or merely an incomplete comparative ordering;
3. whether the permissible functions must be closed under mixing, and what the view says about dilation, the case in which conditioning on evidence the agent regards as irrelevant widens the interval;
4. how the state is updated: conditionalizing each permissible function separately, applying a rule that returns a single updated interval, or allowing conditional credences that are not determined by the unconditional ones;
5. whether imprecision is merely permitted or in some cases rationally required, for example when you know a coin is biased but have no information about its direction;
6. how credence connects to choice: admissibility, understood as an option being permissible if it maximizes expected value for at least one permissible credence, versus maximality or a worst-case rule;
7. whether an imprecise state can be accuracy-dominated by some sharp state, and if your view denies this, how a set of probabilities is being scored instead.

I would also like a branch on whether the agent knows the extent of their own imprecision — the case in which someone's interval is [0.3, 0.5] and we ask what their credence is that their credence lies in [0.3, 0.4].

At least these positions should turn up as leaves: the view that only sharp credences are rational and imprecision is an artefact of our ignorance; the view that identifies a credal state with the set of bets its holder finds acceptable; the robust Bayesian view with convex representors and admissibility-based choice; the view that treats dilation as a reductio of imprecision rather than a tolerable curiosity; and an accuracy-first defence of imprecision. Aim for eight to twelve leaves.

Where the tree cannot separate two positions, name the pair and say so rather than manufacturing a distinction; I suspect at least one pair will resist separation, perhaps a generalized-Bayes view with convex representors and an accuracy-first view that also endorses convex representors, if they coincide on every question the tree can ask. Where a combination of answers corresponds to no defended view, mark it and say whether you take it to be incoherent, merely unattractive, or simply unexplored. I do not need citations, dates, or a reading list; describe each position in plain language and use a standard name only where one exists.
