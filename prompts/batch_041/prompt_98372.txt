I'm making a handout for a philosphy of biology reading group — grad students, plus a couple of molecular biologists who roll their eyes whenever anyone says 'information'. What I want is a decision tree that takes someone from the harmless-looking starting point 'yeah, DNA carries information about proteins and traits' to a specific, nameable view about what that information-talk actually amounts to. The point is to sort people by what they'll say about hard cases, not by which camp they think they belong to, so no node should be answerable by just picking a label.

Each branch node should be one question, phrased so a student can answer it without knowing which leaf it leads to. I think the load-bearing distinctions are something like: (1) Is 'information' here just correlation/causation — the sequence covaries with the protein — or does it require something like a sender, a convention, or a purpose? (2) If there's a code, does it have to be arbitrary (a frozen accident that could've been otherwise, like the mapping from codons to amino acids) or can it be grounded in chemistry and stereochemistry? (3) Does representing require a consumer — some system that uses the signal to do something — or can a molecule represent all by itself, sitting there in the dark? (4) Is the 'genetic program' a real explanatory posit or a leftover metaphor from computing? (5) Is the information in the sequence, or in the interaction between sequence and cellular context — same sequence, different cell state, different outcome, i.e. instructional vs. contextual? (6) does the amount of info track causal specificity — does a cause carry more information the more precisely it controls the effect, so DNA that's necessary but wildly insufficient for a range of outcomes carries very little? (7) do non-coding RNA, or the same stretch read in two frames, or a prion-style templating case change anything?

Leaves should include at least: DNA is a code in basically the same sense as a human code or a language; DNA carries information only in the thin causal-correlation sense and 'code' is a metaphor that should be retired; it's genuinely representational but only because a cell/consumer uses it for a function (the teleological/consumer view); the code is real but it's the arbitrariness that makes it a code; information is relational/context-dependent so it isn't located in the sequence at all; and whatever eliminativist or dual-aspect option falls out of the tree. Each leaf gets a name (or 'unnamed') plus one sentence on its most awkward commitment.

Also: flag any two leaves the tree can't actually pull apart, and say which regions of the logical space come out empty, with a quick diagnosis of why — incoherent, unattractive, or just unexplored. Aim for six to nine branch nodes and roughly six leaves. Don't cite anything, just build the thing.
