Consider the anti-mechanist argument, in the tradition of Lucas and Penrose, that Gödel's incompleteness theorems show the human mind cannot be, or be modelled by, any Turing machine. The argument runs roughly as follows. For any consistent, effectively axiomatized formal system F strong enough for arithmetic, let G(F) be its Gödel sentence — a sentence equivalent to the claim that F does not prove it. If F is consistent, then G(F) is true yet unprovable in F. The human mathematician, the anti-mechanist says, can nevertheless recognize the truth of G(F), and so is not F; and because the same move can be made against any candidate F, the human is not any machine at all.

A natural line of resistance is the bootstrapping reply. Grant that a fixed system F is stumped by G(F); a machine need not stay fixed. Let a reflection machine be a single program that starts from some system F0 and, at each stage, forms the next system by adjoining the Gödel sentence of the current one as a new axiom, so that its successive systems are F0, F0 + G(F0), and so on. The proposal is that such a machine keeps pace with the human's insight and therefore escapes the anti-mechanist conclusion.

Write an essay assessing that proposal. Argue on the merits rather than by appeal to secondary literature, and address at least the following questions. First, if the reflection machine is treated as one program whose output is the union of its successive systems, is that output itself a single formal system, and if so, what can the anti-mechanist say about it? Second, is recognizing the truth of a Gödel sentence the same as being able to prove it in some extension, and what work is done here by soundness as opposed to mere consistency? Third, does the dispute ultimately turn on whether a human can identify the formal system, if any, that captures her own arithmetical competence?

Reach a definite verdict — that the reflection machine rescues mechanism, that it does not, or that the anti-mechanist argument succeeds against some candidate machines but not others — and defend it against the strongest objection you can construct.
