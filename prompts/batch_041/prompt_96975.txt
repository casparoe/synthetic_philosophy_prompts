I was argueing with a friend in a bar about whether history is locked in—he's a physics PhD and thinks philosophers make too much of contingency. He gave me this argument and I can't find the exit. (1) Every event is fully caused by prior events. (2) If an event is fully caused by prior events, then given those events it could not have failed to occur. (3) So every event that happens is necessary given the total state of the world just before it. (4) If an event is necessary given the total prior state, then it would also have happened if we changed some small earlier detail—say, if a messenger had tripped, or if a particular battle had gone the other way. (5) So no outcome depends on any particular small event; if the Black Death hadn't happened, something like the Renaissance would have come anyway; if the printing press hadn't been invented in Europe, something like it would have appeared elsewhere; if the internet had been delayed, something like it would have arrived. (6) Therefore path dependence is an illusion—history is convergent, like eyes evolving independently in many lineages. (7) So the QWERTY keyboard, English as a lingua franca, and the particular shape of the US Constitution were all inevitable in the relevant sense.

I think (7) is absurd, but I also don't want to give up (1) or (2), because I'm not even sure I believe in uncaused events. Where does this go wrong? Which premise or step should I reject, and what does rejecting it cost—what do I have to give up about causation, counterfactuals, or the idea that history is locked in? I'd rather keep (1) if I can, but I'd give up (7) in a heartbeat.
