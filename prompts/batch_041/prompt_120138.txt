I spent last night losing an argument with a friend who insists that two-dimensional semantics is eliminable — that a "primary intension" is just a description plus a possible world, and that once you have the description the diagonal has no work left to do. I want to send him a poem that makes the case I couldn't.

Write me a pantoum on two-dimensional semantics: quatrains in which the second and fourth lines of each stanza return as the first and third of the next, and the poem closes by folding back into itself, so that its last line is its first line and the third line of the opening quatrain is its second-to-last. The recurring lines should be word-for-word identical wherever they appear, but the world around them must keep changing — begin on Twin Earth if it helps, or with a name whose reference was fixed by a description the world then defeated — so that the same words pick out different things as the surrounding world varies. The earlier occurrences should read as something you could know without investigating the world, the line simply following whatever the world supplies; the return to the opening lines should land on the diagonal, where the world the poem has been treating as actual turns out to be the one it is written in, so that the line, anchored there, reads as rigid and a posteriori — holding in every world the poem has visited, yet knowable only once you have learned how this one turned out. Keep it accurate enough that someone who works on this doesn't wince, and let the form carry the argument rather than the poem explaining itself.
