I am trying to find the established term, if there is one, for a phenomenon that arises when an expected-utility-maximizing agent is embedded in a universal prior. The setup is this. We have a prior over computable hypotheses that assigns each program a weight falling off exponentially with the length of the program. The agent is itself a finite program. It uses the prior to form beliefs about its environment and to choose actions. Because the agent's own code is a finite string, the prior assigns non-negligible probability to hypotheses on which the agent's current computation is being simulated by a shorter program. On those hypotheses, the agent's observations—and its very deliberation—are generated by the simulating program rather than by the world the agent takes itself to inhabit. The agent must therefore treat its own decision procedure as part of the evidence it conditions on. The upshot is a systematic tilt: the hypotheses that predict the agent's choices are also the hypotheses under which those choices are most likely to be made, so the prior is not neutral with respect to the agent's reasoning. In the extreme case, the shortest hypotheses consistent with the agent's observations may be ones on which it is being simulated by a more powerful predictor, because those hypotheses can account for the observations without positing a full external world. Is there a name for this phenomenon? If there is an established term, what is it, and how exactly is it defined? If not, can you coin a term and distinguish it from the nearest concepts—for example, the ordinary problem of self-reference in decision theory, the simulation argument, the problem of logical uncertainty, and the embedded agent problem? I am less interested in the label than in the carving: what exactly the phenomenon is, what it is not, and where its boundaries lie.
