My line is that the whole row is a type error. There are two different 'exists' in play. One is tensed: 'the dinosaurs exist' is false and 'this sentence exists' is true, and which is which changes with the clock. The other is untensed: dinosaurs exist in the sense of 'dinosaurs are in the world's inventory', true whenever you say it. Presentists treat the tensed one as basic and read the untensed one as a summary of tensed facts. Eternalists do it the other way round. I want to say both are legitimate and neither reduces to the other, so 'does the past exist?' has no single answer until you say which 'exists' you mean.

The analogy I lean on: the universe as a git repo. Every commit is in the history and stays there — that's the eternalist picture, and it's just true of git. HEAD is the working tree; only one commit is checked out. A presentist says only HEAD is real. I want to say HEAD is real and the rest of the history is real too, but in different ways, so 'real' is doing different work in 'HEAD is real' than in 'that commit is real'. Though git history can be rewritten — rebase, amend — so the past isn't fixed the way the block universe says it is.
