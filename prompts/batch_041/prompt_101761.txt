ok, low-impact AI / side-effect avoidance. before i read another proposal for an impact measure i want to know what one would actually have to do to be any good. so write me the desiderata list for "an impact measure" -- what any adequate measure of an agent's side effects has to deliver, with the case behind each requirement.

the kind of things i mean (you tell me which are real requirements and which are just one camp's taste): it has to not block the agent from doing its actual job; it has to not collapse into "do nothing" or "the safest move is no move"; it has to be computable and not require the true value function as an input; it has to be usable during training when the reward is unknown; it has to survive the fact that *every* action changes the world, so "side effect" needs some baseline; it has to not be gameable by an agent that can manipulate the measure itself; it has to treat effects on the agent and effects on the world consistently; and it probably has to distinguish intended from unintended effects, which already sounds like it needs to know what the agent was supposed to do.

the part i most want is where you flag which requirements can't all be had at once. my suspicion is the whole thing is circular: calling something a "side effect" presupposes some notion of what the agent was meant to do or what's valuable, and if you've got the full value spec you don't need a separate impact measure, while if you don't, the measure either treats everything as a side effect (paralysis) or smuggles in a baseline that's just a value judgement in disguise. tell me if that's right, and which single requirement does the most to rule candidates out. a couple of the named proposals (the ones about preserving attainable utility, and the ones about keeping options reachable relative to a baseline) can get a short score against the list if that helps, but keep the weight on the criteria, not the scorecard.

be straight with me about what's settled here vs what's genuinely contested among people who actually work on this -- don't hand me one camp's view dressed up as the consensus, and if the list is itself a contested object, say so. also a table is fine for the requirements, i won't be offended.
