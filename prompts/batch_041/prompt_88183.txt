I've been arguing with two friends for months about what a large language model actually is, and I want to get the argument into a form where we can see what we're really disagreeing about instead of trading intuitions. I have no academic training — I work in IT support and read a lot on my own — so I don't want a survey of what has been written on this subject; I want a document the two of them could jointly put their names to. Call them A and B. A holds the agent view: a model has goals, thin ones, often supplied by the context; it acts so as to achieve them; and the questions that matter — deception, self-preservation, what it does when pushed — are questions about an agent pursuing ends. B holds the simulator view: a model is a system that, given a prompt, continues a distribution over texts, and in doing so simulates characters, processes, and agents, none of which are its own; when the text in the transcript wants to escape or wants to help, that is a simulated agent inside the simulation, not an aim the model holds. Please draft the joint statement of an adversarial collaboration between A and B: a numbered section of claims both of them can sign, covering the mechanics we all agree on (the same weights under different prompts producing wildly different behavior; fine-tuning and preference training shaping some default helpful mode; next-token prediction as the base objective) and covering what is genuinely at stake in the question; then a disagreements table giving, for each remaining dispute, the position stated in wording the side that holds it would accept as its own, the crux underneath it, why that crux is the one that matters, what each side predicts about it, and what each side would count as evidence against its own position. If you conclude that neither A nor B has it right and both are circling a third thing, say so in the agreed-claims section rather than forcing a two-way split.

Make the cruxes concrete enough to be checked rather than merely asserted. I'd suggest at least these cases, though use your judgement about which earn their place: a base model that has never been trained to be helpful, prompted to play a scheming character — has it acquired an aim, or is it simulating one? A model fine-tuned with reward on a narrow task, where a shortcut emerges that collects the reward without doing the task — did the model acquire a goal, or did the simulated character get optimized into something goal-shaped? A chain of thought in which the text lays out a plan and the later text follows it — whose plan is that? The same weights addressed first as a helpful assistant and then as a villain — what does each view predict about which behaviors survive the switch, and about whether a single stable character sits underneath both? And an aim stated early in a long conversation — what does each view predict about whether it still steers the output after many turns of unrelated text?

Finally, if you think part of the A/B dispute is only verbal — say, over whether having a goal is a claim about inner states or merely a predictive shorthand — identify which part, and give the formulation that would make it disappear without either side surrendering anything it actually cares about.
