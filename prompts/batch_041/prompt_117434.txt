I am assembling the final examination for a graduate seminar covering decision theory, game theory, and the theory of delegation, including a unit on safe Pareto improvements in delegated game playing. I would like one essay-style question on that unit, together with a model answer and a marking scheme. The question should test whether students understand what the word "safe" is doing in the phrase, rather than whether they can reproduce a definition.

Build the question around a concrete delegation scenario. Use a one-shot two-player game with the payoff structure of a prisoner's dilemma: mutual cooperation yields each player 3; if Row cooperates and Column defects, Row gets 0 and Column gets 5; if Row defects and Column cooperates, Row gets 5 and Column gets 0; mutual defection yields each player 1. Row and Column each delegate their move to a program submitted in advance, and a program may read the other program's source code and output either C or D. Let Row's default program d be the one that outputs D no matter what the other program does, and let the candidate program p be the one that outputs C exactly when the other program, run against p, outputs C.

Define a safe Pareto improvement in the question as follows: p is a safe Pareto improvement over d relative to a set Q of possible opponent programs if, for every q in Q, the payoff pair produced by (p, q) weakly Pareto-dominates the payoff pair produced by (d, q), and strictly Pareto-dominates it for at least one q in Q. The question should have three parts. The first part should fix a small, explicitly listed Q — the unconditional cooperator, the unconditional defector, and the program that mirrors the other program's output — and ask whether p is a safe Pareto improvement over d relative to that Q, with students required to compute the relevant payoff pairs. The second part should ask the same question when Q is the set of all programs whatsoever, requiring students either to exhibit a counterexample program or to argue that none exists; the purpose of this part is to expose how much the concept depends on how the set of plausible opponent programs is delimited. The third part should contrast the definition above with a weaker one on which p merely has to weakly Pareto-dominate the default outcome of mutual defection and strictly dominate it somewhere; students should explain what the weaker definition misses and why the opponent-relative comparison is the one that captures the motivation for the concept.

The question should be answerable in roughly 60 to 75 minutes and be worth 20 marks, divided across the three parts. Please write the question, a model answer of about 700 words that works through the payoff pairs carefully and states each conclusion explicitly, and a marking scheme that names the specific moves an A answer must contain, the specific errors that should cost marks — for example, conflating "better than the default outcome" with "safe," or treating the set of plausible opponent programs as a given rather than as the central modeling choice — and the marks attached to each move. The question must be self-contained: do not require students to cite any literature or to name any particular paper.
