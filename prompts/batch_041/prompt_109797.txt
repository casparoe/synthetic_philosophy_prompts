I am a high school student preparing a session for my school's math and economics club, and I would like a decision tree that sorts a person's view of fair bargaining by which axiom they refuse to give up, rather than by which solution they can name. Begin from the bare setup — two bargainers, a set of feasible agreements, a disagreement point, and no procedure specified — and make each branch node a single question about what a bargaining outcome must satisfy: Pareto efficiency, symmetry between the bargainers, invariance to how each person's utility is scaled, independence of irrelevant alternatives, monotonicity when the feasible set grows, and whether the disagreement point fixes an entitlement or is merely a fact about what happens if talks fail. The leaves should be the Nash solution, the Kalai–Smorodinsky solution, the egalitarian solution, a greatest-sum rule, a maximin rule, and the view that no single rule is rationally required, each carrying one sentence naming its most awkward commitment. Phrase every node so it can be answered without knowing which solution it leads to, mark any combination of answers that no one defends and say whether it is empty because it is incoherent or merely unexplored, and flag any two leaves the tree cannot separate.
