EXAMINATION QUESTION 3 (15 marks)

Naive comprehension is the schema according to which, for any condition φ(x), there exists a set {x : φ(x)} whose members are exactly the things satisfying φ.

(a) [4 marks] Reconstruct Russell's derivation and state precisely what it refutes. Identify the feature of the comprehension schema on which the derivation depends.

(b) [4 marks] Consider the following proposal, to be called Q. Retain the comprehension schema, but restrict it to conditions that (i) contain no quantifiers and (ii) contain no reference to the set being defined. Does Q block Russell's derivation? Justify your answer.

(c) [7 marks] Consider the following proposal, to be called SMB. Retain the comprehension schema in full, and add as a further axiom the statement that no set is a member of itself. Does SMB block Russell's derivation? Justify your answer. Then say whether the remedy adopted in standard axiomatic set theory (ZF) is equivalent to Q or to SMB, and if not, what that remedy is.

STUDENT'S ANSWER

(a) Assume the comprehension schema in its unrestricted form. The condition x ∉ x then determines a set, R, whose members are exactly the things that are not members of themselves: for every x, x ∈ R if and only if x ∉ x. Instantiating this equivalence at R gives R ∈ R if and only if R ∉ R. So if R ∈ R then R ∉ R, and if R ∉ R then R ∈ R; either way we are forced to deny the assumption we began with. The derivation therefore refutes the unrestricted comprehension schema, and with it any theory that entails that particular instance of the schema, for the condition x ∉ x — including Frege's, since the value-range principle of the Grundgesetze assigns a value-range to every predicate. What the derivation exploits is simply the schema's guarantee that a set exists for each condition. The condition itself mentions no set and contains no quantifiers, so nothing turns on any circularity in the specification of R; the argument requires no set-theoretic axioms beyond the instance of comprehension it uses.

(b) Q does not block the derivation. The condition x ∉ x is quantifier-free and makes no reference to R, so it satisfies both of Q's restrictions. The instance of comprehension that yields R is therefore still licensed, and the argument of (a) runs unchanged. Restricting comprehension to conditions that do not mention the set being defined may block other paradoxes, but it accomplishes nothing here.

(c) SMB does block the derivation. Under SMB no set is a member of itself, so the condition x ∉ x is satisfied by every set, and R is simply the universal set V, the set of all sets. The difficulty in (a) came from having to ask whether R is a member of itself; under SMB that question is settled in advance, since nothing is a member of itself. So V ∉ V, and no contradiction arises. SMB is thus a genuine repair, and it is in essence the repair that ZF adopts. ZF is a typed theory in Russell's sense: sets are arranged in a cumulative hierarchy of levels, a set can only be formed from sets at lower levels, and the axiom of foundation rules out the self-membership and the circular constructions that generated the paradox in the first place. Separation survives only as a restricted form of comprehension, and it is the hierarchy, rather than any restriction on which conditions may define sets, that does the real work. ZF also proves that there is no universal set, which is what one would expect if the object R of (a) is not to be available.
