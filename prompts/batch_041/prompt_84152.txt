The background, in case it helps: there's this result in game theory where, if you let each player in a one-shot Prisoner's Dilemma submit a *program* instead of just a move, and each program is allowed to read the other player's source code before it outputs cooperate or defect, then mutual cooperation can be an equilibrium. The basic construction has each program essentially saying: I'll cooperate if the other program, reading my code, would cooperate. There are later versions that get the same effect without simulating the other program at all, using self-referential proof instead -- which matters, because in general you *can't* compute what an arbitrary other program will output, so what's really doing the work is the programs reading each other's source, not predicting each other's behaviour. And that last bit is the thing I can't stop thinking about.

My half-idea: the whole setup assumes the code is transparent and cheap to read. Everyone waves that through as a modelling convenience. But I suspect it's not a convenience, it's the load-bearing assumption, and the interesting question is what happens as you weaken it. If I can only read, say, 80% of your code, or the code is obfuscated, or reading it costs me something, or you wrote yours in a different language than mine -- does cooperation unravel gracefully or catastrophically? Is there a threshold? Does it matter *which* parts are hidden? And here's the bit I care most about: in the full-transparency case, cooperation comes from *inspection* (I read your code and it tells me what you'll do when you read mine), not from *prediction*. So I want to know whether the phenomenon is really about mutual transparency of source, or about something weaker like mutual commitment or mutual recognizability. If it's the weaker thing, then program equilibrium isn't doing anything new and the philosophical literature that treats it as a solution to the one-shot PD is overclaiming. If it's really the transparency, then the "solution" only works in a world where decision procedures are legible to each other in a very strong sense -- which is an interesting claim in its own right, almost a formal cousin of the idea that cooperation needs recognition rather than just aligned interest.
