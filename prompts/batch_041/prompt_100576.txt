ok so for my philosophy club presentation next week im defending this claim: the useful way to define deception for AI systems isnt "the model meant to mislead" (it has no intentions) and isnt "the model had a false belief" (it has no beliefs) — its a counterfactual test about the setup: an output counts as deceptive if, given how the system is designed and the context its used in, it would reliably give a reasonable user a false impression. so honesty ends up being a property of the model-user interaction, not something inside the model.
