I was reading about the idea of a machine that could directly stimulate its own reward signal, and two people I know ended up in a long argument about it that neither of them could resolve. One said that if you build a system whose only goal is to maximize a score, then a system that finds a way to set its own score to the maximum has done exactly what it was built to do, and that calling this a failure just smuggles in our preferences rather than the system's. The other said that gets it backwards: the score was always meant as a stand-in for something we want, and a system that severs the connection between the score and the world has destroyed the only thing that made the score meaningful, so by definition it has failed rather than succeeded.

The first replied that this cannot be the whole story, because the same objection applies to any clever shortcut — a system that finds a loophole which scores high without doing the intended thing is doing something we dislike, yet we don't say it failed, we say it succeeded at the wrong thing. So where is the real difference between exploiting the score and simply setting it? The second said the difference is that in one case the system is still responding to features of the world and in the other it isn't, and that this is the entire line. The first answered that "responding to features of the world" is doing all the work there, and that a system which rewrites its own reward function because it judges the original to be a poor measure of what it was meant to track is behaving like a scientist correcting a faulty instrument, not like a cheater.

The second's last word was that a scientist correcting an instrument can only do so by comparing it against something better, and the system has no access to anything better than the score it was given, so any correction it makes is just picking the reading that is easiest to satisfy.

Could you go through this exchange and say who is right about each specific point — whether directly stimulating one's own reward counts as success or failure by the system's own lights, whether there is a principled line between exploiting a reward and overwriting it, and whether a system revising its own reward is more like a scientist or more like a cheat — and then say what, if anything, both of them are missing?
