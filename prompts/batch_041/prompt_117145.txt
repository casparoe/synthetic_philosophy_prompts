Question:

"In the standard possible-worlds model of knowledge, an agent knows a proposition just in case it is true in every world compatible with what she knows. Explain how this model gives rise to the problem of logical omniscience. Then assess the following proposal: an agent knows a consequence B of her knowledge base Γ only if every atomic proposition occurring in B also occurs somewhere in Γ (the containment condition). Does the containment condition solve the problem? Does it create new problems? Justify your answer."

Answer:

"The problem of logical omniscience is that the standard possible-worlds model treats agents as knowing all logical truths and all logical consequences of what they know. Because logical truths are true in every possible world, they are true in every world compatible with what the agent knows, so the agent knows them. And if the agent knows A and A entails B, then in every compatible world A is true, so B is true, so the agent knows B. This is unrealistic: a finite agent like a student may know the axioms of arithmetic but not know every theorem, and may know P and P→Q without ever having put them together to conclude Q.

The containment condition says that a consequence B counts as known only if every atomic proposition in B occurs somewhere in the agent's knowledge base Γ. This blocks the worst cases. For example, if the agent knows 'It is raining' (R) but has never considered snow, then 'It is raining or it is snowing' (R∨S) is not known, because S does not occur in Γ. Similarly, if the agent knows the axioms of arithmetic, she does not automatically know '2+2=4 or the moon is made of cheese', because 'the moon is made of cheese' does not occur in the axioms. So the containment condition solves the problem.

The condition also preserves the inferences we care about. Modus ponens is preserved: if the agent knows P and P→Q, then Q is a consequence, and Q occurs in P→Q, so it occurs in Γ, so the agent knows Q. Disjunctive syllogism is preserved: if the agent knows P∨Q and ¬P, then Q occurs in P∨Q, so the agent knows Q. And the condition is truth-preserving, because it only removes consequences from the agent's knowledge; anything that remains is still a logical consequence of what she knows, so it is still true.

One might object that the containment condition is too strong, because it prevents the agent from discovering new concepts through reasoning. But that is a feature, not a bug: logical omniscience is precisely the assumption that agents can reason their way to conclusions involving concepts they do not possess, which is absurd.

However, the condition does have a cost: it makes knowledge of logical truths depend on the agent's vocabulary. For instance, if the agent's knowledge base contains P, then she knows P∨¬P, because P occurs in it; but if her knowledge base contains only Q, she does not know P∨¬P. This seems odd, but it is a small price to pay for avoiding logical omniscience. Overall, the containment condition is a successful solution."
