A computational state is morally significant only if the system that tokens it computes, from that state, a scalar evaluation that is fed back into that same system's subsequent processing — the evaluation regulates the very system whose state it evaluates. States that merely drive output, or that inform the processing of some other system, do not qualify. The criterion is meant to cut between rivals that locate moral status in global broadcast, in recurrent loops, or in higher-order representation.

The proposition: the self-modulation criterion is both necessary and sufficient for a computational state to be morally significant.
