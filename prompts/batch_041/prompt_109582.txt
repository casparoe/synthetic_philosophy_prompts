I run a reading group on experimental philosophy, and next term we are working through the side-effect effect: the finding that people are far more willing to say an agent intentionally brought about a foreseen bad side effect than a foreseen good one. Our arguments in this area always turn out to be about which explanation of the asymmetry each of us already presupposes, so I want to open the term with a sorting instrument that makes those presuppositions explicit.

Please build a decision tree that carries someone from the starting point — accepting that the asymmetry is genuine in the original cases — to a determinate position on what explains it. Five to seven branch nodes, seven to nine leaves.

Build the tree from the logical space rather than from a list of positions: first the questions and the answer combinations they permit, then the positions located in that space, with unoccupied combinations marked and diagnosed. Every branch node must be answerable by someone who does not know any of the labels: phrase each one as a question about what a speaker would say about a case, or about which feature of a case is doing the work, never as a question like "are you a pragmatist about this?"

To keep us off the standard examples, use these four cases as the tree's working material, and say for each node which case it leans on.

- A youth chess coach adopts a new training method because it produces better tournament results. He knows it will also leave most of his students liking chess less. Did he intentionally make them enjoy the game less?
- A firefighter sets a backburn to stop a wildfire. She knows the backburn will destroy a stand of old-growth trees, does it only because every alternative is worse, and regrets the loss. Did she intentionally destroy the trees?
- A hospital board licenses a cost-cutting triage algorithm, knowing that it will send a small number of patients with a rare condition home instead of admitting them. Did the hospital intentionally send those patients home?
- A clinic administrator orders scans he knows to be medically unnecessary, because each one is billed; the scans incidentally catch several early cancers. Did he intentionally catch the cancers?

The leaves must include, in some form, these five families: the asymmetry lies in the content of the concept of acting intentionally, which is itself partly normative; the asymmetry lies in what speakers convey rather than in what the concept contains; the asymmetry reflects the judge's reasoning about what the agent knew or probably knew; the asymmetry reflects the judge's motivation to blame; the asymmetry is an artifact of how the cases are built or asked about. Split any family the cases pull apart, and add a leaf for an answer combination nobody defends, if you find one. Label leaves by the claim they make, not by author names; no citations, no reading list; and do not lean on empirical findings beyond what the four cases and ordinary reasoning can carry — where a node turns on a finding, state it in one sentence and mark it as an assumption.

Return the instrument as a single JSON object with exactly these fields.

- title: string, the name of the instrument.
- starting_point: string, the one claim a user must accept to enter the tree.
- nodes: array of objects, each with id (N1, N2, ...), question (string), options (array of objects with answer, the option text, and leads_to, the id of the next node or of a leaf), and separates (one sentence naming which leaves this node divides).
- leaves: array of objects, each with id, label (a short descriptive name for the position, or unnamed), claim (one or two sentences), case_verdicts (an object keyed by case number, each value a sentence giving what this position predicts a competent speaker would say about that case and why), awkward_commitment (one sentence), and held_by (a prose description of the kind of theorist who holds it, no names needed).
- unoccupied: array of objects, each with combination (the answer pattern), verdict (exactly one of incoherent, unattractive, unexplored), and why (one or two sentences). Include combinations that the tree's branching makes unreachable as well as those it leaves empty.
- inseparable_pairs: array of objects, each with leaves (two leaf ids), why_the_cases_do_not_separate_them, and what_would_separate_them.
- scoring_key: array of objects, each with answer_pattern (a list of node-and-answer pairs) and position (a leaf id). Every leaf must appear at least once, and you should note any leaf reachable by more than one pattern.
