Exam question

Question 3 (30 points). It is sometimes said that computational complexity theory undermines the classical epistemological ideal of the logically omniscient agent — an agent who believes every logical consequence of her beliefs and can instantly recognize any valid inference.

(a) [10 points] Distinguish a problem's being undecidable from its being intractable, and explain which of the two, if either, would support the claim that some truths are unknowable in principle.

(b) [10 points] NP-completeness is defined in terms of worst-case behavior and polynomial-time reductions. Explain why a problem's being NP-complete does not by itself tell us how hard its typical instances are, and illustrate with a concrete example.

(c) [10 points] Evaluate the following argument: "It is almost universally believed that P ≠ NP. So there is no algorithm that solves SAT efficiently, and hence no rational agent can be required to solve it. Therefore logical omniscience is not merely an unattainable ideal but an incoherent one."

Student's answer

(a) A problem is undecidable when no algorithm can decide it for all inputs; the halting problem is the canonical example, since no machine can determine, for every program and input, whether that program halts. A problem is intractable when it is decidable but no efficient — say, polynomial-time — algorithm solves it in the worst case; it may still be solvable when the inputs are small. Only undecidability supports a limit in principle. Intractability is a practical matter, since an intractable problem still has a solution procedure; it just does not scale.

(b) NP-completeness is a worst-case notion: it says that every problem in NP reduces to the problem in polynomial time, so a polynomial-time algorithm for any NP-complete problem would yield one for all of NP. It says nothing about typical inputs. 3-SAT is the standard illustration: it is NP-complete, yet its hardness is concentrated near the satisfiability threshold, and instances well away from that threshold are usually easy. Deciding whether a formula is a tautology is likewise NP-complete, so the same worst-case caveat applies there. The upshot is that NP-completeness describes the difficulty of the hardest instances, not the difficulty an agent will actually face.

(c) The argument has two steps, and they are not equally good. The first moves from "almost universally believed" to "there is no efficient algorithm for SAT." As stated, this is too quick: a near-consensus is not a proof, and the most the belief licenses is that there probably is no efficient algorithm. The second moves from a claim about algorithms to a claim about what agents are required to believe — an inference from what is computationally possible to what is normatively binding — and it needs a bridging premise, such as the principle that ought implies can. If we grant both steps, however, the conclusion follows: since no agent can meet the requirement to believe all the consequences of her beliefs, the ideal of logical omniscience is incoherent rather than merely unattainable.
