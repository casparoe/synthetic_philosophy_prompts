I teach a graduate methods seminar and we keep having the same argument: a table shows an association in every stratum and the reverse in the pooled data, and half the room reads the pooled number as the finding while the other half reads the strata. Before we work through more examples I want the specification. Set out the desiderata for an adequate account of when an association should be read off the aggregate and when off the strata — adequate, that is, for a working analyst deciding what to report from an observational study. Include the cases it must get right (pooling plainly correct; stratification plainly correct; the choice turning on whether the covariate is causally prior to both variables, causally downstream of one, or a common effect of the two; a reversal with no causal difference behind it; the relevant variable unmeasured or measured with error), the distinctions it must not collapse (association versus effect; a crude contrast versus an adjusted one; a covariate that changes the answer because it is causally prior versus one that changes it because it is causally downstream), and the results it must be consistent with (that one and the same joint distribution can be generated by a structure in which the covariate causes both variables and by a structure in which both cause it, so the data alone may not settle the reading; that some effect measures are not collapsible, so a crude and an adjusted value can differ with no confounding present at all, as with the odds ratio; that the sure-thing principle is supposed to constrain the choice between prospects). Give the consideration behind each requirement, mark which are non-negotiable and which are commitments of a particular camp, say which single requirement does the most to exclude candidates, and flag any pair you suspect cannot be jointly satisfied — that last part is what I most want to see. A line or two on how a graphical account, a potential-outcomes account, and a rule that ignores causation fare against the list is enough to close.
