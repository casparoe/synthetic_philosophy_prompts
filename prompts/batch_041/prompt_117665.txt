The midterm question was as follows.

Fix a computable enumeration M_1, M_2, ... of Turing machines, chosen so that for every i the machine numbered 2i is the machine that first runs M_i to completion and then halts. For each j let H_j be the sentence 'M_j halts on empty input'. It follows that H_i provably entails H_{2i}, by a short uniform proof.

A pricing rule is a computable function P that takes a stage n and a sentence φ built from the H_j by Boolean operations and returns a rational number P_n(φ) in [0,1]. P_n may depend on the record of which machines have halted within n steps, but not on which machines will halt.

P is eventually right if, for every assignment of truth values to the H_j and every sentence φ, P_n(φ) converges to 1 when φ is true in that assignment and to 0 when φ is false in it.

A strategy exploits P if the strategy is computable, if at each stage n it buys or sells finitely many units of finitely many sentences at the prices P_n, and if its net worth — each unit bought contributing the sentence's truth value minus the price paid, each unit sold contributing the price received minus the sentence's truth value — is bounded below and unbounded above in every assignment.

Consider the rule R: at stage n, P_n(H_j) = 1 if M_j has halted within n steps, P_n(H_j) = (n - j + 1)^(-1) if j ≤ n and M_j has not halted within n steps, and P_n(H_j) = 1/2 if j > n; and R prices every Boolean combination of the H_j by treating the H_j as mutually independent.

(a) [6 marks] Is R eventually right? Justify your answer.

(b) [10 marks] Show that R is exploited, by exhibiting a strategy that exploits it.

(c) [9 marks] What does the example show about the prospects for a computable rule for credences about undecidable sentences? In particular, does it show that no computable pricing rule can avoid exploitation? Justify your answer and state the criterion such a rule should meet.

The script I have to mark reads as follows.

(a) Yes. Fix j. If M_j halts, it halts within t steps for some t, so P_n(H_j) = 1 for every n ≥ t, and the sequence converges to 1, which is the truth value of H_j. If M_j never halts then P_n(H_j) = (n - j + 1)^(-1) for every n ≥ j, which converges to 0, again the truth value. A sentence built from the H_j is a Boolean combination of finitely many of them, and R's price for it is the value of the corresponding polynomial in the P_n(H_j) obtained by treating those H_j as independent. Each P_n(H_j) converges to a value in {0,1}, and a polynomial is continuous, so P_n(φ) converges to the value the polynomial takes when each H_j is set to its truth value; by the definition of the independence formula that value is the truth value of φ. So R is eventually right. It is worth noting that R is a genuine probability distribution over the assignments to the H_j, so its defect is not a failure of probabilistic coherence in the narrow sense.

(b) For each n let φ_n be the sentence H_(n+1) ∧ ¬H_(2n+2). Since M_(2n+2) runs M_(n+1) to completion, H_(n+1) provably entails H_(2n+2), so φ_n is false in every assignment; a strategy can establish this by proof search, and since the enumeration is uniform the search takes time bounded by a polynomial in n. At stage n both n+1 and 2n+2 exceed n, so R prices H_(n+1) and H_(2n+2) at 1/2 each, and by independence P_n(φ_n) = (1/2)(1/2) = 1/4. Sell one unit of φ_n at each stage n. Because φ_n is false in every assignment, the short position never pays out, so the strategy's net worth after n stages is n/4: bounded below, and unbounded above, in every assignment. So R is exploited.

(c) The example shows that eventual rightness cannot be the whole story. R converges to the truth on every sentence, yet a strategy takes 1/4 from it at every stage, so a rule can be right in the limit and still leave a sure profit open at every finite stage. The criterion should therefore be a condition on the bets the prices leave open rather than a convergence condition: what matters is whether some computable strategy can earn a profit that is bounded below and unbounded above in every assignment, not whether the credences settle down.

The trade in (b) works because R's credences about machines it has not yet started are coarse and converge slowly; if the marginals for those machines decayed geometrically rather than like 1/n, the trade would not get off the ground. So the lesson is that the rule has to be tightened up at the finite stages, with faster convergence and finer marginals.

Does the example show that no computable rule can avoid exploitation? I think it does. By Gödel's first incompleteness theorem, for any computable rule there are sentences whose logical relations to the rest of the language the rule cannot see: there is always an implication that is not provable, hence not detectable by proof search, so a computable rule must always price some pair of sentences as independent when they are not. A strategy can trade on that discrepancy, so every computable rule leaves a guaranteed arbitrage open. The only rules that are immune are those whose credences are supported entirely on the logically possible assignments, and no computable rule can be supported only on those. We therefore face a choice between an ideal that no computable agent can meet and giving up the demand that credences be computable.
