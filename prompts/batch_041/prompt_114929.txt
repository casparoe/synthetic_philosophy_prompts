**Does a higher-order thought have to be about anything?**

The higher-order theory of consciousness, roughly: a mental state is conscious just in case it's the object of a suitable higher-order representation — a thought, in Rosenthal's version, or a perception-like inner sense, in Armstrong's and Lycan's. Unconscious states are the ones no higher-order state is directed at. That's the whole trick: it explains what makes a state conscious without positing consciousness as a special ingredient of the state itself.

My friend loves this. I think it has a hole. Here it is.

Higher-order representations can be wrong. If I have a thought "I'm in pain," that thought can be false — I can be wrong about my own states, at least in principle, and even if you think first-person self-knowledge is pretty reliable, the theory can't just stipulate infallibility, because then the higher-order state is a magic detector rather than a representation. So:

1. M is conscious iff a suitable higher-order representation R occurs whose content is that one is in M.
2. R's content can fail to match the world.
3. So there's a possible case where R occurs, R says "I am in M," and M is not occurring.
4. By (1), M is conscious in that case.
5. But M isn't occurring. So the theory says a state that doesn't exist is conscious.

My friend says the case in (3) is a fringe fantasy. I don't buy it. There's a mild version: R could represent M as having a property M doesn't have — I feel a dull ache as a sharp one. But that one is cheap for him, because M is still there, just misdescribed. The interesting case is the empty one, where the higher-order state has no first-order state to be about at all. Is that really impossible? If it is, the theory needs a premise that R must be caused by M (or otherwise "anchored" in it), and that premise is doing an awful lot of work — maybe all of it. If it isn't impossible, then the theory says you can be conscious of a state that isn't there, which sounds like a straight contradiction.

So here's the dilemma I want you to check: either (a) you add an anchoring requirement, and then the higher-order state isn't a free-standing representation anymore but a state partly constituted by its target — which starts to look like the first-order state is already doing something consciousness-y, and you've lost the clean story; or (b) you don't add it, and you get the empty case. Is that a real dilemma, or am I faking it by smuggling something into premise 2?

I also want to know whether dispositionalism dodges it. As I understand it (Carruthers?), you don't need the higher-order state to actually occur — it's enough that the first-order state is available to a system that would form one. Maybe then there's no empty case, because if there's no first-order state there's nothing to be available. But that seems to either (i) make the theory vacuous, since everything "available" is conscious, or (ii) relocate the whole mystery into the disposition, which isn't obviously better. Which is it?

And here's the part I most want checked. I think what the empty case really exposes is that higher-order theorists run together two different kinds of aboutness. There's content-aboutness — the higher-order state's content specifies the first-order state — and causal aboutness — the higher-order state is actually triggered by the first-order state. I want to call the requirement that you need at least causal aboutness the anchor requirement, and claim that once you state it out loud the theory is in trouble, because causal aboutness makes the higher-order state observational or inferential, and the theory needs it to be neither. Is that a known move? Does it already have a name? Or did I just reinvent the misrepresentation objection with extra steps and a new label?

Be honest — if the whole thing collapses, say so. And again, please sort out what's standard from what's actually up for grabs; I don't want a tidy answer that manufactures consensus where there isn't any.
