Over the weekend a friend and I burned through most of a long drive arguing about Maxwell's demon, and by the end it was clear we were not really disagreeing about the physics so much as about which assumptions each of us was silently granting. I kept saying the demon is only a bookkeeping problem that dissolves once you count the demon's own memory in the entropy ledger; he kept saying that a clever enough being really does extract work from a single reservoir, and that calling it bookkeeping is just refusing to say where the cost lands. The more we talked, the more the disagreement seemed to fan out into separate questions — whether measuring a molecule is thermodynamically free, whether the demon has to be reset before it can run again, whether the entropy accounting is over the gas alone or over gas-plus-demon-plus-environment, whether the second law is a strict prohibition or only a statistical regularity that a fluctuation can beat, whether entropy is relative to a description at all, and whether the demon's being an agent is doing any real work. I would like to stop relitigating this and instead map the space, so that next time we can point at the branch where we actually part ways.

Please write me a decision tree — really a taxonomy you can walk — that takes someone from a starting commitment to a named position on whether the demon can beat the second law. I want to use it with a philosophy-of-physics reading group, so assume a reader who is comfortable with thermodynamics and information theory but has not memorized the literature. The starting commitment is simply this: no experiment has ever shown the second law failing at the macroscopic level, and the demon's operations are physically implementable in principle. Each branch node should be a single question about one assumption, phrased so a reader can answer it without already knowing which position it leads to — no node may name a position or presuppose the conclusion. Each leaf should be a named position, and I want at least these to appear somewhere: the original view that the demon simply beats the law; the measurement-cost resolution; the erasure-cost resolution in which information turns out to be physical; the view that nothing needs erasing because the demon's records can be kept indefinitely; the view that entropy is observer-relative and the demon only lowers it relative to a coarse-graining; the view that the second law is merely statistical and the demon is a rare fluctuation; the quantum version in which coherence is treated as a resource; and the deflationary view that the demon is just an ordinary control system and the law was never at risk. Aim for seven or eight branch nodes and no more than about a dozen leaves.

Two things I care about especially. First, the distinction that most confuses my friend and me is between resolutions that save the law by making the demon pay a thermodynamic cost somewhere (and thereby make information physical) and resolutions that save it by weakening the law to a statistical statement; make sure the branch that separates these two families is explicit, and say for each leaf which family it belongs to. Second, be honest about the limits of the instrument: flag any pair of positions the tree cannot separate because they make the same predictions or differ only verbally, note which combinations of branch answers no one occupies, and for each unoccupied combination say briefly whether you think it is incoherent, merely unattractive, or simply unexplored. One sentence per leaf on its most awkward commitment would help. No citations needed — I care about the structure of the space, not the reading list.
