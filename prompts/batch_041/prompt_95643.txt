Question: State the independence axiom. Then set out the Allais paradox using the standard lotteries and explain what it shows about expected utility, both as a description of how people choose and as a standard of rational choice.

Answer: "The independence axiom says that if two lotteries differ only in some event, the ranking between them shouldn't depend on what they have in common elsewhere — the shared part is irrelevant. Formally, if L is preferred to M, then a mixture of L with any N (same probabilities) is preferred to the same mixture of M with N.

Allais's example: Option A pays $1M for sure. Option B pays $5M with probability 0.10, $1M with probability 0.89, and $0 with probability 0.01. In the second problem, Option C pays $1M with probability 0.11 and $0 otherwise, while Option D pays $5M with probability 0.10 and $0 otherwise. Most people choose A over B but D over C.

Expected utility can't accommodate both choices. B's expected monetary value is 0.10(5M) + 0.89(1M) = 1.39M, more than A's 1M, so an EU maximizer has to rank B above A. And D's value is 0.5M against C's 0.11M, so an EU maximizer ranks D above C. So the pair {A over B, D over C} is inconsistent with expected utility.

What's doing the work is the common consequence. A and B both pay $1M in the 89% event, whereas C and D both pay $0 in that event. Independence says replacing the common consequence of $1M with $0 shouldn't flip the ranking, but it does.

So the modal choices are inconsistent. Since there's no utility function that assigns values to the four lotteries so as to represent both choices, the agent's preferences are intransitive, and independence is really a consequence of the more basic axioms of completeness and transitivity, so violating it is a genuine inconsistency rather than a separate assumption. The underlying cause is risk aversion: people overweight the certainty of A, and expected utility can't capture that because it assumes risk neutrality. So expected utility fails as a descriptive theory, and since the choices people actually make seem defensible, it fails as a normative one too."
