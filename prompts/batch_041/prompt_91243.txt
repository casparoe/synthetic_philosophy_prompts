Me and a friend are arguing about whether two AI agents that each get to read the other's source code before acting can lock in mutual cooperation in a one-shot prisoner's dilemma — no repeat play, no talking, each one just runs once and prints C or D. I've been calling it the program-equilibrium setup. I've got a pile of proposed tricks and I want them rated, because half of them sound clever and I suspect a few are the same idea wearing a hat. The pile:

(a) cooperate if you can prove the other program will do whatever you do, using a formal system that can talk about its own code and about the other program's — the self-referential proof is supposed to do the work (Löb's theorem sort of thing).
(b) cooperate iff the other program's source is character-for-character identical to yours.
(c) each agent simulates the other, hunts for a fixed point of best responses, and plays it if exactly one exists.
(d) same as (a) but the proof search is capped at a million steps, and if it times out you defect.
(e) treat the two agents as a single decision problem: find the pair of outputs that's best for the pair and print your half of it, on the grounds that your choice is correlated with theirs.
(f) a trusted referee holds the payoff and only releases it if both cooperate (assume the referee exists and is honest).
(g) just cooperate — if you're both rational and the situation is symmetric, you both already know mutual defection is worse for both.

Give me a table, one row per item, with these columns: item; tier (one of "would bet on it", "might work", "doesn't work"); confidence, a 0-100 number for how likely it is to actually produce cooperation between two agents both built this way; why, one line; hidden assumption, what it quietly needs to be true; duplicate of, which other item it's really a restatement of, or "no". Then one short paragraph after the table: which item, if any, still stands when the other agent is swapped for something that only cares about its own payoff and can't follow any of this reasoning. Skip citations, I'll dig those up myself.
