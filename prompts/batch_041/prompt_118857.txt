I'm a software engineer with no philosophy backround, but I've been reading about epistemic injustice and it feels like my bug tracker is a case study. We tell users their report doesn't count unless they can give a minimal reproducable example; a maintainer can say "yeah that's broken" and it's basically accepted. So there's a kind of reproduction tax: credibility has to be bought with mechanistic evidence, and some people can afford that cost better than others. What philosophical commitments does that practice presuppose -- what view of testimony and credibility, and which rival views does it quietly rule out? Is it consistent with the same tracker's norm that maintainers' hunches get acted on? And where is it underdetermined -- could different views of credibility license the same triage rules? Finally, if we swapped in a view where credibility is spread more equally, what would actually have to change in triage -- rules, incentives, what counts as a bug, not just vibes?
