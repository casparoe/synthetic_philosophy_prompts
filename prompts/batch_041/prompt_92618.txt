I'm an undergraduate enrolled in a course on machine learning and cognition, and I'm designing my term project around inverse reinforcement learning, the problem of inferring an agent's reward function from its observed behavior. We covered ordinary reinforcement learning first, and the contrast is what motivates my project. In the forward problem you are given a reward function and you solve for a policy that maximizes it; the problem is well posed, and we spent several lectures on convergence and on the conditions under which a solution exists and is essentially unique. Inverse reinforcement learning runs the same machinery in reverse: it takes observed behavior and solves for the reward function that would render that behavior optimal. My plan is to assemble a large corpus of human demonstrations, on the order of several thousand hours of people performing ordinary tasks, run an inverse reinforcement learning method over it, and thereby recover the reward function that these people are implicitly maximizing, which I am treating as a formal encoding of their underlying preferences. The larger framing is that this supplies a route to value alignment: if the recovered reward function matches the human's, then training a system to maximize the recovered function makes its objectives match the human's by construction.

My question concerns the quantitative side. Because the forward problem is well posed and the inverse problem is simply its reverse, I have been assuming that the only genuine obstacles are data and compute, and that the recovered reward function should converge to the human's actual reward function as the demonstration set grows. If that is right, the practical question is how large the demonstration set must be before the recovered function can be guaranteed to coincide with the true one. Is there a standard sample-complexity result of this kind, giving the rate at which the recovered reward approaches the true reward, and what determines the constant in that rate? More broadly, I would like to know what I should expect to be the binding constraint in practice, how I might verify empirically that I have recovered the true reward function rather than one that is merely adequate to reproduce the observed behavior, and whether there are any subtleties in the inverse problem that I ought to be designing around before I commit to this as my project.
