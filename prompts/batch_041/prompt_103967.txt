I'm developing a distinction between two ways an omission can enter a causal explanation: an interruptive omission, in which the agent fails to halt a process already under way, and an initiatory omission, in which the agent fails to start a process that nothing else would have set going. I want to argue that only the first is a genuine cause, while the second is at most a failure to confer a benefit. Please describe the most important implications of this asymmetry for how blame and liability should be apportioned in cases of institutional neglect — for example, a regulator that declines to open an investigation versus one that halts an investigation it had already begun — ranked by how much they matter, and indicate which of those implications are counterintuitive enough to count as evidence against the asymmetry itself.
