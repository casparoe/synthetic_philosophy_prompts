Me and my flatmate (he minored in philosophy, I write backend services, so flag it if I garble the terms) have been arguing for three months about higher-order theories of consciousness — the family of views where a mental state only counts as conscious if the system also has some further, higher-order representation of that state. He's convinced; I think it's backwards, that a state is conscious because of what it is in itself and the higher-order part just lets you report on it. We keep going in circles, so I want the document we should of written instead of yelling at each other: a joint statement we could both sign.

Start with a numbered list of claims we agree on — what the view actually says, what it's meant to explain, what it isn't committed to, and which standard objections we both think are bad. Then a disagreements table, one row per remaining difference, each row worded so the side that holds it would accept the wording as fair.

The cruxes, as best I can tell (tell me if I'm wrong): (1) the misrepresentation case — the higher-order state gets the target wrong, representing red when the state underneath is green, or representing something when there's nothing underneath at all: what's the experience, and is either answer even coherent? (2) whether the higher-order state has to be thought-like and concept-using or can be more perceptual, since if it's conceptual that seems to rule out a lot of animals and babies. (3) whether the higher-order state itself has to be conscious, and if not, how an unconscious representation of another state produces anything. (4) whether a system with a self-model — a robot predicting its own joint angles, a net that outputs a description of its own activations — is even in the running or just a different thing with the same name. (5) what could count as evidence either way, given we can't ask the neurons.

For each crux, give the strongest consideration both of us would agree is relevant, plus what each side predicts about it. And if part of our arguement is really about words — if we mean different things by representation or by conscious, or if his theory is really about reportability while mine is about experience — say which part it is and spell out the two readings. If my side turns out to be wrong about something, put it in the agreed claims anyway; I'd rather sign something true than win.
