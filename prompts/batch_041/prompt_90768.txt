Question 3 (short essay, roughly one page). Skolem's paradox is the observation that ZF, if consistent, has a countable model, and yet proves that there are uncountable sets. (a) State the theorem responsible and explain how it yields a countable model of ZF. (b) Explain how a countable model can nevertheless satisfy 'there is an uncountable set'. In particular, say what the model's version of the power set of ω looks like from outside the model, and where the bijection that makes the model's real numbers countable from outside lives. (c) Does the paradox show that countability is relative? Distinguish what the paradox establishes as a matter of mathematics from the two philosophical readings discussed in lecture: the relativist reading, on which 'countable' and 'uncountable' have no absolute significance, and the absolutist reading, on which the paradox shows only that a first-order axiomatization fails to pin down the intended universe, which may itself be perfectly determinate.

Student's answer. The theorem is the Löwenheim–Skolem theorem: if a first-order theory in a countable language is consistent, then it has a countable model. The language of set theory is countable, and ZF proves that an infinite set exists, so if ZF is consistent then it has a countable model M.

Let M be a countable transitive model of ZF. Since M satisfies ZF, Cantor's theorem holds inside M: M proves that there is no surjection from ω onto P(ω), so M satisfies 'P(ω) is uncountable'. From outside, however, M is countable, and so is each of its elements; in particular the set that M takes to be the set of subsets of ω, which I'll write P(ω)^M, is a countable set of the real world. It is also a proper subset of the genuine P(ω): it contains only those subsets of ω that M happens to contain, so M's power set operation is incomplete from the outside. The bijection witnessing that P(ω)^M is countable is a set of ordered pairs in the real world, and M contains it as an element but does not recognize it as a bijection onto ω, which is why M is not thereby inconsistent in holding its reals to be uncountable. So countability is not absolute between M and V: a set that M calls uncountable can be countable in the metatheory, and the ordinal that M calls ω₁ is really a countable ordinal.

What the paradox establishes mathematically is that first-order satisfaction is model-relative: 'x is uncountable' can hold in a model and fail in the real world. It does not show that ZF is inconsistent, and it does not refute Cantor's theorem, which holds inside M. The philosophical moral is disputed. On the absolutist reading, the paradox shows that a first-order axiomatization of set theory is too weak to pin down the intended universe, which may nevertheless be perfectly determinate. On the relativist reading, it shows that countability itself has no absolute significance. The paradox by itself does not settle which of these is right.

One last remark: the argument does not really need the assumption that M is transitive. Consistency alone gives a countable model by Löwenheim–Skolem, and the Mostowski collapse turns that model into a transitive one, so nothing is lost.
