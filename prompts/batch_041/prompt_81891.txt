Student answer: Expressivism says that moral sentences don't state facts; they express the speaker's non-cognitive attitudes. So murder is wrong is more like saying boo to murder than like saying murder has property F. The Frege-Geach problem is that this story only works when the sentence is asserted. In a conditional like If murder is wrong, then telling the police is right, the antecedent murder is wrong isn't asserted, so it can't be expressing an attitude. But the meaning of the words has to stay the same across asserted and unasserted uses, otherwise the argument murder is wrong; if murder is wrong then telling the police is right; therefore telling the police is right is not valid modus ponens. So expressivism seems to make moral reasoning impossible. The problem is specifically for expressivism because expressivists are the ones who say moral sentences are not truth-apt.

The quasi-realist reply says we can be minimalists about truth. Truth is not a heavy property; it's just a device for endorsing a sentence. So once we have a stable attitude of disapproval toward murder, we can say murder is wrong is true. Then the conditional can be true as well, and modus ponens is valid. The expressivist doesn't have to posit weird moral facts. So I think this basically solves Frege-Geach, because it lets expressivists use truth and validity in the same way as everyone else. Maybe the only remaining issue is that it makes moral truth depend on our attitudes, which sounds like subjectivism. But the quasi-realist can say the attitude is a normative one, not a mere preference, so it's not just subjectivism. Overall the problem is serious but not fatal.
