The question (20 marks, split roughly 7/7/6 across the three parts) was:

State the downward Löwenheim–Skolem theorem and explain how it yields a countable model of ZF. Say what, if anything, is paradoxical about the existence of such a model, given that ZF proves Cantor's theorem. Finally, assess the claim that the paradox shows that the apparent uncountability of the reals is an artefact of the model — that is, that there is no model-independent fact as to whether the set of real numbers is countable.

The script:

The downward Löwenheim–Skolem theorem says that if a theory in a countable language has a model, then it has a countable model. ZF is a first-order theory in a countable language — there are countably many formulas, hence countably many axioms — and it has models, so by Löwenheim–Skolem it has a countable model M. We may as well take M to be transitive, since if we start from a well-founded model we can collapse it. ZF proves Cantor's theorem, that there is no surjection from ω onto the set of subsets of ω, so M satisfies 'the set of real numbers is uncountable'. But M itself is countable. That is the paradox.

The resolution is that 'countable' is not an absolute notion. M is countable from outside, but the bijection witnessing this is not an element of M, and the only way M can certify that a set is countable is to contain a bijection between that set and its ω. M's version of the reals is a countable set of subsets of ω — these are precisely the subsets of ω that are definable in the language of set theory, and there are only countably many formulas — so there is no mystery about how M's continuum can be countable, and no conflict with Cantor's theorem, which is a theorem about what happens inside M. Cantor's theorem remains true in M: M contains no surjection from its ω onto its P(ω).

What the paradox really shows, though, is that cardinality is not an absolute matter. Whether the set of real numbers is countable depends on which model you are working in: the very same set of reals is countable when viewed from the metatheory and uncountable when viewed from inside M. So there is no model-independent fact of the matter about whether the continuum is countable; the uncountability of the reals is internal to a model, and Skolem's result shows that set theory cannot pin down a determinate notion of set.
