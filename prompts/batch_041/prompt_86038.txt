I am a teaching assistant for an intermediate game theory course, and before I return a midterm script I want a mark and a set of comments I can stand behind. Here is the question as it was set, followed by the student's answer, reproduced in full.

Question (20 points). Consider the two-player game below, in which Row chooses T, M or B and Column chooses L, C or R; each cell lists (Row's payoff, Column's payoff):

        L         C         R
T     (4, 1)    (2, 1)    (0, 3)
M     (1, 0)    (1, 4)    (1, 0)
B     (0, 3)    (2, 1)    (4, 1)

Terminology as used in the course. A strategy s for a player is strictly dominated if there is some strategy of that player, pure or mixed, that earns strictly more than s against every pure strategy of the opponent. Iterated elimination means repeatedly deleting strictly dominated strategies until none remain, and the surviving set is the set of profiles not deleted along the way. The elimination is order-independent if every maximal sequence of deletions — one that stops only when no strictly dominated strategy remains — leaves the same surviving set. The game is dominance solvable if the process leaves exactly one strategy for each player.

(a) [4 points] Which pure strategies are strictly dominated in the game as given, and by what?

(b) [6 points] Carry out the iterated elimination of strictly dominated strategies. State the surviving set, say whether the elimination is order-independent and why, and say whether the game is dominance solvable.

(c) [4 points] State the criterion for a pure strategy to be strictly dominated by a mixed strategy, and say which strategies in this game, if any, can be eliminated only by a mixed dominator.

(d) [6 points] Find all Nash equilibria of the game, and state the relation between iterated elimination of strictly dominated strategies and Nash equilibrium.

The student's answer.

(a) The only strictly dominated strategy is Row's M. It is not dominated by T alone or by B alone: T earns 0 against R, less than M's 1, and B earns 0 against L, also less than M's 1. But M is strictly dominated by the mixture ½T + ½B, which earns 2 against L, 2 against C and 2 against R, strictly more than M's 1 in every column. The other five strategies are each a best reply to some pure strategy of the opponent — T to L (4), B to R (4), L to B (3), R to T (3), C to M (4) — so none of them is strictly dominated.

(b) Round 1 deletes M. With only T and B left for Row, Column's payoffs against (T, B) are L = (1, 3), C = (1, 1), R = (3, 1). C is now strictly dominated by ½L + ½R, which earns 2 against each of T and B while C earns 1 against each; neither L nor R alone will do, since L only ties C against T and R only ties C against B. Round 2 deletes C. In the remaining 2 × 2 game T = (4, 0) and B = (0, 4) for Row, and L = (1, 3) and R = (3, 1) for Column, so no dominated strategy is left and the process stops. Surviving set: {T, B} × {L, R}. The game is not dominance solvable, since two strategies survive for each player. The elimination here is not order-independent: C is not dominated in the original game and only becomes dominated once M has been removed, so if one had inspected Column's strategies first one would have deleted nothing, and what survives depends on the sequence of deletions. Order-independence would require the dominance relations to be visible in the initial game.

(c) A pure strategy is strictly dominated by a mixed strategy exactly when it is not a best reply to any pure strategy of the opponent. M meets this condition — against L, C and R it is beaten by T, T and B respectively — which is why a mixture is needed to eliminate it, and C meets it too once M is gone, since R beats it against T and L beats it against B. C is not dominated in the original game because it is a best reply to M, where it earns 4 against 0 for both L and R.

(d) In the 2 × 2 game that remains, Row's payoffs are T = (4, 0) and B = (0, 4), and Column's are L = (1, 3) and R = (3, 1). No pure profile is an equilibrium: at (T, L) Column prefers R (3 > 1); at (T, R) Row prefers B (4 > 0); at (B, L) Row prefers T; at (B, R) Column prefers L. For a mixed equilibrium, Row is indifferent only if Column plays L with probability q satisfying 4q = 4(1 − q), so q = ½, and Column is indifferent only if Row plays T with probability p satisfying 1p + 3(1 − p) = 3p + 1(1 − p), so p = ½. Hence the unique equilibrium is (½T + ½B, ½L + ½R), with payoff 2 to each player. Since M and C are strictly dominated they are never best replies and so appear in no equilibrium. As for the general relation: a strictly dominated strategy is never a best reply to anything, so iterated elimination of strictly dominated strategies never deletes a strategy that is used in a Nash equilibrium; in this game the surviving set happens to be exactly the support of the unique equilibrium.

Item 1 is the mark and the single most important reason for it; items 2 to 5 take parts (a), (b), (c) and (d) in order, each saying whether the answer to that part is correct and why. Keep each item to one or two sentences.
