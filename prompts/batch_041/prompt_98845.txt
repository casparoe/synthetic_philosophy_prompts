I was in a reading group last week where two participants, A and B, got into an extended argument about coherence arguments for expected utility maximization. A third participant had proposed a rule—choose the act that maximizes the minimum expected utility over a set of admissible probability distributions, and break ties by worst-case—and claimed it was both rational and immune to the usual money-pump and Dutch-book objections. A and B disagreed about what that showed. I took notes; here is the exchange as faithfully as I can reconstruct it.

A: If your choices cannot be represented as maximizing expected utility with respect to a single probability distribution and a utility function, then there is a sequence of trades you will accept that leaves you worse off no matter what happens. That is what a coherence argument shows. So any rational agent must maximize expected utility. C's maximin rule is not expected utility maximization, so it is incoherent.

B: That is too fast. A money-pump argument shows that certain patterns of preference are exploitable if the agent will make each trade in isolation and cannot commit or anticipate. C's rule is applied to whole plans; it can refuse a trade that lowers the worst-case outcome, even if the trade is favorable under every admissible probability. Refusing such a trade is not a sure loss, because there is no single probability by which to measure the loss. So the pump does not get started.

A: If C refuses a trade that is favorable under every admissible probability, then C is leaving a sure gain on the table. That is irrational. And if C's preferences over acts violate the independence axiom, we can construct a lottery version: suppose C prefers A to B but prefers a 50–50 mixture of B and C to a 50–50 mixture of A and C. A bookie can then extract a sure loss from C. Avoiding that requires independence, and independence plus the other standard axioms gives expected utility maximization.

B: The lottery argument assumes that C will accept each mixture bet at the offered stakes and that C's preferences over mixtures are stable. But more importantly, avoiding a Dutch book may require only that C's preferences be representable by a set of probability distributions, not a single one. C's maximin rule can be represented that way. It is not vulnerable to a Dutch book in the same sense. So the coherence argument establishes at most that C should have a convex set of probabilities and avoid sure loss—not that C must maximize expected utility with a single probability.

A: But if C has a set of probabilities, then a bet that is favorable under every probability in the set is a sure gain. If C refuses it, C is irrational. And if C accepts it, C is effectively using a single probability—the one that makes the bet favorable—or at least a rule that is equivalent to expected utility maximization for that bet. So the distinction collapses.

B: No. A bet can be favorable under every probability in the set and still increase ambiguity, and C may rationally prefer the less ambiguous option. That is not a sure gain in C's terms, because C does not rank acts by expected utility with respect to a single probability. You are assuming the very thing at issue: that rationality requires a single probability and a utility function. The coherence argument only shows that if you want to avoid a certain kind of exploitation, you must satisfy certain consistency conditions. It does not show that those conditions are sufficient for expected utility maximization, nor that they are the only rational ones. In fact, I think the argument conflates two things: having coherent degrees of belief, which is one thing, and having preferences that maximize expected utility, which is another. A Dutch book on beliefs does not by itself force expected utility maximization of preferences.

A: Then what is the force of the coherence argument? If it does not force expected utility maximization, it is much weaker than it is usually taken to be. I think it does force it, because the only way to be immune to all sure-loss sequences is to have a complete, transitive, independent preference ordering that is representable by expected utility.

B: And I think that is exactly the contested claim. The argument may show that a rational agent must not have preferences that are exploitable in certain ways, but it does not show that the only way to avoid exploitation is expected utility maximization. There are non-expected-utility rules that avoid the standard pumps. You may think they are irrational for other reasons, but the coherence argument by itself does not settle it.

I'd like you to adjudicate this exchange move by move. For each of the main moves—A's first claim, B's first reply, A's lottery argument, B's reply about sets of probabilities, A's collapse claim, B's ambiguity reply, and A's final challenge—say whether it is clearly mistaken, defensible, or clearly right, and briefly justify each rating. Then say who is more right overall, and what both parties are missing. In doing so, separate what is settled from what is genuinely contested among people who know the topic, and do not present a contested view as the consensus. I am interested in the arguments themselves, not in attributions or reading lists.
