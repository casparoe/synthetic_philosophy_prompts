I have no formal training in philosophy or mathematics; what I know about the subject comes from popular science writing and from long arguments with a friend who reads the same books. There is one claim I keep running into that I cannot let go of, and I would like to see the strongest version of both sides of the dispute set out as a dialogue.

The claim is that preferring simple explanations to complicated ones is not a matter of taste but something close to a theorem. The argument, as I understand it, runs like this. Imagine a machine that prints one symbol a day, forever, according to some fixed set of rules, and imagine that we want to guess tomorrow's symbol. Any hypothesis about what the machine is doing can be written down as a set of instructions, and the number of symbols needed to write it down measures how complicated the hypothesis is. Assign each hypothesis a prior probability of two raised to the power of minus its length — shorter instructions, higher prior — and then update by the ordinary rules of probability as symbols arrive. The remarkable thing I am told is that this procedure is guaranteed to home in on the truth for any machine whose behavior can be captured by a finite set of rules, that it does about as well as any rival method that could be written down, and that the language in which we write the instructions barely matters: switching from one description language to another changes every hypothesis's length, but only by adding or subtracting a fixed amount, the same amount for all hypotheses.

That last clause is what I cannot get past. A fixed amount is only a small amount if it is small, and my understanding is that it can be astronomically large, and that it is fixed entirely by the two languages rather than by anything about the machine we are watching. My friend tells me this is a quibble, and that the theorem is precisely what makes simplicity objective. I say the fixed amount is where all the work is being done. To make the dispute concrete, we invented this case. Two people each design a description language, and then rank the same set of hypotheses about the machine. In the first language, a sober, parameter-heavy, ordinary scientific hypothesis about the machine is the shortest one that fits the data. In the second — a language whose basic symbols were chosen, more or less arbitrarily, so that one bizarre numerological rule about the machine can be written as a single symbol — the numerological rule comes out shortest, and the sober hypothesis takes thousands of symbols to state. Nothing about the data distinguishes the two languages. So which language is the right one to be simple in?

Please write a dialogue between two people who hold these opposing views: one who believes the mathematical argument genuinely establishes simplicity as objective, and one who believes that the objectivity is an artifact of an arbitrary choice of language. Both should be sharp, and neither should be a strawman — the first should not simply repeat that the theorem proves it, and the second should not simply repeat that the fixed amount is enormous. They should answer each other's actual points rather than talk past one another. I would especially like them to press on: what the fixed amount does and does not buy us; whether the choice of a description language can be justified without circularity, or whether it is merely the language we happen to find natural; whether a guarantee that takes effect only at lengths no one will ever observe counts as a real justification for creatures like us; and whether the disagreement is ultimately mathematical at all, or whether it is about what we are asking for when we ask for an explanation. Neither of them may cite any literature or appeal to authority — they have to argue it out from scratch, and I want to see where each of them is forced to give ground.
