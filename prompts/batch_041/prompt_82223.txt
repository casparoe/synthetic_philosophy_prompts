2. Whatever I think of is before my mind while I think of it — it's an object of my mind, I've got it, it's in there.
3. So at the moment I understand the sentence, that mountain is an object of a mind, namely mine. (He says, don't waste my time telling me that imagining a mountain isn't perceiving one. 5. So the situation the sentence describes — the mountain existing with no mind on it — isn't something I can even think, because my thinking of it puts it in a mind, mine, right then.

So if to exist is to be an object of some mind, then the past, the letter I never opened, the room nobody's in, and my friend himself all exist only in whatever mind happens to be on them at that moment. When that mind is mine, that's solipsism: everything that exists is an idea in my head.
8. Berkeley's escape is God, who is on everything all the time, so the unperceived stuff lives in God's mind and doesn't need me. But the same crank turns on God: when I think about God, God is before my mind. And if God's own perceivings are things that exist, they need to be objects of a mind too — God's own, or somebody else's, forever.
