My opening move. I have been drawing a distinction I find useful. Call a simplicity measure gauge-fixed if the ordering it induces among hypotheses is stable across the choice of reference universal machine, and gauge-anchored if it also fixes the additive constant, so that it says not merely which of two hypotheses is simpler but by how much. My claim is that the universal prior is gauge-fixed and cannot be gauge-anchored, and that every finite inductive practice needs the anchor. Here is why the gap is not a rounding error. The bound in the invariance theorem is a constant in the length of the data, and it is not small: for short strings it can exceed the complexity of the shortest description of the string itself, so two machines can disagree about the ranking of precisely the hypotheses we care about when evidence is scarcest. And the constant is set by conventions of encoding — how the machine reads its input, whether programs are self-delimiting, which alphabet — none of which the world selects. So the prior a finite agent actually uses is fixed by notation, while the objectivity you want lives in a limit that no finite data stream ever reaches. Which is it, then: is the prior a claim about the world or about our notation? And if the honest answer is the limit, tell me what a limit that is approached but never attained can do for a creature whose every problem is finite.
