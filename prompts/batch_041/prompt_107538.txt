Question 3. The handout defines Buchak's risk-weighted expected utility (REU) as follows. Take a gamble g with outcomes x1,...,xn and probabilities p1,...,pn, ordered so that u(x1) ≤ ... ≤ u(xn). Then

REU(g) = u(x1) + Σ (from i = 2 to n) [ r(pi + ... + pn) · (u(xi) − u(xi−1)) ],

where r is the agent's risk function: increasing, with r(0) = 0 and r(1) = 1.

(a) Setting u(x) = x/100 and r(p) = p², compute the REU of the gamble that pays $0 with probability 0.2, $50 with probability 0.3, and $100 with probability 0.5. Compare this with the gamble's expected utility, and say what the comparison tells you about the agent's attitude to risk.

(b) What does r(p) = p correspond to, and how does the risk function relate to the probability weighting function used in prospect theory?

(c) Does REU satisfy stochastic dominance? One line is fine.

Student's answer:

(a) Ordering worst to best gives $0 (p = 0.2), $50 (p = 0.3), $100 (p = 0.5), so with u = x/100 the utilities are 0, 0.5 and 1. The cumulative probabilities I need are 0.3 + 0.5 = 0.8 for the $50 step and 0.5 for the $100 step. So

REU = 0 + r(0.8)(0.5 − 0) + r(0.5)(1 − 0.5) = (0.64)(0.5) + (0.25)(0.5) = 0.32 + 0.125 = 0.445.

Expected utility is 0.2(0) + 0.3(0.5) + 0.5(1) = 0.65. Since REU comes out below EU, the agent values the gamble below its expected value, and since the risk function here is concave, this is a risk-averse agent.

(b) With r(p) = p the formula collapses back to ordinary expected utility, because each utility increment is just weighted by its probability. The risk function is really the same sort of device as the probability weighting function in Kahneman and Tversky's prospect theory — both squash or stretch probabilities to capture how people actually react to risk — so REU takes on board prospect theory's loss aversion and its dependence on a reference point.

(c) Yes, it satisfies stochastic dominance: the weights r(...) are all non-negative, so shifting probability mass toward better outcomes can only push the value up.
