I'm putting together a handout for a decision theory reading group, and I want a decision tree that sorts people into the live positions (causal, evidential, functional/updateless, and whatever else is actually defended) based on how they answer concrete cases, not on which label they like. Use three cases: (1) counterfactual mugging -- Omega flips a coin; on tails it asks you for $100, on heads it pays you $10,000 if and only if it predicted you would have paid on tails; (2) an XOR blackmail variant where the payoff is rigged so that paying and refusing are each rewarded in exactly one branch of the coin flip, so neither action dominates across branches; (3) Newcomb's problem as a control. Each branch node should be a question a reader can answer without already knowing which theory it leads to -- things like 'does what you would have done in a branch that didn't happen count as a reason for what you do now?' -- and each leaf should name a position plus one sentence on its most awkward commitment in the XOR case specifically. Flag any pair of leaves the tree can't separate, and note any combination of answers that doesn't match a defended view and why (incoherent, unattractive, or just unexplored). Keep it to maybe eight to ten nodes.
