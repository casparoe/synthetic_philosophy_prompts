I'm in a philosophy of mind course and I've constructed an argument I can't decide whether to be pleased with or embarrassed by. The conclusion is absurd, but every step looked innocent when I wrote it, and my study group split over which step to blame.

(1) A physical system implements a computation when there is a mapping from its physical states to the computational states that takes its actual state-transitions onto the transitions the computation prescribes. (2) Take any system with at least two distinguishable states and any finite-state program; enumerate the states the program occupies in order and assign them to successive slices of the system's actual history, so that the trajectory mirrors the program. (3) Nothing blocks such a mapping, so any two-state system implements any finite-state program: my kitchen kettle implements the program for perfect tic-tac-toe, and a bucket of water implements the program that computes the digits of pi. (4) A computationalist holds that a system is in mental state M just in case it implements the program that specifies M. (5) So the kettle is in every finite-state mental state, believing that Vienna is in Austria and hoping for rain; and since the same trajectory can be read as the program for denying computationalism as easily as for affirming it, the kettle holds contradictory beliefs. (6) A kettle holds no beliefs at all. (7) So computationalism is false.

One friend blames (2), saying my mapping is history-indexed: it reads the program off the trajectory after the fact, so it says nothing about what the system could have done otherwise, and once I require a mapping that is time-invariant and counterfactually robust, the kettle implements only trivial automata and computationalism is untouched — at the price, perhaps, of making implementation interest-relative. A second friend grants the mapping and blames (4): implementation was never meant to be sufficient for mentality. A third blames (1), insisting that describing a trajectory as a computation does no causal work.

I would rather keep (4) than (7), since I became a computationalist for a reason, but I want to know what keeping it costs. Which step should I reject, why did it look fine, and what does each of the standard repairs have to pay?
