Hey — I'm in a philosophy of mind course this term and something from last week's seminar is still bugging me. We were doing computational functionalism and the prof made the point that because computation is substrate-independant, you can describe pretty much any physical system as implementing any program you like, as long as you get to choose the state-mapping; she did the version where a rock comes out as implementing a lookup table. Then in the same session we talked about how from the outside we only ever get behaviour and never a view of which computation is actually running inside. Here's where I've landed: if any system can be described as implementing the computation that grounds experience, and we can never verify from the outside which computation is really happening, then there's no fact of the matter about which computations matter morally — moral status is just something we attribute, i.e. hand out. So the real question isnt 'which computations matter' but 'which ones should we decide to treat as mattering,' and that's a pragmatic call, not a discovery. Is that right, and if so is there any principled basis for drawing the line, or is it stipulation all the way down? One paragraph, max 200 words please.
