I came across a short popular piece on Russell's paradox and its aftermath, and I'd like an accuracy audit. It says: 'Russell showed that the set of all sets that are not members of themselves both is and is not a member of itself, which destroyed the naive assumption that every predicate determines a set. The argument is really the old barber and liar paradoxes in mathematical dress, and its lesson is that self-reference is illegitimate in a formal system. Russell's own remedy, the theory of types, arranged sets in a hierarchy so that no set could be a member of itself, and modern set theory follows the same strategy: ZF forbids self-membership, which is why the paradox cannot arise there. Two further morals are usually drawn -- that mathematics had to give up the idea that every property has an extension, and that there is simply no set of all sets.'

Which parts would a set theorist endorse, which are loose but harmless popularization, and which are actually false? I'm especially unsure about the self-reference diagnosis, and about the claim that banning self-membership is what does the work. Is there a consistent set theory in which a set can contain itself, or in which there is a set of all sets -- and if so, what becomes of the piece's morals? And is the closing claim about the universal set really the same moral as the rest, or a different one that has been folded in?
