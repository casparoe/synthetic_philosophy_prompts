I put together this arguement for a reading group on genetic information and now I can't decide whether it's clever or just broken. It seems to prove way too much. Here it is, numbered:

(1) A code is an arbitrary mapping between symbols and what they stand for: nothing about the symbol itself fixes what it means.
(2) The genetic code is arbitrary in exactly that way. Nothing about the codon UUU makes it fit phenylalanine rather than leucine; the assignment is a historical contingency, not a physical necessity.
(3) So the genetic code is a genuine code.
(4) But a genuine code requires an interpreter who knows the mapping. Morse code without a telegraphist is just dots and dashes; ASCII without a machine that reads it is just voltages.
(5) There is no interpreter in the cell. The ribosome is a chemical machine; it does not know that UUU stands for phenylalanine. The tRNA synthetases attach amino acids to tRNAs, but they don't represent the mapping either; they just catalyse reactions.
(6) So the genetic code is not a genuine code. Talk of genetic information is at best a metaphor.
(7) If you resist (6) by saying DNA carries information because it causally covaries with protein structure, then by that standard a thermometer carries information about temperature, tree rings carry information about age, and a footprint carries information about the burglar.
(8) So the claim that DNA is a code is either trivial (everything is a code) or false (DNA isn't). Either way it can't do the work people want it to do.

I'd rather keep the idea that the genetic code is arbitrary and that DNA carries information in some non-metaphorical sense, but I definately can't have both. Which premise or step should I give up, and what does giving it up cost? Tell me how confident you are in your diagnosis and which point you're least sure of. Keep it under 500 words.
