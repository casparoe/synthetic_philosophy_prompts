I'm building a handout for a grad seminar on historical explanation, and I want a decision tree that takes someone from the vague intuition 'big historical events usually have more than one sufficient cause' down to a named position on overdetermination. The thing I keep running into is that my students collapse three pretty different ideas into one: (a) many independent factors each of which was enough on its own, (b) many factors none of which was enough alone but which jointly did it, and (c) factors that were redundant given the others. I want the tree to force those apart before it hands out a label.

Structure it as a tree where every branch node is a question a student could answer without already knowing which position it leads to -- so no node that just asks 'are you a counterfactual theorist?' The nodes should be things like: does a factor count as a cause at all when the outcome would have happened without it? when several factors are each sufficient, does the outcome have one cause, several, or no interesting number of causes? is the multiplicity out there in the world or in our explanatory interests? do we explain by subsuming under conditions, by tracing a mechanism, or by narrating? and whatever else you think has to be on the tree to keep it honest.

For leaves, I want each one to carry the name of the position (or 'unnamed' if nobody defends it) plus one sentence on its most awkward commitment. The positions I definitely want to show up: the plain counterfactual/but-for view; the 'condition-set' view where a cause is an insufficient but necessary part of an unnecessary but sufficient condition (I know that formula is a mouthful, use it however you need to); the sufficiency-pluralist view that takes overdetermination at face value and says each sufficient cause is a cause; the preemption view that says redundant factors aren't causes at all, only the one that actually did the work is; the view that in history strict overdetermination basically never happens because the counterfactuals are too vague to be true or false; and the deflationary/interest-relative view that says 'overdetermined' is a fact about our why-questions, not about the past. Add any others the logical space seems to demand.

Two more things. First, the tree has to be able to handle at least these cases, so test each leaf against them and tell me where a leaf gives a verdict nobody would want: the outbreak of WWI in 1914, the collapse of the Soviet bloc around 1989-91, and the 2008 financial crisis -- plus, for contrast, the small-scale case of a firing squad where several shooters hit at once, and the two-fires-converging-on-a-house case. If a leaf only works for the metaphysical toy cases and not the historical ones, say so.

Second, flag any pair of leaves the tree can't actually separate, and go through the combinations of answers that don't correspond to any position anyone holds -- for each empty spot, give me a one-line diagnosis of whether it's empty because the view is incoherent, unattractive, or just unexplored. I'd rather have an honest 'these two are the same view wearing different hats' than a fake distinction. Keep it to something a student could work through in a class session, so maybe eight to twelve nodes at most.
