I'm in a Kant ethics course and I've argued myself into a view I'm not sure is even a view. I think the universalizability test is really one test, not two. The contradiction in conception is doing all the work: a maxim fails if you can't conceive everyone acting on it without the practice it depends on collapsing. The contradiction in will is not a seperate test; it's either the same failure restated for maxims that don't destroy a practice but make it pointless, or it's a different test Kant smuggled in because the conception test wasn't pulling its weight. So the standard two-test reading is wrong, and the four Groundwork examples are misleading. The suicide and false-promise cases are both conception failures; the neglected-talents and beneficence cases are doing something else, and calling them contradictions stretches the word.

What would count against this? I want the strongest objections, not the usual Kant-is-a-formalist stuff. Specifically: is there a maxim that clearly passes the conception test but is still morally wrong, and does the will test catch it without turning into a different principle? If so, does that vindicate the two-test reading? Also, what does a defender of the two-test reading think I lose by collapsing them? And is my view falsifyable, or have I just redescribed the text in a way that can't be wrong? I'd rather know if I'm making a merely verbal point. Rank the defeaters from fatal to merely awkward, and tell me which ones a committed one-test reader would concede and which they'd dismiss.

Here's a case I came up with that might be a test: I will break a promise only when keeping it would require me to break a more important promise. Does that pass the conception test? If it does, the test seems too weak; if it doesn't, then the false-promise example is about the practice of promising, not about lying as such. Which is it, and which reading of the test does that case put pressure on?
