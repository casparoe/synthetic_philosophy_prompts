I run a small reading group that's half philosophers and half ML people, and next week's guest is someone who's spent the last few years trying to make "avoid side effects" precise — the low-impact work, where you penalize an agent for moving the world away from where it would have been if it had done nothing, or for leaving the world harder to put back the way it was. He's a good sport and dosn't mind being pushed, so I want questions that get passed the pitch. Draft 8-10 of them, in an order that builds, and for each one write the follow-up I should have ready for the answer he's most likely to give — he's the type who'll say the measure doesn't need a full value spec, just one that's conservative across plausible ones, so plan for that reply a lot.

Roughly one question each on:

- the baseline. The standard gloss — what would have happened if the agent hadn't acted — sounds fine until you notice the agent is part of the world it's being measured against, so there's no clean counterfactual. Ask what the baseline actually is, and how he stops the obvious cheat where the agent first makes the baseline worse so that whatever it does next looks low-impact. Then ask what recomputing the baseline at every step buys him, and where that breaks down.
- the no-spec-needed claim. Is the measure really value-free, or has the value just moved into the choice of features and the distance between worlds — if you have to decide which differences count as impact, haven't you already decided what matters? Have a follow-up ready for the reply that those are just the observable features and the value function is a separate thing.
- the sign problem, which I think is the real killer. A penalty on diverging from the baseline can't tell the agent flooding the village from the agent vaccinating it — both are big divergences. If he says the value function signs it, ask whether that isn't the full spec he said he didn't need; if he says a truly conservative measure would never diverge at all, ask whether that's the point or the reductio.
- task versus side effect. A side effect is only defined relative to what's in the objective, so if the objective is incomplete then so is the notion of a side effect — the specification problem seems to reappear one level up. Get him to say where the line gets drawn, and by what.
- reversibility, which I suspect is doing intuitive work it can't carry. Some irreversible changes are obviously fine (curing someone) and some reversible ones are obviously bad (temporary but catastrophic damage you later clean up). So is options-preserved actually a proxy for harm-avoided, or a different thing that happens to be easy to measure?
- options versus power. Is the measure really about optionality, or about control, and is keeping the world's options open itself a substantive value claim rather than a neutral safety constraint? Follow-up: what about preserving options for someone who'll use them badly?
- the heuristic story. The reason low impact is meant to be safe is that if you don't know the true objective, messing with the world is likely to destroy something it values. Does that make the measure a compressed value spec after all? And as the agent learns more about the objective, should the penalty shrink?
- alignment or manners. Is an impact penalty a substitute for getting the objective right, or a complement that only helps once the objective is roughly right? I want him to commit on this one.

Write them so they're sayable out loud, and keep the follow-ups short — I want to fire them off without reading from a page.
