I run a small option module for third-years that mixes typography students with philosophy students, and next week's session is the one I always look forward to: what actually makes an 'a' an 'a'? The reading for it is thin on purpose — I'd rather they built the space of positions themselves than recited Hofstadter's Letter Spirit project at each other — so what I want to hand out is a decision tree they can walk through and land on a view.

So: build me the tree. Every branch node has to be a question a student can answer without already knowing which view it commits them to. No nodes like 'do you think letterforms have essences?' — that's just asking them to pick a label. Start from the logical space: which questions genuinely split it, then locate the actual positions in the leaves, then tell me which combinations of answers nobody occupies, and whether that's because the view is incoherent, unattractive, or simply unexplored. Keep it to something they can get through in twenty minutes — a dozen nodes at most. Each leaf should carry the name of the position (or 'unnamed' if nobody defends it) and one sentence on its most awkward commitment.

These are the cases I want the nodes to bite on, so work them in somewhere:

- the two-storey 'a' of a Times-ish text face verss the one-storey 'a' of Futura or my own handwriting — both 'a', apparently
- an 'a' five pixels tall in a bitmap font, where almost none of the strokes survive
- 'a' turned upside down, which in the IPA is a perfectly respectable letter in its own right, and 'a' mirrored, which is nothing at all
- a Cyrillic 'а' that looks to the eye exactly like a Latin 'a' — Unicode gives the two of them different code points
- an italic 'a' used as a variable in an equation, which also gets its own code point, if you can belive it
- 'å' in Swedish (a letter of the alphabet), 'ä' in German (also a letter), and an 'a' with a diacritic in English or French (not a letter)
- the 'a' in a joined-up cursive hand, which is honestly an 'o' with a tail
- the '@', which is a sort of 'a' with a ring round it
- an 'a' in a captcha or on a badly photocopied page, half eaten by compression

I want these leaves to appear: a Platonist line on a letter's essence that the fonts merely approximate; Goodman-ish conventionalism, where the letter is a compliance class fixed by a notation; prototype theory of the Rosch sort; exemplar theory; family resemblance; a purely differential view, where 'a' is whatever contrasts with its neighbours in the system; a causal-historical view, where it's an 'a' because of its descent from earlier 'a's; and a deflationary no-fact-of-the-matter option. If the tree needs a leaf that isn't on that list, add it and say why in a sentence.

Two more things to build in, because I don't want them reaching for the obvious vocabulary. First, the Metafont way of describing a letter: a skeleton path drawn with a pen that has a width and an angle. At least one node should turn on whether the identity of the 'a' lives in the skeleton, the flesh, or both — and whether the same skeleton drawn with a fatter, slanted pen is still the same 'a'. Second, Selfridge's pandemonium, those little feature demons feeding cognitive demons feeding a decision demon: I want a node asking whether 'a'-ness is better thought of as a detection routine in the visual system than as a fact about shapes at all.

Finally, flag the pairs of leaves your tree can't separate, and say for each whether some extra question would separate them or whether nothing could. Don't bother with citations, I'll add those myself.
