Construct a thought experiment in which a Goodhart effect occurs that is purely causal, with the regressional, extremal, and adversarial variants all absent or demonstrably negligible. For the purposes of this prompt, treat the four variants as follows: regressional — selection for an imperfect proxy also selects for noise, so the proxy overstates the goal in the selected tail; extremal — selection pushes the state distribution into a region where the old proxy-goal relationship no longer holds; causal — the regulator's own action causes the proxy-goal relationship to collapse; adversarial — an agent with different goals causes the collapse. The scenario should be realistic and ordinary — a workplace, a hospital, a school, or a similar setting — and no longer than one paragraph. It must not involve any agent deliberately gaming the metric, nor any science-fictional device, nor any perfect predictor. After the scenario, provide a demonstration that it meets the specification: for each of the four variants, state whether it is present and why. Then identify which single feature of the case is doing the work of making the effect causal rather than one of the others. Finally, say what happens if that feature is removed: does the case collapse into a different variant, or does the Goodhart effect disappear altogether? Close with an honest note on how a defender of the view that these four variants are not genuinely distinct — or that causal Goodhart cannot occur without adversarial gaming — would attack the case. The entire answer should be in British English.
