OK so this is a naming question more then a research question, but I've been carrying it around for a couple of years and I'd like to put it down.

I write about long-range forecasting for a living — regime collapse, the "is America Rome" genre, that whole corner of things — and there's a move I keep watching analysts make. Let me do it with the two examples that are actually in my notebook, because the abstract version always sounds like I'm complaining about pundits in general, which I am, but that's not the point.

First one: I ask someone how likely it is that the current global order breaks down in the next thirty years. They give me the story first — fiscal position, elite competition, the usual — and then at the end they produce the number that's supposed to keep the story honest: "of the 40-odd hegemons since 1500, about two-thirds lost the position within a century of their peak." Fine. Except the list of cases got assembled after the story, by someone who already has a view about how this one goes. The number arrives last, but it wasn't computed first, and it never once lands on the other side of the story.

The part that really nags me is the start dates. Every count like this starts the clock at the peak. Rome from 100 AD and Rome from 300 AD give you opposite answers, and we only know which is the peak because we know what happened next. So the thing that defines the reference class is downstream of the outcome the reference class is supposed to predict. Second example, smaller scale: recession pieces that cite the post-war record of expansions and contractions, re-dating the cycle each time so the "historical rhythm" always ends right about where the writer thinks we are.

And the tell, for me, is that these base rates never turn out to be wrong. Miss, and it was the 30% tail. So the number is doing rhetorical work — borrowing the authority of the outside view to launder a judgment that was inside all along — while being insulated from the one thing that makes an outside view worth anything, which is that it can embarrass you.

I've been calling it back-dating the base rate, which I'm sure is terrible. Is there an established name for this, or for the specific part of it, the reference class being constituted by the outcome? And if there isn't, I definately don't want a label slapped on it — I want the carving. What exactly is the phenomenon, what is it not, where are its edges. I keep being told it's just the reference class problem, and that doesn't feel like it, since the reference class problem is about which class is right and this is about the class being reverse-engineered. Does it require bad faith? The people doing it seem perfectly sincere to me. If someone writes their reference class down before they look, does the phenomenon disappear, or is that a patch over something that's still happening? And is there a real difference between a case where the class genuinely is indeterminate — is Byzantium an empire, does the Ottoman case count — and one where the analyst is quietly laundering a prior?

Last thing, and I mean it: I'd rather have the failure mode than a tidy answer, so tell me where this is most likely to be wrong. Which of my two examples is the weak one, and what would make you say there's no separate phenomenon here at all?
