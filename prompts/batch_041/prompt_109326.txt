I've been thinking about this wierd game called the Pasadena game. You flip a fair coin until it lands heads. If it lands heads on the nth flip, you win (-1)^(n-1) * 2^n / n dollars. So if heads on first flip, you win $2; if tails then heads, you lose $2; if tails, tails, heads, you win $8/3; etc. The expected value is the alternating harmonic series, which sums to ln 2 if you add it in the natural order. But because it's only conditionally convergent, you can rearrange the terms to get any sum you want. So people say the expected value is undefined. There's also the Altadena game, which is the same but with every payoff increased by $1, so its expected value would be ln 2 + 1 if it existed, but it doesn't. So you can't compare them by expected value.

Should a rational agent be indifferent between Pasadena and Altadena? Or is there a better decision rule? Also consider a biased version where the coin has probability p of heads. For p > 1/2, the expected value is well-defined and equals (p/(1-p)) * ln(3 - 2p). For p = 1/2, it's conditionally convergent. For p < 1/2, it diverges. What does this tell us about the nature of the problem? Does the discontinuity at p = 1/2 suggest that the undefined expected value is a measure-zero pathology, or does it reveal a deeper issue?
