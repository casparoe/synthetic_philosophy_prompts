Kim's causal exclusion argument starts from two claims. First, physical causal closure: every physical event that has a cause has a sufficient physical cause. Second, mental properties supervene on physical properties, meaning there can be no mental difference without a physical difference. Now suppose a mental property M causes a physical event P*. Since M supervenes, M is realized by some physical property P. P is sufficient for P*, so P already causes P*. If M also causes P*, then P* has two sufficient causes, which is overdetermination. Overdetermination is impossible, so M does not cause P*. Therefore mental causation is impossible. This is Kim's conclusion: epiphenomenalism is true. He thinks the only way out is substance dualism, because if mental properties are not physical then they can have their own causal powers. But dualism is scientifically implausible. A non-reductive physicalist might say mental properties are higher-level properties with their own causal powers. But if supervenience is true, mental properties are just identical to physical properties, so that view collapses into identity theory. So Kim's argument is basically right. The lesson is that mental causation requires giving up physical causal closure, which no one should do.
