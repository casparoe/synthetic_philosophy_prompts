Two researchers have argued for years about the reference class problem without converging. The first holds that a single-case probability is meaningful only relative to a reference class, and that no fact of the matter selects the right class, so single-case probabilities are indeterminate. The second holds that the only well-defined single-case probability is a rational agent's credence given its total evidence, and that the demand for a uniquely correct reference class is a demand for something that does not exist.

Draft the joint statement these two could both sign. It should contain: (a) a numbered list of agreed claims, including a shared formulation of the problem (what a reference class is, what a solution would have to supply, and which proposed resolutions they jointly reject); (b) each residual disagreement stated in wording its own side would accept; (c) the cruxes, in particular whether there is a fact of the matter about the correct class, whether a credence can be assessed as correct rather than merely coherent with the evidence, and whether any part of the dispute is verbal; and (d) for each crux, a case both agree bears on it, with each side's prediction recorded in advance. Use two cases: a patient whose broad reference class gives a low risk but whose narrow, causally relevant biomarker profile gives a high risk; and a one-off event belonging to no non-trivial class with more than one member. Format it as a numbered agreed-claims section followed by a disagreements table.
