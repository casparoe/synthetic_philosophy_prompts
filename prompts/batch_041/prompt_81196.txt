I've been going around in circles on heuristic arguments — the kind where you say "there's no reason for the digits of pi to be special, so treat them as random", or "this sum shouldn't have any structure, so assume it's about the size of a random walk". What I can't pin down is what actually licenses the presumption of independence. When I decide to treat some quantity as if it were independent of everything I know, or as if it were incompressible, what am I allowed to base that on?

So: rate the licenses below. For each one give me a number from 0 to 100 for how much you'd trust it *as a justification* for the claim "this thing behaves as if it were random / is incompressible". Not "is it suggestive", but "if this is all I've got, how much should I actually believe it". Then put them in tiers, and say in a sentence or two per item what's doing the work and where it would fail.

1. Counting. Almost all strings are incompressible (the fraction of n-bit strings that have some description a lot shorter than n is under about 2^-9), so whatever string gets handed to me, assume it's one of the typical ones.
2. Physical randomness. The bits came out of a physical process I have no handle on — a quantum measurement, thermal noise — so assume they're independent of whatever I'm trying to predict.
3. Symmetry. The thing is defined by a formula that's invariant under a big group of transformations, and the quantity I care about isn't, so assume the group scrambles it and the value is typical for its orbit.
4. No known shortcut. I know of no way to get the value other than just computing it, and the computation looks expensive, so assume the value is as if random.
5. Failed search. Alot of people have looked hard for structure and found none, so assume there isn't any.
6. Empirical passing. The first billion values pass every statistical test anyone's thrown at them, so assume the rest behave the same way.
7. No short description. If there were a pattern, there'd be some short description of it. I've tried and can't find one, so there isn't one.
8. Consensus. Everyone who's thought about it says it's random.
9. Two arguments agreeing. Two derivations that share no steps both predict "typical", so assume typical.
10. The independence presumption itself. If a quantity doesn't show up anywhere in my heuristic argument, the argument carries no information about it, so I'm licensed to treat it as independent of my argument.

A few things I want beyond the ranking. One, #10 feels like the actual engine and the rest like ways of feeding it — is that right, or are some of these genuinely seperate licenses that do work #10 can't? Two, is there a license I'm missing that doesn't collapse into one of these? Three, if I have to delete exactly one entry, which one goes? And four, I have a nagging worry that a heuristic argument short enough to be found is also short enough for someone to hide the answer inside it, which would sink the whole business — if that worry is right, does it mean one of these entries, or all of them, should be replaced by a criterion, something like "trust a heuristic only if an adversary who knows it couldn't use it to smuggle in the answer"?

Also tell me how confident you are in the numbers you give, and flag the single one you're least sure of.
