I'm writing a post for a rationalist-adjacent audience arguing that a lot of what looks like substantive disagreement about distributive justice is really a disagreement about one technical assumption: whether we can compare how much two people gain or lose, or only compare how well off they are. I need a constructed case in which that assumption is the only moving part. Build me a two-person scenario with ordinary stakes -- a scheduling decision, a raise, a housing assignment, nothing science-fictional -- in which two candidate policies are ranked in opposite ways depending on whether you compare the levels of the two people's well-being or the differences between the levels the two policies produce. Set it up ordinally: give each person's preferences over the outcomes and nothing else, then state precisely what extra fact about the two people's situations has to be true for the difference comparison to go through and the ranking to flip. No utility numbers in the setup; if a number appears, it should appear only as the thing being assumed. After the scenario: run both comparisons explicitly, name the social-choice rule that inherits each verdict -- the one that needs only level comparisons, and the one that needs differences -- and say which of the two a defender of each would call the real ranking. Then tell me which single feature of the case is doing the work and what the case collapses into if you delete it; I want to be able to write that taking away this one fact makes the disagreement vanish. Finish with the strongest objection from someone who thinks interpersonal comparison beyond ordinal Pareto is meaningless -- where exactly does that person say the case smuggled in an assumption, and can the case be rebuilt to survive it? The case is for showing that the level/difference distinction, rather than any substantive value disagreement, is what separates the two rules, so a case that stipulates a verdict instead of deriving it from the two comparisons is useless to me.
