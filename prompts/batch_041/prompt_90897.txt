Everyone keeps saying DNA is a code and genes carry information. I want you to argue the other way: that the genetic code isn't really a code and genetic information is at best a loose way of talking. Dont just give me the usual it's-all-just-chemistry line — thats boring and probably wrong anyway, since the codon-to-amino-acid mapping is stable enough that something needs explaining. The angle I want is that the mapping isn't fixed the way a real code should be: the same codon gets read differently depending on the organism and the cellular context (a stop codon that sometimes codes for an amino acid, for instance), and where it is fixed it's constrained by chemistry rather than being arbitrary. Argue that once you take that seriously the code metaphor falls apart, say what weaker claim survives, and then give the strongest reply from someone who wants to keep the code picture.
