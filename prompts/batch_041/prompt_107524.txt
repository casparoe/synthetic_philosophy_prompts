A colleague has constructed an argument she says the accuracy-first programme cannot survive, and I cannot find the loose joint. It runs: (1) A credence function is irrational if some other credence function would have been strictly more accurate at some possible world and less accurate at none. (2) Let c be any credence function that is not perfectly accurate at every world. (3) Consider the function that assigns credence 1 to every true proposition and credence 0 to every false one — the truth function. (4) At any world the truth function is perfectly accurate, so it is at least as accurate as c there, and strictly more accurate at every world where c falls short. (5) Hence the truth function dominates c. (6) By (1), c is irrational; since c was arbitrary, only the truth function is rational, and every actual agent is irrational. (7) That is absurd, so accuracy-first epistemology refutes itself.

I want to keep (1): the anti-dominance principle is the engine of the whole view, and I would rather not give up the conclusion that incoherent credences are irrational. But I plainly cannot keep (6). Which step should I reject, and what does rejecting it cost?

I am especially interested in the following. If the reply is that the truth function is not a single option, since which propositions are true varies from world to world, then tell me why the same reply does not also dissolve the original dominance argument for probabilism — whose dominating function, if I understand it, is a fixed assignment rather than a world-dependent one. If the asymmetry between the two cases is genuine, say exactly what makes a credence function a single available option; if it is not genuine, say how much of the accuracy-first architecture has to go.
