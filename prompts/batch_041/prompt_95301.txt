I'm not an academic — I fix bikes for a living — but I've been chewing on something for months and I dont know where to start with it. It began with the bylaws of the housing co-op I live in. One rule says any bylaw can be changed by a two-thirds vote of the members. Another says the clause about membership fees can never be changed. Someone pointed out that if two-thirds of us can change any bylaw, we can change the never-clause first and then change the fees, so nothing is really protected. Someone else said no, that's like using a key to unlock the box the key is locked inside — the rules never gave us permission to do that, and if we did it the document would stop being the thing we agreed to. Then a third person said: whatever we do, some rule has to be the one that makes the change legal, and if that rule is the new one you're assuming the conclusion, and if it's the old one then nothing actually changed. Nobody could settle it, and honestly I think about it in the shower now. A friend also showed me a game where changing the rules mid-play IS the game, and the same knot shows up there — some move always lets you rewrite the rule that let you make the move.

So I want to spend my evenings on this for about a year, ten hours a week, and end up with something a normal person could actually use — co-op boards, tenants unions, little clubs, anyone drafting rules for a group that has to govern itself. I can't go back to school and I'm not going to read a hundred books.

Which questions here are actually worth that year, and in what order? I want the reasoning more than the list: which ones are upstream of the others, so that sorting one out makes the rest easier; which ones a person with no training and no library access can actually make progress on; which sound deep but wouldn't change a single sentence of what I'd write for a co-op; and what would move a question up or down your list. Also tell me straight if the honest answer is that this all collapses into whoever happens to enforce it wins — and if that's the answer, whether that's the boring answer or the real one.
