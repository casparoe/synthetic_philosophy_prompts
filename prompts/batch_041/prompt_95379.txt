What the student wrote:

"The first incompleteness theorem says that any consistent formal system strong enough to express arithmetic contains true statements it can't prove. Gödel's method is to number the formulas and proofs (Gödel numbering) so a formula can be about formulas, and then to construct a sentence G that says, in effect, 'this sentence is not provable in this system.' If the system could prove G, then since G says there's no proof of G, the system would be proving something false — it'd be unsound. So a sound system can't prove G. But that's exactly what G says, so G is true. Hence there's a true sentence the system can't prove, and by the same construction infinitely many. So no formal system captures all mathematical truth, and there are truths that are in principle beyond the reach of any formal system.

The second theorem says a consistent system can't prove its own consistency. That's what killed Hilbert's program — you can't certify arithmetic from inside arithmetic. It also means consistency can never be established, only assumed: any proof would have to happen in a stronger system, whose consistency would in turn be unproven, and so on forever.

Now the mind. Hofstadter's idea is that G is a sentence that, by referring to itself, sees a truth about its own system that the system can't prove — it jumps out of itself. In GEB he finds that pattern everywhere, in DNA, in Escher, in Bach's canons, and says a mind is a system that by representing itself can outrun any fixed set of rules. The Gödel sentence is the formal core of self-awareness.

Lucas and Penrose take this literally. Take any formal system F that someone claims is me. I can construct F's Gödel sentence and I can see that it's true, while F can't prove it. So I know something F doesn't, so I'm not F, and since F was arbitrary, I'm not any formal system. The usual objection is that computers might one day be cleverer than us, but that misses the point, because the argument works for any system however powerful. Another objection is that the theorem only applies to systems that can do arithmetic, but that actually helps, since thinking presumably isn't reducible to arithmetic. The only real caveat is that the whole thing is suggestive rather than a proof — Hofstadter is careful to say the strange loop is a picture, not a theorem."
