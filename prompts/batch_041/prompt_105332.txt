Here's the student's answer:

(a) The successor-state axiom for at after move is: at(r, l') holds after move(r, l) if l' = l, and otherwise it holds after the action just in case it held before. A frame axiom is what you need on top of that: it says if at(r, l) was true before move and l wasn't the destination, then at(r, l) is still true afterward. Without frame axioms the logic has no way to tell that moving somewhere doesn't also change, say, holding(r, x). So the frame problem is: how do you state compactly all the stuff that stays the same when an action happens.

(b) The qualification problem is basically the same issue seen from the other side. It's about how you specify everything that has to be true for an action to actually work -- the object isn't bolted down, the robot's battery is charged, the gripper isn't already full, and so on. Really both problems are one problem, namely that in the real world there are indefinitely many conditions you can't enumerate in advance. The frame problem was first named by Dennett, whose robot examples in the 1980s showed that a purely deductive system would have to spend forever checking that its actions didn't have unexpected side effects.

(c) The relevance reading says the real trouble isn't just writing down the frame axioms, it's that a thinking system has to work out which facts are even relevant to a given change in the first place. On this reading, a system that gets every frame axiom right still faces the problem of knowing what to look at, so the deep version isn't solved just by switching to non-monotonic logic. Circumscription helps with the narrow, representational version, but people like Fodor and Dennett argue the deep version is really about how cognition homes in on what matters.
