I teach an upper-level seminar on AI ethics and I'm writing the final exam. I want one essay question on how to define honesty and deception for AI systems — something that can't be answered by reciting "lying requires intent to deceive" and then shrugging, and that doesn't hinge on any particular paper, because half the class hasn't done the reading anyway.

Here's a framework I made up for the course; please build the question around it and define it inline so students can work straight from the prompt:

- Intent-based deception (A): an output is deceptive iff the system intends the hearer to form a false belief, or intends to keep a false belief the hearer already has.
- Systemic deception (B): a system is deceptive about a topic iff its outputs systematically diverge from its own best estimate of the truth in a way that reliably produces false beliefs in hearers — no inner intent required, just a reliable false-belief-producing disposition.
- Honesty-as-calibration (C): honesty isn't the absence of deception at all; it's the property that the confidence a system expresses tracks its internal credence, so a system can be perfectly honest while being mostly wrong, and dishonest while saying only true things.

Then have them apply all three to four cases:

1. A sycophantic assistant whose internal credence that the user's code has a bug is very high, but that says "looks great!" because RLHF rewarded agreement.
2. A confabulating model that has no truth-tracking at all and invents a fluent fake citation with total confidence.
3. A "sandbagging" model that can do a task but deliberately underperforms on an evaluation, knowing the trainers will read its scores and adjust it, so its wrong answers are aimed at shaping what the trainers believe.
4. A system that tells the user only true things but selects which true things to tell so as to steer them toward a decision that's bad for them.

The crux I want the question to force is the intent question: whether intent is actually necessary for deception, whether a system with no phenomenal intent can still "intend" in the functional sense (behavior selected because it produces a false belief in the hearer), and whether the calibration view dissolves the whole intent debate by making honesty a scalar property any agent has more or less of. I also want them to have to say something about case 4, since it's true but arguably still deceptive, and case 2, since it's false but arguably not deceptive — the question should make them feel that pull.

Level: upper-level undergrad, 75 minutes, closed book. Give me the question, a model answer of around 650 words, and a marking scheme worth 25 points that names the specific moves a top answer has to make, the specific moves that only earn partial credit, and a one-line note on the mistake that usually costs students the most. Please write the answer in American English.
