A colleague in the statistics department has persuaded himself that the reference class problem is not a puzzle about how to choose a reference class but a proof that objective probability is incoherent. His argument runs as follows. (1) Every event is particular; no two events are exactly alike in every respect. (2) A probability is a fact about the relative frequency of an attribute within a reference class of events. (3) A probability is determinate only if the reference class is one the event fits exactly; otherwise the choice of class is arbitrary. (4) For any particular event, the only reference class it fits exactly is the singleton class containing that event and nothing else. (5) Within that singleton class the attribute is either present or absent, so its relative frequency is either 1 or 0. (6) Hence every event has a determinate objective probability of either 1 or 0, and no intermediate probability is determinate. (7) Yet meteorology, medicine, and insurance all treat intermediate probabilities as determinate objective facts about the world. Something has to give. I would most like to keep (2). Tell me which premise or step to reject, why it looked plausible, and what rejecting it costs. Say how confident you are in your diagnosis, and identify the point you are least sure of.
