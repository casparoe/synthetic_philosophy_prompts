Next month I present to a theory seminar — mostly classical game theorists and mechanism designers, plus two computer scientists who work on multi-agent systems — a paper arguing that the robustness of program equilibrium has been overstated. The standard setup has each player submit a program that can read the opponent's source code before choosing an action, with cooperation in the one-shot Prisoner's Dilemma sustained by programs that cooperate just in case the opponent's program does. My contribution swaps perfect source-code access for an oracle that hands back a corrupted copy of the opponent's program with probability ε; I show that a modified cooperative equilibrium survives, but that the cooperative payoff advantage over defecting shrinks linearly in ε, so cooperation is exactly as fragile as the transparency assumption the literature treats as costless.
