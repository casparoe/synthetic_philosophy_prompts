Selection doesn't need to understand the design; a machine doesn't need to understand arithmetic to crank through it. For our team reading group I want a short poem, 16 to 20 lines, that enacts the reversal instead of explaining it. Use a mirror/chiasmus structure: pick four motifs, something like understanding, mechanism, result, selection, and run them A-B-C-D in the first half, then D-C-B-A in the second, so the poem literally runs the order of explanation backwards. The turn should be where the reader notices the doing was already happening before any mind got involved. Keep it a little creepy; the comprehension might just be a README written after the code was already running. Don't make it a smug AI poem or a TED talk. Someone who knows the Darwin/Turing inversion should recognize it, but don't name-drop if the poem doesn't need it.
