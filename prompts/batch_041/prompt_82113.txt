If heads first appears on toss n, the player receives a payoff of (−1)^{n−1} · 2^n / n dollars. (So if heads on toss 1, you win $2; if heads on toss 2, you lose $2; if heads on toss 3, you win $8/3; etc.) Does this game have an expected monetary value? If so, what is it? If not, why not? And what does your answer imply for the claim that a rational agent should maximize expected monetary value?

One student wrote: The Pasadena game is a variant of the St. Petersburg game. In the St. Petersburg game, you win 2^n dollars if heads first appears on toss n, and the expected value is infinite. In the Pasadena game, the payoffs are divided by n and given alternating signs, so the expected value is the alternating harmonic series: 1 − 1/2 + 1/3 − 1/4 + ... This series converges to ln 2, which is about 0.693. So the expected monetary value is ln 2 dollars. However, the series is only conditionally convergent, meaning that if you rearrange the terms you can get different sums. For example, you can rearrange it to get 1.5 or even to diverge. This means that the expected value is not well-defined, because the order in which you add up the outcomes is arbitrary. So the Pasadena game shows that expected value maximization is not always well-defined. But since the natural order of the game gives ln 2, and that's the order in which the game is played, I think it's still reasonable to say the expected value is ln 2. The deeper lesson is that decision theory needs to specify an order of summation, or we should use a different decision rule like maximin. So in conclusion, the game has an expected value of ln 2 in the natural order, but it's not well-defined in general, so expected value maximization is problematic.
