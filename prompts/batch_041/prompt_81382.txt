Question 3. The Pasadena game is played as follows. A fair coin is tossed until it lands heads. If heads first appears on toss n, the player receives (-1)^(n-1) 2^n / n dollars. (So the player wins $2 if heads appears on the first toss, loses $2 if it appears on the second, wins $8/3 if it appears on the third, and so on.)

(a) Write the expected monetary value of the Pasadena game as a series and evaluate it.

(b) The Pasadena game is often described as having an undefined expected value. Explain what this means and why it is so, given your answer to (a).

(c) A decision theorist claims that because the expected value is ln 2 > 0, a rational agent should be willing to pay a small positive fee to play the Pasadena game. Assess this claim.

(d) The Altadena game is identical to the Pasadena game except that every payout is made positive. What is its expected value? What, if anything, does the comparison between the two games show about the significance of undefined expected value?

Student's answer:

(a) Let n be the toss on which the first head appears. The probability of this outcome is (1/2)^n, and the payout is (-1)^(n-1) 2^n / n. So the expected monetary value is

Σ_{n=1}^∞ (1/2)^n · (-1)^(n-1) 2^n / n = Σ_{n=1}^∞ (-1)^(n-1) / n.

This is the alternating harmonic series, which converges to ln 2. So the expected value is ln 2, approximately 0.693 dollars.

(b) The series converges, but only conditionally. Its terms alternate in sign and decrease in magnitude toward zero, while the series of absolute values, Σ 1/n, diverges. Because the convergence is conditional, rearranging the terms can change the sum: a conditionally convergent series can be rearranged to converge to any real number, or to diverge. So a different ordering of the outcomes would yield a different "expected value." This is why the game is often said to have an undefined expected value. However, the outcomes of the game have a natural order, given by the sequence of coin tosses: first toss, second toss, and so on. In that natural order, the series sums to ln 2. Since the natural order is generated by the game itself, it is not an arbitrary rearrangement, and so the game does have a well-defined expected value of ln 2. The talk of an undefined expected value is therefore somewhat misleading.

(c) Since the natural order yields ln 2 > 0, a rational agent should be willing to pay a small positive fee to play the Pasadena game. Other orderings of the outcomes yield other sums, but those orderings do not correspond to how the game actually unfolds, so they are irrelevant to the decision.

(d) In the Altadena game, every payout is positive: the payout on toss n is 2^n / n. The expected value is

Σ_{n=1}^∞ (1/2)^n · 2^n / n = Σ_{n=1}^∞ 1/n = ∞.

So the Altadena game has infinite expected value. Since infinity is not a real number, its expected value is also undefined, just like the Pasadena game's. The comparison therefore shows that making all the payouts positive does not remove the problem: both games fail to have a well-defined finite expected value.
