"Kim's exclusion argument is meant to show that non-reductive physicalism can't give mental properties any real causal role. It starts from the causal closure of the physical, which says that every event that has a cause has a sufficient physical cause. It also assumes non-reductive physicalism, so mental properties are not identical to physical properties — instead they supervene on them, which means any difference in mental properties requires a difference in physical properties. Now suppose a mental property M causes a physical event P, like a belief causing the movement of my arm. But P already has a sufficient physical cause: the physical state that M supervenes on. We don't want to say P is systematically overdetermined, so one of the two causes has to go. The physical cause can't be given up without violating causal closure, so it's the mental one that gets excluded. So the mental property ends up being a cause only in some derivative sense, and really the physical cause is doing all the work.

And it's worse than that, because since M supervenes on the physical it is also caused by the physical, so even if we let M be a cause it's just an effect of the physical base, which is basically epiphenomenalism. That's why Kim thinks non-reductive physicalism collapses. Actually the argument is stronger than people give it credit for, because it also rules out reductive physicalism: if mental properties were identical with physical properties then you'd still have the same event being caused twice, so you'd get overdetermination either way. That leaves dualism as the only option, which I think is why Kim himself ends up accepting some kind of dualism. Overall I think the argument basically works, because causal closure is obviously true given science, and there's no good reason to allow overdetermination in the brain. The only escape would be to deny supervenience, and nobody wants to do that."
