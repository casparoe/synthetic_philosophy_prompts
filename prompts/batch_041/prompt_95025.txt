"The simple conditional analysis says that an object is disposed to give manifestation M in stimulus conditions S just in case, were S to occur, M would occur. So a glass is fragile iff it would break if struck.

The electro-fink case is meant to show this is wrong. Suppose a wire is live, so it is disposed to conduct electricity when touched. A device is attached that detects the moment of touching and immediately cuts the current in the wire. If you touch the wire, it does not conduct. So the counterfactual that it would conduct if touched is false, even though the wire is live. Hence the simple analysis fails.

The masking case makes the same point from the other direction. A masking case is where some external factor interferes with the disposition's manifestation. For example a fragile glass is wrapped in packing foam, so it doesn't break when struck. Here the glass is still fragile, but it doesn't manifest, so again the counterfactual comes out false and the analysis fails. In the electro-fink, the device is the masker: it stops the wire conducting without taking away its power to conduct.

The difference between a fink and a mask, then, is mostly about where the interference comes from. A fink is built into the object (the device is attached to the wire), while a mask is external to the object (the foam is around the glass, not part of it).

Lewis's reformed conditional analysis fixes this by adding a proviso. It says x is disposed to M when S iff x has some intrinsic property B such that, if S were to occur and x were to keep B, then x would M. This gets around the electro-fink, because although the wire loses its conducting power at the moment of touching, it does have an intrinsic property B, and the counterfactual is evaluated under the supposition that it keeps B. Since the same proviso covers the masking case as well, the reformed analysis deals with both problems at once, which is why it is generally regarded as the successful analysis of dispositions."
