Question. In the Two Ledgers framework, an agent distinguishes first-order verdicts, which concern what to do now, from second-order verdicts, which concern which deliberative procedure to adopt. Indirect normativity is the thesis that a first-order verdict is correct just in case it is what the agent’s idealised second-order procedure would endorse. A critic objects that this makes first-order verdicts merely derivative: the idealised procedure can endorse whatever it likes, and a first-order verdict has no independent authority to constrain it. Set out the strongest version of the critic’s objection, assess whether the framework can answer it, and say what follows for the framework if idealised deliberation is indeterminate between several procedures rather than delivering a unique verdict.

Candidate’s answer. The critic’s objection is best read as a regress worry. If a first-order verdict is correct only because the idealised second-order procedure endorses it, then either the procedure is correct in virtue of something further, or the framework is circular. The Two Ledgers theorist can answer that the procedure is not a proposition that needs to be correct; it is a procedure, and its authority is constitutive. On this reading, indirect normativity is a form of procedural realism: there is a fact of the matter about what the idealised procedure would endorse, but no further fact about whether the procedure tracks an independent normative order. That is a coherent position.

The objection bites only if the procedure is supposed to be purely procedural. If the idealised procedure is an idealisation of the agent’s own deliberation, then it can only transform the agent’s existing commitments; it cannot generate substantive verdicts about what to do. So the framework must either import substantive normative content into the procedure, in which case the first-order verdict is derivative after all, or admit that the procedure is empty. This is why the framework is really a version of ideal observer theory: the idealised agent is stipulated to be fully informed and impartial, and those stipulations do the substantive work.

Indeterminacy makes the problem sharper. If idealised deliberation is indeterminate between several procedures, indirect normativity cannot tell the agent what to do. The agent is left with a set of first-order verdicts, each endorsed by some idealised procedure. That is not a decision procedure; it is a menu. The only way out is to build a tie-breaking rule into the idealised procedure, but then the tie-breaking rule is doing the normative work, and the first-order verdict is again derivative.

A better version of indirect normativity would say that the idealised procedure constrains first-order verdicts rather than generating them. The procedure sets the boundaries of acceptable deliberation, whilst first-order reasoning determines the particular act. This preserves the authority of first-order verdicts and avoids the regress. So the critic’s objection succeeds against the strong reading but not against the weak reading.
