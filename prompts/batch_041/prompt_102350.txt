A reading group I'm in has spent two weeks on the idea that if two agents' choices are fixed by their source code and each can read the other's code before acting, then mutual cooperation is rationally available in a one-shot Prisoner's Dilemma: you write 'cooperate if the other program cooperates, otherwise defect', and against that program the other agent's best move is to cooperate, and vice versa. Thats the result I want to keep. But I sketched the following last night and now I suspect the whole thing is a conjuring trick. (1) In this setting my choice of program is rational if no other program I could have written would have earned me more, given the program you are running — the same test a firm applies to its price when its rival's price is fixed. (2) Let M be 'cooperate if the other program cooperates, otherwise defect'. M is a best response to M: running M against M gets me the mutual-cooperation payoff, and running anything that defects against M gets me the mutual-defection payoff. So mutual cooperation is a rational outcome of a one-shot PD, even though defect-defect is the unique Nash equilibrium of the game itself. (3) Nothing in (1) or (2) mentioned the PD, or its payoffs, or the number of players. So run the same test on a bargaining game: we each name a share of £10, and if the shares sum to more than £10 we both get nothing. Your program R: 'if the other program names 10, name 0; otherwise name 10.' My best response to R is to name 10, which gets me the lot; and R is a best response to 'name 10' as well, in the weak sense that against 'name 10' every share you could name gets you nothing anyway. So the very same test certifies a 10-0 split, with the responder's program rational only because they are indifferent between all their options. (4) Worse, off-path branches are never reached, so the test cannot see them. Against M, 'cooperate if the other program cooperates, otherwise defect' and 'cooperate if the other program cooperates, otherwise hand the other player everything' are equally best responses, and in a game with something nastier to do to a defector than defect, a program that does that instead is equally a best response. The moral difference between a conditional cooperator and a conditional monster is invisible to the test. (5) Drop the other agent altogether and let 'their program' be the weather, or a market, or a bureaucracy's rule-book. Then (1) says: do the best you can given how things will go, which is a truism. So every bit of work the criterion does, it does in the case where the other party's action is a function of my program. (6) And I don't get my program for free. I have to choose it, knowing you can read it and that you know I know you can, so the same question comes back one level up, about the program that chooses my program, and then again. Either something is fixed at some level — why there? — or nothing ever is, and then (1) never gets to apply to anything. (7) So I'm stuck: keeping (2) seems to require a test that also certifies (3) and (4) and never bottoms out at (6), while giving up (2) throws away the thing we spent two weeks on. Something is being smuggled in between (1) and (6) and I can't see what. Which step do you give up, why did it look fine, and what does giving it up cost me — specifically, does it cost me (2)? British English please, and make the last line just the step you are rejecting, as \answer{N}, or \answer{none} if you think the chain survives.
