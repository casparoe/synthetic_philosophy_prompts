Write a joke about program equilibrium: the idea that two programs playing a one-shot Prisoner's Dilemma can reach mutual cooperation if each is allowed to submit its source code and to make its move a function of the other's code.

Please don't write the generic version of this, i.e. two robots eyeing each other warily. Build the joke around a specific variant, which I'll stipulate: each program can read the opponent's source in full, but is barred from reading its own. It is perfectly transparent to the other player and completely opaque to itself — it cannot introspect, cannot simulate its own decision procedure, cannot inspect the branch that determines its own move. In every other respect the setup is the ordinary one.

The joke should be funny to someone who actually knows how program equilibrium works, so the punchline should turn on the substance. It might turn, for instance, on the kind of nested reasoning one program has to do about the other's reasoning, or on the gap between a program that cooperates because it has proved something about its opponent and one that cooperates merely because it was built to. It should not turn on robots, on mutual suspicion in the abstract, or on the word "recursion."

Alongside the joke, give me a brief note on where it takes liberties: which elements of the scenario are faithful to program equilibrium as it is usually set up, and which are my own stipulation or a contested way of reading it. And if the premise doesn't hold up — if, say, "a program that cannot read its own source code" turns out not to describe a coherent variant, or if what I've stipulated isn't enough for the joke to have a real punchline — say so plainly rather than writing the joke regardless.
