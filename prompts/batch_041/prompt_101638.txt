I have been trying to write down my position on whether trained neural networks genuinely have internal representations, and I would like a consistency check before I commit to it in print. What I hold is roughly the following.

First, realism: when a trained network's internal states reliably track some feature of its inputs and that information is used downstream, the network genuinely represents that feature, and representational talk about it is not a mere convenience. Second, the causal-role criterion: a state counts as representing X only if intervening on it changes the network's downstream computation in the way it would change if X itself had changed. Third, basis-independence: for a typical trained network there is no privileged basis for its internal states, so content is fixed only up to an invertible recoding, and questions about which individual units or directions carry a given piece of content are usually ill-posed. Fourth, superposition: networks represent far more features than they have dimensions by spreading them across overlapping, near-orthogonal directions, so any account that assigns a single feature to a single unit is at best an idealization. Fifth, the prediction-and-control criterion: an interpretability claim earns its keep only if it improves our ability to predict and steer the network's behavior on inputs we have not tested. Sixth, I take convergent agreement between interpretability methods that rest on different assumptions to be strong evidence that the feature they agree on is real.

Which of these are actually in tension, which only appear to be, and how severe is each genuine conflict? Please rank the tensions rather than treating them as equally bad, and for each one say what would have to give and what that concession would cost me. I am especially concerned about whether my realism can survive the way I have set up the other five commitments.
