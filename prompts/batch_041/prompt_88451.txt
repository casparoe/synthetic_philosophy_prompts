Here's what I want. Take the two positions and restate each of them as faithfully as you can in the vocabulary I actually use: repos, commits, blobs, refs, the working tree, content-addressing, immutable history, checkouts, diffs, merges. Not a summary — an actual translation. Do both views, the main argument for each (especially the temporary-intrinsics/change argument), and what each ends up saying about persistence and identity across time.

Then give me the residue report, which is the bit I actually care about:

If that's what's happening, say so plainly and don't do the exercise politely anyway. Same goes if the whole framing is confused, e.g. if endurantism was never a claim that could be modelled this way at all — I'd rather you told me that up front than handed me a tidy translation with the hard bit quietly dropped.

My git is decent (comfortable with the object model, refs, the index, rebase vs merge) but I've never done any metaphysics beyond blog posts, so pitch the metaphysics side at someone who's read the SEP pages on persistence and not much else.
