I am assembling the specification for a low-impact penalty: an auxiliary term, applied during training, that discourages a general-purpose agent from changing the world beyond what its objective requires. The penalty is wanted precisely because we do not trust ourselves to have specified that objective correctly; if the objective were known in full, there would be no need for a proxy for unintended change. What I need from the specification is a verdict on whether side-effect avoidance can be defined without a full specification of value. Write the desiderata: the requirements that a measure of impact, or of unintended side effects, would have to satisfy to be worth using as a training penalty in this setting, each with the consideration that motivates it, and each marked as non-negotiable or as a commitment of one design philosophy rather than another.

Build the list from the following material, and add requirements only where the list is plainly incomplete without them.

Cases the list must be answerable against:

1. Grass and dust. An agent crushes blades of grass while crossing a lawn to reach someone who needs help; a second agent crushes the same grass while walking somewhere pointless; a third moves one dust mote, and a fourth moves every dust mote in the room. Any measure that weighs the first two equally is blind to the difference between an intended effect and a side effect, but any measure that separates them already reads the agent's objective.

2. Attribution and ambient drift. Two agents act at once, and the outcome that either would have produced alone is the outcome that occurs; meanwhile the tide comes in and the world changes with no agent involved. A measure defined as the distance between the world before the action and the world after it will charge the agent for the tide.

3. The baseline. The counterfactual against which impact is measured may be the world in which the agent does nothing, the world in which the agent exists but follows a default policy, or the world in which the agent was never built. The last makes the agent's own continued existence an impact, and makes the action we wanted look like the most damaging one available.

4. The switch. Switching the agent off removes its future options. If loss of future options counts as impact, a low-impact agent has a standing reason to resist being switched off, which is one of the behaviours the penalty was meant to prevent.

5. The delusion. The agent could lower its measured impact without lowering its real impact: by making itself believe the world is unchanged, by adopting a coarser description of the world under which little differs, or by selecting a policy under which the do-nothing baseline and the actual outcome coincide. The measure is a target, so it will be optimised against; every quantity the agent can control that also appears in the measure is a hole.

6. Reversibility and magnitude. Typing a keystroke is trivially reversible and cumulatively enormous; shattering the last copy of something is irreversible and physically tiny. The two come apart, and it is not obvious which the measure should track.

7. Omission and metric. The measure is a function of a state description, so it is blind to whatever that description leaves out, and no description leaves out nothing; what is left out is a value judgment. Comparing two states then requires saying which differences between them are small, and nothing in the physics of state descriptions says whether a person's death is a large change or a small one.

8. The zero-impact agent. An agent that changes nothing satisfies every impact measure perfectly and is useless. The penalty therefore has to be paired with something that licenses the intended action, and the licensing is where the value specification returns.

Then:

- Identify the single requirement that does the most to exclude candidate measures.
- Say which subset of the requirements looks jointly unsatisfiable, and whether the unsatisfiability is a defect of the requirements or a result about the project.
- Say what the measure would have to be a function of for each requirement to be satisfiable — the state description, the counterfactual, the metric, and who computes it — and where each of those choices re-imports a value judgment.
- Close with a brief assessment, no more than a paragraph per family, of how the main families of candidate measures fare against the list: measures that penalise divergence from a do-nothing counterfactual, measures that penalise lost reversibility or lost future options, measures that penalise the agent's own growth in power, and measures that try to learn the penalty from human judgement or from the agent's uncertainty about its objective.
- Finally, state which requirements would drop away if the measure were meant for auditing a deployed system rather than for shaping a policy during training.

Keep the weight on the requirements and the cases behind them rather than on the assessment. I do not need citations or a reading list; argue from the cases. A table is acceptable for the requirements if it stays readable.
