A colleague proposes the following fix for the reference class problem. To estimate the probability that a particular event E occurs, first list all the properties of the case. Then, for each property, form the narrowest reference class of past cases that share that property and compute the frequency of E in that class. Finally, average these frequencies, weighting each class by how many properties it shares with the case. She claims this dissolves the problem because no single reference class is privileged. Please explain what is conceptually wrong with this proposal. In particular, address whether averaging over reference classes is well defined, whether the weights can be justified without already presupposing a reference class, and whether the proposal confuses the reference class problem with the problem of selecting a statistical model.
