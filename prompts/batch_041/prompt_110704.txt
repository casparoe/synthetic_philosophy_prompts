ok so i've been in this reading group about whether you can get an AI to tell you what it "really" knows, and they've asked us to write our own positions down so people can poke holes. here's mine, roughly:

(1) there's a fact of the matter about what a model knows. when we say a model "has" knowledge it can't currently express, that isn't just a way of talking -- theres something in the model that makes it true or false.

(2) a model's own statements about its own knowledge ("i don't know that", "i'm not aware of any X") are very weak evidence. you can train a model to confidently deny something it can otherwise be shown to represent.

(3) the real test of whether a model knows something is behavioral: if the right prompt, fine-tune or scaffold gets it out, it knew it. if no amount of elicitation gets it out, it didn't know it.

(4) training on human feedback doesn't add knowledge, it only changes which of the models existing representations get expressed. all the knowledge was there after pretraining.

(5) there's a sharp distinction between the base model and the assistant persona. the persona is a character the base model is playing, and the base model has its own beliefs, which the persona's statements are evidence about only very indirectly.

(6) once interpretability gets good enough we'll be able to read the answer straight off the weights, and that will settle questions behavioral probing can only guess at.
