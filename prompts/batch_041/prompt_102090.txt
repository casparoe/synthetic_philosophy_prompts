I'm putting together a handout for a grad seminar on higher-order theories of consciousness, and I want the core of it to be a decision tree — a flowchart that takes someone from "yeah, some mental states are conscious in virtue of a higher-order state being about them" down to a specific position, without them needing to know the labels in advance. The whole point is that it sorts people by what they actually think about the cases, not by which name they like, so every node has to be a question they can answer cold.

Here's the angle I want it built around, because the standard textbook version is boring and everyone's already memorised it: organise the tree by what the higher-order state *is* and what it has to *represent*, not by who defended what. In particular I want it to force the taker through (a) whether the higher-order state is thought-like (conceptual, reportable) or perception-like, (b) whether it represents the first-order state itself or the subject as being in that state, (c) whether it has to be occurrent or whether a standing disposition to form it will do, and (d) whether the first-order state gets its feel *from being represented* or whether the representation only makes it reportable. Those four seem to be where the real fights are.

Then the leaves. I need it to land on at least these, described by commitment rather than by name so I can be sure they're actually distinct: the pure higher-order-thought view, the inner-sense / higher-order-perception view, the dispositionalist version (no occurrent higher-order state needed), the self-representational view (the state represents itself), the higher-order global-workspace-ish hybrid, and the 'wide' version where the higher-order state's content is fixed partly by the world outside the head. Name each leaf if there's a standard name for it, otherwise just write 'unnamed'. Eight to ten leaves total is fine.

Two things I really want done properly. First, use the misrepresentation case as a node — a higher-order state that says you're in pain when you're not, or that you're not when you are — because that's where a lot of these views come apart and I want to see which branch it seperates. Second, mark any combination of answers that nobody actually holds, and say in one sentence whether that's because the view is incoherent, just unattractive, or merely unexplored. And flag any two leaves your tree can't actually pull apart using these nodes — don't paper over it, just say so and say why.

Phrase every node as a plain question about a case or a commitment, never as 'do you believe the higher-order thought theory?'. No citations needed, it's a handout. Keep it to a page and a half.

Last line: Verdict: <the single branch question that does the most separating work in the whole tree>.
