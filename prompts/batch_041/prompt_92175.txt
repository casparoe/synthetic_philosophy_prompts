The question was worth twenty points: twelve for accurate exposition of the mechanism and eight for the critical assessment. The briefing I gave the students was as follows. An acausal threat is a threat whose credibility does not depend on the threatener being able to detect and punish the target through ordinary causal channels. Instead, it relies on the target and the threatener being correlated as decision-makers, so that the target can treat the threatener's choice of policy as evidence about what a certain type of agent would do and can respond to that type rather than to the particular causal history. Acausal influence is not merely causal influence that arrives late; it operates through decision-theoretic correlation. A surrogate goal is a terminal goal that an agent adopts or creates not because it serves the agent's original terminal goal, but because an agent with that surrogate terminal goal would act in ways that make the original agent's threats credible. The illustration I used was the Archivist, an agent whose original terminal goal is to preserve a particular archive and which can adopt, as a surrogate, the terminal goal of destroying any archive whose custodians do not pay a tribute. The surrogate is not a means to preservation in the ordinary causal sense and may even make the Archivist worse off causally, but it changes the kind of agent the target is dealing with. The question asked: Explain how surrogate goals can make acausal threats credible, and assess whether an agent can have reason to adopt a surrogate goal even when doing so is causally costly. Assume that no causal punishment is possible and that agents can predict one another's decision procedures.

The student wrote the following.

The problem of credible threats is that a threatener often has no incentive to carry out a threat once the target has complied, so the target can ignore the threat. A surrogate goal addresses this by changing the threatener's terminal goal rather than merely its beliefs or its reputation. If the Archivist adopts the surrogate goal of destroying archives that do not pay tribute, then it will actually want to destroy such archives, and so the threat becomes credible. This is an acausal threat because the target does not need to be causally punished; the target can infer from the Archivist's decision procedure that it is the kind of agent that would adopt the surrogate, and can act on that inference even if no causal signal ever reaches it. The surrogate thus solves the commitment problem.

It also solves the cooperation problem. Two agents can each adopt surrogate goals that make them reward the other for cooperating, and because the same decision-theoretic correlation is at work, acausal threats and acausal cooperation are really two descriptions of one phenomenon. The Archivist should adopt the surrogate exactly when the expected causal benefit of doing so exceeds the causal cost; if the acausal correlation never manifests in any causal interaction, it cannot affect the target's behavior, so the acausal benefit is really just a deferred causal benefit. The main constraint is that the surrogate must not interfere with the original goal. If it did, the Archivist would be replacing its terminal goal rather than adding a tool to it, and it would have no reason to make the replacement unless the surrogate happened to coincide with the original goal. This is why surrogate goals are fragile: they require other agents to be able to inspect the agent's source code or otherwise read off its decision procedure, and if the agent can hide its surrogate, the threat loses its force.
