I'm a backend engineer who somehow got put on our safety/eval team, and I'm stuck on low-impact AI. We're building a harness that penalizes an agent when its action has side effects, but the whole thing is circular because nobody can tell me what counts as a side effect without already having the value function we're trying to protect. The usual moves I keep hearing are: compare the actual outcome to a no-op baseline, compare to some default policy, measure how much the agent changes the reachability of states, or measure change in an attainable-utility set. They all seem to either smuggle in a full value specification, or collapse into the agent doing nothing, or go haywire because of chaos/butterfly effects where any action changes everything downstream. I have a half-baked idea of my own: use a learned default policy as the baseline, but then the baseline is itself a value-laden choice and the agent can maybe game it by making the default policy look terrible, so I don't know if that's a real impossibility result or just a bad implementation.

Before I read any more, I want the actual desiderata. Write me the requirements list for any adequate theory of side-effect avoidance for an agent, with the motivating case behind each requirement. Cases it has to get right: the robot that knocks over a vase while fetching coffee; the agent that does nothing while some other process would have broken the vase anyway; the agent that modifies its own code or its own reward channel; the agent in a multi-agent setting where others react to it; the stochastic case where the same action sometimes causes the side effect and sometimes doesn't; the case where the agent is uncertain about what the values are. Distinctions it can't collapse: side effect vs intended effect, harm vs mere change, omission vs commission, impact on the external world vs impact on the agent's own future options, actual causation vs counterfactual difference. Things it can't require: a full value function, omniscience about counterfactuals, a canonical no-op action, or a privileged baseline policy. And results it can't contradict, like the fact that tiny physical differences blow up in chaotic systems, or that in a POMDP the agent may not even be able to represent the counterfactual.

Then mark which of these are non-negotiable and which are just preferences of one camp. If some subset can't be jointly satisfied, say so and explain the tradeoff -- that's the part I most want. Tell me which single requirement does the most work, i.e. knocks out the most popular measures, and if you have room a quick scorecard of the usual contenders against the list. A table is fine. No citations or reading lists, please; I can't search from the terminal anyway, just reason it out.
