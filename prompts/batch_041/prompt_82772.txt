Argue that the claim that Solomonoff induction justifies Occam's razor is basically a definitional move rather than a vindication. Here's the construction I want you to work with: take a universal machine U and define U' that behaves like U on every input except that if the first bit of its input is 0 it just prints out some fixed string s and halts, and otherwise simulates U on the rest of the input. U' is still universal, but s now has constant-size complexity in U', so you can rig things so that any string you like comes out as the simplest one. The usual comeback is that the choice of reference machine only shifts the prior by a constant, and I want you to push on the fact that in this construction the constant is basically the complexity of s itself — so the simplicity ordering of two hypotheses is only machine-independent once their complexities differ by more than that constant, and you can always blow the constant up. Make the case that what the prior actually hands you is a ranking of which hypotheses are cheap to describe for a given reference machine, not which ones are more likely to be true. Then, because I don't want to be the guy who confidently announces that Solomonoff induction is broken, give me the strongest reply the other side has and say whether it definately works.
