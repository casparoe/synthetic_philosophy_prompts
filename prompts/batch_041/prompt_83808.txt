I've been reading about higher-order theories of consciousness for a while, and there's a gap in the standard presentations that I'd like you to lay out carefully for me — not as a survey, and not with a reading list, but as an argument I can follow and push back on.

The gap is this. Every higher-order theory seems to ask a single higher-order state to do two jobs at once: to make a first-order state *conscious* (to give it phenomenal character), and to make that first-order state *available* — poised for report, self-ascription, and use in reasoning. Some versions model the higher-order state on perception, as an inner sense that scans the first-order state; others model it on belief or thought, as a non-inferential judgment that one is in the first-order state. I want to understand why the two jobs can come apart, why each version needs them to line up, and which version pays less for keeping them together.

Make it concrete with a case I've invented. A system has a first-order state S whose content is that something is red at location L. Its higher-order representation of S is non-inferential: caused by S and by nothing else relevant. In the first variant — the mismatch case — the higher-order representation is accurate about S's existence and location but systematically wrong about S's quality: it represents S as a state of seeing green. In the second variant, the higher-order representation is accurate, and it is itself something the system can query and use in reasoning (call it, if you like, a conscious higher-order state). In the third variant, everything is as in the second except that the higher-order representation has no conceptual content — it is more like a bare perception of S than a judgment about it.

Address, in order:

- In each variant, what does the system experience, and what does it report? Are those two answers the same answer, and if not, which one does the theory take to be the phenomenology?
- Does the theory have any way to distinguish a first-order error (a state that misrepresents the world) from a purely higher-order error (an accurate first-order state that is itself misrepresented)? If not, does the theory lose empirical content, or is there a principled reply?
- Does it matter whether the higher-order state is conceptual? What does each answer imply about which creatures could be phenomenally conscious at all?
- On the strength of all this, is the view a theory of phenomenal consciousness, or a theory of access consciousness wearing phenomenal clothing? Take a side.

Please structure the response as five named sections, roughly these lengths: "The two jobs" (about 200 words); "How each version ties them together" (about 400 words); "The worked case" (about 500 words); "Where the theory is exposed" (about 350 words); and "Bottom line" (about 120 words, stating which version you would defend and the single strongest reason against it).
