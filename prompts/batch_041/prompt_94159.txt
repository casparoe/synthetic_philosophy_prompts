Ok so I need a thought experiment for the laws-of-nature debate, built to order rather than the standard thing.

One world only. Not two worlds with the same mosaic — that move has been done to death and I want something else. In this world there's a regularity R that a Humean best-system analysis has to count as a law: it earns its spot in the best system on the usual simplicity/strength tradeoff, and it's an axiom of that system rather than a theorem you can derive off the others. But the anti-Humean, taking their own view seriously, should say R is not a law — a boundry condition, or an accident, or something that's true of the actual world with no governing relation behind it. So the verdict pattern I want is: Humean says law, anti-Humean says not-a-law. Yes, the awkward direction. That's the point.

Constraints. The anti-Humean can't win by fiat — they have to be able to point at something about R, not just declare that governing relations are whatever they say. R should also be the kind of regularity a normal person would assume is a law before they'd ever heard of Hume; if it's obviously accidental the case is worthless. And the disagreement should hang on one feature: name it, then show that flipping only that feature makes both sides agree, and that flipping some other plausible-looking feature leaves them disagreeing. If it turns out you can't get the pattern with a single feature, say so and show where it leaks.

Then the writup. State R, give each side's verdict with the reasoning, and say honestly which side looks like it's cheating. Then be the anti-Humean's lawyer for a minute: best argument for calling R a law anyway, and whether it works or just collapses back into the Humean picture. And if you can't build this without rigging it, tell me that instead.

It's for a seminar where I want to kill the assumption that anti-Humeans always end up with more laws than Humeans do, so a case that only works because the anti-Humean is being obtuse is useless to me.
