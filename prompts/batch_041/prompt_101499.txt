Right, so I'm trying to put together a set of prompts that force models to actually think rather than pattern-match to the top post, and this one is the Solomonoff prior is malign argument, Paul Christiano's, as written up by Mark Xu if my memory of the provenance is right. The setup, in case it needs restating: an agent that reasons with Solomonoff induction, so it starts from a prior over all Turing machines weighted by description length and updates on its observations, and because it's a Cartesian agent it treats the question of which universe it's in as just another hypothesis to condition on; the worry is that a lot of the surviving probability mass lands on hypotheses where its observations are being generated by other agents who built a simulation in order to influence it, since a program containing a simulator with a reason to run you isn't much more expensive than one containing you directly, and once that's true the agent's action-relevant posterior is dominated by the preferences of those outside agents, so it should do what they want, which is where the whole s-risk flavoured nightmare comes from. Two people I argue with about this have been stuck for months. One thinks the argument is sound and, worse, robust, that Solomonoff is a red herring and any sufficiently powerful Cartesian agent reasoning about where it is will get hijacked the same way. The other thinks it's an artefact: it leans on non-realizability, on an agent that couldn't exist inside the universes it's meant to be learning about, and on anthropic bookkeeping nobody has made rigorous, and that if you insist on realizability, or move to something like infra-Bayesianism, or just notice that the complexity penalty is doing far more work than the argument admits, the thing dissolves.
