The question:

"Naive comprehension says that every predicate determines a set. (a) Derive Russell's paradox from naive comprehension. (b) Frege's Grundgesetze rests on Basic Law V. What does the paradox show about his project, and what replaced unrestricted comprehension in modern set theory? (c) True or false, justify: 'Russell's paradox shows that in any consistent set theory, no set can be a member of itself.'"

Student's answer:

(a) Let R be the set of all sets that are not members of themselves. Naive comprehension guarantees R exists, since "is not a member of itself" is a predicate. Now ask whether R is a member of itself. By excluded middle, either R is in R or it isn't. If R is in R, then by the definition of R it is not a member of itself, i.e. R is not in R. If R is not in R, then R satisfies the defining predicate, so R is in R. Either way we get both R in R and R not in R, which is a contradiction. So naive comprehension is inconsistent.

(b) Basic Law V says that two concepts have the same extension just in case exactly the same objects fall under them. That is what licenses treating extensions as objects and running logic on them, and it is the engine of the logicist reduction of arithmetic. Russell's paradox shows the law is false, since it lets you form the extension of "is not a member of itself" as an object, and then the argument from (a) goes through. So Frege's project as stated fails. The standard repair is to replace unrestricted comprehension with an axiom of separation: for any set and any property, there is a subset of that set whose members are exactly the members of the original set satisfying the property. Since you can only carve subsets out of sets you already have, you can never form the set of all sets, and you can never form a set that is a member of itself either. This is essentially the fix Russell proposed with his theory of types, which is why ZFC is often described as a typed theory.

(c) True. The paradox is exactly the liar paradox with sets substituted for sentences: "this sentence is false" has no stable truth value, and "the set of all sets that do not contain themselves" has no stable membership status. In both cases the culprit is self-reference, and the cure is to ban it, which is what the type hierarchy and the separation axiom both do. So no consistent set theory can have self-membering sets, and a fortiori none can have a universal set.
