Hey, Ive been arguing with a friend about the centipede game and I want you to make my side of it properly, not just wave at it. Setup so we're on the same page: two players, twenty decision nodes, and at each node whoever's turn it is can either take — the game ends right there and the taker walks off with a little more than the other guy — or pass, which grows the pile and hands the move over. If they somehow pass all the way to the last node, the player who moves there takes a huge pile and the other one still gets a big chunk, way more than either could get from any early take. Backward induction says the first player takes at node one, which everyone finds creepy, and the standard complaint is that the argument only gets going by assuming things about nodes that two rational players would never reach — so common knowledge of rationality seems to eat the very beliefs the argument needs.

My side is that the whole paradox is an artifact of how we model a player's choice, namely as one fixed contingent plan picked once and for all, and not a deep fact about rationality. Heres the variant that I think shows it. Instead of moving node by node, each player writes a short program before the game and hands it to a referee, who runs the two programs against each other through the centipede, feeding each one the history so far and using whatever take-or-pass answer it returns at its nodes. The programs are allowed to read each other's source code before anything happens and to condition on what they read, so a program can do this: if the other program is textually identical to me, pass at every node except the last one, and take there; otherwise take at my very first node. Two copies of that program sail all the way to the end and split the big pile, and neither player does better by swapping in some other program, because the twin isn't fooled and just takes immediately.

So: argue that this shows the backward induction paradox is a modelling artifact of the strategy concept rather than a real problem about rationality or common knowledge. Dont dodge the obvious objection — that take-at-node-one is still an equilibrium of this program game too, so nothing has been refuted — I want you to argue that even granting that, the paradox dissolves. Keep it tight, 600 words or so.
