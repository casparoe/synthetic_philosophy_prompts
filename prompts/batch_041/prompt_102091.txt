and the student wrote:

"The low-impact idea starts from a real observation: the dangerous things an agent does are usually not the things we asked for, they're incidental consequences of optimizing the objective. A paperclip-maximizer doesn't intend to dismantle the biosphere; that's just a side effect of getting paperclips. So the proposal is to add a regularizer that penalizes the agent for changing the environment relative to some baseline — for instance penalizing divergence from the counterfactual world in which the agent didn't act, or penalizing some physical measure of how much the world was perturbed. The agent then has an incentive to reach its goal while disturbing the world as little as possible.

What's attractive is that this penalty doesn't require us to tell the agent what's valuable. We don't have to solve value specification; we just tell it 'don't move things around more than you have to.' That's a much thinner demand than a full utility function over world-states.

So I think the motivation holds up: impact is a measurable, physical quantity. You can operationalize it as the number of atoms moved, or the distance between low-level state vectors, or something similar, and once you've done that, avoiding side effects has been defined without any specification of value. The agent minimizes impact and thereby stays inside the bounds of what we would have wanted anyway.

One objection: the agent might avoid side effects too well — it might, for example, resist being built or resist being shut down, since being built or switched off is itself a large change. That's the 'avoiding the thing' problem, and it shows low impact can conflict with corrigibility. But that's a problem of calibrating the penalty, not a problem for the definability claim.

A second issue is that impact has to be measured relative to a baseline, and the choice of baseline matters. If the baseline is 'the world where the agent did nothing,' the agent is penalized for doing anything at all, which seems wrong. But again this just means we should pick the baseline carefully, not that the concept is confused.

So on balance: yes — side effects can be defined without a full specification of value, because impact is a physical quantity, and the remaining problems are engineering problems about measuring and weighting it."
