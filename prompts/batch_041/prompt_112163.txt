I have been thinking about a puzzle in decision theory on my own, without any academic training, and I have built an argument that I can no longer tell whether to trust. I would like you to diagnose it. Please do not assume I know the standard literature; explain as you go.

The argument is about the Pasadena game. The game works like this: a fair coin is tossed until it first lands heads. If the first heads occurs on toss n, the player receives an amount equal to 2 to the power n, divided by n, in dollars, with the sign positive when n is odd and negative when n is even. So the player wins $2 if the first heads is on toss 1, loses $2 if it is on toss 2, wins $8/3 if it is on toss 3, loses $4 if it is on toss 4, and so on.

Here is the argument, laid out in steps.

(1) A rational agent, when every option before her has a well-defined expected monetary value, should choose the option with the highest expected value.

(2) In the Pasadena game, the probability that the first heads occurs on toss n is 1 divided by 2 to the power n.

(3) So the expected value of the Pasadena game is the sum, over n from 1 upward, of the probability of the first heads on toss n multiplied by the payoff at toss n. Each term has magnitude 1/n, and the signs alternate. The sum is therefore 1 minus 1/2 plus 1/3 minus 1/4, and so on.

(4) That series converges to a finite number only because its terms are added in one particular order. If you rearrange the very same terms — the same magnitudes, the same signs, the same multiset of numbers — you can make the sum come out to any real number you like, or make it diverge.

(5) The game itself does not tell you in which order to add the terms. So the game has no well-defined expected value.

(6) Now define a second game, which I will call the Altadena game. It is exactly like the Pasadena game, except that every payoff is increased by one dollar. Where Pasadena pays 2 to the power n divided by n with a certain sign, Altadena pays that same amount with the same sign, plus one dollar.

(7) Whatever the coin does, Altadena pays exactly one dollar more than Pasadena. So Altadena is strictly better than Pasadena.

(8) Therefore a rational agent should prefer Altadena to Pasadena.

(9) But if Pasadena has no expected value, and Altadena is just Pasadena plus a constant, then Altadena has no expected value either.

(10) So the rule in (1) has no verdict between Altadena and Pasadena. It cannot say to prefer Altadena, because neither option has an expected value for the rule to compare.

(11) Therefore the rule in (1) is false, since it cannot rank two options that any sensible person can rank.

I find (11) too strong, but I cannot see where the argument goes wrong. It seems to me that the same pattern of reasoning would refute any rule that ever leaves a pair of options unranked, including the dominance reasoning I used to get from (7) to (8). There are pairs of options where neither dominates the other and neither has a well-defined expected value, so dominance is silent there too. By the standard of (11), dominance would be false as well. Yet the friend who gave me this argument treats dominance as obviously sound. So I suspect something has slipped, but I cannot name it.

Which step should I reject, and what does rejecting it cost me? I would prefer to keep (1) if I can. If I can, tell me what I must add to it, and what I would then have to say about the Altadena and Pasadena games. If I cannot keep (1), tell me what replaces it and what the replacement gives up.
