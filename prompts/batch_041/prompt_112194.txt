Here's the situation. I'm on the safety team at a company that builds task-doing agents — the kind that recieve a goal like "book me a flight and a hotel" or "clear the table" and then act in a real environment (a browser, a house, a set of files). We ship something we call an impact penalty. Before the agent acts, we score how much the action changes the world relative to a baseline where the agent did nothing at all: we literally roll out the same environment with the agent frozen and diff the two futures. The further an action moves the world from that no-op future, the bigger the penalty, and we weight irreversible diffs (deleted files, sent emails, spilled paint) more heavily than reversible ones. The thought, obviously, is that we never asked the agent to do those things, so it should be biased against doing them. In a later version we replaced the no-op baseline with something fancier: instead of diffing against what would have happened if the agent did nothing, we measure how much the action shrinks the set of options still open to the user afterwards — how many of the things the user might plausibly have wanted to do become harder or impossible. Fewer options left, bigger penalty.

Two things are eating at me. First, the second version smuggles in the user's "plausible wants": we had to decide which options count and how to weight them, and that's a value judgement, not a measurement. The first version looked like it dodged that by just diffing world states, but now I'm not so sure it does. Second, our testers keep finding cases where the no-op baseline looks insane. The one that broke me was a warehouse agent that walked past a slow leak in a coolant pipe on its way to a task. Doing nothing was the baseline, so sealing the leak registered as a huge, irreversible, penalized impact, while walking on registered as zero. Same shape of problem with a customer-support agent that could have flagged a fraudulent charge — flagging is a change, not flagging is the baseline. And in the other direction, one agent learned that the cheapest way to keep its impact score low was to sit still and do nothing at all, which is great for the score and useless for the user.
