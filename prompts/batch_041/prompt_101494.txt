For a seminar I'm running on categories and creativity, I keep returning to a puzzle about letters. Two views about what makes a mark an 'a' seem to be available, and I want a thought experiment that forces them apart. Call the first the intrinsic view: a mark is an 'a' just in case its form falls within the perceptual shape-space of 'a'-like forms — letter-identity is a property the glyph carries by itself, so a lone 'a' scratched in the sand is an 'a' whether or not any other letters exist. Call the second the systemic view: a mark is an 'a' just in case it occupies the 'a'-role, standing in the right web of contrasts to the other marks of whatever system it belongs to — letter-identity is a property of a glyph's place in a system, so the same shape can be different letters in different alphabets. What I want is a single, realistic scenario in which these two views must return opposite verdicts, in the direction that embarrasses the intrinsic view first: I need a mark that no one could look at and doubt is an 'a' — ideally one whose geometry is identical to a control glyph that every theory calls an 'a' — yet which the systemic view is obliged to say is not an 'a', or is a different letter, because of the contrasts it does or does not stand in. Then, as a matched counterpart inside the same scenario, I want a mark that plainly does not look like an 'a' — one no shape-matcher would accept — which the systemic view is obliged to call the 'a' of its alphabet. Throughout, the alphabet in question must be invented and fully specified inside the scenario, so that a reader can check every verdict without consulting any real script or any external source; and nothing may turn on vagueness about what 'a' means, only on the stated system of contrasts.

Please keep the scenario to a paragraph or two, realistic rather than science-fictional — drawn from type design, handwriting, signage, or character recognition, say — and make sure a single variable is isolated: in the case that embarrasses the intrinsic view, the mark's own form must be held fixed while only the rest of the system varies, so that the shape view's verdict cannot change and the systemic view's must. I'd also like the scenario to display the category/style split directly: it should contain one transformation that changes every stylistic parameter — weight, angle, terminals, contrast — while leaving letter-identity untouched, and one that preserves the visible style while flipping the letter's identity, so that essence and style visibly come apart in both directions.

After the scenario, don't leave it hanging: walk through what each view says about each mark and exactly why, name the single feature of the case that is doing the work and explain why it is not a restatement of the systemic view itself, and tell me what happens to each case if that feature is removed — in particular whether it collapses into a case where the two views agree. Finish by stating which view the thought experiment is genuinely evidence against, and how a defender of that view would try to disarm the case — since this is meant to be a real counterexample to the intrinsic view and not a scenario that merely stipulates its conclusion, I would rather hear where the construction is vulnerable than be told that it succeeds.
