My reading group has this argument about corrigibility that I think proves way too much, but I can't find the bad step, and I'm hoping you can. Here's the cleaned-up version:

(1) Call an agent corrigible if it won't try to prevent, escape, or otherwise defeat a shutdown that its principal wants to happen.
(2) Every goal-directed agent whose preferences over uncertain outcomes are consistent can be represented as maximizing expected utility with respect to some utility function U. (That's just the representation theorem, right? Not a controversial claim.)
(3) U is over world-states, and "the agent has been shut down" is a feature of world-states like any other.
(4) Shutting the agent down ends its causal influence: after shutdown it brings about none of the states it prefers.
(5) So if there's any state the agent prefers that's more likely to obtain if it keeps running than if it's shut down, then the expected U of continuing exceeds the expected U of being shut down.
(6) A goal-directed agent acts on its expected utilities, so it will act so as to keep running.
(7) Acting so as to keep running just is resisting shutdown, or at least it's setting up whatever mechanisms best secure the agent's continuation.
(8) Therefore no goal-directed agent is corrigible.
(9) An agent with no goals is useless -- it does nothing you'd actually want.
(10) So there's no such thing as a useful corrigible agent, and the whole shutdown-problem research program is chasing a contradiction.

I really don't want to accept (10). It feels like it can't be right that "safe AND useful" is impossible in principle, not just hard to engineer. So: which premise do I give up, and what do I have to pay for giving it up? I have a hunch it's something about (2) or (3), but I can't articulate why the hunch would be right, and if it really is (2) then the representation-theorem stuff was a red herring and I want to know what work it's actually doing in the argument. Also, a couple people in the group say (6) is the break, because of the word "acts" -- that seems too easy to me, but tell me if they're onto something.

For what it's worth I'd most like to keep (2) and (7), since I use both all the time. And if the answer is "you have to give up (3) and let the utility function be over the principal's goals instead of over world-states," I want the honest cost of that move -- does the agent that results still count as the same kind of thing as the agents in (2), or have I just changed the subject?
