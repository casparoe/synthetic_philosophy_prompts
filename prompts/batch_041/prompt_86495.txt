I'll be keynoting next month's annual meeting of an invertebrate-neuroscience society, and the talk defends a view I've been calling hedonic dimensionality. The claim: moral status does not turn on whether a system is sentient, as though that were a threshold, nor on how intense its pains are, as though that were a single scalar. It turns on how many independent dimensions a system's valenced state space has — how many distinct ways it can be made better or worse off. A system whose only aversive state is one "too much / too little" signal has a one-dimensional hedonic space and so has some, but very little, moral status; a creature that can be pained, frightened, bored, lonely, and humiliated has a high-dimensional one and so has a great deal. On this view the insect/mammal gap is a gap in dimensionality rather than merely in degree, and even a thermostat scores nonzero, if vanishingly so. The argument I'll run: dimensionality tracks the number of independent control variables a system's evaluative machinery must integrate, and integration is what makes a state a state for the system at all.

Write my Q&A prep sheet.
