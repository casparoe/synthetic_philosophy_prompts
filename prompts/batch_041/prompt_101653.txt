I serve on an internal safety review board for a lab that deploys a powerful model we treat as potentially misaligned. Our decisions so far have been these. We approved a protocol in which the untrusted model works only in a sandbox on reversible, low-stakes tasks, with a smaller trusted model monitoring its actions and a human able to halt it. We rejected a protocol in which the untrusted model acted in the world on irreversible tasks while relying on its own report of its chain of thought that it was not deceiving us, even with random audits. We approved a protocol that used a trusted weaker model as a monitor on reversible tasks, with no access to the untrusted model's internal reasoning. We rejected a protocol that used two instances of the untrusted model to check each other on irreversible tasks, with no trusted monitor. The new proposal would have the untrusted model handle reversible, low-stakes tasks; a trusted weaker model would monitor its internal reasoning, but the monitor's only signal would be a classifier trained on the untrusted model's own explanations; if the classifier flagged, a second instance of the untrusted model would adjudicate, and if both agreed the plan was safe, it would execute with no human review. What should we decide if we want to be consistent with our precedents? Which precedent is the closest analog? Which competing rules fit our earlier decisions, what does each predict here, and which should we prefer? If the precedents genuinely underdetermine the case, what principle would we be adopting with each choice, and what further case would best distinguish the rules?
