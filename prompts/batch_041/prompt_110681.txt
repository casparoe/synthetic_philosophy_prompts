I write about science and ideas for a monthly magazine, and last month I sat in on a small workshop on decision theory where a session on triage protocols turned into a long argument between two researchers I will call A and B. The speaker had described a rule used in some emergency departments: when demand exceeds capacity, clinicians sort patients into categories and accept the first treatment plan whose predicted survival probability clears a threshold set by the average outcome of the last twenty cases in that category, rather than searching for the plan with the highest expected value. A said this is a clean case of satisficing, and that its rationality comes from the cost of further deliberation. B said that if the threshold is chosen because it maximizes expected outcomes given search costs, then the rule is just constrained optimization, and calling it satisficing adds nothing. A replied that the threshold in real protocols is not derived from any explicit utility function; it is set by precedent, habit, and institutional memory, and it drifts with the agent's recent experience of success and failure. B countered that an implicit utility function is still a utility function, and that if the threshold really did drift with history, then the rule would be exploitable and not rational. A then offered a thought experiment: an agent whose aspiration level rises after success and falls after failure, so that it never settles on a single optimizing policy. A said this agent is not irrational, just boundedly rational, and that B's insistence on a single utility function begs the question. B responded that the thought experiment either describes a time-varying utility function or a mistake, and that A is using satisficing to name a phenomenon rather than explain it.

They asked me, as the only philosopher in the room, to referee, and I deferred. Please adjudicate their exchange move by move: identify what each is right about, where each overreaches, and what both are missing about the relationship between satisficing, optimization, and endogenous aspiration levels.
