I am a third-year cognitive science student in a reinforcement learning seminar, and I am trying to understand why inverse reinforcement learning is supposed to be hard. A classmate in my study group has an argument that I can follow step by step but whose conclusion I cannot accept. (1) An inverse reinforcement learning system observes an agent's behavior and returns a reward function that explains it. (2) Two reward functions are behaviorally equivalent when they induce the same optimal policy from every state. (3) A standard result in the field says that for any reward function R, one can add a potential-based shaping term—roughly, a term of the form γΦ(s′) − Φ(s), where Φ is a function of states and γ is the discount factor—to obtain a different reward function R′ that induces exactly the same optimal policy as R. (4) So from data consisting only of an agent's optimal behavior, R and R′ are indistinguishable. (5) If two reward functions are indistinguishable from the agent's optimal behavior, then no evidence can determine which one the agent actually has. (6) Therefore inverse reinforcement learning cannot recover the agent's true reward function. (7) If it cannot recover the true reward function, it cannot recover the agent's preferences. (8) Therefore inverse reinforcement learning is not a viable method for learning human values. I would like to keep (1) and (3) if I can, because the course is built on both, but (8) seems far too strong; a method can be useful without being able to recover a unique true reward function. Where does the argument go wrong? Name the premise or step you would reject, explain why it looked plausible, and say what rejecting it costs. Please answer in no more than 500 words.
