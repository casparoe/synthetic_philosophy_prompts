I have an argument that a colleague handed me, and it has the shape of a proof, but I suspect it proves too much. It concerns whether a system that sees only behavior can recover the preferences or reward that produced it.

(1) An inverse reinforcement learning system receives a record of behavior — a trajectory, a policy, a sequence of choices — and nothing else, and must output the reward function the agent was maximizing.
(2) For any finite record of behavior over a finite set of situations, there exists a reward function under which that behavior is exactly optimal. One can always construct one: assign the observed action in each observed situation a value strictly above every available alternative.
(3) Learning from data is possible only where the data rules some hypotheses out. If a hypothesis class contains a member consistent with every possible data set, then the data cannot tell its members apart.
(4) By (2), no reward function is ever ruled out by behavioral data.
(5) Therefore behavior carries no information about reward. Whatever the system outputs is fixed entirely by whatever prior we installed; the observations do no work.
(6) So inverse reinforcement learning, understood as inferring preferences from behavior, is impossible in principle. The practice is either prior-engineering under another name or a mild self-deception.

I find (2) hard to deny — it looks like a trivial construction. But (6) cannot be right, and the trouble is that the argument seems to generalize. Any finite data set is consistent with endlessly many hypotheses: fit a polynomial through any points, add an epicycle to save the orbit. So by (3) no experiment would ever separate a theory from its rivals, which would make all of science impossible. Science is not impossible. So something here is wrong.

Tell me which step to reject, and what rejecting it costs. If I must give up one of (2) and (6), I would rather keep (2), because it seems obviously true; but I want to know exactly what I am buying and paying. In particular, is the inference from behavior to preference special in some way, or is this just the ordinary problem of induction wearing a costume — and if it is the ordinary problem, why does the reward case feel so much worse than the physics case?
