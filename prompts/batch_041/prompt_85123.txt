Question 3 (16 marks)

The MIU system has one axiom, MI, and four rules. Here x and y stand for arbitrary strings of M's, I's and U's (either can be empty), and a theorem is anything you can get from the axiom by applying the rules:
R1: from xI infer xIU
R2: from Mx infer Mxx
R3: from xIIIy infer xUy
R4: from xUUy infer xy

(a) Show that MU is not a theorem. State the property of strings that your argument relies on, and check it against each of the four rules. (6 marks)

(b) The argument in (a) is normally presented as a case of jumping out of the system. Say what is supposed to be outside what, and whether the MIU system can itself establish that MU is not a theorem — that is, whether the non-theoremhood of MU is itself derivable in MIU. (5 marks)

(c) Now consider MIU+, which is MIU with a fifth rule added:
R5: from xUy infer xIIIy
Is MU a theorem of MIU+? And does the argument you gave in (a) still do the work it did there? (5 marks)

Student's answer, as written:

(a) The property is that no theorem has a number of I's that is a multiple of three. MI has one I, and one isn't a multiple of three. R1 adds a U to a string ending in I, so it leaves the number of I's alone, and R4 deletes a pair of U's, so it leaves the number of I's alone as well. R2 doubles everything after the M, so it doubles the number of I's, and if n isn't a multiple of three then neither is 2n. R3 replaces III with U, taking the number of I's down by exactly three, and you can't get from a non-multiple of three to a multiple of three by subtracting three. So every theorem has a number of I's that isn't a multiple of three. MU has no I's at all, and zero is a multiple of three. So MU is not a theorem.

(b) What's inside is the derivations: rules applied to strings, one line at a time. What's outside is reasoning about all the derivations at once, since the invariant is a fact about the shape of the whole set of derivations rather than a line in any of them. So MIU can't establish this about itself, because it has no way of saying that a string is not derivable — no negation, and nothing that lets it talk about its own theorems. This is the same shape as Gödel's first incompleteness theorem: the system is incomplete, and MU's underivability is a truth about the system that the system can't prove for itself. Which is the point of jumping out of the system — you only see the limits from the outside.

(c) MU is not a theorem of MIU+. R5 does change the number of I's, so the invariant from (a) is broken: the new rule manufactures I's out of nothing, so a theorem can perfectly well end up with a multiple of three of them. MU still isn't derivable though, because R5 only ever adds I's and R3 is the only rule that takes them away, and it takes them three at a time, so you can never get down to none.
