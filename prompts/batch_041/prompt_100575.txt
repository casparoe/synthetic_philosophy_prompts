I'm a second-year PhD student in a lab that sits somewhere between comp neuro and ML, and there's a thing I keep running into that I can't tell is a real, named problem or just me being confused. We train the same architecture on the same data twice, only the random seed changes. Both hit basically the same accuracy. Then we go digging inside to find where the model's "representation" of some feature lives — take anything, say whether an image is blurry. In run A there's a little cluster of directions whose activity tracks blurriness, and if we ablate them the model basically stops caring about blurriness. In run B there's a completely different cluster, different units, different geometry, doing the same job — ablate it and again the behavior goes. So both runs seem to "represent" blurriness in the sense that the representation is there and it's causally load-bearing, but the two don't overlap at all and you can't line them up. And there's a second thing on top of it: sometimes the same unit seems to carry two totally unrelated features depending on what else is in the input, so it isn't even one-feature-per-unit. So when my advisor says "the model represents X," I want to ask, represents it according to which run? And if two physically different internal states are each sufficient for the same behavior, in what sense is one of them *the* representation? It feels like the word "representation" is doing work that the physics underneath doesn't definately license.

I'm sure this is adjacent to stuff that already has a name — I half-remember "multiple realizability" from a philosophy class, and a systems-neuro friend said "degeneracy," and a stats friend said "non-identifiability," but none of those quite felt like the thing I'm pointing at. What I want isn't a bare label, it's the carving: is there an established concept for exactly this configuration (same function, many non-alignable internal encodings, each causally sufficient), and how precisely does it differ from each of those near-misses — where does the analogy break? If nothing fits, coin something, define it, and give me the edges: what would clearly NOT count as an instance. Please don't hand me a reading list, I just want you to think it through with me.
