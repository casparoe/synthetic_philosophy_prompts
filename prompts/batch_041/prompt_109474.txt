"One ambition behind impact measures is to penalize an agent for side effects, or for impact, without presupposing a complete specification of the agent's values. The hope is to define a penalty that says, roughly, do not disturb the world more than necessary, while remaining neutral about what the world is for. Two proposals in this vein are (i) penalizing deviation from a baseline, where the baseline is the state the environment would have been in had the agent taken no action at the current step, and the deviation measure is the change in the reachability of states (the stepwise relative reachability approach), and (ii) rewarding the agent for preserving its ability to attain a set of auxiliary objectives, even when those objectives are generated at random rather than derived from the designer's values (attainable utility preservation).

Assess whether these proposals actually succeed at defining impact without a full value specification, or whether they smuggle a value specification back in. Student's answer:

"Both proposals operationalize the intuition that a capable agent should not make the world harder to steer. The key move in each is to define the penalty over the agent's options rather than over the agent's preferences, and this is what is supposed to make the measure value-neutral.

Consider the first proposal. A side-effect penalty has two independent parts: a baseline against which the current state is compared, and a measure of how far the current state has departed from that baseline. These must be chosen separately, and the choice of each has consequences. If the baseline is the state at the start of the episode, then the agent is penalized for changes that were part of its legitimate task, and it is also penalized for changes made by other agents or by natural processes, which gives it an incentive to prevent others from acting at all and to keep the world as close to frozen as it can. The stepwise inaction baseline is meant to fix this by resetting the comparison whenever the agent is penalized: the baseline is the episode's initial state, and the agent is charged only for deviations it has not yet been charged for. The deviation measure is the second independent choice. Measuring deviation as raw distance in state space would penalize any change, including changes the agent's task requires, whereas measuring it as the loss of reachability to other states focuses on whether the agent has foreclosed future options rather than on whether the world looks different. This is a genuine improvement, because reachability is defined relative to the agent's own dynamics and action set rather than to any reward function, so nothing about the agent's values enters the measure.

The second proposal makes the same bet from the other direction. Instead of penalizing deviation from a baseline, the agent is rewarded for keeping a set of auxiliary objectives attainable, and the striking empirical claim is that even randomly generated auxiliary objectives are enough to induce conservative behavior. The idea is that if the agent must retain the ability to optimize many different objectives, it will avoid destroying resources or foreclosing options that some unspecified objective might have needed, so the method does not require the designer to say in advance what matters.

Taken together, the two proposals suggest that impact can be defined without a full value specification, and the random-auxiliaries result is the strongest evidence for this: if the auxiliary objectives carry no information about the correct reward function, then the conservatism they induce cannot be coming from a smuggled-in value judgment. The residual value-laden choices, such as how many auxiliary objectives to use and how to weight the penalty against the primary reward, look like tuning parameters rather than a specification of what the agent should value, and in that sense the ambition of a value-neutral impact measure seems to me to be met, at least in outline. The real difficulty is computational rather than conceptual: computing reachability over large state spaces is expensive, and this is where I would expect the approach to break down in practice."
