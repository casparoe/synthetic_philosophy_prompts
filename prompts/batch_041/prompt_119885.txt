**Problem 2 (10 points)**

Recall the MIU-system. The only axiom is the string MI, and there are four rules of inference, in which x and y stand for any strings (possibly empty) of the symbols M, I, and U:

- R1: from xI, infer xIU.
- R2: from Mx, infer Mxx.
- R3: from xIIIy, infer xUy.
- R4: from xUUy, infer xy.

A string is a theorem of the system just in case it can be obtained from MI by finitely many applications of R1–R4.

(a) [6 points] Prove that MU is not a theorem. State the invariant you use, and verify that each of the four rules preserves it.

(b) [4 points] The MIU-system is the standard illustration of the difference between working inside a formal system and reasoning about it — what is sometimes called jumping out of the system, or JOOTSing. Is the argument you gave in (a) a case of JOOTSing? Explain why or why not, and compare the situation with the Gödelian one, where the metatheoretic argument that a system cannot prove its own Gödel sentence is standardly taken to be mirrored, via arithmetization, by results that the system can itself express and prove.

**Student's answer**

**(a)** Let n(s) be the number of I's in the string s. I claim that for every theorem s of the MIU-system, n(s) is not divisible by 3. The axiom is MI, and n(MI) = 1, which is not divisible by 3, so the claim holds at the start. Now suppose s is a theorem with n(s) not divisible by 3, and consider what each rule does to it. R1 appends a U and R4 deletes a pair of U's, so neither of them changes n. R3 replaces three I's with a single U, so it lowers n by exactly 3, and subtracting 3 from a number that is not divisible by 3 leaves a number that is not divisible by 3. R2 doubles everything after the M, so it doubles the number of I's; doubling a number only makes it larger, and making a number larger cannot turn a number that is not a multiple of 3 into a multiple of 3. So in every case the invariant is preserved. Since it holds of MI and is preserved by all four rules, it holds of every theorem. But n(MU) = 0, and 0 = 3 × 0, so n(MU) is divisible by 3. MU therefore cannot be a theorem, and the puzzle has no solution.

**(b)** What I did in (a) was not to derive MU from MI, and it was not a derivation in the system at all: it was a piece of reasoning about the strings and their properties rather than a sequence of applications of R1–R4. That is the sense in which I had to step outside the system. The four rules are the only moves available inside it, and none of them gets you to MU, or tells you anything about what all the rules together can and cannot produce. A machine that only applies the rules could run forever without discovering that MU is unreachable, which is why the puzzle is a good illustration of the difference between using a system and talking about it. The moral is the same as in Gödel's theorem: the MIU-system is incomplete, since there is a string it cannot produce even though the fact that it cannot produce it is true, and more generally any formal system rich enough to be worth studying has truths that it cannot reach. The only difference in the arithmetic case is that the unprovable sentence is a sentence of arithmetic, whereas here the unreachable string is a string of the MIU-system, so in the MIU case the incompleteness is if anything more striking.
