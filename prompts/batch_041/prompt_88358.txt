I chair the research review committee of an AI safety foundation. Our next vote is on a proposal to fund a two-year project on program equilibrium. The applicants propose a series of tournaments in which each participating AI agent submits source code; before choosing an action, an agent's code may read the source code of the agent it is paired with. They define a program equilibrium as a pair of submitted programs each of which is a best response to the other, given that both can condition on each other's code. Their claim is that this is the right model for advanced AI systems that can inspect and predict one another, and that the tournaments will show whether cooperation can be achieved without central enforcement. Two reviewers object that the setup assumes away the central difficulty: if an agent can read its opponent's code, cooperation is trivial, and the tournament will measure only how cleverly contestants exploit the transparency condition. A third reviewer replies that the objection misses the point, because the interesting question is not whether cooperation occurs but whether a program can genuinely commit to a strategy that depends on another program's code. The committee must decide whether to fund the proposal, reject it, or fund it with conditions. Please draft the decision memo I will circulate before the vote. It should recommend a concrete course of action with a time frame, engage the strongest version of the objection, and state what the funded project would have to show for the committee to regard it as a success rather than an artifact of the tournament design.
