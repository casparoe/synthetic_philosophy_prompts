Right, so I teach a philosophy of mind seminar and one of my students, Priya, has spent the last two weeks building an argument out of Dennett's two-bitser example, and I'm embarrased to admit I can't find the exit. You probably know the example: the coin machine that takes only genuine US quarters, and Dennett asks whether we should say the machine *believes* the coin is a quarter or just responds to some physical property, then imagines the identical machine dropped into a world where the coinage is different, so the very same internal state ends up triggered by a different coin. So the state's content isn't intrinsic to the machine. Fine. Priya has turned that into this:

(1) Take any system with internal states, and any content we might want to attribute to one of those states.
(2) For any such state, there's a physically possible set-up in which the same state is caused by something else, or put to a different use, or embedded in a world with different regularities.
(3) In that set-up we'd describe the state as representing something different. Same state, different content.
(4) So nothing inside the system fixes what the state represents -- the content depends on the environment, the history, the interpreter, whatever.
(5) And if the content isn't fixed by anything inside the system, then the system doesn't have its own intentionality -- whatever content it has is assigned from the outside.
(6) So no system has original intentionality. All intentionality is derived.
(7) A human brain state is no better off: I can always cook up a scenario where the same brain state is caused by something else, or where it only coincidentally tracks what it does.
(8) So humans don't have original intentionality either. Nothing does. "Meaning" is a stance we take toward things, not a fact about them.
(9) Which means this very argument doesn't strictly mean anything either -- it's just a useful stance. So Dennett gets to be right and also can't claim his theory is true rather than merely handy.

It's that last step where I start to think the thing proves too much, but I honestly can't tell whether that's a real defect in the argument or just me not wanting to swallow the conclusion. What I'd really like to keep is the thought that some ascriptions of content are correct and others are wrong -- if nothing means anything then I dont see how (9) is supposed to be a reason to believe anything, itself included.
