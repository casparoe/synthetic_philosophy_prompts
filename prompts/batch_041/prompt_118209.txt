Ok so I'm writing a chapter defending act-consequentialism against the cluelessness objection, and I want to pressure-test the line I've been running before I commit to it. Roughly it goes: sure, the downstream consequences of any action branch out forever and we can't know them, but that's less threatening than it sounds, because past a certain point — call it the cluelessness horizon, the point where the tree of downstream effects gets so wide that tracing it any further just returns "something roughly like what usually happens when people do things like this" — the expected value of the far effects regresses to a common baseline across my options. If that's right, the differences between the options live almost entirely in the near-term, knowable effects, and act-consequentialism can still rank them. So cluelessness is real but not paralyzing.

What I want from you: what would actually count against this? Not the generic "but the far future matters" complaint — I know that one. I want the observations, formal results, cases, and arguements that should genuinely move me, sorted by how decisive they'd be. Specifically: does the regression-to-baseline move survive heavy-tailed value distributions, i.e. the Pascal's-mugging-ish worry that a tiny probability of an astronomically large good or bad swamps every near-term difference — and if it doesn't survive in general, what would the value distribution actually have to look like for my move to work? Are there cases where the cluelessness is systematically asymmetric, where we have some structural reason to think one option's far effects are net positive in expectation — and does that break the "it all washes out" claim or quietly support it? Which of these would a fellow consequentialist concede as a real cost, versus wave away, and would I be able to tell the difference from the outside?

And be honest with me about whether I've defined the cluelessness horizon in a way that makes the view unfalsifiable. If any inconvenient result can be absorbed by saying "ah, that's beyond the horizon," is that a bug, or is it just what a decision-theoretic view of this kind has to look like? Rank the defeaters from fatal to merely awkward, tell me which one you'd bet on if you had to, and definately don't spare the view just because it's mine.
