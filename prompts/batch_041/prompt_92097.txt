Question: Set out the argument from illusion as it's standardly used against direct realism, explain how a disjunctivist responds to it, and say whether that response actually succeeds.

Student answer: "The argument from illusion starts from cases where an object looks other than it is -- a straight stick half-submerged in water looks bent. In the illusory case you are aware of something bent; in the veridical case you are aware of something straight; and from the inside the two experiences are indistinguishable. Since you can't tell them apart, whatever you're immediately aware of must be the same kind of thing in both cases, so it can't be the mind-independent stick. It has to be a mind-dependent object -- a sense-datum. This is sometimes called the argument from hallucination, because the same reasoning runs for a hallucinated object that isn't there at all.

The disjunctivist blocks this by denying the common kind assumption -- the assumption that the veridical experience and the illusory one are experiences of the same fundamental kind. On the disjunctivist view, a veridical perception is a relation to the mind-independent object itself, with no intermediary, whereas the illusory case is a different kind of thing altogether. So the inference to a shared mind-dependent object never gets going, and direct realism is safe. To make this work, though, the disjunctivist has to deny that the two experiences are really indistinguishable -- if they're different kinds, there must be some introspectable difference between them. So the disjunctivist ends up saying that in the illusory case you aren't really having an experience at all, just a brute seeming, which I'd say is a cost but a payable one. Overall I think the response works: it shows the argument from illusion only gets you to sense-data if you already grant that veridical and illusory cases are the same kind of experience, and that's exactly the premise a direct realist should reject."
