I'm a third-year student in a course on decision theory, and for a seminar on the Allais paradox and the independence axiom I've been asked to bring a case of my own rather than present the standard one. The point I want to make is narrow: the familiar Allais result does not by itself identify the mechanism behind it, because you can change how readily people reverse without changing a single probability or payoff, by changing only how the problem is laid out. So I need a case engineered to make that point, to these specifications.

One choice problem, described twice. The descriptions must be the same problem in the strictest sense: same states, same probabilities, same consequence for each option in each state, so that a sceptical classmate can read both and agree that nothing has been added or taken away. The only difference is the display. In the first version, the event in which the two options pay the same amount appears as a single shared branch, visible as a shared branch. In the second, the same event is broken into two or more separate branches, or the options are described one after the other rather than side by side, so that the coincidence is no longer on display. Neither option, in either version, may be a sure thing; I don't want the certainty effect available as an explanation, so every option must carry some chance of a bad outcome. Prizes should be amounts I could plausibly be offered, and no option should have more than three distinct outcomes.

Then the two halves of the work. First the theories: for expected utility, for rank-dependent utility (or cumulative prospect theory, if you prefer, in which case tell me the weighting function and the parameters), and for regret theory, state what each predicts in each version, and show that the predictions do not shift between versions, since all three read an option only as a map from states to consequences and none of them can see how that map is written down. If you think one of them is not in fact invariant here, say so and explain, because that would be worth knowing. I would also like the shared-branch version to be one in which expected utility and rank-dependent utility genuinely disagree, so that I can show the class a case where a non-expected-utility theory earns its keep; say which option regret theory sides with, and whether that agreement is forced by the structure of the theory or is an artefact of the numbers you chose. Second the chooser: tell me which feature of the display does the work, what would have to be true of a decision-maker for the reversal to appear in the shared-branch version and vanish in the other, and what happens if I remove that feature and present the same state space as a plain list with no shared branch anywhere; does the case collapse back into the textbook problem, or into something else?

Finish with the strongest reply available to someone who thinks the whole exercise is beside the point, namely that the two versions are one and the same problem, so any difference in what people choose is an error of reasoning rather than evidence about the axioms. Say whether that reply defeats the argument I want to make, and what I would have to add to survive it.

Two notes. I half-remember a remark from lecture that presentation effects of roughly this kind have been found experimentally, but I have no reference for it and don't want to claim it, so please don't build the case on it or tell me what the literature says; the case should stand on its own as a piece of design. And this is going on a handout I will read on a phone, so I want continuous prose only, with no headings, no bullet points, no bold and no tables. Give the probabilities and payoffs in ordinary sentences; a slightly clunky sentence is better than a grid.
