I'm a third-year student and I sit on my univeristy's research ethics and safety comittee as the student rep, and I'm also taking a course on game theory and philosophy where we've been talking about the Prisoner's Dilemma and whether rational agents can cooperate without enforcement. The committee has to vote next Thursday on a protocol from the computational cognitive science lab. They want to run a bunch of trials where two AI agents play a one-shot Prisoner's Dilemma. Before either agent moves, each has to submit its full source code to a neutral referee, who passes it to the other agent. Then each agent can decide its move by actually running the other agent's code, or by reasoning about what the other will do given that it can see this agent's code. The PI calls the resulting equilibrium a program equilibrium. The idea is that even in a one-shot Prisoner's Dilemma, two programs can cooperate if each can prove to the other that it will cooperate if the other does. One committee member says this is just a trick: the agents aren't really choosing under uncertainty, they've turned the game into a fixed-point math problem, and the cooperation isn't genuine or moral, it's just a consequence of the code. Another member says it's the only stable cooperation in a world where agents can read each other's code, and that if we don't study it we'll be blindsided by systems that use it. There's also a safety worry: the protocol would involve training some agents to search the other agent's source code for exploitable patterns, which could be dual-use.

Draft the short written opinion I'll circulate before Thursday's meeting. I need a clear recommendation -- approve, approve with conditions, or reject -- with a concrete course of action and a time frame for any conditions, and I need it to engage seriously with the strongest point on the losing side rather than just asserting that cooperation is good or that source-code transparency is dangerous. It should explain program equilibrium in plain language for the non-game-theorists on the committee, say what would count as evidence for or against the PI's claim that the cooperation is robust, and address whether the dual-use risk of teaching agents to exploit code is enough to reject the protocol outright. I'd also like it to say something about the philosophical issue underneath: does program equilibrium actually dissolve the dilemma, or does it just relocate the choice into the decision of which program to submit?
