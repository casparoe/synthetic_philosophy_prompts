I am preparing a position statement for a graduate seminar on epistemic value and would like a consistency audit before I circulate it. The package I intend to defend is this:

(1) Knowledge is more valuable than mere true belief, and the difference is not incidental; it is part of what knowledge is for.
(2) The value of knowledge is instrumental: knowledge is valuable because it is a more reliable guide to action than true belief.
(3) True belief is sufficient for successful action. Once a belief is true, adding justification, warrant, or a no-false-lemmas condition does not make the agent more likely to succeed in what she does.
(4) The Meno problem is a problem about differential value: what needs explaining is the value of the difference between knowledge and true belief, not the value of knowledge as a whole.
(5) What explains the differential value is stability: knowledge survives counterfactual challenge and revision better than mere true belief.
(6) Knowledge requires a no-false-lemmas condition, so a true belief that is reliably formed but rests on a false intermediate premise is not knowledge.
(7) Epistemic value is monistic: all epistemic value derives from the value of true belief and the disvalue of false belief. There is no independent epistemic value in justification, coherence, or cognitive achievement as such.
(8) Understanding is a species of knowledge, and it is more valuable than knowledge because it is more explanatory.
(9) Knowledge is the norm of practical reasoning: it is appropriate to act on what one knows, and inappropriate to act on what one merely believes truly.

I suspect that some of these are in tension, but I cannot see where the fault lines lie. Please audit the set. Which pairs are genuinely in tension, which only appear to be, and how severe is each genuine tension? Rank the genuine tensions by severity. For each, say what would have to give and what the cheapest revision would be. Then tell me which single revision would remove the most tension. I am not asking for a literature review, citations, or a survey of positions; I want the internal structure of this position and a verdict on whether it hangs together.
