Exam question: Explain the Skolem paradox and assess the claim that it shows that there is no absolute, model-independent fact about whether a set is countable or uncountable; countability is always relative to a model. In your answer, (a) state the relevant theorem and how the paradox arises for a first-order theory such as ZFC; (b) distinguish the sense in which a countable model can satisfy “there is an uncountable set” from the sense in which that set is countable from the outside; (c) evaluate whether the paradox is a fatal objection to set theory, a limitation on first-order formalization, or neither.

Student’s answer: The Skolem paradox begins with the Löwenheim–Skolem theorem, which says that every consistent first-order theory with an infinite model has a countable model. Since ZFC is a first-order theory and, if consistent, has an infinite model, it has a countable model. Call it M. Inside M, Cantor’s theorem is a theorem, so M satisfies the sentence “there exists an uncountable set.” For example, M thinks that the set it calls P(ω) is uncountable. But M itself is countable. So the set that M calls P(ω) is a countable set when viewed from the outside, since it is a subset of M’s countable domain. This looks like a contradiction: M says that P(ω) is uncountable, but we can see that it is countable.

The resolution is that countability is relative to a model. When we say that M’s P(ω) is countable from the outside, we mean that there is a bijection between it and ω in the metatheory. But that bijection is not an element of M, so M cannot see it. Inside M, there is no bijection between M’s P(ω) and M’s ω, so M is right to call it uncountable. Thus the paradox is not a real contradiction. It shows that first-order logic cannot pin down the intended interpretation of set-theoretic notions: “uncountable” does not have an absolute meaning, because a countable model can satisfy the same first-order sentences as an uncountable one. Skolem himself concluded from this that set theory is merely a formal game and that we should not treat its notions as referring to a unique universe of sets. So the paradox is best seen as a problem for the idea that first-order axioms can capture the real world of sets, rather than as a proof that set theory is inconsistent. The only way to avoid it is to use second-order logic, which has a unique standard model of arithmetic and set theory, so it does not have countable models.
