I'm a software engineer with no formal training in philosophy, and I've been reading around the inside view versus outside view distinction and the reference-class forecasting literature that grew out of it, because it bears directly on how I estimate schedules and risk at work. This started as a lunch argument: a project I'd estimated at six weeks ran to five months, and the universal advice was that I should have used the outside view. I couldn't shake the feeling that the advice was right only by accident, because the reference class happened to be a well-chosen one, and that the standard prescription — epistemic modesty consists in discounting your own case-specific reasoning in favour of the base rate for the reference class — quietly assumes something the literature never earns: that the reference class has already been chosen correctly. Choosing the class looks like an irreducibly case-specific judgment, and if that's right, then 'be modest and defer to the base rate' is either incomplete or self-undermining, since it tells you to distrust the very faculty you must exercise in order to know which base rate to defer to. I'd like you to build me a thought experiment that makes this concrete, engineered so that the verdicts fall out of the two views rather than being stipulated in advance. The case is meant to test whether modesty-as-deference is a coherent policy at all, and that fixes what counts as cheating: a case that simply declares the base rate inapplicable fails, and so does one in which the agent is merely guessing.

I want the usual direction reversed — the outside view should be the overconfident party and the inside view the corrective one. Specifications: a single realistic decision-maker facing a go/no-go decision; no science fiction, no perfect predictors, no lotteries, no startup pitches, no megaproject cost overruns. There must be a large, credible, externally supplied base rate for a coarse reference class that the agent did not choose and has no incentive to flatter. The agent's own preference must run the other way — she would like the base rate to be right, so that her pessimism cannot be written off as wishful thinking, and so that the modest choice is also the convenient one, which is precisely when the label 'modest' should start to feel suspicious. The coarse base rate's good outcomes must be driven by a structural feature that the case at hand verifiably lacks, visible from the case rather than asserted. No adequate data may exist for the finer class that would settle the matter, whether because the numbers are too small or because membership in the finer class is itself determined by the prior judgments of agents like the one deciding, so that the agent cannot resolve the question by reaching for a better frequency. And third parties must bear the downside if she is wrong. Give me the scenario in one paragraph of no more than about two hundred words.

Then do the analytical work in order. State the forecast or recommendation each view issues and why, showing that neither is stipulated. Identify the single feature of the case that does the work. Say what happens if you remove or weaken that feature — in particular whether the case collapses back into the standard planning-fallacy shape in which the outside view is plainly right, and exactly which modification collapses it. Then give the strongest reply available to a defender of the outside view, especially the reply that what looks like inside-view reasoning is really just the outside view applied at a finer grain, since refining a reference class on causal grounds is something the outside-view literature itself recommends; tell me what would have to be true for that reply to succeed and whether the case as built survives it. Finish by saying which of the two choices is the modest one, and whether 'be modest' picks out a determinate policy here or merely relocates the judgment to a step that no one is watching.
