ok so I've been trying to get my head around program equilibrium and I think I've got the shape of it but not the guts. Setup as I understand it: two programs play a one-shot prisoner's dilemma, no repetition, no reputation, no pre-play communication, but each program gets to look at the other's source code before it moves. Somehow mutual cooperation is still an equilibrium, and the fancy trick is a bot that cooperates iff it can prove that the other bot, seeing this bot's code, will cooperate back.

Three things I can't get straight and would love an intuitive (not formal) explanation of:

1) Where is the proof actually doing work? Why can't I just write a bot that says "if the other bot would cooperate against me, then cooperate" and be done? What breaks — is it circularity, is it that "would cooperate against me" isn't something a program can in general compute about an arbitrary other program, or is something subtler going on with the self-referential proof?

2) Does any of this survive if the proof search is bounded? If each bot only gets like a million steps of proof search, my gut says everything collapses back to mutual defection, since neither side can ever finish the proof in time. But I have a nagging feeling that's wrong and that you can still have a cooperating pair where each side's reasoning goes through cheaply. Which is it? And relatedly — does the self-referential trick still work if each bot only sees a hash of the other's source rather than the actual code?

3) bonus confusion: I keep seeing the phrase "open-source game theory" stuck to this stuff. Is that just a cute name for the setup, or is there an actual conceptual claim there, like that publishing your source code is itself a move with game-theoretic consequences?

I don't need the formal proofs, I want the intuition — but I want the intuition to be honest about where the hand-waving is. In particular if the cooperation is really fragile (e.g. some bot could just reason "if I can prove this guy cooperates, I'll defect") then say so, don't sell me the clean story.
