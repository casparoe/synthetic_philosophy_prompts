I'm an undergraduate in my third year, currently taking a seminar on philosophy of the social sciences that has spent the last several weeks on the problem of the reference class — how we pick the population over which a frequency is computed, and whether that choice is a matter of principle or of convenience. I have to write a term paper proposal of roughly 1,500 to 2,000 words, and I want help turning a half-formed idea into a proper proposal. Please write it for me.

My half-formed idea is this. There is a familiar style of reasoning about empires and long-lived states that says: rather than asking what is distinctively wrong with this particular polity and how long it can last, look at a reference class of comparable polities and read off how long such things typically last. This is offered as an antidote to inside-view bias, and it is often presented as the sober, quantitative option. But I think the reasoning has an internal problem that has nothing to do with whether the base rate is well estimated, and that the problem is sharpest precisely for the case people like to use, namely empires.

The problem is that the members of the reference class are not exchangeable with respect to age. If polities differ in some durable, unobserved fragility — quality of institutions, geography, whatever — then even if each polity faced a constant hazard of collapse at every moment, the pooled data would show a hazard that declines with age, because the fragile ones exit early and leave a survivor-heavy remainder. So a forecast that reads the pooled hazard at the current age of a long-lived empire will overstate the danger to that empire, and the naive outside view turns out to be a disguised version of the gambler's fallacy: thinking that a long run of survival makes collapse more imminent. But I want to be careful, because I suspect the opposite error is also available — if there is genuine positive duration dependence, accumulated fragility, institutional decay, the sort of thing historians of decline tend to describe, then long survival really does raise the hazard, and the outside view would be understating it. So the interesting question is not which way the bias runs but whether the outside view, as usually practiced on historical polities, can in principle distinguish exchangeable hazard from heterogeneity-driven apparent decline in hazard, and what it would take to do so.

There is a second thread I want woven in, though I am less sure how to integrate it. The units in the reference class are not given independently of the historiography. Where one empire ends and a successor begins, whether a period of fragmentation counts as a collapse or an interregnum, whether a dynasty change is a new polity or a continuation — these are decisions made by the people constructing the dataset, and they will be made differently by different traditions, and not always independently of the outcome being studied. This is usually raised as a measurement-error complaint, but I think it is more interesting than that: it suggests that the reference class problem for empires is not only a problem about which set to choose but about whether the individuals composing any such set are well-defined prior to the choice. I would like the proposal to take a position on whether this is a separate problem or a version of the first one.

Please write the proposal with the following components, and keep the writing tight and academic rather than chatty. First, state the question so that it has a determinate answer — I would rather have a narrow question with a clear verdict available than a broad one about whether we can predict the fall of empires. Second, explain why the existing positions on the outside view, and on reference classes more generally, do not already settle it; be specific about what they do and do not deliver, without turning this into a literature review, and do not include citations or a bibliography, since I will supply those myself. Third, lay out the method: what I would actually do. I want this to be a conceptual and methodological project rather than a data project, since I cannot run statistics on a large corpus in one semester, so the method should be something like constructing a small set of deliberately simplified models of the historical process and asking what each one implies for what the outside view would report, plus an analysis of what would have to be true of the historical record for the distinction to be recoverable from it. I want the argument to be about the structure of the inference, using generic examples I could fill in later, so that the proposal does not stand or fall on a contested reading of Rome or of any other case.
