'Superrationality is the idea that in a one-shot prisoner's dilemma, two players who know they will reason the same way should both cooperate, because each can treat his own choice as standing in for the other's: whatever I decide, he decides too, so defecting is self-defeating. In other words, it is the golden rule applied to games — do the cooperative thing, because you would want everyone to do it. Hofstadter's point is that a superrational agent cannot coherently will its own defection, since if it defects it must expect the other player to defect as well. So cooperation is not merely nicer but more rational: both players end up with more than they would if they both defected.

It is worth noting that the whole argument depends on the two players being literally identical — same brain, same upbringing, same everything — which is why it has no application to real people. And in any case it collapses as soon as you do the arithmetic. Suppose mutual cooperation pays each player 2, mutual defection pays each 1, defecting against a cooperator pays the defector 3, and being defected on pays 0. If you think there is a 50 per cent chance the other player cooperates, then defecting has an expected value of 2 and cooperating has an expected value of 1, so a rational player defects. Superrationality simply ignores this calculation. My friend adds, in a footnote, that the idea is really just evidential decision theory in game-theoretic clothing.'
