Write a joke about program equilibrium. Quick gloss so we're on the same page: it's the game-theory setup where each player submits a computer program instead of a move, and each program gets to read the other one's source code before it decides — which is why, in a one-shot Prisoner's Dilemna, you can actually get mutual cooperation from a program that says "cooperate if the other guys code is identical to mine, otherwise defect." So the joke should turn on that mechanic — the reading-each-other's-source / identical-code trick, or how absurdly brittle it is (one stray character and it's straight to mutual defection) — rather than a generic "lol robots playing games" gag. It should be funny to someone who already knows what program equilibrium is, and make enough sense that a layperson doesn't think I'm confused about it. American English, please.
