ok so I've been calling myself a fitting-attitude guy for a while now and before I try to write this up properly I want to know whether my little package actually hangs together. Heres what I believe, roughly:

1. Value is fittingness. For something to be good is just for it to be a fitting object of a pro-attitude (admiration, desire, whatever you like). There's no value property lurking behind the fittingness that the fittingness is tracking — fittingness comes first.

2. Fittingness isn't primitive. An attitude is fitting exactly when there are sufficient reasons for it. I dont want some spooky sui generis "fitting" that floats free of reasons and that I then have to intuit.

3. Buck-passing. The fact that something is good is never itself a reason to value it; the reasons to value it are the (non-evaluative) properties in virtue of which it's good.

4. Wrong-kind reasons are real. If a demon credibly threatens to torture me unless I admire him, I have a genuine reason to admire him — but he does not become admirable. So there are reasons for attitudes that simply don't touch fittingness.

5. Fittingness is normative. If an attitude would be fitting, that fact itself counts in favor of having it. It's not a merely descriptive fact about which attitude happens to match its object, like a key matching a lock.

I have a nagging feeling these can't all be true together, even though each one on its own seems like a totally standard move for someone in my camp. So: which pairs actually fight each other, which ones only look like they do, and how bad is each clash? Order them by how much it would hurt to lose, and for each real one tell me the cheapest thing to give up and what I'd be giving up with it. And if one of these five is doing all the damage, just say so.
