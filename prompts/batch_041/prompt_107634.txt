I've got two friends who've been arguing for about a year about what it is for a trait to have a function, and I've offered to write the joint statement they clearly can't write themselves. One of them is in the etiological / selected-effects camp (the Millikan–Neander lineage, roughly): a trait's function is the effect it was selected for, so it's a historical fact about the trait's lineage. The other is a causal-role person (Cummins-style, I think): a function is just the contribution a part makes to some capacity of the containing system, no history required. They keep talking past each other and I want the doc that ends that.

So: draft it. I want (1) a numbered list of claims both of them can sign — about what functions are for, about malfunction and dysfunction, about artifacts, about whether function talk is genuinely normative, and about the reference-class problem (which population, which time window, which system boundary). Then (2) a disagreements table: each row an issue, one column for the disagreement stated in wording the etiologist would accept as fair to their own view, one column for the causal-role wording, and a column flagging whether it's a real disagreement or just the two of them meaning different things by "function". Then (3) the cruxes — the sub-questions where settling the thing would actually move one of them — and for each crux a case or arguement both would agree bears on it, with each side's prediction written down before they run it.

I want you to build the cruxes around three cases I think are under-discussed, and spell each out so there's no ambiguity:

a) a trait that's currently doing useful causal work but was not selected for it — it drifted in, and the payoff only showed up in the last handful of generations, so there's basically no selection history to point to yet;

b) a trait with a real selection history whose current causal role has nothing to do with the effect it was selected for (co-option / exaptation, I think it's called);

c) a part of a self-replicating computer program in an artificial-life ecology — a chunk of code that currently stops a rival replicator from overwriting it, inside a system that reproduces, mutates and competes, but where nobody designed it and there's no biologist in the loop. Does "function" apply, and if so whose account gets it right?

Don't give me a reading list or citations, just do the work. And if it turns out they agree more than they think, say so. End with one line starting "Summary:" that gives me a single sentence version of where they really stand.
