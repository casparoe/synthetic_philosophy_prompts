i'm prepping a reading group on decision theory and before we start arguing about which theory is right i want the spec in front of us. so write me the desiderata: what any adequate theory of rational choice under uncertainty actually has to deliver. not the theory, the checklist it has to pass.

first the cases it has to get right, with the point of each one: newcomb's problem, the smoking lesion, counterfactual mugging, XOR blackmail, parfit's hitchhiker, the twin prisoner's dilemma, and whatever else you think belongs. for each, tell me what the case is actually testing -- is it testing whether the theory is causal or evidential, whether it can make a precommitment stick, whether it survives when the predictor is a copy of you, whether the payoff is hostage to a counterfactual -- because i want to see which cases are load-bearing and which are just the same case wearing a hat.

then the structural requirements, kept separate from the cases: that the theory not be exploitable by someone who knows you're following it, that it be reflectively consistent (if you learn the theory's own verdict before acting, the verdict shouldn't change), that it agree with boring expected-utility reasoning in ordinary cases so we don't get decision-theoretic rock-paper-scissors, that it handle self-locating uncertainty, that it be partition-invariant so how the world gets carved up doesn't change the recommendation.

and here's the part i actually care about: flag any pair of desiderata you think can't be satisfied together. i suspect maximize expected value given your evidence and act so that the policy you'd have picked in advance does best are in direct tension, and that half the field is people quietly dropping one. if that's right, say which you'd drop and what it costs.
