(2) In a standard Frankfurt-style case, the agent decides to do X on his own, but a counterfactual intervener would have forced him to do X if he had shown any sign of deciding otherwise.
(3) The agent could not have done otherwise: if he had been about to decide otherwise, the intervener would have intervened, and he would still have done X.
(4) The agent is morally responsible for doing X.
(5) Therefore PAP is false.
(6) If PAP is false, then what matters for responsibility is only that the action actually issued from the agent's own deliberative process, not that any alternative process was available.
(7) But in any case where an action issues from the agent's own deliberative process, we can imagine a counterfactual intervener who would have ensured the same action if the process had gone differently.
(8) So for any action that issues from the agent's own deliberative process, the agent could not have done otherwise in the relevant sense.
(9) Therefore, by (6), every such action is one for which the agent is morally responsible.
(10) But consider a case of covert brainwashing: the agent's deliberative process has been engineered so that he reliably chooses X, and no counterfactual intervener is needed because the process itself is fixed.
(11) By (6), since the action issues from the agent's own deliberative process, he is morally responsible.
(12) That is unacceptable. The brainwashed agent is not morally responsible.
(13) Therefore either (4) or (6) is false. If (6) is false, then the Frankfurt-style case does not establish what it claims. If (4) is false, then Frankfurt-style cases fail to refute PAP.
