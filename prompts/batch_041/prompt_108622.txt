I'm a third-year physics PhD student who has been sitting in on a philosophy of religion seminar this term, mainly because fine-tuning keeps surfacing in the cosmology reading group I actually belong to, and I have reached the point where I can no longer tell what the arguments are claiming. The pattern that bothers me, stated as plainly as I can: someone asserts that it is enormously improbable that a particular constant of nature falls inside the narrow band compatible with stars, chemistry, or life. The number is always produced by dividing the width of that band by the width of the range of values the constant might have taken, and both quantities, so far as I can see, are chosen by the person doing the dividing rather than derived from anything. The range is typically just a great many orders of magnitude either side of the actual value; the band shrinks or grows according to whether we mean life of some kind or life like ours; and the whole calculation changes if we describe the situation using some function of the constant instead of the constant itself. That last point is what really stops me: the same physical arrangement can be parameterised by a quantity or by its logarithm, and if you suppose the quantity is drawn from some spread of possibilities you get one improbability, while if you suppose its logarithm is drawn from an equally unobjectionable spread you get a different one, with no apparent fact of the matter about which description nature was selecting between. The same thing seems to happen with the question of which possible universes we are supposed to be sampling from, and when anyone is pressed on any of this the discussion slides into the observation that we have no reason to prefer one range or one description over another, which strikes me as conceding the point rather than answering it.

I have tried to find a name for the specific failure and keep landing on near-misses. A statistician friend says it is the reference class problem, and I can see the resemblance, but that appears to concern which class a given individual should be assigned to for the purposes of a frequency, whereas my difficulty lies upstream of that: it concerns which description of the situation we are assigning probabilities to in the first place. Someone else said it is the measure problem that cosmologists worry about, which sounds closer, though that seems to be about how to assign probabilities over an unbounded or infinite space of universes rather than about the answer changing when I rename the variable. A third person told me that any Bayesian would say the argument is fine as a claim about how probable our values are given a hypothesis, and that what surprises us is a matter of our priors — which I suspect is correct, but which relocates the problem rather than naming it.

So: does this pattern have an established name and an established literature, and if the honest answer is that it is several distinct problems run together under one complaint, I would like them separated with the boundaries drawn. Specifically, which part of it is an incompleteness, the argument simply omitting a premise it needs; which part is an artefact of description rather than a feature of the world being described; and which part, if any, is an outright fallacy, the arguer quietly selecting whichever representation is most favourable to the conclusion. I am not asking for a bibliography, and a bare label will not help me. What I want is the carving, a couple of clear cases on either side of each line, and an honest statement of what, if anything, would fix it — some principled way of choosing the range, the description, and the reference class that does not simply assume the conclusion, together with a note on whether any existing proposal actually does that or merely postpones the difficulty.
