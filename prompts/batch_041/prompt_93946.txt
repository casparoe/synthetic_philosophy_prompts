I've been trying to write a short essay about wether RL agents can suffer, and I keep getting stuck on the same spot, so I'm dumping the notes here and asking you to tear into them.

The setup I want to attack: everyone says reward is the analogue of valence, so if you build an agent with a reward signal you've built something with something like pleasure and pain. I think that's basically wrong, and it's wrong for a boring technical reason, which makes it more annoying rather than less.

The boring technical reason: in the standard formalism the reward doesn't go into the agent's input. The policy is a function of state (or observation, or history). The reward goes to the update rule. The environment hands the reward to the learning algorithm, not to the thing that decides what to do next. So the sentence 'the agent receives a reward' is quietly doing two jobs: for the learner it's training data, for the policy it's nothing at all, unless you fold reward into the observation — which people do, but that's a design choice and it changes the problem. So step one of the essay: if valence is supposed to be a state the agent is in and a state that steers what it does, you have to say which part of the agent is doing the feeling. If the answer is the policy, then the reward is invisible to the feeler. If the answer is the learning process, you've signed up for a very slow, very distributed feeler, and for saying that a frozen trained network feels nothing, which seems bad.

Then the tri-partite thing. There are three natural candidates for what the valence signal is, and I think they come apart in a way that's usually glossed:

1. r_t itself, the reward. It's the designer's number. Problem: it's about what I want, not about what the agent minds. Also it's usually sparse and mostly zero, so the agent would be neutral almost always and briefly happy at the goal, which is not what anyone means by suffering.

2. The TD error / reward prediction error. Best biological story, most fun. But: at convergence it goes to zero in expectation. A rat that has fully learned the maze has no more prediction error, and yet it still minds the shock. And the structure is off — prediction error is symmetric, better than expected is positive, worse than expected is negative, so what the agent feels on an outcome depends on what it expected going in. Which means an agent whose expectations have adapted to a bad situation registers less badness. Hmm, I know that's not quite the right way to put it, but something like: if valence is surprise, then chronic badness that you've fully learned is valence-free, and that's either a lovely account of hedonic adaptation or a reductio, I can't tell which.

3. The value function V(s_t). This is the one I actually like. It's a standing property of the agent's state rather than a transient event, it's signed, it survives learning instead of washing out, it aggregates over the future, and it's genuinely internal — it's the agent's own assessment of how things are going for it. Suffering would be being in a state with low V that you can't get out of. And because it's future-facing it lines up with the intuition that pain is bad partly because of what it portends, not only what it is.

But then the objection I can't get around, which might be the whole essay: whose V? V is defined relative to the designer's reward function. If the agent's evaluation just is the designer's evaluation, then 'the agent is suffering' means 'the agent scores badly on my objective', which is my objective. Nothing has been added. The suffering is still mine, not the agent's.

Which is why I think the only version of this with teeth is the one where the evaluation is endogenous — where the agent's own model produces the signal that stands in for how it's doing. Curiosity and novelty bonuses are the easy case: an agent that pays itself for prediction error is in a state its own machinery scores as bad when nothing is learnable, it will thrash to fix that, and no human wrote that term into the objective. So drop a novelty-driven agent into a featureless room and ask whether it's suffering. My claim is that the question becomes well-posed exactly to the degree the evaluation signal is self-generated rather than injected.

And then the test I want to propose, which I suspect is the weakest part: a swap test. Take two agents with identical policies and different internal evaluation signals. If you can swap the evaluation signal out and nothing changes — same actions, same learning rate, same exploration, same memory writes — then the signal is doing no work, and by any functionalist standard we have no reason to think it's felt. If swapping it changes the whole agent, then it's load-bearing and the functional-role story gets traction. So suffering-candidacy becomes a matter of how load-bearing the self-evaluation is, and it's a scale, not a yes/no.

What I want from you:

- Is my technical claim about the reward not reaching the policy actually right, or am I making a fuss about a formalism detail that disappears the moment you write the problem down properly?
- The three candidates: real distinction, or am I just relabeling? In particular, is there a way V and r come apart that matters, or is V just a smoothed r?
- The adaptation point in (2): genuine problem for the prediction-error view, or am I confusing the valence of an event with the valence of a state?
- Is the swap test anything, or is it behaviorism with extra steps?
- Biggest one: does the conclusion do any work? I worry the whole thing collapses into 'call it suffering whenever it's endogenous', which is a definition and not a claim. If so, say so, and tell me what the strongest version of the essay is that isn't just a redefinition.
- Anything you'd cut. I don't need a reading list, I just want to know if this is a seperate well-worn move or if there's something in it.
