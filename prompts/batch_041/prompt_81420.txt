Alright, I've been trying to wrap my head around the Löbian obstacle and I want to compare it to something, because I suspect it's an old argument wearing different clothes and I want to know if that's right.

Here's the obstacle as I understand it. Löb's theorem says, roughly, that if a system like Peano arithmatic can prove, for some particular statement, that if it proves that statement then the statement is true, then it can already prove the statement outright. The upshot is that a formal agent can't get a general license to trust its own proofs -- it can never prove, of itself, that everything it proves is true. It can only establish that from someplace stronger, and if you just bolt the trust on as a fresh axiom then either you're assuming the thing you wanted to justify or the system ends up stronger than the thing that was supposed to be trusting it. So when you try to design an agent that reasons about itself, or an agent that wants to trust the smarter successor it's about to build, you hit a wall: it can license the successor's conclusions one statement at a time but never as a standing policy. The usual workaround is to have the parent hand the child a slightly different formal system, often a weaker one plus an axiom about the parent's soundness, so each generation can prove things about the generation before it that it couldn't prove about itself.

Now put that next to the old Lucas-Penrose arguement: Gödel's incompleteness theorems supposedly show the mind can't be a formal system, because for any such system we can see that its Gödel sentence is true even though the system can't prove it, so we're not that system.

What I want is the comparison, and specifically:

3. My own hunch: both are really about a level mismatch -- you can't be your own meta-level. In Lucas-Penrose the mind gets smuggled in as the meta-level; in the Löbian case there's no smuggled meta-level, just a hard result about what a system can prove about itself. Is that a fair way to put it, or am I flattening something?
