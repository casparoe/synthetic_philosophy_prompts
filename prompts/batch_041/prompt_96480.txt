Question (10 pts):

(a) Fix a prefix-free universal machine U. The Solomonoff prior gives each program p weight 2^−|p|, and the universal distribution is M(x) = the sum of 2^−|p| over all programs p with U(p) = x. In what sense, if any, is this "Occam's razor"?

(b) Explain why, for every computable probability distribution μ, there is a constant c > 0 with M(x) ≥ c·μ(x) for all x. What does that buy you?

(c) Does this solve Hume's problem of induction? Explain.

Answer:

(a) This is Occam's razor, formalized. A program of length n gets weight 2^−n, so of two programs that both produce the data, the shorter one gets exponentially more prior mass, which is exactly the preference for simple hypotheses. And it carries straight through to the data: by the coding theorem M(x) = 2^−K(x), so the universal distribution assigns a string the probability 2^−K(x), where K(x) is the length of the shortest program that outputs it. So Occam's razor here just is the claim that strings with lower Kolmogorov complexity are more probable. Since K is machine-independent up to an additive constant, M is machine-independent too — a different universal machine would just rescale the probabilities by a constant factor, so the choice of U doesn't really matter.

(b) Any computable μ has a program p_μ that samples from it: feed p_μ random bits and it outputs x with probability μ(x). That program has some length |p_μ|, and by construction M(x) ≥ 2^−|p_μ| · μ(x). So the mixture is always at least a constant fraction of the truth — for every computable truth, with the constant depending on μ but not on x. What that buys you is convergence: a Bayesian who starts from M and updates on the data will have the posterior concentrate on the true distribution, and the expected prediction error goes to zero. It's "universal" in that no computable hypothesis is excluded in advance, and the wrong ones get eliminated by the data at a rate that lets the mixture track the truth.

(c) I'd say yes, or at least it dissolves the problem. Hume wanted a justification for expecting the future to resemble the past — i.e. for some particular inductive regularity. Solomonoff's move is that you don't have to bet on any particular regularity; you average over all of the computable ones and the averaging does the work. Whatever computable structure is in the data, some program captures it and the mixture picks it up. The only assumption left over is that the data is generated by something computable, which is about as weak an assumption as you can make — to break it you'd need to be in a non-computable world, and we have no reason to think we live in one. So the problem of justifying induction gets replaced by a much more modest assumption that we can just grant.
