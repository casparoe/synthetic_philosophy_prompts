Write a dialogue between two people arguing about Occams razor. One is a Solomonoff inductivist: the shortest-description prior is the uniquely optimal predictor, so simplicity isn't a heuristic, it's provably truth-tracking. The other reckons that's a con — description length is only defined relative to a choice of language or machine, and you can rig a language so that either of any two rival hypotheses comes out simpler, so the razor just launders our encoding conventions into a metaphysical principle.

Give the sceptic this concrete move. Take a string that happens to be the first digits of pi, and two stories about the process that produced it: (i) a random process that just happened to emit those digits, (ii) a process that computes pi. In the usual encoding (ii) is a short program and (i) has an astronomically tiny prior, so Solomonoff says (ii) crushes (i). But, the sceptic says, that's only because computing pi is cheap in our language; in a language where those digits are just a hard-coded lookup table, (i) comes out shorter and the verdict flips, so the razor's verdict rests on a choice we can't justify. Have the inductivist actually reply — the invariance theorem (switching languages only adds a bounded constant, so the ordering converges in the limit), the gap between the ideal prior and computable stand-ins like minimum description length, the thought that physically realisable encodings aren't arbitrary — and then let the sceptic push back that the limit is a place we never visit and the constant can be as large as you like.

Neither should be a strawman, and they should answer each other's actual points rather than talk past each other. Where does it end up — is the real disagreement about finite cases vs the limit, about whether an uncomputable ideal can justify any actual practice, or something else? Pls write it in British English.
