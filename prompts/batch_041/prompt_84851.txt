Exam question

A five-member grant panel must decide whether to fund a proposal. The panel's charge specifies that the proposal is to be funded if and only if both of the following hold: (P) the proposal's methods are sound, and (Q) the proposal addresses an important question. Write R for the funding decision, so that the panel's rule is: R if and only if P and Q. Each member's individual judgment satisfies this rule. The members' judgments are as follows.

Member 1: P true, Q true, R true
Member 2: P true, Q true, R true
Member 3: P true, Q true, R true
Member 4: P true, Q false, R false
Member 5: P false, Q true, R false

(a) Determine the majority judgment on each of P, Q, and R, and state whether the resulting set of majority judgments is consistent with the panel's rule.

(b) Suppose the panel proceeds by voting first on P and on Q and then applying the rule to derive R (a premise-based procedure). Suppose instead that it votes directly on R (a conclusion-based procedure). Give the outcome of each procedure and explain why the two can differ.

(c) The panel chair proposes that the panel simply adopt the premise-based procedure, on the ground that it is the only procedure under which the panel's collective judgment obeys the panel's own rule. Evaluate the chair's proposal.

(d) What, if anything, does this example show about the general possibility of a group's arriving at a consistent set of judgments?

Student's answer

(a) Counting votes: P is affirmed by members 1, 2, 3, and 4, so P passes by 4 to 1. Q is affirmed by members 1, 2, 3, and 5, so Q passes by 4 to 1. R is affirmed only by members 1, 2, and 3, so R fails by 3 to 2. The set of majority judgments is thus P true, Q true, R false. This set contradicts the panel's rule, which requires R to be true whenever both P and Q are true; the panel's majorities affirm both premises while denying the conclusion.

(b) Under the premise-based procedure the panel votes on P and Q and then derives R. Since P passes and Q passes, the derived judgment is R true, and the proposal is funded. Under the conclusion-based procedure the panel votes only on R, which fails 3 to 2, and the proposal is not funded. The two procedures diverge because the premise-based procedure lets the logical structure of the rule fix the conclusion, whereas the conclusion-based procedure lets each member's overall verdict count directly. The majority on the premises and the majority on the conclusion can point in opposite directions, as they do here.

(c) The chair is right that the premise-based procedure is the only one of the two that guarantees a collectively consistent set of judgments, and on that ground the panel should adopt it. Because it preserves consistency, it also ensures that the panel's decision on R faithfully reflects the majority's view on R, so no member's judgment is overridden.

(d) The example shows that a group of individually rational members can arrive at an inconsistent collective judgment. This is the paradox Condorcet identified: majority rule can generate a collective result that no consistent individual need share, even when every individual's own judgments are consistent. The present case is simply that paradox restated in the currency of judgments rather than preferences. Because the difficulty is really about majority cycling, it disappears as soon as the agenda is confined to a single binary question, which is why the conclusion-based procedure is immune to it.
