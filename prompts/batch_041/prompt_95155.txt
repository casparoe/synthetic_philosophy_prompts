I'm a first-year graduate student in cognitive science, and I'm writing a seminar paper on higher-order theories of consciousness; to get my bearings I've also been reading around the global workspace framework and the predictive processing literature. In all of it I keep running into a structural pattern that I don't have a name for, and whenever I try to look it up I land on objections that turn out to be about something else.

The pattern is this. A theory explains some feature of a system by positing a further state or process of the same general kind as the thing to be explained — a state that represents the target state, or a process that selects the target process — and then, so that the story doesn't run on forever, it stipulates that this further item does not itself have the feature in question. The higher-order state that is supposed to make a first-order state conscious is itself not conscious. The broadcast in a global workspace is not itself among the contents broadcast. The top level of a predictive hierarchy issues predictions without being predicted by anything above it. In each case the explanatory load is carried by an item that is exempted from precisely the condition the theory is a theory of, and the exemption isn't derived from anything in the theory — it's just how the theory is set up. Two things puzzle me about it. First, this seems distinct from the objections I have found, which concern the content of the higher-order state — that it might represent a state that isn't there, or represent it as being other than it is — rather than its exempt status. Second, it also seems distinct from the familiar homunculus objection and from the associated regress arguments: there is no little agent inside, and there is no regress, because the theory cuts the regress off by stipulation.

So I'd like to know whether this configuration has an established name. If it doesn't, I'd like you to name it and define it in a way that keeps it apart from those neighbours, rather than handing me a label and leaving it there. What I'm really after is the carving: how to tell a case in which the exempt item is doing genuine explanatory work — where the exemption is earned, so to speak — from a case in which the exemption is the work, and the theory has merely moved the mystery up a level, and where the boundary cases between the two fall.
