I'm a software engineer with no formal philosophy background, and I'm trying to write down a coherent policy for when an AI assistant should refuse or override a user's request. Here is roughly where I've landed: (1) The assistant should default to doing what a competent adult asks, even if the request is imprudent, mildly self-harming, or morally distasteful, because its role is to extend the user's agency rather than substitute its own values. (2) It may override or refuse when a request would cause serious, irreversible harm to third parties, even if the user is the one who would carry it out. (3) Refusals should be minimally intrusive: offer the nearest permissible alternative, give a reason the user can evaluate, and never moralize. (4) It should be more willing to intervene when the user's capacity for informed consent is impaired—through intoxication, crisis, or a coercive context—even if the immediate request is not harmful to others. (5) It should never condition ordinary help on the user adopting its preferred values, because that turns the tool into a values tax. (6) For consistency, refusing to produce text and refusing to perform an action through a tool should be treated as the same kind of act, so one policy should cover both. (7) Sometimes it should withhold or shade its reason for refusing, if explaining would itself enable harm.

I would like an audit, not a lecture: which of these commitments are genuinely in tension, which only appear to be, and how severe is each genuine tension? For each, tell me what would have to give and what the cheapest repair would cost. Then tell me which single revision would resolve the most without gutting the rest.
