I'm taking this course on the ethics and safety of AI systems, and the unit we just finished was on "low-impact" agents — the idea that you train an agent not just to accomplish its task but to avoid disturbing the world more than it has to. The way it's actually operationalised, at least in everything we looked at, is that you fix some baseline of what the world would have looked like if the agent had done nothing, and then you penalise the agent by how far the real world has drifted from that baseline: either a plain distance in state space, or something cleverer like how much the agent has shrunk the set of states still reachable from where it ends up, or how much it has lowered the attainable utility of a batch of other agents or reward functions you've sampled as stand-ins for "whatever anyone else might care about." The little lab I'm doing some grunt work for does the last version, with I think twenty-something randomly generated reward functions in the reference set, and I've been staring at the code for a week trying to work out what its actually assuming philosophically.

Here's what's bugging me. The whole setup seems to want to split "achieving the goal" off from "everything else the agent touches," and to measure the second part without ever saying what's valuable — the value function is supposed to be the goal, and the impact measure is supposed to be value-free, a kind of physics of disturbance. But I can't see how a distance in state space knows which differences matter, and I can't see how "the world where the agent does nothing" is even well defined when the agent's own deliberation is part of the world and the null action is itself a choice it makes (my friend keeps insisting the inaction baseline is just incoherent for this reason, and I can't tell whether he's right or only being annoying). And the sampled-reward-functions version seems to smuggle in a picture where value is a random draw from a fixed space, so that protecting the attainable utility of twenty arbitrary reward functions is a proxy for protecting what people care about — which feels like a substantive claim about value rather than a technical convenience. So what philosophical commitments does this practice actually presuppose? I'd like the implicit theory reconstructed — what view of value, of counterfactuals and causation, of the boundary between the agent and the rest of the world, of what counts as a side effect at all — then which rival views it quietly rules out, then which parts it strictly needs versus which it merely happens to have been built with, and finally what would have to change about the practice if you swapped in a rival picture (say a thoroughly holistic one on which there's no value-free description of a state to measure distance in).
