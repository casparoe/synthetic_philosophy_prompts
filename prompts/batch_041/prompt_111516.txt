A friend in my aesthetics reading group has an argument about copies that I can't shake and also can't find the hole in. It runs:

(1) The aesthetic value of a painting depends only on how it looks — the visual properties it presents to a viewer.
(2) A perfect copy, by definition, presents exactly the same visual properties as the original. Suppose you could never tell them apart, however long or hard you looked, with any instrument.
(3) So the copy has exactly the same aesthetic value as the original.
(4) Aesthetic value is the only value a painting has in itself. Whatever else we prize about an original — its age, who made it, how it came to be — is value we're attaching to a story we tell about it, not value the thing itself has.
(5) So there is nothing in the original itself that the copy lacks.
(6) So a fully informed buyer who cares about the painting for its own sake should be indifferent between the two, and would be a sucker to pay more for the original.
(7) But we don't think that. The dealer who sells the copy as the original has swindled his buyer. A museum that quietly hung a perfect copy in place of the original would have done something wrong, and not merely a paperwork wrong. If a fire let us save just one of them, we'd save the original.
(8) So one of (1) through (4) has to go.

I'd rather not give up (1) — I genuinely can't see what a painting's value would be if it weren't in how it looks. But I can't accept (6). Tell me where the argument goes wrong, which step it is and why that step looked fine, and if you think it's actually valid, tell me which premise I have to give up and what giving it up costs me. Don't let me keep the nice bits for free.
