Here's the student's answer:

Under MEC, we compute the expected choiceworthiness of each action by weighting each theory's score by our credence in that theory. For A: 0.7*100 + 0.3*(-100) = 70 - 30 = 40. For B: 0.7*0 + 0.3*100 = 30. So MEC recommends A, because 40 > 30. This shows that MEC can recommend an action that is wrong according to a theory we take seriously, which is the distinctive feature of moral uncertainty. It is not the same as simply following the theory we think most likely, since D's verdict still affects the expected score.

If the scores are not intertheoretically comparable, MEC cannot be applied directly, because we cannot say whether C's 100 is greater than D's -100 in a common unit. Some philosophers respond by using variance voting, which normalizes each theory's choiceworthiness scores so that they have the same mean and variance; after normalization, the scores become comparable and we can apply MEC. Others propose the parliamentary model, in which each theory gets a number of seats proportional to our credence, and the parliament decides by majority vote. The parliamentary model avoids the intertheoretic comparison problem because it only asks each theory to rank the actions internally, and then aggregates the rankings. In this case, C ranks A > B and D ranks B > A. With 0.7 seats for C and 0.3 for D, A wins the vote, so the parliamentary model also recommends A.

One might object that the parliamentary model is not really a decision rule but a metaphor, but I think it captures the idea that moral uncertainty should be treated like political disagreement among theories. The main lesson is that MEC and the parliamentary model can disagree when the theories' value scales are distorted, but in this case they agree.
