**Agreeing to Disagree with Imprecise Priors**

§1. The result I am working from. Aumann's agreement theorem states that if two agents share a prior over a finite state space and each agent's posterior probability for some event is common knowledge between them, then the two posteriors are equal. The proof turns on a fact about common knowledge: if it is common knowledge at the actual state ω that A's posterior equals some value q, then A's posterior equals q at every state in the common knowledge cell C containing ω, where C is the finest event containing ω that neither agent's information partition can cut. Each agent's posterior then equals the shared prior conditioned on C, so the posteriors coincide.

§2. Why I want to change the model. Disagreement that survives full mutual disclosure is common, and the usual explanation is that the agents' priors differ. I want to test a different hypothesis: that representing credence as a single real number is doing at least as much work as the common-prior assumption. So I let each agent's credences be imprecise — a convex set of priors rather than a single prior — and ask what becomes of the theorem.

§3. Setup. Ω is finite. A and B have information partitions Π_A and Π_B. A's prior set P_A is a nonempty convex set of distributions on Ω, and P_B is likewise. At state ω, A's posterior set is S_A(ω) = { p(·|Π_A(ω)) : p ∈ P_A and p(Π_A(ω)) > 0 }, with S_B(ω) defined the same way. I assume (i) prior overlap: P_A ∩ P_B is nonempty; (ii) the partitions and the prior sets are common knowledge; (iii) the posterior sets are common knowledge at ω, meaning that S_A and S_B take the same values at every state in the common knowledge cell C containing ω.

§4. Conjecture. Under (i)–(iii), S_A(ω) and S_B(ω) intersect. The thought is that imprecise agents need not agree exactly, but full mutual transparency plus a shared core prior should force their credal sets to overlap. Overlap is the natural analogue of equality once credences are sets: the agents would then be committed to some common probability judgment, even if each has further judgments the other rejects.

§5. Proof sketch. Take μ ∈ P_A ∩ P_B. By (ii), each agent can compute the other's prior set, so the only possible source of disagreement is information. By (iii), S_A and S_B are constant on C. Since Π_A(ω) and Π_B(ω) are both contained in C, S_A(ω) and S_B(ω) are both sets of distributions on C; and each contains the conditional of the shared prior μ on C, because μ is in both prior sets and each agent's cell sits inside C. So the two sets share an element.

§6. A case that worries me. Let Ω = {1, 2, 3}; let both agents have the partition {{1, 2}, {3}}; let P_A be the convex hull of the distribution putting all weight on state 3 and the distribution (0.8, 0.2, 0), and let P_B be the convex hull of that same point mass and (0.5, 0.5, 0). Prior overlap holds, since the point mass on state 3 lies in both sets. At ω = 1 the common knowledge cell is {1, 2}. Every prior in P_A other than the point mass gives (0.8, 0.2, 0) when conditioned on {1, 2}, so S_A(1) = {(0.8, 0.2, 0)}; by the same reasoning S_B(1) = {(0.5, 0.5, 0)}. These are disjoint, and each is constant across the cell {1, 2}, so (iii) appears to hold. (At ω = 3 the two posterior sets coincide, so the failure is localized at {1, 2}.) Either I am misreading my own condition (iii), or the conjecture is false. I notice that this example gives both agents the same partition, which makes the disagreement purely a matter of priors; if that is somehow cheating, tell me why.

§7. Why I care. If the conjecture were true, it would show that rational, mutually transparent agents can persist in disagreement while sharing a core prior, and that the culprit is the exactness of credence rather than the prior. That would weaken the standard use of the theorem as a cudgel — the argument that persistent disagreement among equally informed parties must reflect either different priors or some failure of rationality — by exhibiting that argument as an artifact of representing belief as a single probability function. I also anticipate one objection: that (iii) is so strong that the hypothesis is rarely satisfied. My reply is that (iii) is simply the translation of common knowledge of posteriors into the imprecise setting, and I see no reason it should be unsatisfiable.
