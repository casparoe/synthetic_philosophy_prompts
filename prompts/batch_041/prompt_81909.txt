I direct the mediation office for a mid-sized city, handling roughly forty disputes a year — public-sector labor contracts, inter-departmental budget fights, occasionally a land-use conflict — each of which needs a written settlement proposal within about a week, produced by mediators with no training in game theory, and each of which will be read by both sides and by a commissioner who has to defend it publicly. I want those proposals generated from the Kalai–Smorodinsky principle rather than the Nash one: the settlement should be the point at which each side's gain over what it gets if talks collapse is the same fraction of the most it could possibly have hoped for, so that no side is ever made worse off by the feasible set expanding in its favor.

Write me a procedure my mediators can actually run on a case: the questions to ask in order, what counts as a sufficient answer to each, how to elicit a credible disagreement point and a credible ideal payoff from parties who both have every incentive to inflate them, what to do when the issues are not all money and each side's scale of measurement has to be chosen rather than read off, and what to do when some item is indivisible and the feasible set is therefore not convex. Flag the steps that are really judgment calls wearing arithmetic.

Then run it on two cases: a two-issue contract dispute where the procedure returns a split my own commissioner will hate, and a dispute containing one all-or-nothing item where the answer shifts depending on how the items are ordered. Close with what the procedure cannot do — where it should be set aside and a person should simply decide — and name the property the whole thing rests on, along with the point in a live negotiation where that property is most likely to be false.
