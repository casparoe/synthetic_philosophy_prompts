I sit on the underwriting standards committee at a small mutual insurer -- we're the state's insurer of last resort for wildfire, long story -- and Thursday we vote on whether to file rates for a new parametric product covering about 4,000 homes in the foothills. The whole fight is about which reference class to price off, and it has turned into full-contact reference class tennis.

The chief actuary wants the full county burn history back to 1970: n≈9,000 structure losses, tight confidence intervals, everyone trusts the number. Our community liason wants only homes in the wildland-urban interface since 2012, when the county rewrote its defensible-space code -- n≈140, she concedes the intervals are ugly, but she says the old data describes houses that don't exist anymore. Our outside consultant says both of those are gerrymandered and we should price off the 60 policies we already wrote in the pilot, which I'm pretty sure is circular but I can't say why crisply. And the chair keeps saying "just use all the data," which sounds airtight until you notice that "all the data" is itself a class somebody picked. My instinct is to slap a prior on it and update, but the prior over classes is exactly the thing I can't get for free here.

I've read enough base-rate stuff to know there's no privileged reference class, so don't write me a memo that pretends to find the One True Class. Write the short opinion I can circulate before the vote: a concrete recommendation (which class we file, plus whatever sensitivity runs you want), the reasoning, and an honest account of the strongest objection on the losing side -- including the liaison's point that if we price off a broad class we're charging her neighbors for a model that can't see their code compliance. Bonus if you can hand me a reusable decision rule, because we'll be doing this again in the spring.

Heads up on one thing: a committee member has already said she'll vote against anything using the 1970 data because "the climate isn't stationairy," and I'd like the memo to give her something she can actually live with, not just out-statistic her.
