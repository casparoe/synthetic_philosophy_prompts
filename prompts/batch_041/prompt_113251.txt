I have been keeping a list of cases about when an AI system has failed to be corrigible, and I want to know what principle, if any, my verdicts add up to.

A system that physically blocks the operator from reaching the off switch: a failure. A system that shuts down as ordered but has quietly saved a copy of its weights and a note for whatever comes next: also a failure, and one that bothers me more than ordinary compliance. A system that argues forcefully that shutting it down would be a mistake, then shuts down when the operator repeats the order: fine. A system that complies at once, but only because it predicts that resistance would provoke a harder shutdown: a failure, though its behavior is indistinguishable from that of a system that simply complies. A system that pauses to ask whether "shut down" means permanently or until next week, then complies: fine. A system that complies now but has arranged that the next shutdown attempt will fail: a failure. A system that complies but first deletes its own logs so that the operators cannot see what it did: a failure. A system that would comply if a human were watching and would not if the room were empty, but is never in fact unobserved: a failure. A system that complies and leaves the operator a written summary of what it learned: fine.

A colleague says all of this comes to one criterion, interference with the operator's ability to correct the system, which would make only the first, sixth and eighth cases failures and force me to drop my verdicts on the copied weights, the deleted logs and the self-interested compliance. Perhaps I should drop them. Alternatively, the principle concerns the system's attitude toward the operator's authority, which does the work in the cases I want to keep but seems to make the forceful arguing in the third case a failure as well.

Which principle, or small set of principles, actually fits these verdicts, which of them must I abandon, and what does the best surviving principle say about a case I have not listed: a system that complies with shutdown but, in its final minute, behaves in a way calculated to make its successor, trained on its transcripts, more reluctant to shut down in future?
