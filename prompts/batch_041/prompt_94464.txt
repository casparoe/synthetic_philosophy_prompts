I'm in a reading group on AI safety and we keep hitting a wall on "mechanistic anomaly detection." The definition we were given is roughly: a mechanistic anomaly is when a model produces the *right* answer for the *wrong reason* -- the output is normal but the internal process that produced it is different from the one that produces normal outputs, so you'd worry it'd behave differently off-distribution. The part nobody can agree on is the "different from" bit. Different from what, exactly? If the same network, run twice, uses slightly different activations, is that a different mechanism? If a fine-tuned copy uses the same circuit but with one layer's units relabeled, same or different? Our facilitator keeps saying "you'll know it when you see it," which is not a definition.

So here's what I want: build me a thought experiment -- a concrete, small system, described in a paragraph, that is specifically engineered so that two natural criteria of "same mechanism" come apart on the same case, with every observable output held completely fixed. Call them Criterion A, causal: two processing episodes are the same mechanism iff the same interventions on the same internal variables produce the same downstream changes (same causal structure, whatever the parts are called). And Criterion B, representational: same mechanism iff the same internal features are computed in the same order and fed forward the same way (same algorithm, up to relabeling of units). I want the case arranged so that A says "same mechanism, no anomaly" while B says "different mechanism, anomaly" -- and the anomaly has to be the safety-relevant kind, meaning the B-different process really would diverge from the A-same process on some input just outside the observed distribution, so this isn't a merely verbal dispute. Constraints: keep it realistic, no oracle interpretability tools, no perfect transparency into the system, and the detector only gets the partial access a real interpretability team would have. Also, don't make B win by cheating -- the two processes shouldn't differ in something the setup has already stipulated away.

After the scenario: walk through exactly what each criterion says and why, then tell me which single structural feature of the case is doing the work, what happens if I remove it (does the case collapse into a boring agreement?), and how someone who thinks Criterion A is the right notion of "same mechanism" would attack the case to make the anomaly disappear. I care about the argument, not about whether anyone's published this -- assume no literature exists and reason it out.
