Ok so I've been going round in circles on this and I want someone to actually attack my view instead of just nodding along. I've ended up convinced that statements about the future aren't true or false yet -- "there'll be a sea battle tomorrow" isn't the kind of thing that can be true on Monday, it only picks up a truth value once the day actually happens. That's the only way I can see to stop every future event being fixed in advance.

I know the obvious comeback: fine, so on Monday it was neither true nor false -- but when the battle happens on Tuesday, what was it? Surely it was true all along or it wasn't. My answer is that truth is relative to when you're asking, not just when it's said, so the same sentence can be neither-true-nor-false on Monday and plainly true on Wednesday when we look back. I think that's tidier than it sounds, but I dont really trust myself on it.

So what should count against this? I want the real objections, the ones I can't just bat away, sorted by how much they'd actually hurt. Which bits of logic does it break -- can I still say that one of "it will" and "it won't" has to be the case? Does it quietly turn into a claim about what we can know rather than about what's true? Does making truth something that changes come back to bite me? And be straight with me about whether I've built a view that nothing could ever count against.
