I am putting together a handout for a graduate reading group on the wrong kind of reasons problem, and I want the handout to be a decision tree that takes a reader from a few answerable commitments to a named solution. Not a list of the usual labels: build the tree out of the logical space, so that the branch nodes are the questions that actually divide the candidate views and the leaves are positions located in that space.

Here is the terrain, so that the handout stands on its own. On a fitting-attitude approach, for something to be good, desirable, or admirable is for it to be fitting to value, desire, or admire it; buck-passers add that the value property is not itself a reason but is explained by the reasons the object's natural features supply. The difficulty is that some reasons for an attitude do not bear on whether the attitude is fitting. If a demon threatens to destroy everything unless you admire him, you have some reason to admire him, and he is not thereby admirable; the threat does not make admiration correct. Call such reasons wrong-kind. The obvious diagnosis — the defect is that the reason is state-given, a fact about the consequences of having the attitude, rather than object-given, a fact about the object — is the first thing to test, since it is the diagnosis most candidates accept and the one most easily embarrassed.

The following distinctions must appear somewhere in the tree, not necessarily as adjacent nodes, and you may add others if they do real separating work: whether the right/wrong-kind distinction is a datum an analysis of value must accommodate or a phenomenon that itself needs explaining; whether the defect is located in the reason (its source or its content), in the attitude (its aim or its standard of correctness), in the practice or framework within which the attitude is assessed, or in the order of explanation between fittingness and reasons; whether the account is offered for attitudes generally or only for the cognitive case; and whether the view grants that wrong-kind reasons are genuine reasons at all, and if so whether it denies only that they bear on fittingness.

Every leaf must record a verdict on each of these five cases, and the tree must reach a verdict on all five:

1. the threatened demon and admiration;
2. a self-fulfilling belief — the fact that believing p would bring p about, offered as a reason to believe p;
3. an intention whose reason is that forming it makes the intended act more likely, where the state-given/object-given criterion looks as though it misclassifies a right-kind reason as wrong-kind;
4. trust in a partner on the ground that trusting them improves the relationship, a consequence-based reason that many people treat as right-kind;
5. a reason supplied by a self-referential feature of the object: the fact that the object is such that you will admire it, or that your admiring it is part of what makes it the thing it is.

Each leaf carries the standard label if the position has one and "unnamed" if it does not, one sentence stating its thesis, the answer path that reaches it, and the commitment its opponents will find most awkward. Include at least one leaf for a view that denies the distinction is unified and at least one for a view that keeps fittingness primitive and treats the constraint as brute. Flag any pair of leaves the tree cannot separate and say what further question would separate them. Mark combinations of answers that no position occupies and diagnose each as incoherent, unattractive, or merely unexplored.

Return a single JSON object and nothing outside it, with this schema:

{
  "nodes": [ { "id": string, "question": string (phrased so a reader can answer it without knowing which position it leads to), "answers": [ { "answer": string, "next": string (a node id or a leaf id) } ] } ],
  "leaves": [ { "id": string, "position_label": string (or "unnamed"), "thesis": string (one sentence), "path": [ string, ... ] (each entry "node_id: answer"), "case_verdicts": { "demon": string, "self_fulfilling_belief": string, "bootstrapping_intention": string, "therapeutic_trust": string, "self_referential_property": string } (at most two sentences each), "worst_commitment": string (one sentence), "status": "defended" | "unclear" | "nobody" } ],
  "unoccupied": [ { "answer_pattern": [ string, ... ], "diagnosis": "incoherent" | "unattractive" | "unexplored", "why": string } ],
  "unseparable_pairs": [ { "leaves": [ string, string ], "why": string, "separating_question": string } ],
  "cannot_settle": string (one or two sentences on what the instrument does not decide)
}

Use between six and nine nodes and between seven and ten leaves. Labels only: no author names, titles, references, or citations, and no reading suggestions. Put any framing you would otherwise write outside the object into "cannot_settle".
