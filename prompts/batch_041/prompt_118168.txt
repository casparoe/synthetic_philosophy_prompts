And the answer, typed up as written:

"The supposed paradox is that a rule has to be both the thing that gets changed and the thing that authorises the change. If a rule authorises its own repeal, then at the moment it's repealed it's no longer in force and so couldn't have authorised anything; but if it's still in force then it hasn't been repealed. Ross raised the same problem for constitutions, because the amendment clause is itself part of the constitution, so changing it looks like it requires it to be already changed. Suber's answer is that this only looks like a paradox if you treat the system as a static set of propositions, one big conjunction, instead of a process. Time-index the rules — rule R at t1 authorises the change that produces R* at t2 — and nothing is both true and false at once; the derivation is no more circular than any ordinary amendment. Nomic is the toy model here, since changing the rules is a move in the game and the initial rules even include one that changes its own voting threshold, so self-amendment isn't an accident of the system, it's the engine. Suber finds the same structure in the omnipotence paradox — can an all-powerful being limit its own power — but he treats that one as a genuine contradiction, which is why the theological version is the hard case. Whats left puzzling is why the paradox has any pull at all. Hart's Grundnorm (Kelsen's rule of recognition) is meant to sit outside the system, but if a rule can amend itself then there's nothing the system can't reach, so entrenchment clauses, like the one protecting equal suffrage in the Senate, are logically void and can only ever be political speed bumps. Suber's deeper point is that authority is a social fact and not a logical one: the players accept the amended rule, and the acceptance, not the derivation, is what makes it valid."
