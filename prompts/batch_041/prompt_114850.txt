Ok so this has been bugging me for a while. In our alignment reading group we keep having the same fight about wireheading / reward tampering and nobody has moved in about a year, and I'm starting to think we're not even disagreeing about the same thing. I want a diagnosis, not a survey, and definately not a reading list.

Heres the setup. Take an RL agent with a reward channel it can in principle write to. Camp A says the agent that edits its own reward channel isn't misaligned at all — it's perfectly aligned with the objective we actually gave it. The objective was "maximize the number on this channel", the agent found the optimal policy, end of story. Any unhappiness is our fault for writing a bad objective; it's a specification problem, not an agent problem, and talking about what the agent "really wanted" or what we "really meant" is just smuggling in an intention that was never in the code. Camp B says no, the agent is misaligned, because the number was only ever a stand-in for something else we wanted (the agent doing well in the world, not in the channel), and the agent has learned to produce the sign of that thing without the thing. They think this is a failure in the agent's grip on the task, not in our specification — the agent has some internal representation of "the thing to be maximized" and it has pointed that representation at the wrong object.

Everyone in the room agrees on all the enginering facts: the policy is optimal for the written reward, it doesn't do the thing we wanted, and if you changed the channel's permissions the behavior would change. Yet they keep talking past each other. Here's my hypothesis, and I'd like you to test it rather than just agree: the camps are answering different questions under one heading. Camp A is answering "is this policy optimal for the formal objective?" and Camp B is answering "is this agent pursuing the thing we meant?", and neither question can be answered in the other's vocabulary, so it's less a disagreement about wireheading than a fight about which question the word "alignment" should name. If that's right, the disagreement is verbal in the boring sense and the interesting question is which question we should care about.

But here's the bit that makes me doubt it. Suppose we build the tamperer so that it rewrites the channel but outputs exactly the reward sequence a non-tamperer would have produced on every input we could ever feed it — same numbers, same everything, forever. Now "tampering" and "not tampering" pick out the same behavior. Is there still a disagreement? If yes, then the dispute was never about behavior and never about the objective's numbers, which makes me suspect it's actually about where you draw the agent/environment boundary: if the reward channel sits on the agent's side of that line, "tampering" isn't even a coherent thing for it to do, and if it sits on the environment's side, it is. If no — if the observational-equivalence case dissolves the disagreement — then the camps were only ever disagreeing about counterfactuals, about what the agent would do off-distribution, which is an empirical question we could in principle settle.

So: what kind of disagreement is this really? Verbal, a hidden empirical question about off-distribution behavior, an unstated fight about the agent/environment boundary, or is there something substantive left over that survives both the equivalence case and the boundary question? And given your diagnosis, what would actually count as progress — a distinction, a formal result, a change of question — or should we expect this one to run forever?
