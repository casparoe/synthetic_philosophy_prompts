On Dennett's account of real patterns, the physical, design, and intentional stances are all legitimate ways of describing a system, and a pattern counts as real when a description of it predicts the system's behavior better than a chance baseline and compresses the data. On that account the reality of a pattern is relative to a description language and to our interests rather than to any privileged level of description. I have convinced myself that this cannot be made to work, and I would like you to assess my argument rather than the position in general. The argument runs as follows. (i) A pattern is real only relative to some description language. (ii) For any finite body of behavior, there is a description language in which that behavior compresses, since we are free to introduce a primitive term for it. (iii) So the reality of a pattern is always relative to a language we choose, and there is no stance-independent fact about which patterns a system has. (iv) So when the intentional stance credits a system with a belief, the attribution is neither true nor false, only more or less convenient. (v) So the physical stance is the only description that tracks what is really there, and the design and intentional stances are instruments. Please reply as exactly five numbered points, each one or two sentences, with no introduction and no conclusion: first, whether the argument succeeds as a refutation; then, in order, which steps fail and why; what the compressibility criterion has to involve if it is not to be trivialized in the way step (ii) suggests; what follows for whether a system can genuinely be said to believe something; and, finally, which part of my worry is legitimate and should be conceded by a defender of the account.
