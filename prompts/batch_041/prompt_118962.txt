Hey, I'm building an eval on mechanistic anomaly detection and I keep getting stuck on the same thing: nobody agrees on when two internal structures should count as "the same mechanism", which is annoying because the whole safety story rests on being able to say "this new behavior is a re-implementation of something I already understand" vs "this is a genuinely novel mechanism I've never seen". So I want to pin down which criteria should actually carry weight.

Here's the list I've been kicking around. Some of these I made up myself, so dont feel obliged to have seen them anywhere:

1. Same computational role in the task — both do the thing the model needs done at that point (e.g. both are the copy/induction head).
2. Same causal graph topology — same wiring pattern among components, regardless of what's stored where.
3. Same parameters up to a symmetry — you can map one onto the other by permutation/scaling.
4. Same behavior under all interventions — ablate either one and the model breaks in the same way.
5. Same counterfactual robustness profile — they fail on the same adversarial and near-distribution inputs.
6. Same training lineage — both emerged from the same phase of training / the same data ordering.
7. Same sparse-autoencoder latent signature — the same set of SAE features lights up for both.
8. Same minimality under compression — both are the smallest circuit that accounts for the behavior.

Score each one 0-100 for how much weight it should get when the question is whether a new model's behavior is a novel mechanism (an anomaly) or just a re-implementation of one you already understand. Higher = you'd let it swing the verdict on its own. Then sort rows highest to lowest.

Give me a markdown table with these columns: criterion | score | what it gets right | where it breaks. Keep the last two columns to one sentence each. Then one short paragraph after the table: if you could only keep a single criterion, which one and why. Start the whole thing with a one-line lead that names the top criterion and the score gap between #1 and #2.
