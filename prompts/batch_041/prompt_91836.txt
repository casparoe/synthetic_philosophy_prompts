Exam question:
In Plato's Meno, Socrates raises the problem of why knowledge is more valuable than true belief. Explain the problem, reconstruct at least one influential response to it, and evaluate whether that response succeeds. You may use examples.

Student response:
The Meno problem asks why we should care about knowledge when true belief seems to do the same practical work. Plato's example is a person who has a true belief about the road to Larissa and a person who knows the road; both will arrive at the same place. So if true belief and knowledge both get you to the destination, knowledge seems to add nothing. Socrates replies with the image of Daedalus's statues. True beliefs are like statues that run away unless they are tied down, while knowledge is tied down by working out the reason why. So knowledge is more valuable because it is stable and does not escape.

This means that knowledge is more valuable because the tether of justification makes the belief true. A true belief is only accidentally true, whereas knowledge is non-accidentally true, so knowledge guarantees truth in a way that mere true belief does not. That is Plato's answer, and it is basically right.

A contemporary version of this is reliabilism, which says knowledge is true belief produced by a reliable process. This solves the Meno problem because reliable processes like good eyesight or careful reasoning are intrinsically valuable. We value them for their own sake, not only because they produce true beliefs. So even if a true belief is already true, the fact that it came from a reliable process adds value. The swamping objection says that reliability is only valuable because it leads to truth, but that objection fails because reliability is a good-making feature of a belief in the same way that a well-made knife is good even if it never cuts anything.

A virtue epistemology response says knowledge is true belief that comes from intellectual virtue, so the knower deserves credit for having it. This also solves the problem because credit is valuable independently of the truth of the belief. Therefore, either reliabilism or virtue epistemology gives a satisfying answer to the Meno problem.
