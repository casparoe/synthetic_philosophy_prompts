I'm a backend engineer, no philosophy background at all, but I've been reading a lot of mech interp stuff lately and I keep getting stuck on the same question: when someone says "the model represents the concept X in layer 7," what does that even mean, and how would we know? Everyone seems to have their own private standard. Someone trains a linear probe on the activations, it decodes the label with 95% accuracy, and they say the concept is there. Someone else says ok but I can train a probe on a randomly initialized network and get 80% too, so what did you actually show. Someone else has a steering vector that flips the behavior when you add it, and says that's the real evidence because it's causal. And then there's superposition, where there are way more features than dimensions so nothing has its own direction, and polysemantic neurons that light up for like five unrelated things, and the annoying fact that I've trained the same tiny net twice with different seeds and it solves the task with what looks like a totally different internal code. So before I read any more of these papers I want the spec first.

Can you write me the desiderata -- what any adequate theory of "this network represents X" has to actually deliver? Not a definition, a checklist. Concretely I want: which cases it has to get right (the probe that decodes but the network never seems to use it; the probe on a random net; the steering vector that works and the random vector that also kind of works; superposition; polysemantic units; two nets that behave identically but code it differently; and the case where a net solves a task in a way I didn't expect and there's no ground truth to compare against), which puzzles it has to dissolve rather than just talk around, and which distinctions it can't collapse -- like representing X versus merely carrying information about X, representing versus computing, and representing X versus representing X-under-some-description. For each requirement give me the actual case or consideration that motivates it, so I can tell which ones are real constraints and which are just one camp's taste. Also mark which ones you think are non-negotiable and which are preferences.

The part I most want is where the list turns on itself: are any of these jointly unsatisfiable? I have a suspicion that the requirement that a representation be individuated by its causal role in the network clashes with the requirement that we be able to say what it's *about* independent of the network's quirks, but I don't have the vocabulary to say why. And tell me which single requirement does the most to kill off the popular views on offer, because that's the one I'll use to filter everything I read next. Skip scoring the actual theories, I'll do that myself once I have the criteria.
