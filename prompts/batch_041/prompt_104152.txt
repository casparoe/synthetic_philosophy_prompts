I'm a teaching assistant for a graduate seminar in rational choice theory, and I'm grading the second problem on this term's midterm. The problem concerns a construction we covered in week six under the heading of program equilibrium; because the exam was closed-book, the setup was reproduced on the exam sheet, and I'll reproduce it here in the same form. Two players face a one-shot Prisoner's Dilemma with the usual payoffs: mutual cooperation yields 3 to each, mutual defection yields 1 to each, and a player who defects against a cooperator receives 5 while the cooperator receives 0. The players do not choose actions directly. Each instead submits a program; the programs are then run once, each being handed the other's source code as input and returning a single action, cooperate or defect. There is no repetition, no communication beyond the code access, and no third party. We stipulated in lecture that the programs are deterministic, that they are written in a fixed language, and that submitting a program counts as choosing a strategy in the larger game whose strategies are programs.

The question asked students to explain how mutual cooperation can arise as an equilibrium of this game and to assess what, if anything, the construction shows about the rationality of cooperating in the underlying one-shot dilemma. The rubric allocates roughly half the ten points to the mechanics of the equilibrium argument and half to the interpretive question. Here is the answer I have to grade, written by a student who is usually solid and who spent about a page on it:

The natural strategy to consider is the conditional program P: cooperate if the program I am handed as input is identical to my own source code, and defect otherwise. When two copies of P meet, each sees code identical to its own, so both cooperate and each receives 3. Now consider whether either player can do better by submitting some other program Q. Since Q is not identical to P, P will defect against it, so Q's payoff is either 1, if Q defects as well, or 0, if Q cooperates. Either way Q earns less than the 3 it would have earned by sticking with P. Note that a deviation to the program that always defects is punished in exactly this way: the defector does not collect the temptation payoff of 5, because P is not fooled into cooperating with a program that is not its twin. So mutual cooperation is an equilibrium of the program game. Moreover, since deviation is unprofitable and the conditional program is what makes it unprofitable, universal defection is no longer an equilibrium either: a player who is currently defecting can switch to P, and P will cooperate with itself, so the defector has a profitable deviation. It follows that mutual cooperation is the unique equilibrium of the program game, and this is what the construction shows about the original dilemma. The reason two rational players defect in the ordinary Prisoner's Dilemma is that each fears the other's defection; once the players can see each other's strategies, that fear is misplaced, and a rational player should recognize that defection cannot pay. The dilemma is therefore dissolved rather than merely relocated: rationality itself, and not any external enforcement, selects cooperation.
