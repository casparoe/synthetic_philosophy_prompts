Me and a friend keep having the same arguement about the Anthropocene and I've started to think we aren't even answering the same question, so I want to build a little flowchart that sorts out which disagreement we're actually having. Start from stuff we both already agree on — humans have changed the planet plenty, and geologists have some process for officially naming spans of time — then make every branch a question you can answer without knowing which position it leads to. Like: is 'when did it start' a question about what the rocks will show, or about who's to blame and when the damage turned into a crime? Does a stretch of time need one sharp marker that shows up everywhere at the same moment, or can its start be smeared across centuries? If it does need a marker, is the marker a physical layer or a date that people vote on? And who has standing to decide — the people who read the rocks, or everyone who has to live in the thing being named? Put a concrete case under each branch to sort people with: medieval farmers clearing forest, the first coal smoke, radioactive dust from bomb tests — which one, if any, is the moment, and if someone in the year 3000 dug up a layer of plastic would that tell them where the line goes? The leaves should be named positions (starts with farming, starts with industry, starts in the mid-20th century, not a period at all but an event with no single date, just a political label and the geology question is a category error, no such thing so drop the word) with one line each on the worst thing that position has to swallow. Flag any positions the tree can't pull apart and any answer-combos nobody holds, and say whether that's because the combo is incoherent or just unexplored. Keep it to six or eight branch questions.
