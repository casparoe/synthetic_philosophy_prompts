ok so i fell down a rabbit hole on this and i need someone to sort me out.

the story i keep running into is: gödel showed that any consistent formal system that can do arithmetic has a sentence it can neither prove nor disprove, and that sentence is actually true (it says, roughly, that there's no proof of it in the system). and since a computer is just a formal system, then for any computer there's a sentence it can't prove. but a human can look at that sentence and just see that it's true. so no computer can do what we do, so minds aren't machines. i think this is the lucas-penrose argument, or one version of it.

my problem is that the step where the human sees that it's true looks like its being smuggled in for free. when i see that a gödel sentence is true, what am i actually relying on? the sentence is true exactly when the system is consistent. so to get from theres-no-proof-of-this to its-true, i have to already be taking the system's consistency for granted. and a machine can do that much too -- it can prove, no problem at all, that if the system is consistent then the gödel sentence is true and unprovable. it can print that conditional all day long. so the human isnt doing anything the machine cant, unless the human can actually certify that the system is consistent, and not just conditionally.

and thats where i get stuck. if the system in question is me -- if im the formal system, or the machine -- then by the second incompleteness theorem i cant prove my own consistency either. i also cant just assume it, or at least not for free. and honestly ive held beliefs that turned out to contradict each other, so maybe im not even consistent. so it looks like its one of two things:

(a) the anti-mechanist needs me to be consistent, in which case i also cant know im consistent, so i cant reliably pull the seeing-the-gödel-sentence move for my own system -- i just take it on faith, like a machine could be programmed to; or

(b) im allowed to be inconsistent, in which case the seeing is worthless, because an inconsistent system proves everything, so id see the negation too.

i have a nagging feeling im missing the real move though, because the people who push this are usually careful. maybe the move is that i can step outside any particular system to a stronger one, and thats what a fixed machine cant do? but then a machine could just be handed the stronger system, and i could step outside that one, and this never ends -- so the claim has to be that i can somehow do the whole endless ladder at once, and that seems like a big ask. also it feels like the argument only ever refutes one machine at a time: for any given machine theres a sentence it misses. going from that to no machine can do it means i have to already know im not any of the machines, which is the thing we were trying to prove in the first place.
