ok so I've been messing around with a little font project — the idea is to build a whole alphabet out of a handful of recombining strokes, where every letter is some arrangement of the same few curves and straight bits, and the "style" of the font is basically the rules for how those bits get shaped and joined. Anyway it's turned into a philosophy problem and I want a sanity check on where I've landed, because I suspect it doesnt all hang together.

Here's roughly what I think:

1. Being an 'a' is not a matter of degree. A shape either is an 'a' or it isn't — there's no such thing as a shape that's 60% an 'a'. (Sure, some 'a's look more prototypical than others, but looking typical isn't the same as being more of an 'a'.)

2. What makes a shape an 'a' is its abstract structure — the topology, roughly: a bowl with an enclosed counter, a stroke on the right, the relation between them. Not the exact geometry. That's why a double-story 'a' and a single-story one, or Helvetica's and some scrawl, are all 'a's: they share the structure.

3. A typeface's style is holistic. You can't really decide the 'a' independently of the 'g' — how you draw any one letter is answerable to how you draw the rest, or it stops looking like it belongs to the same font.

4. You can't say what an 'a' is apart from a style. There's no free-floating 'a'-essence hovering above Garamond, Helvetica, and a kid's handwriting; 'a'-ness only gets defined relative to a way of drawing letters.

5. A kid learning to read, or an OCR system, can recognize an 'a' in a style it's never seen before — so whatever makes it an 'a' has to be something style-independent.

6. Whether a shape reads as an 'a' can depend on what's next to it — the same squiggle can be an 'a' in one word and something else in another.

Go through these and tell me which ones actually conflict, which only look like they conflict, and how bad each real conflict is. Order them by severity, and for each genuine one say what the cheapest fix is and what it costs me. I'm not especially attached to any single one of these yet, so don't assume which one I'd give up.
