I am preparing a methods module on idealization in scientific modeling. Please rank the following five justifications for retaining assumptions known to be false in a model that is meant to guide intervention, from most to least trustworthy, giving each a score from 0 to 100 and one sentence of justification: (a) Milton Friedman's as-if defense, where predictive success licenses false assumptions; (b) derivational robustness, where the result survives relaxing the assumption; (c) Galilean idealization, where the falsehood is a deliberate simplification meant to isolate a causal factor; (d) fictionalist modeling, where the model is a credible fiction and truth is not the relevant standard; and (e) the assumption-ledger view, on which each false assumption must be paired with an explicit error budget and a specified range of interventions over which it is counterfactually stable. Then, for the two highest-ranked, explain what additional piece of non-empirical information a modeler would need to move from useful fiction to warranted instrument.
