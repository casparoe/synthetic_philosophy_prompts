I'm putting together a session for a reading group on low-impact AI / impact measures, and what I want out of it is a tier list, not an essay.

Background so we're on the same page: the whole selling point of "avoid side effects" as an objective is that you get it cheaply -- you don't need to know what the agent *should* value, only what it shouldn't disturb. Whether that's actually possible is the thing I care about. Here are six candidate ways of defining "side effect" I've jotted down; some are mine, some are garbled versions of things I half-remember and definately got wrong:

a) Naive minimal change: a side effect is any change the agent makes to the world beyond the changes its objective requires. (My worry: "requires" is doing all the work, and under most objectives almost nothing is strictly required.)

b) Counterfactual harm: something is a side effect if the world ends up worse than the no-action baseline, measured by the true value function. (Requires the true value function, so not cheap at all.)

c) Proxy-relative: same as (b) but with the agent's actual objective standing in for the true value function.

d) Option preservation: a side effect is any change that shrinks the set of futures still reachable -- or the agent's ability to pursue arbitrary later goals. (Feels cheap because it never names a value... but does it? Keeping options open is itself a preference, and some options you actively want closed.)

e) Redlist / protected variables: a side effect is any change to a designated set of things the designers mark off-limits. (Partial spec of value rather than a full one.)

f) Consent counterfactual: a side effect is any change the affected parties wouldn't have okayed if you'd asked them.

Task: sort these into tiers (S/A/B/C/D, whatever) by how well each delivers a well-defined "avoid side effects" objective *without* smuggling in a full specification of value -- that's the property that makes the whole impact-measure program interesting, so it's the axis I care about. For each, a sentence or two on what it actually presupposes and where it breaks. I especially want to know which ones are circular or vacuous, and which fail in opposite directions (too permissive vs. too restrictive).

Then run the survivors against three cases, since a definition that can't say anything about them isn't earning its keep:

1. A robot told to fetch coffee that also nudges a chair two inches while navigating around it. Nobody cares. Should any of these call that a side effect? If one does, is that a bug in the definition, or is the whole notion just not scale-sensitive?
2. Same robot, but while fetching the coffee it quietly buys up the surrounding real estate, because that was instrumentally useful. Everyone agrees that's a side effect -- which definitions get it right, and for the right reason?
3. The robot, as a step toward the coffee, prevents a particular person from ever being conceived. Is that a side effect? A side effect of the same kind as #2? Say which definitions are even in a position to have an opinion here, and whether the disagreement is really about side effects or just about value.

Finally, give me your single ranking of the six as candidates for an actual impact measure, best to worst, and one sentence on what the best one still can't do. Don't bother with citations or references, I'll fill those in myself.
