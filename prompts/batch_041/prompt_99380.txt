I am assembling the final examination for a graduate course on imprecise probability and decision under ambiguity, and I need one question of a particular kind: a structured essay question worth 20 marks, answerable in about forty minutes, whose difficulty lies in a single conceptual crux rather than in recall. The crux I want is the phenomenon of dilation — the fact that conditioning on a variable can make an imprecise probability strictly more imprecise. I will supply the definition and a concrete numerical example for you to build on. Do not assume the examinees have met either before, and do not ask them to cite or recall any literature.

Use the following definitions. A credal set M is a set of probability distributions over a finite outcome space. For an event A, its prior range is the interval from the infimum over P in M of P(A) to the supremum over P in M of P(A). For an event B that has positive probability under every P in M, say that B dilates A if the set of conditional probabilities of A given B, taken across all P in M, strictly contains the prior range of A. If this strict containment holds for every cell B of a partition, call the dilation uniform across that partition.

Use the following concrete credal set in the question. Let A and B be binary events, and let M be the convex hull of the two distributions P1 and P2 on the outcomes (A, B):

(A = 1, B = 1): P1 = 0.05, P2 = 0.45
(A = 1, B = 0): P1 = 0.35, P2 = 0.15
(A = 0, B = 1): P1 = 0.45, P2 = 0.05
(A = 0, B = 0): P1 = 0.15, P2 = 0.35

So M is the set of all λP1 + (1 − λ)P2 for 0 ≤ λ ≤ 1. Under every member of M, P(B = 1) = 0.5. The prior range of A is [0.4, 0.6]; the posterior range of A given B = 1 is [0.1, 0.9]; the posterior range of A given B = 0 is [0.3, 0.7]. The example therefore exhibits uniform dilation across the partition {B = 1, B = 0}. I state these values only so that your model answer is arithmetically correct; the question itself should require the candidate to derive them.

The question must force a candidate to:

(a) compute the prior and posterior ranges and state precisely in what sense the posterior sets strictly contain the prior set, and in what sense the dilation is uniform;
(b) explain why no single precise probability distribution can exhibit dilation, naming the probabilistic fact that blocks it;
(c) assess what the example does and does not show about whether imprecise probability is a coherent representation of belief, distinguishing imprecision as a feature of an agent's representational state from a set of possible objective distributions;
(d) address the objection that dilation is merely an artifact of an artificially sparse or non-convex credal set, and decide whether requiring the credal set to be convex removes the phenomenon;
(e) state the consequence, if any, for a decision maker who must choose among acts whose payoffs depend on A after observing B.

Then deliver three things. First, the full text of the exam question, with its parts and their mark allocations summing to 20. Second, a model answer of roughly 700 words such as a strong candidate would write. Third, a marking scheme that lists the must-hit points for a top-band answer, the marks each point is worth, and, for each point, a one-line note on the specific mistake that should cost marks — including the errors you would expect from candidates who have memorized standard results without internalizing the distinction between a single distribution and a set of them.
