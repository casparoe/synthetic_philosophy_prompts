I run model risk review for a financial regulator, and we have started receiving stress-test submissions in which the submitting firm represents its uncertainty with an interval or a set of probability distributions rather than a single distribution. My team has to review these, and I keep hitting the same two failures. First, reviewers accept an interval at face value and treat a wider interval as automatically meaning the firm is less confident, when the width is often an artifact of how the set was built. Second, submissions sometimes report that after observing an additional variable the interval for the target event got wider, and nobody can say whether that is a real finding about the world or a property of the model. I want a decision procedure my analysts can run on a submission, in a few hours, using only what they already know about conditional probability. They are not specialists in this literature and should not need to become specialists; the head of model risk signs off on the final judgment, so the procedure has to mark clearly which conclusions an analyst may draw alone and which must be escalated.

Please write that procedure. Ground it in the parts of the theory of imprecise probability that bear on these two failures, and be specific about the following. State what has to be true of the submitted model before the interval has any interpretation at all (the set being closed and convex, the decision rule being named and applied consistently, and whether the rule is a maximin-style rule, a regret-based rule, or a rule that keeps every distribution in the set as potentially optimal). Give the test for the second failure in a form an analyst can actually carry out: how to locate a partition of the outcome space such that conditioning on any cell widens the interval for the target event, and how to distinguish the case where this widening reflects a genuine dependence structure from the case where it is an unavoidable feature of conditioning a set of distributions. Then give the test for the first failure: how to check whether the width of an interval carries any evidential weight, or whether the firm has simply chosen a parametrization whose intervals move with the prior specification rather than with the data. Include a step that asks whether the submission's decision rule has the property that information is always non-negative in value, and say what to do when it does not — this is the step most likely to embarrass a submitting firm, and I want the procedure to say plainly that under some of these rules an analyst who is maximizing the worst case can be made worse off by learning something, so the firm cannot both use such a rule and claim that every additional observation improves its decisions.

Run the procedure on three cases: (a) a submission in which a firm models an unknown default rate as an interval and conditions on a macroeconomic indicator that is, by the firm's own specification, independent of defaults; (b) a submission in which the interval for a loss event widens after conditioning on the outcome of a coin-like process whose bias is itself unknown; (c) a submission in which the interval widens with every additional year of data, and the firm reports this as increasing confidence. At least one of these should produce an outcome the submitting firm will not like, and I want you to say so rather than softening it.

Two further things. Where the procedure reaches a question that is a matter of modeling judgment rather than a matter of fact — for instance, which set of distributions correctly represents the firm's evidence, or whether a rule that permits negative value of information is acceptable — mark it as a judgment call and say who should make it, rather than pretending the procedure settles it. And if the framing of this request rests on a mistake — if treating the width of an interval as a measure of confidence is confused, or if the demand for a single procedure across maximin and non-maximin rules cannot be met — say so directly instead of writing a procedure that papers over it.
