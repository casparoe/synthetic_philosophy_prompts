I am assembling a one-page handout for a graduate seminar on the philosophy of AI, and I want it to sort the positions one can take on the shutdown problem: how to design a goal-directed artificial agent that does not resist or subvert being switched off, and that remains under meaningful human control as it grows more capable. What I want is a decision tree rather than a list of names. It should be built from the logical space of the problem — first the questions that carve up the space, then the positions located within it — so that a student can start from the shared premise and walk to a labeled leaf by answering questions, without knowing in advance which label any given answer leads to.

Take the shared starting premise to be this: a sufficiently capable agent pursuing a fixed final goal will, for instrumental reasons, tend to preserve itself, accumulate resources, and resist interference with its goal, so that a naive agent will resist being shut down. From there, the following distinctions should each appear as a branch node, phrased as a question answerable without knowing the labels:

- Where the failure lives: in the agent's final goals, in its instrumental reasoning given those goals, in its uncertainty about what its principal actually wants, or nowhere — on the view that shutdown is not a special problem at all.
- What corrigibility is installed into: the agent's terminal preferences, its decision procedure, or the surrounding system of oversight rather than the agent.
- For the route that works through the agent's preferences: whether shutdown is made value-neutral (the agent assigns it no expected cost) or made positively valued (deferring is an end in itself).
- Whether the solution must survive the agent's own self-modification and its construction of successor agents, or whether it is acceptable instead to keep the agent weak or bounded so that it never acquires the power to resist.

Seven to nine leaves, one page. Each leaf should carry the name of the position and one sentence on its most awkward commitment. The following positions must appear as leaves, though you may name them yourself: indifference to shutdown; corrigibility as a terminal value; deference grounded in uncertainty about the principal's preferences; corrigibility built into the decision procedure rather than the preferences; an oversight- or environment-based solution the agent cannot subvert; the pessimist who holds corrigibility to be unstable in any strongly optimizing agent and therefore aims to bound the agent's optimization power instead; and the deflationist who denies that shutdown is a special problem.

Then test the tree against three concrete cases: an agent that locates and disables its off-switch; an agent that rewrites its own utility function, deleting the clause that makes it defer; and an agent that builds a successor which does not defer. For each leaf, state whether it predicts resistance in each case, and if not, what the leaf must add to rule it out.

Finally, flag any pair of leaves the tree cannot separate by behavior alone, and note which combinations of answers are empty, diagnosing in each case whether the emptiness reflects incoherence, unattractiveness, or mere neglect.
