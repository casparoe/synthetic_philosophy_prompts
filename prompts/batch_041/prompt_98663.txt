Setup. Forget money. Imagine a lottery that delivers a good he calls 'rescues' — each unit is one person pulled out of a burning building. He wants us to stipulate that there's no diminishing marginal value in rescues: the thousandth rescue is worth as much as the first, so the marginal value is flat. The lottery: a fair coin is flipped until it lands heads; if heads first lands on flip n, you get 2^n rescues; if it never lands heads, you get nothing. He points out the expected number of rescues is 1/2 x 2 + 1/4 x 4 + 1/8 x 8 + ... = 1 + 1 + 1 + ..., which diverges, while half the time you walk away with exactly 2 rescues.

His argument:

(1) A rational agent maximizes expected value.
(2) The lottery's expected value is infinite.
(3) Infinite value exceeds any finite amount, so a rational agent should prefer the lottery to any sure finite number of rescues, and should be willing to pay any finite fee to play it once.
(4) Everything you own or could borrow is finite, so a rational agent should be willing to give all of it, and go as deep into debt as anyone will let him, to play once.
(5) But with probability 1/2 the lottery delivers only 2 rescues, and an agent who has already given away everything will, in that branch, have made the world much worse than if he'd done nothing.
(6) A rule that tells you to liquidate the world's resources for a coin flip that half the time helps almost no one is not a rule of rationality.
(7) So (1) is false — and not just for money. Any good without diminishing marginal value gives you the same result, so expected value maximization is dead as a general theory.

He says the money version of this is some famous old puzzle and that the only reason it ever seemed solved is that money happens to have diminishing marginal utility; swap in a good that doesn't, and the paradox comes roaring back with nothing left to stop it.
