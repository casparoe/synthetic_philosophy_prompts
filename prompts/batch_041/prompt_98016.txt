Ok so I've been going down a rabbit hole on the Russell paradox era, and I want to do something with it that isn't the standard "naive comprehension is inconsistent, so eventually we got ZF and everyone lived happily ever after" story. I already know that story. What I want is a case analysis where the theory and the episode actually push on each other.

Here's the episode as I've got it, correct me if I'm wrong: Frege is basically done with the second volume of the Grundgesetze when Russell writes to him in 1902 pointing out the paradox, and the thing that breaks is Basic Law V, which let you assign an extension to every concept you could define. Frege sees the problem immediately, bolts on an appendix acknowledging it, and the logicist project basically dies there. Then you get two pretty different diagnoses of what went wrong. One is Russell's: the trouble is circularity, you're defining a collection by quantifying over a domain that already includes the thing being defined, so the definition is vicious and illegitimate — hence ramified type theory and all the pain that came with it. The other is the size-flavored diagnosis that ends up in Zermelo: the trouble isn't circularity at all, it's that some collections are simply too big to be sets, so you throw out unrestricted comprehension and keep only separation — you carve subsets out of sets you've already got. And those two diagnoses are not the same thing wearing different hats. The circularity one would also rule out a bunch of stuff Zermelo is perfectly happy with, and Zermelo's doesn't care about circularity, it cares about size.

What I want from you is to run the episode through one of those lenses and then run it back the other way. Take the vicious-circle diagnosis first: say what it claims actually happened, what it says Frege should have done differently, and then be honest about which parts of the actual recovery it can and can't account for — separation, the cumulative hierarchy, the fact that ZF became the default and Russell's type theory didn't. Then do the same with the limitation-of-size diagnosis. And then tell me which one the history actually vindicates, if either, or whether the honest answer is that the field settled on a fix that quietly stopped asking the question Frege and Russell were asking.

One more thing I'd like folded in, because I think it stresses the framing: Quine's New Foundations in the late thirties keeps something that looks a lot like naive comprehension and only restricts it by stratification. If that's right, does it break the neat two-diagnosis story? Which diagnosis does NF count as a version of, if any?

Two things I don't want. I don't want the "and this just shows why rigor matters" moral, and I don't want you to tell me the two diagnoses are secretly the same once you look closely.
