Question. Accuracy-first epistemology holds that the sole fundamental epistemic good is the accuracy of an agent's credences, where accuracy is measured by a scoring rule: a function that assigns a score to each credence function at each possible world, higher for credence functions closer to the truth at that world. A scoring rule is strictly proper if, for every credence function, that function's own expected score is strictly greater than the expected score of any other credence function.

(a) Explain how a dominance argument is supposed to establish Probabilism — the requirement that an agent's credences satisfy the axioms of probability — and how an expected-accuracy argument is supposed to establish Conditionalization.
(b) State one standard objection to the accuracy-first program and assess it.

Answer. Accuracy-first epistemology takes accuracy to be the only fundamental epistemic value and tries to derive the standard norms of credence from it. Accuracy is measured by a scoring rule, and the crucial constraint is strict propriety: if the rule were not strictly proper, an agent's expected score could be maximized by credences other than her own, and then accuracy could not play the foundational role the program assigns to it.

The dominance argument for Probabilism begins with any credence function that violates the probability axioms. For each possible world there is a probability function that scores at least as well at that world, and at some worlds strictly better. So the incoherent credence function is no more accurate than some coherent rival whatever the world is like, and strictly less accurate at some worlds. Since a rational agent will not adopt a credence function that is guaranteed to be no better than an available alternative, Probabilism is vindicated. The argument is in effect a Dutch book argument: it shows that an agent with incoherent credences is committed to a set of bets on which she is bound to lose, and it is that guaranteed loss that makes the credences irrational.

Strictly speaking, though, the dominance argument does not escape the need for expected-accuracy maximization. For the fact that a rival credence function would have scored better at the actual world to give the agent any reason to change, she must already be committed to maximizing expected accuracy; so the dominance argument and the expected-accuracy argument rest on the same underlying premise.

The expected-accuracy argument for Conditionalization has a different form. Suppose you are certain that you will learn E and nothing more. Consider the credence functions you could adopt on learning E, and compute the expected accuracy of each, taking the expectation with respect to your current credences conditional on E. The function that uniquely maximizes expected accuracy is the one obtained by conditionalizing your current credences on E. So Conditionalization is the rule an expected-accuracy maximizer will follow. Like the dominance argument, this one requires a strictly proper scoring rule, and it additionally requires that the agent maximize expected accuracy.

(b) The standard objection is that accuracy is a grading notion rather than a normic one: a scoring rule tells you how well a credence function is doing relative to the truth, but it does not by itself tell you what you ought to believe. To get from accuracy to a norm, the accuracy-firster needs a further premise connecting the two, and that premise is precisely what is in dispute. I take this to be a serious challenge rather than a refutation: it shows that the program is incomplete as stated, since the normativity of accuracy has to be assumed rather than derived, but it does not show that no accuracy-based account can be given.
