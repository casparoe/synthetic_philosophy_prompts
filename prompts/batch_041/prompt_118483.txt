I'm applying for a summer research stipend my department runs (two pages, they fund six or seven of us, deadline's the end of the month) and I want to pitch something on the Pasadena game, which I cant stop thinking about since a seminar discussion went off the rails. Setup in case it's not familiar, since I keep having to draw it on napkins: you flip a fair coin until it comes up heads for the first time; if that happens on toss n you win 2^n/n dollars when n is odd and lose 2^n/n dollars when n is even. If you add up the toss-by-toss expected contributions you get 1 − 1/2 + 1/3 − 1/4 + ..., which converges, but only conditionally — the sum of the absolute values blows up — so the total you get depends on the order you add the outcomes in, and with a clever enough ordering you can make it come out to any real number you like. The usual verdict is that the game has no determinate expected value. And the all-positive version (same payoffs, no sign flip) dominates it outcome by outcome and has an expected value of +∞, which is somehow worse. Two friends of mine have been going at this for weeks: one says it's a freak of infinite series with no philosophical content, the other says it shows expected utility theory is a wreck. I think there both wrong, and I want the proposal built around my half-formed idea.

The idea: the puzzle isn't really about infinity or about 'undefined' values. Adding up outcome-values presupposes an order in which to add them, and in this game the toss number is a bare label — nothing about the decision problem privileges adding toss 1's contribution before toss 2's. So 'no determinate value' should be read as 'no value invariant under reordering the outcome space', which is a claim about symmetry rather than about size. That makes the real question: when IS an ordering privileged? Time is the case that interests me. In an infinite-horizon consumption or population problem the temporal order isn't a bookkeeping convention — so if the total depends on the order of summation there, that looks like a real feature of the situation, whereas in Pasadena it's an artifact of how we wrote the list down. I want to argue that we should stop asking 'does this gamble have an expected value' and start asking 'does this decision problem come with a canonical way of aggregating its outcomes', and that the answers diverge in exactly these two cases — which is why the same mathematics reads as a paradox in one place and a technicality in the other. (There's also a variant I invented to test the machinery, I've been calling it the Sierra Madre game: same coin, but the payoff is 2^n/n when n is odd and −2^n/(n+1) when n is even. I haven't worked out whether its series is conditionally convergent or outright divergent, and part of what I want the proposal to do is say what the method predicts in either case.)
