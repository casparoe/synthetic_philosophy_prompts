The researcher concludes that the network represents car-presence in that layer. And here's the student's answer, typed up as written:

"The researcher's inference is too quick. Decodability isn't use: a linear probe can read out information that the network never relies on for its output, so 97% probe accuracy on its own doesn't show that the network represents car-presence. The randomly-initialised control does rule one thing out, though — it shows the information isn't just sitting in the input and getting passed through — so training really did put something into the middle layer in a form a simple linear map can read. What would settle it is an intervention: if I ablate the direction the probe found, or steer along it, and the network's behaviour changes in the way I'd predict if it were using car-presence, then the feature is not merely decodable but causally used. A probe is only a lens, it doesn't add information to the network, and we prefer linear probes precisely because a simple probe can't be inventing structure that isn't there. So the linear probe is already doing the causal work, and the intervention is really just confirming what the probe has told us. There's a deflationary line that says 'representation' is just a useful fiction and we should only talk about what the network does, not what it represents; the critic's point and this line are basically the same move, both saying the representation-talk is doing no work. I don't think that can be right, because the point of interpretability is to recover the network's own internal vocabulary, so we have to read representation-talk literally. On balance the researcher is closer to the truth and the critic is wrong: the critic's worry that the probe might be doing the work is answered by the fact that a linear probe has no hidden layers, so there's nothing in it that could be doing the work."
