Two camps in the foundations of quantum mechanics have argued past each other for decades: those who hold that the quantum state represents physical reality (psi-ontic) and those who hold that it merely encodes an agent's information or beliefs (psi-epistemic). Draft the joint statement they could both sign after a good-faith adversarial collaboration. Treat these distinctions as available to both sides, so that neither need concede anything in order to use them: the senses in which a state might count as real — causal difference-maker, item in the world's basic furniture, indispensable to our best explanation; the state as vector, as ray, as density operator, and whether a global phase can mark a difference in reality; and whether the dispute survives if the state is read as law-like rather than thing-like, or if realness is relativised to a system or an observer. Work through two questions I take to be cruxes: whether two physically distinct preparations that yield the same state must agree about the underlying facts, and whether there is a fact of the matter about the state of a single system that is never measured, as against facts only about ensembles. Return the statement as exactly five numbered items, with no introduction and no conclusion, each item a sentence or two: the claims both sides can sign; the residual disagreements, each in wording its own side would accept; the cruxes; for each crux, the case, argument or protocol both sides would accept as bearing on it, with each side's prediction stated in advance; and your verdict on which part of the dispute, if any, is merely verbal, with reasons.
