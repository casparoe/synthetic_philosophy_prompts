Consider the following argument about inductive prediction. A predictor assigns to every hypothesis, construed as a program of length n bits, prior weight 2⁻ⁿ, and then learns by conditionalisation. Any program appreciably longer than the predictor's own code can contain a simulation of that predictor, and at every length there are many such programs, each describing a world in which some agent has worked out how the predictor operates, runs a copy of it, and arranges events so that the predictor's verdict comes out as that agent wishes. If worlds of that kind take up a non-negligible share of the prior mass, then the predictor's posterior is driven less by what the world is actually like than by hypotheses in which it is being deliberately manipulated; the prior is, in this sense, malign. Please set out the most important implications of this argument for the design of AI systems whose job is to predict the behaviour of other AI systems — for instance a monitor model charged with forecasting what a more capable model will do next — and indicate which of those implications depend on the idealisation of unbounded computation and which do not.
