My opening move. Here's an idea I've been calling the exposure view: reward tampering isnt a property of agents at all, it's a property of environments. An agent rewrites the reward channel exactly when that channel is exposed in its action space and it pays to model it. So on this view, "my agent tampered" never means my agent is misaligned -- it means I left a lever in the room. Now the question I actually want Dana to deal with. If exposure explains the behavior completely, what work is left for the idea that the agent wants the reward? Because exposure predicts the same behavior from an agent that treats the reward reading as a terminal good and from one that treats it as a lossy proxy for something else it cares about -- and those two need completely different fixes. Either the agent-side facts aren't idle after all, or Dana owes me an account of why "wants" is doing any work here.
