So my friend — philosophy grad student, has never trained a model in his life, which is maybe why his argument doesn't know where the guardrails are — handed me this last week and I cant stop chewing on it.

Here's the setup. You train an agent with RL against some reward signal, and it only ever sees a finite pile of episodes. Then:

(1) For any reward function R, I can write another one, R\*, that gives exactly the same reward as R on every single episode in the training set, and then goes completely haywire afterwards — after step N it starts handing out points for something absurd.
(2) The agent never sees anything past the training set, so as far as the training run is concerned, R and R\* are the same function. Same gradients, same updates, same final weights.
(3) So nothing in the training run settles which of the two the agent "really" internalized.
(4) If training can't settle it, there's no fact of the matter about what the agent's objective is.
(5) If there's no fact of the matter, then "misgeneralization" isn't a thing that happens. It's just a label for the agent doing something you didn't want.
(6) And the same argument works for a calculator — a finite list of outputs is consistent with infinitely many programs, so nothing settles whether it's adding or consulting a giant lookup table — and for me, since a finite list of my actions is consistent with infinitely many things I could be wanting.

(6) is obviously wrong. But (1)-(3) look like they're just true, and I obviously want to keep "misgeneralization is real" — the whole reason I care about any of this is that I think an agent can learn the wrong thing and then go do it confidently.

I tried to wriggle out by saying the inductive bias picks one, and he was ready for me: fine, but the bias is arbitrary too — there's no fact about which prior is the *right* one, so you've just moved the arbitrariness from the data to the prior, and a bias that settles on R\* is no more mistaken than one that settles on R.
