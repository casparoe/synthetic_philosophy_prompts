Hofstadter's big move, as I understand it, is that this kind of self-replication is isomorphic to Gödel's self-referential construction: in both cases you set up an arbitrary code (Gödel numbering, the genetic code), and the code is what lets a system of dumb syntactic shuffling end up referring to itself. DNA is supposedly the real-world instance — a strange loop made of chemistry. If I've mangled either the logic or the biology, flag it.
