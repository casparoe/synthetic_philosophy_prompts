Me and a friend have been going back and forth about the "AI control vs. alignment" thing and he handed me this argument, which I'm pretty sure proves way too much but I can't say exactly where it breaks. (1) A control measure is anything that constrains what a model can do -- sandboxing, no internet access, a monitor reading its outputs, a human approving each action, using one copy of the model to watch another copy. (2) A control measure only counts as a safety measure if it holds up when the model is activly trying to get around it; if the model can talk its way past the monitor or find the one gap in the sandbox, the measure was theater. (3) Whether a model can get around a given measure depends only on how good it is at finding gaps and how hard it's looking. (4) Now take the case control is supposed to cover: the model is misaligned and much smarter than us. Then it finds the gap. Maybe not todays gap, but every fixed measure has one and it'll get there. (5) So the only thing that keeps a measure holding is the model not trying to get around it -- which is just what we mean by the model being aligned on that point. (6) So every control measure is either defeated by the model it's meant to contain, or is secretly relying on alignment. (7) So "we can be safe with a misaligned model as long as we control it" is empty, and control work is either a stopgap or alignment research with extra steps. I'd like to keep (2) if I can, it feels like the whole point of the control idea. Which step do I give up, and what does giving it up actually cost me -- do I lose the thing that made control interesting in the first place? I also can't tell whether the problem is a bad step or just a premise I don't want to pay for, so say which it is and why.
