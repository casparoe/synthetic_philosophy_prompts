I'm setting the final for a 400-level course I run on complexity theory and epistemology, and I want one essay question that students can't answer by paraphrasing "P vs NP is about whether creativity can be automated." The crux I want them to hit is that complexity hardness is a claim about familys of instances in the limit, not about any particular instance — and that "no efficient algorithm exists" is not the same claim as "we can't prove that no efficient algorithm exists." Build the question around a thesis I'll state in the exam itself, roughly: "Finding a proof is only hard because we don't yet know how. If P = NP then discovery becomes routine; if P ≠ NP then there are truths no efficient reasoner could ever reach." They should have to say which parts of that are true, which are confused, and why. Two things I want them to have to notice on their own: (i) that for NP problems, deciding and searching are basically the same task up to polynomial factors, so the thesis can't cleanly separate "recognising" from "discovering"; (ii) that a polynomial algorithm with an astronomical constant or exponent would settle the math and change nothing about practice, so "tractable" doesn't follow from "in P". Give me the question (90 minutes, one page), a model answer around 700 words, and a marking scheme with five must-hit points totalling 20 marks and, for each, the one-line way students typically blow it. Start with the exam question itself, no preamble.
