I've been messing around with the typogenetics stuff and I've talked myself into a stronger claim than I think Hofstadter meant: that the DNA–Gödel isomorphism isn't just an analogy but a genuine constraint — that any system which actually copies itself has to carry a description of itself held apart from the machinery that reads that description, and that this description/reader split is the same move as encoding a formal system inside itself. Self-replication without the split, on this view, is impossible in principle, not just unknown.

So what would count against it? I dont want reassurance, I want the defeaters, ranked by how much they should actually move me. Which real replicators are the dangerous ones — autocatalytic sets, growing crystals, prions, von Neumann's kinematic self-reproduction — and which of those genuinely break the claim versus only looking like they do because I've drawn the description/interpreter line too loosely? Does the whole thing collapse because Gödel is about provability while this is about construction and computation? And what's the defender's concession here — is there something a committed version of the view would itself have to admit counts against it? Finally, be straight with me: has this been qualified into unfalsifiability, and if so is that fatal or just the cost of a view this abstract? If I'm basically restating the universal-constructor point in fancier clothes and 'description' is doing no real work, say that instead of playing along.
