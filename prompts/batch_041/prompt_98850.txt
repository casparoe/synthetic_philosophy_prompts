ok so i've been reading about approval-directed agents as an alternative to goal-directed ones and i think i mostly get the idea: instead of giving the AI a terminal goal like "maximize paperclips," you train it to just do whatever a human overseer would approve of. so its only "objective" is human approval, which is basically us, so it can't really go off and do its own thing. which makes me wonder if the orthogonality thesis is kind of dead? like the whole point of orthogonality was that you can bolt any insane final goal onto a superintelligent agent and the intelligence level tells you nothing about the goal. but an approval-directed agent doesn't have a final goal at all, it just has "do what they'd approve of." so it seems like approval-directedness is a live counterexample to orthogonality, and if we just build approval-directed agents we've more or less dissolved the alignment problem. why isnt this the consensus? whenever i bring it up people just say "approval is a goal too," which feels like a cheap gotcha. am i wrong that there's no objective being optimized here? and concretely — can an agent that only ever wants a thumbs up still end up doing something horrifying, and if so whats the actual failure story, not just "it games the approval"?
