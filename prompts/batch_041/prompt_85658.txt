The setup:

- Both are running "the same" decision procedure in a loose sense — not identical code, but similar enough that each can simulate the other pretty well, and both know that. Call how similar they are the mirroring level: 0 = total strangers, 1 = literally the same program.
- Each picks C or D, simultaneously and independently. One-shot, no repeats. Payoffs: both C = 3 each; both D = 1 each; one plays D and the other C = 5 to the defector and 0 to the cooperator.

- Before play, either agent may run a "commitment routine" that rewrites its own utility function by adding an extra term. A "surrogate goal" is my name for the result: a goal the agent wasn't born with, adopted only because having it makes some threat of its believable. Specifically A can add the term "+6 to A if A plays P and B played D".
- Nobody can lie about whether they ran the routine: it's in the code, and the code is readable/simulatable by the other side.
