"Hofstadter's central move is to take the structure of Gödel's proof and treat it as a template for the self. Gödel showed that you can encode statements about a formal system inside the system itself, so that the system can in effect talk about its own sentences. By a clever diagonalization, one can build a sentence that says of itself that it is not provable in the system. This sentence cannot be proved if the system is consistent, and it cannot be disproved either, so the system is incomplete. Hofstadter's insight is that this is exactly the shape of self-reference: a system reaching around to represent itself. He calls this a strange loop, and he proposes that the human self is a strange loop of the same general kind, arising when a brain's representations become rich enough to represent the brain itself. The self is not an extra ingredient added on top of the neurons; it is the pattern that emerges when the system models itself.

From this, Hofstadter draws the conclusion that no formal system can capture the mind. The Gödel sentence is a case where we can see the truth of something the system cannot prove, so there is always a step we can take that the system cannot take. Since a mind can always take that step, the mind cannot be identified with any formal system. This is essentially the argument made by Lucas and later by Penrose, and Hofstadter endorses it as the payoff of the Gödelian analogy. The reason this matters for the self is that the self is precisely the thing that can always outrun its own formal description, which is what makes it more than a machine.

The one place I would push back is that the analogy seems to depend on the Gödel sentence being a genuine contradiction, like the liar paradox. If the sentence were really a contradiction, the system would be inconsistent rather than incomplete, and that seems like a different situation. So I think Hofstadter is on solid ground about the strange loop but on shakier ground when he uses it to prove that minds are not machines."
