I hold that a rational agent's credences need not be sharp: a body of evidence can leave one with a set of admissible probability functions rather than a single privileged one, and this is a stable resting place rather than a defect to be repaired by introspection or by some further principle of indifference. I want an honest map of the view's exposure. Take the strongest version of it -- a set of credences is a genuine doxastic state with its own norms, not a vague report of a sharp state the agent cannot articulate.

What would count against it? Rank what you give me from fatal to merely awkward, and separate the costs the view's own defenders would concede from the refutations only its critics allege.

I am particularly interested in whether the following pressures can be absorbed, and at what price.

First, action. If a set of credences is to be a full state of opinion, it must guide choice; but every rule for choosing among the functions in the set seems to do one of two bad things -- smuggle in structure the evidence does not license, or collapse into a sharp rule with extra steps. Is there a rule that avoids both, and if not, is the problem the rule or the set?

Second, the sequential cases. I understand that under some natural rules, an agent can be led through a finite sequence of bets, each acceptable by the agent's own lights at the time it is taken, to a position worse under every function in the set than where it began -- and that this can happen even when the agent foresees the whole sequence. I want to know whether this is a genuine inconsistency in the view or an artefact of how the bets are packaged, and whether the escape is to restrict the decision rule, to refuse the sequence, or to give up the set.

Third, learning. Suppose the agent conditionalizes function by function. Is it true that there are cases in which the agent judges two quantities independent and yet learning the value of one widens its interval for the other, so that it becomes less confident about one coin after watching a different coin? If so, does that count against imprecision itself or against a particular way of modelling independence and evidence? And if the only way to block it is an extra assumption that sharpens the interval, say so plainly.

Here is the case I keep returning to, and I would like you to use it as a test. An agent's evidence leaves exactly two functions admissible, one on which a coin falls heads with probability 0.4 and one on which it falls heads with 0.6; nothing privileges either. A bookmaker, knowing this, offers a long finite sequence of bets, each of which the agent can accept without violating either admissible function, yet the sequence as a whole leaves the agent poorer under both. The agent sees the whole sequence in advance. Did the agent act irrationally? If not, what does that show about the demand that a doxastic state rationalize action? If so, what exactly was the error, and can it be avoided without making the state sharp?

Then the meta-question, which matters to me most: has this position been qualified into unfalsifiability? Because it is permissive where sharp probabilism is restrictive, it may accommodate almost any result by widening or narrowing the set. What would a decisive defeat even look like? Is there a finding that should make me abandon the set-valued state altogether, as opposed to adjusting which states count as admissible?

What I would personally find most persuasive is a demonstration that any set-valued state can be replaced by a sharp one with no loss in the agent's ability to act, learn, or be criticized -- that would make the extra machinery idle. If you think that is the wrong thing to be moved by, tell me what is.
