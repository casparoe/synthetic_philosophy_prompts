I have been reading rationalist blogs and the alignment-adjacent interpretability literature for years, and I keep running into the same gap: nobody states cleanly what would have to be true for a claim of the form "this trained network represents property P" to be warranted. Before I read another paper that infers a representation from a probe or a feature dictionary, I want the specification. Set out the desiderata for an adequate account of neural representation — the cases it must get right, the distinctions it must not collapse, and the results it must stay consistent with — giving the consideration behind each requirement and marking which are non-negotiable and which are commitments of a particular camp.

Write it for a specific purpose: I want to take a real trained network, poke at it with the tools I actually have (probes, ablations, activation patching, feature dictionaries), and decide whether a claimed internal representation is real. So the account has to be usable on a black box; an account that only works if I can read the source code or the mind is not what I am after. I am also suspicious of any criterion that makes the question come out trivially true or trivially false.

Cases I want handled, and I would rather see the requirements motivated by these than stated abstractly:

- a single direction that is decodable for two unrelated properties, or a feature whose activating inputs look like an uninterpretable grab bag, so that no single content is the natural reading;
- an internal state that a linear probe reads accurately but that ablation shows the network does not use, and the converse, a state the network plainly uses but that no probe decodes;
- a state that is used only to modulate confidence rather than to carry content;
- a student network trained on a teacher's outputs that ends up with an internal variable it never needed for its own task;
- a network trained on data generated by an algorithm we can read, so that the ground-truth intermediate quantities are known and can be compared;
- a network whose internals amount to a faithful simulation of a physical system it was trained to predict;
- two networks with identical behavior and different internals, or a rotation of one network's internal basis that leaves behavior fixed.

Distinctions I do not want collapsed: having information about P versus representing P; representing P versus computing with something that merely correlates with P; a representation that is genuinely distributed versus one that is only an artifact of the probe; the content of a state versus its causal role.

Results it must not contradict: that behavior can be preserved under internal permutation or rotation; that a sufficiently flexible probe can decode almost anything; that internals can change while behavior stays fixed; and that a network can be trained on fictions, so content need not be inherited from a real referent.

Tell me which requirements are genuinely necessary and which are the prejudices of one camp, whether any pair of them cannot be jointly satisfied, and which single requirement excludes the most candidates. Then, briefly, where the main families stand against the list — probing as ground truth, dictionary or sparse-coding decompositions, interventionist accounts, and the eliminativist line that we should drop representation talk altogether. Keep the weight on the criteria; I will do my own scoring if I need it.
