A friend in my reading group keeps pushing this and I cant tell whether it's a trick or a real problem.

(1) A thing deserves moral consideration just in case there's something it's like to be it; if there's no experience going on, there's nobody home to be wronged.
(2) Having an experience is just having the right kind of information processing going on, so a system with the same functional organization as a creature that feels pain feels pain, whatever it happens to be made of.
(3) What matters is the organization, not the material, so the same program can be running in a brain, in silicon, or in anything else, provided the parts are hooked up to each other the right way.
(4) Any physical system can be mapped onto the state-transitions of any finite program, if you get to choose the mapping. Take a rock, list its states in some order, call the first one state 1 and the next one state 2, and nothing in the rock resists the assignment.
(5) So the rock is running the pain program, and so is every other lump of matter, running every program there is, including the one that is me.
(6) But I don't owe the rock anything, and if every lump of matter is a subject of moral concern then nothing is.

I really want to keep (1) and (2) — they're the only reasons I have for caring about a system whose insides I can't inspect. So which step do I give up, and what does giving it up cost me? If it helps: think of a block of ice with a state-transition table carved into it, one row per region, so there's a mapping from parts of the ice to states of the program but nothing in the ice is happening; or a machine that passes through the states in the right order by sheer coincidence, with no causal link between one state and the next.
