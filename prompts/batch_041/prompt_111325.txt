For a certification body I oversee technical assessment: applicants submit safety cases as trees of claims, each claim supported by sub-claims and bottoming out in tests, standards, and engineering judgement, and we keep relitigating the same dispute. Assessors demand support for the bottom nodes; applicants reply that those nodes are basic and that the demand is endless; our board says the case should be judged as a whole, by whether it hangs together. Please write a decision procedure that turns the debate about the regress of justification — foundationalism, coherentism, infinitism — into something an assessor can run on any case: the questions to ask in order at each node, what counts as a sufficient answer, where the procedure stops with a no, and where it hands the decision to the board because what is at issue is how much risk we will accept rather than what is true. It must be usable by engineers with no philosophy training, run in two days on a case with a few hundred nodes, and leave a written record a board can sign off on or overturn.

Have it distinguish a node that is terminal because of what it is — a definition, a stipulation, a measurement traceable to a national standard — from one that is terminal only because the applicant stopped there, and have it treat every unsupported node as a promissory note, saying when the note must be discharged, when it may stand so long as the applicant can extend the chain on demand, and when a set of nodes supporting each other only in a circle is acceptable. Then run it on three nodes: a claim resting on a calibrated sensor specification; a claim resting on a simulation and a validation report that each cite the other; and the claim that the operating environment will contain no unmodelled pedestrians, which the applicant can always support further but never finally. Finally, say where the procedure returns an answer applicants will hate, and where it fails — in particular whether it can distinguish a case that is justified from one that is merely internally consistent, and if not, what the board is really deciding when it signs.
