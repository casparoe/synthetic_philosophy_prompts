I have been trying to reconstruct, for a seminar, an argument that opens as the familiar refutation of unrestricted comprehension and closes somewhere I am not willing to follow. Reconstructed as charitably as I can, it runs like this.

(1) For every predicate with one free variable there is a set whose members are exactly the things that satisfy it.

(2) Apply (1) to the predicate that holds of a thing just in case it is not a member of itself. There is then a set R whose members are exactly the things that are not members of themselves, and by the terms of (1), R is a member of itself if and only if it is not.

(3) Classically, either R is a member of itself or it is not; on either branch we get both that it is and that it is not. No set can be in that position, so R does not exist.

(4) The fault must lie with the predicate in (2). R is picked out by reference to the whole of which it would be a part: the predicate ranges over all sets, R included, so the definition presupposes the very totality it is supposed to define, and a definition that does that defines nothing. This is the diagnosis that has come to be known as the vicious-circle principle.

(5) What (4) says about this one predicate holds of any definition that refers to a totality containing its own object. Nothing that defines an object in terms of a collection to which that object belongs can be legitimate.

(6) But the ordinary definitions on which analysis rests are of precisely that form. The least upper bound of a bounded set of reals is defined as the least of its upper bounds, and is therefore defined by reference to a collection that contains it. The natural numbers are standardly identified with the members common to every set that contains zero and is closed under successor, which is again a collection containing the numbers themselves. The transitive closure of a relation, and more generally any definition that takes the least collection containing a given thing and closed under a given operation, are built the same way, and that pattern is everywhere in mathematics and logic.

(7) So if (5) is right, the completeness of the reals, the set of natural numbers, and the least-collection pattern generally all have to go. That cannot be the lesson of the paradox.

Tell me which step I should give up, and what giving it up costs. I would sooner surrender (5) than (6), and I do not want to surrender classical logic or ordinary analysis. I would also like to know whether the argument has slipped somewhere rather than merely overreached, and if so, where. If the price of keeping (6) is that (1) must be replaced by some restriction, tell me what kind of restriction actually does the work, why it is not merely ad hoc, and how it blocks the paradox without the circularity story. If instead the honest answer is that (5) is a genuine consequence and analysis must be rebuilt on a predicative basis, tell me which results I lose, and whether a ramified hierarchy together with something like an axiom of reducibility is unavoidable.
