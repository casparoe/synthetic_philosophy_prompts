ok so I'm in third year and I'm taking this philosophy of mind course where each of us has to run one of the seminar sessions, and mine is on computationalism — the idea that the brain is a kind of computer, cognition = computation over representations, that whole picture. 18 people, 80 minutes, normal seminar room, no budget for anything fancy. I really want to do it as an activity rather than a discussion of the readings, because I think the readings will just bounce off them.

Here's the thing I want them to actually feel. I read somewhere that there's an old objection along these lines: if you're allowed to decide freely which physical states of some object map onto which states of the machine, and which goings-on in it count as the inputs and outputs, then basically any object whatsoever can be shown to implement any finite-state machine you like — a rock, a bucket of water, my shoe. So the mere fact that you *can* describe the brain as running a program doesn't yet tell you anything, because you could have said exactly the same about the desk it's sitting on. I think I might be mangling it a bit, but that's the shape of it. There are proposed fixes — the states have to be real and genuinely distinct, the transitions have to actually be caused by the inputs, the input and output signals have to be real physical signals rather than things you just designate — but then you have to argue for those constraints and they're not free.

What I want is a game where people *succeed* at implementing a machine with some random object they're handed, so they feel clever, and then discover that every other group also succeeded, with a different machine, on the same object — or that they could have done it with the opposite machine, or with literally anything. I'd rather they run into that themselves than hear me explain it, so no lecture up front.

Can you design it? Rules, what I need to print or hand out (I've got a box of random junk and a printer), roles if you think they help, a timeline for the 80 minutes, and a debrief that maps what happened onto the objection and onto the fixes people have proposed for it. Also tell me what will definately go wrong the first time I run it and how to handle that, and be honest about what the activity can't show — I assume it can't show that the brain *isn't* a computer, only that this particular way of arguing for it is cheap, so tell me if that's right and what the facilitator has to supply.
