I have just returned from a long argument with a friend about imprecise probabilities, and I would like detailed comments on the essay I wrote afterward to clarify my own position. He holds that an imprecise probability is either just a set of ordinary probabilities, in which case it is a description of your uncertainty about which ordinary probability is correct, or else a decision-theoretic heuristic, in which case it is not a doxastic state at all. I think there is a third possibility: a credal state can be imprecise in its own right. The essay below is my attempt to make that possibility precise. I would like comments on its accuracy, on whether the central distinction is real, and on whether the proposed repair is coherent. Please do not give me a bibliography or reading list; I want an internal assessment of the argument as it stands.

Draft essay: Imprecision Without Indecision

1. Two roles

I distinguish representational imprecision from instrumental imprecision. Representational imprecision is the thesis that an agent's doxastic state is a set of probability functions, and that rationality constraints apply to the set as such. Instrumental imprecision is the thesis that an agent may have a sharp credence but uses a set of probability functions as a computational device to avoid overconfidence in a model or to choose robustly. The two roles are often run together. Arguments from ambiguity aversion typically treat imprecision as representational; arguments from worst-case decision rules typically treat it as instrumental. The conflation makes both sides talk past each other.

2. A test case

Consider two urns. Urn A has 50 red and 50 blue balls. Urn B has 100 balls, each red or blue, with an unknown composition. You must bet on red from one urn. Many people prefer A. If imprecision is representational, your credence in red from B is an interval or a set of sharp credences. If imprecision is instrumental, your preference for A reflects a robustness preference, not a different credal state. Now add a twist. Suppose you learn an irrelevant fact about the color of the table the urns sit on. In some imprecise models, learning such a fact can make the set of posterior probabilities for red from B wider than the prior set. Call this dilation. If imprecision is representational, dilation is a feature of the doxastic state. If imprecision is instrumental, dilation is an artifact of the representation and can be avoided by sharpening for the decision at hand. So the two roles come apart.

3. The bookkeeping argument

If imprecision is representational, then each member of the set must be a candidate for the agent's credence under some possible evidential state. Otherwise the set includes functions the agent would never adopt, and it is unclear in what sense they are part of the agent's doxastic state. But if each member is a candidate, then learning evidence that eliminates some functions should narrow the set. In dilation cases, learning an irrelevant event widens the set. That means the agent is treating the event as relevant to which candidate is correct, contrary to the initial description. So representational imprecision either denies that the event is irrelevant or admits that the set is not a set of candidate credences.

4. A proposed repair

I propose partition-relative imprecision. Imprecision is always relative to a partition of questions the agent treats as unresolved. The credal set is not a free-floating object; it is a summary of the agent's commitments across that partition. Under this view, dilation is not a bug: it shows that the agent's partition changes when new questions are introduced. But the fix has a cost. It makes imprecision non-compositional. You cannot combine credal sets across partitions without a rule for merging partitions, and that rule will itself be either sharp or imprecise, leading to a regress. The open question is whether partition-relative imprecision can guide choice without collapsing into either sharp credences or a new level of imprecision.

5. Conclusion

My friend is half right. Many uses of imprecise probabilities are instrumental. But the representational program is not empty; it needs a partition-relative account. I am not sure whether that account is a genuine third position or a disguised version of the first.

I would like your comments in the following order. First, on accuracy: is the distinction between representational and instrumental imprecision stable, and is my description of dilation correct? Second, on interest: does the partition-relative proposal add anything, or is it a restatement of known positions? Third, on the weakest link: where does the argument most need repair? Fourth, on specific passages: identify any sentence that overstates the case or slides between the two roles. Please be concrete, and where you disagree, say what would have to be true for my argument to go through.
