Bit of an odd one. A friend and I have been building a board game where the players can rewrite the rules mid-game, and we've hit something I don't have a name for, and I keep feeling like the different bits of it are secretly different problems wearing the same coat.

The basic setup: Rule 12 says any rule can be changed by a majority vote. Rule 30 sets the win condition. Pretty quickly a playtester worked out that you can just move to amend Rule 30 to say "this player wins," win by majority, done. Legal, gross, funny. So we added Rule 40: Rule 12 can only be changed by a unanimous vote. Which raised the obvious question of whether you could use Rule 12 (majority) to undo Rule 40 — which is exactly what Rule 40 is meant to prevent. So we added Rule 50: Rule 40 may never be repealed. And now I genuinely can't tell whether Rule 50 is doing anything, because it's just a rule that says it can't be changed, and *any* rule could say that, and if every rule can say that then the "real" rule is whatever the last unamendable rule says, and there is no last one.

A few more that turned up and might be seperate things:
- an amendment that voids earlier rules it conflicts with, which might also void the rule that gave it the power to void anything
- an amendment that changes how the *existing* rules are to be read, so a rule that was clear yesterday means the opposite today, without anyone having "changed" it
- a change that makes something already done retroactively legal, or illegal
- two rules that are each perfectly sensible alone but contradict each other, where nobody noticed for months

People keep telling me it's "just self-reference" and waving at Russell's paradox, but that doesn't feel right, because the game obviously works — we play it — so it can't be the same kind of thing. Other people say there's no problem at all, the rules just say whatever they say and you follow them. I don't buy that either.

Is there an established name for this whole area, and for the individual patterns above? And if not, can you name and define the distinct ones for me — say which of them are really the same phenomenon in different clothes, which are genuinely different, and where the line sits between "self-referring rules are fine and normal" and "the rules have actually eaten themselves"? I don't just want labels. I want to know what each thing *is*, what it isn't (e.g. is a rule that can't be amended *by its own terms* the same as one that can't be amended *in fact*, because nobody can ever get the votes?), and where the edges are.
