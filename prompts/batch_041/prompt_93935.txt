Two pictures of 'the genetic code' keep getting run together in my head and I cant work out whether they're rival claims or just two descriptions of one thing.

Picture one: DNA really is a code, in the loaded sense. The triplets are signs. Nothing about the chemistry of a given triplet makes it specify one amino acid rather than another, so the assignment has to be carried by something outside the chemistry, the way the meaning of a Morse letter is carried by a convention you have to learn. On this reading the genome is a text, the cell reads it, and the 'information' in it is representation in the full sense -- the sequence says something about the protein.

Picture two: that's all borrowed language. There are no signs and no conventions inside a cell, just molecules doing chemistry, and the so-called mapping from triplet to amino acid is a causal fact about which tRNA, with which amino acid already attached, happens to pair up where. Calling it a code quietly imports a reader, a language and a message, and none of them are there. On this reading 'the genetic code' is shorthand at best and a category error at worst.

So compare them for me. Do they actually contradict each other, or is one about representation and the other about mechanism, so that both can be true at once? And ther's a snag inside picture one that I never get past: the code is supposed to be arbitrary (the assignments could have been otherwise) and also universal (the same table holds from bacteria to us). Those seem to pull in opposite directions -- if it's arbitrary, why would every lineage land on the same assignments, and if something forced them, in what sense are they arbitrary? Tell me what each picture makes of that, which one survives it, and whether there's a middle position -- the code is real but it isnt a language, more like a lock-and-key arrangement that got frozen in early -- and if there is one, does it realy earn the word 'code' or is it just borrowing it?
