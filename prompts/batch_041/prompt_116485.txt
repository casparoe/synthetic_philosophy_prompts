I'm in a reading group that has been working through some older cognitive-science texts, and we've hit a snag in a chapter about the location of meaning. The chapter distinguishes three layers of a message: the inner message (the content you recover once you've decoded the thing), the outer message (the totality of cues that tell you how to decode it), and the frame message (the part that announces that there is a message here at all and that it is meant to be decoded). The point, as I understand it, is that meaning is not located in the physical vehicle — the grooves on a record, the ink on a page, the bits in a file — but emerges from the interaction between the vehicle, a decoder, and these outer and frame layers. I'm on board with the idea that the inner message isn't intrinsic to the medium.

But I've run into a puzzle that makes me think the whole picture is either circular or inconsistent. If the frame message is what tells you that something is a message, and the frame message is itself a message, then by the theory's own lights it should need its own frame message to be recognized as a message. That frame message would need another, and so on without end. The only way I can see to stop the regress is to say that some messages — presumably the frame messages — are intrinsically meaningful, that is, they carry their status as messages in themselves without needing a decoder or an outer message. But that is exactly what the theory denies for inner messages, and I don't see why frame messages should be exempt. So either the theory is inconsistent, or I'm misunderstanding what a frame message is. Could you help me see where the regress actually stops, and whether the frame message is really a message in the same sense as the inner message?
