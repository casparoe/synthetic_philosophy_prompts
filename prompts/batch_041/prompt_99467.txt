I keep meeting a pattern in the decision theory blogs I follow and cannot tell whether it has a name, because the names I can think of do not quite fit. The setup is one-shot: two parties act once, never interact again, and can neither reward nor punish each other afterwards. Neither is generous; each would defect against a defector. What produces cooperation is that each party's rule for deciding is visible to the other, and each rule says, in effect: cooperate exactly if I can see that the other will. Both then cooperate, and neither is weighing payoffs at the moment of acting, since its answer was already fixed by the other's rule; asked why, the honest reply is that defecting would have been pointless.

What keeps me from assuming the familiar case — both parties' procedures open to each other — already covers this is a variant. Let the visibility run only one way: A can read B's rule, B cannot read A's. A cooperates iff B does. B, in the dark, cooperates anyway, reasoning that A's output is a function of B's own rule, so defecting would merely be read off and matched. One-way visibility suffices, and the party being read is the one doing the work. I suspect something similar holds when the visibility is merely probable: if each thinks the other is likely enough to be the matching type, cooperating can be the better bet with nothing verified at all.

Does this have an established name, and which of the three — symmetric, one-way, merely probable — fall under it? I care less about the label than about the edges: is the one-way case a distinct structure or the symmetric one with lopsided parts, and is the probabilistic case the same phenomenon or a cousin?
