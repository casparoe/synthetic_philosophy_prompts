I'm in a seminar on rational choice and fair division, and we just finished the Nash bargaining solution and the Kalai-Smorodinsky solution. I'm trying to write down my own view for a response paper, but I want a consistency check before I hand it in. Here's roughly where I've landed:

(1) A fair two-person bargain should be Pareto efficient: no other feasible outcome makes both players better off.
(2) It should be symmetric: if the feasible set and the disagreement point are symmetric, the two players should get equal gains.
(3) It should be scale-invariant: if I change the units I use to measure one player's utility, say from dollars to cents, the recommended split shouldn't change.
(4) It should satisfy independence of irrelevant alternatives: if the feasible set shrinks but the point that was recommended before is still available, the recommendation shouldn't change.
(5) It should satisfy individual monotonicity: if the feasible set expands so that player 1's best possible payoff goes up while player 2's best possible payoff stays the same, player 1's recommended payoff shouldn't go down.
(6) The fair point is the Kalai-Smorodinsky point: draw a line from the disagreement point to the ideal point, where each player's ideal coordinate is their best feasible payoff subject to the other player getting at least their disagreement payoff, and take the point where that line hits the Pareto frontier.
(7) In a concrete case: two roommates are splitting a rent discount, and one has a much better outside option. I think the fair split should be proportional to how much each could gain relative to their disagreement point, not the Nash product.

I have a nagging feeling that (3) and (7) might pull against each other, because talking about gains relative to an ideal sounds like it requires comparing utilities across people, which scale-invariance is supposed to forbid. But I can't tell if that's a real tension or just me being confused about units. I also suspect there might be a bigger conflict somewhere in the list that I'm not seeing.
