For a graduate seminar on epistemic logic, write a decision tree for the problem of logical omniscience that carries a student from one starting commitment — an agent can know P and know that P implies Q yet never come to know Q, without being irrational — to a named account of how knowledge relates to logical consequence. Phrase every branch node as a question about a case (the agent who knows the axioms of arithmetic but not a theorem that follows in a few hundred steps; the one who assents to the schema that a contradiction implies anything but not to its instances) rather than about a doctrine, so that a student can answer it without knowing which account it leads to. The nodes should cover at least: whether the object of knowledge is a set of possible worlds or a structured, proof-like item; whether logically equivalent propositions can be distinct objects of knowledge; whether closure is restored by admitting impossible worlds, by restricting which propositions count for the agent, by weakening the consequence relation, or by treating closure as a process rather than a property; and whether the failure lies in the agent or in our description of it. Derive the space from the questions first and locate the accounts in it second, labelling each leaf with the account it picks out or marking it unnamed. Note the combinations nobody occupies and diagnose each briefly as incoherent, unattractive, or merely unexplored, and flag any two leaves your questions cannot separate — if an impossible-worlds leaf and a restricted-propositions leaf make the same predictions about which inferences an agent actually draws, say so and tell me what further question would prise them apart. Six to eight nodes; no historical survey.
