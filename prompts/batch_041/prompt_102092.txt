I'm a backend engineer with no formal training in philosophy, and I'm trying to work out where I actually stand on whether morality can be written down as a set of rules. I keep modeling it as a rule engine with exception handlers, but I suspect that picture is quietly smuggling in a position, and that I've been collapsing several genuinely different views into one. So I'd like you to build me a decision tree that sorts the positions on this question, where every branch node is phrased as a concrete case or claim I could answer from the inside, without already knowing which label it leads to, and where the leaves are named only at the end.

Make the root of the tree the question of whether any finite set of principles could get the moral facts right in every case. Let the nodes below it turn on the distinctions I actually care about: whether a consideration that is a reason in one situation can be no reason at all, or a reason against, in another (what I gather is the holism/atomism split); whether the correct response in a case is fixed by general features together with a rule for combining them, or whether it also depends on the particular details of the case in a way no finite combination rule captures; and whether principles, if there are any, are exceptionless, or real but defeasible, or merely useful summaries that never do the sorting work themselves.

I want the leaves to include at least these: exceptionless generalism; pluralist generalism built on a short list of defeasible duties; the view that principles are true but ineliminably vague or incomplete; outright particularism, on which there are no true moral principles at all; and the hybrid that is particularist about what is right while remaining generalist about what counts as a reason for what.

Use these as the concrete material for the nodes, because they are the cases that make me uncertain: a promise kept or broken because an emergency intervened; a feature like "it would be fun" that counts in favor of picking a leisure activity but against picking a surgeon; two features that each give a reason on their own but not when combined; and a pair of cases that differ only in a detail I would have called irrelevant yet seem to call for different verdicts.

If some pair of leaves cannot be separated by any question a person could answer from the inside, say so at the node where the tree fails rather than inventing a distinction to keep them apart, and if a combination of answers corresponds to no position anyone actually holds, mark that leaf as empty and say in a clause whether that is because the view is incoherent or merely unexplored. Present the whole thing as exactly five numbered items, one per branch node, in the order the tree is traversed: for each, give the node's question as a concrete case or claim in one sentence, and in a second sentence name which positions fall on each side, flagging any empty leaf and any pair the tree cannot separate. No preamble and no closing summary.
