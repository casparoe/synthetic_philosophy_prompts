Question:

Consider an agent whose utility function is u(x) = x and whose risk function is r(p) = p². The agent faces a choice between two acts:

A: a certain £20.

B: a lottery paying £0 with probability 0.6, £40 with probability 0.3, and £100 with probability 0.1.

(i) Compute the expected utility of each act and state which act expected utility recommends.

(ii) Using the definition of risk-weighted expected utility below, compute the REU of each act and state which act REU recommends.

(iii) Explain what the comparison shows about the relationship between REU and EU, and identify the feature of the risk function responsible for the reversal.

Definition of REU: For an act f with outcomes ordered from worst to best x₁ ≤ x₂ ≤ … ≤ xₙ, with corresponding probabilities pᵢ, and for an increasing risk function r with r(0) = 0 and r(1) = 1,

REU(f) = u(x₁) + Σᵢ₌₂ⁿ [u(xᵢ) − u(xᵢ₋₁)] r(Σⱼ₌ᵢⁿ pⱼ).

Treat this definition as authoritative for the purposes of marking.

Candidate's answer:

(i) EU(A) = u(20) = 20. EU(B) = 0.6·u(0) + 0.3·u(40) + 0.1·u(100) = 0 + 12 + 10 = 22. So expected utility recommends B.

(ii) REU is a weighted sum in which the risk function replaces the probabilities. Thus REU(B) = r(0.6)·u(0) + r(0.3)·u(40) + r(0.1)·u(100) = 0.36·0 + 0.09·40 + 0.01·100 = 3.6 + 1 = 4.6. REU(A) = r(1)·u(20) = 20. So REU recommends A.

(iii) The comparison shows that REU can reverse the ranking delivered by EU. The reversal is due to the risk function: because r(p) = p² is convex, the agent is risk-seeking and gives extra weight to the worst outcomes.
