I've been reading a pop philosphy of math book — the author's a physicist who drifted into foundations, so he's solid on the physics but I don't trust him on the set theory — and there's a section on Skolem's paradox I want to sanity-check. His gloss goes roughly like this: Cantor proved the reals outnumber the naturals. But Skolem showed that any first-order theory with a model has a countable model, so set theory, if it has a model at all, has a model in which every set is countable — including the set the model calls the reals. So in the only kind of model first-order logic can actually hand us, Cantor's theorem comes out false. There really is a matching between the reals and the naturals, he says; the only catch is that no formula in the language can define it. The moral he draws is that uncountability isn't a fact about sets at all but an artifact of the language you happen to formalize things in, and whether a given set is countable just depends on which model you pick.

I'd especially like the internal/external distinction spelled out, because I have a feeling it's carrying most of the weight here and he never mentions it. And then the part I actually care about — if I patched every technical slip, which of his conclusions would still stand?
