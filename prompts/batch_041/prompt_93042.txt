As a side project I've been writing a small program that takes an action I'm considering, strips out the details that seem particular to me, and checks whether the resulting rule could be adopted by everyone at once without contradiction. I had assumed Kant's universalizability test was essentially a consistency check of this kind, so the program should reproduce a careful human's verdict on any case. In practice the verdict moves with my phrasing: the same act fails when I describe it as skipping a meeting I promised to attend, passes when I describe it as protecting my health on a day when the meeting would have exhausted me, and fails again when I enter something plainly permissible, such as my decision to train as an engineer rather than a doctor, because a world where everyone did that would have no doctors. If the test is a formal requirement that a rule hold consistently when universalized, shouldn't there be a single correct description of any given action, so that the verdict is fixed rather than left to my wording? Where is that description supposed to come from?
