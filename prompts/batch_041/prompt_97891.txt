I've ended up believing something I can't quite shake, and I want you to tell me what should change my mind. Call it the dogmatist move: if I genuinely know something — not believe it really strongly, actually know it — then any evidence that turns up later and seems to count against it has to be misleading, because the thing is true, so nothing can really be evidence against it. Which means I'm entitled to just ignore it. Knowing is a licence to stop updating. (I'm an engineer, so the way I picture it is like a belief that's already been committed — merged, tests green — and you don't re-run the whole pipeline on it every time new input shows up.)

So what would actually count against this? Not the lazy "but that's just closed-minded" reply, I can see that one coming — I want the real defeaters: the cases it can't describe, the things it predicts that we could actually check, whether it secretly collapses into some other view, and whether it's even the kind of position that can lose or whether I've just defined it so nothing touches it. Sort whatever you give me from "this genuinely should move me" down to "shrug", and be honest about which of them a defender of the view would themselves admit counts against them.
