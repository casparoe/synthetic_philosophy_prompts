I work on tooling for debugging neural networks — probing classifiers, sparse-autoencoder feature dictionaries, activation patching — and my team keeps having the same argument in different clothes. One of us says a feature "represents" a concept; another says it is just a direction that happens to predict an output; we never agree on what would settle it. I would like a decision tree that takes a reader from a starting point we all accept — a probe or dictionary feature is causally load-bearing, in that intervening on it reliably moves behaviour, and it beats our alternatives at predicting held-out activations — to a named position about what, if anything, the network represents. Build it from the logical space first, so that the branch nodes are the questions that actually separate the positions, each phrased so a reader can answer it without knowing which position it leads to. I want the following distinctions on the tree whether or not they turn out to be standard: (i) whether being causally load-bearing is enough for an internal state to count as a representation, or whether representation requires something more, such as being about something and being capable of being wrong; (ii) whether "what does this feature represent?" has a single correct answer or is only well-formed relative to a task specification — a choice of input distribution and output vocabulary — so that different specifications yield different but equally correct answers; (iii) if there is a fact of the matter, whether it is fixed by what the feature does downstream in the circuit, by what the network was trained to do, or by which description best compresses the network's behaviour for an interpreter; (iv) whether the real unit of analysis is a single feature or direction, a whole subcircuit or computation, or the network's overall input-output function — that is, whether there is a privileged level of granularity or whether the choice of level is itself a modelling decision; and (v) whether calling a state a representation adds anything at all over calling it a causal mediator that correlates with something and drives something else, and if so whether the addition is a truth-evaluable claim or a normative one. Please also include the distinction between a feature that is merely load-bearing in one context and a feature that is relied upon across contexts, since that is the case we keep tripping over.

Aim for roughly seven to nine leaves. Give each leaf the name of the position if there is a standard one and "unnamed" otherwise, plus one sentence stating its most awkward commitment. Tell me which leaves the tree cannot separate and why, and which combinations of answers at the nodes nobody occupies — and for each of those, whether the view is incoherent, merely unattractive, or simply unclaimed. Where a leaf is really a family of views, say so and give the internal split. Keep the audience in mind: my team reads interpretability papers but has no philosophy training, so the node questions should be in plain language. I do not want citations or a reading list — just the instrument.
