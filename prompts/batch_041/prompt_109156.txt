I've been working through a modal ontological argument and have hit a snag. The argument seems to prove not only that a maximally great being exists, but that there are no contingent truths at all. Here is the argument as I've reconstructed it. (1) A property is positive if and only if its negation is not positive. (2) If a property is positive, it is necessarily positive. (3) Being God-like is positive, where a being is God-like if and only if it has every positive property essentially. (4) Necessary existence is positive. (5) It is possible that a God-like being exists. (6) Therefore, a God-like being exists necessarily. (7) Now consider any true proposition p. The property of being such that p is true is either positive or not positive. (8) If it is positive, then a God-like being has it essentially, so p is necessarily true. (9) If it is not positive, then by (1) its negation is positive, so a God-like being has the negation essentially, so p is necessarily false. (10) So every proposition is either necessarily true or necessarily false. (11) Therefore there are no contingent truths. (12) But there plainly are contingent truths. I would like to keep (5) and (6) if I can, but I cannot accept (11). Where does the argument go wrong, and what does rejecting each candidate step cost?
