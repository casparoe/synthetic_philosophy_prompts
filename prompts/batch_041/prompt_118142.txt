Question (20 points). A fair coin is tossed until it first lands heads. If heads first appears on toss n, the player receives a payoff of (−1)^(n−1) · 2^n / n dollars. Call this Game A. (i) [6 points] Compute the expected monetary value of Game A under the standard definition, and state whether it is well-defined. Justify your answer. (ii) [6 points] Now consider Game B, which is exactly like Game A except that the payoff on toss n is (−1)^(n−1) · 2^n / n + 1/n dollars. Compute the expected monetary value of Game B, and state whether it is well-defined. Justify your answer. (iii) [8 points] Suppose a decision theorist says: "Because Game A has an undefined expected value, expected utility theory is silent about whether a rational agent should choose Game A over a sure $0. So a rational agent is indifferent between Game A and the sure $0." Assess this claim. Is the decision theorist right about expected utility theory's silence? Is the inference to indifference correct?

Student's answer: (i) The probability that heads first appears on toss n is (1/2)^n. So the expected value of Game A is the sum from n = 1 to infinity of (1/2)^n · (−1)^(n−1) · 2^n / n. The 2^n cancels with the 1/2^n, leaving the sum from n = 1 to infinity of (−1)^(n−1)/n. This is the alternating harmonic series, which converges to ln 2. So the expected value is ln 2, or about $0.69. However, the series is only conditionally convergent, not absolutely convergent: the sum of the absolute values is the harmonic series, which diverges. By the Riemann rearrangement theorem, a conditionally convergent series can be rearranged to converge to any real number, or to diverge to plus or minus infinity. Since the standard definition of expected value sums over outcomes without specifying an order, and the game's outcomes can be enumerated in different orders, the expected value is not well-defined. So the expected value is ln 2 if you sum in the natural order, but undefined in general. (ii) Game B's expected value is the sum from n = 1 to infinity of (1/2)^n · ((−1)^(n−1) · 2^n / n + 1/n). This splits into two sums: the sum of (−1)^(n−1)/n, which we already know is ln 2, and the sum of (1/2)^n · (1/n), which is the sum from n = 1 to infinity of 1/(n · 2^n). The second sum is absolutely convergent: since 1/(n · 2^n) ≤ 1/2^n and the geometric series converges, the comparison test applies. In fact, the second sum equals ln 2, using the series for −ln(1 − x) with x = 1/2. So the expected value of Game B is ln 2 + ln 2 = 2 ln 2, or about $1.39. Because the added term is absolutely convergent, it pins down the value of the whole sum: even though the first part is only conditionally convergent, the presence of the absolutely convergent second part means that any rearrangement of the terms of the full series must still converge to 2 ln 2. So Game B has a well-defined expected value, unlike Game A. (iii) The decision theorist is right that expected utility theory is silent about Game A. If the expected value of Game A is undefined, then the theory cannot assign it an expected utility, and so it cannot say that Game A is better or worse than the sure $0. And since the theory gives no reason to prefer Game A to the sure $0, or vice versa, a rational agent is indifferent between them. Indifference just means that the agent has no preference either way, which is exactly what the theory's silence implies. So the decision theorist is right on both counts.
