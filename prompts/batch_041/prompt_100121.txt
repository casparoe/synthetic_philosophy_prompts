My opening: here's where I think you're stuck. You say the two-bitser's inner state is about a coin only because we read it that way -- its aboutness is derived, borrowed, observer-relative. Borrowed from who? Somebody has to be doing the lending, and the only lenders around are creatures whose own states are already about things, so "derived" quietly presupposes "original" and you've explained nothing. Worse, run the regress out: suppose the two-bitser is a component in a bigger machine, and that machine's designer was itself a machine, all the way down. Where does the loan originate? If the answer is "with us," then we're just the last artifact in the chain, and Dennett wins by default. If the answer is "with consciousness" or "with biological causal powers," then you owe me an account of what that ingredient is and how it does the work, because "it's biological" isn't an argument, it's a location. So which is it: is the distinction a substantive claim about what's going on inside a system, or is it just the fact that we're the ones doing the interpreting? Because I dont see a third option, and if there is one, that's what I want from you.
