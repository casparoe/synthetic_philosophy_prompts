Setup we both accept, so you don't have to re-derive it: Löwenheim–Skolem says a consistent first-order theory in a countable language, if it has an infinite model, has a countable model. ZFC is such a theory and (if it's consistent) has infinite models, so it has a countable model, call it M. ZFC proves Cantor's theorem, so M has an element that M calls the set of reals, and M says that set is uncountable — i.e. no bijection between it and M's ω shows up in M. But from where we're standing M's entire domain is countable, so there is such a bijection, it just isn't in M, and it can't be, or M would be proving one of its own theorems false. Fine. That bit we're agreed on.

My line is that this shows there's no fact of the matter about whether a set is really countable — "uncountable" only ever means "uncountable relative to some model" — so there's no privileged intended universe of sets, and if you bolt on the completeness theorem you get the Putnam version where even reference is indeterminate. Which means the platonist's "the real sets" is a story we tell ourselves. I'm pretty sure Skolem himself was on this side, he thought set theory hands you relative notions rather than the absolute ones.

Priya's line is: no, all this shows is that M's membership relation isn't the real one, so M was never the intended interpretation of the axioms to begin with. "Countable in M" is just a different property from "countable", and the real property is as determinate as anything. She also says my argument eats itself, because when I say M's domain is "really only countable" I'm helping myself to an absolute notion of countability from outside the model, which on my own view doesn't exist.
