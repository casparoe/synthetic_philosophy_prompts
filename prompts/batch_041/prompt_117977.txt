Quick background so we're on the same page (apologies if this is stuff you already know, but I want to be sure we're aligned): the priority view (Parfit's thing) says the moral value of helping someone is greater the worse off they are — it's about how much a given benefit counts, not about equality being good in itself. Egalitarianism, at least the version where equality is intrinsically valuable, says a more equal distribution is better in itself, even when nobody is made better off by it. The levelling-down objection is the standard complaint about that: if equality is good in itself, then tearing down the better off so that everyone is equally badly off counts, in one respect, as an improvement. Prioritarians say they dodge this, because making the better off worse off doesn't help the worse off, so it registers as nothing on their view.
