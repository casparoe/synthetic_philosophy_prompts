I'm currently taking a graduate seminar on philosophy of probability and inductive logic, and I'm trying to settle on a defensible position for a term paper on the reference class problem. The position I want to defend is this: the reference class problem is not a genuine problem for probabilistic inference, but a symptom of an incoherent demand for a unique, agent-independent, single-case probability. Once we accept that the only well-defined probabilities are conditional on a chosen partition, a chosen model, and a set of purposes, the question of which reference class is the correct one has no more force than the question of which coordinate system is the correct one. There is no fact of the matter to get right, only choices that are more or less useful for a given inference. I also want to defend a stronger and more speculative claim: that the reference class problem is structurally the same as the problem of choosing a coarse-graining in statistical mechanics and the problem of choosing a feature representation in machine learning, and that in each case the apparent need for a privileged partition is an artifact of treating a pragmatic modeling choice as a metaphysical discovery. What I want from you is a map of what would count against this position. Which objections, cases, intuitions, or formal results should actually move me? I am interested in defeaters that a sympathetic defender would themselves concede, not only the standard complaints from frequentists or from those who believe there is a unique objective chance. Please rank them from fatal to merely awkward, and say for each what it would take to rebut it. In particular, I want to know whether the position risks becoming unfalsifiable: if every proposed counterexample can be absorbed by saying that it merely reflects a different choice of partition, is that a virtue of the view or a sign that it has been insulated from criticism? If the analogy to coarse-graining and feature selection is doing real work, what would break it — what would show that the reference class problem has a kind of normative grip that those other choice problems lack? And if the position collapses into a familiar form of subjectivism or relativism, is that a problem for a view of this kind? I would find it especially persuasive if you could identify a case where the choice of reference class changes a credence in a way that cannot be redescribed as a difference in purposes or information, or a formal result showing that some partitions are objectively privileged by the structure of the world.
