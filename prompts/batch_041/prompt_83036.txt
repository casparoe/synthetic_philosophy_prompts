For my final project I want a decision tree that keeps those three axes apart rather than collapsing them. Each branch node should be a question about a concrete case that a reader could answer without already knowing which position it leads to; build it from the color phi phenomenon, the cutaneous rabbit, masked stimuli that subjects report as unseen, blindsight, and the confabulated explanations split-brain patients give for actions initiated elsewhere, glossing each case in a clause so that nothing depends on the reader's having read the original papers. The leaves should be the named positions: Cartesian materialism (the target of Dennett's attack), global workspace theory, higher-order thought theory, the multiple drafts model itself, illusionism about phenomenal properties, and eliminativism about them. Tell me which leaves the tree cannot separate and why, and which combinations of answers nobody occupies, saying for each empty cell whether the view there is incoherent, unattractive, or simply unexamined. No citations or reading list — I need the instrument itself.
