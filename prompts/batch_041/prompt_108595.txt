I teach a graduate seminar in logic and strategic interaction, and the unit I am currently writing the final exam for is on program equilibrium: the device of letting two players submit programs to a referee instead of actions, so that the object of analysis becomes the meta-game in which each player chooses a program and the referee runs the two programs against each other. Every year most of my students can recite that program equilibrium makes cooperation achievable in a one-shot Prisoner's Dilemma without repetition, enforcement, or binding commitment, and almost none of them can say what that result quietly assumes. I want the final to consist of a single essay question, answerable in ninety minutes and worth twenty marks, that exposes exactly this gap.

Please build the question on the following construction, and make it self-contained enough that a student who has done the reading but has a poor memory for names can still answer it.

1. Payoffs. A one-shot Prisoner's Dilemma with the usual ordering: mutual cooperation 3 to each, mutual defection 1 to each, unilateral defection 5 to the defector and 0 to the cooperator.

2. The meta-game. Each player submits a program rather than a move. The referee gives each program the other player's source text as input, runs both, and reads off the pair of moves the programs return; payoffs are then as above. A profile is a program equilibrium when each program is a best response to the other, that is, a Nash equilibrium of this meta-game.

3. The obvious construction. Consider the program that returns cooperate if and only if its input string is textually identical to its own source, and defects otherwise. Two copies of it reach mutual cooperation, and that profile is a Nash equilibrium of the meta-game. But cooperation here requires exact syntactic identity between the two programs, which makes it brittle: introduce any difference in the text and both programs defect.

4. Why simulation does not help. A natural next idea is for a program to simulate the opponent on its own source and cooperate just in case the simulation cooperates. Two such programs, run against each other, generate an infinite regress.

5. The proof-based variant. Instead of simulating, an agent may search for a proof. Fix a recursively axiomatized formal system S strong enough to formalize facts about program execution; first-order arithmetic will do. Define the prover agent so that, against an opponent x, it returns cooperate exactly when S proves the sentence saying that x returns cooperate when run on the prover's own source, and returns defect otherwise. Take this as a stipulation about the agent's behaviour rather than a description of a literal search procedure, which could not in general decide the negative case. Assume S is sound.

6. Facts about the prover. The prover against the prover yields mutual cooperation; the prover against an unconditional cooperator also yields mutual cooperation; the prover against an unconditional defector yields mutual defection. The self-cooperation result is not available to ordinary conditional reasoning — the tempting argument, that if I cooperate then my opponent, who is running the same reasoning, will cooperate too, is circular — and the standard route instead uses Löb's theorem: for any sentence φ, if S proves that the provability of φ in S implies φ, then S proves φ.

I want the essay question to make students do three things. First, reconstruct why the prover cooperates with itself and identify the step that conditional reasoning, and simulation, cannot license. Second, determine whether the cooperating profile is a Nash equilibrium of the meta-game, by checking whether either player can profitably deviate, and state exactly which property of S the answer depends on. Third, say whether the agents themselves can establish that property about S. My own view is that the profile is an equilibrium, that the proof turns on a property of S stronger than mere consistency, and that this property is one S cannot prove of itself; but do not simply assert any of this — the point of the question is to make the student find it, and the marking scheme should reward the student who finds it and penalise the one who reaches for the most familiar self-reference theorem instead.

Close the question by requiring a verdict, not a survey: does program equilibrium show that rational agents can cooperate in a one-shot Prisoner's Dilemma without enforcement, or does it relocate the problem into an assumption the agents cannot certify?

Give me the question, a model answer of about eight hundred words at the level a strong candidate could produce in the time, and a marking scheme built from must-hit points with marks totalling twenty, a one-line note on how candidates typically miss each point, and an explicit statement of the A/B boundary — the specific move an A answer contains that a B answer lacks, not just a longer list of points. The model answer and the marking scheme must contain no citations, no bibliographies, and no quotations, and must not rest on who proved what: my students are not expected to have memorised attributions and I do not want unverifiable quotations in the key. I would rather have a model answer that stakes out a definite verdict on the philosophical question, even one I end up disagreeing with, and defends it, than one that lays out the possible positions and leaves the choice to me; the marking scheme should be equally decisive about what counts as a top answer.
