I write about science and ideas for a general-reader magazine, and I've got a draft I have to file Friday that I'm not happy with, so I'm hoping you'll tear into it. It's about Hofstadter's typogenetics — the toy system in Gödel, Escher, Bach where you've got strands of letters and little rules that chop, move, copy and paste them, and the whole game is figuring out whether some strand can manufacture the enzymes that would build a copy of itself. The received reading, which is the one I think most people walk away with, is that there's a deep isomorphism here: DNA getting translated into protein is supposed to line up with the way a formal system can encode statements about itself, so the self-replicating strand is a cousin of the Gödel sentence, and self-replication is really self-reference wearing a lab coat. My draft argues the famous version of that analogy is the wrong one. A cell's DNA doesn't say anything about DNA — it just gets copied by machines that read it, and nobody in there is proving theorems — so the self-reference half is doing less work than advertised. The half that actually earns the comparison, I claim, is the code itself: it's arbitrary (nothing in the chemistry forces these three letters to mean that amino acid) but frozen (you can't renegotiate it without scrambling every protein in the cell at once, and the only reason it looks inevitable is that everyone's been running the same version for a few billion years). Gödel numbering is arbitrary too, but it's free — you can renumber whenever you like and nothing breaks. So the real motif is "arbitrary but frozen code," and the self-reference stuff is a different animal that we've smuggled in because it's the exciting one. I also tack on a last section where I point at machine learning — a model's learned vector space is also a code nobody wrote and nobody can just edit, so maybe these things are typogenetic in the relevant sense — and I genuinely can't tell if that section is the best part of the piece or a bridge too far.
