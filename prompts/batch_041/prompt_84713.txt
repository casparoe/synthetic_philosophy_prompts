I teach a graduate seminar on theories of consciousness, and the final is a 90-minute essay exam. I need one question on the multiple drafts model that cannot be answered by reciting the familiar slogans about there being no single place where everything comes together. Set the students this stipulated case: a system whose processing is entirely parallel, with no privileged stage, but which maintains a shared bulletin board that subsystems read from and write to — with the further stipulation that no subsystem ever reads the whole board at once, so the board's global state is never present to any part of the system. Ask whether this system has a Cartesian theater, and make them say precisely which of the theater's commitments the multiple drafts model must deny and which it can grant: a single locus at which content is fixed, a single time at which a content is experienced, or an authoritative witness whose access is what makes a content conscious. Require them to say how their answer bears on the Orwellian/Stalinesque choice, and on whether the denial of a fact of the matter about the order of experiences is a metaphysical claim or merely an epistemic one. Please write the question, a model answer of about 700 words, and a 20-mark scheme that names the specific moves separating an A from a B answer, with a one-line note on the characteristic error behind each losing move.
