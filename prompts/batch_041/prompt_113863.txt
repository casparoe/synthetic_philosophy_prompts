A neural network has representations just in case you can train a linear probe on its internal activations that recovers some property of the input — whether a sentence is negated, where an object sits in an image, which token is likely next. Interpretability researchers have found such probes succeeding almost everywhere they look, at every layer and for every property anyone has bothered to test, so the network plainly represents all of these properties, and we can in fact read off what it represents at any layer we choose. The one complication is superposition: because features are smeared across many neurons rather than localized in single units, there is no clean correspondence between units and concepts, which shows that these systems have nothing like the structured, compositional representations of classical symbolic AI. The honest verdict, then, is that networks have representations only in a loose, statistical sense — a way of speaking rather than a fact about what is inside them.
