I am in the second term of an upper-level course on information, computation, and scientific explanation, and I have run into a distinction I need and cannot find a name for. Please begin with your verdict in the first sentence — whether there is an established name and, if so, what it is — and then give the reasoning, with no preamble and no restatement of my question.

What I keep wanting to say is that there are three different ways for something to be complicated, and that the measures we use in the course record only one of them.

Consider a crystal. Its structure is regular, a very short rule generates it, and the rule runs about as fast as you can write it down, so a short description hands you the object almost immediately.

Now consider a genome. It is not random at all; it has plenty of redundancy, it compresses, and a fairly short description of it can be written. But no short description lets you obtain the object quickly. The only way to get the thing itself is to run a long process — replication, selection, transcription — that depends on a particular history.

Now consider the output of a physical noise source. There is no short description of it, and yet it costs nothing to produce; you simply read it off.

The same three-way split shows up in less physical cases. The digits of pi look patternless and serve as random for most purposes, yet a short program describes them; obtaining the ten-thousandth digit still means running a computation. A string from a pseudorandom generator is like this too: a few dozen bits specify it, and you still cannot get it without doing the work. A string of genuine noise is the reverse: it cannot be specified at all, and it is free. And a shuffled deck of cards, I want to say, belongs with the noise rather than with the genome, even though the deck obviously had a definite causal history.

So there appear to be two axes — how long the shortest description is, and how much work stands between a description and the object — and the case I care about is the one that is low on the first and high on the second. My claim is that this second axis is what people are tracking when they say a genome is more complex than a crystal and more complex than a shuffled deck, and that a short description does not let you shortcut the history. My questions:

1. Does this have a name? If it does, what exactly is it a measure of, and if the name is one I am likely to have met in some other context, tell me how that other context differs.
2. If it does not, coin one, define it precisely, and say what falls on each side, including the cases where you would want to hedge.
3. I suspect this property is not machine-independent in the way the course's measure is supposed to be — that the additive constant we are told to ignore is doing all the work, and that my property slides around when I change the machine or the programming language. Is that right, or is there a formulation that survives the change?
4. I suspect it is also uncomputable, for the same reason the course's measure is. If so, is the situation worse here, and does anything usable survive — restricted comparisons, bounds, approximations with known failure modes?

I should say what would satisfy me. I am not after the label. If a label exists, I want the boundary: what counts as the work, whether it has to be the work of a particular kind of process, why a shuffled deck is on the shallow side when it plainly took a long history to produce, and which of the neighbouring complexity measures — the ones that people who work on this distinguish from each other — mine is most likely to be confused with. If my two-axis picture is wrong, if the second axis collapses into the first or is really just a claim about how long programs take to run, say so plainly and tell me what I would have to give up.
