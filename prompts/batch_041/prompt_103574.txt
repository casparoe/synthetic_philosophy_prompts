I have been handed an argument that seems to show that deliberation is pointless, and each step looks innocent on its own. (1) If an event is simultaneous with an event that exists, then that event exists. (2) Simultaneity is frame-relative: for any two events separated by a spacelike interval there is an inertial frame in which they occur at the same time. (3) So if an event is spacelike-separated from an event that exists, that event exists. (4) Spacelike separation can be traversed in finitely many steps from any event to any other event in the universe. (5) Therefore every event in the universe exists. (6) If every event exists, then the future is already as much a fact as the past, and the upshot of my deliberating is settled independently of my deliberating. (7) What is settled independently of my deliberating cannot be changed by it. (8) So deliberating cannot change anything and is pointless. Tell me which step to reject, and what rejecting it costs. I would rather keep (2) and (6) than (8), but I want to know what I am paying for that.
