Heres my reconstruction: take a formal system strong enough to talk about its own proofs, like arithmetic. Löb's theorem says (roughly) that if such a system can prove 'if it's provable that X, then X' — for a particular sentence X — then it can already just prove X outright, no detour needed. So if the system goes further and adopts that as a general axiom schema, i.e. 'for every X: if I can prove X, then X is true' — which is just what it means for the system to trust its own reasoning — then by Löb it proves every sentence X, so it either collapses into triviality/inconsistency or it can never adopt the schema in the first place. Fine so far, I think. My friends say this is basically Gödel's second incompleteness theorem with a new coat of paint, and honestly that matches my intuition, it's got the same 'no system can vouch for itself' flavour.
