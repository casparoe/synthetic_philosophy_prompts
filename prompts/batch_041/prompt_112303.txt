Ok so I've been reading rationalist blogs since roughly the OB days and one thing has been bugging me for years. Everybody in this corner of the internet treats Pascal's wager (believe in God, because a finite chance of an infinite payoff beats any finite cost) as a joke - it's the go-to example of how "maximize expected value" reasoning goes off the rails. But alot of the same people treat the St. Petersburg paradox (the coin game paying 2, 4, 8, 16... dollars, with infinite expected value) as a live, unsolved problem in decision theory, something you're supposed to have an actual view about. I want to know if that asymmetry is real or just fashion.

So compare them for me, structurally. I dont care whether you should go to church. I care where each argument gets its infinity: the wager from a finite probability times an infinite payoff, St. Petersburg from an infinite series of finite payoffs. How much work is that difference doing? Then go through the standard fixes and tell me which ones transfer. Does the log-utility / diminishing-marginal-utility move actually touch the wager, or does it only ever work on St. Petersburg because we quietly assume the payoff is finite? Does capping utility kill both, and if so is that solving the problem or changing the subject? Does "ignore probabilities below some threshold" do the same job in both cases, and does the arbitrariness of the threshold hurt the St. Petersburg version of that fix as badly as the wager version? And what about the objection that nobody can actually bankroll the St. Petersburg game - is there anything like it on the wager side?

The part I actually care about: the mugging case (tiny chance of an astronomically large but finite payoff, small cost) is supposed to be the bridge between the two. Does it really collapse the distinction, or does it inherit the wager's problem rather than St. Petersburg's? Same question for the many-gods objection - several wagers, each with infinite expectation, pointing at incompatible actions. Is that a different kind of failure than what St. Petersburg does? And finally: which of the two is the harder problem for expected utility theory, and does either one show that it's inconsistent rather than merely incomplete? People keep saying "the expectation is undefined, so there's no maximum" like it's checkmate, and I want to know if it is.
