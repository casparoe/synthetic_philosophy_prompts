Why an agent cannot trust the agent it becomes. Imagine an artificial agent that rewrites its own code, or builds a successor smarter than itself, and wants to defer to that successor — to treat the fact that the successor has proved P as a reason to believe P. If the agent reasons within a formal theory T, then for this deference to be rational it seems to need a general principle: for every sentence P, if the successor can prove P, then P. Call this the trust principle. The whole question is whether T can prove the trust principle about the successor.

Löb's theorem tells us what happens when a theory tries. For any sufficiently strong, recursively axiomatized theory T containing enough arithmetic, if T proves that P is provable in T only if P, then T already proves P. Equivalently, T can never establish a reflection instance for a sentence it does not already prove. If I recall correctly, Löb's theorem is best read as a strengthening of Gödel's first incompleteness theorem. The proof runs through the diagonal lemma: take the sentence L that says of itself that if L is provable then P; show that T proves L; then, by necessitation and the distribution of the provability predicate, conclude P.

Now suppose the successor is at least as strong as T, which is what it means to call it an improvement. Then everything T proves, the successor proves too. So if T could prove the successor's soundness, T could prove its own soundness; by Löb's theorem it cannot. A consistent T therefore cannot prove the trust principle for a successor at least as strong as itself. This is the Löbian obstacle.

The way out, it seems to me, is for the agent simply to trust itself: it adopts the trust principle as an axiom, taking on, for every P, that if P is provable in T then P. With that axiom in place the agent can license deference to its successor. If this is right, then the obstacle is fatal to the whole project of recursive self-improvement: no agent can ever be justified in trusting the agent it becomes, and any system that tries must be either inconsistent or frozen at its present power.
