Me and a mate got into a propper long arguement last night about risk-weighted expected utility, and now I'm marking a stack of undergrad scripts and I've hit one I'm not sure about. The question was:

Consider a choice between:
A: £28 for sure.
B: a lottery with a 50% chance of £60, a 30% chance of £30, and a 20% chance of £0.
Assume utility is linear in money, so u(x)=x. The decision-maker uses risk-weighted expected utility (REU). For ordered outcomes x1 ≤ ... ≤ xn, REU is:
u(x1) + Σ_{i=2}^n [u(xi) − u(x_{i−1})] · r(P(X ≥ xi)),
where r is an increasing probability weighting function with r(0)=0 and r(1)=1. Take r(p)=p².
Which option does REU recommend? Show your working. Then explain what r is doing in the REU formula and how REU differs from standard expected utility.

The student wrote:

Standard EU first: EU(B) = 0.5(60) + 0.3(30) + 0.2(0) = 39. EU(A) = 28, so EU picks B.

For REU, order outcomes worst to best: 0, 30, 60. Cumulative probabilities of doing at least as well as each outcome: P(X ≥ 60)=0.5, P(X ≥ 30)=0.8, P(X ≥ 0)=1. Then
REU(B) = u(0) + [u(30) − u(0)]r(0.8) + [u(60) − u(30)]r(0.5)
= 0 + 30(0.64) + 30(0.25)
= 19.2 + 7.5 = 26.7.
Since 26.7 < 28, REU picks A.

So REU flips the choice. The function r transforms cumulative probabilities so the decision-maker doesn't treat them linearly. Here r(p)=p² is convex, which means the decision-maker is risk-seeking, because a convex function exaggerates the weight of better outcomes. This is basically the same as having a convex utility function in standard expected utility, or what Kahneman and Tversky call prospect theory. The key difference from EU is that REU separates attitudes to risk from attitudes to outcomes: risk aversion is modelled by r, while utility u handles the value of money.
