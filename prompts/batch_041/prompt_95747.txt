I am a software engineer with no formal training in logic or philosophy, and this term I am grading the short-answer section of an undergraduate seminar on formal systems. One of the questions concerns the MU-puzzle. The system it describes uses strings made up of the letters M, I and U; it has a single axiom, the string MI, and four rules for producing new strings from strings you already have:

1. If a string ends in I, you may append U to it.
2. Given a string of the form Mx, where x is any string, you may form Mxx, that is, you may repeat everything after the M.
3. Any occurrence of the block III may be replaced by U.
4. Any occurrence of the block UU may be deleted.

The question asks three things: whether the string MU can be derived from MI; whether that answer changes if rule 3 is altered so that any occurrence of the block II, rather than III, may be replaced by U; and what the exercise shows about the difference between working inside a formal system and reasoning about one from the outside, the move that is sometimes called jumping out of the system.

The student's answer:

---

I. The axiom MI contains exactly one I. The only rules that can change the number of I's in a string are rule 2, which doubles that number, and rule 3, which removes exactly three of them; rule 1 only appends a U, and rule 4 only removes U's. Now suppose a string has a number of I's that is not a multiple of three. Doubling such a number cannot make it a multiple of three, and subtracting three from it does not change its remainder modulo three. So no string derivable in the system can have a number of I's that is divisible by three. Since the axiom has one I, every derivable string has an I-count of the form 3k+1 or 3k+2. MU contains no I's at all, and zero is divisible by three, so MU is not derivable: no sequence of rule applications, however long, will produce it.

It is worth being clear about what kind of argument this is. It is not a derivation of anything inside the system; it is a fact about every derivation the system could ever perform, and it can only be seen from outside the rules.

II. Weakening rule 3 makes no difference to the result. The argument above never depended on the number of I's removed being three; what mattered was that rule 3 removes a fixed number of I's, so the count moves by a constant, and moving a count by a constant cannot turn a non-multiple of three into a multiple of three. Replacing three with two simply changes the constant. So MU is still not derivable under the modified rules.

III. The invariant is not a rule of the system, and the rules alone will never hand it to you; that is what it means to step outside the system. What the exercise shows is that the system is incomplete: MU is a truth about the system that the system itself cannot establish. This is Gödel's situation in miniature, something that is true but that the system cannot prove, and it illustrates that no formal system can capture all of the truths about itself.
