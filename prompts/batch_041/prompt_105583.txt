ok so I've been lurking on LessWrong and in the mech interp corners of the internet since forever, and I want to finally turn the endless "do neural nets actually have representations" thread into something you can actually settle instead of going in circles. So build me a decision tree / quiz for it.

The thing I keep noticing is that everyone in these threads holds a different view but uses the same words, so a "which camp are you in" listicle is useless. Build the tree from the questions, not from the labels. Every branch node has to be a question someone can answer about a concrete case without already knowing which camp it drops them in. Leaves get the position name (or "unnamed" if it's a combo nobody defends) plus one line on the most uncomfortable thing that position has to swallow.

Stuff that should show up somewhere as a node or a case:

- Is there a fact of the matter about what a net represents, or does it depend on the level of description you pick? Press it with: two interp methods that both predict behavior perfectly but disagree about which units are "the" features. Is one of them wrong, or just a different coordinate system?
- Does causal load-bearingness settle it? If patching or ablating a feature reliably moves the output, is that feature real, or just one intervention among many that happens to work? Include the nasty case where the effect is real but so is the effect of some gerrymandered alternative feature you cooked up.
- Are features discovered or built? If two people train sparse autoencoders (SAEs) with different seeds and get different dictionaries that all work, what is the claim "the model has these features" even asserting?
- Superposition. If a net stores way more features than it has dimensions, is the honest description "the features exist, just superposed" or "there's a big vector space and 'features' are a lossy readout we impose on it"?
- The deflationary option: maybe the whole vocabulary (represents, believes, attends-to) is a stance we adopt because it predicts well, and asking whether it's "literally true" is a category error. Does that view have to give up on interp being a science, or not?
- The hard eliminativist: nets are functions, "representation" is anthropomorphism, full stop. What's the strongest thing they have to explain away (steering vectors that transfer, probes that generalize, etc.)?

Then tell me which positions this actually separates. I specifically want these to come out as distinct leaves if they really are distinct, and if some of them collapse into each other, say so and tell me which case could split them apart if any:
- robust realism (features are the model's real computational parts)
- causal-mechanistic realism (real iff it's load-bearing for behavior)
- pluralism / no privileged basis (many equally good decompositions, "which one is real" is the wrong question)
- instrumentalism / useful fiction (SAEs are tools, not maps)
- the intentional-stance / real-patterns view
- full eliminativism (no representations, period)

Also flag any pair of leaves the tree can't split with the cases I gave. Dont paper over it, just say "these two answer every node the same, you'd need X to tell them apart."

Two more things: (1) note the empty cells, the combos of answers the tree allows that I bet nobody actually holds, and say for each whether it's empty because it's incoherent, because it's unattractive, or just because nobody bothered. (2) No reading lists or citations, I'm not gonna chase papers, I just want the structure and where the real disagreements are. If a node is secretly doing the work of three different debates, split it and say why.

Audience is smart but doesn't already know the labels, so no node can be phrased as "do you accept so-and-so's account of X."
