Building a handout for a grad seminar on the heterogeneity problem for hedonism -- the "what, if anything, do all pleasures have in common?" question. Give me a decision tree that starts from the plain fact that a warm bath, hearing good news, an itch you finally get to scratch, and the taste of sugar don't seem to share any single feature, and leads to a named position. Each branch node should be a question that actually splits the views (is there any one shared feature? if so, is it a sensory quality, a pro-attitude, or a representational content? is "pleasure" one natural kind or just a word doing several jobs?), phrased so a student can answer it without knowing where it leads. Leaves should include the sensory-quality view, the attitudinal/liking view, the desire-satisfaction view, a family-resemblance pluralism, and an eliminativist "no such kind" option -- name each leaf and add one line on its most awkward commitment. The tree has to route around two cases: the same bodily sensation feeling pleasant when you're cold and unpleasant when you're hot, and enjoying something you wish you weren't enjoying. Flag any leaves the tree can't tell apart, and say which branch of the space nobody actually seems to occupy.
