Two colleagues of mine who both work on making agents safer by giving them an incentive to leave the world as it is got into an argument I couldn't referee. One of them, Dana, had proposed a concrete measure: to score an action, compare the world it produces with the world the agent would have produced by doing nothing, and count how much the set of futures available to each other agent has changed; penalize that, and you get an agent that avoids side effects, with no utility function or theory of value anywhere in the definition. Ravi attacked this on three fronts. First, the measure is relative to a baseline, and doing nothing is not privileged: a surgeon who stays home has enormous impact relative to the world in which she operates, so calling her omission impact-free while her operating counts as impact gets things backwards. Second, counting other agents and their available futures requires deciding which things count as agents and what counts as a state, and that decision is where all the contested value actually sits, so the measure is value-free only if you pretend the hard part away. Third, an agent minimizing this measure will avoid beneficial interventions, and will also resist being corrected or shut down, since correction changes its own future options; the measure therefore fights the very compliance we wanted. Dana's replies: the baseline is a modeling choice like choosing a state space, not a value judgment; we don't need the true theory of what matters, only a conservative proxy that penalizes things we would all agree are side effects; and if self-directed effects are the trouble, exclude the agent itself from the measure, and note that a shutdown the operator chose is part of the plan, not a side effect. Neither convinced the other. Please go through the exchange move by move, say which of them is right about each point and why, then say what both of them are missing about whether side effects can be defined without a full specification of value.
