Ok, so I've been trying to figure out if there's a name for something. When I reason about stuff I don't know, I keep catching myself doing this move: if I've got no idea whether two things are related, I just treat them as unrelated and multiply the odds. I don't know if this job candidate is honest and I don't know if she's competent, so I figure the chance she's both is roughly half times half. Same thing when I'm doing a rough estimate — every unknown factor gets treated as independent of all the others and I just stack them up. It feels principled, like I'm not smuggling in assumptions, but it's clearly doing a huge amount of work, and sometimes its obviously wrong (two unknowns that are secretly the same thing get counted twice). Is there an established name for this exact default? I know about the principle of indifference and about maximum entropy, but those seem to be about spreading belief evenly across possibilities, whereas this is specifically about assuming independence between things I have no information about. If there's a name, what is it; if there isn't, what would you call it? And either way I want the actual boundaries — when does this default help, when does it blow up — not just a label.
