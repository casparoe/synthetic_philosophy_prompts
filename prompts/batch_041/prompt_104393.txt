I am assembling materials for a graduate seminar session in metaethics and normative theory — twelve students, ninety minutes — on the problem of the wrong kind of reasons, and for this session I want a classification instrument rather than a lecture. Please build a taxonomy, presented as a decision tree, of the positions one can hold on the following question: when some consideration gives an agent a reason to have a pro-attitude — a belief, an admiration, a fear, a desire, an intention — but does not bear on whether that attitude is correct or fitting, is that consideration a reason of a fundamentally different kind from the considerations that do bear on the attitude's fittingness, and if it is, what does the difference consist in?

Build the tree from the logical space rather than from a list of names. Settle first which combinations of answers to the branching questions are available, then locate actual positions in that space, and mark the combinations that turn out to be unoccupied, with a brief diagnosis of each: is nobody there because the view is incoherent, because it is coherent but unattractive, or merely because no one has explored it? Every branching node must be a single question with a small fixed set of answers, phrased so that a student can answer it without already knowing which position the answer leads to. No node may simply ask which label the student prefers.

The tree must represent both of the axes I care about, even if that requires the branches to interleave. The first axis is where the difference, if there is one, is located: in the content of the reason itself, in the nature of the attitude the reason is a reason for, or in the normative role the reason plays. The second axis is what sort of difference it is: a difference in kind, a difference only in degree or in strength, or not a difference in the reasons at all but a difference in what they are reasons for — having the attitude, on the one hand, versus bringing it about or wanting to have it, on the other. Make sure the tree also forces a decision about whether the problem extends uniformly to conative attitudes such as intention and desire, or whether it is an artifact of the cognitive case, and about whether anything changes when the attitude's fittingness is itself the effect of having the attitude.

The diagnostic nodes should be concrete cases, each stated so that it can be answered without labels. I want at least the following on the tree, though you may add others if the space requires them: a powerful being who will destroy something the agent cares about unless the agent comes to admire him; a pill that would induce a belief the agent has no evidence for, in a case where holding the belief would make the agent's life go better; a reward offered for feeling afraid of something the agent knows to be harmless; an offer of payment for forming the intention to perform an action that, when the time comes, the agent will have no reason to perform; and a reason to be amused by a joke that is not funny, offered by someone whose goodwill the agent needs. Phrase each node so that answering it commits the student to something, and make clear in the tree which cases separate which positions.

Each leaf must carry a name for the position — the standard label if a recognizable one exists, and a descriptive name otherwise — together with one sentence stating the commitment that position will find hardest to defend. Do not include a leaf unless it is a position someone could actually hold; if you find a leaf you can only populate by inventing a position, say so and explain why it is nonetheless worth marking.

Close the instrument in three parts. First, flag any two leaves the tree cannot separate, rather than papering over the gap, and say what further question would be needed to separate them. Second, identify which nodes are genuinely contested — that is, where the answer is a matter of substantive disagreement rather than of how carefully one reads the case. Third, add a short paragraph on what the instrument cannot do: which distinction a student is likely to think the tree has settled when it has not, and where the tree's verdict will be one my students will resist.

No citations, no reading list, and no dependence on attributions: if a recognizable label exists, use it, but the instrument must stand on its own without a single author's name.
