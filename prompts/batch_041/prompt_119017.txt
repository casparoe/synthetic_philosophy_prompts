Examination question:

Fitch's paradox of knowability is often presented as a refutation of the thesis that every truth is knowable. (a) State the knowability principle precisely. (b) Reconstruct the derivation that shows the principle, as stated, to be inconsistent with the existence of unknown truths. (c) Identify which principles governing the knowledge operator and which principles of modal logic the derivation actually requires. (d) Explain how a proponent of the knowability principle should respond, and what that response costs.

Student's answer:

(a) The knowability principle states that every truth can be known: for any proposition p, if p is true then it is possible that someone knows that p. Formally, p → ◇Kp, where K is the knowledge operator and ◇ is the possibility operator.

(b) Suppose there is a truth that nobody knows. Let that truth be p, so that p is true and p is not known. The conjunction "p and nobody knows that p" is therefore itself a truth. By the knowability principle, this conjunction is knowable, so it is possible that someone knows the conjunction: ◇K(p ∧ ¬Kp). Now knowledge distributes over conjunction — anyone who knows a conjunction knows each of its conjuncts — so the embedded knowledge claim entails Kp ∧ K(¬Kp). Knowledge is factive: if one knows that q, then q. So K(¬Kp) entails ¬Kp. Combining these, we obtain Kp ∧ ¬Kp, a contradiction. Since a contradiction cannot possibly be true, ◇K(p ∧ ¬Kp) must be false, which contradicts what the knowability principle delivered. So the assumption that there is an unknown truth is untenable: if every truth is knowable, then every truth is known.

(c) The derivation turns on two features of the knowledge operator. First, factivity — knowledge entails truth. Second, the KK principle, that if one knows something then one knows that one knows it, which is what licenses the move from the conjunctive knowledge claim to knowledge of each conjunct. On the modal side we need the distribution axiom of the normal modal logic K, and the proof is standardly run in S4, since the KK principle corresponds to the transitivity axiom.

(d) The lesson is usually taken to be that the knowability principle must simply be given up, since it has the absurd consequence that there are no unknown truths. That is a serious blow to verificationism and to anti-realist accounts of truth, which rested on the idea that truth is not evidence-transcendent. If one insists on keeping the knowability principle, one would have to deny that there are any unknown truths at all, which is plainly false — we do not know, for instance, how many hairs were on Caesar's head at noon on the Ides of March.
