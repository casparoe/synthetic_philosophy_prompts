In my concepts-and-categorization seminar we have been working on letterforms, on the question of what makes every 'a' an 'a'. The view I have found most attractive is that a letter has an essence: an abstract structure, a set of parts and relations among them, that every instance of the letter shares and that no instance of any other letter shares, with a typeface's style being a consistent way of rendering that structure in a particular hand. I tried to state the view carefully and ended up with an argument that seems to demolish it. I would like you to tell me where the argument goes wrong.

(1) Whether a shape counts as an 'a' depends on how it is categorized, and categorizing is something done by readers, or by a convention, not a brute physical fact about the shape.
(2) For any shape and any letter, we can imagine a reader or a convention under which that shape is that letter.
(3) So for any shape there is some convention under which it is an 'a'.
(4) If a shape is an 'a' under some convention, then that shape can be an 'a'.
(5) So every shape can be an 'a'.
(6) If every shape can be an 'a', then no shape is an 'a' in virtue of anything in itself.
(7) If no shape is an 'a' in virtue of anything in itself, then there is no essence of 'a'.
(8) Therefore letters have no essences.

The conclusion is the opposite of what I set out to defend, and it seems to prove too much: run the same argument on words, faces, or chairs and you conclude that none of those categories has an essence either. It also seems to dissolve the very notion of style along with essence. If any shape can be an 'a', then a coherent typeface and a random assortment of marks are on a par, since each is just one more shape that some convention could read as a letter; I do not believe that. The example that first made me worry is the single-story versus the double-story 'a', which seem to share nothing you can point to and yet are both unmistakably 'a', which is what pushed me toward an abstract essence in the first place.

Which step should I give up? I would rather keep (1), since I think it is simply true that categorization is done by readers, and I am attached to the conclusion that letters do have essences. Tell me which step is doing the illegitimate work, why it looked harmless when I wrote it, and what I have to pay to reject it, in particular whether giving up that step forces me to abandon anything else I have said I want to keep. Answer in no more than 600 words.
