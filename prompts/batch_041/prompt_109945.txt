I'm a software engineer with no formal training in philosophy, and I've been trying to work through the reference class problem on my own. I've gotten stuck on a passage in John Venn's *The Logic of Chance* (third edition, 1888, Chapter I). The first sentence that stops me is:

"Here then we have a class of things as to the individuals of which we feel quite in uncertainty, whilst as we embrace larger numbers in our assertions we attach greater weight to our inferences."

And a few paragraphs later, in the same chapter:

"In these classes of things, which are those with which Probability is concerned, the fundamental conception which the reader has to fix in his mind as clearly as possible, is, I take it, that of a series. But it is a series of a peculiar kind, one of which no better compendious description can be given than that which is contained in the statement that it combines individual irregularity with aggregate regularity."

My difficulty is this. The reference class problem, as I understand it, is precisely that a single individual belongs to indefinitely many classes, and the frequency of the outcome of interest can differ sharply from class to class. So which series is *the* series? Does Venn's requirement of aggregate regularity work as a criterion for selecting the right reference class — namely, the class in which a stable limiting frequency actually exists — or does he simply assume that each event comes with a determinate series already attached, which would make the reference class problem invisible from where he sits?

Please walk me through what Venn is doing in this passage, and tell me whether his notion of a series helps with, sidesteps, or silently presupposes a solution to the reference class problem. I'm also unsure whether "combines individual irregularity with aggregate regularity" is meant as a definition of a probabilistic series, a test for one, or something else — and if it is a test, how one could ever apply it to the single case I actually care about, since I can observe only one instance of the event in question.
