I recently read a blog post explaining the Pasadena paradox, and I want to know how much of it I should trust. The post says:

"The Pasadena game is a coin-tossing game: you flip a fair coin until it comes up heads, and if it takes n flips, you win (-1)^(n-1) × 2^n / n dollars (so $2 on the first flip, -$2 on the second, about $2.67 on the third, -$4 on the fourth, and so on). The expected value is the alternating harmonic series 1 - 1/2 + 1/3 - 1/4 + ..., which is not well-defined because you can reorder the terms to get any number you like. So the Pasadena game has no expected value, just like the St. Petersburg game has an infinite one. The lesson is that expected value maximization is not a coherent decision rule, and no amount of mathematical sophistication can fix that. The Altadena game — same as Pasadena but every payoff is increased by a dollar — makes it even sharper: since Altadena is obviously better than Pasadena, but neither has a well-defined expectation, the expected-value rule cannot even rank two games where one dominates the other. So we should abandon expected value maximization."
