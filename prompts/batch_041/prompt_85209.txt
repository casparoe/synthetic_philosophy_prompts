My reading group has an argument that I'm pretty sure proves too much, and I can't work out wich premise to drop.

(1) An agent that reasons at all should be able to trust its own reasoning: if it has genuinely proved P, it should be willing to treat P as true. Otherwise whats the point of proving anything?
(2) The agent's reasoning can be written down as a formal theory T -- a set of axioms and rules -- and T is strong enough to talk about its own proofs, so it can express 'P is provable in T'.
(3) So the agent should accept, for each sentence P: if P is provable in T, then P.
(4) She says there's a standard result in logic: if a theory of that kind proves 'if P is provable then P', then it already proves P. So if the agent takes all those instances on board as axioms, it gets a proof of P for every P -- of '0 = 1', and of its negation.
(5) So an agent that trusts its own proofs is inconsistent, and can't be rational.
(6) So (1) is false: no rational agent can trust its own reasoning, not even one step at a time.
(7) But (6) can't be right -- it would also show that any mathematician who believes what they've just proved is inconsistent, and the whole idea of an agent that reasons falls apart.

I want to keep (1). So which step do I give up, why did it look so plausible, and what's the price of keeping (1) instead? I'd especially like to know whether the trouble is in (3) itself or in the move from (3) to (4). Answer in British English.
