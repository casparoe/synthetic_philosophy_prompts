ok, I need a consistency check on my decision-theory commitments before I present them at a reading group, because I have a strong feeling that two of them are quietly at war and I honestly cant tell which one is the problem.

First, the two games everything hangs off, defined so we're on the same page.

Game A (the St. Petersburg one). Flip a fair coin until it lands heads. If the first heads is on toss n you win 2^n dollars. So: 2, 4, 8, 16, ... with probabilities 1/2, 1/4, 1/8, ... Expected money is 1 + 1 + 1 + ... = infinite.

Game B (the Pasadena one). Same flipping, but if the first heads is on toss n you win 2^n / n when n is odd and lose 2^n / n when n is even. So the payoffs run +2, -2, +8/3, -4, +32/5, ... Sum them in that natural order and the expectation is 1 - 1/2 + 1/3 - 1/4 + ... = ln 2. But the series is only conditionally convergent: reorder the terms and you can make it sum to any real number you like, or blow up. There's no single well-defined sum.

Here's where I've landed.

(a) The correct theory of rational choice is maximize expected utility. My utility-of-money function is increasing and bounded above (it flattens out at large sums; I'm also a bit risk-averse).

(b) Preferences are complete and transitive: for any two options, one is at least as good as the other.

(c) Game A has infinite expected money, but I wouldn't pay more than about twenty bucks to play it, and I think that refusal is completely rational. Infinite expected money doesn't obligate me to pay anything finite, because it's expected utility that does the work, and mine is finite.

(d) Game B has no well-defined expected value at all, so expected utility theory just returns no verdict on it. I think playing it and declining it are both rationally permissible; there's no fact of the matter about which is better.

(e) A limit principle I'm fond of: if I'd accept a bet at every finite truncation of a game, I should accept the full game too. Rational choice should be the limit of rational choices on the approximations. (Each finite truncation of Game B is a bet I'd take, by the way -- they all have positive expectation.)

(f) Description invariance: the value of an option can't depend on how it's described or on what bookkeeping I use to work it out. Two different ways of writing down the same game can't give different answers about what it's worth.

So: which of these actually pull against each other, which only look like they do, and for each real clash what's the cheapest fix and what does it cost me? Rank the tensions by severity rather than dumping them all out as equally bad, and if any pair is flatly inconsistent rather than merely in tension, say so straight. I've got a hunch that one of these is doing quiet damage somewhere, but I can't see where, so please dont be polite about it.
