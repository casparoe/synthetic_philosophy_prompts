Over the past few years I have spent a great deal of time in the decision-theory corners of the rationalist internet — the long-running arguments about Newcomb problems, superrationality, and whether an agent should treat its own decision procedure as something other agents can predict — and I keep encountering a construction that is presented as the clean formal version of the underlying idea. The setup, as I understand it, replaces the one-shot Prisoner's Dilemma with a game in which each player submits a program rather than a bare action, and each program is permitted to read the other's source code before returning an output; a Nash equilibrium of that enlarged game is what people call a program equilibrium. The headline result is that mutual cooperation can be an equilibrium: each side submits a program that returns cooperate exactly when the other program, run against it, returns cooperate — or, in the more elaborate versions, a program that cooperates whenever it can prove, within some shared formal system, that its opponent cooperates against it, and defects otherwise — and neither side can improve by substituting a different program. The people I read treat this as having settled the old debate: two sufficiently reflective agents cooperate in a one-shot Prisoner's Dilemma, so defection is simply a mistake that a cleverer agent would not make, and the dilemma was an artifact of modelling strategies as bare actions rather than as procedures.

I suspect I am holding this wrong, because the conclusions I keep drawing from it feel much too strong. If mutual cooperation is the equilibrium, then it seems I should also conclude that real defection — in arms races, in climate bargaining, in ordinary competitive markets — is best explained as a failure of legibility: the parties cannot inspect one another's source code, so they fall back on defection, and the remedy is to make each side's policy verifiably transparent to the other. And since the mechanism, as I understand it, has each program simulate the other and condition on the result, the trick ought to bite only for agents with unbounded time and no risk of a simulation that never halts, which would make the whole construction a curiosity about ideal reasoners, with no purchase on anything an actual institution could do.

So: is the legibility reading correct, and if so, what is the concrete proposal supposed to be — should I be reading the program-equilibrium literature as recommending that adversarial parties publish verifiable policies? If not, where exactly does my reasoning come apart? And I would like to know what the construction actually establishes about the original dilemma, since the way it is cited suggests that the dilemma has been dissolved rather than relocated.
