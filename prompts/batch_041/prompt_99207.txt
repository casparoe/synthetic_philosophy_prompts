Question: Explain Skolem's paradox. Does it show that ZF is inconsistent, or that there are no uncountable sets? How can a countable model of ZF satisfy the claim that there is an uncountable set? In your answer, say what is and isn't absolute between the model and the metatheory.

Student answer: Skolem's paradox is the apparent conflict between the Löwenheim–Skolem theorem, which says that every consistent first-order theory with an infinite model has a countable model, and ZF's theorem that there are uncountable sets. So ZF has a countable model M. Inside M, the set M calls P(ω) is uncountable, because M satisfies Cantor's theorem that there is no bijection from ω onto P(ω). But from outside M we can enumerate all the elements of M, so M's P(ω) is really countable. The missing bijection is not in M, so countability is not absolute. This doesn't show ZF is inconsistent, because the theorem only gives a model if ZF is consistent, and it doesn't show there are no uncountable sets, because the set that M thinks is P(ω) is not the real P(ω); it only contains the subsets of ω that are definable in M. It also shows that first-order logic cannot pin down the intended interpretation of uncountable, so Skolem concluded that set-theoretic notions are relative. One subtlety: the model's ω must be the standard ω, otherwise finite and countable would be interpreted non-standardly. And the paradox would disappear if we used second-order ZF, since the Löwenheim–Skolem theorem does not apply to second-order logic.
