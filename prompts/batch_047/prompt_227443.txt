so i've been reading about judgment aggregation and the discursive dilemma and every paper i open proposes its own pet aggregation rule and then defends it with one handpicked example. before i read another one i want the spec first: what does a rule for merging individual judgments into a collective judgment actually have to do to count as adequate?

setup so we're on the same page: three judges, agenda is p, q, and (p and q). judge 1 accepts all three, judge 2 accepts p but not q (so rejects the conjunction), judge 3 accepts q but not p (so rejects the conjunction). majority vote on each issue separately gives you: accept p, accept q, reject (p and q) -- an inconsistent collective judgment set. the premise-based procedure (vote on p and q, let logic decide the conjunction) and the conclusion-based procedure (vote on the conjunction directly) give different collective judgments on the same profile. that's the problem any rule has to face.

so write me the desiderata list. things like: the output always has to be consistent and deductively closed (collective rationality), the rule has to work for any profile of complete consistent individual judgments (universal domain), it shouldn't matter which voter cast which ballot (anonymity), it shouldn't play favorites between logically symmetric issues (neutrality), the verdict on each issue should depend only on individual verdicts on that issue (independence), adding support shouldn't flip an accepted issue to rejected (monotonicity). feel free to add ones i missed or reframe these. for each desideratum: the case or profile that motivates it, i.e. what goes wrong if you drop it. and i want your judgment calls on three things:

1. which of these are genuine desiderata any rule owes us vs which are just the prejudice of a particular camp (e.g. is full universal domain actually reasonable, or is it fine to only promise consistency on "easy" agendas?)
2. which subset is jointly unsatisfiable -- the List-Pettit style impossibility results basically say you cant have all of them at once on rich enough agendas, and i want the list to say exactly which combination breaks and why, since that's the interesting part
3. which single desideratum knocks out the most rules people actually propose (my money is on independence, but argue it)

then, briefly, score the obvious contenders against the list: premise-based, conclusion-based, quota/threshold rules, and distance-based rules (pick the consistent judgment set that minimizes total distance from the profile). keep the scoring short -- the criteria are the deliverable, the scorecard is just so i can see the list doing work.
