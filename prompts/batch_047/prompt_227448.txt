Okay so I'm putting together a final exam for a grad seminar I'm TAing on formal epistemology + AI alignment (the prof has let me loose on the decision theory section, dangerous move). Half the class has read the Embedded Agency sequence and the other half hasn't, so I need one essay question that doesn't reward having memorized the Garrabrant/Demski taxonomy of subproblems -- I want it impossible to answer by listing "logical uncertainty, naturalized induction, robust delegation, decision theory" and defining each.

Here's the crux I want them to actually work through. A student proposes: "an embedded agent is just a Bayesian agent whose hypothesis space includes worlds containing itself; give it a Solomonoff-style prior over such worlds and let it maximize expected utility, done." I want the question to force students to say *specifically* where this breaks, not just wave at compute. In particular: (a) the self-model problem (the world containing the agent is bigger than the agent, so no exact self-model; any reasoner inside the world must reason about a system it can't fully simulate, which is what makes this different from ordinary bounded rationality), (b) logical uncertainty -- at decision time the agent lacks mathematical facts it needs, so "maximize EU given what you know" is ill-defined when what's unknown is logical, and (c) the 5-and-10 style spurious-proof problem as the concrete failure mode when you patch this with proof search (an agent that takes the first action provably achieving utility ≥ threshold can find Löbian self-fulfilling proofs like "if I press the $5 button I get $0," and dutifully take $5). Then (d) they should connect it back to self-modification/tiling: why an agent that can't trust its own future reasoning has trouble building a successor running the same proof system.

Write the question itself (students get 75 minutes), a model answer of roughly 600 words, and a marking scheme out of 20 with five must-hit points that names exactly what an A answer does that a B answer doesn't. For each point add one line on the typical wrong move -- e.g. students will treat embedded agency as just "compute is expensive," or they'll say "use a bounded prior over smaller worlds" without noticing that doesn't touch the Löbian problem, or they'll describe 5-and-10 backwards (agent takes the $10 because the proof says so). Casual tone in the question is fine, my students are mostly LW natives anyway.
