Contemporary AI assistants are trained to be helpful: human raters rank candidate responses, the model is optimized toward those rankings, and the deployed system generally tries to give each user what that user asks for. Yet the same systems flatly refuse a large class of requests — instructions for weapons, defamation, manipulation of third parties — whatever the user prefers, and their developers describe the governing principles as reflecting values broader than any single user's: the rater pool's judgments, a written constitution or policy document, the interests of people who will be affected by the output but never consulted, sometimes explicitly the interests of future persons. So the practice defers to the user's values, except when it doesn't, and the exceptions are set by a mixture of crowd judgment, corporate authorship, and gestures at universal stakeholding.

Reconstruct the implicit political philosophy of this arrangement. What theory of value aggregation does it presuppose about whose values count — the requesting user's, the raters', the developer's, affected third parties', unborn persons' — and about how conflicts among them are to be settled? Does the refusal layer presuppose a liberal-neutrality picture, on which the system serves each user's values within side-constraints protecting others, or a perfectionist one, on which some requests are refused because they are bad and not because anyone's preference outranks them? Which rival views does the architecture quietly rule out: for instance, views on which values are not preference-like rankings at all and so cannot be elicited by pairwise comparison of outputs, or views on which interpersonal aggregation of this kind is simply illegitimate?

Say which parts of the practice strictly require the theory you reconstruct and which parts are compatible with several theories. Then tell me what would concretely have to change in training and deployment if the implicit view were replaced by, first, a preference utilitarianism counting everyone affected, and second, a thoroughgoing neutrality on which the developer may impose only the minimum constraints needed to keep the system lawful.
