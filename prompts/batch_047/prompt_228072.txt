ok so background: I'm a software engineer, no philosophy training, but I've been messing around with a bioinformatics side project and fell down a rabbit hole about whether DNA is "really" a code or whether that's just a metaphor everyone got lazy with. I've landed on the following set of views and want to know if they actually hang together before I embarass myself in a blog post:

1. The genetic code is a code in the literal sense, not a metaphor. The codon-to-amino-acid mapping is arbitrary — it could have been otherwise, and there are in fact organisms with slightly variant codes — and arbitrariness is exactly what makes something a code rather than just chemistry. Morse code is arbitrary too.

2. Codes only have content because of conventions agreed by symbol-users. If nobody stipulates the mapping, there's no meaning, just causal regularities.

3. There is no designer or mind behind the genome. Natural selection fully explains why the mapping is what it is.

4. Information talk in biology is genuinely explanatory, not just a convenient shorthand. "This gene encodes that protein" tells you something a purely chemical description doesn't.

5. When people call a mutation a "transcription error" or a "typo", that's loose talk. Chemistry can't make mistakes, it just does what it does.

6. Part of what makes me doubt the arbitrariness thing, honestly, is that the code is nearly universal across all life. If it were genuinely arbitrary I'd expect different lineages to have landed on totally different codes.

Which of these are in genuine tension, which only look like they are, and what's the cheapest fix if something has to give? Please rank the tensions by severity rather than flagging everything as equally bad, and for each one say what I'd have to drop or soften to resolve it. I don't have a strong sense of which commitment I'd sacrifice, so don't assume one.
