Background so this is self-contained: Solomonoff's universal prior gives each hypothesis about the world a probability that falls off exponentially with the length of the shortest program that would generate it, so it's the standard formalization of Occam's razor, and induction using it provably converges on the truth for any world whose data comes out of a computable process. Now the argument, which a friend of mine swears is airtight. (1) A rational agent acts so as to maximize expected value. (2) Computing an expected value requires a prior over hypotheses. (3) The right prior is the universal prior, for the reason just given. (4) That prior charges you for the length of the rule that generates a world, not for how much the world contains, so a world with one person in it and a world with 10^40 people churned out by the same short physics can be nearly equally cheap to write down. (5) In the crowded worlds the total amount of value at stake is astronomically larger. (6) Expected value is additive across the people an action affects. (7) So the expected value of anything I do is dominated by its consequences in the crowded hypotheses, however improbable they'd look to me on ordinary grounds. (8) So the rational thing is to do whatever maximizes value in the biggest worlds: try to please whoever's running the simulation, maximize the number of future minds, hand my savings to a stranger who claims he'll otherwise run a vast number of tormented simulations. (9) But an agent whose entire life is organized around hypotheses he can't test and would otherwise have called science fiction isn't rational, he's a crank. (10) So one of (1) through (7) is false.

I'd rather keep (1) and (3) if I possibly can, I'm not giving up expected value maximization or Occam's razor, they've earned their keep, so which step is the one to drop, and what does dropping it actually cost me?
