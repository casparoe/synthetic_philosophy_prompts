I am a software engineer with no formal training in philosophy, and I have been asked to help design the final assessment for a graduate seminar on decision theory. The instructor wants one essay question on the Pasadena game and the problem of undefined expected values. I need you to write the question, a model answer of roughly 700 words, and a marking scheme that distinguishes an A from a B answer by naming the specific moves each must contain.

The question should be aimed at students who have already seen the St. Petersburg paradox and the standard expected value maximization framework. It should be answerable in 90 minutes and worth 25 marks. It should not be answerable by simply reciting a summary of the Pasadena game or by saying that its expected value is undefined; it should force students to explain why the undefined expected value is a genuine problem for standard decision theory, not merely a mathematical curiosity, and to evaluate at least one proposed response.

To make the question self-contained, here is the setup you should use. The Pasadena game: a fair coin is tossed until it lands heads for the first time. If heads appears on toss n, the payoff is (-1)^(n+1) * 2^n / n. So the payoffs are +2, -2, +8/3, -4, +32/5, and so on. The Altadena game: same setup, but the payoff is 2^n / n, so all payoffs are positive. The expected value series for the Pasadena game is the alternating harmonic series, which is conditionally convergent; its terms can be rearranged to yield any real number or diverge to positive or negative infinity. The Altadena game has an infinite expected value, and it dominates the Pasadena game in every outcome.

The question should ask students to do the following: (1) explain why the Pasadena game's expected value is undefined rather than infinite, and why this is not just a technicality about infinite series; (2) explain what this implies for the principle that a rational agent should maximize expected value; (3) evaluate whether the dominance relation between the Altadena and Pasadena games offers a way out for the expected value maximizer, or whether it leaves the core problem untouched; and (4) assess at least one other response, such as restricting decision theory to games with well-defined expectations, adopting a bounded utility function, or using a non-expected-value criterion like stochastic dominance or median payoff.

The model answer should be self-contained and should not rely on citations. It should make clear why conditional convergence matters: because the order in which you sum the probability-weighted payoffs changes the result, so there is no fact of the matter about what the game is worth in expected value terms. It should distinguish this from the St. Petersburg case, where the expectation is infinite and the problem is that the theory says to pay any finite amount. It should explain that the Pasadena case is worse because the theory is silent: it does not even say the game is worth infinity. It should discuss the Altadena game as a contrast: Altadena has an infinite expected value and dominates Pasadena, so if you are choosing between them, dominance reasoning might seem to favor Altadena, but that does not tell you what to do if you are offered the Pasadena game alone, and it does not restore a well-defined expected value to Pasadena. It should then evaluate one or more responses: for example, one might say that standard decision theory should be restricted to prospects with well-defined expectations, but then it fails to guide choice in this case; or one might say that we should use a bounded utility function, but that changes the subject from monetary payoffs to utilities and does not solve the problem for the original game; or one might say that we need a different decision rule altogether, such as maximizing the median or using stochastic dominance, but those rules have their own problems. The model answer should conclude by saying what the case shows: either that expected value maximization is incomplete as a theory of rational choice, or that it needs to be supplemented by a theory of how to handle undefined expectations, or that the Pasadena game is not a legitimate prospect for some other reason.

The marking scheme should be built around five must-hit points, each worth 5 marks, for a total of 25. The points should be: (1) correctly explains that the Pasadena game's expected value series is conditionally convergent and therefore undefined, and why rearrangement can yield any value; (2) distinguishes undefined from infinite, and explains why the Pasadena case is a different and arguably deeper problem than the St. Petersburg case; (3) explains what this implies for expected value maximization: the principle cannot rank the Pasadena game against other prospects, and so it fails to be a complete decision rule; (4) discusses the Altadena game and the dominance relation, and correctly notes that dominance can sometimes guide choice between the two games but does not solve the problem of evaluating the Pasadena game on its own; and (5) evaluates at least one proposed response, such as restricting decision theory, bounded utility, or non-expected-value criteria, and states what the case shows about the limits or prospects of standard decision theory.

An A answer must make all five moves, with the first two explained in a way that shows understanding of the mathematics, not just the labels. A B answer might make three or four of the moves, or might make all five but treat the undefined expected value as a mere technicality, or confuse undefined with infinite, or fail to see why the dominance relation does not fully resolve the problem. The marking scheme should also note common mistakes: saying the expected value is zero, saying it is infinite, saying that rearrangement is irrelevant because the probabilities are fixed, or thinking that the Altadena game's infinite expected value means the Pasadena game must also have an infinite expected value.

Please write the exam question first, then the model answer, then the marking scheme. The question itself should be no more than 150 words, so that students have room to write. The model answer should be about 700 words. The marking scheme should be clear and usable by a teaching assistant.
