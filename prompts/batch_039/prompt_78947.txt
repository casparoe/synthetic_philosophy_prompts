I've been trying to pin down the conceptual issue behind supertasks, and Thomson's lamp keeps defeating me. The setup, as I understand it: a lamp starts off, is switched on half a minute before noon, off a quarter of a minute before noon, on an eighth of a minute before noon, and so on, so that the switch is thrown infinitely many times before noon. The standard verdict is that there is no fact of the matter about the lamp's state at noon, because the states alternate and never settle, so any answer is as consistent with the flips that were actually carried out as any other, and the question is simply ill-posed. I can recite that, but I don't see what licenses it. A friend told me I should just accept it the way I accept that Achilles catches the tortoise, since I already grant that an infinite sequence can have a finite limit; but that seems to run together two different things — whether there is a state at noon at all, and whether anything fixes which state it is — and it is the second that is supposed to be the problem.

Here is a variant that I think isolates the real issue. Replace the toggle switch with a lever whose position is a real number, and let the lamp be on exactly when the lever is past the midpoint at 1/2; the lever starts at 0 and the lamp is off. A machine nudges the lever at the same shrinking intervals, and I can tune the nudges so that the lever's positions form a sequence converging to 1/2 while landing alternately above and below it — 1/4, then 5/8, then 7/16, then 17/32, and so on. The lever's trajectory is continuous and its positions converge perfectly well, yet the lamp still flips forever and its state never settles, so this case looks just as undetermined as the original. That makes me suspect the culprit was never the non-convergence of the underlying physical quantity; it is that the lamp's state is a discontinuous function of that quantity, so convergence in the physics buys nothing. But if I retune the nudges so the lever converges to a value away from the threshold, the lamp's state converges too, and if it converges exactly to 1/2 the verdict seems to depend on whether the rule counts the boundary as on or off, which feels like a separate worry about how sharp the rule is rather than about the supertask.

So what I want is an explanation of the conceptual issue itself: what, if anything, makes Thomson's lamp ill-posed, whether there is a principled criterion for when a supertask has a determinate outcome, and whether my lever construction shows the usual convergence-based story to be confused or merely incomplete. I would rather have the underlying picture than the potted Zeno moral. Please write it as continuous prose, with no headings, bullet points, bold, or tables — just paragraphs, the way you would write a long email.
