Here is the position I want restated, as I understand it. The KK principle says roughly that if one knows that p then one is in a position to know that one knows that p. Its usual generalization is a luminosity claim about some condition C: necessarily, for any case in which C obtains, the subject in that case is in a position to know that C obtains. The standard argument against it — usually credited to Timothy Williamson, though the provenance does not matter to me — runs roughly as follows. Take a condition like feeling cold, and a fine-grained series of cases running from one in which it clearly obtains to one in which it clearly does not: successive moments on a morning as a room slowly warms, each case differing from the last by less than any margin you like. Suppose the condition were luminous. In the first case it obtains, and so by luminosity the subject is in a position to know that it does. Now add the premise that knowledge, or being in a position to know, requires a margin for error: a subject can be in a position to know that C obtains in a case only if C also obtains throughout some neighbourhood of nearby cases, since otherwise the verdict would be too fragile to count as knowledge at all. From that margin the argument gets C obtaining in the next case of the series; luminosity then makes the subject able to know it there; the margin carries the condition one step further; and by induction the condition is dragged all the way to the far end of the series, where by construction it does not obtain. So no non-trivial condition is luminous, and the KK principle goes with it if knowing is supposed to be a condition one can always tell that one is in.

I have a variant I want put through the same treatment. Call a condition epsilon-luminous when, for any case in which C obtains robustly — that is, obtains throughout an epsilon-sized neighbourhood of nearby cases and not merely at the case itself — the subject is in that case in a position to know that C obtains. My suspicion is that this blocks the induction, because the margin the argument delivers at one case does not obviously re-establish the robust obtaining needed to trigger luminosity at the next, and my further suspicion is that this is not a real escape but only the familiar "luminosity holds for clear cases" reply wearing quantitative clothing. I would like you to tell me whether those two suspicions are consistent or whether one of them is confused.
