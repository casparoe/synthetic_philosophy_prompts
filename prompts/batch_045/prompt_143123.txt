ok so i fell into a rabbit hole a couple weeks ago abt the pasadena game and i cant stop thinking about it and i think ive talked myself into a position that might be dumb, so here goes.

the setup as i understand it: you flip a fair coin until it lands heads. if that takes n flips the payoff is plus-or-minus 2^n/n with the sign alternating, so the first few payoffs are something like +2, -2, +2.67, -4, and so on, growing. prob of exactly n flips is 1/2^n, so each term's contribution to the expected value is plus-or-minus 1/n — which means the EV is the alternating harmonic series. add it up in that order and you get ln 2, about 0.69. but its only conditionally convergent, so rearrange the terms and you can make it add up to whatever number you want. so the EV isnt infinite like in st petersburg, it just doesnt exist.

my position: this is a real problem for "maximize expected value" as a rule for how to decide things, not a cute technicality for people who like series. and the move where you just say "fine, add the terms up in the order they come and its 69 cents" is cheating, because the order you add numbers up in isnt a fact about the world.

the version of the argument i came up with and think is my strongest: imagine a machine randomly permutes which payoff goes with which number of flips before you play, and you dont get to see the permutation. now there is no "natural order" built into the game at all — you just have a probability distribution over dollar amounts, and EV still spits out nothing. so "privilege the order the game was defined in" seems to me to secretly work by smuggling the describer's bookkeeping into reality. i also think the problem spreads: if one option in a choice has undefined EV, i dont see how you get to rank anything in that choice, even the other options that have perfectly normal EVs. that part im less sure about.
