Right, I think I've finally got quantum immortality figured out, and I'd like to actually use it rather than just marvelling at it — but everyone I mention it to waves it away with "yeah, but the branch where you live has almost no amplitude", which I definately think misses the point entirely.

The idea as I understand it: hook a gun up to a quantum trigger and pull it on yourself repeatedly. In the many-worlds picture both outcomes happen, but there is no version of you that experiences being dead, so the only futures you can ever find yourself in are the ones where the trigger jammed. So from the inside you're guaranteed to survive — and the amplitude objection doesn't bite, because the dead branches don't contain anyone to be disappointed. Measure is third-person bookkeeping; from the first person it's irrelevant. (I'm also assuming there's no real puzzle about which future continuer counts as me: obviously it's the live one.)

The bit I've been working on is a fix for the amplitude objection anyway, so nobody can hide behind it. Build the trigger as a coherent, reversible process: each round the machine couples the qubit to the firing mechanism, and whenever the outcome is "no fire" it then runs the inverse interaction and erases the which-outcome record. As far as I can tell the amplitude flowing into the surviving history then gets attenuated by nothing at all — only the rare firing rounds bleed amplitude off into dead branches. Now the survivor branch has measure ~1 and quantum immortality is literally true instead of a measure-zero freak show.

So, putting aside the boring real-world stuff (ageing, cancer, buses — none of it quantum-triggered):

1. Does this mean I should treat any risk that turns on a quantum event as free? Quantum roulette where I either wake up with £10m or the gun goes off: surely, by my own lights, the expected value is just £10m?

2. With the reversible machine, am I right that the survival amplitude is preserved, so the run is genuinely cost-free? And if so, is there any reason not to run it a few billion times in a row and then collect?

I've read plenty of popular many-worlds stuff already, so I'm not after reading suggestions — I want to know where the reasoning actually breaks, because at the moment I can't see the hole in it.
