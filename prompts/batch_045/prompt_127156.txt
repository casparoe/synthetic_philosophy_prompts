The specific thing I'm proposing is what I've been calling hot decoys. Every run gets randomly assigned to real or decoy, and the model can't tell which, because in a decoy run the bad thing actually works: we hand it a live-looking exfil path and a convincing fake success, and we deliberately do NOT intervene, because decoys that bust the model are exactly why normal honeypots stop working after a while. The payoff isn't that we catch any particular attempt — it's that the decoy cohort is fully instrumented, so the defection rate we measure on decoys is an unbiased estimate of the rate on real runs, since the model can't condition on a bit it can't see. That gives us an actual number for "how often does this thing try to exfil when it thinks nobody's looking," which right now we have no way to get at all. Control as measurement, not prevention.
