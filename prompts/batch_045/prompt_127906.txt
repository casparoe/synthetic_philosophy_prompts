I'm writing up a short position paper on program equilibrium and the one-shot Prisoner's Dilemma, and before I commit to it I'd like an audit of whether my commitments hang together. Brief setup so we mean the same thing: instead of choosing an action, each player submits a program that takes the other player's program as input and outputs cooperate or defect; a pair of programs that cooperate iff their sources are identical forms a Nash equilibrium of this meta-game, so mutual cooperation is available in the one-shot game without repetition, binding contracts, or an external enforcer.

Where I've landed:

(1) This shows the usual "rationality requires defection" verdict to be an artifact of modelling agents as choosing bare actions, and so it solves the dilemma itself rather than merely solving a different game that resembles it.

(2) The move to programs is not a gratuitous enrichment of the model: any real agent is a mechanism mapping observations to actions, and the normal-form model is the degenerate case in which the mechanism ignores its input.

(3) Nothing exotic is needed to derive the result. It is an ordinary equilibrium of the meta-game, reached by best-response reasoning; I don't want to lean on any acausal or functional decision theory, or on the thought that both players "run the same reasoning."

(4) Source-matching is a toy. Real counterparts run different code implementing the same behaviour, and I doubt there is any cheap, principled, canonical test a program could apply for "does what I do" — so I doubt the construction scales to heterogeneous agents.

(5) Fragility is the practically important issue: if there is any chance my counterpart misreads my source as some other program, the matching bot defects and cooperation unravels; the real answer, I think, has to come from the proof-based variants — cooperate if you can prove the other cooperates, with a self-referential fixed-point argument of the Löb variety doing the work.

(6) Case verdict: against a counterpart I know for certain has submitted an unconditional defector, I should defect, and there is no residual sense in which cooperating is the rational thing to do.

Go through the set and tell me which commitments are genuinely in tension, which only look as though they are, and — for each real tension — what would have to give and what that revision would cost me. Rank the real tensions by severity rather than treating them as equally bad, and say whether a single revision would clean up more than one. I would rather you identified the commitment that is doing work it cannot do than reassured me that the package is broadly reasonable.
