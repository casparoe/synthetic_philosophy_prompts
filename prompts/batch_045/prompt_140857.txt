Bit of an odd question, hope it fits here. I'm a backend dev who reads interpretability writeups on the train, so I probly get the vocabulary wrong.

I keep noticing the same move in these papers and I don't have a word for it. Two cases.

Case one: they run the model on sentence A, grab the internal numbers at some middle layer, force those numbers into the run on sentence B, and the output changes the way you'd expect if the model now 'thought' whatever sentence A was about. Then they say the model represents that thing at that layer. But the numbers they pasted in were an average over ten sentences, so its a combination the model would never arrive at on its own, on any input.

Case two: someone finds a direction in the same space. Scale up the activations along it and the model won't stop talking about bridges. But if you instead flatten out that direction, normal text output barely changes.

So there's a gap between 'I can push here and the model follows' and 'the model puts itself in this state and reads it off'. The first is treated as enough for 'the model has a representation of X'; the second is what I'd naively want, and I can't tell whether anyone checks for it.

Is there an established name for this gap — something like imposable-but-unused, or steering-available vs actually-consulted? I know there's the older philosophy move about a thermometer indicating temperature without representing it, and I've seen 'causal abstraction' thrown around for matching a program to a model's internals, but neither looks like quite my thing: the thermometer case is about whether mere indication is enough for content, while mine is about whether the state ever does any work; causal abstraction seems happy to count a state as a variable in the program even when you had to force it there by hand. It's also not latent knowledge, where the model has the right answer inside but doesn't say it — my worry is more basic, that nobody checks whether the inner bit is used at all.

If there's no name, coin one and define it, and either way give me the carving rather than the label: is this a difference of degree (how often the model lands near that state) or of kind; what about a state that's inert on almost every input but read off on rare ones; and what experiment would settle it. Answer as exactly five numbered points, one or two sentences each, no intro line and no summing-up at the end.
