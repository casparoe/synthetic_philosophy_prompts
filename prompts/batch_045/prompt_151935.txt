I'm applying for a one-year dissertation fellowship and need a two-page proposal for a project on whether DNA literally carries information in the sense in which a code does. Here is the half-formed idea I want turned into a proposal.

The usual dialectic asks whether the mapping from codons to amino acids is arbitrary, and so convention-like and in need of an interpreter, or chemically constrained, and so mere causation. I suspect both sides are arguing about the wrong feature. What makes something a code rather than a causal trigger is not the arbitrariness of the mapping but the availability of a distinction between being read correctly and being misread: a norm that a bare regularity does not supply. The question then becomes whether correctness of translational outcome can be naturalized at all, for instance by grounding it in the etiological function of the translation machinery rather than in a phenotype-relative notion of what the organism needs.

The twist I want the proposal to exploit is that the two marks of a code pull apart. Arbitrariness and normativity are usually treated as joint warrants for calling the genetic code a code, but if the standard code is in fact strikingly robust to single-nucleotide substitution and to translational error, an empirical claim I want taken as background rather than defended, then the mapping looks less arbitrary, and its structure looks shaped by selection for a standard of correctness it did not itself impose. That is either the strongest available argument that code talk is apt or the beginning of a reductio of it. I don't know which, and the proposal should say what would settle it.

Please give me: the question stated so that a yes and a no are both live outcomes; why the standard families of position leave it open, the information-theoretic and causal ones on the literalist side, the teleological and etiological ones in the middle, and the developmental-systems skeptics on the other; an approach built around cases where the code is violated rather than more conceptual analysis of the metaphor, working through mistranslation and transfer-RNA mischarging, programmed recoding such as frameshifting and stop-codon reassignment, divergent codes in some organelles and lineages, and synthetic systems in which codons are reassigned to non-canonical amino acids; a deliverable that a practicing molecular biologist could use to decide whether a given sequence-involving explanation is genuinely information-bearing; what would count as the project failing; how the argument changes if the error-robustness claim is false or exaggerated, since I would rather not have everything rest on it; and a work plan for the year with the point at which I would have to cut the project down.
