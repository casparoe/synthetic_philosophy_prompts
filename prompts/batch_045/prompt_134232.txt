Two people in my old stats department have been going at each other for months about Simpson's paradox, and I want the document they should have written instead of all the arguments.

Call the camps the Poolers and the Splitters. Poolers: report the overall (marginal) association, that's the number a decision-maker actually acts on, and the subgroup tables are mostly where you go to fool yourself. Splitters: the pooled figure is a weighted average with weights set by whoever happened to show up, so it's an artefact — condition on the partition that reflects how the world is actually structured.

Give me: (1) a numbered list of claims both can sign — both tables can be true at once, the reversal comes from unequal weights across strata, no table settles the question by itself, that sort of thing; (2) a table of the disagreements that are left, each row worded so that side would accept it as a fair statement of its own view; (3) the cruxes, and please seperate the genuine ones from the ones that were only ever about words.

Both sides accept these two cases as bearing on the cruxes, so write down each side's prediction in advance. Case A: two surgeons, one deliberately takes the nastier cases — worse overall, better within every severity band. Case B: a discharge follow-up programme whose main effect is getting patients to attend their outpatient appointment, audited after stratifying by whether they attended.

One wrinkle: the trust running case B can only roll the programme out to everyone or scrap it, no targeting. So part of the rule has to be about the action space, not just the causal story. Answer in British English, and keep it reasonably tight.
