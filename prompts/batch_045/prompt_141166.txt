Here are the two criteria I want pried apart. Call the first one bottom-up grounding (BUG): the classic Harnad-style requirement — a symbol is grounded for a system only if the system itself can, using its own non-symbolic sensorimotor apparatus, learn to discriminate the things the symbol picks out, bottoming out in iconic/categorical representations built from raw sensor input rather than in a dictionary of more symbols. Call the second one interventional grip (IG), which I'm making up: a symbol has grip for a system to the extent that (i) interventions which swap what is present systematically change whether the system tokens the symbol at all, and (ii) tokening the symbol changes what the system does next, including in an arrangement of the environment it was never trained on. Roughly: BUG asks how the symbol got hooked to the world; IG asks whether it currently tracks the world and steers anything.
