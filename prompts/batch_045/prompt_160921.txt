Hi — I'm putting together a one-page handout for the second-year philosophy of mind module I TA for, and I want it to be a decision tree rather than prose. The topic is the causal exclusion argument: the worry that if every physical effect already has a sufficient physical cause, and mental states aren't identical to physical states, then mental states don't cause anything. My students can recite the four claims fine, but they have no idea which combination of denials corresponds to which view, and they all end up declaring themselves non-reductive physicalists because it sounds safe. So I want something that sorts them by what they'll say about a case, not by the label they like. Don't put citations or paper titles in it — no bibliography, I'll add the reading myself — but do use the normal position names at the leaves so they can go look things up.

The case I've been using comes from my old job (I wrote simulation code before I switched to philosophy). There's a small agent in a grid world with a variable `thirsty` in memory, and whenever it's set the agent walks to the fountain. Today `thirsty` is implemented by voltage pattern V1; I port the code to new hardware and the same variable is implemented by a completely different pattern V2, and the behaviour tracks the variable, not the voltage. Three wrinkles I use in tutorials: (a) I can set `thirsty := false` in a debugger, but doing that also changes the voltages, so there's no intervening on the mental without intervening on the physical; (b) I can make the agent walk away from the fountain by writing straight to its motor-output register, bypassing the variable's usual route, which some students think shows the variable does no work; (c) I can describe the effect at a very fine grain (body moves at exactly t along exactly this path with exactly this force) or a coarse one (goes to the fountain), and the intuition flips depending on which I use. Please use this case, or improve it, as the spine of the tree.

Two things I care about more than coverage. First, the fault line I actually want exposed is between students who want to rescue the mental cause via a metaphysical relation between the mental and the physical (constitution, grounding, causal inheritance, token identity — the mental borrows its causal power from its realizer) and students who want to rescue it via a thesis about causation itself (interventionist difference-making, proportionality, causal pluralism, or the thought that the exclusion argument only bites if you assume causation lives at the fundamental physical level). I think that's the real split and the standard taxonomy hides it, so I want those branches to come apart early. Second, I have a half-formed conviction I want stress-tested: that the argument only looks forceful because people are imaging the effect at a fine grain, and that once you fix the effect coarsely the physical state stops being a candidate cause at all. If that's right, one branch of my tree might be empty; if it's confused, tell me where instead to put the grain-of-the-effect point.

Practical constraints: build it from the logical space rather than from a list of names — questions first, then place the actual positions in the combinations they occupy, and for any combination nobody occupies say whether that's because it's incoherent, unattractive, or just unexplored. Leaves should include at least: reductionist/type-identity, token-identity-with-inheritance, overdeterminationist, epiphenomenalist, eliminativist, interventionist or difference-making compatibilist, proportionality-based compatibilist, and the emergentist/dualist who denies closure and claims downward causation. The proportionality branch should have to face a gerrymandered property — something like `thirsty-or-it's-Tuesday` — so students see what that rescue might also let in. Every node should be phrased as a question a second-year could answer without knowing which position it leads to (so no "do you accept the causal closure of the physical?" at the top), aim for no more than about eight branch nodes and ten leaves so it fits on one side of A4, give each leaf one sentence on its most awkward commitment, and flag any pair of leaves your tree genuinely can't seperate rather than pretending the distinction is clean. If you think a short quiz version with a scoring key would work better than a tree for a handout, say so and do that instead, but keep the same requirements about sorting by cases.
