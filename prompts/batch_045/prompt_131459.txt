A podcast episode I was listening to explained acausal trade roughly like this:

'Two agents who can't send each other any signals can still trade. Each one's decision is correlated with the other's, because they're both working out what the same kind of agent should do in the same kind of situation. So if I cooperate with you acausally, the version of you that's algorithmically tied to me cooperates back, and we both end up with the payoff we'd have gotten from an actual bargain. It's basically the same reasoning as one-boxing in Newcomb's problem, and it's why functional decision theory says you cooperate in the twin prisoner's dilemma. It's also why you'd cooperate with a superintelligence that's simulated you: the simulation runs either way, so you can only gain by cooperating. The big upshot is that acausal trade is close to free money for any agent smart enough to model others — a sufficiently advanced AI should cooperate with basically any agent it can reason about, including us, and the more value the other side controls, the more there is to gain.'
