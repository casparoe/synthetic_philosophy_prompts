**Problem 3 (30 marks)**

Let W = {w₁, w₂, w₃}. A credence function is a vector c = (c₁, c₂, c₃) with cⱼ ≥ 0; it is *coherent* (probabilistic) iff Σⱼ cⱼ = 1. Write vᵢ for the i-th unit vector (1 in position i, 0 elsewhere) — the credence function that is perfectly accurate at wᵢ. Fix λ = (λ₁, λ₂, λ₃) with λⱼ > 0 for each j, and define the *stakes-weighted quadratic score*

s_λ(c, wᵢ) = − Σⱼ λⱼ (cⱼ − vᵢ,ⱼ)² = − [λᵢ(cᵢ − 1)² + Σ_{j≠i} λⱼ cⱼ²],

where λⱼ records how much the agent cares about getting the proposition {wⱼ} right; unequal weights model an agent for whom some distinctions matter more than others.

**1.** (a) [4 marks] Show that for every coherent p the quantity E_p[s_λ(c, ·)] = Σᵢ pᵢ s_λ(c, wᵢ) is uniquely maximized, over all credence functions c, at c = p, and give the maximum value. What does this show about how much the accuracy argument for probabilism depends on the weights?

(b) [4 marks] Say that a score is *truth-directed* iff, for every world w, s(c, w) > s(c′, w) whenever c is closer than c′ to v_w in ordinary (unweighted) Euclidean distance. Is s_λ truth-directed? Prove it or give a counterexample, and say in two or three sentences what your answer implies for whether s_λ can underwrite an accuracy argument for probabilism.

**2.** Say that c is *strictly dominated* (relative to a score s) iff some coherent p has s(p, wᵢ) > s(c, wᵢ) for every i.

(a) [3 marks] Take λ = (1, 1, 1) and write s for s_λ. Let d = 1 − Σⱼ cⱼ and c* = c + (d/3)(1, 1, 1). Show that s(c*, wᵢ) − s(c, wᵢ) = d²/3 for each i, and hence that every incoherent c with c* ≥ 0 is strictly dominated. What should be said when c* has a negative coordinate?

(b) [3 marks] Does the same construction work for arbitrary positive λ? Prove it or give a counterexample.

(c) [4 marks] Is it true for arbitrary positive λ that every incoherent c is strictly dominated? Prove it or give a counterexample.

(d) [3 marks] Let σ(c, wᵢ) = 1 if cᵢ > cⱼ for every j ≠ i, and σ(c, wᵢ) = 0 otherwise. Show that σ is proper but not strictly proper; show that some incoherent c is not strictly dominated relative to σ; and say what this shows about which feature of s_λ the domination argument relies on.

(e) [2 marks] Contrast: with the logarithmic score s_L(c, wᵢ) = log cᵢ, show that c = (0.9, 0.9, 0.9) is not strictly dominated. What is the moral?

**3.** Let E = {E₁, ..., E_k} be a partition of W, and suppose you are certain that you will learn which cell of E obtains. An *updating plan* is a map C assigning a credence function C(Eⱼ) to each cell; its ex ante value is

V(C) = Σⱼ p(Eⱼ) Σ_{w ∈ Eⱼ} p(w | Eⱼ) s_λ(C(Eⱼ), w),

where p is your current coherent credence function.

(a) [3 marks] Show that V is uniquely maximized by the conditionalizing plan C(Eⱼ) = p(· | Eⱼ), for any positive λ.

(b) [3 marks] Where exactly does this argument use the assumption that you will learn for sure which cell obtains? What would have to be established in order to extend the result to a case in which your experience merely shifts your marginals over E, without settling which cell obtains?

(c) [4 marks] State precisely what the result establishes and what it does not. Is a conditionalizer guaranteed to be more accurate, at the world that actually obtains, than someone who updates in some other way?

**Candidate's answer**

*1(a).* E_p[s_λ(c, ·)] = − Σᵢ pᵢ Σⱼ λⱼ (cⱼ − vᵢ,ⱼ)². Differentiating with respect to c_k:

∂/∂c_k E_p[s_λ(c, ·)] = −2 Σᵢ pᵢ λ_k (c_k − vᵢ,k) = −2λ_k(c_k − p_k),

using Σᵢ pᵢ = 1 and Σᵢ pᵢ vᵢ,k = p_k. So the only stationary point is c = p; and since the Hessian is −2·diag(λ₁, λ₂, λ₃), which is negative definite, the function is strictly concave in c and c = p is its unique global maximum. Substituting, the maximum value is

E_p[s_λ(p, ·)] = − Σᵢ pᵢ [λᵢ(1 − pᵢ)² + Σ_{j≠i} λⱼ pⱼ²] = − Σⱼ λⱼ pⱼ(1 − pⱼ).

So s_λ is strictly proper: expected inaccuracy by your own lights is uniquely minimized at your own credence function. The weights drop out of the first-order condition, so strict propriety holds for every positive λ, and the accuracy argument for probabilism is not hostage to any particular choice of stakes.

*1(b).* No, not in general. Let λ = (100, 1, 1), p = (0.9, 0.05, 0.05) and c = (1, 0.3, 0.3). Then ‖p − v₁‖² = 0.01 + 0.0025 + 0.0025 = 0.015, while ‖c − v₁‖² = 0 + 0.09 + 0.09 = 0.18, so p is closer than c to the truth-vector for w₁. But

s_λ(p, w₁) = −[100(0.01) + 0.0025 + 0.0025] = −1.005, and s_λ(c, w₁) = −[100·0 + 0.09 + 0.09] = −0.18,

so p is the less accurate of the two at w₁ despite being the closer. Unequal stakes make accuracy track weighted rather than Euclidean distance. This matters, because the accuracy argument for probabilism is normally motivated by two separable thoughts — that inaccuracy is distance from the truth, and that you expect your own credences to be the most accurate ones — and a stakes-weighted agent honours the second while violating the first. I argue in 2(c) that the argument survives anyway, because what the domination argument actually requires is strict propriety; but if one insists on truth-directedness as an independent platitude, then s_λ is not a legitimate measure of inaccuracy at all.

*2(a).* With c*ⱼ = cⱼ + d/3,

s(c*, wᵢ) − s(c, wᵢ) = − Σⱼ [(cⱼ + d/3 − vᵢ,ⱼ)² − (cⱼ − vᵢ,ⱼ)²]
= −(2d/3) Σⱼ (cⱼ − vᵢ,ⱼ) − 3(d²/9)
= −(2d/3)(Σⱼ cⱼ − 1) − d²/3
= 2d²/3 − d²/3 = d²/3,

which is strictly positive when c is incoherent, and is the same in every world. Since Σⱼ c*ⱼ = 1, c* is coherent; so, provided c* ≥ 0, it strictly dominates c. If some coordinate of c* is negative — which can only happen when d < 0, i.e. when Σⱼ cⱼ > 1 — take instead the Euclidean projection p of c onto the simplex Δ = {x ≥ 0 : Σx = 1}. The variational characterization of projection gives (c − p)·(x − p) ≤ 0 for every x ∈ Δ; putting x = vᵢ and expanding,

‖c − vᵢ‖² = ‖c − p‖² + ‖p − vᵢ‖² − 2(c − p)·(vᵢ − p) ≥ ‖c − p‖² + ‖p − vᵢ‖² > ‖p − vᵢ‖²,

so s(p, wᵢ) > s(c, wᵢ) for each i. Either way, every incoherent c is strictly dominated.

*2(b).* Yes. Positive weights are only a change of units: if s is strictly proper then so is any positive rescaling of it, and expected accuracy is maximized at the same credence function; the same holds here, since each λⱼ merely rescales the contribution of one coordinate. So for any λ > 0 the shift toward coherence still dominates, with

s_λ(c*, wᵢ) − s_λ(c, wᵢ) = − Σⱼ λⱼ [2(d/3)(cⱼ − vᵢ,ⱼ) + d²/9] = (d²/9) Σⱼ λⱼ > 0

in every world. The size of the improvement varies with λ, but its sign does not: an incoherent credence function is dominated however the agent distributes her concern across the worlds.

*2(c).* Yes. Repeat the projection argument of 2(a) using the λ-weighted inner product ⟨x, y⟩_λ = Σⱼ λⱼ xⱼ yⱼ, i.e. take p = argmin over Δ of ‖x − c‖_λ. The variational characterization now gives ⟨c − p, vᵢ − p⟩_λ ≤ 0 for each i, and expanding as before,

‖c − vᵢ‖_λ² = ‖c − p‖_λ² + ‖p − vᵢ‖_λ² − 2⟨c − p, vᵢ − p⟩_λ ≥ ‖c − p‖_λ² + ‖p − vᵢ‖_λ² > ‖p − vᵢ‖_λ²,

since c ∉ Δ and hence ‖c − p‖_λ > 0. As s_λ(x, wᵢ) = −‖x − vᵢ‖_λ², this says s_λ(p, wᵢ) > s_λ(c, wᵢ) for every i. So every incoherent c is strictly dominated under s_λ, for every positive λ. This is worth having in addition to 2(b): the projection route also avoids the nonnegativity caveat that besets the uniform shift when Σⱼ cⱼ > 1.

*2(d).* For coherent p, E_p[σ(c, ·)] = Σᵢ pᵢ σ(c, wᵢ) equals p_{i*} if c has a unique maximum at i*, and 0 if c has no unique maximum. This is maximized, at the value maxᵢ pᵢ, by any c whose unique maximum is a maximum of p; so σ is proper. It is not strictly proper: any two credence functions with the same argmax tie — (0.7, 0.2, 0.1) and (0.5, 0.3, 0.2) receive exactly the same expected score. Now take c = (0.6, 0.6, 0.6): σ(c, wᵢ) = 0 for every i, since c has no unique maximum. A strict dominator c′ would need σ(c′, wᵢ) = 1 for every i, i.e. would need a different unique maximum at each of the three worlds, which is impossible. So c is not strictly dominated relative to σ. This shows that the feature of s_λ doing the work is strict propriety: with a merely proper rule, an incoherent credence function can be no worse, world by world, than any coherent rival, and the weak domination that σ does deliver here tells us nothing about whether the incoherent agent is doing worse than she had to.

*2(e).* A strict dominator p of c = (0.9, 0.9, 0.9) would need log pᵢ > log 0.9 for each i, i.e. pᵢ > 0.9 for all three i, which is incompatible with Σᵢ pᵢ = 1. So no dominator exists; and the same argument works for any c with Σᵢ cᵢ > 1. Moral: the accuracy argument for probabilism is not neutral between scores. The logarithmic score rewards high credence in the true world without any compensating penalty for excess credence elsewhere, so credence functions that are globally over-confident escape; the quadratic scores, being bounded above by 0 and geometrical in form, have no such gap.

*3(a).* Fix j and write q_j = p(· | Eⱼ), which is coherent and assigns weight 0 outside Eⱼ. The inner sum in V is then Σ_{w ∈ W} q_j(w) s_λ(C(Eⱼ), w), and by 1(a) this is uniquely maximized, over credence functions, at C(Eⱼ) = q_j = p(· | Eⱼ). The outer weights p(Eⱼ) are nonnegative and sum to 1, so V is maximized by maximizing each inner sum separately: V is uniquely maximized by the conditionalizing plan. (Uniqueness is up to cells with p(Eⱼ) = 0, whose prescription does not affect V — there, conditionalization is not mandatory but merely permissible.) The argument uses only strict propriety, so it goes through for every positive λ.

*3(b).* The assumption enters at the definition of a plan. V is defined on maps from cells to posteriors, and the decomposition V(C) = Σⱼ p(Eⱼ) Σ_w p(w | Eⱼ) s_λ(C(Eⱼ), w) treats p(Eⱼ) as the probability that the agent receives input Eⱼ, so that the posterior she ends up with is a function of that input alone. If a soft experience merely raises the marginal of E₁ without settling which cell obtains, no cell is learned, there is no map from cells to posteriors to evaluate, and the decomposition is unavailable. To extend the result one would have to fix an ex ante value for a soft updating rule — for instance, asking which posterior compatible with the new marginals over E minimizes weighted distance from the prior. But that is a minimal-change principle, not an expected-accuracy argument, and it carries the further commitment that this particular distance, and hence rigidity within cells, is the right one. So the accuracy argument as stated does not vindicate Jeffrey-style updating; at best it is silent about it.

*3(c).* What (a) establishes is that conditionalizing maximizes the ex ante expected accuracy of the posterior, the expectation being taken with respect to the agent's own current credences. Two corollaries are worth separating. First, it is a genuine optimality result over plans: no alternative plan does better at every world, since if s_λ(C(E_w), w) exceeded s_λ(C*(E_w), w) at every w, then, p(w) being positive, we would have V(C) > V(C*). Secondly, since the argument can be rerun at each later stage with the then-current credence function in the role of p, conditionalizing maximizes expected accuracy at every stage of the inquiry. Because this holds at every stage and for every partition of possible inputs, the upshot is not merely an expectation: a conditionalizer is guaranteed to have been more accurate, at the world that actually obtains, than she would have been under any other updating policy, and so ends the inquiry with more accurate credences than any alternative policy would have given her. That is the sense in which conditionalization, and only conditionalization, is the rational updating policy.
