I need help predicting how a colleague will rule on two cases she has not yet ruled on, and I care less about the cases themselves than about what her existing table of rulings actually commits her to.

The setup, so that we are using the same vocabulary. Two players face a one-shot Prisoner's Dilemma: 3/3 for mutual cooperation, 1/1 for mutual defection, and 5/0 for the exploiter and the exploited. Rather than choosing a move, each player submits a program that receives the other player's source code, in full, as its input and returns C or D; the two programs are then run, and their outputs determine the payoffs. Whenever a program searches for a proof, it searches for a proof in first-order Peano arithmetic of at most L symbols, where L is a generous bound (10^9 unless I say otherwise); if no proof of that size exists, the search fails and the program takes its fallback action.

The programs that appear in her table:

- MATCH: return C if and only if the opponent's source is character-for-character identical to mine; otherwise return D.
- PROVE: return C if and only if there is a proof that the opponent returns C against me; otherwise return D.
- PRUDE: return C if and only if there is a proof that the opponent returns C against me and a proof that the opponent returns D against a program that always returns D; otherwise return D.
- SAINT: always return C.
- FINK: always return D.

Her rulings so far, in every case a claim about what the two programs actually output when run against each other:

1. MATCH against MATCH: both cooperate.
2. PROVE against PROVE, L = 10^9: both cooperate.
3. PRUDE against PRUDE, L = 10^9: both cooperate.
4. PROVE against PROVE, L = 200: both defect. She says the bound leaves no room for the handshake.
5. PROVE against FINK: both defect.
6. PRUDE against FINK: both defect.
7. MATCH against PROVE: both defect.
8. MATCH against SAINT: MATCH defects, SAINT cooperates.

The two cases she has not ruled on:

(A) PROVE against SAINT, L = 10^9.
(B) PROVE against PRUDE, L = 10^9.

My own guess is that she will report mutual cooperation in both, but I do not trust it: I can think of more than one rule that reproduces all eight verdicts, and those rules do not all agree here.

What I want from you: a verdict for (A) and for (B), each with the reasoning that produces it; the rule she seems to be running, stated explicitly enough that I could apply it myself to a pair of programs she has not seen; the other rules that fit all eight of her verdicts just as well, with what each of them predicts for (A) and for (B); which of the two cases does more of the work in telling those rules apart; and one further pair of programs, described precisely enough that someone could implement and run it, that would settle whichever candidates remain if her answers to (A) and (B) leave more than one standing. If one of the eight verdicts is doing most of the work in your prediction, say which one, and say what her ruling would have had to be instead to move you.
