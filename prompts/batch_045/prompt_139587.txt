(c) Is Russell's paradox essentially a paradox about self-reference? One answer, transcribed:

(a) Naive set theory is governed by the principle of naive comprehension: for any predicate φ of the language of set theory there is a set whose members are exactly the things of which φ holds, formally ∃y ∀x (x ∈ y ↔ φ(x)), with y not free in φ. Take φ(x) to be x ∉ x. This is perfectly well formed, since ∈ is a relation that can hold between any two sets and so can be applied to a set and itself. Comprehension then gives a set R such that ∀x (x ∈ R ↔ x ∉ x), and instantiating x := R yields R ∈ R ↔ R ∉ R. Reading the biconditional left to right, if R ∈ R then R ∉ R; reading it right to left, if R ∉ R then R ∈ R. Either way we obtain a sentence together with its negation, so naive set theory is inconsistent and, given that contradictions entail everything, trivial: it proves every sentence of the language. The diagnostic point worth stressing is that the argument never assumes that some set is a member of itself. What it establishes is that the Russell class is not a set. That is a limitative result about set existence rather than a proof that self-membership is incoherent, and it is consistent with the paradox that there be self-membered sets — class theories in the von Neumann–Bernays–Gödel style can treat the Russell class as a proper class while remaining consistent.

(b) The axiom of Zermelo–Fraenkel set theory that excludes the Russell set is the axiom of foundation, also called regularity. It says that membership is well founded: every non-empty set has an ∈-minimal element, and consequently no set is a member of itself. That is exactly the pattern Russell's set would violate, since the equivalence R ∈ R ↔ R ∉ R makes it both self-membered and not. This is Zermelo's way of implementing Russell's own vicious-circle principle — a collection may not contain objects specifiable only by reference to that very collection — and it is the deeper reason why ZFC has no universal set, since a set of all sets would have to contain itself. The axiom schema of separation, Aussonderung, is best seen as a corollary of the same thought rather than as the main engine: it tells us that a definable subcollection of an already given set is itself a set, and it is what deals with the paradoxes of size, such as Cantor's paradox, where a set of all sets would have to contain its own power set in violation of Cantor's theorem.
A response that is not merely a restriction on size is the stratification restriction of Quine's New Foundations. There comprehension is retained in full generality but only for stratified predicates: those for which variables can be assigned natural-number levels so that in every atomic x ∈ y the level of y is exactly one greater than the level of x. The predicate x ∉ x is stratified, since the variable on both sides of ∈ receives the same level, and so the Russell set exists in NF as a set; what saves the theory is that the universal set is stratified too and NF is otherwise very weak. The contrast with ZFC is that this is a syntactic restriction on which predicates may define sets, not a restriction on how big sets can be.

(c) Yes — the paradox is essentially one of self-application, and essentially classical. The equivalence R ∈ R ↔ R ∉ R is a fixed point of negation, and the step from that equivalence to an outright contradiction is an indirect proof: assume R ∈ R, derive R ∉ R, assume R ∉ R, derive R ∈ R, and discharge the assumptions. That step is what bivalence buys you. In an intuitionistic setting it is unavailable, so the equivalence can simply be left unsettled: the Russell set is consistently regarded as neither a member of itself nor not a member of itself, and comprehension survives intact. This is why non-classical approaches can restore the naive theory. A paraconsistent set theory can take the Russell set to be both self-membered and not, since in it a contradiction does not entail everything; an intuitionistic set theory can take it to be neither. Both thereby admit a universal set of the kind classical ZFC must deny, and both pay for it in logic rather than in mathematics, which is arguably the more principled trade. The set-theoretic restrictions canvassed in (b) are, by this light, second best: they save the theory by discarding comprehension rather than by repairing the logic.
