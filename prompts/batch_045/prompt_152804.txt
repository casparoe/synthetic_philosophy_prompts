I'm on the internal review board that has to sign off before any RL agent gets shipped into a shared environment at my company — right now that's warehouse AMRs and a controller that tunes cooling in our datacenters. We meet weekly, maybe six proposals a month, we're almost all engineers plus one compliance person, nobody has time for theory, and whatever we use has to be runnable by an engineer in about an hour.

Right now we basically just ask "is there an impact penalty? what's the coefficient?" and it's obvously not enough. I want an actual decision procedure we can run on a proposal: the questions in order, what counts as an adequate answer to each, where the procedure returns a hard no, and where it stops and hands the decision to a human because the question is about which things matter rather than about facts.

The bit I keep tripping on: every impact penalty we've seen compares what the agent did to some counterfactual baseline — "what would have happened if it did nothing", or "what the old controller was doing" — so it measures a distance between two worlds, not how bad the world is. Which makes the choice of baseline most of the decision, and I suspect there's no way to choose it that doesn't already bake in a view about what matters. Please build the procedure around that: how we interrogate the baseline (including whether the agent can make the baseline look worse so it looks better by comparison), how we decide which variables go into the distance metric, what we do about everything the sensors never see (that stuff is free by construction, which terrifies me), irreversibility versus magnitude, and what to do when the metric was only ever validated in the training environment.

Then run it on two real-ish cases: (1) a warehouse robot rewarded for throughput, with an impact penalty measured against an inaction baseline inside the same simulator it trained in; (2) a cooling controller whose penalty is deviation from "normal operations" logged off the old PID controller. I want at least one of them to come out as a no, and I want you to say plainly which steps are judgment calls wearing a lab coat. If the honest answer is that some proposals just can't be signed off on without a full specification of value, tell me exactly where in the procedure that shows up.
