QUESTION (20 points: 4/4/8/4). Someone proposes that Russell's paradox is at bottom a paradox about negation: the fatal instance of naive comprehension is the predicate ¬(x ∈ x), so if our language had no negation we could keep the principle that every predicate has an extension. Assess this claim.

(a) Set up the Russell set R and derive the contradiction, and say exactly which ingredients of the derivation involve negation.

(b) A classmate objects: the derivation also uses the law of excluded middle, so if we run the whole thing in intuitionistic rather than classical logic, naive comprehension is safe after all. Is he right?

(c) Let N⁻ be the theory whose axioms are Extensionality plus unrestricted comprehension for every formula of the language L⁻, which has the symbols ∈, =, ∧, ∨, →, ∀, ∃ and nothing else (no negation, no falsity constant; ↔ may be used as an abbreviation). Is N⁻ consistent? If it is trivial, prove that it is, and say exactly which logical rules your derivation relies on — modus ponens, conditional proof, excluded middle, or anything else — since that matters for what we should conclude.

(d) Say what actually does the blocking in ZF. Is it the Axiom of Foundation, which implies that no set is a member of itself? And would simply adding ∀x (x ∉ x) as an axiom to naive comprehension be enough to save it?

STUDENT ANSWER:

(a) Naive comprehension says that for any formula φ(x) with just x free there is a set {x : φ(x)} whose members are exactly the things that satisfy φ. Take φ(x) to be x ∉ x, that is ¬(x ∈ x). Then there is a set R such that for every y, y ∈ R ↔ y ∉ y. Putting y = R gives R ∈ R ↔ R ∉ R, i.e. R is a member of itself iff it isn't, which is a contradiction. So the theory is inconsistent. Where does negation come in? In the choice of the defining predicate: x ∉ x is a negated atomic formula, and in a language without negation we could not write it down at all. So the proposal in the question has this much right — the usual presentation of the paradox needs a negated predicate to be available.

(b) My classmate is right. The step that gets from the equivalence to an outright contradiction is the case split on R ∈ R versus R ∉ R, which is an instance of excluded middle, and that is exactly what intuitionistic logic withholds. Intuitionistically, from A ↔ ¬A you can prove ¬A: assume A, then ¬A follows by the equivalence, contradicton, discharge, done. But you cannot then get A back from ¬A, since that would need double-negation elimination, which intuitionistic logic doesn't have. So you are left with ¬A and no contradiction, which means the derivation depends on classical logic as well as on negation. As far as this argument shows, an intuitionistic set theory with full comprehension is consistent.

(c) In N⁻ the Russell formula can't even be written, so the argument in (a) never gets off the ground. But N⁻ is trivial anyway, by Curry's paradox. Let p be any sentence of L⁻ and consider
K = {x : x ∈ x → p},
which exists by comprehension since its defining formula is in L⁻. Comprehension gives, for every y, y ∈ K ↔ (y ∈ y → p), so with y = K:
K ∈ K ↔ (K ∈ K → p).
Now either K ∈ K or it isn't. If K ∈ K, then by the equivalence K ∈ K → p, so p. If K ∉ K, then the conditional K ∈ K → p is vacuously true, so the equivalence gives K ∈ K, and then p. Either way p. Since p was arbitrary, every sentence of L⁻ is provable and N⁻ is trivial. This derivation uses only modus ponens and conditional proof, together with the comprehension axiom, so it goes through in N⁻ even though L⁻ contains no negation. The proposal in the question is therefore wrong: dropping negation doesn't help. What Russell's and Curry's paradoxes really share is self-reference — both R and K are defined by a formula that applies membership to the very set being defined — or, more generally, impredicativity, a set defined in terms of a totality that already includes it. That is the real culprit, and it is why the iterative conception of set, and type theory before it, rule out that kind of circular definition.

(d) In ZF what blocks the paradox is the Axiom of Foundation, which says that every nonempty set has an ∈-minimal element; it follows that no set is a member of itself, so nothing can fail to satisfy x ∉ x and the Russell set is never formed. Equivalently, ZF replaces naive comprehension by Separation: given a set A and a formula φ, the set {x ∈ A : φ(x)} exists, so you can only carve subsets out of sets you already have, and since there is no universal set you never get {x : x ∉ x}. This shows that the real fix is banning self-membership. So yes: adding ∀x (x ∉ x) to naive comprehension would save it. R = {x : x ∉ x} would then just be the universal set V, and the contradiction in (a) required R ∉ R, which the new axiom rules out; and there is nothing inconsistent about a universal set as such, ZF just chooses not to have one.
