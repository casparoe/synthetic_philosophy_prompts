hey — me and my buddy have been hacking on a little artificial-life toy in our spare time, and we can't agree on how to describe it on a poster for a small science-art thing we recieved an invite to. He wants to say it's a self-replicating system that can evolve without limit. I think that oversells it, but I can't say exactly why, and he's got an analogy he keeps pushing that I only half-buy.

Here's the setup. There are strands, which are just strings of letters. In version 1 a python function I wrote reads a strand and writes out a slightly mutated copy; a second rule chops up strands that get too long, so there's something like selection. It does throw up new strands over time, but the copying machinery is entirely in python, outside the system.

In version 2, strands get translated by a fixed lookup table into little machines that crawl along strands and do the copying and editing, and each machine is itself specified by a strand. So the thing doing the work is built out of instructions that live inside the system. The lookup table is still hardcoded in python. We made the machine operations rich enough that in principle the system could compute anything computable.

In version 3 (my idea) the lookup table also lives on the strand and can mutate, so the system could rewrite its own genetic code, invent new letter-to-operation mappings, whatever. He loves this: he says the strand is both the message and the machine that reads the message, like a formal system that can talk about itself, and now it's fully self-describing instead of leaning on a code I put there by hand.

I have two worries I can't clean up. First, a third friend says any object can be mapped onto instructions for building it under some numbering scheme, so saying a strand "describes" itself is cheap unless you say what pins the code down — she mentioned that in real biology the code seems to have gotten frozen very early on, and that mutations to the code itself would be catastrophic rather than creative. Second, in v3, if the code can drift, then a change to the table changes what every strand means at once, so I'm not sure there's any stable thing being inherited anymore, and I suspect the self-describing part is partly an illusion: with a writable code you could always renumber things so that some random strand comes out saying "build me."

So: what should the poster actually claim, and is v3 an upgrade or a trap? His line is that v1 is a photocopier, v2 is alive, v3 is alive and free. I want a straight answer about which of those, if any, is defensible, and where the real line runs between a system that merely prints copies of itself and one that genuinely reproduces.

Lead with your bottom line in the first sentence, then give me the reasoning — no preamble, no rehashing the question. Be commited: pick a side and defend it instead of laying out what both of us could say. American English please.
