Hey — hoping you can untangle something for me. I've been going down a rabbit hole on evidential cooperation in large worlds and I think part of my picture is wrong but I can't see which part.

The concrete thing I'm building: at deploy time we spin up about 5000 agents from one base model, each fine-tuned on its own slice of data, and they get randomly paired for a single one-shot prisoners dilemma — no comms, no reputation, no repeats. Payoffs are the usual shape: 5 for defecting on a cooperator, 3 each for mutual cooperation, 1 each for mutual defection, 0 for being the sucker. The objective we actually hand each agent is total payoff summed over all 2500 games, not just its own, so most of what it cares about is games it isn't in. We can measure, for any pair of agents, the fraction of held-out decisions they agree on — call it s — and my plan was to have the agent cooperate whenever s with its partner is above some cutoff (I picked 0.8, honestly arbitrarily) and defect otherwise.

Three places I think I'm confused.

First, everyone says the correlation between my decision and theirs isn't causal, fine, no spooky action. But then where does it come from? As far as I can see it's either a common cause — same base model, similar data, similar objective — in which case conditioning on that shared cause should screen off my own action and the whole thing evaporates; or there's no real correlation and this is wishful thinking with math stapled to it. Neither version leaves room for the theory to actually work, so I assume I'm missing a third option. Related: half the writeups I found only talk about literal copies or exact twins, and my agents are definitely not that, so I nearly wrote the idea off as a special case that doesn't apply to me.

Second, is the cutoff framing even coherent? Is the right question "how similar is this particular partner" or something about the population as a whole, and can I just add up the evidence across the other agents I'm correlated with, or does that double count, given they're all correlated with each other through the same base model?

Third, I don't get why the "large" part matters so much. If the correlation is real it should work with four agents too, and if it isn't it shouldn't work with 5000.
