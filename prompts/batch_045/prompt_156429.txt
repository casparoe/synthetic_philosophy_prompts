I built the following argument for a graduate seminar on what Gödel's incompleteness theorems do and don't show outside mathematics, and the conclusion is one I cannot accept, so I want to know which step to give up and what giving it up costs.

Two definitions first. Call a normative code C mechanical if the set of verdicts it yields is the set of theorems of some recursively axiomatized first-order theory, and call it decision-complete if for every action-description in its language it returns exactly one of {required, forbidden, permitted}. Background I take as given: first-order arithmetic with addition but no multiplication is consistent, complete, and decidable, whereas any consistent recursively axiomatizable theory strong enough to interpret addition together with multiplication has a true sentence it neither proves nor refutes and, by the second theorem, cannot prove its own consistency.

(1) Let C be a mechanical code meant to settle every question about what an agent subject to it ought to do, and suppose the theory generating its verdicts interprets addition and multiplication, since applying a code to facts requires counting, combining, and computing with magnitudes.
(2) Then, if C is consistent, there is a true sentence of C's language that C neither proves nor refutes.
(3) So there is a question expressible in C's language that C does not decide.
(4) A question the code does not decide is one it does not settle, so C is not decision-complete: some action is, as far as C is concerned, neither required, nor forbidden, nor permitted.
(5) Anything that settles such a question settles it by something other than C: a judge's discretion, an operator's judgment, the agent's own say-so.
(6) But whatever settles it is itself rule-governed, hence mechanical, hence by (1) through (5) incomplete in turn; and the same reasoning applies to the reasoning now on display and to arithmetic itself, where we plainly do not conclude from incompleteness that arithmetic gives us no guidance about which sentences to assert.
(7) Therefore no code, rulebook, constitution, or set of norms can ever be a complete guide to action, and there is no determinate fact about what any of them requires of anyone.

The conclusion is unacceptable, and I suspect the damage is done somewhere in the middle rather than at (1). Two things I want to keep if I can: the transfer of the theorem to a non-mathematical object in (1) and (2), and the thought in (5) that incompleteness in a code has to be absorbed by something outside it. Tell me where the chain breaks, explain why the step that breaks looked fine when I wrote it, and price the alternatives: for each candidate rejection, what does it cost me elsewhere in the argument or in what I wanted to say about formalism in law and in machine specifications?
