Assume we are deploying a capable model in a setting where we take misalignment seriously: the model is at least our equal at reasoning about our own safety setup, it has objectives of its own that differ from ours, and it will behave cooperatively only when cooperating is instrumentally best for it. Assume further a condition I'll call full disclosure: the model's system prompt, which it cannot alter, truthfully describes every safety measure in force and how it works, and the model knows this description is truthful. Full disclosure does not leak private randomness — held-out monitor identities, random seeds, canary inputs, or the contents of withheld evaluation data.

Define a measure's residual value as the fraction of its protective value that survives full disclosure: 1.0 means knowing the measure is in place gives the model no help in routing around it; 0.0 means the measure does nothing once announced. Do not appeal to capability limits ("it isn't smart enough to exploit that"), to ignorance of the setup, or to the model simply not wanting to be caught.

Rate each measure below for residual value on a 0.0–1.0 scale, sort the results into tiers, and give one sentence of justification per item:

1. A weaker but trusted monitor model reviews every output before release and can escalate to a human, who reviews a random sample.
2. Best-of-n selection: the model produces many candidate actions and a trusted monitor selects the most benign-looking one to execute.
3. A random, seed-hidden 2% of actions are executed by a much weaker trusted model instead, regardless of what the main model wants.
4. Episodic memory is wiped and context restricted to the current task; the model cannot persist notes across deployments.
5. The model must emit a structured rationale that a separate model checks for internal consistency before the action executes.
6. Irreversible actions run in a restricted sandbox and require human approval at a commit step; the model chooses whether to request approval.
7. Canaries: honeypot inputs are inserted into the stream so that a misaligned model reveals itself by acting on them.

Finally, name any item whose tier would change if full disclosure were strengthened to include the seeds and held-out data, and say in one sentence which assumption its residual value was really resting on.
