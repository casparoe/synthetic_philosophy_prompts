So I got totally nerd-sniped at work last week. Someone dropped this thing called Fitch's paradox in our #random Slack channel and I've been chewing on it since. The way I half-understand it: if you sign on to that verificationist-sounding principle that every truth is knowable — nothing is true in a way that's in principle beyond any possible evidence — then given two tiny assumptions (knowing something means it's true, and if you can know a conjunction you can know each conjunct) you can apparently prove that every truth is *actually known*. You run the principle on the proposition "p is true and nobody knows p" and it detonates in your face, because that one can't be known without contradicting itself, so it can't be true, so there are no unknown truths. Which is obviously false, so something has to give. As far as I can tell from arguing with my teammate, the ways out are: restrict the principle so it doesn't apply to self-undermining propositions like that one (only propositions whose truth survives being known), or give up some of the closure/factivity machinery, or bite the bullet and deny that there are any unknown truths, or read the principle as a conditional with a different scope so the derivation doesn't go through. I'm a backend engineer with zero philosophy training, so correct me gently if I've mangled the setup — and please don't send me to papers, I dont have library access and I'm not chasing citations anyway.
