i do sound for a theatre company — long dead stretches between cues — so I've been reading pop-science biology books and then arguing with my brother-in-law Darren about them, and I've got nowhere. Please help me get somewhere. One favour first: don't send me to books or papers, and don't tell me who to read. I've got no library access and I'm definatly not going to look anything up, so just explain the arguments in your own words.

Darren's move is this. He says DNA isn't *like* a code, it literally *is* one, in exactly the sense Morse code or a computer language is a code. His evidence: there's a real lookup table you can print on one page, sixty-four three-letter words mapped onto twenty amino acids plus a stop, and the mapping is arbitrary — nothing about the chemistry forces a given triplet to stand for a given amino acid — and arbitrariness is the hallmark of a code. Then he cashes it in: so the genome is a set of instructions, a program; so the organism is specified in the DNA the way a message is specified in Morse; so it isn't sloppy or misleading to talk the way the popular books do, as if the genome is the blueprint or the manual for a person. He got one of those ancestry-and-traits kits back last month and keeps talking as if the report is a transcript of something.

I'm not sure where to push back, because the table is real and the arbitrariness point feels strong to me, but the conclusion feels way bigger than the premise. Here's what I've come up with on my own — tell me which of these are real problems and which are just me being pedantic:

1. Translation runs one way. English to Morse and back is lossless. Genome to protein and back isn't, because several triplets stand for the same amino acid, so you can't recover the original text from the protein. And genome to *organism* isn't a translation at all, it's more like a construction. So maybe it's a code for making proteins and not a code for making a person — and the interesting claim is the second one.
2. The codebook is written in the code. The things that actually do the translating — the little adapter molecules and the enzymes that load them — are themselves proteins, made from instructions in the DNA. So the lookup table is part of the message: like a cipher whose key is hidden inside the ciphertext, or a dictionary printed in the language it defines. Morse doesn't have this problem; its convention lives outside the message, in people's heads.
3. Nothing is in the strand without a reader. DNA in a test tube doesn't say anything. Sure, Morse on a page also needs someone who knows Morse — but the difference I'm groping at is that with Morse the reader could be anyone who learned it, while with DNA the reader is a specific machine that the message also has to build, and the same stretch of text gets read differently depending on what's around it. I've read that bits of a gene can be cut out and pasted into a different message, that the same mutation can do nothing in one genetic background and a lot in another, and that chemical tags on the DNA change whether a stretch gets read at all.
4. Arbitrary might be doing less work than he thinks. If the mapping were arbitrary in the way Morse is arbitrary, it could be renegotiated — a convention you change by agreement. But you can't reassign a triplet now, because every existing protein would come out wrong. The code is frozen: more like a path-dependent standard (the layout of a keyboard, the width of a railway track) than like a cipher somebody chose. Is it being arbitrary at the start, if it even was, enough to make it a code now?
5. One thing I half remember and can't check: the table isn't perfectly universal, there are a few variant versions knocking about in mitochondria and so on. If that's right, does it help his case or hurt it?

Two more things.

Give me a table: for a language or a signalling code, what plays the role of the sender, the message, the code itself, the receiver, the meaning, the thing the message is about; then what the corresponding item is supposed to be in the cell; and mark each row as forced, stretched, or empty because there's nothing on the DNA side. Then tell me which of the gaps actualy matter for the conclusion he wants and which are nitpicks — I don't want to win on technicalities and lose the thing we were arguing about.

My own attempts, from work: (a) a play script — not the performance, unperformable without a company that already knows how to act, the same script gives you wildly different shows, and most of what makes the show happen isn't in the script. Is either of those better than the code picture, what does each one quietly smuggle in that the other doesn't, and is there something better than both?
