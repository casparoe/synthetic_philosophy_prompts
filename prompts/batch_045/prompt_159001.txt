I've got about eight weeks and a 20-ish page term paper to write, and I don't want it to be another survey of the usual escape routes — I've already read that menu (restrict the principle to propositions that are stably knowable, go intuitionistic, drop the aggregation of knowledge, impose type restrictions on what can be substituted in), and re-listing them feels like padding.

Two things I keep playing with instead. First: a stratified version, where the knowledge operator gets a level index and the substitution instance that drives the argument becomes ill-typed, so the principle can hold unrestricted at each level but you never get the diagonal sentence. Second: replacing the static possibility operator with a dynamic one — read knowability as something like "there is some finite sequence of information updates after which p is known" — on the thought that the collapse secretly leans on the modality being normal and on aggregation, which is exactly what you lose when updates don't commute. A friend in the seminar thinks both of these are just the type-restriction move wearing a costume; another thinks the dynamic version is genuinely different because the fixed points you can write down in the static language aren't reachable by any actual update sequence.
