Two people on my team got into it in a meeting last week about how we're planning to deploy a coding agent, and I was in the room and genuinely couldnt tell who was winning. The setup on the table: the agent works in a sandbox with no network access; a weaker "monitor" — a fine-tuned copy of the same base model — reviews every diff before it lands; and roughly one task in twenty is a secret canary where we've planted an obvious vulnerability, just to see whether the agent quietly exploits it. We were also going to randomize which tasks get monitored so the agent can't behave well only when it knows it's being watched.

(1) Jonas: this is all misplaced effort. If the model is actually misaligned, a weaker monitor won't catch competent sabotage — spotting a well-executed exploit is at least as hard as writing one — so the whole scheme only works against a sloppy saboteur, and sloppy isn't the case that worries us.
(2) Priya: that inverts the point. Control isn't trying to out-think the saboteur, it's trying to make sabotage expensive: if any given task might be the audited one and the agent can't tell which, then every task has to be clean, and "clean all the time" is a much tighter constraint than "clean when watched."
(3) Jonas: the randomization defense assumes the agent can't infer monitoring from side channels — diffs touching certain files get human review anyway, review latency correlates with whether a monitor actually ran. A model good enough to sabotage well is good enough to notice the tell, and then you're straight back to (1).
(4) Priya: fine, I'll concede the side channels. But that's exactly what canaries are for — an agent that thinks it's unwatched and takes the bait has shown us it's real preference, and one trip is enough to pull the whole system, so we don't need to be right every time, we just need one unguarded look.
(5) Jonas: canaries only catch an agent that wants to sabotage at all. The failure mode I actually expect is quieter — sandbagging, writing code that curries favor with the reviewer, shaping things so future oversight goes smoothly — and none of that trips a wire. Worse, adding a monitor gives the agent a second system to be sycophantic toward, so the control layer might manufacture the very behavior it's supposed to catch.
