Writing a short position note for a reading group on open-source game theory, and I want someone to check whether my set of views actually hangs together before I inflict it on them. No need for references or pointers to the literature, I know it exists — I want the audit.

Setup so we're on the same page: two agents play a one-shot prisoners dilemma, standard payoffs (T > R > P > S), except each submits a program that gets the other's full source code as input and outputs C or D.

Where I think I've landed:

1. Program equilibrium is decision-theoretically important, not a curiosity. Once source-reading is on the table there are programs that cooperate with each other in equilibrium, and that blocks the dominance argument for defecting in the one-shot case. I want to say: rational agents in that situation can cooperate, full stop.

2. The objection that this changes the subject — the program game isn't the PD anymore, so who cares — is a dud. Filling in the epistemic facts about what the agents can detect about each other isn't changing the game, it's describing the game that was always being played.

3. CliqueBot-style solutions (cooperate iff the other program is literally your own source text) are a non-answer, and the thing that makes them a non-answer is brittleness: add a comment, rename a variable, run it through a compiler, and it defects. So: the verdict has to be invariant under any meaning-preserving rewrite, including one performed by a hostile third party who wants to break the match. And it shouldn't depend on incidental facts about what machine I'm running on or how big my proof-search budget is — I should reach the same verdict if I delegate the choice of program to a slower proxy that only knows behavioral facts about the opponent.

4. So the real vindication is the proof-theoretic one: cooperate iff you can prove, in your own formal system, that the other program cooperates, with mutual cooperation secured by Lob's theorem (a system that can prove "if p is provable then p" can prove p). That's semantic rather than syntactic, so unlike 3's target it survives the rewrite test.

5. But I also dont want to be a sucker, and I read that as pretty demanding: no proof, no cooperation. So I defect against a black-box agent I only have massive inductive evidence about (a million simulated games against my exact source, cooperated every time, and I've verified it can't read my source at all), and I also defect against a copy of myself running with a smaller proof-search budget, since I can see it won't find the proof in time and will defect against me.

6. My general standard for saying an outcome is available to rational agents is: it's an equilibrium of the game those agents are actually playing. I dont want to help myself to common knowledge of rationality doing equilibrium-selection work, or to anything moralized.

Separately: I've been assuming without really checking that the real payoff of all this is the "whatever a trusted mediator could enforce, we can do without the mediator" result. Is that a further commitment of mine, or does it already follow from 1 and 4?

What I want: go through these and tell me which pairs are genuinely in tension, ranked by severity; which ones only look like they conflict; and for each real tension, what the cheapest fix is and which of my claims has to go. I'd rather drop a favourite than keep an incoherent package. Then tell me which single revision cleans up the most. Please don't just tell me everything is in tension with everything — I can do that myself.
