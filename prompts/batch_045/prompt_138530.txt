hey, I want to spar about the Löbian obstacle and I need you to play the pessimist, and play them hard.

Setup so we're starting from the same place (nothing here needs looking up): an agent reasons in a computably axiomatized theory T strong enough to do arithmetic — think Peano arithmetic. Löb's theorem says that if T proves "if T proves φ then φ", then T already proves φ; putting φ = ⊥ gives Gödel's second incompleteness theorem, so T can't prove its own consistency. Now the agent is deciding whether to build a successor that reasons in a strictly stronger computably axiomatized S (say T plus the consistency of T). The obstacle: before handing over control the agent wants something like "whatever S proves, I may act on" — uniform reflection for S — but if T proved that for every φ, then in particular T would prove that S doesn't prove ⊥, i.e. Con(S), which implies Con(T), which T can't prove. So by reasoning alone it can't license a strictly stronger successor. Climbing to T, T+Con(T), T+Con(T)+Con(T+Con(T)) and so on just relocates the leap one rung up each time.

My opening move — I'm playing the optimist, and I think the obstacle is an artifact of asking for the wrong thing.

You don't need a general trust policy. Put the child on a leash. The child doesn't get to act; it proposes an action together with a candidate proof in S, and the parent side checks that proof as a concrete finite object. Checking whether a number n codes a valid S-derivation of φ is decidable, so the parent can confirm "yes, this really is an S-proof" without trusting S one bit. And the Löbian gap is precisely an instance-versus-uniform gap: T proves "if n is a T-proof of φ then φ" for each individual standard n, it just can't prove it with n universally quantified. So trust doesn't have to be per-system at all, it can be per-proof, and per-proof is something I can keep doing one case at a time, forever. No one ever has to prove a soundness schema, so there's no obstacle here — just a slightly clunky workflow.
