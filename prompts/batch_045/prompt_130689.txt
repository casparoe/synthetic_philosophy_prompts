At my philosophy-of-mathematics reading group last night, one member used an analogy to argue that Skolem's paradox shows there is no perspective-independent fact about how many real numbers there are. He said a countable model of ZFC is like an open-world video game running on a server with only countably many memory states: the characters inside can prove, using the game's own physics, that their world contains uncountably many objects, while from our engineer's chair outside, every object in the game is one of countably many bit patterns. So, he concluded, "uncountable" only ever means "not enumerable from within the system," and Cantor's theorem is a result about the expressive limits of first-order axiomatizations, not about how many reals there are. A second member countered with a rival picture: the model is like a jigsaw puzzle missing exactly one piece, the enumeration function — a defective artifact, so it tells us nothing about the genuine reals. A third said the worry dissolves if set theory is done in second-order logic, whose full models, people say, are just the V_κ for inaccessible κ.

Please audit the pictures rather than simply answering the question. Give the correspondence table for the video-game analogy — what plays the role of the hardware, the players, the in-game proof, the missing list — and then name the features it imports that the set-theoretic situation lacks: is the external vantage privileged in a way the analogy assumes, is the model's set of reals the reals, and what happens to the argument if the ambient universe is itself viewed from outside? Where does the jigsaw picture go wrong, given that no model of ZFC can contain an enumeration of its own reals? Is the second-order move a fix or a change of subject? Finally, does the anti-absolutist conclusion survive once the disanalogies are on the table, or was the analogy carrying it — and is there a better comparison available?
