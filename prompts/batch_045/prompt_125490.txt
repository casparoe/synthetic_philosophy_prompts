So I got into a long argument last night with a friend who does ML and reads a lot of this literature, and he gave me his summary of the field, roughly this:

There are two problems people constantly run together. Intent alignment — the narrow one — is just: build a system that does what the person operating it wants. That's basically an engineering problem, the same shape as getting a robot to track a target: you write down an objective, the system optimizes it, and the question is whether it reliably hits the target. Value alignment is the broad one: getting the system to act on human values, which is philosophical and probably never fully solvable, since nobody agrees on what values are and you can't write them down anyway. The two are independent questions — you can have a perfectly intent-aligned system pursuing awful values, because intent alignment says nothing about what you point it at. And the narrow one is what matters for safety right now: a system that doesn't do what its operator wants is dangerous whatever its values are, whereas a system with the right intentions but the wrong values is a political disagreement, not a safety failure. So the philosophy people agonizing over values are working on something downstream and optional.
