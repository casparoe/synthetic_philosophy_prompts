The setup we were fighting over: assume some program, run on one machine once, is by hypothesis a mind. Now take that same program and consider: (1) it's deployed as a replicated state machine on a thousand nodes with identical inputs, like BFT replicas; (2) it runs once, but the runtime checkpoints and deterministically replays the whole run for debugging, so the exact same state sequence happens twice; (3) a runtime notices two replicas are in byte-identical states and lets them share one physical copy of that state, re-deriving separate copies only if they ever diverge; (4) someone replaces the online computation with a lazily-expanding memo table over the same input-output function, so the intermediate states exist only as entries looked up on demand; (5) all the intermediate states are computed as usual but nothing downstream reads them except a diagnostic probe nobody ever inspects.
