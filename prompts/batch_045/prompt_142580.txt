**My thesis.** The phrase "lost cause" should be a technical term, and it should be defined counterfactually rather than by defeat. Call a commemorative practice *vindication-dependent* when the community would still have reason to hold the memory had the cause won, and *vindication-fragile* when the defeat is doing the justificatory work — when the practice would have to be abandoned, or would have become something quite different and less serviceable, under victory. Defeats that are vindication-fragile in the strong sense I call *auspicious defeats*: losses that leave the community better furnished, identity-wise, than a win would have. I explain fragility by three mechanisms, which can combine: *untestedness*, where the loss spares the cause's professed ideals the test of having to be implemented and lived under; *moral alchemy*, where defeat converts a culpable project into a tragic one, so grief quietly displaces guilt; and *inheritance without succession*, where the memory is valuable precisely because it carries none of the burdens of the power the cause sought.

**The four cases as I use them.** The Confederacy is my central case: vindication-fragile and auspicious, because a win would have forced the memorial practice to become either a state cult or an object of internal dissent, whereas the loss lets later generations inherit the cause without ever having to have run it. Masada I use stipulatively — I concede at the outset that the mass-suicide narrative rests largely on a single ancient source and is archaeologically contested — and my claim is only about commemorative shape: the defeat is the entire point, and later military success makes the memory awkward in a way it was not before, so its function thins as the state becomes secure. Kosovo 1389 is fragile in a different, active mode: the defeat is held as a pledge rather than an ending, so the memory is structured to keep a future claim alive. Dunkirk, I argue, is not a lost-cause memory in my sense at all: it is a deliverance memory, commemorated as that without which later victory would have been impossible, and had the war been lost the same events would have had to be remembered very differently. So my test does not condemn it — which I present as a feature, since myth and objectionable myth come apart on my account and the test marks where.

**The payoff I claim.** The test is supposed to sort cases where removal is apt from cases where recontextualization or counter-monument is apt from cases where the object should simply stay, and to explain why adding an explanatory plaque sometimes feels like a dodge and sometimes does not.
