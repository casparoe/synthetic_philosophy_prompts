Setup. Ω = {1, 2, 3, 4}, with the uniform distribution as the agents' common prior. Agent 1's information partition is {{1,2}, {3,4}}; agent 2's is {{1,3}, {2,4}}. Recall that the common-knowledge (meet) partition is the finest partition coarser than both agents' partitions, and that an event E is common knowledge at a state ω just in case E contains the cell of the meet partition that contains ω. Fix the event A = {1,2}.

(a) Compute both agents' posterior probability for A at each state, and compute the meet partition. [4]
(b) Aumann's agreement theorem says: if two agents have a common prior and their posteriors for an event are common knowledge at a state, then those posteriors are equal. Does what you found in (a) contradict the theorem? Explain. [4]
(c) Prove or disprove: with a common prior, it can be common knowledge at a state that agent 1's posterior for A is strictly greater than agent 2's posterior for A. [8]
(d) Prove or disprove: with a common prior, it can be common knowledge at a state that the two agents' posteriors for A differ. [6]
(e) Finiteness is often said to matter for the agreement results. Where exactly does it enter — in Aumann's theorem itself, or in the Geanakoplis–Polemarchakis result about reaching agreement by repeatedly announcing posteriors? One paragraph. [3]

Here's the answer I'm looking at:

(a) Agent 1 conditionalises on {1,2} or {3,4}, so her posterior is 1 at states 1 and 2 and 0 at states 3 and 4. Agent 2 conditionalises on {1,3} or {2,4}, each of which contains exactly one state in A and one outside, so her posterior is 1/2 everywhere. For the meet: agent 1 can't separate 1 from 2, agent 2 can't separate 1 from 3, so 1, 2 and 3 are chained together, and 4 joins them too since agent 2 can't separate 2 from 4. So the meet is the trivial partition {Ω}, and the only events common knowledge at any state are ∅ and Ω.

(b) No contradiction. At state 1 the posteriors are 1 and 1/2, and that pair is not common knowledge: the event {q₁ = 1} is {1,2}, which does not contain the meet cell Ω, so a fortiori {q₁ = 1 and q₂ = 1/2} isn't common knowledge. The theorem only bites when the posteriors themselves are common knowledge, which here they aren't. (Note that agent 2's posterior alone is common knowledge at every state, since it's constant across Ω — but the theorem is a claim about both agents' posteriors being common knowledge, so this is no problem.)

(c) Disproof. Suppose for contradiction that at some state ω it is common knowledge that q₁ > q₂. Then the agents' posteriors are common knowledge at ω: agent 1 knows her own posterior, and common knowledge of the strict inequality means she knows that agent 2's is lower than hers, and knows that agent 2 knows that hers is lower, and so on; so the event {q₁ = q₁(ω), q₂ = q₂(ω)} is common knowledge at ω. Aumann's theorem then gives q₁(ω) = q₂(ω), contradicting q₁(ω) > q₂(ω). Also note that if the inequality were common knowledge at ω, the whole meet cell at ω would have to lie inside {q₁ > q₂}, so the inequality would have to hold at every state in that cell.

(d) Proof by example: the model in (a) is a witness. q₁ ≠ q₂ at every state (1 against 1/2 at states 1 and 2, 0 against 1/2 at states 3 and 4), so the event {q₁ ≠ q₂} is all of Ω, which is common knowledge at every state because the meet is trivial. Intuitively the disagreements have to cancel on average: the prior-weighted average of q₁ over Ω is p(A) = 1/2, and the same goes for q₂, so nothing forces the two posteriors to coincide state by state. This is consistent with (c) — what can't be common knowledge is the direction of the disagreement, not the disagreement itself.

(e) Finiteness enters Aumann's own theorem. The argument works by having the agents announce their posteriors over and over and refining their information each time — that's the Geanakoplis–Polemarchakis argument — and with finitely many states the process has to terminate, at which point the posteriors are common knowledge and hence equal by the theorem. With infinitely many states the process need not terminate, and then the conclusion can fail. That is why the result is standardly stated for a finite state space.
