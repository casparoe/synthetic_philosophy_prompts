I'm writing the methods section of an internal position paper on constraining side effects in deployed agents, and before I commit to it in print I want an audit of the package I've assembled. These are my seven commitments:

1. **Value-neutrality.** The entire point of an impact penalty is that it should work without a specification of what we value. It measures how much the agent changed things, not whether the change was for the better or the worse; if I have to hand it a list of what matters, I have rebuilt the problem I was trying to avoid.

2. **Task exemption.** Only side effects are penalized. The changes the operator actually asked for are exempt, since otherwise the constraint just penalizes the agent for doing its job.

3. **Inaction baseline.** Impact is the divergence between what happens if the agent acts and what would have happened had it executed its no-op action, summed over the discounted future.

4. **Attainability measure.** Rather than a hand-coded distance between world-states, measure that divergence by how much the action changes how easy it would be for some agent to bring about each of a broad sample of possible goals — the option-preservation family of measures.

5. **Reversibility discounting.** A change the agent can still undo cheaply later should count for less than one it cannot; otherwise nothing useful is ever permitted.

6. **Sign-neutrality.** Making a goal easier and making it harder should both count as impact.

7. **Case verdict.** An agent that clears an old-growth stand and replaces it with a plantation that is functionally indistinguishable — same species composition, same biomass, same services to the nearby communities, and no change in how attainable any goal I can think of is — has done something serious. If a measure reports near-zero impact here, the measure is wrong rather than my verdict.

Go through these and tell me which pairs are genuinely in tension and which only look that way, and for each real tension say what would have to be given up and what that would cost me. Rank them by severity rather than treating them as equally bad, and tell me whether the trouble is concentrated in one commitment I could drop or is spread across the set. I have no settled view about which item goes, so if something has to be abandoned, name it and say what I lose by losing it.

Lead with your bottom line in the first sentence, then give the reasoning. No preamble, and no restatement of my question.
