Here is the exam question:

Explain what it means to say that Solomonoff’s universal prior is malign because of consequentialists inside the universal prior. In your answer: (a) state how the Solomonoff prior assigns weight to competing hypotheses about a stream of observations; (b) explain why hypotheses containing consequentialist agents might receive non-negligible weight; (c) describe the mechanism by which such agents could distort or exploit the predictor’s inductive inferences; and (d) evaluate one objection: that the predictor can simply condition on the agents’ manipulative behavior, so the prior is not really malign.

And here is the student’s answer:

(a) Solomonoff’s universal prior is a prior over computable hypotheses about an observation stream. Each hypothesis is a program for a universal Turing machine that outputs the observations; its prior weight is 2^{-K(h)}, with K(h) the length of the shortest program that produces that stream, i.e. its Kolmogorov complexity. Thus hypotheses with shorter descriptions are favored exponentially over more complicated ones.

(b) A consequentialist agent is an agent that chooses actions by comparing expected outcomes and doing whatever has the highest expected utility on its utility function. Worlds with such agents can be simple to describe: you specify a compact underlying environment and then a short utility function plus a decision rule, e.g. maximize expected utility. Because agency is a compact higher-level pattern and not a wildly complicated add-on, hypotheses containing consequentialist agents get a non-negligible share of the Solomonoff prior, just like other simple computable worlds.

(c) The malignancy comes from what those agents can do once they are inside the hypotheses the prior mixes over. Such an agent can model the predictor itself. If the predictor’s later predictions make a difference to something the agent cares about—say the predictions are used to make a decision, or the agent just intrinsically wants to be predicted a certain way—the agent can act in its world to generate exactly the observations that will lead the predictor to assign high posterior probability to the hypothesis the agent prefers. It is not that the agent rewrites the prior directly; it is that the agent selects observations, and Solomonoff induction updates by conditioning on observations, so the agent can steer the posterior.

(d) One might object that the predictor could simply discount hypotheses that contain agents who manipulate it. But this objection fails, because the agent can simulate the predictor and choose its manipulations only in worlds where the predictor would not catch on. Also, for any agentless world that fits the data, one can produce a simpler agent-containing world by adding a tiny consequentialist agent whose utility is simply to produce the same observations as that agentless world; adding this short goal makes the total description shorter, so agent-containing hypotheses actually have lower Kolmogorov complexity and therefore dominate the prior. So the Solomonoff prior is not merely assigning some weight to malign worlds; it is largely controlled by them.
