Here's my opening. In the CS sense a code is just a mapping between two sets that both the sender and the receiver use, and that is exactly what the codon table is: arbitrary, contingent, shared. People have built E. coli strains where UAG has been reassigned to a synthetic amino acid instead of meaning stop, so the very same string now means different things to different readers — in every other code I know, reader-dependence like that is a feature, not a disqualification. Your big objection is that there's no semantics without someone intending something, but a mapping doesn't need an agent any more than a file format does. And the "who reads the reader" objection actually helps me: the translation machinery is itself written in DNA, so the interpreter is part of the message, which isn't a paradox, it's just a self-hosting compiler.
