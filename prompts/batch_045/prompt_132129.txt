Assume the standard synchronic Dutch book theorem has been established: if an agent's betting quotients violate the probability axioms, a bookie can assemble finitely many bets, each acceptable by the agent's own lights, that together guarantee a net loss; and if those quotients satisfy the axioms, no such assembly exists. Take that as given, and set aside for present purposes whether avoiding sure loss is itself the right epistemic goal.

Below are six candidate extensions of Dutch-book-style reasoning, each stating a further constraint on rational credence.

(a) Countable additivity: credence should sum to one over an infinite partition, so that merely finitely additive credences count as incoherent as well.
(b) Conditionalization: an agent who plans to update by any other rule can be exploited by a bookie who is allowed to return at a later time.
(c) Reflection: one's current credence in H, conditional on one's later self assigning H credence x, should equal x.
(d) Chance coordination: one's credence in H, conditional on H's objective chance being p, should equal p.
(e) Sharpness: a doxastic state should be a single probability function rather than a set of them, since a set can escape sure loss without pinning down any one quotient.
(f) Conditionals: credence in a conditional should equal conditional credence in its consequent given its antecedent.

Please do two things.

First, rate each item on a 0–10 scale for how much genuine normative work the sure-loss framing itself does in that case — that is, how much it adds to what already follows from the synchronic theorem together with ordinary demands of coherence — and sort the six into tiers (top, middle, bottom, ties permitted), with one sentence of justification per item.

Second, mark each item as menu-robust or menu-fragile. By a menu assumption I mean the stipulation about which bets the bookie may assemble: bets on conditionals, on the agent's own later credences, on objective chances, infinitely many bets at once, or stakes scaled to the agent's other holdings. An item is menu-fragile if the sure loss materializes only once the menu is expanded beyond the modest menu used in the synchronic theorem, in a way an actual bookie might not be able to offer. Say whether menu-fragility should lower an item's rating, and why.
