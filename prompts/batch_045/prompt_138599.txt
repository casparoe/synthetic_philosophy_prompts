so i've been stuck on this for a while and I keep loosing track of whether I'm reasoning or just going in circles, so I figure it's worth asking someone.

Context: I'm writing the object model for a simulation-ish thing (a game engine, sort of) and I need to decide when a bunch of parts counts as one object, which dragged me into the special composition question. I think I've landed somewhere, but I want to check I'm not fooling myself.

My reasoning: both nihilism and universalism are "cheap" theories — neither one adds any new kind of thing, universalism just hands you a lot more objects, and extra objects don't cost anything. So there's no real argument against universalism, and given that, the rest of the debate looks verbal to me. "There's a table" and "there are particles arranged tablewise" are the same claim in two notations, so it should be possible to write down a general paraphrase scheme that turns any sentence about composites into a sentence about simples, and then just use whichever vocabulary makes my code cleaner.

What I'd actually prefer is a middle view. I've been calling it the causal-bonding criterion: some things compose something iff they're bound into a single dense-enough web of causal interaction, with "dense enough" left deliberately vague. And the vagueness seems harmless to me, because vagueness is a feature of our words, not of the world — so a vague criterion just means my predicate has borderline cases, not that there are objects that vaguely exist.

Three things I'd like checked:

1. Is "universalism plus paraphrase" actually the obvious package here, or am I helping myself to something?
2. Does causal-bonding survive the standard objections? The ones I can see coming are scattered objects (a bikini, a constellation, a scattered asteroid) and that it seems to make composition contingent — things would go out of existence the moment the interactions thin out.
3. And a smaller thing: if unrestricted composition is true, then since a bunch of parts has exactly one fusion, the statue and the lump of clay should just be the same object, right?

Happy to be told my whole framing is off — I'd rather find that out now than after I've built the object hierarchy around it.
