I'm helping write the rules for an open-agent trading sandbox. Each entrant submits the full source of a bot, and before every pairwise match the platform hands each bot the other's source — except it runs that source through an obfuscator first (variables renamed, independent statements reordered, dead code sprinkled in), so what you recieve behaves identically to what was submitted but won't be byte-identical to anything. On top of that, each match has maybe a 5% chance of being run against a lightly mutated build of the opponent's program instead of the submitted one.

I've read a bit about program equilibrium and the cooperate-if-you-can-recognize-me style of bot, and my worry is that all the cute constructions there lean on literally reading the other guy's source text, which our setup destroys on purpose. So: what are the most important implications of program equilibrium for a sandbox like this — for whether cooperation between independently written bots is realistic at all, for what a bot would have to do instead of source-matching if it wants to cooperate without being a pushover, and for what we should actually expect to happen when we turn it on? Be concrete about where the usual results stop carrying over once syntactic identity and exact knowledge of your own code are off the table.
