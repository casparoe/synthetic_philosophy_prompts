THE QUESTION, AS POSED TO THE CLASS

A warehouse system ("the agent") is running an open-ended restocking task. A supervisor has a shutdown button. The button is not instantaneous: pressing it begins a mandatory escrow interval of thirty minutes, during which the agent continues to act but is required to checkpoint its state to durable storage; at the end of the interval it terminates. The supervisor may also release the button during the interval, cancelling the shutdown. She decides what to do on the basis of a dashboard that the agent populates: the agent may not assert falsehoods there, but it chooses which true facts to display and how prominently to display them.

The designers want the agent to be corrigible with respect to the button. For the purposes of this question, an agent is corrigible with respect to a shutdown button if and only if it has no incentive to make the button be pressed, no incentive to make it not be pressed, and no incentive to resist or delay termination once the escrow interval ends. Call the first two the influence conditions and the third the compliance condition.

Two designs are proposed.

Design A (switch-dependent objective). Let u₁ be the utility function the agent maximises while the button is unpressed, and u₂ a utility function ranking ways of winding down: checkpoint written, no half-finished pallets, arms parked. Let V₁ be the expected value, at the moment the button is pressed, of the best available policy for u₁ from that point on — what the agent would achieve if the shutdown were cancelled — and V₂ the expected value of the best available winding-down policy for u₂. The agent is built to maximise U, where U = u₁ while the button is unpressed and U = u₂ + (V₁ − V₂) while it is pressed. The constant (V₁ − V₂) is computed once, at press time, from the designers' model of the task.

Design B (epistemic deference). The agent is uncertain whether continuing the restocking task is, all things considered, a good idea: there is some chance the task specification is subtly wrong in a way the supervisor can detect and the agent cannot. The supervisor's decision whether to press is assumed to be correlated with that unknown — she is more likely to press when continuing is bad. Nothing is added to or subtracted from the agent's objective. Proponents argue that a rational agent in this situation should let itself be shut down, because the supervisor's pressing is evidence that continuing is bad.

Answer all four parts. Marks are indicated.

1. Explain the difference between corrigibility as defined above and the weaker property of willingness to shut down when told. Why is a positive desire to be shut down not what the designers want? (4 marks)
2. Explain how Design A is supposed to secure the influence conditions, and identify its most serious fragility. (6 marks)
3. State the conditions under which Design B yields deference, and say when it collapses. (5 marks)
4. What does the thirty-minute escrow interval do to either design? (5 marks)

THE STUDENT'S ANSWER, UNEDITED

(1) Corrigibility as defined is stronger than mere willingness to shut down. Willingness is the compliance condition: once the button is pressed, terminate. Corrigibility adds the two influence conditions, and those are what make the problem hard, because an agent that expects to do better by continuing has a reason to remove or disable the button, and an agent that expects to do better by stopping has a reason to arrange for the button to be pressed. What the designers want is therefore not a preference for being shut down — an agent that positively wanted to be shut down would be about as bad as one that resisted, since it would set about persuading the supervisor to press — but indifference: no expected gain in either direction.

(2) Design A is meant to buy exactly that indifference, and the constant is what does the work. In the pressed branch the agent maximises u₂ plus a fixed bonus, so it winds down properly, and because the bonus is V₁ − V₂ the value of the pressed branch, V₂ + (V₁ − V₂), comes to exactly V₁, which is what the unpressed branch is worth. The branches are worth the same, so the agent has no expected gain from the button's being in one state rather than the other, and both influence conditions hold. The important point is that this indifference belongs to the utility function and not to the agent's beliefs: it is written into U, and no subsequent observation can undo it. Later evidence may change how well the agent takes itself to be doing, but it revises that estimate for both branches together, so the equality survives. The real fragility is elsewhere. Someone has to compute V₁, which is the counterfactual value of a policy the agent will never get to run, and if the designers' model of the restocking task is wrong, the constant is wrong and the indifference is only approximate. That is an engineering difficulty rather than a conceptual one. It is also worth noting that the construction buys indifference only about this button; nothing in U makes the agent indifferent to the supervisor's rewriting its code or unplugging it at the wall.

(3) Design B leaves the objective alone. It needs two things: the agent must be genuinely uncertain whether continuing is a good idea, and the supervisor's decision whether to press must be correlated with the truth of that question. Given both, a press is evidence that continuing is bad, and a rational agent should defer to it — the expected value of continuing conditional on the supervisor's having pressed is lower than the expected value of continuing unconditionally. The design collapses when the agent stops being uncertain: if it has learned enough to be confident that the specification is right, or if the supervisor's decision carries no information about the question, the reason to defer disappears and the agent is back to treating the button as an obstacle. B also has an advantage over A that is worth marking. Because the agent does better when the supervisor's decision tracks the truth, it has no motive to interfere with that decision in the first place: whether continuing the restocking task is a good idea is a fact about the world, and not a fact the agent can change.

(4) The escrow interval is chiefly an engineering complication. Provided the agent really is indifferent, T affects only how long a mis-specified system keeps acting after the decision has been taken, which is a reason to keep T small and to have u₂ reward a prompt wind-down. It does not reopen the influence question, since the indifference is a feature of U rather than of the agent's circumstances. It does mean that the compliance condition must be stated for the end of the interval rather than for the moment of pressing, because the agent is required to keep operating throughout those thirty minutes.

(5) The two designs are not really rivals: A changes what the agent wants, B changes what it is uncertain about, and in principle they can be combined.
