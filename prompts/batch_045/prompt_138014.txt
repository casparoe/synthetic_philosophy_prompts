The question (25 points):

A fair coin is tossed until it lands heads for the first time; let n be the toss on which the first heads appears, so P(n) = 2^(−n).

Game P: if the first heads is on toss n you win (−1)^(n+1) · 2^n / n dollars.
Game A: if the first heads is on toss n you win (−1)^n · 2^n / n dollars.
Game M: before any tossing, an independent fair coin decides whether you play P or A. You then play that one game only.

(a) [8 points] Show that the expected value of P, summing the terms in the order n = 1, 2, 3, ..., is ln 2. Then explain why the standard verdict is nevertheless that P has no defined expected value. If you think that verdict is wrong, say what you think the value is and why.

(b) [7 points] Now consider the gamble consisting of P and A together, with the same sequence of tosses fixing both payoffs. What is that gamble worth? Does the problem raised in (a) cause any trouble here?

(c) [10 points] Now consider M. Sum its terms in the order that pairs, for each n, the P-term with the A-term. What do you get? Then say whether M has a well-defined expected value, and explain how your answer bears on your answers to (a) and (b).

The student's answer:

(a) The probability that the first heads comes on toss n is 2^(−n) and the payoff is (−1)^(n+1) · 2^n / n, so the expected value is the sum of the terms (−1)^(n+1)/n, that is 1 − 1/2 + 1/3 − 1/4 + ..., which is the alternating harmonic series and sums to ln 2, about 0.69. But that number isn't the expectation. The expectation is defined only when the expected absolute value is finite, and here E|X| is the sum of the absolute values of those terms, which is 1 + 1/2 + 1/3 + ... and diverges. So the expectation is infinite rather than finite: this is the same reason the St Petersburg game has no finite expectation, the payoffs just grow too fast relative to their probabilities. And because the absolute sum diverges, Riemann's rearrangement theorem applies: by reordering the terms you can make the sum come out to anything you like, or diverge, which is why there's no fact of the matter about the value of the game.

(b) If you're given P and A together, then whatever n turns out to be, the two payoffs cancel exactly, since (−1)^(n+1) · 2^n / n + (−1)^n · 2^n / n = 0. So you receive 0 on every possible outcome and the gamble is worth 0. Nothing from part (a) causes trouble, because we never have to add two undefined expectations together — the payoff is identically zero state by state, so any sane way of evaluating it gives 0.

(c) M is just the average of P and A: half the time you get P's payoff, half the time A's, so by linearity E[M] = (1/2)E[P] + (1/2)E[A] = (1/2)(ln 2) + (1/2)(−ln 2) = 0. Equivalently, the two games cancel state by state, so M is really the same gamble as in (b), where we already saw the cancellation is exact. So M has a perfectly well-defined expected value of 0 even though P and A individually don't. That shows the undefinedness in (a) is only an artifact of insisting on one arbitrary ordering of the sum: the sensible value of P is ln 2 after all, and the fuss about these games is overblown.
