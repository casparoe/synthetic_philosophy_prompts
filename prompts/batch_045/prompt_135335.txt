A set of lecture notes I found online (not my course's) introduces Zorn's lemma like this:

"Zorn's lemma says: in any nonempty partially ordered set in which every chain has an upper bound, there is a maximal element — that is, an element larger than every other one. It is equivalent to the axiom of choice, hence independent of the rest of set theory, and every use of it is non-constructive: you learn that an object exists without learning which one. The standard application is that every vector space has a basis. Order all linearly independent subsets by inclusion; the union of a chain of linearly independent sets is linearly independent, so every chain has an upper bound, and Zorn gives you a maximal one, which is therefore the largest linearly independent set in the space. It has to span, since otherwise you could throw in a vector outside its span and contradict maximality. You can also run the argument above a fixed independent set, which is how you extend any independent set to a basis. The same 'keep going until you can't' pattern yields other results too: for instance, every infinite set has a maximal countable subset — order the countable subsets by inclusion, note that a union of countable sets is countable, and apply Zorn. Zorn's lemma is just a licence to keep going until you can't go further."
