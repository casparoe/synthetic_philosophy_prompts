Me and my friend spent like two hours last night arguing about whether an LLM is an agent, a simulator, or something else entirely, and we got nowhere because we kept using the words differently. So I'm making a one-page handout for our reading group (mostly ML engineers, plus one philosopher who will definitely be pedantic about the word agent) and I want it as an actual decision tree, not an essay: start from something everyone in the room already accepts — a transformer trained by next-token prediction on internet text, then post-trained and shipped behind a chat UI — and branch on one claim at a time until you land on a named position. The reason it matters for us is practical: we want to know whether it even makes sense to talk about the model's goals when we deploy it, so the distinctions that matter are the ones that would change how we build or evaluate systems.

Rules for the tree: every branch node has to be a question someone can answer without already knowing where it leads — a concrete case, never do you think it is an agent? Cases I want used somewhere in there: the same base weights before and after post-training; a model instructed to play a character who wants something the lab that trained it does not; a model with tool access and persistent memory told to book a flight; and a bare completion prompt with no character in it at all, like finishing a list of numbers. Leaves should include at least: it is an agent, it is a simulator of agents, simulator-plus-role, mere tool or instrument, the deflationary nothing-but-next-token-prediction view, and at least one something-else option you think the debate is missing. If two leaves come out behaviorally identical, say so plainly instead of pretending the tree seperates them, and flag any combination of answers nobody actually holds and why (incoherent, unattractive, or just unexplored). One sentence per leaf on its most awkward commitment, tell me which single branch question is secretly doing all the work, keep it to around seven branch nodes and eight leaves, and write the whole thing in American English.
