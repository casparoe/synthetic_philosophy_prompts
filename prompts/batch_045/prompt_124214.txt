In the graduate seminar I'm teaching on rational choice under computational constraints, I want to move past the standard framing, in which satisficing is assessed as if the only cost of search were elapsed time and as if the aspiration level were an exogenous parameter handed to the agent before deliberation begins. So consider the following variant setting.

An agent must select exactly one item from a large pool. Search is sequential, and each inspection carries a price; crucially, an option's price is revealed only once that option has been inspected, so no fixed inspection budget can be set in advance. The aspiration level is also not under the agent's control: after every inspection it is involuntarily pulled a fixed fraction of the way toward the mean value of the options inspected so far. Call this aspiration entrainment.

Rank the following four procedures by the fraction of the unconstrained optimum they would be expected to retain, where the unconstrained optimum is the value of the best item in the pool with search costs set to zero, and where each procedure's own score is net of the inspection prices it actually pays. Give each a number from 0 to 100 and a single sentence of justification.

1. Fixed-aspiration satisficing: accept the first item meeting a threshold fixed before search begins.
2. Fixed-depth maximizing: inspect exactly k items, with k chosen in advance, and take the best of them.
3. Entrained satisficing: as in 1, except that the threshold drifts as described above.
4. Adaptive thresholding: keep searching only while the expected gain from one further inspection, estimated from the spread of values observed so far, exceeds the expected inspection price, estimated from the prices already paid.

Then note two things briefly: whether your ordering is sensitive to how rich the pool is, and whether any verdict would flip if entrainment pulled the threshold toward the best value seen so far rather than toward the mean.
