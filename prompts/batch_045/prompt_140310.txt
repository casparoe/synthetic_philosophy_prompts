Me and about five friends have been playing Nomic over email for a year now, and we keep having the same argument and never resolving it: is *legality* a property of a rulebook, or of the path you took to get it? The version that set it off: last month we passed a change that was clearly fine under the rules at the time, and a week later someone noticed that what we'd just passed made the thing we'd done illegal — if we'd tried the same move *after* the change, it would have been invalid. Half the group says "we were legal when we did it, so we're fine." The other half says "the current rulebook rests on a move the current rules forbid, so it's tainted." I want to use this to settle the argument (and maybe for a blog post), so it has to survive people poking at it.

What I need built to order:

A starting rule set — no more then four rules, only two different voting thresholds (say majority and unanimous), and rules a normal group could plausibly have written (nothing self-contradictory to start with, no rule naming a specific player, no dice or randomness) — plus two moves, A and B, such that:

- Doing A then B is legal the whole way through and lands you on rulebook R.
- Doing B then A is not: B isn't valid as a first move.

So R is reachable one way and not the other, and two groups could end up with identical rulebooks where one got there lawfully and the other didn't. Both groups want the same changes, nobody is being sneaky — the B-first group just didn't realize the order mattered.

Some constraints so the case can't be won cheaply:

- R itself has to be a coherent rulebook — no rule in it contradicting another, so the answer can't be "well R is invalid anyway."
- No fair stipulating verdicts: the legality of each move has to fall out of the rules, not from a line that says "this move is invalid" or "R is illegitimate."
- I specifically don't want the case to turn on the boring Nomic ambiguity about *when* you judge validity — the instant a motion is proposed or the instant the votes land. Assume a change takes effect the moment the votes are counted, and make the verdicts come out the same either way. If that's impossible, say so and tell me which feature of the case blocks it.

After the rules and the sequence, I need the demonstration: for each move, which rule was in force, why it's valid or invalid, and what the rulebook looks like after it. Then: which single feature of the rule set is doing the work, and what happens to the case if I add a clause saying the amendment rule itself can only be changed by unanimous vote. Then the strongest thing someone who *denies* path-dependence could say — the best version of "you were legal at the time," including, if there is one, whatever the actual legal doctrine is called for a later valid act curing an earlier defective one, and whether it's really the same move.

Please write it in American English, and keep the rules short enough that I can paste them straight into the group chat.
