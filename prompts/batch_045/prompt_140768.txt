Here is my opening.

I want a test that separates a mere correlation from a code, and the one I have been working with — I call it the Rewrite Test — is this: a system is a code only if the same message can be re-expressed under a different mapping while the message itself stays fixed. Tree rings fail it. You cannot re-encode a drought as a different pattern of rings, because the mapping is nailed down by the physics of growth; change the mapping and you have changed the cause, not the message. The genetic code looks like it passes. Codon tables differ slightly between lineages; a laboratory can introduce an orthogonal transfer-RNA and its charging enzyme so that a codon which used to carry one amino acid now carries a different, non-standard one, and translation still goes through; and the mapping is not even wholly located in the DNA, since the enzymes that load tRNAs typically recognise the shape of the tRNA body rather than reading its anticodon. So the table is arbitrary with respect to chemistry, multiply realisable, and stored partly in the machinery — which is roughly what a convention looks like when you are only allowed to inspect it from the outside. Your view must reply that all of this is just contingent causal fit. Then tell me two things: what work "information" is still doing in your biology that "specific causal role" was not already doing, and why a mapping that survives re-expression of the same message is not a code — especially given that a lock could equally have been cut for a different key, and nobody thinks a lock is a code.
