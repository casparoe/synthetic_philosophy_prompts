Before I read any actual theory of slurs I want the spec. So: write the desiderata a theory of slurs and pejoratives has to meet to be any use for that job — the cases it must get right, the distinctions it can't collapse, the results from linguistics it can't contradict — with the case behind each requirement, and mark which are non-negotiable and which are just one camp's prejudice.

Use my placeholders, don't write out any real slurs, and don't bother name-dropping authors I can't check.

Six cases the list has to handle, because I don't think the usual accounts handle them jointly:

1. "glim" is a slur for group G in community A; in community B, isolated from A for a century, "glim" is just the word for a lamp and has never been applied to anyone. A B-speaker says it in front of an A-audience.
2. "zark" was coined for a category that turned out to be junk — there are no zarks. People still use it, hearers still flinch, it still lands as an insult.
3. "the z-word" — the censored placeholder. Some hearers react to it nearly as strongly as to the word itself. Related: the polite official term gets taken up as an insult, gets replaced, and the replacement starts the same slide.
4. "flim" is a slur for the dominant group, used by the subordinated one, with no history of being used to exclude anyone from anything.
5. In-group members use "zark" among themselves affectionately; an outsider uses the same string, same tone, in the same sentence frame, and it's an insult. Same reference, presumably same proposition, different verdict — and I need to know whether that's acontent difference, a normative one, or something else.
6. The derogation escapes negation, conditionals, questions and belief-reports ("nobody called him a zark", "if he's a zark, then…"), while the descriptive part stays put.

Also required: a verdict per token that doesn't depend on facts a moderator can't see (say, speaker intent), a story about offence with no audience, and a reason not to collapse "offensive", "derogatory", "pejorative" and "slur".
