If I write

struct Proposition { Relation r; Term a; Term b; }

then as far as I can tell I've just got three things sitting next to each other in a box, the same way a list [r, a, b] has three things in it. But a proposition is supposed to say something — to be the sort of thing that can be true or false — and my box has no assertoric juice in it at all. So the obvious patch is to add a fourth thing that does the tying:

struct Proposition { Relation r; Term a; Term b; Unifies u; } // u glues r, a, b together

But now u is a fourth thing sitting alongside the other three, so I need a thing that glues u, r, a and b, and so on forever. That's the regress. Fine. Here is where I actually get lost, and this is the part I want help with:
