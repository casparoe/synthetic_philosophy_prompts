I convene a second-year game theory course: about 60 students, roughly 600 exam scripts a year marked by four TAs whose own training stops at a first undergraduate course. Answers are hand-written, 20–25 minutes per normal-form question, no solvers, games with at most three actions per player. I want one written procedure that my TAs and I can all run when a question asks students to solve by iterated elimination of dominated strategies, so that we agree on what a complete solution looks like and on how partial credit is assigned.

The part I cannot pin down is the mixed-dominator step. I currently tell students to clear every strictly dominated pure action first, and only afterwards to ask whether some surviving action is strictly dominated by a mixture, repeating the cycle until nothing moves. Please turn that into something a TA can actually execute:

- a hand-checkable test for whether an action is strictly dominated by some mixture of the others, done properly for the cases of two and three surviving actions and stated so that someone who has forgotten linear programming can still apply it, together with an honest account of what breaks beyond three actions;
- a stopping rule, and what each of the three stopping states entitles a student to conclude — one profile left, several profiles left, nothing moving but more than one profile surviving — both about Nash equilibria and about which strategies are still rationalizable;
- how to mark an elimination that appealed to weak rather than strict dominance, given that weak elimination is order-dependent and can delete equilibria, so that a smooth-looking but illegitimate solution gets partial credit and not full credit;
- an elimination ledger the students write down and we grade: the sequence of deletions, the dominator exhibited for each (a pure action, or a mixture with its probabilities), and a depth count — number of rounds, and how many of the deletions required a mixed dominator. I use that count for partial credit; tell me if it is a bad measure and what to use instead.

Run the procedure on the two games below, and on one 2×2 of your own choosing in which a student's use of weak dominance would delete the equilibrium the question asks for.

Game 1. Row chooses A, B, C; Column chooses X, Y. Payoffs (row, column): (A,X) = (0,1); (A,Y) = (6,0); (B,X) = (6,0); (B,Y) = (0,1); (C,X) = (2,2); (C,Y) = (2,2). I expect the mixed step to delete C and then for everything to stall; if that is wrong, say so.

Game 2. Row chooses A, B, C; Column chooses X, Y, Z. Row's payoffs against (X,Y,Z): A = (2,2,2), B = (0,0,5), C = (1,1,1). Column's payoffs: against A, X = 4, Y = 0, Z = 1; against B, X = 0, Y = 4, Z = 1; against C, X = 0, Y = 0, Z = 2. I expect nothing to be mixture-dominated at the start, the deletion of C to unlock a mixed domination of Z, and the game then to collapse to a single profile; correct me if either the description or the expectation is wrong.

Two last requests. Label every step of the procedure as theorem, convention, or rule of thumb, and flag any step that holds only for two-player games or only for finite games. If the mixtures-last rule is indefensible, or if depth-counting is a bad grading measure, say so plainly rather than working around it. Finish with a line \answer{...} giving a short verdict on the mixtures-last rule.
