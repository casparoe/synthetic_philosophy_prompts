QUESTION. Consider a Solomonoff inductor S run on a fixed reference universal Turing machine U. Programs for U are self-delimiting, so the weights 2^{-|p|} sum to at most one; the universal semimeasure M gives every finite bit string x the total weight of the programs that output x; and S's prediction at step t, having seen x_1 ... x_{t-1}, is the normalised conditional p_t = M(x_{<t}1) / (M(x_{<t}0) + M(x_{<t}1)), after which it incurs log-loss -log p_t if x_t = 1 and -log(1 - p_t) if x_t = 0. The environment producing the bits is an arbitrary computable process. Compare three setups. A (sealed): S's outputs are written to a tape that is erased immediately, so nothing in the environment ever causally depends on them. B (broadcast): the exact value of p_t is public before x_t is produced. C (coarse): only the single bit that says whether p_t > 1/2 is public before x_t is produced.

The 'malign prior' objection says: a good chunk of the prior mass sits on hypotheses describing worlds that contain consequentialist agents who model S and choose what to show it so as to steer its later outputs. The data S sees is then partly a function of S's own predictions, so a slice of what looks like a neutral simplicity prior is really somebody else's optimisation pressure, and S's predictions can't be trusted the way the convergence results suggest.

The defense replies: (a) the universal prior is dominated by short programs, and a world containing goal-directed agents who model and manipulate the predictor costs a lot of extra description length, so the malign hypotheses carry negligible total weight; (b) in any case accuracy is safe, since by the bound from lecture the total log-loss over the first n steps is at most -log M(x_{1:n}), which is at most K(x_{1:n}) + O(1), with K plain Kolmogorov complexity with respect to U.

Evaluate the objection and the defense. In your answer: (i) say whether the objection needs the environment to actually observe S's outputs, comparing A, B and C; (ii) assess the extra-description-length argument — whether the malign hypotheses can be treated as a family sharing a common prefix whose length bounds their total weight, and whether the cost of the manipulator is a pure overhead or something that can be paid back out of the description of the data; (iii) say whether S's own outputs can appear inside a hypothesis at all, given that they depend on a posterior which that hypothesis partly determines — whether that is a contradiction that rules such hypotheses out, or only a fixed-point condition.

STUDENT ANSWER. Start with what the objection is and isn't. S predicts with the normalised conditional of the universal semimeasure, so the lecture bound applies: over n steps the total log-loss is at most -log M(x_{1:n}), which is at most K(x_{1:n}) + O(1). That holds whatever the environment is doing, so the objection cannot be that S's accuracy collapses — an environment can only inflict loss by producing data that is itself complex, and a simple adversarial rule can't bleed S indefinitely. The content of the objection therefore has to be about control rather than accuracy: part of S's posterior sits on hypotheses where an agent is choosing the data in order to steer S, so part of what looks like a neutral simplicity prior is really another agent's optimisation pressure. Keeping those apart matters below, because the defense is much stronger against the accuracy version than against the control version.

(i) The steering story needs the data to depend on S's outputs, and dependence needs a channel. In A nothing outside S ever sees p_t, by stipulation, so the environment's bits are independent of what S predicts, the hypotheses on which the data is a function of S's outputs get no posterior weight at all, and the objection has nothing to bite on — sealed is safe. B and C are where it lives, and C is strictly safer than B, because publishing only the hard prediction gives the environment less to condition on. So the objection is a closed-loop worry.

(ii) And in the closed-loop cases the defense goes through, and can be stated exactly. Any malign hypothesis has to contain a block pi of code that (a) specifies a goal-directed agent, (b) gives it a model of S, and (c) lets it pick the data as a function of what it expects S to do. That block costs at least a few hundred bits, since a simulator of S has to be in there; and every malign program contains it, so after moving pi to the front — which changes each program's length by at most an additive constant — the malign hypotheses share a common prefix, and Kraft's inequality bounds their total weight by 2^{-|pi|}. Nor can the cost be earned back: what the agent gains by steering is bounded, so it cannot refund more than O(1) bits of description length, and the posterior mass of the malign family stays negligible. S therefore predicts essentially as if the malign hypotheses weren't there.

(iii) The circularity worry is a red herring. It's true that S's output at step t depends on its posterior, which depends on which hypotheses are live, including any hypothesis that simulates S. But S is a computable object, so a program holding S's code can compute S's outputs step by step from the data, and the joint system has an ordinary well-defined trajectory; all that is required is that the simulation inside the hypothesis agree with what S actually does, which is a self-consistency or fixed-point condition, not a contradiction. Hypotheses like that exist; they are just heavily penalised, by (ii).

Net: the defense wins. The malign prior is a real phenomenon wherever the predictor's outputs are visible to the thing producing the data, but its force is capped by the description-length cost of the machinery, and that cost cannot be recovered.
