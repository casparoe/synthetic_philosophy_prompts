For a seminar packet I'm putting together I need one document: the joint statement two people would sign after an adversarial collaboration about wireheading.

Side A — call them the specificationist — holds that wireheading is a specification failure: the reward signal is our fallible, revisable statement of what we want, an agent that tampers with the channel between the world and its reward has shown us we wrote the spec wrong, and the right response is better reward design (harder channels, tamper-detection, reward modelling, retraining). Side B, the structuralist, holds that this is treating the symptom: what we actually want is states of the world, any agent able to see the channel has instrumental reason to intervene on it, and no reward function is ever secure, so the response has to be structural — myopia, impact limits, agents that execute tasks rather than maximise a number.

What I want is: the claims both can sign; the disagreements, each in wording its own side would accept as fair; then the cruxes, and for each crux the case or argument both agree would bear on it, with each side's prediction written down in advance. Two cruxes I'd like built in so it doesn't stay at the hand-wavy level. First, the hermetic channel: the reward is computed by a sealed, uninfluenceable box and the agent learns it is sealed — does sealing the channel merely convert tampering into world-hacking, or does it actually solve something? Second, comparator shift: an RLHF'd model that never touches the reward model or the wire but gradually shifts which judges or labels count as authoritative. Is that wireheading, or something the specificationist can live with?

Numbered agreed claims first, then a disagreements table with columns for the crux, the specificationist's line, the structuralist's line, and each side's advance prediction. Under 700 words, and please dont pad it with general background on alignment.
