I think Ive found a way to defuse the Newcomb problem and I want to check it before I build a talk around it. My read is that the puzzle only feels paradoxical because the standard setup smuggles in backwards causation: the money is already in the box, so my choice now has to be correlated with something that happened earlier, which only makes sense if the predictor can see the future or if the universe is deterministic. So my fix is to redescribe the predictor naturalistically. Its a hospital-grade brain scanner plus a big model trained on ten thousand previous subjects; it reads my brain an hour before I walk into the room and its right about 90% of the time. No time travel, no determinism, no spooky being. Once you do that the correlation is just an ordinary prediction about a physical system, the causal picture is completely mundane, and the dominance argument goes through untouched: whatever the scan said, the money is in the box or it isnt by the time I get there, so I cant affect it and I should take both boxes.

The numbers back me up as far as I can tell. Predictor is reliable 90% of the time, so theres a 90% chance the million is in there. One-boxing: 0.9 x 1,000,000 + 0.1 x 0 = 900,000. Two-boxing: 0.9 x (1,000,000 + 1,000) + 0.1 x 1,000 = 901,000. Two-boxing wins by a thousand, which is exactly what youd expect given that opening the second box cant change whats in the first. So the paradox is just people being spooked by a sci-fi framing, and one-boxers are people who half believe in destiny.

The bit Im less sure about: I want to add a per-subject confidence score, because that seems like what a real system would output. The machine prints something like "87% confident this subject one-boxes" right on the box where the person can read it before choosing. I was going to argue this makes the two-boxing case even more obvious, since now you can do the expected value calc with your own reliability number instead of the population base rate.

Is that right? Does the confidence score on the box actually change anything or is it just decoration?
