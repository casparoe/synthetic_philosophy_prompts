My brother-in-law Dale — software engineer, recently decided that nothing is actually infinite and that mathematicians are all kidding themselves — got me going at Thanksgiving and I've been chewing on it since. I tried to write out a clean little argument that Hilbert's hotel is perfectly coherent, i.e. that there's nothing wrong with an actual infinity as such, and my argument seems to work too well: if it's sound, Cantor was wrong and there's only one size of infinity. I'm pretty sure that's false, so one of my steps is doing something I didn't intend, but I cant tell which. Which step do I reject, and what does rejecting it cost me?

(1) Two collections have the same number of members just in case their members can be paired off one-to-one with nothing left over on either side.
(2) A collection is infinite just in case it can be paired off one-to-one with a proper part of itself. (That's the whole hotel trick: the guest in room n pairs with room n+1, or with room 2n.)
(3) So an infinite collection can be paired off with parts of itself that look, by any naive count, like only a fraction of it: evict everyone in an odd-numbered room and the survivors still pair off, one-to-one, with everyone you started with.
(4) Running it the other way, a hotel that is completely full can take in infinitely many new guests.
(5) So for infinite collections, "how many" is insensitive to adding and subtracting: double it, halve it, add infinitely many, throw away infinitely many — same number throughout. And none of this turns on anything special about hotels; (1) and (2) never mention them.
(6) Pairing off is the only grip we have on "how many" here, and any infinite collection can be run through member by member: however many you've already ticked off, there are always more to tick off, so the ticking-off never stalls, so the collection gets paired off with the room numbers 1, 2, 3, …
(7) So any two infinite collections have the same number of members: each one pairs off with the room numbers, and therefore with each other.
(8) So there is exactly one infinite number. There aren't more reals than rationals or whole numbers, and the diagonal arguement must go wrong somewhere.

If I have to choose, I'd rather keep (1) and keep Cantor's theorem than keep anything else, and I'd rather not lean on the axiom of choice, because Dale will pounce on it.
