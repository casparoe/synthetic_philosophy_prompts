Consider the following stylized artificial chemistry, which I will call a typogenetic system (it is meant to capture, in miniature, the DNA–Gödel isomorphism between self-replicating strands and Gödel-style fixed points). Call this system T. Strands are non-empty strings over the alphabet A, C, G, T. Every strand S is translated into an enzyme E_S by reinterpreting the exact same string of letters as a program. The enzyme acts on an arbitrary substrate strand X by executing, from left to right, the operations named by its letters: A appends an A to the right end of X; C deletes the rightmost base of X (if this empties X, the output is the empty string, which I treat as a degenerate non-strand result); G replaces X by two copies of itself concatenated; T changes the leftmost base of X from A to C if it is A, and otherwise leaves X unchanged. Let E_S(X) denote the result of running E_S on substrate X, and say that S is self-replicating if and only if E_S(S) equals S concatenated with S.

I have constructed the following argument with a study group, and I now find it suspicious because its conclusion seems to me absurd. I would be grateful for a diagnosis.

(1) In T, translation is the identity on strings: the enzyme E_S is the same sequence of letters as the strand S. Thus one and the same object is, on the one hand, a passive sequence of bases and, on the other hand, an active program that can be run on that very sequence. This is the DNA–Gödel isomorphism in miniature: the strand plays the role of both the coded message and the operator that acts on the code.

(2) Because the operational semantics is deterministic, for every strand S the value E_S(S) is well-defined, and S is self-replicating exactly if E_S(S) = SS.

(3) The recursion (or diagonal) lemma for this language guarantees that self-replication is achievable: there exists at least one strand Q such that E_Q(Q) = QQ. A concrete example is the strand G, whose only command duplicates the substrate, so E_G(G) = GG.

(4) The recursion lemma is completely general. It does not confine the result to one specially chosen strand; it says that for any systematic way of letting a program refer to its own code, there is a program that reproduces its own code. In T that reference is automatic for every strand, because running E_S on S just is a case of a program being supplied with its own source code as its initial data.

(5) A program that has been given its own source code as input is in a position to reproduce that code: it can treat the input as a template and emit a copy of it. In the operation language of T, this means that the enzyme can use the substrate S to build a second S.

(6) Therefore, for every strand S, E_S(S) = SS. Every strand in the system is self-replicating.

But I cannot accept (6). The strand C is a counterexample: its enzyme consists of a single delete command, so E_C(C) is the empty string, not CC. I am confident that step (3) is true (there really are self-replicating strands, G being one), and I am even more confident that C does not self-replicate. So the mistake must lie in the chain from (3) to (6). I would rather keep (3) and the counterexample than accept (6), but I do not want to beg the question against (4) or (5), which looked like straightforward applications of the recursion lemma and of the idea that access to one's own source suffices for self-reproduction.

Which step do you reject, and what does rejecting it cost? In particular, if the flaw is in (4), does that mean the recursion lemma gives only an existence claim (there is some self-replicating strand) rather than a universal mechanism, so that the DNA–Gödel isomorphism is a special fixed-point construction rather than a general property of all strands? If the flaw is in (5), does that mean that merely having one's source available as data is not sufficient for self-replication, because the program must also contain the right copying instructions, so that the isomorphism holds only for those strands that already encode a duplication operation? Please name the step, explain why it looked fine, and price the alternatives. Please write your answer in American English.
