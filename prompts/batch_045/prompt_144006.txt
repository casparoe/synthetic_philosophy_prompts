I'm in a final-year metaphysics seminar on infinity and continuity, and I built the following argument for a class presentation. My tutor read it and said only that it "proves too much," which I've been turning over for a week without locating the seam. The set-up: a lamp with a two-position switch. It is switched on at t = 0 and flipped at t = 1/2, 3/4, 7/8, and so on, so that every flip happens before t = 1 and there are infinitely many of them. (1) For every flip there is a later flip, and all flips occur before t = 1; so the sequence of flips has no last member. (2) The lamp is on at t = 1 only if there is a flip F such that F turns the lamp on and no further flip occurs after F and before t = 1 — that is, only if some flip is the last flip. (3) By (1), no flip is the last flip. (4) So the lamp is not on at t = 1. (5) The parallel argument with "on" and "off" exchanged gives: the lamp is not off at t = 1. (6) If the lamp still exists at t = 1, then it is either on or off. (7) So the lamp does not exist at t = 1. (8) Nothing empirical went into this — no premise about wiring, or the speed of light, or the finite response time of filaments; the contradiction follows from the description of the sequence alone. (9) So the supertask is not merely physically unrealizable but logically impossible: the description is inconsistent, and no amount of idealizing away physical limits would make it coherent.

Here is what broke my confidence. To test the argument I invented a variant, which I've been calling the filament lamp. The switch is thrown on exactly the same schedule — same flip times, infinitely many, no last one — but the lamp's brightness is not a two-valued function of the switch position. Instead the brightness relaxes continuously toward whatever the switch is currently set to, with some fixed response rate: the faster the flips come, the less the brightness manages to move. Because the intervals between flips shrink geometrically while the response rate stays fixed, the total remaining variation after any time t shrinks along with the time left, so the brightness converges to a unique limiting value as t approaches 1. I simulated it on my laptop and got about 0.67 on a 0-to-1 scale, not the 0.5 I had naively expected — apparently it matters that each "on" interval is exactly twice as long as the "off" interval that follows it — and the number came out the same however finely I discretized, which is what convinced me it wasn't an artifact. So here is a device that performs the very same infinite sequence of flips in the very same finite time, with no last flip, and whose state at t = 1 is as determinate as anything. Yet (1), (2) and (3) apply to it word for word, and they would deliver the conclusion that the filament lamp has no brightness at t = 1. That can't be right, so something in my original argument is broken — but I genuinely cannot tell whether the culprit is (2), which now looks to me like an assumption smuggled in from the case of finitely many flips; or the step from (2) and (3) to (4), which maybe holds at every time strictly before t = 1 and then fails exactly at the limit; or (6), which looked like bare logic but might be where a hidden assumption about the lamp's still existing is doing the work; or (9), which might be an overgeneralization from "incompletely described" to "impossible."
