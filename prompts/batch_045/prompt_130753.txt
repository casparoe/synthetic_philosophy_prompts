I'm in a philosophy of computation seminar and I'm trying to work out what rule my professor is actually running. Her rulings so far on "is this a case of computing something no Turing machine can compute" —

- a Turing machine hooked up to a black box that answers halting questions: no, you've just stipulated the answer
- an accelerating machine whose nth step takes half the time of the one before, so it gets through infinitely many steps inside a minute: no, it needs unbounded speed and unbounded precision in the mechanism
- a machine that works over exact real numbers, can be loaded with a non-computable constant, and prints out its digits: no, you can neither set nor read a real to infinite precision
- a machine with a genuine physical coin-flipper built into it: no, noise isn't the halting problem
- a relativistic setup where the machine gets infinite time on its own clock while the person waiting for it only waits an hour: no, speculative physics on top of the same unboundedness
- a black box that answers halting questions correctly for every input anyone has tried, but only provably up to some finite size nobody knows: no, for all you know it's a gigantic table, and a finite fragment isn't the function
- a continuous medium obeying an equation we can write down exactly, with initial conditions we can specify exactly, whose amplitude at a fixed later time is (grant this for the sake of argument) a non-computable number: still no, because getting the value out would take infinite precision in the readout
- and two side remarks: a wave tank being used to model a harbour isn't computing anything, but a digital simulation of the same harbour is; and the unsolvability of the halting problem is a real limit on algorithms, not a limit of current hardware.

Now the new cases. First, the Loudspeaker: take that continuous-medium setup but cascade it into an amplifying stage — the amplitude at the later time tips a switch, the switch feeds a chaotic amplifier, and the result is a single big robust bit on a display. No precision is needed to read it, the bit is non-computable, and I can build fresh copies of the rig and run it again to get further bits. Second, the Stubborn Screen: a machine that never halts and never announces that it is finished, whose screen shows a running guess at "does program n halt", where the guess stops changing at some finite time and is correct from then on, but nothing tells you when it has settled.

What are the candidate rules that fit all of her verdicts — something about physical resources, something about what counts as computation at all, whatever else you can think of — what does each predict about the Loudspeaker and about the Stubborn Screen, which prediction would you bet on and why, and what further case would you put to her to tell the surviving rules apart? I care much more about the shape of the rule than about the final yes-or-no.
