Hope this ok to ask here — I sit in on a metaphysics reading group on Tuesdays (I'm the only one in it who isn't a philosophy PhD student; I work in ML deployment) and we've been going through the literature on dispositions: fragility, solubility, and the counterexamples to the simple conditional analysis. I think I'm missing something basic about the taxonomy. As I understand it, a fink is a case where the stimulus itself destroys the disposition before it can manifest — the wired-up glass that gets de-charged the instant you strike it — and a mask is where something extrinsic blocks the manifestation while the disposition sits there intact, like the same glass packed in foam. But to me those are one objection wearing two hats: in both cases the object is fragile, in both cases "if it were struck, it would break" comes out false, so in both cases the analysis needs the same repair. One of the PhD students said masks are the genuinely hard case and that finks were more or less dealt with by the Lewis-style move of holding the intrinsic basis fixed, which I really don't get: if anything the fink looks worse to me, because there the disposition literally goes out of existence, whereas with a mask nothing about the object changes at all. So what's actually asymmetric between them?

Because I couldn't see the asymmetry I tried to write down one fix that covers both: x is disposed to M in C iff x would M if C obtained and nothing interfered with M-ing. My friend said that's circular and I said only if you're being pedantic, since everyone knows what interfering amounts to. She also said it would count things as disposed that clearly aren't, which I also can't see. What's the real objection to a one-line fix like that?

The bit I actually care about, though, is a case from work I brought to the group, and I've been going back and forth on it. We had a model that would reliably emit a certain kind of toxic completion when prompted a particular way, and we shipped it with a runtime guard that watches for the trigger pattern in the incoming prompt and, if it fires, swaps in a different set of weights for the rest of the call — so the model that actually does the generating isn't the model that recieved the prompt. Someone said that's just a fink with extra steps. I said it isn't, because the swap means there's no single object that has the disposition and then loses it; the property bearer changes, so it's more like swapping the glass for a different glass at the moment of the strike. But then I worried that if that's right, whether something counts as a fink at all depends on where we draw the boundaries of the object, which feels like it shouldn't matter to a metaphysical question. And separately: take the same model with a plain post-hoc output filter instead. Is the filter a mask on the model's disposition, or is it just that the model-plus-filter system doesn't have the disposition, full stop, with no masking going on? Because if it's the second, then "mask" starts to look like nothing more than what we say when we're attached to attributing the disposition to a part rather than to the whole, and the whole category looks deflationary. Where am I going wrong — and does anything of my version survive once the confusions are cleared up?
