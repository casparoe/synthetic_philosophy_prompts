**Question 3 (20 marks).** Anti-realists about a domain are often drawn to the knowability principle: (KP) every truth is knowable — i.e. for every proposition p, if p is true then it is possible that p is known. Fitch's paradox is supposed to show that this collapses into something the anti-realist cannot accept.

(a) Set out the argument as carefully and as formally as you can, and at each step say exactly which assumption about knowledge or about modality you are using. [8]

(b) In the lecture I floated a repair: read "known" as *known by somebody at some time* — call the resulting operator K\* — so that KP becomes: for every truth p, it is possible that somebody at some time knows p. The thought behind the repair is that the anti-realist never claimed every truth has to be within reach of *us, here, now*; they only claimed that truth is not in principle beyond inquiry, and inquiry is spread over all inquirers and all of history. Does this repair block the argument? Either re-run the argument against K\*, or say precisely which step fails and why. [7]

(c) If the repair fails, which assumption should a defender of KP give up, and what does giving it up cost them? [5]

**Student's answer.**

*(a)* Write Kp for "p is known" and let the diamond be metaphysical possibility. KP is ∀p(p → ◇Kp). Non-omniscience (call it NO) says there is some truth we do not know: ∃p(p ∧ ¬Kp). Let q be such a truth, so q is true and ¬Kq.

Since q ∧ ¬Kq is true, KP applies to the proposition (q ∧ ¬Kq), giving ◇K(q ∧ ¬Kq). Knowledge distributes over conjunction, so K(q ∧ ¬Kq) entails Kq ∧ K¬Kq; that entailment is logical, so it holds inside the possibility operator as well, giving ◇(Kq ∧ K¬Kq). Now for the second conjunct: the move from K¬Kq to ¬Kq is an instance of positive introspection, the KK principle — if you know that you do not know q, then you know your own ignorance, and so it really is the case that you do not know q. Conjoining, ◇(Kq ∧ ¬Kq), which is impossible, since nothing possible is contradictory. So the supposition that (q ∧ ¬Kq) is true must be rejected: ¬(q ∧ ¬Kq). As q was arbitrary, q → Kq, and generalising, every truth is known — contradicting NO. So KP and NO cannot both hold, and since NO is certainly true, KP has to go. The assumptions I used: distribution of K over conjunction, positive introspection (KK), the normality of the modal operator (if A strictly entails B then ◇A → ◇B), and classical logic in the final step — intuitionistically you would only get q → ¬¬Kq, so that last step is where classical logic is doing work.

*(b)* I think the repair does block the argument, and the reason is that the Fitch sentence can no longer be constructed. K\* is not an operator which takes a proposition and returns something that is true or false at a time: "somebody at some time knows that p" is only assessable relative to a time, so "q ∧ ¬K\*q" illegitimately mixes something time-relative with something that is not, and there is no well-formed proposition there to feed into the universal quantifier in KP. The argument therefore never gets started. This is not a technical dodge either: if the instance could be formed, the argument would go through, because K\* is still factive (if somebody at some time knows p then p) and still distributes over conjunction. It is specifically the construction of the instance that fails. So the anti-realist can keep KP in the K\* form; and even if the argument did go through, all it would deliver is the weaker claim that every truth is known by someone at some time, which is not absurd in the way that present-tense omniscience is.

*(c)* The best response is a restriction: restrict KP to propositions which do not themselves contain the knowledge operator. That is not ad hoc, because propositions without the knowledge operator are just the empirical, first-order ones, and those are all the anti-realist was ever making a claim about anyway — the whole point of KP was to tie truth to what we could in principle observe or verify. The cost is small: they lose the right to apply KP to epistemic claims like "nobody ever knows that q", which they never wanted to apply it to in the first place.
