In a reading group I keep hearing this defence of Laplace's demon: a deterministic world is exactly like a computer program — fix the input (the complete state at one time) and the rules, and the output (every later state) is fixed as well; a demon is only a machine with more memory and more clock cycles, so determinism really does entail predictability in principle, and chaos merely makes prediction expensive, never impossible.

I want to press on a distinction this glosses over. Distinguish three grades: (i) determinism — the exact state at one time fixes a unique exact state at every later time; (ii) simulability — some finite procedure turns a finite description of the initial state into the state at any later time, to whatever accuracy you ask for; (iii) decidability — some finite procedure answers arbitrary yes/no questions about the whole future trajectory (will it ever enter region R? does it return infinitely often?). Grant the defender unlimited memory and unlimited time, but suppose the exact initial state is a vector of real numbers, and suppose for the sake of argument that some deterministic systems are rich enough to contain a universal computer, so that asking whether the system ever enters R can encode asking whether an arbitrary program halts.

Audit the analogy. Set out explicitly what plays the role of the input, the program, the output and the clock cycle; say which of the three grades the picture quietly assumes and which it only appears to assume; say which grade sensitive dependence on initial conditions actually undermines and which the embedded-computer case undermines; and say whether any claim about predictability in principle survives once the disanalogies are on the table. If the computer-program picture turns out to be carrying more than it can bear, what analogy does the work better? Please answer in British English.
