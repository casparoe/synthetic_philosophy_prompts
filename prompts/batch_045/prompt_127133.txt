I am writing a paper on whether the preface paradox is merely the lottery paradox in professional dress, and I need a pair of cases that pries the two apart. Specifically, I want to know whether the pressure toward "at least one of these is false" can exist in full force in a case where the probabilistic route to that conclusion — the route that does all the work in a lottery — is genuinely unavailable. Call the target a *calibrated-preface pair*.

Build me two scenarios, and build them as a matched pair: same agent, same kind of claim, same number of propositions n, same credence c in each individual proposition, same track record, same professional setting. They may differ in exactly one respect: whether the evidence for the individual propositions is probabilistically independent, or whether all of it passes through a single shared failure mode that the agent knows about only globally — they know that every check was calibrated against one standard, and nothing about which claims that standard is kind or unkind to.

Specifications:

1. No lotteries, no random sampling, no coin flips, and no explicit base rates about the subject matter. The support for each individual proposition must be non-statistical: testimony, checking, measurement, argument. Realistic setting — a critical edition, an audit, a lab's dataset, a regulatory filing — one paragraph per case, no more.
2. Choose the threshold t for justified outright belief, then choose n and c and show the arithmetic. In Case A (independent), c must exceed t while the probability of the conjunction falls below 1 − t. In Case B (common failure mode), the multiplication must be blocked in a way that is principled rather than merely messy, so that the agent's credence in the conjunction stays above t even though each conjunct sits at c.
3. In both cases the agent must also have a preface-style reason: an induction from their own track record on projects of this size, not derived from the individual probabilities, for thinking that at least one claim in the set is false.
4. No asymmetry. In neither case may the agent be able to single out, rank, or selectively retract any particular claim. The error belief has to be irreducibly global.
5. The two routes must be separately detachable: delete the track record from Case A and the paradox should survive; delete the independence from Case A and the probabilistic route should collapse while the preface route remains.

Deliverables:

- For each case: the proposition set, the credence in an arbitrary member and in the conjunction, the arithmetic or the reason no arithmetic is available, and the verdict of three treatments — (a) threshold plus closure; (b) threshold with conjunction introduction restricted so that it is not a generally warranted inference pattern; (c) a coherence treatment on which justification is a property of the whole belief set and an incoherent set must be repaired.
- The honest part. Case B is the hard one, and it may not be buildable. If the track-record reason is just a roundabout way of assigning a low credence to the conjunction, then the agent is either probabilistically incoherent or Case B is Case A in disguise over a hidden binary variable, and the unified treatment wins. I want you to try to build it, and if the only way to satisfy the specifications is to stipulate the verdicts, to sneak in a hidden lottery, or to make the agent incoherent, then say exactly where it fails and what would have to be true of the track-record evidence for it to succeed.
- Which feature does the work, and what happens to each case when it is removed.
- If the pair does come apart, which of the three treatments can handle both cases with a single uniform rule, and what does that rule cost elsewhere.
