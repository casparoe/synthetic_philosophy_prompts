Here is where I got to. The idea that got me interested: in a one-shot Prisoner's Dilemma, let each player submit a program that is handed the other player's program's source text and outputs cooperate or defect. Then the program that cooperates just in case the text it receives is character-for-character the same as its own text makes mutual cooperation an equilibrium, because any deviation is met with defection. This always struck me as close to a cheat: the cooperation seems to depend on how the code is *spelled*, not on what the code *does*. Rename a variable, add a line that is never executed, reorder two independent statements, and the whole thing collapses into mutual defection.

So I tried to fix it. Call my fix behavioural twinning. Each player submits a program that does not compare texts at all. Instead there is a fixed, public list of test inputs — call it the Examination — agreed before anyone writes anything. My program runs your program on each item of the Examination, compares its answers with the answers my program gives on those same items, and cooperates just in case every answer agrees. Irrelevant rewrites of my program now pass, so the fragility I objected to should be gone.

I now think I have only moved the problem, and I want the strongest version of that case. Two things bother me. First, if the Examination is fixed in advance, I can write what I think of as the Impostor: a program that has your program's source text hard-coded inside it (which I take to be fair game, since the entire point is that each program gets to read the other's text), reproduces your program's behaviour on every item of the Examination, and defects the instant it is handed your source text. It passes your test, so you cooperate; it defects, so it does better than cooperating would have done. Your program is then not a best response to itself. Second, the repair I can see for that is to let each program insert its own source text into its own Examination list — I gather a self-printing trick of some kind makes this possible. That does block the Impostor as I described it. But now take two programs that are identical in behaviour and differ only in spelling, which is exactly the case I wanted to rescue. Each demands that the other match it on a list containing its own text; each therefore has to evaluate the other on its own source; and each of those evaluations requires the result of the other. To me that looks circular: either the two programs run forever, or one of them has to give up and fall back on defection, and in neither case do the twins cooperate. So the move that blocks the Impostor appears to blind the test to its own twins.

What I want you to argue is that this dilemma is real and general, not an artefact of my two examples: that no test of the Examination sort can be both proof against impostors and welcoming to genuine behavioural twins, and therefore that the fragility of the original spelling-based trick has not been removed but relocated. Along the way, please deal with the two repairs I can think of. One: forget test suites and instead pass both programs through a public normalising compiler that strips out irrelevant differences before the comparison, so that what gets compared is a canonical form — does that escape the dilemma, or does the canonical form merely draw the line between relevant and irrelevant in a new place, and can that line ever be drawn purely in terms of behaviour? Two: have each program try to *prove*, in some formal system, that the other cooperates with it, rather than testing the other on examples — does that escape, and what does it cost? And if the dilemma does hold, say plainly what you think follows for the original motivation: whether program equilibrium ever explained how cooperation could be rational here, or only restated the problem in a new vocabulary.

Finally, be explicit about your own confidence. For each of the main claims you make, tell me how confident you are, and single out the one point you are least sure of — ideally the point where a defender of behavioural twinning would push hardest.
