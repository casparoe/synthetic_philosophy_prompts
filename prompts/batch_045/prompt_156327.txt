i'm building the risk-scoring layer of a hospital readmission system — the bit that has to take one particular patient, put them into some reference class, and hand a clinician a single number before discharge — and before i commit to a rule i want to know what such a rule would even have to be able to do. so: write me the desiderata for a theory of reference class selection. not what class this patient goes in, but what any account of *which* class is the right one has to deliver, with the case or consideration behind each item, and sorted into non-negotiable, negotiable, and things i only think are requirements because of the camp i'm in.

the purpose is fixed: it has to be good enough to guide a real decision about an individual (extra home visits, a longer stay), the decision will actually be made on the basis of it, and the number has to be defensible afterwards both to the patient and to whoever audits us.

cases i think an adequate account has to handle, and which should be the reason each requirement is on the list:

- a 68-year-old diabetic admitted through the ER in february, living in a postcode that's a decent proxy for low income. intersect all of that and the class has three people in it. intersect only some of it and you get plausible numbers that disagree with each other.
- two perfectly admissible classes that both contain the patient and give different rates: men 60-69 with diabetes, versus everyone admitted via the ER in winter. nothing has gone wrong in either description, they just disagree.
- classes that are defined partly by the outcome. the obvious one is patients we did readmit, which gives 100% and is useless; the interesting one is patients flagged high-risk by our old model, which predicts readmission mostly because the flag caused extra visits. i want to know whether banning the first kind is enough or whether the second kind needs its own clause.
- once we start acting on the number, the class's own rate moves: the home visits work, so the base rate in the class we used to calibrate on drops. the class we wanted before the policy isn't the class we get after it.
- a new biomarker starts being measured next year. same patient, same everything else. i have a strong feeling last year's number does not thereby become wrong, but i also think the new variable should be used from now on, and i can't see how to hold both without the theory saying something about whose information state the class is relative to.
- masking: the wide class says 15%, but inside it one subgroup is at 4% and another at 31%. the person from the 4% subgroup gets told 15%, and i genuinely can't tell if that's the best estimate available given what's knowable or whether it's just averaging away a disparity that we do in fact have the data to see. give this phenomenon a name if it doesn't have one i'd recognise, and tell me whether it generates a requirement or is really just an instance of some other requirement.

requirements to argue about, at least: use all the evidence you have about the individual; use the narrowest class that still has enough members for a stable frequency; never let the class be defined by the outcome; don't let the answer change when a newly measured variable is outcome-irrelevant; stay calibrated inside whatever class you pick; be computable in time to be useful; survive being acted upon; produce one number rather than a spread across admissible classes; and use only classes that are causally homogeneous with respect to the outcome rather than merely statistically associated.

then the part i actually want: which of those are real desiderata and which are just the prejudices of one camp — i suspect one-number-per-patient is an institutional hangover rather than a requirement, and i suspect only-count-actual-finite-classes is a frequentist hangover — and which subset of the list can't be jointly satisfied. my bet is that use-all-the-evidence, only-use-classes-with-reliable-statistics and one-number-for-a-one-off-case can't all hold, but i'd rather you find the pair that genuinely breaks and show me the case where it breaks. if the honest answer is that the list is jointly unsatisfiable, say that plainly, because i can take that back to my team as a result.

and only at the end, a couple of lines each, no table: how the usual contenders do against the list — the narrowest-reliable-class rule, fit-a-model-on-all-the-covariates-and-read-off-the-individual-prediction, a causal view where the class gets picked by what causes the outcome, and pick-whatever-class-is-best-calibrated. which single requirement does the most work excluding candidates.
