Construct a puzzle in the manner of Hofstadter's MU puzzle — a small formal system consisting of an alphabet, a single axiom string, a short finite list of string-rewriting rules, and two candidate target strings — engineered so that it isolates what, if anything, is distinctive about jumping out of a system. The verdicts must be generated by the system you design, not stipulated by you, and everything must be checkable by hand: no external theorems, no appeals to unproven complexity assumptions, no apparatus that would not fit in an undergraduate lecture on formal systems.

Specifications for the system.

1. One target must be derivable from the axiom, but only by a derivation whose length is infeasible — give the exact figure or an elementary lower bound, and state the number of distinct strings reachable within the first few dozen steps, so that it is clear that generating theorems cannot settle the question in practice. The second target must differ from the first in exactly one letter and must not be derivable at all.

2. There must be a meta-level characterization theorem of the form: a string is derivable if and only if it satisfies condition C, where C is decidable by hand in time polynomial in the length of the string. Prove both halves: every rule preserves C, and every string satisfying C can be reached by an explicit construction from the axiom.

3. C must be sensitive to the order of the letters rather than being a restatement of a letter count: exhibit two strings with identical letter counts, one derivable and one not, and show that C separates them. The point is that the case should not be a re-skin of the MU invariant, in which only the number of I modulo three does any work.

4. The system must be a plain rewriting system with at most six rules: no rule may take strings as objects, no marker letters that encode the invariant, no arithmetization, no self-reference, no rule that allows a lemma to be written down. The characterization theorem must live genuinely outside the system, and there must be no way to convert it into a derivation that the system itself could contain.

5. Alongside C, give a decoy criterion C that every derivable string satisfies, that agrees with C on all strings up to length six, and that is nonetheless not sufficient; supply a witness string that satisfies C but is underivable, prove its underivability from C, and say in one sentence which structural feature of the rule set makes the decoy merely necessary. This pair is the variable the case is designed to isolate: the difference between noticing a conserved quantity and having a complete decision procedure for the system.

Deliverables.

a. The system written out in full — alphabet, axiom, every rule, both targets — with the targets given by a compact description such as exponent notation if they are too long to write out literally.

b. The statement and both halves of the proof of the characterization theorem, plus at least one short worked derivation as a sanity check that the rules do what you claim.

c. The verdict on each target with the numbers that decide it, and an explicit contrast between the two ways in which working inside the system fails: for the derivable target it fails only practically, since search would in principle terminate, whereas for the underivable target no finite prefix of an enumeration ever licenses the negative verdict.

d. A statement of which single feature of the design is doing the work, with everything else you have varied or fixed noted explicitly.

e. An ablation: add one rule that lets the system encode and reason about its own rules, and say whether the jump-out then collapses into an in-system derivation, and whether any gap in tractability between search and characterization survives.

f. A note on what the case is for, and therefore on what would count as cheating. It is meant to test the claim that jumping out of the system is a distinctive cognitive achievement rather than a honorific label for reasoning well about a formal object; so it would be cheating to stipulate the verdict by having the agent simply see the answer, to rule out by fiat a search procedure that would in fact settle the question in reasonable time, or to smuggle the meta-level reasoning back in as one of the rules.

g. The strongest objection a deflationist about jumping out of the system would press: that outside the system only marks a choice about which formalization we call the system, that every proof about anything is a meta-level move with respect to its object, and that what your case really exhibits is a complexity gap between blind search and characterization rather than a boundary with philosophical weight. Give the best reply available on behalf of the case, and then say honestly which of the two sides the case as you have built it actually supports.
