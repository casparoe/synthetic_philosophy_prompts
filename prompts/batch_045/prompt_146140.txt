Setup so we mean the same thing. Standard anti-luminosity argument: a condition C is luminous iff whenever C obtains in a case, the subject in that case is in a position to know that C obtains. Add a margin-for-error premise — if you're in a position to know that C obtains in your case, then C obtains in every case that shares your total evidence with yours — build a long sorites of pairwise-indistinguishable cases running from clear-C to clear-not-C, and no non-trivial condition comes out luminous. Apply it to C = S knows that p, and since knowing p presumably puts you in a position to know p, KK goes.

The bit I'm actually stuck on is a shortcut I've started calling the one-step argument, and I want to know how much weight to give it. Take a Gettier pair. In case α, S has evidence E, truly believes p on that basis, and knows p. In case β, S has exactly the same evidence E, still truly believes p, but is Gettiered and doesn't know. Now run the margin premise once instead of n times: if S were in a position to know in α that she knows p, then S knows p would have to obtain in β as well, which it doesn't. So no sorites needed — on any account where knowledge is fragile to Gettier-style luck, KK fails in perfectly ordinary, non-borderline cases. And notice the two places it can be blocked: if evidence is factive (roughly, your evidence is your knowledge), then α and β differ in evidence and the shortcut never leaves the ground; and if you read the margin premise in a reliabilist way — in a position to know implies C obtains in *most* nearby cases rather than *all* evidence-twins — then a single bad twin isn't enough and you're back to needing the full sorites.

Here's the proposition I want a credence on: in a fully worked-out externalist epistemology that treats knowledge as true belief plus some anti-luck or safety condition, there are ordinary non-borderline cases in which a subject knows p but is not in a position to know that she knows p.
