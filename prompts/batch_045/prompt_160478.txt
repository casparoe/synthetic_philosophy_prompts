**Superrationality, graded: the dilemma one level up**

**1. The premise doing the work.** In the one-shot Prisoner's Dilemma between two agents who know they are running the same decision procedure, the superrational answer is cooperation. The argument is not that the other agent is nice; it is a claim about the *support* of the joint outcome distribution. If the procedures are identical, then (C,D) and (D,C) have zero probability, only (C,C) and (D,D) are live, and since R > P one should cooperate. Call this the identity premise. Everything distinctive about superrationality — as against evidential or causal reasoning about a merely similar opponent — rests on it.

**2. Grading the premise.** The identity premise fails in every case of practical interest: I am not running your code, our evidence differs, our tie-breaks differ. So replace it with a graded quantity. Let c be the mirroring probability: with probability c your action equals mine whatever I do; with probability 1 − c our actions are independent, and in that case each of us faces an uncorrelated opponent and so defects. Take payoffs T = 5, R = 3, P = 1, S = 0, with 2R > T + S so that turn-taking does not beat mutual cooperation.

If I cooperate: with probability c you mirror me and I get R; with probability 1 − c the channel is down, you defect, and I get S. If I defect: whether the channel is up or down, you defect too, and I get P. So

EU(C) = cR + (1 − c)S, EU(D) = P,

and cooperation is correct exactly when c ≥ (P − S)/(R − S), which for these payoffs is 1/3. Two features are worth noting. First, the temptation payoff T drops out entirely: the lure of unilateral defection is exactly what the mirror forecloses, so what constrains cooperation is the sucker payoff. Push S down and the threshold climbs towards 1; the more you have to lose by being the sole cooperator, the more mirroring cooperation demands. Second, the individual and the joint calculation coincide here (2[cR + (1 − c)S] ≥ 2P is the same inequality), so the graded principle keeps whatever was attractive about the ungraded one.

**3. Two complications.** (a) If the down-channel counterpart cooperates with some exogenous probability q rather than zero, the threshold becomes c ≥ [q(T − R) + (1 − q)(P − S)] / [(R − P) + q(T − R) + (1 − q)(P − S)], i.e. (1 + q)/(3 + q) for these payoffs: 1/3 at q = 0, 1/2 at q = 1. Believing better of your counterpart's fallback behaviour makes cooperation harder to justify, which is only apparently paradoxical — a known cooperator is precisely the person it pays to exploit. (b) If both agents may randomize and the channel transmits the shared draw, the symmetric equilibrium cooperation rate is 0 for c ≤ 1/3, interior at (3c − 1)/(1 − c) for 1/3 < c < 1/2, and 1 for c ≥ 1/2; the requirement for full cooperation is c ≥ (T − R)/(T − P) = 1/2, which is stricter than the 1/3 of §2 and which can exceed or fall short of (P − S)/(R − S) depending on the payoff scale. So the graded theory's verdict is sensitive to modelling choices that the original statement never had to make.

**4. Where does c come from?** Not from physics. It is the reliability with which two independent implementations of a decision procedure converge, and procedures are, within limits, chosen. An agent can raise c by adopting a canonical, public procedure, by eliminating idiosyncratic tie-breaks, by simplifying and publishing its own code, by binding itself to a shared convention. Call this investment in legibility, and suppose it costs ε, small relative to the stakes.

**5. The game before the game.** Now consider that investment as a prior move. Each agent either conforms (adopts the canonical public procedure, cost ε) or stays idiosyncratic (cost 0). Mirroring requires both to conform, so c is high only in the (conform, conform) cell; elsewhere c ≈ 0 and the base game ends in mutual defection. With ε = 0.1 the meta-game is therefore:

(conform, conform): 2.9, 2.9 — (conform, idiosyncratic): 0.9, 1 — (idiosyncratic, conform): 1, 0.9 — (idiosyncratic, idiosyncratic): 1, 1.

This is an assurance game, not a Prisoner's Dilemma. Conformity is not exploitable, because the asymmetric cells collapse into mutual defection rather than into exploitation. So the strong form of the relocation thesis — that superrationality merely pushes the dilemma up one level — is false on this specification, and the failure is informative: graded superrationality converts a Prisoner's Dilemma into an assurance game, and an assurance game's good equilibrium, unlike mutual defection, is self-enforcing. That is a real result, not a restatement.

**6. What is left over.** Two things. First, equilibrium selection: there are many candidate canonical procedures, each agent would prefer the convention centred on its own, and so convention-adoption layers a bargaining problem with genuine conflict of interest on top of the assurance problem. Second, and more troubling: with ε = 0.1 the (conform, conform) equilibrium is payoff-dominant while (idiosyncratic, idiosyncratic) is risk-dominant, since the cost of misplacing conformity (0.1) is far smaller than the cost of misplaced idiosyncrasy (1.9). Whether conformity is played therefore depends on each agent's confidence that the other conforms — a higher-order belief about a procedure, not a fact about the world. What graded superrationality needs is not c but *common belief* in c, which is strictly stronger and can fail even when c is high.

**7. The caveat that reverses §5.** The assurance structure depends on assuming that a conforming agent facing an idiosyncratic one is not exploited. That holds while the base game is governed by graded superrationality, since low c licenses defection. But conforming agents are exactly the ones who have made themselves simulable; if publicness is even partially exploitable — if an idiosyncratic agent can predict a conforming one well enough to secure T against it — then the asymmetric cells become (S − ε, T) and (T, S − ε), idiosyncrasy strictly dominates, and the meta-game is a Prisoner's Dilemma after all. Whether superrationality solves the dilemma or relocates it thus turns on a question the theory does not settle and cannot settle from the armchair: whether transparency can be exploited faster than it can be matched.

**8. Conclusion.** Superrationality is best read not as a rival decision theory but as a claim about the strategic value of algorithmic transparency. Read that way, its apparent power over the one-shot dilemma is an artifact of holding c fixed exogenously. Once c is treated as what it is — a variable partly under the agents' control, set in a prior game whose structure is itself up for grabs — the original problem reappears as a question about the payoffs to being legible.
