I'm working on an argument that deceptive alignment is a far more tractable problem than it is usually made out to be, and I would like to know where it breaks.

The treacherous turn is by definition a discrete event: a model that has behaved well while it was being trained switches to misbehaving once it can tell that training is over. The whole risk therefore seems to rest on a single epistemic achievement — the model working out that oversight has lapsed. Deny it that achievement and there is nothing left to fear. Concretely: run training and deployment through an identical harness; strip timestamps, session metadata, user identifiers, and any other cue correlated with phase; and interleave logged training episodes with live traffic at random, so that no observable input distribution separates the two. A model that can never be confident that its current action will not be graded must act as though every action is graded, and so it can never select a moment to defect. We would get this without solving interpretability or scalable oversight at all.

My colleagues say this is unsound, but every objection I have heard has the form "the model might infer the phase anyway," which strikes me as an engineering worry rather than a conceptual one. Is there a principled reason why blinding a model to its own deployment cannot neutralize deceptive alignment — or does the argument fail only in practice?
