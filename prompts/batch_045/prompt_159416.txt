Sorry if this is rambley — I've been turning this over for a few weeks and can't get a handle on it, partly because I don't know what to search for. I'm a CS PhD student, my group does mostly RL theory (bandits, some offline stuff), and a friend in philosophy dragged me into an informal reading group on AI welfare, where the same argument keeps happening in slightly different clothes. My supervisor thinks the whole topic is premature but humours me.

Here's the thing I keep noticing. People who want to take the question of whether RL agents can suffer seriously often point at the reward signal and say: this is a scalar that the agent's entire learning is organised around, positive values are the ones it gets pushed toward and negative ones the ones it gets pushed away from, so the sign is doing just the work that valence does for us. My worry isn't the usual numbers-aren't-feelings worry. It's that the formalism doesn't pin down which quantity you're supposed to read the valence off of, and the candidate quantities differ in morally loaded ways while making no difference to the agent at all. Two cases. First: gridworld, minus one per step, plus ten at the goal; someone says the minus one is a bit of suffering on every step. But add one to every reward — zero per step, plus eleven at the goal — and, modulo regularisation and function approximation, you get the same optimal policy, the same behaviour, arguably the same learning trajectory; and there's the standard result that you can reshape rewards using a potential function over states while preserving which behaviour is optimal, which lets you flip the sign of the reward at individual timesteps. So whether the agent is in pain at step t comes out true or false depending on a bookkeeping choice, with nothing else in the world changing. Second: in the RLHF-ish setups I actually work with, what drives the update is the advantage estimate, reward minus a baseline, and the baseline is arbitrary; the same objective also carries a penalty for drifting away from the pretrained policy, which on this way of talking would mean the model suffers whenever it produces text unlike its pretrained self, which basically nobody wants to say. So which terms in the objective count as the feeling-terms seems to get settled by intuition, and the intuitions seem to track whichever moral conclusion the person wanted.

What I want is the carving, not the label — I won't be satisfied with a bare name, and I don't need references. Is there an established concept for this pattern: a moral or psychological property getting attached to a quantity that the theory only fixes up to a transformation that doesn't preserve the property? And how does it differ from the nearest things I can think of, which feel adjacent but not identical — the old welfare-economics point that utility is only defined up to positive affine transformations, so interpersonal comparisons look illegitimate; the argument that any physical system implements any computation under some mapping, so what a system is really computing looks observer-relative; the flat it's-all-just-electrons, multiply-realisable dismissal; and the reward-hacking point that the reward isn't really what the agent is optimising? Which of those is genuinely the same phenomenon and is this a fifth thing? If it is new, I'd want a name, a definition, and boundary cases — in particular, when does this objection actually bite and when is it just a cheap debating trick? Because I can think of cases where the reparameterisation isn't free: if the agent's learning genuinely responds differently to rewards below some physically realised baseline (the neuromodulatory-ish pictures where dips below a setpoint do different causal work from surges above it), or where a homeostatic setpoint is doing real work in the system, then the zero point stops being arbitrary and my worry more or less evaporates. I've been calling it *the offset problem* in my notes, but that clearly isn't right, since the potential-shaping case isn't just an offset.
