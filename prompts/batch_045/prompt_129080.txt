Two people on my team got into it over lunch about whether "don't cause side effects" can even be defined for an AI system without first nailing down what's valuable. I write infra code, no philosophy background, so I'm probably mangling the vocabulary below — I've reproduced it as best I remember. I genuinely couldn't tell who was winning. Please go through it move by move, rate each one from clearly mistaken to clearly right with a sentence or two of justification, then say who's more right overall and what, if anything, both of them are missing.

(1) Avi: It can't be done. Any impact measure is going to be "how much did the world change compared to what would have happened otherwise," and that needs two things: a baseline — what would have happened if the agent just sat there — and a way of measuring distance between world states, i.e. a rule for which changes count as big. Both of those are value judgements wearing a lab coat. So low-impact AI isn't an alternative to the value alignment problem, it's the value alignment problem in a halloween costume.

(2) Bea: Not necessarily. Don't ask "what changed," ask "what can the operator still do?" Penalize the agent for shrinking the human's future ability to hit a broad spread of goals: sample a huge pile of arbitrary goal functions, measure for each one how well it could still be achieved after the agent acts, and penalize any drop. You never have to say which goals actually matter. You're just preserving optionality.

(3) Avi: The pile you sample from is exactly where the values sneak back in, and so is the baseline — you still need the "if the agent did nothing" counterfactual. Plus these things have a known failure mode where the agent matches the baseline by causing the damage itself: the vase was going to get knocked over in the inaction world, so the agent knocks the vase over.

(4) Bea: That's a bug in one implementation, not a conceptual problem. Recompute the baseline fresh at every step from the current state — "what would happen if I froze right now" — and there's nothing left to match.

(5) Avi: Then the measure has amnesia. If you only ever compare against "frozen now," the agent is never charged for a big change it has already committed to; it can walk anywhere it likes as long as each individual step is small, and nothing accumulates. And if you patch that by charging extra for irreversible changes, "irreversible" is defined relative to the states you'd want to get back to, which is values again.

(6) Bea: Fine, forget counterfactuals entirely. Use a physical quantity that nobody's values get a vote on: penalize the agent for decreasing the entropy of its environment — for imposing macroscopic order on the world. Every side effect anybody actually worries about involves shoving matter into some specific arrangement, so a tax on imposed order is a tax on side effects, measured in joules per kelvin, no utility function required.

(7) Avi: Entropy decrease is literally the job description. A clean room, a built house, a sorted array, a file written to disk — all lower entropy. On your measure the ideal agent is a space heater. And it's still gameable: dump waste heat somewhere to pay for the order you made. And entropy of *what* system, coarse-grained *how*? The second you pick the macrovariables you've picked which features of the world matter, which is the same problem as in (1).

(8) Bea: Those aren't the same, because coarse-graining at some fixed human-scale resolution is a parameter, like a learning rate, not a moral theory. And the space heater point is what the task reward is for — impact penalties were only ever meant to be a regularizer on top of doing the job, never a description of the job.

The bit I kept chewing on afterwards and couldn't get either of them to engage with: several of these proposals are budgets you can spend rather than rules you obey, and budgets that can be spent tend to get banked early. I couldn't work out whether that helps one of them or blows up both.
