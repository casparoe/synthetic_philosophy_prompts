My brother is reading one of those popular books about infinity and sent me this passage on Skolem's paradox. I know just enough to smell that something in it is off, and nowhere near enough to say what.

'Start with the Löwenheim-Skolem theorem: any first-order theory that has an infinite model has models of every infinite size. ZFC is written in a countable language, so if it's consistent at all then it has a model whose entire domain is countable. But ZFC proves Cantor's theorem, so it proves that uncountable sets exist. So this countable model has to contain a set that, from inside the model, is uncountable, even though from the outside it obviously has only countably many members. The resolution is that "uncountable" only ever means "there is no bijection inside the model". The bijection that shows the set is countable really does exist — it just isn't one of the model's sets. The model is missing a function, and so it is wrong about the size of its own continuum. Skolem drew the moral himself: notions like uncountability have no absolute meaning, they are always relative to a model, and so there is no fact of the matter about questions like the continuum hypothesis. Really this is an argument about the poverty of first-order logic. Write the axioms of set theory in second-order logic and they pin down a single universe — that is an old categoricity theorem of Zermelo's — so the whole paradox is just an artifact of choosing the wrong logic.'
