I'm putting together a handout for a grad reading group I'm running on tool vs. agent AI, and I want the centerpiece to be a decision tree that sorts actual deployed systems rather than restating textbook definitions of "agent." Lead with the tree itself (or the node list if that's cleaner) in your first line — no preamble, no "great question," no restating what I asked, and no summary at the end.

Constraints I care about: each branch node should be a question someone could answer about a concrete system without already knowing which leaf it leads to — think a spreadsheet macro, a booking bot that can rebook you on a different airline, an autopilot, a trading system with a loss limit, a model that drafts and sends emails you've pre-approved. Build it from the logical space rather than from a list of names: say which questions you're using and what combinations of answers they allow, then locate the actual positions in that space, and mark the unoccupied combinations with a one-line diagnosis (incoherent, unattractive, or just unexplored).

Here's the bit where I want you to engage with my axe to grind instead of smoothing it over: my sense is that "tool" and "agent" aren't properties of a system at all but of a triple — system, principal, and task under a description — so the same artifact is a tool relative to one delegation and an agent relative to another, and most of the public shouting is people silently holding different elements fixed. If you buy that, build the tree with relativized nodes and tell me whether the leaves stay clean; if you don't, say which node forces you back to a monadic property and why.

Leaves I need: mere instrument; instrument with discretion over means but not ends; delegated agent; fiduciary-style agent (the lawyer/broker case, where it's supposed to depart from your literal instruction sometimes); and something for the case where no human is really the principal anymore because the system is coordinating other systems. Also flag any pair of leaves your tree can't separate — I suspect "agent of a collective" and "tool of a bureaucracy" colapse into each other, and I want to know if that's a bug in my framing or an actual result.
