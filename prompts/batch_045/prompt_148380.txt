hey, I need help writing something. I've been reading the rationalist blogs since the Sequences were still going up, so calibrate for that: I know what an outside view is, I don't need it explained to me, and I'd rather you not spend any of the word budget on it.

Background on why I want this: my group chat has a bit we call "reference class tennis." Someone asks for the base rate on some decision they're making, and then everyone takes turns narrowing the class one adjective at a time — "men", "men who've started a company", "men who've started a company in a field they'd only ever read about", "…who also have a defintately-not-load-bearing spreadsheet" — until the class contains exactly one person, at which point whoever got there last declares the answer is 1 or 0 and takes the point. Three years of this and it's genuinely changed how I think. The standard rescue move, "use the narrowest class you still have decent statistics for," turns out to have no principled stopping point: it stops wherever your dataset runs out, not anywhere the world says it should. And the Bayesian version isn't cleaner either — "just condition on all your evidence" tells you nothing about which similarity relation to build the frequency table over in the first place.

So I want to turn that into a piece of satire. Here's the shape:

A help-center / onboarding FAQ page for a fake subscription app — pick a smug name — that promises to give you the correct base rate for any decision by sorting you into the right reference class. 600-700 words, numbered Q&A's, deadpan SaaS customer-support voice (the register where every answer opens with "Great question!" and then cheerfully explains that the thing you asked for does not exist).

The jokes have to come from actually getting the epistemology right. Things I want in there:

- A specificity dial or slider, from "all humans" (huge n, answer useless) at one end to "you, at this instant" (n = 1, frequency either undefined or trivially 0 or 1) at the other. The copy should treat both ends as fully supported settings and offer no way to choose between them.
- A premium "Total Evidence" tier that conditions on everything you know and then still has to pick a class to count over. The failure should be the real one — total evidence doesn't select a similarity relation — not a cheap "haha Bayes is dumb."
- An "Adversarial Class" mode where whoever you're arguing with picks your reference class, and the joke is that both sides can always find one that returns their preferred number, and the app has no tie-breaker because there isn't one to have.
- A question that is really the problem of the single case, phrased the way a normal person would phrase it — "I'm only going to make this decision once, so what's the probability for me?" — answered with the straight-faced recommendation to use the narrowest class with adequate statistics, while making it visible that this is a stipulation rather than a discovery.
- Something self-sampling flavored, because of course: a top-tier feature for questions like "am I living before the end of the world" or "how likely was it that I'd be me," where the answer flips completely depending on whether the class is all observers, all humans, all humans born after 1900, or all readers of this FAQ. Bonus if the doomsday-flavored tier is an upsell.
- Near the end, a quiet reveal of the actual business model: the app doesn't choose at all, it uses whatever reference class your insurer, lender or doctor already uses, and markets this as its most defensible feature — someone else already made the hard call, and they're the ones with skin in the game.

Two constraints I care about. First, don't let it slide into "lol statistics are fake." The outside view really does work for big, boring, well-defined classes — that's why reference class forecasting beats the inside view on things like project timelines, and I want at least one question where the app is unironically great, so the collapse is clearly about the single case and not about base rates in general. Fair target, not a strawman: I want people who'd defend base rates to laugh rather than wince. Second, keep it deadpan the whole way. No winking, no closing paragraph revealing that this has been the reference class problem all along, no explaining the philosophy. Someone who's never heard the term should still get it, and someone who has should feel personally attacked.

Also: don't name any real philosophers in the piece, living or dead, and don't have the app quote anyone. And its a FAQ, so no long paragraphs of prose — short questions, short answers, and let the copy be embarrassed by exactly the places the philosophy is broken without ever admitting that it is.
