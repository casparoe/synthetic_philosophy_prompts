Reworking my lecture on van Fraassen's Judy Benjamin case and I think I've found a way to deflate the whole thing, but I want to be sure I'm not about to tell 200 undergrads something stupid.

Setup as I give it: four quadrants — friendly vs enemy territory crossed with Company A's vs Company B's sector — Judy's prior is symmetric, 1/4 in each cell, and the radio message is: if you're in friendly territory, you're in A's sector. The standard line is that you can't just conditionalize, because what you've learned isn't a proposition about which cell you're in but a conditional, so people drag in minimizing relative information subject to the constraint that the message carries no news about friendly vs enemy (P(friendly) stays at 1/2), and out pops 1/2 on friendly-A, 1/4 on each enemy cell.

My deflation: that's just a relic of not yet having a semantics for conditionals. Read the message as the proposition friendly → A in Stalnaker's sense, so its probability is the conditional probability P(A | friendly) = 1/2, and conditionalize on it. With the natural similarity ordering — each enemy cell's closest friendly world keeps its A-status — friendly → A is true in exactly the A cells, so conditionalizing gives 1/2 / 1/4 / 1/4: same answer as the fancy minimization rule, no new updating principle needed. Problem solved, yes?

Where I'm stuck: my colleague ran the same trick on an asymetric prior (P(A | friendly) = 0.8, P(A | enemy) = 0.4) and got a posterior that moves P(friendly) off 1/2, which she says shows the message is being treated as news about whose territory Judy is in when it plainly isn't. Is she right that my deflation only works by accident of symmetry, or is there a principled way to pick the selection function so that conditionalizing on friendly → A always respects no news about friendly vs enemy? And if there isn't, what exactly is the radio message telling Judy, if not a proposition?
