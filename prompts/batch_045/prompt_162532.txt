Our housing co-op is rewriting its rules and I've argued myself into a corner. Can you tell me which step to give up?

(1) A rule is valid only if some valid rule says how rules get made — call it R.
(2) So R itself can only be changed in whatever way R allows.
(3) Our R lets any rule be changed by a two-thirds vote, R included. So we can use R to replace R with a new R'.
(4) So we can adopt R' = "any rule may be changed by two-thirds, except rule C, which may never be changed" — and last month we did exaclty that, where C is the rule that nobody can be evicted for anything said at a meeting.
(5) But R' only ever has whatever authority R handed it, and R let a two-thirds vote change anything at all.
(6) So a two-thirds vote can still repeal C, and the "never" in C does no work.
(7) Generalize: no rule can ever bind a later vote, because any binding was done by an earlier rule that left the later vote free. Every entrenchment clause, every supermajority lock, every "this charter stands until 2035" is decorative.

I really dont want (7) — we drafted C precisely so that a bad-tempered vote couldn't undo it. A friend says the fix is easy: R isn't validated by any rule, it's just the practice we actually accept, so (1) is false at the top. But if I say that I don't see why C isn't equally just "whatever we happen to accept," and (7) creeps back in through the side door.

So: name the step that's actually doing the fraud, say why it looked innocent, and tell me what I pay for rejecting it — especially whether I can keep entrenchment without saying a legal system can do something legally impossible. Also flag how confident you are in the diagnosis and which bit you're least sure of.
