Hey — I'm making a one-page handout for a philosophy of biology reading group (grad students who know the central dogma but have read none of the 'is DNA really a code' literature), and I want an actual decision tree, not prose about the options.

Start the tree from something everyone in the room already grants: that the base sequence of a stretch of DNA reliably determines which amino acids get chained together. Then branch on the claims that genuinely split the positions, each node phrased as a question someone can answer without knowing which view it leads to, and each leaf a view plus one sentence about its ugliest commitment. No node may just ask 'is DNA literally a code?'

Build it from the logical space, not from a list of names: give the branch questions and the combinations of answers they allow, then locate the real positions in that space, and mark the empty cells with a one-line diagnosis of why nobody lives there (incoherent, unattractive, or just unexplored).

Branches that have to be in there: does codehood require the mapping to be arbitrary rather than forced by the chemistry; does it require an interpreter with purposes, or can selection history supply the function instead; does a code have to be actually read, or does stored-but-never-read count; and does a code have to admit error, i.e. a gap between what the sequence specifies and what the cell in fact does.

One branch must be parse-relativity: the same physical strand supports different readings — shifted reading frames, overlapping genes, mitochondrial tables that differ from the nuclear one, engineered bacteria where a stop codon has been reassigned to a noncanonical amino acid. So does codehood attach to the strand, or to the strand-plus-a-decoder? I want an explicit leaf for the strand-plus-decoder answer, and I want to know whether it collapses into any of the other leaves.

Use cases as the nodes wherever you can: a strand in a test tube with no ribosomes in it, a recoded organism whose products a normal cell would misread, methylation patterns or a prion as heritable-but-non-sequence carriers, and tree rings or hormone levels as contrast cases that everybody agrees aren't codes.

Eight branch questions at most, six to eight leaves. Flag any pair of leaves your tree can't really separate (I suspect the teleosemantic one and the interpreter-requiring one may say the same thing about every case above), and end with one line on which branch question is doing all the work.
