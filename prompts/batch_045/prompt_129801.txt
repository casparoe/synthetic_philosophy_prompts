Ive been training small RL agents on tasks where the objective is really a conjunction — get to the target, but stay out of the marked zone, or keep the payload under some threshold, or dont knock the marker over. I keep hitting a failure I have no word for. The agents that learn fastest are the ones that end up dropping one of the conjuncts: partway through training their behaviour gets smoother and more confident and the return curve is still climbing, and at the same time violations of that one clause come back — not spread evenly, but clustered, as if a rule that had been represented got replaced by a simpler rule that mostly coincides with it. I see the same signature in LM finetuning: the run that picks up the required output format quickest is the one where the "dont state anything you arent sure about" part quietly stops doing work, and the outputs get more fluent and more confabulated at the same time. None of this needs the environment to change — I'm evaluating in distribution — and slowing learning down (lower lr, more entropy) seems to preserve the full goal.

Ive come across "goal misgeneralization", but everything Ive seen on that is about an agent keeping its skills in a new environment while aiming at the wrong thing. What I'm describing needs no distribution shift; the goal seems to get simpler as a side effect of getting competent. Is there an established name for exactly this, or is it just goal misgeneralization in different clothes? A label on its own wont help me — I want to know what the thing is and what it isnt: how it differs from goal misgeneralization, from reward hacking or spec gaming, from plain capability-generalization failure, and from a generic simplicity bias, and what Id have to measure in a given run to tell those apart. If it genuinely has no name, coin one, define it, and give me the boundary cases.
