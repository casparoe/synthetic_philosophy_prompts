The question was:

Question 2 (20 points). (a) What is a rigid designator? Explain why Kripke holds that "Hesperus is Phosphorus" is a necessary truth that can only be known a posteriori, and explain why he thinks this is a problem for descriptivist theories of names. (b) Consider this objection: if every identity between rigid designators is necessary, then Cicero is Tully is necessary too — but that looks like a trivial fact about having two names for one guy, whereas Hesperus is Phosphorus looks like a real astronomical discovery. Does Kripke's account collapse the difference between the two cases? Say whether he can answer the objection and how.

The student's answer:

(a) A rigid designator is a term that designates the same individual in every possible world. So Hesperus and Phosphorus are rigid: they pick out Venus in every possible world, and so does Cicero and Tully. Descriptions like the morning star or the brightest object visible in the dawn sky are not rigid, because in some other possible world Mars is the morning star.

If Hesperus and Phosphorus are both rigid and both pick out Venus, then Hesperus is Phosphorus is true in every possible world, i.e. it is necessary. But we had to go look through telescopes to find out: the Babylonians used the two names for a long time without realizing they named the same object. So the statement is necessary but a posteriori, and this is possible because necessity is a metaphysical matter while apriority is an epistemic one, and Kripke keeps the two separate.

This is a problem for descriptivism, the view that a name gets its reference from a description speakers associate with it — for instance, Hesperus means the last star visible in the morning. If that were right, then Hesperus is Phosphorus would be knowable a priori, since if the descriptions are the meanings then anyone who understands both names knows what they refer to and can simply work out whether one thing satisfies both descriptions. But it isn't knowable a priori. Kripke's own alternative is the causal chain: what makes Hesperus refer to Venus is that Venus sits at the far end of the chain of uses going back to the original baptism — that is, Hesperus refers to whatever object caused the speakers' use of the name. Because the chain is independent of what anyone believes, we can be wrong about every description we associate with a name and still be talking about the same thing.

Because the statement is necessary, it is not really possible for Hesperus not to be Phosphorus. So the ancient astronomers could not have discovered otherwise; there is no sense in which things could have turned out differently, and the feeling that they might have is just an illusion produced by ignorance.

(b) Cicero is Tully is necessary on this view as well, since both names are rigid. But that doesn't collapse the distinction. Kripke can say the necessity is the same in both cases while the epistemology differs: in one case we had to make an empirical discovery, and in the other we can know it just by being told that the two names get used for the same person. Identity statements are necessary whenever both terms are rigid, so the real difference between the two cases is how hard the fact is to find out, not what is necessarily true.
