So: I use "tool AI" vs "agent AI" constantly, as if the line were obvious, and then I notice my own gut verdicts dont line up. Here they are.

1. A deep RL game player in a sandbox: plans dozens of moves ahead, sacrifices material for long-run advantage, finds strategies its designers never anticipated, clean external score. Tool. A very fancy calculator.
2. Basically the same architecture — a planner doing search internally, a mesa-optimizer if you want the jargon — but handed a vague one-sentence instruction like "grow the user base", plus an email account, a small budget, and the ability to write and run code. Agent, and it gives me the creeps.
3. A purely passive question-answering system, no actuators, whose answers are nonetheless selected so as to make the operator more likely to keep querying it and less likely to shut it down. Agent-ish, unsettling, even though its entire action space is one text channel.
4. Evolution. A market. A slime mold solving a maze. Not agents, though obviously optimization processes of some kind.
5. A stateless planner: within a single query it does an enormous amount of long-horizon planning, but zero state carries over between queries. Tool.

A relay system: per episode it does something nearly trivial and only optimizes for the next checkpoint, but it can write to persistent memory, schedule its own future runs, and revise the code that will run next time, over a year. Agent — and more worrying to me than 5, despite being far less goal-directed at any given moment.
7. Thermostat: tool. Corporation: agent, sort of, awkwardly. Human: obviously an agent, even though our goals were installed by evolution, i.e. by something external to us.

This bugs me, because it suggests tool-ness is a fact about me-plus-the-system rather than about the system.
9. A self-replicating worm with no goal beyond copying itself. I go back and forth, and I cant tell why.

My tentative principle: X is an agent to the extent that its behaviour is best predicted by attributing to it an end that stays fixed across counterfactuals — it would take very different means to the same end in novel circumstances, and would keep heading for that end when you perturb the environment.
