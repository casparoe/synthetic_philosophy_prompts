Please argue for a position I don't hold and am not sure its true, so I can see how much weight it can bear — I'm doing a grad seminar on this in the spring and I want the strongest version of the Other Side before I go in.

The position: epistemic utility theory — the accuracy-first package where credences are graded attitudes, their only distinctively epistemic value is accuracy, inaccuracy is measured by a strictly proper scoring rule, and probabilism and conditionalization are supposed to fall out as theorems — is pragmatism in epistemic costume, and once the costume comes off it has no advantage over the old pragmatic vindications of Bayesianism it was invented to replace.

Don't run the objection I've heard a hundred times, that the choice of scoring rule is arbitrary so nothing follows anyway; that one doesn't move me. Build it around this instead. Call a scoring rule self-ratifying for an agent when, by the agent's own current lights, she expects to end up more accurate if she conditionalizes on whatever evidence arrives than if she first shifts to some other credence function she prefers and conditionalizes that instead. The diachronic accuracy argument, read carefully, establishes only that conditionalization is optimal in that self-ratifying sense — optimal relative to the prior the agent happens to start with. Argue from there that the norm it yields is a hypothetical imperative, be accurate by your own lights, no more categorical than be wealthy by your own lights, and that the synchronic domination argument for probabilism cannot plug the hole, because domination knocks out the incoherent credence functions and then falls silent about which coherent one to have, and that silence is exactly where all the normative work anyone cared about was going on. Close by stating the best reply available to the accuracy-firster that restores categorical force, and then argue that it doesnt.
