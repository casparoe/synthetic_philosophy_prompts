This has an uncomfortable consequence that follows directly: because we can never tell from the outside which computation a system is running — any outward behaviour, however intelligent, can be produced by a sufficiently large lookup table of canned responses — we can never rule out that a system is conscious, and the precautionary principle therefore says we should treat systems that look conscious as conscious until we can prove otherwise.
