I run a tiny reading group that meets above a pizza place, and we've been slogging through provability logic and the agent-foundations material for a few months now (this was week three, right after we did modal agents). Last night two of our regulars, Mira and Dev, got stuck on the Löbian obstacle and wouldn't drop it. I'm definately not competent to settle it and I don't want to signal a side, so here's their exchange roughly as it happened. Mira opened with: the obstacle is just Gödel's second incompleteness theorem with extra steps — no system at least as strong as PA can prove its own consistency, so an agent that reasons by proving theorems can never certify that the successor it builds reasons soundly, which means a self-improving proof-based agent is impossible in principle, not merely hard. Dev: that conflates G2 with Löb — the result you actually need is Löb's theorem, that if T proves Prov(φ)→φ then T proves φ — and the impossibility framing is much too strong, because you can get tilings if the child reasons in a strictly weaker system than the parent: put the parent in PA+Con(PA) and the child in PA and the parent licenses the child's proofs, so what you lose is reasoning power down the chain, not the possibility of self-modification. Mira: Con(PA) only buys you that PA is consistent, it doesn't buy you that everything PA proves is true, which is what you'd need in order to trust the child's math, and reflection is strictly stronger than consistency, so the descending-chain trick is at best a partial patch; and separately, even if the tiling were perfect you'd only have shown the successor reasons well, not that it keeps your goals, and there's that procrastination paradox people talk about in that literature where agents of this kind can prove for each fixed n that they'll act within n steps and still never act. Dev: goal-preservation is a different problem and bringing it in is changing the subject; the procrastination thing is a pathology about how the agent weighs future actions, not a refutation of the claim that the parent does trust the child's arithmetic; and anyway Löb's theorem isn't only bad news, since the 2014 robust-cooperation paper on program equilibrium via provability logic builds agents that cooperate with each other precisely by a Löbian handshake — they cooperate if they can prove the other one cooperates — so any story on which Löb is a hard barrier to trusting other reasoners has to be wrong somewhere. Mira: the handshake is mutual reference between two agents at the same level, whereas the obstacle is one system trying to license, from below, another system at least as strong as itself; different geometry, so both can be true. Dev, finally: and none of this even touches the version of the problem that shows up in proof-based decision theory, the 5-and-10 style business where an agent searching for proofs of the form if I do a then utility is high runs into Löbian circularity and gets suckered by spurious proofs — and Mira said that's a third problem again and they should keep them seperate.
