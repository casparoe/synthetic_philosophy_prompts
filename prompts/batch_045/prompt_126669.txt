I run a methods seminar for first-year graduate students and I'm assembling a one-page triage key for thought experiments. Given a case someone has put forward, the practical question is whether it should be repaired (rewritten so that it isolates what it claims to isolate), replaced (kept as a vivid illustration but no longer treated as evidence), or retired (dropped, because nothing in the neighbourhood will do the work being asked of it). Please write that key as a decision tree.

I want the tree generated from five probes rather than from a list of familiar failure modes, so that the leaves are discovered rather than stipulated. Each probe must be a question one can ask of any case, phrased so that a student could answer it without knowing what the tree is for: (1) a flip test — invert the case's morally or theoretically salient surface features (who is named, what is described first, the concrete imagery, the order of presentation) while holding the structure fixed, and ask whether the verdict would track the surface; (2) a fill-in test — supply the causally or normatively relevant detail the description omits and ask whether the verdict survives; (3) a repetition test — run the case many times over, or embed it in a sequence that approaches an ordinary case, and ask whether the verdict is stable; (4) a stipulation audit — list the case's explicit supposes, ask which one is doing the work, and ask whether that one merely asserts what was to be shown; (5) a possibility test — ask what has to be false, incoherent, or unimaginable for the scenario to get off the ground, and whether the verdict depends on that.

Order the probes cheapest-to-run first, give four to six decision nodes and eight to twelve leaves, and give each leaf a plain name for the failure mode (or mark it as an unoccupied or unexplored region) plus one sentence on the disposition it recommends and why. Use one familiar case per leaf as a worked illustration, but state the probes themselves generally. Flag any pair of leaves your probes cannot separate rather than splitting them by a distinction the probes don't encode, and note the answer combinations the tree permits but that no actual case fills, saying briefly whether the gap is incoherence, unattractiveness, or neglect. Please don't cite or attribute anything; I want the distinctions rather than the literature. Finally, state how confident you are in each leaf's placement and single out the one branch where you think a specialist would be most likely to disagree with you, and why.
