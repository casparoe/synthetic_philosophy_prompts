The two camps. We've started calling them the Conceptual camp and the Physical camp. The Conceptual camp holds that the claim "every effectively computable function is Turing-machine computable" is not the sort of thing that could turn out to be empirically false: it is fixed, at least in large part, by what we mean by a procedure that a finite agent could in principle carry out by following rules. On this view, saying "here is a physical system that computes a non-Turing-computable function" is either false as stated or involves a stretched, honorific use of "computes"; the genuine, checkable content in the neighborhood sits elsewhere — in complexity-theoretic claims, roughly of the form that any physically reasonable computing device can be simulated by a Turing machine with not-too-bad overhead, and in the work of saying which specific physical systems implement which specific algorithms. The Physical camp holds that there is a substantive, contingent thesis in play, namely that no physical system can compute anything beyond the Turing limit; that this thesis is very well supported but corrigible, more like a well-confirmed empirical principle than like a definition; and that we can say in advance what would refute it — a described physical system whose input–output behavior provably falls outside the Turing-computable functions.

The device — I'll call it the Ladder.

Take as input a description of a Turing machine M. The device executes stage 1 during an interval lasting one half-second, stage 2 during an interval lasting one quarter-second, stage 3 during an interval lasting one eighth-second, and so on, with all the intervals laid end to end, so that the entire infinite sequence of stages occupies one second of the device's own proper time. At stage n it determines whether M halts within its first n steps. If it finds that M does halt, it stops the whole process and writes the pair (1, n) to an output register; otherwise it proceeds to stage n + 1. If it has found nothing by the end of the second, it writes (0, 0).

Three stipulations, which I want both camps to accept for the sake of the exercise:

(a) The Ladder is described as living in a universe with no lower bound on how short a physical operation can be and no upper bound on signalling speed, so that the convergent schedule is physically admissible there. Both camps agree that this is the load-bearing empirical assumption and that our actual universe may well not permit it.

(b) Building the Ladder requires setting some physical parameter — say a coupling strength or a mirror's reflectivity — to a value specified to infinitely many significant figures. Any finite-precision build gets only finitely many stages right and then stalls or errs. Both camps also agree that this is an idealization, and both agree that a Turing machine with an unbounded tape is unphysical in a broadly similar way. I want the document to say what the Conceptual camp thinks is different about the two idealizations — the Ladder's infinite precision versus the Turing machine's infinite tape — or, if it thinks nothing relevant is different, what follows from that.

(c) The certificate asymmetry. An output of (1, n) can be checked in finite time by an ordinary machine: just run M for n steps and confirm that it halts. An output of (0, 0) carries no finite certificate — nothing a finite agent can do verifies that M never halts. And the Ladder never outputs (1, n) unless M really does halt within n steps. So its answers to the halting problem are one-way-certifiable: verifiable when they say "halts", unverifiable when they say "does not halt".

I also want one variant considered, because we disagreed about whether it matters and I won't tell you which of us thinks what. Call it the Blunt Ladder: a version that behaves exactly as above, except that achieving k reliable stages requires physical resources exponential in k, so that while it still decides the halting problem in principle, it is useless for any purpose anyone actually cares about. Say whether this variant changes either camp's assessment of the epistemic status of the thesis, and why or why not.
