The question we set:

Q3. (a) Distinguish a paraconsistent logic from the thesis of dialetheism, and say whether accepting either one commits you to the other. (b) A critic writes: "if a contradiction were really true, then everything would be true, since from A and not-A any B at all follows — and that's just logic, not a negotiable assumption." Explain how a dialetheist who reasons with the Logic of Paradox (LP) answers this, and say what she has to give up in order to answer it that way. Use the Liar sentence as your example.

One student's answer:

Ans. (a) Classical logic validates explosion: from A ∧ ¬A, infer any B. A paraconsistent logic is one in which explosion isn't valid. Dialetheism is the view that some contradictions are really true. Neither commits you to the other. A dialetheist does need a paraconsistent logic — with classical logic a single true contradiction would make every sentence true, i.e. triviality. But you can use a paraconsistent logic without being a dialetheist: someone reasoning about an inconsistent legal code or a inconsistent database wants to stop everything following, and isn't thereby claiming that any contradiction in the code is really true. So paraconsistency is a claim about which inferences are valid, and dialetheism is a claim about what is true.

(b) The dialetheist's reply is that explosion simply isn't valid. In LP there are four semantic values — true only, false only, both, and neither — and the designated values, the ones valid inference has to preserve, are true and both. Take a model where A is both and B is false only. Then A ∧ ¬A is designated while B is not, so the inference doesn't preserve designation and explosion fails. For the Liar sentence L ("L is not true"), L gets the value both: it is true and false. The rival "gappy" treatments — the Kripke-style ones — assign L the fourth value instead, so the real disagreement between the glut approach and the gap approach is just which of the two non-classical values goes to the Liar.

What the dialetheist gives up: first, the law of non-contradiction, since ¬(A ∧ ¬A) is not a theorem. Second, some classical inferences involving negation, e.g. disjunctive syllogism: if A is both and A ∨ B is designated with B false only, B can't be derived. Third, and most seriously, LP as stated has no conditional at all, so it can't even formulate most of classical mathematics. But that third cost is easily paid: define A ⊃ B as ¬A ∨ B. That gives you modus ponens and recovers the classical results, leaving only Curry's paradox, which is really a problem about the truth predicate rather than about the conditional. So the net cost is accepting some true contradictions and working in a weaker logic; in exchange you get a treatment of the Liar that doesn't need a hierarchy of languages.
