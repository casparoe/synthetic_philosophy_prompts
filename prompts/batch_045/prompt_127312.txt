Hey — I'm in a small reading group (me, two maths people, and one CS person who thinks in types and keeps saying "just use types" every time something gets uncomfortable) and we're slowly working through the early chapters of an intro set theory book plus whatever podcasts we can find. Last week we listened to an episode that summed up Russell's paradox roughly like this:

"Naive set theory lets you form a set out of any property at all. So take the property of not being a member of itself and look at the set R of all sets that are not members of themselves. If R is a member of itself, then by its own defintion it isn't; and if it isn't, then it is. Contradiction. So naive set theory is simply inconsistent, and since Frege had built his whole logicist programme on top of it, his system collapsed. Modern set theory — ZFC — fixes this by adding an axiom that forbids a set from containing itself, which is why mathematics works again. The general moral is that self-reference is poison: whenever a definition reaches back to itself you get a contradiction, which is exactly what happens with the sentence 'this sentence is false'. And because of Gödel we know that no system can prove its own consistency, so we can never really know that ZFC is contradiction-free — there's always a small chance the whole edifice still blows up."

That sounds slick, but a few things in it smell off to me and I can't pin down where. I thought ZFC avoids the paradox by restricting comprehension (you only get to carve subsets out of sets you already have, not conjure a set from a bare predicate), not by banning self-membership — and I also half-remember that there are perfectly consistent set theories that do allow sets containing themselves, which would mean the episode has mixed up two different moves. "Naive set theory is inconsistent" also seems too strong: surely it's the unrestricted comprehension principle together with classical logic that explodes, not the idea of a set as such. And the Gödel bit feels like the standard pop-science exaggeration, but I don't know the precise version I should replace it with.
