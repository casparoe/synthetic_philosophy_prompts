The passage:

"Here is a game that breaks decision theory. A casino tosses a fair coin until it lands heads. If the first heads comes on the n-th toss, the casino pays you (−1)^{n+1}·2^n/n dollars — a gain when n is odd, a loss of the same magnitude when n is even. The probability of that is 1/2^n, so the n-th contribution to the expected value is (−1)^{n+1}/n, and the expected value of the game is the alternating harmonic series 1 − 1/2 + 1/3 − 1/4 + …. That series converges, but only barely: the sum of the absolute values is the plain harmonic series, which diverges. Add the terms in their natural order and you get ln 2, about 69 cents. But by Riemann's rearrangement theorem a conditionally convergent series can be reordered to sum to any number you please, or to diverge outright. So the game has, in a sense, every expected value and none: its expected value is not merely unknown, it is undefined.

The fix is the same one that tames the St. Petersburg game, of which this is just a variant with losses bolted on: stop valuing gambles in dollars and value them in utility, using a utility function that is bounded. The expected-utility series then converges absolutely and the ambiguity disappears. Without such a bound the disease is contagious — rescale the payoffs and any agent with a continuous utility function that is unbounded both above and below can be handed a structurally identical predicament.

Notice too that no real casino can offer infinitely many tosses. Truncate the game after N tosses and its expected value is the N-th partial sum of the alternating harmonic series; let N go to infinity and you get ln 2 again. So 69 cents is, after all, the value of the idealised game.

The moral is that expected-utility theory falls silent exactly where it matters. When the expectation does not exist, no price is rationally preferable to any other, and the rational agent should be indifferent between playing for nothing and declining. And since the stakes in the decisions that actually worry us — existential risk, Pascal-style wagers — are unbounded, expected-utility maximisation is not a complete theory of rational choice in precisely the cases that count."

Separately, someone in my reading group tried to sharpen the truncation move, and I want to know whether the sharpening works. Instead of truncating after N tosses, keep the payoff schedule but restrict it to a finite set of outcomes that grows: for each N, let G^{p,q}_N pay exactly what the Pasadena game pays on the p·N highest-probability winning outcomes (n = 1, 3, …, 2pN−1) and on the q·N highest-probability losing outcomes (n = 2, 4, …, 2qN), and pay nothing on every other outcome. Every outcome of the full game is admitted from some N onwards, so these finite games exhaust the Pasadena game. My calculation is that the expected value of G^{p,q}_N converges to ln 2 + ½·ln(p/q) — which equals ln 2 only when p = q, and gives (3/2)·ln 2, about $1.04, for p:q = 2:1. If that is right, then "approximate by finite games and pass to the limit" does not single out 69 cents unless you have already decided to truncate along prefixes of the toss sequence, and prefix-truncation starts to look like a bookkeeping convention rather than a fact about the gamble. Against this, I can hear the reply that the game is defined by a sequential process, so truncation after N tosses is the physically meaningful finite approximation and the others are gerrymandered.
