I've wrote this up for my reading group and now I don't trust it, because it seems to prove more than I believe.

Setup: illusionism, as I'll use the word, is the view that no mental state has phenomenal character, but that our introspective systems systematically misrepresent some of our own states as having it. Call the output of those systems an *introspective representation*.

(1) An introspective representation misrepresents its target as phenomenally charactered only if it deploys a phenomenal concept, i.e. a concept of phenomenal character as such.
(2) A subject can deploy a concept of a property F only if that subject has been acquainted with F. A concept's content has to be fixed by something, and what fixes it is the property itself being presented to the subject.
(3) To be acquainted with phenomenal character just is to be in a state that has phenomenal character. There is no daylight between being presented with phenomenality and instantiating it, the way there is between being presented with a cloud chamber track and being presented with an electron.
(4) So a subject can be in a state that represents something as phenomenally charactered only if that subject has at least one state that has phenomenal character.
(5) So if illusionism is true, and no state has phenomenal character, then no introspective representation can misrepresent anything as phenomenally charactered.
(6) But illusionism is exactly the claim that introspective representations do misrepresent their targets in that way.
(7) So illusionism cannot be true. It says there is an illusion whose existence requires the very thing it denies.

That's the conclusion I want. Here's why I think the argument is broken. Run (1) through (4) again with F = electron, or F = another person's headache, or F = seven. I have never been presented with an electron as such, and if (2) were right I couldn't so much as think about one; a person born without any ability to feel pain couldn't think *that must hurt*. So (2) generalises into the claim that we can only represent what we have instantiated, which is absurd. But when I try to repair it -- let concepts be fixed by description or causal role, and keep the acquaintance requirement only for the special case in (3) -- the argument stops being an argument and starts restating the disagreement. A friend says the introspective state represents its target as *quasi*-phenomenal rather than phenomenal, which does'nt strike me as helping, since quasi-phenomenal looks like just as much of a phenomenal concept as the plain one. She also says phenomenal concepts are constitutional, content fixed by the introspective vehicle itself rather than by any property presented to the subject, and I genuinely can't tell whether that is a reply or a surrender.

So: which step do I give up, and what does giving it up cost? I'd most like to keep the conclusion and (3), and if I have to I'd rather give up (2) than (1), but I want to know what the surviving illusionism is still claiming, and whether it has quietly become a verbal claim rather than a substantive one about the hard problem. One more thing I can't settle: is *represents as phenomenally charactered* doing the same job in (1) and in (6), or is there a thinner reading available in one place and not the other?
