Setup, so we are discussing the same thing. Aristotle raises the worry in the sea-battle discussion in *De Interpretatione*: if it is already true today that there will be a naval battle tomorrow, then it seems the battle cannot fail to occur, and if it is already false, it cannot occur — in which case deliberation and contingency look like illusions. Standard families of response include: accept bivalence and deny that truth today entails necessity (the truth is there, but it is not a necessitating truth); restrict bivalence for future contingents so that such propositions are neither true nor false until things are settled; make truth time-relative, so that a proposition can be not-true-now yet true-later; treat openness as an epistemic rather than semantic or metaphysical matter; or argue that the argument from truth to necessity smuggles in a modal premise that is independent of bivalence.
