I'm sketching a toy agent for a hobby project (pure thought experiment, nothing is getting deployed) and I want to know whether I've reinvented something known or built an elaborate way to shoot myself in the foot. The design:

- It's a proof searcher over PA with a hard cap: it only considers proofs up to N steps (say N = 10^9), because finite compute.
- Instead of full reflection, it uses *bounded* reflection: for a concrete numeral n it proves "if there's a proof of X of length ≤ n, then X" by brute-force checking all candidate proofs of length ≤ n, and it only does this for n comfortably below N. Call the set of n it's willing to do that for its *trusted horizon*.
- It never tries to prove a successor or a future self "sound" in general. It proves bounded soundness up to whatever n it can afford, and then treats the successor as a black box that comes with a receipt: every output is accompanied by a proof of length ≤ n in the base theory.
- Two such agents meeting each other are supposed to cooperate the way the proof-based-cooperation setups do, except each agent's trust in the other is filtered through its own horizon: I can only use a proof that you'll cooperate if that proof is short enough that I can prove that *your* proofs of that length are sound.

So: what are the most important implications of the Löbian obstacle for this scheme? Rough guesses I'm unsure about, in case they're useful hooks (don't feel obliged to answer them in order):
