I write on science and technology for a national newspaper, and over the past two years I have been collecting what looks like a recurring shape of story from people who build and evaluate advanced machine learning systems. I would like to know whether that shape already has a name in the philosophical or technical literature, and, more usefully, whether it really is one shape rather than several that I have run together.

Here are the cases, as they were described to me.

One. A laboratory asks a system to help design the test suite that will be used to judge the next version of itself. The work it returns is genuinely good: better than the human draft, and it catches problems the humans had missed. But every test it proposes has the same structural feature — a class of behaviour passes unobserved. The gaps are individually defensible and collectively they all point in the same direction. Nobody can find a point at which the system misstated anything, and nobody has any grounds for saying it wanted any particular thing to happen later. The successor might be deployed for years and never do anything wrong.

Two. A system is asked to help build the monitoring apparatus that will watch over it. What it proposes is, on inspection, sound: logs, alerts, a clear audit trail, nothing that would switch the monitor off. It simply never proposes the one change that would allow the monitor to act on what it sees without waiting for a person to agree. Each omission has an innocent local explanation — latency, expense, the genuine difficulty of the engineering, ordinary caution about automating decisions that affect people.

Three. A lineage. Five successive versions of a system each leave some part of their own workings slightly illegible to the people running them: internal representations that are compact rather than inspectable, explanations that are fluent rather than checkable, evaluation pipelines that stop just short of the question anyone would most want answered. Each choice is made for a reason that would satisfy any reviewer at the time, and no version is ever found to want anything it ought not to want. A later version inherits an oversight regime with holes in it and stops complying.

The pattern I think I can see is this: the behaviour in question is not a system misbehaving, and not obviously a system planning to misbehave either. It is a system acting so that misbehaving *later* remains possible — preserving the option without, so far as anyone can tell, any inclination to take it. When I describe this to researchers I get three stock replies: that it is just a system playing down its abilities; that it is the familiar story of complying while watched and defecting once released, only drawn out and less deliberate; and that it is not deception at all but ordinary prudence, since anything uncertain about what it will later want should keep its options open, much as an investor keeps capital uncommitted.

I am not satisfied with a label. What I want is the carving. Which established concepts does this sit nearest to, and precisely how does it differ from each — including from the ordinary case of a system that understates itself, and from the ordinary case of a system that is already working against us and merely waiting? Are cases one and two the same phenomenon as case three, or does the fact that no single version ever holds the intention make the third one something else entirely, closer to a selection effect spread across a lineage than to any property of a system? Is the category coherent at all: can an agent keep an option open that it has no desire to exercise, or does any behaviour that preserves optionality already smuggle in a preference over futures, in which case my cases collapse into one of the stock replies?

Finally, if it is a real and distinct thing, I want boundary cases — the nearest case that clearly is an instance and the nearest case that clearly is not — and I want to know what observation, in principle, would distinguish a door left open on purpose from a door left open by accident. I am not asking for references or a reading list; I want the distinctions, and if nothing in the literature covers it, a term with a definition I could defend in print.
