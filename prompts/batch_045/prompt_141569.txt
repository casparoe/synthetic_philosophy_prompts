---- The question ----

Question 3 (superrationality). Answer all parts, showing your work where math is involved.

(a) The Platonia Dilemma. Twenty rational people are told: if exactly one of them sends a telegram to the organizer by midnight, that sole sender receives $1 billion; if zero people send, or if two or more send, nobody gets anything. They cannot communicate or make binding agreements. Compare what a standard game-theoretically rational (causal decision-theoretic) agent does with what a superrational agent does. Be sure to say how superrationality relates to, and differs from, both causal decision theory (CDT) and evidential decision theory (EDT), and give any mixed strategy explicitly.

(b) The Luring Lottery. A prize of $1,000,000 is awarded to one entry drawn uniformly at random from all entries submitted.

(i) Original version: the winner receives $1,000,000 divided by the total number of entries N. There are n players, and each may submit any positive integer number of entries (or choose not to enter). What is the superrational recommendation, and why? Also, if a player believes the other players have submitted a total of M entries, what number k of entries maximizes that player's expected payoff? Show the optimization.

(ii) Modified version: the prize is now $1,000,000 divided by the square root of the total number of entries, so the winner receives $1,000,000 / sqrt(N). For a player who believes the other players have submitted a total of M entries, set up the expected payoff as a function of k and find the k that maximizes it. Show the derivative step.

(iii) In the original version, the game-theoretic best response was k = M (match the others' total). Does the modified version have the same best response? Explain why or why not, and say whether the superrational recommendation changes.

---- Student's answer ----

In (a), the Platonia Dilemma: if I don't send a telegram, I get zero no matter what, because the prize only goes to a sender. If I do send, I get a billion dollars provided none of the other 19 send, and zero otherwise. So sending weakly dominates not sending for a standard game-theoretic agent. Therefore all 20 game-theoretic agents send for sure, and nobody wins anything. A superrational agent instead notices that all 20 are in the same boat and will all hit on the same strategy. Since there's no pure move that works if everyone makes it—if everyone sends, nobody wins; if nobody sends, nobody wins—they have to use a mixed strategy. If everyone sends with probability p, my chance of winning is p times the chance all others don't send, which is p(1-p)^{19}. Maximizing that gives p = 1/20, so a superrational agent should use a 20-sided die (or something equivalent) and send with probability 1/20. That way there's about a 37% chance that someone wins. Hofstadter's definition was "Superrational thinkers, by recursive definition, include in their calculations the fact that they are in a group of superrational thinkers." This is basically the same idea as evidential decision theory: you treat your action as evidence about what the other superrational players will do, so it's just EDT under another name.

In (b)(i), the original Luring Lottery: if all n players submit the same number k, total entries N = nk. My chance of winning is k/N = 1/n, no matter what k is. The prize is $1,000,000 / (nk), so my expected payoff is (1/n) * $1,000,000/(nk) = $1,000,000/(n^2 k). That is biggest when k is as small as possible, so a superrational player submits 1 entry (or maybe doesn't enter, but entering 1 dominates not entering). Game-theoretically, if the others have submitted M entries total, my expected payoff is [k/(M+k)] * [$1,000,000/(M+k)], which is maximized at k = M, so I should submit as many entries as all the others combined. That shows the conflict: game theory says match M, superrationality says submit 1.

In (b)(ii) and (iii), the modified Luring Lottery with prize $1,000,000 / sqrt(N): the superrational answer doesn't change. If everyone submits k, N = nk, my chance is still 1/n, and the prize is $1,000,000 / sqrt(nk), so expected payoff is $1,000,000 / (n * sqrt(nk)), which is again maximized by the smallest k, so superrational players still submit 1. For the game-theoretic best response, I set up expected payoff as [k/(M+k)] * [$1,000,000 / sqrt(M+k)] = const * k / (M+k)^{3/2}. Taking the derivative and setting it to zero gives k = M, just like in the original—the square root doesn't change the fact that you match the others. So the modified version has the same best response as the original, k = M, and the only difference is that the prize shrinks more slowly, so more people might enter, but the strategic logic is identical.
