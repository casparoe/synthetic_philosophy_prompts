My friend Ravi — condensed matter, insists he isn't doing philosophy — has an argument that the physical Church–Turing thesis isn't an empirical claim at all, and I can't find the exit even though I think the conclusion is wrong. he calls it the shutter argument, because every window you look through is finite. In his order, with my glosses:

(1) The physical Church–Turing thesis (CTT) says: any input-output behaviour a physical device can exhibit can be reproduced by a Turing machine. [Gloss so we don't talk past each other: a Turing machine is the usual idealized computer, finite program with unlimited tape and time; "computable" means some program halts with the right answer.]

(2) Whatever evidence we actually end up with is finite: finitely many trials, finitely many bits per input and output, readings to finite precision. Call the total body of evidence E.

(3) For any finite E there is a Turing machine that matches the device on every case in E — hard-code the observed input-output pairs into a lookup table, let the program do whatever you like off the table. His illustration: a box that, on input n, outputs the nth bit of the halting probability (the real number whose bits encode which programs halt; no Turing machine computes all of its bits). At any finite number of bits, some computable number agrees with it to exactly that many bits, so the box never produces a contradiction.

(3′) He preempts the obvious reply. If you object that the machine in (3) is ad hoc, that it changes as the data comes in, and that it isn't a mechanism anyone would take seriously, he says: fine, but then you are adding a requirement the CTT itself doesn't state — that the reproducing machine be simple, uniform over inputs, or mechanistic. Once you add that, the real work is being done by your preference for simple theories, not by anything about computability.

(4) So no possible evidence could ever conflict with the CTT.

(5) A claim that no possible evidence could conflict with has no empirical content. It isn't a hypothesis about how the world is; at best it's a convention, a definition, or a rule for how we're going to describe things.

(6) So the CTT is not an empirical hypothesis, the debate about whether physical systems could compute uncomputable functions is not a factual dispute, and all the stuff written as if it were a contingent discovery about the universe is confused.

(7) He adds that the same argument runs on the mathematical thesis too. Every computation anyone has ever performed is finite; a Turing machine reproduces all of them; so "effectively computable = Turing computable" also collapses into convention — and yet mathematicians lean on it as something substantive that could have been otherwise.

Here's why I think it proves too much.

(8) Run the same shape of argument on any generalization. "The laws of physics will still hold next Tuesday" has no empirical content, because for all data so far there's a gerrymandered hypothesis that fits and diverges on Tuesday. "There are more than 10^80 particles in the observable universe" has no empirical content, because every finite observation is consistent with a finite-universe theory. There is no scientific generalization at all that survives, since for any finite data set you can always cook up a hypothesis that fits it.

(9) So the argument isn't about computation in particular; its not about Turing machines or hypercomputers at all. It's a general argument that induction is impossible, and I don't accept that, so I think the shutter argument is broken somewhere — I just can't say where, or what fixing it costs.

I'd rather keep (1) than (5): I want to say the CTT is a real claim about the world and not a definition, and I want to say that finite-precision measurement doesn't by itself dissolve empirical content. If something about falsifiability has to go, I'd rather lose that.
