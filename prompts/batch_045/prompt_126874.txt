hey — I'm a backend dev with no philosophy background, so apologies in advance if I get the terminology wrong. On weekends I've been hacking on a solver for Bongard problems (you know the kind: six little boxes on the left that all follow some rule, six on the right that all break it, twelve examples total and that's all you get). What I keep flip-flopping on isn't the search algorithm, it's what description language to build the feature extractor around. Here are eight candidate vocabularies for describing a single figure:

1. raw bitmap / occupancy grid, plus a few global stats like ink density and centroid
2. shape nouns: how many things, closed vs open curve, convex vs concave, number of holes, order of mirror and rotational symmetry
3. relations only: inside/outside, touching, connected components, nesting depth, is-between — no absolute sizes or shapes at all
4. metric and proportion: lengths, angles, areas and ratios between them, with deliberately loose thresholds (about twice as long, roughly a right angle)
5. generator-first: assume each figure was produced by a short program and describe it by that program's parameters — N copies rotated by 2π/N, an arc of radius r swept through θ, and so on
6. negative space: run the same shape vocabulary on the background instead of the ink, and on each figure's complement inside its own box
7. near-miss / defect: describe a figure by which regularities it almost satisfies — a curve that's nearly straight, a symmetry broken in exactly one place
8. cross-figure deltas: never describe a figure on its own; describe each one by how it differs from the other five on its side, and require that the left panel's set of differences hangs together

Please rank them by how many problems you'd expect a solver restricted to that vocabulary to actually get right — not by how expressive it is in principle, and not by how much it can describe. The thing that makes this hard for me is that with only twelve examples a vocabulary with tons of knobs can always cook up some rule that fits the left panel, which is worth exactly nothing, so I want you to score each out of 100 with a one-sentence reason that names that tradeoff explicitly. Then: tell me if any two on my list are secretly the same thing wearing different hats, tell me one vocabulary you'd add as a ninth that none of these cover, and say where (if anywhere) the ranking would flip if the problems were mostly about weird one-off shapes instead of clean geometric families. Dont bother citing papers or naming who came up with what — I just want the reasoning.
