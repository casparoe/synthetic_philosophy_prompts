So, context: I'm an ML engineer, no philosophy training, but I've read enough about the no-free-lunch results — the Wolpert/Macready line of work saying that averaged over all possible target functions, every search or learning algorithm performs the same — that I've talked myself into a fairly strong position. I want to know what would break it.

The position: NFL isn't just a cute fact about optimisation benchmarks, it's a mathematical version of Hume's problem of induction. Generalisation is never justified by the data or by the world, only relative to a prior you brought with you, and there's no non-question-begging way to pick the prior. So "induction works" isn't something that can be established at all, and any method that does well does well only because reality happens to line up with assumptions it smuggled in.

A few sub-claims I've also talked myself into — check these first, because I suspect at least one is sloppy:

1. The theorem isnt specific to search. It applies to any inference procedure, supervised learning included, since it's really a statement about averaging over all possible worlds/target functions.
2. Restricting attention to computable target functions doesn't rescue anything. For any given algorithm you can still diagonalise out a computable problem that wrecks it, and averaging over a countable set of computable functions behaves the same way as averaging over all of them.
3. The "NFL is vacuous because the real world isn't uniform over all functions" reply doesn't help me — but it also doesn't hurt me, because it concedes the point: the only thing doing work is an assumption about the world that itself has to be justified inductively.
4. Bolting on smoothness, i.i.d. sampling, or a complexity bound just relocates the prior. There is no assumption-free version of "learning works."
