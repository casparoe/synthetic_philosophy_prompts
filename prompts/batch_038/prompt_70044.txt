**Question 3 (12 points).** Riverbend Health is the merger of two hospitals that grew up independently and that have, for forty years, each used its own system of abbreviations in patient charts. The systems are mutually incompatible: the same short string picks out different things at the two sites. The unified record system forces a single choice. Clinical staff at both sites insist their own system is obviously clearer and that adopting the other's would put patients at risk. Using Lewis's account in *Convention*:

(a) Say what would have to hold for each site's abbreviation system to count as a convention rather than a mere habit, or rather than a rule kept up by sanctions.

(b) Explain Lewis's claim that conventions are arbitrary, and say what it does and does not imply about how hard this choice will be, and about the staff's insistence that their system is the better one.

(c) Say what Lewis's account predicts about how the merged system ends up settled on one convention, and where a population-dynamics account of norm change — one on which a regularity spreads by imitation and differential success rather than because anyone reasons about anyone else's expectations, the sort of thing you get in Skyrms — would come apart from Lewis's.

**Student answer:**

(a) For Lewis a convention is a regularity in the behaviour of a population in a recurrent situation of interaction, and it is a convention rather than a habit or a sanction-backed rule when several things line up. The abbreviation systems have to be regularities in the first place: at each site chart entries overwhelmingly use the local code and new staff pick it up. The situation has to be a coordination situation rather than a conflict situation — each staffer's interest in matching everyone else's is much larger than any interest they have in seeing one particular code win. The preferences have to be conditional: what each staffer wants is to use the code others are using, not to use their own code no matter what anyone else does. That is what separates this from a rule backed by sanctions, where you would comply even expecting everyone else to defect because you are avoiding punishment rather than a coordination failure, and it separates it from a habit, where there is no expectation-dependence at all. There also has to be some alternative regularity that would have served just as well, and there is: the other site's code. None of this needs anyone ever having agreed to anything — no promise, no contract, no founding meeting. Lewis is explicit that conventions are sustained by a structure of expectations rather than by anything like an act of consent, which is why he thinks the social-contract picture gets these cases backwards.

Common knowledge is satisfied here because the merger was announced hospital-wide and both code books were distributed, so everyone knows there are two systems in play and knows that everyone else knows.

(b) Lewis says conventions are arbitrary. That does not mean they are unimportant, or that they can be changed at will. It means that among the regularities which would solve the coordination problem, which one actually obtains is not fixed by anything about the problem itself but by precedent and salience. This is why a bad convention can survive for decades: switching only pays if everyone moves together, and no individual gains by moving alone. So the choice facing Riverbend will be hard, and hard in a specific way — not because the two sides disagree deeply about values but because the gains are locked behind coordinated movement.

But that also means the staff's claims are confused. On Lewis's view "clearer" is itself a product of the convention. A code looks self-evidently better to the people raised on it, and that appearance is exactly what the convention generates, so when the east-site nurses say their abbreviations are clearer they are not reporting a fact about the two codes that would survive the merger; they are reporting their own conditioning. There is no answer to the question which code is really clearer, and that is precisely why the choice is arbitrary.

(c) Lewis predicts the outcome will be settled by salience and precedent rather than by argument. The likely candidates are the code belonging to whichever site has more beds, more senior staff, or more of the merged administration, since that one is salient as *the* existing practice. Once it is in place the conditional preferences do the rest: it becomes self-enforcing, and reopening it later will be prohibitively expensive.

Because Lewis's account is about what sustains conventions rather than how they arise, an evolutionary model cannot really disagree with him — they have different explananda. A Skyrms-style model tracks how often each regularity is imitated and how well the populations using it do; Lewis can grant that this is how a code gets started. What he adds is that once started it persists because each agent has a conditional preference to conform, and that is a claim about reasons rather than frequencies. So the evolutionary story sits downstream of his.

There is one place they come apart in prediction, though. Lewis thinks precedents accumulate in the direction of what works, since a regularity that failed to solve the coordination problem would not be a convention at all — it would simply stop being followed. So the merged system should end up with the more efficient code in the long run even if short-run politics first picks a worse one. The evolutionary model says much the same but for a different reason: worse codes get imitated less because their users do worse. Both agree the better code eventually wins; Lewis just does not need any replicator machinery to get there.
