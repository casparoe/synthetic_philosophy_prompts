Take a language with a conditional connective →, and suppose → has truth conditions, so it picks out a set of worlds.

(1) If → has truth conditions then for every probability function P over the language, P(A→B) is well-defined and equals the measure of the set of worlds where A→B is true.
(2) The conditional-probability constraint: for every P with P(A) > 0, P(A→B) = P(B|A). (This is meant to be the probabilistic core of Adams's thesis; I've stated it as a constraint on the probability of the conditional, which is how it gets used in these proofs.)
(3) Pick any P with P(A) > 0, P(B|A) = 1, and P(A) < 1. By (1) and (2), P(A→B) = 1, so the set of A→B worlds has P-measure 1.
(4) Now vary P over all such functions. A world w fails to be an A→B world only if some such P gives the A→B set measure less than 1 while putting weight on w; but you can always arrange P so that w carries the weight and the A→B set still comes out at measure 1. So the only worlds that survive are the A&B worlds and the not-A worlds.
(5) Therefore A→B is true exactly at the ~A ∨ B worlds: any conditional with truth conditions satisfying (2) is material implication.
(6) Steps (1)–(5) never mentioned which conditional we were talking about. For counterfactuals you only need the parallel probabilistic principle: the probability of the counterfactual equals the probability of the consequent given the antecedent.
(7) So counterfactuals, if they have truth conditions at all, are material implication as well.
(8) Hence any conditional with a false antecedent is automatically true — 'if I had stepped off the balcony this morning I would have flown to the seminar' comes out true — and an indicative and a counterfactual sharing an antecedent and consequent can never differ in truth value, only in whether you should assert them.
(9) But they do differ in truth value. Gardener case: indicatively, if the gardener didn't take the money then someone else in the house did — plausible, the money is definitely gone. Counterfactually, if the gardener hadn't taken the money then someone else in the house would have — implausible, nobody else had a motive or a way in.
(10) So the reductio lands on (1): conditionals don't have truth conditions. Which is definately not a conclusion I want, since my thesis is a Stalnaker-Lewis style possible-worlds semantics for counterfactuals, i.e. it assumes (1) for the counterfactual →.

I'm reasonably confident (1)–(5) is just the standard result and isn't where I went off the rails — that bit lines up with what the hand-out said, modulo notation. My worry is (6) onward. Specifically, (6) feels like it slides, because 'the probability of the consequent given the antecedent' might not mean the same thing in the two cases: for an indicative it looks like a ratio of my own credences, but for a counterfactual you seem to want a chance, or a probability under a supposition that isn't just conditioning on the antecedent being true. If that's right then (7) never gets going and (10) doesn't follow. I'd much rather give up (6) than (2), and (2) than (1). Tell me where it actually breaks and price the alternatives.
