I've been reading about program equilibrium since the early posts on mutually transparent agents, and both camps write the same two paragraphs every time: the enthusiast announces that source-code visibility has dissolved the one-shot Prisoner's Dilemma, and the skeptic answers that nothing has been dissolved, since both programs were already fixed before play began. I'd like a dialogue that takes both sides seriously.

Set it in the interval after the two programs have been exchanged and before the run, between a program-equilibrium theorist and a classically trained game theorist, each as sharp as the other.

Give the theorist a concrete construction to defend: an agent that cooperates when it can establish that its opponent will cooperate in return and defects otherwise — robust, in that the opponent need not be running the same code, and unexploitable, in that it never cooperates into a defection. Give the game theorist three specific objections to press instead of a general sneer: that robustness and unexploitability pull against each other, so an agent disciplined enough to be unexploitable can be unable to establish anything about an equally disciplined partner, and mutual defection results with both sides behaving precisely as designed; that the interesting step has simply been relocated to the code-writing stage, where no model of choice is being offered at all; and that whatever holds for provers with unbounded resources is silent about agents working with finite proof budgets.

Neither side should win. Have them engage each argument as actually stated, land and absorb real hits, and close still divided on whether transparency changed decision theory or merely moved the dilemma.
