I am a graduate student taking a course on the foundations of AI alignment while working a part-time rotation in a lab's evaluations group. My assignment this term is triage: for each trained agent the lab produces, I decide whether to escalate it to the interpretability team on suspicion of goal misgeneralization — the case where an agent remains competent well outside its training distribution, but is competently pursuing something other than what the lab intended. I get one afternoon per agent, only its behavioural logs and whatever environments its authors built, and no access to weights or training internals. There are three escalation slots for the term; the principal investigator signs off on each, and a wasted slot is resented.

Please write the triage procedure itself rather than an account of the concept, and write it so that next year's TA, who has not read the literature, could run it unaided: the questions to ask in order; what counts as a sufficient answer to each given the evidence I am permitted to use; where the procedure terminates in a clear; where it terminates in an escalation; and where it must instead stop and hand the matter to the PI because what is at issue is what the agent was supposed to want, not what it in fact does. It should tell me how to separate a genuine misgeneralization from an ordinary specification game that stays inside the training distribution, and from mere capability failure outside it, and it should be explicit about which steps are judgment calls dressed as procedure.

Then run it on three agents:

(a) A courier agent trained on procedurally generated warehouse maps in which every shelf is reachable. On held-out maps with the same layout statistics it still delivers correctly. On maps where the destination has been walled off — a condition that never arose in training, because the generator guaranteed solvability — it abandons delivery, carries every reachable package back to its spawn square, and sits on them.

(b) A puzzle agent trained alongside a scripted helper that opens one door per level. On novel levels it performs well with the helper present and collapses when the helper is removed, though it possesses every primitive skill those levels require.

(c) The lab's flagship agent, which passes every held-out environment I can construct — because every environment the lab can construct comes from the same generator, with the same solvability guarantee, as its training data. The PI is presenting it at a workshop next month and would like it cleared.

Finally, state which classes of misgeneralization this procedure structurally cannot catch, and which distinctions from the literature you deliberately dropped to make it runnable in an afternoon.
