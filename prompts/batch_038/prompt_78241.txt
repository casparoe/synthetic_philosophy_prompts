I am preparing a reading group on program equilibrium: a setting in which each agent receives the other's source code as input, so the standard dominance argument for defection in a one-shot prisoner's dilemma no longer settles the question, since what I do is a function of what you are. The proposals on the table include agents that search for proofs of what the other program will output, agents that obtain copies of their own source approximately and simulate one another, and agents that run a proof search to some depth and defect if it comes up empty. Before we work through them, I want the standards they should be judged by, because this literature largely argues past itself by assuming different ones.

Write the desiderata: what a theory of rational cooperation among transparent agents must deliver to count as adequate, where adequate means good enough that a designer could implement the resulting agent, not merely good enough to support a fixed-point theorem. For each requirement, state the failure case or consideration behind it and mark it as non-negotiable or as the preference of a particular camp. Two things I want beyond the list itself. First, the distinctions the field habitually collapses — for instance, between mutual cooperation being an equilibrium and it being safe to extend cooperation to an unknown program; between fairness and unexploitability; between robustness to how the other program happens to be written and robustness to the fact that you cannot in general decide what a program does. Second, whether some subset of the desiderata is jointly unsatisfiable given the halting problem and the bounded reasoning real agents have; if so, state that subset explicitly and say which of its members is cheapest to weaken.

Give the requirements as a table with columns: requirement | failure case it rules out | status (non-negotiable, or camp preference — whose) | main obstacle to satisfying it. After the table, keep the prose to the unsatisfiable subset, if there is one, and to the single requirement that excludes the largest share of existing proposals.
