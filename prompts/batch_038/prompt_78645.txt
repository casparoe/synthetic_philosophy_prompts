A mate of mine has been reading up on whether virtual worlds are real and he's come at me with an argument I can't find the exit from, but the conclusion is that Grand Theft Auto is a war crimes simulator, so something has gone wrong somewhere and I cant name it.

(1) Something is real if it genuinely exists — if it isn't an illusion or a nothing.
(2) The house I built in my survival game genuinely exists: its a standing pattern of processes running on real hardware, made of ordinary physical stuff, doing real causal work inside the game world.
(3) So my virtual house is real.
(4) The same goes for events. When I shoot an NPC, that's a process in a running computer, one that I intended and caused, and it leaves the world permanently altered — the body's there, the other villagers react, the door doesn't open any more.
(5) So the killing is a real killing.
(6) A real killing, intended by an agent, is morally serious in the way killings are. That it was made of bits rather than flesh is no reason to downgrade it, any more than a murder done with poison rather than a bullet is.
(7) So shooting NPCs is morally serious in the way shooting people is.

I want to keep (3), honestly — I do think my house is a real thing in some sense. But then I can't see how to stop at (7), and it gets worse, because the exact same steps run on a novel on my Kindle. The murder in the book is also a pattern of bits on real hardware, which I caused to run and which changed the state of the device, so by (2) through (6) Anna Karenina's death is a real death and I've been party to it.

Which step do I drop, and what does dropping it cost? And what do you say about the Kindle version — same argument, same steps, so whichever premise you reject has to rule that one out too.
