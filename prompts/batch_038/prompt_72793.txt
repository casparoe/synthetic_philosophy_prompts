hey — I need someone to actually argue a position for me, not hedge it into mush. I'm prepping a session on whether DNA really is a code or whether that's just a metaphor left over from the early days of information theory that nobody ever bothered to retire.

The tired version of the debate goes like this: the codon table is arbitrary and got locked in very early, so it looks code-like; but the arbitrariness is contested, and the translator is itself specified by the genome, so the whole thing looks circular. I want to sidestep all of that.

Here's the criterion I've been working with, call it substitution-closure. A physical system carries a code only if (a) there are two distinct vocabularies and a many-to-one map from one to the other; (b) the particular pairing isnt readable off the physical-chemical properties of the items in the first vocabulary — you couldn't derive it from the physics alone, you'd have to learn or look up it; and (c) the redundancy in the map is actually exploited by the system, meaning there are genuine synonyms (different first-vocabulary items landing on the same second-vocabulary item) and the system gains something from their being interchangeable, rather than the redundancy just being slop.

The position I want argued: DNA meets (a), (b) and (c), and — the part people always miss — it's meeting (b) and (c) *together* that does the work, because the standard objection that the code is error-minimised and therefore not arbitrary and therefore not really a code actually cuts the other way. Morse was built so the most frequent letters got the shortest sequences; nobody thinks that stops it being a code. Optimisation layered on top of an assignment that physics doesn't dictate is a mark of a selected or designed code, not of a measurement scale.

Argue that. Steelman the objector as hard as you like — including the point that a code seems to presuppose a community of readers who could have agreed otherwise, and the point that most of the genome never gets translated at all so the code covers a percent or two of it — but come down clearly on yes, DNA is a code under substitution-closure.
