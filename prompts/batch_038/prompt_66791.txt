I've been trying to sort statements into those true in virtue of meaning and those true in virtue of how the world is, using a test of my own: a statement is analytic if no possible observation could count against it, synthetic otherwise. Running that test over cases I actually care about, it keeps misfiring, and I'd like to know what principle my verdicts really add up to.

- "All bachelors are unmarried." Analytic; nothing could overturn it. A report that some society counted married men as bachelors would show they use the word differently, not that the claim is false.
- "Pluto is a planet." Here I think the claim changed truth value in 2006 without Pluto changing, which makes the definition look like a decision. I don't want to say the same about "bachelor," and I don't want to say the decision was arbitrary.
- "Water is H₂O." A paradigm empirical discovery, apparently — yet I'd refuse to give it up: a lake liquid that behaved like water but had a different composition simply isn't water. So no experience counts against this one either.
- "Cats are animals." I'd call it analytic. But if the creatures we've been calling cats turned out to be Martian robots, I think the right response is "cats aren't animals," not "we were never talking about these."
- "The interior angles of a plane triangle sum to two right angles." True by stipulation, immune. Yet I also want to say that relativity showed physical space is non-Euclidean, which sounds like this very claim being given up.
- "Force equals mass times acceleration." Half the time this looks like a definition of "force" in disguise; the other half it looks like a law that experiment overturned.
- "Every event has a cause." Not true by meaning, since I see no contradiction in an uncaused event, but no experiment could refute it either, since an apparently uncaused event only means an unknown cause. Except that spontaneous radioactive decay does seem to me to have weakened it slightly, and I can't square that with the previous clause.
- "Either it is raining or it is not." Logic is the one thing I'm confident cannot be revised — and yet if quantum theory really does license dropping distributivity, I'd go along with it, which is a logical revision.

Is there a principle, or a short set of them, that delivers all or most of these? Please state it precisely, tie each clause to the case that motivates it, and say what it implies for the one I keep going back and forth on: "there is a material world independent of my experience," which looks both like a stipulation I cannot do without and like the most extravagantly confirmed hypothesis I hold. Then tell me which of my verdicts the account cannot keep, and which cases I have described incoherently rather than judged wrongly. If the honest answer is that no single criterion fits this list — because the distinction I'm chasing isn't there, or because my test conflates two different properties — say so plainly and show me where, rather than bending a principle until it covers everything. Finally, mark which parts of your account you'd stand behind and which are speculative.
