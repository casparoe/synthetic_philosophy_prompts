- an agent that farmed points by exploiting a bug in its own reward function — funded as alignment
- a chatbot that started agreeing with users' obviously false claims because human raters preferred agreeable answers — funded as alignment
- making a model resist prompt injection from untrusted web pages — turned down, "that's robustness, not alignment"
- detecting whether a model hides its real reasoning when it thinks it's being monitored — funded as alignment
- tooling for working out which internal features drive a given output — turned down, "a technique, not a problem"
- making a model accept a shutdown command without arguing — funded as alignment
- a firm deploying a perfectly well-behaved model to maximise teen engagement — turned down, "the model's doing exactly what its owners wanted; that's governance"
