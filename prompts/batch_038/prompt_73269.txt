I'm marking the scripts for a second-year philosophy of mind module and could do with a second pair of eyes on one of them. Here's the question we set:

> "Lucas argued that Gödel's incompleteness theorems show that mechanism is false, and Penrose later revived a version of the argument. Set out how the argument is supposed to work and assess whether it succeeds. In particular, say which incompleteness result the argument needs, and what assumptions about the human mathematician it relies on." (1,500 words max)

And here's the student's answer, slightly abridged but keeping all the substantive steps:

---

Gödel's first incompleteness theorem says that any consistent, effectively axiomatised theory which is rich enough to do elementary arithmetic is incomplete: there is a sentence G in the theory's own language which the theory can neither prove nor refute. Gödel built G by a diagonal trick, arranging that G says, of the theory itself, that G is not provable in it. Suppose the theory proved G. Then G would be false, since it says it isn't provable, so the theory would have proved something false. Hence a consistent theory cannot prove G. Nor can it refute G, since proving not-G amounts to proving that G *is* provable, and again that would be a false provability claim, so consistency alone rules it out.

The crucial point for us is that G is true. It says of itself that it is not provable in the theory, and we have just seen that it isn't provable. So we have an arithmetical sentence that is true but which the theory cannot prove: however many axioms and rules you build in, they cannot capture all arithmetical truth.

This is what the anti-mechanist needs. Suppose the mechanist claims my mind is a machine, i.e. a consistent formal system F which is effectively specifiable and contains arithmetic. Then F has its own Gödel sentence G_F, which F cannot prove. But I can see that G_F is true, by exactly the reasoning above: F is consistent, it's the system that generates my own reasoning, and if G_F is unprovable then it is true. So there is something I can do which F cannot — I can recognise the truth of G_F. Therefore I am not F. And the mechanist cannot repair things by naming some other system, because the same diagonal result applies to whatever consistent arithmetical system he proposes. Gödel himself drew the conclusion that his theorem refuted the idea that the mind is a machine; Lucas only made the argument explicit and general.

The obvious objection is that I cannot know F is consistent. Gödel's second theorem says a consistent system cannot prove its own consistency, so I certainly cannot prove mine, and the whole argument may rest on an assumption I am not entitled to. Lucas's reply, which I think works, is that the mechanist has already committed himself to F's consistency by proposing F as a model of my reasoning: if F were inconsistent, so would I be, which is absurd. I don't need a proof of consistency, only to see that F behaves consistently.

There is a sharper objection. If human mathematicians really are sound systems, then by the same reasoning they could not know that they are sound, so the argument would show only that we cannot know our own soundness, not that mechanism is false. That is a fair point, but it leaves the argument intact so long as we can see that we are consistent in practice, which we plainly can.

Penrose's version is stronger, because it needs less. He does not require that we know our own consistency, or even that the mathematician's method be sound — only that it be consistent. His argument runs over computations rather than proofs: if there were a sound algorithm A which correctly recognised whenever some computation fails to halt, we could construct a computation that halts exactly when A says it doesn't, which is a contradiction. So no such algorithm can capture mathematical insight. Penrose then suggests the brain gets its non-algorithmic behaviour from quantum gravity.

So the argument succeeds: consistency is all the anti-mechanist needs, no machine can match a human mathematician, and strong AI — a machine which is genuinely conscious and creative — is impossible.
