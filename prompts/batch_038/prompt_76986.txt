So in a program game (the setup where each player is a program that gets handed the opponent's source code before choosing an action), the standard move is to write a program that cooperates iff the opponent's code cooperates with it. But taken literally that seems to launch a regress: to know what you do I have to know what you do once you know what I do, and so on forever. Yet these programs are supposed to terminate and settle on mutual cooperation.

Can you explain what actually breaks the regress — how the pair ends up at a determinate outcome at all? I have a vague sense it involves programs that can quote their own source, recursion-theorem style, but I don't get how that's more than a trick, and whether the resulting "program equilibrium" is a real fixed point or just an artifact of how the class of programs was chosen.
