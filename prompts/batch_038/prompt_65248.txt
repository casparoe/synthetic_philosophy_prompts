---

The downward Löwenheim–Skolem theorem says that if a countable first-order theory has an infinite model, then it has a model whose domain is countable. ZFC is a countable first-order theory, so if it is satisfiable at all it has a model M with only countably many elements. But ZFC also proves Cantor's theorem, so ZFC proves that there is a set which cannot be put in one-to-one correspondence with the natural numbers, for instance the power set of omega. Since M is a model of ZFC, M satisfies this theorem. So there is some element a of M such that M says a is uncountable.

The contradiction seems to be this. Everything in M's domain is countable when we look at M from outside, since the whole domain is countable. So a is countable. But M says a is not countable. So M and the real universe disagree about the same set, and it looks like ZFC proves something false.

It isn't a real contradiction though. To say a is countable is to say there exists a bijection between omega and a. That bijection is itself a set. M can be missing that set even if the full universe has it, because M only contains countably many sets and it doesn't have to be closed under anything. So a is uncountable relative to M and countable relative to the real universe. Countability isn't absolute, it's relative to which functions the model has available. Also M's power set of omega isn't the real power set of omega, it's just the countable collection of reals that happen to be in M, so Cantor's theorem is still true inside M.

For (i): you can't escape by moving to second-order set theory. Löwenheim–Skolem is a theorem about satisfiability, so a second-order version of ZFC has a countable model too. You also can't escape by insisting on transitive models, because in a transitive model the membership relation is the real membership relation, so the paradox disappears there.

For (ii): this shows that set-theoretic truth isn't determinate. Skolem's paradox by itself already shows there is no fact of the matter about the continuum hypothesis, since a countable model can be extended or shrunk without changing what its sentences say. Putnam pushed this into the philosophy of language: if our theory can't pin down the size of the domain, our words don't determinately refer to sets.
