I write a science-and-ideas column and I've spent the last few weeks around people who build monitors that watch a model's internals instead of its outputs — the pitch being you snapshot the circuitry doing the work on release day, then raise an alarm if the machinery drifts later. Talking to them it became obvious the whole project rests on a question nobody in the room could answer cleanly: what counts as the same mechanism? Their own demos are a mess of it. Quantizing a model so it could run cheaply lit the monitor up everywhere while behavior stayed basically the same. A fine-tune on a customer's data moved almost nothing the monitor was watching, but a targeted ablation that used to break a capability just stopped having any affect. And the thing they happily call the same circuit in the 8B and the 70B model shares a functional description and very little structure.

So before I write any of this up I want the spec, not the lit review: the desiderata a theory of mechanism-identity has to meet to be usable for anything like this. Give me the cases it has to get right, with your verdict on each, and add ones I've missed; the distinctions it's not allowed to collapse — same function vs same implementation, same causal role vs same weights, a mechanism that's gone vs one that's been absorbed into a redundant distributed backup, a mechanism that changed vs the description of it that got sharper; and the findings about how these networks actually organize themselves that it has to stay consistent with (features smeared across many directions, one component doing several jobs at once, the same capability getting implemented differently at different scales), plus the unglamorous constraint that whatever identity criterion you land on, a monitor has to be able to compute it on a model nobody has fully reverse-engineered. For each one, say what's doing the work — why it's a requirement and not just an aesthetic preference. Then mark which are genuinely non-negotiable and which are the tastes of a camp (implementation-first people vs causal-role-first people), and if some subset turns out to be jointly unsatisfiable, say so plainly and show me the argument, because that's the bit I'd build a column around. Finish with which single requirement does the most damage to the answers people currently give. No bibliography, no suggested reading, I'll chase that down myself — I want the requirements and the reasoning behind them.
