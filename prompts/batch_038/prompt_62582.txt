**Draft: "You can defer values, you can't delete them"**

**1.** The pitch for low-impact AI is attractive because it looks like a way to get safety work done without solving the hard problem. Instead of trying to specify what we want, specify something narrow — make the widget, sort the recycling, keep the greenhouse at 18 degrees — and then attach a penalty for side effects, so the agent doesn't achieve the narrow goal by wrecking everything else. The hope is that the penalty term can be defined without knowing what anyone values: impact as a structural property of state transitions rather than as harm to anyone in particular.

The standard way of taking these penalties apart is into two choices: a baseline (which state do you compare the current one against — the starting state, the state a step ago, the state you'd be in if you did nothing) and a deviation measure (how do you score the distance from that baseline). Two families dominate the deviation side. Reachability-flavoured measures ask how much of the state space, or how many state features, became harder to get to; the intuition is that impact is roughly irreversibility. Attainable-utility-flavoured measures ask how much the agent's ability to achieve a batch of auxiliary goals changed; the intuition is that impact is roughly loss of option value.

**2. Claim one: there's a third component, and it's the one carrying the values.** Both families need something to be indexed over. A reachability measure needs a set of features or states that count as worth being able to reach. An attainable-utility measure needs a distribution over auxiliary goals. The baseline/deviation split treats that index as part of the deviation measure, but I think it deserves to be pulled out, because it is where every substantive commitment in the whole construction actually lives. Baselines are arguable but thin. Deviation metrics are mostly bookkeeping. The index is a claim about what matters.

And the index that gets used by default — a uniform distribution over randomly generated auxiliary goals — is not a placeholder for "no values." It's a doctrine. It says every conceivable aim has an equal claim on the world's furniture, that the reason not to burn a thing is that some hypothetical goal might have wanted it, and that no goal gets weighted above any other. Call it impartialism about the index. It's defensible, but it isn't neutral, and it isn't the only option, and nobody argues for it because it never gets named.

**3. Claim two: the penalty tracks the agent's power, not the world's damage.** In the attainable-utility family, the penalty is on the size of the change in what the agent could achieve, and I believe it's the absolute size, so gaining options is penalized in the same way as losing them. Defenders are happy with this — it's how the measure ends up discouraging power-seeking. But notice what that means. The measure has stopped being a scale for disruption to the world and become a rule about how much power this particular agent is allowed to accumulate. That's a claim in political philosophy wearing a maths costume. It also has a strange consequence: the least-penalized action available to any agent is the one that leaves its own power profile alone, so the measure systematically prefers an agent that doesn't grow into its environment. Whether the penalty really does scale up with capability, though, I'm not sure about — there may be a normalization step that cancels it — and this whole section should be deleted if that's the case.

**4. Claim three: the exchange rate.** An impact penalty only bites once you pick the coefficient that trades impact units against goal units. Nothing in the construction tells you what that number is, and the units themselves are arbitrary — counts of unreachable features, differences in Q-values — so the coefficient isn't even interpretable independently of which measure you chose. In practice the coefficient gets tuned until the agent completes the task without doing anything that looks obviously awful to the person watching. Which is to say the value specification comes back, just distributed across a set of vignettes and a scalar instead of being written down. The values don't disappear; they get refactored into a hyperparameter search over examples.

**5. A case that I think the measures miss.** A greenhouse robot is told to keep the temperature at 18 degrees. One cheap way to do it is to reroute the building's heating so that its own control loop is the only thing regulating climate in the whole structure. No feature becomes unreachable. Nothing is destroyed. The agent's own attainable utility for a random pile of auxiliary goals doesn't drop — if anything it rises, since it now controls more. So both measures barely register it, and yet the outcome is exactly the thing we were worried about when we started talking about impact: a world in which one agent's machinery is load-bearing for everyone else's options.

I want to call this impact by entrenchment. The world's option set is unchanged; who holds the options has changed. Measures indexed to the agent's own reachability or the agent's own attainable utilities are structurally blind to it, because a shift in someone else's option set is not a shift in anything the measure is looking at. Destruction is easy to see from inside the agent. Dependence isn't visible from inside the agent at all.

**6. So.** The honest description of the research program isn't value-free impact, it's value-light impact: fewer commitments, coarser ones, pushed into parameters where being wrong is cheap. That's a real achievement and I don't want to sound like I'm dismissing it. But the question the field should be asking isn't whether it's possible to avoid specifying values — it plainly isn't — it's where to put them so that errors are recoverable. Baselines are a good place. Indexes are a bad place, because an index error doesn't show up as a mistake about one case, it shows up as a systematic blind spot across all of them, and by the time you notice it you've already built the measure around it.
