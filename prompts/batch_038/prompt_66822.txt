(1) ZFC is a countable first-order theory: countably many symbols, countably many axioms (or axiom schemas).
(2) Downward Löwenheim–Skolem: any countable first-order theory that has a model has a model with a countable domain.
(3) So if ZFC is consistent at all, there's a countable model M of it.
(4) M satisfies the usual theorem that there's no bijection between the naturals and the reals. So from M's own point of view, the thing M calls ℝ is uncountable.
(5) But M's domain is countable, so M has only countably many members, hence only countably many subsets of M's ω — which means there really is a one-to-one correspondence between M's naturals and the set M calls ℝ.
(6) So the theory can't tell the difference between "such a correspondence exists" and "no such correspondence exists." Which one is true depends on which model you happen to be standing in, not on the axioms. The axioms don't fix what the terms mean.
(7) Nothing in (6) used anything special about sets, or about ZFC. It only used: here's a first-order theory, here are two models of it.
(8) So the same goes for any first-order theory, physics included. A countable model fits the axioms just as well as the intended one, so the axioms don't fix what "electron" or "mass" refers to either.
(9) Therefore there is no fact of the matter about what any of our theories are about. Reference is indeterminate all the way down — including for the terms in this argument.
