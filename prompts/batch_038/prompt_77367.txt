My reading group spent three weeks trying to turn the Lucas–Penrose argument into a numbered chain we could actually argue about, and I think we built a monster. Here it is, cleaned up:

(1) If I'm a machine, then there's some effectively axiomatized formal system F, containing enough arithmetic, such that every arithmetical statement I can see to be true is a theorem of F.
(2) F is Π1-sound: it never proves a false statement of the form "this particular computation never halts." (We weakened full soundness to Π1-soundness on purpose, so the mechanist in our group can't duck by pointing out that I get things wrong about set theory or the weather.)
(3) Let G(F) be the Π1 sentence saying that no number codes an F-proof of that very sentence. G(F) is true. This is supposed to follow from (2): if G(F) were false, there would be an actual F-proof of it, so F would have proved a false Π1 sentence.
(4) If someone hands me F as my own program, I can inspect it and come to see that G(F) is true. I don't need to prove it inside F, I just need to see it.
(5) G(F) is not a theorem of F, by (2) and (3).
(6) So if F is my program, there's something I can see to be true that F can't prove, which contradicts (1).
(7) Therefore I'm not a machine.

Two problems, and I cant tell whether they're the same problem.

First, (4) smells like the sleight of hand but I can't say what it is. Our mechanist says: go ahead and run it, but you only ever get to build G(F) for an F that somebody actually hands you, and nobody hands you your own. On that reading all the premises license is "for any F offered to me as my own code, I can turn down the offer," which is perfectly compatible with there being an F that is my code and that nobody ever offers. And yet (4) is supposed to be doing something reflexive, about me, or step (6) doesn't get off the ground. My instinct is that something shifts between (4) and (6) but I can't name it.

Second, and worse: the argument seems to prove that I could never know my own soundness. Because if I knew both that F is me and that F is Π1-sound, I could see G(F), and (1) would be contradicted. So maybe the honest conclusion is just "no sound reasoner can know her own program," which is a lot less exciting and, as far as I can tell, something a mechanist should happily accept and even expect. Then someone in the group noticed that if (4) is a genuine uniform recipe rather than a one-off trick, we can feed the outputs back in — F, then F plus G(F), then that plus its own Gödel sentence, iterating up through the recursive ordinals — and I'd end up able to see true Π1 sentences beyond any hyperarithmetic system, which is way too much for a creature that can't reliably add two large numbers by hand.

So: which single step do you reject? Give me the step number and a sentence on why it looked innocent when we wrote it down, then price the three escapes I can see — giving up (2) and accepting that I might be an unsound machine, giving up (4), or keeping (4) but restricting it to F's that aren't me. I'd rather lose (2) than lose (7), but I suspect thats motivated reasoning and I want to know what it actually costs me. And tell me whether the iteration worry in my second problem is a real consequence of (4) or whether it dissolves once (4) is restricted.
