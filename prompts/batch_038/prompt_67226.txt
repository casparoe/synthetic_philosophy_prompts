----- ANSWER I HAVE TO GRADE -----
(a) The thing both of these are reacting to is that you can't write down everything you care about in a reward function. If you tell the agent "deliver the packages," nothing in that reward says "don't smash the vase" or "don't disable the fire alarm," so it'll do those things whenever they help, and some of them can't be walked back afterward. So you add a second term that charges the agent for impact and you trade that off against the task reward.

Both terms work the same way underneath. You compare the state the agent ends up in to the state it would have ended up in if it hadn't taken the action — that's the baseline — and you charge it for the gap. What differs is only how you measure the gap.

Relative reach measures it in terms of possibilities. From the baseline state some set of other states is still reachable; from the state the agent actually ended up in, some of those aren't anymore, or take a lot longer to get to. The states that fell out are the side effect, and the penalty tracks how much reachability was lost. Comparing to a baseline instead of just counting everything the agent makes irreversible is what keeps this from being useless, because on a strict reading basically every action is irreversible — you can't unring a bell — so an absolute rule would leave the agent paralyzed, or blaming itself for changes the weather and other agents caused.

AUP measures the same gap with a reward instead of a count. You pick an auxiliary goal, deliberately not the agent's task goal — something generic like acquiring resources or surviving — and you ask how much of that goal the agent could still attain from where it now stands. If the action drops that number, it gets charged. So AUP is roughly relative reach with "how many states can I still get to" swapped for "how much auxiliary reward can I still get," which is why in practice you'd probably run both, relative reach for the value-free part and AUP for the part where you want specific things protected.

That's also the main difference between them: relative reach only looks at the structure of the environment, so it carries no value assumptions at all, while AUP needs an auxiliary reward that has to be a decent approximation of what we actually want preserved. Get that wrong and the agent protects the wrong stuff — set the auxiliary goal to "make paperclips" and it'll happily flatten a forest as long as that's good for paperclips.

(b) I think the critic is right. Both proposals need something the designer has to supply: a baseline state for relative reach, an auxiliary reward for AUP. Choosing the baseline is already a judgment about which future counts as the normal one, and choosing the auxiliary reward is a judgment about what's worth preserving. So the value question hasn't been dodged, just relocated. It's relocated somewhere much smaller though — you don't have to list every vase, just pick a baseline and one crude goal — so the proposals still do useful work even if the critic wins the argument.
