WORKING DRAFT: *Which Failure Would You Rather Have? The Reference Class Problem as a Dispute about Acceptable Error*

1. Setting up. Any single-case probability attribution — that this patient survives the procedure, that the bus which struck the plaintiff belonged to the defendant, that this applicant defaults, that humanity is extinct within some horizon — requires a class of cases relative to which the number is computed. Reichenbach's directive is to use the narrowest class containing the case for which adequate statistics are available. Von Mises pushed in the opposite direction, holding that probability claims are meaningful only relative to a specified collective and that the probability of a single event is not a well-formed magnitude at all. They agree on the crucial point: the class must be settled before the number means anything, and neither offers a non-arbitrary procedure for settling it, since any case falls into indefinitely many classes with different frequencies. I assume throughout Hájek's insistence that this is not a local embarrassment for frequentism but a general one, affecting any account on which a probability attaches to a proposition about an individual case, including subjective ones, since the subjectivist too must say which proposition the credence is in.

2. The narrowing rule relocates the problem rather than solving it. To narrow is to select a property, and selection requires a criterion of admissibility. The natural candidate is relevance — the property tracks the outcome — and the general form of that requirement is Goodman's: distinct, extensionally divergent ways of carving a class can be equally supported by the evidence, so the choice among them cannot be made on logical or purely statistical grounds. The reference class problem is therefore a species of the new riddle of induction. This inheritance is usually reported as bad news, on the grounds that it makes the problem look unsolvable. I want to argue the opposite: it is informative, because it fixes the shape of the difficulty. The trouble is not that we lack data. It is that the rule for choosing among data-adequate options is not itself data-driven, and so a solution, if there is one, will have to be pragmatic in the specific sense in which entrenchment is pragmatic — an appeal to which properties our practices have licensed. The familiar objection that a pragmatic resolution is no resolution at all is then question-begging, since it assumes logical form could do work that the grue case shows it cannot.

3. The core claim: the two failure modes are not symmetric. Narrowing and broadening are habitually treated as rival policies with rival costs. But the costs are of different kinds, and the difference is epistemic in a way the literature does not register. Narrow too far and you run out of statistics: small samples, wide intervals, frequencies that shift when you resample. This failure is self-announcing. The practitioner can foresee it and can diagnose it afterwards from the data alone. Broaden too far and you import a property whose distribution in your subpopulation differs from its distribution in the class you sampled, so the frequency you report is simply not the one that governs the case. This failure is silent. From inside the data the broad class looks homogeneous, the interval is tight, and nothing in the numbers registers the mistake; detecting it requires an antecedent suspicion about some property, which is exactly what the rule was supposed to supply.

Reichenbach's rule therefore embeds a preference for the error that announces itself over the error that does not. That preference may well be right, but it is a normative commitment about how to distribute acceptable error, not a deliverance of the concept of probability — and it is not stable across practices. Courts refuse to let bare class frequencies carry a burden of proof at all, effectively demanding narrowing all the way to the particular case; on my reading that is an explicit refusal to run the silent error at the defendant's expense, and it is purchased at the cost of the visible one, since it forgoes statistically adequate classes entirely. Insurance pricing does the reverse, accepting a tight interval computed over a broad class and treating the resulting silence as an acceptable premium. The ordering of the two failure modes is thus a parameter that varies by practice, and it is set normatively in each.

4. A prediction. Because this ordering is normative but presents itself in technical dress — a choice of class, a choice of threshold, a choice of sample — applied disputes about reference classes will be interminable and will be systematically misdiagnosed as disputes about data quality. Concretely: whenever class choice is contested and the contest is socially live, the disagreement will survive the production of better statistics, and each side's argument will be translatable into a claim about which error is worse. Consider the standing controversy over using a protected attribute in actuarial or credit models. The industry case is predictive adequacy: the narrower class has power and the broader one does not. The critic's case is irrelevance: the attribute does not track anything about this individual's own conduct. Neither position is answerable by a larger sample, which only sharpens the interval within whichever class has already been chosen. The same structure appears, more faintly, in anthropic reasoning, where the persuasiveness of Doomsday-style arguments tracks whether the reader's self-sampling assumption treats the reference class as all observers or as a narrower class fixed by a relevance intuition — that is, tracks which of the two failures the reader finds more frightening.

5. The objection I most fear. A statistician will say the asymmetry in section three is false, because relevance is testable: narrow exactly when the candidate property is statistically dependent on the outcome given what you already condition on, and treat the homogeneity of the broader class as a hypothesis you can test and reject. If that works, both failure modes become visible from inside the data, the normative residue disappears, and sections three and four collapse into a remark about significance thresholds.

My reply has two parts, and I am not equally happy with either. First, regress: the test is run on a sample, and that sample is itself a reference class chosen under the same problem, so the procedure cannot ground the choice it presupposes. Second, and better: the test does not return a yes or no but a graded quantity, so applying it requires a threshold, and a threshold is precisely an ordering of the two errors — false narrowing against false broadening. The apparatus of relevance testing is therefore where my normative ordering gets smuggled in, and where it becomes invisible, which is a point in favour of the paper rather than against it.

6. Conclusion. The reference class problem is not a technical puzzle awaiting better statistics. It is a standing disagreement about the distribution of acceptable error, and the philosophical work is to surface the ordering in each practice rather than to hunt for a universal narrowing rule.
