Context: I write backend infra for a living, zero formal philosophy training, but I fell down a rabbit hole on the knowability paradox (the Fitch thing) and I want an actual number out of you, not a survey of the views.

Here's my understanding of the derivation — tell me if I've garbled it. Assume every truth is knowable. Take some true thing nobody knows, call it p. Then "p and nobody knows p" is itself a truth, so by the assumption it's knowable. But knowing that conjunction would mean knowing both halves, and knowing the second half makes it false, so it can't be known. So by the assumption it wasn't a truth after all. So there are no unknown truths. Which is absurd, so some step has to go.

My pet idea (I have thought about this way more than is healthy): maybe the step that goes is "knowing a conjunction means knowing both halves." For any real bounded agent — finite memory, finite time, finite attention — that closure looks like exactly the same kind of idealization as assuming a process can do unbounded computation. If you model knowledge for actual finite minds instead of an oracle, maybe the contradiction never fires and the whole paradox is an artifact of the idealization.
