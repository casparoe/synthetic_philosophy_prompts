I'm on the design-systems team at a fintech and I keep going in circles about two practices in our own guidelines that seem to pull in opposite directions.

First one: when a fraud check or an identity lookup comes back in about 300ms, we hold the result and animate a "working" state for roughly a second and a half. The duration isn't arbitrary, it was tuned in user studies until reported trust and perceived thoroughness peaked. Nothing is happening during that time. Our own doc defends it as reflecting the effort involved, which is — well, it isn't really what it does.

Second: optimistic updates. You submit something small and the interface flips to the new state immediately, before the server has answered; if the request later fails we roll it back, and it fails rarely enough that noone notices. Here the display runs ahead of reality instead of lagging behind it.

Same team, same vocabulary of "perceived performance." A colleague said the pair only makes sense if you think the screen is a control surface for the user's experience rather than a picture of the machine's actual state — an interface, not a window — and then claimed that's more or less what some philosophers say about consciousness in general. I don't think those are the same claim and I'd like them pried apart.

So what does this combination presuppose about what a user's conscious experience of an interface is? Under what account of experience can you both stage work that never happened and assert a state that isn't yet true without either one counting as a lie? Say which rival accounts get ruled out — for instance the picture of users as little scientists forming calibrated beliefs from the evidence the system hands them. There's also a third thing living in the same component: a busy flag that assistive tech is meant to read, and that one is supposed to report honestly whether the region is genuinely still updating. Is that consistent with the fake second and a half, or does it mean we're running two different theories of the user at once?

Then separate what's strictly presupposed from what merely fits nicely. My worry is that one theory licenses both practices but also licenses a bunch of stuff we'd refuse outright, and I want to know where the refusal would have to come from if not from that theory. And if we swapped in the blunt version — the display never depicts anything, it only has to be useful — what would actually change in how we'd write these guidelines?
