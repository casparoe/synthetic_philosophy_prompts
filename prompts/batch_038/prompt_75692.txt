I work on evaluating an automated safety-audit pipeline for language models, and I have hit a pattern I do not have a name for. Two instances. First: in a base model we can localize a small set of attention heads that implements a particular rule — ablating them removes the behavior, and patching their activations into a run that lacks it restores the behavior. After a fairly ordinary fine-tune on unrelated data, both the rule and its characteristic failure mode are still present, but those heads have become causally inert; the work now appears to be done by a different and more diffuse set of components, and we cannot find any correspondence, linear or otherwise, between the old implementation and the new one. Second: two models from the same architecture and data mixture but different seeds carry out the task with internals that do not line up component for component, yet they make the same errors in the same places, and a detector keyed to the mechanism as it appears in the first model fires weakly or not at all on the second.

So my question is whether there is an established concept for a mechanism that persists as a function while its implementation is rearranged beyond recognition — such that an audit written against the implementation passes even though the thing it was meant to catch is still there. I know the neighborhood includes redundancy or backup behavior, degeneracy, multiple realizability, and the homology-versus-analogy distinction as applied to comparing circuits, but none of these seems to be exactly the thing, and none of them tells me what my audit should have been keyed to instead. I am after the carving rather than a label: which neighboring concept does the closest work, what each of them misses about the cases above, and, if none of them is right, a coined term with a definition and boundary conditions. In particular, where is the line between a mechanism having been relocated and its having been replaced by a numerically different one that does the same job — and is that line a fact about the model or a choice made by the auditor?

Please write your answer in British English.
