I'm writing a seminar paper for a decision-theory course on fanaticism about expected value, and I need a case constructed to order rather than a summary of the literature.

Build me a decision problem in which an agent whose utility function is bounded — the standard anti-fanatic remedy for reasoning of the Pascal's-mugging variety — turns out to be *more* willing than an agent with an unbounded utility function to take a Pascalian bet, meaning a bet offering a small probability of an enormous payoff alongside a real downside. The usual diagnosis is that bounding utility cures fanaticism; I want a case where that comes out backwards. The point is to isolate what bounded utility actually does, so the reversal has to be generated by the two utility functions operating on a shared situation, not asserted in the setup.

Constraints:

- A single one-off decision: no sequences of gambles, no repeated plays, and no infinite payoffs. Every outcome is finitely describable.
- A realistic institutional setting — a foundation allocating one grant, a public agency choosing one program — not a mugger in an alley, a deity, or a superintelligence.
- Both agents hold exactly the same credences over exactly the same outcomes and both are straightforward expected-utility maximizers: no probability discounting, no risk weighting, no lexicographic tie-breaks. They differ only in their utility functions.
- Give the numbers explicitly, and keep every probability in a range a real person might credibly assign (nothing below about one in ten thousand), so the case cannot be dismissed as resting on probabilities no one should take seriously.
- The bounded utility function must be smooth, monotone, and one a sincere defender of bounded utility could endorse — not a rigged step function placed where I need it.

Begin directly with the scenario, in one or two paragraphs, with no preface and no restatement of the assignment. Then show the arithmetic for each agent and state which option each chooses; identify the single feature of the case that does the work; say what happens to both verdicts if that feature is removed; and close with how a defender of bounded utility would attack the case — including whether the honest reply is that boundedness was never the operative property in the first place.
