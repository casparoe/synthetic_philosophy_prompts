Been chewing on this for my quals and I genuinely can't tell if it's a neat result or a wreck.

(1) If a property P of a belief is valuable only in virtue of making the belief more likely to be true, then in a case where the belief is already true, P contributes nothing further to its value. (Swamping: the value of a reliable coffee maker is already in the coffee.)
(2) Every distinctively epistemic property — justification, reliability, resting on good evidence, issuing from a properly functioning faculty — is valuable only in virtue of making belief more likely to be true. That's supposed to be what makes them *epistemic* rather than, say, aesthetic.
(3) So in any case of justified true belief, none of those properties adds value to the belief.
(4) So knowledge is worth no more than mere true belief, and any X you bolt onto JTB is swamped too, so long as X is itself truth-conducive. Fine — that's just the Meno problem, everybody knows it.
(5) Here's the part I can't shake. Run the same schema outside epistemology. Take any property of an action that's valuable only because it makes the action likelier to produce good outcomes — honesty, justice, a benevolent motive, respect for rights. Apply (1): in a case where the outcome was already good, the property adds nothing.
(6) So a morally worthy action is worth no more than an accidentally good one, and motive matters only as a reliable route to good results.
(7) Which is basically the consequentialist thesis about value, derived as a side-effect of an argument about the Meno.

I don't buy (7)'s pedigree for a second, but I also can't find where (1)–(6) actually breaks, and I don't want to give up (2), because without it "epistemic" stops picking anything out. So: which step do you reject, and what does rejecting it cost you — do you end up a value pluralist about belief, a holist about value, or something else? And then tell me whether the diagnosis transfers: if you kill the argument in the ethics run, why does the epistemology run survive, and if it dies in both, what's left of the value problem as a problem?
