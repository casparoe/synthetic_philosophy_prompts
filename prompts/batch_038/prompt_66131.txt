I'm TAing a grad seminar on the philosophy of AI risk and I need to grade the short-answer section of the midterm. The question was worth 10 points (5 for part a, 5 for part b), ~400 word limit, closed book — students weren't expected to name papers or give references, so dont dock them for that.

**Q3.** Proponents of "low-impact" agents claim we can build a system that avoids large, irreversible disruptions to its environment without first solving the problem of specifying human values. Recall the general schema: the agent maximizes its task reward minus an impact penalty, where the penalty measures how far the state produced by the agent's action deviates from a baseline state (the starting state, or the state that would have occured had the agent done nothing), and where deviation is cashed out in terms of something like the loss of reachability of other states, or the loss of the agent's ability to achieve some auxiliary goal.

(a) Explain how this schema is supposed to get you "avoid side effects" without a value specification.

(b) State what you take to be the strongest objection to that claim, and say whether you think it is fatal.

**Student's answer:**

(a) The trick is that the penalty is structural rather than evaluative. To know what the task is you need values, but to know what an action *changes* you only need a model of the environment's dynamics. Reachability is a fact about the state space: from the state I'm now in, which other states can I still get to? Compare that with what I could have reached from the baseline, and the difference measures how much of the world's future I've foreclosed. Nothing in that comparison mentions what anyone wants, so the designer only supplies a thin input — a baseline and a way of counting — while all the substantive normative content stays in the task reward, where it belongs. The constraint is a floor, not a target: it doesn't say what a good world looks like, only that the agent shouldn't burn down the possibility space on the way there. The auxiliary-goal version is honestly less clean, since there you do have to say which goal's attainability you're preserving, but the reachability version doesn't.

(b) The strongest objection is that the thin inputs aren't thin. You have to pick a baseline and the choice does real work: if the baseline is the starting state, then any irreversible process that happens on its own — a human eating lunch, a species going extinct — shows up as reachability the agent is charged for losing, so it gets an incentive to freeze the world, and the fix is to grade the loss finely instead of treating reachability as all-or-nothing. Second, unweighted counting charges the agent the same for rearranging a pile of sand as for the death of the people who owned it, which is absurd, and the only way to get the weights right is a value function. At that point the impact measure already contains the specification it was supposed to let you avoid, so the middle position collapses: either you have human values nailed down or your penalty is arbitrary, and there's nothing in between.

One thing in the measure's favor, though. The penalty is a cost charged to the agent, not a harm done to it, so a low-impact agent has no stake in its own continuation. Being switched off would just show up as one more impact, already priced in, so it won't defend its own existence the way a naive utility maximizer does. Impact measures therefore get us corrigibility for free, which matters more than the weighting problem suggests.
