> **(b)** Hofstadter says that solving this puzzle requires "jumping out of the system." Explain what that means and how your argument in (a) illustrates it. *(6 points)*

and here's the student's answer:

> **(a)** The rules are: (1) if a string ends in I, you may tack a U on the end; (2) if a string has the form Mx, you may replace it with Mxx, i.e. double everything that follows the M; (3) anywhere that three I's occur in a row you may replace III with U; (4) anywhere that two U's occur in a row you may delete them. MI is the axiom.
>
> MU is not derivable. Trying it by hand just makes the point: MI → MII → MIIII → MUI → MUIU, and you can keep going, but every time rule 2 fires the string gets longer and you never seem to be any closer, and since rule 2 can always be applied again there's no largest string you could check, so you could search forever without settling it. So instead of searching, look at the number of I's in a string. Call it n. Rule 1 adds a U and leaves n alone. Rule 2 doubles n. Rule 3 replaces III with U, so it drops n by 3 (and can only fire when n ≥ 3). Rule 4 deletes UU and leaves n alone. So the only ways n can change are doubling and subtracting 3. We start with n = 1. Doubling a number that isn't a multiple of 3 gives a number that isn't a multiple of 3, and subtracting 3 from a number that isn't a multiple of 3 gives another one that isn't, so by induction on the length of the derivation n is never a multiple of 3. MU has n = 0, and 0 is a multiple of 3. So MU can't be reached from MI. ∎
>
> **(b)** Hofstadter distinguishes a mechanical mode, where you just apply rules blindly and generate strings, from an intelligent mode, where you step back and think about what the system is doing as a whole. Jumping out of the system means going to that second mode: you stop manipulating strings inside MIU and start reasoning about MIU from the outside, treating its strings and derivations as objects to be studied. The proof in (a) is exactly this, because nothing inside the system produces a non-theorem — derivations can only ever yield theorems, so no amount of rule-applying could show that MU isn't reachable. And I think the reason it has to be done from outside is that the argument is an induction on the length of derivations, and MIU has no induction principle at all, whereas a system rich enough to have one could carry it out internally.
>
> **(c)** Yes, I'd say it's a miniature version of Gödel's first incompleteness theorem. "MU is not a theorem of MIU" is a true statement that the system itself cannot prove, which is the same shape as Gödel's sentence. And the lesson generalizes: any formal system will have true things it can't establish from the inside, and the only way to get at them is to jump out to a bigger system, which then has its own unprovable truths. This is why Hofstadter thinks the mind can't be a formal system — jumping out isn't something a rule-following machine can do, since a machine is stuck inside whatever system it's running, and the mod-3 argument is the kind of insight that has to come from somewhere else.
