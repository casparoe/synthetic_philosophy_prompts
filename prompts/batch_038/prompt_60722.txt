You are helping me grade for an upper-level course on metaphysics. Below is a 30-minute, closed-book short-answer question worth 20 points, followed by one student's response, reproduced as submitted.

**Question.** State the Principle of the Identity of Indiscernibles and distinguish it from the indiscernibility of identicals. Then explain how Max Black's two-sphere thought experiment is meant to undermine the former, and assess one line of response available to a defender of the principle.

**Student's response.**

The Principle of the Identity of Indiscernibles (PII) says that if x and y have all their properties in common, then x is identical to y; equivalently, two things can be numerically distinct only if there is some property one has and the other lacks. This is not the same as the indiscernibility of identicals, which says that if x is identical to y, then whatever is true of x is true of y. The second is normally treated as a logical truth about identity, whereas PII is a substantive metaphysical thesis, though Leibniz held both, and together they would make numerical identity amount to complete qualitative similarity.

Note that if the discerning properties are allowed to include ones that mention individuals by name, or the identity relation itself, PII becomes trivial: being identical with a belongs to a and to nothing else. So the interesting version is the strong one, which restricts attention to purely qualitative properties, meaning properties whose specification doesn't smuggle in a reference to any particular thing.

Black's example targets that strong version. He asks us to imagine a universe containing nothing except two exactly similar spheres, say of iron, in an otherwise empty and perfectly symmetric space: same size, same shape, same colour, same temperature, same mass, and the same relations to everything else, since the only other thing there is the other sphere. Clearly there are two spheres and not one, since nothing in the description collapses them, yet no purely qualitative property distinguishes them. And because PII is supposed to hold necessarily, a merely possible case of this kind would be enough to refute it; it is no objection that we could never verify whether the actual universe is like that.

The most common response is that Black's spheres are after all qualitatively different, because each stands in relations the other does not. One of them is to the left of the other, and each occupies a different place in space, so there is a property, being to the left of an iron sphere, that only one of the two has. I think this response succeeds, and it shows that Black has not really given us a counterexample but only a description that conceals a difference we have overlooked.

A more concessive response appeals to primitive thisness: each sphere has the property of being that very sphere, which is not analyzable in qualitative terms, and this is what makes them two rather than one. On this view the spheres do differ in a property after all, so PII is preserved; we need only concede that some properties are non-qualitative.
