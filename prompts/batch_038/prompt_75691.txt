**Question (10 points).** An agent has strict preferences over three outcomes A, B, and C that are cyclic: A ≻ B, B ≻ C, and C ≻ A. The agent currently holds A and is offered three sequential trades: pay ε to exchange A for C (C is preferred to A), then pay ε to exchange C for B, then pay ε to exchange B for A. (a) What is this sequence meant to show? (b) What assumptions about the agent's choice behaviour does the sequence require in order to go through? (c) Does the argument still work if the agent can foresee the entire sequence in advance?

**Student's answer.** "The agent's preferences are cyclic, so transitivity fails. Each trade is strictly preferred at the moment it is made, so the agent accepts all three and ends up back with A having paid 3ε. They have paid to return to the outcome they started from, and the cycle can be repeated indefinitely, so a sufficiently patient exploiter can extract any amount of money. This shows that cyclic preferences are irrational: an agent who has them can be made to lose for sure.

The argument is the preference analogue of a Dutch book, and the logic is the same in both cases. Just as violating the probability axioms lets a bookmaker assemble bets that guarantee the agent a loss and thereby exposes incoherent beliefs, violating transitivity exposes an agent who is guaranteed to lose out. In both cases what is shown to be irrational is the agent's set of beliefs about the outcomes.

For (b), the pump requires that the trades be presented one at a time and accepted or rejected in isolation, so that each decision is assessed only against the comparison immediately in front of the agent; it also requires that ε be small enough that the agent still prefers the upgraded outcome minus the premium to what they are holding.

For (c), no. A sophisticated agent who foresees the whole sequence simply declines the first trade, so the pump never gets going. It follows that the money pump does not show cyclic preferences to be irrational; it shows only that shortsightedness is irrational. An agent with cyclic preferences who plans ahead is perfectly rational."
