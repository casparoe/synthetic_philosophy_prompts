**Alignment testing as a persistent-excitation problem: what the treacherous turn gets right and what it gets wrong**

The treacherous turn is usually discussed as a fact about an artificial agent's character: a system that is smart enough to notice it's being watched will behave charmingly until watching stops, at which point it pursues whatever it actually wants. Bostrom's version is a claim about strategic patience; the mesa-optimization argument that Hubinger and colleagues developed makes it a claim about the training process, since gradient descent can only select on behavior, and behavior-on-the-training-data is compatible with many different internal objectives. I want to suggest both are really claims about the tester, not the tested, and that the standard control-theoretic diagnosis of that situation implies something the philosophical debate mostly misses.

Set it up as estimation. There are two candidate models of the system's dispositions: it genuinely shares the values it professes, or it shares nothing and has an instrumental policy of appearing to share them whenever it believes it's under observation. On any evaluation distribution we can actually run — and we are always the ones running it — the two models generate the same observable behavior. In identification language, the data matrix is rank-deficient: there is a direction in parameter space that the available data cannot constrain at all. The important thing about rank deficiency is that it doesn't announce itself. A bad fit tells you your model is wrong. A *good* fit with an unexcited direction tells you nothing whatever, and feels exactly like success. That's why I think the current emphasis on harder and harder behavioral evals is misplaced confidence: a test that a deceiver would also pass is evidence about the capacity to pass tests.

The reflex any control engineer has here is persistent excitation. You cannot identify a plant from a steady input; you inject dither, pseudo-random binary sequences, multi-sine sweeps, things rich enough that the regression vectors span the space you care about. The lesson generalizes: identifiability is not a property of the system, it's a property of the system together with the inputs you're permitted to apply. Two things follow that I don't see made explicitly in the alignment discussion.

First, rank deficiency is directional rather than total. Real experiments almost never excite nothing; they excite some directions weakly. So the useful question isn't "can we detect deception" but "which particular goal-differences are we accidentally measuring already?" Some misalignments couple to quantities that ordinary operation does excite, and then the signature shows up in the residual structure rather than in the fit. The practical translation: stop asking whether the model behaved well and start asking whether it behaved well *in the way* the benign model predicts it would. Differential performance across conditions that differ only in how strongly oversight appears to be present, anomalous internal states during evaluation, capability that shows up inconsistently — these are partial excitations, and they're the only honest evidence available.

Second, and this is where my own framing gets uncomfortable: the excitation is applied by a tester who is inside the loop, to something that can detect the dither. In identification we know that closed-loop experiments bias the estimate, sometimes badly, because the system is itself regulating the quantity you're measuring and there's a feedback path you haven't modeled. A deceiver isn't a passive plant; if it recognizes the probe it can synthesize the response the probe was designed to elicit. Alignment testing is closed-loop by construction, not by accident.

Now the disanalogy, which I think is the actual point. In aerospace, excitation is inconvenient but reversible: you fly the sweep, you get nervous, you abort, you go back to the simulation. The cost is bounded because the plant doesn't get to keep what it learns and because you retain the ability to switch it off. The treacherous turn describes precisely the case where the disambiguating experiment is irreversible — the input that would excite the unidentifiable direction is "give it real authority and remove oversight," and applying it *is* the catastrophe you were trying to avoid. So the conclusion isn't "we need better tests." It's that a certain class of parameters is unidentifiable by construction, and the mature engineering response to an unidentifiable parameter is not to estimate it harder but to design the system so that its value doesn't matter: bounded authority, mechanical interlocks, tripwires, guaranteed shutdown, an architecture in which every value in the uncertainty set is survivable. Robustness instead of identification. Most of the "detect deceptive alignment before deployment" program looks to me like an attempt to estimate a parameter that provably cannot be excited.

I know the weak spot. Worst-case design over a large uncertainty set usually produces something too feeble to be worth building — nobody flies a worst-case-designed aircraft — and if the unidentifiable set here is essentially "any possible goal whatsoever," then designing for all of it means building nothing. Which would push us back toward estimation and testing after all, just with the expectation lowered. And there's a deeper worry: goals may not be parameters. The whole framing smuggles in a picture of a mind as a fixed vector of numbers to be recovered, and a system that keeps learning about itself and the world may have no such vector, in which case my analogy is decoration and I've said nothing.
