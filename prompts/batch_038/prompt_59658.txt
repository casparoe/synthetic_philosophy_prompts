A lab's ethics board is deciding whether to execute a program that one of its researchers wrote out in full but never ran: on the lab's own functional criteria, executing it would instantiate a mind capable of suffering. Two board members disagree about the moral status of computations that are fully specified but never instantiated. The first holds that instantiation is what creates the subject — until the program is physically run, there is no one to be harmed, so execution would bring new suffering into the world and declining to run it is the only safe course. The second holds that every coherent computation is equally real, its subjects existing whether or not anyone runs them, so execution cannot add a victim; what execution changes is only whether anyone is positioned to intervene in that subject's condition.

Write a dialogue between them about whether the program should be run. Let each press the consequences distinctive to their own view: the modal realist should be made to answer why a duty to relieve the suffering of an uninstantiated computation does not amount to manufacturing sufferers in order to rescue them, and why any duty attaches to the computations one happens to have written down rather than being swamped by the indefinitely many one could never specify or affect; the instantiation theorist should be made to answer how their view can say anything determinate about which physical processes count as executions of the program at all, given how promiscuous implementation relations are known to be. Both are equally well informed and neither is a strawman: each should engage the other's strongest formulation of a point rather than restate their own position.
