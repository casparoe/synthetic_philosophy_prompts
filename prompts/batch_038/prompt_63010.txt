I teach an upper-level seminar on formal systems and self-reference, mostly GEB-flavoured, and I need one exam question on the MU-puzzle. Trouble is everyone has read the chapter and half of them have read a blog post that spells out the mod-3 trick, so anything I set on the original MIU system gets answered from memory. I want to break that by using two one-rule variants where the change looks equally trivial but only one of them actually destroys the usual impossibility argument — and obviously the question shouldn't tip off which is which.

Setup I want handed to the students: same alphabet {M, I, U}, same axiom MI, same rules I, II and IV as normal (append a U to a string that ends in M; double everything after the initial M; delete any adjacent pair of U's), but rule III is replaced. In system A, any run of four I's may be replaced by a single U. In system B, any run of three I's may be replaced by two U's. For each system the question asks whether MU is derivable from MI, and demands a proof either way — an explicit derivation if the answer is yes, and an argument that covers all possible derivations, not just the short ones, if it's no.

I also want a third part built around this line from last year's script, which you should quote to the students as an anonymous excerpt and ask them to evaluate: "Since the rule that turns I's into U's has been changed in both systems, the old argument that the number of I's is never a multiple of three can't be used in either of them." That student was strong everywhere else and bombed this question, and I want the wording to make clear that being half right about that sentence isn't worth much on its own.

Then the last part should ask what the contrast between A and B shows about the difference between deriving strings inside a system and reasoning about the system from outside — but write it so that defining JOOTSing or name-checking Hofstadter earns nothing. Marks only for pointing at the specific step in each proof where the argument has left the system, and saying what licenses that step.

Deliverables: (1) the question exactly as students would see it, marks per part totalling 25, with a stated 50-minute allocation; (2) a model answer of roughly 800 words that does the work — for the negative case I want a genuine induction over derivation length rather than an assertion that the invariant is preserved, and for the positive case a line-by-line derivation naming the rule used at each line; (3) a marking scheme, seperate from the model answer, that names the concrete mistakes that cost marks. Things I'd expect in there: claiming an invariant survives a rule change without checking every rule against it, producing a derivation that silently uses the original three-I's-to-one-U rule, proving only that MU isn't reachable within some small number of steps, and writing the outside-the-system discussion as a general homily about mechanism and minds. For each, say what it costs and what the student would have to add to win those marks back. No reading list, no citations.
