Consider a one-shot prisoner's dilemma in which each player submits a program rather than a move, and each program can read the opponent's source code before deciding — the framework known as program equilibrium. I would like five jokes set entirely within that framework, where the humor depends on knowing how the framework actually behaves: programs that cooperate only after proving the other will cooperate, proofs that stall because neither program can settle the matter first, the diagonalizing program that refuses to be predicted, the fact that such programs exist at all because a fixed-point construction guarantees them, and the question of what a program of this kind is supposed to do about an opponent whose code it cannot read.

Please meet the following requirements. First, each joke must consist of a setup and a punchline occupying one or two sentences, and no joke may depend on the reader's familiarity with any particular author, paper title, or publication date. Second, no two jokes may share the same device; generic jokes about formal systems, self-reference, or undecidability that would survive being relabeled with some other framework do not count. Third, output exactly five numbered items, each containing a joke plus, where needed, a single clause naming what the joke turns on; write no introduction and no conclusion. Fourth, in American English, add to any item a brief flag wherever the joke takes a liberty with the mechanics, and be careful not to represent as settled among people who work on this material anything that is genuinely contested there — for instance, how robustly cooperation of this kind survives changes to the proof system, or how it should be compared with other approaches to transparent opponents.
