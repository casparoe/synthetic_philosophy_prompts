I've spent a year going in circles with a collaborator over a toy agent whose only channel to the world is an instrument that emits not a reading but a probability vector over a fixed partition — a classifier's softmax output, say. My position: the rational response is Jeffrey conditionalization, shifting credences across that partition to the reported numbers while holding conditional credences rigid. Hers: the only coherent option is ordinary conditionalization on the single proposition the agent is actually certain of — that the instrument emitted this vector — with all unreliability absorbed into the model's likelihoods. I suspect we are talking past each other about what counts as evidence and about how much idealization an agent's model is allowed to contain.

Draft the joint statement an adversarial collaboration between us ought to produce: a numbered list of claims both sides can sign; a table of the residual disagreements, each stated in wording its own side would accept; then the cruxes — the sub-questions whose settlement would move at least one of us — with, for each, the argument or case both sides agree bears on it and each side's prediction recorded in advance. I expect one crux to be whether adopting the instrument's vector double-counts the confidence already built into it, and another to be where the new partition probabilities come from if not from a model of the instrument. If some portion of the dispute turns out to be merely verbal, identify that portion and say why. Hard cap: 700 words, table included.
