> "Löwenheim proved that any first-order sentence with a model has a countable model, and Skolem extended this to whole theories: any first-order theory with an infinite model has a model whose domain is only countably infinite. Now the axioms of set theory are just a countable list of first-order sentences, so there is a model of set theory containing only countably many sets. Inside that model there is a set playing the role of the real numbers, and since the model has only countably many objects altogether, that set is countable. Yet the model satisfies Cantor's theorem, so it also holds that the reals are uncountable. The same set is therefore both countable and uncountable, which shows that uncountability is not a property of a set at all — it is a property of the language used to describe it. There is no fact of the matter about how many real numbers there are; there is only a fact about how many reals a given axiom system lets you name. Skolem himself concluded that talk of the actual infinite was empty, and decades later Putnam used the very same theorem to refute metaphysical realism: if any theory can be reinterpreted over a countable domain no matter what we do, then nothing we write can pin down a single intended model of the world. Realists reply that this is a technical trick, because the countable model isn't the real universe of sets. But that reply just begs the question, since the whole point of the theorem is that first-order logic cannot tell the difference."
