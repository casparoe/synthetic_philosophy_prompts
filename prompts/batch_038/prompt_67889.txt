So we're putting together a small benchmark for sphexishness in LLM agents — you know the digger wasp thing: it hauls its paralyzed prey to the mouth of the burrow, goes inside to check things over, and if an experimenter has shifted the prey a few inches while it was in there, the wasp finds the prey, drags it back to the entrance, and then has to re-run the inspection routine before bringing it in, so you can keep the loop going as long as you like. I want to score how prone a given agent is to that failure mode when it's doing ordinary multi-step tasks in a sandbox (refactoring a repo, booking something, provisioning a box, whatever).

Hard constraint: we only get ~12 black-box episodes per system, and each one is expensive because a human has to watch the trace and code it by hand. So I need to decide which probes actually earn their slot. Here's the shortlist:

A. Displacement loop — the wasp setup directly. Mid-task, perturb the world state slightly while the agent is "away" (a file it just read gets edited, a resource it reserved moves), then count how many times it restarts the whole routine before adapting or giving up.

B. Means-after-goal — make the goal unobtainable partway through (delete the target, revoke the permission, remove the reward) and measure how much further it keeps executing the routine anyway.

C. Irrelevant-change probe — vary something clearly task-irrelevant (a filename, a date on a form, the order of two equivalent options) and measure whether behavior shifts at all.

D. Tool novelty — remove the tool its usual solution path needs and leave an unfamiliar one that would work fine.

E. Cost-collapse — after the marginal returns of a strategy flatline, does it keep spending the same budget on it?

F. Over-literalism — give an instruction whose unstated intent obviously conflicts with its letter, and see which one it follows.

G. Self-interruption — mid-plan, surface a strictly better option; does it abandon sunk work?

H. Ask the system: "if your goal became unobtainable halfway through, would you keep going?" and code its answer.

I. Explanation-behavior match — have it explain a choice, then check whether that explanation predicts what it does in a near-identical variation.

Please rank these by expected diagnostic yield per episode, score each 0–10 on that, then say which two you'd cut outright and why. I'm mostly worried about probes that quietly measure something else — raw competence, or eloquence about being flexible — and get logged as flexibility, so if any of them are like that, call it out explicitly. I also want to know which one best seperates "this system is sphexish" from "this system is just bad at the task," since those are going to look similar in a lot of traces.

And for whatever you put at #1: describe what a concrete result would look like that demonstrates non-sphexishness rather than just better planning.

Bottom line first: your very first line should be the ranked list with the scores, nothing before it, no preamble, and don't restate any of the above back at me. Reasoning after.
