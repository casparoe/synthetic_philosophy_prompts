running a reading group on commitment devices and program equilibrium, and last week we did safe Pareto improvements — the next session starts with a poem and I want to hand you the job. 16 to 20 lines, a pantoum (or as close to one as you can get), titled something that isn't a pun on chicken.

Here's the setup as I've been explaining it to the group, so you don't have to know the literature to write this: two principals are stuck in a mixed-motive game where the Pareto-efficient outcomes are all fine but they can't agree on which one they'll land in, so the default play is the bad one. Neither has any real belief about how the other will actually behave. So each hands the game to a delegate — a program the other side can inspect — and the delegate is told: cooperate if you can verify the other delegate was given the same instructions, and if you can't verify it, just do exactly what your principal would have done by default. Mutual verification gets both of them off the bad equilibrium; the fallback clause is what makes signing safe, since being unable to read the other side's code costs you nothing you wouldn't have paid anyway. That distinction — safety as a fallback branch, not as a hope — is the whole point, and I want the poem to hold onto it rather than sliding back into a generic "two prisoners learn to trust each other" thing.

The form should carry the argument. The pantoum's returning lines are the delegates quoting each other's source: a promise that gets said in one stanza comes back as the premise of the next, which is exactly how the condition gets discharged instead of hanging there. Somewhere in there I want the vertigo of the regress — I cooperate only if you cooperate, you cooperate only if I cooperate, and nobody ever moves first — and then the turn where the code being on the table is what breaks it, because a condition you can read is a condition you can settle rather than wish for.

Two hard constraints. First, break the pantoum's rule at the very end: the closing circle where the first stanza's third line comes back as the last line should fail, and that last line should be new, unrepeated, belonging to no one else — the fallback branch, where the quoting stops and the agent plays its own strategy. A reader who knows the form should feel that as a drop. Second, keep the payoff numbers out and the jargon thin; I don't mind default, delegate, verify, renogotiation, but no lecture. Slant rhyme is welcome, doggerel is not.

Send me the poem and then one line telling me which stanza carries the regress and which one carries the fallback — if the form is doing its job I should be able to guess both without the note.
