I'm a third-year grad student nominally in philosophy of biology, but my funding is attached to a synthetic biology group, so I sit in on their lab meetings and help with their outreach copy. Our PI opens basically every grant talk with some version of 'DNA is just software' — we write genomes the way programmers write code, same deal, different alphabet. Last week a visiting philosopher asked him whether he meant that literally, and he waved it off with 'the genetic code is literally called a code, open any textbook,' which is true and also completely fails to answer her. I mumbled something and moved on, and I've been annoyed about it ever since, because I think there are like four or five totally different claims packed into that one sentence and he was sliding between them.

Some context that I think cuts in weird directions. The group works on codon reassignment — building strains whose code differs from the standard table so they can't swap genes with wild bacteria, the genetic firewall idea — and there's that synthetic E. coli strain from a few years back where they rewrote the genome to use fewer codons. My PI says that work *proves* DNA is software, since you can rewrite the sequence and the organism runs a different program. But a couple of us think the firewall strains point the other way: change the intepreter and the same string of bases comes out meaning something else, which feels more like dialects of a language than versions of a program. And separately, the standard table isn't even universal — mitochondria and some ciliates reassign codons, and stop codons get reassigned in various lineages — which I genuinely dont know whether it helps or hurts the software story.

So: can you lay out the distinct precise claims that 'DNA is a code' could be making, from the ones that are just uncontroversial biochemistry up through the ones that are real philosophical bets? I want exactly five numbered items, a sentence or two each, with no introduction and no conclusion — each item names one reading, tags it as a platitude / a live contested question / just false, and says whether it actually supports the way my PI uses it, i.e. whether it licenses both 'we write DNA like programmers write code' and 'asking whether that's literal isn't a real question.' Please be explicit about which parts are settled and which are genuinely disputed among people who work on this, and don't sell me a contested view as the consensus — I'm going to be quoting this back at lab meeting, so I need to know where the ground is soft.
