I'm grading take-homes for an upper-level AI safety course and could use a second pair of eyes on one of them. Here's the question and the student's response.

**Question (25 points).** Suppose an agent picks its action by searching for theorems of the form "if I take action A, the resulting outcome has value at least v." State precisely what such an agent would have to establish about its own proof system in order for that procedure to be trustworthy, use Löb's theorem to explain why it can't establish that, and then evaluate the proposal that the problem goes away if the agent's decision procedure lives in some system S while all reasoning *about* S is done in a strictly stronger meta-system M.

**Student's answer.** "The agent has to be sure its proof system is reliable: whatever it can prove about the consequences of its candidate actions has to actually be true. Call this soundness — for every sentence p, if the system proves p then p. Löb's theorem says a consistent system that proves its own soundness proves everything, so any system strong enough to do arithmetic can't prove its own soundness without collapsing. (Gödel's second incompleteness theorem is just the same result with p replaced by any sentence the system can already prove.) And since the agent reasons about its own decision procedure with the same system it uses to reason about the world, it can never prove that its self-model is accurate. So there's a hard limit on how much an agent can know about what it's going to do, sort of like the halting problem.

On the second part, the meta-system proposal works. S doesn't have to prove anything about S; M does that, and M is stronger than S, so M can prove S's soundness without having to prove its own. S just carries out whatever action M's proofs recommend. The obstacle only bites when a system reasons about itself, and here the reasoning about S sits entirely outside S, so there's no self-reference left to exploit. Honestly I think people worry about the Löbian obstacle more than it deserves."
