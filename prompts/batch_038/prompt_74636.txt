Our game theory reading group was working through program equilibrium — Tennenholtz's setup where each player in a one-shot prisoner's dilemma submits a program that receives the opponent's source code as input and then outputs C or D. Two people got into a genuine argument and I honestly couldn't tell who was landing the punches.

(1) Ana said the old line that cooperation needs the shadow of the future is dead. Two FairBots — each cooperates iff it can prove the other one would cooperate with it — both cooperate by Löb's theorem, and neither gains by deviating, since a DefectBot can't be proven to cooperate and so you just fall back to mutual defection. Cooperation in a one-shot PD, no iteration, no reputation.

(2) Ben said she hasn't dissolved anything, she's assumed it away. Real cooperation problems are hard precisely because nobody gets to read your source code before committing. Grant full transparency and you've definately defined the problem out of existence.

(3) Ana said transparency is an idealization like common knowledge of rationality — what matters is whether the result survives weakening it, and it does: there are simulation-based bots that cooperate with small probability ε and otherwise just copy what the opponent's program outputs, which terminate almost surely and are still equilibria. So it isn't resting on logical omniscience.

(4) Ben said fine, but beside the point, because DefectBot vs DefectBot is still an equilibrium too. The folk theorem here says a payoff pair is achievable iff it's feasible and individually rational, which is exactly the repeated-game condition. So program equilibrium hands you a bigger equilibrium set and zero selection — all Ana showed is that the same old multiplicity got relocated.

(5) Ana said selection was never the claim; the claim is that the achievable set of a one-shot game now matches the repeated game's, and that's the substantive content.
