I've become convinced by updateless decision theory: the view that a rational agent should select its entire policy once, from its prior, rather than choosing act by act after conditionalizing on the evidence it has gathered. My reasons are the familiar ones — cases where the payoff turns on what the agent would have decided before it learned which situation it was in, and the worry that an agent who updates freely ends up dynamically inconsistent, undermining at later stages the plans its earlier self would have preferred to bind itself to.

Map out what would count against this. I want the exposure, sorted by how decisive each item would be: which arguments, results, or problem cases would be fatal, which would be merely embarrassing, and which a committed defender should simply absorb. Specifically assess three lines, and add any others you think matter more.

First: if an agent can build binding commitment devices, doesn't it already get everything updatelessness promises, leaving updatelessness with no independent work to do — and if so, what is left of the view for agents who cannot precommit? Second: the suspicion that once an agent is allowed uncertainty about its own source code and about whether it is the agent in the problem, updateless recommendations collapse into causal decision theory operating on a peculiar prior, which would make the position a notational variant rather than a rival. Third: whether there are problems where updateless reasoning yields a clearly unacceptable verdict and no rival does — and, conversely, what updateless agents predictably do that updateful agents predictably fail to do, so the dispute has some behavioral content at all.

I also want an honest read on insulation. A defender can often dissolve a counterexample by adjusting the prior over which decision problem the agent is in. Is the framework now unkillable? If so, is that a defect in a normative theory the way it would be in an empirical one, or is the demand misplaced? Give me a definite verdict on that rather than a hedge, and say where you think defenders are right to dismiss objections and where they are rationalizing.

If you think I've misstated the position, or that demanding falsification-style defeaters from a framework of this kind is the wrong question to ask, say so plainly instead of answering the version you'd prefer.
