**Question 3.** Recall the Pasadena game: a fair coin is tossed until it lands heads for the first time. If heads first lands on toss n, the payoff is (−1)^(n+1) × 100 × 2^n / n dollars. So the player receives +$200 for heads on the first toss, −$200 for heads on the second, +$266.67 for heads on the third, −$400 for the fourth, +$640 for the fifth, and so on; the probability of the payoff attached to toss n is 1/2^n. The Altadena game is identical except that the payoff for heads on the first toss is $202 rather than $200.

(a) [4 marks] Write out the series whose sum would be the expected value of the Pasadena game, and say what it would sum to if that sum were legitimate.

(b) [6 marks] Explain precisely why the standard notion of expected value does not apply to this game. Your explanation should make clear how the Pasadena game's predicament differs from the St. Petersburg game's.

(c) [6 marks] The Altadena game dominates the Pasadena game: it is at least as good in every possible outcome and strictly better in one. Explain what trouble this creates, and assess the following line of response: the games do have values after all, since the description of the game fixes an order in which to add the terms.

(d) [4 marks] Evaluate one proposed way of saving expected-value reasoning from this family of cases.

And here is the answer I have to mark. I've copied it out in full, paragraph labels mine.

---

(a) Multiplying each payoff by its probability gives 100, −50, +100/3, −25, +20, −100/6, ... which is 100 × (1 − 1/2 + 1/3 − 1/4 + 1/5 − ...), the alternating harmonic series scaled by 100. That series sums to ln 2, so the expected value would be 100 ln 2, about $69.31.

(b) An expectation is only defined when the probability-weighted values can be summed in a way that doesn't depend on how you do the summing, which in practice means the series has to converge absolutely. It doesn't here. Add up only the positive terms and you get 100(1 + 1/3 + 1/5 + ...), which is the harmonic series in disguise and diverges; the negative terms diverge the same way. So the expectation is infinity minus infinity, which is no number at all. In that respect the Pasadena game is just like the St. Petersburg game: its expected value is infinite, only the infinity isn't all of one sign, which is why the textbook says undefined rather than infinite. The deeper problem is Riemann's rearrangement theorem. A conditionally convergent series can be rearranged to converge to any real number you like, or to diverge to plus or minus infinity. Since the value comes out different depending on the order in which the outcomes are listed, and nothing in the description of a coin game privileges one listing over another, there is simply no fact of the matter about what the Pasadena game is worth.

(c) The Altadena game changes the first payoff from $200 to $202, so the first term of the series goes from 100 to 101 and the series becomes 101 − 50 + 100/3 − 25 + ..., which sums to 100 ln 2 + 1, about $70.31. That's a dollar better than Pasadena, as it should be, since Altadena is Pasadena plus a dollar on one branch. And this is how the theory should handle the case: the coin game itself tells you the order in which the terms arise, toss 1 then toss 2 then toss 3, and if you respect that order you get a definite number for each game and a definite ranking between them. So the paradox is less threatening than it looks. The worry Nover and Hájek are pressing is really a worry about the sure-thing principle, which is what forbids you from ranking a dominating option below a dominated one, and once you see that the sums exist in the natural order the principle is satisfied again.

(d) The most common response is Bernoulli's: stop valuing money linearly, use a bounded utility function, and the runaway payoffs get capped so the sum converges. That response is aimed at the wrong target here. The Pasadena payoffs are not what's causing the trouble, because the terms of the series shrink towards zero (100, 50, 33.33, 25, 20 ...), and a series whose terms shrink to zero converges. Bounding utility repairs the St. Petersburg game, but in Pasadena there is nothing for it to repair, so this response can't be the way out. A more promising line is to deny that anyone ever actually faces a Pasadena game. Any real bookmaker caps the stake, and a capped game has only finitely many nonzero terms, so its expectation is unproblematic. One thing worth noting against all quick-fix approximations: you can't just truncate the series at some large n and report that number, because the partial sums swing above and below $69.31 rather than settling down from one side, so a truncation tells you the value only up to a slack that shrinks very slowly.
