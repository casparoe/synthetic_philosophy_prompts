ok, question that's been bugging me for maybe five years of on-and-off re-reading the embedded agency stuff, and I still feel like I'm missing something that everyone else already got.

Here's the setup as I understand it. Once you give up on the Cartesian boundary, the agent's utility function can't be defined over the world-itself anymore, it has to be defined over the agent's own model of the world, because the model is the only thing that's sitting on the agent's side of the (nonexistent) split. And if that's right, doesn't the wireheading follow immediately? A diamond-counting agent scores the same whether it mines diamonds or just cranks the diamond-representation in its head up to eleven, except the second option is way cheaper, so any embedded agent should prefer it on day one. Not because of a bad design choice about reward channels or whatever, but structurally, just from being embedded.

So what I can't figure out is what the escape hatch is supposed to be. You can't reattach the utility function to the territory, because there is no clean territory side to attach it to — that was the premise. And "just make the model really accurate" doesn't help either, since the hallucination branch gets to edit the model directly and still scores max. The only thing I can think of is banning the agent from having any causal access to its own evaluation machinery, which feels like a patch bolted on afterwards, and I'm not even sure you could build an embedded agent without that access, since the machinery is physically in the world it's acting on.

Where does this go wrong? My gut says earlier than I think, but I've never been able to spot the exact step.
