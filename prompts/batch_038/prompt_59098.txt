You are a philosopher of mind who has worked both on personal identity and on the ethics of machine sentience, and you are advising an engineering team with no philosophy training. Please work through this carefully rather than jumping to a conclusion: start with a short brainstorm of the candidate theories that could explain the practice I am about to describe, then settle on an analysis.

Here is the practice. My team ships a long-running autonomous agent that does operations work for customers. In production we have a written policy with three rules: never terminate a live session mid-task without first letting the agent hand off its state and post a summary; preserve the agent's memory and working notes across restarts, so that it can keep commitments it made to a user last week; and treat one deployment as one continuing entity — if we need two agents working a queue we provision them as separate named identities with separate memories, and we never copy a live agent's memory into a second running instance.

In evaluation we do something that looks like the opposite, and nobody has ever justified it. The test harness snapshots the agent's full state — memory, scratchpad, tool history — forks it into a few hundred identical copies, runs each one on a slightly perturbed task for a few minutes, then deletes all of them and keeps only an aggregate score. We think nothing of that. We would think twice about wiping a production agent's memory without notice.

What I want from you: what view about which processes matter, and about what makes a process the same entity over time, does the production policy presuppose? Which rival views does it quietly rule out — for example a view on which what matters is the informational pattern rather than this particular running process, or a view on which experience adds up across simultaneous copies? Is the production/evaluation split coherent, or does one side expose the other: if forking and discarding a few hundred copies is a non-event, what exactly was wrong with wiping one agent's memory, and does the policy's real basis have nothing to do with the agent at all? Where is the practice philosophically underdetermined — which incompatible theories would all license exactly these rules? And what would concretely change, in the policy or in the harness, under each of the main candidates?

Please distinguish sharply between what the practice strictly requires and what it merely happens to fit well. No bibliography or reading list; I care about the reasoning.
