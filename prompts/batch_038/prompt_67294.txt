Here's the argument I want to build the hour around, roughly as I remember it. Pick A and C such that P(A∧C) and P(A∧¬C) are both nonzero. Suppose the equation holds for every probability function in the family, including the ones you get by conditioning. Condition on C: in the new function P'(·) = P(·|C), C has probability 1, so P'(C|A) = 1, so P'(A→C) = 1, which is to say P((A→C)|C) = 1. Do the same thing conditioning on ¬C and you get P((A→C)|¬C) = 0. Now apply the partition rule and P(A→C) = P(C). The antecedent has dropped out entirely: the conditional has the same probability as its consequent no matter what A is.
