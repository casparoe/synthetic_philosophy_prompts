The question was: "Explain the accuracy-dominance argument for Probabilism. In particular: (i) what work is done by the assumption that the inaccuracy of a whole credence function is the sum of the inaccuracies of its individual credences, and would the argument survive if we dropped that assumption? (ii) What does the argument establish, if anything, about how credences ought to respond to evidence?"

Student's answer:

Probabilism says that a rational agent's degrees of belief over an algebra of propositions should form a probability function: 1 on tautologies, 0 on contradictions, respect for negation, and finite additivity over incompatible propositions. The accuracy-dominance argument — Joyce (1998), developing a scoring-rule idea de Finetti already had — tries to show that this requirement falls out of caring about accuracy and nothing else, so it doesn't inherit the pragmatic baggage that makes the Dutch book argument unsuitable as an epistemic justification.

Fix a measure of inaccuracy A that assigns each credence function a penalty at each possible world, where a world is a truth assignment over the algebra, lower being better, with no penalty for credence 1 in a truth or credence 0 in a falsehood. Say c* strongly dominates c when c* is strictly more accurate than c at every world. Joyce's theorem has two halves: every incoherent credence function is strongly dominated by some coherent one, and no coherent credence function is strongly dominated by any credence function at all. So incoherence isn't merely risky, it's a guaranteed loss — you could have been more accurate come what may.

The argument is purely alethic. Any measure that ranks being right above being wrong will generate it; the Brier score is just the convenient choice, because then the dominating coherent function turns out to be the Euclidean projection of your incoherent credences onto the convex set of probability functions. In fact the dominance argument and the Dutch book argument are the same theorem in different notation — de Finetti proved it as a result about previsions and Joyce repackaged it in terms of accuracy — which is exactly why it's surprising that the accuracy version is supposed to be non-pragmatic while the betting version isn't.

(i) Additivity — total inaccuracy equals the sum of the individual inaccuracies — is a convenience that keeps the measure mathematically well behaved. Nothing substantive rides on it. Dominance is a pointwise comparison at worlds: if the coherent alternative is closer to the truth on each proposition at every world, then summing across propositions can't reverse that, and the projection result already guarantees it's closer on each one. So the theorem goes through for any continuous strictly proper measure, additive or not, and in particular you still get the second half: coherent credence functions are never dominated.

(ii) The argument is static, so it says nothing directly about updating. But it delivers the dynamic norms through the back door, because coherent credence functions are exactly the ones that can't be diachronically Dutch booked, and if accuracy talk and betting talk are intertranslatable then the matching accuracy result is that only agents who plan to conditionalize stay inside the undominated set. The projection is also unique once the measure is fixed, so the argument supports Uniqueness as well: for any body of evidence there is exactly one rationally permitted credence function, and an incoherent agent can use the theorem to work out which one it is.
