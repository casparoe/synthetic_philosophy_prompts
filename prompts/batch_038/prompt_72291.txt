Fitch week in my epistemology seminar went sideways and I want a second pair of eyes before I put anything in the handout.

Ground rules first, so we're not talking past each other. Fitchs proof — the thing that showed up as Theorem 5 in his 1963 value-concepts paper, and that Church had already sent him in a referee report — runs like this. Assume every truth is knowable, ∀p(p → ◇Kp). Assume also, for reductio, that there's some unknown truth; then in particular the conjunctive proposition *q and nobody knows that q* is true, for suitable q. By the knowability principle that conjunction is possibly known. But knowledge is factive, and knowing a conjunction requires knowing each conjunct, so knowing *q and nobody knows that q* requires knowing q and knowing that nobody knows q — hence q being unknown and known. So that conjunction is not possibly known, so it is not true, so if there is any unknown truth at all, there is a truth that is not merely unknown but unknowable. Contingent ignorance collapses into necessary ignorance. Everyone in the seminar is on board with that much.

Then one of my grad students, call him R, pointed out that nothing in that proof is about knowledge. It only uses two formal features of the operator. He abstracted them and ran the thing again, and I can't tell whether he's rediscovered something standard or built a howler that happens to look impressive. His argument, as charitably as I can render it:

1. Call a sentential operator F a *success operator* just in case both schemas are logically true, for all propositions p and q: (i) Fp → p, and (ii) F(p ∧ q) → (Fp ∧ Fq).
2. "Is known," "is remembered by someone," "is truly believed by someone," "is truly asserted by someone," and "is correctly written down somewhere" all satisfy (i) and (ii).
3. The Theorem 5 proof uses only (i), (ii), and a normal modal logic. So for *any* success operator F: ∃p(p ∧ ¬Fp) ⊢ ∃p(p ∧ ¬◇Fp); equivalently, ∀p(p → ◇Fp) ⊢ ∀p(p → Fp).
4. Therefore, for every success operator F, either the thesis "all truths are possibly F" is false, or it is true only because all truths are actually F.
5. Instances. F = remembered: either some truths could not possibly have been remembered by anyone, or every truth is in fact remembered. The second is false, so the first holds. F = truly asserted in some language: either some truths could not possibly have been truly asserted in any language at all, or every truth has been truly asserted. Again the second is false, so the first holds — and note that we got universal inexpressibility without counting sentences, without uncountable reals, without any semantics for "language." F = truly believed: likewise.
6. So no thesis of the shape "all truths are possibly F" is available to anybody. Anti-realism is not so much refuted as inexpressible, and a great deal of casual philosophical talk — anything true could have been known, could have been recorded, could have been said — is false as a matter of logic.
7. And because (3) is a schema rather than a claim about knowledge, no richer account of knowledge can rescue knowability. Whatever K turns out to be, if it is factive and conjunctive, the collapse follows. So there's no epistemology-shaped escape hatch.

R thinks (5) is the exciting part and (6) is just bookkeeping. I have the opposite instinct but I can't articulate it, which is not a state I enjoy being in at 9am.

If I'm forced to trade, I'd rather keep the proof than keep "everything is sayable" — that seems a cheap thing to give up. But I don't know whether that's a stable package, and I'd hate to be giving away the proof for nothing.
