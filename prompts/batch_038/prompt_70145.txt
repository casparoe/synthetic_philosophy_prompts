And here's the answer, verbatim except that I've cleaned up the handwriting-driven spacing:

(a) Setup: F is a finite set of propositions, W the set of possible worlds. Each w in W fixes a vindicated credence function v_w, which gives 1 to every member of F true at w and 0 to every member false at w. Inaccuracy of c at w is the Brier score B(c,w) = the sum over X in F of (c(X) − v_w(X))², so inaccuracy is just squared Euclidean distance from c to v_w in the space of credence functions on F.

Probabilism says your credences should form a probability function over F. Joyce's theorem: if c is not a probability function, then there is a probability function c\* that strongly dominates it, meaning B(c\*,w) < B(c,w) at every w. So an incoherent agent is guaranteed to be less accurate than some coherent one no matter how the world turns out, and since it's irrational to be in an epistemic state that's guaranteed to be less accurate than an available alternative, incoherent credences are irrational. Notice no bets appear anywhere.

Why it holds: the probability functions on F form a closed convex set C, and each v_w is in C, since a 0/1 assignment that tracks the truth is additive. Any point outside a closed convex set in Euclidean space has a unique closest point in it, and for that closest point c\* the projection inequality gives ||c − v_w||² ≥ ||c − c\*||² + ||c\* − v_w||², which is strictly greater than ||c\* − v_w||² whenever c is not in C. That's dominance at every world.

(b) A scoring rule is proper if each credence function expects itself to do at least as well as any rival, where the expectation is taken by its own lights: the sum over w of c(w)·B(c,w) is at most the sum over w of c(w)·B(c′,w), for every c′. Strictly proper if that inequality is strict for every c′ different from c. The Brier score is strictly proper.

Propriety is what stops the theorem from overreaching. It gives the converse direction: no probability function is strongly dominated. So the argument cannot be used to pick out one coherent credence function as uniquely rational — Probabilism comes out permissive, which is what you'd expect from a dominance argument. With an improper rule you could have coherent credences that expect a rival to beat them, and then the same reasoning would prove far too much.

Propriety also makes the choice of measure harmless. Any strictly proper scoring rule is a positive affine transformation of the Brier score, so the theorem isn't hostage to Brier's particular functional form and nothing special is doing work in the choice of it.

(c) Yes, and in the same shape. Suppose you start with a coherent c and you learn E, where c(E) > 0, with certainty. If your new credence b is not c(·|E), then b is strongly dominated by c(·|E) at every world in E, so you are required to conditionalize — and here the conclusion is not permissive, because exactly one posterior survives the dominance test. Nothing beyond propriety of the score was used, so Conditionalization falls out of the same theorem instead of needing an argument of its own.

Difference from the Dutch book argument: that one has to assume my credences just are my betting quotients and that a sure money loss is a bad thing, which is a pragmatic premise doing epistemic work — the usual complaint being that it shows incoherent agents are bad at gambling rather than bad at believing. The accuracy argument scores belief states directly against the truth, so it needs neither assumption. They share the convexity machinery, but only one of them is actually about accuracy.
