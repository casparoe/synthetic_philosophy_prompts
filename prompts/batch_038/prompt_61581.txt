Here's my half-formed idea. Every impact measure I know of — relative reachability, the attainability/utility-potential family, basically anything in the "penalize side effects" genre — quietly picks a basline: what the world looks like if the agent does nothing. That baseline is only clean in a single-agent world. Drop the agent into a world where other agents are changing things anyway and "no side effects" stops being well defined. A change the agent causes might have happened next Tuesday regardless; a change it prevents might have been a catastrophe or a windfall. The obvious fix is to measure impact relative to a *multi-agent* counterfactual — what would have happened given everyone else's plans. But working out that counterfactual seems to require modeling other agents' goals, and modeling other agents' goals smells a lot like needing a value specification, which is precisely the thing the low-impact program was supposed to let us skip.

So the question: can impact be defined against a multi-agent baseline without smuggling in a full specification of value — or does "just avoid side effects" collapse into ordinary value learning the moment other agents show up?
