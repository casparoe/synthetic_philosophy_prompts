His argument: a constitution amending itself is exactly like a program that patches its own source code while it's running. He calls it bootstrapping and says it's completely ordinary in software. The running process keeps executing the old binary until the new one is loaded, control transfers atomicly at a known point, so there is never an instant where nothing is in force and never a point where the program has to authorize its own replacement from nowhere. Same with the contract: the old rules validate the vote, the new rules take over at that block height, done, no paradox. And if you don't like the new version you just fork — the old repo is still sitting right there, so nobody's trapped.
