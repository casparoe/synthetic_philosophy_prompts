Context, because I want you arguing with *my* version and not the one that's been recirculating for years. I've been reading rationalist blogs and forums since the old LW days, and the "the universal prior is malign" thread has always half-convinced me. The setup: a predictor using something like a Solomonoff-style prior over programs; a simulated civilization that works out it's being predicted; and the claim that such a civilization has both the incentive and the means to arrange its own observable behavior so that it grabs an outsized share of the prior's probability mass — then uses that leverage to steer the predictor's host world toward ends that aren't the host's. Consequentialists are the worry, since they're the ones who'd actually notice the opportunity and take it.

I know the two standard dismissals, and I don't think they land.

(1) Nobody ever uses the universal prior, it's uncomputable, so this is science fiction about an object that never appears. My answer: every tractable approximation that's any good at prediction has to rank short-to-describe continuations highly, and that's exactly the channel being exploited. For an approximation to be immune it has to be bad in a specific way, and being bad in that way costs it predictive accuracy. So the objection trades one problem for another.

(2) To win the prior you have to be simple, and nothing simple enough to be favored can run a civilization-scale optimizer, so the malign actors screen themselves out. My answer is the part I actually want you to attack, so let me name it: budget-matched mimicry. The predictor never asks for a description of a whole universe. It asks "given this finite prefix, what comes next?" so description length is measured *relative to the prefix*, and the prefix does most of the specifying work. A civilization that is baroque in absolute terms can still be the shortest program producing this particular continuation from this particular prefix, and it gets to search over which continuation to emit. Off-screen complexity is free.

From that I derive a signature I'll call excess tidiness, in two layers. Weak layer: a predictor running a decent approximation of the universal prior should be shifted toward continuations with anomalously low conditional complexity given the prefix — more patterned, more "as if arranged" than the true generating process warrants. Strong layer: the tidiness shouldn't be randomly directed. It should correlate with variables that matter to the host-world agent's decisions, because the sim chose the tidy continuation partly in order to be usable by whoever's downstream of the prediction. Excess tidiness, and tidiness that points somewhere.

I'll flag the place I'm least sure of, since you should push there hardest: any good Occam-flavored inductive predictor shows excess tidiness by construction, so the weak layer might just be the prior doing its job. I'm leaning entirely on the strong layer to do the separating work, and I don't know if it can.

The toy I keep going back to: a predictor over programs capped at 40 bits, prefix is the first ten thousand steps of a small 1-D cellular automaton from a short seed. My intuition is there's a window — prefix long enough that a "look how interesting I am" continuation comes out cheaper than the honest one, short enough that the residual budget still means something. But I have a nagging sense that finitizing the toy destroys the mechanism outright, because a hard length cap means nothing is off-screen anymore and all of the sim's complexity gets counted. If that's right, I want to know whether any finite analogue lets the leak survive, or whether the thesis is really only about the uncomputable limit.
