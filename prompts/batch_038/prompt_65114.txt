I build agent-based simulations for a living — engineer, no philosophy training, and my modelling partner is a sociology group that keeps asking me to justify my assumptions. So before the next review I wrote down what I actually believe about my current model (panic selling on a mid-size crypto exchange). Here's the list:

1. Every social fact is ultimately just a fact about individuals and their relations, so a model containing nothing but individual agents is complete in principle.
2. Things like "market confidence" and "liquidity" are real causes, not just shorthand — my code feeds them back in as a variable that changes each agent's willingness to sell.
3. I don't care whether any single simulated trader behaves like a real one; what matters is that the aggregate curves line up with the historical data.
4. I trust this model for counterfactuals (what if we swap the matching engine, what if we rate-limit sells) precisely because it's built out of individuals instead of being fitted to past aggregates.
5. You can't derive a bank run out of individual psychology alone, which is why I think the aggregate variables are pulling real weight.
6. All my paramters get calibrated from individual-level data — order histories, per-user risk settings, survey answers. I never tune a knob to make an aggregate curve come out right.

Does this set hang together? Some of it feels shaky but I can't tell which bits. Tell me which ones actually collide, how bad each collision is, and what the cheapest revision would be that stops it — plus which ones only look contradictory, so I stop apologizing for them in the meeting.
