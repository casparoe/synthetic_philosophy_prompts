I am working through the family of paradoxes that arises when a gamble's expectation fails to exist, and I want a careful conceptual explanation of a distinction that I think is usually glossed over. I have written in British English; please write your answer in American English.

Fix the following cases. In each, a fair coin is tossed until it lands heads for the first time, and the payoff is fixed by the number *n* of the toss on which that first head appears. I give both the payoff *u_n* and the probability-weighted term *t_n* = 2^−n *u_n*, since it is the *t_n* that get summed.

- **Case A.** *u_n* = (−1)^(*n*−1) 2^n/*n*, so the payoffs run $2, −$2, $8/3, −$4, $32/5, … and the terms run +1, −1/2, +1/3, −1/4, +1/5, … This is the familiar "Pasadena" configuration. Summed in this order the terms converge to ln 2, about $0.69.
- **Case A′.** The very same gamble as Case A — same states, same probabilities, same payoff attached to the same state — but with the states listed in the order *s*₁, *s*₃, *s*₂, *s*₅, *s*₇, *s*₄, *s*₉, *s*₁₁, *s*₆, …, that is, two positive terms per negative one. The same terms now run +1, +1/3, −1/2, +1/5, +1/7, −1/4, …, and they converge to (3/2) ln 2, about $1.04. Other listings of the same terms diverge to +∞, diverge to −∞, or oscillate. Nothing about the option the agent faces has changed; only the listing has.
- **Case C(ε).** *u_n* = (−1)^(*n*−1) 2^n/*n*^(1+ε), so *t_n* = (−1)^(*n*−1)/*n*^(1+ε). For ε > 0 the terms are absolutely summable, the value is unique, and it varies continuously with ε, approaching ln 2 as ε ↓ 0. At ε = 0 we are back in Case A. For ε < 0 the terms fail to tend to zero.
- **Case D.** *u_n* = (−1)^(*n*−1) 2^n, so *t_n* = (−1)^(*n*−1): the terms do not tend to zero, and no ordering sums them.
- **Case E.** The ordinary St. Petersburg game: *t_n* = 1 for every *n*, so the sum is +∞ in every ordering.
