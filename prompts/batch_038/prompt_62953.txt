**Function ascriptions have an extra argument place**

*1. The stalemate.* Wright's descendants say F is a function of T because T is around in the population in virtue of having done F. Cummins's descendants say F is a function of T because T does F and doing F is part of how some containing system S accomplishes something we're interested in. Each camp has its cases. Etiology handles malfunction and handles the trait that's around by luck but does nothing; causal role handles novel traits, handles traits whose current effect isn't what got them there, and handles function talk in systems with no history at all — machines, economies, arguably a genome treated as a chemical system. Then each camp does one of two things: bites the bullet on the other's best cases, or says the other side isn't really talking about function. Nothing has moved in decades and I don't think it can move, because the disagreement is set up wrong.

*2. The syntax error.* Both sides write function ascriptions as two-place: function(T, F). Then they fight about what makes such a sentence true. But actual practice writes them as four-place: function(T, F, S, H) — trait, capacity, containing system, and a history index. On that reading the two theories are not rival accounts of the truth conditions of the same sentence. They're two different policies for filling the H slot. Etiology fills it with a lineage. Causal-role theory leaves it null, or defaults it to the system as currently constituted. That's exactly why they look contradictory: everybody is reading sentences with H suppressed, and a suppressed argument place looks like a disagreement about the predicate.

*3. The practice I'm leaning on.* Take the Gene Ontology. An annotation says a gene product has some function term — a molecular activity like catalysis or binding, a role in a larger process, a location in the cell. Two features matter for me. First, annotations carry evidence codes, and the codes draw a hard line between "we assayed this product and it did that" and "we attribute this because the sequence resembles something else that was assayed." The second kind — homology-based, not manually reviewed — massively outnumbers the first. So the database keeps a standing, structural distinction between a capacity demonstrated in a token and a capacity attributed through descent with modification. Philosophers treat those as competing answers to one question. The database treats them as two evidential grades of one question, and that's only coherent if the question has somewhere to record the difference. Second, the phylogenetically-derived annotations are built from an explicit model of where on a tree a function was gained and where it was lost, and each one can be traced back to the experimental annotations it rests on. Read that description again. It is a selected-effects story whose relata are branch-indexed and whose base is assay data. It is neither Wright nor Cummins. It is the four-place form, in the wild, at scale.

*4. Malfunction without proper function.* A human embryo's heart fails to septate and never pumps. The proper-function theorist says: still a heart, still has pumping as its function, and cashing that out needs something over and above actual causal contribution. On my view nothing extra is needed. One ascription — heart-token, pumping, circulatory system, index set to the mammalian heart lineage — is true. Another — heart-token, pumping, this embryo as constituted now, null index — is false. Malfunction is just the gap between an indexed ascription and a null-indexed one about the same token. No new metaphysical category, no appeal to what the thing is supposed to do. Same machinery then handles the vestigial structure that has been recruited for something new, and it explains why exaptations feel puzzling: they're the case where the two indices come apart in time, and we were trying to describe them with one.

*5. The objection I expect.* This is pluralism with extra steps — the pluralist already says there are several legitimate notions and that the two camps answer different questions, what-is-it-for versus how-does-it-work. My answer is that pluralism is a list, and a list predicts nothing: any two incompatible ascriptions can be sorted into different notions after the fact. The index view is a claim about argument structure, and it predicts which pairs of ascriptions will collide and which will merely look like they do. Two ascriptions collide only when they share S and H. That's testable against real disputes, which pluralism never is.

*6. What I don't have.* No independent account of what fixes S apart from H. No answer to whether the null index is a genuine default or a useful fiction. And if every H worth caring about turns out to be a lineage, the view collapses back into etiology with a fancy notation.
