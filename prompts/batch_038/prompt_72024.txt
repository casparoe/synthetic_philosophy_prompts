Consider the standard setting for program equilibrium. Two agents play a one-shot prisoner's dilemma, but each agent is a computer program, and each program receives the other's source code as input before acting. It is well known that this setting admits stable equilibria in which both parties cooperate, despite there being no repetition and no shadow of the future: each program can be built to cooperate just in case it can establish that the opponent's program cooperates against it (these are sometimes called fair bots). I am interested not in whether such equilibria exist, but in how much normative work they can do for an agent who is not already such a program.

Here is the objection I want a number on. Call it the pre-commitment regress. The cooperative equilibria are not action-guiding, because the cooperative outcome is conditional on both parties already having adopted a transparent, fairness-constrained decision procedure — and adopting one is itself a choice with a dominant strategy. Ahead of the game, each party would prefer that the other write itself into inspectable, cooperative code while it retained the option to defect against whatever it finds there. So the prior decision whether to become the kind of program capable of entering such an equilibrium reproduces the original dilemma at one level up, with the same dominant strategy. On this reading, program equilibrium establishes only that transparent agents can cooperate, not that anyone has a reason to become transparent.

Please give me your credence that this objection succeeds — that is, your probability that the cooperative results in transparent one-shot dilemmas give a not-yet-transparent agent no decisive reason to adopt such a decision procedure — and decompose it. I would like at least the following terms broken out, each with a number and a sentence or two of justification:

1. Whether an agent can in fact control its own decision procedure at the required level. This presupposes that there is a genuine pre-choice point at which the agent picks what kind of program to be; the familiar thought that one can cause oneself to become the sort of agent whom it would then be rational to be may or may not survive contact with how these programs are actually specified. If there is no such choice to make, the objection has no premise to work with.

2. Whether that pre-choice is itself transparent. If each party can read the other's code at the pre-commitment stage as well, the regress seems to dissolve rather than bite; if the pre-choice is private, dominance returns with force. Which of these describes the setting the equilibrium results are actually about?

3. Whether the objection is question-begging about the standard of rationality. It measures a disposition by act-level dominance. If act-level evaluation is the right criterion, the cooperative equilibria were never normative results to begin with; if dispositions or policies can be rational without every choice that produces them being act-optimal, the objection has no bite.

4. Whether exact mutual code access is attainable at all. Verification against the halting problem, the cost of simulating an opponent that simulates you, and the resulting reliance on approximations or partial disclosure may mean the idealized setting never arises, which could either moot the objection or relocate it.

Show how you combine these, with the arithmetic visible. State which term your final number is most sensitive to, and name the single consideration that would move it furthest. For calibration: I sit at roughly 0.55, because term 3 persuades me while term 2 seems to undercut it. Finally, give me a second number for a variant in which the two programs are written by rival organizations that can disclose about ninety percent of each other's code under audit, but not all of it.
