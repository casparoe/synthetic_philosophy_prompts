Several engineers on my team want to make this channel richer, finer-grained, and more accurate, on the intuition that an agent which knows itself better will behave better and that we cannot fix what the system cannot introspect. I have come to think the opposite position is at least as defensible, and I want it argued properly rather than merely agreed with.

Thesis to defend: a rational embedded agent should maintain a deliberately inaccurate — coarse-grained, biased, and partly opaque to itself — model of its own decision procedure, and the push toward introspective transparency is a liability precisely in the cases where it is usually sold as a virtue.

The diagonalization point that a system's predictions about its own future behavior can be defeated by the system itself, so self-prediction lacks the accuracy ceiling that world-prediction enjoys. The problem of a predictor that cannot tell whether it is tracking a fact or causing one, applied to an agent forecasting its own character. The observation that a monitoring channel visible to the monitored system is a channel that system can optimize, so introspection is exposed to Goodhart-style distortion in a way external telemetry is not. The incomputability-flavored result that a system cannot in general simulate itself completely, which would make any self-model an approximation whose errors are chosen rather than discovered.
