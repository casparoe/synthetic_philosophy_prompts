I am the instructor for an upper-level philosophy of language course and am grading the final exam. The short-answer question below was worth 20 points, with roughly 25 minutes allotted to it.

**Question:** Kripke argues that if an identity statement is true and both of its terms are rigid designators, then it is necessarily true — and yet that some such identities are knowable only a posteriori. Reconstruct the argument for the necessity of identity. Then explain, using "Hesperus is Phosphorus," how a single statement can be both necessary and a posteriori. Finally, say whether it follows from the necessity of that identity that Venus is necessarily the brightest object visible in the evening sky, and justify your answer.

**Student's answer:**

Everything is necessarily self-identical: for any x, necessarily x = x. Now suppose a = b. By Leibniz's law, whatever is true of a is true of b; taking the property in question to be being necessarily identical with a, it follows that b is necessarily identical with a, so necessarily a = b. Any true identity is therefore necessary. The qualification about rigid designators matters, though. A name designates the same object in every possible world in which that object exists, so if a and b are both names the argument goes through; a definite description like "the morning star" does not designate the same object across worlds, so an identity involving one can be contingent even when true.

"Hesperus is Phosphorus" is a case of the first kind. Both names rigidly designate Venus, so there is no possible world in which they come apart, and the identity is necessary. It is nonetheless a posteriori, because nothing about the meanings of the two names settles the matter: the Babylonians had to observe the sky and track the two lights over time to learn that the descriptions through which each name's reference had been fixed pick out one and the same planet. That is why the discovery was informative and could not have been made from the armchair.

Theoretical identities work the same way. "Water" and "H₂O" are both rigid designators of the same natural kind, so if water is H₂O, it is necessarily H₂O. But the necessity here is only as strong as the evidence for the identification: it is necessary given what chemistry has so far shown, and if it later turned out that the liquid in our lakes and oceans is compositionally heterogeneous, we would have to say that the identity was contingent after all. Necessity of this kind tracks how well confirmed the science is.

On the last question, yes. Since Hesperus is necessarily Phosphorus, and necessarily identical objects share all of their properties, whatever is true of Hesperus is necessarily true of Phosphorus. Hesperus is the brightest object visible in the evening sky, so it is necessary that Phosphorus is the brightest object visible in the evening sky. Substituting one rigid designator for another cannot change the modal status of the sentence it appears in.
