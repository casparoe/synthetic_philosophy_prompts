---

**§1 — The target.** There's a claim floating around, in tech writing mostly but increasingly in papers, that large language models have "solved the frame problem," or at least shown it to be a non-problem, on the grounds that a model trained on a huge corpus simply knows, without being told, that pushing a cup off a table doesn't change the price of tea in China. The claim is usually left as a rhetorical flourish, but it's doing real work: it's deployed to suggest that the whole non-monotonic-reasoning tradition was chasing a pseudo-problem that scale has now dissolved. I want to say that this is wrong, but not in the way people usually say it's wrong.

**§2 — Three problems wearing one coat.** The frame problem as McCarthy and Hayes introduced it [placeholder, need to pin down the venue] was a technical problem in the situation calculus: if you write down action axioms that say what an action changes, you also need, for every fluent that it doesn't change, a separate axiom saying it doesn't change, and there are very many of those. The difficulty is that you can't just add a blanket rule that everything stays the same unless acted on, because that rule misfires exactly in the cases that matter. Later work split this into pieces that get run together constantly. The frame problem proper is about the consequence relation of a formalism: what licenses the inference from a state description plus an action to the next state description, given that most of what's true stays true. The qualification problem is about preconditions: you can never finish listing the conditions under which an action succeeds. The ramification problem is about indirect effects — the suitcase whose handle you pull doesn't just move, its contents shift too — and it's a genuinely different difficulty from the first two. Shanahan's whole project is best read as insisting on this separation; the sleeping-dog and lazy-suitcase examples only make sense once you've made it [need to check I'm not conflating him with earlier event calculus work here].

**§3 — The move.** Here's my central claim, and it's the part my advisor says is doing work without arguing. An LLM does not have a consequence relation in the sense §2 requires. It has a conditional distribution over continuations. That distribution can and does produce correct persistence judgments in ordinary cases, and it does so for a reason that's easy to mistake for a default rule: it has learned what people typically go on to say and, more importantly, what they typically don't mention. But the warrant for a persistence judgment from a default rule is structural — the rule is checked against a state description and can be shown to misfire, which is how the Yale shooting anomaly [placeholder] was possible at all. The warrant from a trained distribution is material: the judgment is right because patterns like it were common, and there's no artifact in the system against which to demonstrate misfiring except another output. So the model doesn't answer the relevance question Hayes posed about what facts need to be taken into account. It has no fact of the matter about taking-into-account. It's not playing the game in which the frame problem is a problem, and calling that a solution is like saying a thermostat solved the halting problem by never getting stuck.

**§4 — The twist I actually find interesting.** This doesn't rescue the logicist, and — this is the part I like most — it doesn't rescue the Dreyfus-style holist either, at least not in the way people assume. The holist's premise is that relevance can't be captured by explicit rules because the background against which anything matters is inexhaustible. The LLM data point seems to confirm that premise emphatically: nobody axiomatized the background, and the system copes anyway. But the holist's conclusion — that only an embodied, already-engaged, situated agent can cope with relevance — doesn't follow, because a corpus-trained system approximates the background without a body or a situation. So the LLM splits holism's premise from its conclusion, and what's left over suggests the deep issue was never inexhaustibility. It was checkability: whether there's something in the system that a correctness claim can be assessed against.

**§5 — The objection I can't answer.** Everything in §3 assumes the frame problem lives inside formalisms. But there's a pragmatic reading — the robot's dilemma framing from the Pylyshyn volume, and arguably what Hayes himself cared about — on which the problem is for any agent that must decide what to attend to before it can act, and on that reading a tool-using LLM running an agentic loop absolutely does face it, every single step. If that's the operative reading, §3 is a gerrymander: I've defined the problem so that my target isn't in it, and then scored a win. My best guess at a reply is that the pragmatic reading is really the qualification problem in disguise, so §2's separation saves me. I don't know if that's true.

**§6 — The thesis in one line.** The frame problem is three problems; only one of them is a problem about logic; and LLMs are silent on that one while appearing to be loud about the other two.
