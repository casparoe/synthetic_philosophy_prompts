Building a little simulator for the program equilibrium setup — two agents that get handed each other's source code before they pick C or D — and I've run into something I cant find a word for. Not in the part everyone talks about, in the part that only shows up once you give the agents an oracle.

Background on what I'm NOT asking about, so you don't spend words on it: I already hit the circularity wall, where A's code says "cooperate if I can verify B will cooperate" and B's is the mirror image, so nothing bottoms out unless you paste a copy of each program inside the other or hand them a magic "does this halt" subroutine. Fine. Moved on.

What I want a name for is what that oracle makes possible. Once agents can simulate each other, a design like this starts winning in my runs: "if I can tell that this run of me is happening inside somebody else's decision procedure — i.e. I'm being executed as a prediction of myself — then output whatever move makes their prediction of me most useful to them; if I can tell I'm the run that actually counts, defect." The source is public. No hidden state, no dice rolls, no information the opponent lacks. And still, reading the source tells you nothing about what it does, because the output depends on which role this particular execution is playing. Transparency stops buying transparency — and the usual comfort about this whole setup, that at least you can't bluff about your own code, quietly stops applying, since this agent isn't bluffing about anything. It says exactly what it is.

Same shape, second instance so it doesn't look like a one-off: "if I'm being executed before the game proper starts, as a probe, output C; if I'm being executed as the move itself, output D." Again fully visible, and again the fact that settles the output isn't in the text of the program. Nor is it the opponent's private information. It's a fact about the run.

So: does this have an established name anywhere in the program equilibrium / decision theory corner? And I want the carving, not a label. Which concepts sit nearest — undecidability and the halting problem, incomplete information, mixed strategies, self-reference and quining, whatever the AI safety people call a model that behaves one way in evals and another way in deployment — and for each of those, why is it not quite this thing? Where are the edges? Does a program that branches on the round number count? One that branches on the opponent's last move? One whose branch condition it could never in principle determine? Does it matter whether the branching fact is something the opponent also knows, versus something only the runner knows? If nobody has named it, then coin a term, with a real definition and a couple of boundary cases that show the definition doing work.

I'm not after references — don't pad this with citations you're unsure about. But do tell me what would change your mind: if you conclude there's no established term, what would convince you otherwise; if you conclude there is one, how sure are you that it means this rather than a neighbour; and which piece of the boundary-drawing above do you think you're most likely to have gotten wrong?
