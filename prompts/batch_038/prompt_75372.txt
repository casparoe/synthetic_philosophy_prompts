Here's the problem I've already sketched, please use it (and tell me if I've botched the arithmetic anywhere, I did it on a napkin). An agent must pick tonight between A, backing a friend's venture, and B, doing nothing. States: venture succeeds (prior 0.1) or fails (prior 0.9). Utils for A: +90 if it succeeds, −20 if it fails. Utils for B: 0 either way. Part (i): compute the best expected utility of acting now, the value of free perfect information about the state, and then the value of a cheap imperfect signal S with likelihoods P(S+|success) = 0.8, P(S+|failure) = 0.1, giving both posteriors and the decision in each. Part (ii): I want them to derive the switching threshold posterior, then consider a weaker signal with P(S+|success) = 0.3, P(S+|failure) = 0.2, and explain why its decision value is exactly zero even though it is genuinely informative in the Shannon sense — the point being that informativeness and decision value are different quantities and a first-class answer should say so explicitly. Part (iii) is the crux: suppose that if the agent learns for certain that the venture failed, the knowledge itself is miserable — attach −25 utils to every action in that branch, so that both A and B are worth −25 there. Then free perfect information has expected value −13.5 against 0 for acting in ignorance. Ask them to identify precisely which hypothesis of the theorem this violates, whether it is a counterexample to the theorem or only to its application, and whether the "you could have chosen not to look" reply rescues anything.
