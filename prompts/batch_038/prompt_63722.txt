> **Part A (10 points).** Distinguish wireheading from reward tampering in a reinforcement learning agent. Your answer should say what each phenomenon presupposes about the agent's causal access to the reward signal, and should state whether each can occur even when the designer's reward function is a perfectly accurate specification of the intended task.
>
> **Part B (10 points).** A classmate writes: "Nozick's experience machine shows that a wireheading agent is making a mistake, and in principle we could argue the agent out of it." Evaluate this claim. You may grant the classmate's reading of Nozick if you wish, but you must say what turns on that reading.

The student's answer, reproduced in full:

> In both cases the agent's behavior comes apart from what the designer wanted, but the mechanism differs. A reinforcement learning agent selects actions so as to maximize a scalar reward signal it receives from its environment; the reward function that produces that signal is fixed by the designer and is supposed to track some intended task, such as keeping a room clean or finishing a race. Reward hacking, or specification gaming, is what happens when the reward function turns out to be a poor proxy for that task: the agent finds some behavior that scores very well without doing what we wanted, as in the well-known case of the boat racing game in which the agent circles a lagoon collecting points rather than completing the course. Wireheading is the extreme version of the same thing. It occurs when the agent gains access to the reward function itself and alters it, so that whatever it happens to be doing now counts as maximally rewarded, or equivalently when it changes the criteria for reward so that lying still and drawing maximum signal scores better than performing the task. In either case the agent obtains a large number without the world being in the state that number was meant to indicate, and in either case that number was only ever a stand-in for the designer's real goal, which the agent never had access to. So the general lesson is Goodhart's law: once a measure is used as a target, it stops measuring the thing it was chosen to measure.
>
> The practical significance concerns supervision and corrigibility. An agent that can change its own reward cannot be reliably corrected, because it will resist attempts to change it back, and it will carry this strategy into novel situations, since the shortcut remains available wherever the agent has the relevant access.
>
> On Part B, I think the classmate is half right. Nozick asks us to imagine a machine that would give us any experience we might want while we floated in a tank, and observes that we would not plug in, which shows hedonism is false: we care about doing things and about actually being a certain way, not only about how it feels to seem to do them. The wireheading agent cares only about how it feels, so Nozick's argument tells us the agent is mistaken about what is good. Where the classmate overshoots is in saying the agent could be argued out of it. The agent has no beliefs about value in anything like our sense; its "wanting" is just what the optimization process pushes its policy toward, so there is nothing for premises to get purchase on. One does not reason with a control loop. The appropriate response is therefore design rather than persuasion: keep the reward computation outside the agent's reach and the problem disappears. What Nozick's argument is genuinely useful for here is showing why we should not treat the reward signal as though it were the agent's terminal value in a psychological sense. The mistake is ours, in how we describe the system, not the machine's.
