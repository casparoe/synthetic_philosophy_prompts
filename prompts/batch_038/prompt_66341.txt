I have a linguistics background but work in ML now, so I see the same argument shape from both sides, and I've never seen anyone name it. It goes like this: someone shows that one particular learning setup can't get from the data children actually hear to the target grammar — the hypothesis space is too permissive, or theres no negative evidence, or whatever — and the result then gets reported as though it showed the data itself is too thin, full stop. When you point out that a different setup does manage it on the same input, the reply is that the second setup had the needed structure sitting in its priors, so it only looked like learning from the data. Which is true! But now the original claim has quietly become "no setup could get there without already having the answer," and that much stronger thing never gets argued for on its own. Same shape in ML papers: prove a toy model can't fit some function, conclude the function needs inductive bias, don't mention that the bias got relocated instead of removed.

It's got a Duhem-Quine smell to it, but that's about testing theories rather than learning them, and underdetermination is way too broad. So: is there an established term for this? I don't want just a label though, I want the carving. How is it different from a straight poverty-of-the-stimulus argument that might be perfectly sound in a given case, from plain question-begging, and from the no-free-lunch point that learnability is always relative to a hypothesis class? And if nothing fits, coin something and tell me what would and wouldnt count as an instance.
