I'm not a physicist, I write backend software, but I've been deep in the Maxwell's demon rabbit hole for about a month now and I think I've talked myself into something, so I want it stress-tested. I've got the standard Bennett line down: the measurement itself can be done reversibly, so the cost doesn't land there, it lands on erasure, kT ln 2 per bit dumped into the bath. I also know there's a newer feedback-control version of the second law (Sagawa and Ueda, I think) where the bound on extractable work gets a mutual-information term, and that tabletop experiments with colloidal particles and single-electron devices have actually measured both the erasure cost and the information-to-work conversion. So far so good.

Here's where I went off-piste. My view is that Landauer's principle is doing no real work in the exorcism, and that the whole paradox is a boundary-convention illusion. Concretely: take a one-shot demon with N bits of memory that is never reset and never reused — it runs a finite number of cycles and then gets retired, memory and all. The joint gas+demon dynamics is entropy-preserving, so whatever entropy the demon pulled out of the gas is still sitting in the correlations between its memory register and the gas. The total never went down, so the second law applied to the whole closed system is never violated, not even temporarily, and nothing ever has to be dissipated. Then extend it: even for a cyclic demon, I think the erasure cost only shows up because people insist the demon return to one *particular* standard state instead of any state from which it can keep working. My proposed dodge, which I'll call memory laundering, is to keep a big stockpile of blank ancillas and swap used registers out for fresh ones, resetting the dirty ones lazily and in bulk, maybe at a time when the bath is colder. On my account the second law is really a claim about finite-memory reusable machines plus a choice of where you draw the system boundary, and Landauer is just a special case you can decline to invoke.
