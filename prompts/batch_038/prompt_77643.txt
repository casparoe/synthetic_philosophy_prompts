so I'm writing a little bargaining solver for a class project. two players, feasible set given as a convex polygon (just a list of vertices), disagreement point at the origin. I implemented Kalai–Smorodinsky the way I understand it: compute each player's ideal payoff, draw the ray from the disagreement point to that ideal point, take where it hits the Pareto frontier.

here's my problem. the paper I'm reading for the writeup says KS violates independence of irrelevant alternatives, and I'm pretty convinced that's either flat wrong or a quibble about terminology — because IIA is about *irrelevant* options, i.e. the dominated ones nobody would ever choose, and my solver never looks at dominated points. it only uses the Pareto frontier and d. so moving the irrelevant alternatives around literally can't change the output, can it?

I even tried to catch it failing. first set: vertices (0,0), (3,0), (0,3). KS gives (1.5, 1.5), as expected. then I chopped off the (0,3) corner and used (0,0), (3,0), (1.5,1.5), (0,2) instead — every point in the second polygon is still inside the first, and (1.5,1.5) is still feasible and still on the frontier — and my code spits out (1.8, 1.2). that's got to be a vertex-ordering bug in my hull routine, since the old answer was still available. (annoyingly, running the Nash solution on both polygons gives (1.5,1.5) both times, so its not my Nash code thats broken.)

and if KS really does fail IIA, doesn't that mean it's failing something else too? I thought Nash was the *unique* thing satisfying Pareto + symmetry + scale invariance + IIA, so anything that gives up IIA must be breaking one of the other three as well. also, seperate question: why can't a solution just have both IIA and monotonicity? I don't get what the tradeoff is suposed to be — they sound like they're about totally different things.
