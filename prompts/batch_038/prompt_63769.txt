What has hooked me lately is program equilibrium: the idea that instead of players picking strategies, they hand over little programs that get read-access to each other's source code before choosing an action, so that in a one-shot prisoner's dilemma two such programs can actually end up cooperating in equilibrium. That's the part my old intuitions keep tripping over, because in an ordinary Nash setup defection is the only stable outcome, and here transparency — the fact that you cant hide your own code from your opponent — is doing the work that niceness never could. I've also read that the earliest constructions were pretty brittle, along the lines of a program that cooperates only when the opponent's source code is character-for-character identical to its own, and that later work needed tricks from provability logic to get cooperation that survives the two codes being merely similar.
