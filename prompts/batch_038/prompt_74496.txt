**Student script:**

(a) The first incompleteness theorem says that any consistent formal system which is strong enough to express basic arithmetic is incomplete: there is a sentence in its language that the system can neither prove nor refute. So no consistent axiomatisation of arithmetic can be complete — the hope of pinning arithmetic down once and for all with a list of axioms, which is roughly what Hilbert's programme was about, was doomed.

The idea of the proof is to let arithmetic talk about arithmetic. Gödel assigned a number to each symbol, and then to each formula and each proof, by coding sequences as products of primes or something equivalent, so that syntactic properties turn into arithmetical properties of numbers. The crucial fact is that "x codes a proof of the formula with code y" is primitive recursive, and so can be expressed by a formula of the language itself; call it Proof(x, y). There is then a general diagonal construction: given any formula φ(x) you can build a sentence ψ that is provably equivalent in the theory to φ applied to the code of ψ. Take φ(x) to be "nothing proves x," and you get a sentence G that is equivalent, in the theory, to the claim that G itself has no proof. So in effect G says of itself that it isn't provable.

Now if the theory proved G, then G would have a proof, so what G says would be false, and the theory would have proved a falsehood. If the theory proved ¬G, then G would be refutable, so again what G says would be false and the theory would be proving a falsehood. A consistent theory can do neither, so G is undecidable in it. Notice that the only hypothesis used is consistency. And G is in fact true, since it correctly reports that no proof of it exists. Which means there are arithmetical truths that no formal system whatsoever can prove. You can try adding G as a new axiom, but then the enlarged system has a Gödel sentence of its own, so the gap is permanent.

(b) Lucas's argument goes like this. Suppose I, a human mathematician, am equivalent to some Turing machine M. Everything I can establish is then the output of some effective procedure, so it is captured by a formal system T whose theorems are exactly what M outputs. But by (a) I can construct T's Gödel sentence G, and I can see that G is true: T is consistent, and G just says that T doesn't prove it. M cannot output G, because G is unprovable in T. So there is a truth I can see and M cannot. Hence I am not equivalent to M; and since M was arbitrary, no human mathematician is a Turing machine. The second theorem sharpens the point: T cannot prove its own consistency, so the machine can't even establish the premise its own reasoning would need.

Does it work? Partly. Two things go right for Lucas. First, the argument doesn't lean on any mystery about consciousness or qualia — it's just the incompleteness theorem applied to a machine that outputs theorems, which is why it's harder to dismiss than people assume. Second, the popular objection that a mind isn't a proof-generating system at all but a lump of chemistry concedes too much: if the chemistry is mechanical in the sense Lucas means, its outputs are still captured by some formal system, and the theorem still applies. There is one real difficulty, which is the step where Lucas says we can see that G is true. That requires knowing T is consistent, and it isn't obvious we have better access to T's consistency than T does; we could prove Con(T) in some stronger system, but then the same worry recurses a level up. And strictly the argument only shows I'm not that machine, not that I'm not any machine. Still, the general point survives: the theorem shows that truth outruns proof, and any system that can only prove what its axioms force on it will permanently trail us.
