Setup: a spacetime is a smooth manifold M together with a metric g on it, and g plus some matter fields satisfy Einstein's equation. Now:

(1) GR is generally covariant, so if I take a smooth invertible map d from M to M and drag every field along with it, the result still satisfies the equations.
(2) Let H be some small open region of M — the hole — and choose d so that it's the identity map everywhere outside H but shifts points around inside H.
(3) So the dragged model and the original model agree exactly on the metric and the matter everywhere outside H, and they differ inside H.
(4) I can also pick H to sit entirely to the future of some spacelike slice S, so the two models agree on all the data on S and before it.
(5) A manifold point is just an element of the set M. The point p inside H is literally the same element of the same set in both models, so when I say the two models differ at p, that's a claim about one and the same point having two different metrics.
(6) A theory is deterministic if the state on S plus the laws fix everything else: there's at most one way the world can be that's compatible with them.
(7) By (3), (4), (5) and (6), GR allows two different ways the world can be that match perfectly on and before S and disagree after it. So GR is indeterministic.
(8) Nothing in (1) through (7) used anything specific about gravity. Any theory you write in generally covariant form lets you run the same trick, so covariant electromagnetism comes out indeterministic too, and so does Newtonian mechanics if you dress it up that way — theories nobody thinks are indeterministic.
(9) And the same move works outside physics entirely. Take any model of arithmetic and permute its domain: you get another structure that makes all the same sentences true but hooks the numerals up to different objects, so nothing ever has a determinate reference either.

So the argument ends up showing that no theory of anything is deterministic and no terms refer to anything in particular, which is definately too much — if it were true my whole presentation collapses and honestly so does every physics class I've ever taken.
