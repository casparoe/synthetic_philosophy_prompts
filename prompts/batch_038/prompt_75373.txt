Just got out of a two hour argument with a friend who does mech interp and I still can't tell who's right, so I want to know whether there's a principle hiding under my gut calls. Context: we're both circling anomaly detection — you understand some mechanism in a clean model, and you want to say whether it's still there, broken, or swapped out in a fine-tuned or tampered model. That's only well-defined if "the same mechanism" means something.

Here's what I say, case by case:

- Model A does the thing with one attention head; model B does it with two heads that each handle half the computation, and ablating either one kills the behavior completely. Same mechanism, obviously.
- Same setup, except in model B the two heads are redundant — each can do the whole job alone, and ablating one barely changes performance. Not the same mechanism. Or not *one* mechanism anyway, it's two.
- Model B is deeper, so the thing sits in layer 20 instead of layer 12. Same mechanism. Depth is bookkeeping.
- In model B the whole thing runs over a different representational format — say the relevant quantity is encoded as a pair of trig-like features instead of a linear direction — but it's the same algorithm, same inputs, same downstream effect. Same mechanism.
- Reinitialize model B from scratch, retrain, and a structurally unrelated but functionally identical circuit shows up again. Same mechanism. Independent convergence doesn't break identity.
- Model A had a genuine general rule; model B, after tuning, gets the same answers on everything I can think to test by leaning on memorized cases, and comes apart off-distribution. Not the same mechanism, even though every benchmark number matches exactly.

My friend says 4 and 5 commit me to mechanism = algorithm implemented, and that once you accept that, the distinction between 1 and 2 is incoherent, since redundancy is an implementation detail too. I don't buy it but I cant say why.

So: what principle, if any, delivers all six? State it precisely enough that I can tell what it says about a case neither of us thought of, and be straight with me about which of my verdicts it has to overturn.
