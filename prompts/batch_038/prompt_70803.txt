so, background: I'm a backend engineer, never taken a philosophy class in my life, but I read GEB when I was 19 and the typogenetics bit has been rattling around in my head for twenty years. I've been arguing about it in a group chat with two friends (one has a math degree, one's a bio postdoc) and I figured I'd just write down what I actually believe and get it stress-tested, because right now it's smeared across three years of Slack messages and I can't tell what thier objections have already forced me to give up.

here's the package:

1. DNA is code in a non-metaphorical sense. Four-letter alphabet, strings, codons fed into a lookup table that spits out amino acids. And since any finite string over a finite alphabet can be coded as a number, Gödel numbering isn't a stretch here, it's basically free.

2. A quine is what a Gödel sentence looks like when you write it in Python instead of Peano arithmetic — a string that arranges to get itself out the other end. So when Hofstadter lines up strands/enzymes against strings/theorems, that isn't a teaching analogy, it's the same formal situation showing up in two substrates.

3. The mechanism is von Neumann's: the description gets used twice, once as data (copy it) and once as instructions (execute it), which is why a replicator doesn't have to be twice the size of its own description. Same trick that makes quines short.

4. Which means the checker problem is unavoidable. For a copier to verify its own fidelity, the verifier has to be verified, and that regress bottoms out the same way the consistency proof does. So there's a hard floor on replication error that no amount of engineering removes, and mutation is what incompleteness looks like in wetware.

5. Also: polymerase proofreading plus mismatch repair gets you something like one error per billion bases per round, and that is definately engineered — a real error-correction system with a real energy budget, not an accident of messy chemistry.

6. And the genome is not self-contained. Ribosomes, cytoplasm, methylation patterns, prions — inherited but not spelled out in the sequence. Structurally that's the Ken Thompson compiler thing, where a compiler that compiles itself can carry a backdoor that isn't in its own source. The interpreter gets to inject content the code never contained.

the one I keep losing sleep over is whether (6) wrecks (2) — if the machinery outside the code contributes stuff, is the isomorphism just dead? but I honestly don't know if that's a real problem or if I'm chasing a ghost.
