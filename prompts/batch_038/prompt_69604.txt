I'm a software engineer working on multi-objective optimization, and I have no formal philosophy training, so please treat my framing as a proposal for you to defend rather than as terminology I'm using correctly. I've been reading about incommensurable values and Ruth Chang's account of hard choices, and I want the strongest argument you can give for the position that parity is not a fourth comparative relation but a mis-description of a representational choice.

The proposal is this. Model an option as a vector of realized values — relationships, achievement, security, aesthetic goods, and so on — with no privileged scalarization. Comparability is then just Pareto dominance, and the residual cases, where neither vector dominates the other, are exactly the cases philosophers call hard choices. On this view the difficulty is not that the values lack a common measure; it is that many scalarization functions are equally admissible and we have not fixed one, so that what Chang calls parity merely names the unfixed weight vector.

Please argue for that position against the claim that parity is irreducible. I'd like the argument to do three things. First, reproduce the phenomena parity was introduced to capture: that a small improvement in one option does not settle the comparison, and that neither option is better, worse, or equally good as the other. Second, answer the worry that our indeterminacy about the weights is really vagueness, and that vagueness and incomparability cannot both live in a single betterness ordering — the line associated with Broome. Third, tell me honestly where the vector picture strains, for instance whether it can accommodate an improvement large enough in one value to swamp several others, or trade-offs within a single dimension, since I don't want a defense that wins only by assuming the weights have already been fixed in advance.

Argue from the concepts rather than from citations, and keep it intelligible to someone without a philosophy background.
