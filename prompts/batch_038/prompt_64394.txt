ok so I keep running into people saying panpsychism is a dead end because of the combination problem — you can't get from a bunch of micro-experiences to one unified subject, and since QM says a macro object like a brain isn't a substance but just a bunch of entangled micro-physical states, the combination problem supposedly sinks it.

but here's the thing: if you take Everett seriously, a macro object IS just a decohered branch of the universal wavefunction. So isn't the objection kind of backwards? Under Everett there's no extra fact about "the subject" over and above the entangled branch structure, which means the combination problem isn't a special problem for panpsychism, it's just the same problem everyone has about why there's one persisting observer per branch. Which would make it a problem for physicalism too, and physicalists don't seem to treat it that way.

am I missing something, or has anyone made this move properly? feels like it should dissolve the whole debate but I never see it argued that way.
