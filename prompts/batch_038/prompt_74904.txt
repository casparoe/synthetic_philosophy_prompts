I'm a software engineer, no philosophy training, but I've read enough about the paradox of voting to know the shape of it: one vote basically never changes an election, so the expected benefit is ~zero, so why does anybody bother, and it seems rational not to.

At work I keep reaching for a different frame: filing a bug report against a huge open-source dependency. The odds your report is the one that triggers a fix are tiny, nobody will ever know it was you, but if everyone skipped it the whole ecosystem rots — so we all file them, and people who don't are treated as freeloaders. I've been using this on colleagues to argue that not voting is basically the same failure mode as not filing bugs.
