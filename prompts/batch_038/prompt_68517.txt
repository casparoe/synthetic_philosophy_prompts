So I write a long-ish ideas column for a science desk and I've got a piece due Friday on illusionism about consciousness — the view that phenomenal consciousness, the felt-ness, is a kind of user illusion the brain generates for itself, with Dennett's computer-interface analogy being the famous version of the metaphor. Editors want 2,500 words. I have about 900 and an outline, and I've been staring at it too long to tell weather the central move is clever or embarrassing. Can you read the draft chunk below and tell me where it goes wrong?

DRAFT (section 3 of 5):

The interface metaphor is doing more work than illusionists usually admit. A desktop is a user illusion in a very specific sense: it hides the machine, but it hides it *from someone*. There is a user sitting at that desk with actual goals — a spreadsheet to finish, a flight to book — and the illusion is calibrated to her limits. Icons are crude because she can't read machine code, and the crudeness is a good deal: she gets more done by not knowing what a disk sector is. The illusion is a service rendered to a real consumer.

Run the metaphor the way illusionism runs it and the consumer vanishes. The brain's user interface is a self-model, and there is no little user reading it, because the whole point of the view is that there is no inner spectator. Fine — nobody serious is defending a Cartesian theater. But then the metaphor has lost the one element that made it explanatory. What's left is a claim about representation: the system models itself in a way that is simpler and more unified than the underlying process. That may be true and it may be interesting, but it is a claim about how self-models get built, not about whether anything is experienced. I want to call this the headless-desktop problem: an interface with no user isn't an illusion, it's just a rendering.

Second, and I think this is the stronger worry: illusions are informative because they are local. An optical illusion earns its keep by being reproducible, bounded, and diagnosable — you can say which conditions produce it and which don't, and the gap between appearance and reality is exactly where the science lives. A global illusion, one that never flickers and never shows a seam, stops functioning as an illusion and starts functioning as a description. If consciousness really is a user illusion, I'd expect glitches of a particular kind: not failures of attention, but misreports about experience itself, stable enough to study in a lab.

Which is why I think the evidence usually cited here gets borrowed rather than owned. Change blindness, inattentional blindness, the gorilla strolling through the basketball game, the notorious sparseness of the peripheral visual field — every one of these is a failure to notice, encode, or report. They show that access is limited. They don't show that experience misrepresents experience. And that difference matters, because an illusionist leaning on them is using the limits of cognition to argue about the character of phenomenology — the same trade the view accuses its opponents of making.

END DRAFT
