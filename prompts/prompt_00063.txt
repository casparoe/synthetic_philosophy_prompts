Write an essay on whether the self-sampling assumption used in the doomsday argument is vulnerable to the "reference class problem" — the difficulty of specifying which set of observers you should consider yourself a random sample from. Consider how different reference class choices (all humans, all sentient beings, all observers with your exact evidence) affect the argument's force, and whether any principled way exists to fix the reference class. Reach a verdict on whether the doomsday argument survives this objection.
