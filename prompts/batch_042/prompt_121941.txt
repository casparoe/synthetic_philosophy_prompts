In a counterfactual scenario, the entire codebase is redeployed on blockchain B (with incompatible consensus rules), every validator is replaced by a geographically disjoint set, and the treasury is migrated to a new address, yet the protocol rules, governance parameters, and functional purpose remain exactly the same. Would this post-migration institution be identical to the original? Counterpart theory, as Lewis presents it, denies that any object exists in more than one possible world. Instead, other worlds contain counterparts—entities that resemble the original in important respects. The resemblance is graded and can be weighted by different properties. By contrast, the transworld-identity view holds that one and the same object can exist in multiple worlds, bearing different properties in each, provided it retains its essential nature.

Applying this to the synthetic institution: on Lewis's account, the redeployed collective on blockchain B is not the original institution but a counterpart. The original exists only in the actual world (and worlds with blockchain A). The counterpart on B resembles it because it shares the protocol rules and treasury function, but because the validator set and substrate differ, the counterpart relation is somewhat weaker—though still strong enough to count as the same institution in ordinary speech, not in strict metaphysical terms.

On the transworld-identity view, the question is whether the blockchain substrate and validator nodes are essential to the institution. If they are essential, then the B-version is a different object altogether. If they are accidental, then the original institution survives with new accidental properties—much as a person survives replacing cells. Here, the functionalist nature of the institution suggests that its essential properties are its constitutional rules and governance parameters, not its physical or distributed substrate. Therefore, the transworld-identity theorist should say the original institution persists on B.

One subtle point: Lewis allows that objects have essential properties, and these determine which counterparts are the closest ones. So if being-on-blockchain-A were essential to the original, then no counterpart on B could share that property, making the B-version a distant counterpart at best. Meanwhile, Plantinga's version of transworld identity requires that essential properties be intrinsic, so the substrate—being an intrinsic feature of the distributed system—must be essential, which means the original does not survive. Thus, both views might actually converge on treating the B-version as non-identical, though for different reasons.
