The summary runs roughly as follows. Hofstadter's core claim is that if functionalism is true, then consciousness is just the right kind of information-processing pattern, regardless of what realizes it. So when Einstein's brain reads a novel, the pattern instantiated in the book's printed pages gets activated in the neural substrate; but since the pattern was already fully present in the text, the book itself was latently conscious all along, merely lacking the right hardware to run it. The brain is therefore just a biological computer running the book's software, and on this view there's no principled reason a printed page couldn't be conscious if it were part of a causally closed loop with the right informational dynamics. The summary presents this as a reductio that Hofstadter endorses: he supposedly concludes that functionalism collapses into a kind of panpsychism about texts, and therefore we should reject substrate-independence in favor of a biologically grounded theory of consciousness where only living neural tissue can host experience. Finally, the summary says this is essentially Searle's Chinese Room argument recast—Searle showed that syntax isn't semantics, and Hofstadter just applies the same insight to show that printed syntax isn't conscious experience.

This strikes me as suspicious on several levels, but I'm working from secondhand descriptions and don't want to misrepresent Hofstadter before I check the primary text.
