people in synthetic biology and bioethics keep saying DNA is literally computer code — there's a source file, CRISPR is just editing text, bugs are mutations, and the genome is the program that builds the organism. it's used to license the idea that genetic enhancement will be as clean as patching software, and that information flows one-way from gene to trait like data from disk to display.

how far does it hold? lay out the correspondence — programmer, compiler, runtime enviroment, bugs, version control — then the places it fractures. i'm especially stuck on a few things: alternative splicing means one "line" can belong to dozens of different "programs"; the ribosome that reads the sequence is itself encoded in DNA, so there's no independent compiler; cytoplasmic inheritance means the egg's machinery determines early development without being in the genome at all; and pleiotropy means editing one "function" often crashes twenty others. there's also the philosophical point that DNA carries Shannon information but not semantic meaning unless a cell is already there to interpret it — so calling it "code" quietly imports an interpreter that the code itself has to construct.

does the "just debug the genome" conclusion survive all that, or was the analogy doing all the work? if it's broken, what's the better metaphor — a recipe, an ecosystem, a self-modifying language? and what does that do to the ethics of enhancement?
