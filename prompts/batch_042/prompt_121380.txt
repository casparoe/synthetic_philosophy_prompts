I hold that the independence of CH from ZFC supports a multiversal determinacy: CH is determinately true in some canonical forcing extensions and determinately false in others, so asking whether CH is true simpliciter is a category error analogous to asking whether there are five planets. What would count against this? I want the evidence and arguments that should move me—especially any result showing that forcing extensions are not ontologically on a par with the ground model, or that there is a privileged canonical universe—sorted by decisiveness. Include what defenders of this multiversal view would themselves concede counts against it, whether the view risks being qualified into unfalsifiability, and if so whether that undermines its philosophical point.
