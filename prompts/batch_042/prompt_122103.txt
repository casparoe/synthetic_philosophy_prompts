I'm defending this idea I cooked up: the whole Buridan's ass thing—where the donkey starves between two identical hay bales—only looks like a real problem if you think preferences have to be complete and continuous like some math function. In actual systems, whether it's a neural net or a rat in a maze, there's always some hidden tie-breaker: noise, latency, the way memory is addressed, whatever. So the "paralysis" never actually occurs, and treating it like an empirical prediction is definately a category error. I call it the "implementation breaks symmetry" argument, which is probably not a real term, but thats the gist.
