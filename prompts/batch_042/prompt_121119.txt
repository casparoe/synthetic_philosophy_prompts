(1) i'm a realist — there are universals like redness or triangularity, not just particular red things.
(2) but they're immanent, not platonic: a universal exists only in its instances, never outside them.
(3) the one-over-many argument works for qualitative properties but not for natural kinds — being human isnt shared the same way being-red is, because kind membership depends on origin/essence not on a shared form.
(4) resemblance nominalism is dead on arrival because resemblance itself needs explaining, and explaining it by another resemblance just regresses.
(5) lately i've been playing with this idea i call partial instantiation: some universals (especially social/political ones like being-democratic) arent fully present in any one country but are distributed across instances, so each democracy instantiates only a slice. i dont know if this is compatible with (2).
(6) i think universals are sparse — theres no universal for being a shoe or being on a tuesday — but i'm not sure my sparsity criterion can distinguish (3) from (5) without being ad-hoc.

is this consistent? specifically: which pairs actually pull against each other, which only look bad but dissolve on inspection, and whats the least costly single revision? please rank tensions by severity rather than listing them all as equally bad.
