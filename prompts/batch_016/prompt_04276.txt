I'm a software engineer (I mostly work on distributed systems, so I have a professional soft spot for consistency guarantees), and I've recently been reading through AI alignment discussions online where people invoke so-called "coherence theorems" to argue that any sufficiently capable agent will end up behaving as if it has transitive preferences, since otherwise it could be money-pumped. The classic version of that argument goes: if an agent prefers A to B, B to C, and yet C to A, someone holding all three goods can walk it around the cycle — trade its C for a B it prefers, that B for an A it prefers, then that A back for a C it prefers — charging a small fee at each step, until the agent has paid three fees and is holding exactly the good it started with.

That seems like a solid argument against a short-sighted agent, but I don't see why it says anything about the preferences themselves being irrational. If the agent has any memory of the trades it's already made, surely it notices, on that last step, that taking the trade just returns it to its starting good at a strict loss, and it can simply decline — no need to revise the A/B/C ranking at all, just refuse to close the loop. So exploitability looks to me like a fact about naive behavior strung out over a sequence of trades in time, not a fact about which preferences a rational agent can coherently hold at a single moment. It seems like people treat the money-pump argument as settling something about the "shape" a rational preference ordering must have, when really it only seems to constrain how a forgetful agent behaves over time.

Given that, am I right that a sufficiently foresighted, memory-equipped agent could just keep its cyclic preferences and route around the pump indefinitely — meaning these "coherence" arguments (for AI systems, or for rational agents generally) are considerably weaker than advertised? Or is there a version of the argument that still forces transitivity even once you grant the agent perfect foresight and memory?
