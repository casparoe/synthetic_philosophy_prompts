I'm part of an informal reading group (mostly economics and computer-science grad students, plus a couple of us who are just enthusiasts) that spent its last two meetings on Moshe Tennenholtz's 2004 paper on "program equilibrium." The paper asks what happens if, instead of committing to an ordinary strategy, players in a game submit computer programs that get to read each other's source code before acting; Tennenholtz shows this lets you sustain mutual cooperation as a genuine Nash equilibrium even in a one-shot Prisoner's Dilemma, via a program that cooperates only when it finds itself looking at an exact copy of its own code. Two people in the group, Jonah and Naomi, got into a long argument about how much this result actually buys you, which spilled into the following week and got fairly technical. Since nobody else in the room has a background in mathematical logic, none of us could tell who was landing real points and who wasn't, so I've written up the exchange as faithfully as I can, in the order it happened:

(1) Jonah said this is a genuine answer to the classical pessimism surrounding the one-shot Prisoner's Dilemma: because neither player can gain by unilaterally submitting a different program, mutual cooperation becomes stable without repetition, reputation, or outside enforcement. (2) Naomi objected that the trick only works between byte-for-byte identical programs: it would defect against a completely different but equally cooperative piece of code, and even a one-character edit to the program breaks the arrangement entirely, so it isn't recognizing trustworthiness at all, just recognizing its own reflection — which she likened to calling nepotism 'trust.' (3) Jonah replied that this objection proves too much, since tit-for-tat in repeated games also rewards a narrow, specific pattern rather than 'niceness in general,' and an equilibrium was never supposed to certify moral virtue anyway; what's genuinely surprising, he said, is that pure self-interest alone stabilizes cooperation with no history and no kinship involved. (4) Naomi proposed an apparent fix: instead of comparing source code directly, have each program simulate what the other program would do when handed a copy of its own code, and mirror the result, so that two independently written but equally cooperative programs could recognize each other without being identical. (5) Jonah countered that this cannot work even in principle: if program A's move depends on finishing a simulation of B (which requires knowing what B does when shown A), and B's move symmetrically depends on finishing a simulation of A, neither simulation ever terminates — she had smuggled the halting problem back into the game. (6) Naomi answered that this is exactly why you shouldn't simulate at all, and should instead have each program search for a formal proof that the other cooperates with it, cooperating only if it finds one within some bound; two copies of such a program don't need to simulate forever, because — by a result called Löb's theorem — a short proof that one of them cooperates is enough to license a matching proof about the other, so the search bottoms out instead of looping. This, she said, is what actually rescues the kind of cooperation Jonah was defending in (3), now extended to agents that aren't identical. (7) Jonah granted the logic but pointed out that it only helps agents that already share a formal proof system and search depth: two 'find-a-proof-and-reciprocate' programs built on different logics aren't guaranteed to find each other's proofs, so defection becomes the default again — meaning the 'must be identical' requirement hasn't disappeared, it has just moved from the source code up to the logic the code runs on. (8) Naomi conceded the cost but argued it's a far cheaper kind of sameness to arrange than exact code identity: plenty of independently written programs could end up sharing a proof system, the way plenty of independently cut keys fit one lock, whereas sharing an entire source file by accident essentially never happens — so treating the two requirements as equally restrictive, which she thought Jonah was doing, understates how much progress had actually been made.
