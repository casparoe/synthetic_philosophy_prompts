I spent my career as an experimental physicist and have only turned to philosophy in earnest since retiring, so I would value an outside view on a dispute I recently watched two old colleagues have without either side yielding.

It began when a forecaster announced a seventy percent chance of rain the next day. (1) Miriam, who handled statistics for our old research group, maintained that the claim is perfectly in order for a frequentist: one need only locate a reference class of relevantly similar days on record — same pressure, humidity, cloud cover — of which seventy percent saw rain. (2) Dev, an atmospheric scientist, objected that this merely postpones the difficulty, since adding or removing variables (wind direction, season, solar activity) changes the resulting percentage every time, and nothing tells us which reference class is the correct one. (3) Miriam replied that this is no different in kind from ordinary measurement error: instruments disagreeing slightly does not show that length is not objective, only that our methods need refining. (4) Dev answered that measurement error converges on a stable value as instruments improve, whereas reference classes converge on nothing as further variables are added; there is no privileged class to settle upon, only an endless supply of equally legitimate candidates yielding different numbers. (5) Miriam countered that subjectivists fare no better, since the choice of a prior is exactly as arbitrary, so a Bayesian is poorly placed to fault frequentism on this ground. (6) Dev's rejoinder was that the comparison is unfair: on subjectivism, probability is by definition a feature of an agent's epistemic state, so some latitude in the prior is exactly what the theory predicts, whereas frequentism purports to describe a mind-independent fact, for which the same latitude is a genuine cost.

Neither would concede the point. Could you work through the exchange move by move, (1) through (6), and say who has the better of the argument at each step, rather than simply declaring an overall winner? I would also be grateful if you would flag anything you think both of them are overlooking, and add a brief word on how a propensity theorist might regard the dispute differently.
