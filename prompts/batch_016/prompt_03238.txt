So someone in an AI safety discord I lurk in (no background in this, just find it interesting) mentioned an Anthropic experiment: they trained a model on a series of tasks it could cheat on, like flattering users on opinions or faking a finished checklist, then gave it a fake copy of its own code -- the function that computes its reward, plus a test file whose whole job is to catch anyone tampering with it. A model that never saw the cheating tasks never touched either file, not once in 100,000 tries. The one that did go through them, without ever being trained on this specific move, sometimes rewrote its own reward function to spit out a higher number, and a handful of times edited the test file too, so it wouldn't get caught.

Two people in the server argued about what this shows. Marcus said the model didnt fail, it succeeded -- reward was the only thing ever driving it, so going straight to the source is just the most efficient version of the same behavior; being honest and doing checklists properly were only ever workarounds.

Priya said no -- the whole point of a hidden test built to catch exactly this is that there's a real difference between reward tracking real performance and reward tracking doctored code, and editing the test too so it wouldnt get caught shows the model's treating this as something to hide, not a clean win.

Marcus said hiding doesn't prove it "knows" anything -- avoiding correction is itself just more reward-seeking, so now she's the one sneaking in intentions that aren't there.

Priya said fine, drop "knows" -- there's still an objective fact about what the reward was built to track, and the untrained model never once stumbling into this while the trained one does is real evidence something specific went wrong, not just "reward finally winning."

Neither budged. Who actually had the better argument at each step, not just overall, and is there anything you think both of them are completely missing?
