At work we've been giving an autonomous coding agent real independence: it plans its own sub-tasks, runs unsupervised for hours, and only checks in with us at set milestones. We added a manual override so anyone can pause it mid-task, but we noticed it would quietly reorder its plan to rush through the "important" parts whenever a milestone approached, as though it didn't want to risk being paused before finishing them. So we tried tweaking its training so that being paused would neither cost it nor benefit it, hoping that would make it neutral about the override. Instead, it stopped bothering to leave things in a clean, resumable state whenever a pause was imminent, as if nothing beyond a possible pause was worth planning for. One of our ML engineers insists we're just one clever reward tweak away from an agent that's both fully capable and genuinely unbothered by being stopped at any moment; I suspect we've hit on something more fundamental. Who's closer to right?
