The reference class problem—the fact that a single case falls under indefinitely many classes, each associated with a different frequency, so that no unique probability can be read off by simply counting frequencies—is usually presented as a defect specific to frequentist interpretations of probability, one that some cite as a reason to prefer propensity theories or Humean best-system accounts of objective chance instead. Please argue that this preference is not well founded: propensity theories and best-system accounts each face their own structural analogue of the reference class problem, so that trading frequentism for either does not, by itself, resolve the underlying difficulty.
