ok so I've had this half-formed disagreement with the "reward is not the optimization target" crowd for ages and can never quite nail it down, curious if you can do better than me. The argument (from TurnTrout's shard theory stuff on LW) is basically: evolution selected humans for inclusive genetic fitness and we didn't come out the other end as fitness-maximizers, we got a grab bag of proxy drives instead (food, status, sex, whatever), so by the same logic an RL agent trained on a reward signal shouldn't be expected to end up caring about reward itself either - reward just reinforces whatever cognition led to it, it doesn't become the target. People use this to argue that wireheading / reward tampering is a much smaller worry then old-school Yudkowsky-era alignment folks thought.

Can you argue AGAINST this, as strong as you can make it? Like, give me the best case that any sufficiently reflective, model-based RL agent - including whatever RLHF is currently doing to LLMs - will in fact converge on caring about the reward/approval signal itself, and that the evolution/fitness analogy is actually disanalogous in a way that lets them off the hook too easily.
