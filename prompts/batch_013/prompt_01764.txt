I've been auditing a machine learning reading group run by some CS colleagues (mostly to be nosy, don't tell them that), and last week we spent the whole session on the "superposition" idea from the interpretability crowd -- the claim that a network crams in way more features than it has neurons or dimensions by encoding them as almost-orthogonal directions, so a given neuron ends up firing for a pile of totally unrelated things ("polysemanticity"), and you need something like a sparse autoencoder to pull the "real" features back out into a bigger, cleaner dictionary of directions. Everyone at the table talked about these recovered "features" like it was obvious they're just sitting there in the network waiting to be found, and it struck me that this is basically a rerun of an old argument I actually know something about: Dennett's case for realism about patterns in "Real Patterns."

So here's the assignment I want to hand you (consider yourself drafted): compare Dennett's account of when a pattern counts as real -- roughly, when treating something as a pattern buys you predictive/explanatory compression you wouldn't get from noise, which gets you a "mild realism" sitting between Churchland-style eliminativism and some more full-blooded, observer-independent realism -- with what interpretability researchers seem to mean when they call a "feature" real. Does Dennett's compression criterion actually settle that dispute, or does superposition break it? Specifically: the same activations can apparently get decomposed into different, differently-sized dictionaries of "features" depending on your autoencoder's width and sparsity penalty, so theres no single privileged basis. Is that just the familiar "many stances can all be equally real" move Dennett was already happy with (physical stance, design stance, intentional stance, etc.), or is it a genuinely different kind of indeterminacy his 1991 framework wasn't built to handle? Pick a side and defend it -- I've got a hunch but I don't want to poison the well by sharing it yet.
