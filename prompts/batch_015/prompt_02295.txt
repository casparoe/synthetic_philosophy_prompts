My instinct as a dev was always that vague predicates like "heap" or "bald" basically work like fuzzy logic -- truth value slides continuously from 0 to 1 as you pull grains out, kinda like a sigmoid. But apparently some serious philosophers (Williamson's the name that keeps coming up) think that's wrong -- that there's actually one exact, sharp cutoff, like precisely 4,382 grains, where it flips from heap to not-heap, and we just can never know where that cutoff is.

Could you write a dialogue between an epistemicist and a degree-theorist (basically the fuzzy logic take) hashing this out? I want them to really dig into the weak spot in each view -- for the epistemicist, what could possibly fix that exact boundary if nothing about how we actually use the word "heap" pins it down that precisely, and for the degree theorist, whether "degrees of truth" actually solves anything or just relocates the same sharp-cutoff problem one level up (isn't there presumably gonna be a sharp line between degree 1 and everything below it?). don't let either one strawman the other, i want to see them actually respond to each other's best points, not just talk past each other.
