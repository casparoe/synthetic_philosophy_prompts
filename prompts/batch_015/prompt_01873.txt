As a software engineer, my instinct has always been that DNA is "code" in a fairly literal sense: a discrete four-symbol alphabet, triplet codons functioning like words, and a fixed lookup table mapping them onto amino acids, which struck me as structurally similar to a text-encoding scheme. But I recently ran into a philosophy-of-biology objection I can't easily wave away: a genuine code (Morse code, ASCII, a natural language) requires an arbitrary symbol-referent mapping that is conventional in something like David Lewis's technical sense of convention — sustained by mutual expectations among users who could have coordinated on a different scheme but didn't. On this objection, the genetic "code" has contingency but not conventionality. Crick's frozen-accident hypothesis says the codon table could easily have been assigned differently, and this is borne out empirically: mitochondria and several other lineages have in fact reassigned individual codons over evolutionary history. But none of this involves a population of users who settled on one scheme while being able to settle on another. A frozen accident inside a causal mechanism, the objection goes, just isn't the same kind of thing as a convention, so calling DNA a code smuggles in more than the biology actually licenses.

I'd like you to argue against this: make the strongest case you can that the genetic code really is a code and not merely a metaphor imported from cybernetics, engaging directly with the contingency-versus-convention distinction rather than sidestepping it.
