Had a long argument with a friend last night about the Lucas-Penrose thing (it came up because we got into it over whether an LLM could ever really "get" math the way a person does), and I think I won — want a sanity check before I gloat about it. My move: take any formal system F that's supposed to capture everything I can prove. Gödel gives us a sentence for F that's true but that F itself can never prove. I can see from outside that its true, because I know F is consistent - my own reasoning obviously doesn't prove contradictions, so whatever system represents me has to be consistent too. So for any F you hand me, I can do one better, meaning I can't be fully captured by any formal system or algorithm. He kept saying "but how do you actually know F is consistent" like it was some huge gotcha, but that just sounds like question-begging skepticism to me, not a real objection. So who actually wins this, me or him?
