So I've been chewing on this idea that pops up a lot in rationalist blogs and forums: that paltering (misleading someone using only technically true statements) is basically fine, since the false impression comes from the listener's own inference, not from anything you actually asserted. This seems to line up with Grice pretty well—he's explicit that implicature isn't part of "what is said", its worked out by the hearer using the maxims plus context. So doesn't that mean I'm off the hook for a false impression as long as I never technically say the false part, since the implicature was the listener's inference and not something I meant? Or is there something about how Grice actually treats implicature that blocks this move?
