For context: program equilibrium, in the sense introduced by Tennenholtz, is the idea that if players in a game like the one-shot Prisoner's Dilemma submit programs rather than bare actions — programs permitted to read one another's source code before choosing a move — cooperation can become stable in exactly the situations where ordinary game theory says it can't. The specific construction I'd like the joke to hang on, if it can be managed gracefully, is the Löbian one: a program commonly called FairBot that cooperates with any program it can prove will cooperate with it in turn, so that two copies of FairBot facing each other provably cooperate, each having established the other's cooperation before either has to commit to acting — which is also how the construction sidesteps the infinite regress that a cruder "simulate them simulating you" approach would collapse into.
